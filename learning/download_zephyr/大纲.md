# 第1章\_Zephyr\_下载与环境准备阅读大纲

本专题回答一个连续的问题：为 HC32 准备 Zephyr 时，怎样先获得必需内容，再按需要补齐版本管理和构建环境？原有六篇讲解全部保留，按主题分组收纳小节；每章首部提供可点击目录。

操作前先读[环境与目录约定](环境与目录约定.md)和[代理配置](代理配置.md)。本专题的下载实验与当前已集成的 HC32 工程分开；初次安装终端可先读[UCRT64 入门主线](../P01_zephyr_make_project/大纲.md)。

## 1.1\_阅读路线

```text
P01 下载范围：哪些东西需要下载，哪些可以延后
  ↓
P02 Git 基础：历史、工作区与文件对象分别是什么
  ↓
P03 ZIP 路线：先取源码，再按需接回版本管理
  ↓
P04 清单解析：按版本、路径、架构和功能选择模块
  ↓
P05 SDK：选 Windows 主机包与 ARM 目标工具链
  ↓
P06 Host 环境：UCRT64、Windows Python、构建工具与离线包
```

P01 给出整体地图，其中 Git 参数不熟悉时可以先读 P02，再回来比较优化方案。P03—P06 沿同一个独立实验目录继续准备；当前集成工程的实际安装仍按[项目环境说明](../../project-docs/environment.md)执行。
