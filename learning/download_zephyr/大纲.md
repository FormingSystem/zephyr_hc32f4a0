# 第1章\_Zephyr\_下载与环境准备阅读大纲

本专题回答一个连续的问题：为 HC32 准备 Zephyr 时，怎样先获得必需内容，再按需要补齐版本管理和构建环境？六篇讲解按章节组织，每章首部提供可点击目录；P005 已按版本依据、下载、工程接入与实际编译重写。

操作前先读[环境与目录约定](环境与目录约定.md)和[代理配置](代理配置.md)。本专题的下载实验与当前已集成的 HC32 工程分开；初次安装终端可先读[UCRT64 入门主线](../P01_zephyr_make_project/大纲.md)。

## 1.1\_阅读路线

```text
P001 下载范围：哪些东西需要下载，哪些可以延后
  ↓
P002 Git 基础：历史、工作区与文件对象分别是什么
  ↓
P003 ZIP 路线：先取源码，再按需接回版本管理
  ↓
P004 清单解析：按版本、路径、架构和功能选择模块
  ↓
P005 SDK：查版本依据，下载工具链，连接源码并编译
  ↓
P006 Host 环境：UCRT64、Windows Python、构建工具与离线包
```

P001 给出整体地图，其中 Git 参数不熟悉时可以先读 P002，再回来比较优化方案。P003—P006 沿同一个独立实验目录继续准备；主线操作位置为 `G:\zephyr_practice\zephyr-main`。
