# 下载前配置本地代理

本例采用 v2rayN 的“本地混合监听端口 `10808`、第二个本地监听端口未开启”配置。先启动客户端并核对实际端口；本例的 HTTP 代理入口是 `http://127.0.0.1:10808`，不要用 `10809`、PAC 端口或 API 端口代替。

在 UCRT64 中配置并检查 Git：

```bash
# 任意目录；写入当前用户的 Git 配置。
git config --global --replace-all http.proxy http://127.0.0.1:10808
git config --show-origin --get-all http.proxy
```

查询结果应包含 `http://127.0.0.1:10808`。开头的 `http://` 表示连接本地代理使用的协议，目标 GitHub 地址仍然使用 HTTPS。Git 的 [`http.proxy`](https://git-scm.com/docs/git-config#Documentation/git-config.txt-httpproxy) 同时用于 HTTP 与 HTTPS 请求，不需要另设 `https.proxy`；曾误设该键时可用 `git config --global --unset-all https.proxy` 清除，键不存在时无需处理。

下载前先测试一个小请求：

```bash
# 任意目录；终端：UCRT64。
curl -I -x http://127.0.0.1:10808 https://github.com
git ls-remote https://github.com/zephyrproject-rtos/zephyr.git HEAD
```

curl 通常先显示 `200 Connection established`，还应继续看到 GitHub 的 HTTP 响应；Git 成功时返回“提交号 + HEAD”。两者只证明本次小请求成功，不保证大体积下载一定不会中断。

**浏览器下载 ZIP 或 SDK 压缩包时，还需在 v2rayN 开启系统代理，或让浏览器使用同一代理入口。** Git 配置不会替浏览器、curl 或 pip 设置代理；上面的 curl 通过 `-x` 单独指定入口。完整下载操作继续参照所在章节。
