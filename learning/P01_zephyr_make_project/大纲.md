# 第1章\_Zephyr从准备到构建

先准备源码、主机工具和 SDK，再由芯片与当前架构规则确认 CMSIS。随后用官方工程解释驱动模型和硬件配置如何连接，理解以后再为 HC32 引入 DDL 与外部适配，最后进入构建专题。CMake 从普通 C 程序起步，然后解释 Zephyr 应用；west 单独从工作区基础讲到 Zephyr 扩展及 CMake 调用。接口发现与缓存按各自问题另成册，新增板实验最后进行。
