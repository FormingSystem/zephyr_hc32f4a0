Linux 读者从 [Ubuntu 22.04 官方环境安装与源码准备](P001_官方环境安装与源码准备_Linux.md) 开始，配套 [Linux PPT](slides/P001_官方环境安装与源码准备_Linux.pptx) 为 21 页。Windows 主线默认 UCRT64，官方要求的 Windows 安装与 setup.cmd 使用 PowerShell。

Windows 实验在 G:/zephyr_practice/zephyr-main 完成；环境与依赖的输入关系见 [导航](环境与依赖导航.md)，工具来源见 [官方安装依据](主机工具与官方安装来源.md)。P007 中沿用的 p003 构建目录是实验标识，正文已交代，不需要迁移已有实验产物。

P003 的 MD 提供 [配置与构建](P003_Zephyr的CMake接口体系_Windows.md#cmake-build-methods)、[缓存操作](P003_Zephyr的CMake接口体系_Windows.md#cmake-cache-practice)和[本章结果自查](P003_Zephyr的CMake接口体系_Windows.md#cmake-result-check)。首次阅读先理解关系，依赖齐全后再操作；执行前提与 PPT 对应页码均在正文入口列出。
