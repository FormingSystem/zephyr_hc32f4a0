# 第1章\_Zephyr从准备到构建

## 1.1\_与官方译文对照阅读

本专题是带实验步骤的项目教程，官方概念和接口可从[官方主线译文](../zephyr_docs/reading/README.md)核对。译文按各页标注的 `latest` 抓取日期保存，本专题的源码分析则引用固定修订 `25c8f4a23988dd3b2cfb463613622738298c2d6c`；二者不能自动视为同一源码版本。发现差异时，先确认所用源码、SDK 与工具版本，再核对本次构建实际读取的规则。
