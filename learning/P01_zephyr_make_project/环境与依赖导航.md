# 第1章\_环境与依赖导航

尚未确定是否采用 Zephyr 时，先读 [P001 认识 Zephyr 与技术选型](P001_认识Zephyr与技术选型.md)，明确希望复用的能力与待验证条件。已经确定路线的读者可直接进入下面的工程与环境准备。

先读[工程布局与构建全景](P002_工程布局与构建全景.md)，建立应用、架构支持、SoC 适配、板配置与模块的关系，再选择本机环境。硬件职责见 [P002 2.3](P002_工程布局与构建全景.md#hardware-layers)；下载源码后，从 [P010 10.1 的文件定位](P010_工程分层与驱动模型.md#target-to-files)核对 MPS2 的实际目录，该节的只读定位不要求已经构建固件。

| --- | --- | --- |

[SDK 准备](P005_SDK准备与编译器选型.md)、[源码依赖与离线准备](P006_源码依赖与离线准备.md)、[完整构建流程](P008_选择应用与硬件目标并构建.md)。

只有源码 ZIP 时不必恢复 Git 历史，但要另备同修订模块。只能连接公司内部 Git 时，复用公司的依赖来源和清单；主源码改用内部地址不会自动改变全部模块地址。P006 先解释这些背景，再让读者选择已有的 Git 或归档操作；材料已经齐全就直接核验并进入构建。完全离线还要带齐主机包、Python wheel 与 SDK。第一次构建固定 hello_world + mps2/an386，成功后按[大纲](大纲.md)继续。

<a id="hal-origin"></a>

需要接入华大厂商库时，先完成已有目标构建，再读 [HC32 与外部源码模块接入](P014_HC32与外部源码模块接入.md)。它说明厂商来源、固定修订、HAL 与板/SoC 适配的分工。

<a id="chip-selection"></a>
<a id="board-layout"></a>

芯片与板的选择先从 [P002 的硬件目标关系](P002_工程布局与构建全景.md) 理解，再在 [P008](P008_选择应用与硬件目标并构建.md) 选择实际受支持的 BOARD。需要新增板、SoC 或驱动时进入 [P015](P015_新增开发板与芯片支持.md)，不能只改芯片宏。
