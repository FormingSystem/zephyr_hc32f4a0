# 第1章\_环境与依赖导航

先完成 P002 主机/Python 与 P003 SDK；随后按三步推进：P004 从已知芯片和当前架构接入规则确定 CMSIS 并下载，P005 用官方 MPS2 工程讲清设备树、Kconfig、CMake 与驱动模型，P006 再引入 HC32 的厂商 DDL、板/SoC 适配与外部模块。每一步都说明当前有什么、缺什么以及如何判断结果，之后再进入 CMake 和 west 的独立专题。

```mermaid
flowchart TD
    A["P001 源码准备"] --> B["P002 主机工具与 Python"]
    B --> C["P003 SDK 与编译器"]
    C --> D["P004 CMSIS 选择与下载"]
    D --> E["P005 工程组织与驱动模型"]
    E --> E6["P006 HC32 / DDL 与外部模块接入"]
    E6 --> F["P007 原生 CMake 与目标模型"]
    F --> G["P008 Zephyr 应用构建"]
    G --> H["P009 west 零基础与 Zephyr 构建"]
    H --> I["P010 CMake 输入与依赖发现"]
    I --> J["P011 缓存与构建排错"]
    J --> K["P012 编译示例与新增板"]
```

完整入口和页数见 [大纲](大纲.md)。本页保留旧定位锚点，分别跳到拆分后的正文；它们不是另一套待执行流程。

配套 PPT 用橙色区分变量、参数和配置字段，蓝色表示文件或路径，绿色表示接口函数，紫色表示终端命令；每册前部有图例。颜色只帮助辨认对象，命令仍需结合正文的终端、目录和前提阅读。Markdown 使用行内代码与带语言的代码块，由阅读器适配明暗主题；长操作也可从各章命令索引打开完整 TXT 复制。详细样式约定见 [演示资料维护](slides/README.md#semantic-colors)。
