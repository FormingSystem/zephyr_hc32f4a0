# 第3章\_二进制与数字电路：案例与推演

先读[关系与模型](P001_关系与模型.md)与[原理与实现](P002_原理与实现.md)。下面把已建立的对象放进具体输入，先预测再核对；纸面结果与真实芯片观察分别说明。

## 3.1\_把波形变成状态表

假设复位优先于使能，初始 Q=14。连续四个时钟沿的 `(复位, EN)` 为 `(0,1)、(0,1)、(0,0)、(1,1)`。在纸上为每个沿填入“沿前 Q、D、沿后 Q”。

| 沿 | 沿前 Q | D 的选择 | 沿后 Q |
| --- | --- | --- | --- |
| 1 | 14 | 递增得到15 | 15 |
| 2 | 15 | 截断后的0 | 0 |
| 3 | 0 | 保持0 | 0 |
| 4 | 0 | 复位优先，取0 | 0 |

把第二沿的 EN 改为 0，第二、第三沿后都应是 15。若得出 0，说明仍把加法器候选值误当成了寄存器状态。纸面推演只验证逻辑功能，不验证建立保持时间或电气质量。

## 3.2\_用 C 模型核对有限位宽

```c
/* 4位计数器模型；unsigned 不模拟电路传播延迟。 */
unsigned next_count(unsigned q, unsigned enable, unsigned reset)
{
    if (reset) return 0u;
    return enable ? ((q + 1u) & 0xFu) : q;
}
```

用 `next_count(15,1,0)` 核对截断，用 `next_count(15,0,0)` 核对保持，用 `next_count(15,1,1)` 核对复位优先级。分别应得到 0、15、0。不能删去掩码后仍称它为 4 位模型；C 的 unsigned 通常比四位宽，语言运算宽度不等于正在模拟的硬件宽度。
