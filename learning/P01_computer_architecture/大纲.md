# P01\_计算机组成与MCU架构

按下按钮后，芯片怎样读到它、执行判断并点亮指示灯？当显示、采样和通信都在进行时，CPU 又怎样安排这些工作？本专题沿这些具体过程学习计算机组成原理，以 STM32H743 把抽象角色落实到真实芯片，再通过汇编、链接镜像和栈解释执行过程。

读者可以具有基础 C 编程经验，但无需预先掌握芯片架构、汇编或 RTOS。第一部分先讲 CPU 寄存器、寻址、对齐、栈堆、向量表和编译过程，直接用 C 与实际 Arm 指令对照；第十二章准备工具，再亲自生成这些结果。没有开发板也能完成编译与镜像观察，涉及电气连接、烧录和实板调试的步骤另有明确前提。

## 1.1\_沿着一个控制面板逐步深入

第一部分 P001—P008 建立“电路 → CPU 内部状态 → 字节地址与访问 → 芯片存储 → 程序布局 → 入口表 → 编译镜像”的关系。P009—P011 用 GPIO、串行外设和中断演变真实工作流程。P012—P016 亲自编译、观察函数调用、生成启动镜像并解释异常返回，最后讨论 DMA、保护和 RTOS 如何组合已有硬件能力。

## 1.2\_材料、工具和芯片分别到哪一步才需要

前十一章提供就地观察材料，不要求已下载厂商工程；其中前八章已把汇编、构建与入口的基本关系讲通。第十二章安装或选择 Arm 工具，再生成自己的中间文件与反汇编；第十四章手写函数调用，第十五章组合完整启动文件与链接脚本。正文中每个新文件均说明来源和产生步骤。

自有实验原件放在 [labs](labs/README.md)，图放在 `assets/` 并用相对路径引用。复制到自己的练习目录后，生成文件进入练习目录的 `build/`；不要覆盖教材原件，也不必在 Zephyr 源码目录中做这些计算机组成实验。

具体芯片选 H743 单核分支，容量示例以 H743xI 为主。PC13 按钮和 PB0 输出是教学接线约定，不冒充某块开发板的原理图。官方资料的身份和阅读位置见 [资料与阅读方法](资料与阅读方法.md)，各章的关键结论旁仍有就近对照。

## 1.3\_怎样判断自己真正理解了

每章包含能够手工预测或实际观察的问题。遇到新对象时，先回答它保存什么、谁改变它、谁读取它、什么时候完成一次交接。读图时按颜色和编号跟踪同一事件，不把两个并列方框自动理解成两个能独立执行软件的 CPU。

读完后可以拿一段陌生 MCU 程序，沿“板级信号 → 外设状态 → 总线访问 → 指令执行 → 栈与异常 → 软件调度”寻找证据。换芯片时重新核对地址、路由、时钟、存储和勘误；已经建立的层次模型继续使用。
