# P01\_计算机组成与 MCU 架构

从一个按钮怎样改变一盏灯开始，沿着电路、CPU、地址、外设、中断和线程逐步进入系统内部。以 STM32H743 为具体芯片例子，C 语句、汇编、寄存器与存储地址在同一条执行过程中相互对应。
