# P001\_从按键和指示灯认识计算机

[P01 总目录](../大纲.md) · [开始阅读：电平怎样变成一次按键操作](P001_电平怎样变成一次按键操作.md)

一次按键操作要经过电压、输入位、程序判断和输出电流，不能把这些步骤都当成“变量变成1”。先沿实际路径认清各对象，再用持续按下和机械抖动说明程序为什么必须保存历史、观察时间。读完后应能区分电平、边沿与业务事件，并沿路径定位灯不亮的问题。

本专题从日常按键操作开始，不要求已掌握芯片术语。
