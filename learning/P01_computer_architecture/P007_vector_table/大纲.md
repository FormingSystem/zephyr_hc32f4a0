# P007\_复位与中断向量表

[P01 总目录](../大纲.md) · [开始阅读：从IRQ号计算处理入口](P001_从IRQ号计算处理入口.md)

中断编号不是处理函数地址，向量表中的一个槽位也不是一段处理代码。沿IRQ号到异常编号、表项地址和入口值逐步计算，再把复位时的初始MSP与入口放回同一张表。最后讨论搬移与默认处理函数：能找到一个函数符号，还必须确认实际向量表真的引用了它。

需要的前置认识：[P003 CPU怎样执行指令](../P003_cpu_execution/大纲.md)、[P004 地址总线与存储器映射](../P004_addressing/大纲.md)、[P006 程序内存布局与栈堆](../P006_memory_lifetime/大纲.md)。已有相应基础时可以直接从本专题第一篇开始。
