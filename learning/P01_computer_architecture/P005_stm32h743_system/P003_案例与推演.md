# 第3章\_走进STM32H743芯片架构：案例与推演

先读[关系与模型](P001_关系与模型.md)与[原理与实现](P002_原理与实现.md)。下面把已建立的对象放进具体输入，先预测再核对；纸面结果与真实芯片观察分别说明。

## 3.1\_为显示发送缓冲选择位置

场景是 CPU 填充一段像素，DMA1 从内存读出并送给串行外设。先比较 DTCM 与 AXI SRAM 两个候选，而不是直接写 DMA 寄存器。

| 问题 | DTCM候选 | AXI SRAM候选 |
| --- | --- | --- |
| CPU能否按该工程布局访问 | 查链接区间与初始化 | 查链接区间与初始化 |
| DMA1路径是否存在 | 不能照搬CPU的TCM路径 | 继续按互连图核对可达性 |
| CPU可能只改了缓存副本吗 | 与AXI缓存路径不同 | 若可缓存则要处理一致性 |
| 链接结果是否真的放在这里 | 查map中的符号地址 | 同样查map，不能只看声明名字 |

把“CPU 能访问”“DMA 能访问”“数据已经对 DMA 可见”列成三个独立判断。前两个成立，第三个仍可能失败，这就是后续缓存专题要解决的问题。

## 3.2\_换芯片时重做哪些判断

拿到另一型号，先记录完整料号、封装与修订；再从存储器地图找容量和地址，从互连图找发起者到目标，从时钟树找各模块时钟。保留上述问题，重新填写答案。H743 的域划分不是所有 STM32 的共同结构，不能靠同属 Cortex-M7 就复制所有地址和 DMA 路由。
