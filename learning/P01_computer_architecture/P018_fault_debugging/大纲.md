# P018\_MPU故障与调试

[P01 总目录](../大纲.md) · [开始阅读：从非法访问建立故障证据链](P001_从非法访问建立故障证据链.md)

故障处理应从证据建立原因，而不是看到HardFault就猜某一行代码。先沿访问权限与目标路径认识故障来源，再判断状态寄存器、故障地址和异常栈帧是否有效。最后安排错误指针和保护实验，核对故障发生条件、保存现场及恢复边界。

需要的前置认识：[P004 地址总线与存储器映射](../P004_addressing/大纲.md)、[P007 复位与中断向量表](../P007_vector_table/大纲.md)、[P016 异常现场与中断返回](../P016_exception_context/大纲.md)。已有相应基础时可以直接从本专题第一篇开始。
