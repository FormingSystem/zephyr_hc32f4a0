# P015\_从上电复位到main

[P01 总目录](../大纲.md) · [开始阅读：复位怎样建立C运行环境](P001_复位怎样建立C运行环境.md)

芯片复位时，C语言所依赖的变量和运行库还没有自然就绪。先分清硬件启动选择、初始栈和复位入口，再建立data复制与bss清零的因果关系。链接脚本、启动汇编及镜像验证独立成篇，最后从独立上电失败回查初始化边界，避免用调试器留下的状态掩盖问题。

需要的前置认识：[P007 复位与中断向量表](../P007_vector_table/大纲.md)、[P008 从C源码到芯片镜像](../P008_build_pipeline/大纲.md)、[P012 建立汇编观察环境](../P012_assembly_tools/大纲.md)、[P014 函数调用与栈](../P014_calling_convention/大纲.md)。已有相应基础时可以直接从本专题第一篇开始。
