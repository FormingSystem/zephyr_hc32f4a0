# 第3章\_从上电复位到main：案例与推演

先读[关系与模型](P001_关系与模型.md)与[原理与实现](P002_原理与实现.md)。下面把已建立的对象放进具体输入，先预测再核对；纸面结果与真实芯片观察分别说明。

## 3.1\_逐字复制一份初始值

教学布局：Flash 的 `0x08001000` 保存 `19 00 00 00`，RAM 的 `0x24000000` 是 threshold 的运行位置。按小端解释，启动复制四字节后 threshold 才成为25。另设 bss 区间为 `[0x24000004,0x2400000C)`，应清零8字节。

先在纸上画复制前后的两块 RAM，故意把清零终点写为 `<= 0x2400000C`，观察会多写一个地址或一个字。链接脚本中的结束符号通常表示半开区间边界，循环应按所用步长与对齐正确处理。初始化错误会在 main 之前破坏邻接对象，不能只在 main 内排查。

## 3.2\_让镜像证据与运行证据分别成立

完成核心篇的最小启动实验后，在 ELF 中核对向量前两项、Reset_Handler 符号、data 的加载与运行地址，以及 bss 的起止符号。再将镜像内容与纸面布局对应。编译与链接能够证明这些产物存在，不能证明板上启动选项和供电符合要求。

实板前先备份原固件和必要配置，按板卡支持的调试方法验证。若复位后没有到 main，依次查看入口是否有效、MSP 是否位于可用 RAM、早期函数是否使用尚未初始化的数据、复制清零区间是否正确。不要为追踪启动随意改写不可逆的保护或选项字节。
