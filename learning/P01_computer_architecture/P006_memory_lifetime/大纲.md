# P006\_程序内存布局与栈堆

[P01 总目录](../大纲.md) · [开始阅读：对象寿命怎样落到RAM布局](P001_对象寿命怎样落到RAM布局.md)

变量、栈和堆最终都占用存储空间，但它们的建立时机、寿命和管理者不同。从镜像与运行时布局开始，解释data、bss、调用栈和动态分配，再推演返回后的对象失效及堆碎片。用地址变化核对SP，用对象寿命核对指针，避免把“还有这个地址”当作“仍有合法对象”。

需要的前置认识：[P004 地址总线与存储器映射](../P004_addressing/大纲.md)。已有相应基础时可以直接从本专题第一篇开始。
