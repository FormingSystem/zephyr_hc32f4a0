# P008\_从C源码到芯片镜像

[P01 总目录](../大纲.md) · [开始阅读：源码到下载镜像的工具分工](P001_源码到下载镜像的工具分工.md)

一份C文件不能直接交给芯片运行。本专题按预处理、编译、汇编、链接和镜像交付解释每个工具接收什么、生成什么，特别区分主机可执行程序与目标机器码。用跨文件函数调用追踪符号和重定位，遇到构建失败时先判断停在哪一阶段，再查相应输入。

需要的前置认识：[P003 CPU怎样执行指令](../P003_cpu_execution/大纲.md)、[P004 地址总线与存储器映射](../P004_addressing/大纲.md)、[P007 复位与中断向量表](../P007_vector_table/大纲.md)。已有相应基础时可以直接从本专题第一篇开始。
