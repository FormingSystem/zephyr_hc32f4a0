# P011\_从轮询到中断与NVIC

[P01 总目录](../大纲.md) · [开始阅读：事件请求挂起与中断仲裁](P001_事件请求挂起与中断仲裁.md)

轮询依靠CPU再次读取状态，中断则让事件经请求、挂起和仲裁进入处理路径。先认清外设与NVIC各自保存的状态，再解释使能、屏蔽、优先级和嵌套。案例同时检查响应时间与队列容量：更快进入ISR不能替代正确保存数据，也不能消除缓冲溢出。

需要的前置认识：[P007 复位与中断向量表](../P007_vector_table/大纲.md)、[P009 GPIO时钟与轮询程序](../P009_gpio_polling/大纲.md)、[P010 定时器与串行外设](../P010_peripheral_timing/大纲.md)。已有相应基础时可以直接从本专题第一篇开始。
