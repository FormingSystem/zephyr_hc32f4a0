# 计时与基准测试参考大纲

本册翻译计时测量（Timing Measurement）的公共、架构、开发板和片上系统接口，配套计时与类型头文件参考及源码，架构周期计数接口，以及基准测试（Benchmark）头文件参考与源码。另收录精确计时（Precision Timing）的分类页；它的三个子主题是独立条目，完整接口与源码见[精确计时参考册](../precision_reference/大纲.md)。合计十二份官方页面。

读取周期计数、换算纳秒与控制测量区间是不同操作；本册保留原接口、参数、回绕限制及同一CPU核心的约束。源码页保留全部可见代码、法律声明、原始行号锚点和符号提示，英文注释另列中文对照。源码跟踪译注补充实现选择、计数宽度、时间戳起点和基准测试迭代行为，并与官方正文区分。

基准测试宏的完整接口说明见[ZTest基准测试接口](../hardware/P501_ZTest基准测试接口.md)。本地源码使用相对链接，保留中英文术语；仓库环境与实验记录仍在独立资料区。完整范围见[全站进度](../PROGRESS.md)。
