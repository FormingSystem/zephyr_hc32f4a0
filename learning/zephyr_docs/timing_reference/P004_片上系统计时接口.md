## 4.2\_详细说明（Detailed Documentation）

<a id="ga58abe336c243b2edb34d77b8247ac9e2"></a>

### `soc_timing_counter_get()`

```c
timing_t soc_timing_counter_get ( void )
```

```c
#include <zephyr/timing/timing.h>
```

返回计时计数器（Timing Counter）的值。

说明（Note）：并非所有片上系统的计时计数器都具有 64 位精度。内部回绕（Rollover）可能使读数看起来“倒退”。计时代码必须处理回绕，例如采用片上系统相关代码，在相减前先转换为 `uint32_t`；也可以使用必须正确处理这种差异的 `soc_timing_cycles_get()`。

返回（Returns）：计时计数器的值。

另见（See Also）：`timing_counter_get()`。

<a id="ga97f010f79b60089b982d60d543e07660"></a>

### `soc_timing_cycles_get()`

```c
uint64_t soc_timing_cycles_get ( volatile timing_t *const start, volatile timing_t *const end )
```

```c
#include <zephyr/timing/timing.h>
```

获取 `start` 与 `end` 之间的周期数（Cycles）。

**参数（Parameters）**

| 名称／方向 | 说明 |
| --- | --- |
| `start` | 指向被测执行过程开始时计数器读数的指针。 |
| `end` | 指向被测执行过程停止时计数器读数的指针。 |

说明（Note）：计数器的原始数值需要换算才能得到实际周期数，也可能在内部回绕。此函数根据两次返回的周期值计算正向的时间间隔。

返回（Returns）：开始与结束之间的周期数。

另见（See Also）：`timing_cycles_get()`。

## 4.3\_源码定位与版本边界

相对源码定位：[SoC计时声明与公共包装](../../../include/zephyr/timing/timing.h)、[公共计时实现](../../../subsys/timing/timing.c)。官方源码摘要见[来源记录](../SOURCES.md)。

> 译注——源码核对：以下源码跟踪译注独立于官方正文，依据来源记录中保存摘要的官方main文件。源码定位使用相对链接；本地版本如有差异，应核对源码与来源摘要，不能把任意本地构建视为已经验证。

> 译注——源码核对：soc_timing_*只在没有开发板专用覆盖且CONFIG_SOC_HAS_TIMING_FUNCTIONS存在时被公共包装选择。SoC支持与板支持是两层配置，不能仅因公共函数声明存在就判断目标芯片已具备专用计时实现。

> 译注——源码核对：timing_t是uint64_t别名，只规定存储类型，不保证硬件计数器宽度为64位。计数器回绕（Wrap）应由对应timing_cycles_get处理；通用32位实现及本次Cortex-M实现通过uint32_t相减处理模运算，无法恢复两次读数间已丢失的多个完整回绕周期。

本次验证范围为文档与源码对照，未构建固件、配置实板引脚或操作硬件。
