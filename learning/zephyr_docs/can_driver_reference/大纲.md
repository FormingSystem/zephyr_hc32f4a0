# CAN驱动头文件参考大纲

本册完整翻译CAN（控制器局域网，Controller Area Network）控制器与收发器（Transceiver）头文件各自的参考页及源码浏览页，涵盖帧格式、过滤器、位时序、发送与接收、状态回调、错误统计和收发器控制。详细约定见[CAN控制器接口](../hardware/P362_CAN控制器接口.md)、[控制器后端](../hardware/P369_CAN控制器后端接口.md)、[收发器接口](../hardware/P041_CAN收发器接口参考.md)与[收发器后端](../hardware/P050_CAN收发器驱动后端接口.md)。

参考页保留声明与摘要，源码页保留全部可见实现、注释、行号定位和符号提示。源码跟踪译注说明DLC长度映射、发送等待、接收队列、时序计算、状态回调锁和GPIO收发器行为。原代码、许可证与中英文术语保留，仓库定位使用相对路径。完整范围见[全站进度](../PROGRESS.md)。
