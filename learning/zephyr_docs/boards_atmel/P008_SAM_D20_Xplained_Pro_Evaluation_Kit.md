## 概述（Overview）

SAM D20 Xplained Pro评估套件适合评估采用Cortex®-M0+处理器的SAM D20微控制器并制作原型。套件包含Atmel嵌入式调试器（EDBG），无需额外硬件即可提供完整调试接口。

<a id="hardware"></a>

## 硬件（Hardware）


- SAMD20J18 ARM Cortex-M0+处理器，48 MHz
- 32.768 kHz晶体振荡器（Crystal Oscillator）
- 256 KiB闪存（Flash）和32 KiB随机存储器（RAM）
- 一个黄色用户LED
- 一个机械式用户按键
- 1个复位按键（Reset Button）
- 板载基于USB的EDBG单元，提供串口控制台

<a id="system-clock"></a>

### 系统时钟（System Clock）

SAMD20 MCU使用32.768 kHz外部振荡器，经片上PLL生成48 MHz系统时钟。

<a id="serial-port"></a>

### 串口（Serial Port）

SAMD20 MCU有六个基于SERCOM的USART。其中SERCOM3连接板载EDBG，SERCOM4通过EXT1连接器引出。

<a id="spi-port"></a>

### SPI端口（SPI Port）

SAMD20 MCU有六个基于SERCOM的SPI。SAM D20 Xplained Pro的SERCOM0通过EXT1连接器引出。

<a id="flashing"></a>

### 烧录（Flashing）


1. 构建Zephyr内核和[Hello World](../getting_started/P005_HelloWorld示例.md#hello_world)示例应用：

  ```text
  west build -b samd20_xpro samples/hello_world
  ```
2. 通过USB调试端口将SAM D20 Xplained Pro连接到主机。
3. 运行你惯用的终端程序，监听输出。Linux下的终端设备应为`/dev/ttyACM0`，例如：

  ```text
  $ minicom -D /dev/ttyACM0 -o
  ```

  `-o`选项让`minicom`不发送调制解调器初始化字符串（Modem Initialization String）。连接参数应配置如下：


  - 速率（Speed）：115200波特率
  - 数据位（Data）：8位
  - 奇偶校验（Parity）：无（None）
  - 停止位（Stop Bits）：1位
4. 烧录镜像：

  ```text
  west build -b samd20_xpro samples/hello_world
  west flash
  ```

  终端应显示`Hello World! samd20_xpro`。
