# 字节序参考大纲

字节序（Byte Order）规定多字节值在内存或协议字段中的排列。系统辅助接口可转换整数、从可能未对齐的字节区读写字段，也可反转整个缓冲区；蓝牙辅助宏则产生固定大端（Big-endian）或小端（Little-endian）的逗号分隔字节列表。先根据输入与输出的形式选择接口，再决定目标字节序。

本册覆盖两个头文件的参考与可见源码，以及蓝牙字节序分组。原始声明、逐项参数、返回说明、45个宏展开块、全部代码和法律注释保留；源码译注说明主机顺序、窄字段位宽、重复求值、缓冲区重叠及零长度边界。所有本地定位采用相对路径，完整范围见[全站进度](../PROGRESS.md)。
