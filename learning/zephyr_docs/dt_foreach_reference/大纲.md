# 设备树遍历宏参考大纲

本册完整翻译设备树遍历宏（For-each Macros）页面，涵盖全树、祖先节点（Ancestor Node）、子节点（Child Node）、属性元素、兼容字符串（Compatible）、设备类别（Device Class）和节点标签（Node Label）。按所需节点范围选择宏，再确认回调参数、展开顺序、分隔符与嵌套限制。
