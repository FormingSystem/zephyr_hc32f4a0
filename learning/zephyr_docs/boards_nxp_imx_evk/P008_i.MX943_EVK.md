## 概述（Overview）

IMX943LP5EVK-19是基于NXP i.MX 943处理器的设计及评估平台。处理器最多集成4个Arm Cortex-A55核，另有2个Cortex-M33核和2个Cortex-M7核用于功能安全。通过可编程逻辑控制器（PLC）、I/O控制器、车联万物（V2X）加速器、机器学习（ML）加速、能源管理和先进安全功能，为工业、物联网及汽车设备优化性能与能效。原文列出板上i.MX943采用19×19 mm／15×15 mm紧凑封装。

<a id="hardware"></a>

## 硬件（Hardware）


- i.MX 943汽车应用处理器（Automotive Applications Processor）


  - 处理器最多集成4个Arm Cortex-A55核，并通过内置Cortex-M33和Cortex-M7核支持功能安全（Functional Safety）
- 动态RAM（DRAM）：8 Gbit LPDDR5
- XSPI接口：64 MB八线SPI（Octal SPI）NOR闪存
- eMMC：32 GB eMMC NAND闪存
- uSDHC接口：一个SD卡槽
- USB接口：两个USB Type-C端口
- 以太网接口：7个以太网端口
- PCIe接口：一个M.2插槽及一个PCIe x4插槽
- FlexCAN接口：4个CAN控制器及4个CAN连接器
- 低功耗UART（LPUART）接口
- 低功耗SPI（LPSPI）接口
- 低功耗I2C（LPI2C）接口
- 同步音频接口（SAI）
- 中等质量音频接口（MQS）
- 麦克风滤波接口（MICFIL）
- 低压差分信号（LVDS）接口
- 模数转换器接口（ADC）
- SINC滤波器接口
- 调试接口（Debug Interface）


  - 一个USB转UART／多协议同步串行引擎（MPSSE）器件FT4232H
  - 一个用于FT4232H的USB 3.2 Type-C连接器J15，提供4个串口
  - JTAG排针J16

<a id="system-clock"></a>

#### 系统时钟（System Clock）

此板为Cortex-A55配置24 MHz系统时钟，A55核最高1.7 GHz。Cortex-M33最高333 MHz，SYSTICK与M33同频。

<a id="serial-port"></a>

#### 串口（Serial Port）

此板分别通过CPU的UART1为Cortex-A55、UART8为Cortex-M33提供单一串行通信通道。

<a id="ethernet"></a>

#### 以太网（Ethernet）

NETC驱动支持管理物理站接口（PSI）及时间敏感网络（TSN）交换机。M33可通过west build选项-DEXTRA_DTC_OVERLAY_FILE=enetc.overlay启用ENET0、ENETC1及ENETC2端口。

A55默认启用ENET0、ENETC1及ENETC2，无需额外覆盖文件。NETC依赖通用中断控制器中断转换服务（GIC ITS），因此需保证堆内存大于851968字节。原文同时说明，启用GIC ITS会将系统堆下限提高至该值，无需手工设置[CONFIG_HEAP_MEM_POOL_SIZE](https://docs.zephyrproject.org/latest/kconfig.html#CONFIG_HEAP_MEM_POOL_SIZE)。

EVK上的交换机port0与port2同时连接SGMII端口SGMII-swp0／SGMII-swp1及100M端口swp0／swp1。目前只启用100M端口，可连接这些端口验证两个交换机端口。原文端口编号与名称按来源保留。

可在M33或A55上通过分布式交换机架构（DSA）验证这两个端口，例如A55：（[分布式交换机架构（DSA / Distributed Switch Architecture）](../networking/P123_DSA分布式交换机示例.md#dsa)）

```text
# From the root of the zephyr repository
west build -b imx943_evk/mimx94398/a55 samples/net/ethernet/dsa
west flash
```

或者使用M33：

```text
# From the root of the zephyr repository
west build -b imx943_evk/mimx94398/m33/ddr samples/net/ethernet/dsa
```

随后使用west flash或west debug，从主机加载zephyr.bin，在A55 core0上启动Zephyr应用。

### 选项2：使用U-Boot命令启动Zephyr

<a id="id1"></a>

#### 依赖项（Dependency）

需要在U-Boot中停用全部看门狗，否则Zephyr从同一个A55核启动后，看门狗会复位开发板。

<a id="step-1-build-zephyr-application"></a>

```text
# From the root of the zephyr repository
```

<a id="step-2-download-zephyr-image-into-ddr-memory"></a>

#### 步骤2：将Zephyr镜像下载到DDR

首先将Zephyr二进制镜像下载到DDR，可使用TFTP：

```text
tftp 0xd0000000 zephyr.bin
```

也可将zephyr.bin复制到SD卡，并插入开发板。例如，镜像在SD卡FAT分区中时，用以下U-Boot命令加载到DDR。示例假定SD卡设备编号为1、FAT分区编号为1，应按实际配置调整：

```text
fatload mmc 1:1 0xd0000000 zephyr.bin;
```

#### 步骤3：启动Zephyr

使用以下命令在core0上启动Zephyr：

```text
dcache flush; icache flush; go 0xd0000000;
```


<a id="cortex-a55-smp"></a>

### Cortex-A55对称多处理（SMP）

默认SMP变体使用全部4个Cortex-A核。如需减少内核，可在DTS中停用部分A55节点，并将[CONFIG_MP_MAX_NUM_CPUS](https://docs.zephyrproject.org/latest/kconfig.html#CONFIG_MP_MAX_NUM_CPUS)改为DTS中仍启用的A55核数。

构建SMP内核，以下以基本同步示例为例：（[基础同步（Basic Synchronization）](../basic_samples/P029_基本同步示例.md#synchronization)）

```text
# From the root of the zephyr repository
west build -b imx943_evk/mimx94398/a55/smp samples/synchronization
```

无论采用何种启动方式，都必须从DTS的cpus节点列出的第一个CPU核启动SMP Zephyr。默认SMP变体的第一个A55核为Core0，可通过U-Boot go命令、J-Link运行工具或SPSDK运行工具启动。

<a id="option-3-boot-zephyr-by-using-spsdk-runner"></a>

### 选项3：使用SPSDK运行工具（Runner）启动Zephyr

SPSDK运行工具使用[https://spsdk.readthedocs.io](https://spsdk.readthedocs.io)提供的工具集构建可启动镜像flash.bin，其中包含ELE及V2X固件、系统管理器（System Manager）、DDR OEI、TF-A等全部必需固件组件。west flash可将镜像下载到DDR，或写入SD／eMMC。该镜像没有U-Boot，由TF-A直接在第一个Cortex-A55核上启动Zephyr。

使用SPSDK运行工具前需要获取二进制组件（Binary Blobs），命令如下：

```text
west blobs fetch hal_nxp
```

注意（Note）

建议在 `west update` 之后运行上述命令。

SPSDK运行工具通过CONFIG_BOARD_NXP_SPSDK_IMAGE启用，i.MX943 EVK默认未启用。以下以基本同步示例说明如何启用：（[基础同步（Basic Synchronization）](../basic_samples/P029_基本同步示例.md#synchronization)）

```text
# From the root of the zephyr repository
west build -b imx943_evk/mimx94398/a55 samples/synchronization -- -DCONFIG_BOARD_NXP_SPSDK_IMAGE=y
```

若板卡变体提供并启用CONFIG_BOARD_NXP_SPSDK_IMAGE，将自动生成flash.bin。执行以下编程命令前，将SW4[3:0]设为0b1001，以USB下载模式启动，并将USB1及DBG连接PC。系统枚举4个115200、8N1串口，第3个用于A55 Zephyr，第4个用于M33 System Manager。spsdk烧录工具已通过scripts/requirements.txt安装；Linux下需按[https://spsdk.readthedocs.io](https://spsdk.readthedocs.io)安装指南配置USB设备权限。

```text
# load and run without programming. for next flashing, execute 'reset' in the
# fourth serail port
$ west flash -r spsdk

# program to SD card, then set SW4[3:0]=0b1011 and reboot the board from SD
$ west flash -r spsdk --bootdevice sd

# program to emmc card, then set SW4[3:0]=0b1010 and reboot the board from eMMC
$ west flash -r spsdk --bootdevice=emmc
```

Zephyr日志显示在第3个串口控制台。

注意：默认启动镜像面向LPDDR5 EVK。为LPDDR4 EVK构建时，需启用CONFIG_BOARD_NXP_LPDDR4。

### 步骤2：构建可启动固件

生成可写入SD／eMMC的启动固件，需要imx-mkimage工具及i.MX Linux BSP发行版中的其他固件文件。（[i.MX Linux板级支持包（BSP）发行版](https://www.nxp.com/design/design-center/software/embedded-software/i-mx-software/embedded-linux-for-i-mx-applications-processors:IMXLINUX)）

以下示例在Linux主机执行，详细信息参见i.MX Linux BSP 6.12.3_1.0.0发行版。（[i.MX Linux板级支持包（BSP）发行版](https://www.nxp.com/design/design-center/software/embedded-software/i-mx-software/embedded-linux-for-i-mx-applications-processors:IMXLINUX)）

```text
# download

git clone https://github.com/nxp-imx/imx-mkimage.git -b lf-6.12.3_1.0.0
git clone https://github.com/nxp-imx/imx-sm.git      -b lf-6.12.3-imx943-er1
git clone https://github.com/nxp-imx/imx-oei.git     -b lf-6.12.3-imx943-er1

wget https://www.nxp.com/lgfiles/NMG/MAD/YOCTO/firmware-imx-8.27-5af0ceb.bin
wget https://www.nxp.com/lgfiles/NMG/MAD/YOCTO/firmware-ele-imx-2.0.1-0a66c34.bin

# some firmware files need to be unpacked

chmod 777 firmware-imx-8.27-5af0ceb.bin
chmod 777 firmware-ele-imx-2.0.1-0a66c34.bin
./firmware-imx-8.27-5af0ceb.bin --auto-accept
./firmware-ele-imx-2.0.1-0a66c34.bin --auto-accept

# some firmware files need to be built from source

export TOOLS=$ARMGCC_DIR
export SM_CROSS_COMPILE=${TOOLS}/bin/arm-none-eabi-
export OEI_CROSS_COMPILE=${TOOLS}/bin/arm-none-eabi-

make -C imx-oei board=mx943lp5-19 oei=ddr d=1 all
make -C imx-sm config=mx94alt cfg
make -C imx-sm config=mx94alt all

# make bootable firmware flash.bin

cp firmware-imx-8.27-5af0ceb/firmware/ddr/synopsys/lpddr5*v202409.bin imx-mkimage/iMX94/
cp firmware-ele-imx-2.0.1-0a66c34/mx943a0-ahab-container.img          imx-mkimage/iMX94/
cp imx-sm/build/mx94alt/m33_image.bin                                 imx-mkimage/iMX94/
cp imx-oei/build/mx943lp5-19/ddr/oei-m33-ddr.bin                      imx-mkimage/iMX94/
cp zephyr/build/zephyr/zephyr.bin                                     imx-mkimage/iMX94/m33s_image.bin (m70_image.bin or m71_image.bin)

cd imx-mkimage
make SOC=iMX94 OEI=YES flash_m33s     # for TCM target
make SOC=iMX94 OEI=YES flash_m33s_ddr # for DDR target
or
make SOC=iMX94 OEI=YES flash_m33s_m70_m71  # for TCM target


# Program to SD card

dd if=iMX94/flash.bin of=/dev/sdb bs=1k seek=32 && sync
```

