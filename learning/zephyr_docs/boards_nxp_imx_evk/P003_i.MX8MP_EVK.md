## 概述（Overview）

i.MX8M Plus LPDDR4 EVK基于NXP i.MX8M Plus应用处理器，由四核Cortex-A53集群及单个Cortex-M7核组成。原文概述说明Zephyr OS移植于Cortex-A53核。


- 开发板特性（Board Features）：


  - RAM：2 GB LPDDR4
  - 存储（Storage）：


    - SanDisk 16 GB eMMC 5.1
    - Micron 32 MB QSPI NOR闪存
    - microSD卡插槽（Socket）
  - 无线（Wireless）：


    - Wi-Fi：2.4／5 GHz，IEEE 802.11b/g/n
    - 蓝牙（Bluetooth）v4.1
  - 通用串行总线（USB）：


    - USB OTG：2个Type-C接口
  - 以太网（Ethernet）
  - PCI-E M.2
  - 接插件（Connectors）：


    - 40引脚双排排针
  - 发光二极管（LED）：


    - 1个电源状态LED
    - 1个UART LED
  - 调试（Debug）


    - 20引脚JTAG连接器
    - Micro-USB用于UART调试，提供分别用于A53和M4的两个COM端口

开发板更多信息见[NXP网站](https://www.nxp.com/design/development-boards/i-mx-evaluation-and-development-boards/evaluation-kit-for-the-i-mx-8m-plus-applications-processor:8MPLUSLPD4-EVK)。

<a id="option-1-boot-zephyr-by-using-jlink-runner"></a>

### 选项1：使用J-Link运行工具（Runner）启动Zephyr

默认运行工具为J-Link。使用J-Link调试器将EVK的JTAG连接器接至主机，给开发板上电，并停在U-Boot命令行。

随后使用west flash或west debug，从主机加载zephyr.bin，在A53 core0上启动Zephyr应用。

<a id="flash-and-run"></a>

#### 烧录与运行（Flash and Run）

下面以[Hello World](../getting_started/P005_HelloWorld示例.md#hello_world)应用为例。

```text
# From the root of the zephyr repository
west build -b imx8mp_evk/mimx8ml8/a53 samples/hello_world
west flash
```

UART4控制台应显示以下日志：

```text
*** Booting Zephyr OS build v4.1.0-3063-g38519ca2c028 ***
Hello World! imx8mp_evk/mimx8ml8/a53
```

<a id="debug"></a>

#### 调试（Debug）

下面以[Hello World](../getting_started/P005_HelloWorld示例.md#hello_world)应用为例。

```text
# From the root of the zephyr repository
west build -b imx8mp_evk/mimx8ml8/a53 samples/hello_world
west debug
```

<a id="option-2-boot-zephyr-by-using-u-boot-command"></a>

### 选项2：使用U-Boot命令启动Zephyr

U-Boot的cpu命令用于加载Zephyr并启动Cortex-A次级核。目前[Real-Time Edge U-Boot](https://github.com/nxp-real-time-edge-sw/real-time-edge-uboot)支持此命令，分支格式为uboot_vxxxx.xx-y.y.y，其中xxxx.xx为U-Boot版本，y.y.y为[Real-Time Edge软件](https://www.nxp.com/rtedge)版本。例如，uboot_v2023.04-2.9.0表示Real-Time Edge Software v2.9.0使用的U-Boot v2023.04。预构建镜像及用户指南见Real-Time Edge Software。

<a id="step-1-download-zephyr-image-into-ddr-memory"></a>

#### 步骤1：将Zephyr镜像下载到DDR存储器

首先将Zephyr二进制镜像下载到DDR，可使用TFTP：

```text
tftp 0xc0000000 zephyr.bin
```

也可将zephyr.bin复制到SD卡，并插入开发板。例如，镜像在SD卡FAT分区中时，用以下U-Boot命令加载到DDR。示例假定SD卡设备编号为1、FAT分区编号为1，应按实际配置调整：

```text
fatload mmc 1:1 0xc0000000 zephyr.bin;
```

<a id="step-2-boot-zephyr"></a>

#### 步骤2：启动Zephyr

使用以下命令在core0上启动Zephyr：

```text
dcache off; icache flush; go 0xc0000000;
```

也可用cpu命令从次级核启动，例如Core1：

```text
dcache flush; icache flush; cpu 1 release 0xc0000000
```

<a id="option-3-boot-zephyr-by-using-remoteproc-under-linux"></a>

### 选项3：在Linux下使用remoteproc启动Zephyr

A53核运行Linux时，可通过远程处理器（remoteproc）框架加载并启动Zephyr，细节见Real-Time Edge用户指南。预构建镜像及用户指南可在[Real-Time Edge Software](https://www.nxp.com/rtedge)中获取。

此配置可运行基础Zephyr应用及内核测试，例如[基础同步（Basic Synchronization）](../basic_samples/P029_基本同步示例.md#synchronization)示例：

```text
# From the root of the zephyr repository
west build -b imx8mp_evk/mimx8ml8/a53 samples/synchronization
```

这将构建包含同步（Synchronization）示例的镜像，启动后控制台输出如下：

```text
*** Booting Zephyr OS build v4.1.0-3063-g38519ca2c028 ***
thread_a: Hello World from cpu 0 on mimx8mp_evk!
thread_b: Hello World from cpu 0 on mimx8mp_evk!
thread_a: Hello World from cpu 0 on mimx8mp_evk!
thread_b: Hello World from cpu 0 on mimx8mp_evk!
thread_a: Hello World from cpu 0 on mimx8mp_evk!
```

<a id="can-bus-flexcan-a53"></a>

### A53上的CAN总线（FlexCAN）

FlexCAN为支持标准帧及扩展帧的CAN 2.0B控制器，包含两个独立模块FlexCAN1和FlexCAN2。设备树默认启用FlexCAN1；启用FlexCAN2需添加设备树覆盖文件[boards/nxp/imx8mp_evk/dts/flexcan2.overlay](https://github.com/zephyrproject-rtos/zephyr/blob/main/boards/nxp/imx8mp_evk/dts/flexcan2.overlay)。

例如，在[Hello World](../getting_started/P005_HelloWorld示例.md#hello_world)示例中启用CAN Shell及CAN统计，并使用FlexCAN1控制器时，可采用以下配置：

```text
# From the root of the zephyr repository
west build -b imx8mp_evk/mimx8ml8/a53 samples/hello_world -- -DCONFIG_SHELL=y -DCONFIG_CAN=y -DCONFIG_CAN_SHELL=y -DCONFIG_STATS=y -DCONFIG_CAN_STATS=y
```

<a id="programming-and-debugging-m7"></a>

加载M7核镜像有两种方法：U-Boot命令或Linux remoteproc。

<a id="load-and-run-m7-zephyr-image-from-u-boot"></a>

### 通过U-Boot加载并运行M7 Zephyr镜像

通过A53上的U-Boot加载并运行M7 Zephyr镜像：把编译得到的zephyr.bin复制到SD卡第一个FAT分区，插入开发板，上电后在提示符处停止U-Boot执行。

使用以下命令将M7二进制加载到所需存储器并启动：

<a id="itcm"></a>

### 指令紧耦合存储器（ITCM）

```text
fatload mmc 0:1 0x48000000 zephyr.bin
cp.b 0x48000000 0x7e0000 20000
bootaux 0x7e0000
```

<a id="ddr"></a>

### 双倍数据率存储器（DDR）

```text
fatload mmc 0:1 0x80000000 zephyr.bin
dcache flush
bootaux 0x80000000
```

<a id="load-and-run-m7-zephyr-image-by-using-linux-remoteproc"></a>

### 通过Linux remoteproc加载并运行M7 Zephyr镜像

准备设备树：

设备树必须包含compatible为fsl,imx8mn-cm7的CM7节点。如果代码及系统地址使用DDR，还需预留DDR内存，并将m4_reserved加入cm7节点的memory-region列表。原文将该预留区域称为“M4 DDR memory”，这里保留其节点标识。

```text
reserved-memory {
         #address-cells = <2>;
         #size-cells = <2>;
         ranges;

         m7_reserved: m4@80000000 {
               no-map;
               reg = <0 0x80000000 0 0x1000000>;
         };
         ...
}


imx8mp-cm7 {
         compatible = "fsl,imx8mn-cm7";
         rsc-da = <0x55000000>;
         clocks = <&clk IMX8MP_CLK_M7_DIV>,
                  <&audio_blk_ctrl IMX8MP_CLK_AUDIO_BLK_CTRL_AUDPLL_ROOT>;
         clock-names = "core", "audio";
         mbox-names = "tx", "rx", "rxdb";
         mboxes = <&mu 0 1
                  &mu 1 1
                  &mu 3 1>;
         memory-region = <&vdevbuffer>, <&vdev0vring0>, <&vdev0vring1>, <&rsc_table>, <&m7_reserved>;
         status = "okay";
         fsl,startup-delay-ms = <500>;
};
```

DDR镜像需要额外的Zephyr内核配置：

使用remoteproc启动DDR目标imx8mp_evk/mimx8ml8/m7/ddr时，还需启用CONFIG_ROMSTART_RELOCATION_ROM，将romstart存储段放入ITCM，因为M7从ITCM零地址取第一条指令。romstart重定位会使zephyr.bin文件体积过大，因此板卡defconfig默认不启用此选项。

```text
diff --git a/boards/nxp/imx8mp_evk/imx8mp_evk_mimx8ml8_m7_ddr_defconfig b/boards/nxp/imx8mp_evk/imx8mp_evk_mimx8ml8_m7_ddr_defconfig
index 17542cb4eec..8c30c5b6fa3 100644
--- a/boards/nxp/imx8mp_evk/imx8mp_evk_mimx8ml8_m7_ddr_defconfig
+++ b/boards/nxp/imx8mp_evk/imx8mp_evk_mimx8ml8_m7_ddr_defconfig
@@ -12,3 +12,4 @@ CONFIG_CONSOLE=y
CONFIG_XIP=y
CONFIG_CODE_DDR=y
+CONFIG_ROMSTART_RELOCATION_ROM=y
```

随后按以下步骤启动Zephyr内核：


1. 在U-Boot命令行中执行准备脚本：

```text
u-boot=> run prepare_mcore
```


1. 使用指定设备树二进制（DTB）启动Linux内核，再通过remoteproc启动Zephyr：

```text
root@imx8mp-lpddr4-evk:~# echo zephyr.elf > /sys/devices/platform/imx8mp-cm7/remoteproc/remoteproc0/firmware
root@imx8mp-lpddr4-evk:~# echo start  > /sys/devices/platform/imx8mp-cm7/remoteproc/remoteproc0/state
[   39.195651] remoteproc remoteproc0: powering up imx-rproc
[   39.203345] remoteproc remoteproc0: Booting fw image zephyr.elf, size 503992
[   39.203388] remoteproc remoteproc0: No resource table in elf
root@imx8mp-lpddr4-evk:~# [   39.711380] remoteproc remoteproc0: remote processor imx-rproc is now up

root@imx8mp-lpddr4-evk:~#
```
