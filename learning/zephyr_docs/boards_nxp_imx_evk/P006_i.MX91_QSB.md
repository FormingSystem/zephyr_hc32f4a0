## 概述（Overview）

i.MX 91快速入门板（Quick Start Board），即MCIMX91-QSB，用于展示i.MX 91应用处理器的常用功能。它是体积小、成本低的入门开发板，帮助开发者先熟悉处理器，再为更具体的设计投入大量资源。

<a id="hardware"></a>

## 硬件（Hardware）


- i.MX 91应用处理器（Application Processor）


  - 处理器集成一个Arm Cortex-A55核，最高1.4 GHz。
- RAM：1 GB LPDDR4
- 存储（Storage）：


  - SanDisk 16 GB eMMC 5.1
  - microSD卡插槽（Socket）
- 无线（Wireless）：


  - Murata Type-2EL模块，接口为SDIO、UART及SPI；基于NXP IW612 SoC，支持2.4 GHz／5 GHz双频1×1 Wi-Fi 6、蓝牙5.2及802.15.4
- 通用串行总线（USB）：


  - 两个USB 2.0 Type-C连接器
- 以太网（Ethernet）：


  - ENET_QoS：支持时间敏感网络（TSN）的10/100/1000 Mbit/s RGMII以太网，连接外部RTL8211 PHY
- PCI Express（PCIe）：


  - 一个75引脚M.2／NGFF Key E迷你卡连接器
- 接插件（Connectors）：


  - 40引脚双排排针
- 发光二极管（LED）：


  - 1个电源状态LED
  - 两个UART LED
- 调试（Debug）：


  - 20引脚JTAG连接器
  - 用于UART调试的Micro-USB

### 设备（Devices）

<a id="system-clock"></a>

#### 系统时钟（System Clock）

此开发板配置使用24 MHz系统时钟，Cortex-A55最高运行频率1.4 GHz。

#### 串口（Serial Port）

此板为A55内核使用单一串行通信通道，即CPU的UART1。

<a id="programming-and-debugging"></a>

## 烧录与调试（Programming and Debugging）

使用U-Boot的go命令加载Zephyr，并启动Cortex-A55内核运行。

将开发板停在U-Boot命令行，再将Zephyr二进制镜像下载到DDR，可使用TFTP：

```text
tftp 0x80000000 zephyr.bin
```

也可将zephyr.bin复制到SD卡，再将卡插入开发板。例如，镜像位于SD卡FAT分区时，用以下U-Boot命令加载到DDR。示例假设SD卡设备编号为1、FAT分区编号为1，应按实际分区调整：

```text
fatload mmc 1:1 0x80000000 zephyr.bin;
```

随后使用U-Boot加载zephyr.bin并启动Cortex-A55内核：

```text
dcache off; icache flush; go 0x80000000
```

此配置可运行基础Zephyr应用及内核测试，例如[基础同步（Basic Synchronization）](../basic_samples/P029_基本同步示例.md#synchronization)示例：

```text
# From the root of the zephyr repository
west build -b imx91_qsb/mimx9111 samples/synchronization
```

这将构建包含同步（Synchronization）示例的镜像，启动后控制台输出如下：

```text
*** Booting Zephyr OS build v4.0.0-3277-g69f43115c9a8 ***
thread_a: Hello World from cpu 0 on imx91_qsb!
thread_b: Hello World from cpu 0 on imx91_qsb!
thread_a: Hello World from cpu 0 on imx91_qsb!
thread_b: Hello World from cpu 0 on imx91_qsb!
```
