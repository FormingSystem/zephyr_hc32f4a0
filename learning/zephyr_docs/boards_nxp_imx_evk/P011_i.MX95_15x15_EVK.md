## 概述（Overview）

i.MX95 EVK（IMX95LP4XEVK-15）用于展示i.MX 95应用处理器的常用功能，是帮助开发者先熟悉处理器、再为具体设计投入更多资源的入门开发板。板上i.MX 95采用15×15 mm紧凑封装。

<a id="hardware"></a>

## 硬件（Hardware）


- i.MX 95应用处理器（Applications Processor）


  - 处理器最多集成6个Arm Cortex-A55核，并通过内置Cortex-M33和Cortex-M7核支持功能安全（Functional Safety）
- 动态RAM（DRAM）：8 Gbit LPDDR4x
- eMMC：64 GB Micron eMMC
- USB接口：Type-A和Type-C两个端口
- 音频编解码器接口（Audio Codec Interface）


  - 一个WM8962B音频编解码器
  - 一个3.5 mm、四极、符合CTIA标准的音频插孔
  - 一个连接扬声器的4引脚连接器
- 以太网接口（Ethernet Interface）


  - ENET2控制器


    - 通过一个RJ45连接器及外部RTL8211 PHY，支持100 Mbit/s或1000 Mbit/s RGMII以太网
  - ENET1控制器


    - 通过一个RJ45连接器及外部RTL8211 PHY，支持100 Mbit/s或1000 Mbit/s RGMII以太网
- M.2接口：一个基于NXP AW612芯片的Murata Type-2EL Wi-Fi／蓝牙模块，支持1×1 Wi-Fi 6及蓝牙5.3
- MIPI CSI接口：一个22引脚或36引脚miniSAS连接器，配置为4条通道
- MIPI CSIDSI接口：一个36引脚miniSAS连接器，配置为4条通道
- LVDS接口：两个miniSAS连接器，每个配置为4条通道
- CAN接口：一个用于外接设备的4引脚CAN排针
- SD卡接口：一张4位SD 3.0 MicroSD卡
- I2C接口：I2C1—I2C6控制器
- FT4232H I2C接口：PCT2075温度传感器及电流监测器件
- 模数转换（ADC）接口：两个四通道ADC排针
- 调试接口（Debug Interface）


  - 一个USB转UART／多协议同步串行引擎（MPSSE）器件FT4232H
  - 一个用于FT4232H的USB 2.0 Type-C连接器J31，提供4个串口

<a id="programming-and-debugging-a55"></a>

## A55编程与调试（Programming and Debugging）

此配置可运行基础Zephyr应用及内核测试，例如[基础同步（Basic Synchronization）](../basic_samples/P029_基本同步示例.md#synchronization)示例：


1. 构建并运行非SMP应用（Non-SMP Application）

```text
# From the root of the zephyr repository
west build -b imx95_evk_15x15/mimx9596/a55 samples/synchronization
```

此命令构建包含基本同步示例的zephyr.bin镜像。

将编译的zephyr.bin复制到SD卡第一个FAT分区，插入开发板，上电后在提示符处停止U-Boot执行。

使用U-Boot加载zephyr.bin并启动Cortex-A55 Core1：

```text
fatload mmc 1:1 0xd0000000 zephyr.bin; dcache flush; icache flush; cpu 1 release 0xd0000000
```

也可使用以下命令启动Core0上的zephyr.bin：

```text
fatload mmc 1:1 0xd0000000 zephyr.bin; dcache flush; icache flush; go 0xd0000000
```

控制台应显示以下输出：

```text
*** Booting Zephyr OS build v3.6.0-4569-g483c01ca11a7 ***
thread_a: Hello World from cpu 0 on imx95_evk_15x15!
thread_b: Hello World from cpu 0 on imx95_evk_15x15!
thread_a: Hello World from cpu 0 on imx95_evk_15x15!
thread_b: Hello World from cpu 0 on imx95_evk_15x15!
thread_a: Hello World from cpu 0 on imx95_evk_15x15!
```
