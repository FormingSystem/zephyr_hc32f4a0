## 概述（Overview）

i.MX95 EVK（IMX95LPD5EVK-19）用于展示i.MX 95汽车应用处理器的常用功能，是帮助开发者先熟悉处理器、再为具体设计投入更多资源的入门开发板。板上i.MX95采用19×19 mm紧凑封装。

<a id="hardware"></a>

## 硬件（Hardware）


- i.MX 95汽车应用处理器（Automotive Applications Processor）


  - 处理器最多集成6个Arm Cortex-A55核，并通过内置Cortex-M33和Cortex-M7核支持功能安全（Functional Safety）
- 动态RAM（DRAM）：128 Gbit LPDDR5
- eMMC：64 GB Micron eMMC
- SPI NOR闪存：1 Gbit八线（Octal）闪存
- USB接口：Type-A和Type-C两个端口
- 音频编解码器接口（Audio Codec Interface）


  - 一个WM8962BECSN/R音频编解码器，具有一路发送及一路接收通道
  - 一个3.5 mm、四极、符合CTIA标准的音频插孔
  - 一个连接扬声器的4引脚连接器
- 以太网接口（Ethernet Interface）


  - ENET2控制器


    - 连接一个60引脚以太网连接器
    - 支持可配置为100 Mbit/s或1000 Mbit/s的以太网PHY子卡（Daughter Cards）
  - ENET1控制器


    - 通过一个RJ45连接器及外部RTL8211 PHY，支持100 Mbit/s或1000 Mbit/s RGMII以太网
  - 10 Gbit以太网控制器


    - 支持XFI及USXGMII接口，通过一个10 Gbit RJ45集成连接器模块（ICM）连接外部Marvell AQR113C PHY
- M.2接口：一个基于NXP AW693芯片的Murata Type-2EL Wi-Fi／蓝牙模块，支持2×2 Wi-Fi 6及蓝牙5.2
- MIPI CSI接口：一个36引脚miniSAS连接器，配置为4条通道
- MIPI CSIDSI接口：一个36引脚miniSAS连接器，配置为4条通道
- LVDS接口：两个miniSAS连接器，每个配置为4条通道
- CAN接口：两个用于外接设备的4引脚CAN排针
- SD卡接口：一张4位SD 3.0 MicroSD卡
- I2C接口：I2C1—I2C7控制器
- FT4232H I2C接口：PCT2075温度传感器及电流监测器件
- 数字麦克风（DMIC）接口：两个数字麦克风，提供单比特脉冲密度调制（PDM）输出
- 模数转换（ADC）接口：两个四通道ADC排针
- 音频板接口（Audio Board Interface）


  - 支持PCIe x4插槽，用于连接Quantum板
  - 支持PCIe x8插槽，用于连接音频I/O板
- 调试接口（Debug Interface）


  - 一个USB转UART／多协议同步串行引擎（MPSSE）器件FT4232H
  - 一个用于FT4232H的USB 2.0 Type-C连接器J31，提供4个串口

<a id="system-clock"></a>

#### 系统时钟（System Clock）

此板为Cortex-A55配置24 MHz系统时钟，A55核最高1.8 GHz。Cortex-M7最高800 MHz，SYSTICK与M7同频。

<a id="serial-port"></a>

#### 串口（Serial Port）

此板分别通过CPU的UART1为Cortex-A55、UART3为Cortex-M7提供单一串行通信通道。

<a id="tpm"></a>

#### 定时器／PWM模块（TPM）

M7为PWM启用TPM2的两个通道，可用示波器观察。通道2信号引至电阻R881，通道3信号引至R882。

<a id="spi"></a>

#### 串行外设接口（SPI）

EVK需要硬件返工，在R1217、R1218、R1219和R1220焊接0 Ω电阻；J35上的SPI1为M7启用。

<a id="ethernet"></a>

#### 以太网（Ethernet）

NETC驱动支持管理物理站接口（PSI）。第一个ENET1端口可在M7 DDR及A55平台启用。

A55上的NETC依赖GIC ITS，需要保证堆内存大于851968字节。原文同时说明，启用GIC ITS会将系统堆下限提高至该值，无需手工设置[CONFIG_HEAP_MEM_POOL_SIZE](https://docs.zephyrproject.org/latest/kconfig.html#CONFIG_HEAP_MEM_POOL_SIZE)。

有多种在A55核上编程并运行Zephyr的方法：

<a id="option-1-boot-zephyr-by-using-spsdk-runner"></a>

### 选项1：使用SPSDK运行工具启动Zephyr

SPSDK运行工具使用[https://spsdk.readthedocs.io](https://spsdk.readthedocs.io)提供的工具集构建可启动镜像flash.bin，其中包含ELE及V2X固件、System Manager、TCM OEI、TF-A等全部必需固件组件。west flash可将镜像下载到DDR、SD卡或eMMC。该镜像没有U-Boot，由TF-A直接在第一个Cortex-A55核上启动Zephyr。

使用SPSDK运行工具前需要获取二进制组件（Binary Blobs），命令如下：

```text
west blobs fetch hal_nxp
```

注意（Note）

建议在 `west update` 之后运行上述命令。

SPSDK运行工具通过CONFIG_BOARD_NXP_SPSDK_IMAGE启用，i.MX95 EVK默认未启用。以下以基本同步示例说明如何启用：（[基础同步（Basic Synchronization）](../basic_samples/P029_基本同步示例.md#synchronization)）

```text
# From the root of the zephyr repository
west build -b imx95_evk/mimx9596/a55 samples/synchronization -- -DCONFIG_BOARD_NXP_SPSDK_IMAGE=y
```

若板卡变体提供并启用CONFIG_BOARD_NXP_SPSDK_IMAGE，将自动生成flash.bin。执行以下编程命令前，将SW7[1:4]设为0b1001，以USB下载模式启动，并将USB1及DBG连接PC。系统枚举4个115200、8N1串口。原文此处写第1个用于M7、第4个用于M33 System Manager，虽然本节介绍A55，译文保留该描述。spsdk烧录工具已通过scripts/requirements.txt安装；Linux下需按[https://spsdk.readthedocs.io](https://spsdk.readthedocs.io)安装指南配置USB设备权限。

```text
# load and run without programming. for next flashing, execute 'reset' in the
# fourth serail port
$ west flash -r spsdk

# program to SD card, then set SW7[1:4]=0b1011 to reboot
$ west flash -r spsdk --bootdevice sd

# program to emmc card, then set SW7[1:4]=0b1010 to reboot
$ west flash -r spsdk --bootdevice=emmc
```

<a id="option-2-boot-zephyr-by-using-u-boot-command"></a>

### 选项2：使用U-Boot命令启动Zephyr

U-Boot的go命令可在A55 core0上启动Zephyr；cpu命令则用于加载Zephyr并启动其他A55次级核。原文指定[Real-Time Edge U-Boot](https://github.com/nxp-real-time-edge-sw/real-time-edge-uboot)支持cpu命令，分支格式为uboot_vxxxx.xx-y.y.y，其中xxxx.xx为U-Boot版本，y.y.y为[Real-Time Edge软件](https://www.nxp.com/rtedge)版本。例如uboot_v2023.04-2.9.0表示Real-Time Edge Software v2.9.0采用的U-Boot v2023.04。预构建镜像及用户指南见Real-Time Edge Software。

<a id="step-1-download-zephyr-image-into-ddr-memory"></a>

#### 步骤1：将Zephyr镜像下载到DDR存储器

首先将Zephyr二进制镜像下载到DDR，可使用TFTP：

```text
tftp 0xd0000000 zephyr.bin
```

也可将zephyr.bin复制到SD卡，并插入开发板。例如，镜像在SD卡FAT分区中时，用以下U-Boot命令加载到DDR。示例假定SD卡设备编号为1、FAT分区编号为1，应按实际配置调整：

```text
fatload mmc 1:1 0xd0000000 zephyr.bin;
```

<a id="step-2-boot-zephyr"></a>

#### 步骤2：启动Zephyr

此配置可运行基础Zephyr应用及内核测试，例如[基础同步（Basic Synchronization）](../basic_samples/P029_基本同步示例.md#synchronization)示例：

```text
# From the root of the zephyr repository
west build -b imx95_evk/mimx9596/a55 samples/synchronization
```

此命令构建包含基本同步示例的zephyr.bin镜像。

使用以下命令在core0上启动Zephyr：

```text
dcache off; icache flush; go 0xd0000000;
```

也可用cpu命令从次级核启动，例如Core1：

```text
dcache flush; icache flush; cpu 1 release 0xd0000000
```

控制台应显示以下输出：

```text
*** Booting Zephyr OS build v3.6.0-4569-g483c01ca11a7 ***
thread_a: Hello World from cpu 0 on imx95_evk!
thread_b: Hello World from cpu 0 on imx95_evk!
thread_a: Hello World from cpu 0 on imx95_evk!
thread_b: Hello World from cpu 0 on imx95_evk!
thread_a: Hello World from cpu 0 on imx95_evk!
```

<a id="option-3-boot-zephyr-by-using-remoteproc-under-linux"></a>

### 选项3：在Linux下使用remoteproc启动Zephyr

A55核运行Linux时，可通过remoteproc框架加载并启动Zephyr，细节见Real-Time Edge用户指南。预构建镜像及用户指南见[Real-Time Edge Software](https://www.nxp.com/rtedge)。

<a id="option-4-boot-zephyr-by-using-jlink-runner"></a>

### 选项4：使用J-Link运行工具启动Zephyr

此板支持通过J-Link运行工具烧录及调试Zephyr；使用J-Link调试器连接EVK的JTAG接口与主机。

如需在Core0运行或调试Zephyr，给开发板上电并停在U-Boot命令行即可。

随后用west flash -r jlink从主机加载zephyr.bin并启动Zephyr，或用west debug -r jlink调试。

<a id="flash-and-run"></a>

#### 烧录与运行（Flash and Run）

下面以[Hello World](../getting_started/P005_HelloWorld示例.md#hello_world)应用为例。

```text
# From the root of the zephyr repository
west build -b imx95_evk/mimx9596/a55 samples/hello_world
west flash -r jlink
```

<a id="debug"></a>

#### 调试（Debug）

下面以[Hello World](../getting_started/P005_HelloWorld示例.md#hello_world)应用为例。

```text
# From the root of the zephyr repository
west build -b imx95_evk/mimx9596/a55 samples/hello_world
west debug -r jlink
```

<a id="notes"></a>

#### 备注（Notes）

如需在Core0以外的Cortex-A核上运行或调试Zephyr，例如Core2，需先在U-Boot中执行以下命令，将指定CPU核释放到死循环状态。U-Boot须支持cpu命令，具体版本见“选项2：使用U-Boot命令启动Zephyr”。

```text
mw.l 0xD0000000 14000000; dcache flush; icache flush; cpu 2 release 0xD0000000
```

还需按以下方式修改J-Link设备名称，将MIMX9556_A55_0替换为对应内核的设备ID，例如CPU Core2使用MIMX9556_A55_2。

```text

@@ -21,6 +21,6 @@ if(CONFIG_BOARD_NXP_SPSDK_IMAGE OR (DEFINED ENV{USE_NXP_SPSDK_IMAGE}
endif()
```

随后用west flash -r jlink从主机加载zephyr.bin并启动Zephyr，或用west debug -r jlink调试。

<a id="programming-and-debugging-m7"></a>

## M7编程与调试（Programming and Debugging）

i.MX95使用运行于Cortex-M33的i.MX系统管理器（SM / System Manager）。Cortex-M33是启动核，先执行启动ROM，由ROM加载SM及其他启动代码，再跳转到SM。SM配置硬件隔离等机制，并启动系统中的其他核，随后进入服务模式，通过基于Arm[系统控制与管理接口（SCMI）](https://developer.arm.com/documentation/den0056/latest/)的客户端远程过程调用（RPC）API提供时钟、电源、传感器及引脚控制。

为M7编程，需要生成i.MX容器镜像flash.bin，其中包含ELE及V2X固件、System Manager、TCM OEI、Cortex-M7镜像等必需组件。

SPSDK运行工具用于构建flash.bin，需先下载二进制组件（Binary Blobs）：

```text
west blobs fetch hal_nxp
```

注意（Note）

建议在 `west update` 之后运行上述命令。

构建及写入flash.bin有两种方法。

1. 若板卡变体没有CONFIG_BOARD_NXP_SPSDK_IMAGE，应按i.MX95 [MCUX SDK发行版](https://mcuxpresso.nxp.com/)中的Getting Started with MCUXpresso SDK for IMX95LPD5EVK-19.pdf生成并写入flash.bin。DDR变体需使用名称包含ddr的Makefile目标。参见第4.2节“运行示例应用”，将zephyr.bin重命名为m7_image.bin，生成flash.bin并写入SD／eMMC。

2. 若板卡变体提供并启用CONFIG_BOARD_NXP_SPSDK_IMAGE，将自动生成flash.bin。执行以下编程命令前，将SW7[1:4]设为0b1001，以USB下载模式启动，并将USB1及DBG连接PC。系统枚举4个115200、8N1串口，第1个用于M7，第4个用于M33 System Manager。spsdk烧录工具已通过scripts/requirements.txt安装；Linux下需按[https://spsdk.readthedocs.io](https://spsdk.readthedocs.io)安装指南配置USB设备权限。

```text
# load and run without programming. for next flashing, execute 'reset' in the
# fourth serail port
$ west flash

# program to SD card, then set SW7[1:4]=0b1011 to reboot
$ west flash --bootdevice sd

# program to emmc card, then set SW7[1:4]=0b1010 to reboot
$ west flash --bootdevice=emmc
```

Zephyr支持两个基于M7的i.MX95目标：imx95_evk/mimx9596/m7和imx95_evk/mimx9596/m7/ddr。主要区别是内存：前者使用紧耦合存储器（TCM），ITCM存放代码及通常的只读数据，DTCM存放可读写数据；后者使用DDR。


1. 为基于TCM的目标构建[Hello World](../getting_started/P005_HelloWorld示例.md#hello_world)应用

```text
# From the root of the zephyr repository
west build -b imx95_evk/mimx9596/m7 samples/hello_world
```


1. 为基于DDR的目标构建[Hello World](../getting_started/P005_HelloWorld示例.md#hello_world)应用

```text
# From the root of the zephyr repository
west build -b imx95_evk/mimx9596/m7/ddr samples/hello_world
```

生成flash.bin并写入SD／eMMC后，打开串口终端并复位开发板。imx95_evk/mimx9596/m7目标应显示类似以下输出：

```text
*** Booting Zephyr OS build v3.6.0-4569-g483c01ca11a7 ***
Hello World! imx95_evk/mimx9596/m7
```

imx95_evk/mimx9596/m7/ddr目标则应显示以下输出：

```text
*** Booting Zephyr OS build v3.6.0-4569-g483c01ca11a7 ***
Hello World! imx95_evk/mimx9596/m7/ddr
```
