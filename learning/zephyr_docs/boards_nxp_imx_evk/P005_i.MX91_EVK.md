## 概述（Overview）

i.MX 91评估套件（Evaluation Kit），即MCIMX91-EVK，用于展示i.MX 91应用处理器的常用功能。它是体积小、成本低的入门开发板，帮助开发者先熟悉处理器，再为更具体的设计投入大量资源。

i.MX 91应用处理器具有一个Arm Cortex-A55核，最高1.4 GHz。


- 开发板特性（Board Features）：


  - RAM：2 GB LPDDR4
  - 存储（Storage）：


    - SanDisk 16 GB eMMC 5.1
    - microSD卡插槽（Socket）
  - 无线（Wireless）：


    - Murata Type-2EL模块，接口为SDIO、UART及SPI；基于NXP IW612 SoC，支持2.4 GHz／5 GHz双频1×1 Wi-Fi 6、蓝牙5.2及802.15.4
  - 通用串行总线（USB）：


    - 两个USB 2.0 Type-C连接器
  - 以太网（Ethernet）：


    - ENET：10/100/1000 Mbit/s RGMII以太网，连接外部RTL8211 PHY
    - ENET_QoS：支持时间敏感网络（TSN）的10/100/1000 Mbit/s RGMII以太网，连接外部RTL8211 PHY
  - PCI Express（PCIe）：


    - 一个75引脚M.2／NGFF Key E迷你卡连接器
  - 接插件（Connectors）：


    - 40引脚双排排针
  - 发光二极管（LED）：


    - 1个电源状态LED
    - 两个UART LED
  - 调试（Debug）：


    - 20引脚JTAG连接器
    - 用于UART调试的Micro-USB

<a id="option-1-boot-zephyr-by-using-jlink-runner"></a>

### 选项1：使用J-Link运行工具（Runner）启动Zephyr

默认运行工具为J-Link。使用J-Link调试器将EVK的JTAG连接器接至主机，给开发板上电，并停在U-Boot命令行。

随后使用west flash或west debug，从主机加载zephyr.bin，在A55 core0上启动Zephyr应用。

<a id="flash-and-run"></a>

#### 烧录与运行（Flash and Run）

下面以[Hello World](../getting_started/P005_HelloWorld示例.md#hello_world)应用为例。

```text
# From the root of the zephyr repository
west build -b imx91_evk/mimx9131 samples/hello_world
west flash
```

UART1控制台应显示以下日志：

```text
*** Booting Zephyr OS build v4.1.0-3063-g2c7ef313ac38 ***
Hello World! imx91_evk/mimx9131
```

<a id="debug"></a>

#### 调试（Debug）

下面以[Hello World](../getting_started/P005_HelloWorld示例.md#hello_world)应用为例。

```text
# From the root of the zephyr repository
west build -b imx91_evk/mimx9131 samples/hello_world
west debug
```

<a id="option-2-boot-zephyr-by-using-u-boot-command"></a>

### 选项2：使用U-Boot命令启动Zephyr

使用U-Boot的go命令加载Zephyr，并启动Cortex-A55内核运行。

将编译的zephyr.bin复制到SD卡第一个FAT分区，插入开发板，上电后在提示符处停止U-Boot执行。

使用U-Boot加载zephyr.bin，并启动Cortex-A55核：

```text
fatload mmc 1:1 0x80000000 zephyr.bin; dcache flush; icache flush; go 0x80000000
```

此配置可运行基础Zephyr应用及内核测试，例如[基础同步（Basic Synchronization）](../basic_samples/P029_基本同步示例.md#synchronization)示例：

```text
# From the root of the zephyr repository
west build -b imx91_evk/mimx9131 samples/synchronization
```

这将构建包含同步（Synchronization）示例的镜像，启动后控制台输出如下：

```text
*** Booting Zephyr OS build v4.0.0-3277-g69f43115c9a8 ***
thread_a: Hello World from cpu 0 on imx91_evk!
thread_b: Hello World from cpu 0 on imx91_evk!
thread_a: Hello World from cpu 0 on imx91_evk!
thread_b: Hello World from cpu 0 on imx91_evk!
```

<a id="option-3-boot-zephyr-by-using-spsdk-runner"></a>

### 选项3：使用SPSDK运行工具（Runner）启动Zephyr

SPSDK运行工具使用SPSDK工具集，网址[https://spsdk.readthedocs.io](https://spsdk.readthedocs.io)，构建包含全部所需固件组件的可启动镜像flash.bin。west flash可将其下载到DDR、SD卡或eMMC闪存。该镜像不包含U-Boot，因此由可信固件A（TF-A）直接启动Cortex-A55核上的Zephyr。

使用SPSDK运行工具前需要获取二进制组件（Binary Blobs），命令如下：

```text
west blobs fetch hal_nxp
```

注意（Note）

建议在 `west update` 之后运行上述命令。

SPSDK运行工具通过CONFIG_BOARD_NXP_SPSDK_IMAGE启用，IMX91 EVK默认未启用。以下以基本同步（[Basic Synchronization](../basic_samples/P029_基本同步示例.md#synchronization)）示例说明如何启用：

```text
# From the root of the zephyr repository
west build -b imx91_evk/mimx9131 samples/synchronization -- -DCONFIG_BOARD_NXP_SPSDK_IMAGE=y
```

若板卡变体提供并启用CONFIG_BOARD_NXP_SPSDK_IMAGE，将自动生成flash.bin。执行以下编程命令前，将板上SW1301[3:0]设为0b0011，以USB下载模式启动，并将USB1及DBG连接Linux主机。系统枚举两个115200、8N1串口，第一个用于Cortex-A55 Zephyr控制台。spsdk烧录工具已通过scripts/requirements.txt安装；Linux下需按[https://spsdk.readthedocs.io](https://spsdk.readthedocs.io)安装指南设置USB设备权限。

```text
# load and run without programming. for next flashing, need to reset the board firstly
$ west flash -r spsdk

# program to SD card, then set SW1301[3:0]=0b0010 to reboot from SD
$ west flash -r spsdk --bootdevice sd

# program to emmc card, then set SW1301[3:0]=0b0000 to reboot from EMMC
$ west flash -r spsdk --bootdevice=emmc
```

Zephyr日志随后显示在第一个串口控制台。
