## 概述（Overview）

i.MX8M Nano LPDDR4 EVK基于NXP i.MX8M Nano应用处理器，由四核Cortex-A53集群及单个Cortex-M7核组成。Zephyr OS移植于Cortex-A53核。


- 开发板特性（Board Features）：


  - RAM：2 GB LPDDR4
  - 存储（Storage）：


    - SanDisk 16 GB eMMC 5.1
    - Micron 32 MB QSPI NOR闪存
    - microSD卡插槽（Socket）
  - 无线（Wireless）：


    - Wi-Fi：2.4／5 GHz，IEEE 802.11b/g/n
    - 蓝牙（Bluetooth）v4.1
  - 通用串行总线（USB）：


    - USB OTG：2个Type-C接口
  - 以太网（Ethernet）
  - PCI-E M.2
  - 接插件（Connectors）：


    - 40引脚双排排针
  - 发光二极管（LED）：


    - 1个电源状态LED
    - 1个UART LED
  - 调试（Debug）


    - 20引脚JTAG连接器
    - Micro-USB用于UART调试，提供分别用于A53和M7的两个COM端口

开发板更多信息见[NXP网站](https://www.nxp.com/design/development-boards/i-mx-evaluation-and-development-boards/evaluation-kit-for-the-i-mx-8m-nano-applications-processor:8MNANOD4-EVK)。

有多种在A53核上编程及调试Zephyr的方法：

<a id="option-1-boot-zephyr-by-using-jlink-runner"></a>

### 选项1：使用J-Link运行工具（Runner）启动Zephyr

默认运行工具为J-Link。使用J-Link调试器将EVK的JTAG连接器接至主机，给开发板上电，并停在U-Boot命令行。

随后使用west flash或west debug，从主机加载zephyr.bin，在A53 core0上启动Zephyr应用。

<a id="flash-and-run"></a>

#### 烧录与运行（Flash and Run）

下面以[Hello World](../getting_started/P005_HelloWorld示例.md#hello_world)应用为例。

```text
# From the root of the zephyr repository
west build -b imx8mn_evk/mimx8mn6/a53 samples/hello_world
west flash
```

UART4控制台应显示以下日志：

```text
*** Booting Zephyr OS build v4.1.0-3063-g38519ca2c028 ***
Hello World! imx8mn_evk/mimx8mn6/a53
```

<a id="debug"></a>

#### 调试（Debug）

下面以[Hello World](../getting_started/P005_HelloWorld示例.md#hello_world)应用为例。

```text
# From the root of the zephyr repository
west build -b imx8mn_evk/mimx8mn6/a53 samples/hello_world
west debug
```

<a id="option-2-boot-zephyr-by-using-u-boot-command"></a>

### 选项2：使用U-Boot命令启动Zephyr

U-Boot的cpu命令用于加载Zephyr并启动Cortex-A次级核。原文说明，最新U-Boot版本已通过一系列补丁支持该命令；此处保留来源的版本表述。（[补丁系列](https://patchwork.ozlabs.org/project/uboot/list/?series=417536&archive=both&state=*)）

<a id="step-1-download-zephyr-image-into-ddr-memory"></a>

#### 步骤1：将Zephyr镜像下载到DDR存储器

首先将Zephyr二进制镜像下载到DDR，可使用TFTP：

```text
tftp 0x93c00000 zephyr.bin
```

也可将zephyr.bin复制到SD卡，并插入开发板。例如，镜像在SD卡FAT分区中时，用以下U-Boot命令加载到DDR。示例假定SD卡设备编号为1、FAT分区编号为1，应按实际配置调整：

```text
fatload mmc 1:1 0x93c00000 zephyr.bin;
```

<a id="step-2-boot-zephyr"></a>

#### 步骤2：启动Zephyr

使用以下命令在core0上启动Zephyr：

```text
dcache off; icache flush; go 0x93c00000;
```

也可用cpu命令从次级核启动，例如Core1：

```text
dcache flush; icache flush; cpu 1 release 0x93c00000
```

此配置可运行基础Zephyr应用及内核测试，例如[基础同步（Basic Synchronization）](../basic_samples/P029_基本同步示例.md#synchronization)示例：

```text
# From the root of the zephyr repository
west build -b imx8mn_evk/mimx8mn6/a53 samples/synchronization
```

这会构建包含同步示例应用的镜像，启动它并显示以下RAM控制台输出：

```text
*** Booting Zephyr OS build v4.1.0-3063-g38519ca2c028 ***
thread_a: Hello World from cpu 0 on mimx8mn_evk!
thread_b: Hello World from cpu 0 on mimx8mn_evk!
thread_a: Hello World from cpu 0 on mimx8mn_evk!
thread_b: Hello World from cpu 0 on mimx8mn_evk!
thread_a: Hello World from cpu 0 on mimx8mn_evk!
```
