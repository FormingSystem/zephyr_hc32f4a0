# 第20章\_蓝牙LE控制器配置片段

原文：[官方页面](https://docs.zephyrproject.org/latest/snippets/bt-ll-sw-split/README.html)。读取日期：2026-10-14；保存的latest页面及HTML摘要见[来源记录](../SOURCES.md)。

可按照[配置片段使用说明](P002_使用配置片段.md#using-snippets)，使用本片段构建。通过west构建时，可以使用：

```sh
west build -S bt-ll-sw-split [...]
```

<a id="overview"></a>

## 20.1 概述（Overview）

本片段选择Zephyr低功耗蓝牙（Bluetooth Low Energy，Bluetooth LE）控制器。

<a id="requirements"></a>

## 20.2 要求（Requirements）

硬件须支持：

- [`CONFIG_BT`](https://docs.zephyrproject.org/latest/kconfig.html#CONFIG_BT)。

> 译注——现有节点：当前配置启用蓝牙，并通过覆盖文件启用`bt_hci_controller`、将`zephyr,bt-hci`指向它。片段名称中的software-split是控制器实现的名称，不能据此认为任意不带蓝牙控制器节点的板都能获得无线功能。


> 译注——片段源码：[snippet.yml](../../../snippets/bt-ll-sw-split/snippet.yml)、[bt-ll-sw-split.conf](../../../snippets/bt-ll-sw-split/bt-ll-sw-split.conf)、[bt-ll-sw-split.overlay](../../../snippets/bt-ll-sw-split/bt-ll-sw-split.overlay)。片段定义中的名称为`bt-ll-sw-split`；本地参照版本可能与所保存的官方main版本不同。

> 译注——构建占位符：原文`[...]`表示由读者补充的板目标、应用路径等构建参数，实际执行时不能保留方括号省略号。构建位置与片段搜索方法见[使用配置片段](P002_使用配置片段.md)。本文仅翻译和核对，没有执行这些命令。
