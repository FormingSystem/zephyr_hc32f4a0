# 第51章\_TI引脚扩展配置片段

原文：[官方页面](https://docs.zephyrproject.org/latest/snippets/ti/ti-io-exp/README.html)。读取日期：2026-10-14；保存的latest页面及HTML摘要见[来源记录](../SOURCES.md)。

<a id="overview"></a>

## 51.1 概述（Overview）

本片段在Texas Instruments（TI）开发板上启用输入／输出扩展器（Input/Output Expander，I/O Expander）功能。

<a id="supported-boards"></a>

## 51.2 支持的开发板（Supported boards）

- AM62L EVM。

<a id="usage"></a>

## 51.3 用法（Usage）

要启用I/O扩展器功能，在构建中添加本片段。原页面给出的命令如下：

```sh
# From the root of the zephyr repository
west build -b am62l_evm/am62l3/a53 --shield ti-io-exp samples/drivers/pwm/capture
```

> 译注——原命令的选项：原页面在介绍片段时使用了`--shield ti-io-exp`。`--shield`选择扩展板（Shield）；根据当前`snippet.yml`中的片段定义，选择这个配置片段应使用`-S ti-io-exp`。下面只纠正片段选择选项，保留原板目标和示例；它不表示已经验证该硬件构建或接线。

```sh
# 终端：UCRT64 Bash或Linux Bash；工作目录：Zephyr源码根目录
# 前提：目标板、工具链和应用依赖已准备好
west build -b am62l_evm/am62l3/a53 -S ti-io-exp samples/drivers/pwm/capture
```

> 译注——实际配置：当前板级覆盖配置`main_gpio0_2`的GPIO0_89复用，并通过GPIO占用声明（GPIO Hog）将`vout-fet-sel0`输出置高；对应配置启用`CONFIG_GPIO`和`CONFIG_GPIO_HOGS`。这是AM62L EVM的具体信号选择配置，不是给任意板添加通用扩展器芯片。原例使用的[脉宽调制捕获示例](../hardware/P169_PWM输入捕获示例.md)仍有其自己的输入与接线要求。
