# 第6章\_视频原生命名管道配置片段

原文：[Video Native FIFO Snippet (video-native-fifo)](https://docs.zephyrproject.org/latest/snippets/video-native-fifo/README.html)。读取日期：2026-10-13，`latest`。

## 6.1\_使用形式

在 `native_sim` 主机原生仿真目标中使用 `video-native-fifo` **配置片段（Snippet）**：

```bash
west build -b native_sim/native/64 -S video-native-fifo [...]
```

译注：`[...]` 是原文的其余参数占位符，实际执行时须补充应用等参数。在已配置 Zephyr 开发环境的终端中，从 Zephyr 源码根目录运行完整命令；片段由官方仓库提供，west 生成构建产物。完整主机输入例子见[视频采集示例](../hardware/P173_视频采集示例.md)。

## 6.2\_概述（Overview）

该片段实例化 `native_sim` 的主机 **先进先出（First In, First Out，FIFO）**视频源，并在 **设备树（Devicetree）**中将其设为 `zephyr,camera` 对应的选定节点（Chosen Node）。主机端通过命名管道（Named Pipe）输送视频帧。

管道默认位于主机系统临时目录，文件名为 `zephyr-video-fifo-<pid>.fifo`；启动视频流时会打印实际路径。译注：`<pid>` 为进程标识符（Process Identifier，PID），原驱动默认目录是主机根目录下的 `tmp`。项目内相对路径的显式指定方式见前述采集示例，此处不把默认目录写成本地文档资源链接。

应用决定分辨率和像素格式，默认是 320×240 的 `RGB565`：红、绿、蓝（Red, Green, Blue，RGB）分量分别使用 5、6、5 位。

如何指定管道路径、从摄像头或测试图案输入帧，以及驱动的具体行为，见[原生命名管道视频驱动说明](../native_reference/P004_Native_Simulator本机模拟器.md#nsim-per-video-fifo)。

## 6.3\_要求（Requirements）

需要 [native_sim原生仿真目标](../native_reference/P004_Native_Simulator本机模拟器.md#native_sim)，以及一个向命名管道写入所选格式原始帧（Raw Frame）的主机进程。必须通过 [`CONFIG_VIDEO_BUFFER_POOL_HEAP_SIZE`](https://docs.zephyrproject.org/latest/kconfig.html#CONFIG_VIDEO_BUFFER_POOL_HEAP_SIZE) 指定视频缓冲池堆大小（Video Buffer Pool Heap Size），为所选分辨率准备足够内存。
