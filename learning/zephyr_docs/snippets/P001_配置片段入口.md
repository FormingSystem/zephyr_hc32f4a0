# 第1章\_配置片段入口

原文：[Snippets](https://docs.zephyrproject.org/latest/build/snippets/index.html)。读取日期：2026-10-12，`latest`。

**配置片段（Snippet）**把一组构建系统设置集中保存在一个位置，并允许构建任意 Zephyr 应用时复用。这样，适用于多个应用的共同配置就能独立维护，而不用在每个应用中重复编写。

> 译注：本模块的 Snippet 是由 `snippet.yml` 描述的构建配置组合，可同时包含设备树覆盖、Kconfig 文件等；它不只是一个 `.conf` 文件，也不是复制到 C 源码中的代码片段。

## 1.1\_适用场景

原文给出以下示例：

- 把开发板的控制台后端从实际的 **通用异步收发器（Universal Asynchronous Receiver-Transmitter，UART）**换成基于 **通用串行总线（Universal Serial Bus，USB）**的 **通信设备类—抽象控制模型（Communications Device Class—Abstract Control Model，CDC-ACM）**虚拟串口。
- 启用经常使用的调试选项。
- 对采用**非对称多处理（Asymmetric Multiprocessing，AMP）**的**片上系统（System on Chip，SoC）**，将彼此关联的配置应用到主**中央处理器（Central Processing Unit，CPU）**与协处理器核心。
