# 第5章\_视频软件发生器配置片段

原文：[Video Software Generator Snippet (video-sw-generator)](https://docs.zephyrproject.org/latest/snippets/video-sw-generator/README.html)。读取日期：2026-10-13，`latest`。

## 5.1\_使用形式

使用 **配置片段（Snippet）** `video-sw-generator` 时，west 构建命令形式如下：

```bash
west build -S video-sw-generator [...]
```

译注：`[...]` 是原文的其余参数占位符，不能按原样执行。在已配置 Zephyr 开发环境的终端中，从 Zephyr 源码根目录选择开发板与应用，完整示例见[视频采集示例](../hardware/P173_视频采集示例.md)。该配置片段由官方仓库提供，构建产物由 west 生成。

## 5.2\_概述（Overview）

该片段实例化一个模拟视频源（Fake Video Source），持续产生用于测试的图案（Test Pattern），并将它选为 **设备树（Devicetree）**中 `zephyr,camera` 对应的选定节点（Chosen Node）。

## 5.3\_要求（Requirements）

不需要专门的硬件支持，但必须通过 [`CONFIG_VIDEO_BUFFER_POOL_HEAP_SIZE`](https://docs.zephyrproject.org/latest/kconfig.html#CONFIG_VIDEO_BUFFER_POOL_HEAP_SIZE) 为所用视频分辨率准备足够的内存。该配置项指定视频缓冲池的堆大小（Video Buffer Pool Heap Size）。
