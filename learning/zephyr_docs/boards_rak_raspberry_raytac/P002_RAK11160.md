## 概述（Overview）

RAK11160是一款基于STM32WLE5 MCU的WisDuo模块，集成LoRa收发器，并通过Espressif ESP8684H2协处理器支持蓝牙及Wi-Fi连接。该模块适用于家庭自动化、传感器网络、楼宇自动化及其他物联网（IoT）网络应用。

<a id="hardware"></a>

## 硬件（Hardware）

模块具有以下硬件功能：STM32WLE5CC MCU，采用48 MHz的低功耗广域网（LPWAN）单核Cortex-M4；256 KB闪存及64 KB SRAM；支持LoRa调制的射频收发器；256位AES硬件加密及真随机数发生器；LoRa及BLE／Wi-Fi天线SMA连接器；32位单核RISC-V ESP8684 MCU，内含2 MB闪存并支持802.11b/g/n；支持Bluetooth 5及Bluetooth Mesh功能的低功耗蓝牙（Bluetooth LE）子系统。

```text
# From the root of the zephyr repository
west build -b rak11160 samples/hello_world
west flash
```

运行串口终端连接开发板。默认通过USB转TTL转换器访问usart1。


- 速率（Speed）：115200波特率
- 数据位（Data）：8位
- 奇偶校验（Parity）：无（None）
- 停止位（Stop Bits）：1位

```text
Hello World! rak11160/stm32wle5xx
```
