[浏览开发板源码（Browse Board Sources）](https://github.com/zephyrproject-rtos/zephyr/blob/main//boards/rakwireless/rak11720/doc/index.rst/../..)RAK11720是RAK WisBlock的WisBlock Core模块，采用Ambiq的高性能超低功耗Apollo3 Blue SoC，型号AMA3B1KK-KBR-B0，并配有Semtech SX1262 LoRa收发器。

AMA3B1KK-KBR-B0集成低功耗蓝牙（Bluetooth Low Energy）收发器，可增强通信能力。RAK11720邮票孔模块与RAK3172模块尺寸及焊盘布局相同，因此无需设计新PCB，就可为已有设计增加BLE能力。

<a id="hardware"></a>

## 硬件（Hardware）

使用RAK11720的简便方式是WisBlock模块化系统：将RAK11722，即搭载RAK11720的WisBlock Core模块，插入提供电源及编程／调试接口的RAK19007 WisBlock底板（Base Board）。


- Apollo3 Blue片上系统（SoC），最高工作频率96 MHz
- ARM® Cortex®-M4F内核（Core）
- 每个内核配有16 kB两路组相联／直接映射缓存（2-Way Associative / Direct-Mapped Cache）
- 最多1 MB闪存（Flash），用于代码和数据
- 最多384 KB低漏电／低功耗RAM，用于代码和数据
- 集成Bluetooth 5低功耗控制器（Low-Energy Controller）
- Semtech SX1262低功耗远距离LoRa收发器
- LoRa及BLE天线iPEX连接器
- RAK19007 WisBlock底板上的两个用户LED
- 可通过Micro-USB、3.7 V可充电电池或5 V太阳能板端口供电

RAK11720邮票孔模块的更多信息见：


- [WisDuo RAK11720网站](https://docs.rakwireless.com/product-categories/wisduo/rak11720-module/overview/)
- [WisBlock RAK11722网站](https://docs.rakwireless.com/product-categories/wisblock/rak11722/overview/)

RAK11720开发板应连接SEGGER嵌入式调试单元[J-Link OB](https://www.segger.com/jlink-ob.html)，为Apollo3 Blue芯片提供调试接口。可使用J-Link与Apollo3 Blue通信。

<a id="flashing-an-application"></a>

#### 烧录应用（Flashing an Application）

使用JLINK USB端口将设备连接到主机。以下以[Hello World](../getting_started/P005_HelloWorld示例.md#hello_world)示例应用说明：构建Zephyr内核和应用，然后烧录到设备。

```text
# From the root of the zephyr repository
west build -b rak11720 samples/hello_world
west flash
```

注意（Note）

`west flash`要求主机上安装[SEGGER J-Link软件](https://www.segger.com/downloads/jlink)和[pylink](https://github.com/Square/pylink) Python模块。

打开串口终端（如minicom或PuTTY），设置如下：


- 速率（Speed）：115200波特率
- 数据位（Data）：8位
- 奇偶校验（Parity）：无（None）
- 停止位（Stop Bits）：1位

复位开发板后，应能在相应串口（Serial Port）看到以下消息：

```text
Hello World! rak11720/apollo3_blue
```

RAK11720模块搭载于RAK11722核心板，再插入RAK19007底板；三者不可混作同一器件。
