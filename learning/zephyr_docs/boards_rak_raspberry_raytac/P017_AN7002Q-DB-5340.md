## 概述（Overview）

<a id="id3"></a>

<a id="id5"></a>

Raytac AN7002Q-DB-5340是一款单板开发套件，用于评估及开发nRF7002。nRF7002是配合Raytac MDBT53模块主处理器使用的Wi-Fi伴随芯片（Companion IC）。该套件已通过Wi-Fi Alliance的Wi-Fi认证计划[注1](#id2)中的连接、安全及优化类别认证，详情见[UG Wi-Fi certification](https://docs.nordicsemi.com/bundle/ncs-latest/page/nrf/protocols/wifi/wifi_certification.html#ug-wifi-certification) [注2](#id4)。（[Wi-Fi认证计划（Certification Program）](https://www.wi-fi.org/certification)）

nRF7002符合IEEE 802.11ax，即Wi-Fi 6，实现Wi-Fi物理层及媒体访问控制（MAC）层协议。nRF Wi-Fi驱动软件运行于nRF5340主处理器，通过QSPI总线与nRF7002通信。

nRF5340主处理器是基于Arm® Cortex®-M33架构的双核SoC，具有以下特性：


- 功能完整的Arm Cortex-M33F内核，支持DSP指令、浮点单元（FPU）及Armv8-M安全扩展（Security Extension），最高运行频率128 MHz，称为应用核（Application Core）。
- 功能精简的第二个Arm Cortex-M33内核，固定运行于64 MHz，称为网络核（Network Core）。

raytac_an7002q_db/nrf5340/cpuapp目标支持nRF5340 SoC的应用核（Application Core），raytac_an7002q_db/nrf5340/cpunet目标支持其网络核（Network Core）。

<a id="security-components"></a>

#### 安全组件（Security Components）

提供以下安全组件：


- <a id="id7"></a>

  应用核上的实现定义属性单元（[IDAU](https://developer.arm.com/docs/100690/latest/attribution-units-sau-and-idau)）[注3](#id6)。

  IDAU由系统保护单元（System Protection Unit）实现，用于定义安全及非安全内存映射。默认情况下，全部存储空间，包括闪存、SRAM及外设地址空间，都只能由安全访问使用。
- 安全启动（Secure Boot）。

nRF5340应用核支持Armv8-M安全扩展（Security Extension）。为raytac_an7002q_db/nrf5340/cpuapp构建的应用默认以安全状态（Secure State）启动。

nRF5340网络核不支持Armv8-M安全扩展。IDAU可为网络核总线访问设置安全属性，因此可在nRF5340上构建并运行仅安全应用。

<a id="building-secure-non-secure-zephyr-applications-with-arm-trustzone"></a>

### 使用Arm® TrustZone®构建安全／非安全Zephyr应用

<a id="id14"></a>

nRF5340应用可为应用核包含安全及非安全固件镜像。安全镜像可用Zephyr或Trusted Firmware-M（TF-M）[注6](#id13) 构建，非安全镜像始终使用Zephyr。以下分别介绍两种方案。（[可信固件M（TF-M / Trusted Firmware M）](https://www.trustedfirmware.org/projects/tf-m/)）

注意（Note）

默认使用TF-M构建nRF5340应用核的安全处理环境（SPE / Secure Processing Environment）。

<a id="building-the-secure-firmware-with-tf-m"></a>

#### 使用TF-M构建安全固件（Secure Firmware）

用TF-M构建安全镜像、用Zephyr构建非安全镜像，需要以下步骤：


1. 使用-DBOARD=raytac_an7002q_db/nrf5340/cpuapp/ns为应用核构建非安全（Non-Secure）Zephyr应用。Zephyr构建系统需要启用BUILD_WITH_TFM Kconfig选项才能调用TF-M构建；将Zephyr构建为非安全应用时默认启用该选项。构建系统将自动执行以下步骤：


  - 按常规Zephyr应用构建非安全固件镜像
  - 构建TF-M安全固件镜像（Secure Firmware Image）
  - 合并生成的二进制镜像
  - 按需构建引导加载程序镜像（MCUboot）

注意（Note）

根据TF-M配置，可能需要应用设备树覆盖文件（DTS Overlay）来调整非安全镜像的闪存及SRAM起始地址与大小。


1. 使用-DBOARD=raytac_an7002q_db/nrf5340/cpunet构建网络核应用固件。

<a id="building-the-secure-firmware-using-zephyr"></a>

#### 使用Zephyr构建安全固件

使用Zephyr同时构建安全及非安全固件镜像，需要以下步骤：


1. 使用-DBOARD=raytac_an7002q_db/nrf5340/cpuapp为应用核构建安全（Secure）Zephyr应用，并在应用项目配置文件中设置CONFIG_TRUSTED_EXECUTION_SECURE=y及CONFIG_BUILD_WITH_TFM=n。
2. 使用-DBOARD=raytac_an7002q_db/nrf5340/cpuapp/ns为应用核构建非安全（Non-Secure）Zephyr应用。
3. 将两个二进制文件合并。
4. 使用-DBOARD=raytac_an7002q_db/nrf5340/cpunet构建网络核应用固件。

为nRF5340应用核构建安全／非安全应用时，安全应用必须配置IDAU，即安全保护单元（SPU），允许非安全固件访问其使用的全部CPU资源。必须在跳转到非安全应用之前完成SPU配置。

<a id="building-a-secure-only-application"></a>

### 构建仅安全态应用（Building a Secure Only Application）

按常规方式构建Zephyr应用，见“构建应用”及“运行应用”。应用核固件使用-DBOARD=raytac_an7002q_db/nrf5340/cpuapp，网络核固件使用-DBOARD=raytac_an7002q_db/nrf5340/cpunet。（[构建应用（Building an Application）](../application/P001_应用开发.md#build-an-application)；[运行应用（Run an Application）](https://docs.zephyrproject.org/latest/develop/application/index.html#application-run)）

<a id="flashing"></a>

### 烧录（Flashing）

按照[Nordic nRF5x Segger J-Link](../debugging/P005_Nordic_Segger_JLink.md#nordic-segger)页面安装并配置所需软件；更多信息见[烧录（Flashing）](../debugging/P005_Nordic_Segger_JLink.md#nordic-segger-flashing)。随后即可按常规方式构建和烧录应用，详见构建应用及运行应用。（[构建应用（Building an Application）](../application/P001_应用开发.md#build-an-application)；[运行应用（Run an Application）](https://docs.zephyrproject.org/latest/develop/application/index.html#application-run)）

警告（Warning）

nRF5340支持闪存读回保护（Flash Read-back Protection）。该保护启用时，再次烧录前需要恢复芯片（Recover）。若用[west](https://docs.zephyrproject.org/latest/develop/west/build-flash-debug.html#west-build-flash-debug)烧录，执行以下命令查看相关--recover选项详情：

```text
$ west flash -H -r nrfjprog --no-rebuild
```

注意（Note）

原文要求，将nRF Command Line Tools升级到10.12.0版本后再烧录和调试nRF5340 DK应用。工具安装详情见[烧录（Flashing）](../debugging/P005_Nordic_Segger_JLink.md#nordic-segger-flashing)。

以下以运行于nRF5340应用核的[Hello World](../getting_started/P005_HelloWorld示例.md#hello_world)应用为例。

首先运行常用终端程序查看输出。

```text
$ minicom -D <tty_device> -b 115200
```

将<tty_device>替换为nRF7002 DK所在串口，例如Linux下的/dev/ttyACM0。

随后按通常方式构建并烧录应用。

```text
# From the root of the zephyr repository
west build -b raytac_an7002q_db/nrf5340/cpuapp samples/hello_world
west flash
```
