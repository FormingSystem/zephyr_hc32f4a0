## 概述（Overview）

WisTrio NB-IoT Tracker Pro（RAK5010）是一款集成LTE CAT M1及NB1、GPS、BLE和传感器的追踪器（Tracker）。它采用Quectel BG96 LTE CAT M1及NB1模块，该模块集成GPS接收器；开发板由Nordic nRF52840微控制器运行。

由于同时具有GPS及BLE，它适用于需要基于位置服务（Location-based Services）的室外和室内场景。

RAK5010内置温湿度、运动、压力及光照传感器，还可通过扩展I/O增加板载传感器之外的其他传感器。

该板特别适合作为需要窄带物联网（NB-IoT）连接的应用快速测试及原型工具，应用开发支持GCC环境。

<a id="hardware"></a>

## 硬件（Hardware）


- nRF52840 ARM Cortex-M4F处理器
- 32.768 kHz晶体振荡器（Crystal Oscillator）
- 一个Micro-AB USB OTG主机／设备接口
- Quectel BG96，支持LTE CAT M1、LTE NB1及全球导航卫星系统（GNSS）
- LTE及GPS天线使用iPEX连接器，BLE采用板载陶瓷天线
- 提供nano-SIM及eSIM选项
- 多种接口：I2C、UART、GPIO及ADC
- 一个用户LED
- 一个SHTC3温湿度传感器
- 一个OPT3001DNPR环境光传感器
- 一个LPS22HB压力传感器
- 一个LIS3DH运动传感器
- 可通过Micro-USB、3.7 V可充电电池或5 V太阳能板端口供电

RAK5010开发板应连接SEGGER嵌入式调试单元[J-Link OB](https://www.segger.com/jlink-ob.html)，为nRF52840芯片提供调试接口。可使用J-Link与nRF52840通信。

<a id="flashing"></a>

### 烧录（Flashing）


1. <a id="id3"></a>

  从SEGGER [JLink下载页面](https://www.segger.com/downloads/jlink)[注1](#id2)获取JLink，在“J-Link Software and Documentation Pack”一节安装Linux版软件及文档包。应确保`JLinkExe`可通过`PATH`找到。
2. 运行你惯用的终端程序，监听输出。Linux下的终端设备应为`/dev/ttyACM0`，例如：

  ```text
  $ minicom -D /dev/ttyACM0 -o
  ```

  `-o`选项让`minicom`不发送调制解调器初始化字符串（Modem Initialization String）。连接参数应配置如下：


  - 速率（Speed）：115200波特率
  - 数据位（Data）：8位
  - 奇偶校验（Parity）：无（None）
  - 停止位（Stop Bits）：1位
3. 通过USB调试端口将RAK5010连接主机，随后构建并烧录[Hello World](../getting_started/P005_HelloWorld示例.md#hello_world)应用。

  ```text
  # From the root of the zephyr repository
  west build -b rak5010/nrf52840 samples/hello_world
  west flash
  ```

  应在终端中看到“Hello World! rak5010_nrf52840”。

<a id="debugging"></a>

### 调试（Debugging）

可以按常规方式调试应用。下面以[Hello World](../getting_started/P005_HelloWorld示例.md#hello_world)应用为例。

```text
# From the root of the zephyr repository
west build -b rak5010/nrf52840 samples/hello_world
west debug
```
