## 概述（Overview）

<a id="id3"></a>

[Raspberry Pi Debug Probe](https://www.raspberrypi.com/documentation/microcontrollers/debug-probe.html) [注1](#id2)是一块基于Raspberry Pi Ltd. RP2040微控制器的开发板，通过两个3针连接器引出4个GPIO，并带有Micro-USB-B连接器。

注意（Note）

本页说明将Raspberry Pi Debug Probe作为通用微控制器开发板使用的方法。若要恢复其为其他板卡提供调试的原始用途，需要加载官方固件，方法见下文。

<a id="hardware"></a>

## 硬件（Hardware）


- Raspberry Pi RP2040微控制器（Microcontroller），最高频率133 MHz
- 双ARM Cortex-M0+内核
- 264 kByte静态随机存储器（SRAM）
- 2 Mbyte QSPI闪存
- 6个GPIO，其中4个通过3针连接器引出
- 通用异步收发器（UART）
- USB Micro-B接口
- 启动按键（Boot Button）
- 5个用户LED

<a id="default-zephyr-peripheral-mapping"></a>

### Zephyr默认外设映射（Default Peripheral Mapping）


- LED D1：红色，GPIO2
- LED D2：绿色，靠近UART连接器，GPIO7
- LED D3：黄色，靠近UART连接器，GPIO8
- LED D4：绿色，靠近DBUG连接器，GPIO15
- LED D5：黄色，靠近DBUG连接器，GPIO16
- J2连接器（UART）第1脚（TX）：GPIO4，UART1
- J2连接器（UART）第3脚（RX）：GPIO6
- J2连接器（UART）第3脚（RX），经输入缓冲器（Input Buffer）：GPIO5，UART1
- J3连接器（DBUG）第1脚（CLK）：GPIO12
- J3连接器（DBUG）第3脚（DIO）：GPIO14
- J3连接器（DBUG）第3脚（DIO），经输入缓冲器：GPIO13
- J4连接器第1脚：GPIO0
- J4连接器第3脚：GPIO1

UART及DBUG连接器的引脚串联了100 Ω电阻。

J4默认未装连接器，使用时需要在板上焊接3针排针。

### 烧录（Flashing）

运行[闪灯（Blinky）](../getting_started/P004_LED闪烁示例.md#blinky)示例：

```text
# From the root of the zephyr repository
west build -b rpi_debug_probe samples/basic/blinky/
west flash
```
