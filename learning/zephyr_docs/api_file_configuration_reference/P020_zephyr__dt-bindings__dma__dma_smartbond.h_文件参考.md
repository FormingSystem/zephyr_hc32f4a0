厂商特定的 DMA 外设触发源（Vendor-Specific DMA Peripheral Triggering Sources）。

将 DMA 配置为外设到外设（Peripheral-to-Peripheral）或内存到外设（Memory-to-Peripheral）传输时，应提供有效的触发源（Triggering Source）。
