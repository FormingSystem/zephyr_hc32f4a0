## 7.1\_宏定义（Macros）

<a id="r_ga265c3a81b2f6962b11931028c8727863"></a>

```c
#define DT_ZEPHYR_DISPLAY(idx)
```

相关声明：[DT_ZEPHYR_DISPLAY](../hardware/P227_设备树显示接口.md#ga265c3a81b2f6962b11931028c8727863)。

从兼容字符串为 `zephyr,displays` 的节点的 `displays` 属性中，按逻辑索引取得显示节点标识符。

<a id="r_ga5a5f5bc95a76e4f1d09d970a18e6e5b5"></a>

```c
#define DT_ZEPHYR_DISPLAYS_COUNT
```

相关声明：[DT_ZEPHYR_DISPLAYS_COUNT](../hardware/P227_设备树显示接口.md#ga5a5f5bc95a76e4f1d09d970a18e6e5b5)。

取得 Zephyr 显示设备的数量。

## 7.2\_源码定位与版本边界

相对源码定位：[GPIO宏](../../../include/zephyr/devicetree/gpio.h)、[SPI宏](../../../include/zephyr/devicetree/spi.h)、[CAN宏](../../../include/zephyr/devicetree/can.h)、[显示宏](../../../include/zephyr/devicetree/display.h)、[宏生成器](../../../scripts/dts/gen_defines.py)和[显示列表绑定](../../../dts/bindings/display/zephyr,displays.yaml)。本次官方源码摘要见[来源记录](../SOURCES.md)。

> 译注——源码核对：数量与索引访问的回退不同：DT_ZEPHYR_DISPLAYS_COUNT优先读取状态为okay的zephyr,displays节点的displays长度；没有该节点时，若/chosen含zephyr,display则得到1，否则0。DT_ZEPHYR_DISPLAY(idx)直接访问zephyr,displays列表，不包含chosen回退；仅看到COUNT为1就调用DISPLAY(0)，不保证当前设备树满足后者前提。

> 译注——源码核对：节点选择与有效性：官方zephyr,displays绑定要求设备树中最多一个此兼容节点；宏使用GET_ANY_STATUS_OKAY，不负责拒绝多个匹配节点。索引必须对应列表有效条目，返回节点标识，不是显示设备指针；它不初始化面板、不验证驱动就绪，也不检查所引用显示节点自身的status。

> 译注——源码核对：末尾注释差异：源码实际包含保护是ZEPHYR_INCLUDE_DEVICETREE_DISPLAY_H_，但末尾注释写成ZEPHYR_INCLUDE_DEVICETREE_DMAS_H_。原注释保留并说明，不将其误认为DMA头文件。

> 译注——源码核对：版本边界：本批记录四份设备树头文件、gen_defines.py和zephyr,displays绑定，共六份官方源码摘要；四个源码浏览页的非注释代码与本次读取的原始头文件一致。latest、滚动main和本仓库参照版本不自动等同。本次未构建设备树、配置引脚、执行SPI／CAN传输、初始化显示设备或操作硬件。

本次验证范围为文档与源码对照，未编译宏／DTS示例、构建固件或操作硬件。
