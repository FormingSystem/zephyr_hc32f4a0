# 外设设备树头文件参考大纲

本册完整翻译GPIO、SPI、CAN和显示（Display）设备树宏的四个头文件参考页与源码浏览页。声明、摘要及可见源码均按官方页面保留，详细API说明通过相对链接进入已有专题。

阅读时先区分消费节点、控制器节点及返回对象。GPIO读取控制器、引脚和flags，SPI以从设备reg选择总线cs-gpios条目，CAN组合控制器与收发器的比特率边界，显示宏读取列表或计数。源码跟踪译注说明缺省值、GPIO预占项以及显示数量与索引访问的回退差异；这些宏都不替代运行时设备配置。

专有名词中英文对照，原代码和许可证完整保留，仓库定位使用相对路径。完整范围见[全站进度](../PROGRESS.md)。
