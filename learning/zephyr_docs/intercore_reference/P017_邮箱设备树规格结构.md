# 第17章\_邮箱设备树规格结构

原文：[structmbox__dt__spec](https://docs.zephyrproject.org/latest/doxygen/html/structmbox__dt__spec.html)。读取日期：2026-10-13，`latest`。

`struct mbox_dt_spec`保存来自设备树（Devicetree，DT）的邮箱（Mailbox，MBOX）规格，定义于`zephyr/drivers/mbox.h`。

## 17.1\_设备和通道

| 成员 | 类型 | 含义 |
| --- | --- | --- |
| `dev` | `const struct device *` | 邮箱设备指针 |
| `channel_id` | `mbox_channel_id_t` | 通道编号 |

通道编号类型以`uint32_t`定义。构造此结构的`MBOX_DT_SPEC_GET`和`MBOX_DT_SPEC_INST_GET`宏及接收此结构的函数，见[公共接口](P014_邮箱驱动公共接口.md)，原定义见[完整源码](P020_邮箱驱动头文件源码.md)。
