# 第66章\_消息控制台接收端运行数据结构

原文：[structipm__console__receiver__runtime__data](https://docs.zephyrproject.org/latest/doxygen/html/structipm__console__receiver__runtime__data.html)。读取日期：2026-10-13，`latest`。

`struct ipm_console_receiver_runtime_data`是处理器间邮箱（Inter-Processor Mailbox，IPM）控制台（Console）接收端的运行时数据（Runtime Data）结构，头文件为`zephyr/drivers/console/ipm_console.h`。

## 66.1\_运行时成员

| 类型 | 成员 | 含义 |
| --- | --- | --- |
| `struct ring_buf` | `rb` | 环形缓冲区（Ring Buffer），缓存从底层IPM设备接收的字节 |
| `struct k_sem` | `sem` | 信号量（Semaphore），用于唤醒输出消息的线程 |
| `const struct device *` | `ipm_device` | 指向已绑定底层IPM设备的指针 |
| `int` | `channel_disabled` | 表示通道因缓冲区已满而暂时被禁用的标志 |
| `struct k_thread` | `rx_thread` | 接收工作线程（Receiver Worker Thread） |

原页没有为这些字段给出额外取值约定。本结构文档生成自`zephyr/drivers/console/ipm_console.h`，完整声明见[源码](P064_处理器间消息控制台完整头文件.md)，缓存区域的配置见[接收端配置结构](P065_消息控制台接收端配置结构.md)。
