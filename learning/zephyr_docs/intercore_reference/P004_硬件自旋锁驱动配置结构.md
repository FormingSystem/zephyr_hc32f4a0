# 第4章\_硬件自旋锁驱动配置结构

原文：[structhwspinlock__driver__config](https://docs.zephyrproject.org/latest/doxygen/html/structhwspinlock__driver__config.html)。读取日期：2026-10-13，`latest`。

`struct hwspinlock_driver_config`是所有硬件自旋锁（Hardware Spinlock）驱动共享的配置结构，定义在`zephyr/drivers/hwspinlock.h`。

## 4.1\_结构位置与成员

本结构应当位于驱动自身`struct driver_config`声明的**第一个成员位置**。

| 成员 | 类型 | 含义 |
| --- | --- | --- |
| `num_locks` | `uint8_t` | 驱动支持的硬件自旋锁数量 |
| `locks` | `struct k_spinlock *` | 用于保护底层硬件访问的软件自旋锁（Spinlock）数组 |

由设备树（Devicetree）生成该结构及锁数组的宏见[公共接口](P001_硬件自旋锁公共接口.md)，本地软件锁的规则见[自旋锁接口](../kernel/P065_自旋锁公共接口.md)。原定义见[驱动头文件源码](P007_硬件自旋锁驱动头文件源码.md)。
