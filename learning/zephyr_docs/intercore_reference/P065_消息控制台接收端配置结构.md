# 第65章\_消息控制台接收端配置结构

原文：[structipm__console__receiver__config__info](https://docs.zephyrproject.org/latest/doxygen/html/structipm__console__receiver__config__info.html)。读取日期：2026-10-13，`latest`。

`struct ipm_console_receiver_config_info`是处理器间邮箱（Inter-Processor Mailbox，IPM）控制台（Console）的接收端配置结构，头文件为`zephyr/drivers/console/ipm_console.h`。它配置底层驱动、接收线程栈、字符缓冲区及输出目标。

`CONFIG_IPM_CONSOLE_STACK_SIZE`是控制台线程栈大小配置选项。


## 65.1\_底层设备与线程栈

| 类型 | 成员 | 含义 |
| --- | --- | --- |
| `char *` | `bind_to` | 要绑定的底层IPM驱动名称 |
| `k_thread_stack_t *` | `thread_stack` | 接收线程的栈（Thread Stack）；该线程在消息到来时输出消息，栈大小应为`CONFIG_IPM_CONSOLE_STACK_SIZE` |

## 65.2\_字符缓存与长度单位

环形缓冲区（Ring Buffer）暂存中断回调（Interrupt Callback）收到的字符；行缓冲区（Line Buffer）累积待输出的一行。

| 类型 | 成员 | 含义 |
| --- | --- | --- |
| `uint32_t *` | `ring_buf_data` | 用于暂存中断回调字符的环形缓冲区数据区域 |
| `unsigned int` | `rb_size32` | `ring_buf_data`大小，单位为**32位块** |
| `char *` | `line_buf` | 传入消息的行缓冲区；字符在此累积，缓冲区满（包含末尾的`NULL`终止符）或遇到回车（Carriage Return）时交给`printk()` |
| `unsigned int` | `lb_size` | 行缓冲区大小，单位为**字节**，必须至少为2 |

**术语译注：**此处沿用原文“trailing NULL”的写法，它指字符串末尾的空字符终止符；`rb_size32`的计量单位与`lb_size`不同，不能都按字节解释。

## 65.3\_输出目标

`unsigned int flags`指定接收控制台消息的输出目标，是标准输出（Standard Output，STDOUT）标志`IPM_CONSOLE_STDOUT`或内核打印标志`IPM_CONSOLE_PRINTK`之一。对应原宏值见[控制台头文件参考](P063_处理器间消息控制台头文件参考.md)。

本结构文档生成自`zephyr/drivers/console/ipm_console.h`，完整声明见[源码](P064_处理器间消息控制台完整头文件.md)。
