# 第6章\_硬件自旋锁驱动头文件参考

原文：[drivers_2hwspinlock_8h](https://docs.zephyrproject.org/latest/doxygen/html/drivers_2hwspinlock_8h.html)。读取日期：2026-10-13，`latest`。

`zephyr/drivers/hwspinlock.h`是硬件自旋锁（Hardware Spinlock）驱动应用程序接口（Application Programming Interface，API）的主头文件。实现见[完整源码](P007_硬件自旋锁驱动头文件源码.md)。

## 6.1\_包含的头文件和数据结构


```c
#include <zephyr/types.h>
#include <zephyr/sys/util.h>
#include <zephyr/sys/__assert.h>
#include <zephyr/device.h>
#include <zephyr/spinlock.h>
#include <zephyr/devicetree.h>
```

本头文件定义以下三个结构，设备树（Devicetree，DT）规格由 `hwspinlock_dt_spec` 保存：

| 结构 | 用途 |
| --- | --- |
| [`hwspinlock_dt_spec`](P005_硬件自旋锁设备树规格结构.md) | 完整设备树（Devicetree，DT）规格 |
| [`hwspinlock_driver_config`](P004_硬件自旋锁驱动配置结构.md) | 所有驱动共享且位于配置首成员的结构 |
| [`hwspinlock_driver_api`](P003_硬件自旋锁驱动接口结构.md) | 驱动操作表 |

## 6.2\_宏列表

详细参数、约束和展开式见[公共接口](P001_硬件自旋锁公共接口.md)。

| 宏 | 用途 |
| --- | --- |
| `HWSPINLOCK_DT_SPEC_GET_BY_IDX(node_id, idx)` | 按索引构造设备树规格结构初始化器 |
| `HWSPINLOCK_DT_SPEC_GET_BY_NAME(node_id, name)` | 按名称构造设备树规格结构初始化器 |
| `HWSPINLOCK_DT_SPEC_GET(node_id)` | 构造设备树规格结构初始化器 |
| `HWSPINLOCK_DT_SPEC_INST_GET_BY_IDX(inst, idx)` | 按索引宏的实例版本 |
| `HWSPINLOCK_DT_SPEC_INST_GET_BY_NAME(inst, name)` | 按名称宏的实例版本 |
| `HWSPINLOCK_DT_SPEC_INST_GET(inst)` | 默认规格宏的实例版本 |
| `HWSPINLOCK_COMMON_CONFIG_FROM_DT_NODE(node_id)` | 由节点标识构造公共驱动配置初始化器 |
| `HWSPINLOCK_COMMON_CONFIG_FROM_DT_INST(inst)` | 由DT_DRV_COMPAT实例编号构造公共驱动配置初始化器 |
| `HWSPINLOCK_SPINLOCK_ARRAY_DT_DEFINE(node_id)` | 由节点标识定义软件自旋锁数组 |
| `HWSPINLOCK_SPINLOCK_ARRAY_DT_INST_DEFINE(inst)` | 由DT_DRV_COMPAT实例编号定义软件自旋锁数组 |

## 6.3\_回调类型


```c
typedef int (*hwspinlock_api_trylock)(const struct device *dev, uint32_t id);
typedef void (*hwspinlock_api_lock)(const struct device *dev, uint32_t id);
typedef void (*hwspinlock_api_unlock)(const struct device *dev, uint32_t id);
typedef uint32_t (*hwspinlock_api_get_max_id)(const struct device *dev);
```

按声明顺序分别为尝试加锁、加锁、解锁和查询最大编号的回调（Callback）；详见[驱动后端接口](P002_硬件自旋锁驱动后端.md)。

## 6.4\_公共函数


```c
static inline int hw_spin_trylock(const struct device *dev, uint32_t id, k_spinlock_key_t *key);
static inline k_spinlock_key_t hw_spin_lock(const struct device *dev, uint32_t id);
static inline void hw_spin_unlock(const struct device *dev, uint32_t id, k_spinlock_key_t key);
static inline uint32_t hw_spinlock_get_max_id(const struct device *dev);
static inline int hw_spin_trylock_dt(struct hwspinlock_dt_spec *spec, k_spinlock_key_t *key);
static inline k_spinlock_key_t hw_spin_lock_dt(struct hwspinlock_dt_spec *spec);
static inline void hw_spin_unlock_dt(struct hwspinlock_dt_spec *spec, k_spinlock_key_t key);
static inline uint32_t hw_spinlock_get_max_id_dt(struct hwspinlock_dt_spec *spec);
```

前四个函数分别尝试获取锁、等待获取锁、释放锁、查询最大编号；后四个为对应的设备树规格版本。具体参数、返回值和加锁规则见[公共接口](P001_硬件自旋锁公共接口.md)。
