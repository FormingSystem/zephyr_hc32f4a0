# 第5章\_硬件自旋锁设备树规格结构

原文：[structhwspinlock__dt__spec](https://docs.zephyrproject.org/latest/doxygen/html/structhwspinlock__dt__spec.html)。读取日期：2026-10-13，`latest`。

`struct hwspinlock_dt_spec`保存完整的硬件自旋锁（Hardware Spinlock）设备树（Devicetree，DT）信息，声明位于`zephyr/drivers/hwspinlock.h`。

## 5.1\_设备与锁编号

| 成员 | 类型 | 含义 |
| --- | --- | --- |
| `dev` | `const struct device *` | 硬件自旋锁设备 |
| `id` | `uint32_t` | 硬件自旋锁编号 |

由设备树构造规格的`HWSPINLOCK_DT_SPEC_GET`系列宏，以及接收此结构的`_dt`函数，见[公共接口](P001_硬件自旋锁公共接口.md)。完整定义见[驱动头文件源码](P007_硬件自旋锁驱动头文件源码.md)。
