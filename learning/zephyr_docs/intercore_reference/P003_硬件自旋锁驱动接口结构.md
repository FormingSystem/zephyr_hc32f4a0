# 第3章\_硬件自旋锁驱动接口结构

原文：[structhwspinlock__driver__api](https://docs.zephyrproject.org/latest/doxygen/html/structhwspinlock__driver__api.html)。读取日期：2026-10-13，`latest`。

`struct hwspinlock_driver_api`是硬件自旋锁（Hardware Spinlock）的驱动操作（Driver Operations）结构，定义在`zephyr/drivers/hwspinlock.h`。每个硬件自旋锁驱动都需要定义此应用程序接口（Application Programming Interface，API）结构；它包含已实现操作的函数指针及其他驱动专用常量数据。

## 3.1\_操作表成员

| 成员 | 类型 | 要求与用途 |
| --- | --- | --- |
| `trylock` | `hwspinlock_api_trylock` | 可选（Optional，OPT），尝试获取硬件锁 |
| `lock` | `hwspinlock_api_lock` | 必需（Required，REQ），获取硬件锁 |
| `unlock` | `hwspinlock_api_unlock` | 必需（REQ），释放硬件锁 |
| `get_max_id` | `hwspinlock_api_get_max_id` | 可选（OPT），取得最大硬件锁编号 |

驱动**必须**设置标记为`REQ`的成员；`OPT`成员可选。完整类型签名见[驱动后端](P002_硬件自旋锁驱动后端.md)，调用契约见[公共接口](P001_硬件自旋锁公共接口.md)。
