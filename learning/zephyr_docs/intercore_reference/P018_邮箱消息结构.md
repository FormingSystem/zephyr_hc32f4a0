# 第18章\_邮箱消息结构

原文：[structmbox__msg](https://docs.zephyrproject.org/latest/doxygen/html/structmbox__msg.html)。读取日期：2026-10-13，`latest`。

`struct mbox_msg`是邮箱（Mailbox，MBOX）消息结构，用于保存数据及其大小，定义于`zephyr/drivers/mbox.h`。

## 18.1\_消息数据和大小

| 成员 | 类型 | 含义 |
| --- | --- | --- |
| `data` | `const void *` | 指向消息中所发送数据的指针 |
| `size` | `size_t` | 数据大小 |

该结构在发送函数与接收回调中的使用，以及信号通知模式（Signalling Mode）的空指针要求，见[邮箱公共接口](P014_邮箱驱动公共接口.md)。原结构定义见[头文件源码](P020_邮箱驱动头文件源码.md)。
