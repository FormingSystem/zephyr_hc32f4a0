# 第8章\_硬件自旋锁设备树宏

原文：[group__devicetree-hwspinlock](https://docs.zephyrproject.org/latest/doxygen/html/group__devicetree-hwspinlock.html)。读取日期：2026-10-13，`latest`。

这些设备树（Devicetree）宏从`hwlocks`属性取得硬件自旋锁（Hardware Spinlock）的控制器节点和编号，声明位于`zephyr/devicetree/hwspinlock.h`。

## 8.1\_按索引取得控制器

`DT_HWSPINLOCK_CTRL_BY_IDX(node_id, idx)`从`hwlocks`中取得索引`idx`所指元素的控制器节点标识。`node_id`是包含该属性的节点标识。展开式为：

```c
DT_PHANDLE_BY_IDX(node_id, hwlocks, idx)
```

以下示例中的 `DT_NODELABEL` 宏由标签取得节点标识。原设备树示例：

```dts
hwlock1: hwspinlock-controller@... { ... };
hwlock2: hwspinlock-controller@... { ... };

n: node {
        hwlocks = <&hwlock1 8>,
                  <&hwlock2 1>;
        hwlock-names = "rd", "wr";
};
```

原用法：

```c
DT_HWSPINLOCK_CTRL_BY_IDX(DT_NODELABEL(n), 0) // DT_NODELABEL(hwlock1)
DT_HWSPINLOCK_CTRL_BY_IDX(DT_NODELABEL(n), 1) // DT_NODELABEL(hwlock2)
```

返回值为所选元素引用的硬件自旋锁控制器节点标识。底层宏为`DT_PHANDLE_BY_IDX()`，其中节点引用（Phandle）指向控制器节点。

## 8.2\_按名称取得控制器

`DT_HWSPINLOCK_CTRL_BY_NAME(node_id, name)`按名称取得控制器节点标识。`node_id`须包含`hwlocks`；`name`由该节点`hwlock-names`定义，并使用小写字母与下划线形式。

```c
DT_PHANDLE_BY_NAME(node_id, hwlocks, name)
```

原设备树片段及用法：

```dts
hwlock1: hwspinlock-controller@... { ... };
hwlock2: hwspinlock-controller@... { ... };

n: node {
        hwlocks = <&hwlock1 8>,
                  <&hwlock2 1>;
        hwlock-names = "rd", "wr";
};
```

```c
DT_HWSPINLOCK_CTRL_BY_NAME(DT_NODELABEL(n), rd) // DT_NODELABEL(hwlock1)
DT_HWSPINLOCK_CTRL_BY_NAME(DT_NODELABEL(n), wr) // DT_NODELABEL(hwlock2)
```

返回值为该名称元素引用的控制器节点标识；另见底层`DT_PHANDLE_BY_NAME()`。

## 8.3\_按索引取得锁编号

`DT_HWSPINLOCK_ID_BY_IDX(node_id, idx)`取得`hwlocks`中指定索引元素的锁编号。`node_id`标识包含该属性的节点，`idx`是其元素索引。

```c
DT_PHA_BY_IDX(node_id, hwlocks, idx, id)
```

原设备树片段及用法：

```dts
hwlock1: hwspinlock-controller@... {
        #hwlock-cells = <1>;
};

n: node {
        hwlocks = <&hwlock1 1>,
                  <&hwlock1 6>;
};
```

```c
DT_HWSPINLOCK_ID_BY_IDX(DT_NODELABEL(n), 0) // 1
DT_HWSPINLOCK_ID_BY_IDX(DT_NODELABEL(n), 1) // 6
```

原返回值说明：取得对应说明符（Specifier）的通道值，若索引处没有找到硬件自旋锁则为 0；原参见宏为`DT_PHA_BY_IDX()`。

**译注：**此处实际读取的是`id`字段，且展开式直接使用`DT_PHA_BY_IDX`，没有提供默认值的`_OR`形式。原文“未找到时返回 0”的描述与所列实现不一致；不要依赖缺失元素自动返回 0，应保证节点与索引有效。

## 8.4\_按名称取得锁编号

`DT_HWSPINLOCK_ID_BY_NAME(node_id, name)`取得指定名称的锁`id`字段。`node_id`包含`hwlocks`，`name`取自`hwlock-names`并采用小写字母与下划线形式。

```c
DT_PHA_BY_NAME(node_id, hwlocks, name, id)
```

原设备树片段：

```dts
hwlock1: hwspinlock-controller@... {
        #hwlock-cells = <1>;
};

n: node {
        hwlocks = <&hwlock1 1>,
                  <&hwlock1 6>;
        hwlock-names = "rd", "wr";
};
```

硬件自旋锁兼容项的绑定（Binding）片段将说明单元命名为`id`：

```yaml
hwlock-cells:
  - id
```

原用法：

```c
DT_HWSPINLOCK_ID_BY_NAME(DT_NODELABEL(n), rd) // 1
DT_HWSPINLOCK_ID_BY_NAME(DT_NODELABEL(n), wr) // 6
```

原返回值说明：取得指定名称说明符的通道值，若未找到该名称的硬件自旋锁则为 0；另见`DT_PHA_BY_NAME()`。

**译注：**这里同样实际读取`id`，且没有缺省值分支；不要把原文中的“返回 0”作为缺失名称时的保证。完整宏定义见[设备树头文件源码](P010_硬件自旋锁设备树头文件源码.md)。
