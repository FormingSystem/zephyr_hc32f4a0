# 第145章\_核间数据包缓冲区结构

原文：[structpbuf](https://docs.zephyrproject.org/latest/doxygen/html/structpbuf.html)。读取日期：2026-10-13，`latest`。

`pbuf`在读者（Reader）与写者（Writer）共享的内存区域上实现轻量级单向（Unidirectional）数据包缓冲区，提供读／写语义。它内置缓存（Cache）和内存屏障（Memory Barrier）管理，以确保正确的数据访问。

该结构支持单个写者和单个读者。存储的数据被封装成带长度头部（Length Header）的消息；读／写接口的设计用于保护数据不被破坏。原摘要的“Scure packed buffer”有拼写问题，不能据此推导额外的安全属性。

## 145.1\_结构与成员

```c
struct pbuf {
        PBUF_MAYBE_CONST struct pbuf_cfg *const cfg; /* Configuration of the
                                                      * buffer.
                                                      */
        struct pbuf_data data;                  /* Data used to read and write
                                                 * to the buffer
                                                 */
};
```

| 参数 | 含义 |
| --- | --- |
| `cfg` | 缓冲区配置；指向`pbuf_cfg` |
| `data` | 缓冲区读写所用的运行时数据（Run-time Data） |

原字段参考将`cfg`显示为`const struct pbuf_cfg *const cfg`。上方源码使用`PBUF_MAYBE_CONST`，在`CONFIG_ARCH_POSIX`构建配置下允许修改所指配置；其他情况下展开为`const`。指针本身的`*const`限定仍保留。

本页包含`zephyr/ipc/pbuf.h`，字段说明依据该头文件可见注释译出。配置和数据结构分别见[核间数据包缓冲区配置](P146_核间数据包缓冲区配置.md)、[核间数据包缓冲区运行时数据](P147_核间数据包缓冲区运行时数据.md)。
