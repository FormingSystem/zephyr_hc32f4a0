# 第133章\_静态虚拟环常量头文件参考

原文：[static__vrings_8h](https://docs.zephyrproject.org/latest/doxygen/html/static__vrings_8h.html)。读取日期：2026-10-13，`latest`。

本页是静态虚拟环（Static VRINGs）设备树常量头文件`zephyr/dt-bindings/ipc_service/static_vrings.h`的参考索引。设备树（Devicetree）通过这些常量表达优先级类型。

下方`PRIO_COOP`和`PRIO_PREEMPT`是优先级类型宏，分别表示协作式（Cooperative）和抢占式（Preemptive）；`BIT`是位掩码构造宏（Bitmask Macro）。类型含义的依据见本页关联绑定说明。

## 133.1\_包含文件

```c
#include <zephyr/dt-bindings/dt-util.h>
```

## 133.2\_常量定义

```c
#define PRIO_COOP       BIT(0)
#define PRIO_PREEMPT    BIT(1)
```

原参考页列出上述两个宏，没有额外文字说明。宏表达式`BIT(0)`与`BIT(1)`原样保留。

**关联说明：**[OpenAMP静态虚拟环绑定](P110_ZephyrOpenAMP静态虚拟环绑定.md)将`PRIO_COOP`用于协作式（Cooperative）优先级，将`PRIO_PREEMPT`用于抢占式（Preemptive）优先级；它们表示优先级类型，数组中的另一项才是优先级数值。完整可见定义见[常量完整头文件](P134_静态虚拟环常量完整头文件.md)。
