# 第67章\_消息控制台发送端配置结构

原文：[structipm__console__sender__config__info](https://docs.zephyrproject.org/latest/doxygen/html/structipm__console__sender__config__info.html)。读取日期：2026-10-13，`latest`。

`struct ipm_console_sender_config_info`是处理器间邮箱（Inter-Processor Mailbox，IPM）控制台（Console）发送端配置结构，头文件为`zephyr/drivers/console/ipm_console.h`。

## 67.1\_绑定目标与转发来源

| 类型 | 成员 | 含义 |
| --- | --- | --- |
| `char *` | `bind_to` | 要绑定的底层驱动名称 |
| `int` | `flags` | 要转发的消息来源；会为所选来源安装钩子（Hook） |

`flags`可以选择标准输出（Standard Output，STDOUT）标志`IPM_CONSOLE_STDOUT`、内核打印标志`IPM_CONSOLE_PRINTK`，或同时选择二者。两个标志的原位掩码（Bit Mask）定义见[控制台头文件参考](P063_处理器间消息控制台头文件参考.md)。

**对照译注：**发送端原文明确允许同时选择两种来源；[接收端配置](P065_消息控制台接收端配置结构.md)对输出目标的表述则是二者之一，此处分别保留两页的规定。

本结构文档生成自`zephyr/drivers/console/ipm_console.h`，完整声明见[源码](P064_处理器间消息控制台完整头文件.md)。
