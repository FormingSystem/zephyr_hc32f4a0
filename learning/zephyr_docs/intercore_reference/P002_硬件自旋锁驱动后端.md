# 第2章\_硬件自旋锁驱动后端

原文：[group__hwspinlock__interface__backend](https://docs.zephyrproject.org/latest/doxygen/html/group__hwspinlock__interface__backend.html)。读取日期：2026-10-13，`latest`。

本分组提供实现硬件自旋锁（Hardware Spinlock）驱动所需的应用程序接口（Application Programming Interface，API）类型定义、回调（Callback）签名及辅助内容。声明位于`zephyr/drivers/hwspinlock.h`，操作表见[驱动接口结构](P003_硬件自旋锁驱动接口结构.md)。

## 2.1\_加锁与解锁回调


```c
typedef int (*hwspinlock_api_trylock)(const struct device *dev, uint32_t id);
typedef void (*hwspinlock_api_lock)(const struct device *dev, uint32_t id);
typedef void (*hwspinlock_api_unlock)(const struct device *dev, uint32_t id);
```

`hwspinlock_api_trylock`尝试获取硬件锁；`hwspinlock_api_lock`获取硬件锁；`hwspinlock_api_unlock`释放硬件锁。参数`dev`指定设备实例，`id`指定锁编号。详细参数含义分别见[公共接口](P001_硬件自旋锁公共接口.md)中的`hw_spin_trylock()`、`hw_spin_lock()`和`hw_spin_unlock()`。

**译注：**后端回调签名不含公共接口的锁键参数；本地软件自旋锁及锁键由公共包装函数管理，详见[完整源码](P007_硬件自旋锁驱动头文件源码.md)。

## 2.2\_最大编号回调及默认行为


```c
typedef uint32_t (*hwspinlock_api_get_max_id)(const struct device *dev);
```

`hwspinlock_api_get_max_id`取得设备的最大硬件锁编号，`dev`含义见公共`hw_spinlock_get_max_id()`。若驱动没有实现此回调，使用驱动配置中`num_locks - 1`的值。
