# 第29章\_BCM2711邮箱通道常量

原文：[brcm-bcm2711-mbox_8h](https://docs.zephyrproject.org/latest/doxygen/html/brcm-bcm2711-mbox_8h.html)。读取日期：2026-10-13，`latest`。

`zephyr/dt-bindings/mbox/brcm-bcm2711-mbox.h`定义博通（Broadcom）BCM2711 邮箱（Mailbox）控制器的通道常量。原文列出的十个宏如下。

## 29.1\_通道编号和用途

| 宏 | 值 | 用途 |
| --- | --- | --- |
| `BCM2711_MBOX0_CH_POWER_MGMT` | `0` | 电源管理（Power Management） |
| `BCM2711_MBOX0_CH_FRAMEBUFFER` | `1` | 帧缓冲（Framebuffer） |
| `BCM2711_MBOX0_CH_VIRTUAL_UART` | `2` | 虚拟通用异步收发器（Virtual Universal Asynchronous Receiver/Transmitter，Virtual UART） |
| `BCM2711_MBOX0_CH_VCHIQ` | `3` | VCHIQ 通信（原文：VCHIQ IPC） |
| `BCM2711_MBOX0_CH_LEDS` | `4` | 板载发光二极管（On-board Light-emitting Diodes，LEDs） |
| `BCM2711_MBOX0_CH_BUTTONS` | `5` | 实体按键（Physical Buttons） |
| `BCM2711_MBOX0_CH_TOUCHSCREEN` | `6` | 触摸屏（Touch Screen） |
| `BCM2711_MBOX0_CH_RESERVED` | `7` | 保留（Reserved），**禁止使用** |
| `BCM2711_MBOX0_CH_ARM_TO_VC` | `8` | ARM 端到 VC 端（ARM → VC） |
| `BCM2711_MBOX0_CH_VC_TO_ARM` | `9` | VC 端到 ARM 端（VC → ARM） |

这里的 VCHIQ、ARM 和 VC 名称按原页保留；原页未展开其全称，也未定义对应消息载荷（Payload）。完整常量源码见[绑定头文件源码](P030_BCM2711邮箱绑定头文件源码.md)。
