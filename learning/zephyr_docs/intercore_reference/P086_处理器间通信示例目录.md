# 第86章\_处理器间通信示例目录

原文：[Inter-Processor Communication (IPC)](https://docs.zephyrproject.org/latest/samples/subsys/ipc/ipc.html)。读取日期：2026-10-13，`latest`。

以下示例展示处理器间通信（Inter-Processor Communication，IPC）功能，服务说明见[IPC服务（IPC Service）](P092_IPC服务使用指南.md)。

## 86.1\_示例目录

| 示例 | 原文用途 |
| --- | --- |
| [IPC服务：icmsg后端](P095_IPC服务ICMsg示例.md) | 通过IPC服务与icmsg后端（Backend）在两个核心间发送消息 |
| [IPC服务：多端点](P096_IPC服务多端点示例.md) | 使用具有多个端点（Endpoint）的IPC服务 |
| [IPC服务：RPMSG-Lite后端](P097_IPC服务RPMSG-Lite示例.md) | 通过IPC服务与RPMSG-Lite后端在两个核心间发送消息 |
| [IPC服务：静态vrings后端](P098_IPC服务静态虚拟环示例.md) | 通过IPC服务与静态虚拟环（Static Vrings）后端在两个核心间发送消息 |
| [OpenAMP](P088_OpenAMP双核通信示例.md) | 使用OpenAMP在两个核心间发送消息 |
| [使用资源表的OpenAMP](P089_OpenAMP资源表示例.md) | 使用OpenAMP与资源表（Resource Table）在两个核心间发送消息 |
| [RPMsg服务](P090_RPMsg服务示例.md) | 通过RPMsg服务在核心间发送消息 |

OpenAMP、icmsg、RPMSG-Lite与RPMsg为原框架、后端或服务名称。
