# 第60章\_处理器间消息驱动接口结构

原文：[structipm__driver__api](https://docs.zephyrproject.org/latest/doxygen/html/structipm__driver__api.html)。读取日期：2026-10-13，`latest`。

`struct ipm_driver_api`是处理器间邮箱（Inter-Processor Mailbox，IPM）驱动操作（Driver Operations）结构，头文件为`zephyr/drivers/ipm.h`。每个IPM驱动都需要定义自己的驱动接口结构；原文说明它包含驱动实现的操作函数指针，以及驱动专用的其他常量数据。

标为必需（Required，REQ）的成员必须由驱动设置；标为可选（Optional，OPT）的成员可以不设置。各回调（Callback）类型声明见[驱动后端](P059_处理器间消息驱动后端.md)，操作语义见[公共接口](P058_处理器间消息公共接口.md)。

异步回调配置选项`CONFIG_IPM_CALLBACK_ASYNC`控制可选完成成员是否可用。


## 60.1\_成员及要求

| 类型 | 成员 | 要求 | 含义 |
| --- | --- | --- | --- |
| `ipm_send_t` | `send` | 必需（Required，REQ） | 尝试发送IPM消息 |
| `ipm_register_callback_t` | `register_callback` | 必需（REQ） | 注册消息接收回调 |
| `ipm_max_data_size_get_t` | `max_data_size_get` | 必需（REQ） | 返回出站消息最大字节数 |
| `ipm_max_id_val_get_t` | `max_id_val_get` | 必需（REQ） | 返回出站消息标识符最大值 |
| `ipm_set_enabled_t` | `set_enabled` | 必需（REQ） | 使能入站通道的中断和回调 |
| `ipm_complete_t` | `complete` | 可选（Optional，OPT） | 通知异步命令完成；仅启用`CONFIG_IPM_CALLBACK_ASYNC`时可用 |

`CONFIG_IPM_CALLBACK_ASYNC`是异步回调配置选项；`complete`成员仅在启用该选项时可用。[完整可见源码](P062_处理器间消息完整头文件.md)还通过`__DOXYGEN__`条件让文档生成器看到这个成员。
