# 第24章\_邮箱信号通知示例

原文：[MBOX](https://docs.zephyrproject.org/latest/samples/drivers/mbox/README.html)。读取日期：2026-10-13，`latest`。

本示例演示邮箱（Mailbox，MBOX）应用程序接口（Application Programming Interface，API）的使用，可在支持邮箱的开发板上构建并运行。[官方示例源码](https://github.com/zephyrproject-rtos/zephyr/tree/main/samples/drivers/mbox)位于`samples/drivers/mbox`。

## 24.1\_为nRF5340开发板构建

在 Zephyr 仓库根目录，为`nrf5340dk/nrf5340/cpuapp`构建并调试。原命令使用系统构建（Sysbuild），首行注释也说明执行位置：

```shell
# From the root of the zephyr repository
west build -b nrf5340dk/nrf5340/cpuapp --sysbuild samples/drivers/mbox/
west debug
```

打开串口终端（Serial Terminal），例如 minicom 或 PuTTY，按下列参数连接开发板：

| 参数 | 设置 |
| --- | --- |
| 波特率（Baud Rate） | `115200` |
| 数据位（Data Bits） | `8` |
| 校验（Parity） | 无（None） |
| 停止位（Stop Bits） | `1` |

复位开发板后，对应串口分别显示应用核（Application Core，APP）和网络核（Network Core，NET）的消息。日志中的 OS 指操作系统（Operating System）。应用核原输出为：

```text
*** Booting Zephyr OS build zephyr-v3.1.0-2383-g147aee22f273  ***
Hello from APP
Pong (on channel 0)
Ping (on channel 1)
Pong (on channel 0)
Ping (on channel 1)
Ping (on channel 1)
Pong (on channel 0)
Ping (on channel 1)
Pong (on channel 0)
Ping (on channel 1)
...
```

网络核原输出为：

```text
*** Booting Zephyr OS build zephyr-v3.1.0-2383-g147aee22f273  ***
Hello from NET
Ping (on channel 0)
Pong (on channel 1)
Ping (on channel 0)
Pong (on channel 1)
```

`Ping`和`Pong`表示往返请求与应答，`channel`为通道。原日志中的`zephyr-v3.1.0-2383-g147aee22f273`属于官方保留的示例输出，不代表本译文读取时的最新版本。

## 24.2\_为模拟开发板构建和执行

为模拟的`nrf5340bsim`构建：

```shell
# From the root of the zephyr repository
west build -b nrf5340bsim/nrf5340/cpuapp --sysbuild samples/drivers/mbox/
```

然后执行应用：

```shell
$ ./build/zephyr/zephyr.exe -nosim
# Press Ctrl+C to exit
```

在启动命令所在控制台可看到与真实硬件类似的输出；原注释说明按`Ctrl+C`退出。
