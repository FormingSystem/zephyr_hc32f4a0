# 第9章\_硬件自旋锁设备树头文件参考

原文：[devicetree_2hwspinlock_8h](https://docs.zephyrproject.org/latest/doxygen/html/devicetree_2hwspinlock_8h.html)。读取日期：2026-10-13，`latest`。

`zephyr/devicetree/hwspinlock.h`提供硬件自旋锁（Hardware Spinlock）设备树（Devicetree）访问宏。原页列出以下四项。

## 9.1\_宏列表

| 宏 | 用途 |
| --- | --- |
| `DT_HWSPINLOCK_CTRL_BY_IDX(node_id, idx)` | 按`hwlocks`元素索引取得控制器节点标识 |
| `DT_HWSPINLOCK_CTRL_BY_NAME(node_id, name)` | 按元素名称取得控制器节点标识 |
| `DT_HWSPINLOCK_ID_BY_NAME(node_id, name)` | 按名称取得锁编号字段 |
| `DT_HWSPINLOCK_ID_BY_IDX(node_id, idx)` | 按索引取得锁编号 |

参数、返回值、原示例及原文默认值描述的差异见[设备树宏](P008_硬件自旋锁设备树宏.md)，原定义见[完整源码](P010_硬件自旋锁设备树头文件源码.md)。
