# 第148章\_核间数据包缓冲区头文件参考

原文：[pbuf_8h](https://docs.zephyrproject.org/latest/doxygen/html/pbuf_8h.html)。读取日期：2026-10-13，`latest`。

本页对应`zephyr/ipc/pbuf.h`头文件参考（Header Reference）。原文件包含以下依赖：

```c
#include <zephyr/cache.h>
#include <zephyr/devicetree.h>
```

## 148.2\_宏定义

| 宏 | 原页取值或定义位置 | 含义 |
| --- | --- | --- |
| `PBUF_PACKET_LEN_SZ` | `sizeof(uint32_t)` | 数据包长度字段大小 |
| `PBUF_MAYBE_CONST` | `const` | 原参考页展开为常量限定；原生模拟配置下为空 |
| `PBUF_CFG_INIT(mem_addr, size, dcache_align, use_handshake)` | `见接口页` | 初始化配置 |
| `PBUF_HEADER_OVERHEAD(dcache_align)` | `见接口页` | 计算共享内存中读索引、写索引和填充的头部开销 |
| `PBUF_DEFINE(name, mem_addr, size, dcache_align, use_handshake, compatibility)` | `见接口页` | 静态定义并初始化缓冲区 |

## 148.3\_函数接口


```c
int pbuf_tx_init(struct pbuf *pb);
```

初始化发送缓冲区。参数、返回值及使用条件见[核间数据包缓冲区接口](P144_核间数据包缓冲区接口.md)。


```c
int pbuf_rx_init(struct pbuf *pb);
```

初始化接收缓冲区。参数、返回值及使用条件见[核间数据包缓冲区接口](P144_核间数据包缓冲区接口.md)。


```c
int pbuf_write(struct pbuf *pb, const char *buf, uint16_t len);
```

写入数据。参数、返回值及使用条件见[核间数据包缓冲区接口](P144_核间数据包缓冲区接口.md)。


```c
int pbuf_read(struct pbuf *pb, char *buf, uint16_t len);
```

读取完整消息。参数、返回值及使用条件见[核间数据包缓冲区接口](P144_核间数据包缓冲区接口.md)。


```c
uint32_t pbuf_handshake_read(struct pbuf *pb);
```

读取握手字。参数、返回值及使用条件见[核间数据包缓冲区接口](P144_核间数据包缓冲区接口.md)。


```c
void pbuf_handshake_write(struct pbuf *pb, uint32_t value);
```

写入握手字。参数、返回值及使用条件见[核间数据包缓冲区接口](P144_核间数据包缓冲区接口.md)。


```c
int pbuf_get_initial_buf(struct pbuf *pb, volatile char **buf, uint16_t *len);
```

取得队列起始缓冲区。参数、返回值及使用条件见[核间数据包缓冲区接口](P144_核间数据包缓冲区接口.md)。


```c
void pbuf_native_addr_remap(struct pbuf *pb);
```

重映射原生模拟地址。参数、返回值及使用条件见[核间数据包缓冲区接口](P144_核间数据包缓冲区接口.md)。

完整官方可见源码见[核间数据包缓冲区完整头文件](P149_核间数据包缓冲区完整头文件.md)。
