# 第144章\_核间数据包缓冲区接口

原文：[group__pbuf](https://docs.zephyrproject.org/latest/doxygen/html/group__pbuf.html)。读取日期：2026-10-13，`latest`。

本页翻译数据包缓冲区（Packet Buffer）的应用程序编程接口（Application Programming Interface，API）。头文件为`zephyr/ipc/pbuf.h`。原页标题写作“Packed buffer API”，结构摘要还出现“Scure packed buffer”；本译文按正文功能统一称数据包缓冲区，原拼写不构成额外的安全保证。

结构分别见[核间数据包缓冲区结构](P145_核间数据包缓冲区结构.md)、[核间数据包缓冲区配置](P146_核间数据包缓冲区配置.md)和[核间数据包缓冲区运行时数据](P147_核间数据包缓冲区运行时数据.md)。

阅读说明：下面的`MAX`宏取较大值，`BUILD_ASSERT`宏进行构建断言（Build Assertion），`IS_PTR_ALIGNED_BYTES`宏检查字节对齐（Byte Alignment）。`PBUF_MAYBE_CONST`是根据构建配置选择是否添加`const`的宏；`uint32_t`为32位无符号整数类型。负返回值是错误码（Error Code），其具体条件在各函数表中列出。

## 144.1\_配置初始化宏

推荐使用`PBUF_CFG_INIT(mem_addr, size, dcache_align, use_handshake)`初始化数据包缓冲区配置。宏（Macro）展开如下：

```c
{                                                                                       \
        .rd_idx_loc = (uint32_t *)(mem_addr),                                           \
        .handshake_loc = use_handshake ? (uint32_t *)((uint8_t *)(mem_addr) +           \
                                _PBUF_IDX_SIZE) : NULL,                                 \
        .wr_idx_loc = (uint32_t *)((uint8_t *)(mem_addr) + MAX(dcache_align,            \
                                (use_handshake ? 2 : 1) * _PBUF_IDX_SIZE)),             \
        .data_loc = (uint8_t *)((uint8_t *)(mem_addr) +                                 \
                                MAX(dcache_align, (use_handshake ? 2 : 1) *             \
                                                  _PBUF_IDX_SIZE) + _PBUF_IDX_SIZE),    \
        .len = (uint32_t)((uint32_t)(size) - MAX(dcache_align,                          \
                        (use_handshake ? 2 : 1) * _PBUF_IDX_SIZE) - _PBUF_IDX_SIZE),    \
        .dcache_alignment = (dcache_align),                                             \
}
```

| 参数 | 含义 |
| --- | --- |
| `mem_addr` | 数据包缓冲区的内存地址 |
| `size` | 内存大小 |
| `dcache_align` | 数据缓存对齐（Data Cache Alignment） |
| `use_handshake` | 在共享内存（Shared Memory）中加入握手字，通过`pbuf_handshake_read()`和`pbuf_handshake_write()`访问 |

## 144.2\_静态定义与初始化

`PBUF_DEFINE(name, mem_addr, size, dcache_align, use_handshake, compatibility)`静态定义并初始化`pbuf`。

```c
BUILD_ASSERT(dcache_align >= 0,                                                 \
                "Cache line size must be non negative.");                       \
BUILD_ASSERT((size) > 0 && IS_PTR_ALIGNED_BYTES(size, _PBUF_IDX_SIZE),          \
                "Incorrect size.");                                             \
BUILD_ASSERT(IS_PTR_ALIGNED_BYTES(mem_addr, MAX(dcache_align, _PBUF_IDX_SIZE)), \
                "Misaligned memory.");                                          \
BUILD_ASSERT(size >= (MAX(dcache_align, _PBUF_IDX_SIZE) + _PBUF_IDX_SIZE +      \
                _PBUF_MIN_DATA_LEN), "Insufficient size.");                     \
BUILD_ASSERT(!(compatibility) || (dcache_align) >= 8,                           \
        "Data cache alignment must be at least 8 if compatibility is enabled.");\
static PBUF_MAYBE_CONST struct pbuf_cfg cfg_##name =                            \
                PBUF_CFG_INIT(mem_addr, size, dcache_align, use_handshake);     \
static struct pbuf name = {                                                     \
        .cfg = &cfg_##name,                                                     \
}
```

| 参数 | 含义 |
| --- | --- |
| `name` | 数据包缓冲区名称 |
| `mem_addr` | 数据包缓冲区的内存地址 |
| `size` | 内存大小 |
| `dcache_align` | 数据缓存行大小（Data Cache Line Size） |
| `use_handshake` | 在共享内存中加入握手字，通过握手读／写函数访问 |

译注：原宏声明有`compatibility`参数，原参数表却未解释它。代码明确要求：该参数启用时，`dcache_align`至少为8；这里保留原表及宏，不推导未给出的完整兼容模式行为。

宏内五条构建断言（Build Assertion）分别检查：缓存行大小非负；大小为正且按索引大小对齐；内存地址正确对齐；内存大小足够；启用兼容选项时缓存对齐至少为8。对应报错文本依次是“缓存行大小必须非负”“大小不正确”“内存未对齐”“大小不足”“启用兼容选项时数据缓存对齐必须至少为8”。具体条件以原始表达式为准。

## 144.3\_头部开销

`PBUF_HEADER_OVERHEAD(dcache_align)`计算共享内存中头部占用的内存开销，包括读索引（Read Index）、写索引（Write Index）和填充（Padding）。

```c
(MAX(dcache_align, _PBUF_IDX_SIZE) + _PBUF_IDX_SIZE)
```

| 参数 | 含义 |
| --- | --- |
| `dcache_align` | 数据缓存对齐 |

译注：原宏只有`dcache_align`参数，没有`use_handshake`参数；上方公式原样保留。启用握手时的具体布局另见`PBUF_CFG_INIT`中包含`use_handshake`的表达式。

## 144.4\_长度字段与条件常量

`PBUF_PACKET_LEN_SZ`取`sizeof(uint32_t)`，表示数据包长度字段的大小。原参考页将`PBUF_MAYBE_CONST`展开为`const`；完整源码中，定义`CONFIG_ARCH_POSIX`时该宏为空，其他情况下为`const`。这是构建配置（Build Configuration）决定的差异：原生模拟开发板在初始化时需要修改部分指针。

## 144.5\_初始化发送缓冲区

```c
int pbuf_tx_init(struct pbuf *pb);
```

依据给定配置初始化发送（Transmit，TX）数据包缓冲区；配置错误时返回错误。推荐使用`PBUF_DEFINE`进行构建期初始化（Build-time Initialization）。

| 参数 | 含义 |
| --- | --- |
| `pb` | 指向包含配置和数据的数据包缓冲区；**配置必须在初始化之前确定** |

| 返回值 | 含义 |
| --- | --- |
| `0` | 成功 |
| `-EINVAL` | 输入参数不正确 |

## 144.6\_初始化接收缓冲区

```c
int pbuf_rx_init(struct pbuf *pb);
```

初始化接收（Receive，RX）数据包缓冲区；配置错误时返回错误。推荐使用`PBUF_DEFINE`进行构建期初始化。

| 参数 | 含义 |
| --- | --- |
| `pb` | 指向包含配置和数据的数据包缓冲区；**配置必须在初始化之前确定** |

| 返回值 | 含义 |
| --- | --- |
| `0` | 成功 |
| `-EINVAL` | 输入参数不正确 |

## 144.7\_写入数据

```c
int pbuf_write(struct pbuf *pb, const char *buf, uint16_t len);
```

在数据包缓冲区能够容纳数据时，向其中写入指定数量的数据。

| 参数 | 含义 |
| --- | --- |
| `pb` | 目标数据包缓冲区 |
| `buf` | 待写入数据的指针 |
| `len` | 待写入的字节数，**必须为正数** |

| 返回值 | 含义 |
| --- | --- |
| `int` | 成功返回已写入字节数，失败返回负错误码 |
| `-EINVAL` | 任一输入参数不正确 |
| `-ENOMEM` | `len`大于缓冲区能够容纳的长度 |

## 144.8\_读取完整消息

```c
int pbuf_read(struct pbuf *pb, char *buf, uint16_t len);
```

一次读取对应一次写入发送的消息。调用者提供的`buf`必须足以容纳**整条消息**。

| 参数 | 含义 |
| --- | --- |
| `pb` | 要从中读取数据的数据包缓冲区 |
| `buf` | 保存所读数据的指针；若为`NULL`，返回已存储消息的长度 |
| `len` | 要从缓冲区读取的字节数 |

| 返回值 | 含义 |
| --- | --- |
| `int` | 成功返回已读字节数，失败返回负错误码；`buf == NULL`时返回待读字节数 |
| `-EINVAL` | 任一输入参数不正确 |
| `-ENOMEM` | 整条消息放不进所提供的`buf` |
| `-EAGAIN` | 整条消息尚未准备好 |

## 144.9\_读取握手字

```c
uint32_t pbuf_handshake_read(struct pbuf *pb);
```

从数据包缓冲区读取握手字（Handshake Word）。**`pb`必须使用`PBUF_DEFINE`定义，并设置`use_handshake`。**

| 参数 | 含义 |
| --- | --- |
| `pb` | 要从中读取握手字的数据包缓冲区 |

| 返回值 | 含义 |
| --- | --- |
| `uint32_t` | 握手字的值 |

## 144.10\_写入握手字

```c
void pbuf_handshake_write(struct pbuf *pb, uint32_t value);
```

向数据包缓冲区写入握手字。**`pb`必须使用`PBUF_DEFINE`定义，并设置`use_handshake`。**

| 参数 | 含义 |
| --- | --- |
| `pb` | 要写入握手字的数据包缓冲区 |
| `value` | 握手值 |

## 144.11\_取得队列起始缓冲区

```c
int pbuf_get_initial_buf(struct pbuf *pb, volatile char **buf, uint16_t *len);
```

取得位于队列（Queue）起始位置的第一个缓冲区。由于它是第一个缓冲区，因此是一段连续内存（Contiguous Memory）。

| 参数 | 含义 |
| --- | --- |
| `pb` | 要从中读取数据的数据包缓冲区 |
| `buf` | 输出（out）：保存第一个缓冲区数据指针的指针 |
| `len` | 输出（out）：保存第一个缓冲区长度的指针 |

| 返回值 | 含义 |
| --- | --- |
| `0` | 成功 |
| `-EINVAL` | 队列起始位置没有缓冲区 |

译注：原返回值表将`-EINVAL`写在`0`的说明内，这里分别列出；参数说明中的“date”按上下文译为数据（Data）。

## 144.12\_重映射原生模拟地址

```c
void pbuf_native_addr_remap(struct pbuf *pb);
```

将嵌入式地址（Embedded Address）重映射为原生地址（Native Address）。**仅用于基于原生模拟器（Native Simulator）的目标**：把数据包缓冲区的设备树（Devicetree）地址映射到已经分配的原生内存地址范围。此函数仅用于处理器间通信（Inter-Processor Communication，IPC）后端实现。

| 参数 | 含义 |
| --- | --- |
| `pb` | 待重映射的数据包缓冲区 |
