# 第63章\_处理器间消息控制台头文件参考

原文：[ipm__console_8h](https://docs.zephyrproject.org/latest/doxygen/html/ipm__console_8h.html)。读取日期：2026-10-13，`latest`。

`zephyr/drivers/console/ipm_console.h`是处理器间邮箱（Inter-Processor Mailbox，IPM）控制台（Console）头文件。原页列出三个结构和四个宏；完整可见代码见[源码页](P064_处理器间消息控制台完整头文件.md)。

## 63.1\_包含项与结构

```c
#include <zephyr/kernel.h>
#include <zephyr/device.h>
#include <zephyr/sys/ring_buffer.h>
```

三个结构分别是[接收端配置`ipm_console_receiver_config_info`](P065_消息控制台接收端配置结构.md)、[接收端运行数据`ipm_console_receiver_runtime_data`](P066_消息控制台接收端运行数据结构.md)和[发送端配置`ipm_console_sender_config_info`](P067_消息控制台发送端配置结构.md)。

## 63.2\_宏定义

| 宏 | 原值 | 中文识别说明 |
| --- | --- | --- |
| `IPM_CONSOLE_STDOUT` | `(BIT(0))` | 标准输出（Standard Output，STDOUT）标志 |
| `IPM_CONSOLE_PRINTK` | `(BIT(1))` | 内核打印函数`printk()`对应的控制台标志 |
| `IPM_CONSOLE_STACK_SIZE` | `CONFIG_IPM_CONSOLE_STACK_SIZE` | 控制台线程栈大小，取自同名配置选项 |
| `IPM_CONSOLE_PRI` | `2` | 控制台线程优先级（Priority）常量 |

**译注：**原参考页只给出宏定义，没有额外说明；表中用途根据宏名及[接收端](P065_消息控制台接收端配置结构.md)／[发送端](P067_消息控制台发送端配置结构.md)字段说明补充。`BIT(0)`与`BIT(1)`保留原位掩码（Bit Mask）表达式，不改写为其他数值表示。
