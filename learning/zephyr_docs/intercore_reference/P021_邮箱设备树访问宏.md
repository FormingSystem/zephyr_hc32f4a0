# 第21章\_邮箱设备树访问宏

原文：[group__devicetree-mbox](https://docs.zephyrproject.org/latest/doxygen/html/group__devicetree-mbox.html)。读取日期：2026-10-13，`latest`。

本页为邮箱（Mailbox，MBOX）设备树（Devicetree）访问宏，定义于`zephyr/devicetree/mbox.h`。节点的`mboxes`属性保存控制器引用及其说明符，`mbox-names`给对应元素命名。

## 21.1\_按名称取得通道值

`DT_MBOX_CHANNEL_BY_NAME(node_id, name)`宏取得指定名称的通道值，展开式为：

```c
DT_PHA_BY_NAME_OR(node_id, mboxes, name, channel, 0)
```

参数`node_id`是包含`mboxes`属性的节点标识；`name`是由该节点`mbox-names`定义的小写字母与下划线形式名称。返回指定名称说明符（Specifier）中的通道值；不支持通道时返回`0`。这里底层`DT_PHA_BY_NAME_OR()`确实提供缺省值`0`。

原设备树片段：

```dts
mbox1: mbox@... {
        #mbox-cells = <1>;
};

n: node {
    mboxes = <&mbox1 1>,
             <&mbox1 6>;
    mbox-names = "tx", "rx";
};
```

邮箱兼容项的绑定（Binding）把说明单元命名为`channel`：

```yaml
mbox-cells:
  - channel
```

原用法如下；`DT_NODELABEL`宏由节点标签取得节点标识：

```c
DT_MBOX_CHANNEL_BY_NAME(DT_NODELABEL(n), tx) // 1
DT_MBOX_CHANNEL_BY_NAME(DT_NODELABEL(n), rx) // 6
```

## 21.2\_按名称取得控制器节点

`DT_MBOX_CTLR_BY_NAME(node_id, name)`从`mboxes`中按名称取得邮箱控制器节点标识，展开式为：

```c
DT_PHANDLE_BY_NAME(node_id, mboxes, name)
```

参数`node_id`是含`mboxes`的节点标识；`name`由`mbox-names`定义，使用小写字母与下划线形式。返回对应名称元素所引用的邮箱控制器节点标识。底层宏`DT_PHANDLE_BY_NAME()`读取节点引用（Phandle）。

原设备树片段及用法：

```dts
mbox1: mbox-controller@... { ... };

n: node {
        mboxes = <&mbox1 8>,
                 <&mbox1 9>;
        mbox-names = "tx", "rx";
};
```

```c
DT_MBOX_CTLR_BY_NAME(DT_NODELABEL(n), tx) // DT_NODELABEL(mbox1)
DT_MBOX_CTLR_BY_NAME(DT_NODELABEL(n), rx) // DT_NODELABEL(mbox1)
```

完整定义见[设备树头文件源码](P023_邮箱设备树头文件源码.md)。
