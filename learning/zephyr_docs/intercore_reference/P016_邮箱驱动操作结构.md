# 第16章\_邮箱驱动操作结构

原文：[structmbox__driver__api](https://docs.zephyrproject.org/latest/doxygen/html/structmbox__driver__api.html)。读取日期：2026-10-13，`latest`。

`struct mbox_driver_api`为邮箱（Mailbox，MBOX）驱动操作（Driver Operations）结构，定义于`zephyr/drivers/mbox.h`。每个邮箱驱动都需要定义此应用程序接口（Application Programming Interface，API）结构，保存所实现操作的函数指针及其他驱动专用常量数据。

## 16.1\_操作表成员

原文标记中，必需（Required，REQ）成员必须设置，可选（Optional，OPT）成员可不设置。本结构列出的五个成员均标记为`OPT`。

| 成员 | 类型 | 用途 |
| --- | --- | --- |
| `send` | `mbox_send_t` | 尝试经邮箱设备发送消息 |
| `register_callback` | `mbox_register_callback_t` | 为通道的入站消息注册回调 |
| `mtu_get` | `mbox_mtu_get_t` | 返回出站消息的最大字节数 |
| `max_channels_get` | `mbox_max_channels_get_t` | 返回最大通道数 |
| `set_enabled` | `mbox_set_enabled_t` | 使能或禁用入站通道的中断与回调 |

完整回调类型见[驱动后端接口](P015_邮箱驱动后端接口.md)，完整声明见[头文件源码](P020_邮箱驱动头文件源码.md)。
