# 第22章\_邮箱设备树头文件参考

原文：[devicetree_2mbox_8h](https://docs.zephyrproject.org/latest/doxygen/html/devicetree_2mbox_8h.html)。读取日期：2026-10-13，`latest`。

`zephyr/devicetree/mbox.h`是邮箱（Mailbox，MBOX）设备树（Devicetree）宏的公开应用程序接口（Application Programming Interface，API）头文件。

## 22.1\_宏列表

| 宏 | 用途 |
| --- | --- |
| `DT_MBOX_CTLR_BY_NAME(node_id, name)` | 从`mboxes`属性按名称取得邮箱控制器节点标识 |
| `DT_MBOX_CHANNEL_BY_NAME(node_id, name)` | 按名称取得邮箱通道值 |

参数、返回值和原示例见[设备树访问宏](P021_邮箱设备树访问宏.md)，宏定义见[完整源码](P023_邮箱设备树头文件源码.md)。
