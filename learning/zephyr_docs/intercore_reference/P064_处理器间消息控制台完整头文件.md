# 第64章\_处理器间消息控制台完整头文件

原文：[ipm__console_8h_source](https://docs.zephyrproject.org/latest/doxygen/html/ipm__console_8h_source.html)。读取日期：2026-10-13，`latest`。

本页保留处理器间邮箱（Inter-Processor Mailbox，IPM）控制台（Console）头文件`zephyr/drivers/console/ipm_console.h`的完整可见源码（Source Code）。仅去除网页行号和行尾空白，原版权、许可证、注释和声明均保留。结构字段的完整中文说明见[头文件参考及索引](P063_处理器间消息控制台头文件参考.md)。

源码中的`BIT`是生成位掩码（Bit Mask）的宏。`IPM_CONSOLE_STDOUT`和`IPM_CONSOLE_PRINTK`是标准输出（Standard Output，STDOUT）与内核打印的选择标志；`IPM_CONSOLE_STACK_SIZE`和`IPM_CONSOLE_PRI`分别为控制台栈大小与优先级（Priority）宏。

`CONFIG_IPM_CONSOLE_STACK_SIZE`是栈大小配置选项；`CONFIG_IPM_CONSOLE_RECEIVER`和`CONFIG_IPM_CONSOLE_SENDER`分别为控制台接收端与发送端配置选项。


## 64.1\_完整可见源码

```c
/* ipm_console.c - Console messages to/from another processor */

/*
 * Copyright (c) 2015 Intel Corporation
 *
 * SPDX-License-Identifier: Apache-2.0
 */

#ifndef ZEPHYR_INCLUDE_DRIVERS_CONSOLE_IPM_CONSOLE_H_
#define ZEPHYR_INCLUDE_DRIVERS_CONSOLE_IPM_CONSOLE_H_

#include <zephyr/kernel.h>
#include <zephyr/device.h>
#include <zephyr/sys/ring_buffer.h>

#ifdef __cplusplus
extern "C" {
#endif

#define IPM_CONSOLE_STDOUT      (BIT(0))
#define IPM_CONSOLE_PRINTK      (BIT(1))

/*
 * Good way to determine these numbers other than trial-and-error?
 * using printf() in the thread seems to require a lot more stack space
 */
#define IPM_CONSOLE_STACK_SIZE          CONFIG_IPM_CONSOLE_STACK_SIZE
#define IPM_CONSOLE_PRI                 2

struct ipm_console_receiver_config_info {
        char *bind_to;

        k_thread_stack_t *thread_stack;

        uint32_t *ring_buf_data;

        unsigned int rb_size32;

        char *line_buf;

        unsigned int lb_size;

        unsigned int flags;
};

struct ipm_console_receiver_runtime_data {
        struct ring_buf rb;

        struct k_sem sem;

        const struct device *ipm_device;

        int channel_disabled;

        struct k_thread rx_thread;
};

struct ipm_console_sender_config_info {
        char *bind_to;

        int flags;
};

#if CONFIG_IPM_CONSOLE_RECEIVER
int ipm_console_receiver_init(const struct device *d);
#endif

#if CONFIG_IPM_CONSOLE_SENDER
int ipm_console_sender_init(const struct device *d);
#endif

#ifdef __cplusplus
}
#endif

#endif /* ZEPHYR_INCLUDE_DRIVERS_CONSOLE_IPM_CONSOLE_H_ */
```

## 64.2\_可见注释与条件声明

文件首行注释的意思是：“ipm_console.c——向另一个处理器发送控制台消息，或从另一个处理器接收控制台消息。”此处`ipm_console.c`是原注释文字，当前文件仍为头文件`ipm_console.h`。

栈大小和优先级宏前的原注释提出：“除了反复试验，有没有确定这些数值的好方法？在线程中使用`printf()`似乎需要多得多的栈空间。”这里保留其经验性疑问，没有把它改写为确定的栈需求公式。

**声明译注：**接收端初始化函数`ipm_console_receiver_init(const struct device *d)`只在`CONFIG_IPM_CONSOLE_RECEIVER`条件成立时声明；发送端初始化函数`ipm_console_sender_init(const struct device *d)`只在`CONFIG_IPM_CONSOLE_SENDER`条件成立时声明，二者返回类型均为`int`。原页未提供这两个函数的独立参数或返回码说明。
