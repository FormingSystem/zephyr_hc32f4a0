# 第147章\_核间数据包缓冲区运行时数据

原文：[structpbuf__data](https://docs.zephyrproject.org/latest/doxygen/html/structpbuf__data.html)。读取日期：2026-10-13，`latest`。

`pbuf_data`是数据包缓冲区（Packet Buffer）的数据块（Data Block），包含于`zephyr/ipc/pbuf.h`。

## 147.1\_完整结构

```c
struct pbuf_data {
        volatile uint32_t wr_idx;       /* Index of the first holding first
                                         * free byte in data[]. Used for
                                         * writing.
                                         */
        volatile uint32_t rd_idx;       /* Index of the first holding first
                                         * valid byte in data[]. Used for
                                         * reading.
                                         */
};
```

## 147.2\_成员说明

以下含义依据完整头文件的可见注释译出；它们是读／写使用的本地索引。

| 参数 | 含义 |
| --- | --- |
| `wr_idx` | 用于写入的索引，指向`data[]`中第一个空闲字节 |
| `rd_idx` | 用于读取的索引，指向`data[]`中第一个有效字节 |

对应共享索引地址见[核间数据包缓冲区配置](P146_核间数据包缓冲区配置.md)。
