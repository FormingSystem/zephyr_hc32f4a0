# 第25章\_邮箱数据传输示例

原文：[MBOX Data](https://docs.zephyrproject.org/latest/samples/drivers/mbox_data/README.html)。读取日期：2026-10-13，`latest`。

本示例演示邮箱（Mailbox，MBOX）应用程序接口（Application Programming Interface，API）的数据传输模式（Data Transfer Mode），**只适用于支持该模式的邮箱驱动**。[官方示例源码](https://github.com/zephyrproject-rtos/zephyr/tree/main/samples/drivers/mbox_data)位于`samples/drivers/mbox_data`。

## 25.1\_往返数据与缓冲区配置

示例通过两个邮箱通道（Channel）在两个核心之间往返传输数据。数据大小取决于驱动的最大传输单元（Maximum Transmission Unit，MTU），不同平台有所不同。每个核心收到数据后，将计数器加`1`，再把数据发回另一核心。

消息缓冲区容量由`CONFIG_MBOX_DATA_MAX_MSG_SIZE`配置，默认 **4 字节**。若开发板邮箱驱动支持更大的 MTU，应在开发板专用配置片段`boards/<board>.conf`中覆盖此值，例如：

```kconfig
CONFIG_MBOX_DATA_MAX_MSG_SIZE=32
```

程序在运行时使用`mbox_mtu_get_dt()`查询实际 MTU，并检查它是否超出所配置的容量。

## 25.2\_为不同开发板构建

以下命令均在 Zephyr 仓库根目录执行，使用系统构建（Sysbuild）；原命令中的开发板标识按原文保留。

为`mimxrt1160_evk_cm7`构建和调试：

```shell
# From the root of the zephyr repository
west build -b mimxrt1160_evk_cm7 --sysbuild samples/drivers/mbox_data/
west debug
```

为`mimxrt1170_evk_cm7`构建和调试：

```shell
# From the root of the zephyr repository
west build -b mimxrt1170_evk_cm7 --sysbuild samples/drivers/mbox_data/

```

为`lpcxpresso55s69_cpu1`构建和调试：

```shell
# From the root of the zephyr repository
```

## 25.3\_串口连接与客户端输出

打开串口终端（Serial Terminal），例如 minicom 或 PuTTY，以波特率（Baud Rate）`115200`、8 数据位（Data Bits）、无校验（Parity）、1 停止位（Stop Bit）连接开发板。复位后，两个串口分别显示主核（Main Core）和远端核（Remote Core）的消息。

日志中的 OS 指操作系统（Operating System）。客户端（Client）原输出：

```text
*** Booting Zephyr OS build zephyr-v3.5.0-4051-g12f4f4dc8679 ***
mbox_data Client demo started
Using MTU: 4 bytes
Client send (on channel 3) value: 0
Client received (on channel 2) value: 1
Client send (on channel 3) value: 2
Client received (on channel 2) value: 3
Client send (on channel 3) value: 4
...
Client received (on channel 2) value: 95
Client send (on channel 3) value: 96
Client received (on channel 2) value: 97
Client send (on channel 3) value: 98
Client received (on channel 2) value: 99
mbox_data Client demo ended
```

示例使用 4 字节 MTU。客户端从通道 3 发送，从通道 2 接收；数据依次递增，最后显示演示结束。

## 25.4\_服务端输出与参见

服务端（Server）原输出：

```text
*** Booting Zephyr OS build zephyr-v3.5.0-4051-g12f4f4dc8679 ***
mbox_data Server demo started
Using MTU: 4 bytes
Server receive (on channel 3) value: 0
Server send (on channel 2) value: 1
Server receive (on channel 3) value: 2
Server send (on channel 2) value: 3
Server receive (on channel 3) value: 4
...
Server send (on channel 2) value: 95
Server receive (on channel 3) value: 96
Server send (on channel 2) value: 97
Server receive (on channel 3) value: 98
Server send (on channel 2) value: 99
mbox_data Server demo ended.
```

服务端从通道 3 接收，从通道 2 发回数据。原日志中的`zephyr-v3.5.0-4051-g12f4f4dc8679`属于官方示例，不代表本译文读取时的最新版本。

概念说明见[邮箱驱动](../hardware/P069_邮箱驱动.md)，接口契约见[邮箱公共接口](P014_邮箱驱动公共接口.md)。
