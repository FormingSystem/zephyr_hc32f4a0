# 第15章\_邮箱驱动后端接口

原文：[group__mbox__interface__backend](https://docs.zephyrproject.org/latest/doxygen/html/group__mbox__interface__backend.html)。读取日期：2026-10-13，`latest`。

本分组提供实现邮箱（Mailbox，MBOX）驱动所需的应用程序接口（Application Programming Interface，API）类型定义、回调（Callback）签名与辅助内容，声明位于`zephyr/drivers/mbox.h`。驱动操作表见[`struct mbox_driver_api`](P016_邮箱驱动操作结构.md)。

## 15.1\_收到消息时的回调


```c
typedef void (*mbox_callback_t)(const struct device *dev,
                                mbox_channel_id_t channel_id, void *user_data,
                                struct mbox_msg *data);
```

通过`mbox_register_callback()`注册接收回调。它在中断上下文（Interrupt Context）执行，因此只能使用中断安全（Interrupt-safe）的接口。信号通知模式（Signalling Mode）下，`data`必须为`NULL`。

| 参数 | 含义 |
| --- | --- |
| `dev` | 邮箱设备实例 |
| `channel_id` | 通道编号 |
| `user_data` | 注册时提供的私有数据指针 |
| `data` | 消息结构 |

## 15.2\_发送消息操作


```c
typedef int (*mbox_send_t)(const struct device *dev,
                           mbox_channel_id_t channel_id,
                           const struct mbox_msg *msg);
```

发送邮箱消息的回调类型。`dev`为设备实例，`channel_id`为通道编号，`msg`为消息结构。返回值与相关说明见[公共`mbox_send()`接口](P014_邮箱驱动公共接口.md)。

## 15.3\_查询最大消息大小


```c
typedef int (*mbox_mtu_get_t)(const struct device *dev);
```

取得最大数据大小的回调类型；参数`dev`为设备实例，返回值见[`mbox_mtu_get()`](P014_邮箱驱动公共接口.md)。这里 MTU 指最大传输单元（Maximum Transmission Unit）。

## 15.4\_注册回调操作


```c
typedef int (*mbox_register_callback_t)(const struct device *dev,
                                        mbox_channel_id_t channel_id,
                                        mbox_callback_t cb, void *user_data);
```

注册接收处理函数时调用的操作。`dev`为设备实例，`channel_id`为通道编号，`cb`为接收消息中断时执行的回调，`user_data`为执行回调时传入的应用专用指针。返回值见[`mbox_register_callback()`](P014_邮箱驱动公共接口.md)。

## 15.5\_设置中断使能


```c
typedef int (*mbox_set_enabled_t)(const struct device *dev,
                                  mbox_channel_id_t channel_id, bool enabled);
```

设置中断使能时调用的操作。`dev`为设备实例，`channel_id`为通道编号；`enabled`设为`0`表示禁用，非零表示使能。返回值见[`mbox_set_enabled()`](P014_邮箱驱动公共接口.md)。

## 15.6\_查询最大通道数


```c
typedef uint32_t (*mbox_max_channels_get_t)(const struct device *dev);
```

查询最大通道数的回调类型，`dev`为设备实例，返回值见[`mbox_max_channels_get()`](P014_邮箱驱动公共接口.md)。该公共接口页同时保留了原文负错误码描述与无符号返回类型之间差异的译注。
