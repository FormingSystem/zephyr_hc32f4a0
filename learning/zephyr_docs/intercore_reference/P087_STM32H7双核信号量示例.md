# 第87章\_STM32H7双核信号量示例

原文：[Hardware Semaphore (HSEM) Inter-Processor Communication on STM32 H7](https://docs.zephyrproject.org/latest/samples/boards/st/h7_dual_core/README.html)。读取日期：2026-10-13，`latest`。

本示例使用STM32 H7的硬件信号量（Hardware Semaphore，HSEM）进行处理器间通信（Inter-Processor Communication）：邮箱（Mailbox）收到新消息时触发发光二极管（Light-Emitting Diode，LED）闪烁。

## 87.1\_构建与运行

在Zephyr仓库根目录，为`stm32h747i_disco/stm32h747xx/m7`构建：

```sh
# From the root of the zephyr repository
west build -b stm32h747i_disco/stm32h747xx/m7 samples/boards/st/h7_dual_core
```

为`stm32h747i_disco/stm32h747xx/m4`构建：

```sh
# From the root of the zephyr repository
west build -b stm32h747i_disco/stm32h747xx/m4 samples/boards/st/h7_dual_core
```

## 87.2\_原始输出

```text
STM32 h7_dual_core application
```

原页没有提供额外烧录或串口配置步骤。另见[处理器间邮箱接口（Inter-Processor Mailbox，IPM）](P058_处理器间消息公共接口.md)。

源码入口：[官方示例目录](https://github.com/zephyrproject-rtos/zephyr/tree/main/samples/boards/st/h7_dual_core)。
