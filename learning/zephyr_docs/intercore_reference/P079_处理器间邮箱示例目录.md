# 第79章\_处理器间邮箱示例目录

原文：[Inter-Processor Mailbox (IPM)](https://docs.zephyrproject.org/latest/samples/drivers/ipm/README.html)。读取日期：2026-10-13，`latest`。

以下示例演示处理器间邮箱（Inter-Processor Mailbox，IPM）驱动应用程序编程接口（Application Programming Interface，API）的用法。IPM概述见[处理器间消息](../hardware/P068_处理器间消息.md)。

## 79.1\_示例目录

| 示例 | 原文说明 |
| --- | --- |
| [ESP32双核IPM](P080_ESP32双核IPM示例.md) | 在ESP32的APP与PRO中央处理器（Central Processing Unit，CPU）之间实现IPM |
| [NXP i.MX IPM](P081_NXPiMX处理器间邮箱示例.md) | 在包含消息单元（Messaging Unit）外设的i.MX片上系统（System on Chip，SoC）上实现IPM |
| [NXP LPC IPM](P083_NXPLPC处理器间邮箱示例.md) | 在NXP LPC系列上实现IPM |
| [基于IVSHMEM的IPM](P082_IVSHMEM处理器间邮箱示例.md) | 通过虚拟机间共享内存（Inter-VM Shared Memory，IVSHMEM）实现IPM；VM为虚拟机（Virtual Machine） |
| [Arm MHU IPM](P084_ArmMHU双核IPM示例.md) | 使用消息处理单元（Message Handling Unit，MHU）实现IPM |

APP、PRO和LPC保留原核心或产品系列名称。

另见[IPM公共接口](P058_处理器间消息公共接口.md)。
