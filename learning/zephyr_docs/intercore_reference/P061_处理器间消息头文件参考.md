# 第61章\_处理器间消息头文件参考

原文：[ipm_8h](https://docs.zephyrproject.org/latest/doxygen/html/ipm_8h.html)。读取日期：2026-10-13，`latest`。

`zephyr/drivers/ipm.h`是处理器间邮箱（Inter-Processor Mailbox，IPM）驱动应用程序编程接口（Application Programming Interface，API）的主头文件。原页列出以下包含项、一个驱动结构、七个类型定义和六个函数；完整代码见[源码页](P062_处理器间消息完整头文件.md)。

## 61.1\_包含项与驱动结构

```c
#include <zephyr/kernel.h>
#include <zephyr/device.h>
#include <zephyr/syscalls/ipm.h>
```

驱动操作结构为[`struct ipm_driver_api`](P060_处理器间消息驱动接口结构.md)。

## 61.2\_回调与后端类型


```c
typedef void (*ipm_callback_t)(const struct device *ipmdev, void *user_data,
                               uint32_t id, volatile void *data);

typedef int (*ipm_send_t)(const struct device *ipmdev, int wait, uint32_t id,
                          const void *data, int size);

typedef int (*ipm_max_data_size_get_t)(const struct device *ipmdev);

typedef uint32_t (*ipm_max_id_val_get_t)(const struct device *ipmdev);

typedef void (*ipm_register_callback_t)(const struct device *port,
                                        ipm_callback_t cb,
                                        void *user_data);

typedef int (*ipm_set_enabled_t)(const struct device *ipmdev, int enable);

typedef void (*ipm_complete_t)(const struct device *ipmdev);
```

`ipm_callback_t`处理收到的消息；其他六个类型分别负责发送消息、查询数据大小上限、查询标识符上限、注册回调、启用或禁用入站中断，以及通知异步完成。完整类型说明见[公共接口](P058_处理器间消息公共接口.md)和[驱动后端](P059_处理器间消息驱动后端.md)。

## 61.3\_公共函数


```c
int ipm_send(const struct device *ipmdev, int wait, uint32_t id,
                       const void *data, int size);

int ipm_max_data_size_get(const struct device *ipmdev);

uint32_t ipm_max_id_val_get(const struct device *ipmdev);

int ipm_set_enabled(const struct device *ipmdev, int enable);

void ipm_complete(const struct device *ipmdev);

static inline void ipm_register_callback(const struct device *ipmdev,
                                         ipm_callback_t cb, void *user_data);
```

`ipm_send()`尝试发送；`ipm_register_callback()`注册接收回调；`ipm_max_data_size_get()`返回出站消息最大字节数；`ipm_max_id_val_get()`返回出站消息标识符最大值；`ipm_set_enabled()`控制入站中断与回调；`ipm_complete()`通知异步命令完成。参数与返回值见[公共接口详解](P058_处理器间消息公共接口.md)。
