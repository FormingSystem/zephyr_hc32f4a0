# 第13章\_硬件自旋锁驱动示例

原文：[HWSPINLOCK](https://docs.zephyrproject.org/latest/samples/drivers/hwspinlock/README.html)。读取日期：2026-10-13，`latest`。

本示例通过硬件自旋锁（Hardware Spinlock，HWSPINLOCK）与邮箱（Mailbox，MBOX）应用程序接口（Application Programming Interface，API）演示跨核同步。原目录为`samples/drivers/hwspinlock`，可浏览[官方示例源码](https://github.com/zephyrproject-rtos/zephyr/tree/main/samples/drivers/hwspinlock)。

## 13.1\_两个镜像如何协作

本例用系统构建（Sysbuild）运行两个 Zephyr 镜像（Image）：

- 主端（HOST）定期锁定一个硬件自旋锁门（Gate），持锁期间发送邮箱请求（Ping），随后释放锁并等待应答（Pong）。
- 远端（REMOTE）接收请求，展示主端持锁时非阻塞（Non-blocking）尝试加锁会失败；然后等待同一锁门可用，取得锁后回复。

目的是展示 HWSPINLOCK API 通过硬件控制器实现真正的核间互斥（Inter-core Mutual Exclusion），而 MBOX 用于信号通知（Signaling）。

## 13.2\_构建与运行

为 FRDM-MCXN947 的中央处理器（Central Processing Unit，CPU）CPU0 和 CPU1 构建。在 Zephyr 仓库根目录运行以下原命令；首行注释也说明该执行位置：

```shell
# From the root of the zephyr repository
west build -b frdm_mcxn947/mcxn947/cpu0 --sysbuild samples/drivers/hwspinlock
```

## 13.3\_预期输出

主端输出示例：

```text
Hello from HOST - frdm_mcxn947/mcxn947/cpu0
...
HOST: locked gate id=0, sending ping on channel 1
HOST: unlocked gate, waiting for pong...
HOST: received pong
```

含义是：主端已锁定编号 0 的锁门，经通道 1 发送请求；释放锁后等待应答，最后收到应答。

远端输出示例：

```text
Hello from REMOTE - frdm_mcxn947/mcxn947/cpu1
...
REMOTE: got ping (rx_sem), checking gate contention...
REMOTE: trylock returned -16 (expected if HOST holds the lock)
REMOTE: waiting to acquire gate...
REMOTE: acquired gate id=0
REMOTE: locked gate id=0, sending pong on channel 0
```

远端通过`rx_sem`收到请求后检查锁竞争（Contention）；主端持锁时，`trylock`返回`-16`是预期结果。随后远端等待锁、取得编号 0 的锁门，并经通道 0 发送应答。输出保留原英文，便于与串口日志对照。
