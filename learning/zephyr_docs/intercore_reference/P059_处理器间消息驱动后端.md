# 第59章\_处理器间消息驱动后端

原文：[group__ipm__interface__backend](https://docs.zephyrproject.org/latest/doxygen/html/group__ipm__interface__backend.html)。读取日期：2026-10-13，`latest`。

处理器间邮箱（Inter-Processor Mailbox，IPM）驱动后端（Driver Backend）提供实现驱动所需的应用程序编程接口（Application Programming Interface，API）类型定义、回调签名和辅助声明。它们都来自`zephyr/drivers/ipm.h`，驱动操作结构为[`ipm_driver_api`](P060_处理器间消息驱动接口结构.md)。

以下六项均为回调（Callback）函数指针类型。各参数定义由对应的[公共函数说明](P058_处理器间消息公共接口.md)给出。

## 59.1\_发送IPM消息


```c
typedef int (*ipm_send_t)(const struct device *ipmdev, int wait, uint32_t id,
                          const void *data, int size);
```

`ipm_send_t`用于发送IPM消息；参数定义见公共接口中的`ipm_send()`。

## 59.2\_查询最大数据大小


```c
typedef int (*ipm_max_data_size_get_t)(const struct device *ipmdev);
```

`ipm_max_data_size_get_t`用于查询最大数据大小；参数定义见公共接口中的`ipm_max_data_size_get()`。

## 59.3\_查询消息标识符最大值


```c
typedef uint32_t (*ipm_max_id_val_get_t)(const struct device *ipmdev);
```

`ipm_max_id_val_get_t`用于查询消息标识符最大值；参数定义见公共接口中的`ipm_max_id_val_get()`。

## 59.4\_注册消息接收回调


```c
typedef void (*ipm_register_callback_t)(const struct device *port,
                                        ipm_callback_t cb,
                                        void *user_data);
```

`ipm_register_callback_t`用于注册消息接收回调；参数定义见公共接口中的`ipm_register_callback()`。

## 59.5\_启用或禁用入站通道中断


```c
typedef int (*ipm_set_enabled_t)(const struct device *ipmdev, int enable);
```

`ipm_set_enabled_t`用于启用或禁用入站通道中断；参数定义见公共接口中的`ipm_set_enabled()`。

## 59.6\_通知异步命令完成


```c
typedef void (*ipm_complete_t)(const struct device *ipmdev);
```

`ipm_complete_t`用于通知异步命令完成；参数定义见公共接口中的`ipm_complete()`。

**名称译注：**注册类型中的设备参数名保留原声明`port`，公共函数使用`ipmdev`；两处类型均为`const struct device *`。完整声明见[头文件源码](P062_处理器间消息完整头文件.md)。
