# 第134章\_静态虚拟环常量完整头文件

原文：[static__vrings_8h_source](https://docs.zephyrproject.org/latest/doxygen/html/static__vrings_8h_source.html)。读取日期：2026-10-13，`latest`。

本页保留官方源码浏览页中`zephyr/dt-bindings/ipc_service/static_vrings.h`的完整可见代码，用于静态虚拟环设备树常量。静态虚拟环（Static VRINGs）的设备树（Devicetree）常量保持原始标识。展示行号已移除，声明、版权和许可证均保留。

阅读提示：`PRIO_COOP`和`PRIO_PREEMPT`分别表示协作式（Cooperative）与抢占式（Preemptive）优先级类型，见[常量参考页](P133_静态虚拟环常量头文件参考.md)；`BIT`为位掩码构造宏（Bitmask Macro）。

## 134.1\_完整可见源码

```c
/*
 * Copyright (c) 2022 Carlo Caione <ccaione@baylibre.com>
 *
 * SPDX-License-Identifier: Apache-2.0
 */
#ifndef ZEPHYR_INCLUDE_DT_BINDINGS_IPC_SERVICE_STATIC_VRINGS_H_
#define ZEPHYR_INCLUDE_DT_BINDINGS_IPC_SERVICE_STATIC_VRINGS_H_

#include <zephyr/dt-bindings/dt-util.h>

#define PRIO_COOP       BIT(0)
#define PRIO_PREEMPT    BIT(1)

#endif /* ZEPHYR_INCLUDE_DT_BINDINGS_IPC_SERVICE_STATIC_VRINGS_H_ */
```
