> 译注——源码核对：当前普通文本与字典输出的丢弃数量提示都将计数限制为最多9999；字典丢弃通知编码为专用消息类型，不恢复原日志内容。

> 译注——源码核对：type区分普通日志与丢弃通知。本结构只保存类型和丢弃数量，不含被丢弃日志的原消息或时间戳；解码时不能按普通消息头读取。
