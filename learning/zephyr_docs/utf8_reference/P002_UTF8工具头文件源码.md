## 2.3\_原页符号提示（Symbol Descriptions）

### `utf8_trunc`

```c
char * utf8_trunc(char *utf8_str)
```

正确截断以空字符终止的 UTF-8 字符串。

符号定位：[utf8_trunc](../util_reference/P001_通用工具公共接口.md#ga1bbcfa5d7bfe757afab489d2ce41e30a)。

### `utf8_lcpy`

```c
char * utf8_lcpy(char *dst, const char *src, size_t n)
```

将 UTF-8 编码字符串从 src 复制到 dst。

符号定位：[utf8_lcpy](../util_reference/P001_通用工具公共接口.md#ga376935d7e6eece7dbdd382de057ec2f9)。

```c
int utf8_count_chars(const char *s)
```

统计 UTF-8 编码字符串 s 中的字符数。

符号定位：[utf8_count_chars](../util_reference/P001_通用工具公共接口.md#ga94a461a4ea751deb7c6b4565c85e6d98)。

## 2.4\_源码跟踪译注

> 译注——字符与容量：UTF-8采用可变长度编码（Variable-length Encoding），一个码点（Code Point）可能占多个字节。utf8_lcpy的n是目标缓冲区字节容量，最多先复制n-1字节，然后去掉末尾残缺序列；不能将它理解成最多复制n-1个Unicode字符。原文参数说明与对应译注见公共接口页。

> 译注——终止与截断：utf8_trunc要求输入已经以空字符终止且可写，只修整末尾；utf8_lcpy在n>0时写入终止符，n=1得到空串，n=0不修改目标。这些函数不提供完整的UTF-8合法性验证，源和目标的容量及重叠前提由调用者保证。

> 译注——计数范围：utf8_count_chars检查基本的起始字节／续字节模式，遇到不匹配模式返回-EINVAL，但不会完整排除过长编码或代理码点。返回的码点数不等于用户看到的字素簇（Grapheme Cluster）数。

> 译注——配置与版本：lib/utils/CMakeLists.txt仅在CONFIG_UTF8启用时纳入utf8.c；只包含头文件并不启用实现。本页可见代码与本次官方头文件去除注释和展示空白后的内容一致；本仓库相对定位用于跟踪，不代表所有本地版本与滚动main相同。

头文件相对定位：[include/zephyr/sys/util_utf8.h](../../../include/zephyr/sys/util_utf8.h)，关联实现／接口：[lib/utils/utf8.c](../../../lib/utils/utf8.c)；[官方原始头文件](https://github.com/zephyrproject-rtos/zephyr/blob/main/include/zephyr/sys/util_utf8.h)与[官方关联文件](https://github.com/zephyrproject-rtos/zephyr/blob/main/lib/utils/utf8.c)的摘要见来源记录。去掉注释和展示空白后，本页代码与本次读取的原始头文件一致，不能推广到以后滚动更新的main或任意本地版本。
