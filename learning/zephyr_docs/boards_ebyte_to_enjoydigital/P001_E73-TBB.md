## 概述（Overview）

EBYTE E73-TBB硬件支持Nordic Semiconductor nRF52832 ARM Cortex-M4F CPU及以下器件：


- 模数转换器（ADC）
- 时钟（CLOCK）
- 闪存（FLASH）
- 通用输入输出（GPIO）
- 集成电路间总线（I2C）
- 存储器保护单元（MPU）
- 嵌套向量中断控制器（NVIC）
- 脉宽调制（PWM）
- 无线电（RADIO，低功耗蓝牙 / Bluetooth Low Energy）
- 实时时钟（RTC）
- Segger实时传输（RTT，RTT控制台 / RTT Console）
- 串行外设接口（SPI）
- 通用异步收发器（UART）
- 看门狗定时器（WDT）

## 硬件（Hardware）

E73-TBB具有两个外部振荡器：低速时钟32.768 kHz，主时钟32 MHz；此外还带有CH340 USB转UART转换器。可以通过U.FL插座连接外部蓝牙（BT）天线，并在NFC_ANT连接器处焊接近场通信（NFC）天线。

<a id="flashing"></a>

### 烧录（Flashing）

按[Nordic nRF5x Segger J-Link](../debugging/P005_Nordic_Segger_JLink.md#nordic-segger)页面安装并配置全部必要软件。烧录开发板时，将E73-TBB的SWDIO、SWDCLK、RST及GND接到J-Link设备的对应引脚，然后按通常方式构建及烧录应用。

```text
# From the root of the zephyr repository
west build -b ebyte_e73_tbb/nrf52832 samples/basic/blinky
west flash
```
