# 第23章\_可移植性示例目录

原文：[官方页面](https://docs.zephyrproject.org/latest/samples/subsys/portability/portability.html)。读取日期：2026-10-14；保存的latest页面及HTML摘要见[来源记录](../SOURCES.md)。

本组示例展示[操作系统抽象与可移植性（OS Abstraction and Portability）](P001_操作系统抽象入口.md#osal)功能。

<a id="cmsis_rtos_v1"></a>

## 23.1 CMSIS实时操作系统接口v1（CMSIS RTOS v1）

分类入口：[CMSIS实时操作系统接口v1（CMSIS RTOS v1）](P004_CMSISRTOS1示例目录.md)。

- [CMSIS RTOS V1哲学家就餐（Dining Philosophers (CMSIS RTOS V1 APIs)）](P005_CMSISRTOS1哲学家就餐示例.md#cmsis-rtos-v1)：通过CMSIS RTOS V1实现哲学家就餐问题（Dining Philosophers Problem）的一个解法。

- [CMSIS RTOS V1线程同步（Synchronization using CMSIS RTOS V1 APIs）](P006_CMSISRTOS1定时同步示例.md#cmsis-rtos-v1-sync)：使用CMSIS RTOS v1 API中的定时器和消息队列同步线程。

<a id="cmsis_rtos_v2"></a>

## 23.2 CMSIS实时操作系统接口v2（CMSIS RTOS v2）

分类入口：[CMSIS实时操作系统接口v2（CMSIS RTOS v2）](P007_CMSISRTOS2示例目录.md)。

- [CMSIS RTOS V2哲学家就餐（Dining Philosophers (CMSIS RTOS V2 APIs)）](P008_CMSISRTOS2哲学家就餐示例.md#cmsis-rtos-v2)：通过CMSIS RTOS V2实现哲学家就餐问题的一个解法。

- [CMSIS RTOS V2线程同步（Synchronization using CMSIS RTOS V2 APIs）](P009_CMSISRTOS2定时同步示例.md#cmsis-rtos-v2-sync)：使用CMSIS RTOS v2 API中的定时器和消息队列同步线程。

<a id="posix"></a>

## 23.3 POSIX接口（POSIX API）

分类入口：[POSIX接口（POSIX API）](P017_POSIX示例目录.md)。

- [环境变量（Environment Variables）](P018_POSIX环境变量示例.md#posix-env)：从Zephyr应用中操作环境变量（Environment Variable）。

- [事件通知文件描述符（eventfd()）](P019_eventfd事件通知示例.md#posix-eventfd)：使用eventfd()创建用于事件通知的文件描述符（File Descriptor）。

- [带时钟初始化的时间获取（gettimeofday() with clock initialization）](P020_系统时间与SNTP示例.md#posix-gettimeofday)：通过SNTP初始化时钟，并使用gettimeofday()获取时间。

- [POSIX哲学家就餐（POSIX Philosophers）](P021_POSIX哲学家就餐示例.md#posix-philosophers)：通过POSIX API实现哲学家就餐问题的一个解法。

- [系统信息获取（uname()）](P022_uname系统信息示例.md#posix-uname)：使用uname()获取系统信息，并输出到控制台。
