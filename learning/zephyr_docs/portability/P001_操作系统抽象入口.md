# 第1章\_操作系统抽象入口

原文：[官方页面](https://docs.zephyrproject.org/latest/services/portability/index.html)。读取日期：2026-10-14；保存的 latest 页面及 HTML 摘要见[来源记录](../SOURCES.md)。

## 1.1\_操作系统抽象（OS Abstraction）

操作系统抽象层（Operating System Abstraction Layer，OSAL）通过包装函数 API 封装操作系统提供的常见系统功能，使面向多个软件和硬件平台的开发与代码移植更容易、更快捷。

以下章节介绍 Zephyr RTOS 支持的软件和硬件抽象层：

- [可移植操作系统接口（Portable Operating System Interface，POSIX）](P010_POSIX文档入口.md)。
- [CMSIS-RTOS 第 1 版](P002_CMSISRTOS版本1.md)。
- [CMSIS-RTOS 第 2 版](P003_CMSISRTOS版本2.md)。

译注：本页为官方目录。抽象层提供的是应用所用的兼容接口，其实现仍依赖 Zephyr 的内核和配置；入口完成不代表所链接的全部标准、API 和平台均已覆盖。
