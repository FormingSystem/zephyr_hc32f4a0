# 可配置错误检查参考大纲

CHECKIF用可配置错误检查（Configurable Error Checking）控制一段错误处理代码：默认在错误条件为真时执行，另一配置可改成断言（Assertion），也可省略检查。条件的求值与后续代码块是否执行都会随配置改变，所以它不能直接替代所有普通if语句。

本册覆盖官方接口、头文件参考和源码，保留原始示例、宏展开、声明、参数及法律注释。源码译注解释错误条件方向、检查省略、副作用、断言配置和多语句展开的使用前提。全部本地定位采用相对路径，完整范围见[全站进度](../PROGRESS.md)。
