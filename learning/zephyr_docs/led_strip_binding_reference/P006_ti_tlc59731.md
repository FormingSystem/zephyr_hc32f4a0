# 第6章\_ti_tlc59731

原文：[官方页面](https://docs.zephyrproject.org/latest/build/dts/api/bindings/led_strip/ti,tlc59731.html)。读取日期：2026-10-16；来源摘要见[来源记录](../SOURCES.md)。

<a id="ti-tlc59731"></a>
<a id="dtbinding-ti-tlc59731"></a>
<a id="std-dtcompatible-ti-tlc59731"></a>

兼容字符串（Compatible String）：`ti,tlc59731`。厂商：[ Texas Instruments ](https://docs.zephyrproject.org/latest/build/dts/api/bindings.html#dt-vendor-ti)。

采用此设备树绑定（Devicetree Binding）的开发板见[官方筛选目录](https://docs.zephyrproject.org/latest/boards/index.html#compatibles=ti,tlc59731)。

驱动源码（Driver Source）：[drivers/led_strip/tlc59731.c](https://github.com/zephyrproject-rtos/zephyr/blob/main/drivers/led_strip/tlc59731.c)。

<a id="description"></a>

TLC59731 RGB LED控制器。

<a id="properties"></a>

属性类型：`int` 为整数，`boolean` 为布尔属性，`string` 为字符串，`string-array` 为字符串数组，`array` 为数值数组，`compound` 为复合类型；`phandle` 为节点引用（Phandle），`phandles` 为节点引用列表，`phandle-array` 为节点引用与说明符单元数组。

## 6.1\_节点专用属性

这些属性不继承自基础绑定文件。

| 属性 | 类型 | 中文说明与约束 |
| --- | --- | --- |
| `gpios` | `phandle-array` | **必需**。向控制器发送命令数据的GPIO。 |
| `chain-length` | `int` | **必需**。菊花链（Daisy Chain）中的设备数量。 |
| `color-mapping` | `array` | **必需**。通道到颜色的映射（Channel-to-Color Mapping），也称像素顺序（Pixel Order）。下方保留绿、红、蓝（GRB）顺序的原例。 |

本页没有已弃用的节点专用属性。

## GRB颜色顺序原例

```dts
   color-mapping = <LED_COLOR_ID_GREEN
                    LED_COLOR_ID_RED
                    LED_COLOR_ID_BLUE>;
```
