## 概述（Overview）

Icarus SoM是一款硬币大小、易于焊接的蜂窝物联网模块（Cellular IoT Module）。它围绕Nordic Semiconductor nRF9160调制解调器（Modem）构建，集成LTE-M、窄带物联网（NB-IoT）、GPS、加速度计（Accelerometer）、嵌入式SIM（eSIM），并支持选配外部nano-SIM接口。

主微控制器（Microcontroller）为Nordic Semiconductor nRF9160，具有ARM Cortex-M33F处理器、ARMv8-M安全扩展（Security Extension）以及以下由Nordic直接提供的设备：


- 模数转换器（ADC）
- 时钟（CLOCK）
- 闪存（FLASH）
- 通用输入输出（GPIO）
- 集成电路间总线（I2C）
- 存储器保护单元（MPU）
- 嵌套向量中断控制器（NVIC）
- 脉宽调制（PWM）
- 实时时钟（RTC）
- Segger实时传输（RTT，RTT控制台 / RTT Console）
- 串行外设接口（SPI）
- 带EasyDMA的通用异步收发器（UARTE）
- 看门狗定时器（WDT）
- 实现定义的归属单元（IDAU）

## SIM选择（SIM Selection）

可以在设备树（Devicetree）中调整`sim_select`节点的`sim`属性，选择eSIM或nano-SIM。

<a id="security-components"></a>

### 安全组件（Security Components）


- <a id="id5"></a>

  实现定义的归属单元（[实现定义的归属单元（IDAU）](https://developer.arm.com/docs/100690/latest/attribution-units-sau-and-idau) / Implementation Defined Attribution Unit）[注1](#id4)。IDAU由系统保护单元（SPU / System Protection Unit）实现，用于定义安全与非安全存储器映射（Secure / Non-secure Memory Maps）。默认情况下，整个存储空间，包括Flash、SRAM及外设地址空间，都被定义为仅允许安全访问（Secure Access）。
- 安全启动（Secure Boot）。

<a id="building-secure-non-secure-zephyr-applications"></a>

### 构建安全／非安全Zephyr应用（Secure / Non-Secure Applications）

该过程包含以下步骤：


1. 使用`-DBOARD=actinius_icarus_som`构建安全Zephyr应用（Secure Application）。
2. 使用`-DBOARD=actinius_icarus_som/ns`构建非安全Zephyr应用（Non-Secure Application）。
3. 将两个二进制文件合并。

如果使用Segger Embedded Studio v4.18或更新版本，除非手动禁用了该功能，否则这两个二进制文件会自动完成构建、合并和烧录。

构建安全／非安全应用（Secure / Non-Secure Application）时，安全应用必须配置IDAU（SPU），使非安全应用固件用到的所有CPU资源允许非安全访问（Non-Secure Access）。SPU配置必须在跳转到非安全应用之前完成。
