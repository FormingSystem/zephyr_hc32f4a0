## 概述（Overview）

SEGGER NAND Flash Evaluator（nandeval_h743zi）用于评估并行NAND闪存，包含基于ST STM32H743ZI Arm Cortex-M7的底板及承载NAND器件的适配板。适配板通过排针插入底板，接受8位或16位数据总线的TSOP48及VFBGA63封装NAND。随附适配板提供TSOP48插座，可无需焊接更换NAND器件。

NAND连接微控制器专用的灵活存储控制器（Flexible Memory Controller，FMC）NAND接口，实现高速传输。底板可通过Micro-USB或调试连接器供电，跳线选择3.3 V或1.8 V，同时为微控制器及NAND供电。

主要特性（Key Features）


- ST STM32H743ZI Arm Cortex-M7微控制器，LQFP144封装
- 三组8引脚排针，用于连接NAND适配板
- 绿／红双色用户LED
- 20引脚标准Cortex Debug+ETM连接器
- 全速USB接口（Full-speed USB）
- Micro-USB连接器，用于供电及数据传输
- 可选3.3 V或1.8 V供电

更多板卡信息见SEGGER NAND Flash Evaluator网站。（[SEGGER NAND闪存评估板网站](https://www.segger.com/evaluate-our-software/segger/nand-flash-eval-board/)）

## 硬件（Hardware）

NAND闪存评估底板基于STM32H743ZI，提供以下硬件：


- LQFP144封装的STM32H743ZI
- Arm 32位Cortex-M7 CPU，带浮点单元（FPU）
- CPU最高频率480 MHz
- 2 MB闪存（Flash）
- 1 MB SRAM
- FMC NAND闪存接口
- 全速USB OTG
- 支持外部中断（External Interrupt）的 GPIO。

微控制器更多信息见[ST网站上的STM32H743ZI资料](https://www.st.com/en/microcontrollers-microprocessors/stm32h743zi.html)及STM32H743参考手册。（[STM32H743参考手册（Reference Manual）](https://www.st.com/resource/en/reference_manual/dm00314099.pdf)）

底板通过20引脚Cortex Debug+ETM连接器及调试探针编程和调试。除调试信号外，此连接器还引出ITM及DWT跟踪数据，以及位于TRACEDATA[0..3]和TRACECLK的嵌入式跟踪宏单元（ETM）指令跟踪信号，因此SWD及JTAG模式下均可使用ETM。

nandeval_h743zi板级配置的应用可按常规方式构建及烧录，详情见“构建应用”及“运行应用”。（[构建应用（Building an Application）](../application/P001_应用开发.md#build-an-application)；[运行应用（Run an Application）](https://docs.zephyrproject.org/latest/develop/application/index.html#application-run)）

<a id="flashing"></a>

### 烧录（Flashing）

将兼容JTAG探针连接主机及底板的Cortex Debug+ETM连接器，再构建并烧录应用。

下面以[Hello World](../getting_started/P005_HelloWorld示例.md#hello_world)应用为例。

```text
# From the root of the zephyr repository
west build -b nandeval_h743zi samples/hello_world
west flash
```

控制台通过SEGGER RTT输出，因此需要打开RTT终端查看：

```text
$ west rtt
```

控制台上应显示以下消息：

```text
$ Hello World! nandeval_h743zi
```

<a id="debugging"></a>

### 调试（Debugging）

可以按常规方式调试应用。下面以[Hello World](../getting_started/P005_HelloWorld示例.md#hello_world)应用为例。

```text
# From the root of the zephyr repository
west build -b nandeval_h743zi samples/hello_world
west debug
```
