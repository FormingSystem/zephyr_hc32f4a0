# Base64编解码参考大纲

Base64编码（Encoding）把二进制字节转换为有限字符集中的文本，解码（Decoding）执行反向转换。这组接口由调用者提供缓冲区，支持先查询空间再写入；正确区分容量、实际长度和字符串终止符，才能避免少分配一个字节或把二进制输出误当作C字符串。

本册覆盖官方接口、头文件参考及源码，保留全部声明、参数、返回说明、原始代码、完整法律注释与适配作者信息。源码跟踪译注标注查询值和成功长度的差别、空输入、非法输入时olen的状态，以及解码器的验证范围。全部本地链接采用相对路径，完整范围见[全站进度](../PROGRESS.md)。
