# 第48章\_CC13x2／CC26x2 系统关闭（CC13x2/CC26x2 System Off）

原文：[官方页面](https://docs.zephyrproject.org/latest/samples/boards/ti/cc13x2_cc26x2/system_off/README.html)。快照读取日期：2026-10-15；来源摘要见[来源记录](../SOURCES.md)。

[在 GitHub 浏览源码（Browse source code on GitHub）](https://github.com/zephyrproject-rtos/zephyr/blob/main//samples/boards/ti/cc13x2_cc26x2/system_off/README.rst/..)

<a id="overview"></a>

## 48.1 概述（Overview）

本示例可用于基础功耗测量，也可作为 TI CC13x2／CC26x2 平台各种睡眠模式的示例。其功能行为如下：

> 译注——模式和计时：五秒 k_busy_wait() 保持 CPU 活动；两毫秒和三秒分别通过睡眠 API 给电源策略进入低功耗状态的机会。Idle、Standby 的实际进入和功耗受平台与设备配置影响，不能把日志标题当作电流测量。

- 忙等（Busy-wait）五秒。

- 休眠两毫秒（空闲模式，Idle mode）。

- 休眠三秒（待机模式，Standby mode）。

- 启用按键唤醒后关闭系统（关断模式，Shutdown mode）。

可以使用功耗监测工具（例如 [EnergyTrace](http://www.ti.com/tool/ENERGYTRACE)）区分这些状态。

<a id="requirements"></a>

## 48.2 前提条件（Requirements）

本应用使用 CC13x2／CC26x2 LaunchPad 进行演示。

<a id="building-flashing-and-running"></a>

## 48.3 构建、烧录与运行（Building, Flashing and Running）

> 译注——执行前提：west 命令从读者的 Zephyr 源码根目录，在 UCRT64 Bash 或 Linux Bash 中执行。先按[入门指南](../getting_started/大纲.md)准备工具、工作区、模块和目标工具链；应用与 overlay 为官方源码，构建目录由工具生成。构建成功后按具体板文档处理下载与启动，不能把通用 west flash 视为所有板都采用同一种连接方式。失败时先检查构建输出、目标板配置和实际硬件；本次没有运行这些命令或进行实板测量。

```text
west build -b cc1352r1_launchxl samples/boards/ti/cc13x2_cc26x2/system_off
west flash
```

烧录设备后，按以下步骤运行代码：

1. 拔下 LaunchPad 的 USB 线，再重新连接，使其完整断电后重新上电。

2. 打开 UART 终端。

3. 按下 LaunchPad 上的 Reset 按钮。

4. 设备会关闭默认处于开启状态的外部 Flash，以降低功耗。

> 译注——板级外部 Flash：本次源码调用 CC1352R1_LAUNCHXL_shutDownExtFlash()，这是针对相应板硬件的节电处理，不是擦除 Flash 数据。不能只替换板目标就假定其他板具有相同外部存储器和关闭接口。

5. 设备会演示活动模式（Active）、空闲模式（Idle）与待机模式（Standby）。

6. 设备会主动进入关断模式关闭自身。按下按钮 1，可唤醒设备，使应用像重新上电一样从头启动。

> 译注——关断后的行为：sys_poweroff() 后按键唤醒使应用从启动流程重新运行，不是在原位置接着执行。源码对 sw0 引脚设置 IOC_WAKE_ON_LOW，并在关断前清除 GPIO 事件；按实际板的 BUTTON1 对应关系操作。
