# 第21章\_电池电压测量（Battery Voltage Measurement）

原文：[官方页面](https://docs.zephyrproject.org/latest/samples/boards/nordic/battery/README.html)。快照读取日期：2026-10-15；来源摘要见[来源记录](../SOURCES.md)。

[在 GitHub 浏览源码（Browse source code on GitHub）](https://github.com/zephyrproject-rtos/zephyr/blob/main//samples/boards/nordic/battery/README.rst/..)

<a id="overview"></a>

## 21.1 概述（Overview）

本示例使用 Zephyr 模数转换器（Analog-to-Digital Converter，ADC）基础设施的 Nordic 配置，测量设备供电电压。支持以下两种供电配置：

> 译注——测量边界：ADC（模数转换器，Analog-to-Digital Converter）测的是接入通道的电压。分压电阻、ADC 参考源及供电连接必须与实际板一致；不能把稳压后的 Vdd 不变误认为电池没有放电。

- 如果开发板设备树中存在兼容标识符（compatible）为 `voltage-divider` 的 `/vbatt` 节点，则通过该分压器测量电压。下面是描述电池监测分压器的设备树节点示例：

> ```text
> / {
>    vbatt {
>       compatible = "voltage-divider";
>       io-channels = <&adc 4>;
>       output-ohms = <180000>;
>       full-ohms = <(1500000 + 180000)>;
>       power-gpios = <&sx1509b 4 0>;
>    };
> };
> ```

- 如果开发板没有分压器，因此也没有 `/vbatt` 节点，则需要通过 `zephyr,user` 节点提供 ADC 配置（设备与通道）。此时假定电源直接连接数字供电电压信号，并选择 `Vdd` 的内部采样源。下面给出这种情况的设备树（Devicetree）配置示例：

> ```text
> / {
>    zephyr,user {
>       io-channels = <&adc 4>;
>    };
> };
> ```

注意，没有分压器时，数字供电电压在许多情况下由稳压器提供，并非直接来自电源；稳压器无论输入电源电压如何都会提供固定电压。含稳压器的配置中，测得的电压将保持不变。

示例提供放电曲线（Discharge curve），将测得的电压映射为剩余容量估计值。正确的曲线取决于电池类型：普通锂聚合物（Lithium Polymer，LiPo）电池所需的曲线不同于普通碱性电池。曲线可以通过测量取得，也可以根据电池数据手册估算。

> 译注——容量估算单位：源码 battery_level_pptt() 返回万分比（Parts per ten thousand，pptt），10000 表示 100%，625 表示 6.25%。示例 levels[] 是针对特定 LiPo 电池及负载粗估的曲线，不是通用电量标定表。

<a id="application-details"></a>

### 21.1.1 应用细节（Application Details）

应用启动时初始化电池测量，随后循环运行，每隔五秒显示一次电池状态。

> 译注——五秒间隔的实现：本次 main.c 使用 k_busy_wait(5 * USEC_PER_SEC) 忙等，注释明确用于消耗电池以便观察变化；它没有每次休眠五秒。做低功耗产品时不能把这份演示原样当作省电测量实现。

## 21.2 前提条件（Requirements）

一块基于 Nordic 芯片的开发板；可选择在设备树配置中提供前述分压器。

## 21.3 构建与运行（Building and Running）

> 译注——执行前提：除本页另有说明的目录外，west 命令从读者自己的 Zephyr 源码根目录，在 UCRT64 Bash 或 Linux Bash 中执行。先准备[入门指南](../getting_started/大纲.md)所需的主机工具、west 工作区、模块与目标工具链；应用、配置及 overlay 为官方源码，构建目录由工具生成。构建成功后再按目标板文档烧录，失败时返回构建输出或板文档检查；下方日志是官方预期示例，本次未执行硬件步骤。

代码位于 [samples/boards/nordic/battery](https://github.com/zephyrproject-rtos/zephyr/blob/main/samples/boards/nordic/battery)。

```text
west build -b thingy52/nrf52832 samples/boards/nordic/battery
west flash
```
