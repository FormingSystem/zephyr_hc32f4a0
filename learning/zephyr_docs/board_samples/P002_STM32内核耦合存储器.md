# 第2章\_内核耦合存储器（Core Coupled Memory，CCM）

原文：[官方页面](https://docs.zephyrproject.org/latest/samples/boards/st/ccm/README.html)。快照读取日期：2026-10-15；来源摘要见[来源记录](../SOURCES.md)。

[在 GitHub 浏览源码（Browse source code on GitHub）](https://github.com/zephyrproject-rtos/zephyr/blob/main//samples/boards/st/ccm/README.rst/..)

<a id="overview"></a>

## 2.1 概述（Overview）

本示例展示多种 STM32 设备中内核耦合存储器（CCM）的用法。它与普通 RAM 的重要区别是 CCM 不能用于直接存储器访问（Direct Memory Access，DMA）。

本示例用 CCM 保存数据，即将其作为数据紧耦合存储器（Data Tightly Coupled Memory，DTCM）。在变量前添加 `__dtcm_data_section`、`__dtcm_bss_section` 或 `__dtcm_noinit_section`，即可将变量放入 CCM。

> 译注——存储区域与 DMA：此处使用 Zephyr 的 DTCM 段标记把数据放入该 STM32 的 CCM，并不意味着所有芯片上 CCM 与 DTCM 完全等同。按本例原文，CCM 不可供 DMA 使用；下文“接收数据的缓冲区”不能据此用作 DMA 目标缓冲区。

`__dtcm_data_section` 前缀用于具有初始值的变量。与普通 data 段一样，其初始值会占用 Flash 镜像空间。

`__dtcm_bss_section` 前缀用于应初始化为 0 的变量。与普通 bss 段一样，它们不占用 Flash 空间。

`__dtcm_noinit_section` 前缀用于不要求确定初值的变量，例如随后会接收数据的缓冲区。与 bss 或 data 段相比，内核不需要初始化 noinit 段，因此启动会略快一些。

为开发板添加 CCM 支持时，在该板 DTS 文件的 `chosen` 节中添加以下内容：

```text
zephyr,dtcm = &ccm0;
```

例如，Olimex STM32 E407 的 DTS 文件如下：

> 译注——文件来源与适用对象：下面是官方板级 DTS 原文件的完整引用，用于说明 `chosen` 与 `ccm0` 的关系，不是要求读者创建或整体替换自己板的 DTS。为另一板适配时先确认其 SoC 确有对应存储区域及节点，再修改该板适用的配置；不能把 E407 的引脚、外设和内存布局直接当作通用模板。

```text
/*
 * Copyright (c) 2017, Erwin Rol <erwin@erwinrol.com>
 *
 * SPDX-License-Identifier: Apache-2.0
 */

/dts-v1/;
#include <st/f4/stm32f407Xg.dtsi>
#include <st/f4/stm32f407z(e-g)tx-pinctrl.dtsi>
#include <zephyr/dt-bindings/input/input-event-codes.h>

/ {
	model = "Olimex STM32-E407 board";
	compatible = "olimex,stm32-e407";

	chosen {
		zephyr,console = &usart1;
		zephyr,shell-uart = &usart1;
		zephyr,sram = &sram0;
		zephyr,flash = &flash0;
		zephyr,dtcm = &ccm0;
	};

	leds {
		compatible = "gpio-leds";

		green_led_1: led_1 {
			gpios = <&gpioc 13 GPIO_ACTIVE_HIGH>;
			label = "LED1";
		};
	};

	gpio_keys {
		compatible = "gpio-keys";

		user_button: button {
			label = "Key";
			gpios = <&gpioa 0 GPIO_ACTIVE_LOW>;
			zephyr,code = <INPUT_KEY_0>;
		};
	};

	aliases {
		led0 = &green_led_1;
		sw0 = &user_button;
	};
};

&clk_lsi {
	status = "okay";
};

&clk_hse {
	clock-frequency = <DT_FREQ_M(12)>;
	status = "okay";
};

&pll {
	div-m = <12>;
	mul-n = <336>;
	div-p = <2>;
	div-q = <7>;
	clocks = <&clk_hse>;
	status = "okay";
};

&rcc {
	clocks = <&pll>;
	clock-frequency = <DT_FREQ_M(168)>;
	ahb-prescaler = <1>;
	apb1-prescaler = <4>;
	apb2-prescaler = <2>;
};

&usart1 {
	pinctrl-0 = <&usart1_tx_pb6 &usart1_rx_pb7>;
	pinctrl-names = "default";
	current-speed = <115200>;
	status = "okay";
};

&usart3 {
	pinctrl-0 = <&usart3_tx_pb10 &usart3_rx_pb11>;
	pinctrl-names = "default";
	current-speed = <115200>;
	status = "okay";
};

&usart6 {
	pinctrl-0 = <&usart6_tx_pc6 &usart6_rx_pc7>;
	pinctrl-names = "default";
	current-speed = <115200>;
	status = "okay";
};

&rtc {
	clocks = <&rcc STM32_CLOCK(APB1, 28)>,
		 <&rcc STM32_SRC_LSI RTC_SEL(2)>;
	status = "okay";
};

&rng {
	status = "okay";
};

/* Only one interface should be enabled at a time: usbotg_fs or usbotg_hs */
usb_otg1: &usbotg_fs {
	pinctrl-0 = <&usb_otg_fs_dm_pa11 &usb_otg_fs_dp_pa12>;
	pinctrl-names = "default";
	status = "disabled";
};

zephyr_udc0: &usbotg_hs {
	pinctrl-0 = <&usb_otg_hs_dm_pb14 &usb_otg_hs_dp_pb15>;
	pinctrl-names = "default";
	status = "okay";
};

&mac {
	status = "okay";
	pinctrl-0 = <&eth_rxd0_pc4
		     &eth_rxd1_pc5
		     &eth_ref_clk_pa1
		     &eth_col_pa3
		     &eth_crs_dv_pa7
		     &eth_tx_en_pg11
		     &eth_txd0_pg13
		     &eth_txd1_pg14>;
	pinctrl-names = "default";
	phy-connection-type = "rmii";
	phy-handle = <&eth_phy>;
};

&mdio {
	status = "okay";
	pinctrl-0 = <&eth_mdio_pa2 &eth_mdc_pc1>;
	pinctrl-names = "default";

	eth_phy: ethernet-phy@0 {
		compatible = "ethernet-phy";
		reg = <0x00>;
	};
};
```

## 2.2 构建与运行（Building and Running）

> 译注——执行环境与文件：以下构建命令从读者自己的 Zephyr 源码根目录，在 UCRT64 Bash 或 Linux Bash 中执行。先按[入门指南](../getting_started/大纲.md)准备工具链、west 工作区和相应板定义；`samples/...` 是官方原有应用目录。原命令给出的板名仅对应示例，未显式给出 `-b` 时应指定实际受支持的板，不能依赖未知缓存。设备树和 Kconfig 片段写入相应配置文件，不作为终端命令执行；构建输出由工具生成。构建成功后按板文档烧录，并按正文核对串口或硬件现象，失败时回查配置、设备就绪和连接条件。本次仅翻译与核对来源，未执行构建、烧录或硬件实验。

```text
# From the root of the zephyr repository
west build -b None samples/boards/st/ccm
west flash
```
