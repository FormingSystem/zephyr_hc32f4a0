# 第10章\_意法半导体（STMicroelectronics）

原文：[官方页面](https://docs.zephyrproject.org/latest/samples/boards/st/index.html)。快照读取日期：2026-10-15；来源摘要见[来源记录](../SOURCES.md)。

这些示例演示 STM32 硬件具有的开发板专用或 SoC 专用功能。

> 译注——本册范围：这里只整理 Zephyr 官网的开发板专用示例，不翻译或混入本仓库自有芯片手册。下列目录保留官方全部条目；已译页面链接到本地，未译页面继续指向官网，具体完成状态见[全站进度](../PROGRESS.md)。本次完成此目录不代表全部 STM32 示例或开发板文档已完成。

- [备份 SRAM（Backup SRAM）](P001_STM32备份SRAM.md#stm32_backup_sram)：在备份 SRAM 中存储可跨主电源断电周期保留的变量。

- [内核耦合存储器（Core Coupled Memory，CCM）](P002_STM32内核耦合存储器.md#stm32_ccm)：在 CCM 中放置并使用变量。

- [STM32 H7 硬件信号量核间通信（Hardware Semaphore，HSEM Inter-Processor Communication）](../intercore_reference/P087_STM32H7双核信号量示例.md#stm32_h7_dual_core)：使用 HSEM 从一个内核触发另一个内核上的 LED 闪烁。

- [I2C V2 时序（I2C V2 timings）](P003_STM32的I2C时序.md#stm32_i2c_v2_timings)：在运行时取得 I2C V2 时序。

- [主时钟输出（Master Clock Output，MCO）](P004_STM32主时钟输出.md#stm32_mco)：输出内部时钟供应用在外部使用。

## 10.3 [电源管理（Power Management）](../power/P053_STM32电源管理示例目录.md)

- [ADC 电源管理（ADC power management）](../power/P054_STM32_ADC电源管理示例.md#stm32_pm_adc)：在 STM32 的低功耗场景中使用 ADC。

- [带电源管理的 LED 闪烁（Blinky with power management）](../power/P055_STM32低功耗闪灯示例.md#stm32_pm_blinky)：在 STM32 的低功耗场景中使用 GPIO API 让 LED 闪烁。

- [STM32WB 上的蓝牙低功耗电源管理（Bluetooth Low Energy Power Management on STM32WB）](../power/P057_STM32WB蓝牙低功耗示例.md#stm32_pm_stm32wb_ble)：启用 Zephyr 电源管理，在 STM32WB 上执行 Bluetooth LE 操作。

- [GPIO 唤醒引脚（GPIO as wake-up pin）](../power/P060_STM32唤醒引脚示例.md#stm32_pm_gpio_wkup_src)：使用 GPIO 引脚作为唤醒引脚。

- [串口唤醒（Serial wakeup）](../power/P056_STM32串口唤醒示例.md#stm32_pm_serial_wakeup)：通过 STM32 上的串口活动唤醒系统。

- [STOP3 模式（STOP3 mode）](../power/P058_STM32_STOP3示例.md#stm32_pm_stop3)：在 STM32U5 上使用 STOP3 低功耗模式。

- [挂起到 RAM（Suspend to RAM）](../power/P059_STM32挂起到RAM示例.md#stm32_pm_suspend_to_ram)：在 STM32 上使用挂起到 RAM 的低功耗模式。
