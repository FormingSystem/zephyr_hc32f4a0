# 第105章\_主核中断低功耗核（Interrupt ULP）

原文：[官方页面](https://docs.zephyrproject.org/latest/samples/boards/espressif/ulp/lp_core/interrupt_ulp/README.html)。快照读取日期：2026-10-15；来源摘要见[来源记录](../SOURCES.md)。

[在 GitHub 浏览源码（Browse source code on GitHub）](https://github.com/zephyrproject-rtos/zephyr/blob/main//samples/boards/espressif/ulp/lp_core/interrupt_ulp/README.rst/..)

<a id="overview"></a>

## 105.1 概述（Overview）

本示例展示如何由高性能核触发低功耗核中断。

> 译注——中断方向：HP 主循环调用 ulp_lp_core_sw_intr_trigger()，然后休眠约一秒；LP 注册的软件中断处理函数清除中断、增加计数并打印。这里没有把 HP 送入深度睡眠后再由 LP 唤醒的流程。

按以下命令构建示例代码：

> 译注——等待与串口：LP 开启中断后在循环中执行 RISC-V 的 wfi（Wait For Interrupt，等待中断），响应后继续运行，不会像本组 GPIO／定时器示例那样每次从 main() 重启。LP 日志默认走 115200 波特率的 lp_uart，TX GPIO5、RX GPIO4；HP 默认控制台是另一个设备，应按对应设备树与连接分别读取。

```text
west build -b esp32c6_devkitc/esp32c6/hpcore --sysbuild samples/boards/espressif/ulp/lp_core/interrupt_ulp
```

使用以下命令将其烧录到设备：

```text
west build -b esp32c6_devkitc/esp32c6/hpcore --sysbuild samples/boards/espressif/ulp/lp_core/interrupt_ulp
west flash
```
