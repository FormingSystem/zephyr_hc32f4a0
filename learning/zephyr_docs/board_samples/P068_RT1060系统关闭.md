# 第68章\_RT1060 系统关闭（RT1060 System Off）

原文：[官方页面](https://docs.zephyrproject.org/latest/samples/boards/nxp/mimxrt1060_evk/system_off/README.html)。快照读取日期：2026-10-15；来源摘要见[来源记录](../SOURCES.md)。

[在 GitHub 浏览源码（Browse source code on GitHub）](https://github.com/zephyrproject-rtos/zephyr/blob/main//samples/boards/nxp/mimxrt1060_evk/system_off/README.rst/..)

<a id="overview"></a>

## 68.1 概述（Overview）

本示例可用于基础功耗测量，也可作为 NXP i.MX RT 平台软关闭（Soft off）的示例。其功能行为如下：

- 忙等（Busy-wait）两秒。

- 启用按键唤醒后关闭系统，同时设置十秒后的闹钟，以唤醒处理器。

功耗监测仪可以区分这些状态。

<a id="requirements"></a>

## 68.2 前提条件（Requirements）

本应用使用 MIMXRT1060_EVK 或 MIMXRT1060_EVKB 演示。

<a id="building-flashing-and-running"></a>

## 68.3 构建、烧录与运行（Building, Flashing and Running）

> 译注——执行前提：west 命令从读者的 Zephyr 源码根目录，在 UCRT64 Bash 或 Linux Bash 中执行；先按[入门指南](../getting_started/大纲.md)准备工具链、模块及对应板。构建产物由工具生成，下载与启动按具体板文档核对。本次未执行构建、烧录或硬件测量。

```text
west build -b mimxrt1060_evk samples/boards/nxp/mimxrt1060_evk/system_off
west flash
```

运行步骤（Running）：

1. 打开 UART 终端。

2. 将设备断电后重新上电。

3. 设备启动，并空闲两秒。

> 译注——完整源码顺序：本次应用先 k_busy_wait() 两秒，再 k_sleep() 两秒，然后设置十秒后的 SNVS RTC 闹钟。原文运行列表省略了前一阶段，不能把忙等与可调度睡眠合并成同一电源状态。

4. 设备使用深度睡眠状态 1 关闭自身。按 SW5 可唤醒设备并重新启动应用，表现如同重新上电。也可以等待十秒，由 SNVS RTC 闹钟自动触发唤醒。

> 译注——进入接口：本次示例使用 pm_state_force(PM_STATE_SOFT_OFF) 后睡眠，让空闲线程进入软关闭；不是直接调用 sys_poweroff()。按键 sw0 与 SNVS RTC 都是唤醒条件，唤醒后从复位流程重启应用。ERROR: System off failed 表示关闭路径未按预期生效。
