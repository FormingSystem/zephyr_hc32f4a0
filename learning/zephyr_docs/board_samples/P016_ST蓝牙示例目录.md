# 第16章\_蓝牙（Bluetooth）

原文：[官方页面](https://docs.zephyrproject.org/latest/samples/boards/st/bluetooth/index.html)。快照读取日期：2026-10-15；来源摘要见[来源记录](../SOURCES.md)。

这些示例演示 STM32 开发板上蓝牙的用法。

> 译注——两种连接用途：交互式 GUI 页说明 PC 经 UART 操作蓝牙协处理器；Sensor Demo 页说明手机经 GATT 访问 MCU 上的服务。两者都与蓝牙有关，但主机位置、数据链路及观察方式不同，按具体任务选择正文。

- 蓝牙 ST 交互式图形界面（Bluetooth: ST Interactive GUI）：通过 UART 提供 ST BlueNRG 蓝牙网络协处理器接口。 相关链接：[蓝牙：ST 交互式图形界面（Bluetooth: ST Interactive GUI）](P011_ST蓝牙交互式GUI.md#st_bluetooth_interactive_gui)。

- [ST 蓝牙低功耗传感器演示（ST Bluetooth LE Sensor Demo）](P012_ST蓝牙低功耗传感器演示.md#bluetooth_st_ble_sensor)：通过蓝牙提供厂商专用 GATT 服务。

对应官方文档源码：[samples/boards/st/bluetooth/index.rst](https://raw.githubusercontent.com/zephyrproject-rtos/zephyr/main/samples/boards/st/bluetooth/index.rst)。
