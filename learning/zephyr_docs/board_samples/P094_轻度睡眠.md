# 第94章\_轻度睡眠（Light Sleep）

原文：[官方页面](https://docs.zephyrproject.org/latest/samples/boards/espressif/light_sleep/README.html)。快照读取日期：2026-10-15；来源摘要见[来源记录](../SOURCES.md)。

[在 GitHub 浏览源码（Browse source code on GitHub）](https://github.com/zephyrproject-rtos/zephyr/blob/main//samples/boards/espressif/light_sleep/README.rst/..)

<a id="overview"></a>

## 94.1 概述（Overview）

本示例说明轻度睡眠（Light sleep）模式的用法。与深度睡眠不同，轻度睡眠保留内存、CPU 和外设的状态。

启用电源管理（Power management）后，系统空闲时会自动进入轻度睡眠。当前实现只支持通过 RTC 定时器从轻度睡眠唤醒，因为恢复执行由 Zephyr 调度器（Scheduler）控制，唤醒时间需要提前安排。

> 译注——进入条件：k_sleep() 让当前线程休眠，由空闲线程和电源管理策略选择可用状态，并非该调用无条件强制轻睡眠。app.overlay 启用 rtc_timer 并标记 wakeup-source，prj.conf 启用 PM 和设备 PM；有其他可运行线程或电源约束时，应检查实际选择的状态。

<a id="building-flashing-and-running"></a>

## 94.2 构建、烧录与运行（Building, Flashing and Running）

> 译注——执行前提：下面主机命令从读者自己的 Zephyr 源码根目录，在 UCRT64 Bash 或 Linux Bash 中执行；先按[入门指南](../getting_started/大纲.md)准备工具、模块、工具链与目标板。west flash 会下载固件；串口输出块是原文示例，提示符和日志不作为命令执行。本批未构建、烧录或运行硬件实验。

```text
west build -b esp32_devkitc/esp32/procpu samples/boards/espressif/light_sleep
west flash
```

<a id="sample-output"></a>

### 94.2.1 示例输出（Sample Output）

下方输出展示系统在调用 `k_sleep()` 时反复进入轻度睡眠。示例采用设备树中为轻度睡眠，即待机（Standby）电源状态配置的最短驻留时间（Minimum residency time），加入计时余量，再让系统转入轻度睡眠。系统通过 RTC 定时器唤醒，并在 Zephyr 调度器控制下恢复执行。

> 译注——时间范围：当前 app.overlay 的 min-residency-us 为 3000，main.c 再加 50000 微秒，即请求睡眠 53 ms；旧日志的 51 ms 不是必须复现的固定结果。日志中的 slept for 是两次 k_uptime_get() 的差，包含恢复调度等开销，不是仪器测得的纯低功耗驻留时间。
