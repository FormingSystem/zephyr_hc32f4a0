# 第4章\_主时钟输出（Master Clock Output，MCO）

原文：[官方页面](https://docs.zephyrproject.org/latest/samples/boards/st/mco/README.html)。快照读取日期：2026-10-15；来源摘要见[来源记录](../SOURCES.md)。

[在 GitHub 浏览源码（Browse source code on GitHub）](https://github.com/zephyrproject-rtos/zephyr/blob/main//samples/boards/st/mco/README.rst/..)

<a id="overview"></a>

## 4.1 概述（Overview）

本示例是一个最小应用，演示如何输出某个内部时钟，供应用在外部使用。

<a id="requirements"></a>

## 4.2 前提条件（Requirements）

SoC 应支持 MCO 功能，并使用具有 MCO 复用功能的引脚。要支持另一块板，在 boards 目录添加 DTS 覆盖文件，并确保在其中启用要输出的时钟。不同 STM32 系列的每个 MCOx 可选时钟源及预分频值可能不同；DTS 从对应系列允许的取值中选择时钟源，并通过属性 `prescaler = <MCOx_PRE(MCO_PRE_DIV_n)>;` 设置预分频器。

参见 [dts/bindings/clock/st,stm32-clock-mco.yaml](https://github.com/zephyrproject-rtos/zephyr/blob/main/dts/bindings/clock/st,stm32-clock-mco.yaml)。

必须查阅参考手册（Reference Manual）以正确配置 DTS。

<a id="building-and-running"></a>

## 4.3 构建与运行（Building and Running）

> 译注——执行环境与文件：以下构建命令从读者自己的 Zephyr 源码根目录，在 UCRT64 Bash 或 Linux Bash 中执行。先按[入门指南](../getting_started/大纲.md)准备工具链、west 工作区和相应板定义；`samples/...` 是官方原有应用目录。原命令给出的板名仅对应示例，未显式给出 `-b` 时应指定实际受支持的板，不能依赖未知缓存。设备树和 Kconfig 片段写入相应配置文件，不作为终端命令执行；构建输出由工具生成。构建成功后按板文档烧录，并按正文核对串口或硬件现象，失败时回查配置、设备就绪和连接条件。本次仅翻译与核对来源，未执行构建、烧录或硬件实验。

```text
# From the root of the zephyr repository
west build -b nucleo_u5a5zj_q samples/boards/st/mco
west flash
```

烧录后，LSE 时钟会从设备树启用的 MCO 引脚输出，可用逻辑分析仪等探测设备观察。

> 译注——输出取决于配置：本次 main.c 只检查启用的 MCO 设备就绪状态，时钟源与预分频由设备树及驱动初始化决定。原文 LSE 指低速外部时钟（Low-Speed External clock）；更换时钟源或分频后，应按实际配置计算预期频率，并在正确的复用引脚测量。设备就绪日志不能代替引脚波形测量。
