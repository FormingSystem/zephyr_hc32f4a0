## 3.1 概述（Overview）

本示例演示 STM32 I2C 驱动的 get_config API。它按 I2C 比特率检查外设配置，比特率可为：

> 译注——原文常量拼写：下方 `I2C_BITRATE_FAST_STANDARD` 是官方页面原样写法；本次官方[设备树 I2C 头文件](../../../include/zephyr/dt-bindings/i2c/i2c.h)实际定义的是 `I2C_BITRATE_STANDARD`（100000）、`I2C_BITRATE_FAST`（400000）和 `I2C_BITRATE_FAST_PLUS`（1000000）。标准模式配置应使用实际存在的符号，不复制原文中的拼写错误。

> - `<I2C_BITRATE_FAST_STANDARD>`
>
> - `<I2C_BITRATE_FAST>`
>
> - `<I2C_BITRATE_FAST_PLUS>`

对于 I2C V2，需要向 STM32 微控制器 I2C 外设的 TIMING 寄存器写入适当值，才能产生正确的 I2C 时钟信号。该值取决于外设输入时钟和 I2C 速率，可使用 [STM32CubeMX](https://www.st.com/en/development-tools/stm32cubemx.html) 应用或本示例计算。

计算 I2C V2 TIMING 值的代码开销较大，因此不建议在生产固件中启用。启用 CONFIG_I2C_STM32_V2_TIMING 后，本示例可取得指定 `clock-frequency` 对应的时序寄存器配置；随后可根据本例输出调整下面的 DTS 片段，在应用中配置时序：

> 译注——设备树片段与输入：`timings` 的三项分别是外设输入时钟频率、I2C 比特率和时序寄存器值，前两项单位为 Hz。160000000 和相应十六进制值仅属于原文条件；改变时钟、目标速率或控制器配置后须重新确定。`&i2c` 是概括写法，实际应指向启用的节点，例如本例 `&i2c2`；原片段结尾还缺少节点终止分号，写入有效 DTS 时需使用 `};`。

> ```text
> &i2c {
>     timings = <160000000 I2C_BITRATE_STANDARD  0xB0C03E40>,
>                 <160000000 I2C_BITRATE_FAST  0xC041090F>,
>                 <160000000 I2C_BITRATE_FAST_PLUS  0x6021050A>;
> }
> ```

## 3.2 构建与运行（Building and Running）

> 译注——执行环境与文件：以下构建命令从读者自己的 Zephyr 源码根目录，在 UCRT64 Bash 或 Linux Bash 中执行。先按[入门指南](../getting_started/大纲.md)准备工具链、west 工作区和相应板定义；`samples/...` 是官方原有应用目录。原命令给出的板名仅对应示例，未显式给出 `-b` 时应指定实际受支持的板，不能依赖未知缓存。设备树和 Kconfig 片段写入相应配置文件，不作为终端命令执行；构建输出由工具生成。构建成功后按板文档烧录，并按正文核对串口或硬件现象，失败时回查配置、设备就绪和连接条件。本次仅翻译与核对来源，未执行构建、烧录或硬件实验。

运行本示例前，确保：

> 译注——配置来源与输出：示例已有 `prj.conf` 开启 I2C、运行时序计算及 INFO 日志；板级 `.overlay` 是设备树配置，`.conf` 是 Kconfig 配置，不互相替代。`i2c-0` 别名必须指向启用节点，源码以 `DT_ALIAS(i2c_0)` 取得设备。取得 TIMING 输出说明配置查询路径运行，不代表已与某个从设备完成收发测试。

- 在板级设备树文件中启用 `i2c` 节点。

- 在板级 conf 配置文件中启用 CONFIG_I2C_STM32_V2_TIMING=y。

- 在板级 overlay 文件中，将 i2c-0 别名指向该板的 `i2c` 节点。

> ```text
> west build -b b_u585i_iot02a samples/boards/st/i2c_timing
> ```

### 3.2.1 输出示例（Sample Output）

当 b_u585i_iot02a.overlay 设置如下时：

> ```text
> / {
>     aliases {
>      i2c-0 = &i2c2;
>   };
> };
> &i2c2 {
>     /delete-property/ clock-frequency;
>     clock-frequency = <I2C_BITRATE_FAST>;
> };
> ```

示例给出如下对应 TIMING 值，可将其填回设备树：

> 译注——快速增强模式输出的符号：本次官方 i2c_stm32.c 在 1 MHz 分支的日志写为 `I2C_SPEED_FAST_PLUS`，而 DTS 所需比特率常量是 `I2C_BITRATE_FAST_PLUS`；前者是驱动速度编码概念，不能按日志字符串直接写入设备树比特率位置。输出先核对输入时钟和速率，再按绑定与头文件使用对应常量；本页原始日志未被改写。

```text
I2C timing value, report to the DTS :
timings = <160000000 I2C_BITRATE_FAST  0xC041090F>;

I2C config : I2C_BITRATE_FAST
```
