# 第52章\_Raspberry Pi

原文：[官方页面](https://docs.zephyrproject.org/latest/samples/boards/raspberrypi/index.html)。快照读取日期：2026-10-15；来源摘要见[来源记录](../SOURCES.md)。

这些示例展示如何在 Zephyr 中使用 Raspberry Pi 开发板。

> 译注——两类平台：Pico W／Pico 2 W 是带无线芯片的微控制器板，Raspberry Pi Board Info 示例则面向提供 VideoCore 固件接口的板。它们在同一厂商目录下，但硬件、启动与下载方式分别按正文和板文档处理。

- [Pico W 的 WiFi 与 LED（Pico W WiFi + LED）](P050_Pico_W的WiFi与LED.md#pico-w-wifi-led)：扫描 WiFi 网络的同时，使板载 LED 闪烁。

- [Raspberry Pi 开发板信息（Raspberry Pi Board Info）](P051_Raspberry_Pi板信息.md#rpi-board-info)：通过 VideoCore 固件接口取得并显示 Raspberry Pi 开发板信息。

对应官方文档源码：[samples/boards/raspberrypi/index.rst](https://raw.githubusercontent.com/zephyrproject-rtos/zephyr/main/samples/boards/raspberrypi/index.rst)。

> 译注——源码跟踪：本仓库[对应源码](../../../samples/boards/raspberrypi/index.rst)可用于对照，版本可能与网页不同。本批仅翻译和核对文档，未构建、烧录或执行硬件实验。
