# 第79章\_S32 网络控制器（S32 Network Controller，NETC）

原文：[官方页面](https://docs.zephyrproject.org/latest/samples/boards/nxp/s32/netc/README.html)。快照读取日期：2026-10-15；来源摘要见[来源记录](../SOURCES.md)。

[在 GitHub 浏览源码（Browse source code on GitHub）](https://github.com/zephyrproject-rtos/zephyr/blob/main//samples/boards/nxp/s32/netc/README.rst/..)

<a id="overview"></a>

## 79.1 概述（Overview）

本示例展示如何针对不同用例配置 NXP S32 网络控制器 NETC：

1. Zephyr 应用控制物理站接口（Physical Station Interface，PSI），并通过 EMDIO 控制以太网 PHY。

2. Zephyr 应用控制 PSI、虚拟站接口 1（Virtual SI 1），并通过 EMDIO 控制以太网 PHY。

示例启用 net-shell，以及仅在 Zephyr 控制 PSI 时可用的 mdio-shell，便于查看网络设置；同时启用 Telnet Shell 及其后端。

> 译注——接口术语：PHY 是物理层收发器（Physical Layer Transceiver），MDIO 是管理数据输入输出（Management Data Input/Output）接口。PSI 与 VSI 是 NETC 站接口，用例二并不要求两根独立网线；overlay 同时配置相应站接口和消息通道。

本示例应用的源码位于 [samples/boards/nxp/s32/netc](https://github.com/zephyrproject-rtos/zephyr/blob/main/samples/boards/nxp/s32/netc)。

<a id="requirements"></a>

## 79.2 前提条件（Requirements）

运行本示例需要一台 GNU/Linux 或 Windows 主机，其网络适配器通过以太网线连接目标板 ETH0 端口。

<a id="building-and-running"></a>

## 79.3 构建与运行（Building and Running）

> 译注——执行前提：west 构建命令从读者的 Zephyr 源码根目录，在 UCRT64 Bash 或 Linux Bash 中执行。先按[入门指南](../getting_started/大纲.md)准备工作区、工具链、模块与具体板；下载按板文档核对。主机网络和模型转换步骤另按相应小节的执行环境处理。本次未构建、烧录或运行硬件实验。

用例 1 的构建和运行方式如下：

```text
# From the root of the zephyr repository
west build -b s32z2xxdc2/s32z270/rtu0 samples/boards/nxp/s32/netc
west flash
```

用例 2 的构建和运行方式如下：

> 译注——覆盖文件位置：DTC_OVERLAY_FILE 的相对路径由应用配置解析；./vsi-and-psi.overlay 位于本示例应用目录。切换两个用例时应避免沿用旧构建配置，把原命令中的应用路径与主机当前目录区分开。

<a id="setting-up-host"></a>

## 79.4 主机配置（Setting up Host）

要从主机访问开发板，需要配置主机网络接口的 IP 地址和默认路由。本指南假设主机 IPv4、IPv6 地址分别为 `192.0.2.3` 和 `2001:db8::3`。例如，GNU/Linux 主机接口名为 `enp1s0`，Windows 主机接口名为 `Ethernet`，可以使用下列命令：

> 译注——命令作用范围：以下为 Linux 和 Windows 两组独立步骤，选用实际主机对应的一组。Windows 的 set address 会改动所选网卡地址，IPv6 default／::/0 会改动路由；接口名必须对应连接目标板的适配器。本次仅保留官方步骤，没有修改主机网络。

<a id="tab-0-TGludXg="></a>

**Linux**

<a id="tab-0-V2luZG93cw=="></a>

<a id="panel-0-TGludXg="></a>

```text
ip -4 addr add 192.0.2.3/24 dev enp1s0
ip -6 addr add 2001:db8::3/128 dev enp1s0
route -A inet6 add default dev enp1s0
```

**Windows**

<a id="panel-0-V2luZG93cw=="></a>

```text
netsh interface ipv4 set address "Ethernet" static 192.0.2.3 255.255.255.0
netsh interface ipv6 add address "Ethernet" 2001:db8::3/128
netsh interface ipv6 add route ::/0 "Ethernet" ::
```

注意（Note）

上述命令必须以具有相应权限的用户执行。

若配置正确，可在 Zephyr Shell 中成功执行以下命令：

```text
net ping -I<iface> 192.0.2.3
net ping -I<iface> 2001:db8::3
```

其中 `<iface>` 是从 1 开始的接口编号。

> 译注——连通性含义：iface 是 Zephyr 网络接口索引，不是主机网卡名称或 PHY 地址。示例为 PSI、VSI 配置不同 IP，ping 成功只确认相应网络路径可达，不能据此证明完整吞吐量、隔离策略或所有 NETC 功能。
