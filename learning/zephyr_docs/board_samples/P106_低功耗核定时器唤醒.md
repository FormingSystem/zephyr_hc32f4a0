# 第106章\_低功耗核定时器唤醒（LP Timer Wakeup）

原文：[官方页面](https://docs.zephyrproject.org/latest/samples/boards/espressif/ulp/lp_core/timer_wakeup/README.html)。快照读取日期：2026-10-15；来源摘要见[来源记录](../SOURCES.md)。

[在 GitHub 浏览源码（Browse source code on GitHub）](https://github.com/zephyrproject-rtos/zephyr/blob/main//samples/boards/espressif/ulp/lp_core/timer_wakeup/README.rst/..)

<a id="overview"></a>

## 106.1 概述（Overview）

本示例演示低功耗核使用低功耗定时器（LP timer），周期性地将高性能核从深度睡眠中唤醒。低功耗核采用单次运行（One-shot）模型：唤醒后通知高性能核，根据高性能核通过共享内存（Shared memory）配置的睡眠时长，重新设置低功耗定时器，然后停止运行，等待下一次定时器告警。

高性能核启动后打印唤醒计数，再通过 `sys_poweroff()` 进入深度睡眠。一个带 `RTC_DATA_ATTR` 属性的变量跨深度睡眠周期记录唤醒次数。

睡眠时长由 [`CONFIG_ESP32_ULP_LP_CORE_LP_TIMER_SLEEP_DURATION_US`](https://docs.zephyrproject.org/latest/kconfig.html#CONFIG_ESP32_ULP_LP_CORE_LP_TIMER_SLEEP_DURATION_US) 配置，默认值为 2000000 微秒，即 2 秒。

> 译注——配置与时间单位：本次主应用 prj.conf 显式设置 2000000 微秒，Kconfig 也以此为默认值。HP 把时长交给 LP 启动配置，LP 读取共享配置中的 sleep_duration_ticks；不能把微秒数直接当作硬件节拍值。两秒描述定时器设定间隔，完整的打印／启动／再次休眠过程还含处理开销。

<a id="how-it-works"></a>

## 106.2 工作过程（How it works）

1. 高性能核加载低功耗核二进制镜像，按期望睡眠时长配置低功耗定时器唤醒源，然后进入深度睡眠。

> 译注——启动分支：本次 SoC 加载器在冷启动读取 slot0_lpcore_partition，将 HP_CPU 初次触发与 LP_TIMER 唤醒源组合；ULP 唤醒的恢复分支会跳过重新加载 LP 镜像，保留 LP RAM。原文工作过程中的“加载镜像”不能理解为每次定时器唤醒都覆盖共享内存。

2. 低功耗核被低功耗定时器告警唤醒后，调用 `ulp_lp_core_wakeup_main_processor()` 唤醒高性能核。

3. 低功耗核从共享内存读取预先计算好的睡眠时长，单位为时钟节拍（Ticks），并为下一周期重新设置低功耗定时器。

> 译注——单次执行：remote/src/main.c 只在 sleep_duration_ticks 非零时重新设置告警，然后调用 ulp_lp_core_halt()。它没有持续轮询计时的主循环，下一次告警后按原文所述重新启动 LP；零时长不会由这段代码重新安排下一次告警。

4. 低功耗核调用 `ulp_lp_core_halt()`，进入低功耗睡眠。

5. 下一次低功耗定时器告警到来时，低功耗核复位并从步骤 2 重复执行。

## 106.3 构建与烧录（Building and Flashing）

> 译注——执行前提：在读者的 Zephyr 源码根目录，用 UCRT64 Bash 或 Linux Bash 执行主机命令；先按[入门指南](../getting_started/大纲.md)准备工具、模块、RISC-V 工具链和 ESP32-C6 板。--sysbuild 会构建 HP 主应用及 remote 中的 LP 子应用；烧录使用同一构建目录。提示符和输出日志不作为命令粘贴；本次未构建、烧录、调试或连接设备。

按以下命令构建示例代码：

```text
west build -b esp32c6_devkitc/esp32c6/hpcore --sysbuild samples/boards/espressif/ulp/lp_core/timer_wakeup
```

使用以下命令将其烧录到设备：

> 译注——Sysbuild 差异：下面原文第二条构建命令遗漏 --sysbuild。首次应使用前面带 --sysbuild 的命令构建两个镜像，成功后对同一构建目录执行 west flash；重新配置时也保留 --sysbuild。不要将仅构建 HP 的产物当作完整示例。

```text
west build -b esp32c6_devkitc/esp32c6/hpcore samples/boards/espressif/ulp/lp_core/timer_wakeup
west flash
```
