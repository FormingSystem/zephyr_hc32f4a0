<a id="overview"></a>

## 103.1 概述（Overview）

本示例演示 Zephyr 通用异步收发器（Universal Asynchronous Receiver/Transmitter，UART）驱动子系统中轮询式 API 的用法。它通过 [`uart_poll_in()`](../hardware/P332_UART轮询接口.md#gae81ac8cc976a20d774cfbda09e9c983d) 从低功耗 UART 读取字符，再使用 [`uart_poll_out()`](../hardware/P332_UART轮询接口.md#ga06ba27ba772a7a18462b8cdbc7f9353c) 将字符回显。

> 译注——串口与核：收发循环位于 remote/src/main.c，由 LP 核运行；HP 的 main() 只循环休眠。LP 板级设备树选择 lp_uart 为控制台，速率为 115200；本次 SoC DTSI 的 TX 为 GPIO5、RX 为 GPIO4。它不是 HP UART0 或 USB 控制台，外部串口适配器的接线应对应 LP UART，不能只打开用于下载的串口就假定能收到回显。

## 103.2 构建与烧录（Building and Flashing）

> 译注——执行前提：在读者的 Zephyr 源码根目录，用 UCRT64 Bash 或 Linux Bash 执行主机命令；先按[入门指南](../getting_started/大纲.md)准备工具、模块、RISC-V 工具链和 ESP32-C6 板。--sysbuild 会构建 HP 主应用及 remote 中的 LP 子应用；烧录使用同一构建目录。提示符和输出日志不作为命令粘贴；本次未构建、烧录、调试或连接设备。

按以下命令构建示例代码：

> 译注——回显行为：源码仅在 uart_poll_in() 返回 0 时回传字符；收到回车 CR 后再追加换行 LF。循环没有 k_sleep()，没有输入时也持续轮询，因此“在低功耗核上执行”不等于应用已进入低功耗睡眠。设备未就绪会返回错误，原文横幅只表示代码运行到打印位置。

```text
west build -b esp32c6_devkitc/esp32c6/hpcore --sysbuild samples/boards/espressif/ulp/lp_core/echo_ulp
```

使用以下命令将其烧录到设备：

```text
west build -b esp32c6_devkitc/esp32c6/hpcore --sysbuild samples/boards/espressif/ulp/lp_core/echo_ulp
west flash
```
