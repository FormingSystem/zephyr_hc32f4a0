# 第69章\_RT595 系统关闭（RT595 System Off）

原文：[官方页面](https://docs.zephyrproject.org/latest/samples/boards/nxp/mimxrt595_evk/system_off/README.html)。快照读取日期：2026-10-15；来源摘要见[来源记录](../SOURCES.md)。

[在 GitHub 浏览源码（Browse source code on GitHub）](https://github.com/zephyrproject-rtos/zephyr/blob/main//samples/boards/nxp/mimxrt595_evk/system_off/README.rst/..)

<a id="overview"></a>

## 69.1 概述（Overview）

本示例可用于基础功耗测量，也可作为 NXP i.MX RT 平台软关闭（Soft off）的示例。其功能行为如下：

- 忙等（Busy-wait）两秒。

- 启用 RTC 唤醒后关闭系统，并设置十秒后的闹钟，以唤醒处理器。

<a id="requirements"></a>

## 69.2 前提条件（Requirements）

本应用使用 MIMXRT595-EVK 演示。

> 译注——时序差异：原文提到两秒忙等／空闲，但本次 main.c 没有相应等待语句；它启动 RTC、设置十秒闹钟后直接调用 sys_poweroff()。应按实际源码辨认测量窗口，不能根据这里的旧文字假定有两秒准备时间。

<a id="building-flashing-and-running"></a>

## 69.3 构建、烧录与运行（Building, Flashing and Running）

> 译注——执行前提：west 命令从读者的 Zephyr 源码根目录，在 UCRT64 Bash 或 Linux Bash 中执行；先按[入门指南](../getting_started/大纲.md)准备工具链、模块及对应板。构建产物由工具生成，下载与启动按具体板文档核对。本次未执行构建、烧录或硬件测量。

```text
west build -b mimxrt595_evk/mimxrt595s/cm33 samples/boards/nxp/mimxrt595_evk/system_off
west flash
```

运行步骤（Running）：

1. 打开 UART 终端。

2. 将设备断电后重新上电。

3. 设备启动，并空闲两秒。

4. 设备以深度掉电模式关闭自身。RTC 闹钟唤醒设备，应用从热复位（Warm reset）重新启动。

<a id="background"></a>

## 69.4 背景（Background）

在默认设置的 EVK 上，本示例从深度掉电（Deep Power Down，DPD）模式唤醒后无法恢复应用运行，因为通常不会在 DPD 唤醒时复位 Flash。本示例从外部 Flash 原地执行（eXecute-In-Place，XIP）。MCU 从 DPD 唤醒时进入复位流程；如果外部 Flash 没有复位，MCU 与 Flash 就不再同步，MCU 无法继续 XIP。在这种默认状态下，可以确认 RTC 已将 MCU 从 DPD 唤醒：MCU 会将 PMIC_MODE 引脚设置为 0b00，请求电源管理芯片（PMIC）进入默认启动模式，PMIC 随后启用给 VDDCORE 电源轨提供 1.0 V 的稳压器。然而 MCU 仍无法从 Flash 恢复 XIP。这时可按复位按钮重新启动应用。

要从 DPD 唤醒并恢复从 Flash 原地执行，需要配置 MCU，使其复位外部 Flash。可通过编程 MCU 的一次性可编程（One-Time-Programmable，OTP）熔丝实现。下面说明如何设置 OTP BOOT_CFG1 熔丝，使用 GPIO 引脚 PIO4_5 复位 Flash；该设置指示 ROM 引导程序在复位 Flash 时翻转 PIO4_5。MIMXRT595-EVK 的硬件将 PIO4_5 连接到 FlexSPI0 上八线 Flash 的复位引脚。使用同一 MCU 的其他板可能连接不同 GPIO，OTP 熔丝设置必须匹配实际连接的复位引脚。编程熔丝前，最好先写 OTP 影子寄存器（Shadow register）验证操作，再在确认设置正确后编程 OTP 熔丝。有关熔丝及影子寄存器的更多信息，参见此 MCU 的参考手册，以及参考手册 PDF 附件中的 OTP Fuse Map 表格。

> 译注——OTP 边界：影子寄存器验证与永久熔丝编程不同。以下参数针对原文 MIMXRT595-EVK 的 PIO4_5 接线，不能直接用于其他板；熔丝写入不是普通可逆配置。本次只翻译与核对，未连接设备，也未运行 blhost 或编程熔丝。

<a id="tools-needed"></a>

## 69.5 所需工具（Tools needed）

这些步骤使用可在 Linux、Windows 或 macOS 主机上运行的 blhost 工具。下载 blhost 后，找到适合主机操作系统的可执行文件，再按下述命令行步骤编程 OTP 熔丝。下载时访问 https://www.nxp.com/mcuboot，在 Downloads 中查找 Blhost 软件包。 相关链接：[NXP MCU Boot 下载入口](https://www.nxp.com/mcuboot)。

<a id="steps-to-program-otp-fuses-on-mimxrt595-evk"></a>

## 69.6 在 MIMXRT595-EVK 上编程 OTP 熔丝的步骤

以下步骤使用 USB 作为 blhost 与 ROM 引导程序之间的接口；也可以使用 UART，详情参见 blhost 文档和 MCU 参考手册的 Boot ROM 章节。

> 译注——命令字符：网页普通段落把官方 RST 中的两个 ASCII 连字符 -- 排版成了 –；下方保留网页呈现用于对照，实际命令分隔符必须使用 --。本节预期日志则按官方 RST 恢复逐行文本和原始字符。ISP 为在系统编程（In-System Programming），HID 为人机接口设备（Human Interface Device）。

> 1. 为 EVK 供电，并将 USB J38 连接到主机。J38 对应 MCU 的 USB 外设，也可为 EVK 供电。
>
> 2. 将 SW7 拨码开关按 1、2、3 顺序设为 On-Off-On，以 ISP USB HID 模式启动。
>
> 3. 按 SW3 复位按钮进入 ISP 模式。EVK 应在主机上枚举为 USB HID 设备。
>
> 4. 以下命令确认 BOOT_CFG1 熔丝的当前设置：blhost -u 0x1fc9,0x0023 – efuse-read-once 0x61
>
> 5. 以下命令编程 BOOT_CFG1，启用 PIO4_5 作为 Flash 复位引脚：blhost -u 0x1fc9,0x0023 – efuse-program-once 0x61 0x164000
>
> 6. 以下命令确认 BOOT_CFG1 中已编程的熔丝：blhost -u 0x1fc9,0x0023 – efuse-read-once 0x61
>
> 7. 将 SW7 拨码开关按 1、2、3 顺序设为 Off-Off-On，以从 FlexSPI0 上的外部 Flash 启动。
>
> 8. 按 SW3 复位按钮，从 Flash 启动并运行应用。
