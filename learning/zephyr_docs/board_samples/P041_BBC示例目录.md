# 第41章\_BBC

原文：[官方页面](https://docs.zephyrproject.org/latest/samples/boards/bbc/index.html)。快照读取日期：2026-10-15；来源摘要见[来源记录](../SOURCES.md)。

这些示例展示如何在 Zephyr 中使用 BBC 开发板。

> 译注——官方归属：本页沿用 Zephyr 的 BBC 示例分类，包含 micro:bit 子目录及四个具体示例。这里整理的是官方文档和上游源码依据，不是另行扩写本仓库的芯片资料。

<a id="bbc_microbit"></a>

## 41.1 [BBC micro:bit](P040_BBC_microbit示例目录.md)

- [LED 矩阵显示（LED matrix display）](P036_microbit_LED矩阵显示.md#bbc_microbit_display)：使用 BBC micro:bit 开发板上的 5×5 LED 矩阵显示屏。

- [巡线机器人（Line following robot）](P037_microbit巡线机器人.md#bbc_microbit_line_follower_robot)：使用 BBC micro:bit 开发板和机器人底盘实现巡线机器人。

- [Pong 游戏（Pong game）](P038_microbit_Pong游戏.md#bbc_microbit_pong)：以单人模式玩 Pong，或让两台 micro:bit 设备通过蓝牙连接进行游戏。

- [声音输出（Sound）](P039_microbit声音输出.md#bbc_microbit_sound)：使用 BBC micro:bit 开发板上的压电蜂鸣器。

对应官方文档源码：[samples/boards/bbc/index.rst](https://raw.githubusercontent.com/zephyrproject-rtos/zephyr/main/samples/boards/bbc/index.rst)。
