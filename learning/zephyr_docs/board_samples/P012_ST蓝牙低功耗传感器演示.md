# 第12章\_ST 蓝牙低功耗传感器演示（ST Bluetooth LE Sensor Demo）

原文：[官方页面](https://docs.zephyrproject.org/latest/samples/boards/st/bluetooth/st_ble_sensor/README.html)。快照读取日期：2026-10-15；来源摘要见[来源记录](../SOURCES.md)。

[在 GitHub 浏览源码（Browse source code on GitHub）](https://github.com/zephyrproject-rtos/zephyr/blob/main//samples/boards/st/bluetooth/st_ble_sensor/README.rst/..)

<a id="overview"></a>

## 12.1 概述（Overview）

本应用通过提供厂商专用 GATT 服务演示 Bluetooth LE 外设功能。目前仅实现按钮通知和 LED 服务，也可继续添加其他蓝牙低功耗传感器服务。添加新服务的方法见 [BlueST 协议](https://www.st.com/resource/en/user_manual/dm00550659.pdf)文档。

> 译注——演示内容：名称中的 Sensor 不表示该应用默认已经读取温度、湿度等传感器；原文当前范围是 LED 控制与按钮通知。添加其他功能需实现相应服务、数据取得与协议字段，不能只更改设备名。

<a id="requirements"></a>

## 12.2 前提条件（Requirements）

- [ST Bluetooth LE Sensor Android 应用](https://play.google.com/store/apps/details?id=com.st.bluems)

- 一块支持 Bluetooth LE 的开发板。

<a id="building-and-running"></a>

## 12.3 构建与运行（Building and Running）

> 译注——执行环境：构建与烧录命令从读者自己的 Zephyr 源码根目录，在 UCRT64 Bash 或 Linux Bash 中执行；先按[入门指南](../getting_started/大纲.md)准备工具链、west 工作区及对应开发板。应用目录与配置为官方提供，构建目录由工具生成。板型替换前先核对其硬件条件，构建成功后再按板文档准备启动／烧录模式并烧录。失败时先回查构建配置或板的烧录步骤；本次只核对文档与源码，没有运行固件或操作设备。

按以下方式构建并烧录，将 `<board>` 替换为目标开发板：

```text
west build -b <board> samples/boards/st/bluetooth/st_ble_sensor
west flash
```

打开 [ST Bluetooth LE Sensor Android 应用](https://play.google.com/store/apps/details?id=com.st.bluems)，点击“CONNECT TO A DEVICE”（连接设备）扫描 Bluetooth LE 设备，然后点击列表中的设备进行连接。连接后，点击应用中的 LED 图标测试 LED 服务，或按下开发板上的 SW0 按钮测试按钮通知服务。

> 译注——按键与通知条件：本次源码以 `sw0` 设备树别名取得按钮；普通 LED 路径使用 `led0`，特定板还有 RGB LED 实现。按钮回调同时检查已连接和通知订阅状态，客户端未启用相应 CCC 通知时会记录 Notify not enabled（未启用通知）；仅连接成功不足以收到按钮事件。
