# 第97章\_ESP32 正交解码器按单元阈值触发（ESP32 qdec per-unit threshold trigger）

原文：[官方页面](https://docs.zephyrproject.org/latest/samples/boards/espressif/qdec_trigger/README.html)。快照读取日期：2026-10-15；来源摘要见[来源记录](../SOURCES.md)。

[在 GitHub 浏览源码（Browse source code on GitHub）](https://github.com/zephyrproject-rtos/zephyr/blob/main//samples/boards/espressif/qdec_trigger/README.rst/..)

<a id="overview"></a>

## 97.1 概述（Overview）

每个脉冲计数器（Pulse Counter，PCNT）单元有两个可编程阈值监视点（Threshold watchpoint），计数器达到任一监视点时都会产生中断。Zephyr 的 [`sensor_trigger`](https://docs.zephyrproject.org/latest/doxygen/html/structsensor__trigger.html) 没有 `chan_idx` 字段，因此驱动允许调用方使用 `<zephyr/drivers/sensor/pcnt_esp32.h>` 中旧有的 [`SENSOR_CHAN_PCNT_ESP32_UNIT`](https://docs.zephyrproject.org/latest/doxygen/html/pcnt__esp32_8h.html#a19a6a63bf5efb926d34d080f81d908e8) 辅助定义来指定单元。单元 0 也可通过 `SENSOR_CHAN_ROTATION` 或 `SENSOR_CHAN_ENCODER_COUNT` 指定。

示例为单元 0 设置上限阈值，为单元 1 设置下限阈值；监视点每触发一次，就增加相应单元的计数。程序每秒打印一次累计命中次数。

> 译注——阈值与次数：main.c 设置单元 0 的 +100 和单元 1 的 -100；hits 是回调累计次数，不是脉冲数，也不是每秒重新清零的频率。当前驱动的 ISR 还可能把高／低极限和过零事件交给同一回调，不能把每一次命中都解释成又收到了 100 个脉冲。

本示例专用于 ESP32，因为它使用 `SENSOR_CHAN_PCNT_ESP32_UNIT(n)` 辅助定义。只有 Zephyr 传感器触发 API 携带通道索引后，才能实现可移植的等价方案，参见原文所述拉取请求（Pull Request，PR）说明中的后续 RFC。

> 译注——版本与错误判断：原页没有提供所述后续 RFC 的具体链接，本译文不臆测其编号。当前应用会打印设置属性和注册触发器的返回码，但错误后仍继续循环；tests.yaml 标记 build_only，不证明接线或回调运行成功。

<a id="requirements"></a>

## 97.2 硬件与配置要求（Requirements）

需要具有 PCNT 外设的 Espressif SoC。把两个脉冲源接到相应 `boards/<board>.overlay` 文件所配置的引脚。没有脉冲源时，计数器不会达到阈值，也就不会触发回调。

> 译注——计数方向：本次 ESP32-S3 覆盖文件将单元 0 的信号／控制端放在 GPIO4／5，单元 1 放在 GPIO6／7。两个单元均配置 sig-pos-mode=1、sig-neg-mode=0，控制端也不反转方向；按绑定定义，这是只在上升沿递增。因此该配置不能靠普通正向脉冲到达单元 1 的 -100 阈值。测试下限前应按实际信号与绑定配置递减或反向计数，不能仅照抄示例命中日志。

<a id="building-and-running"></a>

## 97.3 构建与运行（Building and Running）

> 译注——执行前提：下面主机命令从读者自己的 Zephyr 源码根目录，在 UCRT64 Bash 或 Linux Bash 中执行；先按[入门指南](../getting_started/大纲.md)准备工具、模块、工具链与目标板。west flash 会下载固件；串口输出块是原文示例，提示符和日志不作为命令执行。本批未构建、烧录或运行硬件实验。

```text
west build -b esp32s3_devkitc/esp32s3/procpu samples/boards/espressif/qdec_trigger
west flash
```
