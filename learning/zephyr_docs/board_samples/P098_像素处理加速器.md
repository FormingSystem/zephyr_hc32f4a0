# 第98章\_像素处理加速器（Pixel processing accelerator）

原文：[官方页面](https://docs.zephyrproject.org/latest/samples/boards/espressif/ppa_srm/README.html)。快照读取日期：2026-10-15；来源摘要见[来源记录](../SOURCES.md)。

[在 GitHub 浏览源码（Browse source code on GitHub）](https://github.com/zephyrproject-rtos/zephyr/blob/main//samples/boards/espressif/ppa_srm/README.rst/..)

<a id="overview"></a>

## 98.1 概述（Overview）

本示例直接驱动像素处理加速器（Pixel Processing Accelerator，PPA），不经过图形库，以便在屏幕上检查缩放（Scale）、旋转（Rotate）和镜像（Mirror）操作。

> 译注——验证边界：本次 tests.yaml 仅列出 ESP32-P4 Function EV Board 的 hpcore 目标并标为 build_only。串口的 step 日志说明执行到相应代码，不代替屏幕上的几何变换检查；本次没有运行 PPA 或显示设备。

程序在内存中生成一幅由四个彩色象限和一条白色对角线组成的源图像，绘制在显示屏左侧。然后每三秒执行一步变换，并将结果绘制在右侧，依次包括恒等变换（Identity）、两倍缩放、旋转 90 度、旋转 180 度和水平镜像。

> 译注——图片来源：四象限和白线由 main.c 的 draw_source() 运行时绘制，官方页面没有可下载的图片或动图附件。SRM 表示缩放、旋转和镜像（Scale, Rotate, Mirror）；这里使用阻塞式操作，每轮处理和显示完成后再休眠三秒，并非精确的三秒画面周期。

<a id="requirements"></a>

## 98.2 硬件与配置要求（Requirements）

需要配备像素处理加速器和显示屏的开发板，以及足以容纳源图像和目标图像的外部 RAM。

> 译注——内存与显示配置：当前源码固定使用 1024×600、每像素 3 字节的 RGB888 屏幕缓冲区，源图为 128×128，目标缓冲区为 256×256，三块合计 2088960 字节，尚不含对齐和其他运行内存。它从外部共享堆分配，并按 L2 缓存行对齐，执行前刷写源／目标缓存，完成后使目标缓存失效；更换屏幕时不能仅替换板名。

<a id="building-and-running"></a>

## 98.3 构建与运行（Building and Running）

> 译注——执行前提：下面主机命令从读者自己的 Zephyr 源码根目录，在 UCRT64 Bash 或 Linux Bash 中执行；先按[入门指南](../getting_started/大纲.md)准备工具、模块、工具链与目标板。west flash 会下载固件；串口输出块是原文示例，提示符和日志不作为命令执行。本批未构建、烧录或运行硬件实验。

```text
west build -b esp32p4x_function_ev_board/esp32p4/hpcore samples/boards/espressif/ppa_srm
west flash
```

<a id="sample-output"></a>

## 98.4 示例输出（Sample Output）

```text
PPA SRM: source is red/green/blue/yellow quadrants + white diagonal
step 0: 1x identity -> out 128x128
step 1: 2x scale -> out 256x256
step 2: 1x rotate 90 -> out 128x128
step 3: 1x rotate 180 -> out 128x128
step 4: 1x mirror-x -> out 128x128
```
