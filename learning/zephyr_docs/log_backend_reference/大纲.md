# 日志后端接口参考大纲

本册翻译日志后端（Logging Backend）API、头文件参考与源码，以及后端对象、操作表、运行时控制块和事件参数，共七份官方页面。保留全部声明、参数、返回值、宏展开及交叉引用。

后端负责处理和输出日志消息。源码跟踪译注说明初始化、就绪与激活的区别，必需与可选回调、消息内存生命周期、过滤控制、格式设置和处理线程事件。控制块原页隐藏的内部字段不冒充公开字段说明；相关可见源码照常保留。
