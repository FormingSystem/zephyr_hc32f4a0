> 译注——源码核对：LOG_BACKEND_EVT_PROCESS_THREAD_DONE仅用于延后处理，是处理线程的一次通知，不是每条消息均有的交付回执，也不是线程退出事件。当前核心调用通知时传入NULL事件参数；处理回调应根据事件约定解释参数，不能无条件解引用arg。
