### `sys_multi_heap_fn_t`

```c
typedef void *(* sys_multi_heap_fn_t) (struct sys_multi_heap *mheap, void *cfg, size_t align, size_t size)
```

```c
#include <zephyr/sys/multi_heap.h>
```

多堆选择函数（Multi-heap Choice Function）。

此函数由使用者提供，负责根据不透明配置值（Opaque Configuration）cfg 选择具体的 sys_heap 后端（Backend），并代表调用者完成分配。cfg 是使用者传给 sys_multi_heap_alloc() 的参数。回调可从已注册的堆后端中任选一个执行分配，可按需要对请求值增加填充，并在配置要求时采用对齐分配。

可以返回 NULL；此时本次分配失败，调用代码收到 NULL。

**参数（Parameters）**

| 名称／方向 | 说明 |
| --- | --- |
| `mheap` | 多堆结构。 |
| `cfg` | 使用者提供的不透明值，应用可按任意方式解释它。 |
| `align` | 请求内存的对齐值；为 0 表示不额外指定对齐。 |
| `size` | 使用者指定的分配大小，单位为字节。 |

**返回（Returns）**：返回指向已分配内存的指针。

> 译注——源码核对：choice回调不仅选择后端，还必须实际完成分配并返回指针。cfg没有内建统一类型或自动策略；注册了多个堆也不会自动轮询、回退或满足缓存／DMA属性，须由集成代码实现。

<a id="gacd6b92e8090a56e1eb59a18166d659d1"></a>

### `sys_multi_heap_add_heap()`

```c
void sys_multi_heap_add_heap ( struct sys_multi_heap * mheap, struct sys_heap * heap, void * user_data )
```

```c
#include <zephyr/sys/multi_heap.h>
```

向多堆包装添加 sys_heap。

向现有多堆包装添加一个已知的 sys_heap 后端，使多堆内部能够跟踪堆的边界，并判断被释放的内存块来自哪个堆，或是否不属于任何堆。

**参数（Parameters）**

| 名称／方向 | 说明 |
| --- | --- |
| `mheap` | 要向其添加堆的 sys_multi_heap。 |
| `heap` | 要添加的堆。 |
| `user_data` | 指向该堆任意关联数据的指针。 |

> 译注——源码核对：当前将后端指针及user_data加入固定数组，并按后端内部起始地址排序；MAX_MULTI_HEAPS当前为8，容量通过断言检查。没有重复或重叠区域检查，也不初始化后端或取得存储所有权。应在使用前完成配置，并同步后续变更。

<a id="ga9f958dbfa86e12236b8e356375b8d04c"></a>

### `sys_multi_heap_aligned_alloc()`

```c
void * sys_multi_heap_aligned_alloc ( struct sys_multi_heap * mheap, void * cfg, size_t align, size_t bytes )
```

```c
#include <zephyr/sys/multi_heap.h>
```

从多堆包装分配满足对齐要求的内存。

与 sys_multi_heap_alloc() 一样，按指定字节数分配一块内存；另接收一个额外参数，指定以字节为单位且为 2 的幂的对齐值。

**参数（Parameters）**

| 名称／方向 | 说明 |
| --- | --- |
| `mheap` | 多堆指针。 |
| `cfg` | 不透明配置参数，含义与 sys_multi_heap_fn_t 中相同。 |
| `align` | 返回指针的对齐值，以字节为单位，必须是 2 的幂。 |
| `bytes` | 请求分配的字节数。 |

**返回（Returns）**：返回有效的堆内存指针；无可用内存时返回 NULL。

> 译注——源码核对：当前直接把align和bytes传给choice；包装层不独立验证回调返回值是否满足对齐。回调须遵守约定，并从已登记后端返回能由对应sys_heap_free归还的指针。

<a id="ga603800e6e2ae8c6e058fff18c891c3f0"></a>

### `sys_multi_heap_aligned_realloc()`

```c
void * sys_multi_heap_aligned_realloc ( struct sys_multi_heap * mheap, void * cfg, void * ptr, size_t align, size_t bytes )
```

```c
#include <zephyr/sys/multi_heap.h>
```

调整多堆包装中已有分配的大小。

返回指向新内存区域的指针：内容保留，分配大小改变。如果能原地扩展，返回指针与原指针相同；否则将数据复制到新块，并按 sys_heap_free() 的规则释放旧块。如果请求大小小于原大小，则原地截短该块，把剩余内存归还给堆。若新块分配失败，则返回 NULL，旧块既不释放也不修改。如果需要新的分配，则根据 cfg 参数选择所用堆，与 sys_multi_heap_aligned_alloc 中相同。

**参数（Parameters）**

| 名称／方向 | 说明 |
| --- | --- |
| `mheap` | 多堆指针。 |
| `cfg` | 不透明配置参数，含义与 sys_multi_heap_fn_t 中相同。 |
| `ptr` | 前一次分配返回的原始指针。 |
| `align` | 以字节为单位的对齐值，必须是 2 的幂。 |
| `bytes` | 为新内存块请求的字节数。 |

**返回（Returns）**：返回调用者现在可以使用的内存指针，或 NULL。

> 译注——源码核对：当前先在原后端调用sys_heap_aligned_realloc，既可能原地调整，也可能在原堆移动；只有这一步失败才用cfg调用choice。因此改变cfg不保证把已有分配迁移到新的内存属性区域。ptr=NULL直接分配；非NULL且bytes=0释放并返回NULL。正数大小最终分配失败保留旧块，成功搬移按min(旧可用大小,新大小)复制。

<a id="ga050d7499b982ed62f85d5fc15f79548b"></a>

### `sys_multi_heap_alloc()`

```c
void * sys_multi_heap_alloc ( struct sys_multi_heap * mheap, void * cfg, size_t bytes )
```

```c
#include <zephyr/sys/multi_heap.h>
```

从多堆包装分配内存。

与 sys_heap_alloc() 一样，按指定字节数分配一块内存；另接收一个不透明配置指针并传给多堆选择函数，由集成代码据此选择堆后端。

**参数（Parameters）**

| 名称／方向 | 说明 |
| --- | --- |
| `mheap` | 多堆指针。 |
| `cfg` | 不透明配置参数，含义与 sys_multi_heap_fn_t 中相同。 |
| `bytes` | 请求分配的字节数。 |

**返回（Returns）**：返回有效的堆内存指针；无可用内存时返回 NULL。

> 译注——源码核对：当前直接调用choice(mheap, cfg, 0, bytes)。分配策略、失败回退及同步由调用方和回调负责；此包装不增加k_heap式等待语义。

<a id="gac6f913a3bbf247807ba80408a242db73"></a>

### `sys_multi_heap_free()`

```c
void sys_multi_heap_free ( struct sys_multi_heap * mheap, void * block )
```

```c
#include <zephyr/sys/multi_heap.h>
```

释放从多堆包装分配的内存。

将指定内存块归还给分配它的堆后端。该块必须是先前成功调用 sys_multi_heap_alloc() 或 sys_multi_heap_aligned_alloc() 所得的返回值。

允许 block 参数为 NULL，此时不产生作用。

**参数（Parameters）**

| 名称／方向 | 说明 |
| --- | --- |
| `mheap` | 多堆指针。 |
| `block` | 要释放的块，必须是 sys_multi_heap_alloc 返回的已分配内存块指针。 |

> 译注——源码核对：必须只传本包装分配返回的有效指针，NULL为无操作。内部先按起始地址查找记录，再调用sys_heap_free；由于查找不验证结束边界，不能依赖它拒绝所有不属于堆的地址。

<a id="gad98b78be5c0ed50e1e0715a15c289b3a"></a>

### `sys_multi_heap_get_heap()`

```c
const struct sys_multi_heap_rec * sys_multi_heap_get_heap ( const struct sys_multi_heap * mheap, void * addr )
```

```c
#include <zephyr/sys/multi_heap.h>
```

根据给定地址获取对应的堆。

查找管理给定指针的单个系统堆及其 user_data。

**参数（Parameters）**

| 名称／方向 | 说明 |
| --- | --- |
| `mheap` | 多堆指针。 |
| `addr` | 要查找的地址，必须是 sys_multi_heap_alloc 返回的已分配内存块指针。 |

**返回（Returns）**：原文返回说明为“0 multi_heap_rec pointer”：返回包含结果数据的记录结构指针；未找到堆时返回 NULL。原文此处的 0 和结构名存在表述问题，实际声明返回 const struct sys_multi_heap_rec *，见下方源码译注。

> 译注——源码核对：实际返回const struct sys_multi_heap_rec *，没有输出结构参数；原文返回说明中的0和multi_heap_rec名称保留为原文差异。当前按有序起始地址找不大于addr的最后一个记录，没有检查对应堆的结束边界或分配块边界。因此位于堆间隙或最后一个堆之后的任意地址也可能取得记录；这不是通用指针归属验证。返回内部记录还可能在后续add_heap排序时改变位置。

<a id="ga50ded513b50c7aed7d89386bb8f425cc"></a>

### `sys_multi_heap_init()`

```c
void sys_multi_heap_init ( struct sys_multi_heap * heap, sys_multi_heap_fn_t choice_fn )
```

```c
#include <zephyr/sys/multi_heap.h>
```

初始化多堆包装（Multi-heap）。

使用指定选择函数初始化 sys_multi_heap 结构。随后必须通过 sys_multi_heap_add_heap 添加各个堆，才能由多堆代码跟踪其边界。

**参数（Parameters）**

| 名称／方向 | 说明 |
| --- | --- |
| `heap` | 要初始化的 sys_multi_heap。 |
| `choice_fn` | 在分配时用于选择堆的 sys_multi_heap_fn_t 回调。 |

**说明（Note）**：通常，多堆会根据系统配置以近似静态的方式建立，例如使用链接器提供的不同内存区域边界，或设备树（Devicetree）中定义的硬件可寻址内存。一般预期由 SoC 或开发板级的平台设备在系统启动时依据这些配置源完成初始化，而不是由应用自行组装一个多堆。

> 译注——源码核对：当前仅清零nheaps并保存choice函数，不初始化后端sys_heap，不提供锁，也不检查空回调。各后端应先初始化，再添加；不要在仍有存活分配时重新初始化多堆对象。
