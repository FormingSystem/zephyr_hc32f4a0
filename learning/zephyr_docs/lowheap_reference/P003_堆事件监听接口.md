## 3.6\_详细说明（Detailed Documentation）

<a id="ga77e603053a5b69caae2a49e441a525c0"></a>

### `HEAP_ID_FROM_POINTER`

```c
#define HEAP_ID_FROM_POINTER ( heap_pointer)
```

```c
#include <zephyr/sys/heap_listener.h>
```

展开值（Value）：

```c
((uintptr_t)heap_pointer)
```

由堆指针构造堆标识符（Heap Identifier）。

从堆对象指针构造堆标识符，例如 sys_heap 对象的指针。

**参数（Parameters）**

| 名称／方向 | 说明 |
| --- | --- |
| `heap_pointer` | 指向堆对象的指针。 |

> 译注——源码核对：此宏只是转换为uintptr_t，不登记堆，也不验证对象。sys_heap事件使用sys_heap对象地址作为ID，而不是其后备缓冲区地址。监听k_heap底层事件时还需核对所用对象，不能仅凭地址相近推断匹配。

<a id="ga7627d1b500bb7e833770c99071f9255d"></a>

### `HEAP_ID_LIBC`

```c
#define HEAP_ID_LIBC ((uintptr_t)0)
```

```c
#include <zephyr/sys/heap_listener.h>
```

C 标准库堆标识符（Libc Heap Identifier）。

全局 C 标准库堆的标识符。

> 译注——源码核对：常量0专指全局libc堆，不是匹配所有堆的通配符（Wildcard）；sys_heap对象事件通常使用对象指针转换后的ID。

### `HEAP_LISTENER_ALLOC_DEFINE`

```c
#define HEAP_LISTENER_ALLOC_DEFINE ( name, _heap_id, _alloc_cb )
```

```c
#include <zephyr/sys/heap_listener.h>
```

展开值（Value）：

```c
struct heap_listener name = { \
        .heap_id = _heap_id, \
        .event = HEAP_ALLOC, \
        { \
                .alloc_cb = _alloc_cb \
        }, \
}
```

定义监听分配事件的堆事件监听器节点（Heap Event Listener Node）。

使用示例：

原始示例（Example）：

```c
void on_heap_alloc(uintptr_t heap_id, void *mem, size_t bytes)
{
  LOG_INF("Memory allocated at %p, size %ld", mem, bytes);
}

HEAP_LISTENER_ALLOC_DEFINE(my_listener, HEAP_ID_LIBC, on_heap_alloc);
```

**参数（Parameters）**

| 名称／方向 | 说明 |
| --- | --- |
| `name` | 堆事件监听器对象的名称。 |
| `_heap_id` | 要监听的堆的标识符。 |
| `_alloc_cb` | 分配事件发生时调用的函数。 |

> 译注——源码核对：宏只定义并初始化节点，不自动注册。对象需在注册期间保持有效，之后显式调用heap_listener_register。原始日志示例保留；实际格式符应与size_t类型及目标日志实现匹配，不能把示例当作所有平台均已编译验证。

### `heap_listener_alloc_cb_t`

```c
typedef void(* heap_listener_alloc_cb_t) (uintptr_t heap_id, void *mem, size_t bytes)
```

```c
#include <zephyr/sys/heap_listener.h>
```

堆分配发生时使用的回调。

**参数（Parameters）**

| 名称／方向 | 说明 |
| --- | --- |
| `heap_id` | 堆标识符。 |
| `mem` | 指向已分配内存的指针。 |
| `bytes` | 已分配内存的大小。 |

**说明（Note）**：由 Zephyr 主代码仓库之外的库管理的堆可能不发出此事件。已分配字节数不一定与分配函数收到的请求完全一致；堆的内部机制可能分配多于请求的内存。

> 译注——源码核对：通知中的bytes来自具体堆实现，不一定等于应用请求值；sys_heap还可能在原地重分配时成对发出新大小的alloc和旧大小的free。不能把一次回调直接等同于一次应用层malloc调用。回调在通知路径的自旋锁内执行，避免阻塞和递归分配。

### `heap_listener_notify_alloc()`

```c
void heap_listener_notify_alloc ( uintptr_t heap_id, void * mem, size_t bytes )
```

```c
#include <zephyr/sys/heap_listener.h>
```

向监听器通知堆分配事件。

通知堆标识符匹配的已注册监听器：该堆已完成一次分配。

**参数（Parameters）**

| 名称／方向 | 说明 |
| --- | --- |
| `heap_id` | 堆标识符。 |
| `mem` | 指向已分配内存的指针。 |
| `bytes` | 已分配内存的大小。 |

> 译注——源码核对：当前同步调用heap_id相等、event为HEAP_ALLOC且回调非NULL的节点；调用期间一直持有全局自旋锁。回调应简短、不能阻塞，也不能重入可能再次通知的堆分配或监听注册接口。CONFIG_SYS_HEAP_LISTENER控制sys_heap自动通知，仅启用HEAP_LISTENER接口不意味着所有堆都会发事件。

将监听器加入全局堆监听器列表，使不同堆实现可在发生与堆使用有关的特定事件时通知它。

**参数（Parameters）**

| 名称／方向 | 说明 |
| --- | --- |
| `listener` | 指向 heap_listener 对象的指针。 |

> 译注——源码核对：当前在全局自旋锁（Spinlock）内将节点追加到链表，没有重复注册检查。每个节点同一时刻只能注册一次；对象必须保持有效且不能在注册期间随意改写字段。不要在监听回调内注册或注销，因为通知路径仍持有同一把锁。

### `heap_listener_unregister()`

void heap_listener_unregister ( struct heap_listener * listener)

注销堆事件监听器。

从全局堆监听器列表移除监听器；该列表中的监听器可由不同堆实现在发生与堆使用有关的特定事件时通知。

**参数（Parameters）**

| 名称／方向 | 说明 |
| --- | --- |
| `listener` | 指向 heap_listener 对象的指针。 |

> 译注——源码核对：当前在全局自旋锁内查找并移除节点，不释放对象内存。须与对象生命周期和后续注册协调；从回调内部调用会再次获取同一锁，不是支持的用法。
