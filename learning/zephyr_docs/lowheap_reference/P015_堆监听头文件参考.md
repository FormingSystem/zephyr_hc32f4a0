本页与[底层堆接口](P001_底层堆分配接口.md)、[多堆包装接口](P002_多堆包装接口.md)、[堆监听接口](P003_堆事件监听接口.md)及[共享多堆指南](../kernel/P024_共享多堆.md)互相对照。

源码对照：[本头文件源码译文](P016_堆监听头文件源码.md)、[对应公共接口／结构](P003_堆事件监听接口.md)。

相对定位：[include/zephyr/sys/heap_listener.h](../../../include/zephyr/sys/heap_listener.h)与[lib/heap/heap_listener.c](../../../lib/heap/heap_listener.c)；官方依据：[头文件](https://github.com/zephyrproject-rtos/zephyr/blob/main/include/zephyr/sys/heap_listener.h)、[实现](https://github.com/zephyrproject-rtos/zephyr/blob/main/lib/heap/heap_listener.c)。

> 译注——源码核对：CONFIG_HEAP_LISTENER关闭时，通知函数成为空内联函数，HEAP_ID_FROM_POINTER变为NULL对应的整数；注册接口、事件类型和定义宏位于启用分支。Doxygen通过__DOXYGEN__展示公开接口，不代表每个构建均启用监听功能。

> 译注——源码核对：监听对象使用侵入式单向链表（Intrusive Singly Linked List）节点，定义宏只建立对象，不自动注册。一个节点不能重复登记；联合体一次保存一种事件对应的回调，监听多种事件需要多个对象。

> 译注——源码核对：HEAP_EVT_UNKNOWN是零值占位事件，HEAP_ID_LIBC的零值则标识libc堆，二者意义不同。HEAP_REALLOC虽出现在枚举中，当前头文件只提供alloc、free、resize三类回调及通知入口。

> 译注——源码核对：当前实现持全局自旋锁（Spinlock）同步调用监听回调。回调应短小、不可阻塞，不要在其中注册／注销监听器或重入会通知同一监听框架的分配路径。

原始页面与官方源码摘要见[来源记录](../SOURCES.md)。滚动main、latest网页及仓库源码不能自动视为同一版本。本次未构建或运行并发、区域溢出、重分配或实板实验。
