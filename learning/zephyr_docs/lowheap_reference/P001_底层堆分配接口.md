## 1.2\_详细说明（Detailed Documentation）

<a id="ga92a973158860c6863e1aba8516311076"></a>

### `sys_heap_aligned_alloc()`

```c
void * sys_heap_aligned_alloc ( struct sys_heap * heap, size_t align, size_t bytes )
```

```c
#include <zephyr/sys/sys_heap.h>
```

从 sys_heap 分配满足对齐要求的内存（Aligned Allocation）。

行为与 sys_heap_alloc() 相同，区别是分配成功时，返回内存的起始地址是所指定对齐值的整数倍；对齐值以字节为单位，必须是 2 的幂。align=0 时行为与 sys_heap_alloc() 完全相同。所得内存可通过 sys_heap_free() 归还。

**参数（Parameters）**

| 名称／方向 | 说明 |
| --- | --- |
| `heap` | 从中分配内存的堆。 |
| `align` | 以字节为单位的对齐值，必须是 2 的幂。 |
| `bytes` | 请求的字节数。 |

**返回（Returns）**：返回调用者现在可以使用的内存指针。

> 译注——源码核对：公开用法是align为0或2的幂；额外对齐会带来填充开销。分配失败返回NULL，不等待。返回指针仍须交还同一个sys_heap，不能传给系统k_free。

<a id="ga16e1408c3ad5541daac756e46b33b612"></a>

### `sys_heap_aligned_realloc()`

```c
void * sys_heap_aligned_realloc ( struct sys_heap * heap, void * ptr, size_t align, size_t bytes )
```

```c
#include <zephyr/sys/sys_heap.h>
```

调整已有分配的大小（Reallocation）。

行为与 sys_heap_realloc() 相同，区别是分配成功时，返回内存的起始地址是所指定对齐值的整数倍；对齐值以字节为单位，必须是 2 的幂。只有传入的内存指针满足指定对齐要求时，才尝试原地扩展（In-place Expansion）；否则会将数据移动到新的内存块。

**参数（Parameters）**

| 名称／方向 | 说明 |
| --- | --- |
| `heap` | 从中分配内存的堆。 |
| `ptr` | 前一次分配返回的原始指针。 |
| `align` | 以字节为单位的对齐值，必须是 2 的幂。 |
| `bytes` | 为新内存块请求的字节数。 |

**返回（Returns）**：返回调用者现在可以使用的内存指针，或 NULL。

> 译注——源码核对：当前非NULL指针且bytes=0时释放并返回NULL；正数大小先在满足新对齐时尝试原地调整，再尝试同堆的新分配。失败保留旧块。整个操作没有内部锁，旧指针也不能被另一执行上下文同时读写或释放。

<a id="ga6b8bdf02c9be5576fddbe711904a3aad"></a>

### `sys_heap_alloc()`

```c
void * sys_heap_alloc ( struct sys_heap * heap, size_t bytes )
```

```c
#include <zephyr/sys/sys_heap.h>
```

从 sys_heap 分配内存。

返回指向堆中一块未使用内存的指针。在通过 sys_heap_free() 释放之前，这块内存不会另作他用。如果无法分配内存，则返回 NULL。返回内存的起始地址保证是 sizeof(void *) 的整数倍；若需要更大的对齐值，应改用 sys_heap_aligned_alloc()。

**参数（Parameters）**

| 名称／方向 | 说明 |
| --- | --- |
| `heap` | 从中分配内存的堆。 |
| `bytes` | 请求的字节数。 |

**说明（Note）**：sys_heap 实现内部没有同步保护（Internal Synchronization）。任意两个 sys_heap 函数都不能同时操作同一个堆；所有加锁工作均须由使用者提供。

**返回（Returns）**：返回调用者现在可以使用的内存指针。

> 译注——源码核对：此层不等待、不加锁，也不清零分配内容。当前bytes=0直接返回NULL。CONFIG_SYS_HEAP_ALLOC_LOOPS限制最小候选桶的搜索次数；NULL不必然证明堆中所有空闲块都小于请求，更不能只用空闲字节总数判断分配一定成功。

### `sys_heap_array_get()`

```c
int sys_heap_array_get ( struct sys_heap *** heap)
```

```c

```

获取已保存的堆指针数组。

### `sys_heap_free()`

```c
void sys_heap_free ( struct sys_heap * heap, void * mem )
```

```c
#include <zephyr/sys/sys_heap.h>
```

将内存释放回 sys_heap。

释放先前由 sys_heap_alloc 返回的内存，使其可以重新用于其他用途。从进入此函数开始，调用者就不得再使用这段内存。

**参数（Parameters）**

| 名称／方向 | 说明 |
| --- | --- |
| `heap` | 内存要归还到的堆。 |
| `mem` | 先前由 sys_heap_alloc() 返回的指针。 |

**说明（Note）**：sys_heap 实现内部没有同步保护（Internal Synchronization）。任意两个 sys_heap 函数都不能同时操作同一个堆；所有加锁工作均须由使用者提供。

> 译注——源码核对：NULL为无操作；非NULL必须是这个堆尚未释放的分配指针，不能传偏移地址或其他堆的指针。调用者还须对该堆全部并发访问提供统一同步，包括统计和验证。配置化完整性检查不能替代所有权规则。

### `sys_heap_get_largest_free_block()`

```c
int sys_heap_get_largest_free_block ( struct sys_heap * heap, size_t * bytes )
```

```c
#include <zephyr/sys/sys_heap.h>
```

获取 sys_heap 中最大空闲块（Largest Free Block）的大小。

将当前堆中最大一块连续空闲块（Contiguous Free Block）的可用字节数写入 bytes。按原文说明，在没有其他分配或释放造成进一步碎片化的情况下，这就是当前传给 sys_heap_alloc() 仍能成功的最大大小。

**参数（Parameters）**

| 名称／方向 | 说明 |
| --- | --- |
| `heap` | 指向指定 sys_heap 的指针。 |
| `bytes` | 用于存放结果的 size_t 指针。 |

**返回（Returns）**：传入空指针时返回 -EINVAL，否则返回 0。

> 译注——源码核对：当前在最高非空桶内扫描最大可用块，受CONFIG_SYS_HEAP_RUNTIME_STATS控制且不加锁。原文把结果描述为一定能成功分配的最大值；但实际分配器对候选桶有CONFIG_SYS_HEAP_ALLOC_LOOPS搜索上限，可能未遍历到该块。因此该值是容量观察，不是分配成功或资源预留的保证。

### `sys_heap_realloc()`

```c
void * sys_heap_realloc ( struct sys_heap * heap, void * ptr, size_t bytes )
```

```c
#include <zephyr/sys/sys_heap.h>
```

调整已有分配的大小（Reallocation）。

返回指向新内存区域的指针：内容保留，分配大小改变。如果能原地扩展，返回指针与原指针相同；否则将数据复制到新块，并按 sys_heap_free() 的规则释放旧块。如果请求大小小于原大小，则原地截短该块，并把剩余内存归还给堆。若新块分配失败，则返回 NULL，旧块既不释放也不修改。

**参数（Parameters）**

| 名称／方向 | 说明 |
| --- | --- |
| `heap` | 从中分配内存的堆。 |
| `ptr` | 前一次分配返回的原始指针。 |
| `bytes` | 为新内存块请求的字节数。 |

**返回（Returns）**：返回调用者现在可以使用的内存指针，或 NULL。

> 译注——源码核对：当前ptr=NULL走分配，非NULL且bytes=0释放旧块并返回NULL；正数大小分配失败才是旧块保持不变。使用临时指针接收结果，避免丢失旧块。普通重分配不保证移动后保留此前额外要求的更强对齐。

> 译注——源码核对：当前实现受CONFIG_SYS_HEAP_RUNTIME_STATS控制，直接读取统计字段而不加锁。计数反映堆实际管理的块容量，可能含分配粒度和对齐造成的差额，不等于应用请求值之和，也不代表整段后备缓冲区大小。

### `sys_heap_stress()`

```c
void sys_heap_stress ( void *(* alloc_fn )(void *arg, size_t bytes), void(* free_fn )(void *arg, void *p), void * arg, size_t total_bytes, uint32_t op_count, void * scratch_mem, size_t scratch_bytes, int target_percent, struct z_heap_stress_result * result )
```

```c
#include <zephyr/sys/sys_heap.h>
```

sys_heap 压力测试工具（Stress Test Rig）。

用于验证堆分配的测试工具。循环执行 op_count 次，每轮随机选择分配或释放；大小采用幂律分布（Power-law Distribution），启发式策略使堆的填充程度接近 target_percent。分配与释放由调用者通过回调（Callback）提供，因此理论上可以测试任意堆。释放次数、分配成功与失败次数等结果通过 result 结构返回。

**参数（Parameters）**

| 名称／方向 | 说明 |
| --- | --- |
| `alloc_fn` | 执行分配的回调；会将 arg 参数作为上下文句柄传回。 |
| `free_fn` | 释放 alloc_fn 所返回指针的回调；会将 arg 参数作为上下文句柄传回。 |
| `arg` | 要传回回调的上下文句柄（Context Handle）。 |
| `total_bytes` | 用于初始化堆的字节数组大小。 |
| `op_count` | 测试的迭代次数。 |
| `scratch_mem` | 指向测试使用的临时工作内存（Scratch Memory）。需要着重测试碎片化时，该区域大小应约为堆大小的一半。 |
| `scratch_bytes` | scratch_mem 所指内存的大小。 |
| `target_percent` | 随机分配决策所追求的填充百分比，范围为 1–100。值较高时，会出现大量分配失败和严重的堆碎片化（Fragmentation）。 |
| `result` | 用于保存测试结果的结构。 |

> 译注——源码核对：实现由CONFIG_SYS_HEAP_STRESS控制。临时工作内存用于记录分配地址和大小，须有足够容量并满足记录结构的对齐；total_bytes须非零且满足实现的32位百分比运算范围。函数返回void，结果是统计量，不是完整性证明；当前循环结束后不会统一释放尚存活的测试块，应使用隔离测试堆并安排清理。此处仅作源码核对，未运行压力测试。

<a id="gaf8cb77365c04022181e2fc45e3fbce4a"></a>

### `sys_heap_usable_size()`

```c
size_t sys_heap_usable_size ( struct sys_heap * heap, void * mem )
```

```c
#include <zephyr/sys/sys_heap.h>
```

返回已分配内存的大小。

返回成功调用 sys_heap_alloc() 或 sys_heap_alloc_aligned() 后所得内存块的大小，单位为字节。返回值是堆所管理的内存大小，受分配粒度（Allocation Granularity）影响，可能大于请求字节数。堆代码保证，在之后对同一指针调用 sys_heap_free() 之前，不访问该内存区域。

**参数（Parameters）**

| 名称／方向 | 说明 |
| --- | --- |
| `heap` | 包含该内存块的堆。 |
| `mem` | 指向从该堆分配的内存的指针。 |

**返回（Returns）**：返回内存区域的字节数。

> 译注——源码核对：原文sys_heap_alloc_aligned()是名称笔误，本页实际接口为sys_heap_aligned_alloc()。当前实现按块可用字节数减去对齐间隙计算，调用对象必须是存活分配；这不是请求大小记录，也不是任意指针有效性检查。启用内存访问检测工具（Sanitizer）时，请求范围外的额外容量还可能仍受访问限制，不应据此自行扩大对象边界。

<a id="ga81de9cc56f9fb88ae12ea70cc85d1db1"></a>

### `sys_heap_validate()`

```c
bool sys_heap_validate ( struct sys_heap * heap)
```

声明属性：`inline`、`static`。

```c
#include <zephyr/sys/sys_heap.h>
```

验证堆的完整性（Heap Integrity）。

验证 sys_heap 的内部完整性。主要面向单元测试（Unit Test）和验证代码，也可能适合运行时可靠性要求复杂的应用。注意：它无法发现所有可能的错误；但按原文说明，若返回 true，则堆处于一致状态，可以正确处理 sys_heap_alloc() 请求，并释放先前分配返回且仍有效的指针。

**参数（Parameters）**

| 名称／方向 | 说明 |
| --- | --- |
| `heap` | 要验证的堆。 |

**返回（Returns）**：堆有效时返回 true，否则返回 false。

> 译注——源码核对：CONFIG_SYS_HEAP_VALIDATE未启用时，头文件中的内联替身直接返回true，没有执行检查。因此true不能脱离配置解释为已验证。启用时也只是当前堆结构一致性核验，不能证明应用没有越界、泄漏或并发错误。
