## 6.2\_详细说明（Detailed Documentation）

<a id="a01dd6ce40b1ab9c84c034475e70a4fa6"></a>

### `choice`

```c
sys_multi_heap_fn_t sys_multi_heap::choice
```

> 译注——源码核对：多堆选择回调（Choice Callback）负责选择已登记后端并实际完成分配。cfg的意义由集成代码约定；仅保存回调并不会自动实现回退、锁定或属性检查。

<a id="a36be24709ad7083957a65aad6100806e"></a>

### `heaps`

```c
struct sys_multi_heap_rec sys_multi_heap::heaps[8]
```

> 译注——源码核对：固定容量的后端记录数组（Backend Record Array），当前MAX_MULTI_HEAPS为8。添加时会按内存起始地址排序，所以此前取得的记录指针可能在排序后表示另一条记录。

<a id="a3830f646e39d16401cfe75099e2facc1"></a>

### `nheaps`

```c
unsigned int sys_multi_heap::nheaps
```

> 译注——源码核对：已登记后端数（Registered Heap Count），不是剩余内存块数。通过sys_multi_heap_init和sys_multi_heap_add_heap维护，不应手动修改。
