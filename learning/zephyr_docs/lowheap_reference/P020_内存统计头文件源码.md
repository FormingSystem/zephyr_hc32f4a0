## 20.4\_源码跟踪译注

> 译注——sys_memory_stats是统计结果容器（Statistics Container），没有自身的锁或采样动作。free_bytes、allocated_bytes、max_allocated_bytes分别承载空闲量、已分配量及已分配峰值；实际计数口径、统计启用条件和复位规则由填充它的分配器决定。

> 译注——累计空闲量不等于最大连续可分配块，峰值为零也不统一表示从未分配。查询结果不是资源预留，随后并发分配可能改变可用容量。底层堆统计实现受CONFIG_SYS_HEAP_RUNTIME_STATS控制，调用者须遵守底层堆的同步责任。

实现定位：[lib/heap/heap_stats.c](../../../lib/heap/heap_stats.c)与[官方实现](https://github.com/zephyrproject-rtos/zephyr/blob/main/lib/heap/heap_stats.c)。头文件相对定位：[include/zephyr/sys/mem_stats.h](../../../include/zephyr/sys/mem_stats.h)；[官方原始文件](https://github.com/zephyrproject-rtos/zephyr/blob/main/include/zephyr/sys/mem_stats.h)的摘要见来源记录。去掉注释和展示空白后，本页代码与本次读取的原始头文件一致，不能推广到以后滚动更新的main或任意本地版本。
