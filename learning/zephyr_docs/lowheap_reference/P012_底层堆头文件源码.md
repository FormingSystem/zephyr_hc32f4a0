## 12.2\_可见注释译文（Comments）

1. 版权声明：Copyright (c) 2019 Intel Corporation；Copyright (c) 2026 Qualcomm Technologies, Inc.；许可证标识为 Apache-2.0。原法律文本完整保留。

2. 简单、快速的堆实现（Heap Implementation）。它基本采用传统的分离适配分配器（Segregated Fit Allocator），以2的幂组织桶（Bucket）。空间效率很高：内存块（Chunk）可以按8字节单位任意拆分；每个已分配块仅有4字节管理开销，对于大于256kb的堆或64位系统则为8字节，此外还有一个按log2规模增长的桶头数组，每个桶头占两个字。块没有粗粒度的对齐限制，可以按8字节单位任意拆分与合并。API简单：运行时用一段内存初始化，无需由宏生成、仔细对齐的静态数组；分配和释放采用用户指针，而非不透明块句柄（Opaque Block Handle）。抗碎片能力良好：释放的块立即与相邻空闲块合并；分配先在可能容纳请求的最小桶中抽样尝试，再迅速退到保证能容纳请求的最小块；拆分后余下的内存立即归还堆供其他分配使用。性能很好，执行时间有严格上界：所有操作都为常数时间，不过搜索最小桶有一个编译期可配置的上限，设置得极大时实际上会退化为对链表的线性搜索；实际执行很快，约为百条指令，适合在加锁状态下运行。

3. 注意：init_mem／init_bytes字段用于让静态初始化器（Static Initializer）有地方存放参数。运行时真正的堆元数据（Heap Metadata）位于堆内存本身，此结构仅起到不透明指针的作用。若能整理这一设计并把两个值移到别处会更好，但这样会使SYS_HEAP_DEFINE的编写略为棘手。

4. 前向声明（Forward Declaration）；完整定义位于zephyr/sys/bitarray.h。

5. 头文件包含保护（Include Guard）的结束标记：ZEPHYR_INCLUDE_SYS_SYS_HEAP_H_。
