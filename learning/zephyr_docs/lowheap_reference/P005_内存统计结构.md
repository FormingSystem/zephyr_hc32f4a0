## 5.2\_详细说明（Detailed Documentation）

<a id="a5592af7e45f38f79447fd8b81cfa1285"></a>

### `allocated_bytes`

```c
size_t sys_memory_stats::allocated_bytes
```

> 译注——源码核对：已分配字节数（Allocated Bytes）。此结构为通用结果容器，实际计数口径由填充它的分配器决定；不能统一解释成所有malloc请求大小之和。

<a id="aeb79d9aad2232b3451737b8fdb335132"></a>

### `free_bytes`

```c
size_t sys_memory_stats::free_bytes
```

> 译注——源码核对：空闲字节数（Free Bytes）。累计空闲量不等于最大连续空闲块，不表示任意同等大小的分配都会成功。结构本身不持有锁，也不预留内存。

<a id="a0d89b378e4e3974c4ca778040eb34697"></a>

### `max_allocated_bytes`

```c
size_t sys_memory_stats::max_allocated_bytes
```

> 译注——源码核对：最大已分配字节数（Peak Allocated Bytes）。通常表示统计期间的使用峰值；是否启用跟踪、如何重置以及未启用时的值由具体提供者定义，不应将0一概解释为从未分配。
