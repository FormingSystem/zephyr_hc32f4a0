## 7.2\_详细说明（Detailed Documentation）

<a id="abced99d59a80e299a76c6ea29fcc18e8"></a>

### `heap`

```c
struct sys_heap* sys_multi_heap_rec::heap
```

> 译注——源码核对：指向该记录的底层sys_heap后端。添加记录不会替代sys_heap_init，也不会转移后端存储的所有权；对象和后备内存须在使用期间有效。

<a id="ac6f27a9f92989284a852a24e01422be7"></a>

### `user_data`

```c
void* sys_multi_heap_rec::user_data
```

> 译注——源码核对：调用者附带的用户数据（User Data）指针。通用多堆只存储它，不复制对象、不自动解释内容或释放资源；生命周期由调用者管理。
