# 底层堆与多堆监听参考大纲

本册翻译底层堆分配器（Low Level Heap Allocator）、多堆包装（Multi-Heap Wrapper）、堆事件监听器（Heap Listener），以及相关对象、内存统计、共享多堆（Shared Multi-Heap，SMH）接口及五组头文件参考／源码浏览页。先读[内存堆指南](../kernel/P023_内存堆.md)和[共享多堆指南](../kernel/P024_共享多堆.md)，再按接口及对象查询；另见[内核堆及固定块内存池](../heap_reference/大纲.md)。

底层sys_heap与普通多堆包装由使用者提供同步；共享多堆分配、释放及重分配包装增加自旋锁保护，区域仍须在单一初始化上下文中配置。监听器只观察事件，不取得内存所有权。原始声明、宏展开、示例、参数与返回值完整保留，源码差异另作译注；所有仓库链接使用相对路径。完整范围与待译情况见[全站进度](../PROGRESS.md)。
