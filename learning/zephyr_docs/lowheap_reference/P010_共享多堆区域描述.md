## 10.2\_详细说明（Detailed Documentation）

<a id="a905df61648eaa18cebf53bb10dcde91d"></a>

### `addr`

```c
uintptr_t shared_multi_heap_region::addr
```

内存堆的起始虚拟地址（Starting Virtual Address）。

> 译注——源码核对：起始虚拟地址（Virtual Address），应是CPU可访问且允许分配器写入元数据的有效区域；不应把总线物理地址或设备寄存器地址直接当作普通堆内存。此字段本身不建立映射。

<a id="a5fcdce28a57be4b652a9a53a70ae796f"></a>

### `attr`

```c
uint32_t shared_multi_heap_region::attr
```

内存堆属性（Memory Heap Attribute）。

> 译注——源码核对：指定本区域参与哪一类共享分配。当前使用标准属性枚举的有效值；设为不可缓存或外部内存标签，不会改变硬件映射或缓存状态。

<a id="a3f6565062f70b2c8d25c3a0be579482c"></a>

### `size`

```c
size_t shared_multi_heap_region::size
```

内存堆大小，单位为字节。

> 译注——源码核对：后备区域总字节数，不是全部可交给应用的净容量；sys_heap需要管理结构、边界标记及对齐空间。区域描述可在add返回后另作使用，但后备内存和user_data指向对象必须保持相应生命周期。
