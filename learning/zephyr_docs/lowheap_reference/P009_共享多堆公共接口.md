共享多堆（Shared Multi-Heap，SMH）接口。

<a id="details"></a>

共享多堆（Shared Multi-Heap，SMH）接口。

共享多堆管理器使用多堆分配器（Multi-heap Allocator）管理一组具有不同能力／属性的内存区域，例如可缓存与不可缓存区域。

可以在运行时将不同区域加入共享多堆池，同时提供一个不透明属性值（Opaque Attribute），其形式可以是整数或枚举。驱动或应用可用它请求具备特定能力的内存。

此框架通常按以下方式使用：

1. 启动时，平台代码通过 shared_multi_heap_pool_init 初始化共享多堆框架，再通过 shared_multi_heap_add 将内存区域加入池；所需区域信息可以从设备树（Devicetree，DT）取得。
2. 每个内存区域由 shared_multi_heap_region 结构描述；其中还包含使用者定义的不透明整数值，用于表示区域能力，例如缓存属性（Cacheability）、CPU 亲和性（CPU Affinity）等。
3. 驱动或应用需要具有特定能力的动态内存时，可调用 shared_multi_heap_alloc 或其对齐版本，用不透明参数选择所需属性。框架根据该参数和各堆的运行时状态，例如可用内存和堆状态，选择实际提供内存的堆及区域。

此接口的分配函数可以安全地从任意线程和中断服务程序（Interrupt Service Routine，ISR）调用。区域应在初始化期间，由单一执行上下文（Single Context）加入。

## 9.5\_详细说明（Detailed Documentation）

### `MAX_SHARED_MULTI_HEAP_ATTR`

#define MAX_SHARED_MULTI_HEAP_ATTR SMH_REG_ATTR_NUM

#include <zephyr/multi_heap/shared_multi_heap.h>

标准属性的最大数量。

> 译注——源码核对：当前展开为SMH_REG_ATTR_NUM，形成静态数组及上界检查。这里是属性数量，不是可任意扩大的运行时字典，也不是用于按位组合的标志集合。

<a id="ga11861c5c373f9e5d81496ae1be7df1d4"></a>

### `shared_multi_heap_attr`

```c
enum shared_multi_heap_attr
```

```c
#include <zephyr/multi_heap/shared_multi_heap.h>
```

SMH 区域属性枚举类型。

用于表示若干常见内存区域属性的枚举类型（Enumeration Type）。

**枚举值（Enumerators）**

| 名称／方向 | 说明 |
| --- | --- |
| `SMH_REG_ATTR_CACHEABLE` | 可缓存（Cacheable）。 |
| `SMH_REG_ATTR_NON_CACHEABLE` | 不可缓存（Non-cacheable）。 |
| `SMH_REG_ATTR_EXTERNAL` | 外部内存（External Memory）。 |
| `SMH_REG_ATTR_NUM` | 必须是最后一个枚举项。 |

> 译注——源码核对：当前标准枚举包含可缓存、不可缓存、外部内存三种属性，SMH_REG_ATTR_NUM为计数哨兵（Sentinel），不能作为有效分配属性。虽然总体说明使用“不透明属性”表述，当前实现仍以枚举值索引固定数组；新增任意整数不会自动得到支持。标签仅选择区域，不会配置缓存、MPU、MMU或DMA可达性。

<a id="ga086362a2a8fce827a246039ef8757cc5"></a>

### `shared_multi_heap_add()`

```c
int shared_multi_heap_add ( struct shared_multi_heap_region * region, void * user_data )
```

```c
#include <zephyr/multi_heap/shared_multi_heap.h>
```

向共享多堆内存池添加堆区域。

将一个共享多堆区域加入多堆池。

**参数（Parameters）**

| 名称／方向 | 说明 |
| --- | --- |
| `user_data` | 指向该堆任意关联数据的指针。 |
| `region` | 指向待加入的内存区域描述的指针。 |

**返回值（Return Values）**

| 名称／方向 | 说明 |
| --- | --- |
| `0` | 成功。 |
| `-EINVAL` | 区域属性超出允许范围。 |
| `-ENOMEM` | 没有更多可用的堆。 |
| `other` | 其他 errno 错误码。 |

> 译注——源码核对：当前读取region属性、选择槽位并sys_heap_init后备区域，最后在smh_lock内登记。不是整个流程都受锁保护，应按官方要求从单一初始化上下文添加。region指针和区域必须有效且容量足够；实现不检查空描述符、重叠区域或重复添加。每属性槽位虽各有MAX_MULTI_HEAPS项，共享sys_multi_heap总记录也只有MAX_MULTI_HEAPS项，因此总区域数不能按“属性数乘8”估算；越过总上限可能触发底层断言，而非本函数的-ENOMEM。

<a id="ga328b199253da06ed724e9b0157167ede"></a>

### `shared_multi_heap_aligned_alloc()`

```c
void * shared_multi_heap_aligned_alloc ( enum shared_multi_heap_attr attr, size_t align, size_t bytes )
```

```c
#include <zephyr/multi_heap/shared_multi_heap.h>
```

从共享多堆内存池分配满足对齐要求的内存。

分配指定字节数、具有指定能力／属性的内存块；另接收一个额外参数，指定以字节为单位且为 2 的幂的对齐值。

**参数（Parameters）**

| 名称／方向 | 说明 |
| --- | --- |
| `attr` | 为内存块请求的能力／属性。 |
| `align` | 返回指针的对齐值，以字节为单位，必须是 2 的幂。 |
| `bytes` | 请求分配的字节数。 |

**返回值（Return Values）**

| 名称／方向 | 说明 |
| --- | --- |
| `ptr` | 有效的堆内存指针。 |
| `err` | 无可用内存时返回 NULL。 |

> 译注——源码核对：当前在共享自旋锁内调用多堆分配器，并把align传给sys_heap_aligned_alloc；align=0表示普通对齐。强对齐可能增加空间损耗，仍不等待。后端监听回调可能在共享锁尚未释放时执行，不能从回调重入共享分配或释放。

<a id="ga8cd3d321f5ae516cd55812d304289971"></a>

### `shared_multi_heap_alloc()`

```c
void * shared_multi_heap_alloc ( enum shared_multi_heap_attr attr, size_t bytes )
```

```c
#include <zephyr/multi_heap/shared_multi_heap.h>
```

从共享多堆内存池分配内存。

分配指定字节数、具有指定能力／属性的内存块。后端（Backend）使用不透明属性参数，选择用于分配内存的堆。

**参数（Parameters）**

| 名称／方向 | 说明 |
| --- | --- |
| `attr` | 为内存块请求的能力／属性。 |
| `bytes` | 请求分配的字节数。 |

**返回值（Return Values）**

| 名称／方向 | 说明 |
| --- | --- |
| `ptr` | 有效的堆内存指针。 |
| `err` | 无可用内存时返回 NULL。 |

> 译注——源码核对：当前转到align=0的对齐分配包装；该包装持smh_lock，并按目标属性的加入顺序尝试各后端，遇到成功便返回，不会跨到另一属性。没有等待参数，零字节请求或无匹配可用区域返回NULL。同步保护是共享层增加的，不能反推裸sys_multi_heap也线程安全。

<a id="gab968bf26483d22939aaa7c2b1b6743ad"></a>

### `shared_multi_heap_free()`

```c
void shared_multi_heap_free ( void * block)
```

```c
#include <zephyr/multi_heap/shared_multi_heap.h>
```

释放共享多堆内存池中的内存。

释放传入的内存块；该块必须是先前调用 shared_multi_heap_alloc 或 shared_multi_heap_aligned_alloc 的返回值。

**参数（Parameters）**

| 名称／方向 | 说明 |
| --- | --- |
| `block` | 要释放的块，必须是 shared_multi_heap_alloc 或 shared_multi_heap_aligned_alloc 分配所得的指针。 |

> 译注——源码核对：当前在共享自旋锁内调用sys_multi_heap_free，NULL为无操作；非NULL必须是本池的有效存活分配，不可混用k_free。底层按起点查找并不验证任意地址的结束边界，因此包装的锁并不使非法指针变得安全。

<a id="ga5b7f09666e3eac051b4c4942572f9ca3"></a>

### `shared_multi_heap_pool_init()`

```c
int shared_multi_heap_pool_init ( void )
```

```c
#include <zephyr/multi_heap/shared_multi_heap.h>
```

初始化内存池（Pool）。

初始化共享多堆池时必须首先调用此函数；之后再通过 shared_multi_heap_add 加入各个独立堆。

**返回值（Return Values）**

| 名称／方向 | 说明 |
| --- | --- |
| `0` | 成功。 |
| `-EALREADY` | 内存池已经初始化。 |
| `other` | 其他 errno 错误码。 |

**说明（Note）**：与通用多堆分配器一样，预期由 SoC 或开发板层调用此函数。

> 译注——源码核对：当前只允许首次初始化成功，后续调用返回-EALREADY；没有清空全部分配的复位语义。内部原子状态先被设为1再初始化choice，第二个并发调用者得到-EALREADY并不等价于等待第一个调用完成；仍须按官方要求在单一初始化上下文中完成配置后再供其他执行上下文使用。

<a id="ga594e00506e2edff1ad60cb76e47bb2d6"></a>

### `shared_multi_heap_realloc()`

```c
void * shared_multi_heap_realloc ( enum shared_multi_heap_attr attr, void * ptr, size_t bytes )
```

```c
#include <zephyr/multi_heap/shared_multi_heap.h>
```

重新分配共享多堆内存池中的内存。

返回指向新内存区域的指针：内容保留，分配大小改变。如果能原地扩展（In-place Expansion），返回指针与原指针相同；否则将数据复制到新块，并按 sys_heap_free() 的规则释放旧块。如果请求大小小于原大小，则原地截短内存块，把剩余内存归还给堆。若新块分配失败，则返回 NULL，旧块既不释放也不修改。需要新的分配时，后端使用不透明属性参数选择适当的堆。

**参数（Parameters）**

| 名称／方向 | 说明 |
| --- | --- |
| `attr` | 为内存块请求的能力／属性。 |
| `ptr` | 指向要重新分配的内存块的指针。 |
| `bytes` | 请求分配的字节数。 |

**返回值（Return Values）**

| 名称／方向 | 说明 |
| --- | --- |
| `newptr` | 指向大小为 bytes 的新堆内存块的有效指针。 |
| `err` | 无可用内存时返回 NULL。 |

> 译注——源码核对：当前先验证属性上界，再在共享锁内调用sys_multi_heap_aligned_realloc且align=0。原堆能完成调整或同堆移动时，不会按新attr重新选择，所以改attr不保证迁移到相应区域，也不承诺保持额外对齐。合法attr下ptr=NULL为分配；非NULL且bytes=0为释放并返回NULL；正数大小失败保留旧块。属性被拒绝时直接返回NULL，连零大小释放分支也不执行。
