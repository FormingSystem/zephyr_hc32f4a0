## 8.2\_详细说明（Detailed Documentation）

<a id="a2cd780402d745bdd2dfbaf632e2a6df6"></a>

### `[union]`

```c
union { ... } heap_listener
```

> 译注——源码核对：三个回调字段共享联合体（Union）存储，不是同一节点可同时保存的三项独立回调。根据event设置对应字段；需要监听多种事件时分别定义并注册节点。

<a id="a34a982da6ecc3564ef2194f045eea646"></a>

### `alloc_cb`

```c
heap_listener_alloc_cb_t heap_listener::alloc_cb
```

> 译注——源码核对：分配回调（Allocation Callback）在通知函数持有全局自旋锁时同步调用，应简短、不可阻塞，也不要递归触发堆通知。

<a id="a1ef2db791f5422fa7e6bb17c2b6bf247"></a>

### `event`

```c
enum heap_event_types heap_listener::event
```

要通知的堆事件（Heap Event）。

> 译注——源码核对：指定这个节点监听的一种事件，不是任意按位组合的事件掩码（Bitmask）；当前通知实现按枚举值相等进行过滤。

<a id="a46a7f4856397851c64ce07c95b1d9b19"></a>

### `free_cb`

```c
heap_listener_free_cb_t heap_listener::free_cb
```

> 译注——源码核对：释放回调（Free Callback）只观察事件，不接管地址所指内存，也不能再次释放。原地realloc可能以alloc/free对表示大小变化，不能只按事件名推断应用操作。

<a id="a9b13bffbb860ea78207b4ebe7c61b768"></a>

### `heap_id`

```c
uintptr_t heap_listener::heap_id
```

被监听事件所属堆的标识符（Heap Identifier）。

如果堆由对象表示，可以使用堆指针作为标识符；对于全局 C 标准库堆（Global Libc Heap），则使用 0。

> 译注——源码核对：sys_heap通常以堆对象指针转换为uintptr_t作为ID；值0专指全局libc堆，不是所有堆的通配符。必须与事件发送方使用的ID一致。

<a id="ab0f3071d7828856bcbee55ff9791a27c"></a>

### `node`

```c
sys_snode_t heap_listener::node
```

单向链表节点（Singly Linked List Node）。

> 译注——源码核对：这是侵入式链表（Intrusive List）的节点，同一个监听器只能登记一次。注册期间对象必须持续存在，不应复制或重用其node字段。

<a id="a0dcba80daeebe0be96d5e75051cbf287"></a>

### `resize_cb`

```c
heap_listener_resize_cb_t heap_listener::resize_cb
```

> 译注——源码核对：堆区域大小调整回调（Heap Resize Callback）表示整个堆末尾边界变化；不等同于单个分配块realloc。
