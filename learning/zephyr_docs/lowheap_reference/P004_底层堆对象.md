## 4.2\_详细说明（Detailed Documentation）

<a id="ac67ddabc4097bebe6fcd2068fd8cd5d9"></a>

### `heap`

```c
struct z_heap* sys_heap::heap
```

> 译注——源码核对：指向运行时堆管理元数据（Metadata），不是应用可直接写入的分配块，也不是可用于k_free的指针。通过sys_heap_init及配套分配接口维护，应用不要自行修改。

<a id="a319a113212300c7bbb383a474af0793e"></a>

### `init_bytes`

```c
size_t sys_heap::init_bytes
```

> 译注——源码核对：这是供静态初始化流程保存的区域大小参数，不是当前空闲字节数。查询运行时使用量应调用相应统计接口。

<a id="af0764ddfe848b03712e3fe7164766ef5"></a>

### `init_mem`

```c
void* sys_heap::init_mem
```

> 译注——源码核对：头文件注释明确这是静态初始化器存放后备内存参数的位置。当前kheap.c在启动初始化静态k_heap时读取该字段；不能据此断言每个运行时sys_heap_init都会把该字段更新为当前区域地址。
