### `MCHP_CLOCK_DERIVE_ID`

```c
#define MCHP_CLOCK_DERIVE_ID ( type, mclkbus, mclkmaskbit, gclkperiph, inst )
```

展开值（Value）：

```c
(((type) << 26) | ((mclkbus) << 20) | ((mclkmaskbit) << 14) | ((gclkperiph) << 8) | inst)
```

编码时钟类型（Clock Type）、MCLK 总线、MCLK 掩码位（Mask Bit）、GCLK 外设通道（PCH）和实例编号（Instance Number）。

将时钟子系统选择字段（Clock Subsystem Selection Fields）编码为一个打包的 32 位标识符（Packed 32-bit Identifier）。

位字段（Bit Fields）：

- 位（Bits）[7:0]：`inst`，8 位。
- 位（Bits）[13:8]：`gclkperiph`，6 位，有效范围为 0..12。
- 位（Bits）[19:14]：`mclkmaskbit`，6 位，有效范围为 0..31。
- 位（Bits）[25:20]：`mclkbus`，6 位，取以下值之一：`MBUS_AHB`（0）、`MBUS_APBA`（1）、`MBUS_APBB`（2）、`MBUS_APBC`（3）。
- 总线（Bus）：`MBUS_AHB`（0）。
- 总线（Bus）：`MBUS_APBA`（1）。
- 总线（Bus）：`MBUS_APBB`（2）。
- 总线（Bus）：`MBUS_APBC`（3）。
- 位（Bits）[31:26]：`type`，6 位，取以下值之一：`SUBSYS_TYPE_OSCHF`（0）、`SUBSYS_TYPE_RTC`（1）、`SUBSYS_TYPE_XOSC32K`（2）、`SUBSYS_TYPE_OSC32K`（3）、`SUBSYS_TYPE_GCLKGEN`（4）、`SUBSYS_TYPE_GCLKPERIPH`（5）、`SUBSYS_TYPE_MCLKCPU`（6）、`SUBSYS_TYPE_MCLKPERIPH`（7）。
- 子系统类型（Subsystem Type）：`SUBSYS_TYPE_OSCHF`（0）。
- 子系统类型（Subsystem Type）：`SUBSYS_TYPE_RTC`（1）。
- 子系统类型（Subsystem Type）：`SUBSYS_TYPE_XOSC32K`（2）。
- 子系统类型（Subsystem Type）：`SUBSYS_TYPE_OSC32K`（3）。
- 子系统类型（Subsystem Type）：`SUBSYS_TYPE_GCLKGEN`（4）。
- 子系统类型（Subsystem Type）：`SUBSYS_TYPE_GCLKPERIPH`（5）。
- 子系统类型（Subsystem Type）：`SUBSYS_TYPE_MCLKCPU`（6）。
- 子系统类型（Subsystem Type）：`SUBSYS_TYPE_MCLKPERIPH`（7）。

**参数（Parameters）**

| 名称／方向 | 说明 |
| --- | --- |
| `type` | 时钟子系统类型（Clock Subsystem Type）。 |
| `mclkbus` | 从 AHBx/APBx 总线中选择，参见 `MBUS_*`。 |
| `mclkmaskbit` | 所选 AHBx/APBx 总线上的模块掩码位（Module Mask Bit），范围为 0..31。 |
| `gclkperiph` | `PCHCTRLm` 中的 GCLK 外设通道编号（Peripheral Channel Number）`m`，范围为 0..12。 |
| `inst` | 指定时钟类型（Clock Type）的实例编号（Instance Number）。 |

**返回（Returns）**：返回值（Returns）：打包的 32 位时钟子系统标识符（Packed 32-bit Clock Subsystem Identifier）。
