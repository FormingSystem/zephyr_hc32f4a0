# 线程公共接口与对象参考大纲

本册翻译线程公共接口（Thread APIs）、线程头文件的参考与源码、线程对象结构（k_thread），共四份官方页面。公共接口包括创建与栈分配、启动与退出等待、睡眠与唤醒、挂起与恢复、优先级与截止时间、时间片、CPU掩码、对象访问和线程遍历等内容。

线程状态、调度策略与资源生命周期需要分别理解。挂起不停止超时计时，中止不自动清理所持资源，调度锁不阻止其他CPU执行，截止时间也不是完成期限保证。译文保留全部参数、配置条件、返回语义、原始示例与警告；源码跟踪细节独立标为译注。

源码浏览页保留全部可见代码、注释、许可证、符号提示与对应行号锚点。线程结构随配置变化，不能将内部字段当作稳定二进制布局或绕过API直接写入。相关内容见[线程栈参考册](../thread_stack_reference/大纲.md)、[CPU运行统计参考册](../cpu_runtime_reference/大纲.md)和[内核主线](../kernel/大纲.md)。完整覆盖情况见[全站进度](../PROGRESS.md)。
