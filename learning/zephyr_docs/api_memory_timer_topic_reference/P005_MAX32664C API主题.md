### `max32664c_acc_fill_fifo()`

```c
int max32664c_acc_fill_fifo ( const struct device * dev, struct max32664c_acc_data_t * data, uint8_t length )
```

```c
#include <zephyr/drivers/sensor/max32664c.h>
```

用加速度计数据填充先进先出缓冲区（FIFO Buffer）。

注意（Note）：此函数最多支持 16 个样本，必须周期性调用，以向 MAX32664C 提供加速度计数据（Accelerometer Data）！

**参数（Parameters）**

| 名称／方向 | 说明 |
| --- | --- |
| `dev` | 指向设备（Device）的指针。 |
| `data` | 指向加速度计数据结构体（Accelerometer Data Structure）的指针。 |
| `length` | 要填充的样本数量（Number of Samples）。 |

返回（Returns）：成功时为 0。

**注意（Attention）**：注意（Attention）：仅在启用 Kconfig 选项 CONFIG_MAX32664C_USE_EXTERNAL_ACC 时可用。
