## 8.1\_框架（Frameworks）

本节介绍高层框架和库，用于组织应用逻辑、运行时加载代码、传输媒体流，以及建立传感器模型。

- [可链接可加载扩展（Linkable Loadable Extensions，LLEXT）](../llext/P001_可链接加载扩展概览.md)。
- [多媒体流水线（Multimedia Pipeline，mpipe）](P012_多媒体流水线.md)。
- [感知子系统（Sensing Subsystem）](../io_services/P002_传感子系统.md)。
- [状态机框架（State Machine Framework）](../smf/P001_状态机框架.md)。
