原文：[官方页面](https://docs.zephyrproject.org/latest/services/index.html)。读取日期：2026-10-14；保存的 latest 页面及 HTML 摘要见[来源记录](../SOURCES.md)。

## 1.1\_服务（Services）

Zephyr 提供完善的子系统及配套服务供应用使用。这些服务暴露标准化的应用程序编程接口（Application Programming Interface，API），隐藏硬件实现细节，使应用能够跨不同平台移植。
