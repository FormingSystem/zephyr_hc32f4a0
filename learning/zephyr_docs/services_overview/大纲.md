# 服务总览与连接框架官方译文大纲

本册从官方服务分类进入身份认证、无线连接、调制解调器、多媒体流水线和虚拟化服务。分类入口保留全部子项，已译页面连接到本地正文；尚未翻译的页面连接到官方原文。专有名词保留中英文对照，源码跟踪注明版本边界并采用相对链接。

1. [服务总览](P001_服务总览.md)：十二类服务与各子项导航。
2. [算法与数据](P002_算法与数据.md)：算法、数据结构与编码服务入口。
3. [身份认证入口](P003_身份认证入口.md)：身份认证服务入口。
4. [FIDO2认证器](P004_FIDO2认证器.md)：CTAP2 架构、传输、使用者在场、存储、证明和状态回调。
5. [连接服务入口](P005_连接服务入口.md)：网络、蓝牙、USB、CAN、LoRa、Modbus 与调制解调器入口。
6. [LoRa与LoRaWAN](P006_LoRa与LoRaWAN.md)：物理层、协议栈后端、区域和配置选项。
7. [调制解调器模块](P007_调制解调器模块.md)：管道、PPP、CMUX、脚本、蜂窝连接、树外扩展与节能。
8. [框架入口](P008_框架入口.md)：事件、状态机、传感器和多媒体框架入口。
9. [输入输出服务](P009_输入输出服务.md)：控制台、输入、RTIO 与格式化输出入口。
10. [内存管理服务](P010_内存管理服务.md)：分配、缓冲区、共享内存与存储管理入口。
11. [进程间通信入口](P011_进程间通信入口.md)：处理器间通信、zbus、通知与虚拟化入口。
12. [多媒体流水线](P012_多媒体流水线.md)：元素、状态、能力与缓冲池协商、数据流及扩展实现。
13. [电源管理服务](P013_电源管理服务.md)：系统与设备电源管理入口。
14. [安全服务入口](P014_安全服务入口.md)：安全服务分类入口。
15. [虚拟化入口](P015_虚拟化入口.md)：虚拟化服务入口。
16. [虚拟机间共享内存](P016_虚拟机间共享内存.md)：QEMU、ACRN、门铃、ivshmem-v2 与相关示例。

本册16页已翻译。分类入口完成仅指该页正文和导航，不代表其所有子页、API、示例和开发板都已完成；实际范围见[全站进度](../PROGRESS.md)。原图与内嵌 SVG 保存在 images 目录；Mermaid 保留原始源码并提供图中文字的中文解释。项目环境与实验路线单独放在[项目实验补充](../../zephyr_project_notes/README.md)。
