# 第16章\_虚拟机间共享内存

原文：[官方页面](https://docs.zephyrproject.org/latest/services/virtualization/ivshmem.html)。读取日期：2026-10-14；保存的 latest 页面及 HTML 摘要见[来源记录](../SOURCES.md)。

<a id="overview"></a>

## 16.1\_概览（Overview）

Zephyr 可以作为客户操作系统（guest OS）运行在 QEMU 和 [ACRN](https://projectacrn.github.io/latest/tutorials/using_zephyr_as_uos.html) 上，因此可能需要让虚拟机（Virtual Machine，VM）彼此感知，或感知宿主机。通过向各方暴露共享内存的 ivshmem 特性，可以实现这一点；ivshmem 是虚拟机间共享内存（inter-VM Shared Memory）的缩写。

支持两种形式：普通共享内存 `ivshmem-plain`；以及允许一个虚拟机向另一个虚拟机产生中断、并接收对方中断的 `ivshmem-doorbell`。更多信息见 [QEMU 官方 ivshmem 文档](https://www.qemu.org/docs/master/system/devices/ivshmem.html)。

<a id="support"></a>

## 16.2\_支持情况（Support）

Zephyr 同时支持 plain 和 doorbell。启用 [`CONFIG_IVSHMEM`](https://docs.zephyrproject.org/latest/kconfig.html#CONFIG_IVSHMEM) 构建驱动，默认提供 plain；启用 [`CONFIG_IVSHMEM_DOORBELL`](https://docs.zephyrproject.org/latest/kconfig.html#CONFIG_IVSHMEM_DOORBELL) 才能使用 doorbell。

doorbell 使用 MSI-X 向量进行通知，因此必须按所需数量调整 [`CONFIG_IVSHMEM_MSI_X_VECTORS`](https://docs.zephyrproject.org/latest/kconfig.html#CONFIG_IVSHMEM_MSI_X_VECTORS)。

启用 [`CONFIG_IVSHMEM_SHELL`](https://docs.zephyrproject.org/latest/kconfig.html#CONFIG_IVSHMEM_SHELL)，还可提供一个小型 shell 模块来测试 ivshmem。

<a id="ivshmem-v2"></a>

## 16.3\_ivshmem-v2

Zephyr 也支持 [ivshmem-v2 规范](https://github.com/siemens/jailhouse/blob/master/Documentation/ivshmem-v2-specification.md)。它主要用于 Jailhouse 虚拟机监控器（hypervisor）中的处理器间通信（IPC），例如 [ivshmem 以太网](../driver_samples/P060_IVSHMEM以太网示例.md#eth-ivshmem)。

也可以不使用 Jailhouse：构建 [Siemens 的 QEMU 分支](https://github.com/siemens/qemu/tree/wip/ivshmem2)，并修改 QEMU 启动参数，即可使用 ivshmem-v2。

<a id="api-reference"></a>

## 16.4\_API与相关示例（API Reference / Related Code Samples）

接口参考：[虚拟机间共享内存 API](../intercore_reference/P214_IVSHMEM共享内存接口.md)。

- [ivshmem 以太网](../driver_samples/P060_IVSHMEM以太网示例.md#eth-ivshmem)：通过 IVSHMEM Ethernet 与 Jailhouse 中的另一个隔离单元（cell）通信。
- [IVSHMEM 门铃（doorbell）](../driver_samples/P067_IVSHMEM门铃示例.md#ivshmem-doorbell)：通过虚拟机间共享内存，让运行于不同操作系统的两个进程交换消息。
