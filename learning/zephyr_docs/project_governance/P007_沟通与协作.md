# 第7章\_沟通与协作（Communication and Collaboration）

原文：[官方页面](https://docs.zephyrproject.org/latest/project/communication.html)。快照读取日期：2026-10-15；来源摘要见[来源记录](../SOURCES.md)。

[Zephyr Discord 服务器](https://chat.zephyrproject.org)是开发者、贡献者和用户主要使用的即时交流场所。

邮件列表是成员、贡献者和社区的补充沟通工具，按不同兴趣设有专用列表，其中多个列表公开开放。当 Discord 不可用或不适合某项讨论时，仍可使用邮件列表。 相关链接：[Zephyr 项目邮件列表](https://lists.zephyrproject.org/g/main/subgroups)。

通常应通过 GitHub Issue 报告缺陷及其他问题，不要向邮件列表群发；代码评审同样如此。 相关链接：[GitHub 问题（Issue）](https://github.com/zephyrproject-rtos/zephyr/issues)。

对应官方文档源码：[doc/project/communication.rst](https://raw.githubusercontent.com/zephyrproject-rtos/zephyr/main/doc/project/communication.rst)。
