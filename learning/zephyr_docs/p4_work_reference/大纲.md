# P4工作队列参考大纲

本册完整翻译P4工作队列的头文件参考、源码浏览，以及队列、初始化参数和工作项三个结构体，共五份官方页面。P4表示池化、并行、可抢占、按优先级调度（Pooled Parallel Preemptible Priority-based）。

先阅读头文件参考中的初始化、提交、取消和等待约定，再到源码页及结构体页查阅字段与实现。原始声明、宏展开、可见代码、注释、符号提示及交叉引用完整保留；源码译注说明优先级、截止时间、完成回调、取消和所有权边界。

本地源码链接均为相对路径，未加入本机环境和实板实验步骤。相关[RTIO工作队列](../rtio_work_reference/大纲.md)当前实现使用不同的队列路径，不因包含P4类型就自动具有相同调度行为。完整翻译范围见[全站进度](../PROGRESS.md)。
