## 概述（Overview）

Nucleo L4A6ZG搭载基于Arm Cortex-M4的STM32L4A6ZG微控制器，提供丰富连接能力及配置，主要特点如下：


- QFP144封装的STM32微控制器
- USB OTG全速接口，带Micro-AB连接器
- 两类扩展资源：


  - Arduino Uno V3连接接口
  - ST morpho扩展排针，可访问全部STM32 I/O
- 带SWD连接器的板载ST-LINK/V2-1调试器／编程器
- 灵活的开发板供电方式：


  - 通过USB VBUS或外部电源（3.3 V、5 V、7～12 V）供电
  - 电源管理接入点
- 8个LED：用户LD1、LD2、LD3，通信LD4，USB电源故障LD5，电源LD6，以及USB FS OTG的LD7、LD8
- 2个按键：USER用户键和RESET复位键

更多开发板信息见[Nucleo L4A6ZG网站](https://www.st.com/en/evaluation-tools/nucleo-l4a6zg.html)。

## 硬件（Hardware）

STM32L4A6ZG SoC提供以下硬件能力：


- 支持FlexPowerControl的超低功耗设计：待机电流最低108 nA，运行模式91 µA/MHz
- 内核：ARM® 32位Cortex®-M4 CPU，带浮点单元（FPU），最高80 MHz；Dhrystone 2.1性能为100 DMIPS或1.25 DMIPS/MHz
- 时钟源（Clock Sources）：


  - 4–48 MHz晶体振荡器（Crystal Oscillator）
  - 用于实时时钟（RTC）的32 kHz低速外部晶体振荡器（LSE）
  - 内部16 MHz RC振荡器，出厂校准（Factory-Trimmed），精度±1%
  - 内部低功耗32 kHz RC振荡器，精度±5%
  - 内部多速率100 kHz至48 MHz振荡器，由LSE自动校准，精度优于±0.25%
  - 三个锁相环（PLL），用于系统时钟、USB、音频和ADC
- 带硬件日历、闹钟及校准功能的实时时钟（RTC）
- LCD驱动8×40或4×44，带升压转换器（Step-up Converter）
- 最多24个电容感应通道，支持触摸键、线性及旋转触摸传感器
- 16个定时器（Timers）：


  - 两个16位高级电机控制定时器（Advanced Motor-Control）
  - 通用定时器：2个32位及5个16位
  - 两个16位基本定时器（Basic Timers）
  - 两个16位低功耗定时器，在停止模式（Stop Mode）下可用
  - 两个看门狗（Watchdogs）
  - 系统节拍定时器（SysTick Timer）
- 最多136个高速I/O，多数耐受5 V；最多14个I/O具有独立供电，最低1.08 V
- 存储器（Memories）


  - 最多1 MB闪存，双存储区支持读写并行（Read-While-Write），提供专有代码读出保护（Code Readout Protection）
  - 最多320 KB SRAM，其中64 KB支持硬件奇偶校验
  - 面向静态存储器的外部存储器接口（External Memory Interface），支持SRAM、PSRAM、NOR和NAND存储器
  - 四线SPI存储器接口（Quad SPI Memory Interface）
- 四个用于Σ-Δ调制器（Sigma Delta Modulator）的数字滤波器（Digital Filters）
- 丰富的模拟外设（Analog Peripherals），采用独立供电


  - 三个12位、5 MSPS模数转换器（ADC），硬件过采样（Oversampling）后最高16位，功耗200 μA/MSPS
  - 两个12位数模转换器（DAC），支持低功耗采样保持（Sample and Hold）
  - 两个运算放大器（Operational Amplifiers），内置可编程增益放大器（PGA）
  - 两个超低功耗比较器（Comparators）
- 20个通信接口


  - USB OTG 2.0全速，支持链路电源管理（LPM）和电池充电检测（BCD）
  - 两个串行音频接口（SAI）
  - 4路I2C FM+（1 Mbit/s），支持SMBus/PMBus
  - 5路U(S)ART，支持ISO 7816、LIN、IrDA及调制解调器
  - 一路低功耗UART（LPUART）
  - 三路SPI，加上Quad SPI后为四路
  - 2路CAN 2.0B Active及SDMMC接口
  - 单线协议主机接口（SWPMI / Single Wire Protocol Master Interface）
  - 红外定时器（IRTIM，Infrared Interface）
- 14通道直接存储器访问控制器（DMA Controller）
- 真随机数发生器（True Random Number Generator）
- 循环冗余校验计算单元（CRC），96位唯一标识（Unique ID）
- AES及HASH硬件加速器
- 开发支持：串行线调试（SWD）、JTAG及嵌入式跟踪宏单元（Embedded Trace Macrocell™）

STM32L4A6ZG的更多信息见：


- [STM32L4A6ZG在ST官网的产品页](https://www.st.com/en/microcontrollers-microprocessors/stm32l4a6zg.html)
- [STM32L4A6参考手册（Reference Manual）](https://www.st.com/resource/en/reference_manual/dm00083560.pdf)

<a id="connections-and-ios"></a>

### 连接与输入输出（Connections and IOs）

Nucleo L4A6ZG有8个通用输入输出（GPIO）控制器，负责引脚复用（Pin Muxing）、输入输出、上拉等功能。

更多细节见[STM32 Nucleo-144开发板用户手册](https://www.st.com/resource/en/user_manual/dm00368330.pdf)（User Manual）。

<a id="default-zephyr-peripheral-mapping"></a>

#### Zephyr 默认外设映射（Peripheral Mapping）：


- LPUART_1 TX/RX : PG7/PG8（ST-Link虚拟COM端口）
- UART_3 TX/RX : PD8/PD9（Arduino串口）
- I2C_1 SCL/SDA : PB8/PB7（Arduino I2C接口）
- SPI_1 SCK/MISO/MOSI/NSS : PA5/PA6/PA7/PD14（Arduino SPI接口）
- `USER_PB : PC13`
- PWM_15_CH1：PB14（红色LED）
- LD1：PC7（绿色LED）
- LD2：PB7（蓝色LED）
- LD3：PB14（红色LED）

<a id="system-clock"></a>

#### 系统时钟（System Clock）

Nucleo L4A6ZG系统时钟可来自内部振荡器、外部振荡器或主PLL。默认以16 MHz高速内部振荡器（HSI）驱动PLL，产生80 MHz系统时钟。板上未焊接高速外部振荡器（HSE），因此不能用HSE驱动PLL。

<a id="serial-port"></a>

#### 串口（Serial Port）

Nucleo L4A6ZG有5路UART，Zephyr控制台分配给连接板载ST-LINK/V2-1虚拟COM接口的LPUART1，默认参数115200、8N1。

Nucleo L4A6ZG开发板内置ST-LINK/V2-1调试工具接口。

nucleo_l4a6zg开发板的应用可按常规方式构建和烧录，详见“[构建应用（Building an Application）](../application/P001_应用开发.md#build-an-application)”与“[运行应用（Run an Application）](https://docs.zephyrproject.org/latest/develop/application/index.html#application-run)”。

<a id="flashing"></a>

### 烧录（Flashing）

此板默认通过west的[STM32CubeProgrammer](https://www.st.com/en/development-tools/stm32cubeprog.html)运行器（Runner）烧录，因此需要安装该工具。（[installation](https://docs.zephyrproject.org/latest/develop/flash_debug/host-tools.html#stm32cubeprog-flash-host-tools)）

也可通过`--runner`（或`-r`）选项选择OpenOCD或JLink烧录：

```text
$ west flash --runner openocd
$ west flash --runner jlink
```

<a id="flashing-an-application-to-nucleo-l4a6zg"></a>

#### 向Nucleo L4A6ZG烧录应用（Flashing an Application）

通过ST-LINK USB接口将Nucleo L4A6ZG连接主机，然后构建并烧录应用。以下以[Hello World](../getting_started/P005_HelloWorld示例.md#hello_world)为例。

运行主机串口程序，连接Nucleo开发板：

```text
$ minicom -D /dev/ttyUSB0
```

随后构建并烧录应用。

```text
# From the root of the zephyr repository
west build -b nucleo_l4a6zg samples/hello_world
west flash
```

控制台上应显示以下消息：

```text
Hello World! nucleo_l4a6zg
```

<a id="debugging"></a>

### 调试（Debugging）

可以按常规方式调试应用。下面以[Hello World](../getting_started/P005_HelloWorld示例.md#hello_world)应用为例。

```text
# From the root of the zephyr repository
west build -b nucleo_l4a6zg samples/hello_world
west debug
```
