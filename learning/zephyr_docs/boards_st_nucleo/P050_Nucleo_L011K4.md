## 概述（Overview）

搭载STM32L011K4 MCU的STM32 Nucleo-32开发板支持Arduino Nano V3连接。

STM32 Nucleo开发板以经济、灵活的方式帮助用户尝试新概念和构建STM32微控制器原型，可按性能、功耗及功能选择不同组合。

Arduino* Nano V3连接接口支持多种专用扩展板，便于扩展STM32 Nucleo开放开发平台功能。

STM32 Nucleo开发板集成ST-LINK/V2-1调试器与编程器（Debugger / Programmer）。

STM32 Nucleo开发板配套完整的STM32硬件抽象层（HAL）软件库及多种打包软件示例。

<a id="id3"></a>

更多开发板信息见[Nucleo L011K4网站](https://www.st.com/en/evaluation-tools/nucleo-l011k4.html) [注1](#id2)。

<a id="hardware"></a>

## 硬件（Hardware）

Nucleo L011K4提供以下硬件组件：


- LQFP32封装的STM32微控制器
- 扩展资源（Extension Resources）：


  - Arduino* Nano V3连接接口
- 带串行线调试（SWD）连接器的板载ST-LINK/V2-1调试器／编程器：


  - 通过模式选择开关，可将套件用作独立ST-LINK/V2-1
- 灵活的开发板供电方式：


  - USB VBUS或外部3.3 V、5 V、7—12 V电源
  - 电源管理接入点
- 三个LED：


  - USB通信LED LD1、用户LED LD2及电源LED LD3
- 一个按键：RESET复位
- 支持USB重新枚举（Re-enumeration），提供三种USB接口：


  - 虚拟COM端口
  - 大容量存储（Mass Storage）
  - 调试端口（Debug Port）

<a id="id5"></a>

STM32L011K4的更多信息见[STM32L0x1参考手册](https://www.st.com/resource/en/reference_manual/dm00108282-ultralowpower-stm32l0x1-advanced-armbased-32bit-mcus-stmicroelectronics.pdf)（Reference Manual）[注2](#id4)。

<a id="connections-and-ios"></a>

### 连接与输入输出（Connections and IOs）

每个GPIO都可由软件配置为推挽／开漏输出、带或不带上拉／下拉的输入，或外设复用功能。大多数GPIO与数字或模拟功能复用，除模拟输入外，所有GPIO均支持大电流驱动。

<a id="default-zephyr-peripheral-mapping"></a>

#### Zephyr 默认外设映射（Peripheral Mapping）：


- UART_2 TX/RX : PA2/PA15（ST-Link虚拟COM端口）
- I2C1 SCL/SDA : PA4/PA10（Arduino I2C接口）
- SPI1 SCK/MISO/MOSI : PA5/PA6/PA7（Arduino SPI接口）
- LD2 : PB3

<a id="id7"></a>

更多细节见[STM32 Nucleo-32开发板用户手册](https://www.st.com/resource/en/user_manual/dm00231744-stm32-nucleo32-boards-mb1180-stmicroelectronics.pdf)（User Manual） [注3](#id6)。

<a id="flashing"></a>

### 烧录（Flashing）

<a id="id9"></a>

开发板配置为使用west的[STM32CubeProgrammer](https://www.st.com/en/development-tools/stm32cubeprog.html) [注4](#id8)运行工具烧录，因此需先安装STM32CubeProgrammer。（[installation](https://docs.zephyrproject.org/latest/develop/flash_debug/host-tools.html#stm32cubeprog-flash-host-tools)）

也可通过`--runner`（或`-r`）选项选择OpenOCD或JLink烧录：

```text
$ west flash --runner openocd
$ west flash --runner jlink
```

<a id="flashing-an-application-to-nucleo-l011k4"></a>

#### 向Nucleo L011K4烧录应用（Flashing an Application）

以下以[Blinky](../getting_started/P004_LED闪烁示例.md#blinky)应用为例。

```text
# From the root of the zephyr repository
west build -b nucleo_l011k4 samples/basic/blinky
west flash
```

可以看到LED每秒闪烁一次。

<a id="debugging"></a>

### 调试（Debugging）

可以按常规方式调试应用。下面以[Hello World](../getting_started/P005_HelloWorld示例.md#hello_world)应用为例。

```text
# From the root of the zephyr repository
west build -b nucleo_l011k4 samples/hello_world
west debug
```
