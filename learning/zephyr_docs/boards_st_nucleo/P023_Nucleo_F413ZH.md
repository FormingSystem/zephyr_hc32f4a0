## 概述（Overview）

Nucleo F413ZH搭载基于Arm Cortex-M4的STM32F413ZH微控制器，提供丰富连接能力及配置，主要特点如下：


- LQFP144封装的STM32微控制器
- 两类扩展资源：


  - ST Zio连接器支持Arduino* Uno V3接口（A0～A5、D0～D15），并引出更多信号以访问多种外设
  - ST morpho扩展排针，可访问全部STM32 I/O
- 带SWD连接器的板载ST-LINK/V2-1调试器／编程器
- 灵活的开发板供电方式：


  - ST-LINK/V2-1 USB VBUS提供5 V
  - 外部电源：ST Zio或ST morpho连接器提供3.3 V及7～12 V，ST morpho连接器还可提供5 V
- 3个用户LED
- 两个按键：USER及RESET

更多开发板信息见[Nucleo F413ZH网站](https://www.st.com/en/evaluation-tools/nucleo-f413zh.html)。

<a id="hardware"></a>

## 硬件（Hardware）

Nucleo F413ZH提供以下硬件组件：


- LQFP144封装的STM32F413ZHT6
- 带浮点单元（FPU）的 ARM 32 位 Cortex-M4 CPU。
- CPU 最高频率 100 MHz。
- VDD 为 1.7–3.6 V。
- 1.5 MB闪存
- 320 KB静态随机存储器（SRAM）
- 支持外部中断（External Interrupt）的 GPIO。
- 2个12位ADC，16个通道，支持FIFO及突发传输
- 实时时钟（RTC）
- 14个通用定时器
- 2个看门狗定时器：独立看门狗（Independent）和窗口看门狗（Window）
- 系统节拍定时器（SysTick Timer）
- 10路USART/UART
- 4路I2C
- 5路串行外设接口（SPI）
- SD输入输出接口（SDIO）
- USB 2.0 OTG 全速接口（Full Speed，FS）。
- 直接存储器访问控制器（DMA Controller）。
- 循环冗余校验计算单元（CRC Calculation Unit）

STM32F413ZH的更多信息见：


- [STM32F413ZH在ST官网的产品页](https://www.st.com/en/microcontrollers/stm32f413zh.html)
- [STM32F413/423参考手册](https://www.st.com/resource/en/reference_manual/dm00305666.pdf)

### 连接与输入输出（Connections and IOs）

Nucleo F413ZH有8个通用输入输出（GPIO）控制器，负责引脚复用（Pin Muxing）、输入输出、上拉等功能。

#### 可用引脚：

![官方原图：Nucleo F413ZH Morpho connectors (left)](images/nucleo_f413zh_morpho_left.jpg)

更多细节见[STM32 Nucleo-144开发板用户手册](https://www.st.com/resource/en/user_manual/dm00244518.pdf)（User Manual）。

<a id="default-zephyr-peripheral-mapping"></a>

#### Zephyr 默认外设映射（Peripheral Mapping）：


- UART_3 TX/RX : PD8/PD9（ST-Link虚拟COM端口）
- UART_6 TX/RX : PG14/PG9（Arduino串口）
- I2C1 SCL/SDA : PB8/PB9（Arduino I2C接口）
- SPI1 NSS/SCK/MISO/MOSI : PD14/PA5/PA6/PA7（Arduino SPI接口）
- `PWM_2_CH1 : PA0`
- USB_DM：PA11
- `USB_DP : PA12`
- `USER_PB : PC13`
- LD1 : PB0
- LD2 : PB7
- LD3 : PB14

<a id="system-clock"></a>

#### 系统时钟（System Clock）

Nucleo F413ZH系统时钟可来自内部振荡器、外部振荡器或主锁相环（PLL）。默认以8 MHz高速外部时钟驱动PLL，产生96 MHz系统时钟。

<a id="serial-port"></a>

#### 串口（Serial Port）

Nucleo F413ZH有10路UART，Zephyr控制台分配给UART3，默认串口参数为115200、8N1。

<a id="usb"></a>

### 通用串行总线（USB）

Nucleo F413ZH的USB OTG双角色设备（DRD）控制器可通过Micro-USB用户接口支持设备和主机功能；原文指出Zephyr目前仅支持设备功能。

<a id="flashing"></a>

### 烧录（Flashing）

此板默认通过west的[STM32CubeProgrammer](https://www.st.com/en/development-tools/stm32cubeprog.html)运行器（Runner）烧录，因此需要安装该工具。（[installation](https://docs.zephyrproject.org/latest/develop/flash_debug/host-tools.html#stm32cubeprog-flash-host-tools)）

```text
$ west flash --runner openocd
$ west flash --runner jlink
```
