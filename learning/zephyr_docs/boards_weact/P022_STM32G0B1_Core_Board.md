## 概述（Overview）

WeAct STM32G0B1核心板是STM32G0B1CBT6引出板。

<a id="hardware"></a>

## 硬件（Hardware）

搭载STM32G0B1CBT6，提供USB-C、调试排针、1个LED、复位／启动／用户三个按键及两组24针排针。

### 系统时钟（System Clock）

STM32G0B1CBT6由8 MHz外部高速晶体驱动PLL，生成64 MHz系统时钟。
