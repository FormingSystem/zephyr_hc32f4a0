## 概述（Overview）

MiniSTM32H750采用STM32H750VBT6，板型紧凑，带用户LED及按键，以及外部SPI和QuadSPI NOR闪存。

主要特性（Key Features）


- LQFP100封装的STM32微控制器
- USB双角色接口（OTG）或全速设备（Full-Speed Device）
- 一个用户LED
- 用户、启动及复位按键
- 32.768 kHz晶体及25 MHz HSE晶体振荡器
- 外部NOR闪存：64 Mbit QuadSPI及64 Mbit SPI
- 板上连接器（Board Connectors）


  - 8位摄像头连接器
  - ST7735 TFT-LCD，160×80像素，RGB565、三线SPI
  - MicroSD存储卡
  - USB Type-C连接器
  - 供外部调试器连接的SWD排针
  - 2组40针GPIO连接器

更多信息见[Mini_STM32H7xx网站](https://github.com/WeActStudio/MiniSTM32H7xx)。

<a id="hardware"></a>

## 硬件（Hardware）

MiniSTM32H750核心板具有以下硬件：


- STM32H750VBT6，LQFP100封装
- 32位Arm Cortex-M7 CPU，带FPU
- Chrom-ART图形加速器（Accelerator）
- 硬件JPEG编解码器（Codec）
- CPU最高频率480 MHz
- VDD电压范围1.62–3.6 V
- 128 KB闪存（Flash）
- 约1 MB SRAM
- 高分辨率定时器（High-Resolution Timer），2.1 ns
- 2个32位定时器
- 10个16位定时器
- 6路SPI
- 4路I2C
- 3路I2S
- 4路USART
- 4路UART
- 1路全速及高速USB OTG
- 1路全速USB OTG
- 2路CAN FD
- 4路串行音频接口（SAI）
- 4路SPDIF接收（SPDIF_Rx）
- 1路HDMI消费电子控制（HDMI_CEC）
- 1路双模式四线SPI（Dual Mode Quad SPI）
- 摄像头接口（Camera Interface）
- 最多82路GPIO，支持外部中断
- 3个16位ADC，16通道
- 2个12位DAC，每个2通道
- 真随机数发生器（RNG / True Random Number Generator）
- 16通道直接存储器访问（DMA）
- 支持XGA分辨率的LCD-TFT控制器

STM32H750更多信息：


- [ST网站上的STM32H750VB](https://www.st.com/en/microcontrollers-microprocessors/stm32h750vb.html#overview)
- [STM32H750参考手册](https://www.st.com/resource/en/reference_manual/rm0433-stm32h742-stm32h743753-and-stm32h750-value-line-advanced-armbased-32bit-mcus-stmicroelectronics.pdf)
- [STM32H750VB数据手册](https://www.st.com/resource/en/datasheet/stm32h750vb.pdf)

<a id="pin-mapping"></a>

### 引脚映射（Pin Mapping）

MiniSTM32H750有5个GPIO控制器，负责引脚复用、输入输出、上拉等。

详情见[Mini_STM32H7xx网站](https://github.com/WeActStudio/MiniSTM32H7xx)。

<a id="default-zephyr-peripheral-mapping"></a>

#### Zephyr 默认外设映射（Peripheral Mapping）：

MiniSTM32H750配置如下：


- USART1 TX／RX：PB14／PB15，控制台
- 用户LED：PE3
- `USER_PB : PC13`
- SPI1 SCK／MISO／MOSI／NSS：PB3／PB4／PD7／PD6，NOR闪存
- QuadSPI CLK／NCS／IO0／IO1／IO2／IO3：PB2／PB6／PD11／PD12／PE2／PD13，NOR闪存
- SDMMC1 CLK／DCMD／CD／D0／D1／D2／D3：PC12／PD2／PD4／PC8／PC9／PC10／PC11，MicroSD卡
- `USB DM/DP : PA11/PA12`

<a id="system-clock"></a>

### 系统时钟（System Clock）

STM32H750VB系统时钟可由内部、外部振荡器或主PLL驱动，默认25 MHz外部高速时钟经PLL生成480 MHz。

<a id="serial-port"></a>

### 串口（Serial Port）

Zephyr控制台输出分配给USART1，默认115200波特率、8N1。

MiniSTM32H750可通过USB DFU引导加载器更新固件，但DFU不提供调试能力。SWD排针可连接ST-Link等外部调试器。

使用STM32CubeProgrammer或ST-Link GDB Server烧录外部QSPI闪存，例如--runner stm32cubeprogrammer或--runner stlink_gdbserver时，需要外部闪存加载器STM32H7xx_W25Q128_WeActStudio.stldr。从[Mini_STM32H7xx QSPI Flasher](https://github.com/WeActStudio/MiniSTM32H7xx/tree/master/SDK/QSPI_Flasher)下载并复制到STM32CubeProgrammer安装目录的ExternalLoader子目录。

<a id="flashing"></a>

### 烧录（Flashing）

按以下步骤激活引导加载器：


1. 按住BOOT0键。
2. 保持BOOT0按下，同时按下再松开RESET键。
3. 等待0.5秒后松开BOOT0。

成功后设备进入引导加载器模式，呈现为USB DFU设备，可用west或STM32CubeProgrammer编程。

<a id="application-in-soc-flash"></a>

### 应用位于片上闪存（SoC Flash）

以下展示[Hello World](../getting_started/P005_HelloWorld示例.md#hello_world)应用的构建及烧录方法。

先按前述步骤进入引导加载器模式，再常规构建及烧录：

```text
# From the root of the zephyr repository
west build -b mini_stm32h750 samples/hello_world
west flash
```

运行主机串口程序连接开发板：

```text
$ minicom -D <tty_device> -b 115200
```

随后按RESET键，应看到以下消息：

```text
Hello World! mini_stm32h750
```

将<tty_device>替换为开发板串口，例如Linux中的/dev/ttyUSB0。

若应用大于片上闪存容量，可用Zephyr代码和数据重定位（[Code and Data Relocation](https://docs.zephyrproject.org/latest/kernel/code-relocation.html#code-data-relocation)）将非关键的大块内容移到外部闪存。

#### 调试（Debugging）

可经SWD排针使用OpenOCD或J-Link调试。

```text
# From the root of the zephyr repository
west build -b mini_stm32h750 samples/hello_world
west debug
```

<a id="application-in-external-flash"></a>

### 应用位于外部闪存（External Flash）

片上闪存仅128 KB，可将应用放在外部QSPI闪存并从中执行。这需要MCUboot引导加载器链式加载（Chainload）应用，为此提供ext_flash_app专用目标变体。

系统构建（Sysbuild）可构建及烧录外部闪存应用所需的全部镜像。（[系统构建（Sysbuild / System Build）](../sysbuild/P001_系统构建.md#sysbuild)）

以下示例启用Sysbuild构建[Hello World](../getting_started/P005_HelloWorld示例.md#hello_world)：

```text
# From the root of the zephyr repository
west build -b mini_stm32h750/stm32h750xx/ext_flash_app --sysbuild samples/hello_world
```

Sysbuild默认生成MCUboot及用户应用镜像。

Sysbuild构建目录与传统Zephyr构建不同，输出按域（Domain）组织到子目录：

```text
build/
├── hello_world
|    └── zephyr
│       ├── zephyr.elf
│       ├── zephyr.hex
│       ├── zephyr.bin
│       ├── zephyr.signed.bin
│       └── zephyr.signed.hex
├── mcuboot
│    └── zephyr
│       ├── zephyr.elf
│       ├── zephyr.hex
│       └── zephyr.bin
└── domains.yaml
```

注意（Note）

使用--sysbuild时，每次全新构建（Pristine Build）都会重建MCUboot；但若配置未变，MCUboot只需烧录一次。

系统构建的更多信息见 Sysbuild（System Build）文档。（[系统构建（Sysbuild / System Build）](../sysbuild/P001_系统构建.md#sysbuild)）

运行以下命令烧录MCUboot及用户应用两个镜像：

```text
$ west flash
```

主机串口程序应显示以下消息：

```text
*** Booting MCUboot v2.2.0-173-gb192716c969a ***
*** Using Zephyr OS build v4.2.0-6260-ge39ba1a35bc4 ***
I: Starting bootloader
I: Image index: 0, Swap type: none
I: Image index: 0, Swap type: none
I: Bootloader chainload address offset: 0x0
I: Image version: v0.0.0
I: Jumping to the first image slot
*** Booting Zephyr OS build v4.2.0-6260-ge39ba1a35bc4 ***
Hello World! mini_stm32h750/stm32h750xx/ext_flash_app
```

后续构建若只烧录用户应用，使用：

```text
$ west flash --domain hello_world
```

默认使用MCUboot偏移交换模式（Swap-using-offset）。各运行模式及应用升级方式见[MCUboot设计文档](https://docs.mcuboot.com/design.html)；外部闪存镜像安全保护见MCUboot加密文档。（[MCUboot加密（Encryption）](https://docs.mcuboot.com/encrypted_images.html)）

<a id="id1"></a>

#### 调试（Debugging）

可通过west和GDB调试外部闪存中的应用。

烧录MCUboot及应用后执行：

```text
$ west debugserver
```

再打开另一终端，记得激活Zephyr环境，执行：

```text
$ west attach
```
