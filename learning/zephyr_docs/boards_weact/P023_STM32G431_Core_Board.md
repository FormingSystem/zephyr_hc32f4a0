<a id="modifications-usb-c-power-delivery"></a>

## USB-C供电协商（Power Delivery，PD）硬件修改

标准配置不支持USB-C PD。启用时须断开CC1／CC2下拉电阻，并分别连接PB6／PB4。无电池启动（Dead Battery）支持需将PA9／PA10接到CC1／CC2；VBUS还须通过分压器连接MCU。

移除USB-C旁SB8／SB9上的0 Ω电阻以断开下拉，然后闭合SB3、SB5、SB6、SB7，将CCx接到MCU；闭合SB4把分压器接到PB2。

修改后，PA9、PA10、PB2、PB4、PB6应视为USB-C保留引脚，不再用于其他用途。

警告（Warning）

若未启用Dead Battery支持，内部USB DFU引导加载器在遵循USB PD信号规则的主机上可能无法正确工作。可用USB-C转USB-A适配器或SWD烧录绕过。

<a id="pin-mapping"></a>

### 引脚映射（Pin Mapping）

<a id="default-zephyr-peripheral-mapping"></a>

#### Zephyr 默认外设映射（Peripheral Mapping）：


- UART_2 TX／RX：PA2／PA3
- UCPD1 CCx：PB6／PB4，默认未连接
- UCPD1 DBCCx：PA9／PA10，默认未连接
- 用户按键：PC13
- BOOT0按键：PB8
- LED0：PC6
- ADC测量VBUS：PB2

ADC默认关闭，因为标准配置未连接VBUS分压器。

<a id="clock-sources"></a>

#### 时钟源（Clock Sources）

开发板有两个外部振荡器（Oscillators）。低速外部时钟（LSE）频率为32.768 kHz，主时钟，即高速外部时钟（HSE），频率为8 MHz。

默认HSE经PLL生成144 MHz系统时钟。USB的48 MHz时钟也来自PLL，而非内部48 MHz振荡器。

<a id="flashing-an-application"></a>

### 烧录应用（Flashing an Application）

连接USB-C供电，保持BOOT0键按下，同时按下再松开NRST键，即可强制进入DFU模式。

此开发板支持`dfu-util`运行工具（Runner），因此可方便地构建及测试示例。

```text
# From the root of the zephyr repository
west build -b weact_stm32g431_core samples/basic/blinky
west flash
```

### 调试（Debugging）

安装随附的100 mil，即0.1英寸间距排针后，可将SWD调试器连接排针上的3V3、GND、SCK及DIO进行调试。
