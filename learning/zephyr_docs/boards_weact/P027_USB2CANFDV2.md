## 概述（Overview）

WeAct USB2CANFDV2是专用USB转CAN-FD适配板，更多信息见[USB2CANFDV2网站](https://github.com/WeActStudio/WeActStudio.USB2CANFDV2)。

<a id="hardware"></a>

## 硬件（Hardware）

USB2CANFDV2搭载STM32G431CB，提供USB-C、CAN接线端子、三个LED、BOOT0键及控制120 Ω CAN终端电阻的滑动开关。

<a id="system-clock"></a>

### 系统时钟（System Clock）

STM32G431CB由16 MHz HSE晶体驱动PLL，生成160 MHz系统时钟及80 MHz FDCAN1内核时钟。
