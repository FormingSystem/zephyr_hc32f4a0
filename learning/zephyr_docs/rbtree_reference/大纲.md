# 红黑树参考大纲

平衡红黑树（Balanced Red/Black Tree）维护固定比较关系下的有序节点集合，通过再平衡限制查找和移除的路径长度。rbnode嵌入应用对象，树管理链接而不分配或释放对象。先读[红黑树指南](../kernel/P056_红黑树.md)，再查公共API、结构和源码；使用示例见[红黑树示例](../basic_samples/P033_红黑树示例.md)。

本册保留原页声明、宏展开、参数说明、源码和法律注释。源码译注单独说明布尔比较谓词、节点身份、空树调用前提、遍历复杂度以及CONFIG_MISRA_SANE下共享辅助栈的边界。需要持续取出最小元素时，也可对照[最小堆参考](../minheap_reference/大纲.md)。所有本地定位使用相对路径，完整范围见[全站进度](../PROGRESS.md)。
