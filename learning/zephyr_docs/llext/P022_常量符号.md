# 第22章\_常量符号

原文：[官方页面](https://docs.zephyrproject.org/latest/doxygen/html/structllext__const__symbol.html)。读取日期：2026-10-14；保存的 latest 页面及 HTML 摘要见[来源记录](../SOURCES.md)。

## 22.1\_概述

常量符号（Constant Symbol）是不可更改的具名内存地址。符号可以是为链接而导出的具名函数或全局对象。这些常量符号可放入只读存储器（Read-only Memory，ROM），因此适用于基础镜像。

**原文注意（Note）**：更新此结构体时，也要更新构建脚本 scripts/build/llext_prepare_exptab.py。

```c
#include <zephyr/llext/symbol.h>
```

原页成员摘要中的匿名联合体（Anonymous Union）嵌套关系如下；name 与 slid 共享存储，addr 位于联合体之外：

```c
struct llext_const_symbol {
    union {
        const char *const name;
        const uintptr_t slid;
    };
    const void *const addr;
};
```

## 22.2\_[union]

<a id="a1ffacf8c4906e0d64a0f292405e16a15"></a>
<a id="r_a1ffacf8c4906e0d64a0f292405e16a15"></a>

```c
union { ... } llext_const_symbol
```

构建时始终写入 `name` 字段。

运行时使用哪个字段取决于 `CONFIG_LLEXT_EXPORT_BUILTINS_BY_SLID`。
