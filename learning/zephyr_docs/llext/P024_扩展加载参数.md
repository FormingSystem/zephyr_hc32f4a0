# 第24章\_扩展加载参数

原文：[官方页面](https://docs.zephyrproject.org/latest/doxygen/html/structllext__load__param.html)。读取日期：2026-10-14；保存的 latest 页面及 HTML 摘要见[来源记录](../SOURCES.md)。

## 24.1\_概述

[`llext_load`](P011_扩展管理API.md#ga0a4c3db30bc3ec7aa8a9b0e076af7157) 的高级参数（Advanced Parameters）。此结构体包含 [`llext_load`](P011_扩展管理API.md#ga0a4c3db30bc3ec7aa8a9b0e076af7157) 的高级参数。

```c
#include <zephyr/llext/llext.h>
```

## 24.2\_keep\_section\_info

<a id="ae8e62920c8f47e7d2bcf7b7309058fb7"></a>
<a id="r_ae8e62920c8f47e7d2bcf7b7309058fb7"></a>

```c
bool llext_load_param::keep_section_info
```

加载扩展后，在内存中保留 `ELF` 节数据。

使用 `ELF` 检查 API 中的部分函数需要这些数据。

**原文注意（Note）**：必须先通过 [`llext_free_inspection_data`](P011_扩展管理API.md#ga54f3aaed749e8c6bad6fbecb1622ab06) 释放相关内存，然后才能通过 [`llext_unload`](P011_扩展管理API.md#gad3df7ed4d436846504c0047166eb929e) 卸载扩展。

## 24.3\_pre\_located

<a id="a5e9fdb238b8a706155a873e82e35393d"></a>
<a id="r_a5e9fdb238b8a706155a873e82e35393d"></a>

```c
bool llext_load_param::pre_located
```

计算重定位目标时，使用 `ELF` 中的虚拟符号地址（Virtual Symbol Address），而非内存缓冲区内的地址。

这也意味着应用负责把扩展放置到预先定义的地址，LLEXT 核心无需在内部执行分配和复制。内存管理单元（Memory Management Unit，MMU）的权限调整同样由应用负责。

## 24.4\_relocate\_local

<a id="a3c1683b0baafc636af18df3808d08031"></a>
<a id="r_a3c1683b0baafc636af18df3808d08031"></a>

```c
bool llext_load_param::relocate_local
```

执行局部重定位（Local Relocation）。

## 24.5\_section\_detached

<a id="af3d61fa83c93361e4c5292b078d51a93"></a>
<a id="r_af3d61fa83c93361e4c5292b078d51a93"></a>

```c
bool(* llext_load_param::section_detached) (const elf_shdr_t *shdr)
```

扩展可以实现自定义 `ELF` 节，将其加载到特定内存区域，与类型兼容的其他节分离。

此可选回调检查是否应将某个节分离（Detach）。
