# 第16章\_扩展管理头文件

原文：[官方页面](https://docs.zephyrproject.org/latest/doxygen/html/llext_8h.html)。读取日期：2026-10-14；保存的 latest 页面及 HTML 摘要见[来源记录](../SOURCES.md)。

## 16.1\_概述

可链接加载扩展支持（Support for Linkable Loadable Extensions）。本文件描述在 Zephyr 中加载 LLEXT 并与之交互的 API。

```c
#include <zephyr/sys/slist.h>
#include <zephyr/llext/elf.h>
#include <zephyr/llext/symbol.h>
#include <zephyr/kernel.h>
#include <sys/types.h>
#include <stdbool.h>
#include <zephyr/syscalls/llext.h>
```

[查看源码浏览译页](P017_扩展管理头文件源码.md)。
