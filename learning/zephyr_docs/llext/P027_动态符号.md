# 第27章\_动态符号

原文：[官方页面](https://docs.zephyrproject.org/latest/doxygen/html/structllext__symbol.html)。读取日期：2026-10-14；保存的 latest 页面及 HTML 摘要见[来源记录](../SOURCES.md)。

## 27.1\_概述

符号（Symbol）是具名内存地址，可以是为链接而导出的具名函数或全局对象。这里的符号可修改，应来自扩展；根据内存放置位置，其位置可能需要更新。

```c
#include <zephyr/llext/symbol.h>
```
