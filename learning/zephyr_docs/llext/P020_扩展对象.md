# 第20章\_扩展对象

原文：[官方页面](https://docs.zephyrproject.org/latest/doxygen/html/structllext.html)。读取日期：2026-10-14；保存的 latest 页面及 HTML 摘要见[来源记录](../SOURCES.md)。

## 20.1\_概述

描述可链接加载扩展（Linkable Loadable Extension，LLEXT）的结构体。它保存已加载扩展的数据，由 [`llext_load`](P011_扩展管理API.md#ga0a4c3db30bc3ec7aa8a9b0e076af7157) 创建，由 [`llext_unload`](P011_扩展管理API.md#gad3df7ed4d436846504c0047166eb929e) 销毁。

```c
#include <zephyr/llext/llext.h>
```

<a id="a76cc3ef7989f2d4bfaeedadd05738de2"></a>


## 20.10\_sym\_tab

<a id="a4f67c792a963ac124f32b2d7880f9cdf"></a>

```c
struct llext_symtable llext::sym_tab
```

扩展中全部全局符号的表；在内部用于链接过程。

例如，扩展由多个文件构建且文件之间引用符号时，会使用此表完成它们之间的链接。
