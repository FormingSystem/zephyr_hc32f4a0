## 18.2\_arch\_elf\_relocate\_global()

<a id="acf5a8cd07260bd76f990530ad41453f0"></a>
<a id="r_acf5a8cd07260bd76f990530ad41453f0"></a>

```c
int arch_elf_relocate_global ( struct llext_loader * loader, struct llext * ext, const elf_rela_t * rel, const elf_sym_t * sym, uint8_t * rel_addr, const void * link_addr )
```

执行全局绑定重定位（Global Binding Relocation）的架构专用函数。

**参数（Parameters）**

| 名称／方向 | 说明 |
| --- | --- |
| `[in] loader` | 扩展加载器的数据与上下文。 |
| `[in] ext` | 要在其中调用函数的扩展。 |
| `[in] rel` | `ELF` 提供的重定位数据。 |
| `[in] sym` | 对应的符号表条目。 |
| `[in] rel_addr` | 执行重定位的位置地址。 |
| `[in] link_addr` | 基于表的重定位所使用的目标地址。 |

**返回（Returns）**：成功返回 0，否则返回负错误码。

## 18.4\_arch\_elf\_veneer\_init()

<a id="afcd1febfeb71243573c406872cd0adf6"></a>
<a id="r_afcd1febfeb71243573c406872cd0adf6"></a>

```c
int arch_elf_veneer_init ( struct llext_loader * ldr, struct llext * ext )
```

初始化跳转桥接表（Veneer Table）的架构专用函数。

在分配各区域之前调用一次，使架构能够在 `ldr`->sects[`LLEXT_MEM_VENEER`] 中填入跳板桩（Trampoline Stub）所需的大小。这些桩用于扩展超出原指令可达范围的分支的跳转范围。

**参数（Parameters）**

| 名称／方向 | 说明 |
| --- | --- |
| `[in] ldr` | 扩展加载器的数据与上下文。 |
| `[in] ext` | 正在链接的扩展。 |

**返回（Returns）**：成功返回 0，否则返回负错误码。
