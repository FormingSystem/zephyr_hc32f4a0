# 第25章\_扩展加载器上下文

原文：[官方页面](https://docs.zephyrproject.org/latest/doxygen/html/structllext__loader.html)。读取日期：2026-10-14；保存的 latest 页面及 HTML 摘要见[来源记录](../SOURCES.md)。

## 25.1\_概述

可链接加载扩展的加载器上下文（Loader Context）。LLEXT 子系统加载扩展期间，通过本对象访问 `ELF` 文件数据并缓存其内容。扩展加载完成后，不再需要此对象。

```c
#include <zephyr/llext/loader.h>
```

## 25.3\_peek

<a id="af5452f4b4f1099379d110c1bcd7773f6"></a>
<a id="r_af5452f4b4f1099379d110c1bcd7773f6"></a>

```c
void *(* llext_loader::peek) (struct llext_loader *ldr, size_t pos)
```

可选函数，用于直接查看 `ELF` 中某个绝对位置（Absolute Location）。

返回指向缓冲区指定偏移处的指针。

**参数（Parameters）**

| 名称／方向 | 说明 |
| --- | --- |
| `[in] ldr` | 加载器。 |
| `[in] pos` | 要取得指针的位置。 |

**返回（Returns）**：返回指向缓冲区内部的指针；操作不受支持或指针越界时返回 `NULL`。

> 译注：此处“绝对位置”是 `ELF` 数据流中的位置，不是主机文件系统的绝对目录。

## 25.5\_read

<a id="a29a16df55b72bc299b338036437f53e0"></a>
<a id="r_a29a16df55b72bc299b338036437f53e0"></a>

```c
int(* llext_loader::read) (struct llext_loader *ldr, void *out, size_t len)
```

从加载器读取（复制）数据的函数。

从加载器的当前位置复制 `len` 字节到 `buf`。

**参数（Parameters）**

| 名称／方向 | 说明 |
| --- | --- |
| `[in] ldr` | 加载器。 |
| `[in] out` | 输出位置。 |
| `[in] len` | 复制到输出位置的长度。 |

**返回（Returns）**：成功返回 0，否则返回负错误码。

> 译注：原文正文写 `buf`，声明及参数表实际使用 `out`；它们在这段说明中指同一个输出缓冲区。原参数方向标成 [in]，这里保留该标记，但该地址指向接收复制数据的位置。

## 25.6\_seek

<a id="a2376c3774af219972e164b0ee8a6bb6d"></a>
<a id="r_a2376c3774af219972e164b0ee8a6bb6d"></a>

```c
int(* llext_loader::seek) (struct llext_loader *ldr, size_t pos)
```

定位到流中新的绝对位置的函数。

把加载器当前位置改为给定的新绝对位置。

**参数（Parameters）**

| 名称／方向 | 说明 |
| --- | --- |
| `[in] ldr` | 加载器。 |
| `[in] pos` | 加载器要移动到的流内位置。 |

**返回（Returns）**：成功返回 0，否则返回负错误码。

> 译注：此处“绝对位置”是相对于数据流起点的偏移，不是作者机器上的目录。
