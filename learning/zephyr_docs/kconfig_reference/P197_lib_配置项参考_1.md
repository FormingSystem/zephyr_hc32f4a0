# 第197章\_`lib`配置项参考（1/3）

本章翻译官方 Kconfig 数据库中 `lib` 的 100 条定义记录。提示（Prompt）、帮助（Help）与菜单路径均已翻译；条件表达式、默认值和配置标识符保留原值。原页：[Kconfig Search](https://docs.zephyrproject.org/latest/kconfig.html)。来源数据库版本为 `main`，快照摘要与完整覆盖范围见[本册大纲](大纲.md)。

`main` 源码链接随上游变化；行号来自本次数据库快照，不能视为固定提交定位。无提示的配置项保留其不可直接由用户赋值的属性。原库中存在未收录定义的交叉引用，本章在对应位置明确标出。

## 197.1 `CONFIG_ARCMWDT_LIBC`

**提示（Prompt）**：ARC MWDT C 库（C library）

**说明（Help）**

ARC MWDT 工具链（toolchain）提供的 C 库。

**类型（Type）**：布尔值（Boolean），`bool`。

**依赖条件（Dependencies）**

```text
"zephyr" = "arcmwdt" && <choice CONFIG_LIBC_IMPLEMENTATION>
```

**主动选择（Selects）**

```text
CONFIG_STATIC_INIT_GNU
CONFIG_LIBC_ALLOW_LESS_THAN_64BIT_TIME
```

**定义位置（Location）**：[`lib/libc/Kconfig:135`](https://github.com/zephyrproject-rtos/zephyr/blob/main/lib/libc/Kconfig#L135)。

**菜单路径（Menu Path）**：顶层（Top） → C 库（C Library） → C 库实现（C Library Implementation）

**配置项引用（Symbol References）**：[`CONFIG_LIBC_IMPLEMENTATION`](P197_lib_配置项参考_1.md#CONFIG_LIBC_IMPLEMENTATION)、[`CONFIG_STATIC_INIT_GNU`](P002_kernel_配置项参考_2.md#CONFIG_STATIC_INIT_GNU)、[`CONFIG_LIBC_ALLOW_LESS_THAN_64BIT_TIME`](P197_lib_配置项参考_1.md#CONFIG_LIBC_ALLOW_LESS_THAN_64BIT_TIME)。

## 197.82 `CONFIG_LIBC_ALLOW_LESS_THAN_64BIT_TIME`

**提示（Prompt）**：不要求 time_t 至少为 64 位

**说明（Help）**

**类型（Type）**：布尔值（Boolean），`bool`。

**默认值（Defaults）**

```text
y if CONFIG_NATIVE_LIBC
```

**被选择（Selected by）**

```text
CONFIG_ARCMWDT_LIBC
```
