## 198.3 `CONFIG_NET_BUF_ALIGNMENT`

**提示（Prompt）**：网络缓冲区对齐限制（Network buffer alignment restriction）

**说明（Help）**

网络缓冲区的对齐限制（alignment restriction）。适用于具有 DMA 的某些硬件 IP：这些 IP 要求缓冲区按特定字节边界对齐，或需要处理缓存行限制（cache line restrictions）。默认值 `0` 表示按 `void` 指针大小对齐，其他值则强制网络缓冲区按指定字节数对齐。

**类型（Type）**：整数（Integer），`int`。

**依赖条件（Dependencies）**

```text

```

**默认值（Defaults）**

```text
0
```

**定义位置（Location）**：[`lib/net_buf/Kconfig:74`](https://github.com/zephyrproject-rtos/zephyr/blob/main/lib/net_buf/Kconfig#L74)。

## 198.4 `CONFIG_NET_BUF_HARDENING`

**提示（Prompt）**：网络缓冲区运行时完整性检查（runtime integrity checks）

**说明（Help）**

在修改缓冲区之前，对网络缓冲区的长度／指针字段执行始终启用的完整性检查（integrity checks），不受断言开关控制。如果缓冲区的 `len`／`data` 已损坏，导致不再落在其自身存储范围内，例如 `len` 回绕成很大的值，或 `data` 移出 `__buf..__buf+size`，则采用失败关闭（fail-closed）方式拒绝操作：修改操作返回 `NULL`，而不是越界读写。返回数值的操作返回 `0`，不返回值的操作不执行写入，因此调用者并非总能识别出操作已被拒绝。这会将原本的越界访问，尤其是尾部剩余空间下溢（tailroom-underflow）导致的 `net_buf_add()` 溢出，转为可控失败。它给 `net_buf_simple_add()`／`push()`／`pull()`／`remove()` 带来少量运行时开销，面向安全敏感的构建；如需保持快速路径（fast path）仅使用断言检查，应禁用此项。

**类型（Type）**：布尔值（Boolean），`bool`。

**依赖条件（Dependencies）**

```text
CONFIG_NET_BUF
```

**定义位置（Location）**：[`lib/net_buf/Kconfig:55`](https://github.com/zephyrproject-rtos/zephyr/blob/main/lib/net_buf/Kconfig#L55)。

**菜单路径（Menu Path）**：顶层（Top） → 附加库（Additional libraries） → 网络缓冲区（Network buffer）支持

**配置项引用（Symbol References）**：[`CONFIG_NET_BUF`](P198_lib_配置项参考_2.md#CONFIG_NET_BUF)。

## 198.8 `CONFIG_NET_BUF_WARN_ALLOC_INTERVAL`

**提示（Prompt）**：网络缓冲区分配警告间隔（allocation warnings interval）

**说明（Help）**

网络缓冲区分配警告的间隔，单位为秒。使用 `K_FOREVER` 分配却无法立即取得缓冲区时会生成警告，因为这可能导致死锁（deadlock）。开始等待分配时打印一次警告，之后按此间隔重复；获得缓冲区时打印阻塞持续时间。设为 `0` 会禁用周期性警告，仅保留首次和最后一次输出。

**类型（Type）**：整数（Integer），`int`。

**依赖条件（Dependencies）**

```text
CONFIG_NET_BUF_LOG && CONFIG_NET_BUF
```

**默认值（Defaults）**

```text
1
```

**取值范围（Ranges）**

```text
[0, 60]
```

**定义位置（Location）**：[`lib/net_buf/Kconfig:26`](https://github.com/zephyrproject-rtos/zephyr/blob/main/lib/net_buf/Kconfig#L26)。

**菜单路径（Menu Path）**：顶层（Top） → 附加库（Additional libraries） → 网络缓冲区（Network buffer）支持

## 198.10 `CONFIG_NEWLIB_LIBC_ALIGNED_HEAP_SIZE`

**提示（Prompt）**：Newlib 对齐堆大小（aligned heap size）

**说明（Help）**

如果启用了用户模式（user mode），MPU 硬件要求区域大小为 2 的幂并按自身大小对齐，且用户模式线程需要访问该堆，则必须设置此项，才能正确为堆定义 MPU 区域。若保持为 `0`，该区域会使用剩余系统 RAM，可能无法将其配置为一个 MPU 区域。

**类型（Type）**：整数（Integer），`int`。

**依赖条件（Dependencies）**

```text
CONFIG_MPU_REQUIRES_POWER_OF_TWO_ALIGNMENT && CONFIG_USERSPACE && CONFIG_NEWLIB_LIBC
```

**默认值（Defaults）**

```text
0
```

**定义位置（Location）**：[`lib/libc/newlib/Kconfig:34`](https://github.com/zephyrproject-rtos/zephyr/blob/main/lib/libc/newlib/Kconfig#L34)。

**菜单路径（Menu Path）**：顶层（Top） → C 库（C Library）

## 198.55 `CONFIG_RING_BUFFER`

## 198.97 `CONFIG_SYS_HEAP_ALLOC_LOOPS`

**说明（Help）**

`sys_heap` 分配器限制在最小内存块级别（smallest chunk level，可能无法满足所请求分配的级别）上的尝试次数，以维持常数时间性能。设为较大值时，可在严重碎片化（fragmentation）的情况下提高分配成功率，代价是可能进行耗时明显、呈线性时间的空闲链表搜索（free list search）。默认值为 3，可兼顾良好的统计特性——“多数”能够容纳的分配都会成功——并严格限制最长运行时间，使此堆适合在持锁或中断服务程序（ISR）上下文中使用。

**类型（Type）**：整数（Integer），`int`。

**默认值（Defaults）**

```text
3
```

**定义位置（Location）**：[`lib/heap/Kconfig:34`](https://github.com/zephyrproject-rtos/zephyr/blob/main/lib/heap/Kconfig#L34)。
