# 第136章\_`drivers/pinctrl`配置项参考

本章翻译官方 Kconfig 数据库中 `drivers/pinctrl` 的 96 条定义记录。提示（Prompt）、帮助（Help）与菜单路径均已翻译；条件表达式、默认值和配置标识符保留原值。原页：[Kconfig Search](https://docs.zephyrproject.org/latest/kconfig.html)。来源数据库版本为 `main`，快照摘要与完整覆盖范围见[本册大纲](大纲.md)。

`main` 源码链接随上游变化；行号来自本次数据库快照，不能视为固定提交定位。无提示的配置项保留其不可直接由用户赋值的属性。原库中存在未收录定义的交叉引用，本章在对应位置明确标出。

## 136.1 `CONFIG_MCUX_XBARA`

**提示（Prompt）**：MCUX XBARA 驱动

**说明（Help）**

启用 MCUX XBARA 驱动。

**类型（Type）**：布尔值（Boolean），`bool`。

**依赖条件（Dependencies）**

```text
DT_HAS_NXP_MCUX_XBAR_ENABLED && CONFIG_PINCTRL
```

**定义位置（Location）**：[`drivers/pinctrl/Kconfig.imx:27`](https://github.com/zephyrproject-rtos/zephyr/blob/main/drivers/pinctrl/Kconfig.imx#L27)。

**菜单路径（Menu Path）**：顶层（Top） → 设备驱动（Device Drivers） → 引脚控制器驱动（Pin Controller Drivers）

**配置项引用（Symbol References）**：[`CONFIG_PINCTRL`](P136_drivers_pinctrl_配置项参考.md#CONFIG_PINCTRL)。
