# Kconfig 配置项完整参考

本册翻译官方 [Kconfig Search](https://docs.zephyrproject.org/latest/kconfig.html) 动态页面使用的[配置项数据库](https://docs.zephyrproject.org/latest/_static/kconfig.json)，包括提示、帮助、类型、依赖、默认值、其他位置默认值、选择与弱选择关系、取值范围、选择项、源码位置及菜单路径。数据库含 22402 条定义记录、22234 个不同符号；同名的多处定义分别保留。

**本次固定快照的 22402/22402 条定义记录、437/437 章已全部翻译并核验。全站清单按一个官方动态页面计数，分册章节不重复增加官方页面数。** 本目录仅链接已完成正文的章节，不为未译项创建占位文章。详细覆盖和逐条核验依据见[覆盖记录](coverage.json)。

本册按源码所属模块分组，每章最多 100 条记录；单个符号可能有多处定义，不能按符号名称去重丢弃。表达式保留原始标识符和运算符，不能把 `select`、`imply` 或依赖条件改成建议配置值。未收录定义的原始引用会在正文注明，避免把搜索入口误作已有定义。源码位置使用仓库或模块相对路径；上游构建环境目录前缀已去除。默认值中的构建机展开路径也以相对形式表示，并逐字段注明以 Zephyr 源码根目录或 west 工作区顶层目录为起点；覆盖记录保留原始记录摘要和路径起点，实际配置仍由原构建系统解析。

来源数据库版本：`main`；大小：16069067 字节；SHA-256：`46a96b5fc940e9683496603b34713b071da682b05a7b9da9ae810968ed874b3a`。原始文件快照与已译 API 中的 Kconfig 引用采用同一份数据库。`latest` 与源码 `main` 会变化，本摘要标识实际翻译依据。
