## 5.1\_概述

为了模拟 nRF54LM20 片上系统（SoC），Zephyr 提供目标开发板 `nrf54lm20bsim/nrf54lm20a/cpuapp`。

它使用 [BabbleSim](https://BabbleSim.github.io) 模拟无线电活动，通过 [POSIX 架构](../native_reference/P002_POSIX架构.md#posix-arch)和[本机模拟器（Native Simulator）](https://github.com/BabbleSim/native_simulator/blob/main/docs/README.md)在开发系统上本机执行应用。这样既有本机代码的执行性能，也便于用本机工具调试，但同时继承[对应限制](../native_reference/P002_POSIX架构.md#posix-arch-limitations)。

与 `nrf54lm20dk` 目标一样，`nrf54lm20bsim/nrf54lm20a/cpuapp` 支持模拟 nRF54LM20 SoC 的应用核（Application Core）。

> 原文注意：与真实 nRF54LM20 器件不同，`nrf54lm20bsim` 的随机存取存储器（RAM）容量不受限制，代码也不占用电阻式随机存取存储器（Resistive RAM，RRAM）。

> 原文注意：此模拟目标尚不支持以 `cpuflpr` 核为目标。

此开发板包含下列 nRF54LM20 外设模型，并使用与 `nrf54lm20dk` 目标相同的驱动。

- 加速地址解析器（Accelerated Address Resolver，AAR）。
- AES CCM模式加密（AES CCM Mode Encryption）；CCM为计数器模式结合CBC-MAC的认证加密模式。
- 时钟控制（Clock Control，CLOCK）。
- 密码加速引擎（Crypto Accelerator Engine，CRACEN）。
- 分布式可编程外设互连（Distributed Programmable Peripheral Interconnect，DPPI）。
- AES电子密码本模式加密（AES Electronic Codebook Mode Encryption，ECB）。
- 事件生成单元（Event Generator Unit，EGU）。
- 工厂信息配置寄存器（Factory Information Configuration Registers，FICR）。
- 通用输入输出（General-purpose Input/Output，GPIO）及其任务与事件（GPIO Tasks and Events，GPIOTE）。
- 全局实时计数器（Global Real-time Counter，GRTC）。
- 可编程外设互连桥（PPI Bridge，PPIB）。
- 无线电（RADIO）。
- 电阻式RAM控制器（Resistive RAM Controller，RRAMC）。
- 温度传感器（Temperature Sensor，TEMP）。
- 定时器（TIMER）。
- 带EasyDMA直接存储器访问的通用异步收发器（UART with Easy DMA，UARTE）。
- 用户信息配置寄存器（User Information Configuration Registers，UICR）。

各外设建模到什么程度，见[硬件模型实现状态](https://github.com/BabbleSim/ext_nRF_hw_models/blob/main/docs/README_impl_status.md)。
