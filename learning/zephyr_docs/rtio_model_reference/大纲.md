# RTIO数据结构与事件标志参考大纲

本册完整翻译实时输入输出（Real-Time I/O，RTIO）的七个数据结构及四组标志、操作码和优先级官方页面。先看上下文如何连接提交队列（SQ）与完成队列（CQ），再追踪提交事件（SQE）、完成事件（CQE）和输入输出设备（IODEV），最后按操作需要查阅标志与优先级。

各页保留全部可见成员、声明、详细说明、宏值及原始交叉引用。源码跟踪译注与原文分开，说明对象池生命周期、联合体成员、缓冲区所有权及文档与本次实现的差异。来源摘要可追溯，本地链接为相对路径；没有加入作者机器的环境步骤。

函数的完整使用约定见[RTIO核心接口参考册](../rtio_core_reference/大纲.md)。本册不代替其他头文件或子主题的独立翻译状态，完整范围见[全站进度](../PROGRESS.md)。
