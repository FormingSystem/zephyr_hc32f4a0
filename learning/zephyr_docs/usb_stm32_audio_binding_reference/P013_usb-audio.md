# 第13章\_usb-audio

原文：[官方页面](https://docs.zephyrproject.org/latest/build/dts/api/bindings/usb/usb-audio.html)。读取日期：2026-10-16；来源摘要见[来源记录](../SOURCES.md)。

<a id="usb-audio"></a>
<a id="dtbinding-usb-audio"></a>
<a id="std-dtcompatible-usb-audio"></a>

兼容字符串（Compatible String）：`usb-audio`。厂商：[ 无厂商前缀 ](https://docs.zephyrproject.org/latest/build/dts/api/bindings.html#dt-no-vendor)。

采用此设备树绑定（Devicetree Binding）的开发板见[官方筛选目录](https://docs.zephyrproject.org/latest/boards/index.html#compatibles=usb-audio)。

<a id="description"></a>

USB音频设备（USB Audio Device）的公共字段。

<a id="properties"></a>

属性类型：`int` 为整数，`boolean` 为布尔属性，`string` 为字符串，`string-array` 为字符串数组，`array` 为数值数组，`compound` 为复合类型；`phandle` 为节点引用（Phandle），`phandles` 为节点引用列表，`phandle-array` 为节点引用与说明符单元数组。

## 13.1\_节点专用属性

这些属性不继承自基础绑定文件。

本页没有节点专用属性。

本页没有已弃用的节点专用属性。
