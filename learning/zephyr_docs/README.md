# Zephyr 官方文档中文翻译集

本集按 Zephyr 官方文档目录逐模块翻译，范围包括开发指南、内核、服务、构建、硬件、API 自动生成参考、全部开发板和示例，以及贡献、项目治理、安全与发布说明。**本次固定范围的 16336 个适用官方页面正文已全部翻译；16331 页完整完成，另 5 页仍缺 8 个原始图片文件，整套媒体交付尚未完成。** [缺失媒体及这五页的阅读入口](MISSING_MEDIA.md)逐项列出当前状态。 页面清单和本地导航不计作正文翻译；官方本身只有入口内容的页面按原页范围登记，不能代表子页面已完成。

## 阅读入口

- **[官方主线阅读](reading/README.md)**：入门、工具链、west、应用开发、构建、内核、硬件移植、驱动和服务指南。页尾主线导航只在指南之间前进。
- **[官方扩展参考](reference_library/README.md)**：已有芯片绑定、自动生成 API、开发板和示例译文，按需查阅。正文、原图与动图保留原位，已有链接继续有效。
- **[官方示例与演示目录](samples_overview/P001_官方示例与演示目录.md)**：按官方分类浏览示例简介并跳转到本地译文；当前清单中的 812 个示例类页面已译完，开发板与 API 正文也已译完，原图缺项单独跟踪。
- **[搜索全部官方页面](catalog.html)**：默认显示已译主线，可切换到扩展参考或完整范围。

建议使用我们的 [Typora Code](https://github.com/FormingSystem/typora_code) 阅读本集：正文中的 GIF 动图和图片链接预览都可播放原始动画；双击图片或使用“全屏查看”可放大查看。HTML 动画可通过正文提供的独立播放链接打开。请保留 Markdown 与相邻 `images/`、动画文件的相对位置，复制资料时一并带走这些文件。

项目环境和实验路线放在译文集之外的[项目实验补充](../zephyr_project_notes/README.md)。源码跟踪、实现对照和技术纠错仍保留在对应页面，仓库源码链接使用相对路径；它们明确标为译注，不混作官方原话。

源码跟踪以文件、符号和版本依据定位，不绑定作者的仓库位置。本地页面、源码、图片和动图均从所在文档解析相对路径；命令中的工程位置由读者实际工作区确定。官方文档讨论的绝对路径解析机制照实保留，它不等于要求写入作者机器的盘符、用户名或目录。

译注中的源码定位应交代文件、函数或配置符号及版本差异；只有依赖个人环境的操作路线才移到项目实验补充。命令先说明从哪个源码根或应用目录执行，再使用相对位置。若工具接口确实要求绝对路径，应从读者当前工作区动态解析，并说明变量的读取者与有效范围，不能填入作者的固定位置。在仓库根运行 `python learning/check_docs.py` 会检查本集及项目实验补充中的 Markdown 链接与 HTML 媒体引用，拒绝盘符、文件 URL 和根目录形式的本地链接。

正文已经覆盖本次官方全站清单，包括生成的 API、全部开发板和示例。现阶段剩余工作是取得缺失的原始媒体文件。[全站进度](PROGRESS.md)和 [inventory.json](inventory.json)继续登记完整范围；阅读分组不改变翻译完成数量。

## 来源和版本

入口为 [Zephyr 官方文档](https://docs.zephyrproject.org/latest/index.html)，原始请求页面为 [Introduction](https://docs.zephyrproject.org/latest/introduction/index.html)。2026-10-12 核对时，官方首页显示 `main` 文档版本 **4.5.0-rc1**；Introduction 页面显示生成日期 2026-10-11，来源更新日期 2026-09-07。

`latest` 会变化。本集以实际读取日期、页面 URL 和所读取 HTML 的 SHA-256 摘要记录翻译依据，见[来源记录](SOURCES.md)。网页上的 `main` 源码链接也会变化，不能冒充固定提交链接；本次没有得到官网构建对应的 Git 提交号。本仓库的参照源码也不能自动视为这批网页的同版本源码。

## 怎样阅读和使用命令

译文保留原意、命令、配置标识符和各系统分支；英文标题改为中文并增加本地阅读序号。补充解释、原文过时内容和明确修正均标为“译注”，不混作官方原话。专有名词首次承担解释作用时采用“中文名（English Full Name，缩写）”，在正文中说明用途；产品名、命令和源码标识符不杜撰英文全称。原文页面上的站点侧栏、搜索框和重复导航不属于正文，不逐项翻译。

文档位于仓库的 `learning/zephyr_docs`，本地文档和图片均使用相对链接，不绑定读者的盘符或用户名。正文原图保存到各模块的 `images/` 目录，保留原始格式与文件内容；动图保留全部帧，不转成静态截图。原文如有音视频，保留对应媒体文件及相对引用；阅读器是否支持其播放，不影响原文件交付。来源、摘要及引用页面见 [原图清单](official-images.json)。官方原文的 `zephyrproject` 是一套独立示例布局，**阅读译文不意味着需要重新初始化已有实验环境**。译文中的命令用于与官方说明对照，按自己的工作区位置和目标环境执行。

本批只做翻译和文档验证，没有安装工具、下载模块、更新工程源码、运行固件或烧录硬件。预期输出与实际执行记录分别标明，验证范围见 [VALIDATION.md](VALIDATION.md)。
