# I2C驱动头文件参考大纲

本册完整翻译I2C（集成电路互连总线，Inter-Integrated Circuit）驱动主头文件的参考页及源码浏览页，涵盖控制器（Controller）、目标设备（Target）、消息标志、同步和异步传输、实时I/O（RTIO）、设备定义与寄存器辅助操作。详细约定见[I2C公共API](../hardware/P305_I2C公共接口.md)，比特率常量见[绑定头文件参考](../dt_pwm_binding_reference/P005_I2C绑定常量头文件参考.md)。

参考页保留声明和摘要，源码页保留可见实现、注释、行号定位和符号提示。译注说明速率编码、STOP的修改路径、异步对象生存期、RTIO缓冲区引用、目标注册层级及统计范围；这些说明不替代具体驱动的硬件能力核对。原代码、许可证与中英文术语保留，仓库定位使用相对路径。完整范围见[全站进度](../PROGRESS.md)。
