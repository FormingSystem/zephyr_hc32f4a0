# 第1章\_示例与演示（Samples and Demos）

原文：[官方页面](https://docs.zephyrproject.org/latest/samples/index.html)。快照读取日期：2026-10-15；来源摘要见[来源记录](../SOURCES.md)。

Zephyr 提供丰富的示例与演示，展示内核及其子系统的功能。

这些示例力求简单易懂，可作为你自己项目的起点。

> 译注——目录与正文：本页保留官方分类及每个示例的简介，原网站的筛选控件属于界面功能；阅读本地 Markdown 时可用编辑器搜索查找条目。简介来自官方示例元数据，可能保留旧名称，例如 ICM42605 条目的标题写 MPU6050、VEML6031 简介写 VEML4040；这里保留这些差异，实际型号与执行条件请核对链接正文。所有本地链接相对定位，目录完成不替代正文完成或硬件验收。

欢迎为项目贡献新示例；如有意提交自己的示例，请阅读《示例定义与准则》（Sample Definition and Criteria）。 相关链接：[示例定义与准则（Sample Definition and Criteria）](../basic_samples/P062_示例定义与准则.md#definition-and-criteria)。

- [基本同步示例（Basic Synchronization）](../basic_samples/P029_基本同步示例.md#synchronization)：操作内核的基本同步原语。
