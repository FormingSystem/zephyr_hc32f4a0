## 概述（Overview）

RP2350B Plus W是基于Raspberry Pi RP2350B的基础开发板，可在单个Cortex-M33或Hazard3 RISC-V核上运行代码，并通过Raspberry Pi RM2模块提供Wi-Fi及Bluetooth连接。

<a id="hardware"></a>

## 硬件（Hardware）


- 双Cortex-M33或Hazard3处理器，最高150 MHz
- 520 KB SRAM及16 MB板载闪存
- Raspberry Pi RM2无线模块，2.4 GHz Wi-Fi及Bluetooth 5.2
- USB 1.1，支持设备及主机（Device / Host）模式
- 低功耗睡眠（Sleep）及休眠（Dormant）模式
- 通过USB大容量存储（Mass Storage）拖放文件编程
- 48个多功能GPIO，其中8个可用于ADC
- 2路SPI、2路I2C、2路UART，1个12位500 ksample/s ADC，含8通道，以及24路可控PWM
- 2个带4路闹钟的定时器，1个常开定时器（AON Timer）
- 温度传感器（Temperature Sensor）。
- 3个可编程I/O（PIO）模块，共12个状态机（State Machines），支持自定义外设
- [rp2350b_plus_w原理图](https://files.waveshare.com/wiki/RP2350B-Plus-W/RP2350B-Plus-W.pdf)

<a id="wi-fi-firmware-setup"></a>

### 设置Wi-Fi固件（Wi-Fi Firmware Setup）

构建前必须获取所需Wi-Fi二进制固件文件。

运行以下命令下载这些二进制文件：

```text
west blobs fetch hal_infineon
```

注意（Note）

建议在 `west update` 之后运行上述命令。

此命令从Infineon仓库下载所需固件文件。
