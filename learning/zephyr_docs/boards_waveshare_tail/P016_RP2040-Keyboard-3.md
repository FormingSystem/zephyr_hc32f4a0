## 概述（Overview）

<a id="id3"></a>

Waveshare三键快捷键盘开发板[注1](#id2)基于RP2040，三个按键默认对应CTRL、C、V。带两个USB Type-C连接器，塑料及金属外壳两个版本共用本板级定义。（[微雪三键快捷键盘开发板](https://www.waveshare.com/rp2040-keyboard-3.htm)）

<a id="hardware"></a>

## 硬件（Hardware）


- Raspberry Pi RP2040微控制器（Microcontroller），最高频率133 MHz
- 双ARM Cortex-M0+内核
- 264 kByte静态随机存储器（SRAM）
- 2 Mbyte QSPI闪存
- 3个用户按键
- 3个RGB LED，即NeoPixel，每个按键一个
- 两个USB Type-C连接器，一次只使用一个
- RESET及BOOT按键

RESET及BOOT位于板背面相对的两个长边；BOOT在带USB连接器的长边，RESET在另一长边。

<a id="default-zephyr-peripheral-mapping"></a>

### Zephyr默认外设映射（Default Peripheral Mapping）


- 左侧CTRL键：GPIO14
- 中间C键：GPIO13
- 右侧V键：GPIO12
- RGB LED：GPIO18

注意，开发板没有引出串口RX或TX引脚，默认使用USB输出终端信息。

### 烧录（Flashing）

运行LED[灯带（LED Strip）](../hardware/P191_LED灯带示例.md#led-strip)示例：

```text
# From the root of the zephyr repository
west build -b rp2040_keyboard_3 samples/drivers/led/led_strip/
west flash
```

还可尝试哲学家就餐、输入转储（Input Dump）及按键示例。（[哲学家就餐（Dining Philosophers）](../basic_samples/P030_哲学家就餐示例.md#dining-philosophers)；[输入事件转储（Input Dump）](../interaction/P014_输入事件转储示例.md#input-dump)；[按键（Button）](../basic_samples/P003_按钮输入.md#button)）

[Hello World](../getting_started/P005_HelloWorld示例.md#hello_world)等仅在启动瞬间输出文本的示例较难观察，因为连接新建USB控制台端点时，文本可能已经输出。

若要实现CTRL、C、V键盘功能，可修改[USB HID键盘](../usb/P051_HID键盘示例.md#usb-hid-keyboard)示例。先从[boards/waveshare/rp2040_keyboard_3/Kconfig.defconfig](https://github.com/zephyrproject-rtos/zephyr/blob/main/boards/waveshare/rp2040_keyboard_3/Kconfig.defconfig)删除source "boards/common/usb/Kconfig.cdc_acm_serial.defconfig"行，再按以下内容修改[samples/subsys/usb/hid-keyboard/src/main.c](https://github.com/zephyrproject-rtos/zephyr/blob/main/samples/subsys/usb/hid-keyboard/src/main.c)。

将以下内容（Change）：

```text
case INPUT_KEY_0:
    if (kb_evt.value) {
        report[KB_KEY_CODE1] = HID_KEY_NUMLOCK;
    } else {
        report[KB_KEY_CODE1] = 0;
    }

    break;
case INPUT_KEY_1:
    if (kb_evt.value) {
        report[KB_KEY_CODE2] = HID_KEY_CAPSLOCK;
    } else {
        report[KB_KEY_CODE2] = 0;
    }

    break;
case INPUT_KEY_2:
    if (kb_evt.value) {
        report[KB_KEY_CODE3] = HID_KEY_SCROLLLOCK;
    } else {
        report[KB_KEY_CODE3] = 0;
    }

    break;
```

改为（To）：

```text
case INPUT_KEY_LEFTCTRL:
    if (kb_evt.value) {
        report[KB_MOD_KEY] = HID_KBD_MODIFIER_LEFT_CTRL;
    } else {
        report[KB_MOD_KEY] = 0;
    }

    break;
case INPUT_KEY_C:
    if (kb_evt.value) {
        report[KB_KEY_CODE1] = HID_KEY_C;
    } else {
        report[KB_KEY_CODE1] = 0;
    }

    break;
case INPUT_KEY_V:
    if (kb_evt.value) {
        report[KB_KEY_CODE1] = HID_KEY_V;
    } else {
        report[KB_KEY_CODE1] = 0;
    }

    break;
```
