## 概述（Overview）

RP2350-Zero是基于Raspberry Pi RP2350的低成本、高性能类Pico开发板。

<a id="hardware"></a>

## 硬件（Hardware）


- RP2350A微控制器，由英国Raspberry Pi设计
- 采用双核双架构设计：双核Arm Cortex-M33及双核Hazard3 RISC-V，可选架构，灵活时钟最高150 MHz
- 520 KB SRAM及4 MB板载闪存
- 采用USB Type-C连接器
- 邮票孔模块可直接焊接到载板
- USB 1.1，支持设备及主机（Device / Host）模式
- 低功耗睡眠（Sleep）及休眠（Dormant）模式
- 通过USB大容量存储（Mass Storage）拖放文件编程
- 29路多功能GPIO，其中20路从边缘引出，其余通过焊点引出
- 2路SPI、2路I2C、2路UART、4路12位ADC及24路可控PWM
- 片上精确时钟及定时器外设
- 温度传感器（Temperature Sensor）。
- 片上加速浮点运算库
- 12个PIO状态机，用于自定义外设

### 引脚映射（Pin Mapping）

RP2350外设可路由到不同板上引脚，可通过DTS修改；各外设可用路由见数据手册。

硬件详情见[RP2350-Zero微雪Wiki](https://www.waveshare.com/wiki/RP2350-Zero)。

<a id="default-zephyr-peripheral-mapping"></a>

#### Zephyr 默认外设映射（Peripheral Mapping）：


- `UART0_TX : P0`
- `UART0_RX : P1`
- I2C0串行数据（SDA）：P4
- I2C0串行时钟（SCL）：P5
- I2C1串行数据（SDA）：P6
- I2C1串行时钟（SCL）：P7
- ADC通道0（ADC_CH0）：P26
- ADC通道1（ADC_CH1）：P27
- ADC通道2（ADC_CH2）：P28
- ADC_CH3：P29

<a id="flashing"></a>

### 烧录（Flashing）

<a id="using-uf2"></a>

#### 使用UF2（Using UF2）

以下示例构建用于驱动板载RGB LED的程序。

```text
west build -b rp2350_zero/rp2350a/m33_0 samples/drivers/led/led_strip
```

RP2350-Zero可使用UF2文件烧录，例如通过west。按住BOOT连接USB，主机会识别为大容量存储设备；已接USB时也可按住BOOT，按下再松开RESET，最后松开BOOT。随后运行以下命令烧录：

```text
west flash
```

也可找到build/zephyr/zephyr.uf2，在进入UF2烧录模式后直接拖入设备。
