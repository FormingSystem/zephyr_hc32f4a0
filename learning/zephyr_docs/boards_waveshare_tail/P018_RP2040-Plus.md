## 概述（Overview）

RP2040-Plus是基于Raspberry Pi RP2040的低成本高性能类Pico开发板，带电池充电器。

<a id="hardware"></a>

## 硬件（Hardware）


- 双核Arm Cortex-M0+处理器，最高运行频率133 MHz
- 264 KB片上静态随机存储器（SRAM）
- 4 MB／16 MB板载QSPI闪存，支持就地执行（XIP）
- 26个GPIO
- 3路模拟输入（Analog Inputs）
- 2个通用异步收发器外设（UART Peripherals）
- 2个串行外设接口控制器（SPI Controllers）
- 2个I2C控制器
- 16个脉宽调制（PWM）通道
- USB 1.1控制器，支持主机／设备模式（Host / Device）
- 8个可编程输入输出（PIO / Programmable I/O），用于自定义外设
- 板载LED（On-board LED）
- 1个看门狗定时器外设（Watchdog Timer Peripheral）
- 板载电池充电器

<a id="flashing"></a>

### 烧录（Flashing）

<a id="using-uf2"></a>

#### 使用UF2（Using UF2）

下面给出驱动内置LED的示例构建方法。

```text
west build -b rp2040_plus samples/basic/blinky
```

RP2040-Plus必须使用UF2文件烧录，可使用Zephyr元工具west。按住BOOT连接USB，主机会识别为大容量存储设备。原文另一种顺序为：已接USB时按住RESET，按下再松开BOOT，然后松开RESET；此按键顺序按原文保留。随后运行以下命令烧录：

```text
west flash
```

也可在进入UF2模式后，将生成的`build/zephyr/zephyr.uf2`拖放到该设备。
