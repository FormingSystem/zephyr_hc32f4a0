## 概述（Overview）

<a id="id3"></a>

Waveshare RP2040-GEEK开发板[注1](#id2)基于Raspberry Pi RP2040，带USB-A插头、彩色屏幕、MicroSD卡槽及多个扩展接口。（[微雪RP2040-GEEK开发板](https://www.waveshare.com/rp2040-geek.htm)）

<a id="hardware"></a>

## 硬件（Hardware）


- Raspberry Pi RP2040微控制器（Microcontroller），最高频率133 MHz
- 双ARM Cortex-M0+内核
- 264 kByte静态随机存储器（SRAM）
- 4 MB QSPI闪存
- USB Type-A接口
- BOOT按键
- 1.14英寸彩色LCD，135×240像素
- microSD卡槽（Card Slot）
- 4引脚I2C接口，兼容Qwiic／Stemma QT；原文拼作Quiic
- 3引脚UART接口
- 3引脚GPIO接口

<a id="default-zephyr-peripheral-mapping"></a>

### Zephyr默认外设映射（Default Peripheral Mapping）


- UART连接器GP4：UART1 TX，GPIO4
- UART连接器GP5：UART1 RX，GPIO5
- DEBUG连接器GP2：GPIO2
- DEBUG连接器GP3：GPIO3
- I2C/ADC连接器GP28：I2C0 SDA，GPIO28
- I2C/ADC连接器GP29：I2C0 SCL，GPIO29
- MicroSD时钟SCK：SPI0 SCK，GPIO18
- MicroSD命令CMD：SPI0 MOSI，GPIO19
- MicroSD数据输出DO：SPI0 MISO，GPIO20
- MicroSD D1：GPIO21
- MicroSD D2：GPIO22
- MicroSD D3／片选CS：GPIO23
- LCD数据／命令DC：GPIO8
- LCD SPI1片选CS：GPIO9
- LCD SPI1时钟SCK：GPIO10
- LCD SPI1 MOSI：GPIO11
- LCD复位RST：GPIO12
- LCD背光BL：GPIO25

此板设计为经USB-A连接主机使用，因此默认通过USB输出终端信息。

此板未引出SWDIO及SWCLK，必须经USB编程。按住BOOT连接主机后，设备显示为USB大容量存储单元。构建生成build/zephyr/zephyr.uf2，将其拖入该存储单元即可重新编程。

RP2040板卡编程详情见[Raspberry Pi Pico](../boards_rak_raspberry_raytac/P012_Raspberry_Pi_Pico.md#rpi_pico)，尤其是“编程与调试”一节。（[烧录与调试（Programming and Debugging）](../boards_rak_raspberry_raytac/P012_Raspberry_Pi_Pico.md#rpi-pico-programming-and-debugging)）

<a id="flashing"></a>

### 烧录（Flashing）

运行[哲学家就餐（Dining Philosophers）](../basic_samples/P030_哲学家就餐示例.md#dining-philosophers)示例，确认USB控制台输出：

```text
# From the root of the zephyr repository
west build -b rp2040_geek samples/philosophers/
west flash
```

还可尝试文件系统操作、显示、LVGL基础及UART透传示例。（[文件系统操作（File System Manipulation）](../storage/P084_文件系统操作示例.md#fs)；[显示（Display）](../hardware/P171_显示驱动示例.md#display)；[LVGL基础示例（Basic Sample）](../hardware/P183_LVGL基础示例.md#lvgl)；[UART透传（Passthrough）](../hardware/P352_UART透传示例.md#uart-passthrough)）

[Hello World](../getting_started/P005_HelloWorld示例.md#hello_world)等仅在启动瞬间输出文本的示例较难观察，因为连接新建USB控制台端点时，文本可能已经输出。

可通过I2C连接器方便地接入传感器扩展板，例如adafruit_lis3dh。运行通用三轴加速度计轮询示例：（[通用三轴加速度计轮询（Generic 3-Axis Accelerometer Polling）](../sensors/P009_三轴加速度计轮询示例.md#accel_polling)）

```text
# From the root of the zephyr repository
west build -b rp2040_geek --shield adafruit_lis3dh samples/sensor/accel_polling/
west flash
```

使用DEBUG连接器上的GPIO：

```text
# From the root of the zephyr repository
west build -b rp2040_geek samples/sensor/sensor_shell -- -DCONFIG_GPIO=y -DCONFIG_GPIO_SHELL=y
west flash
```

然后在设备控制台中执行：

```text
uart:~$ gpio conf gpio0 2 o
uart:~$ gpio set gpio0 2 1
```
