# 蓝牙低功耗音频数据结构参考大纲

本册完整翻译音频输入控制服务（Audio Input Control Service，AICS）、音频流控制服务（Audio Stream Control Service，ASCS）、音频编解码器（Audio Codec）和基本音频配置文件（Basic Audio Profile，BAP）的42份官方数据结构参考。范围包括广播源、广播接收端、广播助手、扫描委托端、单播客户端与服务器、音频流和服务质量（QoS）配置。

各页保留完整成员声明、回调语义、参数范围、微秒与毫秒等原始单位，以及原始锚点和交叉引用。首选QoS值与强制上下限分别翻译，广播同步和单播组生命周期的约束均按原文保留。尚未翻译的其他官方页面仍保留在全站待译清单中。
