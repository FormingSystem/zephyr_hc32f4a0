# 第1章\_测试入口

原文：[Testing](https://docs.zephyrproject.org/latest/develop/test/index.html)。读取日期：2026-10-12，`latest`。

官方测试分类包括下列文档：

1. [Ztest测试框架](P002_Ztest测试框架.md)：集成测试、单元测试、夹具、参数化、压力测试和结果处理。
2. [基准测试框架](P004_基准测试框架.md)：周期测量、定时与手动测量、统计及输出。
3. [生成测试覆盖率报告](P003_测试覆盖率.md)：模拟器、主机、Twister 和逐用例覆盖率。
4. [BabbleSim](https://docs.zephyrproject.org/latest/develop/test/bsim.html)：官方仿真测试文档。
5. [持续集成测试计划选择器（CI Test Plan Selector，test_plan_v2）](https://docs.zephyrproject.org/latest/develop/test/ci_test_plan.html)：为**持续集成（Continuous Integration，CI）**选择测试计划。

> 译注：本地章节按“测试框架→覆盖率→性能测量”排列；尚无中文正文的项目保留官方入口，分类页不计作其子页已译完。
