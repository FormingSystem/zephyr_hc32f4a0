原文：[校验器/爬虫辅助页（Validator / crawler helper）](https://docs.zephyrproject.org/latest/doxygen/html/doxygen_crawl.html)。读取日期：2026-10-17；来源摘要见[来源记录](../SOURCES.md)。

## 1.1\_校验器与爬虫辅助页（Validator / crawler helper）

> 译注：官方页面仅有上述标题和 79138 个没有显示文字的链接，用于校验器或爬虫发现页面与锚点；没有接口讲解、参数说明、图片或动画。这里翻译标题，并在[完整原始链接清单](official-crawler-links.json)中保存全部链接及其原始顺序、重复项和锚点。该清单对应本页本身，不代表其中链接到的 API 页面均已完成翻译。

## 1.2\_完整链接清单的读取方式

[完整原始链接清单（JSON）](official-crawler-links.json)中的 `original_relative_hrefs` 按官方原页的顺序逐项保存 `href` 属性，`link_base_url` 是这些相对链接所对应的官方目录地址。将某项链接相对于该目录解析，即可得到原始官方页面或锚点地址。`source_sha256` 用于核对本次读取的原始 HTML，`link_count` 为全部链接数量。

平常查阅接口可从[中文 API 主题目录](../api_topic_index_reference/P001_API主题完整目录.md)进入；各正文的完成状态见[全站覆盖清单](../catalog.html)。
