# 系统控制器参考大纲

系统控制器（System Controller，Syscon）接口用于访问一片系统控制寄存器。本册保留官方公共API、驱动回调、操作结构、头文件参考及可见源码，说明怎样取得区域基地址和大小、读写寄存器以及更新选定位。

源码译注区分区域大小与访问宽度、字节偏移与寄存器序号，说明位更新的驱动锁范围、掩码运算及带副作用寄存器的边界。可选回调未实现时返回-ENOSYS，不能由声明推断具体板卡已经支持。所有本地源码链接使用相对位置，完整翻译范围见[全站进度](../PROGRESS.md)。
