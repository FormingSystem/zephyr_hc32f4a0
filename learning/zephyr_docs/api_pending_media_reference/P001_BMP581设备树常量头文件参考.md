### 无限冲激响应滤波器（IIR Filter）选项

设备树属性（Devicetree Property）`press-iir` 和 `temp-iir` 的取值。

温度和压力 IIR 滤波器系数（IIR Filter Coefficient）的有效取值。


$$
data_n = \frac{data_{n-1} \times filtercoefficient + data_{in}}{filtercoefficient + 1}
$$


其中（Where）：

- $data_n$ 为当前滤波输出（Filtered Output）。
- $data_{n-1}$ 为上一次滤波输出（Previous Filtered Output）。
- $data_{in}$ 为当前输入采样值（Input Sample）。
- $filtercoefficient$ 为下列滤波器系数（Filter Coefficient）之一。

系数（Coefficient）越大，滤波程度越强，输出越平滑，但响应时间（Response Time）也越长。

<a id="r_gaea9da580d5947d8ebf10f25747f1a2ba"></a>

```c
#define BMP581_DT_IIR_FILTER_BYPASS 0x00
```

相关声明：[BMP581_DT_IIR_FILTER_BYPASS](P002_BMP581扩展传感器接口.md#gaea9da580d5947d8ebf10f25747f1a2ba)。
