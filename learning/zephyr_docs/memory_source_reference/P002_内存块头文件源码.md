## 2.2\_可见注释译文（Comments）

1. 版权声明：Copyright (c) 2021 Intel Corporation；许可证标识为 Apache-2.0，原法律文本完整保留。

2. 内存块总数（Total Number of Blocks）。

3. 块大小对应的位移量（Block Size Shift）。

4. 当前正在使用的块数（Used Blocks）。

5. 曾经同时使用的最大块数（Maximum Used Blocks）。

6. 内存块后备缓冲区（Memory Block Buffer）。

7. 记录已分配块的位图（Allocation Bitmap）。

8. 保护内存块内部状态访问的自旋锁（Spinlock）。

9. 该分配器组中的成员数量（Allocator Count）。

10. 头文件包含保护（Include Guard）的结束标记：ZEPHYR_INCLUDE_SYS_MEM_BLOCKS_H_。
