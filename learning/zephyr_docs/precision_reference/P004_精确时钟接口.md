### `precision_clock_adjust_phase()`

```c
int precision_clock_adjust_phase ( const struct precision_clock * precision_clk, precision_time_t phase_ns )
```

```c
#include <zephyr/precision_timing/precision_clock.h>
```

对精确时钟应用相位调整（Phase Adjustment）。

**参数（Parameters）**

| 名称／方向 | 说明 |
| --- | --- |
| `precision_clk` | 待调整的时钟。 |
| `phase_ns` | 有符号相位调整量，以纳秒为单位。 |

**返回值（Return Values）**

| 名称／方向 | 说明 |
| --- | --- |
| `0` | 操作成功。 |

返回（Returns）：失败时返回适配器特有的负错误码。

<a id="ga9a4aa81cfaf51edfadff28265287ee40"></a>

### `precision_clock_adjust_rate()`

```c
int precision_clock_adjust_rate ( const struct precision_clock * precision_clk, int64_t scaled_ppm )
```

```c
#include <zephyr/precision_timing/precision_clock.h>
```

设置精确时钟的速率偏移（Rate Offset）。

**参数（Parameters）**

| 名称／方向 | 说明 |
| --- | --- |
| `precision_clk` | 待调整的时钟。 |
| `scaled_ppm` | 相对于标称频率（Nominal Frequency）的有符号频率偏移，以带有 16 位二进制小数字段的百万分比表示。例如，`PRECISION_CLOCK_SCALED_PPM_ONE` 表示 1 ppm。 |

**返回值（Return Values）**

| 名称／方向 | 说明 |
| --- | --- |
| `0` | 操作成功。 |

返回（Returns）：失败时返回适配器特有的负错误码。

<a id="ga89a3c98bc0453357674a181e9bcaad3e"></a>

### `precision_clock_ppb_to_scaled_ppm()`

```c
int precision_clock_ppb_to_scaled_ppm ( double ppb, int64_t * scaled_ppm )
```

```c
#include <zephyr/precision_timing/precision_clock.h>
```

将十亿分比（Parts Per Billion，ppb）转换为缩放百万分比（Scaled Parts Per Million）。

**参数（Parameters）**

| 名称／方向 | 说明 |
| --- | --- |
| `ppb` | 相对于标称频率的有符号频率偏移，以十亿分比（ppb）表示。 |
| `scaled_ppm` | 用于保存有符号缩放百万分比值的目标位置。 |

**返回值（Return Values）**

| 名称／方向 | 说明 |
| --- | --- |
| `0` | 操作成功。 |
| `-EINVAL` | `scaled_ppm` 为空指针。 |
| `-ERANGE` | `ppb` 不是有限值，或结果超出可表示范围。 |

## 4.6\_源码定位与版本边界

官方源码定位：[precision_clock.h](https://github.com/zephyrproject-rtos/zephyr/blob/main/include/zephyr/precision_timing/precision_clock.h)、[precision_clock.c](https://github.com/zephyrproject-rtos/zephyr/blob/main/subsys/precision_timing/precision_clock.c)。摘要见[来源记录](../SOURCES.md)。本批对应的官方模块未出现在当前仓库源码中，故使用官方来源链接；译文内部导航均为相对链接。

> 译注——源码核对：以下源码跟踪译注依据来源记录中保存摘要的官方main文件，与官方正文分开。精确计时（Precision Timing，也译作精密计时）为协议提供通用部件，本身不负责选择主时钟、拒绝样本、锁定检测或失步恢复；本批核对不表示本仓库已集成该模块。

> 译注——源码核对：precision_clock保存api操作表与data上下文指针。read、set、adjust_phase、adjust_rate公共函数直接分派到对应回调，本次实现没有对空时钟、空操作表或缺失回调追加运行时检查；官方要求全部操作有效。不要把返回int理解为任意无效指针都会安全返回错误。

> 译注——源码核对：速率调整采用带16位二进制小数的百万分比（Scaled ppm），1 ppm对应65536；0表示相对标称频率零偏移，不表示频率为零。ppb转换公式为ppb × 65536 / 1000，例如1000 ppb对应65536，1 ppb的结果经向零截断后为65。

> 译注——源码核对：ppb_to_scaled_ppm检查输出指针、NaN／无穷大与结果范围，再把double转换成int64_t；不是四舍五入，也不是限幅。失败不写输出，本次实现的上界使用小于2^63的检查，避免浮点表示边界导致无效整数转换。

> 译注——源码核对：设置绝对时间（Set）、应用相位偏移（Adjust Phase）和改变运行速率（Adjust Rate）是不同操作。公共层不添加锁、能力协商、同步状态或硬件限制检查，适配器负责其操作语义，调用方负责实例生命周期及并发访问安排。

本次验证范围为文档与源码对照，未构建固件、配置实板引脚或操作硬件。
