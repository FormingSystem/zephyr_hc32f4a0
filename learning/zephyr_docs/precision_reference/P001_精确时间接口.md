<a id="gad8df34edd3d28fc61a70c3889c4d10ba"></a>

### `precision_time_add()`

```c
int precision_time_add ( precision_time_t a, precision_time_t b, precision_time_t * result )
```

```c
#include <zephyr/precision_timing/precision_time.h>
```

将两个精确时间值相加，并检查溢出（Overflow）。

**参数（Parameters）**

| 名称／方向 | 说明 |
| --- | --- |
| `a` | 第一个操作数，以纳秒为单位。 |
| `b` | 第二个操作数，以纳秒为单位。 |
| `result` | 用于保存和的目标位置。 |

**返回值（Return Values）**

| 名称／方向 | 说明 |
| --- | --- |
| `0` | 操作成功。 |
| `-EINVAL` | `result` 为空指针。 |
| `-ERANGE` | 和超出可表示范围。 |

<a id="gafa71ea001cb63ebf567a356c055ddb07"></a>

### `precision_time_sub()`

```c
int precision_time_sub ( precision_time_t a, precision_time_t b, precision_time_t * result )
```

```c
#include <zephyr/precision_timing/precision_time.h>
```

将两个精确时间值相减，并检查溢出。

**参数（Parameters）**

| 名称／方向 | 说明 |
| --- | --- |
| `a` | 被减数（Minuend），以纳秒为单位。 |
| `b` | 减数（Subtrahend），以纳秒为单位。 |
| `result` | 用于保存差的目标位置。 |

**返回值（Return Values）**

| 名称／方向 | 说明 |
| --- | --- |
| `0` | 操作成功。 |
| `-EINVAL` | `result` 为空指针。 |
| `-ERANGE` | 差超出可表示范围。 |

## 1.5\_源码定位与版本边界

官方源码定位：[precision_time.h](https://github.com/zephyrproject-rtos/zephyr/blob/main/include/zephyr/precision_timing/precision_time.h)、[precision_time.c](https://github.com/zephyrproject-rtos/zephyr/blob/main/subsys/precision_timing/precision_time.c)。摘要见[来源记录](../SOURCES.md)。本批对应的官方模块未出现在当前仓库源码中，故使用官方来源链接；译文内部导航均为相对链接。

> 译注——源码核对：以下源码跟踪译注依据来源记录中保存摘要的官方main文件，与官方正文分开。精确计时（Precision Timing，也译作精密计时）为协议提供通用部件，本身不负责选择主时钟、拒绝样本、锁定检测或失步恢复；本批核对不表示本仓库已集成该模块。

> 译注——源码核对：precision_time_t是有符号int64_t纳秒值，可表示负偏差；它不携带时间域（Time Domain）、纪元（Epoch）或时间尺度标记。两个数能够相加并不证明它们来自可直接比较的时钟，应由协议或调用者确定语义。

> 译注——源码核对：add/sub先检查result是否为空，再用边界比较避免执行会溢出的有符号运算；失败返回-EINVAL或-ERANGE，本次实现不写入结果。它们不是饱和运算（Saturating Arithmetic），不会把超范围结果截到最大／最小值。输出地址除非为空，仍须指向有效可写存储。

本次验证范围为文档与源码对照，未构建固件、配置实板引脚或操作硬件。
