# 精确计时接口与源码大纲

本册完整翻译精确时间（Precision Time）、精确时钟（Precision Clock）、PTP时钟适配器（PTP Clock Adapter）和比例积分控制器（Proportional-Integral Controller）的四组接口、四份头文件参考与四份源码浏览页，以及时钟、操作表、PTP适配器和PI状态四个结构体，共十六份官方页面。

精确计时（Precision Timing，也译作精密计时）提供时间运算、时钟操作和反馈计算部件；协议仍需决定时钟选择、样本处理、锁定与恢复策略。阅读总览见[精密计时指南](../kernel/P036_精密计时.md)和[官方分类译文](../timing_reference/P010_精确计时接口.md)。

本册保留全部接口说明、参数与返回值。源码页保留可见代码、法律声明、原始行号锚点及符号提示，英文注释另列中文对照。源码跟踪译注说明溢出检查、缩放频率单位、适配器生命周期及PI状态边界，与官方正文分开。

本批官方模块尚未出现在当前仓库源码中，来源链接直接指向官方仓库，避免把不存在的文件写成本地依赖；译文之间使用相对链接，不依赖作者机器的仓库位置。完整范围见[全站进度](../PROGRESS.md)。
