# 第3章\_输入子系统

原文：[Input](https://docs.zephyrproject.org/latest/services/input/index.html)。读取日期：2026-10-12，`latest`。

**输入子系统（Input Subsystem）**提供一组**应用程序编程接口（Application Programming Interface，API）**，将输入设备产生的事件分派给应用程序。

## 3.1\_输入事件

子系统以 [`input_event` 结构](https://docs.zephyrproject.org/latest/doxygen/html/structinput__event.html)为核心。一个**输入事件（Input Event）**表示某个独立输入量的变化，例如一个按钮的状态变化，或一个坐标轴的移动。

`input_event` 描述具体事件，并包含一个**同步位（Synchronization Bit，字段名 sync）**，表示设备已达到稳定状态。例如，多轴设备已经上报了各坐标轴对应的事件，就可以用此位标识本次状态更新已完整。

## 3.2\_输入设备

输入设备可以直接调用 `input_report()` 或相关函数上报事件。例如，按钮等只有开、关状态的输入量使用 `input_report_key()`。

复杂设备可以组合多个事件，并在输出稳定时设置 `sync` 位。

`input_report*` 系列函数接收一个设备指针，标识事件由哪个设备产生。订阅者可利用它只接收特定设备的事件。若事件没有对应的实际设备，可以传入 `NULL`；此时只有没有设置设备过滤条件的订阅者才会收到该事件。

## 3.3\_应用接口

应用通过 `INPUT_CALLBACK_DEFINE` 宏注册**回调函数（Callback）**。指定设备时，回调只接收该设备的事件；未指定时，接收系统中的全部事件。子系统仅支持按设备过滤；更复杂的过滤逻辑须由回调自身实现。

子系统根据 `CONFIG_INPUT_MODE` 配置项，以同步方式或事件队列方式运行。使用输入线程时，所有事件先加入队列，再由共用输入线程处理；不使用输入线程时，回调直接在输入驱动的执行上下文中调用。

同步模式既适用于希望减少资源占用的简单应用，也适用于已有事件模型的复杂应用：这时回调仅作为一层包装，把事件转发到应用自己的事件系统。

> 译注：“同步”描述回调如何执行；前一节 `sync` 位则描述一组输入状态是否已报告完整，二者不是同一个概念。回调的阻塞限制还取决于实际驱动调用上下文，不能仅凭启用了输入子系统就假定回调总在线程中执行。

## 3.4\_HID编码映射

输入设备的常见用途之一，是生成**人机接口设备报告（Human Interface Device Report，HID Report）**。为此，`input_to_hid_code()` 与 `input_to_hid_modifier()` 可将输入编码分别映射为 HID 编码和修饰键位。

> 译注：修饰键（Modifier）是 Shift、Ctrl 等改变其他按键含义的按键。输入编码是本子系统的事件标识，HID 编码则属于向主机报告输入的协议表示，不能因数值相似就混用。

## 3.5\_通用驱动

下面保留设备树兼容字符串，并说明每类驱动的用途。

| 驱动或兼容字符串 | 用途 |
| --- | --- |
| [adc-keys](../input_adc_touch_matrix_binding_reference/P002_adc-keys.md#std-dtcompatible-adc-keys) | 连接到电阻梯形网络的按钮；通过模数转换读数区分按键 |
| [analog-axis](../input_adc_touch_matrix_binding_reference/P004_analog-axis.md#std-dtcompatible-analog-axis) | 接到**模数转换器（Analog-to-Digital Converter，ADC）**输入的绝对位置设备，例如摇杆、滑杆 |
| [gpio-kbd-matrix](../input_adc_touch_matrix_binding_reference/P018_gpio-kbd-matrix.md#std-dtcompatible-gpio-kbd-matrix) | 使用**通用输入输出（General-Purpose Input/Output，GPIO）**连接的键盘矩阵 |
| [gpio-keys](https://docs.zephyrproject.org/latest/build/dts/api/bindings/input/gpio-keys.html#std-dtcompatible-gpio-keys) | 直接接到 GPIO 的开关，包含按钮去抖处理 |
| [gpio-qdec](../input_adc_touch_matrix_binding_reference/P019_gpio-qdec.md#std-dtcompatible-gpio-qdec) | 使用 GPIO 连接的**正交编码器（Quadrature Encoder）** |
| [input-keymap](../input_keyboard_optical_ctsu_binding_reference/P002_input-keymap.md#std-dtcompatible-input-keymap) | 将键盘矩阵的行、列、触碰事件映射为按键事件 |
| [zephyr,input-longpress](../input_touch_lvgl_gesture_binding_reference/P015_zephyr_input-longpress.md#std-dtcompatible-zephyr-input-longpress) | 监听按键事件，输出短按与长按事件 |
| [zephyr,input-double-tap](../input_touch_lvgl_gesture_binding_reference/P014_zephyr_input-double-tap.md#std-dtcompatible-zephyr-input-double-tap) | 监听按键事件，输出双击事件，也可选择输出单击事件 |
| [zephyr,lvgl-button-input](../input_touch_lvgl_gesture_binding_reference/P017_zephyr_lvgl-button-input.md#std-dtcompatible-zephyr-lvgl-button-input) | 将输入事件转换为 LVGL 按钮输入 |
| [zephyr,lvgl-encoder-input](../input_touch_lvgl_gesture_binding_reference/P018_zephyr_lvgl-encoder-input.md#std-dtcompatible-zephyr-lvgl-encoder-input) | 将输入事件转换为 LVGL 编码器输入 |
| [zephyr,lvgl-keypad-input](../input_touch_lvgl_gesture_binding_reference/P019_zephyr_lvgl-keypad-input.md#std-dtcompatible-zephyr-lvgl-keypad-input) | 将输入事件转换为 LVGL 键盘输入 |
| [zephyr,lvgl-pointer-input](../input_touch_lvgl_gesture_binding_reference/P020_zephyr_lvgl-pointer-input.md#std-dtcompatible-zephyr-lvgl-pointer-input) | 将输入事件转换为 LVGL 指针输入 |

> 译注：**去抖（Debouncing）**用于过滤机械触点在一次按下或松开过程中产生的短暂重复跳变。正交编码器使用相位错开的两个信号表示旋转位移与方向。LVGL 是嵌入式图形界面库的项目名；上述适配驱动把同一输入事件系统接到图形库所需的不同输入设备类型。

见[输入事件定义参考](https://docs.zephyrproject.org/latest/doxygen/html/group__input__events.html)。相关示例：

- [绘制触摸事件](P015_触摸事件绘制示例.md#draw_touch_events)：在显示器上可视化触摸事件。
