# 第15章\_触摸事件绘制示例

原文：[官方页面](https://docs.zephyrproject.org/latest/samples/subsys/input/draw_touch_events/README.html)。读取日期：2026-10-14；保存的 latest 页面及 HTML 摘要见[来源记录](../SOURCES.md)。

## 15.1\_概述

本示例在最近触摸位置绘制一个小加号（Plus），便于检查开发板触摸屏是否工作，以及坐标轴反向、交换（Inverted/Swapped Axes）等参数。

## 15.2\_构建与运行

这是通用示例，适用于 Zephyr 同时支持显示控制器（Display Controller）和触摸控制器（Touch Controller）的开发板；还须在设备树 `/chosen`（原文写作 `/chosen node`）中设置 `zephyr,touch` 与 `zephyr,display` 属性，分别指定对应设备。

以下是为 STM32F746G Discovery 构建的原始主机命令，在已准备好工具链和依赖模块的 Zephyr 源码根目录执行：

```sh
west build -b stm32f746g_disco samples/subsys/input/draw_touch_events
```

为了不依赖实际硬件进行测试，也支持 [`native_sim`](../native_reference/P004_Native_Simulator本机模拟器.md#native_sim)，构建命令如下：

```sh
west build -b native_sim samples/subsys/input/draw_touch_events
```

译注：上面两段原文只包含构建操作，没有给出烧录或启动命令，也不能据此声称触摸屏已经验证。当前源码检查两个 `/chosen` 节点与设备就绪状态；回调分别接收 `INPUT_ABS_X`、`INPUT_ABS_Y` 和 `INPUT_BTN_TOUCH`，在同步标记（Sync）到达后通知绘制线程处理一组触摸状态。需要先核对目标的显示／触摸驱动、像素格式及坐标范围；`/chosen` 是设备树节点路径，不是主机磁盘绝对地址。
