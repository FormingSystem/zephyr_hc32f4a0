## 5.1\_控制台示例（Console Samples）

本目录中的示例演示控制台（Console）子系统。

| 示例 | 用途 |
| --- | --- |
| [控制台回显](P006_控制台回显示例.md) | 使用控制台 API 将输入字符回显到输出端 |
| [字符输入](P007_控制台字符输入示例.md) | 使用 [`console_getchar()`](P007_控制台字符输入示例.md#console_getchar) 从控制台读取一个字符 |
| [行输入](P008_控制台行输入示例.md) | 使用 [`console_getline()`](P008_控制台行输入示例.md#console_getline) 从控制台读取一行 |

译注：这里是官方示例目录的完整译文。控制台 API 与带命令解析、补全的 Shell 不同，接口说明见[控制台指南](P002_控制台.md)。
