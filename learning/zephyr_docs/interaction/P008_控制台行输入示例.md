# 第8章\_控制台行输入示例

原文：[官方页面](https://docs.zephyrproject.org/latest/samples/subsys/console/getline/README.html)。读取日期：2026-10-14；保存的 latest 页面及 HTML 摘要见[来源记录](../SOURCES.md)。

## 8.1\_概述

本示例介绍 [`console_getline()`](https://docs.zephyrproject.org/latest/doxygen/html/group__console__api.html#ga3454f5b84d38d46a6c2bbf7fd6baa815)。它与 ANSI C 中常见的 `gets()`、`fgets()` 在逐行读取用途上相似：有完整输入行时返回下一行，否则阻塞等待。这个接口便于移植逐行处理控制台输入的 ANSI C、POSIX 或 Linux 应用；示例也展示返回行的具体形式。

需要逐字符输入时，参阅[字符输入示例](P007_控制台字符输入示例.md)。

译注：上述比较是原文对读取用途的说明，不表示各函数的参数、缓冲区管理或安全属性相同，也不是建议使用 `gets()`。

## 8.2\_要求、构建与运行

运行需要 UART 控制台。最简单的运行方式是使用 QEMU：

译注：主机终端位于已准备好构建依赖的 Zephyr 源码根目录。下面构建官方已有的 `samples/subsys/console/getline`，然后运行生成的应用。

```sh
west build -b qemu_x86 samples/subsys/console/getline
west build -t run
```

输入一些字符后按 Enter。程序会打印刚输入的一行，并用十六进制显示最后一个字符的编码，从而展示返回行不包含换行（Line Feed，LF）、回车（Carriage Return，CR）等特殊行尾字符。按 Ctrl+A，再按 x，退出 QEMU。

## 8.3\_源码追踪译注

示例先调用 `console_getline_init()`。当前库实现使用两个内部行缓冲区：应用处理当前行时，另一个缓冲区可继续收集输入；下一次调用 [`console_getline()`](https://docs.zephyrproject.org/latest/doxygen/html/group__console__api.html#ga3454f5b84d38d46a6c2bbf7fd6baa815) 会回收上次返回的缓冲区。因此需要长期保留内容时应自行复制，不能假定返回指针永久有效。

当前示例使用 `s[strlen(s) - 1]` 打印最后一个字符，尚未检查空行；若改用于自己的程序，应先检查长度非零，避免空行时下标越界。这里是对官方样例实现的核对，没有改写原始示例源码。
