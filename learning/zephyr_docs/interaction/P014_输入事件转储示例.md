# 第14章\_输入事件转储示例

原文：[官方页面](https://docs.zephyrproject.org/latest/samples/subsys/input/input_dump/README.html)。读取日期：2026-10-14；保存的 latest 页面及 HTML 摘要见[来源记录](../SOURCES.md)。

## 14.1\_概述与要求

输入转储（Input Dump）示例使用 [输入API](P003_输入子系统.md) 打印输入事件（Input Events）。只要开发板的设备树（Devicetree）中定义了输入驱动，就可以运行该示例。

## 14.2\_构建与运行

按原文构建和烧录，将 `nrf52dk/nrf52832` 换成所用开发板。主机终端位于已具备工具链、模块和烧录工具的 Zephyr 源码根目录；示例是官方已有的 `samples/subsys/input/input_dump`。

```sh
west build -b nrf52dk/nrf52832 samples/subsys/input/input_dump
west flash
```

启动后，控制台会打印输入事件。

译注：当前样例的 `main.c` 只打印启动提示；事件转储由配置中的 `CONFIG_INPUT_EVENT_DUMP` 启用，同时启用 `CONFIG_INPUT` 和日志。输入设备产生事件后才有对应输出，单纯看到启动提示不代表驱动已经上报事件。
