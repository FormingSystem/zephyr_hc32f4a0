# 第7章\_控制台字符输入示例

原文：[官方页面](https://docs.zephyrproject.org/latest/samples/subsys/console/getchar/README.html)。读取日期：2026-10-14；保存的 latest 页面及 HTML 摘要见[来源记录](../SOURCES.md)。

## 7.1\_概述

本示例介绍 [`console_getchar()`](https://docs.zephyrproject.org/latest/doxygen/html/group__console__api.html#ga2ba36eb1081cd0b98aa43216ccd6fbd5)。它类似 ANSI C 中常见的 `getchar()`：有输入字符时返回下一个字符，否则阻塞（Block）等待。用这个接口可以较容易地移植逐字符处理控制台输入的 ANSI C、可移植操作系统接口（Portable Operating System Interface，POSIX）或 Linux 应用。示例也会显示函数返回的按键／字符编码。

需要逐行输入时，参阅[行输入示例](P008_控制台行输入示例.md)。

## 7.2\_要求、构建与运行

运行需要 UART 控制台。最简单的运行方式是使用 QEMU：

译注：在已具备构建依赖的 Zephyr 源码根目录执行主机命令；示例源代码位于官方已有的 `samples/subsys/console/getchar`。第二条命令运行前一条生成的应用。

```sh
west build -b qemu_x86 samples/subsys/console/getchar
west build -t run
```

接着按下键盘按键，程序会同时以十六进制值和字符形式打印输入。也应试按 Enter、上／下方向键等，观察它们产生哪些控制字符（Control Characters）。按 Ctrl+A，再按 x，退出 QEMU。

## 7.3\_源码追踪译注

官方示例先调用 `console_init()`，然后循环取得字符并输出其编码；方向键可能产生多个字符组成的转义序列（Escape Sequence），并不保证一个物理按键对应一次读取。本示例没有命令行编辑或 Shell 命令解析功能。
