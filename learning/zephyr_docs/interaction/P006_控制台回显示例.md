# 第6章\_控制台回显示例

原文：[官方页面](https://docs.zephyrproject.org/latest/samples/subsys/console/echo/README.html)。读取日期：2026-10-14；保存的 latest 页面及 HTML 摘要见[来源记录](../SOURCES.md)。

## 6.1\_概述与要求

本示例演示如何配合 [`console_getchar()`](https://docs.zephyrproject.org/latest/doxygen/html/group__console__api.html#ga2ba36eb1081cd0b98aa43216ccd6fbd5) 与 [`console_putchar()`](https://docs.zephyrproject.org/latest/doxygen/html/group__console__api.html#ga7bd842f1cda6c8218cb1d41420e4de49)，将输入字符回显（Echo）到控制台。运行需要通用异步收发器（Universal Asynchronous Receiver/Transmitter，UART）控制台。

## 6.2\_构建与运行

按下面的原始命令构建和烧录，并将 `nucleo_f401re` 换成自己的开发板。也可以参照[字符输入示例](P007_控制台字符输入示例.md)在 QEMU 中运行。

译注：主机终端位于已准备好工具链和模块的 Zephyr 源码根目录；`samples/subsys/console/echo` 是官方已有示例。先完成构建，再执行适用于所选开发板的烧录命令。下面的命令与输出是原文示例，本次未执行。

```sh
west build -b nucleo_f401re samples/subsys/console/echo
west flash
```

固件给出初始提示后，开始按键，输入的字符就会回显到所用的终端程序。

## 6.3\_在QEMU中运行

QEMU 可以使用已在 Zephyr 中配置的 VIRTIO 控制台设备（VIRTIO Console Device）。原文给出的命令如下：

```sh
west build -b qemu_x86_64 samples/subsys/console/echo -- -DDTC_OVERLAY_FILE=virtconsole.overlay -DEXTRA_CONF_FILE=overlay-virtconsole.conf
west build -t run
```

可在 `overlay-virtconsole.conf` 中配置多个输入／输出端同时使用：加入 `CONFIG_UART_VIRTIO_CONSOLE_F_MULTIPORT=y` 启用多端口（Multiport），再通过 `CONFIG_QEMU_EXTRA_FLAGS` 配置更多端口，细节参见 QEMU 手册。

> 译注——原文与当前源码差异：读取当日的官方示例目录中存在 `virtconsole.overlay`，但原命令引用的 `overlay-virtconsole.conf` 已不存在，获取该文件返回 404。这里保留原命令用于追溯，不能将此分支标为当前可直接复现；应对照所使用版本的配置文件和 UART/VIRTIO 驱动能力修正配置后再构建，不能以创建同名空文件代替所需配置。此差异与读者的仓库所在目录无关。

## 6.4\_示例输出

```text
You should see another line with instructions below. If not,
the (interrupt-driven) console device doesn't work as expected:
Start typing characters to see them echoed back
```

提示译文：下面应再出现一行操作说明；若未出现，说明由中断驱动（Interrupt-driven）的控制台设备未按预期工作。随后应显示“开始输入字符，观察回显”。
