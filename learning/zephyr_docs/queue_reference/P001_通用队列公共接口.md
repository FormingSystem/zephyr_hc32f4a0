### `k_queue_alloc_append()`

```c
int32_t k_queue_alloc_append ( struct k_queue * queue, void * data )
```

声明属性：`isr-ok`（允许从中断服务程序ISR调用）。

```c
#include <zephyr/kernel.h>
```

向队列追加一个元素。

此例程将一个数据项追加到queue。它会隐式分配内存，从调用线程的资源池（Resource Pool）创建额外的临时管理数据结构；该项被移除时，管理结构自动释放。数据本身不会被复制。

**参数（Parameters）**

| 名称／方向 | 说明 |
| --- | --- |
| `queue` | 队列的地址。 |
| `data` | 数据项的地址。 |

**返回值（Return Values）**

| 名称／方向 | 说明 |
| --- | --- |
| `0` | 操作成功。 |
| `-ENOMEM` | 调用者的资源池中没有足够的RAM。 |

> 译注——源码核对：分配的是保存data指针的alloc_node包装，不是data对象副本。已有get等待者时直接交付，无须分配包装；否则通过z_thread_malloc申请，失败返回-ENOMEM。get或remove释放的是包装，数据对象仍由应用管理；peek不会释放。

<a id="gacf3dba40125073c11075e5a134919f88"></a>

### `k_queue_alloc_prepend()`

```c
int32_t k_queue_alloc_prepend ( struct k_queue * queue, void * data )
```

声明属性：`isr-ok`（允许从中断服务程序ISR调用）。

```c
#include <zephyr/kernel.h>
```

在队列头部加入一个元素。

此例程将一个数据项放到queue头部。它会隐式分配内存，从调用线程的资源池（Resource Pool）创建额外的临时管理数据结构；该项被移除时，管理结构自动释放。数据本身不会被复制。

**参数（Parameters）**

| 名称／方向 | 说明 |
| --- | --- |
| `queue` | 队列的地址。 |
| `data` | 数据项的地址。 |

**返回值（Return Values）**

| 名称／方向 | 说明 |
| --- | --- |
| `0` | 操作成功。 |
| `-ENOMEM` | 调用者的资源池中没有足够的RAM。 |

> 译注——源码核对：与alloc_append使用相同包装机制，但缓存时放到头部。无等待者才需要申请包装，直接交付不分配；应用数据不复制、不随包装自动释放。

### `k_queue_append()`

```c
void k_queue_append ( struct k_queue * queue, void * data )
```

声明属性：`isr-ok`（允许从中断服务程序ISR调用）。

```c
#include <zephyr/kernel.h>
```

将一个元素追加到队列末尾。

此例程将一个数据项追加到queue。队列数据项必须满足指针的对齐要求，且其第一个指针大小的字段保留给内核使用。

**参数（Parameters）**

| 名称／方向 | 说明 |
| --- | --- |
| `queue` | 队列的地址。 |
| `data` | 数据项的地址。 |

> 译注——源码核对：这是直接使用数据项内链接字段的入队方式；数据内容不复制，也不自动延长对象寿命。已有等待者时会直接交付，否则链接到队尾。尚未移除的同一链接节点不能同时重复放入当前或其他链表。

<a id="ga91d1a144fc2aeb3dd655accc94ca43aa"></a>

### `k_queue_append_list()`

```c
int k_queue_append_list ( struct k_queue * queue, void * head, void * tail )
```

声明属性：`isr-ok`（允许从中断服务程序ISR调用）。

```c
#include <zephyr/kernel.h>
```

以原子方式将一个元素链表追加到队列。

此例程在一次操作中向queue加入一个数据项链表。数据项必须构成单向链表（Singly Linked List），每个数据项的第一个指针大小的字段指向下一项；链表必须以NULL结束。

**参数（Parameters）**

| 名称／方向 | 说明 |
| --- | --- |
| `queue` | 队列的地址。 |
| `head` | 指向单向链表第一个节点的指针。 |
| `tail` | 指向单向链表最后一个节点的指针。 |

**返回值（Return Values）**

| 名称／方向 | 说明 |
| --- | --- |
| `0` | 操作成功。 |
| `-EINVAL` | 传入的数据无效。 |

> 译注——源码核对：当前实现检查head／tail非NULL，然后在队列锁内先逐项交付给等待者，再将剩余链表追加；并非每个元素都先进入缓存链表。它没有完整检查环、尾节点可达性或所有节点布局，调用者必须提供有效且NULL结尾的链表，并避免并发改写。

<a id="ga7c39d86cc6509f59ff9223cac3ea5071"></a>

### `k_queue_cancel_wait()`

```c
void k_queue_cancel_wait ( struct k_queue * queue)
```

声明属性：`isr-ok`（允许从中断服务程序ISR调用）。

```c
#include <zephyr/kernel.h>
```

取消对队列的等待。

如果存在等待queue的线程，此例程使第一个等待线程从k_queue_get()返回NULL，如同等待超时。如果有k_poll()正在等待该队列，它会返回-EINTR并设置K_POLL_STATE_CANCELLED状态；如上所述，后续k_queue_get()将返回NULL。

**参数（Parameters）**

| 名称／方向 | 说明 |
| --- | --- |
| `queue` | 队列的地址。 |

> 译注——源码核对：当前实现唤醒一个get等待者并传递NULL，还会触发K_POLL_STATE_CANCELLED事件；它不清空数据链表，也不设置永久关闭标志。原文关于后续get返回NULL的表述不是无条件保证：后续调用仍按当时队列内容和timeout运行，可以取得新数据或重新等待。

<a id="ga0a77d8556e7d253319275de034f01619"></a>

### `k_queue_get()`

```c
void * k_queue_get ( struct k_queue * queue, k_timeout_t timeout )
```

声明属性：`isr-ok`（允许从中断服务程序ISR调用）。

```c
#include <zephyr/kernel.h>
```

从队列取得一个元素。

此例程从queue移除第一个数据项。该数据项的第一个指针大小的字段保留给内核使用。

**参数（Parameters）**

| 名称／方向 | 说明 |
| --- | --- |
| `queue` | 队列的地址。 |
| `timeout` | 等待取得数据项的时长，或特殊值K_NO_WAIT、K_FOREVER之一。 |

**说明（Note）**：如果从中断服务程序（Interrupt Service Routine，ISR）调用，timeout必须设置为K_NO_WAIT。

**返回（Returns）**：成功时返回数据项地址；未等待便返回或等待超时时，返回NULL。

> 译注——源码核对：取出的是原data指针，alloc包装在真正出队时被释放；直接交付路径没有包装可释放。NULL也可能来自cancel_wait，不能只凭返回指针区分取消和超时。原文首字段预留要求针对直接入队方式，alloc接口的数据无需为包装另留该字段。

### `k_queue_insert()`

```c
void k_queue_insert ( struct k_queue * queue, void * prev, void * data )
```

声明属性：`isr-ok`（允许从中断服务程序ISR调用）。

```c
#include <zephyr/kernel.h>
```

向队列插入一个元素。

此例程在queue的前一个数据项之后插入数据项。队列数据项必须满足指针的对齐要求，且其第一个指针大小的字段保留给内核使用。

**参数（Parameters）**

| 名称／方向 | 说明 |
| --- | --- |
| `queue` | 队列的地址。 |
| `prev` | 前一个数据项的地址。 |
| `data` | 数据项的地址。 |

> 译注——源码核对：本次底层链表在prev为NULL时前插；否则将prev当作已有链表节点，并不搜索验证它是否属于该队列。经alloc接口加入的数据指针与内部包装节点地址不同，不能未经核对就把这种data指针当作prev节点。

### `k_queue_is_empty()`

```c
int k_queue_is_empty ( struct k_queue * queue)
```

声明属性：`isr-ok`（允许从中断服务程序ISR调用）。

```c
#include <zephyr/kernel.h>
```

查询队列是否有可用数据。

如果其他线程也在尝试读取队列，本函数返回时，数据可能已经被取走。

**参数（Parameters）**

| 名称／方向 | 说明 |
| --- | --- |
| `queue` | 队列的地址。 |

**返回（Returns）**：队列为空时返回非零；有可用数据时返回0。

> 译注——源码核对：返回非零表示空，返回0表示有数据，与“成功返回0”的常见接口习惯不同。它只提供当前观察，不预留任何数据项；下一次get仍需检查返回值。

### `k_queue_merge_slist()`

```c
int k_queue_merge_slist ( struct k_queue * queue, sys_slist_t * list )
```

声明属性：`isr-ok`（允许从中断服务程序ISR调用）。

```c
#include <zephyr/kernel.h>
```

以原子方式将一个元素链表加入队列。

此例程在一次操作中向queue加入一个数据项链表。数据项必须位于由sys_slist_t对象表示的单向链表中。完成后，原链表为空。调用者负责保证其他线程或ISR不会并发访问list。

**参数（Parameters）**

| 名称／方向 | 说明 |
| --- | --- |
| `queue` | 队列的地址。 |
| `list` | 指向sys_slist_t对象的指针。 |

**返回值（Return Values）**

| 名称／方向 | 说明 |
| --- | --- |
| `0` | 操作成功。 |
| `-EINVAL` | 数据无效。 |

> 译注——源码核对：成功后当前实现显式调用sys_slist_init(list)，因此源链表对象已为空，而节点已转移或交付。空链表经检查路径返回-EINVAL。队列锁只保护目标队列，调用者仍需独占源list及其链接；不能把带分配包装标志的内部sflist冒充普通slist。

### `k_queue_peek_tail()`

```c

#include <zephyr/kernel.h>
```

查看队列尾部元素（Peek）。

返回队列尾部元素，但不将其移除。

**参数（Parameters）**

| 名称／方向 | 说明 |
| --- | --- |
| `queue` | 队列的地址。 |

**返回（Returns）**：返回尾部元素；队列为空时返回NULL。

> 译注——源码核对：与peek_head相同，返回时队列锁已释放，包装和数据项仍留在队列中。查看尾指针不自动授予修改该对象或容器内容的独占权限。

### `k_queue_prepend()`

```c
void k_queue_prepend ( struct k_queue * queue, void * data )
```

```c
#include <zephyr/kernel.h>
```

在队列头部加入一个元素。

此例程在queue头部加入数据项。队列数据项必须满足指针的对齐要求，且其第一个指针大小的字段保留给内核使用。

### `k_queue_remove()`

```c
bool k_queue_remove ( struct k_queue * queue, void * data )
```

声明属性：`isr-ok`（允许从中断服务程序ISR调用）。

```c
#include <zephyr/kernel.h>
```

从队列移除一个元素。

此例程从queue移除data数据项。该数据项的第一个指针大小的字段保留给内核使用。从k_queue移除元素依赖sys_slist_find_and_remove，该操作不是常数时间（Constant Time）操作。

**参数（Parameters）**

| 名称／方向 | 说明 |
| --- | --- |
| `queue` | 队列的地址。 |
| `data` | 数据项的地址。 |

**返回（Returns）**：成功移除数据项时返回true。

> 译注——源码核对：原文提到sys_slist_find_and_remove；本次实现实际持锁遍历sys_sflist，先解出每个节点的应用data指针再比较，因此也能匹配分配型包装的数据指针。命中后移除一项并释放包装，不释放应用对象；时间仍随遍历长度变化。

### `k_queue_unique_append()`

```c
bool k_queue_unique_append ( struct k_queue * queue, void * data )
```

声明属性：`isr-ok`（允许从中断服务程序ISR调用）。

```c
#include <zephyr/kernel.h>
```

仅当元素尚不存在时才将其追加到队列。

此例程将data数据项追加到queue。该数据项的第一个指针大小的字段保留给内核使用。向k_queue追加元素依赖sys_slist_is_node_in_list，该操作不是常数时间操作。

**参数（Parameters）**

| 名称／方向 | 说明 |
| --- | --- |
| `queue` | 队列的地址。 |
| `data` | 数据项的地址。 |

**返回（Returns）**：添加了数据项时返回true，否则返回false。

> 译注——源码核对：原文提到sys_slist_is_node_in_list；本次实现实际在同一把队列锁内扫描节点地址再插入。它比较内部节点地址与data，未像remove那样解出分配型包装中的data，因此不保证对混用alloc包装的同一数据指针去重。检查范围只限当前缓存链表，已直接交付给等待者或已出队的对象不在其中。

## 1.4\_源码定位与版本边界

> 译注——阅读与源码边界：普通入队使用数据项内的链接字段，alloc入队另存一个包装节点；二者均不复制应用数据。队列内部以带标志的单链表（Flagged Singly Linked List，sflist）区分包装，get、peek与remove的包装处理不同。FIFO和LIFO分别以前后插入的组合构建在该队列上。
