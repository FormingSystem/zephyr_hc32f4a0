统一的跟踪钩子清单（Canonical Tracing Hook List）。

查看此文件的源码。

<a id="details"></a>

统一的跟踪钩子清单（Canonical Tracing Hook List）。这是全部sys_port_trace_*宏钩子的唯一权威定义来源。每个钩子都由#ifndef包围，因此可以在跟踪后端头文件（tracing_ctf.h、tracing_sysview.h等）之后包含本头文件。所选后端未定义的钩子在此回退为空操作（No-op）。因此，后端只需定义它实际记录的钩子；遗漏的钩子会退化为空操作，而不会导致构建失败或无声的定义偏离。要添加新钩子，应先在此加入空操作定义，再在需要记录该钩子的后端中实现其函数体或宏体。
