## 3.2\_详细说明（Detailed Documentation）

<a id="aba3e9abb310c42fef67ce63cb2845046"></a>

### `SYS_THREAD_MONITOR_HEAD`

```c
#define SYS_THREAD_MONITOR_HEAD ((struct k_thread *)(_kernel.threads))
```

线程监视链表（Thread Monitor List）的头元素。

访问线程监视链表（Thread Monitor List）的头元素。

<a id="aefa138ca1b427f994b994ebe1224764e"></a>

### `SYS_THREAD_MONITOR_NEXT`

```c
#define SYS_THREAD_MONITOR_NEXT ( obj)
```

展开值（Value）：

```c
(((struct k_thread *)obj)->next_thread)
```

获取线程节点的下一个元素（Next Element）。

给定线程监视链表（Thread Monitor List）中的一个节点，获取链表中的下一个元素。

**参数（Parameters）**

| 名称／方向 | 说明 |
| --- | --- |
| `obj` | 要从中获取下一个元素的对象（Object）。 |

## 3.3\_源码定位与版本边界

相对源码定位：[完整钩子清单](../../../include/zephyr/tracing/tracing_hooks.h)、[对象跟踪宏](../../../include/zephyr/debug/object_tracing.h)、[跟踪入口](../../../include/zephyr/tracing/tracing.h)、[包装宏](../../../include/zephyr/tracing/tracing_macros.h)、[线程监视实现](../../../kernel/thread_monitor.c)、[线程结构](../../../include/zephyr/kernel/thread.h)、[内核配置](../../../kernel/Kconfig)。官方源码摘要见[来源记录](../SOURCES.md)。

> 译注——源码核对：官方声明、原始宏展开与源码译注分别保留；以下实现分析以来源记录中的官方源码摘要为界，仓库文件均采用相对路径定位。

> 译注——源码核对：此处对象跟踪（Object Tracing）头文件提供的是线程监视链表访问宏，不是为任意内核对象自动生成事件。HEAD直接读取_kernel.threads，NEXT把参数转换为struct k_thread *后读取next_thread；两个宏都没有建立快照或获取锁。

> 译注——源码核对：本次thread.h把next_thread置于CONFIG_THREAD_MONITOR条件下。使用这些宏前需要相应线程监视配置和有效线程节点；NEXT不包含NULL检查，不能在链表结尾继续解引用。

> 译注——源码核对：kernel/thread_monitor.c使用z_thread_monitor_lock保护链表更新与遍历。公开k_thread_foreach在锁内执行回调，unlocked变体在回调前放锁、之后重新获取；两者有不同并发约束。直接通过HEAD／NEXT遍历不能自动继承这些保护，也不能假定取得的节点在后续访问中一直存活。

> 译注——源码核对：本页完整可见定义见[对象跟踪头文件源码](P004_对象跟踪头文件源码.md)；线程事件记录的含义见[线程跟踪接口](../network_thread_trace_reference/P001_线程跟踪接口.md)。
