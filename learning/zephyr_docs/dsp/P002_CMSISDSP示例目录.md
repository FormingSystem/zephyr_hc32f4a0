## 2.1\_CMSIS-DSP 示例

这些示例展示如何使用 CMSIS-DSP 模块，在 Zephyr 中执行信号处理操作。

- [CMSIS-DSP 移动平均（Moving Average）](P003_CMSISDSP移动平均示例.md#cmsis-dsp-moving-average)：使用 CMSIS-DSP 库计算信号的移动平均值。

译注：CMSIS-DSP 是 Cortex-M 软件接口标准（Cortex-M Software Interface Standard，CMSIS）体系中的数字信号处理算法库，与 CMSIS-RTOS 兼容层用途不同。本页是官方示例目录。
