# 线程与网络跟踪接口大纲

本册完整翻译线程、网络、套接字、命名事件和后端扩展五组跟踪接口，共五份官方页面。跟踪钩子（Tracing Hooks）用于记录API入口、阻塞、出口和生命周期事件，具体记录行为由后端实现。

各页保留宏签名、摘要、完整参数说明与交叉引用。源码译注说明配置与后端、事件位置、返回值语义及原文和调用点的差异，区分调度事件、套接字描述符、错误码与传输字节数，并说明网络时间单位、用户命名事件和后端扩展的版本边界。

本地源码使用相对链接，保留中英文术语和原始许可证；本册不加入作者机器的采集环境或实板步骤。完整范围见[全站进度](../PROGRESS.md)。
