> 译注——源码核对：Enter、Exit及调度相关名称表示标记位置，不保证所有分支成对出现，也不自动证明应用处理或硬件传输已经完成。参数中的对象指针、整数标识和返回码需按实际签名与调用点区分。

> 译注——源码核对：本组同时包含公开API调用标记与调度器（Scheduler）内部标记。例如sched_ready表示就绪状态变化，并不等于线程已开始执行；switched_in／switched_out用于切换位置，签名没有显式线程参数，后端需依据当前上下文解释。

> 译注——源码核对：join在目标已结束时可立即返回0，K_NO_WAIT且目标未结束时返回-EBUSY，自连接或已知互相等待可返回-EDEADLK；仅实际加入等待路径才发出join_blocking。线程终止和自身挂起等行为会影响控制流，不应只凭接口列表要求每次调用都有正常出口记录。

> 译注——源码核对：原文busy_wait简述写作k_thread_busy_wait，实际调用点位于kernel/busy_wait.c的k_busy_wait，参数单位是微秒。sleep_ticks则使用系统节拍，退出ret为剩余睡眠节拍，不是errno；K_NO_WAIT路径执行yield，K_FOREVER路径还可能报告K_TICKS_FOREVER。

> 译注——源码核对：foreach与foreach_unlocked钩子没有回调、用户数据或CPU参数；本次CPU限定的遍历接口也复用同名钩子。name_set记录ret，未启用线程命名时可报告-ENOSYS，因此出现事件不证明名称设置成功。
