> 译注——阅读位置：从[本册大纲](大纲.md)进入线程、网络、套接字、命名事件和后端扩展的跟踪接口，再通过接口链接进入完整说明。源码跟踪译注与官方原文分开标示。

仅由特定后端（Backends）提供的跟踪钩子（Tracing Hooks）。

<a id="details"></a>

仅由特定后端（Backends）提供的跟踪钩子（Tracing Hooks）。这些钩子只在特定后端中定义，例如SystemView的管道内部接口。此处提供空操作回退（No-op Fallbacks），使每个后端都能够解析完整的钩子集合。

> 译注——源码核对：本页保留官方跟踪接口约定，源码核对另列为译注。钩子声明不证明当前配置一定生成事件；实际输出取决于调用点、配置及后端。钩子通常在原上下文直接执行，不能假定由独立工作线程异步处理。

> 译注——源码核对：Enter、Exit及调度相关名称表示标记位置，不保证所有分支成对出现，也不自动证明应用处理或硬件传输已经完成。参数中的对象指针、整数标识和返回码需按实际签名与调用点区分。

> 译注——源码核对：后端扩展（Backend-specific Extensions）列出特定后端使用的补充钩子，通用头文件提供空操作回退以补齐名称集合。这里没有新增一套可直接调用的内核管道功能API；存在宏名不证明当前内核实现一定调用它。

> 译注——源码核对：本次kernel/pipe.c使用read／write、reset和close跟踪；本页仍列出的get／put、flush、buffer_flush、alloc_init和cleanup应按后端及版本核对，不能把旧式扩展名称直接当作当前管道调用路径。当前通用管道接口见[管道跟踪接口](../object_trace_reference/P006_管道跟踪接口.md)。

> 译注——源码核对：heap_assign表示为线程指定关联堆，不等于创建堆或分配一块应用内存。syscall_exit保留可变参数签名，但本页只说明id与name；完整系统调用参数与返回值约定见[系统调用跟踪接口](../sync_trace_reference/P007_系统调用跟踪接口.md)，不能据这里的简表丢弃可变参数。

> 译注——源码核对：本次译注以来源记录中的官方源码摘要为界，仓库文件均采用相对路径定位；未配置跟踪设备、运行网络采集或测量事件时序。

本次验证范围为文档与源码对照，未构建固件、配置实板引脚或操作硬件。
