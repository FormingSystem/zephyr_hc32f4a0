> 译注——源码核对：本页保留官方跟踪接口约定，源码核对另列为译注。钩子声明不证明当前配置一定生成事件；实际输出取决于调用点、配置及后端。钩子通常在原上下文直接执行，不能假定由独立工作线程异步处理。

> 译注——源码核对：Enter、Exit及调度相关名称表示标记位置，不保证所有分支成对出现，也不自动证明应用处理或硬件传输已经完成。参数中的对象指针、整数标识和返回码需按实际签名与调用点区分。

> 译注——源码核对：net_recv_data的出口表示接收入口处理结果：当前实现可将数据包排入接收队列，也可因接收过滤丢弃数据包并返回0。它不证明应用已经收到数据，后端也不能假设出口pkt总能安全解引用。发送出口同样需按具体发送路径解释，不能当作远端已收到报文的确认。

> 译注——源码核对：官方send_data_exit的pkt说明仍写成“Received network packet”，本页按原文保留；宏名与net_send_data调用点表明这里实际是发送路径的数据包。

> 译注——源码核对：原文rx_time／tx_time把end_time描述为ticks。本次net_if.c的发送记录，以及sockets_inet.c接收计时调用点，使用k_cycle_get_32()得到32位周期计数值；不能直接套用CONFIG_SYS_CLOCK_TICKS_PER_SEC把它当作调度节拍换算。它是处理结束时刻的计数值，不是单独的耗时或墙上时钟时间。

> 译注——源码核对：本次译注以来源记录中的官方源码摘要为界，仓库文件均采用相对路径定位；未配置跟踪设备、运行网络采集或测量事件时序。

本次验证范围为文档与源码对照，未构建固件、配置实板引脚或操作硬件。
