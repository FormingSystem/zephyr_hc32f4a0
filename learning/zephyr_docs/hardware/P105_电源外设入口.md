# 第105章\_电源外设入口

原文：[Power](https://docs.zephyrproject.org/latest/hardware/peripherals/power.html)。读取日期：2026-10-13，`latest`。

## 105.1\_电源与唤醒外设目录

官方 **电源（Power）**目录涵盖电源管理、充电、稳压、复位与唤醒控制器。下表保留原文八个入口。

| 文档 | 中英文名称与原文状态 |
| --- | --- |
| [BC1.2设备](P109_BC1.2充电识别.md) | **电池充电1.2（Battery Charging 1.2，BC1.2）**设备，原文标为 **实验性（Experimental）**。 |
| [充电器](P107_充电器.md) | **充电器（Charger）**。 |
| [电量计](P108_电量计.md) | **电量计（Fuel Gauge）**。 |
| [稳压器](P106_稳压器.md) | **稳压器（Regulator）**。 |
| [复位控制器](P019_复位控制器.md) | **复位控制器（Reset Controller）**。 |
| [USB Type-C端口控制器](P110_Type-C端口控制器.md) | **Type-C端口控制器（Type-C Port Controller，TCPC）**；USB为 **通用串行总线（Universal Serial Bus）**。 |
| [USB-C VBUS](P111_USB-C总线电源.md) | USB-C的VBUS **总线电源（Bus Power）**。 |
| [唤醒控制器](P103_唤醒控制器.md) | **唤醒控制器（Wakeup Controller，WUC）**。 |

原页是导航目录，未译主题保留官方入口，具体电气能力与设备支持应进入各主题核对。
