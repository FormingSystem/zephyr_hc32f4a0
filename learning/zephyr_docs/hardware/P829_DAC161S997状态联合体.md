# 第829章\_DAC161S997状态联合体

原文：[uniondac161s997__status](https://docs.zephyrproject.org/latest/doxygen/html/uniondac161s997__status.html)。读取日期：2026-10-13，`latest`。

`union dac161s997_status` 表示数模转换器（Digital-to-Analog Converter，DAC）DAC161S997的状态寄存器（Status Register）STATUS内容。联合体（Union）同时提供原始寄存器值和各状态位的访问方式。

```c
#include <zephyr/drivers/dac/dac161s997.h>
```

## 829.1\_原始值与位域字段

## 829.2\_超时与帧错误条件

SPI默认超时时间为100毫秒（Millisecond，ms）。发生该错误后，向有效地址发送格式正确的写命令即可清除。

帧错误由寄存器写操作中的时钟数量不正确引起：**一次寄存器写操作的时钟周期数不是24的整数倍时，会产生帧错误。**

实时错误标志反映当前电流环供电条件；锁存标志则保留先前发生的错误，直到满足其清除条件。状态回调的读取失败情况见[扩展接口](P828_DAC161S997扩展接口.md)。字段文档由 `zephyr/drivers/dac/dac161s997.h` 生成，声明布局见[源码页](P831_DAC161S997扩展源码.md)。
