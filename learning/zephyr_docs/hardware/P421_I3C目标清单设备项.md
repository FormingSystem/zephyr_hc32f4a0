# 第421章\_I3C目标清单设备项

原文：[structi3c__ccc__deftgts__target](https://docs.zephyrproject.org/latest/doxygen/html/structi3c__ccc__deftgts__target.html)。读取日期：2026-10-13，`latest`。

## 421.1\_目标设备部分

`struct i3c_ccc_deftgts_target` 是**改进的集成电路间总线（Improved Inter-Integrated Circuit，I3C）通用命令码（Common Command Code，CCC）** `DEFTGTS` 的目标设备载荷部分。该命令用于定义目标列表（Define List of Targets），本结构描述总线上现有的目标设备。头文件为 `zephyr/drivers/i3c/ccc.h`。

## 421.2\_声明与联合体

以下按官方字段表整理声明，[`dcr`](https://docs.zephyrproject.org/latest/doxygen/html/structi3c__ccc__deftgts__target.html#a08689c18d74fa4b74fc2ada055394e65) 和 [`lvr`](https://docs.zephyrproject.org/latest/doxygen/html/structi3c__ccc__deftgts__target.html#ab4fbe6aac8d5860ef90613e51b15ef83) 位于同一个匿名联合体（Anonymous Union）：

```c
struct i3c_ccc_deftgts_target {
    uint8_t addr;
    union {
        uint8_t dcr;
        uint8_t lvr;
    };
    uint8_t bcr;
    uint8_t static_addr;
};
```

## 421.3\_字段含义

**设备特征寄存器（Device Characteristic Register，DCR）**适用于 I3C 目标或组；传统**集成电路间总线（Inter-Integrated Circuit，I2C）**设备使用**传统虚拟寄存器（Legacy Virtual Register，LVR）**。**总线特征寄存器（Bus Characteristic Register，BCR）**保存总线相关特征。

| 字段 | 含义 |
| --- | --- |
| [`addr`](https://docs.zephyrproject.org/latest/doxygen/html/structi3c__ccc__deftgts__target.html#a34a02df3d4dc456733746437b2cd983a) | 目标设备的动态地址（Dynamic Address），或组地址（Group Address）。 |
| `dcr` | I3C 目标设备或组的 DCR。 |
| `lvr` | 传统 I2C 设备的 LVR。 |
| [`bcr`](https://docs.zephyrproject.org/latest/doxygen/html/structi3c__ccc__deftgts__target.html#a7c234182e16da66c308e86d72591063d) | 目标设备或组的 BCR。 |
| [`static_addr`](https://docs.zephyrproject.org/latest/doxygen/html/structi3c__ccc__deftgts__target.html#a7374dd59c060462af7ca366ae7165107) | 目标设备或组的静态地址（Static Address）。 |
