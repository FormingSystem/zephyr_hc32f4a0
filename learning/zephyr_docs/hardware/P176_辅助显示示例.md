# 第176章\_辅助显示示例

原文：[Auxiliary display](https://docs.zephyrproject.org/latest/samples/drivers/auxdisplay/README.html)。读取日期：2026-10-13，`latest`。

## 176.1\_概述（Overview）

本示例向 **辅助显示器（Auxiliary Display）**输出示例文本“Hello World”，展示辅助显示驱动的使用方式，接口说明见[辅助显示设备](P131_辅助显示器.md)。

## 176.2\_构建与运行（Building and Running）

此示例需要已经配置辅助显示器的开发板。官方为 `nucleo_f746zg` 提供了一份 **设备树叠加文件（Devicetree Overlay）**示例，通过飞线（Fly-wiring）连接一块兼容 Hitachi HD44780 的显示器，其规格为每行 20 个字符、共 4 行。

接线配置见官方已有文件 [`samples/drivers/auxdisplay/boards/nucleo_f746zg.overlay`](https://github.com/zephyrproject-rtos/zephyr/blob/main/samples/drivers/auxdisplay/boards/nucleo_f746zg.overlay)。

译注：以下官方命令在已配置 Zephyr 开发环境的终端中，从 Zephyr 源码根目录执行；west 生成构建产物，`west flash` 将固件烧录到开发板。

```bash
west build -b nucleo_f746zg samples/drivers/auxdisplay
west flash
```

成功后，显示器上将显示 `Hello World from <board>`。其中 `<board>` 表示对应开发板名称。
