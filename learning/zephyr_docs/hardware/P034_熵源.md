# 第34章\_熵源

原文：[Entropy](https://docs.zephyrproject.org/latest/hardware/peripherals/entropy.html)。读取日期：2026-10-13，`latest`。

## 34.1\_熵源的用途

**熵（Entropy）**接口从平台的熵硬件获取熵值。其 **应用程序编程接口（Application Programming Interface，API）**供随机数子系统和密码服务使用。

原文明确指出：这些熵接口**不适合直接当作随机数生成函数使用**。硬件熵获取与应用所需的随机数生成接口属于不同层次。

## 34.2\_接口参考

完整函数与约束见[熵源API](P039_熵源接口参考.md)。原页没有附加代码或媒体。
