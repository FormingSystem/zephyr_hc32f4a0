# 第167章\_TMCM3216步进电机示例

原文：[TMCM-3216 stepper](https://docs.zephyrproject.org/latest/samples/drivers/stepper/tmcm3216/README.html)。读取日期：2026-10-13，`latest`。

## 167.1\_说明（Description）

本示例展示如何通过 Zephyr 的 **步进电机（Stepper Motor）**驱动 **应用程序编程接口（Application Programming Interface，API）**，使用 Analog Devices（ADI）的 TMCM-3216 三轴独立步进电机控制器与驱动板。

程序首先用通用的 [`stepper_ctrl_configure_ramp()`](P230_步进运动控制接口.md) 接口配置 **运动斜坡参数（Ramp Parameters）**，包括速度与加速度；随后根据 `CONFIG_PING_PONG_N_REV` 配置执行往返运动，每次到达目标位置便反转方向。

示例还展示 TMCM-3216 专用扩展：

| 扩展函数 | 作用 |
| --- | --- |
| `tmcm3216_get_max_velocity` | 读回已配置的速度。 |
| `tmcm3216_get_actual_velocity` | 读取电机实时速度。 |
| `tmcm3216_get_status` | 读取扩展状态，包括位置、速度、行程限位（Endstops）及位置到达标志（Position Reached Flag）。 |

## 167.2\_接线（Wiring）

TMCM-3216 通过 RS485 串行通信接口通信。使用 RS485 收发器（Transceiver）连接开发板与模块：

译注：USART 是 **通用同步/异步收发器（Universal Synchronous/Asynchronous Receiver/Transmitter）**；TX/RX 分别为发送（Transmit）与接收（Receive），GPIO 是 **通用输入输出（General-Purpose Input/Output）**。收发器的 DI 为驱动器输入（Driver Input），RO 为接收器输出（Receiver Output），DE/RE 为驱动器使能（Driver Enable）与接收器使能（Receiver Enable）。PD5、PD6、PA3 为 STM32 引脚标识，A/B 是 RS485 总线的差分线标识。

| 主机或收发器端 | 连接对象 |
| --- | --- |
| STM32 USART2 的 TX（PD5） | RS485 收发器的 DI。 |
| STM32 USART2 的 RX（PD6） | RS485 收发器的 RO。 |
| STM32 GPIO A0（PA3） | RS485 收发器的 DE/RE。 |
| RS485 收发器的 A/B | TMCM-3216 的 RS485 A/B。 |



译注：接线表保留原文的 `A0 (PA3)` 标记，括号内明确写的是 `PA3`，不要把前面的 `A0` 擅自改读为 **微控制器（Microcontroller Unit，MCU）**的 `PA0` 引脚。

## 167.3\_构建与运行（Building and Running）

应用控制电机并将状态输出到控制台（Console）。需要通过 RS485 收发器连接 ADI TMCM-3216 模块。

译注：以下官方命令在已配置 Zephyr 开发环境的终端中，从 Zephyr 源码根目录执行。示例源码由官方仓库提供，west 生成构建产物，`west flash` 将固件烧录到开发板。

```bash
# From the root of the zephyr repository
west build -b nucleo_u575zi_q samples/drivers/stepper/tmcm3216
west flash
```
