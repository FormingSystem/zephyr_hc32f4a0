# 第173章\_视频采集示例

原文：[Video capture](https://docs.zephyrproject.org/latest/samples/subsys/video/capture/README.html)。读取日期：2026-10-13，`latest`。

## 173.1\_说明（Description）

应用使用[视频设备](P141_视频设备.md)的 **应用程序编程接口（Application Programming Interface，API）**从视频采集设备获取帧，再通过[显示设备](P130_显示设备.md)接口把帧显示到 **液晶显示屏（Liquid Crystal Display，LCD）**上，如果系统有显示屏。

## 173.2\_要求（Requirements）

示例通常使用摄像头等视频采集设备，但实际采集硬件并非必需，也可使用后文的软件发生器。原文支持的开发板与摄像头包括：

| 开发板或方案 | 摄像头及配套模块 |
| --- | --- |
| [i.MX RT摄像头方案](https://community.nxp.com/t5/i-MX-RT-Knowledge-Base/Connecting-camera-and-LCD-to-i-MX-RT-EVKs/ta-p/1122183) | 见 NXP 的摄像头与 LCD 连接说明。 |
| [MIMXRT1064-EVK](https://docs.zephyrproject.org/latest/boards/nxp/mimxrt1064_evk/doc/index.html#mimxrt1064_evk) | MT9M114 摄像头模块。 |
| [MIMXRT1170-EVK](https://docs.zephyrproject.org/latest/boards/nxp/mimxrt1170_evk/doc/index.html#mimxrt1170_evk) | OV5640 摄像头模块。 |
| [FRDM-MCXN947](https://docs.zephyrproject.org/latest/boards/nxp/frdm_mcxn947/doc/index.html#frdm_mcxn947) | 任何兼容 `arducam,dvp-20pin-connector` 的摄像头模块，例如 [DVP 20针OV7670模块](https://docs.zephyrproject.org/latest/boards/shields/dvp_20pin_ov7670/doc/index.html#dvp-20pin-ov7670)。DVP 为 **数字视频端口（Digital Video Port）**。 |
| [STM32H7B3I Discovery kit](https://docs.zephyrproject.org/latest/boards/st/stm32h7b3i_dk/doc/index.html#stm32h7b3i_dk) | [ST B-CAMS-OMV-MB1683扩展板](https://docs.zephyrproject.org/latest/boards/shields/st_b_cams_omv_mb1683/doc/index.html#st-b-cams-omv-mb1683)及兼容摄像头模块。 |
| [STM32N6570-DK](https://docs.zephyrproject.org/latest/boards/st/stm32n6570_dk/doc/index.html#stm32n6570_dk) | [ST B-CAMS-IMX-MB1854摄像头模块](https://docs.zephyrproject.org/latest/boards/shields/st_b_cams_imx_mb1854/doc/index.html#st-b-cams-imx-mb1854)。 |
| [XIAO ESP32S3的sense变体](https://docs.zephyrproject.org/latest/boards/seeed/xiao_esp32s3/doc/index.html#xiao_esp32s3) | 配合 [Seeed Studio XIAO圆形显示扩展板](https://docs.zephyrproject.org/latest/boards/shields/seeed_xiao_round_display/doc/index.html#seeed-xiao-round-display)。 |

也可以使用 [Arduino Nicla Vision](https://docs.zephyrproject.org/latest/boards/arduino/nicla_vision/doc/index.html#arduino_nicla_vision) 采集视频，并通过板载 **通用串行总线（Universal Serial Bus，USB）**传输采集到的帧。

## 173.3\_接线（Wiring）

| 开发板 | 接线要求 |
| --- | --- |
| MIMXRT1064-EVK | 把 MT9M114 摄像头模块插入 J35 摄像头连接器；用 USB 线连接主机与 Micro-USB 调试接口 J41，以取得控制台输出。原文称板载调试接口为 `freelink`。 |
| MIMXRT1170-EVK | 把 OV5640 摄像头模块插入 J2 摄像头连接器；用 USB 线连接主机与 Micro-USB 调试接口 J11，通过 DAPLink 板载调试固件接口取得控制台输出。 |
| STM32H7B3I Discovery kit | 将 ST B-CAMS-OMV-MB1683 扩展板连接到 CN7；用 USB 线连接主机与 Micro-USB 接口，取得控制台输出。 |
| STM32N6570-DK | 将 ST B-CAMS-IMX-MB1854 模块接到 J4 **摄像头串行接口（Camera Serial Interface，CSI）**连接器；主机应与两个 USB-C 端口都连接，用于供电、烧录和控制台输出。 |
| XIAO ESP32S3 | 把 sense 摄像头模块和 Seeed Studio XIAO 圆形显示扩展板接到各自的连接器。 |
| Arduino Nicla Vision | 无需额外接线。 |

## 173.4\_为实际开发板构建（Building and Running）

译注：以下命令在已配置 Zephyr 开发环境的终端中，从 Zephyr 源码根目录执行。示例源码由官方仓库提供；扩展板（Shield）配置选择相应摄像头和显示器，west 生成构建产物。各开发板命令是独立分支。

MIMXRT1064-EVK：

```bash
west build -b mimxrt1064_evk --shield dvp_fpc24_mt9m114 --shield rk043fn66hs_ctg samples/subsys/video/capture
```

MIMXRT1170-EVK：

```bash
west build -b mimxrt1170_evk/mimxrt1176/cm7 --shield nxp_btb44_ov5640 --shield rk055hdmipi4ma0 samples/subsys/video/capture
```

Arduino Nicla Vision：

```bash
west build -b arduino_nicla_vision/stm32h747xx/m7 samples/subsys/video/capture
```

FRDM-MCXN947，连接 DVP 20针 OV7670 摄像头模块和 [NXP LCD_PAR_S035显示模块](https://docs.zephyrproject.org/latest/boards/shields/lcd_par_s035/doc/index.html#lcd-par-s035)。后者采用 **薄膜晶体管（Thin-Film Transistor，TFT）**液晶显示技术：

```bash
west build -b frdm_mcxn947/mcxn947/cpu0 --shield dvp_20pin_ov7670 --shield lcd_par_s035_8080 samples/subsys/video/capture
```

STM32H7B3I Discovery kit，使用 ST B-CAMS-OMV-MB1683 扩展板及兼容摄像头：

```bash
west build -b stm32h7b3i_dk --shield st_b_cams_omv_mb1683 samples/subsys/video/capture
```

STM32N6570-DK，使用 ST B-CAMS-IMX-MB1854 摄像头：

```bash
west build -b stm32n6570_dk --shield st_b_cams_imx_mb1854 samples/subsys/video/capture
```

XIAO ESP32S3，使用 Seeed Studio XIAO 圆形显示扩展板：

```bash
west build -b xiao_esp32s3/esp32s3/procpu/sense --shield seeed_xiao_round_display samples/subsys/video/capture
```

## 173.5\_无需真实视频硬件的软件发生器

为了在没有真实视频采集或显示硬件时测试，可在上述构建方式中不指定扩展板，使用[视频软件发生器配置片段（Video Software Generator Snippet）](../snippets/P005_视频软件发生器配置片段.md)。例如使用主机原生仿真目标 `native_sim`：

```bash
west build -b native_sim/native/64 -S video-sw-generator samples/subsys/video/capture
```

## 173.6\_从主机输入视频帧

同样不需要目标视频硬件时，可以使用[视频原生命名管道配置片段（Video Native FIFO Snippet）](../snippets/P006_视频原生命名管道配置片段.md)。它接收主机产生的帧，而不是在设备内部生成帧，因此可接入真实网络摄像头、视频文件或 FFmpeg 的测试源。这里 **先进先出（First In, First Out，FIFO）**在主机上通过命名管道传输帧。

```bash
west build -b native_sim/native/64 -S video-native-fifo samples/subsys/video/capture
```

驱动默认使用 320×240 分辨率和 `RGB565` 像素格式，即红、绿、蓝分别占 5、6、5 位。这也与 `native_sim` 的 **简单直接媒体层（Simple DirectMedia Layer，SDL）**显示窗口匹配，无需额外配置即可显示帧，详见[SDL显示说明](../native_reference/P004_Native_Simulator本机模拟器.md#nsim-per-disp-sdl)。

创建命名管道并启动应用。译注：这段是支持 `mkfifo` 的主机终端分支；以下两段将原文放在系统临时目录中的管道改为源码根目录内的相对路径 `./zephyr-cam.fifo`，以便目录迁移。`mkfifo` 创建的是命名管道，不是普通视频文件；两个终端均先进入同一 Zephyr 源码根目录。原文的 `$` 为提示符，复制执行时不包含它。

```bash
$ mkfifo ./zephyr-cam.fifo
$ build/zephyr/zephyr.exe --video-fifo=./zephyr-cam.fifo
```

然后从第二个终端输入测试图案：

```bash
$ ffmpeg -re -f lavfi -i testsrc2=size=320x240:rate=10 \
    -pix_fmt rgb565le -f rawvideo -y ./zephyr-cam.fifo
```

可以将 FFmpeg 输入替换为 `-f v4l2 -i /dev/video0`，从真实摄像头采集；也可以替换为 `-i <file>` 播放视频文件，并将输出缩放为 320×240。**Linux视频第二版接口（Video for Linux 2，V4L2）**的 `/dev/video0` 是设备节点标识；`<file>` 需替换为实际视频文件。摄像头例子见[原生命名管道驱动说明](../native_reference/P004_Native_Simulator本机模拟器.md#nsim-per-video-fifo)。

## 173.7\_通过命令行控制摄像头

要使用 **命令行交互界面（Shell）**控制摄像头，而不是持续采集，可在构建命令中追加 `-DCONFIG_VIDEO_SHELL=y`：

```bash
west build -b mimxrt1064_evk --shield dvp_fpc24_mt9m114 --shield rk043fn66hs_ctg samples/subsys/video/capture -- -DCONFIG_VIDEO_SHELL=y
```

STM32H7B3I Discovery kit 的对应命令为：

```bash
west build -b stm32h7b3i_dk --shield st_b_cams_omv_mb1683 samples/subsys/video/capture -- -DCONFIG_VIDEO_SHELL=y
```

## 173.8\_示例输出（Sample Output）

以下原文日志列出视频与显示设备能力、默认格式，以及连续收到的帧大小和时间戳。`RGBP`、`YUYV` 为像素格式标识；`<repeats endlessly>` 表示持续重复。

```text
 Video device: csi@402bc000
 - Capabilities:
   RGBP width [480; 480; 0] height [272; 272; 0]
   YUYV width [480; 480; 0] height [272; 272; 0]
   RGBP width [640; 640; 0] height [480; 480; 0]
   YUYV width [640; 640; 0] height [480; 480; 0]
   RGBP width [1280; 1280; 0] height [720; 720; 0]
   YUYV width [1280; 1280; 0] height [720; 720; 0]
 - Default format: RGBP 480x272

 Display device: display-controller@402b8000
 - Capabilities:
   x_resolution = 480, y_resolution = 272, supported_pixel_formats = 40
   current_pixel_format = 32, current_orientation = 0

 Capture started
 Got frame 0! size: 261120; timestamp 249 ms (delta 249 ms)
 Got frame 1! size: 261120; timestamp 282 ms (delta 33 ms)
 Got frame 2! size: 261120; timestamp 316 ms (delta 34 ms)
 Got frame 3! size: 261120; timestamp 350 ms (delta 34 ms)
 Got frame 4! size: 261120; timestamp 384 ms (delta 34 ms)
 Got frame 5! size: 261120; timestamp 418 ms (delta 34 ms)
 Got frame 6! size: 261120; timestamp 451 ms (delta 33 ms)

<repeats endlessly>
```

使用 Shell 时，除非设置 Kconfig 配置选项 `VIDEO_SHELL_AND_CAPTURE`，否则不会自动开始采集。无论是否设置此选项，都可通过 Shell 在运行时修改参数：

```text
uart:~$ video --help
video - Video driver commands
Subcommands:
  start    : Start a video device and its sources
             Usage: start <device>
  stop     : Stop a video device and its sources
             Usage: stop <device>
  capture  : Capture a given number of buffers from a device
             Usage: capture <device> <num-buffers>
  format   : Query or set the video format of a device
             Usage: format <device> <dir> [<fourcc> <width>x<height>]
  frmival  : Query or set the video frame rate/interval of a device
             Usage: frmival <device> [<n>fps|<n>ms|<n>us]
  ctrl     : Query or set video controls of a device
             Usage: ctrl <device> [<ctrl> <value>]
uart:~$
```

译注：原输出中的 `uart:~$` 是通过 **通用异步收发器（Universal Asynchronous Receiver-Transmitter，UART）**访问的 Shell 提示符。`start`/`stop` 启动或停止设备及其源；`capture` 采集指定数量的缓冲区；`format` 查询或设置格式；`frmival` 查询或设置帧率/间隔；`ctrl` 查询或设置视频控制项。`fourcc` 是 **四字符代码（Four-Character Code）**，用于指定像素格式；`fps` 表示每秒帧数（Frames Per Second）。
