# 第162章\_DRV2605触觉驱动示例

原文：[DRV2605 Haptic Driver](https://docs.zephyrproject.org/latest/samples/drivers/haptics/drv2605/README.html)。读取日期：2026-10-13，`latest`。

## 162.1\_概述（Overview）

本示例配置 DRV2605 的 **只读存储器（Read-Only Memory，ROM）**播放事件，播放有节奏的敲击模式（Rhythmic Tapping Pattern）。

## 162.2\_构建与运行（Building and Running）

为 Nucleo F401RE 开发板构建应用，将 DRV2605 连接到 **内部集成电路总线（Inter-Integrated Circuit，I2C）**的 I2C1 控制器上，地址为 `0x5A`。

译注：在配置好 Zephyr 开发环境的终端中，从 Zephyr 源码根目录执行下列官方命令。示例目录由官方仓库提供，构建产物由 west 生成。

```bash
west build -b nucleo_f401re samples/drivers/haptics/drv2605
```

应用烧录方法见[Nucleo F401RE开发板说明](https://docs.zephyrproject.org/latest/boards/st/nucleo_f401re/doc/index.html#nucleo_f401re)的烧录（Flashing）小节。
