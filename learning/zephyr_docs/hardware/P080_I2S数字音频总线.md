# 第80章\_I2S数字音频总线

原文：[Inter-IC Sound (I2S) Bus](https://docs.zephyrproject.org/latest/hardware/peripherals/audio/i2s.html)。读取日期：2026-10-13，`latest`。

## 80.1\_I2S支持的格式

**芯片间声音总线（Inter-IC Sound，I2S）**的 **应用程序编程接口（Application Programming Interface，API）**既支持标准I2S接口，也支持常见非标准扩展，包括 **脉冲编码调制（Pulse Code Modulation，PCM）**的 **短／长帧同步（Short/Long Frame Sync）**以及 **左／右对齐数据格式（Left/Right Justified Data Formats）**。

## 80.2\_通过命令行生成测试音

启用Kconfig配置项 [`CONFIG_I2S_SHELL`](https://docs.zephyrproject.org/latest/kconfig.html#CONFIG_I2S_SHELL) 后，提供 `i2s` **命令行（Shell）**，无需应用代码即可通过I2S控制器传送生成的正弦测试音。该命令只负责传输；要通过 **音频编解码器（Audio Codec）**输出，还需配合codec命令行设置音频路径，编解码器入口见[本地章节](P077_音频编解码器.md)。

音调相关命令统一在 `i2s tone` 下。在目标Zephyr设备shell中执行，前提是固件启用了命令、I2S设备已就绪且需要的硬件路径已配置；不是在主机终端执行。尖括号表示参数占位，方括号表示可选项。

| 命令语法 | 行为 |
| --- | --- |
| `i2s tone start <device> [frequency_hz] [sample_rate] [bits]` | 在指定I2S设备上启动立体声测试音。音调频率默认440 Hz，采样率默认48000 Hz，采样位宽默认16位；有效位宽为16、24、32位。 |
| `i2s tone stop` | 停止正在运行的音调。 |
| `i2s tone info` | 显示当前音调流状态。 |

## 80.3\_原文输出示例

以下例子传送1 kHz测试音，采样率48 kHz，位宽16位：

```text
uart:~$ i2s tone start i2s@0 1000 48000 16
Streaming 1000 Hz tone on i2s@0 @ 48000 Hz, 16-bit stereo
uart:~$ i2s tone info
state    : streaming
i2s dev  : i2s@0
tone     : 1000 Hz
rate     : 48000 Hz
format   : 16-bit stereo, 64-frame blocks x 8
uart:~$ i2s tone stop
Stopped
```

`i2s@0` 是示例设备名，应与实际设备对应；`streaming` 表示流正在发送，`64-frame blocks x 8` 表示所示缓冲组织。控制台显示传输状态并不独自证明编解码器和扬声器路径已经产生声音。`uart:~$` 为串行shell提示符，UART是 **通用异步收发器（Universal Asynchronous Receiver-Transmitter）**。本次没有执行音调播放。

## 80.4\_缓冲与配置

命令行的 **发送（Transmit，TX）**缓冲由 [`CONFIG_I2S_SHELL_BLOCK_FRAMES`](https://docs.zephyrproject.org/latest/kconfig.html#CONFIG_I2S_SHELL_BLOCK_FRAMES)（每块帧数）和 [`CONFIG_I2S_SHELL_BLOCK_COUNT`](https://docs.zephyrproject.org/latest/kconfig.html#CONFIG_I2S_SHELL_BLOCK_COUNT)（块数量）控制。

原页还列出 [`CONFIG_I2S`](https://docs.zephyrproject.org/latest/kconfig.html#CONFIG_I2S) 与 [`CONFIG_I2S_SHELL`](https://docs.zephyrproject.org/latest/kconfig.html#CONFIG_I2S_SHELL)，分别用于I2S和命令行支持。这些都是Kconfig配置项；Kconfig是Zephyr的配置系统。完整类型、函数及约束见[I2S接口参考](https://docs.zephyrproject.org/latest/doxygen/html/group__i2s__interface.html)。
