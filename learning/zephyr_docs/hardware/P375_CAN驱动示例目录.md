# 第375章\_CAN驱动示例目录

## 375.1\_CAN 驱动示例

原文：[Controller Area Network (CAN)](https://docs.zephyrproject.org/latest/samples/drivers/can/index.html)。读取日期：2026-10-13，`latest`。

以下示例演示控制器局域网（Controller Area Network，CAN）驱动应用程序编程接口（Application Programming Interface，API）的使用。

- [CAN 异常持续发送节点（Babbling Node）](P045_CAN持续发送示例.md)：模拟持续占用 CAN 总线的异常节点。
- [CAN 计数器（Counter）](P044_CAN计数器示例.md)：发送和接收 CAN 消息。

驱动接口说明参见 [CAN 控制器](https://docs.zephyrproject.org/latest/hardware/peripherals/can/index.html#can)。
