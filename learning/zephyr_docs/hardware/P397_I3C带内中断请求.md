# 第397章\_I3C带内中断请求

原文：[structi3c__ibi](https://docs.zephyrproject.org/latest/doxygen/html/structi3c__ibi.html)。读取日期：2026-10-13，`latest`。

## 397.1\_请求结构

`struct i3c_ibi` 描述**改进的集成电路间总线（Improved Inter-Integrated Circuit，I3C）**上的**带内中断（In-Band Interrupt，IBI）**请求。头文件为 `zephyr/drivers/i3c/ibi.h`。

## 397.2\_字段

**载荷（Payload）**是随请求携带的数据，以下字段指定中断类型、载荷地址和字节数。

| 字段 | 类型 | 含义 |
| --- | --- | --- |
| [`ibi_type`](https://docs.zephyrproject.org/latest/doxygen/html/structi3c__ibi.html#a88b0ccd636c042ca929412c42a05bc25) | `enum i3c_ibi_type` | IBI 类型，参见[带内中断接口](P396_I3C带内中断接口.md)。 |
| [`payload`](https://docs.zephyrproject.org/latest/doxygen/html/structi3c__ibi.html#a584e3298059e412d7d3671a451ecc117) | `uint8_t *` | 指向 IBI 载荷的指针。 |
| [`payload_len`](https://docs.zephyrproject.org/latest/doxygen/html/structi3c__ibi.html#aa51b8214d4a0708861ac9617f844043f) | [`uint8_t`](https://docs.zephyrproject.org/latest/doxygen/html/stdint_8h.html#a3cb4a16b0e8d6af0af86d4fd6ba5fd9d) | IBI 载荷长度，单位为字节。 |
