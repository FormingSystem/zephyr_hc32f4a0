# 第419章\_I3C目标清单命令数据

原文：[structi3c__ccc__deftgts](https://docs.zephyrproject.org/latest/doxygen/html/structi3c__ccc__deftgts.html)。读取日期：2026-10-13，`latest`。

## 419.1\_DEFTGTS载荷

`struct i3c_ccc_deftgts` 是**改进的集成电路间总线（Improved Inter-Integrated Circuit，I3C）通用命令码（Common Command Code，CCC）** `DEFTGTS` 的载荷（Payload）。命令含义为**定义目标列表（Define List of Targets）**。头文件为 `zephyr/drivers/i3c/ccc.h`。

## 419.2\_字段

| 字段 | 类型 | 含义 |
| --- | --- | --- |
| [`count`](https://docs.zephyrproject.org/latest/doxygen/html/structi3c__ccc__deftgts.html#a82a12e711417111855d76171fbd008c2) | [`uint8_t`](https://docs.zephyrproject.org/latest/doxygen/html/stdint_8h.html#a3cb4a16b0e8d6af0af86d4fd6ba5fd9d) | I3C 总线上存在的目标及组的数量。 |
| [`active_controller`](https://docs.zephyrproject.org/latest/doxygen/html/structi3c__ccc__deftgts.html#a1f59c280bd388eb7e7818eb674b5f12f) | `struct i3c_ccc_deftgts_active_controller` | 描述当前活动控制器的数据。 |
| [`targets`](https://docs.zephyrproject.org/latest/doxygen/html/structi3c__ccc__deftgts.html#a3ead83f46d63c4dd4723ef76dba770ee) | `struct i3c_ccc_deftgts_target []` | 描述总线目标设备的数组。 |

`targets` 是目标数组，元素数量取决于总线上的 I3C 目标数量。无论读取还是写入此 CCC，都必须准备足够的存储空间。

活动控制器和目标元素分别见[活动控制器数据](P420_I3C目标清单活动控制器.md)、[目标设备项](P421_I3C目标清单设备项.md)。
