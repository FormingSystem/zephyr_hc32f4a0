# 第216章\_显示能力结构

原文：[structdisplay__capabilities](https://docs.zephyrproject.org/latest/doxygen/html/structdisplay__capabilities.html)。读取日期：2026-10-13，`latest`。

## 216.1\_用途

结构 [`display_capabilities`](https://docs.zephyrproject.org/latest/doxygen/html/structdisplay__capabilities.html) 保存显示能力（Display Capabilities），定义来自官方头文件 `zephyr/drivers/display.h`，由[显示公共接口](P214_显示公共接口.md)中的能力查询函数填充。

## 216.2\_数据字段（Data Fields）

`CONFIG_DISPLAY_COLOR_PALETTE_MAX_SIZE` 是配置系统 Kconfig 的调色板容量配置项，决定下面数组的元素数。像素格式（Pixel Format）、显示方向（Display Orientation）与事件枚举详见公共接口页。

| 字段 | 类型 | 含义 |
| --- | --- | --- |
| [`x_resolution`](https://docs.zephyrproject.org/latest/doxygen/html/structdisplay__capabilities.html#a09fa14e2c53126d5602cb7b51e21145f) | [`uint16_t`](https://docs.zephyrproject.org/latest/doxygen/html/stdint_8h.html#a5debae8b2a1ec20a6694c0c443ee399e) | X 方向的显示分辨率。 |
| [`y_resolution`](https://docs.zephyrproject.org/latest/doxygen/html/structdisplay__capabilities.html#a2cacb194139aaff90fd56b469f6de4a9) | [`uint16_t`](https://docs.zephyrproject.org/latest/doxygen/html/stdint_8h.html#a5debae8b2a1ec20a6694c0c443ee399e) | Y 方向的显示分辨率。 |
| [`supported_pixel_formats`](https://docs.zephyrproject.org/latest/doxygen/html/structdisplay__capabilities.html#a07548bdd9671dd696b38a5bcf1599412) | [`uint32_t`](https://docs.zephyrproject.org/latest/doxygen/html/stdint_8h.html#a0a8582351ac627ee8bde2973c825e47f) | 显示器支持的各像素格式进行按位或（Bitwise OR）的结果。 |
| [`screen_info`](https://docs.zephyrproject.org/latest/doxygen/html/structdisplay__capabilities.html#ac4a9098db4c2f721fa550c6142f541a9) | [`uint32_t`](https://docs.zephyrproject.org/latest/doxygen/html/stdint_8h.html#a0a8582351ac627ee8bde2973c825e47f) | 显示面板信息。 |
| [`current_pixel_format`](https://docs.zephyrproject.org/latest/doxygen/html/structdisplay__capabilities.html#aed51c9efdc76972fecfa8a733c2a8d0c) | `enum display_pixel_format` | 当前启用的显示像素格式。 |
| [`current_orientation`](https://docs.zephyrproject.org/latest/doxygen/html/structdisplay__capabilities.html#a18986f5d2c385766d5ad3d68edd85887) | `enum display_orientation` | 当前显示方向。 |
| [`supported_events`](https://docs.zephyrproject.org/latest/doxygen/html/structdisplay__capabilities.html#a13d647aa8d6331f17cbc567970b159e7) | [`uint32_t`](https://docs.zephyrproject.org/latest/doxygen/html/stdint_8h.html#a0a8582351ac627ee8bde2973c825e47f) | 支持的回调事件掩码；不支持事件回调时为 0。 |
| [`color_palette`](https://docs.zephyrproject.org/latest/doxygen/html/structdisplay__capabilities.html#ad9a0b9f3cf2ffcb8a768071f4211cf3c) | `struct display_palette_color[CONFIG_DISPLAY_COLOR_PALETTE_MAX_SIZE]` | 显示器支持的调色板（Color Palette），以像素值作为索引。 |

单个颜色条目的完整字段见[显示调色板颜色](P218_显示调色板颜色.md)。
