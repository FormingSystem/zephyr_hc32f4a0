# 第127章\_独立步进运动控制器与驱动器

原文：[Individual Stepper Motion Controller and Driver](https://docs.zephyrproject.org/latest/hardware/peripherals/stepper/individual_controller_driver.html)。读取日期：2026-10-13，`latest`。

## 127.1\_独立控制器连接硬件驱动器

以下原例为具有独立 **步进运动控制器（Stepper Motion Controller）**的 **步进硬件驱动器（Stepper Hardware Driver）**配置 **设备树（Devicetree）**。

TMC2209是驱动芯片型号；`tmc2209` 节点提供使能和细分配置。另一个节点 `step_dir_motion_control` 通过 **步进／方向（Step/Direction，STEP/DIR）**线路执行运动控制，并以 `stepper-driver` 属性引用硬件驱动器。

引脚由 **通用输入输出（General-Purpose Input/Output，GPIO）**控制；原代码中的 `GPIO_ACTIVE_HIGH` 表示高电平有效，`invert-direction` 表示反转方向。

```devicetree
/ {
    aliases {
        stepper_driver = &tmc2209
        stepper_ctrl = &step_dir_motion_control;
    };

    tmc2209: tmc2209 {
        compatible = "adi,tmc2209";
        enable-gpios = <&gpioa 6 GPIO_ACTIVE_HIGH>;
        m0-gpios = <&gpiob 0 GPIO_ACTIVE_HIGH>;
        m1-gpios = <&gpioa 7 GPIO_ACTIVE_HIGH>;
    };

    step_dir_motion_control: step-dir-motion-control {
        compatible = "zephyr,gpio-step-dir-stepper-ctrl";
        step-gpios = <&gpioa 9 GPIO_ACTIVE_HIGH>;
        dir-gpios = <&gpioc 7 GPIO_ACTIVE_HIGH>;
        invert-direction;
        stepper-driver = <&tmc2209>;
    };
};
```

> 译注：原片段中 `stepper_driver = &tmc2209` 行末缺少分号；此外，设备树的 `/aliases` 节点下别名属性只允许小写字母、数字和连字符，原例中的 `stepper_driver` 与 `stepper_ctrl` 含有下划线。用于实际工程时，应补充分号并把别名属性写为 `stepper-driver`、`stepper-ctrl`。C端 `DT_ALIAS(stepper_driver)`、`DT_ALIAS(stepper_ctrl)` 仍使用下划线形式。此规则已对照本仓库[设备树解析器](../../../scripts/dts/python-devicetree/src/devicetree/dtlib.py)的别名校验；本章保留原片段以便比对来源。`/aliases` 是设备树节点路径，不是主机文件路径。

## 127.2\_应用分别使用两个设备

`DEVICE_DT_GET` 是设备对象获取宏，`DT_ALIAS` 是设备树别名查询宏。原应用片段分别取得驱动器指针 `stepper_driver` 和控制器指针 `stepper_ctrl`，调用运动控制函数移动到位置200、停止控制器，最后禁用硬件驱动器：

```c
static const struct device *stepper_driver = DEVICE_DT_GET(DT_ALIAS(stepper_driver));
static const struct device *stepper_ctrl = DEVICE_DT_GET(DT_ALIAS(stepper_ctrl));
...
stepper_ctrl_move_to(stepper_ctrl, 200);
stepper_ctrl_stop(stepper_ctrl);
stepper_disable(stepper_driver);
```

省略号表示未展示的应用代码；这不是一个完整可编译源文件，也未展示就绪检查、使能和异步完成处理。运动位置单位与接口用途见[步进电机](P126_步进电机.md)。本章未接线或运行电机。
