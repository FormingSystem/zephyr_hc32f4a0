# 第423章\_I3C桥接目标设备项

原文：[structi3c__ccc__setbrgtgt__tgt](https://docs.zephyrproject.org/latest/doxygen/html/structi3c__ccc__setbrgtgt__tgt.html)。读取日期：2026-10-13，`latest`。

## 423.1\_单个桥接目标

`struct i3c_ccc_setbrgtgt_tgt` 描述 `SETBRGTGT` 载荷中的一个桥接目标（Bridged Target）。`SETBRGTGT` 是**改进的集成电路间总线（Improved Inter-Integrated Circuit，I3C）通用命令码（Common Command Code，CCC）**，用于设置桥接目标（Set Bridge Targets）。头文件为 `zephyr/drivers/i3c/ccc.h`。

## 423.2\_地址与标识

| 字段 | 类型 | 含义 |
| --- | --- | --- |
| [`addr`](https://docs.zephyrproject.org/latest/doxygen/html/structi3c__ccc__setbrgtgt__tgt.html#a6fa24f8354e856031464aaaa2c8fd1bb) | [`uint8_t`](https://docs.zephyrproject.org/latest/doxygen/html/stdint_8h.html#a3cb4a16b0e8d6af0af86d4fd6ba5fd9d) | 桥接目标的动态地址（Dynamic Address）。 |
| [`id`](https://docs.zephyrproject.org/latest/doxygen/html/structi3c__ccc__setbrgtgt__tgt.html#a1dca2717ca9502f11b300a0d9a1fc0e6) | [`uint16_t`](https://docs.zephyrproject.org/latest/doxygen/html/stdint_8h.html#a5debae8b2a1ec20a6694c0c443ee399e) | 桥接目标的 16 位标识符（Identifier，ID）。 |

`addr` 的地址值左移 1 位，第 0 位始终为 0。

对于驱动和辅助函数，目标设备返回的 `id` 原始数据采用**大端字节序（Big-endian）**。在把结果交给调用者之前，必须转换为**中央处理器（Central Processing Unit，CPU）**所用的字节序。
