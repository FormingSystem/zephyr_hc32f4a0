# 第474章\_设备仿真与模拟

原文：[Zephyr’s device emulators/simulators](https://docs.zephyrproject.org/latest/hardware/emulator/index.html)。读取日期：2026-10-13，`latest`。

## 474.1\_概述与范围

Zephyr 代码库包含一组设备仿真器/模拟器（Device Emulators/Simulators）。这里指与嵌入式软件一起构建的软件组件，它们向系统其他部分表现为特定类别的设备。

这些组件可以为任何具有足够随机存取存储器（Random Access Memory，RAM）和闪存（Flash）的目标构建；个别组件的额外功能可能只在某些目标上可用。

Zephyr 还使用许多其他类型的模拟器或仿真器，包括中央处理器（Central Processing Unit，CPU）、平台和无线电模拟器，以及能在开发主机运行嵌入式代码的构建目标。一些通信控制器/驱动还提供回环（Loopback）模式或设备。**这些均不属于本页范围。**

特定平台专用驱动也不在本页范围内，例如 [native_sim 专用外设驱动](../native_reference/P004_Native_Simulator本机模拟器.md#native-sim-peripherals)，它们通过连接主机应用程序接口（Application Programming Interface，API）模拟某类外设。

## 474.2\_可用的设备仿真与模拟组件

下表保留官方组件、主要 Kconfig 配置项及设备树（Devicetree，DT）绑定。EEPROM 表示电可擦可编程只读存储器（Electrically Erasable Programmable Read-Only Memory）。

| 组件 | 用途 | 主要配置项 | 设备树绑定 |
| --- | --- | --- | --- |
| ADC 仿真器 | 假扮实际模数转换器（Analog-to-Digital Converter，ADC）的驱动，用于测试 ADC 上层 API | [`CONFIG_ADC_EMUL`](https://docs.zephyrproject.org/latest/kconfig.html#CONFIG_ADC_EMUL) | [zephyr,adc-emul](https://docs.zephyrproject.org/latest/build/dts/api/bindings/adc/zephyr%2Cadc-emul.html#std-dtcompatible-zephyr-adc-emul) |
| DMA 仿真器 | 仿真直接存储器访问（Direct Memory Access，DMA）控制器 | [`CONFIG_DMA_EMUL`](https://docs.zephyrproject.org/latest/kconfig.html#CONFIG_DMA_EMUL) | [zephyr,dma-emul](https://docs.zephyrproject.org/latest/build/dts/api/bindings/dma/zephyr%2Cdma-emul.html#std-dtcompatible-zephyr-dma-emul) |
| EEPROM 仿真器 | 在闪存分区上仿真 EEPROM | [`CONFIG_EEPROM_EMULATOR`](https://docs.zephyrproject.org/latest/kconfig.html#CONFIG_EEPROM_EMULATOR) | [zephyr,emu-eeprom](https://docs.zephyrproject.org/latest/build/dts/api/bindings/mtd/zephyr%2Cemu-eeprom.html#std-dtcompatible-zephyr-emu-eeprom) |
| EEPROM 模拟器 | 在 RAM 上模拟 EEPROM | [`CONFIG_EEPROM_SIMULATOR`](https://docs.zephyrproject.org/latest/kconfig.html#CONFIG_EEPROM_SIMULATOR) | [zephyr,sim-eeprom](https://docs.zephyrproject.org/latest/build/dts/api/bindings/mtd/zephyr%2Csim-eeprom.html#std-dtcompatible-zephyr-sim-eeprom) |
| 外部总线及外设仿真器 | 仿真 I2C、SPI 等外部总线及相连外设 | 见[外部总线与外设仿真](P475_外部总线与外设仿真.md) | 见对应总线绑定 |
| 闪存模拟器 | 在 RAM 上模拟闪存 | [`CONFIG_FLASH_SIMULATOR`](https://docs.zephyrproject.org/latest/kconfig.html#CONFIG_FLASH_SIMULATOR) | [zephyr,sim-flash](https://docs.zephyrproject.org/latest/build/dts/api/bindings/flash_controller/zephyr%2Csim-flash.html#std-dtcompatible-zephyr-sim-flash) |
| GPIO 仿真器 | 可由软件驱动的通用输入输出（General-Purpose Input/Output，GPIO）控制器 | [`CONFIG_GPIO_EMUL`](https://docs.zephyrproject.org/latest/kconfig.html#CONFIG_GPIO_EMUL) | [zephyr,gpio-emul](https://docs.zephyrproject.org/latest/build/dts/api/bindings/gpio/zephyr%2Cgpio-emul.html#std-dtcompatible-zephyr-gpio-emul) |
| I2C 仿真器 | 集成电路互连（Inter-Integrated Circuit，I2C）总线仿真 | [`CONFIG_I2C_EMUL`](https://docs.zephyrproject.org/latest/kconfig.html#CONFIG_I2C_EMUL) | [zephyr,i2c-emul-controller](https://docs.zephyrproject.org/latest/build/dts/api/bindings/i2c/zephyr%2Ci2c-emul-controller.html#std-dtcompatible-zephyr-i2c-emul-controller) |
| RTC 仿真器 | 实时时钟（Real-Time Clock，RTC）外设仿真 | [`CONFIG_RTC_EMUL`](https://docs.zephyrproject.org/latest/kconfig.html#CONFIG_RTC_EMUL) | [zephyr,rtc-emul](https://docs.zephyrproject.org/latest/build/dts/api/bindings/rtc/zephyr%2Crtc-emul.html#std-dtcompatible-zephyr-rtc-emul) |
| SPI 仿真器 | 串行外设接口（Serial Peripheral Interface，SPI）总线仿真 | [`CONFIG_SPI_EMUL`](https://docs.zephyrproject.org/latest/kconfig.html#CONFIG_SPI_EMUL) | [zephyr,spi-emul-controller](https://docs.zephyrproject.org/latest/build/dts/api/bindings/spi/zephyr%2Cspi-emul-controller.html#std-dtcompatible-zephyr-spi-emul-controller) |
| MSPI 仿真器 | 多线串行外设接口（Multi-bit Serial Peripheral Interface，MSPI）总线仿真 | [`CONFIG_MSPI_EMUL`](https://docs.zephyrproject.org/latest/kconfig.html#CONFIG_MSPI_EMUL) | [zephyr,mspi-emul-controller](https://docs.zephyrproject.org/latest/build/dts/api/bindings/mspi/zephyr%2Cmspi-emul-controller.html#std-dtcompatible-zephyr-mspi-emul-controller) |
| UART 仿真器 | 通用异步收发器（Universal Asynchronous Receiver/Transmitter，UART）总线仿真 | [`CONFIG_UART_EMUL`](https://docs.zephyrproject.org/latest/kconfig.html#CONFIG_UART_EMUL) | [zephyr,uart-emul](https://docs.zephyrproject.org/latest/build/dts/api/bindings/serial/zephyr%2Cuart-emul.html#std-dtcompatible-zephyr-uart-emul) |

## 474.3\_主机持久化与专题入口

对于原生目标（Native Target），EEPROM 模拟器也可以将内容保存为主机文件系统中的文件。闪存模拟器同样支持这一方式，参见 [native_sim 闪存模拟器](../native_reference/P004_Native_Simulator本机模拟器.md#nsim-per-flash-simu)。

I2C、SPI、MSPI 和 UART 仿真器的相关介绍见[总线仿真专题](P475_外部总线与外设仿真.md)。RTC 的说明见[RTC 仿真设备](https://docs.zephyrproject.org/latest/hardware/peripherals/rtc.html#rtc-api-emul-dev)。
