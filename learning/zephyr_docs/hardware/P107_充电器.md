# 第107章\_充电器

原文：[Chargers](https://docs.zephyrproject.org/latest/hardware/peripherals/charger.html)。读取日期：2026-10-13，`latest`。

## 107.1\_充电器及充电周期

**充电器（Charger）**子系统提供统一访问电池充电设备的 **应用程序编程接口（Application Programming Interface，API）**。

充电器设备或外设以系统获得的外部电源为输入，向下游电池组及系统供电。它可以是一个模块、一颗 **集成电路（Integrated Circuit，IC）**，也可以是 **电源管理集成电路（Power Management Integrated Circuit，PMIC）**中的功能模块。

对电池组执行充电的过程称为 **充电周期（Charge Cycle）**。执行该周期时，充电器按已配置的 **充电特性（Charge Profile）**为电池充电。充电特性由制造商提供的电池组规格定义。对于带控制端口的充电器，主控制器可以通过相关属性配置充电特性，并在运行时调整它以响应环境变化。

## 107.2\_启动、结束与属性访问

通过函数 [`charger_charge_enable()`](https://docs.zephyrproject.org/latest/doxygen/html/group__charger__interface.html#gace1ea9841574d75d314db078df5a0b3a) 启动或终止充电周期。

**属性（Property）**在这里可以是可配置的设置、状态，也可以是充电器能够测量的物理量。充电器通常支持多个属性，例如电池组温度、当前电流或电压。

客户端调用 [`charger_get_prop()`](https://docs.zephyrproject.org/latest/doxygen/html/group__charger__interface.html#ga00e5b61d517c93d7d3c863b14b07b738) 逐个获取属性，调用 [`charger_set_prop()`](https://docs.zephyrproject.org/latest/doxygen/html/group__charger__interface.html#ga0036e3f5924585457a99a2e444ef5aab) 逐个设置属性。这里的“当前”指读取时的状态，不代表所有充电器都支持每一种属性。
