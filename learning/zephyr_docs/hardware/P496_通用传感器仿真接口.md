# 第496章\_通用传感器仿真接口

原文：[group__generic__emul](P496_通用传感器仿真接口.md)。读取日期：2026-10-13，`latest`。

**通用传感器仿真器（Generic Sensor Emulator）**用于测试。控制这一测试设备的接口位于 `zephyr/drivers/sensor/generic_emul.h`，支持重置通道以及指定常用操作的返回码。

## 496.1\_重置通道

[`generic_emul_reset()`](P496_通用传感器仿真接口.md) 将全部通道恢复为未配置状态。

```c
void generic_emul_reset(const struct emul *target, bool reset_rc);
```

参数 `target` 是要重置的通用传感器仿真器，`reset_rc` 表示是否重置**返回码（Return Code）**。函数没有返回值。

## 496.2\_配置操作返回码

[`generic_emul_func_rc()`](P496_通用传感器仿真接口.md) 配置通用传感器设备的操作返回值，使测试能控制恢复、挂起及样本获取的结果。

```c
void generic_emul_func_rc(const struct emul *target,
                         int resume_rc, int suspend_rc, int fetch_rc);
```

| 参数 | 含义 |
| --- | --- |
| `target` | 要配置的通用传感器仿真器 |
| `resume_rc` | `PM_DEVICE_ACTION_RESUME` 的返回码，即设备恢复（Resume）动作的结果 |
| `suspend_rc` | `PM_DEVICE_ACTION_SUSPEND` 的返回码，即设备挂起（Suspend）动作的结果 |
| `fetch_rc` | `sensor_sample_fetch` 的返回码，即传感器样本获取操作的结果 |

这里 PM 指**电源管理（Power Management）**，两个 `PM_DEVICE_ACTION_*` 标识是设备电源管理动作。函数没有返回值。
