# 第190章\_IS31FL3733灯矩阵示例

原文：[IS31FL3733 LED Matrix](https://docs.zephyrproject.org/latest/samples/drivers/led/is31fl3733/README.html)。读取日期：2026-10-13，`latest`。

## 190.1\_概述（Overview）

本示例控制最多由 192 个 **发光二极管（Light-Emitting Diode，LED）**组成的矩阵，并无限重复下列测试步骤。各操作使用相应的 **应用程序编程接口（Application Programming Interface，API）**：

1. 用 [`led_write_channels()`](P202_LED公共接口.md) 把全部 LED 设置为最高亮度。
2. 用 [`led_write_channels()`](P202_LED公共接口.md) 关闭灯阵上方的一个象限（Upper Quadrant）。
3. 用 [`led_set_brightness()`](P202_LED公共接口.md) 依次调暗每一个 LED。
4. 用 [`led_on()`](P202_LED公共接口.md) 和关灯接口依次切换每一个 LED 的开关状态。
5. 用 [`is31fl3733_current_limit()`](https://docs.zephyrproject.org/latest/doxygen/html/is31fl3733_8h.html#ad3de611ed4641cccaaa0920cee160eed) 在低、高电流限制（Current Limit）之间切换，再重复上述测试。

译注：第 4 步原文把关灯函数拼作 `led_of()`；正式 [LED接口](P202_LED公共接口.md)名为 `led_off()`。

## 190.2\_示例配置（Sample Configuration）

可以通过本示例专用的 Kconfig 配置项限制 LED 数量：`CONFIG_LED_ROW_COUNT` 指定行数，`CONFIG_LED_COLUMN_COUNT` 指定列数。

## 190.3\_构建与运行（Building and Running）

本示例可以运行在通过 **内部集成电路总线（Inter-Integrated Circuit，I2C）**连接 IS31FL3733 的开发板上，其 **设备树（Devicetree）**中必须具有兼容标识（Compatible）为 [`issi,is31fl3733`](../led_issi_nordic_nxp_binding_reference/P009_issi_is31fl3733.md#std-dtcompatible-issi-is31fl3733) 的节点。

官方为 [FRDM-K22F](https://docs.zephyrproject.org/latest/boards/nxp/frdm_k22f/doc/index.html#frdm_k22f) 提供设备树源（Devicetree Source，DTS）叠加文件 `boards/frdm_k22f.overlay`，路径相对于本示例目录。该配置假定控制器位于 I2C0 总线上，地址为 `0x50`；SDB 控制引脚对应的 **通用输入输出（General-Purpose Input/Output，GPIO）**应连接到 PTC2，也就是 Arduino 排针上的 A3。
