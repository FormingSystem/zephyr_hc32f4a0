# 第77章\_音频编解码器

原文：[Audio Codec](https://docs.zephyrproject.org/latest/hardware/peripherals/audio/codec.html)。读取日期：2026-10-13，`latest`。

## 77.1\_访问数字音频编解码器

**音频编解码器（Audio Codec）**的 **应用程序编程接口（Application Programming Interface，API）**提供对数字音频编解码器的访问。本页是该驱动接口的概览，原文没有进一步展开数据路径或操作代码。

## 77.2\_配置与接口参考

相关Kconfig配置项为 [`CONFIG_AUDIO_CODEC`](https://docs.zephyrproject.org/latest/kconfig.html#CONFIG_AUDIO_CODEC)，用于音频编解码器支持；Kconfig是Zephyr的配置系统。

完整函数、类型和参数见[音频编解码器接口参考](https://docs.zephyrproject.org/latest/doxygen/html/group__audio__codec__interface.html)。具体设备是否支持某项控制能力，应以相应驱动与器件说明为准。
