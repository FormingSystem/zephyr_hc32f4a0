# 第146章\_蜂鸣器驱动操作表

原文：[structbuzzer__driver__api](https://docs.zephyrproject.org/latest/doxygen/html/structbuzzer__driver__api.html)。读取日期：2026-10-13，`latest`。

## 146.1\_操作表结构与必需字段

`buzzer_driver_api` 是每个 **蜂鸣器（Buzzer）**驱动都需要定义的 **驱动操作表（Driver Operations）**结构。它保存驱动操作的函数指针，以及任何其他驱动特定的常量数据。定义来自 `zephyr/drivers/buzzer.h`。

原文规定，标记 **必需（Required，REQ）**的字段必须由驱动设置，标记 **可选（Optional，OPT）**的字段才可省略。本表四项**全部为REQ**。

## 146.2\_全部四个字段

| 字段 | 类型 | 要求与用途 |
| --- | --- | --- |
| [`tone`](https://docs.zephyrproject.org/latest/doxygen/html/structbuzzer__driver__api.html#a49d9150361b55a6e6f7f082cea7bc484) | [`buzzer_tone_t`](https://docs.zephyrproject.org/latest/doxygen/html/group__buzzer__interface__backend.html#gac6ae53a4674a3c1ca96a7e41735f9ff3) | REQ；以 `freq_hz` 指定频率播放 `duration_ms` 时长的音调。 |
| [`set_volume`](https://docs.zephyrproject.org/latest/doxygen/html/structbuzzer__driver__api.html#a43e80b2dfc113835c30a7f7de7617244) | [`buzzer_set_volume_t`](https://docs.zephyrproject.org/latest/doxygen/html/group__buzzer__interface__backend.html#ga19d504c3b6dc816706d5cdd9dec37e3f) | REQ；设置蜂鸣器音量。 |
| [`beep`](https://docs.zephyrproject.org/latest/doxygen/html/structbuzzer__driver__api.html#a3a3154d8eaf631acbc1056a7126bfe64) | [`buzzer_beep_t`](https://docs.zephyrproject.org/latest/doxygen/html/group__buzzer__interface__backend.html#gae36ee5133f2877ee6bd119214744b362) | REQ；播放默认音调，持续 `duration_ms`。 |
| [`stop`](https://docs.zephyrproject.org/latest/doxygen/html/structbuzzer__driver__api.html#a2a1984f5925f744a57d10238377bc3e6) | [`buzzer_stop_t`](https://docs.zephyrproject.org/latest/doxygen/html/group__buzzer__interface__backend.html#gad6e97a02e02eaf1f127203a856018cf3) | REQ；停止正在播放的音调。 |

字段的完整限定名分别为 `buzzer_driver_api::tone`、`buzzer_driver_api::set_volume`、`buzzer_driver_api::beep`、`buzzer_driver_api::stop`。类型签名见[驱动后端](P145_蜂鸣器驱动后端.md)，操作语义见[公共接口](P144_蜂鸣器接口参考.md)。
