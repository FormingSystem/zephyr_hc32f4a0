# 第392章\_I3C目标硬件配置

原文：[structi3c__config__target](https://docs.zephyrproject.org/latest/doxygen/html/structi3c__config__target.html)。读取日期：2026-10-13，`latest`。

## 392.1\_配置用途

`struct i3c_config_target` 配置**改进的集成电路间总线（Improved Inter-Integrated Circuit，I3C）**硬件，使其作为**目标设备（Target Device）**运行。若控制器需要作为总线目标设备，此结构也可用于配置该控制器。头文件为 `zephyr/drivers/i3c/target_device.h`。

## 392.2\_角色与地址

**动态地址（Dynamic Address）**表示当前分配的地址；**静态地址（Static Address）**用于次级控制器或目标设备角色。

| 字段 | 类型 | 含义 |
| --- | --- | --- |
| [`enabled`](https://docs.zephyrproject.org/latest/doxygen/html/structi3c__config__target.html#a25b0837f2363f880936391d9baed1d1e) | [`bool`](https://docs.zephyrproject.org/latest/doxygen/html/stdbool_8h.html#abb452686968e48b67397da5f97445f5b) | 硬件当前是否正在总线上充当目标设备。 |
| [`dynamic_addr`](https://docs.zephyrproject.org/latest/doxygen/html/structi3c__config__target.html#aac5e8a92468df108ce964bb6a9a7ae9c) | [`uint8_t`](https://docs.zephyrproject.org/latest/doxygen/html/stdint_8h.html#a3cb4a16b0e8d6af0af86d4fd6ba5fd9d) | 当前分配的 I3C 目标动态地址；未分配时为 0。 |
| [`static_addr`](https://docs.zephyrproject.org/latest/doxygen/html/structi3c__config__target.html#ab5345d23ba2afffbf48010e7edff3c26) | [`uint8_t`](https://docs.zephyrproject.org/latest/doxygen/html/stdint_8h.html#a3cb4a16b0e8d6af0af86d4fd6ba5fd9d) | I3C 目标静态地址，在作为次级控制器或目标设备运行时使用。 |

原说明明确：只有硬件充当**主控制器（Primary Controller）**时，`dynamic_addr` 才可写。

## 392.3\_预置标识

**预置标识（Provisioned ID，PID）**由 [`pid`](https://docs.zephyrproject.org/latest/doxygen/html/structi3c__config__target.html#a62e1b1a3dff6cc570ecccdfcfc6b196d) 字段保存。[`pid_random`](https://docs.zephyrproject.org/latest/doxygen/html/structi3c__config__target.html#a2ad289658811d142ba9091574acf485b) 标记其中低 32 位是否为随机值。

| 字段 | 类型 | 含义 |
| --- | --- | --- |
| `pid` | [`uint64_t`](https://docs.zephyrproject.org/latest/doxygen/html/stdint_8h.html#a2095b9bffea4b2656950c6c0419edbf1) | 预置标识。 |
| `pid_random` | [`bool`](https://docs.zephyrproject.org/latest/doxygen/html/stdbool_8h.html#abb452686968e48b67397da5f97445f5b) | 为 `true` 时表示 PID 的低 32 位为随机值。 |

`pid_random` 设置 PID 的第 32 位，该位表示其低 32 位是随机值。

## 392.4\_设备特征与长度限制

**总线特征寄存器（Bus Characteristics Register，BCR）**和**设备特征寄存器（Device Characteristics Register，DCR）**记录相应特征；**最大读取长度（Maximum Read Length，MRL）**和**最大写入长度（Maximum Write Length，MWL）**记录传输长度限制。

| 字段 | 类型 | 含义 |
| --- | --- | --- |
| [`bcr`](https://docs.zephyrproject.org/latest/doxygen/html/structi3c__config__target.html#a1d0b97d6428e471bcf9b6945da947b36) | [`uint8_t`](https://docs.zephyrproject.org/latest/doxygen/html/stdint_8h.html#a3cb4a16b0e8d6af0af86d4fd6ba5fd9d) | 总线特征寄存器。 |
| [`dcr`](https://docs.zephyrproject.org/latest/doxygen/html/structi3c__config__target.html#afaa68c94b35f512a597b35752db8d66e) | [`uint8_t`](https://docs.zephyrproject.org/latest/doxygen/html/stdint_8h.html#a3cb4a16b0e8d6af0af86d4fd6ba5fd9d) | 设备特征寄存器。 |
| [`max_read_len`](https://docs.zephyrproject.org/latest/doxygen/html/structi3c__config__target.html#a4339c8dd33b17ce8363bf28177411830) | [`uint16_t`](https://docs.zephyrproject.org/latest/doxygen/html/stdint_8h.html#a5debae8b2a1ec20a6694c0c443ee399e) | 最大读取长度。 |
| [`max_write_len`](https://docs.zephyrproject.org/latest/doxygen/html/structi3c__config__target.html#aca4dc4aa873ca447d06e573d485ab854) | [`uint16_t`](https://docs.zephyrproject.org/latest/doxygen/html/stdint_8h.html#a5debae8b2a1ec20a6694c0c443ee399e) | 最大写入长度。 |
| [`supported_hdr`](https://docs.zephyrproject.org/latest/doxygen/html/structi3c__config__target.html#a78a74f81e632a428db59803b55239419) | [`uint8_t`](https://docs.zephyrproject.org/latest/doxygen/html/stdint_8h.html#a3cb4a16b0e8d6af0af86d4fd6ba5fd9d) | 支持的高数据速率（High Data Rate，HDR）模式（0—7）的位掩码。 |
