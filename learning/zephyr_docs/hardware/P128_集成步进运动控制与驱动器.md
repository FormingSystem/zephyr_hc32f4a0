# 第128章\_集成步进运动控制与驱动器

原文：[Integrated Stepper Motion Control and Driver](https://docs.zephyrproject.org/latest/hardware/peripherals/stepper/integrated_controller_driver.html)。读取日期：2026-10-13，`latest`。

## 128.1\_一颗芯片内的两个软件角色

若一颗 **集成电路（Integrated Circuit，IC）**同时包含运动控制器和步进驱动器模块，设备树会将它建模为 **多功能设备（Multi-Function Device，MFD）**。软件仍有两个驱动，分别实现 **步进运动控制器（Stepper Motion Controller）**和 **步进硬件驱动器（Stepper Hardware Driver）**的 **应用程序编程接口（Application Programming Interface，API）**。

原例器件为 [adi,tmc50xx](../stepper_binding_reference/P004_adi_tmc50xx.md#std-dtcompatible-adi-tmc50xx)；ADI表示厂商Analog Devices，TMC50xx为器件系列名。

## 128.2\_双轴设备树配置

原例通过 **串行外设接口（Serial Peripheral Interface，SPI）**连接TMC50xx。器件最多控制两个两相双极步进电机，分别以索引 `idx = <0>` 与 `idx = <1>` 表示。每个轴都有独立的驱动器子节点和运动控制器子节点，并分别提供应用访问所需的别名。

设备树中的 `spi-max-frequency` 指定最大SPI频率，`clock-frequency` 指定时钟频率；`DT_FREQ_M` 是按兆赫表示频率的宏。`micro-step-res` 为微步分辨率，**微步（Microstep）**表示细分后的步进单位。原注释中的StallGuard是Trinamic器件的专有功能名，其参数应按对应器件绑定理解。

```devicetree
/ {
    aliases {
        x_axis_stepper_ctrl = &tmc50xx_0_motion_controller;
        y_axis_stepper_ctrl =  &tmc50xx_1_motion_controller;
        x_axis_stepper_driver = &tmc50xx_0_stepper_driver;
        y_axis_stepper_driver = &tmc50xx_1_stepper_driver;
    };
};

&spi0 {
    /* SPI bus options here, not shown */

    /* Dual controller/driver for up to two 2-phase bipolar stepper motors */
    tmc50xx: tmc50xx@0 {
        compatible = "adi,tmc50xx";
        reg = <0>;
        spi-max-frequency = <DT_FREQ_M(8)>; /* Maximum SPI bus frequency */

        poscmp-enable; test-mode; lock-gconf; /* ADI TMC Global configuration flags */
        clock-frequency = <DT_FREQ_M(16)>; /* Internal/External Clock frequency */

        tmc50xx_0_stepper_driver: stepper-driver-0 {
            idx = <0>;
             compatible = "adi,tmc50xx-stepper-driver";
             micro-step-res = <256>;
             /* ADI TMC stallguard settings specific to TMC50XX */
             stallguard2-threshold=<30>;
         };

        tmc50xx_0_motion_controller: motion-controller-0 {
            idx = <0>;
            compatible = "adi,tmc50xx-stepper-ctrl";
            ...
            vmax = <900000>;
            amax = <50000>;
            ...
            activate-stallguard2;
            ...
         };

        tmc50xx_1_stepper_driver: stepper-driver-1 {
            idx = <1>;
             compatible = "adi,tmc50xx-stepper-driver";
             micro-step-res = <256>;
             /* ADI TMC stallguard settings specific to TMC50XX */
             stallguard2-threshold=<30>;
         };

        tmc50xx_1_motion_controller: motion-controller-1 {
            idx = <1>;
            compatible = "adi,tmc50xx-stepper-ctrl";
            ...
            vstart = <1000>;
            ...
            stallguard-threshold-velocity=<200000>;
         };
     };
};
```

原注释保留了未展示的SPI总线配置、双控制器／驱动器用途、全局配置标志、内部／外部时钟以及TMC50xx专用StallGuard设置。省略号代表未展开的配置，不能作为实际设备树语法保留。

> 译注：原例 `/aliases` 节点中的四个别名属性使用了下划线，但本仓库设备树解析器只接受小写字母、数字和连字符。实际设备树应使用 `x-axis-stepper-ctrl`、`y-axis-stepper-ctrl`、`x-axis-stepper-driver`、`y-axis-stepper-driver`；下方C代码中的 `DT_ALIAS` 宏参数仍使用下划线形式。规则见[设备树解析器](../../../scripts/dts/python-devicetree/src/devicetree/dtlib.py)。这里的 `/aliases` 是设备树节点路径，不是主机文件路径。

## 128.3\_按轴取得控制器与驱动器

`DEVICE_DT_GET` 是设备对象获取宏，`DT_ALIAS` 是设备树别名查询宏。原C片段取得X轴和Y轴各自的运动控制器、硬件驱动器对象；然后请求X轴移动到位置200、停止X轴控制器，并禁用两轴硬件驱动器：

```c
static const struct device *x_stepper_ctrl = DEVICE_DT_GET(DT_ALIAS(x_axis_stepper_ctrl));
static const struct device *x_stepper_driver = DEVICE_DT_GET(DT_ALIAS(x_axis_stepper_driver));
static const struct device *y_stepper_ctrl = DEVICE_DT_GET(DT_ALIAS(y_axis_stepper_ctrl));
static const struct device *y_stepper_driver = DEVICE_DT_GET(DT_ALIAS(y_axis_stepper_driver));
...
stepper_ctrl_move_to(x_stepper_ctrl, 200);
stepper_ctrl_stop(x_stepper_ctrl);
stepper_disable(x_stepper_driver);
stepper_disable(y_stepper_driver);
```

原片段包含省略号，未展示完整初始化、就绪判断或等待运动完成逻辑。保留原调用顺序不表示 `move_to()` 后紧接 `stop()` 能使电机完成到达目标的运动。
