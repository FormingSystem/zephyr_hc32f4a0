# 第416章\_I3C最大写入长度命令数据

原文：[structi3c__ccc__mwl](https://docs.zephyrproject.org/latest/doxygen/html/structi3c__ccc__mwl.html)。读取日期：2026-10-13，`latest`。

## 416.1\_SETMWL与GETMWL载荷

`struct i3c_ccc_mwl` 是**改进的集成电路间总线（Improved Inter-Integrated Circuit，I3C）通用命令码（Common Command Code，CCC）** `SETMWL`/`GETMWL` 的载荷（Payload），分别用于设置/获取**最大写入长度（Maximum Write Length，MWL）**。头文件为 `zephyr/drivers/i3c/ccc.h`。

## 416.2\_字段与字节序职责

```c
uint16_t len;
```

字段 [`len`](https://docs.zephyrproject.org/latest/doxygen/html/structi3c__ccc__mwl.html#a5312fa1fc7cc93dfdf88d490352cf08e) 保存最大写入长度。

目标设备返回的原始数据采用**大端字节序（Big-endian）**。驱动和辅助函数必须在把结果交给调用者之前，将其转换为**中央处理器（Central Processing Unit，CPU）**所用的字节序。
