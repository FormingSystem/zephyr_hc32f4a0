# 第200章\_SX1509B三色LED示例

原文：[SX1509B RGB LED](https://docs.zephyrproject.org/latest/samples/drivers/led/sx1509b_intensity/README.html)。读取日期：2026-10-13，`latest`。

## 200.1\_概述（Overview）

本示例控制 Thingy:52 导光腔（Lightwell）中彩色 **发光二极管（Light-Emitting Diode，LED）**的亮度。红、绿、蓝（Red, Green, Blue，RGB）LED 依次渐亮，并不断重复。

## 200.2\_构建与运行（Building and Running）

译注：以下官方命令在已配置 Zephyr 开发环境的终端中，从 Zephyr 源码根目录执行；示例由官方仓库提供，west 生成构建产物，`west flash` 将固件烧录到开发板。

```bash
west build -b thingy52/nrf52832 samples/drivers/led/sx1509b_intensity
west flash
```

日志配置为通过 **实时传输（Real Time Transfer，RTT）**输出，可使用 SEGGER J-Link RTT Viewer 查看。
