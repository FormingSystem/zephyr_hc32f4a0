# 第549章\_脉冲输入输出回环绑定

<a id="dtbinding-zephyr-pulse-io-loopback"></a>

原文：[zephyr,pulse-io-loopback](https://docs.zephyrproject.org/latest/build/dts/api/bindings/pulse-io/zephyr,pulse-io-loopback.html)。读取日期：2026-10-13，`latest`。

`zephyr,pulse-io-loopback` 是软件**脉冲输入输出（Pulse Input/Output，Pulse IO）**回环控制器绑定。它提供一个可工作的后端，把发送的**符号（Symbol）**回送到接收端，使测试可以不依赖硬件来验证子系统**应用程序编程接口（Application Programming Interface，API）**。

提供方是 Zephyr Project，驱动为 [`drivers/pulse_io/pulse_io_loopback.c`](https://github.com/zephyrproject-rtos/zephyr/blob/main/drivers/pulse_io/pulse_io_loopback.c)，相关开发板见[官方筛选目录](https://docs.zephyrproject.org/latest/boards/index.html#compatibles=zephyr,pulse-io-loopback)。

## 549.1\_通道数量与引用参数

下列属性的类型均为整数 `int`。`pulse-ios` 说明符（Specifier）中的唯一参数选择控制器上的通道索引。

| 属性 | 类型 | 中文说明与约束 |
| --- | --- | --- |
| `num-channels` | `int` | 控制器对外提供的通道数量，默认 `4` |
| `#pulse-io-cells` | `int` | `pulse-ios` 说明符的单元数，必需且固定为 `1`；唯一单元选择控制器通道索引 |

说明单元名称为 `channel`（通道）。原页没有已弃用的节点专用属性，基础属性列表为空。
