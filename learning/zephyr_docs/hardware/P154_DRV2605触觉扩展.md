# 第154章\_DRV2605触觉扩展

原文：[group__drv2605__interface](https://docs.zephyrproject.org/latest/doxygen/html/group__drv2605__interface.html)。读取日期：2026-10-13，`latest`。

## 154.1\_执行器、配置数据与头文件

DRV2605触觉驱动支持 **偏心旋转质量电机（Eccentric Rotating Mass，ERM）**和 **线性谐振执行器（Linear Resonant Actuator，LRA）**。扩展 **应用程序编程接口（Application Programming Interface，API）**定义于 `zephyr/drivers/haptics/drv2605.h`。

原页列出ROM配置结构 [`drv2605_rom_data`](P157_DRV2605只读波形配置.md)、**实时播放（Real-Time Playback，RTP）**配置结构 [`drv2605_rtp_data`](P158_DRV2605实时播放配置.md) 和配置数据联合体 [`drv2605_config_data`](P159_DRV2605配置联合体.md)，详细成员见各自结构参考。ROM为 **只读存储器（Read-Only Memory）**。

## 154.2\_波形序列器辅助宏

**波形序列器（Waveform Sequencer）**容量宏 [`DRV2605_WAVEFORM_SEQUENCER_MAX`](https://docs.zephyrproject.org/latest/doxygen/html/group__drv2605__interface.html#gab9069fcfd891cadbe5838d0caac5bca0) 为8，表示最多可存储8个波形项。

等待宏 `DRV2605_WAVEFORM_SEQUENCER_WAIT_MS(ms)` 生成序列器等待／延迟字节，原定义表达式为：

```c
(0x80 | ((ms) / 10))
```

把该值放入 [`drv2605_rom_data::seq_regs`](P157_DRV2605只读波形配置.md) 数组，会使播放引擎空闲指定时长。输入 `ms` 为毫秒数，**向下取整到10 ms的倍数**，有效范围为10～1270；宏返回表示该等待时长的字节字面值。

## 154.6\_按信号源配置设备

函数 [`drv2605_haptic_config()`](https://docs.zephyrproject.org/latest/doxygen/html/group__drv2605__interface.html#gafe7decc53e258a7162b44ae2076c10d1) 的声明为：

```c
int drv2605_haptic_config(const struct device *dev,
                         enum drv2605_haptics_source source,
                         const union drv2605_config_data *config_data);
```

`dev` 指向触觉设备实例，`source` 指定所需信号源，`config_data` 指向该源的配置联合体。成功返回0；不支持该信号源返回 `-ENOTSUP`；其他失败返回相应负错误码。
