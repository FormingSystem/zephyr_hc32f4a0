# 第511章\_测试参数集合结构

原文：[structztest__param__values](P511_测试参数集合结构.md)。读取日期：2026-10-13，`latest`。

`struct ztest_param_values` 表示**值参数化测试（Value-Parameterized Test）**的参数值集合：参数既可以保存在数组中，也可以在每次测试调用前由回调生成。

公开头文件为 `zephyr/ztest_test.h`，源码位置为 `subsys/testsuite/ztest/include/zephyr/ztest_test.h`。这里以公开包含名替代原文构建机的绝对路径。

## 511.1\_数组、数量与元素大小

集合记录参数来源、数量以及每个元素的字节数。

| 字段声明 | 官方说明译文 |
| --- | --- |
| `const void *values` | 参数值数组指针；设置了 [`value_at_cb`](P511_测试参数集合结构.md) 时为 `NULL` |
| `size_t count` | 参数值数量；设置 `value_at_cb` 时表示调用次数 |
| `size_t elem_size` | 每个参数值的大小，单位字节 |

下面三个**回调（Callback）**字段分别负责名称、参数生成及一次性初始化。`NULL` 表示空指针。

## 511.2\_参数名称回调

[`name_cb`](P511_测试参数集合结构.md) 是可选回调，返回索引 `index` 处参数值的便于阅读的名称。

```c
const char *(*name_cb)(size_t index, const void *value);
```

签名中的 `value` 指向该参数值；原页没有提供额外的字符串寿命说明。

## 511.3\_参数生成回调

`value_at_cb` 是基于范围或运行时参数的可选**值生成器（Value Generator）**。

```c
void (*value_at_cb)(size_t index, void *out);
```

非空时，每次测试调用都会调用它一次，传入从 `0` 开始的索引和指向已对齐临时缓冲区的指针。缓冲区至少有 [`elem_size`](P511_测试参数集合结构.md) 字节，回调必须向 `out` 写入**恰好 `elem_size` 字节**。

提供此回调时，[`values`](P511_测试参数集合结构.md) **必须为 `NULL`**。原文建议使用 [`ZTEST_DEFINE_PARAM_RANGE()`](P507_ZTest测试定义宏.md) 或 [`ZTEST_DEFINE_PARAM_GENERATOR()`](P507_ZTest测试定义宏.md) 宏设置参数集合，而不是直接设置此字段；前者定义范围，后者定义运行时生成器。

## 511.4\_分派前的一次性准备

[`setup_cb`](P511_测试参数集合结构.md) 是可选的一次性准备回调，在分派循环之前执行。

```c
void (*setup_cb)(void);
```

非空时，每次参数化测试分派都在生成第一个值之前**恰好调用一次**。可用于设置**伪随机数生成器（Pseudorandom Number Generator，PRNG）**种子、重置有状态生成器，或执行其他每次测试运行需要的初始化。该字段允许为 `NULL`。

使用 [`ZTEST_DEFINE_PARAM_GENERATOR_WITH_SETUP()`](P507_ZTest测试定义宏.md) 宏设置此字段及相应生成器。
