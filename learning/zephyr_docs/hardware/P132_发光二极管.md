# 第132章\_发光二极管

原文：[Light-Emitting Diode (LED)](https://docs.zephyrproject.org/latest/hardware/peripherals/led.html)。读取日期：2026-10-13，`latest`。

## 132.1\_离散LED与可寻址灯带

**发光二极管（Light-Emitting Diode，LED）**的 **应用程序编程接口（Application Programming Interface，API）**既支持单独LED，也支持灯带。它把简单 **通用输入输出（General-Purpose Input/Output，GPIO）**驱动、**脉宽调制（Pulse Width Modulation，PWM）**调光、专用LED控制器 **集成电路（Integrated Circuit，IC）**及可寻址灯带的差异，统一为少量公共操作。

系统提供两个相关子系统：LED通用接口控制离散或控制器管理的LED，支持开关、亮度、颜色和闪烁；**LED灯带（LED Strip）**接口面向WS2812、APA102等可寻址灯串，每个像素有自己的颜色值。

## 132.2\_必需能力与可选操作

驱动实现下列操作的一个子集。调用驱动未提供的可选操作时，返回未实现错误码 `-ENOSYS`。

驱动至少提供开关控制 [`led_on()`](P202_LED公共接口.md)／[`led_off()`](P202_LED公共接口.md) 或亮度设置 [`led_set_brightness()`](P202_LED公共接口.md) 中的一类能力。开关函数使LED完全点亮或熄灭；亮度函数使用0到上限常量 [`LED_BRIGHTNESS_MAX`](P202_LED公共接口.md)（100）的范围。实现亮度设置时，[`led_on()`](P202_LED公共接口.md) 与 [`led_off()`](P202_LED公共接口.md) 也自动使用它。

可选函数及作用如下：

| 函数 | 用途 |
| --- | --- |
| [`led_blink()`](P202_LED公共接口.md) | 按指定点亮、熄灭时长启动闪烁。 |
| [`led_set_color()`](P202_LED公共接口.md) | 设置多色LED各颜色通道的值。 |
| [`led_get_info()`](P202_LED公共接口.md) | 取得描述某个LED的 `led_info` 信息结构，包括标签、索引及颜色映射。 |
| [`led_write_channels()`](P202_LED公共接口.md) | 写入一段原始通道值，供把LED呈现为通道数组的驱动使用。 |

## 132.3\_LED索引与颜色映射

每个驱动控制的LED通过从0开始的 **索引（Index）**寻址。一个多色LED只占一个索引，其颜色通道一起交给 [`led_set_color()`](P202_LED公共接口.md)。

`led_info` 结构中的 `color_mapping` 字段描述多色LED的通道顺序。每项取自源码头文件 `include/zephyr/dt-bindings/led/led.h` 定义的颜色标识：`LED_COLOR_ID_WHITE` 为白色，`LED_COLOR_ID_RED` 为红色，`LED_COLOR_ID_GREEN` 为绿色，`LED_COLOR_ID_BLUE` 为蓝色，`LED_COLOR_ID_AMBER` 为琥珀色，`LED_COLOR_ID_VIOLET` 为紫罗兰色，`LED_COLOR_ID_YELLOW` 为黄色，`LED_COLOR_ID_IR` 为 **红外（Infrared，IR）**。

## 132.4\_设备树配置

简单LED通常描述为LED控制器的子节点，并通过 **设备树别名（Devicetree Alias）**引用。原例中 `led0` 指向节点标签 `status_led`；`GPIO_ACTIVE_HIGH` 表示高电平有效：

```devicetree
/ {
    aliases {
        led0 = &status_led;
    };

    leds {
        compatible = "gpio-leds";
        status_led: led_0 {
            gpios = <&gpio0 13 GPIO_ACTIVE_HIGH>;
            label = "Status LED";
        };
    };
};
```

多色LED通过 `color-mapping` 设备树属性编码颜色信息，其值使用上述 `LED_COLOR_ID_*` 常量。

## 132.5\_原始使用示例

基本开关控制通过别名找到LED子节点。原代码的 `DT_ALIAS` 宏查询别名，`DT_PARENT` 宏取得父控制器节点，`DEVICE_DT_GET` 宏取得设备对象，`DT_NODE_CHILD_IDX` 宏取得子节点索引。`LED_NODE` 是节点宏；未就绪时返回设备不可用错误码 `-ENODEV`：

```c
#include <zephyr/drivers/led.h>
#include <zephyr/devicetree.h>

#define LED_NODE DT_ALIAS(led0)
static const struct device *led_dev = DEVICE_DT_GET(DT_PARENT(LED_NODE));
static const uint32_t led_idx = DT_NODE_CHILD_IDX(LED_NODE);

int turn_on_status_led(void)
{
    if (!device_is_ready(led_dev)) {
        return -ENODEV;
    }
    return led_on(led_dev, led_idx);
}
```

设置0～100范围内的亮度。原注释表示把亮度设为25%：

```c
/* Dim the LED to 25% brightness */
led_set_brightness(led_dev, led_idx, 25);
```

下面原例每500 ms点亮、500 ms熄灭。注释说明 `-ENOSYS` 表示驱动未原生实现闪烁：

```c
int err = led_blink(led_dev, led_idx, 500, 500);

if (err == -ENOSYS) {
    /* Driver does not implement blink natively */
}
```

下面设置多色LED的 **红绿蓝（Red, Green, Blue，RGB）**颜色。原注释要求数组顺序与 `led_get_info()` 报告的 `color_mapping` 一致；标准RGB映射的顺序为红、绿、蓝。数组 `purple` 给出紫色通道值，`ARRAY_SIZE` 是数组元素数量宏：

```c
/* Order of the values must match the color_mapping reported by
 * led_get_info(); for a standard RGB mapping the order is R, G, B.
 */
const uint8_t purple[] = { 0x80, 0x00, 0x80 };

led_set_color(led_dev, led_idx, ARRAY_SIZE(purple), purple);
```

## 132.6\_配置项

相关Kconfig配置项包括LED支持 [`CONFIG_LED`](https://docs.zephyrproject.org/latest/kconfig.html#CONFIG_LED)、灯带支持 [`CONFIG_LED_STRIP`](https://docs.zephyrproject.org/latest/kconfig.html#CONFIG_LED_STRIP)、LED **命令解释器（Shell）**支持 [`CONFIG_LED_SHELL`](https://docs.zephyrproject.org/latest/kconfig.html#CONFIG_LED_SHELL)，以及初始化优先级 [`CONFIG_LED_INIT_PRIORITY`](https://docs.zephyrproject.org/latest/kconfig.html#CONFIG_LED_INIT_PRIORITY)。Kconfig是Zephyr配置系统。
