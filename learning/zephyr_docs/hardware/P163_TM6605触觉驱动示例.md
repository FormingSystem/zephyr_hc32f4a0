# 第163章\_TM6605触觉驱动示例

原文：[TM6605 Haptic Driver](https://docs.zephyrproject.org/latest/samples/drivers/haptics/tm6605/README.html)。读取日期：2026-10-13，`latest`。

## 163.1\_概述（Overview）

本示例循环播放 TM6605 中的一组预编程触觉效果。程序依次选择每种效果，再使用通用触觉 **应用程序编程接口（Application Programming Interface，API）**及辅助函数 `tm6605_select_effect()` 播放。

## 163.2\_构建与运行（Building and Running）

为 Nucleo F401RE 开发板构建应用。将 TM6605 器件，例如 DFRobot Gravity TM6605 模块（DRI0056），连接到 `arduino_i2c` 总线。这里使用 **内部集成电路总线（Inter-Integrated Circuit，I2C）**，器件的 7 位地址为 `0x2D`。

译注：以下官方命令在配置好 Zephyr 开发环境的终端中，从 Zephyr 源码根目录执行。示例源码由官方仓库提供，west 生成构建产物。

```bash
west build -b nucleo_f401re samples/drivers/haptics/tm6605
```

译注：烧录应用的方法见[Nucleo F401RE开发板说明](https://docs.zephyrproject.org/latest/boards/st/nucleo_f401re/doc/index.html#nucleo_f401re)的烧录（Flashing）小节。

使用 DFRobot 模块且开发板具有 I2C 连接器时，可以使用 [DFRobot Gravity TM6605扩展板（Shield）](https://docs.zephyrproject.org/latest/boards/shields/dfrobot_gravity_tm6605/doc/index.html#dfrobot-gravity-tm6605)，代替开发板专用的 **设备树叠加文件（Devicetree Overlay）**。例如，在相同环境与源码根目录执行：

```bash
west build -b adafruit_qt_py_rp2040 --shield dfrobot_gravity_tm6605 samples/drivers/haptics/tm6605
```
