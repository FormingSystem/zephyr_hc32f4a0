# 第298章\_M2串行存储器连接器

原文：[group__m2-memory-connector](https://docs.zephyrproject.org/latest/doxygen/html/group__m2-memory-connector.html)。读取日期：2026-10-13，官方 `latest` 文档版本。

## 298.1\_接口与术语

本页定义ST M.2 Key A串行存储器连接器的非电源信号对外引脚的常量，声明来自 `zephyr/dt-bindings/gpio/m2-memory-connector.h`。通用输入/输出（General Purpose Input/Output，GPIO）连接关系使用下表的原常量。

集成电路间总线（Inter-Integrated Circuit，I²C）使用串行时钟线（Serial Clock，SCL）与串行数据线（Serial Data，SDA）。

串行外设接口（Serial Peripheral Interface，SPI）信号包括串行时钟（Serial Clock，SCK/CLK）、片选（Chip Select，CS）及数据线。控制器输出/外设输入（Controller Out Peripheral In，COPI）与传统主出从入（Master Out Slave In，MOSI）对应；控制器输入/外设输出（Controller In Peripheral Out，CIPO）与传统主入从出（Master In Slave Out，MISO）对应。

常量值与技术说明TN1618中M.2 Key A连接器的物理针号一致；原文有意省略电源、地、保留及缺口（Key）引脚。

扩展串行外设接口（Extended Serial Peripheral Interface，XSPI）为此处存储器接口；数据选通（Data Strobe）保留DQS标识。低压差稳压器（Low-Dropout Regulator，LDO）的使能为必需的开漏（Open Drain）信号；电可擦可编程只读存储器（Electrically Erasable Programmable Read-Only Memory，EEPROM）用于标识或辅助用途；发光二极管（Light-emitting Diode，LED）分别有红、绿两路。

> 译注：XSPI英文展开按[ST官方术语表](https://wiki.st.com/stm32mcu/wiki/Introduction_to_external_serial_memories_XSPI_interoperability_for_STM32)补充，其余连接器说明与数值来自本页原文。
