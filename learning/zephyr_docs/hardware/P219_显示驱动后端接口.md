# 第219章\_显示驱动后端接口

原文：[group__display__interface__backend](https://docs.zephyrproject.org/latest/doxygen/html/group__display__interface__backend.html)。读取日期：2026-10-13，`latest`。

## 219.1\_用途

本组提供实现显示驱动所需的 **应用程序编程接口（Application Programming Interface，API）**类型定义、回调签名（Callback Signature）及辅助接口，声明来自官方头文件 `zephyr/drivers/display.h`。

驱动操作通过[显示驱动函数表](P220_显示驱动函数表.md)提供；本组的关联专题还包括[颜色抖动（Color Dithering）辅助接口](P221_显示颜色抖动接口.md)，用于显示驱动的红、绿、蓝（Red, Green, Blue，RGB）到调色板转换。

## 219.2\_回调类型与声明

以下均为函数指针类型定义（Function Pointer Typedef）。每个类型的参数说明对应同名公共操作，完整错误码、事件上下文限制和参数含义见[显示公共接口](P214_显示公共接口.md)。
