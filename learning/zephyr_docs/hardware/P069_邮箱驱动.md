# 第69章\_邮箱驱动

原文：[Multi-Channel Inter-Processor Mailbox (MBOX)](https://docs.zephyrproject.org/latest/hardware/peripherals/mbox.html)。读取日期：2026-10-13，`latest`。

## 69.1\_邮箱实例与通道

**多通道处理器间邮箱（Multi-Channel Inter-Processor Mailbox，MBOX）**设备是一种外设，可在系统的 **中央处理器（Central Processing Unit，CPU）**和 **处理器簇（CPU Cluster）**之间传递信号；能否同时传递数据取决于具体外设。

每个MBOX实例提供一个或多个 **通道（Channel）**，每个通道指向另一个CPU簇。多个通道可以指向同一个簇，因此不能把通道数量直接等同于目标簇数量。

## 69.2\_接口与相关示例

完整 **应用程序编程接口（Application Programming Interface，API）**见[MBOX参考](../intercore_reference/P014_邮箱驱动公共接口.md)。原页列出四个相关示例。

| 示例 | 原文用途 |
| --- | --- |
| [HWSPINLOCK](../intercore_reference/P013_硬件自旋锁驱动示例.md) | 将 **硬件自旋锁（Hardware Spinlock，HWSPINLOCK）**API与MBOX API结合，演示跨核心同步。 |
| [MBOX](../intercore_reference/P024_邮箱信号通知示例.md) | 使用MBOX API完成处理器间邮箱通信。 |
| [MBOX Data](../intercore_reference/P025_邮箱数据传输示例.md) | 使用带数据的MBOX API完成处理器间邮箱通信。 |
| [OpenAMP Linux Zephyr RPMsg](../intercore_reference/P091_RenesasLinux与Zephyr通信示例.md) | 通过OpenAMP库实现两个核心之间的消息交换：应用核心运行Linux，实时核心运行Zephyr。RPMsg指 **远程处理器消息（Remote Processor Messaging）**。 |

OpenAMP为跨核心通信框架名称。这里保留相关示例入口及其描述，未执行核心间通信或硬件自旋锁测试。
