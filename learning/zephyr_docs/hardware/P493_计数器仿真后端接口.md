# 第493章\_计数器仿真后端接口

原文：[group__counter__emul](https://docs.zephyrproject.org/latest/doxygen/html/group__counter__emul.html)。读取日期：2026-10-13，`latest`。

**计数器捕获（Counter Capture）**仿真行为由应用定义。测试通过设置捕获通道的仿真输入电平来驱动捕获事件。本页接口定义于 `zephyr/drivers/counter/counter_capture_emul.h`。

## 493.1\_电平变化何时产生捕获

测试调用 [`counter_capture_emul_input_set`](P493_计数器仿真后端接口.md) 设置输入电平。当电平变化匹配 [`counter_capture_configure`](../timer_reference/P032_计数器捕获接口.md) 配置的**边沿（Edge）**，且通道已启用时，已注册的捕获回调会**同步（Synchronously）**执行。这类似于 [`gpio_emul_input_set`](P273_GPIO模拟接口.md) 触发**通用输入输出（General-Purpose Input/Output，GPIO）**中断回调的方式。

仿真计数器支持哪些边沿，在**设备树（Devicetree，DT）**计数器节点上通过两个布尔属性声明：`rising-edge` 表示上升沿，`falling-edge` 表示下降沿。

## 493.2\_读取通道输入电平

[`counter_capture_emul_input_get()`](P493_计数器仿真后端接口.md) 取得通道当前的仿真捕获输入电平。

```c
int counter_capture_emul_input_get(const struct device *dev, uint8_t chan_id);
```

参数 `dev` 是仿真计数器设备，`chan_id` 是捕获通道标识。成功返回当前输入电平 `0` 或 `1`；通道标识超出范围时返回无效参数错误 `-EINVAL`。

[`counter_capture_emul_input_get_dt()`](P493_计数器仿真后端接口.md) 根据捕获设备树规格结构（Counter Capture DT Specification）读取电平，是静态内联函数。

```c
static inline int counter_capture_emul_input_get_dt(
    const struct counter_capture_dt_spec *spec);
```

参数 `spec` 为计数器捕获设备树规格。它等价于以下官方调用，返回值来自 [`counter_capture_emul_input_get()`](P493_计数器仿真后端接口.md)：

```c
counter_capture_emul_input_get(spec->dev, spec->chan_id);
```

## 493.3\_设置通道输入电平

[`counter_capture_emul_input_set()`](P493_计数器仿真后端接口.md) 将 `chan_id` 通道的仿真捕获输入驱动为指定电平。如果产生的边沿符合该通道配置的捕获标志，且通道已启用，就以**当前计数器值**同步调用捕获回调。

```c
int counter_capture_emul_input_set(const struct device *dev,
                                   uint8_t chan_id, int level);
```

`dev` 是仿真计数器设备；`chan_id` 是捕获通道标识；`level` 是新的输入电平，用 `0` 或非零值表示。成功返回 `0`；通道标识超出范围时返回 `-EINVAL`。

[`counter_capture_emul_input_set_dt()`](P493_计数器仿真后端接口.md) 根据设备树规格设置电平：

```c
static inline int counter_capture_emul_input_set_dt(
    const struct counter_capture_dt_spec *spec, int level);
```

`spec` 为计数器捕获设备树规格，`level` 为新的输入电平（`0` 或非零）。以下官方调用与该函数等价，返回值来自 [`counter_capture_emul_input_set()`](P493_计数器仿真后端接口.md)：

```c
counter_capture_emul_input_set(spec->dev, spec->chan_id, level);
```
