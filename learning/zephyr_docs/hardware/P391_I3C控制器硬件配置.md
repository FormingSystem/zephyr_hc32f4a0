# 第391章\_I3C控制器硬件配置

原文：[structi3c__config__controller](https://docs.zephyrproject.org/latest/doxygen/html/structi3c__config__controller.html)。读取日期：2026-10-13，`latest`。

## 391.1\_配置结构

`struct i3c_config_controller` 配置**改进的集成电路间总线（Improved Inter-Integrated Circuit，I3C）**硬件，使其作为**控制器（Controller）**运行。包含头文件 `zephyr/drivers/i3c.h`。

下面按原字段表整理完整声明，保留三个嵌套结构：

```c
struct i3c_config_controller {
    bool is_secondary;
    struct {
        uint32_t i3c;
        uint32_t i2c;
    } scl;
    struct {
        uint32_t high_ns;
        uint32_t low_ns;
    } scl_od_min;
    struct {
        uint32_t high_ns;
    } scl_pp_min;
    uint8_t supported_hdr;
};
```

## 391.2\_角色与时钟频率

[`is_secondary`](https://docs.zephyrproject.org/latest/doxygen/html/structi3c__config__controller.html#ac0d0190b6a31499097fc34eda3e27a36) 为 `true` 时，控制器将作为总线的**次级控制器（Secondary Controller）**；为 `false` 时，作为**主控制器（Primary Controller）**。

**串行时钟线（Serial Clock Line，SCL）**的频率由 [`scl`](https://docs.zephyrproject.org/latest/doxygen/html/structi3c__config__controller.html#aebab80b194bf7c35e15edb0466d97e1b) 嵌套结构指定，单位为赫兹（Hertz，Hz）：

| 字段 | 类型 | 含义 |
| --- | --- | --- |
| `scl.i3c` | [`uint32_t`](https://docs.zephyrproject.org/latest/doxygen/html/stdint_8h.html#a0a8582351ac627ee8bde2973c825e47f) | I3C 传输的 SCL 频率。 |
| `scl.i2c` | [`uint32_t`](https://docs.zephyrproject.org/latest/doxygen/html/stdint_8h.html#a0a8582351ac627ee8bde2973c825e47f) | 集成电路间总线（Inter-Integrated Circuit，I2C）传输的 SCL 频率。 |

## 391.3\_开漏与推挽时钟时间

**开漏（Open Drain，OD）**和**推挽（Push-Pull，PP）**是时钟信号的两种驱动方式。下列字段指定请求的最短时钟电平持续时间，单位为纳秒（Nanosecond，ns）：

| 字段 | 类型 | 含义 |
| --- | --- | --- |
| `scl_od_min.high_ns` | [`uint32_t`](https://docs.zephyrproject.org/latest/doxygen/html/stdint_8h.html#a0a8582351ac627ee8bde2973c825e47f) | 请求的最短 SCL 开漏高电平时间。 |
| `scl_od_min.low_ns` | [`uint32_t`](https://docs.zephyrproject.org/latest/doxygen/html/stdint_8h.html#a0a8582351ac627ee8bde2973c825e47f) | 请求的最短 SCL 开漏低电平时间。 |
| `scl_pp_min.high_ns` | [`uint32_t`](https://docs.zephyrproject.org/latest/doxygen/html/stdint_8h.html#a0a8582351ac627ee8bde2973c825e47f) | 请求的最短 SCL 推挽高电平时间。 |

原说明指出：第一次广播消息要求 `tHIGH_OD >= 200 ns`；正常消息的 `tHIGH_OD` 不得超过规范最大值 41 ns。

某些受速度限制的目标设备，需要比总线最小值更长的推挽 SCL 高电平时间；它们通过**通用命令码（Common Command Code，CCC）** `GETMXDS` 公布这一要求。

> 译注：原生成页面将两个同名 [`high_ns`](https://docs.zephyrproject.org/latest/doxygen/html/structi3c__config__controller.html#aee0020925a09ec84b928c92183842da4) 字段合并到一个详情条目。本页按照字段表中的 [`scl_od_min`](https://docs.zephyrproject.org/latest/doxygen/html/structi3c__config__controller.html#a02841be13cb0ff9efba9d7d59811fbdb) 与 [`scl_pp_min`](https://docs.zephyrproject.org/latest/doxygen/html/structi3c__config__controller.html#a332a94fccd721a24a1f93153b9c997f5) 所属结构分别列出，并保留开漏广播/正常消息的不同时间约束。

## 391.4\_高数据速率模式

字段 [`supported_hdr`](https://docs.zephyrproject.org/latest/doxygen/html/structi3c__config__controller.html#abb0eb210bc07911b5648eb490a92c00d) 的类型为 [`uint8_t`](https://docs.zephyrproject.org/latest/doxygen/html/stdint_8h.html#a3cb4a16b0e8d6af0af86d4fd6ba5fd9d)，是支持的**高数据速率（High Data Rate，HDR）**模式（0—7）的位掩码（Bit Mask）。它可用于在运行时启用或禁用硬件所支持的 HDR 模式。
