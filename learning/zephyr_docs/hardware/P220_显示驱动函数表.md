# 第220章\_显示驱动函数表

原文：[structdisplay__driver__api](https://docs.zephyrproject.org/latest/doxygen/html/structdisplay__driver__api.html)。读取日期：2026-10-13，`latest`。

## 220.1\_用途与成员要求

结构 [`display_driver_api`](https://docs.zephyrproject.org/latest/doxygen/html/structdisplay__driver__api.html) 是每个显示驱动都需要定义的 **驱动操作（Driver Operations）**表，定义来自官方头文件 `zephyr/drivers/display.h`。它包含驱动所实现操作的函数指针，以及其他驱动专用的常量数据。

标为 **必需（Required，REQ）**的成员必须由驱动设置；标为 **可选（Optional，OPT）**的成员按需要提供。这里必需的两个成员是 [`write`](https://docs.zephyrproject.org/latest/doxygen/html/structdisplay__driver__api.html#a535221c00caef6f24dc75c919826a889) 和 [`get_capabilities`](https://docs.zephyrproject.org/latest/doxygen/html/structdisplay__driver__api.html#ace3a2eae73f639da890b6798bd215b29)。
