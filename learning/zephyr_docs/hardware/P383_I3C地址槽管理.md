# 第383章\_I3C地址槽管理

原文：[group__i3c__addresses](https://docs.zephyrproject.org/latest/doxygen/html/group__i3c__addresses.html)。读取日期：2026-10-13，`latest`。

## 383.1\_地址与状态

本页提供**改进的集成电路间总线（Improved Inter-Integrated Circuit，I3C）**的地址辅助接口。**地址槽（Address Slot）**记录一个总线地址当前是否空闲、保留，或已关联设备。相关头文件为 `zephyr/drivers/i3c/addresses.h`；状态保存在 `struct i3c_addr_slots` 中。

| 宏 | 值 | 含义 |
| --- | --- | --- |
| [`I3C_BROADCAST_ADDR`](https://docs.zephyrproject.org/latest/doxygen/html/group__i3c__addresses.html#gad516c48319d08db1886719645a682787) | `0x7E` | I3C 总线广播地址（Broadcast Address）。 |
| [`I3C_MAX_ADDR`](https://docs.zephyrproject.org/latest/doxygen/html/group__i3c__addresses.html#ga85a120abff94213b57ce4912f58d5ed8) | `0x7F` | 设备地址的最大数值。 |

**集成电路间总线（Inter-Integrated Circuit，I2C）**设备也可以占用被管理的地址。枚举 `enum i3c_addr_slot_status` 表示以下状态：

```c
enum i3c_addr_slot_status {
    I3C_ADDR_SLOT_STATUS_FREE = 0U,
    I3C_ADDR_SLOT_STATUS_RSVD,
    I3C_ADDR_SLOT_STATUS_I3C_DEV,
    I3C_ADDR_SLOT_STATUS_I2C_DEV,
    I3C_ADDR_SLOT_STATUS_MASK = 0x03U
};
```

| 枚举项 | 含义 |
| --- | --- |
| [`I3C_ADDR_SLOT_STATUS_FREE`](https://docs.zephyrproject.org/latest/doxygen/html/group__i3c__addresses.html#ggaacbed5bbaae3b36d6f3ba175074aecd0a847927f32a28341e0d356c9ec1ccfb2e) | 该地址没有关联设备。 |
| [`I3C_ADDR_SLOT_STATUS_RSVD`](https://docs.zephyrproject.org/latest/doxygen/html/group__i3c__addresses.html#ggaacbed5bbaae3b36d6f3ba175074aecd0a0af543ae2b67f2e8055d496689437d45) | 保留地址。 |
| [`I3C_ADDR_SLOT_STATUS_I3C_DEV`](https://docs.zephyrproject.org/latest/doxygen/html/group__i3c__addresses.html#ggaacbed5bbaae3b36d6f3ba175074aecd0a38b0fd286477bcc936132c25d787749a) | 该地址关联 I3C 设备。 |
| [`I3C_ADDR_SLOT_STATUS_I2C_DEV`](https://docs.zephyrproject.org/latest/doxygen/html/group__i3c__addresses.html#ggaacbed5bbaae3b36d6f3ba175074aecd0ac8d91073cf590626b58bbf5f5b8d9c55) | 该地址关联 I2C 设备。 |
| [`I3C_ADDR_SLOT_STATUS_MASK`](https://docs.zephyrproject.org/latest/doxygen/html/group__i3c__addresses.html#ggaacbed5bbaae3b36d6f3ba175074aecd0a2093cda582c682b292deb065956ca280) | 用于筛选状态位的位掩码。 |

## 383.2\_初始化

```c
int i3c_addr_slots_init(const struct device *dev);
```

[`i3c_addr_slots_init()`](https://docs.zephyrproject.org/latest/doxygen/html/group__i3c__addresses.html#gaf2be07d40d885f60997b5eb5edcf910f) 初始化 I3C 地址槽结构：清除已分配地址位，并根据 I3C 规范设置保留地址位。参数 `dev` 是指向控制器设备驱动实例的指针。

成功返回 0；存在重复地址时返回 `-EINVAL`。

## 383.3\_设置与读取状态

```c
void i3c_addr_slots_set(struct i3c_addr_slots *slots,
                        uint8_t dev_addr,
                        enum i3c_addr_slot_status status);
enum i3c_addr_slot_status i3c_addr_slots_status(
    struct i3c_addr_slots *slots, uint8_t dev_addr);
bool i3c_addr_slots_is_free(struct i3c_addr_slots *slots,
                           uint8_t dev_addr);
```

三个函数的 `slots` 均指向地址槽结构，`dev_addr` 是要操作的设备地址。

- [`i3c_addr_slots_set()`](https://docs.zephyrproject.org/latest/doxygen/html/group__i3c__addresses.html#gae4eb7e22abde57c9bcfdc8407c0da68d) 把指定地址的状态改为参数 `status`。
- [`i3c_addr_slots_status()`](https://docs.zephyrproject.org/latest/doxygen/html/group__i3c__addresses.html#ga3dc021699fc489995b0bbe299753a33e) 返回指定地址的状态。
- [`i3c_addr_slots_is_free()`](https://docs.zephyrproject.org/latest/doxygen/html/group__i3c__addresses.html#gadc2539a0b8793ec5b5ff34e57e68fb60) 检查指定地址是否空闲；空闲返回 [`true`](https://docs.zephyrproject.org/latest/doxygen/html/stdbool_8h.html#a41f9c5fb8b08eb5dc3edce4dcb37fee7)，否则返回 [`false`](https://docs.zephyrproject.org/latest/doxygen/html/stdbool_8h.html#a65e9886d74aaee76545e83dd09011727)。

## 383.4\_查找可分配地址

```c
uint8_t i3c_addr_slots_next_free_find(struct i3c_addr_slots *slots,
                                     uint8_t start_addr);
```

[`i3c_addr_slots_next_free_find()`](https://docs.zephyrproject.org/latest/doxygen/html/group__i3c__addresses.html#gad7eddb7aebf337a31f336ccf3f78cad1) 查找可分配给新设备的下一个空闲地址。`slots` 指向地址槽结构，`start_addr` 指定从哪里开始搜索。

返回下一个空闲地址；未找到时返回 0。

## 383.5\_按用途标记地址

以下四个函数均为静态内联函数（Static Inline Function）：

```c
static inline void i3c_addr_slots_mark_free(
    struct i3c_addr_slots *addr_slots, uint8_t addr);
static inline void i3c_addr_slots_mark_rsvd(
    struct i3c_addr_slots *addr_slots, uint8_t addr);
static inline void i3c_addr_slots_mark_i3c(
    struct i3c_addr_slots *addr_slots, uint8_t addr);
static inline void i3c_addr_slots_mark_i2c(
    struct i3c_addr_slots *addr_slots, uint8_t addr);
```

参数 `addr_slots` 是地址槽结构指针，`addr` 是设备地址。

| 函数 | 标记结果 |
| --- | --- |
| [`i3c_addr_slots_mark_free()`](https://docs.zephyrproject.org/latest/doxygen/html/group__i3c__addresses.html#gaf384836871625543aaa3f087e688f1b4) | 在设备列表中把地址标为未使用。 |
| [`i3c_addr_slots_mark_rsvd()`](https://docs.zephyrproject.org/latest/doxygen/html/group__i3c__addresses.html#gac976f542afb29d2360fc2c8d797dbac5) | 在设备列表中把地址标为保留。 |
| [`i3c_addr_slots_mark_i3c()`](https://docs.zephyrproject.org/latest/doxygen/html/group__i3c__addresses.html#gae10e6aba3335b78a2be728a5f495b436) | 在设备列表中把地址标为 I3C 设备占用。 |
| [`i3c_addr_slots_mark_i2c()`](https://docs.zephyrproject.org/latest/doxygen/html/group__i3c__addresses.html#gad5fc6b00171a4fdf76de20e6da3fbb32) | 在设备列表中把地址标为 I2C 设备占用。 |
