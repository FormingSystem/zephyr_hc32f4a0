# 第112章\_错误检测与纠正

原文：[Error Detection And Correction (EDAC)](https://docs.zephyrproject.org/latest/hardware/peripherals/edac/index.html)。读取日期：2026-10-13，`latest`。

## 112.1\_存储和读取时检测错误

**错误检测与纠正（Error Detection And Correction，EDAC）**是在存储或读取数据时检测、纠正错误的机制。原页列出的具体实现为[带内错误纠正码（In-Band Error Correction Code，IBECC）](P113_带内错误纠正码.md)。

## 112.2\_配置、接口与示例

相关Kconfig配置项为 [`CONFIG_EDAC`](https://docs.zephyrproject.org/latest/kconfig.html#CONFIG_EDAC)；Kconfig是Zephyr配置系统。完整 **应用程序编程接口（Application Programming Interface，API）**见[EDAC参考](https://docs.zephyrproject.org/latest/doxygen/html/group__edac__interface.html)。

原页关联[EDAC命令行示例](P119_EDAC命令行示例.md)，通过 **命令解释器（Shell）**中的命令测试错误检测与纠正。
