# 第161章\_CS40L5x触觉驱动示例

原文：[CS40L5x Haptic Driver](https://docs.zephyrproject.org/latest/samples/drivers/haptics/cs40l5x/README.html)。读取日期：2026-10-13，`latest`。

## 161.1\_概述（Overview）

CS40L5x 是包含 CS40L50/51/52/53 的触觉驱动器系列，面向触控板、平板电脑和汽车应用。本示例使用它驱动 **线性谐振执行器（Linear Resonant Actuator，LRA）**。

示例展示 **只读存储器（Read-Only Memory，ROM）**支持的功能，包括内置效果、自定义 **脉冲编码调制（Pulse-Code Modulation，PCM）**和 **分段线性包络（Piecewise Linear Envelope，PWLE）**效果、边沿触发的触觉效果、嗡鸣效果（Buzz Effects），以及运行时触觉日志（Runtime Haptics Logging）。

自定义 **命令行交互界面（Shell）**暴露 CS40L5x **应用程序编程接口（Application Programming Interface，API）**的一部分；`main()` 提供其他 API 调用的基本演示。

## 161.2\_使用 Nucleo F401RE

为 Nucleo F401RE 开发板构建应用。把驱动器接到 **内部集成电路总线（Inter-Integrated Circuit，I2C）**的 I2C1 控制器上，地址为 `0x34`。根据器件变体选择对应的设备树兼容标识（Compatible）：

| 器件 | 兼容标识与绑定说明 |
| --- | --- |
| CS40L50 | [`cirrus,cs40l50`](https://docs.zephyrproject.org/latest/build/dts/api/compatibles/cirrus%2Ccs40l50.html#std-dtcompatible-cirrus-cs40l50) |
| CS40L51 | [`cirrus,cs40l51`](https://docs.zephyrproject.org/latest/build/dts/api/compatibles/cirrus%2Ccs40l51.html#std-dtcompatible-cirrus-cs40l51) |
| CS40L52 | [`cirrus,cs40l52`](https://docs.zephyrproject.org/latest/build/dts/api/compatibles/cirrus%2Ccs40l52.html#std-dtcompatible-cirrus-cs40l52) |
| CS40L53 | [`cirrus,cs40l53`](https://docs.zephyrproject.org/latest/build/dts/api/compatibles/cirrus%2Ccs40l53.html#std-dtcompatible-cirrus-cs40l53) |

将主机的三个 **通用输入输出（General-Purpose Input/Output，GPIO）**引脚连接到 CS40L5x 的 11、12、13 号引脚，用于边沿触发效果。

译注：以下命令在配置好 Zephyr 开发环境的终端中，从 Zephyr 源码根目录执行；使用官方已有示例，west 生成构建产物。

```bash
west build -b nucleo_f401re samples/drivers/haptics/cs40l5x
```

## 161.3\_使用 CRD40L50-POC-Q

也可以为 CRD40L50-POC-Q 演示板构建应用，在相同环境与目录执行：

```bash
west build -b crd40l50 samples/drivers/haptics/cs40l5x
```

烧录步骤分别参见[Nucleo F401RE开发板说明](https://docs.zephyrproject.org/latest/boards/st/nucleo_f401re/doc/index.html#nucleo_f401re)或 [CRD40L50-POC-Q开发板说明](https://docs.zephyrproject.org/latest/boards/cirrus/crd40l50/doc/index.html#crd40l50)中的烧录（Flashing）小节。
