# 第181章\_自定义字体示例

原文：[Custom fonts](https://docs.zephyrproject.org/latest/samples/subsys/display/cfb_custom_font/README.html)。读取日期：2026-10-13，`latest`。

## 181.1\_概述（Overview）

这是一个简单示例，演示如何在构建时自动生成 **字符帧缓冲（Character Framebuffer，CFB）**使用的字体头文件（Font Header）。

示例从 **便携式网络图形（Portable Network Graphics，PNG）**图片生成表示六面骰子的字体元素（Font Elements），再使用生成的头文件 `cfb_font_dice.h`，把这些元素显示在受支持开发板的屏幕上。

示例源码位于官方仓库的 [`samples/subsys/display/cfb_custom_font`](https://github.com/zephyrproject-rtos/zephyr/tree/main/samples/subsys/display/cfb_custom_font) 目录。

译注：以下图片是原文所述的官方字体输入素材，来自示例目录中的 `fonts/dice.png`，已按原始字节下载到本译文配套目录。官方 [CMakeLists.txt](https://github.com/zephyrproject-rtos/zephyr/blob/main/samples/subsys/display/cfb_custom_font/CMakeLists.txt) 将它交给字体生成函数；`cfb_font_dice.h` 是构建生成的文件，不是要求读者手写的头文件。

![官方骰子字体输入原图](images/cfb-font-dice.png)

## 181.2\_构建与运行（Building and Running）

`cfb_custom_font` 示例目录中有不同配置文件：

| 官方已有文件 | 用途 |
| --- | --- |
| `prj.conf` | 通用配置文件，通常应使用它。 |
| `boards/reel_board.conf` | 叠加配置（Overlay Configuration），为 `reel_board` 启用 SSD16XX 显示控制器支持。 |

为带 SSD16XX 显示器的 `reel_board` 构建并烧录：

译注：在已配置 Zephyr 开发环境的终端中，从 Zephyr 源码根目录执行以下官方命令；west 生成构建产物和字体头文件，`west flash` 将固件烧录到开发板。

```bash
west build -b reel_board samples/subsys/display/cfb_custom_font
west flash
```
