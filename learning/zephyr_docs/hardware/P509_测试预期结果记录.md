# 第509章\_测试预期结果记录

原文：[structztest__expected__result__entry](P509_测试预期结果记录.md)。读取日期：2026-10-13，`latest`。

`struct ztest_expected_result_entry` 表示一条**预期结果记录（Expected Result Entry）**，允许某个测试失败或跳过后仍被视为通过。关联宏为 [`ZTEST_EXPECT_FAIL`](P507_ZTest测试定义宏.md) 和 [`ZTEST_EXPECT_SKIP`](P507_ZTest测试定义宏.md)，分别登记预期失败与预期跳过。

公开头文件为 `zephyr/ztest_test.h`，源码位于 `subsys/testsuite/ztest/include/zephyr/ztest_test.h`。这里将原文构建环境的绝对包含路径改为公开包含名。

## 509.1\_预期结果的定位字段

记录通过套件名与测试名确定对象，再保存预期结果枚举。

| 类型与字段 | 官方说明译文 |
| --- | --- |
| `const char *test_suite_name` | 预期结果所对应的测试套件名称 |
| `const char *test_name` | 预期结果所对应的测试名称 |
| `enum ztest_expected_result expected_result` | 预期结果 |

这里**测试套件（Test Suite）**是测试的组织单位，[`ztest_expected_result`](P507_ZTest测试定义宏.md) 是预期结果枚举类型。
