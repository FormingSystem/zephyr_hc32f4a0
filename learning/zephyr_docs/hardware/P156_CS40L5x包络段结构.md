# 第156章\_CS40L5x包络段结构

原文：[structcs40l5x__pwle__section](https://docs.zephyrproject.org/latest/doxygen/html/structcs40l5x__pwle__section.html)。读取日期：2026-10-13，`latest`。

## 156.1\_分段线性包络段

[`cs40l5x_pwle_section`](https://docs.zephyrproject.org/latest/doxygen/html/structcs40l5x__pwle__section.html) 是 **分段线性包络（Piecewise Linear Envelope，PWLE）**的段结构，定义于 `zephyr/drivers/haptics/cs40l5x.h`。将此结构组成的数组交给 [`cs40l5x_upload_pwle()`](https://docs.zephyrproject.org/latest/doxygen/html/group__cs40l5x__interface.html#ga0283ec128debbc6ece55637e0fb79346)，即可上传PWLE效果；函数条件见[CS40L5x扩展](P153_CS40L5x触觉扩展.md)。

## 156.2\_全部四个字段与格式

原文各字段使用无符号 **Q格式定点数（Q-Format Fixed-Point Number）**表示；下表保留声明类型和格式。**半周期（Half-Cycle）**与时间时长是 [`duration`](https://docs.zephyrproject.org/latest/doxygen/html/structcs40l5x__pwle__section.html#ab7357e9ec16d8985b894a5292980d729) 的两种表示方式。

| 字段 | C类型 | 原文语义与格式 |
| --- | --- | --- |
| `duration` | [`uint16_t`](https://docs.zephyrproject.org/latest/doxygen/html/stdint_8h.html#a5debae8b2a1ec20a6694c0c443ee399e) | 段持续时间；时间方式为无符号Q14.2，半周期方式为无符号Q16.0。 |
| [`frequency`](https://docs.zephyrproject.org/latest/doxygen/html/structcs40l5x__pwle__section.html#a052240f8a3401a013cefc437a61af12c) | [`uint16_t`](https://docs.zephyrproject.org/latest/doxygen/html/stdint_8h.html#a5debae8b2a1ec20a6694c0c443ee399e) | 段频率（Frequency），无符号Q10.2。 |
| [`level`](https://docs.zephyrproject.org/latest/doxygen/html/structcs40l5x__pwle__section.html#aa6b8b9343cc7fa2cefb4082b3bcda7d2) | [`uint16_t`](https://docs.zephyrproject.org/latest/doxygen/html/stdint_8h.html#a5debae8b2a1ec20a6694c0c443ee399e) | 段输出级别（Level），无符号Q0.11。 |
| [`flags`](https://docs.zephyrproject.org/latest/doxygen/html/structcs40l5x__pwle__section.html#a69bf6ad0bbc831177e32b4ade9e0d510) | [`uint8_t`](https://docs.zephyrproject.org/latest/doxygen/html/stdint_8h.html#a3cb4a16b0e8d6af0af86d4fd6ba5fd9d) | 段标志（Flags），无符号Q4.0。 |

原页没有在此处给出时间方式的物理单位、模式切换标志或字段换算示例，本表不补造这些配置。
