# 第556章\_通用性能状态绑定

<a id="dtbinding-zephyr-generic-pstate"></a>

原文：[zephyr,generic-pstate](https://docs.zephyrproject.org/latest/build/dts/api/bindings/p_state/zephyr,generic-pstate.html)。读取日期：2026-10-13，`latest`。

`zephyr,generic-pstate` 是通用**性能状态（Performance State，P-state）**绑定，用于实现通用 P-state 设备节点。提供方是 Zephyr Project，原页没有列出专用驱动文件，相关开发板见[官方筛选目录](https://docs.zephyrproject.org/latest/boards/index.html#compatibles=zephyr,generic-pstate)。

## 556.1\_状态配置示例

官方示例定义三个性能状态，标识依次为 `0`、`1`、`2`，负载阈值依次为 `50`、`20`、`0`：

```dts
performance-states {
        pstate_0: pstate_0 {
                compatible = "zephyr,generic-pstate";
                load-threshold = <50>;
                pstate-id = <0>;
        };
        pstate_1: pstate_1 {
                compatible = "zephyr,generic-pstate";
                load-threshold = <20>;
                pstate-id = <1>;
        };
        pstate_2: pstate_2 {
                compatible = "zephyr,generic-pstate";
                load-threshold = <0>;
                pstate-id = <2>;
        };
};
```

## 556.2\_状态编号与选择条件

以下属性均为整数 `int`。**中央处理器（Central Processing Unit，CPU）**负载决定状态是否具备被驱动选择的资格。

| 属性 | 类型 | 中文说明与约束 |
| --- | --- | --- |
| `pstate-id` | `int` | 性能状态标识，必需；所有同级节点的状态标识必须唯一。建议从 `0` 开始，随着性能降低、节能程度增加而单调递增 |
| `load-threshold` | `int` | 进入此性能状态的 CPU 负载阈值，单位为百分比；当负载超过阈值时，此状态成为 P-state 驱动可以切换到的有效状态 |

原页没有已弃用的节点专用属性，基础属性列表为空。
