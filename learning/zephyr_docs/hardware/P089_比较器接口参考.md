# 第89章\_比较器接口参考

原文：[group__comparator__interface](https://docs.zephyrproject.org/latest/doxygen/html/group__comparator__interface.html)。读取日期：2026-10-13，`latest`。

## 89.1\_比较器接口与版本

本页给出 **比较器（Comparator）**的 **应用程序编程接口（Application Programming Interface，API）**。接口自Zephyr 4.0引入，版本为0.8.0；官方主头文件是 `zephyr/drivers/comparator.h`。设备配置与电源状态见[比较器概览](P087_比较器.md)。

原页还列出[比较器驱动后端API](P093_比较器驱动后端接口.md)和[伪比较器](P090_伪比较器接口.md)两个主题。

## 89.2\_触发条件与回调类型

**触发枚举（Trigger Enumeration）** `enum comparator_trigger` 定义对比较器输出变化的处理方式：

| 枚举项 | 含义 |
| --- | --- |
| `COMPARATOR_TRIGGER_NONE = 0` | 不触发。 |
| [`COMPARATOR_TRIGGER_RISING_EDGE`](https://docs.zephyrproject.org/latest/doxygen/html/group__comparator__interface.html#ggab02743771baf02ee0105aa1303931674a2bd8d1afb67a68a0bbc6737d434d6b89) | 在输出 **上升沿（Rising Edge）**触发。 |
| [`COMPARATOR_TRIGGER_FALLING_EDGE`](https://docs.zephyrproject.org/latest/doxygen/html/group__comparator__interface.html#ggab02743771baf02ee0105aa1303931674a762c9ea031595a909d2b70128adf9734) | 在输出 **下降沿（Falling Edge）**触发。 |
| [`COMPARATOR_TRIGGER_BOTH_EDGES`](https://docs.zephyrproject.org/latest/doxygen/html/group__comparator__interface.html#ggab02743771baf02ee0105aa1303931674a65cb9e6aa70639b15d0ca3cf16777f97) | 在输出两个边沿均触发。 |

[`comparator_callback_t`](https://docs.zephyrproject.org/latest/doxygen/html/group__comparator__interface.html#ga409308b8ba2efdca4a6ec4bdc4d3bc31) 是 **回调函数（Callback Function）**类型：

```c
typedef void (*comparator_callback_t)(const struct device *dev,
                                      void *user_data);
```

`dev` 是比较器设备；`user_data` 是设置触发回调时提供的用户数据指针。回调返回类型为 `void`，并不返回触发状态。

## 89.3\_取得输出与设置触发

函数声明如下：

```c
int comparator_get_output(const struct device *dev);
int comparator_set_trigger(const struct device *dev,
                            enum comparator_trigger trigger);
```

[`comparator_get_output()`](https://docs.zephyrproject.org/latest/doxygen/html/group__comparator__interface.html#ga89ea48c5d4a9d8c8ec44ee4c987309f3) 取得设备 `dev` 的输出状态：返回1表示高，返回0表示低，失败返回负错误码。此处0是有效的低电平结果，不是读取失败。

[`comparator_set_trigger()`](https://docs.zephyrproject.org/latest/doxygen/html/group__comparator__interface.html#ga964fab6458e020d8717ee7c47a84c1d0) 为设备 `dev` 设置 `trigger` 指定的信号与回调触发条件。成功返回0，失败返回负错误码。

## 89.4\_设置和禁用触发回调

[`comparator_set_trigger_callback()`](https://docs.zephyrproject.org/latest/doxygen/html/group__comparator__interface.html#ga1c9dc5dd46f5bb62b3cf4e2cfcd42509) 设置触发回调：

```c
static inline int comparator_set_trigger_callback(
    const struct device *dev, comparator_callback_t callback,
    void *user_data);
```

`dev` 是比较器设备，`callback` 为触发回调，`user_data` 为传给回调的用户数据。成功返回0，失败返回负错误码。

把 `callback` 设为 `NULL` 可禁用回调。**若已有待处理触发，回调会立即被调用。** 因此不能假定注册后一定先返回、将来才收到第一次回调；相关用户数据应在注册前准备好。原页没有另行保证所有驱动使用相同的回调执行上下文。

## 89.5\_查询并清除待处理触发

[`comparator_trigger_is_pending()`](https://docs.zephyrproject.org/latest/doxygen/html/group__comparator__interface.html#ga28aa27594c7c3cf5cd7306d47ebf53f9) 检查是否有待处理触发，并清除它：

```c
int comparator_trigger_is_pending(const struct device *dev);
```

`dev` 是比较器设备。返回1表示此前有待处理触发；返回0表示触发处于清除状态（原文为“Trigger was cleared”）；失败返回负错误码。

这个操作包含清除动作，不是一个完全不改变状态的旁观查询。设计轮询与回调配合时，应保留这一副作用。
