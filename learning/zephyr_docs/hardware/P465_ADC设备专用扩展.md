# 第465章\_ADC设备专用扩展

原文：[group__adc__interface__ext](https://docs.zephyrproject.org/latest/doxygen/html/group__adc__interface__ext.html)。读取日期：2026-10-13，`latest`。

## 465.1\_扩展接口目录

本组收集**模数转换器（Analog-to-Digital Converter，ADC）**的设备专用应用程序接口（Application Programming Interface，API）扩展。官方目录包含以下专题。

| 专题 | 说明 |
| --- | --- |
| [ADS131M02](P467_ADS131M02扩展接口.md) | Texas Instruments（德州仪器）的双通道串行外设接口（Serial Peripheral Interface，SPI）ADC |
| [ADS1x4s0x](P468_ADS1x4s0x扩展接口.md) | Texas Instruments ADS1x4s0x 系列 |
| [电流检测放大器](P457_ADC电流检测放大器接口.md) | Current Sense Amplifier |
| [电流检测分流器](P458_ADC电流检测分流器接口.md) | Current Sense Shunt |
| [Infineon AutAnalog SAR ADC](P469_Infineon自动模拟SAR扩展接口.md) | Infineon（英飞凌）AutAnalog 逐次逼近寄存器（Successive Approximation Register，SAR）ADC 扩展 API |
| [LMP90xxx](P470_LMP90xxx扩展接口.md) | Texas Instruments LMP90xxx 模拟前端（Analog Front End，AFE） |
| [分压器](P459_ADC分压器接口.md) | Voltage Divider |
| [WisBlock ADC](P471_WisBlock_ADC通道.md) | WisBlock Core 模块引出的 ADC 通道常量 |
