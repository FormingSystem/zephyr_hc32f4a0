# 第413章\_I3C设备特征返回数据

原文：[structi3c__ccc__getdcr](https://docs.zephyrproject.org/latest/doxygen/html/structi3c__ccc__getdcr.html)。读取日期：2026-10-13，`latest`。

## 413.1\_GETDCR载荷

`struct i3c_ccc_getdcr` 是**改进的集成电路间总线（Improved Inter-Integrated Circuit，I3C）通用命令码（Common Command Code，CCC）** `GETDCR` 的载荷（Payload）。命令含义是**获取设备特征寄存器（Get Device Characteristics Register）**。头文件为 `zephyr/drivers/i3c/ccc.h`。

## 413.2\_字段

```c
uint8_t dcr;
```

字段 [`dcr`](https://docs.zephyrproject.org/latest/doxygen/html/structi3c__ccc__getdcr.html#a0615f439c4d556b08f7ecba8dff1c007) 保存**设备特征寄存器（Device Characteristics Register，DCR）**。原页面没有列出其具体取值含义。
