# 第106章\_稳压器

原文：[Regulators](https://docs.zephyrproject.org/latest/hardware/peripherals/regulators.html)。读取日期：2026-10-13，`latest`。

## 106.1\_控制电压与电流

**稳压器（Regulator）**子系统用于控制电压和电流调节器。一个常见例子是：**通用输入输出（General-Purpose Input/Output，GPIO）**引脚控制晶体管，由晶体管向并非始终需要工作的设备供电。另一个例子是 **电源管理集成电路（Power Management Integrated Circuit，PMIC）**，这通常是复杂得多的器件。

## 106.2\_设备树依赖与供电请求

**设备树（Devicetree）**中的 `*-supply` 属性标识某个设备树节点直接依赖的一个或多个稳压器。该节点的驱动在设备需要活动时，通过稳压器 **应用程序编程接口（Application Programming Interface，API）**提出供电请求；设备关闭时释放供电请求。

最简单的场景是稳压器只有一个 **客户端（Client）**。原文建议：此时使用稳压器设备框架的开销并不值得，应使用 `*-gpios` 设备树属性。这类供电控制不建立独立稳压器设备接口，而由对应节点的驱动（例如传感器驱动）完全控制。

## 106.3\_接口与相关示例

完整声明见[稳压器API](https://docs.zephyrproject.org/latest/doxygen/html/group__regulator__interface.html)。原页另提供[伪稳压器（Fake Regulator）](P498_稳压器伪设备接口.md)参考。

[带充电器、电量计和稳压器的多功能设备示例](P122_多功能电源设备示例.md)演示 **多功能设备（Multi-Function Device，MFD）**如何同时使用充电器、电量计和稳压器子系统。其中的电池相关接口分别见[充电器](P107_充电器.md)与[电量计](P108_电量计.md)。
