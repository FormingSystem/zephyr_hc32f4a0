# 第81章\_数字麦克风采集示例

原文：[Digital Microphone (DMIC)](https://docs.zephyrproject.org/latest/samples/drivers/audio/dmic/README.html)。读取日期：2026-10-13，`latest`。

## 81.1\_示例用途

本示例是一个简单应用，用于演示 **数字麦克风（Digital Microphone，DMIC）**音频 **应用程序编程接口（Application Programming Interface，API）**，也可辅助开发实现该API的驱动。

它执行两次 **脉冲密度调制（Pulse Density Modulation，PDM）**传输，分别使用单通道和双通道配置，**不处理接收到的音频数据**。因此，该示例验证的操作路径不等同于音频播放或信号处理，接口背景见[数字麦克风](P079_数字麦克风.md)。

## 81.2\_设备和板要求

通过定义名为 `dmic_dev` 的设备树 **节点标签（Node Label）**指定使用的设备。原文报告已在[nRF52840 DK](https://docs.zephyrproject.org/latest/boards/nordic/nrf52840dk/doc/index.html#nrf52840dk)（`nrf52840dk/nrf52840`）和[nRF5340 DK](https://docs.zephyrproject.org/latest/boards/nordic/nrf5340dk/doc/index.html#nrf5340dk)（`nrf5340dk/nrf5340/cpuapp`）测试，并为两块板提供 **覆盖文件（Overlay）**。这是官方报告的测试范围，不是本次实板验证。

> 译注：按原页记录的修订号核对，[该版本示例代码](https://github.com/zephyrproject-rtos/zephyr/blob/776c0cab9a632f9ad2214cf7bebc7d5589baf40b/samples/drivers/audio/dmic/src/main.c#L78)使用 `DT_NODELABEL(dmic_dev)`。其他版本可能改用 `DT_ALIAS(dmic0)`；请按实际 `main.c` 与覆盖文件匹配节点标签或别名，不能混用不同版本的约定。

## 81.3\_构建和运行

官方源码位于 `samples/drivers/audio/dmic`。先准备Zephyr环境、对应工具链及烧录工具，并按板配置连接麦克风；在Ubuntu Bash或已准备好的UCRT64 Bash中，从实验Zephyr源码根目录执行：

```shell
west build -b nrf52840dk/nrf52840 samples/drivers/audio/dmic
west flash
```

`west build` 生成构建产物，成功后再由 `west flash` 烧录。若找不到 `dmic_dev` 或设备未就绪，应返回设备树和驱动配置检查。原页未给出固定日志或音频文件输出；本次未执行构建、烧录或采集。完整声明见[数字麦克风接口](https://docs.zephyrproject.org/latest/doxygen/html/group__audio__dmic__interface.html)。
