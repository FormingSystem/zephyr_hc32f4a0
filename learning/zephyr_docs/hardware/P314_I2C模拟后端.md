# 第314章\_I2C模拟后端

原文：[group__i2c__emul__interface](https://docs.zephyrproject.org/latest/doxygen/html/group__i2c__emul__interface.html)。读取日期：2026-10-13，`latest`。

## 314.1\_模拟接口

本页定义集成电路间总线（Inter-Integrated Circuit，I²C）模拟（Emulation）驱动公共接口，声明来自 `zephyr/drivers/i2c_emul.h`。

结构 [`i2c_emul`](https://docs.zephyrproject.org/latest/doxygen/html/structi2c__emul.html) 表示模拟设备链表节点，[`i2c_emul_api`](https://docs.zephyrproject.org/latest/doxygen/html/structi2c__emul__api.html) 定义模拟器接口，分别见[I2C模拟设备节点](P316_I2C模拟设备节点.md)及[I2C模拟函数表](P317_I2C模拟函数表.md)。

## 314.2\_传输回调

回调（Callback）类型 [`i2c_emul_transfer_t`](https://docs.zephyrproject.org/latest/doxygen/html/group__i2c__emul__interface.html#ga1b27ff11534eeac47cf50ffb2a1c7cca) 将I²C消息传递给模拟器：

```c
typedef int (*i2c_emul_transfer_t)(const struct emul *target,
                                   struct i2c_msg *msgs,
                                   int num_msgs, int addr);
```

`target` 为设备模拟器实例，`msgs` 为消息数组，`num_msgs` 为待传输消息数，`addr` 为目标设备I²C地址。对于读消息，模拟器用读回的数据更新消息的 `buf` 成员所指数据。

成功返回 `0`，一般输入/输出（Input/Output，I/O）错误返回 `-EIO`。

## 314.3\_注册模拟设备

函数 [`i2c_emul_register()`](https://docs.zephyrproject.org/latest/doxygen/html/group__i2c__emul__interface.html#ga92851f09c23531bbaea25301dc2607ce) 在控制器上注册模拟设备：

```c
int i2c_emul_register(const struct device *dev, struct i2c_emul *emul);
```

`dev` 为将使用模拟器的设备，[`emul`](P477_仿真器实例结构.md) 为所用I²C模拟器。原文规定此函数始终返回表示成功的 `0`。
