# 第95章\_运算放大器驱动后端接口

原文：[group__opamp__interface__backend](https://docs.zephyrproject.org/latest/doxygen/html/group__opamp__interface__backend.html)。读取日期：2026-10-13，`latest`。

## 95.1\_运算放大器后端

本组提供实现 **运算放大器（Operational Amplifier，OPAMP）**驱动所需的 **应用程序编程接口（Application Programming Interface，API）**类型、回调签名与辅助内容。官方头文件为 `zephyr/drivers/opamp.h`，原页列出的 `struct opamp_driver_api` 是[运算放大器操作结构](P096_运算放大器操作结构.md)。

## 95.2\_增益设置回调

[`opamp_api_set_gain_t`](https://docs.zephyrproject.org/latest/doxygen/html/group__opamp__interface__backend.html#ga717d064b6e25367a4cf4e5d87bc39408) 是设置增益的 **回调函数（Callback Function）**类型：

```c
typedef int (*opamp_api_set_gain_t)(const struct device *dev,
                                   enum opamp_gain gain);
```

`dev` 为设备指针，`gain` 为增益枚举。原页将参数说明指向 [`opamp_set_gain()`](https://docs.zephyrproject.org/latest/doxygen/html/group__opamp__interface.html#ga2334e3b329d1e5338ff05ee872ca7575)；完整增益值与返回约束见[运算放大器接口参考](P091_运算放大器接口参考.md)。

## 95.3\_功能模式枚举

`enum opamp_functional_mode` 定义OPAMP **功能模式（Functional Mode）**。它的值与官方设备树绑定 `dts/bindings/opamp/opamp-controller.yaml` 中的 `functional-mode` 属性一一对应。

| 枚举项 | 模式 |
| --- | --- |
| `OPAMP_FUNCTIONAL_MODE_DIFFERENTIAL = 0` | **差分放大模式（Differential Amplifier Mode）**。 |
| [`OPAMP_FUNCTIONAL_MODE_INVERTING`](https://docs.zephyrproject.org/latest/doxygen/html/group__opamp__interface__backend.html#ggad931a18f398caef505f00f45261304eaa0a50427f473cc71c28b7592fc1925371) | **反相放大模式（Inverting Amplifier Mode）**。 |
| [`OPAMP_FUNCTIONAL_MODE_NON_INVERTING`](https://docs.zephyrproject.org/latest/doxygen/html/group__opamp__interface__backend.html#ggad931a18f398caef505f00f45261304eaa0708d5e43d7d41d327ecc0c2743adb5b) | **同相放大模式（Non-Inverting Amplifier Mode）**。 |
| [`OPAMP_FUNCTIONAL_MODE_FOLLOWER`](https://docs.zephyrproject.org/latest/doxygen/html/group__opamp__interface__backend.html#ggad931a18f398caef505f00f45261304eaaf4bbaca0018a70120166afd5d998deb9) | **跟随器模式（Follower Mode）**。 |
| [`OPAMP_FUNCTIONAL_MODE_STANDALONE`](https://docs.zephyrproject.org/latest/doxygen/html/group__opamp__interface__backend.html#ggad931a18f398caef505f00f45261304eaaa7fc32cb1654756953d37c2b69576dc2) | **独立模式（Standalone Mode）**。 |

在独立模式下，**增益由外部电阻设置**；设置增益的API调用会被忽略或不起作用。这是原文明确给出的模式限制，不能仅因应用调用了设置函数，就推断硬件增益已经变化。
