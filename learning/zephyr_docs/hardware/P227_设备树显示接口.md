# 第227章\_设备树显示接口

原文：[group__devicetree-display](https://docs.zephyrproject.org/latest/doxygen/html/group__devicetree-display.html)。读取日期：2026-10-13，`latest`。

## 227.1\_按逻辑索引取得显示节点

本页提供 **设备树（Devicetree，DT）**显示相关宏，声明来自官方头文件 `zephyr/devicetree/display.h`。

<a id="ga265c3a81b2f6962b11931028c8727863"></a>

宏 `DT_ZEPHYR_DISPLAY(idx)` 从兼容属性为 `zephyr,displays` 的节点之 `displays` 属性中，按逻辑索引（Logical Index）取得显示节点标识符（Node Identifier）。`idx` 是显示节点引用句柄（phandle）在该属性中的逻辑索引。

原展开式使用宏 [`DT_COMPAT_GET_ANY_STATUS_OKAY`](../dt_identity_reference/P001_设备树节点标识宏.md#ga4858c378b098dcb7c35de1db25442acc) 取得已启用的兼容节点，再用 [`DT_PHANDLE_BY_IDX`](../dt_property_reference/P001_设备树属性读取宏.md#ga8ff163c240878a988d29d727671671de) 按索引取得引用节点：

```c
DT_PHANDLE_BY_IDX(DT_COMPAT_GET_ANY_STATUS_OKAY(zephyr_displays), displays, idx)
```

原设备树片段：

```dts
 displays_node: my-displays {
    compatible = "zephyr,displays";
    displays = <&n2 &n3>;
    status = "okay";
 };

n2: node-2 { ... };
n3: node-3 { ... };
```

上例的 `displays` 属性有两个元素：索引 0 的 `&n2` 引用 `node-2`；索引 1 的 `&n3` 引用 `node-3`。下面两行分别取得这两个显示节点标识：

```c
DT_ZEPHYR_DISPLAY(0) // node identifier for display node node-2
DT_ZEPHYR_DISPLAY(1) // node identifier for display node node-3
```

返回显示节点标识；否则返回无效节点标记 [`DT_INVALID_NODE`](../dt_identity_reference/P001_设备树节点标识宏.md#ga710cc4455dd7e738f43f750153163855)。

## 227.2\_取得显示器数量

<a id="ga5a5f5bc95a76e4f1d09d970a18e6e5b5"></a>

宏 [`DT_ZEPHYR_DISPLAYS_COUNT`](https://docs.zephyrproject.org/latest/doxygen/html/group__devicetree-display.html#ga5a5f5bc95a76e4f1d09d970a18e6e5b5) 返回 Zephyr 显示器数量。

原展开式中的 [`COND_CODE_1`](../util_reference/P001_通用工具公共接口.md#ga358bc3e7669c860a98839a51cd526b20) 是条件展开宏；[`DT_HAS_COMPAT_STATUS_OKAY`](../dt_identity_reference/P002_设备树存在性与状态宏.md#ga916e11b66fdaab46e93c25241b62b52a) 检查启用的兼容节点；[`DT_PROP_LEN`](../dt_property_reference/P001_设备树属性读取宏.md#gaa7f5afcedd1f54be79a5337e8e28a5b6) 取得属性长度；[`DT_HAS_CHOSEN`](../dt_node_reference/P002_设备树chosen节点宏.md#ga9df6bacab5f579284f5f3c1e4856cd15) 检查选定节点属性（Chosen Property）。

```c
COND_CODE_1(DT_HAS_COMPAT_STATUS_OKAY(zephyr_displays),                                    \
            (DT_PROP_LEN(DT_COMPAT_GET_ANY_STATUS_OKAY(zephyr_displays), displays)),       \
            (DT_HAS_CHOSEN(zephyr_display)))
```

若存在兼容属性为 `zephyr,displays` 的节点，返回其 `displays` 属性指定的显示器数；否则，若存在 `zephyr,display` 选定节点属性则返回 1，再否则返回 0。
