# 第420章\_I3C目标清单活动控制器

原文：[structi3c__ccc__deftgts__active__controller](https://docs.zephyrproject.org/latest/doxygen/html/structi3c__ccc__deftgts__active__controller.html)。读取日期：2026-10-13，`latest`。

## 420.1\_活动控制器部分

`struct i3c_ccc_deftgts_active_controller` 是**改进的集成电路间总线（Improved Inter-Integrated Circuit，I3C）通用命令码（Common Command Code，CCC）** `DEFTGTS` 的**活动控制器（Active Controller）**载荷部分。该命令用于定义目标列表（Define List of Targets），本结构描述 I3C 总线上的活动控制器。头文件为 `zephyr/drivers/i3c/ccc.h`。

## 420.2\_地址与特征

**设备特征寄存器（Device Characteristic Register，DCR）**和**总线特征寄存器（Bus Characteristic Register，BCR）**记录该控制器的特征。
