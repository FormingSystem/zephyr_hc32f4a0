# 第554章\_主机原生性能状态绑定

<a id="dtbinding-zephyr-native-sim-pstate"></a>

原文：[zephyr,native-sim-pstate](https://docs.zephyrproject.org/latest/build/dts/api/bindings/p_state/zephyr,native-sim-pstate.html)。读取日期：2026-10-13，`latest`。

`zephyr,native-sim-pstate` 是 Zephyr Project 主机原生模拟目标的**性能状态（Performance State，P-state）**自定义属性模拟实现（Mock Implementation）。原页没有列出专用驱动文件，相关开发板见[官方筛选目录](https://docs.zephyrproject.org/latest/boards/index.html#compatibles=zephyr,native-sim-pstate)。

## 554.1\_状态标识与负载阈值

以下属性均为整数 `int`。**中央处理器（Central Processing Unit，CPU）**负载阈值决定哪些性能状态可以被驱动选中。

| 属性 | 类型 | 中文说明与约束 |
| --- | --- | --- |
| `pstate-id` | `int` | 性能状态标识，必需 |
| `load-threshold` | `int` | 进入此性能状态的 CPU 负载阈值，单位为百分比；当 CPU 负载超过这个阈值时，此状态成为 P-state 驱动可以切换到的有效状态 |

原页没有已弃用的节点专用属性，基础属性列表为空。
