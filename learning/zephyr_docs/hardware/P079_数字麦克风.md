# 第79章\_数字麦克风

原文：[Digital Microphone (DMIC)](https://docs.zephyrproject.org/latest/hardware/peripherals/audio/dmic.html)。读取日期：2026-10-13，`latest`。

## 79.1\_从PDM位流到PCM采样

**数字麦克风（Digital Microphone，DMIC）**音频接口用于访问数字麦克风。数字麦克风通常输出 **脉冲密度调制（Pulse Density Modulation，PDM）**位流，而不是模拟音频。PDM是高速单比特信号，音频幅度由一段时间内1和0的密度表示。

应用通常消费 **脉冲编码调制（Pulse Code Modulation，PCM）**采样，而非原始PDM数据，因此DMIC控制器把麦克风位流转换为PCM音频。转换包括 **滤波（Filtering）**与 **抽取（Decimation）**：滤波去除经噪声整形分布到PDM高频部分的噪声，抽取将位流速率降低到所需PCM采样率。

在Zephyr中，DMIC设备属于音频采集外设。应用配置麦克风与控制器，启动采集，再从驱动读取PCM缓冲区。

## 79.2\_配置的三个部分

DMIC **应用程序编程接口（Application Programming Interface，API）**把配置分成三个部分，对应采集路径中的三个问题：如何在PDM侧驱动麦克风、如何安排输入PDM通道，以及如何把转换后的PCM采样交给应用。它们组合在 [`dmic_cfg`](https://docs.zephyrproject.org/latest/doxygen/html/structdmic__cfg.html) 配置结构中，并传给 [`dmic_configure()`](https://docs.zephyrproject.org/latest/doxygen/html/group__audio__dmic__interface.html#ga09fc7074323c2f3115b06c5212d21fc7)。

| 配置部分 | 含义 |
| --- | --- |
| [`dmic_cfg.io`](https://docs.zephyrproject.org/latest/doxygen/html/structdmic__cfg.html#abac7595e0a03cf976d8359a86259f54b)，PDM输入／输出配置（PDM I/O Configuration） | 描述电气与时序要求，包括支持的PDM时钟频率范围、占空比及控制器相关信号极性。I/O是 **输入／输出（Input/Output）**。 |
| [`dmic_cfg.channel`](https://docs.zephyrproject.org/latest/doxygen/html/structdmic__cfg.html#aaef2d2b475ce65d18c48d60cd1d393c4)，通道配置（Channel Configuration） | 指定哪个物理PDM控制器及左／右麦克风通道对应PCM输出中的哪个逻辑音频通道，并声明应用需要的通道数和流数量。 |
| [`dmic_cfg.streams`](https://docs.zephyrproject.org/latest/doxygen/html/structdmic__cfg.html#a90f08070236a8e2c07c30edc54c687a5)，PCM流配置（PCM Stream Configuration） | 定义采样率、采样位宽、块大小，以及每个启用流用来分配接收缓冲区的 `k_mem_slab`。 |

`k_mem_slab` 是内核 **固定大小内存块池（Memory Slab）**，为接收音频提供预先准备的内存块。

## 79.3\_典型应用流程

1. 获取DMIC设备，通常从设备树取得。
2. 填写 [`dmic_cfg`](https://docs.zephyrproject.org/latest/doxygen/html/structdmic__cfg.html) 的I/O、通道和流配置；接收内存的定义见下一节。
3. 调用 [`dmic_configure()`](https://docs.zephyrproject.org/latest/doxygen/html/group__audio__dmic__interface.html#ga09fc7074323c2f3115b06c5212d21fc7)，传入该配置结构。
4. 调用 [`dmic_trigger()`](https://docs.zephyrproject.org/latest/doxygen/html/group__audio__dmic__interface.html#ga051e82f30b76f0fca789ba0147054184)，使用 [`DMIC_TRIGGER_START`](https://docs.zephyrproject.org/latest/doxygen/html/group__audio__dmic__interface.html#gga24aae0a7871b3bd31b130061feeefc14a031d6c7646642d4858a22c853d6d6eaa) 启动采集。
5. 调用 [`dmic_read()`](https://docs.zephyrproject.org/latest/doxygen/html/group__audio__dmic__interface.html#ga74b51bddaa175c518d45211f936d08e6)，获取PCM数据。
6. 根据需要发送其他触发命令，停止、暂停或重置采集。

设备查找、配置、启动和数据读取是不同阶段；需要先准备配置与接收存储，再开始采集。

## 79.4\_接收缓冲区

接收的PCM数据通过驱动拥有的缓冲区返回。应用通过每个已配置PCM流引用的 `k_mem_slab` 提供底层存储。一种常见做法是静态声明内存块池。

原例中的 `K_MEM_SLAB_DEFINE_STATIC` 是静态定义内存块池的宏，`mem_slab` 是池名，`SAMPLES_PER_BUFFER` 为每个缓冲区的采样数量，`BUFFER_COUNT` 为块数量；它们的具体数值由应用定义。例子使用16位整数存放采样：

```c
 K_MEM_SLAB_DEFINE_STATIC(mem_slab,
                          SAMPLES_PER_BUFFER * sizeof(int16_t),
                          BUFFER_COUNT,
                          sizeof(void *));
```

每块保存一个PCM缓冲区。`BUFFER_COUNT` 决定应用通过 [`dmic_read()`](https://docs.zephyrproject.org/latest/doxygen/html/group__audio__dmic__interface.html#ga74b51bddaa175c518d45211f936d08e6) 读取之前，内部可以排队多少个缓冲区。块字节数为采样数乘以 `sizeof(int16_t)`，最后的 `sizeof(void *)` 指定对齐；它不是PCM采样位宽。

## 79.5\_交互式采集命令

启用Kconfig配置项 [`CONFIG_AUDIO_DMIC_SHELL`](https://docs.zephyrproject.org/latest/kconfig.html#CONFIG_AUDIO_DMIC_SHELL) 后，提供 `dmic` **命令行（Shell）**命令，无需编写专用应用即可交互采集。下列命令在目标Zephyr设备的shell中执行，而不是主机Bash；前提是对应固件已启用该功能、DMIC设备已经就绪。每个子命令第一个参数为设备名称，后面可选音频参数；尖括号代表需要填写的参数，方括号表示可选项，不原样输入。

| 命令语法 | 行为和默认值 |
| --- | --- |
| `dmic read <device> [<count> [<rate_hz> [<channels> [<pcm_width>]]]]` | 采集 `count` 个音频块，打印每个通道的峰值电平。默认5块，每块50 ms音频。 |
| `dmic vu <device> [<rate_hz> [<channels> [<pcm_width>]]]` | 实时显示彩色电平表，每通道一条，带峰值保持和 **削波指示（Clip Indication）**；按任意键退出。`vu` 为电平表命令名。 |
| `dmic dump <device> [<seconds> [<rate_hz> [<channels> [<pcm_width>]]]]` | 采集指定秒数，以Base64编码输出原始PCM，同时打印主机端解码和播放所需命令；默认2秒。 |

`rate_hz` 为采样率，`channels` 为通道数，`pcm_width` 为PCM采样位宽。Base64是一种将二进制内容表示成文本的编码方式，不会把原始PCM自动变成带文件头的音频格式。内置帮助（例如 `dmic read --help`）列出参数及默认值；找不到设备或命令时，应返回设备和固件配置检查。本次没有开启麦克风或采集音频。

## 79.6\_配置与相关示例

相关Kconfig配置项包括 [`CONFIG_AUDIO_DMIC`](https://docs.zephyrproject.org/latest/kconfig.html#CONFIG_AUDIO_DMIC) 和 [`CONFIG_AUDIO_DMIC_SHELL`](https://docs.zephyrproject.org/latest/kconfig.html#CONFIG_AUDIO_DMIC_SHELL)，分别用于DMIC及其命令行支持。Kconfig是Zephyr的配置系统。完整声明见[数字麦克风接口参考](https://docs.zephyrproject.org/latest/doxygen/html/group__audio__dmic__interface.html)。

相关示例为[数字麦克风DMIC](P081_数字麦克风采集示例.md)，演示不同配置下的PDM传输；以及[X-NUCLEO-IKS02A1扩展板麦克风](P082_扩展板MEMS麦克风示例.md)，使用板载数字 **微机电系统（Micro-Electro-Mechanical Systems，MEMS）**麦克风采集音频。
