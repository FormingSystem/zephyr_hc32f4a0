# 第26章\_半主机

原文：[Semihosting Guide](https://docs.zephyrproject.org/latest/hardware/arch/semihost.html)。读取日期：2026-10-12，`latest`。

**半主机（Semihosting）**让运行于 Arm、RISC-V 或 Xtensa 目标上的代码，使用运行调试器或模拟器的主机计算机的输入输出能力。

完整功能见 [Arm 半主机规范](https://github.com/ARM-software/abi-aa/blob/main/semihosting/semihosting.rst)。RISC-V 借用 Arm 的定义，见 [RISC-V 半主机文档](https://github.com/riscv-non-isa/riscv-semihosting/blob/main/riscv-semihosting.adoc)。Xtensa 实现支持 [GDB File-I/O 远程协议扩展](https://sourceware.org/gdb/current/onlinedocs/gdb.html/File_002dI_002fO-Remote-Protocol-Extension.html)。

## 26.1\_文件操作

应用可以打开、读取和修改主机文件。这适合用超出模拟平台 **只读存储器（Read-Only Memory，ROM）** 容量的数据集验证程序。路径既可为绝对路径，也可相对于运行进程的目录。

```c
const char *path = "./data.bin";
long file_len, bytes_read, fd;
uint8_t buffer[16];

/* Open the data file for reading */
fd = semihost_open(path, SEMIHOST_OPEN_RB);
if (fd < 0) {
   return -ENOENT;
}
/* Read all data from the file */
file_len = semihost_flen(fd);
while(file_len > 0) {
   bytes_read = semihost_read(fd, buffer, MIN(file_len, sizeof(buffer)));
   if (bytes_read < 0) {
      break;
   }
   /* Process read data */
   do_data_processing(buffer, bytes_read);
   /* Update remaining length */
   file_len -= bytes_read;
}
/* Close the file */
semihost_close(fd);
```

示例以二进制只读方式打开 `data.bin`，取得长度后分块读取、处理，最后关闭。

> 译注：原例只处理读取返回负数的情况；若剩余长度为正而读取返回 0，循环不会推进，实际代码需处理这种情况。文件长度查询失败也需检查。相对路径的基准是主机提供半主机服务的进程目录，不自动等于 Zephyr 源码根目录；本次未运行此文件操作。

## 26.2\_其他功能与接口

可通过 `semihost_exec()` 直接执行 `semihost_instr` 定义的操作，取得其他功能。所需参数与返回码见上述 Arm 规范。Zephyr 接口见[半主机API](https://docs.zephyrproject.org/latest/doxygen/html/group__semihost.html)。
