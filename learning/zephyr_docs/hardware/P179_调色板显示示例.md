# 第179章\_调色板显示示例

原文：[Color Palette Display](https://docs.zephyrproject.org/latest/samples/subsys/display/color_palette/README.html)。读取日期：2026-10-13，`latest`。

## 179.1\_概述（Overview）

本示例展示 **索引颜色格式（Indexed Color Format）**与 **调色板（Color Palette）**的用法，例如 `I_4` 格式。应用把显示区域划分为垂直色带，每一条用不同的调色板颜色索引填充。

索引颜色格式通过查找表（Lookup Table），也就是调色板，把较小的索引值映射为完整颜色值。当所需颜色数量有限时，这种方式能显著节省内存。例如，`I_4` 每像素仅使用 4 位，可表示 16 种颜色；相比之下，`ARGB8888` 每像素使用 32 位。译注：ARGB 表示透明度与红、绿、蓝分量（Alpha, Red, Green, Blue），8888 表示四个分量各占 8 位。

示例按以下步骤执行：

1. 从显示设备能力信息（Display Capabilities）中读取调色板。
2. 统计有效的非空调色板条目数。
3. 沿显示器宽度均匀划分垂直色带。
4. 用对应的调色板颜色索引填充每条色带。
5. 在屏幕上显示结果。

## 179.2\_要求（Requirements）

显示器必须支持索引颜色格式，并在 **设备树（Devicetree）**中使用兼容标识（Compatible） `zephyr,panel-color-palette` 定义调色板。

支持调色板且集成显示器的开发板包括 [Inkplate 6Color](https://docs.zephyrproject.org/latest/boards/solderedelectronics/inkplate_6color/doc/index.html#inkplate_6color)。仿真时也可使用 [`native_sim`](../native_reference/P004_Native_Simulator本机模拟器.md#native_sim) 主机原生目标，把 **简单直接媒体层（Simple DirectMedia Layer，SDL）**显示驱动配置为 `I_4` 像素格式。

## 179.3\_构建与运行（Building and Running）

译注：下列官方命令在已配置 Zephyr 开发环境的终端中，从 Zephyr 源码根目录执行；示例由官方仓库提供，west 生成构建产物。两种开发板是独立构建分支。

为 [`native_sim`](../native_reference/P004_Native_Simulator本机模拟器.md#native_sim) 构建并运行：

```bash
# From the root of the zephyr repository
west build -b native_sim/native/64 samples/subsys/display/color_palette
west build -t run
```

此命令会打开一个 SDL 窗口，显示 16 条垂直色带，每条对应调色板中的一种颜色，从黑色经过各种颜色到白色。

为 Inkplate 6Color 构建并烧录：

```bash
# From the root of the zephyr repository
west build -b inkplate_6color/esp32/procpu samples/subsys/display/color_palette
west flash
```
