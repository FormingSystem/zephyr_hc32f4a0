# 第415章\_I3C最大读取长度命令数据

原文：[structi3c__ccc__mrl](https://docs.zephyrproject.org/latest/doxygen/html/structi3c__ccc__mrl.html)。读取日期：2026-10-13，`latest`。

## 415.1\_SETMRL与GETMRL载荷

`struct i3c_ccc_mrl` 是**改进的集成电路间总线（Improved Inter-Integrated Circuit，I3C）通用命令码（Common Command Code，CCC）** `SETMRL`/`GETMRL` 的载荷（Payload），分别用于设置/获取**最大读取长度（Maximum Read Length，MRL）**。头文件为 `zephyr/drivers/i3c/ccc.h`。

## 415.2\_字段

**带内中断（In-Band Interrupt，IBI）**的可选载荷大小由 [`ibi_len`](https://docs.zephyrproject.org/latest/doxygen/html/structi3c__ccc__mrl.html#a7480df4486c9eb8a11581e42ff3b6b67) 保存。

| 字段 | 类型 | 含义 |
| --- | --- | --- |
| [`len`](https://docs.zephyrproject.org/latest/doxygen/html/structi3c__ccc__mrl.html#a381d52439049c6a13d232e4e94d17335) | [`uint16_t`](https://docs.zephyrproject.org/latest/doxygen/html/stdint_8h.html#a5debae8b2a1ec20a6694c0c443ee399e) | 最大读取长度。 |
| `ibi_len` | [`uint8_t`](https://docs.zephyrproject.org/latest/doxygen/html/stdint_8h.html#a3cb4a16b0e8d6af0af86d4fd6ba5fd9d) | 可选的 IBI 载荷大小。 |

## 415.3\_驱动与辅助函数的字节序职责

目标设备返回的原始数据采用**大端字节序（Big-endian）**。驱动和辅助函数必须在把结果交给调用者之前，将其转换为**中央处理器（Central Processing Unit，CPU）**所用的字节序。
