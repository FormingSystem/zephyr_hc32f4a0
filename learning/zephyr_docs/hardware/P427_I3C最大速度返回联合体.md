# 第427章\_I3C最大速度返回联合体

原文：[unioni3c__ccc__getmxds](https://docs.zephyrproject.org/latest/doxygen/html/unioni3c__ccc__getmxds.html)。读取日期：2026-10-13，`latest`。

## 427.1\_GETMXDS返回格式

`union i3c_ccc_getmxds` 是**改进的集成电路间总线（Improved Inter-Integrated Circuit，I3C）通用命令码（Common Command Code，CCC）** `GETMXDS` 的载荷（Payload），用于**获取最大数据速度（Get Max Data Speed）**。头文件为 `zephyr/drivers/i3c/ccc.h`。

三个格式是联合体中的三个结构成员。按原字段表整理如下：

```c
union i3c_ccc_getmxds {
    struct {
        uint8_t maxwr;
        uint8_t maxrd;
    } fmt1;
    struct {
        uint8_t maxwr;
        uint8_t maxrd;
        uint8_t maxrdturn[3];
    } fmt2;
    struct {
        uint8_t wrrdturn[5];
        uint8_t crhdly1;
    } fmt3;
};
```

## 427.2\_格式1与格式2

格式 1 和格式 2 都有 [`maxwr`](https://docs.zephyrproject.org/latest/doxygen/html/unioni3c__ccc__getmxds.html#a9307643fd53554053b38cda5a0663a13)、[`maxrd`](https://docs.zephyrproject.org/latest/doxygen/html/unioni3c__ccc__getmxds.html#a668e1ed30b96a40534d96e4b56ce7e98) 两个字节，原字段名称分别为 `maxWr` 与 `maxRd`，表示最大写入/读取速度字段；本页原文没有进一步列出其编码。

格式 2 另有 `maxrdturn[3]`，表示**最大读取周转时间（Maximum Read Turnaround Time）**，单位为微秒。该字段使用**小端字节序（Little-endian）**，第一个字节为最低有效字节（Least Significant Byte，LSB）。

## 427.3\_格式3

**定义字节（Defining Byte）**选择不同的返回数据。`WRRDTURN`、`CRHDLY` 为原文使用的格式名称：

| 字段 | 原声明 | 含义 |
| --- | --- | --- |
| `fmt3.wrrdturn` | `uint8_t wrrdturn[5]` | 定义字节 `0x00`：WRRDTURN；数据含义参见格式 2。 |
| `fmt3.crhdly1` | `uint8_t crhdly1` | 定义字节 `0x91`：CRHDLY；位含义见下表。 |

| CRHDLY位 | 含义 |
| --- | --- |
| 2 | 设置总线活动状态（Set Bus Activity State）。 |
| 1:0 | 控制权移交活动状态（Controller Handoff Activity State）。 |
