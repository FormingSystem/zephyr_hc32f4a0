# 第232章\_步进硬件驱动接口

原文：[group__stepper__hw__driver](https://docs.zephyrproject.org/latest/doxygen/html/group__stepper__hw__driver.html)。读取日期：2026-10-13，`latest`。

## 232.1\_范围与版本

本页定义 **步进硬件驱动器（Stepper Hardware Driver）**的 **应用程序编程接口（Application Programming Interface，API）**，自 Zephyr 4.0 提供，本页版本为 0.9.0，主头文件为 `zephyr/drivers/stepper/stepper.h`。

相关专题为[硬件驱动后端接口](P235_步进硬件驱动后端.md)；位置与运动命令见[步进运动控制接口](P230_步进运动控制接口.md)。

## 232.3\_分辨率辅助宏

宏 `MICRO_STEP_RES_INDEX(res)` 计算微步分辨率的索引，参数 `res` 是分辨率。原展开式使用以 2 为底的对数宏 [`LOG2`](../util_reference/P001_通用工具公共接口.md#ga40805b5dd56ee36df59a7bbe403ddf33)：

```c
LOG2(res)
```

宏 `VALID_MICRO_STEP_RES(res)` 检查分辨率是否有效；`res` 是待检查值。属于支持的分辨率时返回非零，否则返回零。完整展开式：

```c
((res) == STEPPER_MICRO_STEP_1 || (res) == STEPPER_MICRO_STEP_2 ||                 \
 (res) == STEPPER_MICRO_STEP_4 || (res) == STEPPER_MICRO_STEP_8 ||                 \
 (res) == STEPPER_MICRO_STEP_16 || (res) == STEPPER_MICRO_STEP_32 ||               \
 (res) == STEPPER_MICRO_STEP_64 || (res) == STEPPER_MICRO_STEP_128 ||              \
 (res) == STEPPER_MICRO_STEP_256)
```

> 译注：这个宏检查的是上述枚举值集合；某个具体驱动能否实现所选分辨率，仍由设置函数的返回结果判断。

## 232.4\_启用与禁用

以下所有 `dev` 参数均指向驱动实例的设备结构。

```c
int stepper_enable(const struct device *dev);
int stepper_disable(const struct device *dev);
```

函数 [`stepper_enable()`](https://docs.zephyrproject.org/latest/doxygen/html/group__stepper__hw__driver.html#ga3395b5f8b401d8175067edfb25c2e0e8) 启用硬件驱动器，应开启功率级（Power Stage）并给线圈励磁（Energize）。成功返回 0，启用出错返回 `-EIO`（输入输出错误，Input/Output Error）。

函数 [`stepper_disable()`](https://docs.zephyrproject.org/latest/doxygen/html/group__stepper__hw__driver.html#gab892a6b8d8fb34db0e682dd8f7de4218) 禁用硬件驱动器，应关闭功率级并使线圈去励磁（De-energize）。成功返回 0；`-ENOTSUP` 表示不支持禁用（Not Supported）；`-EIO` 表示禁用出错。

## 232.5\_设置与查询微步分辨率

```c
int stepper_set_micro_step_res(const struct device *dev,
                               enum stepper_micro_step_resolution res);
int stepper_get_micro_step_res(const struct device *dev,
                               enum stepper_micro_step_resolution *res);
```

函数 [`stepper_set_micro_step_res()`](https://docs.zephyrproject.org/latest/doxygen/html/group__stepper__hw__driver.html#ga609ddefa299ba40a997c626e4a36bdef) 将硬件驱动器设置为 `res` 指定的微步分辨率。成功返回 0；`-EIO` 表示一般输入输出错误；`-EINVAL` 表示请求值无效（Invalid Argument）；`-ENOTSUP` 表示不支持请求的分辨率。

函数 [`stepper_get_micro_step_res()`](https://docs.zephyrproject.org/latest/doxygen/html/group__stepper__hw__driver.html#gaa5e17e04a470832a305cef048694ec0a) 查询微步分辨率并写入 `res` 指向的变量。成功返回 0，`-EIO` 表示一般输入输出错误。

## 232.6\_驱动事件与回调

枚举 [`stepper_event`](https://docs.zephyrproject.org/latest/doxygen/html/group__stepper__hw__driver.html#gab1534238fbf8d2270ea4f69d3a558b5f) 定义两个事件：`STEPPER_EVENT_STALL_DETECTED = 0` 表示检测到步进驱动堵转（Stall）；`STEPPER_EVENT_FAULT_DETECTED = 1` 表示检测到步进驱动故障（Fault）。

类型 [`stepper_event_cb_t`](https://docs.zephyrproject.org/latest/doxygen/html/group__stepper__hw__driver.html#ga7df452f0e21c8db860616a9e8854b11a) 是硬件驱动事件的回调（Callback）函数指针：

```c
typedef void (*stepper_event_cb_t)(const struct device *dev,
    const enum stepper_event event, void *user_data);
```

函数 [`stepper_set_event_cb()`](https://docs.zephyrproject.org/latest/doxygen/html/group__stepper__hw__driver.html#gad9fff2d103daad42fe49c7bbd5233b1b) 设置事件回调：

```c
int stepper_set_event_cb(const struct device *dev,
                         stepper_event_cb_t callback, void *user_data);
```

`callback` 是事件发生时调用的函数，传空指针 `NULL` 可禁用回调；`user_data` 是传给回调的用户数据。成功返回 0，`-ENOSYS` 表示设备驱动未实现（Not Implemented）。
