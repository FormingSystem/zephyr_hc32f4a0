# 第108章\_电量计

原文：[Fuel Gauge](https://docs.zephyrproject.org/latest/hardware/peripherals/fuel_gauge.html)。读取日期：2026-10-13，`latest`。

## 108.1\_统一访问电池电量计

**电量计（Fuel Gauge）**子系统提供统一访问电池电量计设备的 **应用程序编程接口（Application Programming Interface，API）**。

## 108.2\_单个、批量与缓冲区属性

**属性（Property）**本质上是电量计能够测量的量。电量计通常支持多个属性，例如电池组温度、当前电流或电压。

客户端用函数 [`fuel_gauge_get_prop()`](https://docs.zephyrproject.org/latest/doxygen/html/group__fuel__gauge__interface.html#gab84999beab9a43241992945a3b2d37e1) 逐个读取属性，也可以用 [`fuel_gauge_get_props()`](https://docs.zephyrproject.org/latest/doxygen/html/group__fuel__gauge__interface.html#gaf8a1fed5f6af9c25a12130c481411603) 批量读取。设备名称等 **缓冲区属性（Buffer Property）**通过 [`fuel_gauge_get_buffer_prop()`](https://docs.zephyrproject.org/latest/doxygen/html/group__fuel__gauge__interface.html#ga7e6cb77d2d4dd7a0feb25c92d031614c) 获取。

写入属性时，客户端用 [`fuel_gauge_set_prop()`](https://docs.zephyrproject.org/latest/doxygen/html/group__fuel__gauge__interface.html#ga936be681a82f173b664ae2187bc5a73d) 逐个设置，或用 [`fuel_gauge_set_props()`](https://docs.zephyrproject.org/latest/doxygen/html/group__fuel__gauge__interface.html#gac8efb10ccb6f510dc92618e218c1df9b) 批量设置。电池配置镜像等缓冲区属性通过 [`fuel_gauge_set_buffer_prop()`](https://docs.zephyrproject.org/latest/doxygen/html/group__fuel__gauge__interface.html#gac63f43b6023b9f2183001d6876fe328a) 设置。

## 108.3\_电池切断与缓存

许多嵌入电池组的电量计提供一个寄存器地址；向该地址写入特定 **载荷（Payload）**会触发 **电池切断（Battery Cutoff）**。该功能常称为 **运输模式（Ship Mode）**、**储存模式（Shelf Mode）**或 **睡眠模式（Sleep Mode）**，用于降低设备存放或运输期间的电池消耗。

电量计API通过 [`fuel_gauge_battery_cutoff()`](https://docs.zephyrproject.org/latest/doxygen/html/group__fuel__gauge__interface.html#ga763a40688dc8fc6a0ba85fdc79178ebc) 提供电池切断操作。

电量计API明确**不为客户端提供缓存（Caching）**。

## 108.4\_接口、仿真后端与示例

完整声明见[电量计API](https://docs.zephyrproject.org/latest/doxygen/html/group__fuel__gauge__interface.html)，另有[电量计后端仿真接口（Fuel Gauge Backend Emulator APIs）](P492_电量计仿真后端接口.md)。
