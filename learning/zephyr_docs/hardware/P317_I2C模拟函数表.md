# 第317章\_I2C模拟函数表

原文：[structi2c__emul__api](https://docs.zephyrproject.org/latest/doxygen/html/structi2c__emul__api.html)。读取日期：2026-10-13，`latest`。

## 317.1\_传输操作

结构 [`i2c_emul_api`](https://docs.zephyrproject.org/latest/doxygen/html/structi2c__emul__api.html) 定义集成电路间总线（Inter-Integrated Circuit，I²C）模拟器（Emulator）的应用程序接口（Application Programming Interface，API），声明来自 `zephyr/drivers/i2c_emul.h`。

字段 [`transfer`](https://docs.zephyrproject.org/latest/doxygen/html/structi2c__emul__api.html#af155e9e2145597c9ca14473ddf01d48f) 的类型为 [`i2c_emul_transfer_t`](https://docs.zephyrproject.org/latest/doxygen/html/group__i2c__emul__interface.html#ga1b27ff11534eeac47cf50ffb2a1c7cca)，用于将I²C消息传给模拟器。完整回调签名、参数及返回值见[I2C模拟后端](P314_I2C模拟后端.md)。
