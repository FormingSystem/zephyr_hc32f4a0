# 第492章\_电量计仿真后端接口

原文：[group__fuel__gauge__emulator__backend](P492_电量计仿真后端接口.md)。读取日期：2026-10-13，`latest`。

**电量计（Fuel Gauge）**仿真器的后端接口用于设置关联电池的充放电状态，以及检查电池是否已被切断。接口位于 `zephyr/drivers/emul_fuel_gauge.h`。

## 492.1\_设置电池充放电状态

[`emul_fuel_gauge_set_battery_charging()`](P492_电量计仿真后端接口.md) 设置与电量计**集成电路（Integrated Circuit，IC）**关联的电池充放电情况。电压始终为正；正电流表示充电，负电流表示放电。

```c
int emul_fuel_gauge_set_battery_charging(const struct emul *target,
                                         uint32_t uV, int uA);
```

| 参数 | 含义 |
| --- | --- |
| `target` | 指向电量计仿真器实例结构的指针 |
| `uV` | 电池电压，单位微伏（Microvolt，µV） |
| `uA` | 电池电流，单位微安（Microampere，µA）；负值表示放电 |

成功返回 `0`；`uV` **或** `uA` 为 `0` 时返回无效参数错误 `-EINVAL`。

## 492.2\_检查电池是否切断

[`emul_fuel_gauge_is_battery_cutoff()`](P492_电量计仿真后端接口.md) 检查电池是否已经**切断（Cutoff）**。

```c
int emul_fuel_gauge_is_battery_cutoff(const struct emul *target, bool *cutoff);
```

`target` 指向电量计仿真器实例结构；`cutoff` 指向保存结果的布尔变量。成功返回 `0`；仿真器不支持此操作时返回“不支持”错误 `-ENOTSUP`。

> 译注：查询结果通过 `cutoff` 输出，函数的整数返回值报告操作是否成功；不要用返回值 `0` 判断电池未切断。
