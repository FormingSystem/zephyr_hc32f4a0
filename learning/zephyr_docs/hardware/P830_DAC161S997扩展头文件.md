# 第830章\_DAC161S997扩展头文件

原文：[dac161s997_8h](https://docs.zephyrproject.org/latest/doxygen/html/dac161s997_8h.html)。读取日期：2026-10-13，`latest`。

`zephyr/drivers/dac/dac161s997.h` 是DAC161S997数模转换器（Digital-to-Analog Converter，DAC）的扩展应用程序接口（Application Programming Interface，API）头文件。该文件的包含项为：

```c
#include <stdint.h>
#include <zephyr/device.h>
```

`stdint.h` 提供固定宽度整数类型（Fixed-Width Integer Types），`zephyr/device.h` 提供Zephyr设备接口。原始声明见[源码页](P831_DAC161S997扩展源码.md)。

## 830.1\_状态数据结构

`union dac161s997_status` 表示DAC161S997状态寄存器（Status Register）。完整字段含义见[状态联合体](P829_DAC161S997状态联合体.md)。

## 830.2\_回调类型与设置函数

```c
typedef void (*dac161s997_error_callback_t)(
    const struct device *dev, const union dac161s997_status *status);

int dac161s997_set_error_callback(const struct device *dev,
                                 dac161s997_error_callback_t cb);
```

[`dac161s997_error_callback_t`](https://docs.zephyrproject.org/latest/doxygen/html/group__dac161s997__interface.html#ga24c693e8a7c22c6340db7595a01ef09f) 为错误触发时调用的回调（Callback）类型；[`dac161s997_set_error_callback()`](https://docs.zephyrproject.org/latest/doxygen/html/group__dac161s997__interface.html#gab81de98755b9bffd8e4599fbe4ceb557) 设置该回调。参数、执行上下文和返回值参见[扩展接口](P828_DAC161S997扩展接口.md)。本文件参考页只列上述结构、类型和函数，详细条目由对应接口页提供。
