# 第144章\_蜂鸣器接口参考

原文：[group__buzzer__interface](https://docs.zephyrproject.org/latest/doxygen/html/group__buzzer__interface.html)。读取日期：2026-10-13，`latest`。

## 144.1\_版本、头文件与调用时序

**蜂鸣器（Buzzer）**的 **应用程序编程接口（Application Programming Interface，API）**为简单蜂鸣器及类似单音声源提供音频输出抽象。原页标注自Zephyr **4.5**引入，接口版本 **0.1.0**；主头文件为 `zephyr/drivers/buzzer.h`。

API调用**不等待所请求的音调持续时间**。持续时间表示硬件继续发声多久，不表示调用线程睡眠多久。概览见[蜂鸣器](P124_蜂鸣器.md)，实现接口见[驱动后端](P145_蜂鸣器驱动后端.md)。

## 144.2\_三个常量

下表为宏定义。[`UINT32_MAX`](https://docs.zephyrproject.org/latest/doxygen/html/stdint_8h.html#ab5eb23180f7cc12b7d6c04a8ec067fdd) 表示32位无符号整数最大值。

| 宏 | 定义值 | 含义 |
| --- | --- | --- |
| [`BUZZER_FREQ_REST`](https://docs.zephyrproject.org/latest/doxygen/html/group__buzzer__interface.html#ga8f59503d35269e3535cafeb5140f2ed9) | `0U` | 表示静音的特殊频率。 |
| [`BUZZER_VOLUME_MAX`](https://docs.zephyrproject.org/latest/doxygen/html/group__buzzer__interface.html#ga536d8f9b36f89636ab3e1ce090ce9de4) | `100U` | 最大音量；有效范围为0至该值。 |
| [`BUZZER_DURATION_FOREVER`](https://docs.zephyrproject.org/latest/doxygen/html/group__buzzer__interface.html#ga7a6fa0c0251b4b673cf89b019ddad9c2) | [`UINT32_MAX`](https://docs.zephyrproject.org/latest/doxygen/html/stdint_8h.html#ab5eb23180f7cc12b7d6c04a8ec067fdd) | 持续播放，直到显式停止。 |

将无限时长宏传给 [`buzzer_tone()`](https://docs.zephyrproject.org/latest/doxygen/html/group__buzzer__interface.html#ga11d8fa4f540452ee487164a4af200868) 或 [`buzzer_beep()`](https://docs.zephyrproject.org/latest/doxygen/html/group__buzzer__interface.html#gad22c8c78d97814b849d87e42b1363ea9) 的 `duration_ms` 参数时，驱动不会自动静音；调用者必须调用 [`buzzer_stop()`](https://docs.zephyrproject.org/latest/doxygen/html/group__buzzer__interface.html#ga8990f4ef56d763b59a59e9fc69782106) 或启动另一个音调来结束当前音调。

## 144.3\_指定频率和时长

音调函数 [`buzzer_tone()`](https://docs.zephyrproject.org/latest/doxygen/html/group__buzzer__interface.html#ga11d8fa4f540452ee487164a4af200868) 的声明为：

```c
static inline int buzzer_tone(const struct device *dev,
                             uint32_t freq_hz, uint32_t duration_ms);
```

参数 `dev` 为蜂鸣器设备；`freq_hz` 为频率，单位Hz（赫兹）；`duration_ms` 为持续发声的毫秒数，可用无限时长常量。

调用在硬件配置完成后返回，不等待播放时长结束。硬件继续发声，到时由驱动自动静音。前一个音调仍在播放时再次调用，会**抢占（Preempt）**前一个音调。传入 [`BUZZER_FREQ_REST`](https://docs.zephyrproject.org/latest/doxygen/html/group__buzzer__interface.html#ga8f59503d35269e3535cafeb5140f2ed9) 立即静音。

无法准确实现请求频率的后端，会播放最接近的受支持音调；如果请求静音，则停止。成功安排音调返回0，失败返回负的 `errno` 错误码。

## 144.4\_播放默认音调

蜂鸣函数 [`buzzer_beep()`](https://docs.zephyrproject.org/latest/doxygen/html/group__buzzer__interface.html#gad22c8c78d97814b849d87e42b1363ea9) 的声明为：

```c
static inline int buzzer_beep(const struct device *dev, uint32_t duration_ms);
```

`dev` 为设备，`duration_ms` 为持续时间，可用 [`BUZZER_DURATION_FOREVER`](https://docs.zephyrproject.org/latest/doxygen/html/group__buzzer__interface.html#ga7a6fa0c0251b4b673cf89b019ddad9c2)，直到显式停止或另一项发声调用替换它。函数在硬件配置完成后返回，不等待持续时间结束。

对于 **脉宽调制（Pulse Width Modulation，PWM）**驱动的无源压电蜂鸣器，默认音调来自设备树 `pwms` 属性的周期单元。对于 **通用输入输出（General-Purpose Input/Output，GPIO）**驱动的有源蜂鸣器，实际音高由硬件振荡器决定。

成功安排默认音调返回0；失败返回负错误码。

## 144.5\_设置音量

音量函数 [`buzzer_set_volume()`](https://docs.zephyrproject.org/latest/doxygen/html/group__buzzer__interface.html#ga6ad479424be12d83cab59656cf94cde0) 的声明为：

```c
static inline int buzzer_set_volume(const struct device *dev, uint8_t percent);
```

`dev` 为设备，`percent` 为目标音量百分比，有效范围包含0和 [`BUZZER_VOLUME_MAX`](https://docs.zephyrproject.org/latest/doxygen/html/group__buzzer__interface.html#ga536d8f9b36f89636ab3e1ce090ce9de4) 两个端点。0表示静音，最大值表示硬件能够产生的最响级别。

设置影响后续音调，直到再次修改；**设为0还会立即静音**。没有可编程音量控制的后端把任意非零值映射为唯一可听级别，把0映射为静音。

成功更新返回0；`percent` 越界返回参数无效错误 `-EINVAL`；其他失败返回相应负错误码。

## 144.6\_停止音调

停止函数 [`buzzer_stop()`](https://docs.zephyrproject.org/latest/doxygen/html/group__buzzer__interface.html#ga8990f4ef56d763b59a59e9fc69782106) 的声明为：

```c
static inline int buzzer_stop(const struct device *dev);
```

`dev` 为蜂鸣器设备。停止操作是 **幂等（Idempotent）**的：对已经静音的设备再次调用不执行额外操作。成功停止返回0，失败返回负错误码。
