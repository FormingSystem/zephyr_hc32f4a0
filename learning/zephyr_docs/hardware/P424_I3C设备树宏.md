# 第424章\_I3C设备树宏

原文：[group__i3c__devicetree](https://docs.zephyrproject.org/latest/doxygen/html/group__i3c__devicetree.html)。读取日期：2026-10-13，`latest`。

## 424.1\_设备树初始化辅助接口

本页的宏从**设备树（Devicetree）**生成**改进的集成电路间总线（Improved Inter-Integrated Circuit，I3C）**及其总线上**集成电路间总线（Inter-Integrated Circuit，I2C）**设备的配置和初始化器（Initializer）。头文件为 `zephyr/drivers/i3c/devicetree.h`。

`node_id` 表示设备树节点标识符；`inst` 表示设备树实例编号（Instance Number）。各节说明它对应控制器还是目标设备。`DT_DRV_INST(inst)` 将实例编号转换为当前驱动兼容项（Compatible）下的节点标识符；`DT_DRV_COMPAT` 表示该驱动使用的兼容项。

## 424.2\_控制器配置标志

宏 `I3C_CONTROLLER_CONFIG_FLAGS_DT_INST(inst)` 从 I3C 控制器实例 `inst` 获取驱动配置标志。原展开如下：

```c
(FIELD_PREP(I3C_CONTROLLER_FLAG_DISABLE_BUS_INIT,                               \
            DT_INST_PROP(inst, disable_bus_init)) |                             \
 FIELD_PREP(I3C_CONTROLLER_FLAG_DISABLE_HJ_AT_INIT,                             \
            DT_INST_PROP(inst, disable_hj_at_init)))
```

[`FIELD_PREP`](https://docs.zephyrproject.org/latest/doxygen/html/silabs-pinctrl-siwx91x_8h.html#aa03c8b31bf67a097dd9f8153a04ef86b) 是把字段值放入相应位掩码位置的辅助宏，[`DT_INST_PROP`](../dt_instance_reference/P001_设备树驱动实例宏.md#ga9dce2e631b2a94804e8f2bcc76c6eff8) 读取实例属性。上面的两个属性是 `disable_bus_init` 与 `disable_hj_at_init`。

| 宏 | 值 | 含义 |
| --- | --- | --- |
| [`I3C_CONTROLLER_FLAG_DISABLE_BUS_INIT`](https://docs.zephyrproject.org/latest/doxygen/html/group__i3c__devicetree.html#gad2ae95d27ea32b70e3d36a7b6d74e468) | `BIT(0)` | 在驱动初始化期间禁用 `i3c_bus_init()` 总线初始化。 |
| [`I3C_CONTROLLER_FLAG_DISABLE_HJ_AT_INIT`](https://docs.zephyrproject.org/latest/doxygen/html/group__i3c__devicetree.html#ga7f9635ee0f0b43869478477668259432) | `BIT(1)` | 在驱动初始化期间禁用热加入（Hot Join）确认应答（Acknowledgement，ACK）。 |

## 424.3\_I3C设备数组

宏 `I3C_DEVICE_ARRAY_DT(node_id)` 从设备树生成一组 `struct i3c_device_desc` 的数组初始化器。`node_id` 是 I3C 控制器节点。它遍历状态为可用的子节点（`DT_FOREACH_CHILD_STATUS_OKAY`），调用过滤初始化宏：

```c
{                                                               \
        DT_FOREACH_CHILD_STATUS_OKAY(                           \
                node_id,                                        \
                I3C_DEVICE_DESC_DT_FILTERED)                    \
}
```

实例版本 `I3C_DEVICE_ARRAY_DT_INST(inst)` 的 `inst` 是 I3C 控制器实例编号，原展开为：

```c
I3C_DEVICE_ARRAY_DT(DT_DRV_INST(inst))
```

原文另列出的等价调用为：

```c
I3C_DEVICE_ARRAY_DT(DT_DRV_INST(inst))
```

## 424.4\_I3C设备描述符

宏 `I3C_DEVICE_DESC_DT(node_id)` 读取相关总线和设备数据，展开为 `struct i3c_device_desc` 的静态初始化器。`node_id` 是要创建描述符初始化器的 I3C 设备节点标识符。

```c
{                                                                                          \
        .bus = DEVICE_DT_GET(DT_BUS(node_id)),                                             \
        .dev = DEVICE_DT_GET(node_id),                                                     \
        .static_addr = DT_PROP_BY_IDX(node_id, reg, 0),                                    \
        .pid = ((uint64_t)DT_PROP_BY_IDX(node_id, reg, 1) << 32) |                         \
               DT_PROP_BY_IDX(node_id, reg, 2),                                            \
        .init_dynamic_addr = DT_PROP_OR(node_id, assigned_address, 0),                     \
        .flags = FIELD_PREP(I3C_SUPPORTS_SETAASA, DT_PROP(node_id, supports_setaasa)) |    \
                 FIELD_PREP(I3C_V1P0_SUPPORT, DT_PROP(node_id, v1p0_support)),             \
},
```

其中 `reg` 的索引 0 提供静态地址；索引 1 和 2 组成**预置标识（Provisioned ID，PID）**。`assigned_address` 提供期望动态地址，缺省为 0。设备能力标志从 `supports_setaasa` 和 `v1p0_support` 属性生成。

[`DEVICE_DT_GET`](../device_reference/P001_设备模型公共接口.md#ga9a65996ce21f43acb7db061e23b48ec7) 获取设备对象指针，[`DT_BUS`](../dt_node_reference/P001_设备树总线查询宏.md#ga1082d31ac2dafdf9e085d4c23f2169dc) 取得总线节点；[`DT_PROP_BY_IDX`](../dt_property_reference/P001_设备树属性读取宏.md#ga52ad691ea4cae633ca702020e939d461)、[`DT_PROP`](../dt_property_reference/P001_设备树属性读取宏.md#ga8e1fd9ebacd85d2013df027d041d506b)、[`DT_PROP_OR`](../dt_property_reference/P001_设备树属性读取宏.md#ga5e5bfc9b1a6627b3f73014329e96340f) 分别读取指定索引属性、普通属性及带默认值的属性。

## 424.5\_过滤I3C设备与实例版本

宏 `I3C_DEVICE_DESC_DT_FILTERED(node_id)` 主要由 [`I3C_DEVICE_ARRAY_DT()`](https://docs.zephyrproject.org/latest/doxygen/html/group__i3c__devicetree.html#ga88aac6c42bbcd2f3276b6686c6786363) 使用，当且仅当节点表示 I3C 设备时才创建结构初始化器。原展开通过 [`COND_CODE_0`](../util_reference/P001_通用工具公共接口.md#ga5483ea38af79bc6c4509936288705377) 对 `reg` 索引 1 进行条件选择：

```c
COND_CODE_0(DT_PROP_BY_IDX(node_id, reg, 1),                    \
            (), (I3C_DEVICE_DESC_DT(node_id)))
```

宏 `I3C_DEVICE_DESC_DT_INST(inst)` 从设备树实例生成描述符初始化器，`inst` 为设备实例编号：

```c
I3C_DEVICE_DESC_DT(DT_DRV_INST(inst))
```

原文列出的等价调用为：

```c
I3C_DEVICE_DESC_DT(DT_DRV_INST(inst))
```

## 424.6\_定义I3C目标设备

宏签名为：

```c
I3C_DEVICE_DT_DEFINE(node_id, init_fn, pm, data, config,
                     level, prio, api, ...)
```

它类似 [`DEVICE_DT_DEFINE()`](../device_reference/P001_设备模型公共接口.md#gac49e26fbe91a14307d5ea08d41561dd1)，用于定义实现 I3C 目标设备应用程序编程接口（Application Programming Interface，API）的设备。原宏展开如下：

```c
DEVICE_DT_DEFINE(node_id, init_fn, pm, data, config, level,     \
                 prio, api, __VA_ARGS__)
```

| 参数 | 含义 |
| --- | --- |
| `node_id` | 设备树节点标识符。 |
| `init_fn` | 驱动初始化函数名。 |
| `pm` | 电源管理（Power Management，PM）设备资源引用；不使用 PM 时为 `NULL`。 |
| `data` | 设备私有数据指针。 |
| `config` | 指向本驱动实例配置结构的地址。 |
| `level` | 初始化级别，参见 [`SYS_INIT()`](../device_reference/P005_系统初始化接口.md#gaf507cc0613add8113c41896bd631254f)。 |
| `prio` | 所选初始化级别内的优先级，参见 [`SYS_INIT()`](../device_reference/P005_系统初始化接口.md#gaf507cc0613add8113c41896bd631254f)。 |
| `api` | 驱动 API 函数结构的初始指针，可以为 `NULL`。 |
| `...` | 原展开继续传递的其他参数。 |

## 424.7\_按实例定义目标设备

宏 `I3C_DEVICE_DT_INST_DEFINE(inst, ...)` 以 `DT_DRV_COMPAT` 兼容项的实例定义设备。`inst` 是实例编号，其余参数转交设备定义宏。原展开为：

```c
I3C_DEVICE_DT_DEFINE(DT_DRV_INST(inst), __VA_ARGS__)
```

> 译注：原说明与参数表写的是 `I3C_TARGET_DT_DEFINE()`，但同页展开实际调用 [`I3C_DEVICE_DT_DEFINE()`](https://docs.zephyrproject.org/latest/doxygen/html/group__i3c__devicetree.html#gaab3219d45b125dd12d583bfd1823a61c)。`inst` 被 `DT_DRV_INST(inst)` 替换，其他参数按实际展开转交后者；本页保留并指出原命名差异。

## 424.8\_设备匹配标识初始化器

宏 `I3C_DEVICE_ID_DT(node_id)` 读取设备树中的设备数据，生成 `struct i3c_device_id` 的静态初始化器。`node_id` 是对应 I3C 设备的节点标识符。

```c
{                                                               \
        .pid = ((uint64_t)DT_PROP_BY_IDX(node_id, reg, 1) << 32)\
               | DT_PROP_BY_IDX(node_id, reg, 2),               \
}
```

宏 `I3C_DEVICE_ID_DT_INST(inst)` 从设备实例 `inst` 生成同类初始化器：

```c
I3C_DEVICE_ID_DT(DT_DRV_INST(inst))
```

原文列出的等价调用为：

```c
I3C_DEVICE_ID_DT(DT_DRV_INST(inst))
```

## 424.9\_I2C设备数组

宏 `I3C_I2C_DEVICE_ARRAY_DT(node_id)` 从设备树生成一组 `struct i3c_i2c_device_desc` 的数组初始化器，`node_id` 是 I3C 控制器节点标识符。


实例版本 `I3C_I2C_DEVICE_ARRAY_DT_INST(inst)` 的 `inst` 是 I3C 控制器实例编号：

```c
I3C_I2C_DEVICE_ARRAY_DT(DT_DRV_INST(inst))
```

原文列出的等价调用为：

```c
I3C_I2C_DEVICE_ARRAY_DT(DT_DRV_INST(inst))
```

## 424.10\_I2C设备描述符

宏 `I3C_I2C_DEVICE_DESC_DT(node_id)` 读取设备树中的总线与设备数据，生成 `struct i3c_i2c_device_desc` 的静态初始化器。`node_id` 为要创建初始化器的设备节点标识符。

```c
{                                                               \
        .bus = DEVICE_DT_GET(DT_BUS(node_id)),                  \
        .addr = DT_PROP_BY_IDX(node_id, reg, 0),                \
        .lvr = DT_PROP_BY_IDX(node_id, reg, 2),                 \
},
```

这里 `reg` 索引 0 提供地址，索引 2 提供**传统虚拟寄存器（Legacy Virtual Register，LVR）**值。

> 译注：原参数表将此处设备写为 I3C 设备；本宏的生成类型、名称及字段说明均针对挂在 I3C 总线上的 I2C 设备。

## 424.11\_过滤I2C设备与实例版本

宏 `I3C_I2C_DEVICE_DESC_DT_FILTERED(node_id)` 主要由 [`I3C_I2C_DEVICE_ARRAY_DT()`](https://docs.zephyrproject.org/latest/doxygen/html/group__i3c__devicetree.html#ga78f4d3fa3977989a731e33089d535701) 使用，当且仅当节点表示 I2C 设备时创建结构初始化器：

```c
COND_CODE_0(DT_PROP_BY_IDX(node_id, reg, 1),                    \
            (I3C_I2C_DEVICE_DESC_DT(node_id)), ())
```

宏 `I3C_I2C_DEVICE_DESC_DT_INST(inst)` 从设备实例编号 `inst` 生成同类初始化器：

```c
I3C_I2C_DEVICE_DESC_DT(DT_DRV_INST(inst))
```

原文列出的等价调用为：

```c
I3C_I2C_DEVICE_DESC_DT(DT_DRV_INST(inst))
```

## 424.12\_设备能力标志

**通用命令码（Common Command Code，CCC）** `SETAASA` 用于把所有地址设为静态地址（Set All Addresses to Static Addresses）。设备标志宏如下：

| 宏 | 值 | 含义 |
| --- | --- | --- |
| [`I3C_SUPPORTS_SETAASA`](https://docs.zephyrproject.org/latest/doxygen/html/group__i3c__devicetree.html#ga24fbe85a8cb5ffc049288b1b82e1c15b) | `BIT(0)` | 设备支持 SETAASA CCC。 |
| [`I3C_V1P0_SUPPORT`](https://docs.zephyrproject.org/latest/doxygen/html/group__i3c__devicetree.html#ga91bb0d3b4b86524d5f7a6a0429a123da) | `BIT(1)` | 设备支持 I3C 1.0。 |
