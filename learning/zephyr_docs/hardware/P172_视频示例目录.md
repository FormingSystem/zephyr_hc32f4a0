## 172.1\_示例范围

这些示例展示[视频设备](P141_视频设备.md)的 **应用程序编程接口（Application Programming Interface，API）**用法。

| 示例 | 演示内容 |
| --- | --- |
| [视频采集（Video Capture）](P173_视频采集示例.md) | 使用视频 API 从采集设备获取视频帧（Video Frame）。 |
| [视频采集到LVGL（Video Capture to LVGL）](P174_视频采集到LVGL示例.md) | 采集视频帧，并通过图形库 LVGL 在 **液晶显示屏（Liquid Crystal Display，LCD）**上显示。 |
| [视频TCP服务器输出端（Video TCP Server Sink）](P175_视频TCP服务器示例.md) | 采集视频帧，通过网络发送给 **传输控制协议（Transmission Control Protocol，TCP）**客户端。 |
