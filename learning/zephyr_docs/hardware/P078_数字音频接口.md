# 第78章\_数字音频接口

原文：[Digital Audio Interface (DAI)](https://docs.zephyrproject.org/latest/hardware/peripherals/audio/dai.html)。读取日期：2026-10-13，`latest`。

## 78.1\_通用的高层音频接口

**数字音频接口（Digital Audio Interface，DAI）**是面向音频驱动的通用高层 **应用程序编程接口（Application Programming Interface，API）**。它可以接收专用配置数据，以完成特定厂商所需的配置。

通用接口与厂商专用数据因此可以同时存在；原页并未规定所有设备使用相同的厂商配置字段。

## 78.2\_配置与接口参考

相关Kconfig配置项为 [`CONFIG_DAI`](https://docs.zephyrproject.org/latest/kconfig.html#CONFIG_DAI)，用于DAI支持；Kconfig是Zephyr的配置系统。完整声明见[DAI接口参考](https://docs.zephyrproject.org/latest/doxygen/html/group__dai__interface.html)。原页没有额外代码或媒体。
