# 第35章\_EEPROM入口

原文：[Electrically Erasable Programmable Read-Only Memory (EEPROM)](https://docs.zephyrproject.org/latest/hardware/peripherals/eeprom/index.html)。读取日期：2026-10-13，`latest`。

## 35.1\_按字节访问的非易失性存储

**电可擦可编程只读存储器（Electrically Erasable Programmable Read-Only Memory，EEPROM）**的擦除块大小为1字节，具有较长的寿命，并允许按字节访问和覆盖数据。

> 译注：“较长寿命”是原文的概括，不等于无限擦写；具体耐久性与实际器件规格有关。
