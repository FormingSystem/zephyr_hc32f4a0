# 第418章\_I3C通用命令目标载荷

原文：[structi3c__ccc__target__payload](https://docs.zephyrproject.org/latest/doxygen/html/structi3c__ccc__target__payload.html)。读取日期：2026-10-13，`latest`。

## 418.1\_单个定向命令目标

`struct i3c_ccc_target_payload` 描述面向一个目标的**改进的集成电路间总线（Improved Inter-Integrated Circuit，I3C）定向通用命令（Direct Common Command Code，Direct CCC）**载荷（Payload）。头文件为 `zephyr/drivers/i3c/ccc.h`。

## 418.2\_地址、方向与缓冲区

| 字段 | 类型 | 含义 |
| --- | --- | --- |
| [`addr`](https://docs.zephyrproject.org/latest/doxygen/html/structi3c__ccc__target__payload.html#a2669978506b20ef01569357fbd3a9eef) | [`uint8_t`](https://docs.zephyrproject.org/latest/doxygen/html/stdint_8h.html#a3cb4a16b0e8d6af0af86d4fd6ba5fd9d) | 目标地址。 |
| [`rnw`](https://docs.zephyrproject.org/latest/doxygen/html/structi3c__ccc__target__payload.html#aa09ebbfdff5d9d97be1558a63bb3535e) | `uint8_t : 1` | 1 位读写方向字段，0 表示写（Write），1 表示读（Read）。 |
| [`data`](https://docs.zephyrproject.org/latest/doxygen/html/structi3c__ccc__target__payload.html#abc655b08df77701275038e80bfb5ba85) | `uint8_t *` | 传输数据缓冲区指针。 |
| [`data_len`](https://docs.zephyrproject.org/latest/doxygen/html/structi3c__ccc__target__payload.html#a5ddda39b2aeb2818b389d4df1e25ba0a) | `size_t` | 数据长度，单位为字节。 |

对于写 CCC，`data` 指向待发送字节数组，该数组可以包含**子命令字节（Sub-Command Byte）**及附加数据。对于读 CCC，`data` 指向用于接收数据的字节缓冲区。

## 418.3\_传输结果

| 字段 | 类型 | 含义 |
| --- | --- | --- |
| [`num_xfer`](https://docs.zephyrproject.org/latest/doxygen/html/structi3c__ccc__target__payload.html#ae6091f0b1cc804f9658d941f6ab493ef) | `size_t` | 已传输的总字节数。 |
| [`err`](https://docs.zephyrproject.org/latest/doxygen/html/structi3c__ccc__target__payload.html#af061d387258ee3e2454ceae0b7c0dcf7) | `enum i3c_sdr_controller_error_types` | 单数据速率（Single Data Rate，SDR）错误类型。 |

目标设备可能发出**数据结束（End of Data，EoD）**，控制器也可能在达到缓冲区长度之前中止传输。驱动应在传输完成后写入 `num_xfer`。

`err` 对应 I3C 规范 1.1.1 第 5.1.10.2 节规定的错误，预期由驱动写入。
