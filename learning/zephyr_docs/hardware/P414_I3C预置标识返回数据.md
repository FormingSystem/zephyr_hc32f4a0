# 第414章\_I3C预置标识返回数据

原文：[structi3c__ccc__getpid](https://docs.zephyrproject.org/latest/doxygen/html/structi3c__ccc__getpid.html)。读取日期：2026-10-13，`latest`。

## 414.1\_GETPID载荷

`struct i3c_ccc_getpid` 是**改进的集成电路间总线（Improved Inter-Integrated Circuit，I3C）通用命令码（Common Command Code，CCC）** `GETPID` 的载荷（Payload）。命令含义是**获取预置标识（Get Provisioned ID）**。头文件为 `zephyr/drivers/i3c/ccc.h`。

## 414.2\_字段与字节序

```c
uint8_t pid[6];
```

字段 [`pid`](https://docs.zephyrproject.org/latest/doxygen/html/structi3c__ccc__getpid.html#a060023fcb180e44b39a73c0f955f02c7) 保存 48 位**预置标识（Provisioned ID，PID）**，长度为 6 个字节。数据采用**大端字节序（Big-endian）**，第一个字节为最高有效字节（Most Significant Byte，MSB）。
