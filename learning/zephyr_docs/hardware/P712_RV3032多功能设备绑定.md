# 第712章\_RV3032多功能设备绑定

<a id="dtbinding-microcrystal-rv3032-mfd"></a>

原文：[microcrystal,rv3032-mfd (on i2c bus)](https://docs.zephyrproject.org/latest/build/dts/api/bindings/mfd/microcrystal,rv3032-mfd.html)。读取日期：2026-10-13，`latest`。

`microcrystal,rv3032-mfd` 是设备树绑定（Devicetree Binding），属于多功能设备（Multi-Function Device，MFD）目录，描述Micro Crystal AG的RV-3032-C7，挂接在集成电路间总线（Inter-Integrated Circuit，I²C）上；下方示例展示包含全部可用分功能驱动（Partial Driver）的节点布局。

驱动为 [`drivers/mfd/mfd_rv3032.c`](https://github.com/zephyrproject-rtos/zephyr/blob/main/drivers/mfd/mfd_rv3032.c)。

使用此兼容字符串的开发板见[官方筛选目录](https://docs.zephyrproject.org/latest/boards/index.html#compatibles=microcrystal,rv3032-mfd)。

## 712.1\_原始设备树示例

以下保留官方设备树源码（Devicetree Source，DTS）示例。

示例中的RTC为实时时钟（Real-Time Clock），GPIO为通用输入输出（General-Purpose Input/Output）；配置宏 `GPIO_PULL_UP` 表示上拉（Pull-Up），`GPIO_ACTIVE_LOW` 表示低电平有效（Active Low）。

```dts
rv3032: rv3032c7@51 {
  compatible = "microcrystal,rv3032-mfd";
  reg = <0x51>;
  int-gpios = <&porta 11 (GPIO_PULL_UP | GPIO_ACTIVE_LOW)>;
  evi-gpios = <&porta 10 (GPIO_PULL_UP | GPIO_ACTIVE_LOW)>;
  backup-switch-mode = "disabled";
  always-on;
  status = "okay";

  rtc0: rv3032_rtc {
    compatible = "microcrystal,rv3032";
    status = "okay";
  };

  counter0: rv3032_counter {
    compatible = "microcrystal,rv3032-counter";
    status = "okay";
  };

  temp0: rv3032_temp {
    compatible = "microcrystal,rv3032-temp";
    low-temp = <40>;
    high-temp = <105>;
    status = "okay";
  };
};
```

## 712.2\_节点专用属性

本节TCM表示涓流充电模式（Trickle Charger Mode），TCR表示涓流充电器串联电阻（Trickle Charger Series Resistance）。

本页 `int` 为整数，`string` 为字符串，`boolean` 为布尔属性，`array` 为数值数组，`phandle` 为节点引用（Phandle），`phandles` 为节点引用列表，`phandle-array` 为节点引用与说明单元数组，`string-array` 为字符串数组。电压的 `microvolt` 单位为微伏（Microvolt，µV），电流的 `microamp` 单位为微安（Microampere，µA），时间的 `us` 单位为微秒（Microsecond，µs），温度的 `kelvin` 单位为开尔文（Kelvin，K）。

| 属性 | 类型 | 中文说明与约束 |
| --- | --- | --- |
| `int-gpios` | `phandle-array` | 连接到INT中断输出的GPIO，信号为开漏（Open Drain）、低电平有效（Active Low）；原页在本属性说明中将器件写为RV3028，型号差异见译注 |
| `evi-gpios` | `phandle-array` | 连接到EVI事件／中断输入（Event/Interrupt Input）的GPIO，信号为开漏、低电平有效；原页在本属性说明中将器件写为RV3028，型号差异见译注 |
| `always-on` | `boolean` | 始终开启（Always On，AON）是主电源持续供电、不按预期使用高级备用电源切换的应用场景，并非RV-3032-C7芯片自身的一项功能。设为真时，下次初始化驱动按电源未中断处理；设为假时，每次启动和驱动初始化都如同全新启动，清除闹钟并将器件状态清理为初始状态 |
| `backup-switch-mode` | `string` | **必需**。自动备用电源切换（Automatic Backup Switchover）功能选择，三种模式及电压条件见下表；VDD与VBACKUP分别为原页主电源、备用电源标识；合法值：`disabled, direct, level` |
| `trickle-resistor-ohms` | `int` | 涓流充电器串联电阻（Trickle Charger Series Resistance，TCR），单位为欧姆（Ohm，Ω）。没有 `trickle-charger-mode` 时忽略本属性，即TCM=00；600 Ω对应RV3032的TCR=00（0.6 kΩ）；合法值：`600, 2000, 7000, 12000` |
| `trickle-charger-mode` | `int` | 涓流充电模式（Trickle Charger Mode，TCM）；省略时禁用充电器，即TCM=00。各取值、来源及适用模式见下表；合法值：`1750, 3000, 4500` |
| `supply-gpios` | `phandle-array` | 控制设备供电的通用输入输出（General-Purpose Input/Output，GPIO）说明符。设备有独立供电开关时应提供此属性；供电状态完全由设备驱动负责。与共享稳压器引用 `vin-supply` 相对 |
| `vin-supply` | `phandle` | 控制设备供电的稳压器节点引用；被引用节点必须具有稳压器兼容字符串。由共享稳压器供电时应提供此属性，供电状态取决于所有用电设备的请求状态。与独立开关 `supply-gpios` 相对。两者同时存在时，必须先请求稳压器，再将供电GPIO置为有效；释放稳压器前，必须先将供电GPIO置为无效 |

## 712.3\_备用电源切换模式

| `backup-switch-mode` | 模式与切换条件 |
| --- | --- |
| `disabled` | 禁用切换，仅使用VDD一路电源 |
| `direct` | 直接切换模式（Direct Switching Mode，DSM）：当 `VDD < VBACKUP` 时从VDD切换到VBACKUP，不要求VDD先降到 `VTH:LSM`（2.0 V）以下 |
| `level` | 电平切换模式（Level Switching Mode，LSM）：同时满足 `VDD < VTH:LSM`（2.0 V）**且** `VBACKUP > VTH:LSM` 时，从VDD切换到VBACKUP |

## 712.4\_涓流充电模式

| `trickle-charger-mode` | TCM编码 | 来源与适用模式 |
| --- | --- | --- |
| 省略 | `00` | 禁用涓流充电 |
| `1750` | `01` | DSM（`direct`）使用VDD为源；LSM（`level`）使用内部约1.75 V电源 |
| `3000` | `10` | 内部电荷泵（Charge Pump）约3.0 V，仅在LSM下有效 |
| `4500` | `11` | 内部电荷泵约4.5 V，仅在LSM下有效 |

在LSM下，仅当 `VDD > VTH:LSM` 时才会产生1.75／3.0／4.5 V电平；该阈值典型值2.0 V、最大值2.2 V。

译注：本页绑定及示例对应RV3032／RV-3032-C7，但 `int-gpios`、`evi-gpios` 的原文说明写成RV3028。表中保留了原文的信号方向、开漏和有效电平说明，并标明型号混用。

## 712.5\_总线地址

| 属性 | 类型 | 中文说明与约束 |
| --- | --- | --- |
| `reg` | `array` | **必需**。器件在I²C总线上的地址 |

没有已弃用的节点专用属性。以下完整保留继承的基础属性，不保证全部适用于本绑定；`compatible` 为必需属性。

## 712.6\_状态、兼容字符串与寄存器

本页 `int` 为整数，`string` 为字符串，`string-array` 为字符串数组，`array` 为数值数组，`boolean` 为布尔属性，`compound` 为复合类型。**节点引用（Phandle）**用来指向其他节点；`phandle-array` 表示节点引用及其说明单元，`phandles` 表示节点引用列表。

`status` 的类型为 `string`，描述节点所代表硬件或其他资源的运行状态。`okay` 表示资源可运行，例如可供驱动使用；`disabled` 表示资源不可运行，系统应将它视为不存在。合法值为 `okay`、`disabled`、`reserved`、`fail`、`fail-sss`。详见《设备树规范》（Devicetree Specification）v0.4 第 2.3.4 节。

`compatible` 的类型为 `string-array`，是**必需属性**。它用字符串列表定义节点代表的硬件或其他资源类型；设备驱动检查特定兼容字符串，以寻找应由自己管理的节点。推荐格式为 `vendor,device`，其中 `vendor` 是厂商简称，`device` 通常取自数据手册。多个值应按从最具体到最通用排列，使某一通用家族的具体设备能匹配当前可用的最具体驱动。详见规范 v0.4 第 2.3.1 节。


`reg-names` 的类型为 `string-array`，为 `reg` 中各寄存器块提供可选名称。以下保留官方示例；`#address-cells` 和 `#size-cells` 分别声明地址与长度使用的 32 位单元数。

```dts
  / {
       soc {
           #address-cells = <1>;
           #size-cells = <1>;

           uart@1000 {
               reg = <0x1000 0x2000>, <0x3000 0x4000>;
               reg-names = "foo", "bar";
           };
       };
  };
```

`uart@1000` 节点有两个寄存器块：名称 `foo` 对应基址 `0x1000`、大小 `0x2000`；名称 `bar` 对应基址 `0x3000`、大小 `0x4000`。这里 uart 是**通用异步收发器（Universal Asynchronous Receiver/Transmitter，UART）**节点名称，示例只是演示寄存器块命名。

## 712.7\_地址映射与中断

`ranges` 的类型为 `compound`，定义总线子地址空间与总线节点父地址空间之间的映射或转换。它通常为空，或由“子总线地址、父总线地址、长度”三元组构成。**空属性表示两侧地址空间相同，不需要转换；总线节点没有此属性时，则认为子节点与父地址空间之间不存在映射。**详见规范 v0.4 第 2.3.8 节。

下列属性描述**中断（Interrupt）**，参见规范 v0.4 第 2.4 节“中断与中断映射”。

| 属性 | 类型 | 中文说明 |
| --- | --- | --- |
| `interrupts` | `array` | 设备产生的中断，编码为一个或多个中断说明符；格式由设备在中断树中的位置决定，具有相同 `interrupt-parent` 的设备使用相同格式 |
| `interrupts-extended` | `compound` | 扩展中断说明符，可替代 `interrupts` |
| `interrupt-names` | `string-array` | 设备各中断的可选名称；中断本身在 `interrupts` 或 `interrupts-extended` 中定义 |
| `interrupt-parent` | `phandle` | 若存在，引用负责处理此设备所产生中断的节点 |

## 712.8\_标签、时钟与地址单元

**时钟提供者（Clock Provider）**提供设备使用的时钟。下表同时保留标签和子节点地址编码相关属性。

| 属性 | 类型 | 中文说明 |
| --- | --- | --- |
| `label` | `string` | 描述设备的可读字符串；除逐案确有需要外，已不推荐使用此属性。参见规范 v0.4 第 4.1.2 节“其他属性” |
| `clocks` | `phandle-array` | 设备的时钟提供者信息，通常应遵守下述 dt-schema 时钟绑定约定 |
| `clock-names` | `string-array` | `clocks` 中各时钟提供者的可选名称 |
| `#address-cells` | `int` | 子节点 `reg` 地址字段所用的 `<u32>` 单元数量 |
| `#size-cells` | `int` | 子节点 `reg` 大小字段所用的 `<u32>` 单元数量 |

`<u32>` 是 32 位无符号单元，两个 cells 属性见规范 v0.4 第 2.3.5 节。时钟约定见 [dt-schema 的 clock.yaml](https://github.com/devicetree-org/dt-schema/blob/main/dtschema/schemas/clock/clock.yaml)。`status`、`compatible`、`reg`、`interrupts` 和 `label` 另见官方[重要属性（Important Properties）](https://docs.zephyrproject.org/latest/build/dts/intro-syntax-structure.html#dt-important-props)。

## 712.9\_DMA、输入输出与邮箱通道

**直接存储器访问（Direct Memory Access，DMA）**属性描述设备的 DMA 能力、通道和地址映射；输入输出（Input/Output，I/O）及邮箱（Mailbox）属性描述关联通道。IPM 是**处理器间消息（Inter-Processor Messaging）**接口。

| 属性 | 类型 | 中文说明 |
| --- | --- | --- |
| `dma-coherent` | `boolean` | 表示设备支持一致性 DMA 操作，见规范 v0.4 第 2.3.10 节 |
| `dmas` | `phandle-array` | 与设备相关的 DMA 通道说明符 |
| `dma-names` | `string-array` | `dmas` 中各 DMA 通道说明符的可选名称 |
| `dma-ranges` | `compound` | 定义总线物理地址空间与其父总线物理地址空间之间的映射或转换，见规范 v0.4 第 2.3.9 节 |
| `io-channels` | `phandle-array` | 与设备相关的 I/O 通道说明符 |
| `io-channel-names` | `string-array` | `io-channels` 中各通道说明符的可选名称 |
| `mboxes` | `phandle-array` | 与设备相关的邮箱/IPM 通道说明符 |
| `mbox-names` | `string-array` | `mboxes` 中各邮箱说明符的可选名称 |

## 712.10\_电源域与硬件锁

**电源域（Power Domain）**描述设备所属供电域；**硬件自旋锁（Hardware Spinlock）**为硬件提供的锁资源。属性如下：

| 属性 | 类型 | 中文说明 |
| --- | --- | --- |
| `power-domains` | `phandle-array` | 与设备相关的电源域说明符 |
| `power-domain-names` | `string-array` | `power-domains` 中各电源域说明符的可选名称 |
| `#power-domain-cells` | `int` | `power-domains` 属性中的单元数量 |
| `hwlocks` | `phandle-array` | 与设备相关的硬件自旋锁标识 |
| `hwlock-names` | `string-array` | `hwlocks` 中各锁说明符的可选名称 |

## 712.11\_初始化、唤醒和运行时电源管理

`zephyr,deferred-init` 为 `boolean` 属性：启动时不自动初始化设备，应使用 `device_init()` 手动初始化。

`wakeup-source` 为 `boolean` 属性，标识设备可以作为**唤醒源（Wakeup Source）**。提供它后，设备会设置一个专门标志，告知系统该设备具备唤醒系统的能力。这类设备的唤醒功能默认禁用，即其中断不会唤醒系统，必要时可在运行期间启用。

`zephyr,pm-device-runtime-auto` 为 `boolean` 属性，在初始化函数执行后自动为设备配置**运行时电源管理（Runtime Power Management）**。

`zephyr,disabling-power-states` 的类型为 `phandles`，列出会关闭此设备电源的电源状态。
