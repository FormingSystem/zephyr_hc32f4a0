# 第139章\_单边沿半字节传输

原文：[Single Edge Nibble Transmission (SENT)](https://docs.zephyrproject.org/latest/hardware/peripherals/sent.html)。读取日期：2026-10-13，`latest`。

## 139.1\_与SENT设备通信

**单边沿半字节传输（Single Edge Nibble Transmission，SENT）**的 **应用程序编程接口（Application Programming Interface，API）**提供与SENT设备通信的功能。名称中的 **半字节（Nibble）**表示4位数据单位。

## 139.2\_配置、参考与示例

相关Kconfig配置项为 [`CONFIG_SENT`](https://docs.zephyrproject.org/latest/kconfig.html#CONFIG_SENT)；Kconfig是Zephyr配置系统。完整声明见[SENT API](https://docs.zephyrproject.org/latest/doxygen/html/group__sent__interface.html)。原页关联[SENT接口示例](../driver_samples/P039_SENT接口示例.md#sent)，展示该驱动的使用。
