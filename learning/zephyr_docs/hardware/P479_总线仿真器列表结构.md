# 第479章\_总线仿真器列表结构

原文：[structemul__list__for__bus](https://docs.zephyrproject.org/latest/doxygen/html/structemul__list__for__bus.html)。读取日期：2026-10-13，`latest`。

`struct emul_list_for_bus` 是**总线仿真器列表（Emulator List for Bus）**，用于记录附着在一条总线上的仿真器。结构定义于 `zephyr/drivers/emul.h`。

## 479.1\_子节点标识与数量

列表用一个字段保存节点的子项标识，用另一个字段保存子项数量。这里的 [`emul_link_for_bus`](https://docs.zephyrproject.org/latest/doxygen/html/structemul__link__for__bus.html) 是唯一标识待仿真设备的链接结构。

| 类型与字段 | 官方说明译文 |
| --- | --- |
| `const struct emul_link_for_bus *children` | 该节点的子节点标识 |
| `unsigned int num_children` | 该节点的子节点数量 |

> 译注：[`children`](https://docs.zephyrproject.org/latest/doxygen/html/structemul__list__for__bus.html#a4cd116abd8480895312564dcdf3f2e03) 是指向只读链接结构的指针，[`num_children`](https://docs.zephyrproject.org/latest/doxygen/html/structemul__list__for__bus.html#abcfe7bc6d82a16959c3d89b8598a8563) 的类型为无符号整数。原页没有为该结构声明扩容、释放或所有权转移操作。
