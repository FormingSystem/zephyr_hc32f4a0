# 第218章\_显示调色板颜色

原文：[structdisplay__palette__color](https://docs.zephyrproject.org/latest/doxygen/html/structdisplay__palette__color.html)。读取日期：2026-10-13，`latest`。

## 218.1\_用途

结构 [`display_palette_color`](https://docs.zephyrproject.org/latest/doxygen/html/structdisplay__palette__color.html) 表示一个 **调色板条目（Color Palette Entry）**，采用 ARGB8888 格式，即透明度、红、绿、蓝（Alpha, Red, Green, Blue）四个分量各 8 位。定义来自官方头文件 `zephyr/drivers/display.h`。

## 218.2\_数据字段（Data Fields）

按原文声明顺序列出，各字段都是 [`uint8_t`](https://docs.zephyrproject.org/latest/doxygen/html/stdint_8h.html#a3cb4a16b0e8d6af0af86d4fd6ba5fd9d)，取值范围均为 0～255：

| 字段 | 分量 |
| --- | --- |
| [`b`](https://docs.zephyrproject.org/latest/doxygen/html/structdisplay__palette__color.html#a246ca83b0bdfdef20d93f9439c8cfe19) | 蓝色（Blue）。 |
| [`g`](https://docs.zephyrproject.org/latest/doxygen/html/structdisplay__palette__color.html#ab72b5252ecef18ff4fca49a196b10d1c) | 绿色（Green）。 |
| [`r`](https://docs.zephyrproject.org/latest/doxygen/html/structdisplay__palette__color.html#a054840180d6a2417262bd87f3dca3c30) | 红色（Red）。 |
| [`a`](https://docs.zephyrproject.org/latest/doxygen/html/structdisplay__palette__color.html#ab443cff44dce74c21ad348875b45efe5) | 透明度（Alpha）。 |

该结构用于[显示能力结构](P216_显示能力结构.md)中的调色板数组；像素格式与原内存布局见[显示公共接口](P214_显示公共接口.md)。
