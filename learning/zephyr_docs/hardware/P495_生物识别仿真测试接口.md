# 第495章\_生物识别仿真测试接口

原文：[group__biometrics__emulator](P495_生物识别仿真测试接口.md)。读取日期：2026-10-13，`latest`。

**生物识别（Biometrics）**仿真器提供测试控制函数，用来指定匹配结果、采集异常、图像质量，并验证指示灯控制。所有接口均声明于 `zephyr/drivers/biometrics/emul.h`；本页各函数的 `dev` 参数都指向生物识别设备。

## 495.1\_设置匹配分数与身份

[`biometrics_emul_set_match_score()`](P495_生物识别仿真测试接口.md) 配置下一次匹配操作返回的置信度/匹配分数（Confidence/Match Score），用于测试匹配验证与身份识别。

```c
void biometrics_emul_set_match_score(const struct device *dev, int score);
```

参数 `score` 是要返回的匹配分数，**量表由传感器决定**。

[`biometrics_emul_set_match_id()`](P495_生物识别仿真测试接口.md) 设置身份识别匹配使用的**模板标识（Template ID）**，用于测试身份识别场景。

```c
void biometrics_emul_set_match_id(const struct device *dev, int id);
```

执行 `IDENTIFY` 身份识别匹配操作并成功时，将返回参数 `id` 指定的模板标识。

## 495.2\_模拟匹配失败与采集超时

[`biometrics_emul_set_match_fail()`](P495_生物识别仿真测试接口.md) 控制匹配操作是否失败。启用后，仿真器让匹配操作以“未找到”错误 `-ENOENT` 失败，用于测试匹配失败场景。

```c
void biometrics_emul_set_match_fail(const struct device *dev, bool fail);
```

`fail` 为 `true` 时使匹配失败，为 `false` 时使用正常行为。

[`biometrics_emul_set_capture_timeout()`](P495_生物识别仿真测试接口.md) 控制**采集超时（Capture Timeout）**仿真。启用后，录入过程中的采集（Enrollment Capture）操作返回超时错误 `-ETIMEDOUT`。

```c
void biometrics_emul_set_capture_timeout(const struct device *dev, bool timeout);
```

`timeout` 为 `true` 时模拟超时，为 `false` 时使用正常行为。

## 495.3\_图像质量与指示灯状态

[`biometrics_emul_set_image_quality()`](P495_生物识别仿真测试接口.md) 配置采集和匹配操作返回的**图像质量分数（Image Quality Score）**，用于测试质量反馈。

```c
void biometrics_emul_set_image_quality(const struct device *dev, int quality);
```

参数 `quality` 范围为 **0～100**。这是图像质量分数的范围，不应据此假定前述匹配分数也使用同一量表。

[`biometrics_emul_get_led_state()`](P495_生物识别仿真测试接口.md) 取得当前**发光二极管（Light-Emitting Diode，LED）**状态，用于验证指示灯控制命令。读取的是通过 [`biometric_led_control()`](https://docs.zephyrproject.org/latest/doxygen/html/group__biometrics__interface.html#gaca4596921ea8f1554215d4994da5537e) 设置的当前状态。

```c
enum biometric_led_state biometrics_emul_get_led_state(const struct device *dev);
```

返回值为当前 LED 状态，类型为 [`biometric_led_state`](https://docs.zephyrproject.org/latest/doxygen/html/group__biometrics__interface.html#ga83c3fbd41de6c4f3739880fceadea96f) 枚举。前述五个设置函数均返回 `void`，原页未给出额外返回值。
