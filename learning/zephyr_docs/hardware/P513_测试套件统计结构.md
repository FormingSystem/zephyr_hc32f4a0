# 第513章\_测试套件统计结构

原文：[structztest__suite__stats](P513_测试套件统计结构.md)。读取日期：2026-10-13，`latest`。

`struct ztest_suite_stats` 保存 **Zephyr 测试框架（Zephyr Testing Framework，ZTest）**中一个套件的统计信息。

公开头文件为 `zephyr/ztest_test.h`，源码位置为 `subsys/testsuite/ztest/include/zephyr/ztest_test.h`。这里以公开包含名替代原文构建机的绝对路径。

## 513.1\_套件计数器

所有计数均使用 32 位无符号整数，统计对象为整个**测试套件（Test Suite）**。

| 字段声明 | 官方说明译文 |
| --- | --- |
| `uint32_t run_count` | 套件运行次数 |
| `uint32_t skip_count` | 套件被跳过的次数 |
| `uint32_t fail_count` | 套件失败次数 |
