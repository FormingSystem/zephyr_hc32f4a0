# 第130章\_显示设备

原文：[Display](https://docs.zephyrproject.org/latest/hardware/peripherals/display/index.html)。读取日期：2026-10-13，`latest`。

## 130.1\_与传输方式无关的显示接口

Zephyr的 **显示（Display）**子系统提供统一方式访问多种显示设备。其 **应用程序编程接口（Application Programming Interface，API）**与传输方式无关：描述希望显示器完成什么操作，而不向应用暴露数据如何在线路上传输。

## 130.2\_MIPI显示总线接口

MIPI是接口标准组织及标准族名称；**显示总线接口（Display Bus Interface，DBI）**规范定义连接主机与显示控制器的多种并行、串行总线。Zephyr的DBI支持向驱动提供命令写入、读取、像素传输、复位等总线级原语，由驱动在内部实现通用显示API。

应用不直接使用DBI函数，而是调用通用显示API，例如写入像素；驱动在内部处理DBI协议。

MIPI-DBI定义三种接口类型：Type A为Motorola 6800并行总线，Type B为Intel 8080并行总线，Type C为类似 **串行外设接口（Serial Peripheral Interface，SPI）**的串行位总线。Type C又有三个选项：

1. 每字节9个写时钟；原文称最后一位为命令／数据选择位。
2. 与上一项相同，但每字节16个写时钟。
3. 每字节8个写时钟，通过 **通用输入输出（General-Purpose Input/Output，GPIO）**引脚选择命令或数据。

原文明确：当前API**不支持Type C的16个写时钟选项**，即选项2。完整参考见[MIPI-DBI接口](P245_MIPI显示总线接口.md)。

## 130.3\_MIPI显示串行接口

**显示串行接口（Display Serial Interface，DSI）**是一种高速差分串行总线，面向现代彩色 **薄膜晶体管（Thin-Film Transistor，TFT）**面板。Zephyr的DSI支持提供驱动所需原语，使驱动能在DSI链路之上实现通用显示API。

与DBI一样，应用不直接调用DSI函数，而使用通用显示API保持可移植性，由驱动在内部处理DSI事务。完整参考见[MIPI-DSI接口](P246_MIPI显示串行接口.md)。

## 130.5\_Grove、micro:bit与单色字符帧缓冲

原页还提供[Grove显示接口](https://docs.zephyrproject.org/latest/doxygen/html/group__grove__display.html)及其[Grove LCD示例](../driver_samples/P048_Grove液晶显示示例.md#grove-lcd)，示例显示递增计数器并改变背光颜色。LCD表示 **液晶显示器（Liquid Crystal Display）**。
