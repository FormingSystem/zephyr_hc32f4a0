# 第124章\_蜂鸣器

原文：[Buzzer](https://docs.zephyrproject.org/latest/hardware/peripherals/buzzer.html)。读取日期：2026-10-13，`latest`。

## 124.1\_统一驱动有源与无源蜂鸣器

**蜂鸣器（Buzzer）**子系统提供统一 **应用程序编程接口（Application Programming Interface，API）**，既可驱动由 **脉宽调制（Pulse Width Modulation，PWM）**通道激励的 **无源压电蜂鸣器（Passive Piezo Buzzer）**，也可驱动单根 **通用输入输出（General-Purpose Input/Output，GPIO）**线路控制的 **有源蜂鸣器（Active Buzzer）**。

应用通过 **设备树（Devicetree）**取得蜂鸣器设备，再调用[蜂鸣器头文件](https://github.com/zephyrproject-rtos/zephyr/blob/main/include/zephyr/drivers/buzzer.h) `include/zephyr/drivers/buzzer.h` 中的函数。

## 124.2\_音调持续时间不是线程等待时间

蜂鸣器API调用**不会等待所请求的音调持续时间**。持续时间描述硬件应发声多久，不表示调用线程应睡眠多久。持续时间常量 [`BUZZER_DURATION_FOREVER`](P144_蜂鸣器接口参考.md) 表示一直播放，直到显式停止。

音调函数 [`buzzer_tone()`](P144_蜂鸣器接口参考.md) 以指定频率播放指定时长。硬件在该时长内继续发声，之后由驱动自动静音。

蜂鸣函数 [`buzzer_beep()`](P144_蜂鸣器接口参考.md) 使用蜂鸣器自然工作频率；该频率由板级文件中 `pwms` 设备树属性的周期单元表示，通常对应压电器件的机械谐振点，即器件能够发出最大响度的音调。对于有源蜂鸣器，此调用等同于打开GPIO线路，实际音高由硬件振荡器决定。

音量函数 [`buzzer_set_volume()`](P144_蜂鸣器接口参考.md) 调整感知响度。值为0时立即静音；非零值先保存，在下一次音调播放时应用。有源蜂鸣器没有模拟音量调节，0映射为静音，任意非零值都映射为唯一的可听响度。

停止函数 [`buzzer_stop()`](P144_蜂鸣器接口参考.md) 立即取消正在播放的音调。

## 124.3\_两个设备树后端

原页提供两个可通过设备树发现的后端：

- [pwm-buzzer](../sound_haptic_binding_reference/P003_pwm-buzzer.md#std-dtcompatible-pwm-buzzer)：适用于PWM通道驱动的无源压电蜂鸣器。PWM周期决定音频频率，**占空比（Duty Cycle）**决定感知音量；驱动根据应用请求的音调和音量计算二者。
- [gpio-buzzer](../sound_haptic_binding_reference/P002_gpio-buzzer.md#std-dtcompatible-gpio-buzzer)：适用于单GPIO驱动的有源蜂鸣器。任意非零频率使线路开启，休止频率常量 [`BUZZER_FREQ_REST`](P144_蜂鸣器接口参考.md) 使线路关闭。

## 124.4\_接口与示例

完整接口见[蜂鸣器API](P144_蜂鸣器接口参考.md)。[蜂鸣器音调示例](P143_蜂鸣器音调示例.md)通过设备树别名 `buzzer0` 对应的设备播放一个短蜂鸣及几个音调。
