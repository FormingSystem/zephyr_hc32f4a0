# 第633章\_保留内存头文件

原文：[retained__mem_8h](https://docs.zephyrproject.org/latest/doxygen/html/retained__mem_8h.html)。读取日期：2026-10-13，`latest`。

`zephyr/drivers/retained_mem.h` 是保留内存（Retained Memory）驱动应用程序编程接口（Application Programming Interface，API）的主头文件。

## 633.1\_包含关系与源文件

```c
#include <stdint.h>
#include <stddef.h>
#include <sys/types.h>
#include <zephyr/kernel.h>
#include <zephyr/device.h>
#include <zephyr/types.h>
#include <zephyr/sys/math_extras.h>
#include <zephyr/syscalls/retained_mem.h>
```

[查看官方源码](../memory_retention_reference/P004_保留内存头文件源码.md)。

## 633.2\_操作表与回调类型

结构 [`retained_mem_driver_api`](https://docs.zephyrproject.org/latest/doxygen/html/structretained__mem__driver__api.html) 保存保留内存驱动操作，见[驱动操作表](P632_保留内存驱动操作表.md)。回调（Callback）类型如下：

```c
typedef ssize_t (*retained_mem_size_api)(const struct device *dev);
typedef int (*retained_mem_read_api)(const struct device *dev, off_t offset, uint8_t *buffer, size_t size);
typedef int (*retained_mem_write_api)(const struct device *dev, off_t offset, const uint8_t *buffer, size_t size);
typedef int (*retained_mem_clear_api)(const struct device *dev);
```

| 回调类型 | 中文说明 |
| --- | --- |
| [`retained_mem_size_api`](https://docs.zephyrproject.org/latest/doxygen/html/group__retained__mem__interface__backend.html#ga684490184eedc8d3f56b25d7b6e50a06) | 查询保留内存区域大小 |
| [`retained_mem_read_api`](https://docs.zephyrproject.org/latest/doxygen/html/group__retained__mem__interface__backend.html#ga3831f3ec0e0de7957cc6ce7da0cfbe58) | 从保留内存区域读取数据 |
| [`retained_mem_write_api`](https://docs.zephyrproject.org/latest/doxygen/html/group__retained__mem__interface__backend.html#gaf6e43d230b1a606e90f3a236aeff1909) | 向保留内存区域写入数据 |
| [`retained_mem_clear_api`](https://docs.zephyrproject.org/latest/doxygen/html/group__retained__mem__interface__backend.html#ga3fde220eceb8a45a7a42cfbb1930e27d) | 清除保留内存区域，将全部数据复位为 `0x00` |

详细说明见[驱动接口](P631_保留内存驱动接口.md)。

```c
int retained_mem_write(const struct device *dev, off_t offset, const uint8_t *buffer, size_t size);
int retained_mem_clear(const struct device *dev);
```
