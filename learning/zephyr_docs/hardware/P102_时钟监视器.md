# 第102章\_时钟监视器

原文：[Clock Monitor](https://docs.zephyrproject.org/latest/hardware/peripherals/clock_monitor.html)。读取日期：2026-10-13，`latest`。

## 102.1\_监视时钟异常

**时钟监视器（Clock Monitor）**的 **应用程序编程接口（Application Programming Interface，API）**访问运行时观察时钟信号的硬件。当频率漂移超出预期边界或时钟完全停止时，硬件报告异常。它面向 **功能安全（Functional Safety）**和诊断场景，例如检测振荡器失效、参考时钟丢失，以及关键时钟树频率超出规格。

两种工作模式共用相同生命周期：用 [`clock_monitor_configure()`](../timer_reference/P098_时钟监控公共接口.md) 配置，用 [`clock_monitor_start()`](../timer_reference/P098_时钟监控公共接口.md) 开始，用 [`clock_monitor_stop()`](../timer_reference/P098_时钟监控公共接口.md) 结束。

## 102.2\_连续窗口检查

`CLOCK_MONITOR_MODE_WINDOW` 是 **窗口模式（Window Mode）**，持续检查阈值。硬件依据 `clock_monitor_window_cfg.expected_hz` 的预期频率，以及 `clock_monitor_window_cfg.tolerance_ppm` 的容差，得到可编程高、低边界。

Hz为赫兹；ppm为 **百万分率（Parts Per Million）**。越过阈值时，通过配置阶段安装的用户 **回调函数（Callback Function）**异步交付事件。

## 102.3\_单次频率测量与超时

`CLOCK_MONITOR_MODE_MEASURE` 是 **测量模式（Measure Mode）**。每次调用 [`clock_monitor_start()`](../timer_reference/P098_时钟监控公共接口.md) 进行一次频率测量，通过配置阶段的回调交付 `CLOCK_MONITOR_EVT_MEASURE_DONE` 事件及以Hz表示的测量值。

回调运行前，设备自动回到已配置、已停止状态，所以成功路径不需要再调用 [`clock_monitor_stop()`](../timer_reference/P098_时钟监控公共接口.md)。要重复测量，可以在回调中再次调用 [`clock_monitor_start()`](../timer_reference/P098_时钟监控公共接口.md)；start和stop均可安全用于 **中断服务程序（Interrupt Service Routine，ISR）**，与在计数器告警回调中重新设置告警的做法类似。

测量模式的API不提供阻塞等待，**超时由应用负责**。常见方式是等待一个由回调释放的 **信号量（Semaphore）**，使用应用选择的超时时间；超时后调用 [`clock_monitor_stop()`](../timer_reference/P098_时钟监控公共接口.md) 中止尚未结束的测量。

也可用 [`clock_monitor_get_rate()`](../timer_reference/P098_时钟监控公共接口.md) 轮询最近一次结果。在不能安装回调的 **用户模式（User Mode）**线程中，这也是获取测量结果的途径。

## 102.4\_事件位掩码与用户模式

事件在 `clock_monitor_event_data.events` 中以 **位掩码（Bitmask）**交付。

| 事件 | 含义与模式 |
| --- | --- |
| `CLOCK_MONITOR_EVT_FREQ_HIGH` | 窗口模式：被监视频率超过上限。 |
| `CLOCK_MONITOR_EVT_FREQ_LOW` | 窗口模式：被监视频率低于下限。 |
| `CLOCK_MONITOR_EVT_CLOCK_LOST` | 测量模式的硬件故障：被监视时钟在测量窗口内不再产生边沿。 |
| `CLOCK_MONITOR_EVT_MEASURE_DONE` | 测量模式成功完成，结果位于 `clock_monitor_event_data.measured_hz`。 |

配置时安装的回调是**唯一事件交付路径**。测量模式另保留最近完成结果，供 [`clock_monitor_get_rate()`](../timer_reference/P098_时钟监控公共接口.md) 轮询；轮询结果不等同于获得全部事件。

窗口模式的用户模式观察者不能安装回调时，需要 **特权侧转发（Supervisor-Side Relay）**，例如由回调向 `k_msgq` **消息队列（Message Queue）**写入，再由观察者读取。

## 102.5\_重新配置与参考

启动之前必须先配置。配置包含工作模式、相应参数（预期频率、容差、测量窗口）以及可选异步回调。**只能在监视器停止时配置**；要改变模式或参数，再次调用 [`clock_monitor_configure()`](../timer_reference/P098_时钟监控公共接口.md)，没有单独的拆除操作。完整返回码见[时钟监视器API](../timer_reference/P098_时钟监控公共接口.md)。

相关Kconfig配置项为 [`CONFIG_CLOCK_MONITOR`](https://docs.zephyrproject.org/latest/kconfig.html#CONFIG_CLOCK_MONITOR)，用于时钟监视器支持；Kconfig是Zephyr配置系统。相关示例包括[时钟频率检查](P117_时钟频率检查示例.md)，持续按可编程阈值检查；以及[时钟频率测量](P118_时钟频率测量示例.md)，进行一次测量并打印结果。本章未配置时钟树或执行频率测量。
