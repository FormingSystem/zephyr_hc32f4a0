# 第10章\_DAC数模转换

原文：[Digital-to-Analog Converter (DAC)](https://docs.zephyrproject.org/latest/hardware/peripherals/dac.html)。读取日期：2026-10-12，`latest`。

**数模转换器（Digital-to-Analog Converter，DAC）** 接口提供对数模转换器（Digital-to-Analog Converter，DAC）设备的访问。

相关配置选项为 `CONFIG_DAC`。完整声明见 [DAC 接口参考](P822_数模转换器接口.md)。

[DAC 示例](../driver_samples/P001_DAC数模转换示例.md)使用该驱动接口生成模拟锯齿波。
