# 第177章\_辅助数码显示示例

原文：[Auxiliary digits display](https://docs.zephyrproject.org/latest/samples/drivers/auxdisplay_digits/README.html)。读取日期：2026-10-13，`latest`。

## 177.1\_概述（Overview）

本示例演示如何使用 **辅助显示（Auxiliary Display）**驱动控制数字型显示器，例如 **七段数码管（7-segment Display）**。接口概述见[辅助显示设备](P131_辅助显示器.md)。

## 177.2\_构建与运行（Building and Running）

示例需要已经配置七段数码管的开发板。可以通过飞线（Fly-wiring）把七段数码管接到自己的开发板上，组成相应硬件。

官方也为 `native_sim` 主机原生仿真目标提供 **设备树叠加文件（Devicetree Overlay）**示例，见 [`samples/drivers/auxdisplay_digits/boards/native_sim.overlay`](https://github.com/zephyrproject-rtos/zephyr/blob/main/samples/drivers/auxdisplay_digits/boards/native_sim.overlay)。

译注：在已配置 Zephyr 开发环境的终端中，从 Zephyr 源码根目录执行以下官方构建命令；示例与叠加文件由官方仓库提供，west 生成构建产物。

```bash
west build -b native_sim samples/drivers/auxdisplay_digits
```

成功运行后，显示器按以下顺序工作：先点亮所有段，例如三位数码管显示 `8.8.8.`；然后闪烁一次；接着从左到右依次点亮每一位；最后从 0 开始递增计数，直到显示器能够显示的最大数值。
