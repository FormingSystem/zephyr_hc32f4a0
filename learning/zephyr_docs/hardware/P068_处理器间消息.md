# 第68章\_处理器间消息

原文：[Inter-Processor Mailbox (IPM)](https://docs.zephyrproject.org/latest/hardware/peripherals/ipm.html)。读取日期：2026-10-13，`latest`。

## 68.1\_处理器间邮箱入口

**处理器间邮箱（Inter-Processor Mailbox，IPM）**是本页主题。原页“概览”下没有额外说明文字，直接链接[IPM应用程序编程接口（Application Programming Interface，API）](../intercore_reference/P058_处理器间消息公共接口.md)及下列十个相关示例。

为便于阅读示例名，**CPU（Central Processing Unit）**指中央处理器，**片上系统（System on Chip，SoC）**指集成处理器与外设的芯片。其他示例专有名词在相应行中解释，产品系列名称保持原样。

## 68.2\_相关代码示例

| 示例 | 原文用途 |
| --- | --- |
| [ESP32上的Flash IPM](../intercore_reference/P078_ESP32闪存IPM示例.md) | 使用IPM在CPU核心间共享 **闪存（Flash）**API。 |
| [STM32 H7上的硬件信号量通信](../intercore_reference/P087_STM32H7双核信号量示例.md) | 使用 **硬件信号量（Hardware Semaphore，HSEM）**，从一个核心触发另一个核心的 **发光二极管（Light-Emitting Diode，LED）**闪烁。 |
| [ESP32上的IPM](../intercore_reference/P080_ESP32双核IPM示例.md) | 在ESP32名为APP与PRO的两个CPU之间实现IPM。 |
| [NXP i.MX上的IPM](../intercore_reference/P081_NXPiMX处理器间邮箱示例.md) | 在包含 **消息单元（Messaging Unit）**外设的i.MX SoC上实现IPM。 |
| [NXP LPC上的IPM](../intercore_reference/P083_NXPLPC处理器间邮箱示例.md) | 在NXP LPC系列上实现IPM。 |
| [基于IVSHMEM的IPM](../intercore_reference/P082_IVSHMEM处理器间邮箱示例.md) | 通过 **虚拟机间共享内存（Inter-VM Shared Memory，IVSHMEM）**实现IPM；VM是 **虚拟机（Virtual Machine）**。 |
| [使用Arm MHU的IPM](../intercore_reference/P084_ArmMHU双核IPM示例.md) | 使用 **消息处理单元（Message Handling Unit，MHU）**实现IPM。 |
| [OpenAMP](../intercore_reference/P088_OpenAMP双核通信示例.md) | 使用OpenAMP在两个核心之间发送消息。 |
| [OpenAMP DSP AMP示例](https://docs.zephyrproject.org/latest/samples/boards/nxp/adsp/rtxxx/amp_talk/README.html#amp_talk) | 通过并发通信通道，使用OpenAMP在多个核心之间发送消息。DSP指 **数字信号处理器（Digital Signal Processor）**；AMP指 **非对称多处理（Asymmetric Multiprocessing）**。 |
| [使用资源表的OpenAMP](../intercore_reference/P089_OpenAMP资源表示例.md) | 使用OpenAMP和 **资源表（Resource Table）**在两个核心之间发送消息。 |

OpenAMP为跨核心通信框架的名称。本目录只翻译各示例的官方摘要；链接目标中的完整构建和运行步骤属于各自页面，不能据本目录认定这些目标页面已完成翻译或实板验证。
