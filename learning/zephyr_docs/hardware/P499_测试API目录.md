# 第499章\_测试API目录

原文：[group__testing](P499_测试API目录.md)。读取日期：2026-10-13，`latest`。

本页是 Zephyr **测试应用程序编程接口（Testing Application Programming Interface，Testing API）**的官方目录，按测试用途列出四个入口。

## 499.1\_测试接口主题

**仿真器（Emulator）**用于测试驱动及调用这些驱动的上层代码；**伪函数框架（Fake Function Framework，FFF）**允许测试控制替代函数的行为。以下目录保留原页全部主题。

| 官方主题与入口 | 中文名称及原文说明 |
| --- | --- |
| [Emulator interfaces](P476_外设仿真器API.md) | 仿真器接口：用于测试驱动及使用驱动的上层代码 |
| [FFF extensions](P500_FFF测试扩展接口.md) | FFF 扩展：简化伪函数的配置和使用 |
| [Zephyr Benchmarking Framework](P501_ZTest基准测试接口.md) | Zephyr 基准测试框架；原页仅提供目录入口 |
| [Zephyr Testing Framework (ZTest)](P502_ZTest测试框架接口.md) | Zephyr 测试框架（ZTest）；原页仅提供目录入口 |
