# 第241章\_TMCM3216电机状态

原文：[structtmcm3216__status](https://docs.zephyrproject.org/latest/doxygen/html/structtmcm3216__status.html)。读取日期：2026-10-13，`latest`。

## 241.1\_用途

结构 [`tmcm3216_status`](https://docs.zephyrproject.org/latest/doxygen/html/structtmcm3216__status.html) 保存 TMCM-3216 的 **电机状态（Motor Status）**，定义来自 `zephyr/drivers/stepper/stepper_tmcm3216.h`，由[状态查询接口](P239_TMCM3216步进扩展.md)填充。
