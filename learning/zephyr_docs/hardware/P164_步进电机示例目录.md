# 第164章\_步进电机示例目录

原文：[Stepper](https://docs.zephyrproject.org/latest/samples/drivers/stepper/index.html)。读取日期：2026-10-13，`latest`。

## 164.1\_示例范围

这些示例演示如何使用 **步进电机（Stepper Motor）**驱动的 **应用程序编程接口（Application Programming Interface，API）**。

| 示例 | 演示内容 |
| --- | --- |
| [通用步进电机示例（Stepper）](P165_通用步进电机示例.md) | 以四种运动模式驱动步进电机旋转。 |
| [TMC50XX步进电机示例（TMC50XX Stepper）](P166_TMC50XX步进电机示例.md) | 驱动 TMC50XX 步进电机，并在运行时改变速度。 |
| [TMCM-3216步进电机示例（TMCM-3216 Stepper）](P167_TMCM3216步进电机示例.md) | 通过 RS485 串行通信接口，使用 ADI TMCM-3216 独立控制器与驱动板控制步进电机。 |

译注：ADI 是 Analog Devices 的简称；TMC50XX、TMCM-3216 是器件或模块型号，保留原名。驱动体系参见[步进电机概述](P126_步进电机.md)。
