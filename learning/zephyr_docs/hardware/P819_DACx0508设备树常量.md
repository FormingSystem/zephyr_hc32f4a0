# 第819章\_DACx0508设备树常量

原文：[dacx0508_8h](https://docs.zephyrproject.org/latest/doxygen/html/dacx0508_8h.html)。读取日期：2026-10-13，`latest`。

头文件 `zephyr/dt-bindings/dac/dacx0508.h` 定义数模转换器（Digital-to-Analog Converter，DAC）DACx0508系列使用的设备树常量（Devicetree Constants）。原页逐项列出6个宏及数值，没有附加说明或包含项。[官方源码浏览](P834_DACx0508设备树常量源码.md)保留原始定义。

这些标识供[DAC60508](P810_DAC60508数模转换器绑定.md)、[DAC70508](P813_DAC70508数模转换器绑定.md)、[DAC80508](P815_DAC80508数模转换器绑定.md)的参考源（Reference Source）及通道增益（Channel Gain）属性使用。下表中文是宏名释义；原页未给出参考电压值，不能将宏编码当作电压。

## 819.1\_参考源常量

`INTERNAL` 表示内部参考，`EXTERNAL` 表示外部参考；后缀 `1`／`1_2` 为原始配置标识。

```c
#define DACX0508_REF_INTERNAL_1 0x00
#define DACX0508_REF_INTERNAL_1_2 0x01
#define DACX0508_REF_EXTERNAL_1 0x02
#define DACX0508_REF_EXTERNAL_1_2 0x03
```
