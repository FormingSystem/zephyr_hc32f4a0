# 第131章\_辅助显示器

原文：[Auxiliary Display (auxdisplay)](https://docs.zephyrproject.org/latest/hardware/peripherals/auxdisplay.html)。读取日期：2026-10-13，`latest`。

## 131.1\_面向文字的辅助显示器

**辅助显示器（Auxiliary Display）**是基于文字的显示器，通过简单接口显示文字、数字或字母数字混合数据。与[通用显示设备](P130_显示设备.md)相比，它不支持自定义图形输出，而且大多为单色；通常最复杂的自定义功能是生成自定义字符。

这类显示器价格较低，有多种配置与尺寸，常见规格为每行16个字符、共2行。

原文明确指出：该 **应用程序编程接口（Application Programming Interface，API）**尚不稳定，可能发生变化。

## 131.2\_配置、接口与示例

相关Kconfig配置项为 [`CONFIG_AUXDISPLAY`](https://docs.zephyrproject.org/latest/kconfig.html#CONFIG_AUXDISPLAY) 和初始化优先级配置项 [`CONFIG_AUXDISPLAY_INIT_PRIORITY`](https://docs.zephyrproject.org/latest/kconfig.html#CONFIG_AUXDISPLAY_INIT_PRIORITY)；Kconfig是Zephyr配置系统。

完整声明见[辅助文字显示API](https://docs.zephyrproject.org/latest/doxygen/html/group__auxdisplay__interface.html)。原页关联[辅助数字显示示例](P177_辅助数码显示示例.md)，输出递增数字；以及[辅助显示示例](P176_辅助显示示例.md)，输出原字符串“Hello  World”。
