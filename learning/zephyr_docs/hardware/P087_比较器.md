# 第87章\_比较器

原文：[Comparator](https://docs.zephyrproject.org/latest/hardware/peripherals/comparator.html)。读取日期：2026-10-13，`latest`。

## 87.1\_比较电压与检测变化

**模拟比较器（Analog Comparator）**比较连接到负输入与正输入的两个模拟信号电压。正输入电压高于负输入时，输出为高；否则输出为低。

比较器通常可以设置一个由输出变化引发的 **触发事件（Trigger）**。该事件既可调用 **回调函数（Callback Function）**，也可由应用 **轮询（Polling）**其状态。

相关Kconfig配置项为 [`CONFIG_COMPARATOR`](https://docs.zephyrproject.org/latest/kconfig.html#CONFIG_COMPARATOR)，用于比较器支持；Kconfig是Zephyr配置系统。

## 87.2\_初始配置与运行时更新

嵌入式比较器通常可在运行时配置。启用比较器时，必须通过设备树提供初始配置；运行期间，可使用设备驱动专用的 **应用程序编程接口（Application Programming Interface，API）**更新配置。

**配置在比较器恢复时应用。** 因此，更新配置数据与比较器开始按该配置工作不是原文所说的同一个时刻。

## 87.3\_电源管理控制活动状态

比较器通过 **电源管理（Power Management，PM）**启用。处于 **恢复状态（Resumed）**时，它主动比较输入、产生输出并检测边沿；处于 **挂起状态（Suspended）**时，它不活动。

排查没有输出或没有触发事件时，应把设备活动状态与输入、配置一起考虑，不能只检查回调是否注册。

## 87.4\_比较器命令行

比较器为Zephyr[命令行模块（Shell）](https://docs.zephyrproject.org/latest/services/shell/index.html#shell-api)提供 `comp` 命令及以下子命令。原页列的是功能入口，并未给出每个命令完整参数语法；实际使用时按目标固件的帮助填写设备与参数，不在主机Bash里直接执行这些设备命令。

| 子命令 | 功能或接口对应 |
| --- | --- |
| `get_output` | 取得输出，见 [`comparator_get_output()`](P089_比较器接口参考.md)。 |
| `set_trigger` | 设置触发条件，见 [`comparator_set_trigger()`](P089_比较器接口参考.md)。 |
| `await_trigger` | 等待触发，流程见下一段。 |
| `trigger_is_pending` | 检查是否有待处理触发，见 [`comparator_trigger_is_pending()`](P089_比较器接口参考.md)。 |

`await_trigger` 先通过 [`comparator_set_trigger_callback()`](P089_比较器接口参考.md) 设置触发回调，然后等待回调到达，或在默认／可选指定超时之后结束，最后再次调用 [`comparator_set_trigger_callback()`](P089_比较器接口参考.md) 清除触发回调。等待结束后的清理属于原流程的一部分。

## 87.5\_命令行配置与接口参考

原页列出以下相关Kconfig配置项。

| 配置项 | 作用 |
| --- | --- |
| [`CONFIG_SHELL`](https://docs.zephyrproject.org/latest/kconfig.html#CONFIG_SHELL) | Zephyr命令行模块。 |
| [`CONFIG_COMPARATOR_SHELL`](https://docs.zephyrproject.org/latest/kconfig.html#CONFIG_COMPARATOR_SHELL) | 比较器命令行。 |
| [`CONFIG_COMPARATOR_SHELL_AWAIT_TRIGGER_DEFAULT_TIMEOUT`](https://docs.zephyrproject.org/latest/kconfig.html#CONFIG_COMPARATOR_SHELL_AWAIT_TRIGGER_DEFAULT_TIMEOUT) | 等待触发的默认超时。 |
| [`CONFIG_COMPARATOR_SHELL_AWAIT_TRIGGER_MAX_TIMEOUT`](https://docs.zephyrproject.org/latest/kconfig.html#CONFIG_COMPARATOR_SHELL_AWAIT_TRIGGER_MAX_TIMEOUT) | 等待触发允许的最大超时。 |

可以选择在比较器命令行之外同时启用设备电源管理命令行，相关配置项为 [`CONFIG_PM_DEVICE`](https://docs.zephyrproject.org/latest/kconfig.html#CONFIG_PM_DEVICE) 与 [`CONFIG_PM_DEVICE_SHELL`](https://docs.zephyrproject.org/latest/kconfig.html#CONFIG_PM_DEVICE_SHELL)。

原页接口参考包括[比较器API](P089_比较器接口参考.md)和[伪比较器（Fake Comparator）](P090_伪比较器接口.md)。本章没有更新硬件配置、恢复设备或实际等待触发。
