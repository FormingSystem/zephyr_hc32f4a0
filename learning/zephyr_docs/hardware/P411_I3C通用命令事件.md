# 第411章\_I3C通用命令事件

原文：[structi3c__ccc__events](https://docs.zephyrproject.org/latest/doxygen/html/structi3c__ccc__events.html)。读取日期：2026-10-13，`latest`。

## 411.1\_目标事件命令载荷

`struct i3c_ccc_events` 是**改进的集成电路间总线（Improved Inter-Integrated Circuit，I3C）通用命令码（Common Command Code，CCC）** `ENEC`/`DISEC` 的载荷（Payload）。它们属于目标事件命令（Target Events Command），用于启用或禁用相应事件。头文件为 `zephyr/drivers/i3c/ccc.h`。

## 411.2\_事件字节

唯一字段 `uint8_t events` 为事件字节（Event Byte）：

| 位 | 原命名 | 对应事件 |
| --- | --- | --- |
| 0 | `ENINT` / `DISINT` | 目标中断请求（Target Interrupt Requests）。 |
| 1 | `ENCR` / `DISCR` | 控制器角色请求（Controller Role Requests）。 |
| 3 | `ENHJ` / `DISHJ` | 热加入事件（Hot-Join Event）。 |

原页面没有给出其余位的定义，本页不额外赋予含义。
