# 第129章\_显示与照明入口

原文：[Display](https://docs.zephyrproject.org/latest/hardware/peripherals/display.html)。读取日期：2026-10-13，`latest`。

## 129.1\_视觉输出与照明控制目录

官方 **显示（Display）**分类涵盖视觉输出、视频接口、发光二极管及照明控制，按原顺序列出以下五个入口：

- [显示设备](P130_显示设备.md)：**显示（Display）**子系统。
- [辅助显示器](P131_辅助显示器.md)：**辅助显示器（Auxiliary Display）**。
- [视频](P141_视频设备.md)：**视频（Video）**接口。
- [发光二极管](P132_发光二极管.md)：**发光二极管（Light-Emitting Diode，LED）**。
- [数字可寻址照明接口](P133_数字可寻址照明接口.md)：**数字可寻址照明接口（Digital Addressable Lighting Interface，DALI）**。

目录项不代表对应正文均已翻译；尚未完成的正文保留官方入口。
