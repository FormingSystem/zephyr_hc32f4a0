# 第519章\_伪稳压器设备树绑定

<a id="dtbinding-zephyr-fake-regulator"></a>

原文：[zephyr,fake-regulator](https://docs.zephyrproject.org/latest/build/dts/api/bindings/regulator/zephyr,fake-regulator.html)。读取日期：2026-10-13，`latest`。

`zephyr,fake-regulator` 是 Zephyr Project 提供的伪**稳压器（Regulator）**设备树绑定，用于在测试中充当**模拟对象（Mock）**或**桩（Stub）**。它允许定义任意数量的子节点；驱动实现为 [`drivers/regulator/regulator_fake.c`](https://github.com/zephyrproject-rtos/zephyr/blob/main/drivers/regulator/regulator_fake.c)。

官方[开发板目录中的对应兼容项](https://docs.zephyrproject.org/latest/boards/index.html#compatibles=zephyr,fake-regulator)可查看使用该兼容字符串的开发板。

## 519.1\_子节点属性与基本数值

原页没有顶层属性，以下均为**子节点属性（Child Node Properties）**。`int` 是整数，`string` 是字符串，`boolean` 是布尔属性，`array` 是数组。属性名中的 `microvolt`、`microamp` 分别以**微伏（Microvolt，µV）**、**微安（Microampere，µA）**为单位。

| 属性 | 类型 | 中文说明 |
| --- | --- | --- |
| `fake-is-enabled-in-hardware` | `boolean` | 设置传给 `regulator_common_init` 的 `is_enabled` 标志，使测试能模拟稳压器在硬件中已经启用的情况 |
| `regulator-name` | `string` | 稳压器输出的描述性名称 |
| `regulator-init-microvolt` | `int` | 初始化时设置的电压 |
| `regulator-min-microvolt` | `int` | 使用者可设置的最小电压 |
| `regulator-max-microvolt` | `int` | 使用者可设置的最大电压 |
| `regulator-microvolt-offset` | `int` | 为补偿压降而施加到电压上的偏移 |
| `regulator-init-microamp` | `int` | 初始化时设置的电流 |
| `regulator-min-microamp` | `int` | 使用者可设置的最小电流 |
| `regulator-max-microamp` | `int` | 使用者可设置的最大电流 |
| `regulator-input-current-limit-microamp` | `int` | 稳压器允许的最大输入电流 |

其中 `regulator_common_init` 是公共初始化函数，`is_enabled` 是用于表示已启用状态的参数标志。

## 519.2\_启动状态、旁路与性能配置

**引导加载程序（Bootloader）**可能在操作系统启动前已启用稳压器。下面几个属性分别描述持续启用、启动时状态以及允许运行时配置的能力。

| 属性 | 类型 | 中文说明 |
| --- | --- | --- |
| `regulator-always-on` | `boolean` | 稳压器永远不应被禁用 |
| `regulator-boot-on` | `boolean` | 引导加载程序或固件已启用稳压器，预期它被留在开启状态；若引导程序未开启，操作系统应在启动时开启，但不阻止以后关闭。此属性只用于软件无法读取稳压器状态的情况 |
| `regulator-boot-off` | `boolean` | 启动时应禁用稳压器 |
| `regulator-allow-bypass` | `boolean` | 允许进入旁路模式（Bypass Mode） |
| `regulator-allow-set-load` | `boolean` | 允许配置稳压器性能等级（Performance Level） |

## 519.3\_斜坡、建立时间与软启动

电压转换涉及**斜坡（Ramp）**和达到目标后所需的**建立时间（Settling Time）**。带 `us` 的时间属性使用**微秒（Microsecond，µs）**；斜坡速率属性则使用 µV/µs，不能混用。

| 属性 | 类型 | 中文说明 |
| --- | --- | --- |
| `regulator-ramp-delay` | `int` | 稳压器斜坡延迟参数，单位 µV/µs；支持禁用斜坡速率的硬件应显式写 `regulator-ramp-delay = <0>` 来禁用斜坡延迟 |
| `regulator-enable-ramp-delay` | `int` | 电源轨达到目标电压及板级容差所需的总时间，单位微秒；包括稳压器内部斜坡以及走线电容、供电负载等板级因素 |
| `regulator-settling-time-us` | `int` | 当任意幅度电压变化均需固定时间时的建立时间，单位微秒；适用于指数式电压变化 |
| `regulator-settling-time-up-us` | `int` | 当任意幅度电压上升均需固定时间时的建立时间，单位微秒；适用于指数式电压变化 |
| `regulator-settling-time-down-us` | `int` | 当任意幅度电压下降均需固定时间时的建立时间，单位微秒；适用于指数式电压变化 |
| `regulator-soft-start` | `boolean` | 启用软启动（Soft Start），使电压缓慢上升 |

> 译注：原文把 `regulator-ramp-delay` 称为 delay，但给定单位是电压变化率 µV/µs。译文保留名称和单位，不把它换算成普通时间延迟。

## 519.4\_模式、系统负载与下拉

**工作模式（Operating Mode）**的具体取值取决于硬件能力，各设备绑定说明其支持值。

| 属性 | 类型 | 中文说明 |
| --- | --- | --- |
| `regulator-initial-mode` | `int` | 初始工作模式；可用值由具体硬件能力与绑定规定 |
| `regulator-allowed-modes` | `array` | 软件在运行时获准配置的工作模式列表，元素可按任意顺序列出，支持值由具体硬件绑定规定 |
| `regulator-system-load` | `int` | 稳压器上没有被任何使用者请求计入的负载，单位微安 |
| `regulator-pull-down` | `boolean` | 稳压器禁用时启用下拉电阻（Pull-Down Resistor） |
| `regulator-over-current-protection` | `boolean` | 启用过流保护（Over-Current Protection） |

## 519.5\_过流保护、错误和警告阈值

以下阈值分为三类：**保护（Protection）**达到时硬件紧急关断；**错误（Error）**表示部分硬件可能已异常，需要防止损坏；**警告（Warning）**表示硬件仍可工作但接近损坏边界，应开始恢复操作。

各属性都可取 `0` 禁用相应保护或检测；取 `1` 表示启用相应功能，但允许省略阈值设置。下表逐项保留这种约定。

| 属性 | 类型 | 中文说明 |
| --- | --- | --- |
| `regulator-oc-protection-microamp` | `int` | 过流保护阈值，达到时紧急关断；`0` 禁用保护，`1` 启用而可不设置阈值 |
| `regulator-oc-error-microamp` | `int` | 过流错误阈值，表示部分硬件可能异常，需要防止损坏；`0` 禁用错误检测，`1` 启用而可不设置阈值 |
| `regulator-oc-warn-microamp` | `int` | 过流警告阈值，表示硬件仍可工作但接近损坏，应开始恢复；`0` 禁用检测，`1` 启用而可不设置阈值 |

属性名中的 `oc` 指过流（Over Current），单位微安。

## 519.6\_过压与欠压阈值

**过压（Over Voltage，OV）**与**欠压（Under Voltage，UV）**阈值均以相对稳压器已设置电压的**微伏偏移量**给出。这里不是绝对输出电压；原文没有进一步指定偏移的符号约定。

| 属性 | 类型 | 中文说明 |
| --- | --- | --- |
| `regulator-ov-protection-microvolt` | `int` | 过压保护阈值，达到时紧急关断；`0` 禁用保护，`1` 启用而可不设置阈值 |
| `regulator-ov-error-microvolt` | `int` | 过压错误阈值，表示部分硬件可能异常，需要防止损坏；`0` 禁用错误检测，`1` 启用而可不设置阈值 |
| `regulator-ov-warn-microvolt` | `int` | 过压警告阈值，表示硬件仍可工作但接近损坏，应开始恢复；`0` 禁用检测，`1` 启用而可不设置阈值 |
| `regulator-uv-protection-microvolt` | `int` | 欠压保护阈值，达到时紧急关断；`0` 禁用保护，`1` 启用而可不设置阈值 |
| `regulator-uv-error-microvolt` | `int` | 欠压错误阈值，表示部分硬件可能异常，需要防止损坏；`0` 禁用错误检测，`1` 启用而可不设置阈值 |
| `regulator-uv-warn-microvolt` | `int` | 欠压警告阈值，表示硬件仍可工作但接近损坏，应开始恢复；`0` 禁用检测，`1` 启用而可不设置阈值 |

> 译注：原页两项欠压属性的说明写成 “over under voltage”，按 `uv` 名称和同组属性译为欠压。

## 519.7\_温度阈值

温度属性以**开尔文（Kelvin，K）**为单位，使用与前述相同的保护、错误和警告分级。

| 属性 | 类型 | 中文说明 |
| --- | --- | --- |
| `regulator-temp-protection-kelvin` | `int` | 过温保护阈值，达到时硬件紧急关断；`0` 禁用保护，`1` 启用而可不设置阈值 |
| `regulator-temp-error-kelvin` | `int` | 过温错误阈值，表示部分硬件可能异常，需要防止损坏；`0` 禁用错误检测，`1` 启用而可不设置阈值 |
| `regulator-temp-warn-kelvin` | `int` | 过温警告阈值，表示硬件仍可工作但接近损坏，应开始恢复；`0` 禁用检测，`1` 启用而可不设置阈值 |

## 519.8\_主动放电与切换时间

**主动放电（Active Discharge）**使用三态配置：明确关闭、明确开启或保留默认。

| 属性 | 类型 | 中文说明 |
| --- | --- | --- |
| `regulator-active-discharge` | `int` | 合法值为 `0`、`1`；`0` 禁用主动放电，`1` 启用，不提供属性则使用默认配置 |
| `regulator-max-step-microvolt` | `int` | 单步安全改变电压时，当前电压与目标电压之间允许的最大差值，单位微伏 |
| `startup-delay-us` | `int` | 启动时间，单位微秒 |
| `off-on-delay-us` | `int` | 从关闭到开启的延迟，单位微秒 |

## 519.9\_独立电源开关与共享稳压器

`supply-gpios` 的类型为 `phandle-array`，是控制设备电源的**通用输入输出（General-Purpose Input/Output，GPIO）**说明符。设备有专用供电开关时应提供此属性，供电状态完全由设备驱动负责。

`vin-supply` 的类型为 `phandle`，引用控制设备电源的稳压器。被引用设备树节点必须使用稳压器兼容字符串；设备由共享稳压器供电时应提供此属性，供电状态取决于所有受供电设备的请求状态。

`phandle` 是设备树节点引用，`phandle-array` 携带节点引用及其说明单元。若两个供电属性同时存在，必须**先请求稳压器，再将供电 GPIO 设为有效状态；关闭时先使供电 GPIO 无效，再释放稳压器请求**。
