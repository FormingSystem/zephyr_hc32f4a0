# 第60章\_一次性可编程存储入口

原文：[One Time Programmable (OTP) memory devices](https://docs.zephyrproject.org/latest/hardware/peripherals/otp/index.html)。读取日期：2026-10-13，`latest`。

## 60.1\_用于永久保存的数据

**一次性可编程存储器（One Time Programmable Memory，OTP）**设备处理预期永久保存的数据。这类内存通常在制造阶段进行 **预置（Provisioning）**，但也有一些场景需要在生命周期后续阶段编程，例如 **单调计数器（Monotonic Counter）**或 **密码学密钥（Cryptographic Key）**。

这里的“后续阶段编程”是原文描述的使用场景，并不表示已经编程的存储位可以像普通随机存取存储器那样反复覆盖；实际允许的编程动作以设备能力为准。

## 60.2\_接口文档入口
