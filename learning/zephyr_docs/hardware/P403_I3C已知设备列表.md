# 第403章\_I3C已知设备列表

原文：[structi3c__dev__list](https://docs.zephyrproject.org/latest/doxygen/html/structi3c__dev__list.html)。读取日期：2026-10-13，`latest`。

## 403.1\_已知设备数组

`struct i3c_dev_list` 为控制器描述已知设备，保存已知的**改进的集成电路间总线（Improved Inter-Integrated Circuit，I3C）**与**集成电路间总线（Inter-Integrated Circuit，I2C）**设备数组。它是供控制器驱动辅助设备管理的结构。头文件为 `zephyr/drivers/i3c.h`。

## 403.2\_字段

| 字段 | 类型 | 含义 |
| --- | --- | --- |
| [`i3c`](https://docs.zephyrproject.org/latest/doxygen/html/structi3c__dev__list.html#aba1871e32e1ee9e6a809dd11a7a44dce) | `struct i3c_device_desc *const` | 指向已知 I3C 设备数组的指针。 |
| [`i2c`](https://docs.zephyrproject.org/latest/doxygen/html/structi3c__dev__list.html#a7993101f7b5fa3961773f58fd8b1985e) | `struct i3c_i2c_device_desc *const` | 指向已知 I2C 设备数组的指针。 |
| [`num_i3c`](https://docs.zephyrproject.org/latest/doxygen/html/structi3c__dev__list.html#ab13b77da61fc829c3f6414963f5f2985) | `const uint8_t` | 数组中 I3C 设备的数量。 |
| [`num_i2c`](https://docs.zephyrproject.org/latest/doxygen/html/structi3c__dev__list.html#ae1b33a38150098463187d4016e31b318) | `const uint8_t` | 数组中 I2C 设备的数量。 |

> 译注：两项数组成员的 `const` 位于星号之后，限定的是指针本身；本页保留原字段类型的位置关系。
