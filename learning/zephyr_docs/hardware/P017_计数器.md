# 第17章\_计数器

原文：[Counter](https://docs.zephyrproject.org/latest/hardware/peripherals/counter.html)。读取日期：2026-10-12，`latest`。

本页是**计数器（Counter）**的官方参考入口，原文“概述”标题下没有额外说明。完整接口见[计数器参考](https://docs.zephyrproject.org/latest/doxygen/html/group__counter__interface.html)。

原页关联两个示例：

- [计数器闹钟](https://docs.zephyrproject.org/latest/samples/drivers/counter/alarm/README.html)：使用计数器接口实现闹钟应用。
- [MCXE31B 系统待机](https://docs.zephyrproject.org/latest/samples/boards/nxp/frdm_mcxe31b/system_off/README.html)：使用 FRDM-MCXE31B 唯一的低功耗待机模式，并经 **实时时钟（Real-Time Clock，RTC）** 闹钟唤醒。
