# 第514章\_单元测试统计结构

原文：[structztest__unit__test__stats](P514_单元测试统计结构.md)。读取日期：2026-10-13，`latest`。

`struct ztest_unit_test_stats` 保存**单元测试统计（Unit Test Statistics）**，包括各类结果次数及多次运行中的最长耗时。

公开头文件为 `zephyr/ztest_test.h`，源码位置为 `subsys/testsuite/ztest/include/zephyr/ztest_test.h`。原文构建机的绝对包含路径在这里改为公开包含名。

## 514.1\_结果计数与最长耗时

原页列出的五个字段都使用 32 位无符号整数。

| 字段声明 | 官方说明译文 |
| --- | --- |
| `uint32_t run_count` | 测试运行次数 |
| `uint32_t skip_count` | 测试跳过次数 |
| `uint32_t fail_count` | 测试失败次数 |
| `uint32_t pass_count` | 测试通过次数 |
| `uint32_t duration_worst_ms` | 测试多次运行中的最长持续时间 |

> 译注：[`duration_worst_ms`](P514_单元测试统计结构.md) 字段名中的 `ms` 表示毫秒（Millisecond）。它记录最长时间，不是累计时间或平均时间。
