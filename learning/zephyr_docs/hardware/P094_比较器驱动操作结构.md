# 第94章\_比较器驱动操作结构

原文：[structcomparator__driver__api](https://docs.zephyrproject.org/latest/doxygen/html/structcomparator__driver__api.html)。读取日期：2026-10-13，`latest`。

## 94.1\_比较器操作表

`struct comparator_driver_api` 是每个 **比较器（Comparator）**驱动需要定义的 **应用程序编程接口（Application Programming Interface，API）**结构。它保存驱动操作的函数指针，以及驱动特定的其他常量数据；官方声明与本页生成来源均为 `zephyr/drivers/comparator.h`。

原文用 **必需项（Required，REQ）**表示驱动必须设置的成员，用 **可选项（Optional，OPT）**表示可选成员。本结构列出的四项均为REQ。
