# 第408章\_I3C实时输入输出结构

原文：[structi3c__rtio](https://docs.zephyrproject.org/latest/doxygen/html/structi3c__rtio.html)。读取日期：2026-10-13，`latest`。

## 408.1\_驱动上下文

`struct i3c_rtio` 是使用**实时输入/输出（Real-Time Input/Output，RTIO）**实现**改进的集成电路间总线（Improved Inter-Integrated Circuit，I3C）**的驱动上下文（Driver Context）。包含头文件 `zephyr/drivers/i3c/rtio.h`。

## 408.3\_类型阅读说明

> 译注：以下仅解释声明中出现的类型，不把名称推断当作原文未给出的行为保证。

- [`k_sem`](../synchronization_reference/P009_内核信号量结构.md) 是**信号量（Semaphore）**类型，[`k_spinlock`](../kernel/P066_自旋锁结构参考.md) 是**自旋锁（Spinlock）**类型。
- [`rtio`](../rtio_model_reference/P001_RTIO上下文.md) 是 RTIO 上下文类型，[`rtio_iodev`](../rtio_model_reference/P003_RTIO输入输出设备.md) 是 RTIO 输入/输出设备类型。
- [`mpsc`](../intercore_reference/P159_MPSC无锁队列结构.md) 表示**多生产者单消费者（Multiple Producer, Single Consumer，MPSC）**队列类型。
- [`rtio_iodev_sqe`](../rtio_model_reference/P005_RTIO设备提交条目.md) 表示设备侧的**提交队列项（Submission Queue Entry，SQE）**类型；两个成员均保存指向该类型的指针。
- [`i3c_device_desc`](https://docs.zephyrproject.org/latest/doxygen/html/structi3c__device__desc.html) 是 [I3C 目标设备描述符](P401_I3C设备描述符.md)。
