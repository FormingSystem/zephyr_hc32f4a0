# 第165章\_通用步进电机示例

原文：[Stepper](https://docs.zephyrproject.org/latest/samples/drivers/stepper/generic/README.html)。读取日期：2026-10-13，`latest`。

## 165.1\_说明（Description）

本示例演示如何使用 **步进电机（Stepper Motor）**驱动的 **应用程序编程接口（Application Programming Interface，API）**控制电机，包括旋转、使能、禁用和停止，并将事件输出到控制台（Console）。

电机可采用四种运动模式：相对位置往返运动（`ping_pong_relative`）、绝对位置往返运动（`ping_pong_absolute`）、连续顺时针旋转（`continuous_clockwise`）和连续逆时针旋转（`continuous_anticlockwise`）。**微步（Microstep）**间隔以纳秒为单位，通过 `CONFIG_STEP_INTERVAL_NS` 配置。示例还演示利用步进电机回调函数（Callback）在走过一定步数后改变方向。

按任意按钮应切换当前模式，并将模式输出到控制台。支持的模式包括：

| 模式标识 | 含义 |
| --- | --- |
| `enable` | 使能电机。 |
| `ping_pong_relative` | 按相对位置往返运动。 |
| `ping_pong_absolute` | 按绝对位置往返运动。 |
| `rotate_cw` | 顺时针（Clockwise，CW）旋转。 |
| `rotate_ccw` | 逆时针（Counterclockwise，CCW）旋转。 |
| `stop` | 停止运动。 |
| `disable` | 禁用电机。 |

示例还包含一个监控线程（Monitor Thread），每隔 `CONFIG_MONITOR_THREAD_TIMEOUT_MS` 毫秒打印一次电机的实际位置。

## 165.2\_构建与运行（Building and Running）

此应用使电机旋转，并把事件输出到控制台。译注：在已配置 Zephyr 开发环境的终端中，从 Zephyr 源码根目录执行下列官方命令；示例源码由官方仓库提供，west 生成构建产物，`west flash` 将固件烧录到所选开发板。

```bash
# From the root of the zephyr repository
west build -b nucleo_g071rb samples/drivers/stepper/generic
west flash
```
