# 第67章\_管理数据输入输出

原文：[Management Data Input/Output (MDIO)](https://docs.zephyrproject.org/latest/hardware/peripherals/mdio.html)。读取日期：2026-10-13，`latest`。

## 67.1\_连接以太网物理层设备

**管理数据输入／输出（Management Data Input/Output，MDIO）**是一种常用于与以太网 **物理层（Physical Layer，PHY）**设备通信的总线。许多以太网 **媒体访问控制（Media Access Control，MAC）**控制器也提供通过MDIO总线与外设通信的硬件。

## 67.2\_接口使用者

这套 **应用程序编程接口（Application Programming Interface，API）**主要供PHY驱动使用，也可由用户固件使用。具体函数、参数及能力见[MDIO接口参考](https://docs.zephyrproject.org/latest/doxygen/html/group__mdio__interface.html)。

原页没有给出命令、初始化程序或示意图；本页保留其接口职责说明，不将管理总线读写等同于以太网数据帧收发。
