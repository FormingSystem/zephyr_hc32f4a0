# 第121章\_电池充电示例

原文：[Charger](https://docs.zephyrproject.org/latest/samples/drivers/charger/README.html)。读取日期：2026-10-13，`latest`。

## 121.1\_简单充电任务循环

本示例演示 **充电器（Charger）**的 **应用程序编程接口（Application Programming Interface，API）**，运行一个简单充电任务循环。接口概览见[充电器](P107_充电器.md)。

程序先轮询充电器是否得到外部供电。如果已有供电，就尝试启用 **充电周期（Charge Cycle）**。充电开始后，程序检查充电器设备的状态属性，并把相关信息写入日志。当设备报告充电周期完成后，应用返回并结束。

## 121.2\_示例有意保留的处理边界

本示例在充电周期完成后终止，不尝试对电池组执行 **补充充电（Top-Off）**。

另外，示例有意不响应所报告的 **充电器健康状态（Charger Health State）**，也不处理环境对充电周期执行的影响。原文明确，这些事件的响应责任由使用者或充电器设备实现承担。

## 121.3\_接口与源码

完整声明见[电池充电器API](https://docs.zephyrproject.org/latest/doxygen/html/group__charger__interface.html)，源码见[官方充电器示例目录](https://github.com/zephyrproject-rtos/zephyr/tree/main/samples/drivers/charger)。原页未提供构建命令或运行输出；本章未实际启动充电周期。
