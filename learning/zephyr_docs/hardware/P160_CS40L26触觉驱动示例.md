# 第160章\_CS40L26触觉驱动示例

原文：[CS40L26 Haptic Driver](https://docs.zephyrproject.org/latest/samples/drivers/haptics/cs40l26/README.html)。读取日期：2026-10-13，`latest`。

## 160.1\_概述（Overview）

CS40L26/27 是面向移动应用的触觉驱动器系列。本示例使用该芯片驱动 **线性谐振执行器（Linear Resonant Actuator，LRA）**，展示 **只读存储器（Read-Only Memory，ROM）**中的功能，包括内置效果和嗡鸣效果（Buzz Effects）。

示例提供自定义的 **命令行交互界面（Shell）**，供用户调用 CS40L26/27 的 **应用程序编程接口（Application Programming Interface，API）**。不使用 Shell 时，示例执行基本功能演示。

## 160.2\_构建与运行（Building and Running）

为 Nucleo F401RE 开发板构建应用。将 CS40L26/27 触觉驱动器连接到 **内部集成电路总线（Inter-Integrated Circuit，I2C）**的 I2C1 控制器，器件地址为 `0x40`。

译注：以下是官方构建命令；在已完成 Zephyr 开发环境配置并激活对应环境的终端中，从 Zephyr 源码根目录执行。示例源码由官方仓库提供，构建产物由 west 生成。

```bash
west build -b nucleo_f401re samples/drivers/haptics/cs40l26
```

烧录应用的方法见[Nucleo F401RE开发板说明](https://docs.zephyrproject.org/latest/boards/st/nucleo_f401re/doc/index.html#nucleo_f401re)的烧录（Flashing）小节。
