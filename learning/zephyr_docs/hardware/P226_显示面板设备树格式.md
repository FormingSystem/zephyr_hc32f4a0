# 第226章\_显示面板设备树格式

原文：[group__display__panel__dt](https://docs.zephyrproject.org/latest/doxygen/html/group__display__panel__dt.html)。读取日期：2026-10-13，`latest`。

## 226.1\_用途

本页定义 **设备树（Devicetree，DT）**中的显示面板像素格式位掩码（Bitmask），声明来自官方头文件 `zephyr/dt-bindings/display/panel.h`。

每个 `PANEL_PIXEL_FORMAT_*` 宏使用与[显示公共接口](P214_显示公共接口.md)中 [`display_pixel_format`](https://docs.zephyrproject.org/latest/doxygen/html/group__display__interface.html#gac346bc56771052a8fe919c3ec23d7c9c) 枚举对应 `PIXEL_FORMAT_*` 项相同的位位置。提供这些宏，是因为 C 枚举常量不能用于设备树源文件。

## 226.2\_像素格式宏

RGB 表示红、绿、蓝（Red, Green, Blue），BGR 表示蓝、绿、红（Blue, Green, Red）；A 是透明度（Alpha），X 是未使用分量（Unused），L 是亮度（Luminance），I 是索引色（Indexed Color）。ARGB、ABGR、RGBA、BGRA、XRGB 的字母表示对应分量排列；YUV 表示亮度 Y 与两个色度（Chrominance）分量 U/V，YUYV 表示打包顺序。

## 226.3\_颜色打包宏

宏 `ARGB8888(r, g, b, a)` 把颜色分量打包为 32 位 ARGB8888 值，即透明度、红、绿、蓝（Alpha, Red, Green, Blue）各 8 位，供设备树文件指定颜色。参数顺序为 `r`、`g`、`b`、`a`，依次是红色、绿色、蓝色、透明度分量，每项范围均为 0～255。

原展开式如下，按位或运算符为 `|`：

```c
(((b) << 0) | ((g) << 8) | ((r) << 16) | ((a) << 24))
```

## 226.4\_调色板空值

宏 [`PANEL_COLOR_PALETTE_NULL`](https://docs.zephyrproject.org/latest/doxygen/html/group__display__panel__dt.html#gaae0ff2b3e7c3ed70ca578750595d630b) 的值为 `0`。调色板索引不连续时，用它填充空条目（Empty Entry）。
