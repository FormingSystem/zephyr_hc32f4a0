# 第153章\_CS40L5x触觉扩展

原文：[group__cs40l5x__interface](https://docs.zephyrproject.org/latest/doxygen/html/group__cs40l5x__interface.html)。读取日期：2026-10-13，`latest`。

## 153.1\_接口与执行器

CS40L5x触觉驱动支持 **线性谐振执行器（Linear Resonant Actuator，LRA）**与 **音圈电机（Voice Coil Motor，VCM）**。其 **应用程序编程接口（Application Programming Interface，API）**头文件为 `zephyr/drivers/haptics/cs40l5x.h`。

原页列出 [`cs40l5x_pwle_section`](P156_CS40L5x包络段结构.md) 结构。PWLE为 **分段线性包络（Piecewise Linear Envelope）**，相关术语展开见[Cirrus Logic官方配置指南](https://statics.cirrus.com/pubs/manual/CS40L5x_Configuration_User_Guide.pdf)；其段结构成员另见[结构参考](P156_CS40L5x包络段结构.md)。

## 153.3\_配置ROM嗡鸣

**只读存储器（Read-Only Memory，ROM）**嗡鸣配置函数为：

```c
int cs40l5x_configure_buzz(const struct device *const dev,
                          const uint32_t frequency,
                          const uint8_t level,
                          const uint32_t duration);
```

所有参数均为输入。`dev` 指向设备；`frequency` 为Hz频率，默认 `0xF0`；`level` 为振幅，`UINT8_MAX` 对应100%，默认 `0x1B`；`duration` 为**毫秒数**，0表示无限持续，默认 `0x32`。

大振幅且供电不足时（例如某些内部升压配置），可能引发 **升压错误（Boost Error）**。成功返回0，失败返回负错误码；`-EIO` 明确表示控制端口事务失败。

## 153.4\_配置边沿触发效果

```c
int cs40l5x_configure_trigger(const struct device *const dev,
                            const struct gpio_dt_spec *const gpio,
                            const enum haptics_source src,
                            const union haptics_config *const cfg,
                            const enum cs40l5x_attenuation attenuation,
                            const enum cs40l5x_trigger_edge edge);
```

函数 [`cs40l5x_configure_trigger()`](https://docs.zephyrproject.org/latest/doxygen/html/group__cs40l5x__interface.html#gac6d8832a9952f2e63ec3f5ad0fa6b057) 的输入参数中，`dev` 指向设备；`gpio` 指向作为触发源的 **通用输入输出（General-Purpose Input/Output，GPIO）**规格；`src` 为播放源；`cfg` 为源配置；`attenuation` 为目标效果衰减量；`edge` 指定上升沿或下降沿。

成功返回0，失败返回负错误码；`-EINVAL` 表示波形表源或索引无效，例如索引越界；`-EIO` 表示控制端口事务失败。

## 153.5\_上传PCM效果

**脉冲编码调制（Pulse-Code Modulation，PCM）**效果上传到指定索引：

```c
int cs40l5x_upload_pcm(const struct device *const dev, const int index,
                      const uint16_t redc, const uint16_t f0,
                      const int8_t *const samples, const uint16_t num_samples);
```

所有参数均为输入：`dev` 为设备，`index` 为波形表索引，`samples` 指向有符号8位PCM样本数组，`num_samples` 为样本数。补偿参数按原文保留如下：

- `redc`：ReDC补偿，使用无符号 **Q格式定点数（Q-Format Fixed-Point Number）** Q5.7；原参数说明同时列出 `redc * (24 / 2.9)`。
- `f0`：F0补偿，使用无符号Q9.3；原参数说明列出 `(f0 - 50) * 8`。

译注：以上格式和表达式照录原页；实际编码时应对照器件头文件及驱动约定核对。成功返回0，失败返回负错误码；索引无效或越界返回 `-EINVAL`，控制端口事务失败返回 `-EIO`。

## 153.6\_上传分段线性包络效果

```c
int cs40l5x_upload_pwle(const struct device *const dev, const int index,
                       const struct cs40l5x_pwle_section *const sections,
                       const uint8_t num_sections);
```

函数 [`cs40l5x_upload_pwle()`](https://docs.zephyrproject.org/latest/doxygen/html/group__cs40l5x__interface.html#ga0283ec128debbc6ece55637e0fb79346) 的输入参数中，`dev` 为设备，`index` 为波形表索引，`sections` 指向 [`cs40l5x_pwle_section`](P156_CS40L5x包络段结构.md) 数组，`num_sections` 为段数。成功返回0，失败返回负错误码；索引无效或越界返回 `-EINVAL`，控制端口事务失败返回 `-EIO`。
