# 第39章\_熵源接口参考

原文：[group__entropy__interface](https://docs.zephyrproject.org/latest/doxygen/html/group__entropy__interface.html)。读取日期：2026-10-13，`latest`。

## 39.1\_接口与调用环境

本页说明 **熵（Entropy）**硬件的 **应用程序编程接口（Application Programming Interface，API）**。接口自Zephyr 1.10引入，版本为1.0.0；主头文件为官方源码中的 `zephyr/drivers/entropy.h`。熵用于随机数子系统和密码服务，不能直接把这些接口当作应用随机数生成函数，参见[熵源](P034_熵源.md)。驱动实现见[熵源驱动后端API](P048_熵源驱动后端接口.md)。

<a id="ga66612f1a595aa9d67e51f2b1175edbef"></a>

## 39.2\_取得默认设备

[`entropy_get_default_device()`](https://docs.zephyrproject.org/latest/doxygen/html/group__entropy__interface.html#ga66612f1a595aa9d67e51f2b1175edbef) 返回可用的默认熵设备：

```c
static inline const struct device *entropy_get_default_device(void);
```

查找顺序为：首先选择设备树中 `zephyr,entropy` 指定的设备（如果存在）；其次选择已启用的架构熵设备；均不存在则返回 `NULL`。返回结果因此是默认设备指针或空指针。

> 译注：取得设备指针与检查设备已经就绪是不同动作；该辅助函数本身不执行 `device_is_ready()` 检查。不要仅凭非空指针就推断设备初始化已成功。

<a id="ga54de6cd85d5c557ca91f425944e50ce6"></a>

## 39.3\_填充普通缓冲区

[`entropy_get_entropy()`](https://docs.zephyrproject.org/latest/doxygen/html/group__entropy__interface.html#ga54de6cd85d5c557ca91f425944e50ce6) 用熵数据填满缓冲区。为产生所需随机数据，必要时会 **阻塞（Block）**。

```c
int entropy_get_entropy(const struct device *dev,
                        uint8_t *buffer, uint16_t length);
```

| 参数 | 含义 |
| --- | --- |
| `dev` | 熵设备指针。 |
| `buffer` | 待填入熵数据的缓冲区。 |
| `length` | 缓冲区长度，按字节计。 |

成功返回0，出错返回负错误码。原文将错误返回写作 `-ERRNO`，这是错误码的概括表示，不是要求调用者比较一个名为 `ERRNO` 的特定错误。

<a id="ga71b99316bec395a7078b26e44f20fc9a"></a>

## 39.4\_在中断环境中获取熵

[`entropy_get_entropy_isr()`](https://docs.zephyrproject.org/latest/doxygen/html/group__entropy__interface.html#ga71b99316bec395a7078b26e44f20fc9a) 以非阻塞或 **忙等待（Busy-Wait）**方式填充缓冲区，可从 **中断服务程序（Interrupt Service Routine，ISR）**调用。

```c
static inline int entropy_get_entropy_isr(const struct device *dev,
                                          uint8_t *buffer, uint16_t length,
                                          uint32_t flags);
```

<a id="gade7a19930b671f6924ee89f700bad2ef"></a>

`dev` 为设备结构指针，`buffer` 为待填充缓冲区，`length` 为缓冲区字节长度，[`flags`](https://docs.zephyrproject.org/latest/doxygen/html/parser_8h.html#ab6b306ef981f5e21bb41ea2c2dbe8cd9) 用于调整本次调用行为。其中宏 [`ENTROPY_BUSYWAIT`](https://docs.zephyrproject.org/latest/doxygen/html/group__entropy__interface.html#gade7a19930b671f6924ee89f700bad2ef) 的值为 `BIT(0)`；在 [`flags`](https://docs.zephyrproject.org/latest/doxygen/html/parser_8h.html#ab6b306ef981f5e21bb41ea2c2dbe8cd9) 中设置它，表示允许驱动忙等待随机数据就绪。

函数返回**实际填充的字节数**，失败返回负错误码。驱动没有实现该函数时返回 `-ENOSYS`。与上一节成功返回0的接口不同，调用者要依据这里实际返回的长度使用数据，不能直接认定请求的整个缓冲区都已填满。

> 译注：忙等待仍占用当前执行上下文；它不等同于线程睡眠或让调度器把当前线程挂起。选择ISR接口时，应结合驱动支持和中断执行时间要求处理该差别。
