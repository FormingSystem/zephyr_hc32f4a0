# 第196章\_LP586x灯矩阵示例

原文：[LP586x LED matrix](https://docs.zephyrproject.org/latest/samples/drivers/led/lp586x/README.html)。读取日期：2026-10-13，`latest`。

## 196.1\_概述（Overview）

本示例控制连接到 LP586x 矩阵控制器上的 **发光二极管（Light-Emitting Diode，LED）**灯点（LED Dot）。该系列通过 **内部集成电路总线（Inter-Integrated Circuit，I2C）**通信，具有 18 路 **恒流灌电流输出（Constant Current Sink）**和可配置数量的扫描线（Scan Line）。

| 器件 | 扫描线数 | LED灯点数量 |
| --- | --- | --- |
| LP5861 | 1 | 18 |
| LP5862 | 2 | 36 |
| LP5864 | 4 | 72 |
| LP5866 | 6 | 108 |
| LP5868 | 8 | 144 |
| LP5860 | 11 | 198 |

首先读取并打印每个已配置 LED 节点的信息，然后无限循环执行三种图案，调用相应的 **应用程序编程接口（Application Programming Interface，API）**：

1. 通道测试（Channel Test）：用 [`led_write_channels()`](P202_LED公共接口.md) 同时使所有灯点从熄灭渐亮到最高亮度。
2. LED 亮度测试（LED Brightness Test）：逐个处理已配置节点，用 [`led_set_brightness()`](P202_LED公共接口.md) 使每个单色 LED 渐亮，再用 [`led_off()`](P202_LED公共接口.md) 关闭。
3. LED 颜色测试（LED Color Test）：逐个处理已配置节点，用 [`led_set_color()`](P202_LED公共接口.md) 使每个多色 LED 的各颜色通道逐渐变亮。

## 196.2\_I2C寻址（I2C Addressing）

LP586x 使用非标准的寻址方式：把 10 位寄存器地址的最高 2 位嵌入 7 位 I2C 器件地址。

7 位地址格式为 `[CA4:CA0][RA9:RA8]`，其中 `CA[4:0]` 由硬件 ADDR 地址引脚配置，`RA[9:8]` 选择寄存器页（Register Page）。

**设备树源（Devicetree Source，DTS）**节点的 `reg` 属性必须指定第 0 页基地址，也就是 `RA[9:8] = 00`。驱动会自动计算访问第 1 页和第 2 页时的正确器件地址。

## 196.3\_LED节点配置（LED Node Configuration）

每个子节点表示一个 LED，或者一组连续灯点：

- `index`：该节点第一个灯点的索引，按 `line_number * 18 + sink_number` 计算，即扫描线编号乘以 18，再加灌电流输出编号。
- `color-mapping`：颜色映射，每个灯点对应一个条目；单色灯点使用 `LED_COLOR_ID_WHITE`。

## 196.4\_构建与运行（Building and Running）

此示例需要连接到 I2C 总线的 LP586x 矩阵控制器。根据开发板的 I2C 总线别名（Alias）和硬件地址调整叠加文件（Overlay）。

官方在示例目录中提供 `boards/arduino_i2c.overlay`，适用于带 Arduino 兼容 I2C 连接器的开发板。它在地址 `0x40` 上配置一个 LP5864，此时 `CA[4:0] = 0b10000`，并定义六个 LED 节点。
