# 第19章\_复位控制器

原文：[Reset Controller](https://docs.zephyrproject.org/latest/hardware/peripherals/reset.html)。读取日期：2026-10-12，`latest`。

**复位控制器（Reset Controller）**管理多个外设的复位信号。接口允许外设驱动控制自身复位输入，包括置有效、解除有效、执行复位切换，以及查询复位状态。

原文说明，`line_assert` 与 `line_deassert` 操作可以是可选的，因为大多数场景只需要一次完整复位切换。

相关配置为 `CONFIG_RESET`。完整声明见[复位控制器接口](../reset_reference/P001_复位控制器公共接口.md)。

> 译注：“置有效”不固定表示输出高电平，实际有效电平由硬件定义；外设复位线也不等同于整个 **片上系统（System on Chip，SoC）** 的系统复位。
