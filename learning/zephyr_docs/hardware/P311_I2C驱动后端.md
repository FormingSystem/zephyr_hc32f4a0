# 第311章\_I2C驱动后端

原文：[group__i2c__interface__backend](https://docs.zephyrproject.org/latest/doxygen/html/group__i2c__interface__backend.html)。读取日期：2026-10-13，`latest`。

## 311.1\_接口范围

本组包含实现集成电路间总线（Inter-Integrated Circuit，I²C）驱动所需的接口类型、回调（Callback）签名及辅助定义，声明来自 `zephyr/drivers/i2c.h`。操作分别由 [`i2c_driver_api`](https://docs.zephyrproject.org/latest/doxygen/html/structi2c__driver__api.html) 和 [`i2c_target_driver_api`](https://docs.zephyrproject.org/latest/doxygen/html/structi2c__target__driver__api.html) 组织，参见[I2C驱动函数表](P312_I2C驱动函数表.md)及[I2C目标驱动函数表](P315_I2C目标驱动函数表.md)。

实时输入/输出（Real-Time Input/Output，RTIO）请求通过输入输出设备对象（I/O Device，iodev）提交，其队列条目为提交队列条目（Submission Queue Entry，SQE）。

## 311.2\_回调类型

以下类型的参数说明均对应[I2C公共接口](P305_I2C公共接口.md)中的同名操作。

<a id="ga1f56e22fef350c2b6e122d9f73b715cb"></a>

回调类型 [`i2c_api_configure_t`](https://docs.zephyrproject.org/latest/doxygen/html/group__i2c__interface__backend.html#ga1f56e22fef350c2b6e122d9f73b715cb) 用于配置I²C控制器；参数参见 [`i2c_configure()`](https://docs.zephyrproject.org/latest/doxygen/html/group__i2c__interface.html#ga75326a6f38c011d35df9f3e72f2259e9)。

```c
typedef int(* i2c_api_configure_t) (const struct device *dev, uint32_t dev_config);
```

<a id="ga2f48b56cf40b7cf9f92d9d3318f2fd45"></a>

回调类型 [`i2c_api_full_io_t`](https://docs.zephyrproject.org/latest/doxygen/html/group__i2c__interface__backend.html#ga2f48b56cf40b7cf9f92d9d3318f2fd45) 用于以控制器模式传输总线消息；参数参见 [`i2c_transfer()`](https://docs.zephyrproject.org/latest/doxygen/html/group__i2c__interface.html#ga2958e6fe92ffb17851052d5c9a5c058e)。

```c
typedef int(* i2c_api_full_io_t) (const struct device *dev, struct i2c_msg *msgs, uint8_t num_msgs, uint16_t addr);
```

<a id="gae430d1656f278eb2507cd519396dc60e"></a>

回调类型 [`i2c_api_get_config_t`](https://docs.zephyrproject.org/latest/doxygen/html/group__i2c__interface__backend.html#gae430d1656f278eb2507cd519396dc60e) 用于取得控制器当前配置；参数参见 [`i2c_get_config()`](https://docs.zephyrproject.org/latest/doxygen/html/group__i2c__interface.html#ga6858e0f1a942b22964105135c334baed)。

```c
typedef int(* i2c_api_get_config_t) (const struct device *dev, uint32_t *dev_config);
```

<a id="ga080a192ce4936fc117c976abd6b5c1a5"></a>

回调类型 [`i2c_api_iodev_submit`](https://docs.zephyrproject.org/latest/doxygen/html/group__i2c__interface__backend.html#ga080a192ce4936fc117c976abd6b5c1a5) 用于向控制器提交RTIO请求；参数参见 [`i2c_iodev_submit()`](https://docs.zephyrproject.org/latest/doxygen/html/group__i2c__interface.html#ga1d6d1d28f56a9c7c8fde1e6eb056e128)。

```c
typedef void(* i2c_api_iodev_submit) (const struct device *dev, struct rtio_iodev_sqe *iodev_sqe);
```

<a id="gad97d621367079bae753b226c4e673c77"></a>

回调类型 [`i2c_api_recover_bus_t`](https://docs.zephyrproject.org/latest/doxygen/html/group__i2c__interface__backend.html#gad97d621367079bae753b226c4e673c77) 用于恢复I²C总线；参数参见 [`i2c_recover_bus()`](https://docs.zephyrproject.org/latest/doxygen/html/group__i2c__interface.html#ga93117c531c39259d89ab69d52bbde85c)。

```c
typedef int(* i2c_api_recover_bus_t) (const struct device *dev);
```

<a id="gab2332a5759165d4c9e091c18103d6fce"></a>

回调类型 [`i2c_api_target_register_t`](https://docs.zephyrproject.org/latest/doxygen/html/group__i2c__interface__backend.html#gab2332a5759165d4c9e091c18103d6fce) 用于在控制器上注册目标设备；参数参见 [`i2c_target_register()`](https://docs.zephyrproject.org/latest/doxygen/html/group__i2c__interface.html#gaa47c3fde397188fa126dcaa4a6e85b47)。

```c
typedef int(* i2c_api_target_register_t) (const struct device *dev, struct i2c_target_config *cfg);
```

<a id="ga5e536f82d8d09b0ab074bf0d95386867"></a>

回调类型 [`i2c_api_target_unregister_t`](https://docs.zephyrproject.org/latest/doxygen/html/group__i2c__interface__backend.html#ga5e536f82d8d09b0ab074bf0d95386867) 用于从控制器注销目标设备；参数参见 [`i2c_target_unregister()`](https://docs.zephyrproject.org/latest/doxygen/html/group__i2c__interface.html#ga11eada869173f6bd91db39c794dc8979)。

```c
typedef int(* i2c_api_target_unregister_t) (const struct device *dev, struct i2c_target_config *cfg);
```

<a id="ga36459352e4b1b3a18fa7bf096e3f14f0"></a>

回调类型 [`i2c_api_transfer_cb_t`](https://docs.zephyrproject.org/latest/doxygen/html/group__i2c__interface__backend.html#ga36459352e4b1b3a18fa7bf096e3f14f0) 用于异步传输I²C消息；参数参见 [`i2c_transfer_cb()`](https://docs.zephyrproject.org/latest/doxygen/html/group__i2c__interface.html#gaab152d5d68b6542019b77b244c239fee)。

```c
typedef int(* i2c_api_transfer_cb_t) (const struct device *dev, struct i2c_msg *msgs, uint8_t num_msgs, uint16_t addr, i2c_callback_t cb, void *userdata);
```

<a id="ga8747d3491331f7bae4b466d69e222027"></a>

回调类型 [`i2c_target_api_register_t`](https://docs.zephyrproject.org/latest/doxygen/html/group__i2c__interface__backend.html#ga8747d3491331f7bae4b466d69e222027) 用于要求I²C目标设备注册自身；参数参见 [`i2c_target_driver_register()`](https://docs.zephyrproject.org/latest/doxygen/html/group__i2c__interface.html#ga1ba4520e0c2a3ef19fcc52ba091d97d4)。

```c
typedef int(* i2c_target_api_register_t) (const struct device *dev);
```

<a id="ga4f89da4d89111a2c03750cf7cf4ddb19"></a>

回调类型 [`i2c_target_api_unregister_t`](https://docs.zephyrproject.org/latest/doxygen/html/group__i2c__interface__backend.html#ga4f89da4d89111a2c03750cf7cf4ddb19) 用于要求I²C目标设备注销自身；参数参见 [`i2c_target_driver_unregister()`](https://docs.zephyrproject.org/latest/doxygen/html/group__i2c__interface.html#ga099580e56cfaf800e14f23066db70515)。

```c
typedef int(* i2c_target_api_unregister_t) (const struct device *dev);
```

> 译注：RTIO后端回调显式接收设备参数 `dev`，公共 `i2c_iodev_submit()` 则只接收提交条目；不能仅因参数说明引用公共函数就删去后端设备参数。
