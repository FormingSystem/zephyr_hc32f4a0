# 第429章\_I3C 通用命令码参考

原文：[group__i3c__ccc](https://docs.zephyrproject.org/latest/doxygen/html/group__i3c__ccc.html)。读取日期：2026-10-13，`latest`。

## 429.1\_范围、术语与头文件

本章对应官方 **改进型集成电路互连（Improved Inter-Integrated Circuit，I3C）通用命令码（Common Command Code，CCC）**参考，包含命令编号、能力位、格式枚举及命令辅助函数。**广播（Broadcast）**面向总线上的目标，**定向命令（Direct Command）**面向指定目标设备（Target）；控制器（Controller）发起命令。

```c
#include <zephyr/drivers/i3c/ccc.h>
```

以下术语贯穿本页。MIPI Alliance（MIPI 联盟）、JEDEC 和 DMTF 是规范发布组织的名称；此处保留其官方名称。

| 术语 | 中英文含义 |
| --- | --- |
| BCR / DCR | 总线特征寄存器（Bus Characteristics Register）/ 设备特征寄存器（Device Characteristics Register） |
| PID / DAA | 预置标识（Provisioned ID）/ 动态地址分配（Dynamic Address Assignment） |
| IBI / MDB | 带内中断（In-Band Interrupt）/ 必需数据字节（Mandatory Data Byte） |
| HJ / CRR | 热加入（Hot-Join）/ 控制器角色请求（Controller Role Request） |
| SDR / HDR | 单数据速率（Single Data Rate）/ 高数据速率（High Data Rate） |
| HDR-TSP / HDR-TSL | HDR 纯三符号模式（Ternary Symbol Pure）/ HDR 传统三符号模式（Ternary Symbol Legacy） |
| HDR-DDR / HDR-BT | HDR 双数据速率（Double Data Rate）/ HDR 批量传输（Bulk Transport） |
| CRC | 循环冗余校验（Cyclic Redundancy Check） |
| SCL / SDA | 串行时钟（Serial Clock）/ 串行数据（Serial Data） |
| GETSTATUS / SETBUSCON | 获取目标状态（Get Target Status）/ 设置总线上下文（Set Bus Context） |
| Defining Byte | 定义字节，用于进一步选择命令格式或操作 |
| Controller Handoff | 控制权移交，把控制器角色交给另一个支持控制器能力的设备 |

译注：代码标识符按官方拼写保留，包括虚拟目标单词拼写 `VITRUAL`、控制权移交延迟字段拼写 `CRDHLY` 和数据字节标识 `MDR` 等名称。`BIT(n)` 表示第 n 位，`GENMASK(h, l)` 生成位掩码，`FIELD_GET(mask, value)` 提取位域，`FIELD_PREP(mask, value)` 把值放入位域；这些名称属于代码接口，不作中文替换。

字段 `maxrd`、`maxwr` 和 `crhdly1` 分别表示最大读取速率参数、最大写入速率参数和控制权移交延迟参数字节；其位域提取宏见下文。

## 429.2\_命令宏与能力位

以下宏按官方参考页顺序列出。每项先说明用途，再保留声明；带参数的宏另列原始展开值。广播参数为布尔值，能力字段的参数则是对应返回字节。

### I3C_CCC_BROADCAST_MAX_ID

广播 CCC 的最大标识符。

```c
#define I3C_CCC_BROADCAST_MAX_ID 0x7FU
```


### I3C_CCC_D2DXFER

设备到设备的隧道传输控制（Device-to-Device Tunneling Control），定向命令。

```c
#define I3C_CCC_D2DXFER 0x97U
```


### I3C_CCC_DEFGRPA

定义组地址列表（Define List of Group Address），广播命令。

```c
#define I3C_CCC_DEFGRPA 0x2BU
```


### I3C_CCC_DEFTGTS

定义目标列表（Define List of Targets），广播命令。

```c
#define I3C_CCC_DEFTGTS 0x08U
```


### I3C_CCC_DISEC

禁用事件命令（Disable Events Command）。

```c
#define I3C_CCC_DISEC(broadcast)
```


展开值：

```c
((broadcast) ? 0x01U : 0x81U)
```

参数 `broadcast`：[`true`](https://docs.zephyrproject.org/latest/doxygen/html/stdbool_8h.html#a41f9c5fb8b08eb5dc3edce4dcb37fee7) 选择广播，[`false`](https://docs.zephyrproject.org/latest/doxygen/html/stdbool_8h.html#a65e9886d74aaee76545e83dd09011727) 选择定向命令。

### I3C_CCC_DISEC_EVT_ALL

禁用事件的全部事件位掩码，是上述三类事件位的按位或。

```c
#define I3C_CCC_DISEC_EVT_ALL (I3C_CCC_DISEC_EVT_DISINTR | I3C_CCC_DISEC_EVT_DISCR | I3C_CCC_DISEC_EVT_DISHJ)
```


### I3C_CCC_DISEC_EVT_DISINTR


## 429.3\_SETBUSCON 总线上下文编码

设置总线上下文（Set Bus Context，SETBUSCON）命令用于向目标提供总线采用的规范上下文。I3C 规范上下文字节编码如下。

| 位 | 含义 |
| --- | --- |
| 7:6 | `00` 表示 I3C 规范上下文 |
| 5 | 编辑修订号（Editorial Revision）：0 表示 v1.Y.0，1 表示 v1.Y.1 或更高 |
| 4 | 规范系列：0 表示 MIPI I3C，1 表示 MIPI I3C Basic |
| 3:0 | 次版本 Y：1—15 表示 v1.1—v1.15；0 不合法，因为 SETBUSCON 未在 I3C Basic v1.0 中定义 |

官方给出的 I3C Basic 版本示例：

| 版本 | 各字段拼接 | 完整字节 |
| --- | --- | --- |
| v1.1.0 | `1’b0 \|\| 1’b1 \|\| 4’b0001` | `8’b00010001` |
| v1.1.1 | `1’b1 \|\| 1’b1 \|\| 4’b0001` | `8’b00110001` |
| v1.2.0 | `1’b0 \|\| 1’b1 \|\| 4’b0010` | `8’b00010010` |

译注：示例中的双竖线表示原文的字段拼接排版，不表示 C 语言逻辑或运算。其他标准的上下文编号为 128（JEDEC 边带总线）、129（MCTP）和 130（欧洲电信标准协会，European Telecommunications Standards Institute，ETSI 的安全智能平台）。具体版本和功能见对应宏的说明。
