# 第308章\_I2C目标回调表

原文：[structi2c__target__callbacks](https://docs.zephyrproject.org/latest/doxygen/html/structi2c__target__callbacks.html)。读取日期：2026-10-13，`latest`。

## 308.1\_共享回调结构

结构 [`i2c_target_callbacks`](https://docs.zephyrproject.org/latest/doxygen/html/structi2c__target__callbacks.html) 提供支持集成电路间总线（Inter-Integrated Circuit，I²C）目标设备（Target）接口所需实现的回调（Callback），声明来自 `zephyr/drivers/i2c.h`。

总线上地址不同、但实现相同接口的多个设备可以共享本结构。各回调签名、数据参数和确认行为见[I2C公共接口](P305_I2C公共接口.md)。
