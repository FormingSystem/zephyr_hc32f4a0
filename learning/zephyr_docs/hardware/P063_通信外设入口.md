# 第63章\_通信外设入口

原文：[Communication](https://docs.zephyrproject.org/latest/hardware/peripherals/communication.html)。读取日期：2026-10-13，`latest`。

## 63.1\_通信外设目录

官方 **通信（Communication）**入口收集串行总线和其他通信接口，包括I2C、SPI、UART与CAN。下表按原目录顺序保留全部15个主题，并在名称中给出中英文对应；已译内容链接到本地章节。

| 文档 | 接口名称与用途范围 |
| --- | --- |
| [CAN总线入口](P029_CAN总线入口.md) | **控制器局域网（Controller Area Network，CAN）**。 |
| [I2C总线](P013_I2C总线.md) | **集成电路间总线（Inter-Integrated Circuit，I2C）**。 |
| [I3C总线](P070_I3C总线.md) | **改进的集成电路间总线（Improved Inter-Integrated Circuit，I3C）**。 |
| [SPI总线](P014_SPI总线.md) | **串行外设接口（Serial Peripheral Interface，SPI）**。 |
| [PCIe总线](P075_PCIe总线.md) | **高速外设组件互连（Peripheral Component Interconnect Express，PCIe）**。 |
| [UART](P006_UART.md) | **通用异步收发器（Universal Asynchronous Receiver-Transmitter，UART）**。 |
| [eSPI总线](P071_增强型SPI总线.md) | **增强型串行外设接口（Enhanced Serial Peripheral Interface，eSPI）**。 |
| [管理数据输入输出](P067_管理数据输入输出.md) | **管理数据输入／输出（Management Data Input/Output，MDIO）**。 |
| [多位SPI总线](P065_多位SPI总线.md) | **多位串行外设接口（Multi-bit Serial Peripheral Interface，MSPI）**。 |
| [系统管理总线](P066_系统管理总线.md) | **系统管理总线（System Management Bus，SMBus）**。 |
| [处理器间消息](P068_处理器间消息.md) | **处理器间邮箱（Inter-Processor Mailbox，IPM）**。 |
| [LIN总线](P072_本地互连网络.md) | **本地互连网络（Local Interconnect Network，LIN）**。 |
| [邮箱驱动](P069_邮箱驱动.md) | **多通道处理器间邮箱（Multi-Channel Inter-Processor Mailbox，MBOX）**。 |
| [1-Wire总线](P073_单线总线.md) | **单线总线（1-Wire Bus）**。 |
| [Pulse IO](P074_脉冲输入输出.md) | **脉冲输入／输出（Pulse Input/Output，Pulse IO）**。 |

原页是目录入口，未在此规定统一的帧格式或调用方式；具体使用约束应进入对应总线章节查看。
