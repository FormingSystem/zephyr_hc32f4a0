# 第921章\_ADIAD7124模数转换器绑定

<a id="dtbinding-adi-ad7124-adc"></a>

原文：[adi,ad7124-adc (on spi bus)](https://docs.zephyrproject.org/latest/build/dts/api/bindings/adc/adi,ad7124-adc.html)。读取日期：2026-10-13，`latest`。

`adi,ad7124-adc` 是Analog Devices（ADI）模数转换器（Analog-to-Digital Converter，ADC）的设备树绑定（Devicetree Binding）。此节点描述ADI AD7124 ADC控制器（Controller）。

驱动为 [`drivers/adc/adc_ad7124.c`](https://github.com/zephyrproject-rtos/zephyr/blob/main/drivers/adc/adc_ad7124.c)。

使用此兼容字符串的开发板见[官方筛选目录](https://docs.zephyrproject.org/latest/boards/index.html#compatibles=adi,ad7124-adc)。

以下严格区分各层节点，必需性、固定值及合法取值仅适用于所在层。`int` 为整数，`array` 为数值数组，`uint8-array` 为8位无符号整数数组，`string` 为字符串，`string-array` 为字符串数组，`boolean` 为布尔属性，`compound` 为复合类型；`phandle` 为节点引用（Phandle），`phandles` 为节点引用列表，`phandle-array` 为节点引用及说明单元数组。Kconfig是Zephyr的配置系统。

基础属性可用于多种节点，不保证全部适用于当前硬件。电源域（Power Domain）、直接存储器访问（Direct Memory Access，DMA）、输入输出（Input/Output，I/O）、邮箱（Mailbox）及处理器间消息（Inter-Processor Messaging，IPM）的通用属性也按原页保留。

本页SPI表示串行外设接口（Serial Peripheral Interface），GPIO表示通用输入输出（General-Purpose Input/Output）。

## 921.1\_控制器节点属性

| 属性 | 类型 | 中文说明与约束 |
| --- | --- | --- |
| `reference-enable` | `boolean` | 启用AD7124内部参考源：true启用，false禁用 |
| `pd-switch-enable` | `boolean` | 控制AD7124内部低侧掉电开关（Low-Side Power-Down Switch）：true表示开关闭合（Closed），false表示开关断开（Open）。上电或复位后的默认控制配置使开关保持断开 |
| `filter-type-mask` | `int` | AD7124滤波器类型位掩码（Bitmask）：第0位对应通道0，第1位对应通道1，依此类推。每位为0选择 `AD7124_FILTER_SINC4`，为1选择 `AD7124_FILTER_SINC3`。上电或复位后全部滤波配置采用SINC4，因此默认掩码为0，作为所有通道的默认设置；SINC为滤波器类型名称；默认值：`0` |
| `bipolar-mask` | `int` | AD7124极性配置位掩码：第0位对应通道0，第1位对应通道1，依此类推。每位为0选择单极性（Unipolar）工作，为1选择双极性（Bipolar）工作。上电或复位后所有配置均启用双极性，因此所有通道采用默认掩码 `0xFFFF`；默认值：`0xffff` |
| `inbuf-enable-mask` | `int` | AD7124输入缓冲器（Input Buffer）位掩码：第0位对应通道0，第1位对应通道1，依此类推。每位为0表示模拟输入引脚不经过缓冲，为1表示经过缓冲。上电或复位后全部配置均启用模拟输入缓冲器，因此所有通道采用默认掩码 `0xFFFF`；默认值：`0xffff` |
| `refbuf-enable-mask` | `int` | AD7124参考缓冲器（Reference Buffer）位掩码：第0位对应通道0，第1位对应通道1，依此类推。每位为0表示参考输入引脚不经过缓冲，为1表示经过缓冲。原文称上电或复位后全部参考输入缓冲器“启用”，并据此将所有通道默认值设为0。**译注：这一默认原因与同段“0为不缓冲、1为缓冲”的说明矛盾；这里保留默认值0及原说明，不擅自更改器件行为**；默认值：`0` |
| `adc-mode` | `int` | AD7124工作模式，编码与常量见本层表后。上电或复位后的控制配置启用连续转换（Continuous Conversion）模式，因此默认值为0；默认值：`0`；合法值：`0, 1, 2, 3, 4, 5, 6, 7, 8` |
| `power-mode` | `int` | AD7124功耗模式（Power Mode），编码与常量见本层表后。上电或复位后的控制配置启用低功耗模式，因此默认值为0；默认值：`0`；合法值：`0, 1, 2` |
| `active-device` | `int` | **必需**。实际使用的AD7124器件型号（Active Device），编码与常量见本层表后；合法值：`0, 1` |
| `#io-channel-cells` | `int` | **必需**。输入输出通道说明符（I/O Channel Specifier）的单元数量（Cell Count）；固定值：`1` |
| `spi-max-frequency` | `int` | **必需**。器件SPI接口的最大时钟频率，单位为赫兹（Hertz，Hz） |
| `duplex` | `int` | 双工模式（Duplex Mode）：全双工（Full Duplex）是最常用模式，因此默认编码为 `0`。应使用 `dt-bindings/spi/spi.h` 中的宏，而非直接填写枚举数值：`0` 对应 `SPI_FULL_DUPLEX`，`2048` 对应半双工（Half Duplex）的 `SPI_HALF_DUPLEX`；默认值：`0`；合法值：`0, 2048` |
| `frame-format` | `int` | 帧格式（Frame Format）：Motorola格式最常用，因此默认编码为 `0`。应使用 `dt-bindings/spi/spi.h` 中的宏，而非直接填写枚举数值：`0` 对应 `SPI_FRAME_FORMAT_MOTOROLA`，`32768` 对应TI格式的 `SPI_FRAME_FORMAT_TI`；Motorola与TI保留原格式名称；默认值：`0`；合法值：`0, 32768` |
| `spi-cpol` | `boolean` | SPI时钟极性（Clock Polarity，CPOL），决定时钟空闲状态；设置此属性时空闲电平为逻辑高，否则为逻辑低 |
| `spi-cpha` | `boolean` | SPI时钟相位（Clock Phase，CPHA），决定采样边沿；设置此属性时在第二个边沿采样，否则在第一个边沿采样 |
| `spi-lsb-first` | `boolean` | 器件要求最低有效位优先（Least Significant Bit First，LSB First）的数据模式 |

| `spi-cs-high` | `boolean` | 器件要求片选高电平有效（Active High） |
| `spi-interframe-delay-ns` | `int` | SPI字（Word）之间的延迟，单位为纳秒（Nanosecond，ns）。默认值 `0` 是特殊值，表示串行时钟（Serial Clock，SCK）周期的一半；默认值：`0` |

| `vin-supply` | `phandle` | 控制设备供电的稳压器节点引用；被引用节点必须具有稳压器兼容字符串。由共享稳压器供电时应提供此属性，供电状态取决于所有用电设备的请求状态。与独立开关 `supply-gpios` 相对。两者同时存在时，必须先请求稳压器，再将供电GPIO置为有效；释放稳压器前，必须先将供电GPIO置为无效 |
| `#address-cells` | `int` | 子节点 `reg` 地址字段所用的 `<u32>` 单元数量；`<u32>` 为32位无符号单元，参见《设备树规范》v0.4第2.3.5节；固定值：`1` |

本层 `reg-names` 的原始示例如下。设备树源码（Devicetree Source，DTS）中的 `uart` 是通用异步收发器（Universal Asynchronous Receiver/Transmitter，UART）节点名称，仅用于说明寄存器命名。

```dts
  / {
       soc {
           #address-cells = <1>;
           #size-cells = <1>;

           uart@1000 {
               reg = <0x1000 0x2000>, <0x3000 0x4000>;
               reg-names = "foo", "bar";
           };
       };
  };
```

其中 `uart@1000` 有两个寄存器块：`foo` 和 `bar` 是示例寄存器块名称；`foo` 的基址为 `0x1000`、大小为 `0x2000`；`bar` 的基址为 `0x3000`、大小为 `0x4000`。

AD7124工作模式常量如下。编码8按原文名称保留。

| 编码 | 常量与含义 |
| --- | --- |
| `0` | `AD7124_CONTINUOUS`：连续转换（Continuous Conversion） |
| `1` | `AD7124_SINGLE`：单次转换（Single Conversion） |
| `2` | `AD7124_STANDBY`：待机（Standby） |
| `3` | `AD7124_POWER_DOWN`：掉电（Power Down） |
| `4` | `AD7124_IDLE`：空闲（Idle） |
| `5` | `AD7124_IN_ZERO_SCALE_OFF`：内部零量程失调（Internal Zero-Scale Offset） |
| `6` | `AD7124_IN_FULL_SCALE_GAIN`：内部满量程增益（Internal Full-Scale Gain） |
| `7` | `AD7124_SYS_ZERO_SCALE_OFF`：系统零量程失调（System Zero-Scale Offset） |
| `8` | `AD7124_SYS_ZERO_SCALE_GAIN`：系统零量程增益（System Zero-Scale Gain，按原常量名称） |

功耗模式常量：

| 编码 | 常量与含义 |
| --- | --- |
| `0` | `AD7124_LOW_POWER_MODE`：低功耗（Low Power） |
| `1` | `AD7124_MID_POWER_MODE`：中等功耗（Mid Power） |
| `2` | `AD7124_HIGH_POWER_MODE`：高功耗（High Power） |

器件选择常量：

| 编码 | 常量与含义 |
| --- | --- |
| `0` | `ID_AD7124_4`：AD7124-4 |
| `1` | `ID_AD7124_8`：AD7124-8 |

## 921.2\_通道子节点属性

本层 `reg` 是通道标识（Channel Identifier），并非控制器寄存器地址；增益、参考源和采集时间是原页要求的必需配置。

| 属性 | 类型 | 中文说明与约束 |
| --- | --- | --- |
| `reg` | `array` | **必需**。通道标识（Channel Identifier）；参见[重要属性](https://docs.zephyrproject.org/latest/build/dts/intro-syntax-structure.html#dt-important-props) |
| `zephyr,gain` | `string` | **必需**。增益（Gain）选择，各常量对应的倍率见通道表后的完整对照；合法值：`ADC_GAIN_1_6, ADC_GAIN_1_5, ADC_GAIN_1_4, ADC_GAIN_2_7, ADC_GAIN_1_3, ADC_GAIN_2_5, ADC_GAIN_1_2, ADC_GAIN_2_3, ADC_GAIN_4_5, ADC_GAIN_1, ADC_GAIN_2, ADC_GAIN_3, ADC_GAIN_4, ADC_GAIN_6, ADC_GAIN_8, ADC_GAIN_12, ADC_GAIN_16, ADC_GAIN_24, ADC_GAIN_32, ADC_GAIN_64, ADC_GAIN_128` |
| `zephyr,reference` | `string` | **必需**。参考电压源（Reference Source）选择，各常量对应的源见通道表后的完整对照；合法值：`ADC_REF_VDD_1, ADC_REF_VDD_1_2, ADC_REF_VDD_1_3, ADC_REF_VDD_1_4, ADC_REF_INTERNAL, ADC_REF_EXTERNAL0, ADC_REF_EXTERNAL1` |
| `zephyr,vref-mv` | `int` | 此通道选择的参考源电压，单位为毫伏（Millivolt，mV），便于应用在需要计算时取得该值。内部参考（Internal Reference）的电压通常可由专用ADC应用程序接口（Application Programming Interface，API）获取，因此通常无须设置本属性；其他参考源使用此属性可能有帮助 |
| `zephyr,acquisition-time` | `int` | **必需**。采集时间（Acquisition Time）。使用 `ADC_ACQ_TIME` 宏组合属性值，或传入 `ADC_ACQ_TIME_DEFAULT` 采用硬件默认设置，例如硬件不允许配置采集时间的情况 |
| `zephyr,differential` | `boolean` | 设置后选择差分输入模式（Differential Input Mode）；否则使用单端模式（Single-Ended Mode），但若设置 `zephyr,input-negative`，则会隐式选择差分模式 |

| `zephyr,input-negative` | `int` | ADC负输入（Negative Input），**仅供选择 `ADC_CONFIGURABLE_INPUTS` Kconfig选项的驱动使用**；指定此属性即隐式选择该通道的差分输入模式 |
| `zephyr,resolution` | `int` | 此通道使用的ADC分辨率（Resolution） |
| `zephyr,oversampling` | `int` | 此通道的过采样（Oversampling）设置。指定后，每个采样值由 `2^N` 次转换结果平均得到，N为属性提供的值 |
| `zephyr,current-source-pin` | `uint8-array` | 电流源（Current Source）的输出引脚选择，实际解释由驱动决定。**仅供选择 `ADC_CONFIGURABLE_EXCITATION_CURRENT_SOURCE_PIN` Kconfig选项的驱动使用** |
