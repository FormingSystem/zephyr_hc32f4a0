# 第62章\_SD主机控制器

原文：[Secure Digital (SD card) interface](https://docs.zephyrproject.org/latest/hardware/peripherals/sdhc.html)。读取日期：2026-10-13，`latest`。

## 62.1\_SD卡访问的分层

Zephyr既可以通过系统原生的 **安全数字卡（Secure Digital Card，SD Card）**接口与已连接卡通信，也可以通过 **串行外设接口（Serial Peripheral Interface，SPI）**通信。部分设备还支持 **多媒体卡（MultiMediaCard，MMC）**。

应用可以使用Zephyr的[磁盘访问接口](../storage/P008_磁盘访问.md)，将SD卡作为存储设备；也可以使用SD卡子系统直接读写卡。这里的 **应用程序编程接口（Application Programming Interface，API）**分层很重要：应用通常应使用SD卡子系统，而不是直接调用下面的主机控制器接口。

## 62.2\_主机控制器与请求

**SD主机控制器（SD Host Controller，SDHC）**是能够向SD卡发送命令的设备，命令可以经原生SD接口发送，也可以经SPI发送。

该接口的核心是 [`sdhc_request()`](https://docs.zephyrproject.org/latest/doxygen/html/group__sdhc__interface.html#gac708d55e92a7705f92b90ee6baa65f74)。一个请求包含 `sdhc_command` 命令结构，以及可选的 `sdhc_data` 数据结构。调用者可以检查返回码，或者命令结构中的 `response` 响应字段，判断SDHC请求是否成功。

数据结构允许调用者指定要传输的块数，以及数据读出或写入所用的缓冲区位置。缓冲区是用来发送还是接收数据，取决于命令给出的 **操作码（Opcode）**，不能仅从存在缓冲区这一点判断方向。

## 62.3\_时钟、电压与卡电源

[`sdhc_set_io()`](https://docs.zephyrproject.org/latest/doxygen/html/group__sdhc__interface.html#ga0e6d8259cca442bd1356d00f668d35c4) 允许修改SD主机控制器的 **输入／输出（Input/Output，I/O）**设置，例如时钟频率、I/O电压和卡电源。

不是所有控制器都支持应用全部I/O设置。例如，使用SPI模式的控制器通常不能切换SD卡电源。应用或上层子系统应结合所用控制器能力处理设置结果，不能假定所有连接方式具有同样的电源控制能力。

相关Kconfig配置项为 [`CONFIG_SDHC`](https://docs.zephyrproject.org/latest/kconfig.html#CONFIG_SDHC)，用于SD主机控制器支持。Kconfig是Zephyr配置系统；完整声明见[SDHC接口参考](https://docs.zephyrproject.org/latest/doxygen/html/group__sdhc__interface.html)。
