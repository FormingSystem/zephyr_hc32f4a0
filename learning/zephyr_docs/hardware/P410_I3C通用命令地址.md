# 第410章\_I3C通用命令地址

原文：[structi3c__ccc__address](https://docs.zephyrproject.org/latest/doxygen/html/structi3c__ccc__address.html)。读取日期：2026-10-13，`latest`。

## 410.1\_单个地址载荷

`struct i3c_ccc_address` 保存**改进的集成电路间总线（Improved Inter-Integrated Circuit，I3C）通用命令码（Common Command Code，CCC）**中的单个设备地址载荷（Payload）。头文件为 `zephyr/drivers/i3c/ccc.h`。

用于以下命令：

| 命令 | 中英文名称 |
| --- | --- |
| `SETDASA` | 从静态地址设置动态地址（Set Dynamic Address from Static Address）。 |
| `SETNEWDA` | 设置新动态地址（Set New Dynamic Address）。 |
| `SETGRPA` | 设置组地址（Set Group Address）。 |
| `GETACCCR` | 获取接受控制器角色信息（Get Accept Controller Role）。 |

注意：用于定位命令接收方的目标地址编码在 `struct i3c_ccc_target_payload` 中，不编码在本载荷中。

## 410.2\_地址字段含义

唯一字段为 `uint8_t addr`，其含义随命令变化：

- `SETDASA`：将作为动态地址分配的静态地址。
- `SETNEWDA`：待分配的新动态地址。
- `SETGRPA`：待设置的新组地址。
- `GETACCCR`：次级控制器（Secondary Controller）的正确地址。

## 410.3\_地址与校验位编码

对于 `SETDASA`、`SETNEWDA` 和 `SETGRPA`，地址左移 1 位，第 0 位始终为 0。对于 `GETACCCR`，地址左移 1 位，第 0 位为计算得到的**奇校验位（Odd Parity Bit）**。

> 译注：原编码说明将 `SETDASA` 误写为 `SETDATA`，并在 `GETACCCR` 前多写了 `SET`。本页根据同一页的用途与字段说明写出对应命令，并在此保留原文差异。
