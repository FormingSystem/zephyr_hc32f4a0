# 第390章\_I3C目标设备驱动函数表

原文：[structi3c__target__driver__api](https://docs.zephyrproject.org/latest/doxygen/html/structi3c__target__driver__api.html)。读取日期：2026-10-13，`latest`。

## 390.1\_驱动操作结构

`struct i3c_target_driver_api` 是每个**改进的集成电路间总线（Improved Inter-Integrated Circuit，I3C）目标设备（Target Device）**驱动都需要定义的应用程序编程接口（Application Programming Interface，API）结构。它包含驱动实现的操作函数指针，也可以包含驱动专有的其他常量数据。头文件为 `zephyr/drivers/i3c/target_device.h`。

标记为 `REQ`（Required，必需）的成员必须由驱动设置；标记为 `OPT`（Optional，可选）的成员可以不设置。本结构列出的两个成员均为必需项。
