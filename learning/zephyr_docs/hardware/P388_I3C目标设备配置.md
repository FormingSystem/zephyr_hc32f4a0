# 第388章\_I3C目标设备配置

原文：[structi3c__target__config](https://docs.zephyrproject.org/latest/doxygen/html/structi3c__target__config.html)。读取日期：2026-10-13，`latest`。

## 388.1\_配置用途与生命周期

`struct i3c_target_config` 描述支持**改进的集成电路间总线（Improved Inter-Integrated Circuit，I3C）目标设备（Target Device）**接口的设备。头文件为 `zephyr/drivers/i3c/target_device.h`。

此结构的实例传给 [`i3c_target_register()`](https://docs.zephyrproject.org/latest/doxygen/html/group__i3c__target__device.html#gaf13d2b84a91e17d5ec49a41e9c553d42) 与 [`i3c_target_unregister()`](https://docs.zephyrproject.org/latest/doxygen/html/group__i3c__target__device.html#ga3dc0e6451fb13fa063c5ec3e18fe22e4)，分别表示添加和移除目标设备。

实现设备行为的模块必须先初始化结构字段，再把对象引用传给 [`i3c_target_register()`](https://docs.zephyrproject.org/latest/doxygen/html/group__i3c__target__device.html#gaf13d2b84a91e17d5ec49a41e9c553d42)。

## 388.2\_回调字段

```c
const struct i3c_target_callbacks *callbacks;
```

字段 [`callbacks`](https://docs.zephyrproject.org/latest/doxygen/html/structi3c__target__config.html#a43ed9a3679d54f7bb91dade34a5897b6) 指向设备事件的**回调函数（Callback Function）**表。各回调的调用时机与返回值见[目标设备回调表](P389_I3C目标设备回调表.md)。
