# 第186章\_字符帧缓冲坐标结构

原文：[structcfb__position](https://docs.zephyrproject.org/latest/doxygen/html/structcfb__position.html)。读取日期：2026-10-13，`latest`。

## 186.1\_结构来源

[`cfb_position`](https://docs.zephyrproject.org/latest/doxygen/html/structcfb__position.html) 是 **字符帧缓冲（Character Framebuffer，CFB）**的坐标结构（Position Structure），定义来自官方头文件 `zephyr/display/cfb.h`。

## 186.2\_数据字段（Data Fields）

| 字段 | 原始类型 | 原文说明 |
| --- | --- | --- |
| [`x`](https://docs.zephyrproject.org/latest/doxygen/html/structcfb__position.html#a0d2f18bfdd4b4e1e6f2538e0f3084fd6) | [`int16_t`](https://docs.zephyrproject.org/latest/doxygen/html/stdint_8h.html#afe270aee8d96ad7f279a4020b9d58bdf) | X 方向位置（X Position）。 |
| [`y`](https://docs.zephyrproject.org/latest/doxygen/html/structcfb__position.html#ab18cfc5749666113659c5703e68ea61a) | [`int16_t`](https://docs.zephyrproject.org/latest/doxygen/html/stdint_8h.html#afe270aee8d96ad7f279a4020b9d58bdf) | Y 方向位置（Y Position）。 |

相关绘图函数对坐标的含义各有说明，例如矩形使用左上与右下位置，圆使用圆心位置，见[单色字符帧缓冲接口](P184_单色字符帧缓冲接口.md)。
