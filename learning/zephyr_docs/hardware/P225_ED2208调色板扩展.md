# 第225章\_ED2208调色板扩展

原文：[group__ed2208__gca__display__interface](https://docs.zephyrproject.org/latest/doxygen/html/group__ed2208__gca__display__interface.html)。读取日期：2026-10-13，`latest`。

## 225.1\_范围与版本

本页提供 ED2208-GCA（EL073TF1）六色 **电子墨水（E-Ink）**显示控制器的设备专用 **应用程序编程接口（Application Programming Interface，API）**扩展。接口自 Zephyr 4.5.0 提供，本页版本为 0.1.0，宏定义来自 `zephyr/drivers/display/ed2208-gca.h`。

## 225.2\_颜色宏

以下均为颜色索引（Color Index）或调色板大小的宏：

| 宏 | 值 | 含义 |
| --- | --- | --- |
| [`ED2208_GCA_COLOR_BLACK`](https://docs.zephyrproject.org/latest/doxygen/html/group__ed2208__gca__display__interface.html#ga67dc44a48a9290447856ea5ca28d8439) | `0x00` | 黑色（Black）索引。 |
| [`ED2208_GCA_COLOR_WHITE`](https://docs.zephyrproject.org/latest/doxygen/html/group__ed2208__gca__display__interface.html#ga33d53105e77d0669148111c22e37dc70) | `0x01` | 白色（White）索引。 |
| [`ED2208_GCA_COLOR_YELLOW`](https://docs.zephyrproject.org/latest/doxygen/html/group__ed2208__gca__display__interface.html#gaaac429b04da8a2c3c3d6ae6583b85de7) | `0x02` | 黄色（Yellow）索引。 |
| [`ED2208_GCA_COLOR_RED`](https://docs.zephyrproject.org/latest/doxygen/html/group__ed2208__gca__display__interface.html#ga6887c0ee4a6e683a0ad4cdad2547db9a) | `0x03` | 红色（Red）索引。 |
| [`ED2208_GCA_COLOR_BLUE`](https://docs.zephyrproject.org/latest/doxygen/html/group__ed2208__gca__display__interface.html#ga88671850b7a9954b918edc07fd27a541) | `0x05` | 蓝色（Blue）索引。 |
| [`ED2208_GCA_COLOR_GREEN`](https://docs.zephyrproject.org/latest/doxygen/html/group__ed2208__gca__display__interface.html#ga8ea97937625cb32067e0bdd89ee20669) | `0x06` | 绿色（Green）索引。 |
| [`ED2208_GCA_COLOR_PALETTE_SIZE`](https://docs.zephyrproject.org/latest/doxygen/html/group__ed2208__gca__display__interface.html#ga6069fc9215aba137fe0d9bf179a72b7f) | `7` | 调色板条目数，**包含一个空槽（Empty Slot）**。 |

> 译注：设备支持六色，索引表跳过 `0x04`，因此包含空槽的调色板大小是 7；不能把宏值 7 理解成七种有效颜色。
