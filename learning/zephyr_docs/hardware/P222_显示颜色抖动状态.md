# 第222章\_显示颜色抖动状态

原文：[structdisplay__color__dither__state](https://docs.zephyrproject.org/latest/doxygen/html/structdisplay__color__dither__state.html)。读取日期：2026-10-13，`latest`。

## 222.1\_用途

结构 [`display_color_dither_state`](https://docs.zephyrproject.org/latest/doxygen/html/structdisplay__color__dither__state.html) 是 **颜色抖动（Color Dithering）**辅助接口为一个显示设备实例拥有的 **运行时状态（Runtime State）**，定义来自官方头文件 `zephyr/drivers/display/color_dither.h`。

驱动把此结构作为自身运行数据的成员嵌入，并把指向该成员的指针传给[颜色抖动辅助函数](P221_显示颜色抖动接口.md)。

## 222.2\_禁用时的行为与访问约束

禁用配置系统 Kconfig 的 [`CONFIG_DISPLAY_COLOR_DITHER`](https://docs.zephyrproject.org/latest/kconfig.html#CONFIG_DISPLAY_COLOR_DITHER) 时，这个结构为空，大小为零，因此可以无条件声明该成员，不产生 **随机存取存储器（Random Access Memory，RAM）**开销。

驱动不应直接访问任何字段。原结构参考页未列出公共数据字段。
