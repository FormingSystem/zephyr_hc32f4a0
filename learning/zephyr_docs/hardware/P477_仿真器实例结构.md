# 第477章\_仿真器实例结构

原文：[structemul](https://docs.zephyrproject.org/latest/doxygen/html/structemul.html)。读取日期：2026-10-13，`latest`。

`struct emul` 表示一个**仿真器实例（Emulator Instance）**：它对应被仿真的目标设备或外设，通过仿真总线与调用方交互。该结构定义于 `zephyr/drivers/emul.h`。

## 477.1\_实例与总线节点

一个仿真总线节点实例（例如 [`i2c_emul`](https://docs.zephyrproject.org/latest/doxygen/html/structi2c__emul.html)）与一个 `struct emul` 实例严格一一对应。这里 `i2c_emul` 是**集成电路间总线（Inter-Integrated Circuit，I2C）**的仿真节点类型。

结构内包含名为 [`bus`](P485_仿真器总线联合体.md) 的**联合体（Union）**类型 `union emul::bus`，用于保存指向仿真总线节点的指针。联合体成员详情由对应类型参考页说明；本页保留原文给出的实例字段。

## 477.2\_字段参考

实例把初始化函数、设备句柄、配置、运行数据、总线类型及后端接口组合在一起。**后端应用程序编程接口（Backend Application Programming Interface，Backend API）**由实例向测试代码暴露。

| 类型与字段 | 官方说明译文 |
| --- | --- |
| `emul_init_t init` | 用于初始化仿真器状态的函数 |
| `const struct device *dev` | 设备句柄；此实例为该设备提供底层仿真 |
| `const void *cfg` | 仿真器专用的配置数据 |
| `void *data` | 仿真器专用的数据 |
| `enum emul_bus_type bus_type` | 仿真器所附着的总线类型 |
| `union emul::bus bus` | 仿真总线节点 |
| `const void *backend_api` | 该实例暴露的 API 结构地址 |

> 译注：[`cfg`](https://docs.zephyrproject.org/latest/doxygen/html/structemul.html#ae6f86e44a6b28296528d607124f4b812) 与 [`backend_api`](https://docs.zephyrproject.org/latest/doxygen/html/structemul.html#ac7e90a7ff00a0c08836821c7d49b7dea) 指向只读对象，[`data`](https://docs.zephyrproject.org/latest/doxygen/html/structemul.html#a82f3fcaf221cd329ef1b6cb93cc7c8e6) 指向可变数据。实际对象类型由具体仿真器定义，不能仅凭 `void *` 自行假定其布局。
