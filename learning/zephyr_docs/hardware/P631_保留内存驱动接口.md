# 第631章\_保留内存驱动接口

原文：[group__retained__mem__interface__backend](https://docs.zephyrproject.org/latest/doxygen/html/group__retained__mem__interface__backend.html)。读取日期：2026-10-13，`latest`。

本分组包含实现保留内存（Retained Memory）驱动所需的应用程序编程接口（Application Programming Interface，API）类型、回调（Callback）签名和其他辅助定义。

```c
#include <zephyr/drivers/retained_mem.h>
```

驱动操作由结构 [`retained_mem_driver_api`](https://docs.zephyrproject.org/latest/doxygen/html/structretained__mem__driver__api.html) 组织，见[驱动操作表](P632_保留内存驱动操作表.md)。

## 631.1\_查询大小回调

```c
typedef ssize_t (*retained_mem_size_api)(const struct device *dev);
```

<a id="ga684490184eedc8d3f56b25d7b6e50a06"></a>

[`retained_mem_size_api`](https://docs.zephyrproject.org/latest/doxygen/html/group__retained__mem__interface__backend.html#ga684490184eedc8d3f56b25d7b6e50a06) 查询保留内存区域大小，参数说明见[接口页的查询区域大小](P630_保留内存接口.md#retained-size)。

## 631.2\_读取回调

```c
typedef int (*retained_mem_read_api)(const struct device *dev, off_t offset, uint8_t *buffer, size_t size);
```

<a id="ga3831f3ec0e0de7957cc6ce7da0cfbe58"></a>

[`retained_mem_read_api`](https://docs.zephyrproject.org/latest/doxygen/html/group__retained__mem__interface__backend.html#ga3831f3ec0e0de7957cc6ce7da0cfbe58) 从保留内存区域读取数据，参数说明见[读取数据](P630_保留内存接口.md#retained-read)。

## 631.3\_写入回调

```c
typedef int (*retained_mem_write_api)(const struct device *dev, off_t offset, const uint8_t *buffer, size_t size);
```

<a id="gaf6e43d230b1a606e90f3a236aeff1909"></a>

[`retained_mem_write_api`](https://docs.zephyrproject.org/latest/doxygen/html/group__retained__mem__interface__backend.html#gaf6e43d230b1a606e90f3a236aeff1909) 向保留内存区域写入数据，参数说明见[写入数据](P630_保留内存接口.md#retained-write)。

## 631.4\_清除回调

```c
typedef int (*retained_mem_clear_api)(const struct device *dev);
```

<a id="ga3fde220eceb8a45a7a42cfbb1930e27d"></a>

[`retained_mem_clear_api`](https://docs.zephyrproject.org/latest/doxygen/html/group__retained__mem__interface__backend.html#ga3fde220eceb8a45a7a42cfbb1930e27d) 清除保留内存区域，将所有数据复位为 `0x00`。参数说明见[清除数据](P630_保留内存接口.md#retained-clear)。
