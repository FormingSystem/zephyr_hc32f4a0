# 第515章\_测试套件节点结构

原文：[structztest__suite__node](P515_测试套件节点结构.md)。读取日期：2026-10-13，`latest`。

`struct ztest_suite_node` 表示单个**测试套件节点（Test Suite Node）**。每个节点都应加入同一个**链接段（Linker Section）**，使 [`ztest_run_test_suites()`](P507_ZTest测试定义宏.md) 能遍历这些节点。

公开头文件为 `zephyr/ztest_test.h`，源码位置为 `subsys/testsuite/ztest/include/zephyr/ztest_test.h`。这里将原文构建机的绝对包含路径改为公开包含名。

## 515.1\_回调与统计字段

节点保存套件名称、生命周期回调、可选**谓词（Predicate）**过滤函数以及统计信息。

| 字段声明 | 官方说明译文 |
| --- | --- |
| `const char *const name` | 测试套件名称 |
| `const ztest_suite_setup_t setup` | 准备函数（Setup Function） |
| `const ztest_suite_before_t before` | 测试前函数（Before Function） |
| `const ztest_suite_after_t after` | 测试后函数（After Function） |
| `const ztest_suite_teardown_t teardown` | 清理函数（Teardown Function） |
| `const ztest_suite_predicate_t predicate` | 可选谓词过滤函数 |
| `struct ztest_suite_stats *const stats` | 统计信息 |

> 译注：这些 `ztest_suite_*_t` 是回调指针类型别名。准备与清理作用于整个套件，测试前/后函数作用于套件内每个测试；详见对应类型定义。[`stats`](P515_测试套件节点结构.md) 为不可重新赋值的指针，指向的统计结构并未声明为只读。
