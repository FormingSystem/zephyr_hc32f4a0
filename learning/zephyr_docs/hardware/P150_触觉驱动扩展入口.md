# 第150章\_触觉驱动扩展入口

原文：[group__haptics__interface__ext](https://docs.zephyrproject.org/latest/doxygen/html/group__haptics__interface__ext.html)。读取日期：2026-10-13，`latest`。

## 150.1\_器件专用触觉接口

本页是 **器件专用触觉接口扩展（Device-Specific Haptics API Extensions）**目录。API为 **应用程序编程接口（Application Programming Interface）**；原页未补充详细说明，只列出下表四组扩展。

执行器类型包括 **线性谐振执行器（Linear Resonant Actuator，LRA）**、**音圈电机（Voice Coil Motor，VCM）**和 **偏心旋转质量电机（Eccentric Rotating Mass，ERM）**。芯片型号是器件专名。

| 扩展 | 原文说明 |
| --- | --- |
| [CS40L26／27](P152_CS40L26与CS40L27触觉扩展.md) | CS40L26触觉驱动，支持LRA与VCM。 |
| [CS40L5x](P153_CS40L5x触觉扩展.md) | CS40L5x触觉驱动，支持LRA与VCM。 |
| [DRV2605](P154_DRV2605触觉扩展.md) | DRV2605触觉驱动，支持ERM与LRA。 |
| [TM6605](P155_TM6605触觉扩展.md) | TM6605触觉驱动，支持LRA。 |

这里只登记扩展目录页为已译，四组专用接口正文仍以各自清单状态为准。
