# 第53章\_熵源驱动操作结构

原文：[structentropy__driver__api](https://docs.zephyrproject.org/latest/doxygen/html/structentropy__driver__api.html)。读取日期：2026-10-13，`latest`。

## 53.1\_驱动操作结构

`struct entropy_driver_api` 是**熵（Entropy）**驱动必须定义的 **应用程序编程接口（Application Programming Interface，API）**结构。它保存指向驱动已实现操作的函数指针，以及驱动特定的其他常量数据。官方声明所在头文件为 `zephyr/drivers/entropy.h`，本页参考由该文件生成。

原文以 **必需项（Required，REQ）**与 **可选项（Optional，OPT）**标记字段。标为REQ的成员**必须由驱动设置**；标为OPT的成员可以不实现。下表保留每个字段实际标记，而非把所有操作统一视为可选。

## 53.2\_操作字段

| 字段 | 函数指针类型 | 要求 | 作用 |
| --- | --- | --- | --- |
| <a id="a3fd7758ed4c71ba1d64939297d06faa3"></a>[`get_entropy`](https://docs.zephyrproject.org/latest/doxygen/html/structentropy__driver__api.html#a3fd7758ed4c71ba1d64939297d06faa3) | [`entropy_get_entropy_t`](https://docs.zephyrproject.org/latest/doxygen/html/group__entropy__interface__backend.html#ga661150c9482777f98cdee794e9164b28) | REQ | 用熵数据填充缓冲区。 |
| <a id="ac0356f7fd4600377c6018414f056d766"></a>[`get_entropy_isr`](https://docs.zephyrproject.org/latest/doxygen/html/structentropy__driver__api.html#ac0356f7fd4600377c6018414f056d766) | [`entropy_get_entropy_isr_t`](https://docs.zephyrproject.org/latest/doxygen/html/group__entropy__interface__backend.html#gacaa273da74b4727ea49b25d1ccd9725c) | OPT | 以非阻塞或忙等待方式用熵数据填充缓冲区。 |

普通熵获取操作为必需项，**中断服务程序（Interrupt Service Routine，ISR）**版本为可选项。可选字段未实现时，调用者要按[熵源接口参考](P039_熵源接口参考.md)处理错误；普通操作还必须满足[后端接口](P048_熵源驱动后端接口.md)说明的线程安全要求。

这些字段的参数签名与公共接口的对应关系，见[驱动后端接口](P048_熵源驱动后端接口.md)。原页的逐字段参考与上表一致，没有另外给出字段默认值。

## 53.3\_相关设备定义入口

原页还指向 [`DEVICE_DT_INST_DEFINE()`](../device_reference/P001_设备模型公共接口.md#gada5ba4aca9e0662ccebb2232c7256419)、[`DEVICE_DT_DEFINE()`](../device_reference/P001_设备模型公共接口.md#gac49e26fbe91a14307d5ea08d41561dd1) 与 [`DEVICE_API()`](../device_reference/P007_设备模型头文件参考.md#aa0cdc799fc0b9c80eb29f989eec86707)。前两个宏用于依据设备树定义设备实例，后一个宏用于定义驱动API对象；它们把设备实例与操作结构关联起来。这里保留官方精确链接，具体参数以对应宏参考为准。
