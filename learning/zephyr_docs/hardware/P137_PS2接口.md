# 第137章\_PS2接口

原文：[PS/2](https://docs.zephyrproject.org/latest/hardware/peripherals/ps2.html)。读取日期：2026-10-13，`latest`。

## 137.1\_传统键鼠接口

**PS/2接口（PS/2 Interface）**连接器于1987年随IBM同名桌面计算机产品系列进入市场，后来成为鼠标与键盘连接的行业标准。PS/2沿用该产品系列名称；**个人计算机（Personal Computer，PC）**是原文所说的桌面PC。

原文概述，从约2007年起，**通用串行总线（Universal Serial Bus，USB）**逐步取代PS/2，成为现代外设连接标准。为支持带PS/2连接器的传统板卡，Zephyr提供PS/2驱动 **应用程序编程接口（Application Programming Interface，API）**。

## 137.2\_配置、接口与示例

相关Kconfig配置项为 [`CONFIG_PS2`](https://docs.zephyrproject.org/latest/kconfig.html#CONFIG_PS2)；Kconfig是Zephyr配置系统。完整声明见[PS/2 API](https://docs.zephyrproject.org/latest/doxygen/html/group__ps2__interface.html)。原页关联[PS/2接口示例](../driver_samples/P037_PS2接口示例.md#ps2)，用于与PS/2鼠标通信。
