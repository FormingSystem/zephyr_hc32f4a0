# 第141章\_视频设备

原文：[Video](https://docs.zephyrproject.org/latest/hardware/peripherals/video.html)。读取日期：2026-10-13，`latest`。

## 141.1\_视频设备与端点

**视频（Video）**驱动的 **应用程序编程接口（Application Programming Interface，API）**为视频设备提供通用接口。

**视频设备（Video Device）**抽象一个硬件或软件视频功能，可以产生、处理、消费或变换视频数据。API旨在灵活地创建、操作和组合不同视频设备。

每个设备可以有一个或多个 **端点（Endpoint）**。原文的端点小节描述：输出端点配置视频输出功能并产生数据；输入端点配置视频输入功能并消费数据。

## 141.2\_视频缓冲区生命周期

**视频缓冲区（Video Buffer）**是数据传输机制，自身对内容不作特定要求，内容要求由端点格式定义。缓冲区可以排入设备端点队列，供填充或消费；操作完成后，缓冲区可以出队，以进行后处理、释放或重用。

原文在此把填充操作标为“input ep”，把消费操作标为“output ep”；ep是端点的简写。

> 译注：原页的端点小节与缓冲区小节对输入／输出的使用方向不一致，不能只根据这两段文字推导某个驱动的缓冲区方向。这里保留原文两处说明；具体调用应核对[视频子系统API](https://docs.zephyrproject.org/latest/doxygen/html/group__video__api.html)与目标版本的缓冲区类型定义。

## 141.3\_控制属性

视频控制通过 **控制标识符（Control Identifier，CID）**标识和访问，每个控制代表一项视频控制属性。不同设备支持不同控制，既可能是通用控制，也可能与设备类别有关，或为厂商专用。

设置、读取控制的函数提供通用且可扩展的接口，用于操作和创建控制项。控制标识参考见[Video Control IDs](https://docs.zephyrproject.org/latest/doxygen/html/group__video__control__ids.html)。

## 141.4\_配置、接口与示例

相关Kconfig配置项为 [`CONFIG_VIDEO`](https://docs.zephyrproject.org/latest/kconfig.html#CONFIG_VIDEO)；Kconfig是Zephyr配置系统。参考分为[视频子系统](https://docs.zephyrproject.org/latest/doxygen/html/group__video__api.html)与[视频驱动](https://docs.zephyrproject.org/latest/doxygen/html/group__video__interface.html)。

原页列出五个示例。USB表示 **通用串行总线（Universal Serial Bus）**，UVC表示 **USB视频类（USB Video Class）**；LVGL是嵌入式图形库名称，LCD表示 **液晶显示器（Liquid Crystal Display）**，TCP表示 **传输控制协议（Transmission Control Protocol）**。

| 示例 | 用途 |
| --- | --- |
| [USB主机UVC摄像头](../usb/P125_USB主机摄像头示例.md#usb-host-uvc) | 从USB摄像头采集视频。 |
| [USB视频摄像头](../usb/P124_USB视频摄像头示例.md#uvc) | 通过USB发送视频帧。 |
| [视频采集](P173_视频采集示例.md) | 用视频API从采集设备取得视频帧。 |
| [视频采集到LVGL](P174_视频采集到LVGL示例.md) | 采集视频帧，并用LVGL显示到LCD。 |
| [视频TCP服务器接收端](P175_视频TCP服务器示例.md) | 采集视频帧，再经网络发送给TCP客户端；“接收端”指其在视频数据处理链中的角色。 |
