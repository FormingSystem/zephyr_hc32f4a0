# 第197章\_PCA9633发光二极管示例

原文：[PCA9633 LED](https://docs.zephyrproject.org/latest/samples/drivers/led/pca9633/README.html)。读取日期：2026-10-13，`latest`。

## 197.1\_概述（Overview）

本示例控制连接到 PCA9633 驱动器的 4 个 **发光二极管（Light-Emitting Diode，LED）**，按下列顺序操作：点亮、关闭、把亮度设为 50%、关闭、闪烁、关闭。

## 197.2\_构建与运行（Building and Running）

为 [Nucleo F334R8](https://docs.zephyrproject.org/latest/boards/st/nucleo_f334r8/doc/index.html#nucleo_f334r8) 开发板构建应用，并把 PCA9633 驱动器连接到 Arduino 接口的 **内部集成电路总线（Inter-Integrated Circuit，I2C）**。

译注：以下为示例原文命令，在已配置 Zephyr 开发环境的终端中，从 Zephyr 源码根目录执行。示例由官方仓库提供，west 生成构建产物。

```bash
west build -b nucleo_f334r8_board samples/drivers/led/pca9633
```

译注：示例原命令使用 `nucleo_f334r8_board`；本次核对的官方开发板文档使用 `nucleo_f334r8`。当前版本应按开发板文档使用后者，原命令保留用于与来源对照。

烧录方法见 [Nucleo F334R8开发板文档](https://docs.zephyrproject.org/latest/boards/st/nucleo_f334r8/doc/index.html#nucleo_f334r8)的烧录（Flashing）小节。
