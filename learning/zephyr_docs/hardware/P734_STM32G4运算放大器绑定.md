# 第734章\_STM32G4运算放大器绑定

<a id="dtbinding-st-stm32g4-opamp"></a>

原文：[st,stm32g4-opamp](https://docs.zephyrproject.org/latest/build/dts/api/bindings/opamp/st,stm32g4-opamp.html)。读取日期：2026-10-13，`latest`。

`st,stm32g4-opamp` 是设备树绑定（Devicetree Binding），描述STM32G4运算放大器（Operational Amplifier，OPAMP）。每个运放有两个输入、一个输出，三路输入输出（Input/Output，I/O）均可连接外部引脚，以实现任意外部互连。内部可配置为独立放大器（Standalone Amplifier，外部设定增益）、跟随器（Follower）、增益2至64的同相放大器（Non-Inverting Amplifier），或增益−1至−63的反相放大器（Inverting Amplifier）。同相输入INP可接内部数模转换器（Digital-to-Analog Converter，DAC），输出VOUT可接内部模数转换器（Analog-to-Digital Converter，ADC）。主要特性包括轨到轨（Rail-to-Rail）输入电压范围、低输入偏置电流（Input Bias Current）、低输入失调电压（Input Offset Voltage）、高频增益带宽（Gain Bandwidth）、改善转换速率的高速模式，以及用于改善输入N沟道／P沟道金属氧化物半导体（N-Channel／P-Channel Metal-Oxide-Semiconductor，NMOS／PMOS）晶体管失调电压调整的自校准（Self-Calibration）。PGA指可编程增益放大器（Programmable Gain Amplifier）。

使用此兼容字符串的开发板见[官方筛选目录](https://docs.zephyrproject.org/latest/boards/index.html#compatibles=st,stm32g4-opamp)。

## 734.1\_原始设备树配置示例

独立放大器，增益由外部电路确定。注意：独立模式下 `inm` 固定连接VINM0，与设备树源码（Devicetree Source，DTS）所填值无关。

```dts
    &opamp2 {
      pinctrl-0 = <&opamp2_vinm_pa5 &opamp2_vinp_pa7 &opamp2_vout_pa6>;
      pinctrl-names = "default";
      functional-mode = "standalone";
      inp = "VINP0";
      status = "okay";
    };
```

电压缓冲器／跟随器，以内部DAC作为输入。

```dts
    &opamp2 {
      pinctrl-0 = <&opamp2_vout_pa6>;
      pinctrl-names = "default";
      functional-mode = "follower";
      inp = "DAC";
      status = "okay";
    };
```

同相PGA，增益范围2至64。

```dts
    &opamp2 {
      pinctrl-0 = <&opamp2_vinp_pb14 &opamp2_vout_pa6>;
      pinctrl-names = "default";
      functional-mode = "non_inverting";
      inp = "VINP1";
      status = "okay";
    };
```

反相PGA，增益范围−1至−63；注释要求同相输入路由到外部偏置电压，反相输入只允许VINM0。

```dts
    &opamp2 {
      pinctrl-0 = <&opamp2_vinm_pc5 &opamp2_vinp_pb0
                   &opamp2_vout_pa6>;
      pinctrl-names = "default";
      functional-mode = "inverting";
      inp = "VINP2"; /* shall be routed to external bias voltage */
      inm = "VINM0"; /* VINM0 is only allowed choice */
      status = "okay";
    };
```

定时器控制的输入多路复用器（Multiplexer，MUX）：在TIM1_CH6触发时切换VINP0和VINP3。译注：原文标题称“同相PGA”，但示例的 `functional-mode` 为 `standalone`；保留原例，不替换为另一模式。

```dts
  &opamp2 {
    pinctrl-0 = <&opamp2_vinm_pa5 &opamp2_vinm_pc5
                 &opamp2_vinp_pa7 &opamp2_vout_pa6>;
    pinctrl-names = "default";
    functional-mode = "standalone";
    st,inputs-mux-mode = "TIM1_CH6";
    inp = "VINP0", "VINP3";
    status = "okay";
  };
```

下面示例的 `ADC_GAIN_1` 为单位增益枚举，`ADC_REF_INTERNAL` 为内部参考电压枚举，`ADC_ACQ_TIME_DEFAULT` 为默认采集时间宏；`SYNC` 是ADC同步时钟源（Synchronous Clock Source）标识。

与ADC配合使用：应用程序可使用常规ADC应用程序接口（Application Programming Interface，API）读取ADC。

```dts
  / {
      zephyr,user {
        opamp = <&opamp2>;
      };
    };

    &adc2 {
      st,adc-clock-source = "SYNC";
      st,adc-prescaler = <4>;
      status = "okay";

      #address-cells = <1>;
      #size-cells = <0>;

      channel@3 {
        reg = <3>;
        zephyr,gain = "ADC_GAIN_1";
        zephyr,reference = "ADC_REF_INTERNAL";
        zephyr,acquisition-time = <ADC_ACQ_TIME_DEFAULT>;
        zephyr,resolution = <12>;
        zephyr,vref-mv = <3300>;
      };
    };

    &opamp2 {
      pinctrl-0 = <&opamp2_vinm_pa5 &opamp2_vinp_pa7>;
      pinctrl-names = "default";
      functional-mode = "non_inverting";
      inm = "VINM0";
      inp = "VINP0";
      io-channels = <&adc2 3>;
      status = "okay";
    };
```

## 734.2\_节点专用属性

`int` 为整数，`string` 为字符串，`boolean` 为布尔属性，`array` 为数值数组，`phandles` 为节点引用（Phandle）列表，`phandle-array` 为节点引用与说明单元数组，`string-array` 为字符串数组。

| 属性 | 类型 | 中文说明与约束 |
| --- | --- | --- |
| `st,power-mode` | `string` | 运放功耗模式会影响转换速率（Slew Rate）：`NORMAL` 为6.5 V/µs且功耗较低；`HIGHSPEED` 为45 V/µs且功耗较高。单位V/µs为伏每微秒，来源见本页参考资料；默认值：`NORMAL`；合法值：`NORMAL, HIGHSPEED` |
| `st,lock-enable` | `boolean` | 驱动完成配置后锁定运放，防止意外修改。只有系统复位（System Reset）才能解除锁定；未设置时默认不锁定。在 `st,inputs-mux-mode` 模式下，定时器多路复用寄存器也会锁定 |
| `st,enable-self-calibration` | `boolean` | 启用自校准（Self-Calibration）以获得最佳性能；未设置时默认禁用。此步骤在运放初始化时执行 |
| `inp` | `string-array` | **必需**。同相输入选择。参见RM0440 Rev 9第204表，第777/2140页；启用 `st,inputs-mux-mode` 时，还应提供第二个输入条目；合法值：`VINP0, VINP1, VINP2, VINP3, DAC` |
| `inm` | `string-array` | 反相输入选择。参见RM0440 Rev 9第204表，第777/2140页。使用 `st,inputs-mux-mode` 时：独立模式在VINM0与VINM1之间复用（`VM_SEL = 00` 或 `01`）；反相／同相PGA（`VM_SEL = 10`）或跟随器（`VM_SEL = 11`）模式在电阻反馈与VOUT之间复用，本质上切换PGA与跟随器模式，**此时不会在VINM0与VINM1之间复用**。数组值必须有序，例如 `VINM0, VINM1`；合法值：`VINM0, VINM1` |
| `st,inm-filtering` | `string` | 反相输入滤波（Inverting Input Filtering）选择，只适用于反相／同相PGA模式。参见RM0440 Rev 9第783至784/2140页；默认值：`NONE`；合法值：`NONE, VINM0, VINM1` |
| `st,inputs-mux-mode` | `string` | 定时器控制的多路复用模式（Timer-Controlled Multiplexer Mode）。TIM1 CC6、TIM8 CC6或TIM20 CC6输出触发运放输入多路复用器，使同相、反相输入自动切换。用于双电机控制：先同时测量第一台电机的三相电流，再测量第二台。参见RM0440 Rev 9第25.3.8节，第786/2140页；默认值：`DISABLE`；合法值：`DISABLE, TIM1_CH6, TIM8_CH6, TIM20_CH6` |
| `st,pmos-trimming-value` | `int` | P沟道金属氧化物半导体（P-Channel Metal-Oxide-Semiconductor，PMOS）晶体管的失调微调值（Offset Trimming Value），直接写入原文所称 `OPAMPx_CST` 寄存器的 `TRIMOFFSETP[4:0]`（位23:19）。同时提供此属性并启用自校准时，本值覆盖自校准计算值。参见RM0440 Rev 9第789/2140页；范围：`0 to 0x1f` |
| `st,nmos-trimming-value` | `int` | N沟道金属氧化物半导体（N-Channel Metal-Oxide-Semiconductor，NMOS）晶体管的失调微调值，直接写入原文所称 `OPAMPx_CST` 寄存器的 `TRIMOFFSETN[4:0]`（位28:24）。同时提供此属性并启用自校准时，本值覆盖自校准计算值。参见RM0440 Rev 9第789/2140页；范围：`0 to 0x1f` |
| `pinctrl-0` | `phandles` | **必需**。第一个引脚控制（Pin Control）状态的配置引用；具体内容由选用的引脚控制器驱动实现决定 |
| `pinctrl-names` | `string-array` | **必需**。已提供的引脚状态名称；名称数量必须与状态数量一致 |
| `functional-mode` | `string` | **必需**。选择运算放大器的功能模式（Functional Mode）；五种模式的接线、公式及原始电路图见“功能模式、电路图与增益枚举”节；合法值：`differential, inverting, non_inverting, follower, standalone` |
| `programmable-gain` | `string-array` | 可编程增益（Programmable Gain）列表。如果运放支持此功能，则可在运行时动态改变增益，数值必须取自规定的枚举；完整倍率对照见“功能模式、电路图与增益枚举”节；合法值：`OPAMP_GAIN_1_7, OPAMP_GAIN_1_3, OPAMP_GAIN_1, OPAMP_GAIN_5_3, OPAMP_GAIN_2, OPAMP_GAIN_11_5, OPAMP_GAIN_3, OPAMP_GAIN_4, OPAMP_GAIN_13_3, OPAMP_GAIN_7, OPAMP_GAIN_8, OPAMP_GAIN_15, OPAMP_GAIN_16, OPAMP_GAIN_31, OPAMP_GAIN_32, OPAMP_GAIN_33, OPAMP_GAIN_63, OPAMP_GAIN_64` |
| `pinctrl-1` | `phandles` | 第二个引脚控制（Pin Control）状态的配置引用；具体内容由选用的引脚控制器驱动实现决定，参见 `pinctrl-0` |
| `pinctrl-2` | `phandles` | 第三个引脚控制（Pin Control）状态的配置引用；具体内容由选用的引脚控制器驱动实现决定，参见 `pinctrl-0` |
| `pinctrl-3` | `phandles` | 第四个引脚控制（Pin Control）状态的配置引用；具体内容由选用的引脚控制器驱动实现决定，参见 `pinctrl-0` |
| `pinctrl-4` | `phandles` | 第五个引脚控制（Pin Control）状态的配置引用；具体内容由选用的引脚控制器驱动实现决定，参见 `pinctrl-0` |

## 734.3\_功能模式、电路图与增益枚举

以下为绑定继承的通用功能说明。`Rf` 为反馈电阻（Feedback Resistor），`Rin` 为输入电阻（Input Resistor），`Vin`／`Vin1`／`Vin2` 为输入电压（Input Voltage），`Vout` 为输出电压（Output Voltage），`GND` 为地（Ground）。原始字符电路图完整保留。

`differential`：差分（Differential）模式：两个输入端均接入信号，放大两者之差，抑制共模信号（Common-Mode Signal），用于仪表测量（Instrumentation）与噪声抑制（Noise Rejection）。`Vout = (Rf/Rin) * (Vin2 - Vin1)`，增益为 `Rf/Rin`。

```text
         Rin        Rf
Vin1 --/\/\/\--*--/\/\/\-----
               |            |
               |     |\     |
               ------|- \   |
                     |   >--*-- Vout
               ------|+ /
               |     |/
               |
Vin2 --/\/\/\--*--/\/\/\-----
         Rin        Rf      |
                           GND
```

`inverting`：反相（Inverting）模式：信号接入反相（−）端，同相（+）端接地，反馈电阻连接输出与反相端；输出与输入相差180°。`Vout = (-Rf/Rin) * Vin`，增益为 `-Rf/Rin`。

```text
        Rin        Rf
Vin --/\/\/\--*--/\/\/\-----
              |            |
              |     |\     |
              ------|- \   |
                    |   >--*-- Vout
              ------|+ /
              |     |/
            GND
```

`non_inverting`：同相（Non-Inverting）模式：信号接入同相（+）端，反相（−）端连接反馈网络，输出与输入同相。`Vout = (1 + (Rf/Rin)) * Vin`，增益为 `1 + Rf/Rin`。

```text
      Rin        Rf
 |--/\/\/\--*--/\/\/\-----
 |          |            |
GND         |     |\     |
            ------|- \   |
                  |   >--*-- Vout
        Vin ------|+ /
                  |/
```

`follower`：跟随器（Follower）模式，即电压跟随器（Voltage Follower）或缓冲器（Buffer）：同相放大器的特例，`Vout = 1 * Vin`，增益为1；输出直接反馈至反相输入，输入阻抗很高、输出阻抗很低，用于阻抗匹配（Impedance Matching）。

```text
    --------------
    |            |
    |     |\     |
    ------|- \   |
          |   >--*-- Vout
Vin ------|+ /
          |/
```

`standalone`：独立（Standalone）模式：运放工作方式由外部电路决定。

```text
          |\
Vin- -----|- \
          |   >---- Vout
Vin+ -----|+ /
          |/
```

原文参考：[运算放大器教程](https://www.electronics-tutorials.ws/category/opamp)。

| `OPAMP_GAIN_1_3` | 1/3 |

## 734.5\_状态、兼容字符串与寄存器

本页 `int` 为整数，`string` 为字符串，`string-array` 为字符串数组，`array` 为数值数组，`boolean` 为布尔属性，`compound` 为复合类型。**节点引用（Phandle）**用来指向其他节点；`phandle-array` 表示节点引用及其说明单元，`phandles` 表示节点引用列表。

`status` 的类型为 `string`，描述节点所代表硬件或其他资源的运行状态。`okay` 表示资源可运行，例如可供驱动使用；`disabled` 表示资源不可运行，系统应将它视为不存在。合法值为 `okay`、`disabled`、`reserved`、`fail`、`fail-sss`。详见《设备树规范》（Devicetree Specification）v0.4 第 2.3.4 节。

`compatible` 的类型为 `string-array`，是**必需属性**。它用字符串列表定义节点代表的硬件或其他资源类型；设备驱动检查特定兼容字符串，以寻找应由自己管理的节点。推荐格式为 `vendor,device`，其中 `vendor` 是厂商简称，`device` 通常取自数据手册。多个值应按从最具体到最通用排列，使某一通用家族的具体设备能匹配当前可用的最具体驱动。详见规范 v0.4 第 2.3.1 节。

`reg` 的类型为 `array`，是**必需属性**，给出寻址设备所需的信息，其含义取决于设备及 `compatible`。通常是一组“地址、长度”对，每对称为**寄存器块（Register Block）**，数值惯常写成十六进制。详见规范 v0.4 第 2.3.6 节。

`reg-names` 的类型为 `string-array`，为 `reg` 中各寄存器块提供可选名称。以下保留官方示例；`#address-cells` 和 `#size-cells` 分别声明地址与长度使用的 32 位单元数。

```dts
  / {
       soc {
           #address-cells = <1>;
           #size-cells = <1>;

           uart@1000 {
               reg = <0x1000 0x2000>, <0x3000 0x4000>;
               reg-names = "foo", "bar";
           };
       };
  };
```

`uart@1000` 节点有两个寄存器块：名称 `foo` 对应基址 `0x1000`、大小 `0x2000`；名称 `bar` 对应基址 `0x3000`、大小 `0x4000`。这里 uart 是**通用异步收发器（Universal Asynchronous Receiver/Transmitter，UART）**节点名称，示例只是演示寄存器块命名。

## 734.6\_地址映射与中断

`ranges` 的类型为 `compound`，定义总线子地址空间与总线节点父地址空间之间的映射或转换。它通常为空，或由“子总线地址、父总线地址、长度”三元组构成。**空属性表示两侧地址空间相同，不需要转换；总线节点没有此属性时，则认为子节点与父地址空间之间不存在映射。**详见规范 v0.4 第 2.3.8 节。

下列属性描述**中断（Interrupt）**，参见规范 v0.4 第 2.4 节“中断与中断映射”。

| 属性 | 类型 | 中文说明 |
| --- | --- | --- |
| `interrupts` | `array` | 设备产生的中断，编码为一个或多个中断说明符；格式由设备在中断树中的位置决定，具有相同 `interrupt-parent` 的设备使用相同格式 |
| `interrupts-extended` | `compound` | 扩展中断说明符，可替代 `interrupts` |
| `interrupt-names` | `string-array` | 设备各中断的可选名称；中断本身在 `interrupts` 或 `interrupts-extended` 中定义 |
| `interrupt-parent` | `phandle` | 若存在，引用负责处理此设备所产生中断的节点 |

## 734.7\_标签、时钟与地址单元

**时钟提供者（Clock Provider）**提供设备使用的时钟。下表同时保留标签和子节点地址编码相关属性。

| 属性 | 类型 | 中文说明 |
| --- | --- | --- |
| `label` | `string` | 描述设备的可读字符串；除逐案确有需要外，已不推荐使用此属性。参见规范 v0.4 第 4.1.2 节“其他属性” |
| `clocks` | `phandle-array` | **必需**。设备的时钟提供者信息，通常应遵守下述 dt-schema 时钟绑定约定 |
| `clock-names` | `string-array` | **必需**。`clocks` 中各时钟提供者的名称 |
| `#address-cells` | `int` | 子节点 `reg` 地址字段所用的 `<u32>` 单元数量 |
| `#size-cells` | `int` | 子节点 `reg` 大小字段所用的 `<u32>` 单元数量 |

`<u32>` 是 32 位无符号单元，两个 cells 属性见规范 v0.4 第 2.3.5 节。时钟约定见 [dt-schema 的 clock.yaml](https://github.com/devicetree-org/dt-schema/blob/main/dtschema/schemas/clock/clock.yaml)。`status`、`compatible`、`reg`、`interrupts` 和 `label` 另见官方[重要属性（Important Properties）](https://docs.zephyrproject.org/latest/build/dts/intro-syntax-structure.html#dt-important-props)。

## 734.8\_DMA、输入输出与邮箱通道

**直接存储器访问（Direct Memory Access，DMA）**属性描述设备的 DMA 能力、通道和地址映射；输入输出（Input/Output，I/O）及邮箱（Mailbox）属性描述关联通道。IPM 是**处理器间消息（Inter-Processor Messaging）**接口。

| 属性 | 类型 | 中文说明 |
| --- | --- | --- |
| `dma-coherent` | `boolean` | 表示设备支持一致性 DMA 操作，见规范 v0.4 第 2.3.10 节 |
| `dmas` | `phandle-array` | 与设备相关的 DMA 通道说明符 |
| `dma-names` | `string-array` | `dmas` 中各 DMA 通道说明符的可选名称 |
| `dma-ranges` | `compound` | 定义总线物理地址空间与其父总线物理地址空间之间的映射或转换，见规范 v0.4 第 2.3.9 节 |
| `io-channels` | `phandle-array` | 与设备相关的 I/O 通道说明符 |
| `io-channel-names` | `string-array` | `io-channels` 中各通道说明符的可选名称 |
| `mboxes` | `phandle-array` | 与设备相关的邮箱/IPM 通道说明符 |
| `mbox-names` | `string-array` | `mboxes` 中各邮箱说明符的可选名称 |

## 734.9\_电源域与硬件锁

**电源域（Power Domain）**描述设备所属供电域；**硬件自旋锁（Hardware Spinlock）**为硬件提供的锁资源。属性如下：

| 属性 | 类型 | 中文说明 |
| --- | --- | --- |
| `power-domains` | `phandle-array` | 与设备相关的电源域说明符 |
| `power-domain-names` | `string-array` | `power-domains` 中各电源域说明符的可选名称 |
| `#power-domain-cells` | `int` | `power-domains` 属性中的单元数量 |
| `hwlocks` | `phandle-array` | 与设备相关的硬件自旋锁标识 |
| `hwlock-names` | `string-array` | `hwlocks` 中各锁说明符的可选名称 |

## 734.10\_初始化、唤醒和运行时电源管理

`zephyr,deferred-init` 为 `boolean` 属性：启动时不自动初始化设备，应使用 `device_init()` 手动初始化。

`wakeup-source` 为 `boolean` 属性，标识设备可以作为**唤醒源（Wakeup Source）**。提供它后，设备会设置一个专门标志，告知系统该设备具备唤醒系统的能力。这类设备的唤醒功能默认禁用，即其中断不会唤醒系统，必要时可在运行期间启用。

`zephyr,pm-device-runtime-auto` 为 `boolean` 属性，在初始化函数执行后自动为设备配置**运行时电源管理（Runtime Power Management）**。

`zephyr,disabling-power-states` 的类型为 `phandles`，列出会关闭此设备电源的电源状态。
