# 第834章\_DACx0508设备树常量源码

原文：[dacx0508_8h_source](https://docs.zephyrproject.org/latest/doxygen/html/dacx0508_8h_source.html)。读取日期：2026-10-13，`latest`。

文件路径为 `zephyr/dt-bindings/dac/dacx0508.h`。

本页保留DACx0508数模转换器（Digital-to-Analog Converter，DAC）的设备树常量（Devicetree Constants）声明。文件文档入口对应[常量中文参考](P819_DACx0508设备树常量.md)。

## 834.1\_常量分组

四个参考源（Reference Source）宏使用 `DACX0508_REF_` 前缀：内部参考（Internal Reference）和外部参考（External Reference）分别提供后缀 `1`、`1_2` 的配置标识，编码依次为 `0x00`、`0x01`、`0x02`、`0x03`。两个通道增益（Channel Gain）宏为 `DACX0508_CHANNEL_GAIN_1` 与 `DACX0508_CHANNEL_GAIN_2`，编码分别为 `0x00`、`0x01`。原源码没有补充这些配置的电压说明。

以下保留Doxygen源码页实际展示的代码，剔除网页行号并清理行尾空白。网页隐藏的文档注释由对应参考页提供，本节没有自行补写或修改代码。
