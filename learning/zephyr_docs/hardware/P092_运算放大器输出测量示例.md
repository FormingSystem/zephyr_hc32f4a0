# 第92章\_运算放大器输出测量示例

原文：[Operational Amplifier (OPAMP) output measure sample](https://docs.zephyrproject.org/latest/samples/drivers/opamp/output_measure/README.html)。读取日期：2026-10-13，`latest`。

## 92.1\_配置放大与采样

本示例演示 **运算放大器（Operational Amplifier，OPAMP）**驱动的 **应用程序编程接口（Application Programming Interface，API）**。构建和运行前，需要配置一个 **模数转换器（Analog-to-Digital Converter，ADC）**通道，用于测量OPAMP输出；同时通过 **设备树（Devicetree，DT）**配置OPAMP。

如果OPAMP支持 **可编程增益（Programmable Gain）**，可以通过设备树属性 `programmable-gain` 设置要测试的增益。原文给出两个约束：任何增益都不应使OPAMP输出低于理论最小值或高于理论最大值；OPAMP输出不得超过ADC范围。

这些约束要在选择输入电压和增益时一并核对，不能只选择一个API能够表示的增益值。

## 92.2\_FRDM-MCXA156构建与运行

官方以NXP FRDM-MCXA156为例。准备Zephyr环境、对应工具链和烧录工具后，从实验Zephyr源码根目录，在Ubuntu Bash或已准备好的UCRT64 Bash中执行：

```shell
west build -b frdm_mcxa156 samples/drivers/opamp/output_measure
west flash
```

`samples/drivers/opamp/output_measure` 是官方示例目录，构建成功后再烧录。OPAMP0使用 **差分模式（Differential Mode）**时，原文接线要求为：正输入J2-12（OPAMP0_INP）接电压源；负输入R60-3（OPAMP0_INN）接电压源。

原文输出关系为 `Vout = Vref + (Vinp - Vinn) * Ngain`。其中Vout为输出电压，Vref为参考电压，Vinp和Vinn分别为正、负输入电压，Ngain为增益。参考电压和引脚连接要依据该板实际配置，不能把此处端子编号移用到其他板。

## 92.3\_观察测量结果

应用在支持可编程增益时设置OPAMP增益，再用ADC测量输出。每个已配置增益的测量电压以毫伏打印；原文输出如下：

```text
*** Booting Zephyr OS build v4.2.0-2155-gb21dd897e034 ***
OPAMP output (@gain: 4) is: 1513(mv)
OPAMP output (@gain: 2) is: 907(mv)
OPAMP output (@gain: 1) is: 613(mv)
```

原文说明实际值可能不同。日志中的4.2.0构建字符串属于原示例输出，不代表本次 `latest` 页面版本；1513、907和613也不是每套输入都应得到的固定值。

完整增益与设置接口见[运算放大器接口参考](P091_运算放大器接口参考.md)。本次未接入电压源、烧录、改变增益或执行ADC测量。
