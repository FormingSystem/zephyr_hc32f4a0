# 第199章\_SCT2024发光二极管示例

原文：[SCT2024 LED Controller](https://docs.zephyrproject.org/latest/samples/drivers/led/sct2024/README.html)。读取日期：2026-10-13，`latest`。

## 199.1\_概述（Overview）

本示例控制连接到 SCT2024 驱动器的最多 16 个 **发光二极管（Light-Emitting Diode，LED）**。

程序无限重复以下图案：逐个点亮各 LED；全部点亮后，同时关闭全部 LED，再同时点亮全部 LED；随后按顺序逐个关闭各 LED，然后重新开始。

## 199.2\_构建与运行（Building and Running）

开发板需要连接 SCT2024 驱动器，并在 **设备树源（Devicetree Source，DTS）**文件中定义与器件类型绑定（Binding）匹配的节点。

官方提供 [nRF52840 DK](https://docs.zephyrproject.org/latest/boards/nordic/nrf52840dk/doc/index.html#nrf52840dk) 的设备树叠加文件（Overlay）`boards/nrf52840dk_nrf52840.overlay`，路径相对于示例目录。它假定一个接有 16 个 LED 的 SCT2024 驱动器，通过选定的引脚连接到 **串行外设接口（Serial Peripheral Interface，SPI）**总线。
