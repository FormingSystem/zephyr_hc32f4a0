# 第478章\_总线仿真器链接结构

原文：[structemul__link__for__bus](https://docs.zephyrproject.org/latest/doxygen/html/structemul__link__for__bus.html)。读取日期：2026-10-13，`latest`。

`struct emul_link_for_bus` 是**总线仿真器链接（Emulator Link for Bus）**结构，用于唯一标识待仿真的设备，定义于 `zephyr/drivers/emul.h`。

## 478.1\_设备标识字段

原页只列出以下一个字段。该结构保存设备引用，供总线关联的仿真器列表使用。

| 类型与字段 | 官方说明译文 |
| --- | --- |
| `const struct device *dev` | 待仿真的设备 |

> 译注：[`dev`](https://docs.zephyrproject.org/latest/doxygen/html/structemul__link__for__bus.html#af81ff0873c340778030700d1cd2b7294) 指向 Zephyr 的设备对象（Device Object）。结构名称中的 Link 表示关联关系；原页没有声明链表的前驱或后继字段，不应把它理解成一个带链表指针的节点。
