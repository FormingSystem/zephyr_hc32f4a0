# 第393章\_I3C自定义硬件配置

原文：[structi3c__config__custom](https://docs.zephyrproject.org/latest/doxygen/html/structi3c__config__custom.html)。读取日期：2026-10-13，`latest`。

## 393.1\_自定义参数

`struct i3c_config_custom` 提供**改进的集成电路间总线（Improved Inter-Integrated Circuit，I3C）**的自定义配置参数。头文件为 `zephyr/drivers/i3c.h`。

对于[控制器配置](P391_I3C控制器硬件配置.md) `struct i3c_config_controller` 或[目标配置](P392_I3C目标硬件配置.md) `struct i3c_config_target` 未覆盖的参数，可以使用本结构配置硬件。它主要用于配置 I3C 硬件的厂商专有参数（Vendor-specific Parameter）。

## 393.2\_标识与值

按原字段表整理的声明如下。[`val`](https://docs.zephyrproject.org/latest/doxygen/html/structi3c__config__custom.html#ae0320b4b277b1c3d4ad438cd71d98340) 与 [`ptr`](https://docs.zephyrproject.org/latest/doxygen/html/structi3c__config__custom.html#a2bcc6334871ced958cd0358aeab38dcd) 位于同一个匿名联合体（Anonymous Union），分别提供参数值或参数指针。

```c
struct i3c_config_custom {
    uint32_t id;
    union {
        uintptr_t val;
        void *ptr;
    };
};
```

| 字段 | 类型 | 含义 |
| --- | --- | --- |
| [`id`](https://docs.zephyrproject.org/latest/doxygen/html/structi3c__config__custom.html#a8a9c0173d3439ed1ed10e8c7013bdb31) | [`uint32_t`](https://docs.zephyrproject.org/latest/doxygen/html/stdint_8h.html#a0a8582351ac627ee8bde2973c825e47f) | 配置参数的标识符（Identifier，ID）。 |
| `val` | [`uintptr_t`](https://docs.zephyrproject.org/latest/doxygen/html/stdint_8h.html#a4788399d1d0b37ccf098a7da82254808) | 配置参数的值。 |
| `ptr` | `void *` | 指向配置参数的指针，主要指向驱动能理解的结构体。 |
