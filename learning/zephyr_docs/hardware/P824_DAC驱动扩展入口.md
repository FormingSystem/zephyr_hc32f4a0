# 第824章\_DAC驱动扩展入口

原文：[group__dac__interface__ext](https://docs.zephyrproject.org/latest/doxygen/html/group__dac__interface__ext.html)。读取日期：2026-10-13，`latest`。

本页是数模转换器（Digital-to-Analog Converter，DAC）的器件专用应用程序接口扩展（Device-Specific API Extensions）入口。原页只列出下面一个主题，没有额外正文。

## 824.1\_DAC161S997扩展

[DAC161S997扩展接口](P828_DAC161S997扩展接口.md)：Texas Instruments（TI）的16位单通道串行外设接口（Serial Peripheral Interface，SPI）DAC，用于4至20毫安（Milliampere，mA）电流环（Current Loop）。

相关设备配置见[DAC161S997绑定译文](P804_DAC161S997数模转换器绑定.md)。扩展接口译文说明错误回调，绑定译文说明设备树配置。
