# 第315章\_I2C目标驱动函数表

原文：[structi2c__target__driver__api](https://docs.zephyrproject.org/latest/doxygen/html/structi2c__target__driver__api.html)。读取日期：2026-10-13，`latest`。

## 315.1\_结构约定

结构 [`i2c_target_driver_api`](https://docs.zephyrproject.org/latest/doxygen/html/structi2c__target__driver__api.html) 是每个集成电路间总线（Inter-Integrated Circuit，I²C）目标设备（Target）驱动需定义的应用程序接口（Application Programming Interface，API）结构，声明来自 `zephyr/drivers/i2c.h`。它保存实现操作的函数指针及其他驱动专用常量数据。

必需（Required，REQ）成员必须设置，可选（Optional，OPT）成员可以不实现；本页列出的两个成员均为必需。
