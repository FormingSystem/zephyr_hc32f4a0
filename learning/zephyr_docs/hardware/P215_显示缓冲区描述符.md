# 第215章\_显示缓冲区描述符

原文：[structdisplay__buffer__descriptor](https://docs.zephyrproject.org/latest/doxygen/html/structdisplay__buffer__descriptor.html)。读取日期：2026-10-13，`latest`。

## 215.1\_用途

结构 [`display_buffer_descriptor`](https://docs.zephyrproject.org/latest/doxygen/html/structdisplay__buffer__descriptor.html) 描述显示数据缓冲区布局（Display Data Buffer Layout），定义来自官方头文件 `zephyr/drivers/display.h`，供[显示读写接口](P214_显示公共接口.md)使用。

## 215.2\_数据字段（Data Fields）

| 字段 | 类型 | 含义 |
| --- | --- | --- |
| [`buf_size`](https://docs.zephyrproject.org/latest/doxygen/html/structdisplay__buffer__descriptor.html#aee9f34a6944b8e28622ab06d6907d40a) | [`uint32_t`](https://docs.zephyrproject.org/latest/doxygen/html/stdint_8h.html#a0a8582351ac627ee8bde2973c825e47f) | 数据缓冲区大小，以**字节**为单位。 |
| [`width`](https://docs.zephyrproject.org/latest/doxygen/html/structdisplay__buffer__descriptor.html#aa35cf372266199308211d28dae789be3) | [`uint16_t`](https://docs.zephyrproject.org/latest/doxygen/html/stdint_8h.html#a5debae8b2a1ec20a6694c0c443ee399e) | 数据缓冲区行宽，以像素为单位。 |
| [`height`](https://docs.zephyrproject.org/latest/doxygen/html/structdisplay__buffer__descriptor.html#a572c6560903553b6853360fd29631b95) | [`uint16_t`](https://docs.zephyrproject.org/latest/doxygen/html/stdint_8h.html#a5debae8b2a1ec20a6694c0c443ee399e) | 数据缓冲区列高，以像素为单位。 |
| [`pitch`](https://docs.zephyrproject.org/latest/doxygen/html/structdisplay__buffer__descriptor.html#a00d7d8da4e61f404ad353b9a8f49b2eb) | [`uint16_t`](https://docs.zephyrproject.org/latest/doxygen/html/stdint_8h.html#a5debae8b2a1ec20a6694c0c443ee399e) | 数据缓冲区相邻两行之间的像素数，即行跨度（Pitch）。 |
| [`frame_incomplete`](https://docs.zephyrproject.org/latest/doxygen/html/structdisplay__buffer__descriptor.html#a29e49359561cc0c601196eb9cf1f93b7) | [`bool`](https://docs.zephyrproject.org/latest/doxygen/html/stdbool_8h.html#abb452686968e48b67397da5f97445f5b) | 表示这不是当前帧的最后一个写入缓冲区。 |

> 译注：`pitch` 的单位是像素，`buf_size` 的单位是字节；调用时需要保留这种单位区别。
