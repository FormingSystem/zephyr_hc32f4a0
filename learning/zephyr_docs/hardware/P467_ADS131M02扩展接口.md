# 第467章\_ADS131M02扩展接口

原文：[group__ads131m02__interface](https://docs.zephyrproject.org/latest/doxygen/html/group__ads131m02__interface.html)。读取日期：2026-10-13，`latest`。

## 467.1\_用途与头文件

ADS131M02 是 Texas Instruments（德州仪器）的双通道 **SPI（Serial Peripheral Interface，串行外设接口）模数转换器（Analog-to-Digital Converter，ADC）**。本页是它的扩展应用程序接口（Application Programming Interface，API）。

```c
#include <zephyr/drivers/adc/ads131m02.h>
```

## 467.4\_ads131m02_set_adc_mode

设置 ADC 模式。`dev` 指向驱动实例设备结构，`mode` 是目标 ADC 模式。当 `mode` 为 [`ADS131M02_GLOBAL_CHOP_MODE`](https://docs.zephyrproject.org/latest/doxygen/html/group__ads131m02__interface.html#ggad760dc7a7036158af94ced3d9e8c6723aefc260abb9c9ce184fbb7216e6e45de2) 时，`gc_delay` 指定全局斩波延迟。

```c
int ads131m02_set_adc_mode( const struct device * dev, enum ads131m02_adc_mode mode, enum ads131m02_gc_delay gc_delay );
```

成功返回 0，失败返回负的 errno 错误码。


## 467.5\_ads131m02_set_power_mode

设置功耗模式。`dev` 指向驱动实例设备结构，`mode` 是要设置的功耗模式。

```c
int ads131m02_set_power_mode( const struct device * dev, enum ads131m02_adc_power_mode mode );
```

成功返回 0，失败返回负的 errno 错误码。
