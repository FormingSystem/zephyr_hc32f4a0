# 第143章\_蜂鸣器音调示例

原文：[Buzzer Tone](https://docs.zephyrproject.org/latest/samples/drivers/buzzer/tone/README.html)。读取日期：2026-10-13，`latest`。

## 143.1\_提示音与三个音调

本应用通过 **设备树别名（Devicetree Alias）** `buzzer0` 对应的 **蜂鸣器（Buzzer）**先播放一个短提示音，再播放三个音调，每三秒重复一次。设备树介绍见[本地章节](../devicetree/P001_设备树介绍.md)。

示例使用高层蜂鸣器 **应用程序编程接口（Application Programming Interface，API）**，调用蜂鸣函数 [`buzzer_beep()`](P144_蜂鸣器接口参考.md) 与音调函数 [`buzzer_tone()`](P144_蜂鸣器接口参考.md)，同时支持两个后端：

- [pwm-buzzer](../sound_haptic_binding_reference/P003_pwm-buzzer.md#std-dtcompatible-pwm-buzzer)：驱动接到 **脉宽调制（Pulse Width Modulation，PWM）**通道的 **无源压电蜂鸣器（Passive Piezo Buzzer）**。
- [gpio-buzzer](../sound_haptic_binding_reference/P002_gpio-buzzer.md#std-dtcompatible-gpio-buzzer)：驱动单根 **通用输入输出（General-Purpose Input/Output，GPIO）**线路控制的 **有源蜂鸣器（Active Buzzer）**。该后端忽略音高信息。

## 143.2\_开发板要求

目标板必须通过 `buzzer0` 别名提供蜂鸣器设备。如果其 **设备树源码（Devicetree Source，DTS）**没有配置蜂鸣器，可以在示例的 `boards/` 子目录提供 `<board>.overlay` **覆盖文件（Overlay）**；文件名中的 `<board>` 对应目标板。

## 143.3\_原始构建与运行命令

下面是原页的west构建、烧录命令，从Zephyr仓库根目录执行：

```sh
# From the root of the zephyr repository
west build -b None samples/drivers/buzzer/tone
west flash
```

> 译注：原页生成的构建命令包含 `-b None`，没有给出可直接使用的开发板目标。实际使用时须把 `None` 替换为已配置蜂鸣器及 `buzzer0` 别名的真实目标名。此处保留原命令，未将 `None` 当作有效开发板，也未执行烧录或播放。
