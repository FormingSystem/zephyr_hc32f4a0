# 第555章\_性能状态绑定

<a id="dtbinding-zephyr-pstate"></a>

原文：[zephyr,pstate](https://docs.zephyrproject.org/latest/build/dts/api/bindings/p_state/zephyr,pstate.html)。读取日期：2026-10-13，`latest`。

`zephyr,pstate` 定义**性能状态（Performance State，P-state）**的通用属性，提供方是 Zephyr Project。原页没有列出专用驱动文件，相关开发板见[官方筛选目录](https://docs.zephyrproject.org/latest/boards/index.html#compatibles=zephyr,pstate)。

## 555.1\_负载阈值

属性 `load-threshold` 的类型为整数 `int`，表示进入此性能状态的**中央处理器（Central Processing Unit，CPU）**负载阈值，单位为百分比。当 CPU 负载超过阈值后，此状态成为 P-state 驱动可以切换到的有效状态。

原页没有已弃用的节点专用属性，基础属性列表为空。
