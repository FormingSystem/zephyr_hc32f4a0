# 第185章\_字符帧缓冲字体结构

原文：[structcfb__font](https://docs.zephyrproject.org/latest/doxygen/html/structcfb__font.html)。读取日期：2026-10-13，`latest`。

## 185.1\_结构来源

[`cfb_font`](https://docs.zephyrproject.org/latest/doxygen/html/structcfb__font.html) 是 **字符帧缓冲（Character Framebuffer，CFB）**使用的字体结构（Font Structure），定义来自官方头文件 `zephyr/display/cfb.h`。

## 185.2\_数据字段（Data Fields）

| 字段 | 原始类型 | 对应含义 |
| --- | --- | --- |
| [`data`](https://docs.zephyrproject.org/latest/doxygen/html/structcfb__font.html#abe8771187455817e8085a42820079aea) | `const void *` | 字体原始数据（Raw Data）指针。 |
| [`caps`](https://docs.zephyrproject.org/latest/doxygen/html/structcfb__font.html#a4ac3e8578e577909058fdcd8bce62f3b) | `enum cfb_font_caps` | 字体能力（Font Capabilities）标志。 |
| [`width`](https://docs.zephyrproject.org/latest/doxygen/html/structcfb__font.html#ab58695cca74151c86f442366bd80a039) | [`uint8_t`](https://docs.zephyrproject.org/latest/doxygen/html/stdint_8h.html#a3cb4a16b0e8d6af0af86d4fd6ba5fd9d) | 字体宽度（Width）。 |
| [`height`](https://docs.zephyrproject.org/latest/doxygen/html/structcfb__font.html#ad50168c069d5cda8e924ba336875ef85) | [`uint8_t`](https://docs.zephyrproject.org/latest/doxygen/html/stdint_8h.html#a3cb4a16b0e8d6af0af86d4fd6ba5fd9d) | 字体高度（Height）。 |
| [`first_char`](https://docs.zephyrproject.org/latest/doxygen/html/structcfb__font.html#a204e414d8b0add418fb92914402d14e2) | [`uint8_t`](https://docs.zephyrproject.org/latest/doxygen/html/stdint_8h.html#a3cb4a16b0e8d6af0af86d4fd6ba5fd9d) | 映射到第一个字体元素的字符（First Character）。 |
| [`last_char`](https://docs.zephyrproject.org/latest/doxygen/html/structcfb__font.html#a79ca54ef1b7928c9bde7bc4d730aa417) | [`uint8_t`](https://docs.zephyrproject.org/latest/doxygen/html/stdint_8h.html#a3cb4a16b0e8d6af0af86d4fd6ba5fd9d) | 映射到最后一个字体元素的字符（Last Character）。 |

译注：原结构页仅列出字段与类型，没有独立的字段释义；上表释义根据同一官方接口中 `FONT_ENTRY_DEFINE` 的参数和成员赋值关系整理。该宏明确宽度与高度以像素计，详见[单色字符帧缓冲接口](P184_单色字符帧缓冲接口.md)。
