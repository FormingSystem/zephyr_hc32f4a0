# 第64章\_I2C_EEPROM目标设备

原文：[I2C EEPROM Target](https://docs.zephyrproject.org/latest/hardware/peripherals/i2c_eeprom_target.html)。读取日期：2026-10-13，`latest`。

## 64.1\_I2C EEPROM目标设备入口

本页对应 **集成电路间总线（Inter-Integrated Circuit，I2C）**上的 **电可擦可编程只读存储器（Electrically Erasable Programmable Read-Only Memory，EEPROM）** **目标设备（Target）**文档。原文仅设置“概览”和“接口参考”标题，没有额外概览正文、示例代码或媒体。

## 64.2\_接口参考

具体 **应用程序编程接口（Application Programming Interface，API）**见[I2C EEPROM目标设备参考](P313_I2CEEPROM目标接口.md)。此处保留它在官方目录中的独立入口，不把普通EEPROM存储设备的读写文档冒充为该目标设备接口的实现说明。
