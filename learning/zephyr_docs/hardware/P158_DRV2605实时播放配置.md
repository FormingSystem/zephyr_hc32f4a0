# 第158章\_DRV2605实时播放配置

原文：[structdrv2605__rtp__data](https://docs.zephyrproject.org/latest/doxygen/html/structdrv2605__rtp__data.html)。读取日期：2026-10-13，`latest`。

## 158.1\_实时播放配置

[`drv2605_rtp_data`](https://docs.zephyrproject.org/latest/doxygen/html/structdrv2605__rtp__data.html) 用于DRV2605的 **实时播放（Real-Time Playback，RTP）**源，对应 [`DRV2605_HAPTICS_SOURCE_RTP`](https://docs.zephyrproject.org/latest/doxygen/html/group__drv2605__interface.html#ggae98fe02355253b7d8f4583a36919639ca51dd1dcc3db5a89efd31a9f72c7db43a)，允许流式播放自定义触觉波形。头文件为 `zephyr/drivers/haptics/drv2605.h`。

## 158.2\_三个字段与数组对应关系

| 字段 | 类型 | 含义 |
| --- | --- | --- |
| [`size`](https://docs.zephyrproject.org/latest/doxygen/html/structdrv2605__rtp__data.html#aa9025d92cc16f39d15042b9b41209c0c) | `size_t` | [`rtp_hold_us`](https://docs.zephyrproject.org/latest/doxygen/html/structdrv2605__rtp__data.html#a928e62ef97eccfc70d2c777ad58c98f0) 与 [`rtp_input`](https://docs.zephyrproject.org/latest/doxygen/html/structdrv2605__rtp__data.html#a358f8d7119dbcc42f0b42f41f307c237) 两个数组的条目数量。 |
| [`rtp_hold_us`](https://docs.zephyrproject.org/latest/doxygen/html/structdrv2605__rtp__data.html#a928e62ef97eccfc70d2c777ad58c98f0) | `uint32_t *` | 指向保持时间数组。每项以微秒为单位，规定对应 [`rtp_input`](https://docs.zephyrproject.org/latest/doxygen/html/structdrv2605__rtp__data.html#a358f8d7119dbcc42f0b42f41f307c237) 振幅应保持多久。 |
| [`rtp_input`](https://docs.zephyrproject.org/latest/doxygen/html/structdrv2605__rtp__data.html#a358f8d7119dbcc42f0b42f41f307c237) | `uint8_t *` | 指向8位RTP振幅数组，值写入RTP输入寄存器 `0x02`。 |

振幅值按设备配置可以解释为有符号值或无符号值。原C指针类型仍为 `uint8_t *`，其存储类型不单独决定设备对振幅编码的解释。

把本结构用于[配置联合体](P159_DRV2605配置联合体.md)的RTP分支，再通过[DRV2605配置函数](P154_DRV2605触觉扩展.md)选择相应源。
