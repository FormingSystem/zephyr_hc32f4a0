# 第133章\_数字可寻址照明接口

原文：[DALI](https://docs.zephyrproject.org/latest/hardware/peripherals/dali.html)。读取日期：2026-10-13，`latest`。

## 133.1\_专业照明通信标准

**数字可寻址照明接口（Digital Addressable Lighting Interface，DALI）**是用于专业照明方案的通信标准。原文指出：该 **应用程序编程接口（Application Programming Interface，API）**尚不稳定，可能变化。

## 133.2\_总线帧交换

DALI采用通过总线系统交换 **帧（Frame）**的通信模型。每一帧由 **曼彻斯特编码（Manchester Encoding）**数据构成，并以 **停止条件（Stop Condition）**结束。DALI标准对发送器与接收器的行为有特定要求。

## 133.3\_配置与接口

相关Kconfig配置项为 [`CONFIG_DALI`](https://docs.zephyrproject.org/latest/kconfig.html#CONFIG_DALI) 和 [`CONFIG_DALI_PWM`](https://docs.zephyrproject.org/latest/kconfig.html#CONFIG_DALI_PWM)；Kconfig是Zephyr配置系统，PWM表示 **脉宽调制（Pulse Width Modulation）**。完整声明见[DALI API](https://docs.zephyrproject.org/latest/doxygen/html/group__dali__interface.html)。
