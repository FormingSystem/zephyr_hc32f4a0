# 第118章\_时钟频率测量示例

原文：[Clock Monitor Frequency Meter](https://docs.zephyrproject.org/latest/samples/drivers/clock_monitor/measure_freq/README.html)。读取日期：2026-10-13，`latest`。

## 118.1\_一次测量与应用超时

本示例使用 **时钟监视器（Clock Monitor）**的 **应用程序编程接口（Application Programming Interface，API）**，在测量模式枚举 [`CLOCK_MONITOR_MODE_MEASURE`](../timer_reference/P098_时钟监控公共接口.md) 下，每调用一次 [`clock_monitor_start()`](../timer_reference/P098_时钟监控公共接口.md) 就进行一次测量。

示例展示常用等待方式：**回调函数（Callback Function）**释放 **信号量（Semaphore）**，`main()` 按自身设置的超时时间等待，再用 [`clock_monitor_get_rate()`](../timer_reference/P098_时钟监控公共接口.md) 读取结果。

API不提供阻塞等待，因此**超时由应用负责**。超时后，示例调用 [`clock_monitor_stop()`](../timer_reference/P098_时钟监控公共接口.md) 中止测量；成功路径不需要停止操作，因为设备在回调运行前已自动停止本轮测量。

测量窗口由示例Kconfig配置项 `CONFIG_SAMPLE_WINDOW_NS` 设置；Kconfig是Zephyr配置系统，ns为纳秒。概览见[时钟监视器](P102_时钟监视器.md)。

## 118.2\_所需设备与覆盖文件

开发板必须通过 **设备树别名（Devicetree Alias）** `clock-meter` 暴露一个时钟监视器。注意此处别名与频率检查示例的 `clock-monitor` 不同。

基于NXP **频率测量（Frequency Measurement，FREQME）**外设的开发板还需要共享 **设备树覆盖文件（Devicetree Overlay）** [clock_monitor.overlay](https://github.com/zephyrproject-rtos/zephyr/blob/main/samples/drivers/clock_monitor/clock_monitor.overlay)，位于源码的 `samples/drivers/clock_monitor/`。

## 118.3\_构建与运行

以下原命令从Zephyr源码目录使用west工作区工具构建、烧录FRDM-MCXE31B目标；FRDM是NXP开发板系列标识。

```sh
west build -b frdm_mcxe31b samples/drivers/clock_monitor/measure_freq
west flash
```

使用FREQME外设的板卡需要共享覆盖文件。原例以FRDM-MCXN236为目标，用 `EXTRA_DTC_OVERLAY_FILE` 构建变量指定附加覆盖文件：

```sh
west build -b frdm_mcxn236 samples/drivers/clock_monitor/measure_freq -- -DEXTRA_DTC_OVERLAY_FILE="../clock_monitor.overlay"
west flash
```

## 118.4\_测量结果与时钟丢失日志

原输出中，设备以 **测量模式（Measure Mode）**配置，窗口为1000000 ns，结果为48000000 Hz（赫兹），即48 MHz：

```text
[00:00:00.000,000] <inf> sample: cmu-fm@2bc020 configured in MEASURE mode, window = 1000000 ns
[00:00:00.001,000] <inf> sample: Measured frequency = 48000000 Hz
```

如果被监视时钟停止产生边沿，驱动改为报告时钟丢失。原日志将这一类事件标记为 `FMTO-class event`；这里保留该原始事件标签，并不把硬件报告与应用自身等待超时混为一谈。

```text
[00:00:00.001,000] <wrn> sample: monitored clock lost (FMTO-class event)
```
