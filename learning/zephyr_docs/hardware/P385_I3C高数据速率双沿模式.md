# 第385章\_I3C高数据速率双沿模式

原文：[group__i3c__hdr__ddr](https://docs.zephyrproject.org/latest/doxygen/html/group__i3c__hdr__ddr.html)。读取日期：2026-10-13，`latest`。

## 385.1\_模式与公共返回值

本页为**改进的集成电路间总线（Improved Inter-Integrated Circuit，I3C）**提供**高数据速率（High Data Rate，HDR）双倍数据速率（Double Data Rate，DDR）**模式的应用程序编程接口（Application Programming Interface，API）。相关头文件为 `zephyr/drivers/i3c/hdr_ddr.h`。

三个函数均为静态内联函数（Static Inline Function），目标参数 `target` 均指向 `struct i3c_device_desc` 描述的**目标设备（Target Device）**。返回值相同：

| 返回值 | 含义 |
| --- | --- |
| `0` | 成功。 |
| `-EBUSY` | 总线忙。 |
| `-EIO` | 通用输入/输出（Input/Output，I/O）错误。 |

## 385.2\_同步写入

```c
static inline int i3c_hdr_ddr_write(struct i3c_device_desc *target,
                                   uint8_t cmd, uint8_t *buf,
                                   uint32_t num_bytes);
```

[`i3c_hdr_ddr_write()`](https://docs.zephyrproject.org/latest/doxygen/html/group__i3c__hdr__ddr.html#ga9bf00a59c3c08f4bf1ffd5ae32c0fad8) 使用 HDR DDR 模式，同步向 I3C 目标设备写入指定数量的数据。

| 参数 | 含义 |
| --- | --- |
| `target` | I3C 目标设备描述符。 |
| [`cmd`](https://docs.zephyrproject.org/latest/doxygen/html/group__ft8xx__reference__api.html#gacde1ca3945cbe6c828f65051c5c3a615) | 7 位命令码（Command Code）。 |
| `buf` | 数据来源内存池。 |
| `num_bytes` | 要写入的字节数。 |

## 385.3\_同步读取

```c
static inline int i3c_hdr_ddr_read(struct i3c_device_desc *target,
                                  uint8_t cmd, uint8_t *buf,
                                  uint32_t num_bytes);
```

[`i3c_hdr_ddr_read()`](https://docs.zephyrproject.org/latest/doxygen/html/group__i3c__hdr__ddr.html#ga11e788383aeb52184fdd6483cf702d40) 使用 HDR DDR 模式，同步从 I3C 目标设备读取指定数量的数据。

| 参数 | 含义 |
| --- | --- |
| `target` | I3C 目标设备描述符。 |
| [`cmd`](https://docs.zephyrproject.org/latest/doxygen/html/group__ft8xx__reference__api.html#gacde1ca3945cbe6c828f65051c5c3a615) | 7 位命令码。 |
| `buf` | 保存读出数据的内存池。 |
| `num_bytes` | 要读取的字节数。 |

## 385.4\_组合写后读

```c
static inline int i3c_hdr_ddr_write_read(
    struct i3c_device_desc *target, const void *write_buf,
    size_t num_write, uint8_t read_cmd, void *read_buf,
    size_t num_read, uint8_t write_cmd);
```

[`i3c_hdr_ddr_write_read()`](https://docs.zephyrproject.org/latest/doxygen/html/group__i3c__hdr__ddr.html#gaa752f1095c84ad1b94fb09cc0aeee4fa) 通过一次组合的写后读总线事务（Write-then-read Bus Transaction），支持常见的“这是我要的内容”“现在把它给我”的成对操作。

| 参数 | 含义 |
| --- | --- |
| `target` | I3C 目标设备描述符。 |
| `write_buf` | 指向待写入数据的指针。 |
| `num_write` | 要写入的字节数。 |
| `read_cmd` | 读取所用的 7 位命令码。 |
| `read_buf` | 读取数据的存储位置。 |
| `num_read` | 要读取的字节数。 |
| `write_cmd` | 写入所用的 7 位命令码。 |

> 译注：这里保留原函数签名的参数顺序：`read_cmd` 位于 `read_buf` 之前，`write_cmd` 位于最后，不能按读写动作发生顺序自行调换。
