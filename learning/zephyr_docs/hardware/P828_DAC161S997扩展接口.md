# 第828章\_DAC161S997扩展接口

原文：[group__dac161s997__interface](https://docs.zephyrproject.org/latest/doxygen/html/group__dac161s997__interface.html)。读取日期：2026-10-13，`latest`。

Texas Instruments（TI）DAC161S997是16位、单通道、串行外设接口（Serial Peripheral Interface，SPI）数模转换器（Digital-to-Analog Converter，DAC），用于4至20毫安（Milliampere，mA）电流环（Current Loop）。本页定义其扩展应用程序接口（Application Programming Interface，API）。

公共头文件为[扩展头文件](P830_DAC161S997扩展头文件.md) `zephyr/drivers/dac/dac161s997.h`，状态数据使用[状态联合体](P829_DAC161S997状态联合体.md) `union dac161s997_status`。设备树配置见[DAC161S997绑定](P804_DAC161S997数模转换器绑定.md)。

```c
#include <zephyr/drivers/dac/dac161s997.h>
```

## 828.1\_错误回调类型

```c
typedef void (*dac161s997_error_callback_t)(
    const struct device *dev, const union dac161s997_status *status);
```

错误回调（Error Callback）在发生错误时被调用，函数无返回值。

| 参数 | 含义 |
| --- | --- |
| `dev` | 指向设备的指针 |
| `status` | 无法读取状态时为 `NULL`；否则指向状态数据 |

`NULL` 表示空指针（Null Pointer）。读取失败时不能直接访问 `status` 指向的字段。

## 828.2\_设置错误回调

```c
int dac161s997_set_error_callback(const struct device *dev,
                                 dac161s997_error_callback_t cb);
```

设置错误触发时调用的回调。**回调在工作队列上下文（Work Queue Context）中执行，且执行期间设备处于锁定状态（Locked）。**

| 参数 | 含义 |
| --- | --- |
| `dev` | 指向设备的指针 |
| `cb` | 错误触发时调用的回调函数 |

成功返回0；失败返回负错误码（Negative Error Code），原文记为 `-errno`。原页没有进一步列出具体错误码。
