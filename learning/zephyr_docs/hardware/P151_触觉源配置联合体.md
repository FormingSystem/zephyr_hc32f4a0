# 第151章\_触觉源配置联合体

原文：[unionhaptics__config](https://docs.zephyrproject.org/latest/doxygen/html/unionhaptics__config.html)。读取日期：2026-10-13，`latest`。

## 151.1\_波形索引与数字音频配置

[`haptics_config`](https://docs.zephyrproject.org/latest/doxygen/html/unionhaptics__config.html) 是 **触觉源配置（Haptics Source Configuration）**联合体，定义于 `zephyr/drivers/haptics.h`。多数触觉驱动提供预编程效果，或允许运行时编程新效果；这些效果通常存入 **波形表（Wavetable）**，单个效果通过索引引用。

用 [`haptics_select_source()`](https://docs.zephyrproject.org/latest/doxygen/html/group__haptics__interface.html#ga891fa4c05a4844a658603651e8aabfc5) 选择波形表中特定效果时，使用 [`idx`](https://docs.zephyrproject.org/latest/doxygen/html/unionhaptics__config.html#a69acebb965540a2e65e8d96d13712801) 成员。另一成员 [`dai`](https://docs.zephyrproject.org/latest/doxygen/html/unionhaptics__config.html#a95f9bcd56601626b8c97d2e98a3e2abf) 用于指定 **数字音频接口（Digital Audio Interface，DAI）**总线配置，特别是 **集成电路间音频总线（Inter-IC Sound，I2S）**和 **脉冲编码调制（Pulse-Code Modulation，PCM）**。

## 151.2\_全部成员

| 成员 | 类型 | 含义 |
| --- | --- | --- |
| `idx` | [`uint32_t`](https://docs.zephyrproject.org/latest/doxygen/html/stdint_8h.html#a0a8582351ac627ee8bde2973c825e47f) | 从内存中的波形列表选择效果索引。 |
| `dai` | 匿名结构体 | “音频转触觉（Audio to Haptics）”功能的数字音频配置。 |
| `dai.type` | [`audio_dai_type_t`](https://docs.zephyrproject.org/latest/doxygen/html/group__audio__codec__interface.html#ga147094be4c7c5d62df695673d293f12d) | 数字音频接口类型，例如I2S。 |
| `dai.cfg` | [`audio_dai_cfg_t`](https://docs.zephyrproject.org/latest/doxygen/html/unionaudio__dai__cfg__t.html) | 数字音频接口的详细配置。 |

原自动参考在字段标题中把嵌套成员列为 `haptics_config::type` 与 `haptics_config::cfg`；本表按其匿名结构 `dai` 的层级写出访问关系，避免误把它们当作与 `idx` 并列的独立联合体分支。

数字音频类型见 [`audio_dai_type_t`](https://docs.zephyrproject.org/latest/doxygen/html/group__audio__codec__interface.html#ga147094be4c7c5d62df695673d293f12d)，配置见 [`audio_dai_cfg_t`](https://docs.zephyrproject.org/latest/doxygen/html/unionaudio__dai__cfg__t.html)。使用条件见[触觉公共接口](P147_触觉反馈接口参考.md)。
