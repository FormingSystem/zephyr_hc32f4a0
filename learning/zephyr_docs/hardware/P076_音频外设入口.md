## 76.1\_音频外设目录

原文 **音频（Audio）**目录按下列顺序提供四个入口，分别涉及编解码器、麦克风采集、串行音频总线和通用驱动接口。

| 文档 | 中英文名称 |
| --- | --- |
| [音频编解码器](P077_音频编解码器.md) | **音频编解码器（Audio Codec）**。 |
| [数字麦克风](P079_数字麦克风.md) | **数字麦克风（Digital Microphone，DMIC）**。 |
| [I2S数字音频总线](P080_I2S数字音频总线.md) | **芯片间声音总线（Inter-IC Sound，I2S）**。 |
| [数字音频接口](P078_数字音频接口.md) | **数字音频接口（Digital Audio Interface，DAI）**。 |

原页只有这些目录项，没有额外配置命令或媒体；各类设备的具体职责和接口约束见对应章节。
