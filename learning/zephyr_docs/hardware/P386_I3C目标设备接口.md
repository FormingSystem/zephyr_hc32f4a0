# 第386章\_I3C目标设备接口

原文：[group__i3c__target__device](https://docs.zephyrproject.org/latest/doxygen/html/group__i3c__target__device.html)。读取日期：2026-10-13，`latest`。

## 386.1\_目标设备角色

本页介绍**改进的集成电路间总线（Improved Inter-Integrated Circuit，I3C）**的**目标设备（Target Device）**应用程序编程接口（Application Programming Interface，API）。目标设备响应总线控制器发起的访问。头文件为 `zephyr/drivers/i3c/target_device.h`。

相关类型与后端接口：

- `struct i3c_config_target`：使 I3C 硬件作为目标设备运行的配置参数。
- [目标设备配置结构](P388_I3C目标设备配置.md)：`struct i3c_target_config`。
- [目标设备回调表](P389_I3C目标设备回调表.md)：`struct i3c_target_callbacks`。
- [目标设备驱动后端](P387_I3C目标设备驱动后端.md)。

以下函数均为静态内联函数（Static Inline Function）。它们的 `dev` 参数均指向配置为目标模式的 I3C 控制器驱动的设备结构。

## 386.2\_接受或拒绝控制权移交

```c
static inline int i3c_target_controller_handoff(
    const struct device *dev, bool accept);
```

[`i3c_target_controller_handoff()`](https://docs.zephyrproject.org/latest/doxygen/html/group__i3c__target__device.html#ga09be7f73861bede0071fd8ade344d092) 设置目标设备如何应答当前活动控制器通过**通用命令码（Common Command Code，CCC）** `GETACCCR` 发起的控制权移交（Controller Handoff）。

[`accept`](https://docs.zephyrproject.org/latest/doxygen/html/posix_2sys_2socket_8h.html#a66e3de379c18201b21c889035ec54864) 为 `true` 时，使用**确认应答（Acknowledgement，ACK）**接受移交；为 `false` 时，使用**否定应答（Negative Acknowledgement，NACK）**拒绝移交。成功返回 0。

## 386.3\_注册目标设备

```c
static inline int i3c_target_register(const struct device *dev,
                                      struct i3c_target_config *cfg);
```

[`i3c_target_register()`](https://docs.zephyrproject.org/latest/doxygen/html/group__i3c__target__device.html#gaf13d2b84a91e17d5ec49a41e9c553d42) 使用配置结构 `cfg` 为 `dev` 所对应的 I3C 总线驱动启用目标模式。`cfg` 包含传递总线事件所需的函数和参数。与目标模式有关的 I3C 总线事件通过其 `callbacks` 成员中的回调函数传给 I3C 目标设备驱动。

多数现有硬件可以同时支持主控（Master）和目标模式，但接口不保证所有硬件都支持。

| 返回值 | 含义 |
| --- | --- |
| `0` | 成功。 |
| `-EINVAL` | 参数无效。 |
| `-EIO` | 通用输入/输出（Input/Output，I/O）错误。 |
| `-ENOSYS` | 未实现目标模式。 |

## 386.4\_向发送FIFO填入数据

```c
static inline int i3c_target_tx_write(const struct device *dev,
                                      uint8_t *buf, uint16_t len,
                                      uint8_t hdr_mode);
```

[`i3c_target_tx_write()`](https://docs.zephyrproject.org/latest/doxygen/html/group__i3c__target__device.html#gafb5ebdfd5536ee265a3719beb8ae81dc) 把给定缓冲区的数据写入目标设备的**发送先进先出队列（Transmit First In, First Out Queue，TX FIFO）**。部分 I3C 目标设备在发送队列有数据之前，会对读取请求作 NACK 应答。

此函数尽可能向 FIFO 写入数据，并返回实际写入的总字节数。应用程序负责利用目标回调继续写入剩余数据。负数返回值表示错误。多数现有硬件可以同时支持主控和目标模式，但这并非保证。

| 参数 | 含义 |
| --- | --- |
| `dev` | 配置为目标模式的 I3C 控制器驱动设备。 |
| `buf` | 缓冲区指针。 |
| `len` | 缓冲区长度。 |
| `hdr_mode` | 高数据速率（High Data Rate，HDR）模式，参见 `I3C_MSG_HDR_MODE*` 模式常量。 |

| 返回值 | 含义 |
| --- | --- |
| 非负数 | 实际写入的总字节数。 |
| `-ENOTSUP` | 当前不在目标模式，或者不支持指定 HDR 模式。 |
| `-ENOSPC` | TX FIFO 没有空间。 |
| `-ENOSYS` | 未实现目标模式。 |

## 386.5\_注销目标设备

```c
static inline int i3c_target_unregister(const struct device *dev,
                                        struct i3c_target_config *cfg);
```

[`i3c_target_unregister()`](https://docs.zephyrproject.org/latest/doxygen/html/group__i3c__target__device.html#ga3dc0e6451fb13fa063c5ec3e18fe22e4) 使用给定配置结构 `cfg`，禁用 `dev` 对应 I3C 总线驱动的目标模式。`cfg` 包含目标驱动传递总线事件所用的函数和参数。

成功返回 0；参数无效返回 `-EINVAL`；未实现目标模式返回 `-ENOSYS`。
