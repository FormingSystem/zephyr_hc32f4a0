# 第395章\_I3C传输消息

原文：[structi3c__msg](https://docs.zephyrproject.org/latest/doxygen/html/structi3c__msg.html)。读取日期：2026-10-13，`latest`。

## 395.1\_消息与硬件支持边界

`struct i3c_msg` 定义在**改进的集成电路间总线（Improved Inter-Integrated Circuit，I3C）**上执行事务的一条消息。包含头文件 `zephyr/drivers/i3c.h`。

本接口允许的部分配置，不一定被具体**片上系统（System on Chip，SoC）**的 I3C 硬件实现支持，尤其是要求在单次总线事务中从多个缓冲区读取或向多个缓冲区写入的配置。

遇到不支持的配置时，[`i3c_transfer()`](https://docs.zephyrproject.org/latest/doxygen/html/group__i3c__transfer__api.html#ga067c0f1e3c9abb6ef34ce48cb7e45cb8) 可能不会报错。在一些情况下，无论消息的 [`flags`](https://docs.zephyrproject.org/latest/doxygen/html/structi3c__msg.html#a05113fb61ebbc95ded15fcfe374c0217) 是否带有 [`I3C_MSG_RESTART`](https://docs.zephyrproject.org/latest/doxygen/html/group__i3c__transfer__api.html#gad9ff03f4fdcb117b90c17d667a49c295) 重复起始标志，驱动都会为每个消息片段生成独立事务。

## 395.2\_数据缓冲区与传输计数

| 字段 | 类型 | 含义 |
| --- | --- | --- |
| [`buf`](https://docs.zephyrproject.org/latest/doxygen/html/structi3c__msg.html#aa9d8920782b1a024b70970d60886deff) | `uint8_t *` | 以字节为单位的数据缓冲区。 |
| [`len`](https://docs.zephyrproject.org/latest/doxygen/html/structi3c__msg.html#ada6582cdd126f36e64f17f66ae3817f0) | [`uint32_t`](https://docs.zephyrproject.org/latest/doxygen/html/stdint_8h.html#a0a8582351ac627ee8bde2973c825e47f) | 缓冲区长度，单位为字节。 |
| [`num_xfer`](https://docs.zephyrproject.org/latest/doxygen/html/structi3c__msg.html#a572d9f55461561fb9a8c31e46f0ebfe5) | [`uint32_t`](https://docs.zephyrproject.org/latest/doxygen/html/stdint_8h.html#a0a8582351ac627ee8bde2973c825e47f) | 实际传输的总字节数。 |

目标设备可能发出**数据结束（End of Data，EoD）**，控制器也可能在达到缓冲区长度之前终止传输。驱动应在传输完成后写入 `num_xfer`。

## 395.3\_错误与消息标志

**单数据速率（Single Data Rate，SDR）**是下述错误类型所属的传输模式。

| 字段 | 类型 | 含义 |
| --- | --- | --- |
| [`err`](https://docs.zephyrproject.org/latest/doxygen/html/structi3c__msg.html#ae43cb150bcdec5f0bf654c794757f756) | `enum i3c_sdr_controller_error_types` | SDR 错误类型，定义来自 I3C 规范 1.1.1 第 5.1.10.2 节；预期由驱动写入。 |
| [`flags`](https://docs.zephyrproject.org/latest/doxygen/html/structi3c__msg.html#a05113fb61ebbc95ded15fcfe374c0217) | [`uint8_t`](https://docs.zephyrproject.org/latest/doxygen/html/stdint_8h.html#a3cb4a16b0e8d6af0af86d4fd6ba5fd9d) | 此消息的标志，参见[传输接口的消息标志](P394_I3C传输接口.md)。 |

## 395.4\_HDR模式与命令

**高数据速率（High Data Rate，HDR）**模式由 [`hdr_mode`](https://docs.zephyrproject.org/latest/doxygen/html/structi3c__msg.html#a53f5ef80b2cf467e9ff557be7cc568c9) 选择，[`hdr_cmd_code`](https://docs.zephyrproject.org/latest/doxygen/html/structi3c__msg.html#acab199ec89bfa84915c66e71c872a40b) 提供相应命令码。

| 字段 | 类型 | 含义 |
| --- | --- | --- |
| `hdr_mode` | [`uint8_t`](https://docs.zephyrproject.org/latest/doxygen/html/stdint_8h.html#a3cb4a16b0e8d6af0af86d4fd6ba5fd9d) | `I3C_MSG_HDR_MODE*` 表示的 HDR 传输模式；原说明称当 [`flags`](https://docs.zephyrproject.org/latest/doxygen/html/structi3c__msg.html#a05113fb61ebbc95ded15fcfe374c0217) 设置任意 `I3C_MSG_HDR_*` 时使用 HDR，否则使用 SDR。 |
| `hdr_cmd_code` | [`uint8_t`](https://docs.zephyrproject.org/latest/doxygen/html/stdint_8h.html#a3cb4a16b0e8d6af0af86d4fd6ba5fd9d) | HDR-DDR、HDR-TSP 和 HDR-TSL 的 7 位 HDR 命令码。 |

上述模式名称分别为：**双倍数据速率（Double Data Rate，DDR）**、**纯总线三元符号（Ternary Symbol Pure-bus，TSP）**、**包含传统设备总线的三元符号（Ternary Symbol Legacy-inclusive-bus，TSL）**。

> 译注：原 `hdr_mode` 字段说明使用了 `I3C_MSG_HDR_*` 泛称；[传输接口宏表](P394_I3C传输接口.md)将 `I3C_MSG_HDR` 作为消息标志，将 `I3C_MSG_HDR_MODE*` 作为模式值。两类值属于不同字段，不能把模式位掩码直接当成 [`flags`](https://docs.zephyrproject.org/latest/doxygen/html/structi3c__msg.html#a05113fb61ebbc95ded15fcfe374c0217) 中的读写/停止等消息标志。
