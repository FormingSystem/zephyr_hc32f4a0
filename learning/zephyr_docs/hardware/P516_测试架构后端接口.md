# 第516章\_测试架构后端接口

原文：[structztest__arch__api](P516_测试架构后端接口.md)。读取日期：2026-10-13，`latest`。

`struct ztest_arch_api` 是架构专用的**应用程序编程接口（Application Programming Interface，API）**结构，供测试后端提供运行及选择测试的入口。

公开头文件为 `zephyr/ztest_test.h`，源码位置为 `subsys/testsuite/ztest/include/zephyr/ztest_test.h`。原文的构建机绝对路径在这里改为公开包含名。

## 516.1\_三个函数指针字段

原页只给出以下字段声明，没有提供独立的参数或返回值描述。完整函数指针签名保留如下：

```c
void (*run_all)(const void *state, bool shuffle, int suite_iter, int case_iter);
bool (*should_suite_run)(const void *state, struct ztest_suite_node *suite);
bool (*should_test_run)(const char *suite, const char *test);
```

> 译注：按命名，[`run_all`](P516_测试架构后端接口.md) 为整体运行入口，[`should_suite_run`](P516_测试架构后端接口.md) 判断套件是否运行，[`should_test_run`](P516_测试架构后端接口.md) 判断具体测试是否运行。[`state`](https://docs.zephyrproject.org/latest/doxygen/html/parser__state_8h.html#adc6e5733fc3c22f0a7b2914188c49c90) 表示状态，`shuffle` 控制打乱顺序，`suite_iter`、`case_iter` 对应套件和用例迭代次数；两个判断接口分别接收套件节点以及套件/测试名称。原页未规定空指针输入、线程安全或额外返回码，不能据此自行添加保证。
