# 第630章\_保留内存接口

原文：[group__retained__mem__interface](https://docs.zephyrproject.org/latest/doxygen/html/group__retained__mem__interface.html)。读取日期：2026-10-13，`latest`。

保留内存（Retained Memory）应用程序编程接口（Application Programming Interface，API）自Zephyr **3.4** 引入，接口版本为 **1.0.0**。

```c
#include <zephyr/drivers/retained_mem.h>
```

这是保留内存驱动API的主头文件。驱动实现所需的类型和回调见[驱动接口](P631_保留内存驱动接口.md)，概述见[保留内存](P058_保留内存.md)。

<a id="retained-size"></a>

## 630.1\_查询区域大小

```c
ssize_t retained_mem_size(const struct device *dev);
```

<a id="gaa0b4b6db4c96054a709f803880f3091a"></a>

[`retained_mem_size()`](https://docs.zephyrproject.org/latest/doxygen/html/group__retained__mem__interface.html#gaa0b4b6db4c96054a709f803880f3091a) 返回保留内存区域大小。参数 `dev` 是所使用的保留内存设备。成功返回表示**字节数的正值**，失败返回负的错误码（errno）。

<a id="retained-read"></a>

## 630.2\_读取数据

```c
int retained_mem_read(const struct device *dev, off_t offset, uint8_t *buffer, size_t size);
```

<a id="ga47fba21400c1f7019e7bd0e8f10662b3"></a>

[`retained_mem_read()`](https://docs.zephyrproject.org/latest/doxygen/html/group__retained__mem__interface.html#ga47fba21400c1f7019e7bd0e8f10662b3) 从保留内存区域读取数据。

| 参数 | 中文说明 |
| --- | --- |
| `dev` | 使用的保留内存设备 |
| `offset` | 读取数据的起始偏移 |
| `buffer` | 存放读取结果的缓冲区（Buffer） |
| `size` | 要读取的数据大小 |

成功返回 `0`，失败返回负的错误码。

<a id="retained-write"></a>

## 630.3\_写入数据

```c
int retained_mem_write(const struct device *dev, off_t offset, const uint8_t *buffer, size_t size);
```

<a id="ga1976ac945eb7c09b8dd6121926af0c6a"></a>

[`retained_mem_write()`](https://docs.zephyrproject.org/latest/doxygen/html/group__retained__mem__interface.html#ga1976ac945eb7c09b8dd6121926af0c6a) 向保留内存区域写入数据。**写入前不需要清除底层数据。**

| 参数 | 中文说明 |
| --- | --- |
| `dev` | 使用的保留内存设备 |
| `offset` | 写入数据的起始偏移 |
| `buffer` | 要写入的数据 |
| `size` | 要写入的数据大小 |

成功返回 `0`，失败返回负的错误码。

<a id="retained-clear"></a>

## 630.4\_清除数据

```c
int retained_mem_clear(const struct device *dev);
```

<a id="ga5962d863c21cd91e259bf47abf2154d7"></a>

[`retained_mem_clear()`](https://docs.zephyrproject.org/latest/doxygen/html/group__retained__mem__interface.html#ga5962d863c21cd91e259bf47abf2154d7) 将保留内存区域的数据设置为 **`0x00`**。参数 `dev` 为使用的保留内存设备。成功返回 `0`，失败返回负的错误码。
