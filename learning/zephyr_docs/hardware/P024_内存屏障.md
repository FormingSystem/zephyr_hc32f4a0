# 第24章\_内存屏障

原文：[Barriers API](https://docs.zephyrproject.org/latest/hardware/barriers/index.html)。读取日期：2026-10-12，`latest`。

原页为**屏障（Barrier）**服务的接口入口，完整内容见[屏障服务API](../synchronization_reference/P001_内存屏障公共接口.md)。

> 译注：原页无额外讲解。此处只登记入口页完成，具体屏障函数参考仍独立记录；屏障与前面的缓存写回、失效是不同操作，不能相互替代。

> 译注——配套源码：现已补齐[屏障接口与源码参考](../synchronization_reference/大纲.md)。公共包装是否调用后端取决于配置；内建实现的指令同步回退只是编译器屏障，Arm实现另有DMB／DSB／ISB映射。具体行为应结合实际后端判断。
