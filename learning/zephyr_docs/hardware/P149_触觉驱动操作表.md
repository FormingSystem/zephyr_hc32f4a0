# 第149章\_触觉驱动操作表

原文：[structhaptics__driver__api](https://docs.zephyrproject.org/latest/doxygen/html/structhaptics__driver__api.html)。读取日期：2026-10-13，`latest`。

## 149.1\_操作表与字段要求

`haptics_driver_api` 是每个 **触觉驱动（Haptics Driver）**需要定义的 **驱动操作表（Driver Operations）**结构，包含驱动实现的函数指针，以及其他驱动特定的常量数据。头文件为 `zephyr/drivers/haptics.h`。

字段标记 **必需（Required，REQ）**时必须设置，标记 **可选（Optional，OPT）**时可省略。以下十一项全部按原文保留，其中选择源、启动输出、停止输出为必需操作，其余八项可选。
