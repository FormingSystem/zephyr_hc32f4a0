# 第56章\_存储外设入口

原文：[Memory & Storage](https://docs.zephyrproject.org/latest/hardware/peripherals/memory_storage.html)。读取日期：2026-10-13，`latest`。

## 56.1\_存储相关外设

官方“**内存与存储（Memory & Storage）**”入口覆盖 **非易失性存储器（Non-Volatile Memory）**、闪存、EEPROM和内存控制器。以下按原目录顺序保留全部八个主题；已译主题链接到本地文档，尚未翻译的主题保留官方入口。

| 文档 | 对应对象 |
| --- | --- |
| [Flash闪存](P012_Flash闪存.md) | **闪存（Flash Memory）**设备。 |
| [EEPROM入口](P035_EEPROM入口.md) | **电可擦可编程只读存储器（Electrically Erasable Programmable Read-Only Memory，EEPROM）**。 |
| [SD主机控制器](P062_SD主机控制器.md) | **安全数字卡（Secure Digital Card，SD Card）**接口。 |
| [电池后备内存](P057_电池后备内存.md) | **电池后备随机存取存储器（Battery Backed Random Access Memory，BBRAM）**。 |
| [保留内存](P058_保留内存.md) | **保留内存（Retained Memory）**。 |
| [I2C EEPROM目标设备](P064_I2C_EEPROM目标设备.md) | **集成电路间总线（Inter-Integrated Circuit，I2C）**上的EEPROM目标设备。 |
| [内存控制器](P059_内存控制器.md) | **内存控制器（Memory Controller，MEMC）**。 |
| [一次性可编程存储入口](P060_一次性可编程存储入口.md) | **一次性可编程存储器（One Time Programmable Memory，OTP）**。 |

这些入口分别描述存储介质、访问控制器或访问方式；本目录并未声称它们具有相同的掉电保持能力。
