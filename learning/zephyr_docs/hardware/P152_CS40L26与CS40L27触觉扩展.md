# 第152章\_CS40L26与CS40L27触觉扩展

原文：[group__cs40l26__interface](https://docs.zephyrproject.org/latest/doxygen/html/group__cs40l26__interface.html)。读取日期：2026-10-13，`latest`。

## 152.1\_器件与专用波形源

CS40L26／CS40L27是触觉驱动器件，支持 **线性谐振执行器（Linear Resonant Actuator，LRA）**和 **音圈电机（Voice Coil Motor，VCM）**。扩展 **应用程序编程接口（Application Programming Interface，API）**头文件为 `zephyr/drivers/haptics/cs40l26.h`。

专用播放源枚举 [`cs40l26_source`](https://docs.zephyrproject.org/latest/doxygen/html/group__cs40l26__interface.html#ga2e2d8b57fd4d7452e543acf91ebbb692) 包含 `CS40L26_SOURCE_BUZ = HAPTICS_SOURCE_PRIV_START`，表示从 **嗡鸣效果库（Buzz Library）**播放；该值从通用触觉源的私有扩展起点开始。

## 152.2\_配置ROM嗡鸣效果

函数 [`cs40l26_configure_buzz()`](https://docs.zephyrproject.org/latest/doxygen/html/group__cs40l26__interface.html#ga3e190958f3449a923d99f15cb5a435e7) 配置 **只读存储器（Read-Only Memory，ROM）**中的嗡鸣效果：

```c
int cs40l26_configure_buzz(const struct device *const dev,
                          const uint32_t frequency,
                          const uint8_t level,
                          const uint32_t duration);
```

所有参数均为输入：`dev` 指向触觉设备实例；`frequency` 为频率，单位Hz（赫兹），默认 `0xA5`；`level` 为振幅，`UINT8_MAX` 表示100%，默认 `0x40`；`duration` 为播放时长，**单位为4毫秒**。

原文指出，大振幅且供电不足时可能达到电流限制。成功返回0，失败返回小于0的值。本接口的时长单位与[CS40L5x扩展](P153_CS40L5x触觉扩展.md)不同，不应混用。
