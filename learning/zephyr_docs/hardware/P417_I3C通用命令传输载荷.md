# 第417章\_I3C通用命令传输载荷

原文：[structi3c__ccc__payload](https://docs.zephyrproject.org/latest/doxygen/html/structi3c__ccc__payload.html)。读取日期：2026-10-13，`latest`。

## 417.1\_一次CCC事务

`struct i3c_ccc_payload` 描述一次**改进的集成电路间总线（Improved Inter-Integrated Circuit，I3C）通用命令码（Common Command Code，CCC）**事务的载荷（Payload）。头文件为 `zephyr/drivers/i3c/ccc.h`。

它包含 [`ccc`](https://docs.zephyrproject.org/latest/doxygen/html/structi3c__ccc__payload.html#a45b2f35955bbb2bcaf89077e5abf3466) 与 [`targets`](https://docs.zephyrproject.org/latest/doxygen/html/structi3c__ccc__payload.html#aa93b97b77f8dff8e931731c1f9edcd86) 两个嵌套结构。前者记录命令及命令后的数据，后者记录面向各目标设备的载荷。

## 417.2\_命令部分

| 字段 | 类型 | 含义 |
| --- | --- | --- |
| `ccc.id` | [`uint8_t`](https://docs.zephyrproject.org/latest/doxygen/html/stdint_8h.html#a3cb4a16b0e8d6af0af86d4fd6ba5fd9d) | CCC 标识符（Identifier，ID），取值对应 `I3C_CCC_*`。 |
| `ccc.data` | `uint8_t *` | 指向此 CCC 数据字节数组的指针，即 CCC 帧中命令后面的字节；没有附带数据时设为 `NULL`。 |
| `ccc.data_len` | `size_t` | 可选数据数组长度，单位为字节。 |
| `ccc.num_xfer` | `size_t` | 已传输的总字节数。 |
| `ccc.err` | `enum i3c_sdr_controller_error_types` | 单数据速率（Single Data Rate，SDR）错误类型。 |

控制器可能在达到缓冲区长度之前中止传输，驱动应在传输完成后写入 `ccc.num_xfer`。

`ccc.err` 对应 I3C 规范 1.1.1 第 5.1.10.2 节规定的错误，预期由驱动写入。

## 417.3\_目标部分

**定向通用命令（Direct CCC）**通过目标数组描述各接收方及其数据。

| 字段 | 类型 | 含义 |
| --- | --- | --- |
| `targets.payloads` | `struct i3c_ccc_target_payload *` | 目标载荷数组，每项描述一个目标及与本 CCC 关联的载荷；用于 Direct CCC。 |
| `targets.num_targets` | `size_t` | 目标数量。 |

数组项格式见[通用命令目标载荷](P418_I3C通用命令目标载荷.md)。
