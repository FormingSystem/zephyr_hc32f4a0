# 第122章\_多功能电源设备示例

原文：[Multi-Function Device (MFD) with Charger, Fuel Gauge, and Regulators](https://docs.zephyrproject.org/latest/samples/drivers/mfd_charger/README.html)。读取日期：2026-10-13，`latest`。

## 122.1\_三个子系统共用多功能电源设备

本示例展示 **多功能设备（Multi-Function Device，MFD）**中的电源管理功能如何与Zephyr驱动子系统配合。凡是通过标准Zephyr接口提供充电器、电量计和稳压器功能的MFD，都属于示例的设计适用范围。

示例演示以下内容：初始化与配置MFD驱动；通过 **充电器（Charger）**的 **应用程序编程接口（Application Programming Interface，API）**监视电池充电状态与健康情况；通过 **电量计（Fuel Gauge）**API读取电池电压、**荷电状态（State of Charge，SoC）**和循环次数；通过 **稳压器（Regulator）**API控制、监视稳压器；处理设备的中断、**电源正常信号（Power-Good Signal）**及复位信号。

应用持续轮询充电器与电量计，显示实时电池及充电信息，包括：

- 充电器配置：电流限制、充电电流、电压。
- 充电状态：在线、存在、充电状态、健康状态。
- 电量计数据：电压、荷电状态、循环次数。
- 稳压器输出电压。

概览分别见[充电器](P107_充电器.md)、[电量计](P108_电量计.md)与[稳压器](P106_稳压器.md)。本章的SoC是电池荷电状态，不是片上系统缩写。

## 122.2\_设备树要求

开发板需要一个支持充电器、电量计和稳压器功能的MFD。必须在 **设备树（Devicetree）**中定义设备并设置恰当的节点标签，以便示例访问各子系统。

| 节点标签 | 接口用途 |
| --- | --- |
| `charger` | 充电器接口。 |
| `fuelgauge` | 电量计接口。 |
| `buck` | **降压稳压器（Buck Regulator）**或类似功能。 |
| `buckboost` | **升降压稳压器（Buck-Boost Regulator）**或类似功能。 |

示例提供MFD **设备树覆盖文件（Devicetree Overlay）**，展示如何为特定开发板与MFD芯片配置这些标签。应阅读目标板覆盖文件，再据此适配其他MFD。

## 122.3\_硬件连接

具体接线取决于所用MFD。详细连接应参考器件 **数据手册（Datasheet）**及目标板覆盖文件。至少需要通信总线、电源，以及正确连接至充电器和电量计子系统的电池。

## 122.4\_构建与运行

源码位于 [samples/drivers/mfd_charger](https://github.com/zephyrproject-rtos/zephyr/blob/main/samples/drivers/mfd_charger)。以下原命令使用west工作区工具构建并烧录，路径从Zephyr源码目录起算：

```sh
west build -b <board> samples/drivers/mfd_charger
west flash
```

把占位符 `<board>` 替换为目标开发板名称。如果目标板尚无MFD覆盖文件，需要在该示例的 `boards/` 子目录新建 `<board>.overlay`，写入MFD所需设备树配置；具体示例参见相应板级说明。

## 122.5\_原始输出与字段含义

输出取决于具体MFD与配置。下列原例展示充电和电池监视信息；`uA` 表示微安、`uV` 表示微伏，`CC` 表示 **恒流（Constant Current）**。日志中的 `Fast Mode (CC)` 为恒流快充模式，`SoC` 为前述荷电状态。

```text
[0:00:00.003]: Found device "charger", getting charger data
[0:00:00.006]: Current (Fast Charge): 20000 uA
[0:00:00.009]: Input Regulation Voltage: 3800000 uV
[0:00:00.012]: Current (Termination): 5000 uA
[0:00:03.021]: Fuel gauge Battery Capacity: 1000
[0:00:03.024]: Buck Output Voltage: 1300000
[0:00:03.027]: Buck Boost Output Voltage: 3300000
[0:00:03.030]: Online: Charger is active.
[0:00:03.033]: Present: Battery is Present.
[0:00:03.036]: Status: Charger is Charging.
[0:00:03.039]: Mode: Charger is in Fast Mode (CC).
[0:00:03.042]: Health: Battery is Cool.
[0:00:03.045]: Fuel gauge Voltage: 3950000
[0:00:03.048]: Fuel gauge Status 0x0
[0:00:03.051]: Fuel gauge SoC: 75
```

其中 `Online` 表示充电器活动，`Present` 表示电池存在，`Status` 表示正在充电，`Health` 所示 `Cool` 表示电池处于偏凉的温度状态。原文提醒：以上数值随实际MFD、电池荷电状态及设备配置变化；没有标注单位的原日志字段不应仅凭本例数字推定单位。
