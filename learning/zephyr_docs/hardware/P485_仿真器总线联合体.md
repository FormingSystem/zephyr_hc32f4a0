# 第485章\_仿真器总线联合体

原文：[unionemul_1_1bus](P485_仿真器总线联合体.md)。读取日期：2026-10-13，`latest`。

`union emul::bus` 是仿真器实例中的**总线联合体（Bus Union）**，保存指向仿真总线节点的指针。定义位于 `zephyr/drivers/emul.h`。

## 485.1\_节点指针成员

联合体为每种受支持的总线提供相应类型的节点指针，并提供无总线情况使用的桩。下表保留全部成员和中英文总线名称。

| 类型与成员 | 官方说明译文及名称对照 |
| --- | --- |
| `struct i2c_emul *i2c` | 集成电路间总线（Inter-Integrated Circuit，I2C）的仿真总线节点 |
| `struct espi_emul *espi` | 增强型串行外设接口（Enhanced Serial Peripheral Interface，eSPI）的仿真总线节点 |
| `struct spi_emul *spi` | 串行外设接口（Serial Peripheral Interface，SPI）的仿真总线节点 |
| `struct mspi_emul *mspi` | 多线串行外设接口（Multi-bit Serial Peripheral Interface，MSPI）的仿真总线节点 |
| `struct uart_emul *uart` | 通用异步收发器（Universal Asynchronous Receiver/Transmitter，UART）的仿真总线节点 |
| `struct no_bus_emul *none` | 仿真器没有附着于总线时使用的桩（Stub） |

> 译注：这是联合体，各成员共用存储空间；应结合外层 `struct emul` 的 `bus_type` 字段选择相符的节点类型。
