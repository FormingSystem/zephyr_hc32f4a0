# 第147章\_触觉反馈接口参考

原文：[group__haptics__interface](https://docs.zephyrproject.org/latest/doxygen/html/group__haptics__interface.html)。读取日期：2026-10-13，`latest`。

## 147.1\_接口版本与公共约定

**触觉反馈（Haptics）**的 **应用程序编程接口（Application Programming Interface，API）**用于触觉驱动。原页标注自Zephyr **4.0**引入，接口版本 **0.4.0**；头文件为 `zephyr/drivers/haptics.h`。源配置通过联合体 [`haptics_config`](P151_触觉源配置联合体.md)传递；其成员由单独结构参考页说明。

本章所有公共操作的 `dev` 参数都是触觉设备实例的结构指针。所有操作成功返回0，失败返回负的 `errno` 错误码；下文标为可选的操作若未实现，明确返回 `-ENOSYS`。驱动签名和必需性分别见[驱动后端](P148_触觉驱动后端.md)、[驱动操作表](P149_触觉驱动操作表.md)，器件专用功能见[扩展入口](P150_触觉驱动扩展入口.md)。

## 147.2\_错误类型与回调

多数触觉驱动提供运行保护功能。应用可以注册 **错误回调（Error Callback）**处理错误状态或恢复。错误枚举 [`haptics_error_type`](https://docs.zephyrproject.org/latest/doxygen/html/group__haptics__interface.html#gace3de1e9bf3ad759a618405649a5537a) 用于构造交付给应用的 **位掩码（Bitmask）**；`BIT(n)` 表示第n位标志。

| 枚举项 | 值 | 含义 |
| --- | --- | --- |
| [`HAPTICS_ERROR_OVERCURRENT`](https://docs.zephyrproject.org/latest/doxygen/html/group__haptics__interface.html#ggace3de1e9bf3ad759a618405649a5537aaa7f4e50aaa2dae83fae9a5931fa4be8f) | `BIT(0)` | 输出过流（Output Overcurrent）。 |
| [`HAPTICS_ERROR_OVERTEMPERATURE`](https://docs.zephyrproject.org/latest/doxygen/html/group__haptics__interface.html#ggace3de1e9bf3ad759a618405649a5537aaddb6c50258c48229f27cb77a01116087) | `BIT(1)` | 设备过温（Device Overtemperature）。 |
| [`HAPTICS_ERROR_UNDERVOLTAGE`](https://docs.zephyrproject.org/latest/doxygen/html/group__haptics__interface.html#ggace3de1e9bf3ad759a618405649a5537aac25c879fce04b01e1476e64f4f3cc2cf) | `BIT(2)` | 电源欠压（Power Source Undervoltage）。 |
| [`HAPTICS_ERROR_OVERVOLTAGE`](https://docs.zephyrproject.org/latest/doxygen/html/group__haptics__interface.html#ggace3de1e9bf3ad759a618405649a5537aa1149ae71af655549c1037cd79d5cee75) | `BIT(3)` | 电源过压（Power Source Overvoltage）。 |
| [`HAPTICS_ERROR_DC`](https://docs.zephyrproject.org/latest/doxygen/html/group__haptics__interface.html#ggace3de1e9bf3ad759a618405649a5537aa7ad80e7ab92d1deac3df573b1a76b331) | `BIT(4)` | 输出直流（Direct Current，DC）错误。 |

器件专用错误码必须使用从 `HAPTICS_ERROR_PRIV_START` 开始的不同位标志，例如 `BIT(5)`、`BIT(6)` 等。

错误回调函数类型为：

```c
typedef void (*haptics_error_callback_t)(const struct device *dev,
                                         const uint32_t errors,
                                         void *const user_data);
```

其中 `dev` 为设备指针，`errors` 为上述错误类型位掩码，`user_data` 为注册回调时提供的用户数据；三个参数均为输入参数。

## 147.3\_集成传感器与读数种类

部分驱动集成传感器，用于监视电源或外部 **执行器（Actuator）**的电气与物理特性，例如电压、电流、电阻。监视项枚举 [`haptics_monitor`](https://docs.zephyrproject.org/latest/doxygen/html/group__haptics__interface.html#ga2a801a325778cfa22765d68bd6f97b2f) 交给 [`haptics_monitor_get()`](https://docs.zephyrproject.org/latest/doxygen/html/group__haptics__interface.html#gabf1e580def265fe9bf95f2116d30e6b2) 获取读数，或交给 [`haptics_monitor_set()`](https://docs.zephyrproject.org/latest/doxygen/html/group__haptics__interface.html#gad379139afa8aff76647f180c80706f79) 启用测量。

| 枚举项 | 监视量 |
| --- | --- |
| [`HAPTICS_MONITOR_BEMF`](https://docs.zephyrproject.org/latest/doxygen/html/group__haptics__interface.html#gga2a801a325778cfa22765d68bd6f97b2fa1feeab298cfcabb1d64c87c20042c58f) | 反电动势（Back Electromotive Force，BEMF）。 |
| [`HAPTICS_MONITOR_CURRENT`](https://docs.zephyrproject.org/latest/doxygen/html/group__haptics__interface.html#gga2a801a325778cfa22765d68bd6f97b2fa1f8b833f578dc7dd10edea6e016eb9dd) | 电流（Amperage）。 |
| [`HAPTICS_MONITOR_F0`](https://docs.zephyrproject.org/latest/doxygen/html/group__haptics__interface.html#gga2a801a325778cfa22765d68bd6f97b2faa7fcff3f46d5e8046bd4282b94808870) | 谐振频率（Resonant Frequency）。 |
| [`HAPTICS_MONITOR_RE`](https://docs.zephyrproject.org/latest/doxygen/html/group__haptics__interface.html#gga2a801a325778cfa22765d68bd6f97b2fac7864ee15f177bb81bc38fbdd001b4c0) | 线圈电阻（Coil Resistance）。 |
| [`HAPTICS_MONITOR_AMBIENT_TEMP`](https://docs.zephyrproject.org/latest/doxygen/html/group__haptics__interface.html#gga2a801a325778cfa22765d68bd6f97b2fae9bf20d60ee4f05ec7829ad91d33349a) | 环境温度（Ambient Temperature）。 |
| [`HAPTICS_MONITOR_DIE_TEMP`](https://docs.zephyrproject.org/latest/doxygen/html/group__haptics__interface.html#gga2a801a325778cfa22765d68bd6f97b2fab5a60de2ff470c8f5f6d4801b8ae10d8) | 芯片温度（Die Temperature）。 |
| [`HAPTICS_MONITOR_VBAT`](https://docs.zephyrproject.org/latest/doxygen/html/group__haptics__interface.html#gga2a801a325778cfa22765d68bd6f97b2fa566edc86e881aad6de91333d281eefcb) | 供电电压（Supply Voltage）。 |

| [`HAPTICS_MONITOR_VOUT`](https://docs.zephyrproject.org/latest/doxygen/html/group__haptics__interface.html#gga2a801a325778cfa22765d68bd6f97b2fa72c99e1f6a03ac2cbb7a9bcfa6a2f0a2) | 放大器输出电压（Amplifier Output Voltage）。 |
| [`HAPTICS_MONITOR_ALL`](https://docs.zephyrproject.org/latest/doxygen/html/group__haptics__interface.html#gga2a801a325778cfa22765d68bd6f97b2fae5e1578253a6fa38331bc8b9949c01f8) | 全部集成传感器。 |

各驱动没有统一的集成传感器实现。有的只提供最近读数，有的会按时间聚合最小值、最大值和平均值；具体看驱动。读数种类枚举 [`haptics_monitor_type`](https://docs.zephyrproject.org/latest/doxygen/html/group__haptics__interface.html#gaf86396239e200ecf8ea00fe339e416ca) 包括 [`HAPTICS_MONITOR_TYPE_MIN`](https://docs.zephyrproject.org/latest/doxygen/html/group__haptics__interface.html#ggaf86396239e200ecf8ea00fe339e416caae3c79a961c91ce44d9238a3a7c8a066a)（最小读数）、[`HAPTICS_MONITOR_TYPE_MAX`](https://docs.zephyrproject.org/latest/doxygen/html/group__haptics__interface.html#ggaf86396239e200ecf8ea00fe339e416caa6fc1b297a872e0c72a8e4e4c21a153b7)（最大读数）、[`HAPTICS_MONITOR_TYPE_MEAN`](https://docs.zephyrproject.org/latest/doxygen/html/group__haptics__interface.html#ggaf86396239e200ecf8ea00fe339e416caa5e17304e155cc4478f21a938a90e1955)（平均读数）和 [`HAPTICS_MONITOR_TYPE_SINGLE`](https://docs.zephyrproject.org/latest/doxygen/html/group__haptics__interface.html#ggaf86396239e200ecf8ea00fe339e416caa9e2eb231c9a49e1a482c921c1943ac1a)（最近一次或单次测量读数）。

## 147.5\_GPIO触发类型

**通用输入输出（General-Purpose Input/Output，GPIO）**触发效果可以基于边沿或电平。枚举 [`haptics_trigger_type`](https://docs.zephyrproject.org/latest/doxygen/html/group__haptics__interface.html#gabd96eff4adc560173e4e887e09dcb34b) 的0值保留给禁用类型，具体支持由驱动决定。

| 枚举项 | 值 | 含义 |
| --- | --- | --- |
| [`HAPTICS_TRIGGER_NONE`](https://docs.zephyrproject.org/latest/doxygen/html/group__haptics__interface.html#ggabd96eff4adc560173e4e887e09dcb34ba24be8785a5d6b554be611c730465ea52) | `0` | 禁用指定触发对应的效果。 |
| [`HAPTICS_TRIGGER_RISING`](https://docs.zephyrproject.org/latest/doxygen/html/group__haptics__interface.html#ggabd96eff4adc560173e4e887e09dcb34bae4a997dc3493948814e3dbec94f4dc61) | `BIT(0)` | 上升沿（Rising Edge），低变高。 |
| [`HAPTICS_TRIGGER_FALLING`](https://docs.zephyrproject.org/latest/doxygen/html/group__haptics__interface.html#ggabd96eff4adc560173e4e887e09dcb34ba78d963de3dd4a1c03284e02e8aac5e6d) | `BIT(1)` | 下降沿（Falling Edge），高变低。 |
| [`HAPTICS_TRIGGER_HIGH`](https://docs.zephyrproject.org/latest/doxygen/html/group__haptics__interface.html#ggabd96eff4adc560173e4e887e09dcb34ba594bd6df974f1028b103d60d43ad6554) | `BIT(2)` | 高电平触发（High-Level Trigger）。 |
| [`HAPTICS_TRIGGER_LOW`](https://docs.zephyrproject.org/latest/doxygen/html/group__haptics__interface.html#ggabd96eff4adc560173e4e887e09dcb34ba16d6ece3fd9764d2c79dae48248d53cb) | `BIT(3)` | 低电平触发（Low-Level Trigger）。 |

器件专用标志必须从 `HAPTICS_TRIGGER_PRIV_START` 起使用不同位，例如 `BIT(4)`、`BIT(5)` 等。译注：原页该段注意事项把它们写作“error codes”，但所在枚举与起始标识都是触发类型；这里明确这一原文用词差异。

## 147.6\_校准外部执行器

函数 [`haptics_calibrate()`](https://docs.zephyrproject.org/latest/doxygen/html/group__haptics__interface.html#gaa8a7f36b4b37f7512f9f46133d9f4d1b) 的声明为：

```c
int haptics_calibrate(const struct device *dev, const uint32_t routine);
```

多数驱动可针对外部执行器的物理、电气特性调谐硬件，例如线圈电阻与谐振频率；并非所有驱动都需要独立校准过程。输入参数 `routine` 是器件专用校准过程标识，应查设备头文件和驱动实现。

成功返回0，失败返回负错误码。这是可选操作，未实现时返回 `-ENOSYS`。

## 147.7\_读取集成传感器

函数 [`haptics_monitor_get()`](https://docs.zephyrproject.org/latest/doxygen/html/group__haptics__interface.html#gabf1e580def265fe9bf95f2116d30e6b2) 的声明为：

```c
int haptics_monitor_get(const struct device *dev, const enum haptics_monitor monitor, const enum haptics_monitor_type type, struct sensor_value *const val);
```

输入参数 `monitor` 选择监视项，`type` 选择读数种类；输出参数 `val` 指向 `sensor_value` 结构，接收读数。部分驱动要求先用 [`haptics_monitor_set()`](https://docs.zephyrproject.org/latest/doxygen/html/group__haptics__interface.html#gad379139afa8aff76647f180c80706f79) 启用传感器才能读取。**不能请求同时读取全部传感器**，即 `monitor = HAPTICS_MONITOR_ALL` 无效。

成功返回0，失败返回负错误码。这是可选操作，未实现时返回 `-ENOSYS`。

## 147.8\_启用或禁用集成测量

函数 [`haptics_monitor_set()`](https://docs.zephyrproject.org/latest/doxygen/html/group__haptics__interface.html#gad379139afa8aff76647f180c80706f79) 的声明为：

```c
int haptics_monitor_set(const struct device *dev, const enum haptics_monitor monitor, const bool enable);
```

输入参数 `monitor` 选择监视项；`enable` 为true表示启用，false表示禁用。部分驱动允许禁用集成传感器测量以降低功耗，具体能力看驱动。

成功返回0，失败返回负错误码。这是可选操作，未实现时返回 `-ENOSYS`。

## 147.9\_注册错误回调

函数 [`haptics_register_error_callback()`](https://docs.zephyrproject.org/latest/doxygen/html/group__haptics__interface.html#gaef1b0ecdbeb529f7f10704d259f2f98f) 的声明为：

```c
static inline int haptics_register_error_callback(const struct device *dev, haptics_error_callback_t cb, void *const user_data);
```

输入参数 `cb` 为 [`haptics_error_callback_t`](https://docs.zephyrproject.org/latest/doxygen/html/group__haptics__interface.html#gae0ec52bbeb07c255044a4257df43a396) 类型回调函数；`user_data` 为通过回调交还应用的用户数据。

成功返回0，失败返回负错误码。这是可选操作，未实现时返回 `-ENOSYS`。

## 147.10\_选择播放源与配置

函数 [`haptics_select_source()`](https://docs.zephyrproject.org/latest/doxygen/html/group__haptics__interface.html#ga891fa4c05a4844a658603651e8aabfc5) 的声明为：

```c
int haptics_select_source(const struct device *dev, const enum haptics_source src, const union haptics_config *const cfg);
```

输入参数 `src` 为播放源；`cfg` 为源配置联合体指针，或空指针 `NULL`。通常应在启动播放前调用。本函数未被调用时，各驱动没有统一的默认播放源，行为取决于具体设备。某些播放源不需要附加配置，此时 `cfg` 应设为 `NULL`。

成功返回0，失败返回负错误码。

## 147.11\_设置效果输出级别

函数 [`haptics_set_level()`](https://docs.zephyrproject.org/latest/doxygen/html/group__haptics__interface.html#gaae134ab4f57a7301dbc16cb379f08192) 的声明为：

```c
int haptics_set_level(const struct device *dev, const enum haptics_source src, const union haptics_config *const cfg, const uint32_t level);
```

输入参数 `src` 为播放源，`cfg` 为源配置或 `NULL`，`level` 为器件专用输出级别值。多数驱动支持全局、按播放源或按波形配置级别。例如全局设置可能使用 `src = HAPTICS_SOURCE_ALL` 与 `cfg = NULL`；预编程波形设置可能使用 `src = HAPTICS_SOURCE_ROM`，并在配置中指定所需 `idx`。具体范围和实现由驱动定义。

成功返回0，失败返回负错误码。这是可选操作，未实现时返回 `-ENOSYS`。

## 147.12\_给GPIO触发绑定效果

函数 [`haptics_set_trigger()`](https://docs.zephyrproject.org/latest/doxygen/html/group__haptics__interface.html#ga26851a2c1eafd8da31a3087b0219c6bf) 的声明为：

```c
int haptics_set_trigger(const struct device *dev, const uint32_t trigger, const uint32_t types, const enum haptics_source src, const union haptics_config *const cfg, const uint32_t level);
```

把效果分配给指定GPIO事件或条件，以降低时间关键或快速效果的延迟；触发效果通常是ROM或RAM波形。输入参数 `trigger` 是触发标识，`types` 是 [`haptics_trigger_type`](https://docs.zephyrproject.org/latest/doxygen/html/group__haptics__interface.html#gabd96eff4adc560173e4e887e09dcb34b) 位掩码，`src` 是播放源，`cfg` 是源配置或 `NULL`，`level` 是器件专用级别。`level` 可表示触发效果的增益或衰减；它与 [`haptics_set_level()`](https://docs.zephyrproject.org/latest/doxygen/html/group__haptics__interface.html#gaae134ab4f57a7301dbc16cb379f08192) 的相互作用由驱动决定。

成功返回0，失败返回负错误码。这是可选操作，未实现时返回 `-ENOSYS`。

## 147.13\_启动效果播放

函数 [`haptics_start_output()`](https://docs.zephyrproject.org/latest/doxygen/html/group__haptics__interface.html#ga96e0b0fad35d6535adad7536a9411f44) 的声明为：

```c
int haptics_start_output(const struct device *dev);
```

播放此前通过 [`haptics_select_source()`](https://docs.zephyrproject.org/latest/doxygen/html/group__haptics__interface.html#ga891fa4c05a4844a658603651e8aabfc5) 选定的效果。如果尚未选择源，行为由驱动决定。除设备参数 `dev` 外没有其他参数。

成功返回0，失败返回负错误码。

## 147.14\_停止播放并取消排队效果

函数 [`haptics_stop_output()`](https://docs.zephyrproject.org/latest/doxygen/html/group__haptics__interface.html#ga42a5fc7e6b6247316cdf356573dbbb33) 的声明为：

```c
int haptics_stop_output(const struct device *dev);
```

停止当前效果，并在适用时取消已经排队的效果。若仍需要这些效果，必须通过 [`haptics_start_output()`](https://docs.zephyrproject.org/latest/doxygen/html/group__haptics__interface.html#ga96e0b0fad35d6535adad7536a9411f44) 重新排队。除设备参数 `dev` 外没有其他参数。

成功返回0，失败返回负错误码。

## 147.15\_通过控制端口传输样本

函数 [`haptics_stream_samples()`](https://docs.zephyrproject.org/latest/doxygen/html/group__haptics__interface.html#ga94b7c216edd6adf14a354b64dbc8a396) 的声明为：

```c
int haptics_stream_samples(const struct device *dev, const uint8_t *const samples, const size_t len);
```

通过控制端口流式传输8位样本。输入参数 `samples` 指向8位样本数组，`len` 是要写入的样本数。多数驱动以固定采样率播放控制端口样本，具体见驱动。调用之前应先用 [`haptics_select_source()`](https://docs.zephyrproject.org/latest/doxygen/html/group__haptics__interface.html#ga891fa4c05a4844a658603651e8aabfc5) 选择 `HAPTICS_SOURCE_CONTROL_PORT`。

成功返回0，失败返回负错误码。这是可选操作，未实现时返回 `-ENOSYS`。

## 147.16\_实际触发效果

函数 [`haptics_trigger()`](https://docs.zephyrproject.org/latest/doxygen/html/group__haptics__interface.html#gafb18ed221c2ae5e5b643130bc3d3c8ec) 的声明为：

```c
int haptics_trigger(const struct device *dev, const uint32_t trigger, const enum haptics_trigger_type type);
```

输入参数 `trigger` 为触发标识，`type` 为单个触发类型。函数执行产生效果所需的动作，例如已通过 [`haptics_set_trigger()`](https://docs.zephyrproject.org/latest/doxygen/html/group__haptics__interface.html#ga26851a2c1eafd8da31a3087b0219c6bf) 设置上升沿效果后，以 [`HAPTICS_TRIGGER_RISING`](https://docs.zephyrproject.org/latest/doxygen/html/group__haptics__interface.html#ggabd96eff4adc560173e4e887e09dcb34bae4a997dc3493948814e3dbec94f4dc61) 调用本函数，驱动可能将指定引脚拉高。**应用负责管理物理线路电平**；如果引脚已经为高，再请求上升沿可能不执行任何有效动作。具体行为看驱动。

成功返回0，失败返回负错误码。这是可选操作，未实现时返回 `-ENOSYS`。
