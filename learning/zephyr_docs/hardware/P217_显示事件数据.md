# 第217章\_显示事件数据

原文：[structdisplay__event__data](https://docs.zephyrproject.org/latest/doxygen/html/structdisplay__event__data.html)。读取日期：2026-10-13，`latest`。

## 217.1\_用途

结构 [`display_event_data`](https://docs.zephyrproject.org/latest/doxygen/html/structdisplay__event__data.html) 是显示事件的载荷（Event Payload），由驱动传给回调（Callback），定义来自官方头文件 `zephyr/drivers/display.h`。事件类型及注册规则见[显示公共接口](P214_显示公共接口.md)。

## 217.2\_时间戳与事件信息

字段 [`timestamp`](https://docs.zephyrproject.org/latest/doxygen/html/structdisplay__event__data.html#a2b3fd531cffae409845be4ee04d87c68) 的类型为 [`uint64_t`](https://docs.zephyrproject.org/latest/doxygen/html/stdint_8h.html#a2095b9bffea4b2656950c6c0419edbf1)，用于区分同类型的不同事件。时间戳（Timestamp）例如可由函数 [`k_cycle_get_64()`](../timer_reference/P086_系统时钟公共接口.md) 提供。

字段 [`info`](https://docs.zephyrproject.org/latest/doxygen/html/structdisplay__event__data.html#a3fd29164cf76ef5f2fee818ac61af747) 是联合体（Union），承载驱动传给回调的事件信息，其成员如下：

| 成员 | 类型 | 适用事件与含义 |
| --- | --- | --- |
| [`line`](https://docs.zephyrproject.org/latest/doxygen/html/structdisplay__event__data.html#a7267cf1133ae4f076f4b927f0a3a4ced) | `int` | 用于行中断事件 [`DISPLAY_EVENT_LINE_INT`](https://docs.zephyrproject.org/latest/doxygen/html/group__display__interface.html#gga0042f460c729a5b11ed59f4aac609212a4aecf6d165ca2ec432297cc5664c24a6)；信息不可用时设为 `-1`。 |
| [`buffer_id`](https://docs.zephyrproject.org/latest/doxygen/html/structdisplay__event__data.html#a6bf7995a2713fbda0638c56a950b915a) | `int` | 用于帧完成事件 [`DISPLAY_EVENT_FRAME_DONE`](https://docs.zephyrproject.org/latest/doxygen/html/group__display__interface.html#gga0042f460c729a5b11ed59f4aac609212abd4e3c24f05c2484137855349d6cf794)；信息不可用时设为 `-1`。 |

> 译注：原文未给时间戳统一单位；这里保留其函数示例，不将该字段直接解释为毫秒。
