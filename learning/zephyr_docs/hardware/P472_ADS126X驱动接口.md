# 第472章\_ADS126X驱动接口

原文：[group__ads126x__interface](https://docs.zephyrproject.org/latest/doxygen/html/group__ads126x__interface.html)。读取日期：2026-10-13，`latest`。

## 472.1\_用途与头文件

本页定义 ADS126X **模数转换器（Analog-to-Digital Converter，ADC）**驱动接口中的模拟多路复用器（Analog Multiplexer，MUX）输入选择。

```c
#include <zephyr/drivers/adc/ads126x.h>
```
