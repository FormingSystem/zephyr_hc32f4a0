# 第194章\_LP5562三色LED示例

原文：[LP5562 RGB LED](https://docs.zephyrproject.org/latest/samples/drivers/led/lp5562/README.html)。读取日期：2026-10-13，`latest`。

## 194.1\_概述（Overview）

本示例控制连接到 **德州仪器（Texas Instruments，TI）** LP5562 驱动器上的 4 个 **发光二极管（Light-Emitting Diode，LED）**，执行以下图案：

1. 依次使 LED 显示红、绿、蓝、白、黄、紫、青、橙色。
2. 关闭 LED。
3. 以白色闪烁。
4. 关闭 LED。
5. 以紫色闪烁。
6. 关闭 LED。

红、绿、蓝（Red, Green, Blue，RGB）LED 的接线，以及本示例使用的颜色通道映射，见 [LP5562手册](http://www.ti.com/lit/ds/symlink/lp5562.pdf)。

## 194.2\_构建与运行（Building and Running）

为 [nRF52840 DK](https://docs.zephyrproject.org/latest/boards/nordic/nrf52840dk/doc/index.html#nrf52840dk) 构建应用，将 LP5562 接到 **内部集成电路总线（Inter-Integrated Circuit，I2C）**的 I2C0 控制器，总线地址为 `0x30`。

译注：在已配置 Zephyr 开发环境的终端中，从 Zephyr 源码根目录执行以下官方命令；示例由官方仓库提供，west 生成构建产物。

```bash
west build -b nrf52840dk/nrf52840 samples/drivers/led/lp5562
```

烧录方法见 [nRF52840 DK开发板说明](https://docs.zephyrproject.org/latest/boards/nordic/nrf52840dk/doc/index.html#nrf52840dk)中的烧录（Flashing）小节。
