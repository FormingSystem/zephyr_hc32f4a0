# 第115章\_平台环境控制接口

原文：[Platform Environment Control Interface (PECI)](https://docs.zephyrproject.org/latest/hardware/peripherals/peci.html)。读取日期：2026-10-13，`latest`。

## 115.1\_处理器热管理接口

**平台环境控制接口（Platform Environment Control Interface，PECI）**是一项 **热管理（Thermal Management）**标准，于2006年随Intel Core 2 Duo微处理器推出。

PECI允许外部设备读取处理器温度、执行处理器可管理性功能，以及管理处理器接口的调优与诊断。PECI总线驱动的 **应用程序编程接口（Application Programming Interface，API）**支持嵌入式微控制器与 **中央处理器（Central Processing Unit，CPU）**交互。

## 115.2\_配置、接口与示例

相关Kconfig配置项为 [`CONFIG_PECI`](https://docs.zephyrproject.org/latest/kconfig.html#CONFIG_PECI)；Kconfig是Zephyr配置系统。完整声明见[PECI接口](https://docs.zephyrproject.org/latest/doxygen/html/group__peci__interface.html)。

原页关联[PECI接口示例](P120_PECI温度监视示例.md)，通过PECI监视CPU温度。
