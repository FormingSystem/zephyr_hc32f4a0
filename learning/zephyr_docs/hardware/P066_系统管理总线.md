# 第66章\_系统管理总线

原文：[System Management Bus (SMBus)](https://docs.zephyrproject.org/latest/hardware/peripherals/smbus.html)。读取日期：2026-10-13，`latest`。

## 66.1\_系统管理总线与角色

**系统管理总线（System Management Bus，SMBus）**源自 **集成电路间总线（Inter-Integrated Circuit，I2C）**，用于和主板上的设备通信。系统可通过SMBus与这些外设通信，而不必为各个功能提供专用控制线；外设可以给出制造商信息、报告错误、接收控制参数等。

总线上设备有三种角色：**控制器（Controller）**发起事务并控制时钟；**外设（Peripheral）**响应事务命令；**主机（Host）**是一种专门的控制器，提供连接系统 **中央处理器（Central Processing Unit，CPU）**的主要接口。Zephyr提供控制器角色的 **应用程序编程接口（Application Programming Interface，API）**。

## 66.2\_外设如何发起通知

SMBus外设可通过两种方式主动联系控制器。

**主机通知协议（Host Notify Protocol）**：支持该协议的外设在通知过程中表现为控制器，向特殊地址“SMBus Host（0x08）”写入三字节消息，其中包含自己的地址和两字节相关数据。

**SMBALERT#告警信号（SMBALERT# Signal）**：外设使用专用信号请求控制器注意。控制器从特殊的 **告警响应地址（Alert Response Address，ARA）** `0x0c` 读取一个字节；外设返回包含其自身地址的数据字节。

两者分别通过总线事务和专用告警线触发处理，不能把Host Notify固定地址与ARA地址混为一谈。原文说明当前接口以 **SMBus规范（SMBus Specification）2.0版**为基础。接口术语命名约定见[规则A.2：包容性语言（Inclusive Language）](../contributing/P009_编码准则.md#coding-guideline-inclusive-language)。

## 66.3\_控制器接口与配置

当一个SMBus设备控制总线，特别是控制起始条件、停止条件和时钟时，使用Zephyr的SMBus控制器API。这是与SMBus外设交互的最常见模式。

相关Kconfig配置项为 [`CONFIG_SMBUS`](https://docs.zephyrproject.org/latest/kconfig.html#CONFIG_SMBUS)；Kconfig是Zephyr配置系统。完整接口见[SMBus参考](https://docs.zephyrproject.org/latest/doxygen/html/group__smbus__interface.html)。原页还链接[SMBus命令行示例（SMBus Shell）](../driver_samples/P008_SMBus命令行示例.md#smbus-shell)，用于通过命令行与外设交互。
