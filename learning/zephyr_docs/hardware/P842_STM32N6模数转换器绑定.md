# 第842章\_STM32N6模数转换器绑定

<a id="dtbinding-st-stm32n6-adc"></a>

原文：[st,stm32n6-adc](https://docs.zephyrproject.org/latest/build/dts/api/bindings/adc/st,stm32n6-adc.html)。读取日期：2026-10-13，`latest`。

`st,stm32n6-adc` 是STMicroelectronics模数转换器（Analog-to-Digital Converter，ADC）的设备树绑定（Devicetree Binding）。此兼容字符串覆盖与STM32N6相似的ADC模块，例如C5或U3。其结构与 `st,stm32-adc.yaml` 描述的[通用STM32 ADC](P839_STM32模数转换器绑定.md)相似，但移除了 `st,adc-clock-source` 与 `st,adc-prescaler`。

使用此兼容字符串的开发板见[官方筛选目录](https://docs.zephyrproject.org/latest/boards/index.html#compatibles=st,stm32n6-adc)。

以下严格区分各层节点，必需性、固定值及合法取值仅适用于所在层。`int` 为整数，`array` 为数值数组，`uint8-array` 为8位无符号整数数组，`string` 为字符串，`string-array` 为字符串数组，`boolean` 为布尔属性，`compound` 为复合类型；`phandle` 为节点引用（Phandle），`phandles` 为节点引用列表，`phandle-array` 为节点引用及说明单元数组。Kconfig是Zephyr的配置系统。

基础属性可用于多种节点，不保证全部适用于当前硬件。电源域（Power Domain）、直接存储器访问（Direct Memory Access，DMA）、输入输出（Input/Output，I/O）、邮箱（Mailbox）及处理器间消息（Inter-Processor Messaging，IPM）的通用属性也按原页保留。

## 842.1\_顶层公共控制块属性

本层 `reg` 用于寄存器寻址；下表所示时钟及地址单元配置必须放在本层节点。

| 属性 | 类型 | 中文说明与约束 |
| --- | --- | --- |
| `vref-mv` | `int` | 目标板ADC参考电压（Reference Voltage），单位为毫伏（Millivolt，mV）。启用Kconfig配置项 `CONFIG_ADC_STM32_VREFINT_CALIBRATE` 时，在内部参考VREFINT测量失败后使用此回退值；否则，它作为 `adc_ref_internal()` 为该公共块子节点提供的静态换算基准；默认值：`3300` |
| `st,adc-resolutions` | `array` | **必需**。ADC实例支持的分辨率（Resolution）列表；按约定从高到低排列，例如 `<12 10 8 6>` |
| `sampling-times` | `array` | **必需**。列出实例支持的全部采样时间（Sampling Time），必要时向上取整。**顺序有意义：列表索引对应寄存器中的二进制编码** |
| `num-sampling-time-common-channels` | `int` | 此ADC实例的采样时间共用通道（Sampling Time Common Channel）数量（若存在） |
| `st,adc-sequencer` | `string` | **必需**。ADC序列器（Sequencer）类型：`fixed` 按通道编号从低到高采样；`programmable` 允许序列中各通道按任意顺序采样；合法值：`fixed, programmable` |
| `st,adc-oversampler` | `string` | **必需**。ADC过采样器（Oversampler）类型：`none` 表示没有过采样器；`minimal` 支持8档过采样倍率，即2、4、8至256；`extended` 支持1至1024的1024档倍率；合法值：`none, minimal, extended` |
| `st,adc-internal-regulator` | `string` | **必需**。内部稳压器（Internal Regulator）的存在情况和类型：`none` 表示没有；`startup-sw-delay` 表示存在且用软件延迟（Software Delay）检查启动时间；`startup-hw-status` 表示存在且用寄存器状态标志（Status Flag）检查启动时间；合法值：`none, startup-sw-delay, startup-hw-status` |
| `st,adc-has-deep-powerdown` | `boolean` | 存在该属性表示ADC实例支持深度掉电（Deep Power Down）功能 |
| `st,adc-has-channel-preselection` | `boolean` | 存在该属性表示ADC实例带有通道预选寄存器（Channel Preselection Register） |
| `st,adc-has-differential-support` | `boolean` | 存在该属性表示ADC实例支持差分通道输入（Differential Channel Input） |
| `st,adc-has-injected-support` | `boolean` | 存在该属性表示ADC实例支持注入通道（Injected Channel）功能 |
| `reg` | `array` | **必需**。给出寻址设备所需的信息，具体含义随设备及 `compatible` 而变化。通常是一组地址与长度对，每对称为寄存器块（Register Block），数值通常写为十六进制。参见规范v0.4第2.3.6节及[重要属性](https://docs.zephyrproject.org/latest/build/dts/intro-syntax-structure.html#dt-important-props) |
| `ranges` | `compound` | **必需**。定义总线子地址空间与总线节点父地址空间之间的映射或转换。通常为空，或由子总线地址、父总线地址、长度三元组组成。**空属性表示两侧地址空间相同、不需要转换；总线节点没有此属性则认为子、父地址空间之间不存在映射**。参见规范v0.4第2.3.8节 |
| `#address-cells` | `int` | 子节点 `reg` 地址字段所用的 `<u32>` 单元数量；`<u32>` 为32位无符号单元，参见《设备树规范》v0.4第2.3.5节；固定值：`1` |
| `#size-cells` | `int` | 子节点 `reg` 大小字段所用的 `<u32>` 单元数量；`<u32>` 为32位无符号单元，参见《设备树规范》v0.4第2.3.5节；固定值：`1` |
| `clocks` | `phandle-array` | **必需**。设备的时钟提供者（Clock Provider）信息，通常应遵守[dt-schema时钟绑定约定](https://github.com/devicetree-org/dt-schema/blob/main/dtschema/schemas/clock/clock.yaml) |
| `clock-names` | `string-array` | **必需**。时钟名称与用途：`adcx` 用于使能寄存器时钟（Register Clock），必须提供；`adc_ker` 用于配置内核时钟（Kernel Clock），在适用时提供；`adc_pre` 用于配置预分频器（Prescaler），在适用时提供。**内核时钟及预分频器可能由多个ADC实例共用；共用它们的所有实例必须使用相同的设备树时钟／预分频器配置，避免冲突**；合法值：`adcx, adc_ker, adc_pre` |
| `status` | `string` | 节点代表的硬件或其他资源的运行状态（Operational Status）。`okay` 表示资源可运行，例如可供驱动使用；`disabled` 表示资源不可运行，系统应将其视为不存在。参见《设备树规范》（Devicetree Specification）v0.4第2.3.4节；合法值：`okay, disabled, reserved, fail, fail-sss` |
| `compatible` | `string-array` | **必需**。字符串列表定义节点代表的硬件或其他资源类型。设备驱动通过特定兼容字符串（Compatible String）寻找应由自身管理的设备。推荐格式为 `vendor,device`：前者是厂商简称，后者通常来自数据手册。多个值从最具体到最通用排列，让具体设备匹配当前可用的最具体驱动。参见规范v0.4第2.3.1节 |
| `reg-names` | `string-array` | 为 `reg` 中每个寄存器块提供可选名称；原始例子及逐项说明见本层表后 |
| `interrupts` | `array` | 设备产生的中断，编码为一个或多个中断说明符；格式由设备在中断树中的位置决定，具有相同 `interrupt-parent` 的设备使用相同格式；中断（Interrupt）及中断映射见《设备树规范》v0.4第2.4节 |
| `interrupts-extended` | `compound` | 扩展中断说明符，可替代 `interrupts`；中断（Interrupt）及中断映射见《设备树规范》v0.4第2.4节 |
| `interrupt-names` | `string-array` | 设备各中断的可选名称；中断本身在 `interrupts` 或 `interrupts-extended` 中定义；中断（Interrupt）及中断映射见《设备树规范》v0.4第2.4节 |
| `interrupt-parent` | `phandle` | 若存在，引用负责处理此设备所产生中断的节点；中断（Interrupt）及中断映射见《设备树规范》v0.4第2.4节 |
| `label` | `string` | 描述设备的可读字符串；除逐案确有需要外，已不推荐使用此属性。参见规范 v0.4 第 4.1.2 节“其他属性” |
| `dma-coherent` | `boolean` | 表示设备支持一致性 DMA 操作，见规范 v0.4 第 2.3.10 节 |
| `dmas` | `phandle-array` | 与设备相关的 DMA 通道说明符 |
| `dma-names` | `string-array` | `dmas` 中各 DMA 通道说明符的可选名称 |
| `dma-ranges` | `compound` | 定义总线物理地址空间与其父总线物理地址空间之间的映射或转换，见规范 v0.4 第 2.3.9 节 |
| `io-channels` | `phandle-array` | 与设备相关的 I/O 通道说明符 |
| `io-channel-names` | `string-array` | `io-channels` 中各通道说明符的可选名称 |
| `mboxes` | `phandle-array` | 与设备相关的邮箱/IPM 通道说明符 |
| `mbox-names` | `string-array` | `mboxes` 中各邮箱说明符的可选名称 |
| `power-domains` | `phandle-array` | 与设备相关的电源域说明符 |
| `power-domain-names` | `string-array` | `power-domains` 中各电源域说明符的可选名称 |
| `#power-domain-cells` | `int` | `power-domains` 属性中的单元数量 |
| `hwlocks` | `phandle-array` | 与设备相关的硬件自旋锁（Hardware Spinlock）标识 |
| `hwlock-names` | `string-array` | `hwlocks` 中各锁说明符的可选名称 |
| `zephyr,deferred-init` | `boolean` | 延迟初始化（Deferred Initialization）：启动时不自动初始化设备，应由应用使用 `device_init()` 手动初始化 |
| `wakeup-source` | `boolean` | 标记设备可用作唤醒源（Wakeup Source）。设置该属性后，设备中会设置专门标志，通知系统此设备有唤醒能力。唤醒功能默认禁用，即中断不会唤醒系统；必要时可在运行期间启用 |
| `zephyr,pm-device-runtime-auto` | `boolean` | 初始化函数执行后，自动为设备配置运行时电源管理（Runtime Power Management） |
| `zephyr,disabling-power-states` | `phandles` | 会关闭该设备电源的电源状态（Power State）列表 |

本层 `reg-names` 的原始示例如下。设备树源码（Devicetree Source，DTS）中的 `uart` 是通用异步收发器（Universal Asynchronous Receiver/Transmitter，UART）节点名称，仅用于说明寄存器命名。

```dts
  / {
       soc {
           #address-cells = <1>;
           #size-cells = <1>;

           uart@1000 {
               reg = <0x1000 0x2000>, <0x3000 0x4000>;
               reg-names = "foo", "bar";
           };
       };
  };
```

其中 `uart@1000` 有两个寄存器块：`foo` 的基址为 `0x1000`、大小为 `0x2000`；`bar` 的基址为 `0x3000`、大小为 `0x4000`。

| `reg` | `array` | **必需**。通道标识（Channel Identifier）；参见[重要属性](https://docs.zephyrproject.org/latest/build/dts/intro-syntax-structure.html#dt-important-props) |
| `zephyr,gain` | `string` | **必需**。增益（Gain）选择，各常量对应的倍率见通道表后的完整对照；合法值：`ADC_GAIN_1_6, ADC_GAIN_1_5, ADC_GAIN_1_4, ADC_GAIN_2_7, ADC_GAIN_1_3, ADC_GAIN_2_5, ADC_GAIN_1_2, ADC_GAIN_2_3, ADC_GAIN_4_5, ADC_GAIN_1, ADC_GAIN_2, ADC_GAIN_3, ADC_GAIN_4, ADC_GAIN_6, ADC_GAIN_8, ADC_GAIN_12, ADC_GAIN_16, ADC_GAIN_24, ADC_GAIN_32, ADC_GAIN_64, ADC_GAIN_128` |
| `zephyr,reference` | `string` | **必需**。参考电压源（Reference Source）选择，各常量对应的源见通道表后的完整对照；合法值：`ADC_REF_VDD_1, ADC_REF_VDD_1_2, ADC_REF_VDD_1_3, ADC_REF_VDD_1_4, ADC_REF_INTERNAL, ADC_REF_EXTERNAL0, ADC_REF_EXTERNAL1` |
| `zephyr,vref-mv` | `int` | 此通道选择的参考源电压，单位为毫伏（Millivolt，mV），便于应用在需要计算时取得该值。内部参考（Internal Reference）的电压通常可由专用ADC应用程序接口（Application Programming Interface，API）获取，因此通常无须设置本属性；其他参考源使用此属性可能有帮助 |
| `zephyr,acquisition-time` | `int` | **必需**。采集时间（Acquisition Time）。使用 `ADC_ACQ_TIME` 宏组合属性值，或传入 `ADC_ACQ_TIME_DEFAULT` 采用硬件默认设置，例如硬件不允许配置采集时间的情况 |
| `zephyr,differential` | `boolean` | 设置后选择差分输入模式（Differential Input Mode）；否则使用单端模式（Single-Ended Mode），但若设置 `zephyr,input-negative`，则会隐式选择差分模式 |
| `zephyr,input-positive` | `int` | ADC正输入（Positive Input），**仅供选择 `ADC_CONFIGURABLE_INPUTS` Kconfig选项的驱动使用** |
| `zephyr,input-negative` | `int` | ADC负输入（Negative Input），**仅供选择 `ADC_CONFIGURABLE_INPUTS` Kconfig选项的驱动使用**；指定此属性即隐式选择该通道的差分输入模式 |
| `zephyr,resolution` | `int` | 此通道使用的ADC分辨率（Resolution） |
| `zephyr,oversampling` | `int` | 此通道的过采样（Oversampling）设置。指定后，每个采样值由 `2^N` 次转换结果平均得到，N为属性提供的值 |
| `zephyr,current-source-pin` | `uint8-array` | 电流源（Current Source）的输出引脚选择，实际解释由驱动决定。**仅供选择 `ADC_CONFIGURABLE_EXCITATION_CURRENT_SOURCE_PIN` Kconfig选项的驱动使用** |
| `zephyr,vbias-pins` | `int` | 偏置电压（Bias Voltage）的输出引脚选择，实际解释由驱动决定。**仅供选择 `ADC_CONFIGURABLE_VBIAS_PIN` Kconfig选项的驱动使用** |
