# 第101章\_硬件自旋锁

原文：[Hardware Spinlocks (HWSPINLOCK)](https://docs.zephyrproject.org/latest/hardware/peripherals/hwspinlock.html)。读取日期：2026-10-13，`latest`。

## 101.1\_跨处理器簇保护共享资源

**硬件自旋锁（Hardware Spinlock，HWSPINLOCK）**设备是一种外设，用于在系统不同 **处理器簇（Cluster）**之间保护共享资源。每个HWSPINLOCK实例提供一个或多个自旋锁，其 **应用程序编程接口（Application Programming Interface，API）**与常规Zephyr自旋锁相似。

## 101.2\_簇内访问也需要保护

同一簇内也可能有多个核心使用同一个硬件自旋锁资源。为保护这种访问，每个HWSPINLOCK设备包含一个普通Zephyr自旋锁，用它锁住对HWSPINLOCK硬件的访问。

这两个层面各有职责：外设提供跨簇的共享资源保护，设备内部的常规自旋锁协调同簇多核对该外设的访问。常规接口见[自旋锁API](../kernel/P065_自旋锁公共接口.md)。

## 101.3\_接口与示例

完整声明见[硬件自旋锁参考](../intercore_reference/P001_硬件自旋锁公共接口.md)。原页链接[HWSPINLOCK示例](../intercore_reference/P013_硬件自旋锁驱动示例.md)，将硬件自旋锁API与 **邮箱（Mailbox，MBOX）**API结合，展示跨核心同步；邮箱概览见[本地章节](P069_邮箱驱动.md)。
