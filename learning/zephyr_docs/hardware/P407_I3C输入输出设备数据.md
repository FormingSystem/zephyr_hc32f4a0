# 第407章\_I3C输入输出设备数据

原文：[structi3c__iodev__data](https://docs.zephyrproject.org/latest/doxygen/html/structi3c__iodev__data.html)。读取日期：2026-10-13，`latest`。

## 407.1\_结构与字段

`struct i3c_iodev_data` 是**改进的集成电路间总线（Improved Inter-Integrated Circuit，I3C）**的**输入/输出（Input/Output，I/O）**设备数据结构。头文件为 `zephyr/drivers/i3c.h`。

原页面仅列出以下字段声明，没有附加行为说明：

```c
const struct device *bus;
const struct i3c_device_id dev_id;
```

> 译注：从声明类型看，[`bus`](https://docs.zephyrproject.org/latest/doxygen/html/structi3c__iodev__data.html#a22c368ac3cd8b7b8a8770de3b37afb07) 是设备指针，[`dev_id`](https://docs.zephyrproject.org/latest/doxygen/html/structi3c__iodev__data.html#a3d4146137def71cbb84d1ae3cef67c55) 是设备匹配标识结构。匹配结构的预置标识字段见[设备匹配标识](P400_I3C设备匹配标识.md)。本页不根据字段名称额外推断初始化或所有权规则。
