# 第233章\_步进运动控制后端

原文：[group__stepper__ctrl__backend](https://docs.zephyrproject.org/latest/doxygen/html/group__stepper__ctrl__backend.html)。读取日期：2026-10-13，`latest`。

## 233.1\_用途

本组提供实现步进运动控制器（Stepper Motion Controller）所需的 **应用程序编程接口（Application Programming Interface，API）**类型定义、回调签名（Callback Signature）及辅助内容，声明来自官方头文件 `zephyr/drivers/stepper/stepper_ctrl.h`。微步（Micro-step）表示整步的细分单位。

驱动通过[对应函数表](P234_步进运动控制函数表.md)提供操作，参数及返回语义见[公共接口](P230_步进运动控制接口.md)。

## 233.2\_回调类型

**类型 [`stepper_ctrl_is_moving_t`](https://docs.zephyrproject.org/latest/doxygen/html/group__stepper__ctrl__backend.html#gadc066df6951f3bffed3de0d922588842)：原文概述为“是否已到达步进电机的目标位置”。** 参数说明见函数 [`stepper_ctrl_is_moving()`](https://docs.zephyrproject.org/latest/doxygen/html/group__stepper__ctrl.html#gae78e47cb34035887cf4e8c6a7c6de9de)。

```c
typedef int(* stepper_ctrl_is_moving_t) (const struct device *dev, bool *is_moving);
```

> 译注：原文把 `get_actual_position` 概括成“实际位置，又称参考位置”，而公共接口区分设置参考位置与读取实际步数；这里保留其措辞，不把两项操作合并。原文 `is_moving` 的概述写成“是否到达目标”，但其公共接口及函数表明确是查询**当前是否运动**，输出参数也名为 `is_moving`，不能直接当作到位信号。
