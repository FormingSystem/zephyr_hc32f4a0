# 第88章\_运算放大器

原文：[Operational Amplifier (OPAMP)](https://docs.zephyrproject.org/latest/hardware/peripherals/opamp.html)。读取日期：2026-10-13，`latest`。

## 88.1\_放大差分输入

**运算放大器（Operational Amplifier，OPAMP）**是一种模拟器件，对 **差分输入信号（Differential Input Signal）**进行放大，产生输出电压。差分输入是 **反相输入（Inverting Input）**和 **同相输入（Non-Inverting Input）**之间的信号差。

## 88.2\_初始配置与增益

启用OPAMP时，必须通过设备树提供初始配置；**增益（Gain）**可以在运行时调整。具体模式仍有限制，独立模式由外部电阻决定增益，见[后端功能模式说明](P095_运算放大器驱动后端接口.md)。

相关Kconfig配置项为 [`CONFIG_OPAMP`](https://docs.zephyrproject.org/latest/kconfig.html#CONFIG_OPAMP)，用于运算放大器支持；Kconfig是Zephyr配置系统。完整 **应用程序编程接口（Application Programming Interface，API）**见[OPAMP参考](P091_运算放大器接口参考.md)。

## 88.3\_输出测量示例

原页链接[OPAMP输出测量示例](P092_运算放大器输出测量示例.md)，先放大OPAMP输入，再通过 **模数转换器（Analog-to-Digital Converter，ADC）**采样。该示例把放大与采样两个环节连接起来，完整硬件要求和操作步骤见目标页面；本页没有额外接线图或实测结果。
