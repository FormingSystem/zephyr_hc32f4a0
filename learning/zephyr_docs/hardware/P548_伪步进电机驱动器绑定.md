# 第548章\_伪步进电机驱动器绑定

<a id="dtbinding-zephyr-fake-stepper-driver"></a>

原文：[zephyr,fake-stepper-driver](https://docs.zephyrproject.org/latest/build/dts/api/bindings/stepper/zephyr,fake-stepper-driver.html)。读取日期：2026-10-13，`latest`。

`zephyr,fake-stepper-driver` 是伪**步进电机驱动器（Stepper Driver）**绑定，用于测试中的**测试桩（Stub）**或**模拟对象（Mock）**。提供方是 Zephyr Project；原页列出的驱动为 [`drivers/stepper/fake_stepper_controller.c`](https://github.com/zephyrproject-rtos/zephyr/blob/main/drivers/stepper/fake_stepper_controller.c)，相关开发板见[官方筛选目录](https://docs.zephyrproject.org/latest/boards/index.html#compatibles=zephyr,fake-stepper-driver)。

## 548.1\_微步细分与控制引脚

**微步细分（Microstepping）**的分辨率在驱动初始化时设置。**通用输入输出（General-Purpose Input/Output，GPIO）**控制使能信号和细分配置引脚。`int` 为整数，`phandle-array` 为节点引用及其说明单元数组。

| 属性 | 类型 | 中文说明与约束 |
| --- | --- | --- |
| `micro-step-res` | `int` | 设备驱动初始化时设置的微步分辨率，默认 `1`；合法值 `1`、`2`、`4`、`8`、`16`、`32`、`64`、`128`、`256` |
| `en-gpios` | `phandle-array` | 控制电机驱动器使能信号的 GPIO 引脚 |
| `m0-gpios` | `phandle-array` | 微步配置引脚 0 |
| `m1-gpios` | `phandle-array` | 微步配置引脚 1 |

原页未列出已弃用的节点专用属性，基础属性列表也为空。
