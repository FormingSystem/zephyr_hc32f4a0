# 第91章\_运算放大器接口参考

原文：[group__opamp__interface](https://docs.zephyrproject.org/latest/doxygen/html/group__opamp__interface.html)。读取日期：2026-10-13，`latest`。

## 91.1\_运算放大器接口

本页说明 **运算放大器（Operational Amplifier，OPAMP）**的 **应用程序编程接口（Application Programming Interface，API）**，自Zephyr 4.3引入，接口版本为0.1.0。官方主头文件为 `zephyr/drivers/opamp.h`。

设备概览见[运算放大器](P088_运算放大器.md)，驱动实现者可继续查看[OPAMP驱动后端API](P095_运算放大器驱动后端接口.md)。

## 91.3\_设置增益

[`opamp_set_gain()`](https://docs.zephyrproject.org/latest/doxygen/html/group__opamp__interface.html#ga2334e3b329d1e5338ff05ee872ca7575) 为运算放大器设置增益：

```c
int opamp_set_gain(const struct device *dev, enum opamp_gain gain);
```

`dev` 指向驱动实例的设备结构，`gain` 取自上述 `enum opamp_gain`。设置成功返回0，失败返回负错误码。接口能表达这些倍率，不表示每个实际器件均支持所有倍率；调用者仍应检查设置结果。另据[驱动后端的功能模式说明](P095_运算放大器驱动后端接口.md)，独立模式的增益由外部电阻设置，软件增益调用可能被忽略或不起作用。测量用法见[运算放大器输出测量示例](P092_运算放大器输出测量示例.md)。
