# 第498章\_稳压器伪设备接口

原文：[group__regulator__fake](P498_稳压器伪设备接口.md)。读取日期：2026-10-13，`latest`。

**稳压器（Regulator）**伪驱动是稳压器接口的**伪函数框架（Fake Function Framework，FFF）**实现，供测试使用。启用 Kconfig 配置项 [`CONFIG_REGULATOR_FAKE`](https://docs.zephyrproject.org/latest/kconfig.html#CONFIG_REGULATOR_FAKE) 后，通过 [`zephyr,fake-regulator` 设备树节点](https://docs.zephyrproject.org/latest/build/dts/api/bindings/regulator/zephyr%2Cfake-regulator.html#std-dtcompatible-zephyr-fake-regulator)实例化。接口均位于 `zephyr/drivers/regulator/fake.h`。

## 498.1\_实例和控制结构

一个 `zephyr,fake-regulator` 节点实例化为稳压器父设备，它的每个子节点各自实例化为一个稳压器设备。

每个伪函数（Fake）都有一个 FFF 控制结构，结构名称是函数名再加 `_fake` 后缀。测试可用它设置返回值、安装自定义伪函数、检查调用次数和捕获的实参。控制结构不在本页列出，详见[通过 FFF 进行模拟（Mocking via FFF）](../testing/P002_Ztest测试框架.md)。

只报告状态的伪函数可使用 `return_val` 字段指定返回值；带输出参数的伪函数必须用 `custom_fake` 自定义处理函数，因为 `return_val` 不会改动输出参数。启用 Kconfig 配置项 [`CONFIG_ZTEST`](https://docs.zephyrproject.org/latest/kconfig.html#CONFIG_ZTEST) 时，Zephyr 测试框架（Zephyr Testing Framework，ZTest）的规则会在每个测试用例之前重置全部伪函数。

[`regulator_fake_get_voltage()`](P498_稳压器伪设备接口.md) 默认安装一个报告 **1 V** 的 `custom_fake`，每次重置都会重新安装。测试用例需要改变报告值时，应安装自己的 `custom_fake`。

## 498.2\_使能与电压操作

下面每个函数是 `regulator_driver_api` 对应驱动操作的伪实现；该结构是稳压器驱动的**应用程序编程接口（Application Programming Interface，API）**。原文只提供类型、没有形参名称，译文保留这种声明形式。

| 伪函数 | 对应驱动操作与用途 |
| --- | --- |
| [`regulator_fake_enable()`](P498_稳压器伪设备接口.md) | [`regulator_driver_api::enable`](https://docs.zephyrproject.org/latest/doxygen/html/structregulator__driver__api.html#a518274ecff0d8721a3b883bc344151e6)：使能 |
| [`regulator_fake_disable()`](P498_稳压器伪设备接口.md) | [`regulator_driver_api::disable`](https://docs.zephyrproject.org/latest/doxygen/html/structregulator__driver__api.html#ace034f3b7b9fe74dbcbb5d9ead0497d0)：禁用 |
| [`regulator_fake_count_voltages()`](P498_稳压器伪设备接口.md) | [`regulator_driver_api::count_voltages`](https://docs.zephyrproject.org/latest/doxygen/html/structregulator__driver__api.html#a7daeba7b79bc27d99bf30fb05ef056a0)：取得可用电压数量 |
| [`regulator_fake_list_voltage()`](P498_稳压器伪设备接口.md) | [`regulator_driver_api::list_voltage`](https://docs.zephyrproject.org/latest/doxygen/html/structregulator__driver__api.html#a89613fef0b8adb6de371e8edc178442a)：列举电压 |
| [`regulator_fake_set_voltage()`](P498_稳压器伪设备接口.md) | [`regulator_driver_api::set_voltage`](https://docs.zephyrproject.org/latest/doxygen/html/structregulator__driver__api.html#a67b1aeea6bfb4301972e87564a8656f6)：设置电压 |
| [`regulator_fake_get_voltage()`](P498_稳压器伪设备接口.md) | [`regulator_driver_api::get_voltage`](https://docs.zephyrproject.org/latest/doxygen/html/structregulator__driver__api.html#abb3f66fa87c23a9508e1b7f693c2fd97)：取得电压 |

## 498.5\_父设备操作

父设备使用 `regulator_parent_driver_api` 接口。以下两个函数分别提供其**动态电压调节（Dynamic Voltage Scaling，DVS）**状态设置与**运输模式（Ship Mode）**操作的伪实现。

```c
int regulator_parent_fake_dvs_state_set(const struct device *,
                                        regulator_dvs_state_t);
int regulator_parent_fake_ship_mode(const struct device *);
```

[`regulator_parent_fake_dvs_state_set()`](P498_稳压器伪设备接口.md) 对应 [`regulator_parent_driver_api::dvs_state_set`](https://docs.zephyrproject.org/latest/doxygen/html/structregulator__parent__driver__api.html#a52f314a95ce64485240b1d3cc46dac05)；[`regulator_parent_fake_ship_mode()`](P498_稳压器伪设备接口.md) 对应 [`regulator_parent_driver_api::ship_mode`](https://docs.zephyrproject.org/latest/doxygen/html/structregulator__parent__driver__api.html#aa0d54ca393956b0c6213217c678308a4)。[`regulator_dvs_state_t`](https://docs.zephyrproject.org/latest/doxygen/html/group__regulator__interface.html#ga9a15a21a532e497713724f42052b1dbd) 为 DVS 状态类型。
