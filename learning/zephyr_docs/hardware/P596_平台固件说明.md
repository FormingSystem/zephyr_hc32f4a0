# 第596章\_平台固件说明

原文：[Firmware](https://docs.zephyrproject.org/latest/hardware/firmware/index.html)。读取日期：2026-10-13，`latest`。

## 596.1\_概述

这一类驱动用于与提供系统服务的**固件（Firmware）**交互，例如**时钟管理（Clock Management）**、**电源管理（Power Management）**和**引脚控制（Pin Control，pinctrl）**。

Zephyr 当前支持的固件如下：

| 名称 | 厂商/项目 | 说明 | 官方文档 |
| --- | --- | --- | --- |
| SCMI | ARM | **系统控制与管理接口（System Control and Management Interface）** | [ARM SCMI规范](https://developer.arm.com/documentation/den0056/latest/) |
| TISCI | 德州仪器（Texas Instruments，TI） | **TI系统控制器接口（TI System Controller Interface）** | [TISCI文档](https://software-dl.ti.com/tisci/esd/latest/index.html) |
| QEMU FWCFG | QEMU | **QEMU固件配置（QEMU Firmware Configuration）** | [QEMU固件配置接口](https://www.qemu.org/docs/master/specs/fw_cfg.html) |
| RPI FIRMWARE | 树莓派（Raspberry Pi） | **Raspberry Pi VideoCore固件接口（Raspberry Pi VideoCore Firmware Interface）** | [固件文档](https://github.com/raspberrypi/firmware/wiki) |

## 596.2\_接口定位

固件驱动通常向其他类别的驱动提供功能。不同固件的用途与功能可能不同，因此此类驱动不实现面向最终用户的统一**应用程序编程接口（Application Programming Interface，API）**。
