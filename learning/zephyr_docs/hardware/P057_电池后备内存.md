# 第57章\_电池后备内存

原文：[Battery Backed RAM (BBRAM)](https://docs.zephyrproject.org/latest/hardware/peripherals/bbram.html)。读取日期：2026-10-13，`latest`。

## 57.1\_电池后备内存的状态

**电池后备随机存取存储器（Battery Backed Random Access Memory，BBRAM）**的 **应用程序编程接口（Application Programming Interface，API）**用于访问该内存区域特有的属性。原文列出的常见属性如下。

| 属性 | 检查或取得的信息 |
| --- | --- |
| IBBR，无效状态（Invalid State） | 检查BBRAM是否损坏、处于无效状态。 |
| VSBY，备用电压状态（Voltage Standby State） | 检查BBRAM是否正在使用备用电压。 |
| VCC，正常供电状态（Active Power State） | 检查BBRAM是否使用正常电源。 |
| Size，容量 | 取得BBRAM区域大小，单位为字节。 |

IBBR、VSBY和VCC在这里是原页采用的硬件状态名称；括号中的英文保留原文解释，不额外杜撰寄存器位名称的全称。检查电源状态与检查内存内容是否有效是不同问题，不能仅看到有供电就忽略无效状态。

## 57.2\_读取和写入

除了上述属性，接口还通过 [`bbram_read()`](https://docs.zephyrproject.org/latest/doxygen/html/group__bbram__interface.html#ga9ef786b0fbac3f8523be2bb87b7cff7b) 读取该内存区域，通过 [`bbram_write()`](https://docs.zephyrproject.org/latest/doxygen/html/group__bbram__interface.html#ga51007eed4820aed341d20e4562607564) 写入。原文要求这两个函数**只有在BBRAM处于有效状态且操作范围限定在该区域内部时才应成功**。

因此，偏移和长度不能越过该区域边界；取得容量和检查有效性有助于判断读写是否符合设备要求。完整参数与返回值见[BBRAM接口参考](https://docs.zephyrproject.org/latest/doxygen/html/group__bbram__interface.html)。本页没有给出实际读取或写入示例。
