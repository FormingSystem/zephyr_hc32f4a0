# 第61章\_一次性可编程存储接口

原文：[OTP API](https://docs.zephyrproject.org/latest/hardware/peripherals/otp/api.html)。读取日期：2026-10-13，`latest`。

## 61.1\_预置与读取

**一次性可编程存储器（One Time Programmable Memory，OTP）**的 **应用程序编程接口（Application Programming Interface，API）**提供预置与读取OTP设备的方式。设备用途见[一次性可编程存储入口](P060_一次性可编程存储入口.md)。

接口实现参考为[一次性可编程存储API](https://docs.zephyrproject.org/latest/doxygen/html/group__otp__interface.html)。本页原文没有展开函数声明或给出编程命令。

## 61.2\_配置选项

原文列出以下OTP相关Kconfig配置项；Kconfig是Zephyr配置系统。

| 配置项或查询模式 | 对应内容 |
| --- | --- |
| [`CONFIG_OTP`](https://docs.zephyrproject.org/latest/kconfig.html#CONFIG_OTP) | OTP驱动支持。 |
| [`CONFIG_OTP_PROGRAM`](https://docs.zephyrproject.org/latest/kconfig.html#CONFIG_OTP_PROGRAM) | OTP编程支持。 |
| [`CONFIG_OTP_INIT_PRIORITY`](https://docs.zephyrproject.org/latest/kconfig.html#CONFIG_OTP_INIT_PRIORITY) | OTP驱动初始化优先级。 |
| [`CONFIG_OTP_SHELL.*`](https://docs.zephyrproject.org/latest/kconfig.html#!CONFIG_OTP_SHELL.*) | 匹配OTP命令行相关配置项的查询模式。 |

最后一项中的 `.*` 是官方配置检索使用的模式，不是让读者在配置文件中写一个带星号的配置项。需要使用具体功能时，应查看匹配出的真实符号及其依赖。本章仅翻译接口入口，没有对任何设备执行OTP编程。
