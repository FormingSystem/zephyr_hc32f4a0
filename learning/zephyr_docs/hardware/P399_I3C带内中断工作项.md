# 第399章\_I3C带内中断工作项

原文：[structi3c__ibi__work](https://docs.zephyrproject.org/latest/doxygen/html/structi3c__ibi__work.html)。读取日期：2026-10-13，`latest`。

## 399.1\_排队节点

`struct i3c_ibi_work` 是已经排队的**改进的集成电路间总线（Improved Inter-Integrated Circuit，I3C）带内中断（In-Band Interrupt，IBI）**节点。头文件为 `zephyr/drivers/i3c/ibi.h`。

以下声明按原字段表整理，保留两个匿名联合体（Anonymous Union）：

```c
struct i3c_ibi_work {
    sys_snode_t node;
    struct k_work work;
    enum i3c_ibi_type type;
    union {
        const struct device *controller;
        struct i3c_device_desc *target;
    };
    union {
        struct i3c_ibi_payload payload;
        k_work_handler_t work_cb;
    };
};
```
