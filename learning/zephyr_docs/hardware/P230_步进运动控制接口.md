# 第230章\_步进运动控制接口

原文：[group__stepper__ctrl](https://docs.zephyrproject.org/latest/doxygen/html/group__stepper__ctrl.html)。读取日期：2026-10-13，`latest`。

## 230.1\_范围与版本

本页定义 **步进电机运动控制器（Stepper Motion Controller）**的 **应用程序编程接口（Application Programming Interface，API）**，自 Zephyr 4.0 提供，本页版本为 0.9.0。主头文件为 `zephyr/drivers/stepper/stepper_ctrl.h`。

配套类型为[速度斜坡参数结构](P231_步进速度斜坡结构.md)，驱动实现者另见[运动控制器后端接口](P233_步进运动控制后端.md)。下文位置、位移采用 **微步（Micro-step）**为单位。

## 230.2\_方向、运行模式与事件枚举

枚举 [`stepper_ctrl_direction`](https://docs.zephyrproject.org/latest/doxygen/html/group__stepper__ctrl.html#ga188b64bc308fb78a77cfdcf4bfe1b5f7) 定义方向：`STEPPER_CTRL_DIRECTION_NEGATIVE = 0` 为负方向（Negative Direction），`STEPPER_CTRL_DIRECTION_POSITIVE = 1` 为正方向（Positive Direction）。

枚举 [`stepper_ctrl_run_mode`](https://docs.zephyrproject.org/latest/doxygen/html/group__stepper__ctrl.html#ga81a1a98c7381cf5845d9e6a908bdd4a5) 定义三种运行模式：

| 枚举项 | 值 | 模式 |
| --- | --- | --- |
| [`STEPPER_CTRL_RUN_MODE_HOLD`](https://docs.zephyrproject.org/latest/doxygen/html/group__stepper__ctrl.html#gga81a1a98c7381cf5845d9e6a908bdd4a5a5dadeff6f35458f9310744e9b6e305b7) | `0` | 保持模式（Hold Mode）。 |
| [`STEPPER_CTRL_RUN_MODE_POSITION`](https://docs.zephyrproject.org/latest/doxygen/html/group__stepper__ctrl.html#gga81a1a98c7381cf5845d9e6a908bdd4a5aa7bd6559d26845de9cba1e1a15a1d841) | `1` | 位置模式（Position Mode）。 |
| [`STEPPER_CTRL_RUN_MODE_VELOCITY`](https://docs.zephyrproject.org/latest/doxygen/html/group__stepper__ctrl.html#gga81a1a98c7381cf5845d9e6a908bdd4a5ab5ab3be4513a981e070c65dffac633ad) | `2` | 速度模式（Velocity Mode）。 |

枚举 [`stepper_ctrl_event`](https://docs.zephyrproject.org/latest/doxygen/html/group__stepper__ctrl.html#ga61dfffaeb3d7f76c34c9a9e3ab7627d0) 定义运动控制器事件：

| 枚举项 | 值 | 含义 |
| --- | --- | --- |
| [`STEPPER_CTRL_EVENT_STEPS_COMPLETED`](https://docs.zephyrproject.org/latest/doxygen/html/group__stepper__ctrl.html#gga61dfffaeb3d7f76c34c9a9e3ab7627d0abcdf3ebb12e2452b8dd97a78f7799fa3) | `0` | 用相对移动操作 `move_by` 或绝对移动操作 `move_to` 设定的步数已执行完毕。 |
| [`STEPPER_CTRL_EVENT_LEFT_END_STOP_DETECTED`](https://docs.zephyrproject.org/latest/doxygen/html/group__stepper__ctrl.html#gga61dfffaeb3d7f76c34c9a9e3ab7627d0a391d21e562f172dfd5e554b7540e24a0) | `1` | 左端限位开关（Left End Switch）状态变为按下。 |
| [`STEPPER_CTRL_EVENT_RIGHT_END_STOP_DETECTED`](https://docs.zephyrproject.org/latest/doxygen/html/group__stepper__ctrl.html#gga61dfffaeb3d7f76c34c9a9e3ab7627d0a3339b85fb6aafe8d96b47a1fcc2be21c) | `2` | 右端限位开关（Right End Switch）状态变为按下。 |
| [`STEPPER_CTRL_EVENT_STOPPED`](https://docs.zephyrproject.org/latest/doxygen/html/group__stepper__ctrl.html#gga61dfffaeb3d7f76c34c9a9e3ab7627d0ae8d633746759b9399dc149a1b31429a3) | `3` | 步进电机已停止。 |

## 230.3\_位置基准与位置读取

下文所有 `dev` 参数都指向驱动实例的设备结构。函数 [`stepper_ctrl_set_reference_position()`](https://docs.zephyrproject.org/latest/doxygen/html/group__stepper__ctrl.html#gae723aee1b73b3b65d8ead0546b976cd0) 设置以微步为单位的参考位置（Reference Position），参数 `value` 为要设置的值。

```c
int stepper_ctrl_set_reference_position(const struct device *dev, const int32_t value);
int stepper_ctrl_get_actual_position(const struct device *dev, int32_t *value);
```

函数 [`stepper_ctrl_get_actual_position()`](https://docs.zephyrproject.org/latest/doxygen/html/group__stepper__ctrl.html#gaf2c33e8fcf6cd03dfb9361c0246281fb) 获取实际步数，写入 `value` 指向的位置值，单位为微步。**它不保证返回的位置就是精确的当前物理位置；需要精确定位时，应在运动控制器之外配合编码器（Encoder）。**

这两个函数成功返回 0；`-EIO` 表示一般输入输出错误（Input/Output Error）；`-ENOSYS` 表示设备驱动未实现（Not Implemented）。

## 230.4\_步间隔与速度斜坡

函数 [`stepper_ctrl_set_microstep_interval()`](https://docs.zephyrproject.org/latest/doxygen/html/group__stepper__ctrl.html#ga1cb888e11712c54bd879a5b0015ea298) 设置步与步之间的时间间隔，以纳秒（Nanosecond，ns）为单位，立即生效。

```c
int stepper_ctrl_set_microstep_interval(const struct device *dev,
                                       const uint64_t microstep_interval_ns);
int stepper_ctrl_configure_ramp(const struct device *dev,
                                const struct stepper_ctrl_ramp *ramp);
```

`microstep_interval_ns` 是步间隔。**设置间隔本身不会让电机开始运动**，需要把设置间隔与移动操作结合使用。返回 0 表示成功；`-EIO` 为一般输入输出错误；`-EINVAL` 表示请求的步间隔不受支持（Invalid Argument）；`-ENOSYS` 表示驱动未实现。

函数 [`stepper_ctrl_configure_ramp()`](https://docs.zephyrproject.org/latest/doxygen/html/group__stepper__ctrl.html#gae0ebe9949b9fe2bda51c4dc9d537cac5) 配置 **速度斜坡（Ramp）**，`ramp` 指向斜坡配置结构。成功返回 0；`-EIO` 为一般输入输出错误；`-ENOSYS` 为驱动未实现。

## 230.5\_相对移动与绝对移动

```c
int stepper_ctrl_move_by(const struct device *dev, const int32_t micro_steps);
int stepper_ctrl_move_to(const struct device *dev, const int32_t micro_steps);
```

函数 [`stepper_ctrl_move_by()`](https://docs.zephyrproject.org/latest/doxygen/html/group__stepper__ctrl.html#gaa968ec0a373206d239ac96abc20ee9ea) 设定相对当前位置要移动的微步数，即 **相对移动（Relative Movement）**。`micro_steps` 是从当前位置出发的目标位移。

函数 [`stepper_ctrl_move_to()`](https://docs.zephyrproject.org/latest/doxygen/html/group__stepper__ctrl.html#gac264384ffdd5c4eca154ddf941abf8a5) 设置 **绝对目标位置（Absolute Target Position）**；电机移动到相对于参考位置的给定微步位置，`micro_steps` 是目标位置。

两个函数都是 **非阻塞（Non-blocking）**的。成功返回 0；`-EIO` 表示一般输入输出错误；`-EINVAL` 表示步进时序配置不正确。

## 230.6\_连续运行、停止与运动状态

```c
int stepper_ctrl_run(const struct device *dev,
                     const enum stepper_ctrl_direction direction);
int stepper_ctrl_stop(const struct device *dev);
int stepper_ctrl_is_moving(const struct device *dev, bool *is_moving);
```

函数 [`stepper_ctrl_run()`](https://docs.zephyrproject.org/latest/doxygen/html/group__stepper__ctrl.html#ga544a15b5df405c08127fa8529cfbcf0b) 以给定步间隔和 `direction` 方向运行电机。电机开始后连续运行，直到堵转（Stall）或被其他命令停止。本函数非阻塞。

> 译注：原文在这里举停止命令 `stepper_stop()` 为例；本页实际声明的停止函数是 [`stepper_ctrl_stop()`](https://docs.zephyrproject.org/latest/doxygen/html/group__stepper__ctrl.html#ga780784ec0b192e68849627ff97116c78)。前者是原文说明中的名称差异。

函数 `stepper_ctrl_stop()` 停止步进电机，取消所有正在进行的运动。

函数 [`stepper_ctrl_is_moving()`](https://docs.zephyrproject.org/latest/doxygen/html/group__stepper__ctrl.html#gae78e47cb34035887cf4e8c6a7c6de9de) 查询当前是否运动，并将状态写入 `is_moving` 指向的布尔变量。

三个函数成功均返回 0；均列出 `-EIO`（一般输入输出错误）与 `-ENOSYS`（驱动未实现）。连续运行函数还列出 `-EINVAL`，表示步进时序配置不正确。

## 230.7\_事件回调

类型 [`stepper_ctrl_event_callback_t`](https://docs.zephyrproject.org/latest/doxygen/html/group__stepper__ctrl.html#ga69198946de2a596894b1fc26a13a4c58) 是运动控制器事件的 **回调（Callback）**函数指针：

```c
typedef void (*stepper_ctrl_event_callback_t)(const struct device *dev,
    const enum stepper_ctrl_event event, void *user_data);
```

注册函数 [`stepper_ctrl_set_event_cb()`](https://docs.zephyrproject.org/latest/doxygen/html/group__stepper__ctrl.html#gacd154f195a34a0de50ab26c81ce469d8) 的声明为：

```c
int stepper_ctrl_set_event_cb(const struct device *dev,
    stepper_ctrl_event_callback_t callback, void *user_data);
```

`callback` 是事件发生时调用的函数，传空指针 `NULL` 可禁用回调；`user_data` 是传给回调的用户数据。成功返回 0，`-ENOSYS` 表示驱动未实现。
