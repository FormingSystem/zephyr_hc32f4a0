# 第289章\_BL61x线输出配置

原文：[structbl61x__wo__config](https://docs.zephyrproject.org/latest/doxygen/html/structbl61x__wo__config.html)。读取日期：2026-10-13，`latest`。

## 289.1\_结构用途与字段

结构 [`bl61x_wo_config`](https://docs.zephyrproject.org/latest/doxygen/html/structbl61x__wo__config.html) 保存通用输入/输出（General Purpose Input/Output，GPIO）先进先出队列（First In, First Out，FIFO）的脉宽、极性及引脚相关配置，用于线输出（Wire Out，WO）接口；声明来自 `zephyr/drivers/gpio/gpio_bl61x_wo.h`。

| 字段 | 类型 | 含义 |
| --- | --- | --- |
| [`total_cycles`](https://docs.zephyrproject.org/latest/doxygen/html/structbl61x__wo__config.html#a4aca055fbb5f0b5db088489297590b83) | [`uint16_t`](https://docs.zephyrproject.org/latest/doxygen/html/stdint_8h.html#a5debae8b2a1ec20a6694c0c443ee399e) | 一个翻转周期的总时钟周期长度，原文注明有效宽度为9位 |
| [`set_cycles`](https://docs.zephyrproject.org/latest/doxygen/html/structbl61x__wo__config.html#ac0c5d20792b3d3e1c6ff919980b5918f) | [`uint8_t`](https://docs.zephyrproject.org/latest/doxygen/html/stdint_8h.html#a3cb4a16b0e8d6af0af86d4fd6ba5fd9d) | 对应数据位置1时，引脚翻转所用的时钟周期数 |
| [`unset_cycles`](https://docs.zephyrproject.org/latest/doxygen/html/structbl61x__wo__config.html#a58ee7556887d3b80ffe68312d69915f0) | [`uint8_t`](https://docs.zephyrproject.org/latest/doxygen/html/stdint_8h.html#a3cb4a16b0e8d6af0af86d4fd6ba5fd9d) | 对应数据位置0时，引脚翻转所用的时钟周期数 |
| [`set_invert`](https://docs.zephyrproject.org/latest/doxygen/html/structbl61x__wo__config.html#adff7e30b46544eb722cd9380a2bc3367) | [`bool`](https://docs.zephyrproject.org/latest/doxygen/html/stdbool_8h.html#abb452686968e48b67397da5f97445f5b) | 数据位置1时改为从低到高，而非从高到低 |
| [`unset_invert`](https://docs.zephyrproject.org/latest/doxygen/html/structbl61x__wo__config.html#a2fd1a2bdbb7603b86d39fcb885013630) | [`bool`](https://docs.zephyrproject.org/latest/doxygen/html/stdbool_8h.html#abb452686968e48b67397da5f97445f5b) | 同样改变方向，但适用于数据位置0时 |
| [`park_high`](https://docs.zephyrproject.org/latest/doxygen/html/structbl61x__wo__config.html#a008fe193acd73529d2cdb1a681209ce3) | [`bool`](https://docs.zephyrproject.org/latest/doxygen/html/stdbool_8h.html#abb452686968e48b67397da5f97445f5b) | 序列结束后将引脚停驻（Park）在高电平，而非低电平 |

## 289.2\_原时序示例

示例中 `set_invert`、`unset_invert`、`park_high` 都为 `false`；`total_cycles = 9`，`set_cycles = 6`，`unset_cycles = 4`。共有两帧数据，第一帧对应引脚的数据位为1，第二帧为0。时钟周期单位取决于时钟 `XCLK` 的频率，来源可为原文所列的 `RC32M` 或晶体（Crystal）。

原时序图以文本绘制，以下完整保留。其中 `clock` 为时钟，`data` 为数据位，`Pin value` 为引脚电平，`park` 为序列结束后的停驻阶段。

```text
                   total_cycles
          |-----------------------------------|-----------------------------------|

clock     |"| |"| |"| |"| |"| |"| |"| |"| |"| |"| |"| |"| |"| |"| |"| |"| |"| |"| |"| |"| |
          | |_| |_| |_| |_| |_| |_| |_| |_| |_| |_| |_| |_| |_| |_| |_| |_| |_| |_| |_| |_|

data      1                                   0

Pin value """"""""""""""""""""""""|           |"""""""""""""""|
                                  |___________|               |___________________________

          |-----------------------|-----------|---------------|-------------------|---------
          |     set_cycles        |total - set|  unset_cycles |  total - unset    | park
```

## 289.3\_引脚与数据位映射

原文写作 `toggle bit = pin & 16`，并举例说明引脚0对应位0、引脚17对应位1、引脚2对应位2，依此类推。

> 译注：原公式与所列例子不一致，按位与16无法得到这些例子的位编号。这里保留公式和例子，不擅自改为另一种运算；使用前应核对所用版本的驱动实现及器件文档。
