# 第72章\_本地互连网络

原文：[Local Interconnect Network (LIN)](https://docs.zephyrproject.org/latest/hardware/peripherals/lin.html)。读取日期：2026-10-13，`latest`。

## 72.1\_LIN与标准范围

**本地互连网络（Local Interconnect Network，LIN）**是一种串行总线系统。原文说明它自2016年起由 **国际标准化组织（International Organization for Standardization，ISO）**进行国际标准化；2025年，ISO 17987系列中的若干部分得到更新。该系列覆盖 **开放系统互连（Open Systems Interconnection，OSI）**七层的要求及相应一致性测试计划。

## 72.2\_指挥节点、响应节点与帧

LIN **数据链路层（Data Link Layer）**通常称为LIN协议，规定了 **指挥节点（Commander）**与 **响应节点（Responder）**之间的协议。指挥节点使用一个或多个预先编程的 **调度表（Schedule Table）**安排LIN帧收发；调度表至少包含发起帧发送的相对时刻。

LIN帧分为 **帧头（Header）**与 **响应（Response）**两部分。指挥节点发送帧头，随后由一个指定响应节点或指挥节点自身发送响应。

原文将帧头组成写为：“1字节Break、字节间隔、1字节同步值SYNC（0x55）、标识符以及响应间隔”；将响应写为“载荷字节和CRC字节”。这些字句中的 **间断字段（Break Field）**和 **校验和（Checksum）**需要结合下面译注理解。

> 译注：原文“1字节Break”和“CRC字节”不宜直接作为实现依据。Microchip的[LIN数据链路层说明](https://developerhelp.microchip.com/xwiki/bin/view/applications/lin/data-link-layer/)规定同步Break至少持续13个位时间的显性电平，并将响应末尾称为校验和，区分经典与增强校验和；它不是此处应采用的 **循环冗余校验（Cyclic Redundancy Check，CRC）**算法名称。译文保留原句并标明差异，避免悄悄替换来源。

帧中的数据按8位数据字节串行发送，每字节另外带一个起始位和一个停止位，不带奇偶校验位。原文特别指出，帧头Break字段没有普通数据字节的起始位、停止位结构。

## 72.3\_位率与总线状态

位率范围为1 kbit/s到20 kbit/s。总线上的位为 **隐性（Recessive，逻辑高）**或 **显性（Dominant，逻辑低）**。时间基准由指挥节点的稳定时钟提供，最小单位是一个位时间；原文示例为19.2 kbit/s时约52 µs。

总线定义 **睡眠模式（Sleep Mode）**和 **活动模式（Active Mode）**。传输数据时，所有LIN节点应处于活动模式。经过规定的超时时间后，节点进入睡眠模式；收到 **唤醒帧（Wake-Up Frame）**后恢复活动。

任何需要总线活动的节点都可以发送唤醒帧：可能是按内部计划工作的指挥节点，也可能是被内部应用激活的响应节点。全部节点唤醒后，指挥节点继续安排下一帧。原页还提供[LIN百科入口](https://en.wikipedia.org/wiki/Local_Interconnect_Network)作为附加阅读。

## 72.4\_Zephyr支持与示例

Zephyr LIN控制器支持以下功能：在指挥节点或响应节点模式收发帧；在响应模式通过帧头掩码过滤，使特定帧头标识符触发响应回调；发送唤醒脉冲。

## 72.5\_LIN收发器

**收发器（Transceiver）**是外部器件，把LIN控制器的逻辑电平转换为LIN总线电平。部分板通过 `lin-transceiver-gpio` 兼容性标识直接集成使能／唤醒引脚控制；GPIO是 **通用输入／输出（General-Purpose Input/Output）**。

LIN控制器驱动在 [`lin_start()`](https://docs.zephyrproject.org/latest/doxygen/html/group__lin__controller.html#ga752004d89d50932711c3aa6189874478) 和 [`lin_stop()`](https://docs.zephyrproject.org/latest/doxygen/html/group__lin__controller.html#gaefe6f3853ea2f70d8ba4d6ab86f62b57) 过程中自动启用、禁用收发器，因此应用通常无需直接调用收发器API。相关参考见[LIN收发器API](https://docs.zephyrproject.org/latest/doxygen/html/group__lin__transceiver.html)。本章未执行LIN收发、唤醒或收发器控制。
