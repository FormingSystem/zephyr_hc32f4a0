# 第406章\_I3C驱动公共数据

原文：[structi3c__driver__data](https://docs.zephyrproject.org/latest/doxygen/html/structi3c__driver__data.html)。读取日期：2026-10-13，`latest`。

## 406.1\_公共运行数据的位置

`struct i3c_driver_data` 是所有**改进的集成电路间总线（Improved Inter-Integrated Circuit，I3C）**驱动的公共结构。它应当是驱动自身 `struct driver_data` 声明的第一个成员。头文件为 `zephyr/drivers/i3c.h`。

## 406.2\_配置与附接设备

| 字段 | 类型 | 含义与条件 |
| --- | --- | --- |
| [`ctrl_config`](https://docs.zephyrproject.org/latest/doxygen/html/structi3c__driver__data.html#a00fc23f3b070cdfce304c015b4409cbb) | `struct i3c_config_controller` | 控制器配置，见[控制器硬件配置](P391_I3C控制器硬件配置.md)。 |
| [`attached_dev`](https://docs.zephyrproject.org/latest/doxygen/html/structi3c__driver__data.html#ae64e0be2d004d67900c11adf46630901) | `struct i3c_dev_attached_list` | 已附接的 I3C、集成电路间总线（Inter-Integrated Circuit，I2C）设备及地址；仅在启用 Kconfig 配置项 [`CONFIG_I3C_CONTROLLER`](https://docs.zephyrproject.org/latest/kconfig.html#CONFIG_I3C_CONTROLLER) 时可用。 |

## 406.3\_收到的目标清单

DEFTGTS 是传递目标清单信息的**通用命令码（Common Command Code，CCC）**名称。下列字段均仅在启用 Kconfig 配置项 [`CONFIG_I3C_TARGET`](https://docs.zephyrproject.org/latest/kconfig.html#CONFIG_I3C_TARGET) 时可用。

| 字段 | 类型 | 含义 |
| --- | --- | --- |
| [`deftgts`](https://docs.zephyrproject.org/latest/doxygen/html/structi3c__driver__data.html#a1f1e3c1017b6214486474078b7d948f7) | `struct i3c_ccc_deftgts *` | 指向收到的 DEFTGTS 数据的指针。 |
| [`deftgts_refreshed`](https://docs.zephyrproject.org/latest/doxygen/html/structi3c__driver__data.html#a968fe84e8de0ac443228ebd20493c49c) | [`bool`](https://docs.zephyrproject.org/latest/doxygen/html/stdbool_8h.html#abb452686968e48b67397da5f97445f5b) | DEFTGTS 已刷新标志。 |
