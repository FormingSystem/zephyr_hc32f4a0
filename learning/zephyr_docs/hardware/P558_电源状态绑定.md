# 第558章\_电源状态绑定

<a id="dtbinding-zephyr-power-state"></a>

原文：[zephyr,power-state](https://docs.zephyrproject.org/latest/build/dts/api/bindings/power/zephyr,power-state.html)。读取日期：2026-10-13，`latest`。

`zephyr,power-state` 定义**电源管理空闲状态（Power Management Idle State）**的属性，提供方是 Zephyr Project。原页没有列出专用驱动文件，相关开发板见[官方筛选目录](https://docs.zephyrproject.org/latest/boards/index.html#compatibles=zephyr,power-state)。

## 558.1\_状态名称与子状态

必需属性 `power-state-name` 的类型为字符串 `string`，标识电源状态。完整合法值及名称对照如下：

| 合法值 | 名称对照 |
| --- | --- |
| `active` | 活动（Active） |
| `runtime-idle` | 运行时空闲（Runtime Idle） |
| `suspend-to-idle` | 挂起到空闲（Suspend to Idle） |
| `standby` | 待机（Standby） |
| `suspend-to-ram` | 挂起到随机存取存储器（Suspend to RAM，Random Access Memory） |
| `suspend-to-disk` | 挂起到磁盘（Suspend to Disk） |
| `soft-off` | 软件关机（Soft Off） |

属性 `substate-id` 的类型为整数 `int`，提供平台专属的子状态标识。

## 558.2\_驻留收益与退出延迟

属性 `min-residency-us` 的类型为 `int`，表示**最小驻留时间（Minimum Residency Duration）**，单位微秒（Microsecond，μs）。它描述为了使进入该空闲状态在能耗上值得，必须至少驻留多久。

这一时间包含进入状态所需时间，是能量的**收支平衡时间（Break-Even Time）**：相对于选择紧邻的更浅状态，进入目标状态后实际节约的能量，需要足以抵偿进入与退出状态所耗费的时间和电能。

属性 `exit-latency-us` 的类型为 `int`，表示退出空闲状态所需的最坏情况延迟（Worst-Case Latency），单位微秒。

## 558.3\_设备电源管理开关

属性 `zephyr,pm-device-disabled` 的类型为布尔值 `boolean`，用于在此状态禁用系统管理的设备电源管理。设置后，电源管理子系统不会在进入此状态之前挂起设备。

原页没有已弃用的节点专用属性，基础属性列表为空。
