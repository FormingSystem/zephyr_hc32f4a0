# 第309章\_I2C目标配置

原文：[structi2c__target__config](https://docs.zephyrproject.org/latest/doxygen/html/structi2c__target__config.html)。读取日期：2026-10-13，`latest`。

## 309.1\_注册前初始化

结构 [`i2c_target_config`](https://docs.zephyrproject.org/latest/doxygen/html/structi2c__target__config.html) 描述支持集成电路间总线（Inter-Integrated Circuit，I²C）目标设备（Target）接口的设备，声明来自 `zephyr/drivers/i2c.h`。

实例分别传入 [`i2c_target_register()`](https://docs.zephyrproject.org/latest/doxygen/html/group__i2c__interface.html#gaa47c3fde397188fa126dcaa4a6e85b47) 与 [`i2c_target_unregister()`](https://docs.zephyrproject.org/latest/doxygen/html/group__i2c__interface.html#ga11eada869173f6bd91db39c794dc8979)，表示添加、移除目标设备。在把对象引用传入注册函数前，实现设备行为的模块必须初始化**除 [`node`](https://docs.zephyrproject.org/latest/doxygen/html/structi2c__target__config.html#ab2393d22d8e1fb12a389cd457d30933a) 外的所有字段**。
