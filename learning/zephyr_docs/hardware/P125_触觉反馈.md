# 第125章\_触觉反馈

原文：[Haptics](https://docs.zephyrproject.org/latest/hardware/peripherals/haptics.html)。读取日期：2026-10-13，`latest`。

## 125.1\_驱动触觉反馈事件

**触觉反馈（Haptics）**的 **应用程序编程接口（Application Programming Interface，API）**用于控制触觉驱动设备，使其执行 **触觉反馈事件（Haptic Feedback Event）**。

事件发生期间，触觉设备向 **执行器（Actuator）**输出驱动信号。信号来源取决于设备能力，例子包括模拟信号、预编程 **只读存储器（Read-Only Memory，ROM）**波形表、合成的 **随机存取存储器（Random Access Memory，RAM）**波形表，以及数字音频流。这里的 **波形表（Wavetable）**提供要播放的波形数据。

触觉驱动设备通常还提供调整、调谐驱动信号的控制，以满足相应执行器的电气要求。
