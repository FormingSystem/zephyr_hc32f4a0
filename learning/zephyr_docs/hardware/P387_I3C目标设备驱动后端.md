# 第387章\_I3C目标设备驱动后端

原文：[group__i3c__target__device__backend](https://docs.zephyrproject.org/latest/doxygen/html/group__i3c__target__device__backend.html)。读取日期：2026-10-13，`latest`。

## 387.1\_驱动实现接口

本组包含实现**改进的集成电路间总线（Improved Inter-Integrated Circuit，I3C）目标设备（Target Device）**驱动所需的应用程序编程接口（Application Programming Interface，API）类型、回调签名和其他辅助定义。头文件为 `zephyr/drivers/i3c/target_device.h`。

[驱动操作函数表](P390_I3C目标设备驱动函数表.md)使用 `struct i3c_target_driver_api`，其中包含以下函数指针类型。

## 387.2\_注册与注销回调类型

```c
typedef int (*i3c_target_api_driver_register_t)(const struct device *dev);
typedef int (*i3c_target_api_driver_unregister_t)(const struct device *dev);
```

- [`i3c_target_api_driver_register_t`](https://docs.zephyrproject.org/latest/doxygen/html/group__i3c__target__device__backend.html#gae6b75cf65f1715ff36bc0aa1a0908b07)：指示 I3C 目标设备驱动将自身注册到所属总线控制器。
- [`i3c_target_api_driver_unregister_t`](https://docs.zephyrproject.org/latest/doxygen/html/group__i3c__target__device__backend.html#ga5b45ad9e1388ac39093cd5374a9f5c4c)：指示 I3C 目标设备驱动从所属总线控制器注销自身。

原页面未进一步规定这两个类型的返回码；此处保留原签名，不额外赋予错误码约定。
