# 第134章\_传感器接口入口

原文：[Sensors](https://docs.zephyrproject.org/latest/hardware/peripherals/sensors.html)。读取日期：2026-10-13，`latest`。

## 134.1\_传感器与专用接口目录

官方 **传感器（Sensors）**分类涵盖环境与运动传感器、卫星导航、生物特征识别及传感器接口。原文五个入口按顺序为：

- [传感器驱动概览](../sensors/P001_传感器驱动概览.md)：**传感器（Sensor）**子系统。
- [全球导航卫星系统](P136_全球导航卫星系统.md)：**全球导航卫星系统（Global Navigation Satellite System，GNSS）**。
- [外围传感器接口](P138_外围传感器接口.md)：**外围传感器接口（Peripheral Sensor Interface，PSI5）**。
- [单边沿半字节传输](P139_单边沿半字节传输.md)：**单边沿半字节传输（Single Edge Nibble Transmission，SENT）**。
- [生物特征识别](P135_生物特征识别.md)：**生物特征识别（Biometrics）**。
