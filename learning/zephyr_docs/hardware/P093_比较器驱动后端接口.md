# 第93章\_比较器驱动后端接口

原文：[group__comparator__interface__backend](https://docs.zephyrproject.org/latest/doxygen/html/group__comparator__interface__backend.html)。读取日期：2026-10-13，`latest`。

## 93.1\_比较器后端类型

本组提供实现 **比较器（Comparator）**驱动所需的 **应用程序编程接口（Application Programming Interface，API）**类型定义、回调签名和辅助内容。官方头文件为 `zephyr/drivers/comparator.h`；原页列出的 `struct comparator_driver_api` 是[比较器驱动操作结构](P094_比较器驱动操作结构.md)。

**回调函数（Callback Function）**在本页指驱动实现的具体操作，公共接口通过这些操作取得输出、设置触发和管理事件。

## 93.2\_四种操作签名

以下为原页四个函数指针类型的声明，保留参数类型与顺序：

```c
typedef int (*comparator_api_get_output)(const struct device *dev);
typedef int (*comparator_api_set_trigger)(const struct device *dev,
                                          enum comparator_trigger trigger);
typedef int (*comparator_api_set_trigger_callback)(
    const struct device *dev, comparator_callback_t callback, void *user_data);
typedef int (*comparator_api_trigger_is_pending)(const struct device *dev);
```

| 类型 | 作用 | 原文参数说明入口 |

所有操作的 `dev` 都是设备指针；`trigger` 是触发枚举，`callback` 是上层触发回调，`user_data` 是传给该回调的用户数据。完整参数和返回值已译在[比较器接口参考](P089_比较器接口参考.md)。尤其是待处理查询包含清除动作，后端实现不能将其替换为不改变状态的普通读取。
