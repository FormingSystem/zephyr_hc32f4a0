# 第103章\_唤醒控制器

原文：[Wakeup Controller (WUC)](https://docs.zephyrproject.org/latest/hardware/peripherals/wuc.html)。读取日期：2026-10-13，`latest`。

## 103.1\_管理系统唤醒源

**唤醒控制器（Wakeup Controller，WUC）**的 **应用程序编程接口（Application Programming Interface，API）**为启用、管理能够让系统退出低功耗状态的 **唤醒源（Wakeup Source）**提供统一接口。

WUC设备通常在 **设备树（Devicetree）**中描述，客户端通过 `wuc_dt_spec` 规格结构引用它。

## 103.2\_设备树引用

客户端节点用 `wakeup-ctrls` 属性引用控制器；属性包含指向WUC设备的 **节点句柄（Phandle）**以及唤醒源标识。以下是原片段：

```devicetree
wuc0: wakeup-controller@40000000 {
    compatible = "nxp,mcx-wuc";
    reg = <0x40000000 0x1000>;
    #wakeup-ctrl-cells = <1>;
};

button0: button@0 {
    wakeup-ctrls = <&wuc0 10>;
};
```

`wuc0` 是控制器节点标签，`#wakeup-ctrl-cells = <1>` 表示引用中有一个唤醒控制参数单元；`button0` 用 `<&wuc0 10>` 选择该控制器的唤醒源10。地址、兼容性标识及源编号均为原例，不是任意板都可复用的硬件配置。

## 103.3\_取得规格并启用唤醒

应用通常用规格初始化宏 [`WUC_DT_SPEC_GET`](https://docs.zephyrproject.org/latest/doxygen/html/group__wuc__interface.html#ga83d434b9c2b26dcd448d0b53c63ff295) 从设备树取得 `wuc_dt_spec` 结构，再按需启用或禁用唤醒源。原例用节点标签查询宏 `DT_NODELABEL(button0)` 定义节点宏 `BUTTON0_NODE`，检查设备就绪后启用其唤醒源；设备未就绪时返回设备不可用错误码 `-ENODEV`：

```c
#define BUTTON0_NODE DT_NODELABEL(button0)

static const struct wuc_dt_spec button_wuc =
    WUC_DT_SPEC_GET(BUTTON0_NODE);

if (!device_is_ready(button_wuc.dev)) {
    return -ENODEV;
}

return wuc_enable_wakeup_source_dt(&button_wuc);
```

`BUTTON0_NODE` 是节点宏，`button_wuc` 是静态规格对象。`device_is_ready()` 检查控制器设备是否就绪；未就绪则返回 `-ENODEV`，否则调用 `wuc_enable_wakeup_source_dt()`。这是初始化逻辑片段，条件与return语句应放在实际函数内部，不是把整个片段当作完整源文件。

## 103.4\_检查并清除触发状态

驱动支持时，应用可检查并清除唤醒源的已触发状态；未实现这些操作时返回 `-ENOSYS`。原例为：

```c
int ret;

ret = wuc_check_wakeup_source_triggered_dt(&button_wuc);
if (ret > 0) {
    (void)wuc_clear_wakeup_source_triggered_dt(&button_wuc);
}
```

`wuc_check_wakeup_source_triggered_dt()` 返回正数时，原例调用 `wuc_clear_wakeup_source_triggered_dt()` 清除状态。原代码用 `(void)` 忽略清除返回值，因此它并未展示完整的错误处理；负错误码也不能解释为“从未触发”。

## 103.5\_接口与相关低功耗示例

完整声明见[WUC接口参考](https://docs.zephyrproject.org/latest/doxygen/html/group__wuc__interface.html)。原页列出两个NXP MCX示例，均使用 **唤醒单元（Wakeup Unit，WUU）**：

| 示例 | 用途 |
| --- | --- |
| [NXP MCX挂起到RAM](https://docs.zephyrproject.org/latest/samples/boards/nxp/mcxn_a/s2ram/README.html#nxp_mcx_s2ram) | 将MCXA／MCXN **片上系统（System on Chip，SoC）**挂起到 **随机存取存储器（Random Access Memory，RAM）**保持状态，经WUU唤醒控制器传递的 **低功耗定时器（Low-Power Timer，LPTMR）**或按钮事件恢复。 |
| [NXP MCX系统关闭](https://docs.zephyrproject.org/latest/samples/boards/nxp/mcxn_a/system_off/README.html#nxp_mcx_system_off) | 使用MCXA／MCXN的系统关闭，即 **深度掉电（Deep Power Down）**模式，通过WUU唤醒。 |

WUC是通用接口名，WUU是上述NXP硬件单元名称。本文未切换系统低功耗状态、启用唤醒源或实际清除硬件触发标记。
