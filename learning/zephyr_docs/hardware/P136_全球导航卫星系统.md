# 第136章\_全球导航卫星系统

原文：[GNSS (Global Navigation Satellite System)](https://docs.zephyrproject.org/latest/hardware/peripherals/gnss.html)。读取日期：2026-10-13，`latest`。

## 136.1\_定位与精确时间

**全球导航卫星系统（Global Navigation Satellite System，GNSS）**是用于导航的卫星系统总称，例如 **全球定位系统（Global Positioning System，GPS）**。通常通过GNSS接收模块（原文称 **GNSS Modem**）访问这些服务：模块接收、处理GNSS信号，确定自身位置；更准确地说，确定其天线位置。

模块通常还提供精确时间同步机制，常称为 **每秒脉冲（Pulse-Per-Second，PPS）**。

## 136.2\_子系统与协议支持

GNSS子系统基于[调制解调器模块（Modem Modules）](../services_overview/P007_调制解调器模块.md#modem)。它覆盖从向模块发送命令、接收模块命令，到解析、生成和处理NMEA0183消息的整个过程。NMEA0183是接口消息标准名称，NMEA源自 **美国国家海洋电子协会（National Marine Electronics Association）**。

为额外的NMEA0183 GNSS模块增加支持，通常只需实现该模块特定的电源管理与配置，再加少量其他工作。

也可以支持使用其他协议或总线的模块，不必局限于常见的NMEA0183经 **通用异步收发器（Universal Asynchronous Receiver/Transmitter，UART）**传输，但驱动开发者需要完成更多工作。

## 136.3\_停止跟踪与设备掉电的区别

除非另有配置，GNSS接收器通常在上电后立即开始捕获、跟踪GNSS信号。为节能，应用可以切断接收器电源，也可以让内部GNSS引擎停止主动捕获和跟踪。

后一种方式停止位置计算，但接收器仍然供电、功耗降低，与主机应用的通信链路也继续可用，以执行其他操作或恢复GNSS引擎。

GNSS子系统通过停止函数 [`gnss_stop()`](https://docs.zephyrproject.org/latest/doxygen/html/group__gnss__interface.html#ga43f285927c94079e3b72e81303cff520) 提供这一操作。它不同于Zephyr设备电源管理中的 **挂起／恢复（Suspend/Resume）**：接收器保持供电且仍能与主机通信，只停止GNSS跟踪。

## 136.4\_启动模式与恢复要求

应用用启动函数 [`gnss_start()`](https://docs.zephyrproject.org/latest/doxygen/html/group__gnss__interface.html#ga6bdabc1e89f5c7b10c1099fa74e6c6ca) 恢复跟踪，并可通过启动模式枚举 [`gnss_start_mode`](https://docs.zephyrproject.org/latest/doxygen/html/group__gnss__interface.html#ga7106633a65ddaa29e19ba9f15b86f0f9) 指定方式，影响 **首次定位时间（Time-to-First-Fix）**。

- **热启动（Hot Start）**保留导航数据，因而能较快重新捕获信号。
- **温启动（Warm Start）**丢弃部分导航数据，捕获时间更长。
- **冷启动（Cold Start）**丢弃全部导航数据，捕获时间也更长。

GNSS驱动必须确保设备从挂起或掉电状态恢复时**自动开始跟踪**，无需应用显式调用 [`gnss_start()`](https://docs.zephyrproject.org/latest/doxygen/html/group__gnss__interface.html#ga6bdabc1e89f5c7b10c1099fa74e6c6ca)。大多数接收器在这种情况下会冷启动，因为未供电时已丢失跟踪数据；如果模块保留了足够状态，驱动也可以尝试更快的温启动或热启动。

要求的核心是上电后自动恢复跟踪。清除导航数据只是模块曾经掉电的副作用，不是从挂起恢复时有意执行的步骤。

## 136.5\_配置、导航参考与接口

相关Kconfig配置项为 [`CONFIG_GNSS`](https://docs.zephyrproject.org/latest/kconfig.html#CONFIG_GNSS)、卫星信息支持 [`CONFIG_GNSS_SATELLITES`](https://docs.zephyrproject.org/latest/kconfig.html#CONFIG_GNSS_SATELLITES)，以及日志转储 [`CONFIG_GNSS_DUMP_TO_LOG`](https://docs.zephyrproject.org/latest/kconfig.html#CONFIG_GNSS_DUMP_TO_LOG)；Kconfig是Zephyr配置系统。

原页分别提供[导航参考（Navigation）](https://docs.zephyrproject.org/latest/doxygen/html/group__navigation.html)与[GNSS应用程序编程接口（Application Programming Interface，API）](https://docs.zephyrproject.org/latest/doxygen/html/group__gnss__interface.html)。两组参考关联同一个[GNSS示例](../driver_samples/P013_GNSS定位示例.md#gnss)，用于连接GNSS设备并获取时间、导航数据和卫星信息。
