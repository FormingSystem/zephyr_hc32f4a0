# 第239章\_TMCM3216步进扩展

原文：[group__tmcm3216__stepper__ctrl](https://docs.zephyrproject.org/latest/doxygen/html/group__tmcm3216__stepper__ctrl.html)。读取日期：2026-10-13，`latest`。

## 239.1\_范围

本页提供亚德诺半导体（Analog Devices, Inc.，ADI）TMCM-3216 **步进电机控制器（Stepper Motor Controller）**公共 **应用程序编程接口（Application Programming Interface，API）**，头文件为 `zephyr/drivers/stepper/stepper_tmcm3216.h`。

## 239.2\_查询最大速度与实际速度

```c
int tmcm3216_get_max_velocity(const struct device *dev, uint32_t *velocity);
int tmcm3216_get_actual_velocity(const struct device *dev, int32_t *velocity);
```

函数 [`tmcm3216_get_max_velocity()`](https://docs.zephyrproject.org/latest/doxygen/html/group__tmcm3216__stepper__ctrl.html#gae0777cd5cbac3899d7f1315e9d1c53fb) 获取最大速度（Maximum Velocity），`dev` 指向步进设备，`velocity` 指向存储最大速度的无符号 32 位变量。

函数 [`tmcm3216_get_actual_velocity()`](https://docs.zephyrproject.org/latest/doxygen/html/group__tmcm3216__stepper__ctrl.html#gac41f95b33de1a90356c127b64e586dba) 获取实际速度（Actual Velocity），`dev` 指向步进设备，`velocity` 指向存储实际速度的有符号 32 位变量。

两者成功返回 0，失败返回负的错误码（Negative errno Code）。

## 239.3\_查询电机状态

```c
int tmcm3216_get_status(const struct device *dev, struct tmcm3216_status *status);
```

函数 [`tmcm3216_get_status()`](https://docs.zephyrproject.org/latest/doxygen/html/group__tmcm3216__stepper__ctrl.html#ga1c6fe3f3d758e02e1c4f427bfc1754bf) 获取电机状态，`dev` 指向步进设备，`status` 指向接收结果的[电机状态结构](P241_TMCM3216电机状态.md)。成功返回 0，失败返回负错误码。

> 译注：这页原文未规定速度数值单位，译文不自行补成微步/秒；应与所用驱动版本和器件参数说明对照。
