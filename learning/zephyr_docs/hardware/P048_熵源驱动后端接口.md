# 第48章\_熵源驱动后端接口

原文：[group__entropy__interface__backend](https://docs.zephyrproject.org/latest/doxygen/html/group__entropy__interface__backend.html)。读取日期：2026-10-13，`latest`。

## 48.1\_熵源驱动操作

本组给出实现 **熵（Entropy）**驱动所需的 **应用程序编程接口（Application Programming Interface，API）**类型、回调签名和辅助内容。它们在官方头文件 `zephyr/drivers/entropy.h` 中声明。`struct entropy_driver_api` 是熵源驱动操作结构，见[结构参考](P053_熵源驱动操作结构.md)。

后端 **回调函数（Callback Function）**由驱动实现，用于获取硬件熵；应用侧接口与返回值约束见[熵源接口参考](P039_熵源接口参考.md)。

## 48.2\_普通熵获取回调

[`entropy_get_entropy_t`](https://docs.zephyrproject.org/latest/doxygen/html/group__entropy__interface__backend.html#ga661150c9482777f98cdee794e9164b28) 是获取熵的回调类型：

```c
typedef int (*entropy_get_entropy_t)(const struct device *dev,
                                     uint8_t *buffer, uint16_t length);
```

`dev` 为设备指针，`buffer` 为待填充缓冲区，`length` 为缓冲区字节长度。原文将参数说明指向 [`entropy_get_entropy()`](https://docs.zephyrproject.org/latest/doxygen/html/group__entropy__interface.html#ga54de6cd85d5c557ca91f425944e50ce6)。

**该调用必须是线程安全的（Thread-Safe）**，以满足随机数子系统要求。这意味着驱动实现不能假定始终只有一个线程访问它；应在实现中正确处理并发，而不是让每个调用者自行猜测硬件访问是否冲突。

<a id="gacaa273da74b4727ea49b25d1ccd9725c"></a>

## 48.3\_中断环境中的熵获取回调

[`entropy_get_entropy_isr_t`](https://docs.zephyrproject.org/latest/doxygen/html/group__entropy__interface__backend.html#gacaa273da74b4727ea49b25d1ccd9725c) 用于从 **中断服务程序（Interrupt Service Routine，ISR）**获取熵：

```c
typedef int (*entropy_get_entropy_isr_t)(const struct device *dev,
                                         uint8_t *buffer, uint16_t length,
                                         uint32_t flags);
```

`dev`、`buffer`、`length` 分别是设备、目标缓冲区和请求长度，[`flags`](https://docs.zephyrproject.org/latest/doxygen/html/parser_8h.html#ab6b306ef981f5e21bb41ea2c2dbe8cd9) 调整调用行为。原文将参数说明指向 [`entropy_get_entropy_isr()`](https://docs.zephyrproject.org/latest/doxygen/html/group__entropy__interface.html#ga71b99316bec395a7078b26e44f20fc9a)；非阻塞／忙等待行为、实际填充字节数及未实现的错误返回，见[熵源接口参考](P039_熵源接口参考.md)。不要把普通回调的成功状态返回约定套用到ISR回调的实际字节数返回。
