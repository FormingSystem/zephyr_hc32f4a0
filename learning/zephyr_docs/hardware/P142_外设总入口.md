# 第142章\_外设总入口

原文：[Peripherals](https://docs.zephyrproject.org/latest/hardware/peripherals/index.html)。读取日期：2026-10-13，`latest`。

Zephyr通过一组设备驱动 **应用程序编程接口（Application Programming Interface，API）**支持多种硬件外设。官方按下列十一类组织：每类列出对应外设，分类入口提供进一步说明。下表保留原文的完整英文名称，并链接到本地中文概览。

通用输入输出为 **General-Purpose Input/Output（GPIO）**。分类内的芯片系列、总线与协议名称保留原标识，详细术语与使用条件见对应章节。

官方分类图标以SVG原始片段逐字保存，并另附仅增加XML命名空间的独立SVG副本用于图片引用；未重绘、替换或转为位图。原片段与显示副本均保存在本模块图片目录。
