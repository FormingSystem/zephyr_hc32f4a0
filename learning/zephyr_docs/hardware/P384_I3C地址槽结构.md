# 第384章\_I3C地址槽结构

原文：[structi3c__addr__slots](https://docs.zephyrproject.org/latest/doxygen/html/structi3c__addr__slots.html)。读取日期：2026-10-13，`latest`。

## 384.1\_地址状态存储

`struct i3c_addr_slots` 用于跟踪**改进的集成电路间总线（Improved Inter-Integrated Circuit，I3C）**上的地址。包含头文件 `zephyr/drivers/i3c/addresses.h`。

原页面仅列出以下字段：

```c
unsigned long slots[((0x7F+1) *2)/BITS_PER_LONG];
```

> 译注：[`slots`](https://docs.zephyrproject.org/latest/doxygen/html/structi3c__addr__slots.html#a8117bc5c9b55bb074a845f8a4fe405fb) 为数组字段，[`BITS_PER_LONG`](../util_reference/P001_通用工具公共接口.md#ga2f660aa23a5dbc0f4b8df48b4302b8c3) 表示 `unsigned long` 的位数。按原声明的容量表达式，它为 128 个地址分别保存 2 位状态；具体状态及操作接口见[地址槽管理](P383_I3C地址槽管理.md)。原字段页没有其他字段说明。
