# 第138章\_外围传感器接口

原文：[Peripheral Sensor Interface (PSI5)](https://docs.zephyrproject.org/latest/hardware/peripherals/psi5.html)。读取日期：2026-10-13，`latest`。

## 138.1\_与PSI5设备通信

**外围传感器接口（Peripheral Sensor Interface，PSI5）**的 **应用程序编程接口（Application Programming Interface，API）**提供与PSI5设备通信的功能。

## 138.2\_配置、参考与示例

相关Kconfig配置项为 [`CONFIG_PSI5`](https://docs.zephyrproject.org/latest/kconfig.html#CONFIG_PSI5)；Kconfig是Zephyr配置系统。完整声明见[PSI5 API](https://docs.zephyrproject.org/latest/doxygen/html/group__psi5__interface.html)。原页关联[PSI5接口示例](../driver_samples/P038_PSI5接口示例.md#psi5)，展示外围传感器接口驱动的使用。
