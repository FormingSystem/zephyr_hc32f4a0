# 第316章\_I2C模拟设备节点

原文：[structi2c__emul](https://docs.zephyrproject.org/latest/doxygen/html/structi2c__emul.html)。读取日期：2026-10-13，`latest`。

## 316.1\_链表节点

结构 [`i2c_emul`](https://docs.zephyrproject.org/latest/doxygen/html/structi2c__emul.html) 表示集成电路间总线（Inter-Integrated Circuit，I²C）设备模拟器（Emulator）链表中的一个节点，声明来自 `zephyr/drivers/i2c_emul.h`。

| 字段 | 类型 | 含义 |
| --- | --- | --- |
| [`node`](https://docs.zephyrproject.org/latest/doxygen/html/structi2c__emul.html#a72324f94030625a8be49101f49875a7a) | [`sys_snode_t`](../slist_reference/P001_单向链表公共接口.md#ga69bf43aad81e3ee2d55250c59b857493) | 控制器模拟器单向链表（Singly Linked List）中的节点 |
| [`target`](https://docs.zephyrproject.org/latest/doxygen/html/structi2c__emul.html#a33461303343c3f513a87f1783491324a) | `const struct emul *` | 目标模拟器；任意类型的模拟总线节点都必须设置 |
| [`api`](https://docs.zephyrproject.org/latest/doxygen/html/structi2c__emul.html#a7e6f7e6e69064df666584027c94bf98c) | `const struct i2c_emul_api *` | 此设备提供的接口 |
| [`mock_api`](https://docs.zephyrproject.org/latest/doxygen/html/structi2c__emul.html#abf57cb711e20ab11aa5af247ccc652b2) | `struct i2c_emul_api *` | 非空时优先于实际接口的模拟替身接口（Mock API） |
| [`addr`](https://docs.zephyrproject.org/latest/doxygen/html/structi2c__emul.html#a8d3924790bd825afe41095bfdf0087eb) | [`uint16_t`](https://docs.zephyrproject.org/latest/doxygen/html/stdint_8h.html#a5debae8b2a1ec20a6694c0c443ee399e) | 模拟设备的I²C地址 |

设置了 `mock_api` 后，如果它返回未实现错误码 `-ENOSYS`，会回退到默认的 `api`。
