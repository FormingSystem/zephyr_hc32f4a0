# 第236章\_步进硬件驱动函数表

原文：[structstepper__driver__api](https://docs.zephyrproject.org/latest/doxygen/html/structstepper__driver__api.html)。读取日期：2026-10-13，`latest`。

## 236.1\_用途与成员要求

结构 [`stepper_driver_api`](https://docs.zephyrproject.org/latest/doxygen/html/structstepper__driver__api.html) 是每个步进硬件驱动器（Stepper Hardware Driver）需要定义的 **驱动操作（Driver Operations）**表，包含已实现操作的函数指针，以及驱动专用的其他常量数据。定义来自官方头文件 `zephyr/drivers/stepper/stepper.h`。

标为 **必需（Required，REQ）**的成员必须设置；标为 **可选（Optional，OPT）**的成员按需提供。微步（Micro-step）是整步的细分单位。
