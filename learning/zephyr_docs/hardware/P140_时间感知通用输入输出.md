# 第140章\_时间感知通用输入输出

原文：[Time-aware General-Purpose Input/Output (TGPIO)](https://docs.zephyrproject.org/latest/hardware/peripherals/tgpio.html)。读取日期：2026-10-13，`latest`。

## 140.1\_时间感知GPIO入口

本页为 **时间感知通用输入输出（Time-Aware General-Purpose Input/Output，TGPIO）**的官方入口。原页的概览小节没有进一步说明，仅列出配置、接口和示例。

## 140.2\_配置、接口与时钟同步示例

相关Kconfig配置项为 [`CONFIG_TIMEAWARE_GPIO`](https://docs.zephyrproject.org/latest/kconfig.html#CONFIG_TIMEAWARE_GPIO)；Kconfig是Zephyr配置系统。

完整 **应用程序编程接口（Application Programming Interface，API）**见[Time-Aware GPIO参考](../timer_reference/P191_时间感知GPIO公共接口.md)。原页关联[时间感知GPIO示例](../driver_samples/P065_时间感知GPIO示例.md#timeaware-gpio)，用途为 **时钟同步（Clock Synchronization）**。
