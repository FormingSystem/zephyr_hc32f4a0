# 第126章\_步进电机

原文：[Steppers](https://docs.zephyrproject.org/latest/hardware/peripherals/stepper/index.html)。读取日期：2026-10-13，`latest`。

## 126.1\_两套设备驱动接口

**步进电机（Stepper Motor）**驱动子系统包含两套设备驱动 **应用程序编程接口（Application Programming Interface，API）**：**步进硬件驱动器（Stepper Hardware Driver）**接口与 **步进运动控制器（Stepper Motion Controller）**接口。

## 126.2\_步进硬件驱动器接口

硬件驱动器接口提供以下公共函数。**微步（Microstep）**用于表达细分后的步进单位，**微步分辨率（Micro-Stepping Resolution）**决定细分设置；**事件回调（Event Callback）**用于接收事件通知。

| 函数 | 用途 |
| --- | --- |
| [`stepper_set_micro_step_res()`](P232_步进硬件驱动接口.md)、[`stepper_get_micro_step_res()`](P232_步进硬件驱动接口.md) | 设置、读取微步分辨率。 |
| [`stepper_enable()`](P232_步进硬件驱动接口.md) | 启用步进驱动器。 |
| [`stepper_disable()`](P232_步进硬件驱动接口.md) | 禁用步进驱动器。 |
| [`stepper_set_event_cb()`](P232_步进硬件驱动接口.md) | 注册事件回调。 |

## 126.3\_步进运动控制器接口

控制器提供位置、步进间隔和运动控制函数。**相对运动（Relative Movement）**指定相对当前的位置变化，**绝对运动（Absolute Movement）**指定目标位置。

| 函数 | 用途 |
| --- | --- |
| [`stepper_ctrl_set_reference_position()`](P230_步进运动控制接口.md)、[`stepper_ctrl_get_actual_position()`](P230_步进运动控制接口.md) | 按微步单位设置参考位置、读取实际位置。 |
| [`stepper_ctrl_set_microstep_interval()`](P230_步进运动控制接口.md) | 以纳秒设置相邻步进之间的间隔。 |
| [`stepper_ctrl_move_by()`](P230_步进运动控制接口.md) | 按正、负微步数执行相对运动。 |
| [`stepper_ctrl_move_to()`](P230_步进运动控制接口.md) | 移动至指定绝对位置。 |
| [`stepper_ctrl_run()`](P230_步进运动控制接口.md) | 按固定步进间隔向指定方向连续运行，直到停止。 |
| [`stepper_ctrl_stop()`](P230_步进运动控制接口.md) | 停止步进电机。 |
| [`stepper_ctrl_is_moving()`](P230_步进运动控制接口.md) | 检查电机是否仍在运动。 |
| [`stepper_ctrl_set_event_cb()`](P230_步进运动控制接口.md) | 注册控制器事件回调。 |

## 126.4\_设备树与驱动组合

对于步进运动控制器，**设备树（Devicetree）**按设备提供步进驱动器的初始硬件配置。每个设备必须指定Zephyr设备树绑定，并且最好提供电流设置、**加减速斜坡参数（Ramp Parameters）**等硬件配置项，以便在开发板设备树中设置初始状态。

原页列出两种典型组合：[集成运动控制与驱动器](P128_集成步进运动控制与驱动器.md)及[独立运动控制器与驱动器](P127_独立步进运动控制器与驱动器.md)。

## 126.5\_运动控制器API测试套件

**测试套件（Test Suite）**用于验证步进运动控制器功能。下面原命令在Zephyr仓库根目录执行：替换 `<board>` 为目标板，把 `<path/to/board.overlay>` 替换为相应 **设备树覆盖文件（Devicetree Overlay）**的相对路径。west是工作区工具，命令将构建并烧录测试。

```sh
# From the root of the zephyr repository
west build -b <board> --extra-dtc-overlay <path/to/board.overlay> tests/drivers/stepper/stepper_ctrl
west flash
```

原页给出 `h-bridge-stepper-ctrl` 的一段测试输出。名称中的 **H桥（H-Bridge）**指驱动拓扑；输出包括实际位置、正负相对步数、正负绝对目标、零步数、正反方向运行、零间隔无效值及停止等测试。这里显示的通过结果属于原文示例。`TESTSUITE`／`SUITE` 表示测试套件，`PASS` 表示通过，`SUMMARY START` 与 `SUMMARY END` 标记汇总开始与结束，`PROJECT EXECUTION SUCCESSFUL` 表示项目执行成功：

## 126.6\_公共与专用参考

所有步进硬件驱动器应实现公共的[Stepper Hardware Driver接口](P232_步进硬件驱动接口.md)，所有步进运动控制器应实现公共的[Stepper Motion Controller接口](P230_步进运动控制接口.md)。原页另列出Trinamic的[专用步进控制器API](P240_Trinamic步进扩展.md)。本次未运行测试或驱动电机。
