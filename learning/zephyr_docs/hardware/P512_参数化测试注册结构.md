# 第512章\_参数化测试注册结构

原文：[structztest__param__inst](P512_参数化测试注册结构.md)。读取日期：2026-10-13，`latest`。

`struct ztest_param_inst` 是将测试映射到参数值集合的**注册记录（Registration Entry）**。一个测试可以据此使用指定集合逐个取值执行。

公开头文件为 `zephyr/ztest_test.h`，源码位置为 `subsys/testsuite/ztest/include/zephyr/ztest_test.h`。原文构建机绝对包含路径在这里改为公开包含名。

## 512.1\_实例化名称与参数集合

记录保存所属**测试套件（Test Suite）**、测试函数、当前**实例化（Instantiation）**的标签及对应参数集合。

| 字段声明 | 官方说明译文 |
| --- | --- |
| `const char *test_suite_name` | 此次实例化所属的套件名称 |
| `const char *test_name` | 参数化测试函数名称 |
| `const char *instance_name` | 此次特定实例化的可读标签 |
| `const struct ztest_param_values *values` | 此次实例化需要遍历的参数值集合 |

[`ztest_param_values`](P511_测试参数集合结构.md) 是参数集合结构类型，[`values`](P512_参数化测试注册结构.md) 指向只读集合记录。
