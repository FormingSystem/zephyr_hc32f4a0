# 第422章\_I3C桥接目标命令数据

原文：[structi3c__ccc__setbrgtgt](https://docs.zephyrproject.org/latest/doxygen/html/structi3c__ccc__setbrgtgt.html)。读取日期：2026-10-13，`latest`。

## 422.1\_SETBRGTGT载荷

`struct i3c_ccc_setbrgtgt` 是**改进的集成电路间总线（Improved Inter-Integrated Circuit，I3C）通用命令码（Common Command Code，CCC）** `SETBRGTGT` 的载荷（Payload）。命令含义为**设置桥接目标（Set Bridge Targets）**。头文件为 `zephyr/drivers/i3c/ccc.h`。

注意：桥接目标地址编码在 `struct i3c_ccc_target_payload` 中，而不是编码在本载荷中。

## 422.2\_字段

| 字段 | 类型 | 含义 |
| --- | --- | --- |
| [`count`](https://docs.zephyrproject.org/latest/doxygen/html/structi3c__ccc__setbrgtgt.html#a9099e2979baca2c3fbbb7a6b781edbf3) | [`uint8_t`](https://docs.zephyrproject.org/latest/doxygen/html/stdint_8h.html#a3cb4a16b0e8d6af0af86d4fd6ba5fd9d) | 桥接目标数量。 |
| [`targets`](https://docs.zephyrproject.org/latest/doxygen/html/structi3c__ccc__setbrgtgt.html#aa019eb13d7da60941382c6e43884b60d) | `struct i3c_ccc_setbrgtgt_tgt []` | 桥接目标数组。 |
