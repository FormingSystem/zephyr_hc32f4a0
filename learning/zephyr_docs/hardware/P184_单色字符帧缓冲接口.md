# 第184章\_单色字符帧缓冲接口

原文：[group__monochrome__character__framebuffer](https://docs.zephyrproject.org/latest/doxygen/html/group__monochrome__character__framebuffer.html)。读取日期：2026-10-13，`latest`。

## 184.1\_接口范围与版本

这是公开的 **单色字符帧缓冲（Monochrome Character Framebuffer，CFB）** **应用程序编程接口（Application Programming Interface，API）**。自 Zephyr 1.14.0 提供，本页接口版本为 0.10.0。所有声明来自官方头文件 `zephyr/display/cfb.h`。

相关数据类型包括字体结构 [`cfb_font`](P185_字符帧缓冲字体结构.md)和坐标结构 [`cfb_position`](P186_字符帧缓冲坐标结构.md)。下文各函数的 `dev` 参数均为驱动实例对应的 `const struct device *` 设备结构指针。

## 184.2\_创建字体条目

宏 `FONT_ENTRY_DEFINE(_name, _width, _height, _caps, _data, _fc, _lc)` 创建一个字体条目（Font Entry）。

| 参数 | 含义 |
| --- | --- |
| `_name` | 字体条目的名称。 |
| `_width` | 字体宽度，单位为像素。 |
| `_height` | 字体高度，单位为像素。 |
| `_caps` | 字体能力（Font Capabilities）。 |
| `_data` | 字体的原始数据（Raw Data）。 |
| `_fc` | 映射到第一个字体元素的字符。 |
| `_lc` | 映射到最后一个字体元素的字符。 |

原文给出的宏展开值如下：

```c
static const STRUCT_SECTION_ITERABLE(cfb_font, _name) = {              \
        .data = _data,                                                 \
        .caps = _caps,                                                 \
        .width = _width,                                               \
        .height = _height,                                             \
        .first_char = _fc,                                             \
        .last_char = _lc,                                              \
}
```

字体能力枚举 [`cfb_font_caps`](https://docs.zephyrproject.org/latest/doxygen/html/group__monochrome__character__framebuffer.html#gae98337479a5339d4171797e96313fee5) 给出以下位标志（Bit Flags）：

| [`CFB_FONT_MSB_FIRST`](https://docs.zephyrproject.org/latest/doxygen/html/group__monochrome__character__framebuffer.html#ggae98337479a5339d4171797e96313fee5a837f2231088d93be083dda79095ac82b) | `BIT(2)` | 最高有效位优先（Most Significant Bit First）。 |

译注：原页枚举条目没有额外说明，上表中文解释对应其名称；`BIT(n)` 表示第 n 位的位掩码。

## 184.4\_初始化、释放与提交

三个函数的声明为：

```c
int cfb_framebuffer_init(const struct device *dev);
void cfb_framebuffer_deinit(const struct device *dev);
int cfb_framebuffer_finalize(const struct device *dev);
```

[`cfb_framebuffer_init()`](https://docs.zephyrproject.org/latest/doxygen/html/group__monochrome__character__framebuffer.html#ga2bbe913d7f0a10b4ba543d83ef6fac95) 初始化字符帧缓冲；成功返回 0，否则返回负值。

[`cfb_framebuffer_deinit()`](https://docs.zephyrproject.org/latest/doxygen/html/group__monochrome__character__framebuffer.html#ga981f062bb314c107230e068f575f81ef) 对字符帧缓冲执行反初始化（Deinitialization），无返回值。

[`cfb_framebuffer_finalize()`](https://docs.zephyrproject.org/latest/doxygen/html/group__monochrome__character__framebuffer.html#ga9d0b3f63c2b52458ab040993b3c3b97d) 完成帧缓冲处理并将其写入显示器 **随机存取存储器（Random Access Memory，RAM）**，必要时反转或重排像素；成功返回 0，否则返回负值。

## 184.5\_绘制字符串

```c
int cfb_print(const struct device *dev, const char *const str,
              int16_t x, int16_t y);
int cfb_draw_text(const struct device *dev, const char *const str,
                  int16_t x, int16_t y);
```

[`cfb_print()`](https://docs.zephyrproject.org/latest/doxygen/html/group__monochrome__character__framebuffer.html#ga029d0f320157e6b2936bb9f0794024d6) 和 [`cfb_draw_text()`](https://docs.zephyrproject.org/latest/doxygen/html/group__monochrome__character__framebuffer.html#ga496b3b161fa0bc2e42e3d5de83c4f544) 都向帧缓冲打印字符串。参数 `str` 是要打印的字符串，`x`、`y` 分别是字符串起始位置的 X、Y 坐标。两者成功返回 0，否则返回负值。

相较于 `cfb_print()`，`cfb_draw_text()` 接受不按块对齐的坐标（Non Tile-aligned Coordinates），并且不执行自动换行（Line Wrapping）。

## 184.6\_绘制点、线、矩形和圆

```c
int cfb_draw_point(const struct device *dev, const struct cfb_position *pos);
int cfb_draw_line(const struct device *dev, const struct cfb_position *start,
                  const struct cfb_position *end);
int cfb_draw_rect(const struct device *dev, const struct cfb_position *start,
                  const struct cfb_position *end);
int cfb_draw_circle(const struct device *dev, const struct cfb_position *start,
                    uint16_t radius);
```

| 函数 | 绘制内容与参数 |
| --- | --- |
| [`cfb_draw_point()`](https://docs.zephyrproject.org/latest/doxygen/html/group__monochrome__character__framebuffer.html#gae1943e8d138f5e612f6508dd0f510134) | 绘制点，`pos` 为点的位置。 |
| [`cfb_draw_line()`](https://docs.zephyrproject.org/latest/doxygen/html/group__monochrome__character__framebuffer.html#ga81af74d2831d5a4fc1338da693401958) | 绘制线，`start` 为起点，`end` 为终点。 |
| [`cfb_draw_rect()`](https://docs.zephyrproject.org/latest/doxygen/html/group__monochrome__character__framebuffer.html#ga0b26cd0d9e2de71f754f85849ccba001) | 绘制矩形，`start` 为左上角，`end` 为右下角。 |
| [`cfb_draw_circle()`](https://docs.zephyrproject.org/latest/doxygen/html/group__monochrome__character__framebuffer.html#ga2a87d5fd58bb7a56081668313f7038f6) | 绘制圆，`start` 为圆心位置，`radius` 为半径。 |

四个函数均在成功时返回 0，否则返回负值。

## 184.7\_清除与反色

```c
int cfb_framebuffer_clear(const struct device *dev, bool clear_display);
int cfb_framebuffer_invert(const struct device *dev);
int cfb_invert_area(const struct device *dev, int16_t x, int16_t y,
                    uint16_t width, uint16_t height);
```

[`cfb_framebuffer_clear()`](https://docs.zephyrproject.org/latest/doxygen/html/group__monochrome__character__framebuffer.html#gac9a957b5dd6e99377d9c070085df3252) 清空帧缓冲；`clear_display` 指定是否同时清除显示器内容。

[`cfb_framebuffer_invert()`](https://docs.zephyrproject.org/latest/doxygen/html/group__monochrome__character__framebuffer.html#ga8e86d48a0c6d951de34089f5d6cf5fb1) 反转像素（Invert Pixels）。

[`cfb_invert_area()`](https://docs.zephyrproject.org/latest/doxygen/html/group__monochrome__character__framebuffer.html#ga02dbf9751af0ee01e20a293b94fcfb7a) 反转指定区域内的像素；`x`、`y` 为区域起始位置的坐标，`width`、`height` 为区域宽度和高度，单位为像素。

三个函数均在成功时返回 0，否则返回负值。

## 184.8\_查询显示参数

```c
int cfb_get_display_parameter(const struct device *dev,
                              enum cfb_display_param);
```

[`cfb_get_display_parameter()`](https://docs.zephyrproject.org/latest/doxygen/html/group__monochrome__character__framebuffer.html#gaeb46dfb72c31474c1acbc46d2f08803e) 的第二个参数从 [`cfb_display_param`](https://docs.zephyrproject.org/latest/doxygen/html/group__monochrome__character__framebuffer.html#ga32e8edb517093dbc1b612a1bef24c7af) 枚举中选择显示参数。函数直接返回对应参数值。

## 184.9\_字体选择与字距

```c
int cfb_framebuffer_set_font(const struct device *dev, uint8_t idx);
int cfb_set_kerning(const struct device *dev, int8_t kerning);
```

[`cfb_framebuffer_set_font()`](https://docs.zephyrproject.org/latest/doxygen/html/group__monochrome__character__framebuffer.html#ga29343c61a7a9e28c50cb384ba4f383cf) 用 `idx` 指定字体索引（Font Index），设置当前字体。

[`cfb_set_kerning()`](https://docs.zephyrproject.org/latest/doxygen/html/group__monochrome__character__framebuffer.html#gac0918644cb24a39ef578e54acac46d64) 用 `kerning` 设置字距（Kerning），即相邻字母之间的间隔。

两个函数均在成功时返回 0，否则返回负值。

## 184.10\_查询字体大小与数量

```c
int cfb_get_font_size(const struct device *dev, uint8_t idx,
                      uint8_t *width, uint8_t *height);
int cfb_get_numof_fonts(const struct device *dev);
```

[`cfb_get_font_size()`](https://docs.zephyrproject.org/latest/doxygen/html/group__monochrome__character__framebuffer.html#ga63ea5f559391ed735da8afa78745e458) 查询索引为 `idx` 的字体大小。`width` 和 `height` 分别指向保存字体宽度与高度的变量；成功返回 0，否则返回负值。

[`cfb_get_numof_fonts()`](https://docs.zephyrproject.org/latest/doxygen/html/group__monochrome__character__framebuffer.html#ga5ef3b84b6169eaef398cf47b3583c827) 返回字体数量。
