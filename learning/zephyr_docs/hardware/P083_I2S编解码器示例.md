# 第83章\_I2S编解码器示例

原文：[I2S codec](https://docs.zephyrproject.org/latest/samples/drivers/i2s/i2s_codec/README.html)。读取日期：2026-10-13，`latest`。

## 83.1\_音频流送入编解码器

本示例演示用 **芯片间声音总线（Inter-IC Sound，I2S）**驱动进行简单音频流处理。它配置并启动数据路径，从包含示例正弦波的内存缓冲区，或从 **数字麦克风（Digital Microphone，DMIC）**取得音频数据，再通过 **直接内存访问（Direct Memory Access，DMA）**送入 **音频编解码器（Audio Codec）**。

## 83.2\_构建、烧录与监听

原文报告在 `mimxrt595_evk/mimxrt595s/cm33` 上测试过。官方源码位于 `samples/drivers/i2s/i2s_codec`。准备Zephyr环境、目标工具链和烧录工具后，在Ubuntu Bash或已准备好的UCRT64 Bash中，从实验Zephyr源码根目录执行：

```shell
west build -b mimxrt595_evk/mimxrt595s/cm33 samples/drivers/i2s/i2s_codec
west flash
```

构建成功后烧录。运行时，原文建议将耳机接至 **线路输出（Line Out）**接口，听取DMIC或内存缓冲区产生的声音；示例包含正弦波供参考。具体输出接口和连接设备需以目标板说明为准。

## 83.3\_平台说明与接口

对于 `rd_rw612_bga`，默认配置把音频路由到J2线路电平音频输出插孔。不能把J2编号直接套用于其他板。

相关 **应用程序编程接口（Application Programming Interface，API）**见[I2S参考](https://docs.zephyrproject.org/latest/doxygen/html/group__i2s__interface.html)，概览见[I2S数字音频总线](P080_I2S数字音频总线.md)。本次未构建、烧录、录音或播放示例音频。
