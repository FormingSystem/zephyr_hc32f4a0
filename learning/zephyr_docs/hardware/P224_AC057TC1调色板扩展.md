# 第224章\_AC057TC1调色板扩展

原文：[group__ac057tc1__display__interface](https://docs.zephyrproject.org/latest/doxygen/html/group__ac057tc1__display__interface.html)。读取日期：2026-10-13，`latest`。

## 224.1\_范围与颜色表示

本页提供 AC057TC1 七色 **电子墨水（E-Ink）**显示控制器的设备专用 **应用程序编程接口（Application Programming Interface，API）**扩展。接口自 Zephyr 4.4.0 提供，本页版本为 0.1.0，宏定义来自 `zephyr/drivers/display/ac057tc1.h`。

显示器支持七种颜色，通过 3 位索引（Index）0～6 映射。[显示能力结构](P216_显示能力结构.md)的调色板以 ARGB8888 表示这些颜色，即透明度、红、绿、蓝（Alpha, Red, Green, Blue）各 8 位，供 **用户界面（User Interface，UI）**渲染使用，例如图形库 LVGL。

控制器渲染时直接使用索引值；ARGB8888 到硬件颜色表示的转换由应用决定。
