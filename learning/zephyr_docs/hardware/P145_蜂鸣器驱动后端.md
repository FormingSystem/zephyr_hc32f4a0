# 第145章\_蜂鸣器驱动后端

原文：[group__buzzer__interface__backend](https://docs.zephyrproject.org/latest/doxygen/html/group__buzzer__interface__backend.html)。读取日期：2026-10-13，`latest`。

## 145.1\_驱动实现所需类型

**蜂鸣器驱动后端（Buzzer Driver Backend）**包含实现蜂鸣器所需的 **应用程序编程接口（Application Programming Interface，API）**类型定义、回调签名及其他辅助项。头文件为 `zephyr/drivers/buzzer.h`，操作表结构是 [`buzzer_driver_api`](P146_蜂鸣器驱动操作表.md)。

## 145.2\_四个操作函数指针类型

下列均为返回 `int` 的 **函数指针类型（Function Pointer Type）**，声明按原页保留：

```c
typedef int (*buzzer_tone_t)(const struct device *dev,
                             uint32_t freq_hz, uint32_t duration_ms);
typedef int (*buzzer_set_volume_t)(const struct device *dev, uint8_t percent);
typedef int (*buzzer_beep_t)(const struct device *dev, uint32_t duration_ms);
typedef int (*buzzer_stop_t)(const struct device *dev);
```

[`buzzer_tone_t`](https://docs.zephyrproject.org/latest/doxygen/html/group__buzzer__interface__backend.html#gac6ae53a4674a3c1ca96a7e41735f9ff3) 播放指定持续时间的单音，参数对应 [`buzzer_tone()`](https://docs.zephyrproject.org/latest/doxygen/html/group__buzzer__interface.html#ga11d8fa4f540452ee487164a4af200868)；[`buzzer_set_volume_t`](https://docs.zephyrproject.org/latest/doxygen/html/group__buzzer__interface__backend.html#ga19d504c3b6dc816706d5cdd9dec37e3f) 设置音量，参数对应 [`buzzer_set_volume()`](https://docs.zephyrproject.org/latest/doxygen/html/group__buzzer__interface.html#ga6ad479424be12d83cab59656cf94cde0)；[`buzzer_beep_t`](https://docs.zephyrproject.org/latest/doxygen/html/group__buzzer__interface__backend.html#gae36ee5133f2877ee6bd119214744b362) 播放默认音调，参数对应 [`buzzer_beep()`](https://docs.zephyrproject.org/latest/doxygen/html/group__buzzer__interface.html#gad22c8c78d97814b849d87e42b1363ea9)；[`buzzer_stop_t`](https://docs.zephyrproject.org/latest/doxygen/html/group__buzzer__interface__backend.html#gad6e97a02e02eaf1f127203a856018cf3) 停止正在播放的音调，参数对应 [`buzzer_stop()`](https://docs.zephyrproject.org/latest/doxygen/html/group__buzzer__interface.html#ga8990f4ef56d763b59a59e9fc69782106)。

原文将参数说明统一引用到公共函数；完整的设备、频率、毫秒时长、音量百分比及返回码说明见[蜂鸣器接口参考](P144_蜂鸣器接口参考.md)。
