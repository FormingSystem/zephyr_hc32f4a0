# 第231章\_步进速度斜坡结构

原文：[structstepper__ctrl__ramp](https://docs.zephyrproject.org/latest/doxygen/html/structstepper__ctrl__ramp.html)。读取日期：2026-10-13，`latest`。

## 231.1\_用途

结构 [`stepper_ctrl_ramp`](https://docs.zephyrproject.org/latest/doxygen/html/structstepper__ctrl__ramp.html) 定义 **步进运动控制器（Stepper Motion Controller）**的 **速度斜坡（Ramp）**参数，来自官方头文件 `zephyr/drivers/stepper/stepper_ctrl.h`，供[配置斜坡函数](P230_步进运动控制接口.md)使用。

## 231.2\_数据字段（Data Fields）

三个字段类型均为 [`uint32_t`](https://docs.zephyrproject.org/latest/doxygen/html/stdint_8h.html#a0a8582351ac627ee8bde2973c825e47f)；微步（Micro-step）是这里速度和加减速度的位移单位。

| 字段 | 原文含义 | 单位 |
| --- | --- | --- |
| [`acceleration_max`](https://docs.zephyrproject.org/latest/doxygen/html/structstepper__ctrl__ramp.html#ad14c31f2db1191e46585b03edcc14719) | 加速度（Acceleration）。 | 微步/秒²，即 `micro_steps/s²`。 |
| [`speed_max`](https://docs.zephyrproject.org/latest/doxygen/html/structstepper__ctrl__ramp.html#ae3348ab71b3f686c0cb872c7d65dee29) | 最大速度（Maximum Speed）。 | 微步/秒，即 `micro_steps/s`。 |
| [`deceleration_max`](https://docs.zephyrproject.org/latest/doxygen/html/structstepper__ctrl__ramp.html#a3975a535adcf407c19ae9ab804b73efe) | 减速度（Deceleration）。 | 微步/秒²，即 `micro_steps/s²`。 |
