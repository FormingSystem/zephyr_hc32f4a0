# 第7章\_时钟控制

原文：[Clock Control](https://docs.zephyrproject.org/latest/hardware/peripherals/clock_control.html)。读取日期：2026-10-12，`latest`。

**时钟控制（Clock Control）** **应用程序编程接口（Application Programming Interface，API）** 提供系统时钟的访问能力，包括开启和关闭时钟。

## 7.1\_配置选项

相关配置项为 [CONFIG_CLOCK_CONTROL](https://docs.zephyrproject.org/latest/kconfig.html#CONFIG_CLOCK_CONTROL)。

## 7.2\_接口参考与示例

接口详情见[官方 Clock Control API](../timer_reference/P092_时钟控制公共接口.md)。原文列出两个示例：

- [AXI Clocking Wizard](https://docs.zephyrproject.org/latest/samples/boards/amd/xclk_wiz/README.html)：启用、重新配置并回读 AXI Clocking Wizard 输出时钟。
- [LiteX 时钟控制驱动](../timer_reference/P117_LiteX时钟控制示例.md)：使用 LiteX 驱动生成多个时钟信号。

> 译注：官方说明页本身仅包含上述概览、配置和参考入口。API 参考与示例是独立待翻译页面，本页完成不表示这些子页面已完成，也没有把特定芯片的 PLL、晶振或分频参数补写成官方原文。
