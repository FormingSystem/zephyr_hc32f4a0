# 第135章\_生物特征识别

原文：[Biometrics](https://docs.zephyrproject.org/latest/hardware/peripherals/biometrics.html)。读取日期：2026-10-13，`latest`。

## 135.1\_生物特征传感器的统一接口

**生物特征识别（Biometrics）**的 **应用程序编程接口（Application Programming Interface，API）**为指纹扫描器、虹膜扫描器和人脸识别模块等传感器提供统一接口。这些传感器常用于嵌入式系统、门禁设备和 **物联网（Internet of Things，IoT）**应用中的安全身份认证。

API覆盖生物特征操作的完整生命周期，包括 **录入（Enrollment）**、**模板管理（Template Management）**及 **匹配（Matching）**。根据硬件能力，传感器可将模板保存在设备自身，也可保存在主机系统。

典型的指纹录入需要对同一手指采集多个样本，以生成可靠模板。匹配过程将采集样本与已存模板比较，以验证身份。

## 135.2\_配置、接口与示例

相关Kconfig配置项为 [`CONFIG_BIOMETRICS`](https://docs.zephyrproject.org/latest/kconfig.html#CONFIG_BIOMETRICS) 和初始化优先级配置项 [`CONFIG_BIOMETRICS_INIT_PRIORITY`](https://docs.zephyrproject.org/latest/kconfig.html#CONFIG_BIOMETRICS_INIT_PRIORITY)；Kconfig是Zephyr配置系统。

完整声明见[生物特征识别API](https://docs.zephyrproject.org/latest/doxygen/html/group__biometrics__interface.html)。原页关联[指纹传感器示例](../driver_samples/P032_指纹传感器示例.md#fingerprint-sensor)，演示指纹录入、**验证（Verification）**、**识别（Identification）**和模板管理。
