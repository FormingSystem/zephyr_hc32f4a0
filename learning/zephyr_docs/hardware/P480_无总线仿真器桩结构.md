# 第480章\_无总线仿真器桩结构

原文：[structno__bus__emul](https://docs.zephyrproject.org/latest/doxygen/html/structno__bus__emul.html)。读取日期：2026-10-13，`latest`。

`struct no_bus_emul` 是仿真器实际上没有连接总线时使用的**接口桩（API Stub）**结构，定义于 `zephyr/drivers/emul.h`。**应用程序编程接口（Application Programming Interface，API）**在此指具体仿真器提供的接口对象。

## 480.1\_接口与地址字段

原页仍为这个无总线桩保留接口指针和设备地址，字段说明如下：

| 类型与字段 | 官方说明译文 |
| --- | --- |
| `void *api` | 仿真器专用的总线 API |
| `uint16_t addr` | 被仿真设备的地址，来自设备树的 `reg` 属性 |

**设备树（Devicetree）**用于描述设备；这里的 `reg` 是属性名称。[`addr`](https://docs.zephyrproject.org/latest/doxygen/html/structno__bus__emul.html#aee2b4297901108a071658fa07e56043f) 使用 16 位无符号整数保存该属性给出的地址。

> 译注：“没有连接总线”与字段注释中的“总线 API”均为原文表述；保留这些字段不表示实际存在一条硬件总线。
