# 第192章\_LP3943四色LED示例

原文：[LP3943 RGBW LED](https://docs.zephyrproject.org/latest/samples/drivers/led/lp3943/README.html)。读取日期：2026-10-13，`latest`。

## 192.1\_概述与要求

本示例控制接到 LP3943 驱动器上的 16 个 **发光二极管（Light-Emitting Diode，LED）**：每隔一秒依次点亮一个，直到全部点亮，然后按相反顺序依次关闭，并不断重复该图案。

原页题名中的 RGBW 指红、绿、蓝、白（Red, Green, Blue, White）。[Neonkey开发板](https://docs.zephyrproject.org/latest/boards/96boards/neonkey/doc/index.html#96b_neonkey)板载 LP3943 驱动器和 16 个 LED，因此作为本例使用的开发板。

## 192.2\_构建与运行（Building and Running）

为含有 LP3943 驱动器的 Neonkey 构建应用。译注：在已配置 Zephyr 开发环境的终端中，从 Zephyr 源码根目录执行下列官方命令；示例由官方仓库提供，west 生成构建产物。

```bash
west build -b 96b_neonkey samples/drivers/led/lp3943
```

烧录方法见 [Neonkey开发板文档](https://docs.zephyrproject.org/latest/boards/96boards/neonkey/doc/index.html#96b_neonkey)的烧录（Flashing）小节。

除了观察 LED 图案，还可以连接串行控制台（Serial Console），查看下列输出。OS 为 **操作系统（Operating System）**，日志中的历史版本按原文保留。`BOOTING` 表示正在启动，`ZEPHYR` 是项目名称，`INF` 是信息级日志（Informational Log）标记：

```text
***** BOOTING ZEPHYR OS v1.11.99 *****
[general] [INF] main: Found LED device LP3943
[general] [INF] main: Displaying the pattern
```
