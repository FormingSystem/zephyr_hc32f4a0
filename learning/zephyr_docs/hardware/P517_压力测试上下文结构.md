# 第517章\_压力测试上下文结构

原文：[structztress__context__data](P517_压力测试上下文结构.md)。读取日期：2026-10-13，`latest`。

`struct ztress_context_data` 保存 `ztress` **压力测试（Stress Testing）**使用的上下文数据。公开头文件为 `zephyr/ztress.h`，源码位置为 `subsys/testsuite/ztest/include/zephyr/ztress.h`；这里以公开包含名替代原文构建机的绝对路径。

## 517.1\_处理函数与完成条件字段

原页仅列出以下五个字段，没有字段说明。下表保留完整类型和名称；右栏均为结合前述压力测试宏参数给出的译注。

| 字段声明 | 译注：对应含义 |
| --- | --- |
| `ztress_handler handler` | 用户处理函数，使用压力测试回调类型 |
| `void *user_data` | 传给处理函数的用户数据 |
| `uint32_t exec_cnt` | 执行次数条件 |
| `uint32_t preempt_cnt` | 被抢占次数条件；抢占（Preemption）是更高优先级上下文打断当前执行 |
| `k_timeout_t t` | Zephyr 超时类型保存的初始时间基准 |

各字段在 `ZTRESS_CONTEXT_INITIALIZER` 和 `ZTRESS_THREAD` 宏中的完成规则见[压力测试宏](P508_ZTest压力测试宏.md)。
