# 第707章\_IT8801多功能映射绑定

<a id="dtbinding-ite-it8801-mfd-map"></a>

原文：[ite,it8801-mfd-map](https://docs.zephyrproject.org/latest/build/dts/api/bindings/mfd/ite,it8801-mfd-map.html)。读取日期：2026-10-13，`latest`。

`ite,it8801-mfd-map` 是设备树绑定（Devicetree Binding），属于多功能设备（Multi-Function Device，MFD）目录，描述ITE Tech. Inc.的IT8801复用控制器节点（Alternate Controller Node）。

使用此兼容字符串的开发板见[官方筛选目录](https://docs.zephyrproject.org/latest/boards/index.html#compatibles=ite,it8801-mfd-map)。

## 707.1\_子节点属性

本页 `phandle-array` 表示节点引用（Phandle）及其说明单元组成的数组。

| 属性 | 类型 | 中文说明与约束 |
| --- | --- | --- |
| `altctrls` | `phandle-array` | **必需**。原页未提供文字说明，仅声明此子节点属性的类型及必需性；其值是节点引用与说明单元数组 |

本绑定没有顶层属性（Top-Level Properties）；上表仅针对子节点（Child Node），不能将 `altctrls` 的必需性移到父节点上。原页也没有列出继承的基础属性。
