# 第159章\_DRV2605配置联合体

原文：[uniondrv2605__config__data](https://docs.zephyrproject.org/latest/doxygen/html/uniondrv2605__config__data.html)。读取日期：2026-10-13，`latest`。

## 159.1\_选择与信号源对应的配置指针

[`drv2605_config_data`](https://docs.zephyrproject.org/latest/doxygen/html/uniondrv2605__config__data.html) 是DRV2605的 **配置数据联合体（Configuration Data Union）**，保存所选触觉源需要的具体配置结构指针。调用 [`drv2605_haptic_config()`](https://docs.zephyrproject.org/latest/doxygen/html/group__drv2605__interface.html#gafe7decc53e258a7162b44ae2076c10d1) 前，必须填入与所选源对应的成员。定义来自 `zephyr/drivers/haptics/drv2605.h`。

## 159.2\_两个配置分支

**只读存储器（Read-Only Memory，ROM）**源与 **实时播放（Real-Time Playback，RTP）**源分别使用下表成员。

| 成员 | 类型 | 对应源与配置 |
| --- | --- | --- |
| [`rom_data`](https://docs.zephyrproject.org/latest/doxygen/html/uniondrv2605__config__data.html#a5ce02bc581a432bc04eec84e00bbc342) | `struct drv2605_rom_data *` | 源为 [`DRV2605_HAPTICS_SOURCE_ROM`](https://docs.zephyrproject.org/latest/doxygen/html/group__drv2605__interface.html#ggae98fe02355253b7d8f4583a36919639ca38623b24d3ca65f42e8ab09ad2764d5d) 时使用，指向[ROM配置](P157_DRV2605只读波形配置.md)。 |
| [`rtp_data`](https://docs.zephyrproject.org/latest/doxygen/html/uniondrv2605__config__data.html#a7be34001008f23458c72b3b537f6c0bd) | `struct drv2605_rtp_data *` | 源为 [`DRV2605_HAPTICS_SOURCE_RTP`](https://docs.zephyrproject.org/latest/doxygen/html/group__drv2605__interface.html#ggae98fe02355253b7d8f4583a36919639ca51dd1dcc3db5a89efd31a9f72c7db43a) 时使用，指向[RTP配置](P158_DRV2605实时播放配置.md)。 |

两个成员均为配置结构指针。配置调用及返回值见[DRV2605触觉扩展](P154_DRV2605触觉扩展.md)。
