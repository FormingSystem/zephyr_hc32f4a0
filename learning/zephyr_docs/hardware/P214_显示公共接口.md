# 第214章\_显示公共接口

原文：[group__display__interface](https://docs.zephyrproject.org/latest/doxygen/html/group__display__interface.html)。读取日期：2026-10-13，`latest`。

## 214.1\_范围与版本

本页提供显示控制器（Display Controller）的 **应用程序编程接口（Application Programming Interface，API）**，自 Zephyr 1.14 提供，本页版本为 0.10.0。主头文件为 `zephyr/drivers/display.h`。

配套数据结构包括[缓冲区描述符](P215_显示缓冲区描述符.md)、[显示能力](P216_显示能力结构.md)、[事件数据](P217_显示事件数据.md)和[调色板颜色](P218_显示调色板颜色.md)。

## 214.2\_每像素位数宏

宏 `DISPLAY_BITS_PER_PIXEL(fmt)` 展开为给定显示格式每个像素所需的位数，可用于按像素格式分配 **帧缓冲区（Framebuffer）**。参数 `fmt` 是显示格式；展开式中的 `PIXEL_FORMAT_*` 都是 `display_pixel_format` 枚举的像素格式常量，中文含义、位数与布局见下一节。下面完整保留原宏展开式：

```c
((((fmt & PIXEL_FORMAT_RGB_888) >> 0) * 24U) +                          \
(((fmt & PIXEL_FORMAT_MONO01) >> 1) * 1U) +                             \
(((fmt & PIXEL_FORMAT_MONO10) >> 2) * 1U) +                             \
(((fmt & PIXEL_FORMAT_ARGB_8888) >> 3) * 32U) +                         \
(((fmt & PIXEL_FORMAT_RGB_565) >> 4) * 16U) +                           \
(((fmt & PIXEL_FORMAT_RGB_565X) >> 5) * 16U) +                          \
(((fmt & PIXEL_FORMAT_L_8) >> 6) * 8U) +                                \
(((fmt & PIXEL_FORMAT_AL_88) >> 7) * 16U) +                             \
(((fmt & PIXEL_FORMAT_XRGB_8888) >> 8) * 32U) +                         \
(((fmt & PIXEL_FORMAT_BGR_888) >> 9) * 24U) +                           \
(((fmt & PIXEL_FORMAT_ABGR_8888) >> 10) * 32U) +                        \
(((fmt & PIXEL_FORMAT_RGBA_8888) >> 11) * 32U) +                        \
(((fmt & PIXEL_FORMAT_BGRA_8888) >> 12) * 32U) +                        \
(((fmt & PIXEL_FORMAT_I_4) >> 13) * 4U) +                               \
(((fmt & PIXEL_FORMAT_L_4) >> 14) * 4U) +                               \
(((fmt & PIXEL_FORMAT_YUYV) >> 15) * 16U))
```

## 214.3\_像素格式及原始内存布局

枚举 [`display_pixel_format`](https://docs.zephyrproject.org/latest/doxygen/html/group__display__interface.html#gac346bc56771052a8fe919c3ec23d7c9c) 定义 **像素格式（Pixel Format）**。RGB 表示红、绿、蓝（Red, Green, Blue）；BGR 表示相反的蓝、绿、红分量顺序。A 表示透明度分量（Alpha），X 表示未使用位；L 表示亮度（Luminance），I 表示索引色（Indexed Color）。

ARGB/ABGR 分别表示 Alpha-Red-Green-Blue / Alpha-Blue-Green-Red；RGBA/BGRA 分别表示 Red-Green-Blue-Alpha / Blue-Green-Red-Alpha；XRGB 表示 Unused-Red-Green-Blue。AL88 是 Alpha-Luminance 各 8 位，RGB565 的数字表示红、绿、蓝分量位数；YUV 是亮度 Y 与两个色度分量 U/V 的命名，YUYV 表示它们的打包顺序。

原文总述称：格式包含多个字节时，字节序为 **大端序（Big Endian）**。下列字符图按原文逐字保留，表示其内存组织。

> 译注：原文的“大端序”总述与部分图中 `Byte 0` 对应低位的排列存在理解上的冲突。本译文同时保留总述与原图，不自行翻转字节；实际缓冲区布局应结合对应格式、驱动实现和接口版本核对。

## 214.5\_读写、清屏与帧缓冲访问

下列各函数中的 `dev` 均指向设备结构。读写函数的 `x`、`y` 是操作矩形左上角的坐标；`desc` 指向描述缓冲区布局的结构，`buf` 指向缓冲区数组。

```c
static inline int display_write(const struct device *dev, const uint16_t x,
    const uint16_t y, const struct display_buffer_descriptor *desc,
    const void *buf);
static inline int display_read(const struct device *dev, const uint16_t x,
    const uint16_t y, const struct display_buffer_descriptor *desc, void *buf);
static inline int display_clear(const struct device *dev);
static inline void *display_get_framebuffer(const struct device *dev);
```

函数 [`display_write()`](https://docs.zephyrproject.org/latest/doxygen/html/group__display__interface.html#ga3a5114b4537039fc4d3258678b82cd18) 向显示器写入数据，[`display_read()`](https://docs.zephyrproject.org/latest/doxygen/html/group__display__interface.html#ga3f497776520b0eac16b8aea80ccbbcfc) 从显示器读取数据，[`display_clear()`](https://docs.zephyrproject.org/latest/doxygen/html/group__display__interface.html#ga62a6cd9e338aa07f789de60e64d3b3c4) 清除显示设备屏幕。这三个函数成功返回 0，失败返回负的错误码（Negative errno Code）。错误码标识保留原名：`-EINVAL` 表示参数无效（Invalid Argument），`-ENOTSUP` 表示操作不支持（Not Supported），`-EAGAIN` 表示暂时不可用/需重试（Try Again），`-EIO` 表示输入输出错误（Input/Output Error），`-ENOMEM` 表示内存不足（Not Enough Memory），`-ENOSYS` 表示未实现（Not Implemented）。原文逐项列出的驱动含义如下：

| 函数 | 错误返回及含义 |
| --- | --- |
| `display_write()` | `-EINVAL`：描述符、矩形或缓冲区无效；`-ENOTSUP`：不支持请求的更新模式，例如局部写入；`-EAGAIN`：设备忙或未启动，是驱动相关的临时状态；`-EIO`：传输或编程失败；`-ENOMEM`：内存或资源不足。 |
| `display_read()` | `-ENOSYS`：未实现；`-EINVAL`：描述符、矩形或缓冲区无效；`-EAGAIN`：设备忙或未启动，是驱动相关的临时状态；`-EIO`：传输或编程失败。 |
| `display_clear()` | `-ENOSYS`：未实现。 |

函数 [`display_get_framebuffer()`](https://docs.zephyrproject.org/latest/doxygen/html/group__display__interface.html#ga4b66d380e46909caaa7317857f84a9e8) 返回可直接访问的帧缓冲指针；不支持直接访问时返回空指针 `NULL`。

## 214.6\_消隐、亮度与对比度

```c
static inline int display_blanking_on(const struct device *dev);
static inline int display_blanking_off(const struct device *dev);
static inline int display_set_brightness(const struct device *dev,
                                         uint8_t brightness);
static inline int display_set_contrast(const struct device *dev,
                                       uint8_t contrast);
```

函数 [`display_blanking_on()`](https://docs.zephyrproject.org/latest/doxygen/html/group__display__interface.html#gac6ad1f33067165e4c3bf7c0c345bb4e4) 启用 **消隐（Blanking）**，使整屏不显示。帧缓冲内容保留，仍可读写；驱动支持背光控制时，背光关闭，但背光配置保留且可继续配置。驱动支持消隐时，其初始状态等同于已调用本函数。

函数 [`display_blanking_off()`](https://docs.zephyrproject.org/latest/doxygen/html/group__display__interface.html#ga4d9e288891a6bde679c3aa00b9913e1d) 关闭消隐，将帧缓冲内容恢复到显示器；驱动支持背光控制时也恢复背光配置。

函数 [`display_set_brightness()`](https://docs.zephyrproject.org/latest/doxygen/html/group__display__interface.html#gad5cdeb245d17c8d680a5843b3cce1f8c) 设置亮度（Brightness），参数 `brightness` 按 1/256 步进，255 为全亮，0 为最低亮度。函数 [`display_set_contrast()`](https://docs.zephyrproject.org/latest/doxygen/html/group__display__interface.html#ga855c72f72238b25f23e95e50546e2f27) 设置对比度（Contrast），参数 `contrast` 同样按 1/256 步进，255 为最大差异，0 为最小。

四个函数均成功返回 0，否则返回负错误码；均列出 `-ENOSYS`（未实现）。两个消隐函数及亮度函数另列出 `-ENODEV`（依赖的设备未就绪）。

## 214.7\_查询能力、设置格式与方向

```c
static inline void display_get_capabilities(const struct device *dev,
                                             struct display_capabilities *capabilities);
static inline int display_set_pixel_format(const struct device *dev,
                                            const enum display_pixel_format pixel_format);
static inline int display_set_orientation(const struct device *dev,
                                           const enum display_orientation orientation);
```

函数 [`display_get_capabilities()`](https://docs.zephyrproject.org/latest/doxygen/html/group__display__interface.html#ga6a13e42773be13b141ebd8f047f8db50) 查询显示能力，写入 `capabilities` 指向的结构，无返回值。

函数 [`display_set_pixel_format()`](https://docs.zephyrproject.org/latest/doxygen/html/group__display__interface.html#ga7ede828663090760c2558a231d9f2150) 选择 `pixel_format` 指定的格式；成功返回 0，失败返回负错误码：`-ENOSYS` 未实现；`-ENOTSUP` 不支持该格式；`-ENOMEM` 底层帧缓冲太小或重新分配失败；`-EWOULDBLOCK`（Would Block）状态无效（显示器正在运行）；`-EIO` 重新配置失败。

函数 [`display_set_orientation()`](https://docs.zephyrproject.org/latest/doxygen/html/group__display__interface.html#ga4e0a4dc2e434144874af014b8e7c4394) 设置 `orientation` 指定的方向；成功返回 0，失败返回负错误码：`-ENOSYS` 未实现；`-ENOTSUP` 不支持该方向；`-ENODEV` 依赖的设备未就绪。

## 214.8\_事件类型与回调

枚举 [`display_event`](https://docs.zephyrproject.org/latest/doxygen/html/group__display__interface.html#ga0042f460c729a5b11ed59f4aac609212) 定义以下事件位。VSYNC 表示垂直同步（Vertical Synchronization）；FIFO 表示先进先出缓冲区（First In, First Out）；UI 表示用户界面（User Interface）。

| 事件 | 值 | 触发条件 |
| --- | --- | --- |
| [`DISPLAY_EVENT_LINE_INT`](https://docs.zephyrproject.org/latest/doxygen/html/group__display__interface.html#gga0042f460c729a5b11ed59f4aac609212a4aecf6d165ca2ec432297cc5664c24a6) | `BIT(0)` | 控制器到达配置的扫描行（Scanline）。 |
| [`DISPLAY_EVENT_VSYNC`](https://docs.zephyrproject.org/latest/doxygen/html/group__display__interface.html#gga0042f460c729a5b11ed59f4aac609212acb5772017ec3e4d6677fee78295a379c) | `BIT(1)` | 垂直同步或新一帧开始。 |
| [`DISPLAY_EVENT_FRAME_DONE`](https://docs.zephyrproject.org/latest/doxygen/html/group__display__interface.html#gga0042f460c729a5b11ed59f4aac609212abd4e3c24f05c2484137855349d6cf794) | `BIT(2)` | 向面板传输一帧或更新帧缓冲完成。 |
| [`DISPLAY_EVENT_FIFO_UNDERFLOW`](https://docs.zephyrproject.org/latest/doxygen/html/group__display__interface.html#gga0042f460c729a5b11ed59f4aac609212a456bc992ffdf5604828b7280f94dd649) | `BIT(3)` | FIFO 下溢；Qt Ultralite 等 UI 框架会检查此事件。 |

回调类型 [`display_event_cb_t`](https://docs.zephyrproject.org/latest/doxygen/html/group__display__interface.html#gadca2fe10ecb27b5e82309bbab5e886ee) 的声明：

```c
typedef enum display_event_result (*display_event_cb_t)(
    const struct device *dev, uint32_t evt,
    const struct display_event_data *data, void *user_data);
```

`dev` 指向设备结构；`evt` 是待处理的 [`display_event`](https://docs.zephyrproject.org/latest/doxygen/html/group__display__interface.html#ga0042f460c729a5b11ed59f4aac609212) 事件位；`data` 是驱动传给回调的数据；`user_data` 是驱动转交的用户数据。返回值属于枚举 [`display_event_result`](https://docs.zephyrproject.org/latest/doxygen/html/group__display__interface.html#ga5c3bcf15b62c66c1677e51a10451efe5)：`DISPLAY_EVENT_RESULT_CONTINUE = 0` 让驱动继续默认处理；`DISPLAY_EVENT_RESULT_HANDLED = 1` 表示回调已处理，驱动应跳过此事件的默认处理。

回调可以在 **中断服务程序（Interrupt Service Routine，ISR）**上下文执行，或在线程（Thread）上下文执行。注册时 `in_isr=true` 选择前者；为 `false` 时驱动调度工作来调用。ISR 回调必须极快，禁止调用会阻塞的 API 或休眠。

## 214.9\_注册与注销回调

```c
static inline int display_register_event_cb(const struct device *dev,
    display_event_cb_t cb, void *user_data, uint32_t event_mask,
    bool in_isr, uint32_t *out_reg_handle);
static inline int display_unregister_event_cb(const struct device *dev,
                                               uint32_t reg_handle);
```

函数 [`display_register_event_cb()`](https://docs.zephyrproject.org/latest/doxygen/html/group__display__interface.html#ga99b7e7da6b85bee97398a8a9b161c777) 注册显示设备回调：`cb` 是用户回调函数指针；`user_data` 将由驱动转交；`event_mask` 是触发该回调的 [`display_event`](https://docs.zephyrproject.org/latest/doxygen/html/group__display__interface.html#ga0042f460c729a5b11ed59f4aac609212) 事件掩码。`in_isr=true` 时在 ISR 中调用，必须快速且不阻塞；为 `false` 时在线程/工作队列（Workqueue）上下文调用。驱动可以只实现其中一种上下文。

`out_reg_handle` 让调用者证明这次注册的所有权，从而安全注销。成功返回 0，并输出一个非零句柄；失败返回负错误码：`-EBUSY`（Busy）已有回调注册；`-ENOTSUP` 不支持所请求的调用上下文；`-ENOSYS` 未实现；`-EINVAL` 参数无效。

原文建议非关键工作优先在线程上下文交付；ISR 应保持快速，可仅设置标志并调度工作，避免调度器 API、互斥量（Mutex）和打印。

函数 [`display_unregister_event_cb()`](https://docs.zephyrproject.org/latest/doxygen/html/group__display__interface.html#gaa4e433439206bc426db363c64882a395) 使用 `reg_handle` 句柄注销。成功返回 0，否则为负错误码：`-EINVAL` 表示 `reg_handle == 0`；`-EPERM`（Operation Not Permitted）表示调用者不是所有者或已注销；`-ENOSYS` 表示本操作或驱动的 `register_event_cb` 操作未实现。
