本页给出DAC161S997数模转换器（Digital-to-Analog Converter，DAC）的扩展声明。网页跳转文字“Go to the documentation of this file”对应[头文件中文参考](P830_DAC161S997扩展头文件.md)。

## 831.1\_源码中的声明

头文件保护宏（Header Guard）防止重复包含。`extern "C"` 为C++调用方提供C语言链接（C Linkage）。状态联合体（Union）既包含8位原始值 [`raw`](https://docs.zephyrproject.org/latest/doxygen/html/uniondac161s997__status.html#ae607e4cf155134e1924ab6e82fd4c77c)，也包含匿名位域结构（Anonymous Bit-Field Structure）；`__packed` 保留原始紧凑布局标记（Packed Layout Attribute）。

各状态位包括电流环实时错误、锁存错误、串行外设接口（Serial Peripheral Interface，SPI）超时、帧错误、ERR_LVL引脚状态和3位分辨率字段，逐项语义见[状态联合体](P829_DAC161S997状态联合体.md)。回调（Callback）类型 [`dac161s997_error_callback_t`](https://docs.zephyrproject.org/latest/doxygen/html/group__dac161s997__interface.html#ga24c693e8a7c22c6340db7595a01ef09f) 与设置函数 [`dac161s997_set_error_callback()`](https://docs.zephyrproject.org/latest/doxygen/html/group__dac161s997__interface.html#gab81de98755b9bffd8e4599fbe4ceb557) 的参数及工作队列执行约束见[扩展接口](P828_DAC161S997扩展接口.md)。

        uint8_t raw;

                bool current_loop_status: 1;

                bool spi_timeout_error: 1;
                bool frame_status: 1;
                bool error_level_pin_state: 1;
                uint8_t dac_resolution: 3;
        } __packed;
};

typedef void (*dac161s997_error_callback_t)(const struct device *dev,
                                            const union dac161s997_status *status);

int dac161s997_set_error_callback(const struct device *dev, dac161s997_error_callback_t cb);

}
