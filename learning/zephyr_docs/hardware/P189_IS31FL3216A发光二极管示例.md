# 第189章\_IS31FL3216A发光二极管示例

原文：[IS31FL3216A LED](https://docs.zephyrproject.org/latest/samples/drivers/led/is31fl3216a/README.html)。读取日期：2026-10-13，`latest`。

## 189.1\_概述（Overview）

本示例控制接在 IS31FL3216A 驱动器上的最多 16 个 **发光二极管（Light-Emitting Diode，LED）**，使用 **脉冲宽度调制（Pulse Width Modulation，PWM）**调节亮度。

每个 LED 逐渐增亮到 100%，然后逐渐熄灭。各灯分别完成变化后，示例使用 [`led_write_channels()`](P202_LED公共接口.md) **应用程序编程接口（Application Programming Interface，API）**同时控制多个灯的亮度变化。

## 189.2\_测试图案（Test Pattern）

对每一个 LED，先把亮度增加到 100%，再降低到完全熄灭。随后同时把第 2 至第 4 个 LED 的亮度增加到 100%，再降低到完全熄灭。

## 189.3\_构建与运行（Building and Running）

当 **设备树（Devicetree）**中启用了兼容标识（Compatible）为 [`issi,is31fl3216a`](../led_issi_nordic_nxp_binding_reference/P008_issi_is31fl3216a.md#std-dtcompatible-issi-is31fl3216a) 的 **内部集成电路总线（Inter-Integrated Circuit，I2C）**器件节点，同时启用其总线控制器时，即可构建并执行此示例。

官方为 [LPCXpresso55S28](https://docs.zephyrproject.org/latest/boards/nxp/lpcxpresso55s28/doc/index.html#lpcxpresso55s28) 提供设备树源（Devicetree Source，DTS）叠加文件 `boards/lpcxpresso55s28.overlay`，路径相对于该官方示例目录。配置假定一个接有 16 个 LED 的 IS31FL3216A 驱动器连接到 I2C 总线，地址为 `0x74`。
