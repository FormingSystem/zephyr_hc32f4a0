# 第307章\_I2C消息结构

原文：[structi2c__msg](https://docs.zephyrproject.org/latest/doxygen/html/structi2c__msg.html)。读取日期：2026-10-13，`latest`。

## 307.1\_一条消息

结构 [`i2c_msg`](https://docs.zephyrproject.org/latest/doxygen/html/structi2c__msg.html) 定义在集成电路间总线（Inter-Integrated Circuit，I²C）上执行事务的一条消息（Message），声明来自 `zephyr/drivers/i2c.h`。

| 字段 | 类型 | 含义 |
| --- | --- | --- |
| <a id="ac4aa590487270589a51964b38f853a37"></a>[`buf`](https://docs.zephyrproject.org/latest/doxygen/html/structi2c__msg.html#ac4aa590487270589a51964b38f853a37) | `uint8_t *` | 以字节为单位的数据缓冲区（Data Buffer） |
| <a id="ae122c36d1fdc0829321fa116921d7a52"></a>[`len`](https://docs.zephyrproject.org/latest/doxygen/html/structi2c__msg.html#ae122c36d1fdc0829321fa116921d7a52) | [`uint32_t`](https://docs.zephyrproject.org/latest/doxygen/html/stdint_8h.html#a0a8582351ac627ee8bde2973c825e47f) | 缓冲区长度，单位为字节 |
| <a id="ae6f9dc8a50b611adbca38e29b529ab9c"></a>[`flags`](https://docs.zephyrproject.org/latest/doxygen/html/structi2c__msg.html#ae6f9dc8a50b611adbca38e29b529ab9c) | [`uint8_t`](https://docs.zephyrproject.org/latest/doxygen/html/stdint_8h.html#a3cb4a16b0e8d6af0af86d4fd6ba5fd9d) | 当前消息的标志 |

## 307.2\_多缓冲区事务限制

特定片上系统（System on Chip，SoC）的I²C硬件可能不支持此接口表达的全部配置，尤其是一次总线事务内对不同缓冲区读写的功能。

遇到不受支持的配置时，[`i2c_transfer()`](https://docs.zephyrproject.org/latest/doxygen/html/group__i2c__interface.html#ga2958e6fe92ffb17851052d5c9a5c058e) **可能不报错**。某些驱动会为每个消息片段生成独立事务，不论 [`flags`](https://docs.zephyrproject.org/latest/doxygen/html/structi2c__msg.html#ae6f9dc8a50b611adbca38e29b529ab9c) 中是否设置了重复起始（RESTART）标志 [`I2C_MSG_RESTART`](https://docs.zephyrproject.org/latest/doxygen/html/group__i2c__interface.html#ga8c6cf7be2a04979fdb9d0b7dd9c4f831)。具体传输接口见[I2C公共接口](P305_I2C公共接口.md)。
