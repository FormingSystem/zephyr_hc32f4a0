# 第148章\_触觉驱动后端

原文：[group__haptics__interface__backend](https://docs.zephyrproject.org/latest/doxygen/html/group__haptics__interface__backend.html)。读取日期：2026-10-13，`latest`。

## 148.1\_驱动后端类型

**触觉驱动后端（Haptics Driver Backend）**包含实现触觉驱动所需的 **应用程序编程接口（Application Programming Interface，API）**类型、回调签名和辅助项。所有声明来自 `zephyr/drivers/haptics.h`；操作表为 [`haptics_driver_api`](P149_触觉驱动操作表.md)。

原页为每个类型引用对应公共函数的参数说明；完整参数方向、条件和返回码见[触觉反馈接口参考](P147_触觉反馈接口参考.md)。以下完整保留十一项 **函数指针类型（Function Pointer Type）**。

## 148.2\_校准外部执行器

操作类型 [`haptics_calibrate_t`](https://docs.zephyrproject.org/latest/doxygen/html/group__haptics__interface__backend.html#ga6d174ac558915159e501abecebc3e327) 对应函数 [`haptics_calibrate()`](https://docs.zephyrproject.org/latest/doxygen/html/group__haptics__interface.html#gaa8a7f36b4b37f7512f9f46133d9f4d1b)，用途为校准外部执行器。

```c
typedef int (*haptics_calibrate_t)(const struct device *dev, const uint32_t routine);
```
