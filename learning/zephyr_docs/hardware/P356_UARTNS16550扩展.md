# 第356章\_UARTNS16550扩展

原文：[uart__ns16550_8h](https://docs.zephyrproject.org/latest/doxygen/html/uart__ns16550_8h.html)。读取日期：2026-10-13，`latest`。

## 356.1\_公开头文件

`zephyr/drivers/serial/uart_ns16550.h` 是 NS16550 通用异步收发器（Universal Asynchronous Receiver/Transmitter，UART）的公开头文件，NS16550 为硬件型号/接口系列名称。

## 356.2\_分频小数设置

原页定义以下命令，用于设置 DLF：

```c
#define CMD_SET_DLF 0x01
```

> 译注：DLF 是分频锁存器小数部分（Divisor Latch Fraction），名称见[官方驱动寄存器定义](https://github.com/zephyrproject-rtos/zephyr/blob/main/drivers/serial/uart_ns16550.c#L102)。

此命令只适用于 Synopsys Designware UART 硬件模块。原文称其为知识产权核（Intellectual Property Block，IP Block），即可集成到芯片的硬件设计模块；Synopsys Designware 为产品名称。

## 356.3\_获取设备地址

[`uart_ns16550_get_port`](https://docs.zephyrproject.org/latest/doxygen/html/uart__ns16550_8h.html#a9022b0b187af1ef0b778a4575d92fbac) 从 `uart_ns16550` 驱动取得设备地址：

```c
uint32_t uart_ns16550_get_port(const struct device *dev);
```

`dev` 为 UART 设备实例。原页没有额外的错误码或地址解释，返回类型按原声明保留。
