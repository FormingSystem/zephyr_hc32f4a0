# 第213章\_TLC5971灯带扩展

原文：[group__tlc5971__interface](https://docs.zephyrproject.org/latest/doxygen/html/group__tlc5971__interface.html)。读取日期：2026-10-13，`latest`。

## 213.1\_范围与亮度上限

本扩展适用于 **德州仪器（Texas Instruments）** TLC5971 及兼容的 **发光二极管灯带（Light-Emitting Diode Strip，LED Strip）**控制器，声明来自官方头文件 `zephyr/drivers/led_strip/tlc5971.h`。

宏 [`TLC5971_GLOBAL_BRIGHTNESS_CONTROL_MAX`](https://docs.zephyrproject.org/latest/doxygen/html/group__tlc5971__interface.html#gaee75c4832a72869ca6e2960c726ed707) 为 `127`，表示全局亮度控制的最大值，对应 100% 亮度。

## 213.2\_设置全局亮度

函数声明：

```c
int tlc5971_set_global_brightness(const struct device *dev,
                                 struct led_rgb pixel);
```

函数 [`tlc5971_set_global_brightness()`](https://docs.zephyrproject.org/latest/doxygen/html/group__tlc5971__interface.html#gacc0ab1f6ae658de98d043e49291abea4) 设置 TLC5971 灯带的全局 **亮度控制（Brightness Control，BC）**值。器件为红、绿、蓝（Red, Green, Blue，RGB）每组颜色分别提供一个 7 位全局亮度控制。

`dev` 是灯带设备；`pixel` 是 RGB 各通道的全局亮度值，采用颜色结构 [`led_rgb`](P209_LED灯带颜色结构.md)，按值传入。

`pixel` 的 `r`、`g`、`b` 分量分别映射到全局亮度控制寄存器 `BCR`、`BCG`、`BCB`，每个值都必须小于或等于 [`TLC5971_GLOBAL_BRIGHTNESS_CONTROL_MAX`](https://docs.zephyrproject.org/latest/doxygen/html/group__tlc5971__interface.html#gaee75c4832a72869ca6e2960c726ed707)。

修改在下一次灯带更新时生效。成功返回 0，出错返回负值。
