# 第510章\_单元测试记录结构

原文：[structztest__unit__test](P510_单元测试记录结构.md)。读取日期：2026-10-13，`latest`。

`struct ztest_unit_test` 是 **Zephyr 测试框架（Zephyr Testing Framework，ZTest）**的单元测试记录。公开头文件为 `zephyr/ztest_test.h`，源码位置为 `subsys/testsuite/ztest/include/zephyr/ztest_test.h`；原文的构建机绝对包含路径在这里改为公开包含名。

## 510.1\_名称、测试函数与统计

原页只对 [`stats`](P510_单元测试记录结构.md) 给出“统计信息”的说明，其他字段仅列出类型和名称。下表保留全部声明，职责解释明确标为译注。

| 字段声明 | 官方说明或译注 |
| --- | --- |
| `const char *test_suite_name` | 译注：所属测试套件（Test Suite）的名称 |
| `const char *name` | 译注：测试名称 |
| `void (*test)(void *data)` | 译注：测试函数指针，接收一个 `void *data` 数据参数，无返回值 |
| `uint32_t thread_options` | 译注：线程选项（Thread Options） |
| `struct ztest_unit_test_stats *const stats` | 统计信息 |

> 译注：`stats` 的 `const` 修饰指针本身，指向的统计对象仍可更新；这与 `const struct ztest_unit_test_stats *` 不同。
