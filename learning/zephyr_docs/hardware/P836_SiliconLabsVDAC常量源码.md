# 第836章\_SiliconLabsVDAC常量源码

原文：[silabs-vdac_8h_source](https://docs.zephyrproject.org/latest/doxygen/html/silabs-vdac_8h_source.html)。读取日期：2026-10-13，`latest`。

文件路径为 `zephyr/dt-bindings/dac/silabs-vdac.h`。

本页保留Silicon Labs电压数模转换器（Voltage Digital-to-Analog Converter，VDAC）的设备树常量（Devicetree Constants）声明。文件文档入口对应[常量中文参考](P821_SiliconLabsVDAC设备树常量.md)。

## 836.1\_生成说明与输出选择

原注释说明：**此文件由 `hal_silabs` 模块中的 `gen_vdac.py` 脚本生成，不要手工编辑。**这是对官方生成头文件的说明，原英文注释也保留在下方源码中。

65个输出选择常量（Output Selection Constants）包括辅助输出（Auxiliary Output） `VDAC_OUTPUT_AUX`，以及端口A、B、C、D各16个引脚的输出标识。辅助输出编码为 `0x0`，端口A至D的编码区间依次为 `0x10`至`0x1f`、`0x20`至`0x2f`、`0x30`至`0x3f`、`0x40`至`0x4f`。逐项中文引脚名称见常量参考页。
