# 第547章\_伪步进电机控制器绑定

<a id="dtbinding-zephyr-fake-stepper-ctrl"></a>

原文：[zephyr,fake-stepper-ctrl](https://docs.zephyrproject.org/latest/build/dts/api/bindings/stepper/zephyr,fake-stepper-ctrl.html)。读取日期：2026-10-13，`latest`。

`zephyr,fake-stepper-ctrl` 是伪**步进电机控制器（Stepper Controller）**绑定，用于测试中的**测试桩（Stub）**或**模拟对象（Mock）**。提供方是 Zephyr Project，驱动为 [`drivers/stepper/fake_stepper_controller.c`](https://github.com/zephyrproject-rtos/zephyr/blob/main/drivers/stepper/fake_stepper_controller.c)，相关开发板见[官方筛选目录](https://docs.zephyrproject.org/latest/boards/index.html#compatibles=zephyr,fake-stepper-ctrl)。
