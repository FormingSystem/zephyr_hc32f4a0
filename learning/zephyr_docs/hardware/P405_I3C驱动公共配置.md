# 第405章\_I3C驱动公共配置

原文：[structi3c__driver__config](https://docs.zephyrproject.org/latest/doxygen/html/structi3c__driver__config.html)。读取日期：2026-10-13，`latest`。

## 405.1\_公共配置的位置

`struct i3c_driver_config` 是所有**改进的集成电路间总线（Improved Inter-Integrated Circuit，I3C）**驱动的公共结构。它应当是设备结构 `config` 字段所指向对象的第一个成员。包含头文件 `zephyr/drivers/i3c.h`。

## 405.2\_字段

设备列表同时包括 I3C 与**集成电路间总线（Inter-Integrated Circuit，I2C）**设备。**主控制器动态地址（Primary Controller Dynamic Address）**由 [`primary_controller_da`](https://docs.zephyrproject.org/latest/doxygen/html/structi3c__driver__config.html#a52b9e5a36b65fbadc7fd2369ff184271) 保存。

| 字段 | 类型 | 含义 |
| --- | --- | --- |
| [`dev_list`](https://docs.zephyrproject.org/latest/doxygen/html/structi3c__driver__config.html#aaa79d44e949dfdfe51e3994c08837193) | `struct i3c_dev_list` | I3C/I2C 设备列表结构，见[已知设备列表](P403_I3C已知设备列表.md)。 |
| `primary_controller_da` | [`uint8_t`](https://docs.zephyrproject.org/latest/doxygen/html/stdint_8h.html#a3cb4a16b0e8d6af0af86d4fd6ba5fd9d) | I3C 主控制器的动态地址。 |
| [`flags`](https://docs.zephyrproject.org/latest/doxygen/html/structi3c__driver__config.html#a9fcff5242bf1148d0d318f464015f19c) | [`uint8_t`](https://docs.zephyrproject.org/latest/doxygen/html/stdint_8h.html#a3cb4a16b0e8d6af0af86d4fd6ba5fd9d) | 驱动配置标志（Driver Configuration Flags）。 |
