# 第20章\_硬件信息

原文：[Hardware Information](https://docs.zephyrproject.org/latest/hardware/peripherals/hwinfo.html)。读取日期：2026-10-12，`latest`。

**硬件信息（Hardware Information，HW Info）**接口提供设备标识、复位原因标志等信息。

复位原因标志可用于判断设备为什么复位，例如看门狗超时或电源重新上电。各设备支持的标志子集不同，通过 `hwinfo_get_supported_reset_cause()` 查询当前设备支持哪些原因。

大多数实现与 **片上系统（System on Chip，SoC）** 相关，从厂商寄存器或存储区域读取标识。通用的 [`zephyr,hwinfo-nvmem` 后端](../hwinfo_binding_reference/P016_zephyr_hwinfo-nvmem.md)从 NVMEM 单元取得设备 ID，并可选取得 EUI-64；相关说明见[非易失性内存 NVMEM](https://docs.zephyrproject.org/latest/services/storage/nvmem/index.html)。

相关配置为 `CONFIG_HWINFO`、`CONFIG_HWINFO_NVMEM`。完整参考见[硬件信息接口](../hardware_util_reference/P003_硬件信息公共接口.md)。

> 译注：查询“支持的复位原因”得到的是能力集合，不是本次实际复位原因；二者不可混用。
