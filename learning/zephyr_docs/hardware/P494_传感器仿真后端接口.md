# 第494章\_传感器仿真后端接口

原文：[group__sensor__emulator__backend](P494_传感器仿真后端接口.md)。读取日期：2026-10-13，`latest`。

传感器仿真器的**后端应用程序编程接口（Backend Application Programming Interface，Backend API）**让测试程序设置通道预期值、查询有效范围并控制属性。接口定义于 `zephyr/drivers/emul_sensor.h`，以下均为静态内联函数（Static Inline Function）。

## 494.1\_查询后端支持情况

[`emul_sensor_backend_is_supported()`](P494_传感器仿真后端接口.md) 检查给定传感器仿真器是否支持后端 API。

```c
static inline bool emul_sensor_backend_is_supported(const struct emul *target);
```

参数 `target` 指向待查询的仿真器实例。支持时返回 `true`；不支持或 `target` 为 `NULL` 空指针时返回 `false`。

后续接口使用 [`sensor_chan_spec`](https://docs.zephyrproject.org/latest/doxygen/html/structsensor__chan__spec.html) 结构指定**传感器通道（Sensor Channel）**。数值采用 **定点格式（Fixed-Point Format）**，其 [`q31_t`](https://docs.zephyrproject.org/latest/doxygen/html/group__math__dsp.html#gadc89a3547f5324b7b3b95adec3806bc0) 类型保存定点值，`shift` 提供对应的移位/缩放因子；单位按传感器类型使用**国际单位制（International System of Units，SI）**。错误 `-ENOTSUP` 表示不支持，`-ERANGE` 表示范围错误。

## 494.2\_设置通道预期值

[`emul_sensor_backend_set_channel()`](P494_传感器仿真后端接口.md) 为指定仿真器的指定通道设置预期值。

```c
static inline int emul_sensor_backend_set_channel(const struct emul *target,
                                                  struct sensor_chan_spec ch,
                                                  const q31_t *value,
                                                  int8_t shift);
```

| 参数 | 含义 |
| --- | --- |
| `target` | 指向待操作仿真器实例的指针 |
| `ch` | 要设置预期值的传感器通道 |
| `value` | 采用该传感器类型标准 SI 单位的定点预期值 |
| `shift` | 应用于 `value` 的移位值，即缩放因子 |

成功返回 `0`；没有后端 API 或仿真器不支持该通道时返回 `-ENOTSUP`；给定值不在传感器支持范围内时返回 `-ERANGE`。

## 494.3\_查询样本范围与容差

[`emul_sensor_backend_get_sample_range()`](P494_传感器仿真后端接口.md) 查询通道支持的样本值范围及**容差（Tolerance）**，用于比较预期值和实际值时考虑舍入及传感器精度。

```c
static inline int emul_sensor_backend_get_sample_range(
    const struct emul *target, struct sensor_chan_spec ch,
    q31_t *lower, q31_t *upper, q31_t *epsilon, int8_t *shift);
```

| 参数 | 方向与含义 |
| --- | --- |
| `target` | 指向待操作仿真器实例的指针 |
| `ch` | 要查询的通道；不支持时返回 `-ENOTSUP` |
| `lower` | 输出：支持的最小样本值，SI 单位、定点格式 |
| `upper` | 输出：支持的最大样本值，SI 单位、定点格式 |
| `epsilon` | 输出：比较预期与实际值使用的容差；通常可设为最小样本步进，采用 SI 单位、定点格式 |
| `shift` | 输出：与 `lower`、`upper`、`epsilon` 关联的移位值，即缩放因子 |

成功返回 `0`；没有后端 API 或仿真器不支持该通道时返回 `-ENOTSUP`。

## 494.4\_设置属性值

[`emul_sensor_backend_set_attribute()`](P494_传感器仿真后端接口.md) 设置仿真器的**属性（Attribute）**值。属性由 [`sensor_attribute`](https://docs.zephyrproject.org/latest/doxygen/html/group__sensor__interface.html#ga0dcb6842bc969492bd1c9eb49708940b) 枚举指定，值的实际类型取决于通道和属性的组合。

```c
static inline int emul_sensor_backend_set_attribute(
    const struct emul *target, struct sensor_chan_spec ch,
    enum sensor_attribute attribute, const void *value);
```

全部参数均为输入：`target` 指向待操作实例；`ch` 为通道，不支持时返回 `-ENOTSUP`；`attribute` 为待设置属性；`value` 为要使用的值，应按通道/属性组合进行类型转换。成功返回 `0`；出错返回负值。

## 494.5\_查询属性元数据

[`emul_sensor_backend_get_attribute_metadata()`](P494_传感器仿真后端接口.md) 查询属性的**元数据（Metadata）**，包括最小值、最大值和每个**最低有效位（Least Significant Bit，LSB）**对应的增量。比较结果时，这个增量可作为容差使用。

```c
static inline int emul_sensor_backend_get_attribute_metadata(
    const struct emul *target, struct sensor_chan_spec ch,
    enum sensor_attribute attribute, q31_t *min, q31_t *max,
    q31_t *increment, int8_t *shift);
```

| 参数 | 方向与含义 |
| --- | --- |
| `target` | 输入：指向待操作仿真器实例的指针 |
| `ch` | 输入：要查询的通道；不支持时返回 `-ENOTSUP` |
| `attribute` | 输入：要查询的属性；不支持时返回 `-ENOTSUP` |
| [`min`](../numeric_reference/P001_最小最大值与限幅宏参考.md#ac6afabdc09a49a433ee19d8a9486056d) | 输出：属性可设置的最小值 |
| [`max`](../numeric_reference/P001_最小最大值与限幅宏参考.md#affe776513b24d84b39af8ab0930fef7f) | 输出：属性可设置的最大值 |
| `increment` | 输出：每增加一个 LSB 时属性增加的值 |
| `shift` | 输出：用于 [`min`](../numeric_reference/P001_最小最大值与限幅宏参考.md#ac6afabdc09a49a433ee19d8a9486056d)、[`max`](../numeric_reference/P001_最小最大值与限幅宏参考.md#affe776513b24d84b39af8ab0930fef7f) 和 `increment` 的移位值 |

成功返回 `0`，出错返回负值。
