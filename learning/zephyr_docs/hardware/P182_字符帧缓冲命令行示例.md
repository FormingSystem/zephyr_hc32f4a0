# 第182章\_字符帧缓冲命令行示例

原文：[Character Framebuffer shell module](https://docs.zephyrproject.org/latest/samples/subsys/display/cfb_shell/README.html)。读取日期：2026-10-13，`latest`。

## 182.1\_概述与构建

这个简单的 **命令行交互模块（Shell Module）**通过 **字符帧缓冲（Character Framebuffer，CFB）**子系统操作显示器。

选择目标开发板构建示例，例如以下 `reel_board`。译注：构建命令在已配置 Zephyr 开发环境的主机终端中执行，工作目录为 Zephyr 源码根目录；示例源码由官方仓库提供，west 生成构建产物。

```bash
# From the root of the zephyr repository
west build -b reel_board samples/subsys/display/cfb_shell
```

## 182.2\_命令帮助（Shell Module Command Help）

下文是设备运行后提供的 CFB 命令及示例，不是在主机终端里执行的操作。示例提示符 `uart:~$` 对应 **通用异步收发器（Universal Asynchronous Receiver-Transmitter，UART）**访问的设备 Shell。SSD16XX 是示例显示控制器的型号名称。

```text
cfb - Character Framebuffer shell commands
Options:
        -h, --help  :Show command help.
Subcommands:
        init        :[none]
        get_device  :[none]
        get_param   :<all, height, width, ppt, rows, cols>
        get_fonts   :[none]
        set_font    :<idx>
        invert      :[none]
        print       :<col: pos> <row: pos> <text>
        scroll      :<dir: (vertical|horizontal)> <col: pos> <row: pos>
                     <text>
        clear       :[none]
```

## 182.3\_初始化（init）

必须先调用 `init` 初始化显示器。`reel_board` 示例：

```text
uart:~$ cfb init
Framebuffer initialized: SSD16XX
Display Cleared
```

## 182.4\_取得设备名称（get_device）

`get_device` 打印显示设备名称：

```text
uart:~$ cfb get_device
Framebuffer Device: SSD16XX
```

## 182.5\_取得显示参数（get_param）

`get_param` 读取高度（Height）、宽度（Width）、每块像素数（Pixel Per Tile，ppt）、行数（Rows）和列数（Columns）。高度、宽度与 ppt 以像素为单位；行位置按 ppt 的倍数递增。

```text
uart:~$ cfb get_param all
param: height=120
param: width=250
param: ppt=8
param: rows=15
param: cols=250
```

## 182.6\_列出字体（get_fonts）

`get_fonts` 命令 打印系统中静态定义字体的索引（Index），以及以像素计的高度和宽度。

```text
uart:~$ cfb get_fonts
idx=0 height=32 width=20
idx=1 height=24 width=15
idx=2 height=16 width=10
```

## 182.7\_选择字体（set_font）

向 `set_font` 命令 传入字体索引，选择要使用的字体。同一时间只能使用一种字体。

```text
uart:~$ cfb set_font 0
Font idx=0 height=32 width=20 set
```

## 182.8\_反色（invert）

`invert` 命令 反转显示器像素颜色。

```text
uart:~$ cfb invert
Framebuffer Inverted
```

## 182.9\_打印文字（print）

向 `print` 命令 传入起始列位置、行位置以及文本。文本含空格时必须使用双引号括起。如果文本到达显示边缘，剩余字符会显示在下一行；之前打印的文本会被覆盖。下例要显示的文本为 `ZEPHYR`。

```text
uart:~$ cfb print 60 5 ZEPHYR
```

## 182.10\_滚动文字（scroll）

向 `scroll` 命令 传入滚动方向、起始列位置、行位置和文本，方向为垂直（Vertical）或水平（Horizontal）。文本含空格时使用双引号括起；到达显示边缘的剩余字符会显示在下一行。

传入的文字沿指定方向移动，直到达到显示边界：水平滚动到最后一列，垂直滚动到最后一行。

```text
uart:~$ cfb scroll vertical 60 5 ZEPHYR
```

## 182.11\_清屏（clear）

`clear` 命令 清除显示屏内容。

```text
uart:~$ cfb clear
Display Cleared
```
