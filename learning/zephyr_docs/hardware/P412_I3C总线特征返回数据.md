# 第412章\_I3C总线特征返回数据

原文：[structi3c__ccc__getbcr](https://docs.zephyrproject.org/latest/doxygen/html/structi3c__ccc__getbcr.html)。读取日期：2026-10-13，`latest`。

## 412.1\_GETBCR载荷

`struct i3c_ccc_getbcr` 是**改进的集成电路间总线（Improved Inter-Integrated Circuit，I3C）通用命令码（Common Command Code，CCC）** `GETBCR` 的载荷（Payload）。命令含义是**获取总线特征寄存器（Get Bus Characteristics Register）**。头文件为 `zephyr/drivers/i3c/ccc.h`。

## 412.2\_字段

```c
uint8_t bcr;
```

字段 [`bcr`](https://docs.zephyrproject.org/latest/doxygen/html/structi3c__ccc__getbcr.html#a09df0a49b57a38b91fe2e51c4de5c334) 保存**总线特征寄存器（Bus Characteristics Register，BCR）**。原页面没有列出具体位定义。
