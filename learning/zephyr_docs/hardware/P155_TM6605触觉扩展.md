# 第155章\_TM6605触觉扩展

原文：[group__tm6605__interface](https://docs.zephyrproject.org/latest/doxygen/html/group__tm6605__interface.html)。读取日期：2026-10-13，`latest`。

## 155.1\_只写I2C驱动与效果编号

Titan Micro Electronics的TM6605通过 **集成电路间总线（Inter-Integrated Circuit，I2C）**控制 **线性谐振执行器（Linear Resonant Actuator，LRA）**。原页说明它提供44个可通过 **标识符（Identifier，ID）**选择的预编程效果，通过效果选择和播放控制两个寄存器控制；**I2C接口只能写入**。

头文件为 `zephyr/drivers/haptics/tm6605.h`。效果枚举 [`tm6605_effect`](https://docs.zephyrproject.org/latest/doxygen/html/group__tm6605__interface.html#ga8684b734f5192c0d22a3eddc4ca97d1e) 包含可写入效果选择寄存器的有效编号。原文列出的时长来自数据手册，只是近似参考值，实际播放时间取决于LRA。

## 155.3\_睡眠命令的特殊语义

选择并启动 `TM6605_EFFECT_SLEEP_COMMAND` 这个“效果”会让TM6605进入睡眠模式。I2C的 **串行时钟线（Serial Clock Line，SCL）**出现下降沿时（也就是下一次I2C事务）会唤醒器件，但芯片**可能丢弃唤醒后的第一条命令**。

## 155.4\_选择效果不立即播放

效果选择函数的声明为：

```c
int tm6605_select_effect(const struct device *dev, enum tm6605_effect effect);
```

`dev` 为TM6605设备实例，`effect` 为上述有效效果ID。该函数只写效果选择寄存器，**不会开始播放**；之后调用 [`haptics_start_output()`](https://docs.zephyrproject.org/latest/doxygen/html/group__haptics__interface.html#ga96e0b0fad35d6535adad7536a9411f44) 才触发效果。

成功返回0；效果ID无效返回无效参数错误码 `-EINVAL`；底层I2C控制器失败时返回其负错误码。公共启动接口见[触觉反馈接口参考](P147_触觉反馈接口参考.md)。
