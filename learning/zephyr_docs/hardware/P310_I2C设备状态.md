## 310.1\_状态扩展

结构 [`i2c_device_state`](https://docs.zephyrproject.org/latest/doxygen/html/structi2c__device__state.html) 保存集成电路间总线（Inter-Integrated Circuit，I²C）专用设备状态，允许添加I²C设备类别所需的状态信息，声明来自 `zephyr/drivers/i2c.h`。

| 字段 | 类型 | 含义 |
| --- | --- | --- |
| <a id="ad02c0d18dd2db2c35ccdc4c0913b0f0b"></a>[`devstate`](https://docs.zephyrproject.org/latest/doxygen/html/structi2c__device__state.html#ad02c0d18dd2db2c35ccdc4c0913b0f0b) | `struct device_state` | 通用设备状态（Common Device State） |
| <a id="a2bc920f08c8c88a420d3f63ac55cad8c"></a>[`stats`](https://docs.zephyrproject.org/latest/doxygen/html/structi2c__device__state.html#a2bc920f08c8c88a420d3f63ac55cad8c) | `struct stats_i2c` | I²C统计信息（Statistics） |
