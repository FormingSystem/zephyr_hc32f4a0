# 第235章\_步进硬件驱动后端

原文：[group__stepper__hw__driver__backend](https://docs.zephyrproject.org/latest/doxygen/html/group__stepper__hw__driver__backend.html)。读取日期：2026-10-13，`latest`。

## 235.1\_用途

本组提供实现步进硬件驱动器（Stepper Hardware Driver）所需的 **应用程序编程接口（Application Programming Interface，API）**类型定义、回调签名（Callback Signature）及辅助内容，声明来自官方头文件 `zephyr/drivers/stepper/stepper.h`。微步（Micro-step）表示整步的细分单位。

驱动通过[对应函数表](P236_步进硬件驱动函数表.md)提供操作，参数及返回语义见[公共接口](P232_步进硬件驱动接口.md)。

## 235.2\_回调类型

以下均为函数指针类型定义（Function Pointer Typedef），各类型关联相应的公共函数。

**类型 [`stepper_enable_t`](https://docs.zephyrproject.org/latest/doxygen/html/group__stepper__hw__driver__backend.html#gab72c41a4685429cdb01365c66a247bb8)：启用步进硬件驱动器。** 参数说明见函数 [`stepper_enable()`](https://docs.zephyrproject.org/latest/doxygen/html/group__stepper__hw__driver.html#ga3395b5f8b401d8175067edfb25c2e0e8)。

```c
typedef int(* stepper_enable_t) (const struct device *dev);
```

**类型 [`stepper_disable_t`](https://docs.zephyrproject.org/latest/doxygen/html/group__stepper__hw__driver__backend.html#ga3bdb240620979bb7c1aec00bdc1e7391)：禁用步进硬件驱动器。** 参数说明见函数 [`stepper_disable()`](https://docs.zephyrproject.org/latest/doxygen/html/group__stepper__hw__driver.html#gab892a6b8d8fb34db0e682dd8f7de4218)。

```c
typedef int(* stepper_disable_t) (const struct device *dev);
```

**类型 [`stepper_set_micro_step_res_t`](https://docs.zephyrproject.org/latest/doxygen/html/group__stepper__hw__driver__backend.html#ga01d81191585ac83ca1cdd2bcff16e7cb)：设置微步分辨率（Micro-step Resolution）。** 参数说明见函数 [`stepper_set_micro_step_res()`](https://docs.zephyrproject.org/latest/doxygen/html/group__stepper__hw__driver.html#ga609ddefa299ba40a997c626e4a36bdef)。

```c
typedef int(* stepper_set_micro_step_res_t) (const struct device *dev, const enum stepper_micro_step_resolution resolution);
```

**类型 [`stepper_get_micro_step_res_t`](https://docs.zephyrproject.org/latest/doxygen/html/group__stepper__hw__driver__backend.html#gae2e5fe2ffa722cafe649bc6fbd945296)：获取微步分辨率。** 参数说明见函数 [`stepper_get_micro_step_res()`](https://docs.zephyrproject.org/latest/doxygen/html/group__stepper__hw__driver.html#gaa5e17e04a470832a305cef048694ec0a)。

```c
typedef int(* stepper_get_micro_step_res_t) (const struct device *dev, enum stepper_micro_step_resolution *resolution);
```

**类型 [`stepper_set_event_cb_t`](https://docs.zephyrproject.org/latest/doxygen/html/group__stepper__hw__driver__backend.html#gac903b636e01a33fa52882f0d70e745b3)：设置步进驱动事件回调（Event Callback）。** 参数说明见函数 [`stepper_set_event_cb()`](https://docs.zephyrproject.org/latest/doxygen/html/group__stepper__hw__driver.html#gad9fff2d103daad42fe49c7bbd5233b1b)。

```c
typedef int(* stepper_set_event_cb_t) (const struct device *dev, stepper_event_cb_t callback, void *user_data);
```
