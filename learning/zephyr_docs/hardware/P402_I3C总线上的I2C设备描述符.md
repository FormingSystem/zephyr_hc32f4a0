# 第402章\_I3C总线上的I2C设备描述符

原文：[structi3c__i2c__device__desc](https://docs.zephyrproject.org/latest/doxygen/html/structi3c__i2c__device__desc.html)。读取日期：2026-10-13，`latest`。

## 402.1\_用途与初始化

`struct i3c_i2c_device_desc` 描述挂在**改进的集成电路间总线（Improved Inter-Integrated Circuit，I3C）**上的**集成电路间总线（Inter-Integrated Circuit，I2C）**设备。头文件为 `zephyr/drivers/i3c.h`。

此结构实例传给 I3C 控制器设备接口。原文以 `i3c_i2c_device_register()` 举例，表示向控制器告知 I2C 设备；以 `i3c_i2c_transfers()` 举例，表示启动控制器与 I2C 设备之间的数据传输。这里保留原页面的举例名称。

实现设备行为的模块，必须在传递对象引用给控制器接口之前，初始化除 [`node`](https://docs.zephyrproject.org/latest/doxygen/html/structi3c__i2c__device__desc.html#acfcf72db311b19e479e9147ce5257245) 之外的字段。

## 402.2\_字段

**传统虚拟寄存器（Legacy Virtual Register，LVR）**由 [`lvr`](https://docs.zephyrproject.org/latest/doxygen/html/structi3c__i2c__device__desc.html#a610c28ac5e56b540415d48dfabe46dad) 字段记录。地址字段保存该 I2C 设备的静态地址（Static Address）。

| 字段 | 类型 | 含义 |
| --- | --- | --- |
| `node` | [`sys_snode_t`](../slist_reference/P001_单向链表公共接口.md#ga69bf43aad81e3ee2d55250c59b857493) | 原页面仅给出此节点字段的声明，不要求调用方初始化它。 |
| [`bus`](https://docs.zephyrproject.org/latest/doxygen/html/structi3c__i2c__device__desc.html#a2c37ea680bc4affe83f9e1bd1a1da5d2) | `const struct device *` | 此 I2C 设备附接的 I3C 总线。 |
| [`addr`](https://docs.zephyrproject.org/latest/doxygen/html/structi3c__i2c__device__desc.html#a6148be0b55e526b31cb493d697075670) | [`uint16_t`](https://docs.zephyrproject.org/latest/doxygen/html/stdint_8h.html#a5debae8b2a1ec20a6694c0c443ee399e) | 此 I2C 设备的静态地址。 |
| `lvr` | [`uint8_t`](https://docs.zephyrproject.org/latest/doxygen/html/stdint_8h.html#a3cb4a16b0e8d6af0af86d4fd6ba5fd9d) | LVR，参见 [`I3C_LVR`](P425_I3C公共接口参考.md) 定义组。 |
