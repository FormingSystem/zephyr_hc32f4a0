# 第491章\_BC1.2仿真后端接口

原文：[group__b12__emulator__backend](P491_BC1点2仿真后端接口.md)。读取日期：2026-10-13，`latest`。

**电池充电规范1.2（Battery Charging 1.2，BC1.2）**的仿真后端接口用于模拟充电对端的连接状态。接口定义于 `zephyr/drivers/usb/emul_bc12.h`，以下均为静态内联函数（Static Inline Function）。

## 491.1\_设置充电对端类型

[`bc12_emul_set_charging_partner()`](P491_BC1点2仿真后端接口.md) 设置连接到 BC1.2 设备的**充电对端（Charging Partner）**类型。对应仿真器会更新厂商专用寄存器，模拟指定对端类型的连接；如果支持，还会产生中断供真实驱动处理。

```c
static inline int bc12_emul_set_charging_partner(const struct emul *target,
                                                  enum bc12_type partner_type);
```

`target` 指向 BC1.2 仿真器实例的结构；`partner_type` 为要模拟的对端类型。将其设为 `BC12_TYPE_NONE` 枚举值可断开充电对端。

成功返回 `0`；不支持该对端类型时返回无效参数错误 `-EINVAL`。

## 491.2\_设置便携设备连接状态

[`bc12_emul_set_pd_partner()`](P491_BC1点2仿真后端接口.md) 设置**便携设备对端（Portable Device Partner，PD Partner）**的状态。仿真器更新厂商专用寄存器，模拟该对端的连接或断开；如果支持，还会产生中断供真实驱动处理。

```c
static inline int bc12_emul_set_pd_partner(const struct emul *target,
                                           bool connected);
```

`target` 指向 BC1.2 仿真器实例。`connected` 为 `true` 时模拟便携设备对端连接，为 `false` 时模拟断开事件。成功返回 `0`；不支持 PD 对端连接或断开时返回 `-EINVAL`。

> 译注：此处 PD 来自原文的 Portable Device，意为“便携设备”；不要将这个参数直接理解成另一套充电协议的电力传输（Power Delivery）。
