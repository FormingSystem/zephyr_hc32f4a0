# 第632章\_保留内存驱动操作表

原文：[structretained__mem__driver__api](https://docs.zephyrproject.org/latest/doxygen/html/structretained__mem__driver__api.html)。读取日期：2026-10-13，`latest`。

[`retained_mem_driver_api`](https://docs.zephyrproject.org/latest/doxygen/html/structretained__mem__driver__api.html) 是保留内存（Retained Memory）驱动必须定义的应用程序编程接口（Application Programming Interface，API）结构。它包含指向驱动实现的操作的函数指针，以及驱动专用的其他常量数据。

```c
#include <zephyr/drivers/retained_mem.h>
```

## 632.1\_保留范围与驱动要求

本接口允许设备在保留内存区域存储数据。**只要设备持续供电，数据就会保留；设备掉电会导致数据丢失。某些设备的低功耗模式也可能清除数据。**这类区域可以是未初始化的随机存取存储器（Random Access Memory，RAM）区域，也可以是专用寄存器；切换到另一个应用执行，或在不断电情况下重新启动设备，不会将其复位。

驱动必须支持按字节读取和写入，写入前不需要擦除数据。

原页用 `REQ` 表示必需（Required）成员，用 `OPT` 表示可选（Optional）成员。**本结构的全部四个函数都必须实现，没有可选函数。**

## 632.2\_成员类型与用途

```c
struct retained_mem_driver_api {
    retained_mem_size_api size;
    retained_mem_read_api read;
    retained_mem_write_api write;
    retained_mem_clear_api clear;
};
```
