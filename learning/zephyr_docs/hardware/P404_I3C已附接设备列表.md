# 第404章\_I3C已附接设备列表

原文：[structi3c__dev__attached__list](https://docs.zephyrproject.org/latest/doxygen/html/structi3c__dev__attached__list.html)。读取日期：2026-10-13，`latest`。

## 404.1\_已附接设备

`struct i3c_dev_attached_list` 为控制器描述已附接的设备，包含**改进的集成电路间总线（Improved Inter-Integrated Circuit，I3C）**与**集成电路间总线（Inter-Integrated Circuit，I2C）**设备的单向链表（Singly Linked List）。它用于辅助控制器驱动进行设备管理。头文件为 `zephyr/drivers/i3c.h`。

## 404.2\_地址槽

字段 [`addr_slots`](https://docs.zephyrproject.org/latest/doxygen/html/structi3c__dev__attached__list.html#ab5aba9e4e47d3acedc88754946e21474) 的类型为 `struct i3c_addr_slots`，保存**地址槽（Address Slots）**状态，用于：

- 辅助动态地址分配（Dynamic Address Assignment）。
- 快速判断某个目标地址属于 I3C 还是 I2C 设备。

具体状态与操作见[地址槽管理](P383_I3C地址槽管理.md)。

## 404.3\_设备链表

嵌套结构 [`devices`](https://docs.zephyrproject.org/latest/doxygen/html/structi3c__dev__attached__list.html#adb06812783825a1d6b825c0d4b04e130) 包含两个链表：

| 字段 | 类型 | 含义 |
| --- | --- | --- |
| `devices.i3c` | [`sys_slist_t`](../slist_reference/P001_单向链表公共接口.md#ga44658c336b634c03938a251cdc8134f8) | 已附接 I3C 设备的链表。 |
| `devices.i2c` | [`sys_slist_t`](../slist_reference/P001_单向链表公共接口.md#ga44658c336b634c03938a251cdc8134f8) | 已附接 I2C 设备的链表。 |
