# 第400章\_I3C设备匹配标识

原文：[structi3c__device__id](https://docs.zephyrproject.org/latest/doxygen/html/structi3c__device__id.html)。读取日期：2026-10-13，`latest`。

## 400.1\_设备匹配

`struct i3c_device_id` 用于匹配**改进的集成电路间总线（Improved Inter-Integrated Circuit，I3C）**设备。头文件为 `zephyr/drivers/i3c.h`。

## 400.2\_预置标识字段

```c
uint64_t pid : 48;
```

[`pid`](https://docs.zephyrproject.org/latest/doxygen/html/structi3c__device__id.html#a78a8fb4cda85690d866a8e03b982666f) 保存设备的**预置标识（Provisioned ID，PID）**。原字段表将其声明为底层类型 [`uint64_t`](https://docs.zephyrproject.org/latest/doxygen/html/stdint_8h.html#a2095b9bffea4b2656950c6c0419edbf1)、宽度 48 位的位域；字段详情未重复显示位宽，这里保留字段表中的完整声明。
