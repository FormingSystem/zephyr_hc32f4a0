# 第435章\_I2C总线示例

原文：[Inter-Integrated Circuit (I2C) Bus](https://docs.zephyrproject.org/latest/samples/drivers/i2c/README.html)。读取日期：2026-10-13，`latest`。

## 435.1\_示例目录

这些示例演示如何使用**集成电路互连（Inter-Integrated Circuit，I2C）**驱动的应用程序接口（Application Programming Interface，API）。接口概述见[I2C 驱动文档](https://docs.zephyrproject.org/latest/hardware/peripherals/i2c.html#i2c-api)。

| 示例 | 用途 |
| --- | --- |
| [I2C 自定义目标](P436_I2C自定义目标示例.md) | 在 I2C 接口上建立自定义目标（Custom Target） |
| [I2C RTIO 回环](P438_I2C实时IO回环示例.md) | 使用实时输入输出（Real-Time Input/Output，RTIO），在 I2C 控制器与自定义目标之间传输数据 |
| [I2C 目标 EEPROM](P437_I2C目标EEPROM示例.md) | 在 I2C 接口上建立目标设备；该示例使用电可擦可编程只读存储器（Electrically Erasable Programmable Read-Only Memory，EEPROM）目标设备接口 |
