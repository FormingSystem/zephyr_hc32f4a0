# 第195章\_LP5569九通道LED示例

原文：[LP5569 9-channel LED controller](https://docs.zephyrproject.org/latest/samples/drivers/led/lp5569/README.html)。读取日期：2026-10-13，`latest`。

## 195.1\_概述（Overview）

本示例控制连接到 LP5569 驱动器上的 9 个 **发光二极管（Light-Emitting Diode，LED）**。程序以一秒间隔依次点亮所有 LED，然后让全部 LED 逐渐变暗直到熄灭；接着一次点亮全部 LED，等待一秒，再全部关闭。该图案无限重复。

## 195.2\_构建与运行（Building and Running）

为 [nRF52840 DK](https://docs.zephyrproject.org/latest/boards/nordic/nrf52840dk/doc/index.html#nrf52840dk) 构建应用，将 LP5569 控制器接到 **内部集成电路总线（Inter-Integrated Circuit，I2C）**的 I2C0 控制器，总线地址为 `0x32`。

译注：在已配置 Zephyr 开发环境的终端中，从 Zephyr 源码根目录执行以下官方命令；示例源码由官方仓库提供，west 生成构建产物。

```bash
west build -b nrf52840dk/nrf52840 samples/drivers/led/lp5569
```

烧录方法见 [nRF52840 DK开发板文档](https://docs.zephyrproject.org/latest/boards/nordic/nrf52840dk/doc/index.html#nrf52840dk)中的烧录（Flashing）小节。
