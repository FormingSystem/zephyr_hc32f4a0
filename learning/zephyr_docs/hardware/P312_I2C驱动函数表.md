# 第312章\_I2C驱动函数表

原文：[structi2c__driver__api](https://docs.zephyrproject.org/latest/doxygen/html/structi2c__driver__api.html)。读取日期：2026-10-13，`latest`。

## 312.1\_结构约定

结构 [`i2c_driver_api`](https://docs.zephyrproject.org/latest/doxygen/html/structi2c__driver__api.html) 是每个集成电路间总线（Inter-Integrated Circuit，I²C）驱动需定义的应用程序接口（Application Programming Interface，API）结构，声明来自 `zephyr/drivers/i2c.h`，包含所实现操作的函数指针及驱动专用常量数据。

必需（Required，REQ）成员必须设置，可选（Optional，OPT）成员可以不实现。各回调类型见[I2C驱动后端](P311_I2C驱动后端.md)。
