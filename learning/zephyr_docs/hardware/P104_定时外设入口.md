## 104.1\_定时相关外设目录

官方 **定时（Timing）**目录涵盖定时器、时钟、看门狗及计时基础功能，原文依次列出五个主题。

| 文档 | 中英文名称 |
| --- | --- |
| [时钟控制](P007_时钟控制.md) | **时钟控制（Clock Control）**。 |
| [时钟监视器](P102_时钟监视器.md) | **时钟监视器（Clock Monitor）**。 |
| [计数器](P017_计数器.md) | **计数器（Counter）**。 |
| [实时时钟](P018_实时时钟.md) | **实时时钟（Real-Time Clock，RTC）**。 |
| [看门狗](P016_看门狗.md) | **看门狗（Watchdog）**。 |

各类外设的控制目标不同，具体接口与配置在对应章节；原入口没有额外代码或媒体。
