# 第180章\_字符帧缓冲示例

原文：[Character frame buffer](https://docs.zephyrproject.org/latest/samples/subsys/display/cfb/README.html)。读取日期：2026-10-13，`latest`。

## 180.1\_概述（Overview）

本示例使用 **字符帧缓冲（Character Frame Buffer，CFB）**子系统框架显示字符串。

## 180.2\_要求（Requirements）

需要受支持的开发板，以及支持 CFB 的显示器，例如 [reel board](https://docs.zephyrproject.org/latest/boards/phytec/reel_board/doc/index.html#reel_board)。

## 180.3\_构建与运行（Building and Running）

使用下列命令构建应用。译注：在已配置 Zephyr 开发环境的终端中，从 Zephyr 源码根目录执行；示例源码由官方仓库提供，west 生成构建产物。

```bash
west build -b reel_board samples/subsys/display/cfb
```

烧录方法见 [reel board开发板说明](https://docs.zephyrproject.org/latest/boards/phytec/reel_board/doc/index.html#reel_board)。
