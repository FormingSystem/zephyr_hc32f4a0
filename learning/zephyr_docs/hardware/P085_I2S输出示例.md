# 第85章\_I2S输出示例

原文：[I2S output](https://docs.zephyrproject.org/latest/samples/drivers/i2s/output/README.html)。读取日期：2026-10-13，`latest`。

## 85.1\_输出一段正弦音频数据

本示例使用 **芯片间声音总线（Inter-IC Sound，I2S）**驱动发送音频数据流。示例当前不使用 **音频编解码器（Audio Codec）**，可用 **信号分析仪（Signal Analyzer）**核对I2S输出。

它发送一小段由正弦波组成的音频数据，随后 **排空（Drain）**I2S **发送（Transmit，TX）**队列，音频输出停止。有限长度发送结束是预期行为，不应据此直接判断为输出中断故障。

## 85.2\_目标设备要求

通过名为 `i2s_tx` 的设备树 **别名（Alias）**指定I2S设备。注意这里原文要求的是别名，与前一回声示例所用节点标签不同。源码使用 `DT_ALIAS(i2s_tx)`，其设备树属性写作 `i2s-tx`；宏参数中的下划线形式不能原样当作设备树别名属性名。

原文报告在MIMXRT1060-EVK上测试，要求段括号写作 `mimxrt1060_evkb`；构建命令实际使用带修订号的 `mimxrt1060_evk@B`。这里保留这一差异，实际板目标应核对所用版本的[板说明](https://docs.zephyrproject.org/latest/boards/nxp/mimxrt1060_evk/doc/index.html#mimxrt1060_evk)。

## 85.3\_构建与运行

官方源码位于 `samples/drivers/i2s/output`。准备Zephyr环境、目标工具链和烧录工具后，在Ubuntu Bash或已准备好的UCRT64 Bash中，从实验Zephyr源码根目录执行：

```shell
west build -b mimxrt1060_evk@B samples/drivers/i2s/output
west flash
```

构建成功后再烧录。找不到设备时，应先检查 `i2s_tx` 别名及驱动；输出验证使用实际I2S信号，不应期待本示例凭空提供模拟音频输出。相关 **应用程序编程接口（Application Programming Interface，API）**见[I2S参考](https://docs.zephyrproject.org/latest/doxygen/html/group__i2s__interface.html)。本次未构建、烧录或连接分析仪。
