# 回调格式化输出参考大纲

回调格式化输出（Callback-based Formatted Output）把普通字符和格式参数逐字符交给输出函数，不必预先保存整个文本。延迟打包（Deferred Packaging）则先保存格式与参数状态，在另一个上下文中生成文本；字符串是否复制、包能否移动及何时仍依赖外部存储，是使用这组接口的关键。

先读[格式化输出指南](../observability/P008_格式化输出.md)，再查下列公共接口、包结构、创建／转换标志和C/C++源码。

本册保留原始声明、参数、宏展开、代码及法律注释。源码跟踪译注说明字符串生命周期（Lifetime）、对齐（Alignment）、应用二进制接口（ABI）和错误传播的版本边界；完全自包含并不保证跨架构通用。全部本地定位采用相对路径，完整范围见[全站进度](../PROGRESS.md)。
