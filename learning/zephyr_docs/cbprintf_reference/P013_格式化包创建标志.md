## 13.1\_宏定义（Macros）

```c
#define CBPRINTF_PACKAGE_CONST_CHAR_RO BIT(0)
```

相关声明：[CBPRINTF_PACKAGE_CONST_CHAR_RO](#ga6c16ab0b5d98012ffb00942e85d859b3)、[BIT](../util_reference/P001_通用工具公共接口.md#ga3a8ea58898cb58fc96013383d39f482c)。

```c
#define CBPRINTF_PACKAGE_ADD_RW_STR_POS BIT(2)
```

相关声明：[CBPRINTF_PACKAGE_ADD_RW_STR_POS](#gac6ac59dda3a1a8a4572c1012b4adcbaa)、[BIT](../util_reference/P001_通用工具公共接口.md#ga3a8ea58898cb58fc96013383d39f482c)。

指示传入参数带有类型标签。

## 13.2\_详细说明（Detailed Documentation）

<a id="ga406facc18bf99afe16d453253d042dbb"></a>

### `CBPRINTF_PACKAGE_ADD_RO_STR_POS`

```c
#define CBPRINTF_PACKAGE_ADD_RO_STR_POS BIT(1)
```

```c
#include <zephyr/sys/cbprintf.h>
```

追加只读字符串指针在包内的位置。

<a id="gac6ac59dda3a1a8a4572c1012b4adcbaa"></a>

### `CBPRINTF_PACKAGE_ADD_RW_STR_POS`

```c
#define CBPRINTF_PACKAGE_ADD_RW_STR_POS BIT(2)
```

```c
#include <zephyr/sys/cbprintf.h>
```

追加可读写字符串指针在包内的位置。

不使用此标志时，可读写字符串会被追加到包内。

<a id="ga95b0b7f91303781b8bad610f7cac3fa3"></a>

### `CBPRINTF_PACKAGE_ADD_STRING_IDXS`

```c
#define CBPRINTF_PACKAGE_ADD_STRING_IDXS (CBPRINTF_PACKAGE_ADD_RO_STR_POS | CBPRINTF_PACKAGE_CONST_CHAR_RO)
```

```c
#include <zephyr/sys/cbprintf.h>
```

把只读字符串参数的索引追加到包内。

使用此标志后，包内包含只读字符串参数的位置；有了这些信息，即可通过cbprintf_fsc_package转换为完全自包含包。

<a id="gaa8edaf31e7acfb7cb113afa873efa126"></a>

### `CBPRINTF_PACKAGE_ARGS_ARE_TAGGED`

```c
#define CBPRINTF_PACKAGE_ARGS_ARE_TAGGED BIT(6)
```

```c
#include <zephyr/sys/cbprintf.h>
```

指示传入参数带有类型标签。

设置此标志表示传入参数带有类型标签，需要按相应方式处理。

<a id="ga6c16ab0b5d98012ffb00942e85d859b3"></a>

### `CBPRINTF_PACKAGE_CONST_CHAR_RO`

```c
#define CBPRINTF_PACKAGE_CONST_CHAR_RO BIT(0)
```

```c
#include <zephyr/sys/cbprintf.h>
```

假定const char指针指向只读的常量字符串。

此标志仅对CBPRINTF_STATIC_PACKAGE有效。

<a id="ga26b5e05198f6609049c54e439b78cf3c"></a>

### `CBPRINTF_PACKAGE_FIRST_RO_STR_CNT`

```c
#define CBPRINTF_PACKAGE_FIRST_RO_STR_CNT ( n)
```

```c
#include <zephyr/sys/cbprintf.h>
```

展开值（Value）：

```c
(n << Z_CBPRINTF_PACKAGE_FIRST_RO_STR_OFFSET)
```

指示前n个字符串格式参数是指向只读位置的char指针。

这些字符串会跳过运行时算法，即地址分析（Address Analysis）。

**参数（Parameters）**

| 名称／方向 | 说明 |
| --- | --- |
| `n` | 视为只读的字符串参数数量。 |

> 译注——源码核对：职责：cbprintf通过回调逐字符输出；package接口捕获格式字符串和参数，稍后再格式化。打包不等于已经得到文本，打包函数返回包字节数，输出函数返回字符数。两者的缓冲区大小、错误路径与生命周期不能混用。

> 译注——源码核对：版本：本册核对本次官方main头文件与实现，原文和代码保持原样，差异另列译注。仓库内的相对源码链接用于定位，不保证任意本地版本与滚动更新的latest一致。

> 译注——源码核对：静态打包（Static Packaging）按类型推导布局，不代表写包动作在编译时完成。当前宏在运行时把实参值写入调用者提供的内存；C使用_Generic，C++使用重载和模板。字符指针用于%p时应转为void *，避免被识别为字符串候选。

> 译注——源码核对：当前静态宏检测到可读写字符串参数而未设置ADD_RW_STR_POS时，outlen置-EINVAL。其参数存储先检查起始偏移小于容量，再写完整参数；尾部位置数组也在最终总容量检查之前写入。因此不要故意用不足容量的缓冲区试探长度：先以NULL查询，再按相同对齐提供足量空间。-ENOSPC不是当前实现所有写入均受边界保护的证明。

> 译注——源码核对：FIRST_RO_STR_CNT使用3位计数，调用者应保持n在0至7内；宏本身不先屏蔽任意大的n。格式字符串隐含为只读，不计入这里的n。long double、各架构栈对齐与创建标志存储均受配置影响，不能固定假设所有包头只有一个指针宽度。

> 译注——源码核对：带标签参数（Tagged Arguments）要求相应配置和匹配的类型标签／值序列，普通va_list不能直接按带标签列表解释。内部枚举、Z_宏及C++辅助模板用于实现公共接口，不能据源码浏览页的可见性认定它们是稳定的独立应用API。
