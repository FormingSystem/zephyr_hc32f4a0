## 概述（Overview）

<a id="id3"></a>

STM32H7 HDMI开发板[注1](#id2)集成STMEWH747XIH6微控制器（型号依原文保留）及多个外部外设。PCB使用外部SDRAM、eMMC、microSD卡和NOR闪存等扩展存储资源，并提供USB、支持增强型以太网供电（PoE+）的以太网、HDMI、模拟音频及CAN接口。（[STM32H7 HDMI开发板（Board）](https://openhardware.antmicro.com/boards/stm32h7-hdmi-board)）

主要特性包括：


- STM32H747XIH6微控制器（MCU）
- 采用144针SODIMM接口的外部SDRAM
- MicroSD卡槽（Card Slot）
- 4 GB嵌入式多媒体卡存储器（eMMC）
- 2 Gb四线SPI NOR闪存（QSPI NOR Flash）
- 两个USB-A端口
- 支持高清晰度多媒体接口（HDMI）
- 支持显示串行接口（DSI）
- 10/100 Mbit以太网，支持增强型以太网供电（PoE+）
- USB-C调试接口，支持USB电力传输（Power Delivery）
- 支持USB-C OTG
- Pmod扩展接口（PMOD Connector）
- CAN及工业标准GPIO
- 模拟音频接口（Analog Audio Interface）
- 120 × 120 mm，即4.72 × 4.72英寸的PCB

## 硬件（Hardware）

STM32H7 HDMI开发板提供以下硬件：


- STM32H747XI微控制器（MCU）
- ARM Cortex-M7与Cortex-M4双核微控制器
- Memory:

  > - 1 MB随机存取存储器（RAM）
  > - 2 MB闪存（Flash）
  > - 2 Gbit四线SPI NOR外部闪存（QSPI NOR）
  > - 采用144针SODIMM接口的外部SDRAM
  > - 4 GB嵌入式多媒体卡存储器（eMMC）
  > - MicroSD卡槽（Card Slot）
- 通信接口（Communication Interfaces）：

  > - 一路灵活数据速率CAN（FDCAN）
  > - 一路I2C快速模式（Fast Mode），支持SMBus/PMBus
  > - 一路经USB-C调试端口接出的UART
  > - 一路USB-C OTG全速接口
  > - 两个USB-A接口
  > - 10/100 Mbit/s以太网媒体访问控制器（MAC），支持PoE+
  > - HDMI／DSI显示接口
  > - 四路工业GPIO，输出控制电压最高24 V，输入读取电压最高58 V
  > - Pmod连接器（PMOD Connector）：
  >
  >   > - 一路SPI（Type 2）或一路USART（Type 3），通过板载拨码开关（DIP Switch）选择
  >   > - 引脚7–10提供四路GPIO
- 其他外设（Other Peripherals）：

  > - 一个通过GPIO连接的RGB LED
  > - 一个用户按键
  > - Chrom-ART图形加速器（DMA2D）、LCD-TFT控制器和JPEG编解码器（Codec）
  > - 真随机数发生器（RNG / True Random Number Generator）
  > - 循环冗余校验计算单元（CRC Calculation Unit）
  > - 实时时钟（Real-Time Clock）

### 连接与输入输出（Connections and IOs）

Antmicro STM32H7 HDMI开发板为外设提供以下默认引脚映射：


- `I2C2 SCL/SDA : PH4/PH5`

<a id="serial-port"></a>

### 串口（Serial Port）

Zephyr控制台输出分配给UART5，它连接到USB PD端口上的USB转UART转换器。

<a id="external-displays"></a>

### 外部显示器（External Displays）

STM32H7 HDMI开发板可连接HDMI显示器，也可通过DSI FMC接口连接外部DSI显示器。两种显示器共用相同的MIPI DSI线路，因此不能同时使用HDMI和DSI FMC。

<a id="resources-sharing"></a>

### 资源共享（Resources Sharing）

STM32H747片上系统的双核特性要求在两个内核之间共享硬件资源，主要通过以下三种方式实现：


- 编译（Compilation）：只有M7内核可访问时钟配置；M4内核只能启用或停用总线时钟。
- 编译前静态分配（Static Pre-Compilation Assignment）：UART等外设在编译前通过设备树分配，必须确保同一外设不会同时分配给两个内核。
- 运行时保护（Run Time Protection）：两个内核可能在运行时访问中断控制器和GPIO配置，通过硬件信号量（Hardware Semaphore）保护访问，以避免潜在的并发访问问题。

<a id="flashing"></a>

### 烧录（Flashing）

此开发板具有USB-JTAG接口，可使用OpenOCD。

通过USB PD端口将开发板连接到主机，然后构建并烧录应用。

<a id="flashing-an-application-to-stm32h747i-m7-core"></a>

#### 将应用烧录到STM32H747I M7内核（Core）

以下以[Blinky](../getting_started/P004_LED闪烁示例.md#blinky)应用为例。

```text
# From the root of the zephyr repository
west build -b stm32h7_hdmi_board/stm32h747xx/m7 samples/basic/blinky
west flash
```

运行主机串口程序连接开发板：

```text
$ picocom /dev/ttyUSB2 -b 115200
```

同样，也可以为M4目标构建和烧录示例，但需要注意资源共享，例如控制台使用的UART端口。

以下以M4内核上的[Hello World](../getting_started/P005_HelloWorld示例.md#hello_world)应用为例。

```text
# From the root of the zephyr repository
west build -b stm32h7_hdmi_board/stm32h747xx/m4 samples/hello_world
west flash
```

<a id="debugging"></a>

### 调试（Debugging）

可以按通常方式调试Cortex-M7上的应用。以下以[Hello World](../getting_started/P005_HelloWorld示例.md#hello_world)为例。

```text
# From the root of the zephyr repository
west build -b stm32h7_hdmi_board/stm32h747xx/m7 samples/hello_world
west debug
```

目前不能使用west调试Cortex-M4侧的Zephyr应用。
