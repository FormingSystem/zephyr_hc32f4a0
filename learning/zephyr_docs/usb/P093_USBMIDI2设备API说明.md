## 93.1\_MIDI 2.0 类设备 API（MIDI 2.0 Class Device API）

USB MIDI 2.0 设备专用 API 定义于 [`include/zephyr/usb/class/usbd_midi2.h`](https://github.com/zephyrproject-rtos/zephyr/blob/main/include/zephyr/usb/class/usbd_midi2.h)。MIDI 是乐器数字接口（Musical Instrument Digital Interface）的缩写。
