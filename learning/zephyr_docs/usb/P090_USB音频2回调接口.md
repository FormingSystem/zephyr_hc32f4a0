## 90.3\_详细说明（Detailed Documentation）

<a id="aa934f5ecee8f8e67e2165735a6dd2bca"></a>

### 90.3.1\_`buf\_release\_cb`

```c
void(* uac2_ops::buf_release_cb) (const struct device *dev, uint8_t terminal, void *buf, void *user_data)
```

发送缓冲区释放（Transmit Buffer Release）回调。

当类驱动不再需要通过 usbd_uac2_send 提供的缓冲区时，此函数负责释放该缓冲区。调用 usbd_uac2_send 时必须注册此回调。

**参数（Parameters）**

| 名称／方向 | 说明 |
| --- | --- |
| `dev` | USB 音频 2 设备。 |
| `terminal` | 与音频流（AudioStreaming）接口关联的输出终端 ID。 |
| `buf` | 之前通过 usbd_uac2_send 提供的缓冲区。 |
| `user_data` | 不透明用户数据指针。 |

> 译注（源码核对）：释放回调表示类驱动已不再使用数据缓冲区，不等于主机已播放该音频；应用负责按缓冲区来源释放或归还内存池。

<a id="abb973db8018d09ba34f508c4e8aff573"></a>

### 90.3.2\_`data\_recv\_cb`

```c
void(* uac2_ops::data_recv_cb) (const struct device *dev, uint8_t terminal, void *buf, uint16_t size, void *user_data)
```

收到数据。

USB 已向缓冲区写入数据，或者不再需要该缓冲区时，此函数负责释放此前通过 get_recv_buf 取得的缓冲区。从 USB 主机接收 USB 音频的设备必须注册此回调。

**参数（Parameters）**

| 名称／方向 | 说明 |
| --- | --- |
| `dev` | USB 音频 2 设备。 |
| `terminal` | 与音频流（AudioStreaming）接口关联的输入终端 ID。 |
| `buf` | 之前通过 get_recv_buf 取得的缓冲区。 |
| `size` | 写入缓冲区的字节数。 |
| `user_data` | 不透明用户数据指针。 |

> 译注（源码核对）：当前接收包装分配或入队失败时，会用size=0把已取得的缓冲区交还应用。应用须按实际size处理，不能假定每次回调都包含一整帧音频。

<a id="ad427ec3534c8c2b1fe097a7eb83a2e87"></a>

### 90.3.3\_`feedback\_cb`

```c
uint32_t(* uac2_ops::feedback_cb) (const struct device *dev, uint8_t terminal, void *user_data)
```

获取显式反馈（Explicit Feedback）值。

显式反馈值的格式取决于终端连接速度。支持高速（High-Speed）的设备，当且仅当 terminal_update_cb 调用的 microframes 参数为 true 时，必须使用 Q16.16 格式。仅支持全速（Full-Speed）的设备，或以全速运行的高速设备（microframes 为 false），使用 Q10.14 格式，存储在最低 24 位中，即忽略最高 8 位。如果 USB 音频流接口关联的输入终端由异步时钟（Asynchronous Clock）驱动，即时钟源没有 sof-synchronized; 属性，且该接口没有 implicit-feedback; 属性，则必须注册此回调。

**参数（Parameters）**

| 名称／方向 | 说明 |
| --- | --- |
| `dev` | USB 音频 2 设备。 |
| `terminal` | 要返回其反馈值的输入终端 ID。 |
| `user_data` | 不透明用户数据指针。 |

> 译注（源码核对）：全速Windows兼容选项不会改变应用回调的格式约定：当前驱动先取得Q10.14值，再左移2位转换为Q16.16并发送4字节；应用不应重复转换。

<a id="ab41274aadc39d39cbcbfe0047a56f24b"></a>

### 90.3.4\_`get\_recv\_buf`

```c
void *(* uac2_ops::get_recv_buf) (const struct device *dev, uint8_t terminal, uint16_t size, void *user_data)
```

获取接收缓冲区地址。

USB 协议栈调用此函数，取得音频流接口的接收缓冲区地址。在 data_recv_cb 回调调用之前，缓冲区由 USB 协议栈拥有。缓冲区必须满足 UDC 驱动的对齐及其他使用要求。从 USB 主机接收 USB 音频的设备必须注册此回调。

**参数（Parameters）**

| 名称／方向 | 说明 |
| --- | --- |
| `dev` | USB 音频 2 设备。 |
| `terminal` | 与音频流（AudioStreaming）接口关联的输入终端 ID。 |
| `size` | USB 协议栈将写入缓冲区的最大字节数。 |
| `user_data` | 不透明用户数据指针。 |

<a id="ad8a5599b97edbecc653da41a970f378d"></a>

### 90.3.5\_`get\_sample\_rate`

```c
uint32_t(* uac2_ops::get_sample_rate) (const struct device *dev, uint8_t clock_id, void *user_data)
```

获取当前采样率（Active Sample Rate）。

如果时钟源实体（Clock Source Entity）支持多个采样率，当主机查询当前采样率时，USB 协议栈调用此函数。如果所有时钟源实体都只支持一个采样率，则永远不会调用此函数，此回调应为 NULL。

**参数（Parameters）**

| 名称／方向 | 说明 |
| --- | --- |
| `dev` | USB 音频 2 设备。 |
| `clock_id` | 要返回其采样率的时钟源 ID。 |
| `user_data` | 不透明用户数据指针。 |

**返回（Returns）**：当前采样率，单位为 Hz。

<a id="ab658d1468ba300f882dfb61e3e73ed1b"></a>

### 90.3.6\_`set\_sample\_rate`

```c
int(* uac2_ops::set_sample_rate) (const struct device *dev, uint8_t clock_id, uint32_t rate, void *user_data)
```

设置当前采样率。

主机设置当前采样率时，USB 协议栈调用此函数。如果所有时钟源实体都只有一个采样率，此回调可以为 NULL。USB 协议栈会将采样率调整为给定时钟源实体最接近的有效采样率。

**参数（Parameters）**

| 名称／方向 | 说明 |
| --- | --- |
| `dev` | USB 音频 2 设备。 |
| `clock_id` | 要设置其采样率的时钟源 ID。 |
| `rate` | 采样率，单位为 Hz。 |
| `user_data` | 不透明用户数据指针。 |

**返回（Returns）**：成功返回 0，出错返回负值。

### 90.3.8\_`terminal\_update\_cb`

```c
void(* uac2_ops::terminal_update_cb) (const struct device *dev, uint8_t terminal, bool enabled, bool microframes, void *user_data)
```

终端更新（Terminal Update）回调。

通知应用，主机已启用或停用某个终端。必须注册此回调。

**参数（Parameters）**

| 名称／方向 | 说明 |
| --- | --- |
| `dev` | USB 音频 2 设备。 |
| `terminal` | 与音频流（AudioStreaming）接口关联的终端 ID。 |
| `enabled` | 主机启用终端时为 true，否则为 false。 |
| `microframes` | USB 连接速度采用微帧（Microframes）时为 true。 |
| `user_data` | 不透明用户数据指针。 |
