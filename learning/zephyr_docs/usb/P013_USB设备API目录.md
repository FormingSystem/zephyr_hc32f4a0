# 第13章\_USB设备API目录

原文：[官方页面](https://docs.zephyrproject.org/latest/services/connectivity/usb/device_next/api/index.html)。读取日期：2026-10-14；保存的 latest 页面及 HTML 摘要见[来源记录](../SOURCES.md)。

## 13.1\_新版USB设备支持API

官方接口参考分为以下部分：

- [USB 设备控制器（USB Device Controller，UDC）驱动 API](P029_USB设备控制器API说明.md)。
- [USB 设备栈 API](P014_USB设备栈API说明.md)。
- [人机接口设备（Human Interface Device，HID）API](P041_新版HID设备API说明.md)。
- [音频类 2（Audio Class 2）设备 API](P088_USB音频2设备API说明.md)。
- [USB 大容量存储类（Mass Storage Class，MSC）设备 API](P057_USB大容量存储API说明.md)。
- [MIDI 2.0 类设备 API](P093_USBMIDI2设备API说明.md)，MIDI 为乐器数字接口（Musical Instrument Digital Interface）。
- [USB 设备固件升级（Device Firmware Upgrade，DFU）API](P061_USB设备固件升级API说明.md)。

> 译注：本页是官方分类目录，各类 API 的具体声明在对应页面。先阅读[USB设备支持指南](P002_USB设备支持.md)，理解设备上下文、描述符、配置和类实例之间的关系；已翻译的核心 API 与消息参考从下一章进入，其余尚未翻译的入口仍保留官方链接。
