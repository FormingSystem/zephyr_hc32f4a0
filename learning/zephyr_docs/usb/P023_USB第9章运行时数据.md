## 23.3\_详细说明（Detailed Documentation）

<a id="a8f831eca1974b8411072f8102c444d45"></a>

### `alternate`

```c
uint8_t usbd_ch9_data::alternate[16U]
```

用于跟踪接口替代设置（Alternate Setting）的数组。

> 译注（源码核对）：网页将数组长度展开为 16U，当前头文件使用 USBD_NUMOF_INTERFACES_MAX。它为各接口记录替代设置值，不是端点号数组；不能从该数组大小推定控制器具有16个端点。

<a id="a1f759fb0d758e50c4589b6b6b1fd2a24"></a>

### `ep_halt`

```c
uint32_t usbd_ch9_data::ep_halt
```

处于停止（Halted）状态的端点位图（Bitmap）。

<a id="a6ab6f611fd1eff8d6fde0617c587fefb"></a>

### `post_status`

```c
bool usbd_ch9_data::post_status
```

需要在状态阶段（Status Stage）完成后执行工作，例如：

设置新的设备地址。

> 译注（源码核对）：当前第9章请求处理实现将设置新设备地址等动作延后到状态阶段结束后处理；这个字段记录延后工作的需要，不表示控制请求的数据阶段长度。
