## 5.3\_原页符号提示（Symbol Descriptions）

### `sys_trace_isr_exit_to_scheduler`

```c
void sys_trace_isr_exit_to_scheduler(void)
```

跟踪中断服务程序（ISR）退出并进入调度器（Scheduler）。

符号定位：[sys_trace_isr_exit_to_scheduler](P004_默认底层钩子头文件参考.md#a303fe60fd4de8ddcc02c6920656e326d)。

### `sys_trace_isr_enter`

```c
void sys_trace_isr_enter(void)
```

跟踪中断服务程序（Interrupt Service Routine，ISR）的入口。

符号定位：[sys_trace_isr_enter](P004_默认底层钩子头文件参考.md#a37f43a02961a847af3b7de6c474a8da4)。

### `sys_trace_isr_exit`

```c
void sys_trace_isr_exit(void)
```

跟踪中断服务程序（Interrupt Service Routine，ISR）的出口。

符号定位：[sys_trace_isr_exit](P004_默认底层钩子头文件参考.md#a7113e2760b1a7ffb1bfa108ad9bfb4be)。

### `sys_trace_idle_exit`

```c
void sys_trace_idle_exit(void)
```

跟踪CPU离开空闲状态（Idle State）。

符号定位：[sys_trace_idle_exit](P004_默认底层钩子头文件参考.md#ac7b7973acf38a440e88242aca52e424c)。

### `sys_trace_idle`

```c
void sys_trace_idle(void)
```

跟踪CPU进入空闲状态（Idle State）。

符号定位：[sys_trace_idle](P004_默认底层钩子头文件参考.md#ac9b542f78ed796b4b572de19d295c824)。

## 5.4\_源码跟踪译注

> 译注——底层回退：本页只有ISR／idle函数声明，函数实现位于tracing_none.c并带__weak；启用CPU负载空闲钩子后，部分默认实现参与空闲时间记账。

> 译注——预处理保护：命名事件及初始化事件的#ifndef仅检测同名宏，不能识别普通C函数定义；自定义格式应遵循完整接口说明中的两层钩子及包含关系。

头文件相对定位：[include/zephyr/tracing/tracing_default_hooks.h](../../../include/zephyr/tracing/tracing_default_hooks.h)，关联实现／接口：[subsys/tracing/tracing_none.c](../../../subsys/tracing/tracing_none.c)；[官方原始头文件](https://github.com/zephyrproject-rtos/zephyr/blob/main/include/zephyr/tracing/tracing_default_hooks.h)与[官方关联文件](https://github.com/zephyrproject-rtos/zephyr/blob/main/subsys/tracing/tracing_none.c)的摘要见来源记录。去掉注释和展示空白后，本页代码与本次读取的原始头文件一致，不能推广到以后滚动更新的main或任意本地版本。
