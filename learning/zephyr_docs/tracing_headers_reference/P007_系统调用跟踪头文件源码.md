## 7.4\_源码跟踪译注

> 译注——独立选择：系统调用跟踪头文件只列出SystemView、CTF、测试三种具体选择，其余分支为空宏。通用tracing.h中的其他格式配置并不自动扩展这一选择表。

> 译注——生成包装：gen_syscalls.py生成API入口／出口包裹，并按void或非void区别处理可变参数末尾的返回值。观察到系统调用跟踪入口不必然代表发生用户态到内核态切换，具体调用仍可走直接实现路径。

头文件相对定位：[include/zephyr/tracing/tracing_syscall.h](../../../include/zephyr/tracing/tracing_syscall.h)，关联实现／接口：[scripts/build/gen_syscalls.py](../../../scripts/build/gen_syscalls.py)；[官方原始头文件](https://github.com/zephyrproject-rtos/zephyr/blob/main/include/zephyr/tracing/tracing_syscall.h)与[官方关联文件](https://github.com/zephyrproject-rtos/zephyr/blob/main/scripts/build/gen_syscalls.py)的摘要见来源记录。去掉注释和展示空白后，本页代码与本次读取的原始头文件一致，不能推广到以后滚动更新的main或任意本地版本。

本次验证范围为文档与源码对照，未构建固件、配置实板引脚或操作硬件。
