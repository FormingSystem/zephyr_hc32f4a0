# 跟踪头文件源码大纲

本册完整翻译五份跟踪头文件源码浏览页，以及默认底层钩子和系统调用跟踪的两份头文件参考页，共七份官方页面。跟踪钩子（Tracing Hooks）用于记录API入口、阻塞、出口和生命周期事件，具体记录行为由后端实现。

源码页保留全部可见代码、法律声明、原始行号锚点和符号提示，英文注释另列中文对照。参考页完整保留原说明和参数表；源码译注解释两层钩子、格式选择、编译期过滤及系统调用包装，不将本仓库环境混入官方正文。
