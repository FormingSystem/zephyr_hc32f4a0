# 第4章\_默认底层钩子头文件参考

原文：[官方页面](https://docs.zephyrproject.org/latest/doxygen/html/tracing__default__hooks_8h.html)。读取日期：2026-10-15；来源摘要见[来源记录](../SOURCES.md)。

> 译注——阅读位置：从[本册大纲](大纲.md)进入公共、格式、包装宏、默认钩子及系统调用跟踪头文件的源码和接口说明，再通过接口链接进入完整说明。源码跟踪译注与官方原文分开标示。

底层sys_trace_*钩子层的默认实现（Default Implementations）。

查看此文件的源码。

<a id="details"></a>

底层sys_trace_*钩子层的默认实现（Default Implementations）。除了sys_port_trace_*宏钩子（参见tracing_hooks.h），内核还调用少量更底层的sys_trace_*钩子，用于调度器／中断服务程序（Scheduler/ISR）、空闲（Idle）、系统初始化（System Init）和用户命名事件（User-named Events）。不对这些位置进行插桩（Instrumentation）的跟踪格式可以包含本头文件，以获得可用的默认处理：

- sys_trace_isr_*／sys_trace_idle*使用tracing_none.c中以弱符号（Weak Symbols）定义的空操作或CPU负载统计实现；格式实现可以用实际定义覆盖它们。
- sys_trace_named_event和sys_trace_sys_init_*变为空操作宏（No-op Macros），并用#ifndef保护，因此格式自身的定义优先。

树内格式（CTF、SystemView等）自行提供这一层，不包含本头文件；本头文件面向通过CONFIG_TRACING_FORMAT_HEADER或CONFIG_TRACING_CUSTOM选择的树外格式（Out-of-tree Formats）。

> 译注——源码核对：默认底层钩子（Default Low-level Hooks）与tracing_hooks.h中的sys_port_trace_*宏钩子分属两层。本头文件为ISR／idle入口声明外部函数，为命名事件和初始化入口提供受#ifndef保护的空宏；仅包含本头文件不等于启用了事件输出。

> 译注——源码核对：本次tracing_none.c以__weak实现ISR和idle函数；在CONFIG_CPU_LOAD_BACKEND_IDLE_HOOK开启时，ISR入口及idle入口／出口可用于CPU负载统计。因此默认行为不一定完全为空，替换这些定义时需要核对实际用途。

> 译注——源码核对：#ifndef只检查预处理宏是否存在，不能检测另一个同名C函数声明。官方已说明树内格式自行提供该层，不包含本头文件；自定义格式若提供函数式命名事件，应自行处理包含顺序及宏定义关系，避免把函数调用意外替换为空宏。

> 译注——源码核对：完整可见源码见[默认底层钩子头文件源码](P005_默认底层钩子头文件源码.md)，各初始化参数和ISR／idle说明在本页保留。
