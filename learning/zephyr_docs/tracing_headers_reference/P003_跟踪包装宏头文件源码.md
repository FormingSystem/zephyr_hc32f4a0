## 3.2\_可见注释译文（Comments）

1. 版权与许可证：Copyright (c) 2018 Intel Corporation；SPDX-License-Identifier: Apache-2.0。原始法律声明保留。

2. 扩展跟踪系统使用的辅助宏（Helper Macros）。

3. 对象跟踪宏用于根据跟踪配置检查是否需要跟踪特定对象。

4. 无法正面枚举所有被跟踪的API，因为应用可能跟踪系统不知道的任意自定义API。因此，要求通过显式禁用来关闭某个API的跟踪。这与对象跟踪／追踪不同：所有可跟踪对象类型都是已知的，参见下方SYS_PORT_TRACING_TYPE_MASK方案。

5. subsys_tracing_macros跟踪宏文档组结束。

6. CONFIG_TRACING条件分支结束。

7. ZEPHYR_INCLUDE_TRACING_TRACING_MACROS_H_头文件包含保护结束。

## 3.4\_源码跟踪译注

> 译注——配置分支：关闭CONFIG_TRACING时，事件包装宏编译为空do／while，参数中的副作用不执行。文档分支显示启用后的展开；SYS_PORT_TRACING_TYPE_MASK辅助宏本次也只在启用或Doxygen分支定义，不能忽略配置直接使用。

> 译注——过滤方式：对象包装使用明确的对象类型掩码，普通函数包装采用主动禁用标记，未枚举的自定义API仍可参与跟踪。宏只拼接名称并传递参数，不自动捕获返回值、测量耗时或保证入口出口成对。

头文件相对定位：[include/zephyr/tracing/tracing_macros.h](../../../include/zephyr/tracing/tracing_macros.h)，关联实现／接口：[include/zephyr/tracing/tracing_hooks.h](../../../include/zephyr/tracing/tracing_hooks.h)；[官方原始头文件](https://github.com/zephyrproject-rtos/zephyr/blob/main/include/zephyr/tracing/tracing_macros.h)与[官方关联文件](https://github.com/zephyrproject-rtos/zephyr/blob/main/include/zephyr/tracing/tracing_hooks.h)的摘要见来源记录。去掉注释和展示空白后，本页代码与本次读取的原始头文件一致，不能推广到以后滚动更新的main或任意本地版本。
