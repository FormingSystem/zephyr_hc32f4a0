### `mfd_npm2100_hibernate()`

```c
int mfd_npm2100_hibernate ( const struct device * dev, uint32_t time_ms, bool pass_through )
```

```c
#include <zephyr/drivers/mfd/npm2100.h>
```

nPM2100 休眠（hibernate）。

进入低功耗状态（Low-power State），经过指定时间或收到 `shphld` 引脚信号后唤醒。当电池电压足以直接为电源管理芯片（PMIC）供电而无需升压时，可使用直通模式（Pass-through Mode），降低休眠模式（Hibernate Mode）期间 PMIC 的功耗。

**参数（Parameters）**

| 名称／方向 | 说明 |
| --- | --- |
| `dev` | nPM2100 多功能设备（Multi-function Device，MFD）。 |
| `time_ms` | 定时器时间值，单位为毫秒（ms）；设为 0 则禁用定时器。 |
| `pass_through` | 置位以使用直通休眠模式（Pass-through Hibernate Mode）。 |

**返回值（Return Values）**

| 名称／方向 | 说明 |
| --- | --- |
| `-EINVAL` | 时间值过大。 |
| `-EBUSY` | 定时器已被使用。 |

**返回（Returns）**：**返回值（Returns）：**成功返回 0，失败返回负的 `errno` 值，参见 `i2c_write_dt()`。

### `mfd_npm2100_set_timer()`

```c
int mfd_npm2100_set_timer ( const struct device * dev, uint32_t time_ms, enum mfd_npm2100_timer_mode mode )
```

```c
#include <zephyr/drivers/mfd/npm2100.h>
```

写入 nPM2100 定时器寄存器（timer register）。

定时器节拍（Timer Tick）分辨率为 `1/64` 秒。本函数不启动定时器；参见 `mfd_npm2100_start_timer()`。

**参数（Parameters）**

| 名称／方向 | 说明 |
| --- | --- |
| `dev` | nPM2100 多功能设备（Multi-function Device，MFD）。 |
| `time_ms` | 定时器时间值，单位为毫秒（ms）。 |
| `mode` | 定时器模式（Timer Mode）。 |

**返回值（Return Values）**

| 名称／方向 | 说明 |
| --- | --- |
| `-EINVAL` | 时间值过大。 |

**返回（Returns）**：**返回值（Returns）：**成功返回 0，失败返回负的 `errno` 值，参见 `i2c_write_dt()`。
