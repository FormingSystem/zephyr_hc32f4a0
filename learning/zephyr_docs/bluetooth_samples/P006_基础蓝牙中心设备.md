<a id="overview"></a>

## 6.1\_概览（Overview）

本应用演示LE中心设备（Central）的基本功能：扫描其他LE设备，连接第一个信号足够强的设备。


<a id="core-features"></a>

## 6.2\_核心特性（Core features）


<a id="scanning-for-devices"></a>

### 6.2.1\_设备扫描（Scanning for devices）

应用执行被动扫描（Passive Scan），寻找附近LE设备，特别筛选信号强度大于−50dBm的设备。该门限用于滤掉弱信号，使交互对象处于适合通信的RSSI范围；RSSI为接收信号强度指示（Received Signal Strength Indicator）。


<a id="connection-handling"></a>

### 6.2.2\_连接处理（Connection handling）

中心设备扫描外设（Peripheral）；发现信号强度高于−50dBm的外设后，尝试建立LE连接。连接成功后立即发起断开，再重新扫描；没有连接时持续扫描。

示例意在演示中心设备能力，因此连接后立即断开，以便继续扫描其他设备。


<a id="requirements"></a>

## 6.3\_要求（Requirements）

主机上运行BlueZ，或使用支持低功耗蓝牙（Bluetooth Low Energy，LE）的开发板。


<a id="building-and-running"></a>

## 6.4\_构建与运行（Building and Running）

构建和烧录如下，将 `board_name` 替换为目标开发板。

```bash
west build -b board_name samples/bluetooth/central
west flash
```

测试扫描功能时，可以在第二块兼容开发板上烧录[外设示例](P005_基础蓝牙外设.md#ble_peripheral)，或使用能够充当LE外设的现成设备，例如手机或智能手表。

> 译注：成功连接后主动断开是本例的预期流程，不能仅凭断连现象判断示例失败。
