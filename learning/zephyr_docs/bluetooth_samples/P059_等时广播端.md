# 第59章\_等时广播端（Isochronous Broadcaster）

原文：[官方页面](https://docs.zephyrproject.org/latest/samples/bluetooth/iso_broadcast/README.html)。快照读取日期：2026-10-15；来源摘要见[来源记录](../SOURCES.md)。

[在 GitHub 浏览源码（Browse source code on GitHub）](https://github.com/zephyrproject-rtos/zephyr/blob/main//samples/bluetooth/iso_broadcast/README.rst/..)

<a id="overview"></a>

## 59.1 概述（Overview）

> 译注——配对与功能支持：本页等时广播端发送广播等时流（Broadcast Isochronous Stream，BIS），接收示例见[等时同步接收端](P060_等时同步接收端.md)。广播等时组（Broadcast Isochronous Group，BIG）与连接型的 CIG／CIS 是不同链路组织方式；控制器必须实际实现所需广播 ISO 功能，标称 Bluetooth 5.2 或只开启主机配置并不能代替此能力。

本简单应用演示低功耗蓝牙等时广播端功能。

<a id="requirements"></a>

## 59.2 前提条件（Requirements）

- 主机上运行 BlueZ；或者

- 一块支持 Bluetooth Low Energy 5.2 的开发板。

- 支持设置 CONFIG_BT_CTLR_ADV_ISO=y 的蓝牙控制器和开发板。

<a id="building-and-running"></a>

## 59.3 构建与运行（Building and Running）

> 译注——执行环境：以下构建命令在读者自己的 Zephyr 源码根目录，用 UCRT64 Bash 或 Linux Bash 执行。先按[入门指南](../getting_started/大纲.md)准备工具链、west 工作区、板定义及控制器；`samples/...` 是官方已有目录，`<board>` 替换为实际目标。构建成功后按板文档烧录，分别核对对端角色、串口输出和本页预期结果；失败时先回查构建配置、烧录连接或角色与功能支持。本次仅翻译和核对来源，未执行构建、烧录或无线测试。

```text
west build -b <board> samples/bluetooth/iso_broadcast
west flash
```

烧录后，示例自动启动等时广播。

在支持的板上，使用 `-DEXTRA_CONF_FILE=overlay-bt_ll_sw_split.conf` 为 Zephyr 蓝牙控制器启用所需 ISO 功能。示例默认对广播等时流（Broadcast Isochronous Stream，BIS）的子事件采用顺序排列（Sequential packing）；添加 `-DCONFIG_ISO_PACKING_INTERLEAVED=y` 可改用交错排列（Interleaved packing）。

在另一块开发板上运行[等时同步接收端（Synchronized Receiver）](P060_等时同步接收端.md#bluetooth_isochronous_receiver)示例；它会扫描、建立周期广播同步、生成 BIGInfo 报告，并与本示例的广播等时组（Broadcast Isochronous Group，BIG）事件同步。
