# 蓝牙基础与设备接入示例官方译文大纲

本册按 Zephyr 官方示例原页翻译，先了解广播者（Broadcaster）、观察者（Observer）、中心设备（Central）与外设（Peripheral），再阅读服务、逻辑链路控制与适配协议（Logical Link Control and Adaptation Protocol，L2CAP）信道及最大传输单元（Maximum Transmission Unit，MTU）交换。原文的板型是对应示例目标，不表示本仓库目标板已通过验证。

1. [蓝牙信标](P001_蓝牙信标.md)：Eddystone-URL 信标与无线共存配置。
2. [蓝牙广播者](P002_蓝牙广播者.md)：制造商数据广播与发送计数。
3. [蓝牙观察者](P003_蓝牙观察者.md)：扫描报告、扩展广播及调试配置。

5. [基础蓝牙外设](P005_基础蓝牙外设.md)：标准服务与厂商自定义服务。

10. [L2CAP信道发起端](P010_L2CAP信道发起端.md)：CoC 客户端、动态信道与发送日志。
