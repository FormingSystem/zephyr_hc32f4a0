> 译注——命令前提：以下构建命令从读者自己的Zephyr源码根目录执行，终端采用该工作区已配置的Shell；需先具备相应工具链、模块和目标板支持。烧录还需要对应开发板及烧录工具。占位符按实际目标替换，原文指定的型号属于该分支示例。BlueZ或外部控制器的环境说明见[官方工具译文](../bluetooth/P008_蓝牙开发工具.md)。本批未执行构建、烧录或无线测试。

<a id="overview"></a>

## 7.1\_概览（Overview）

本应用类似[基础外设示例](P005_基础蓝牙外设.md#ble_peripheral)，但专门提供心率（Heart Rate，HR）的通用属性配置文件（Generic Attribute Profile，GATT）服务。设备连接后，示例生成模拟心率值，不进行实际心率测量。

<a id="requirements"></a>

## 7.2\_要求（Requirements）

主机上运行BlueZ，或使用支持低功耗蓝牙（Bluetooth Low Energy，LE）的开发板。

<a id="building-and-running"></a>

## 7.3\_构建与运行（Building and Running）

<a id="building-a-minimal-variant"></a>

### 7.3.1\_构建最小变体（Building a minimal variant）

```bash
# From the root of the zephyr repository
west build -b qemu_cortex_m3 samples/bluetooth/peripheral_hr -- -DCONF_FILE=prj_minimal.conf
```

<a id="building-a-minimal-variant-for-bbc-microbit"></a>

### 7.3.2\_为bbc\_microbit构建最小变体（Building a minimal variant for bbc\_microbit）

```bash
# From the root of the zephyr repository
west build -b bbc_microbit samples/bluetooth/peripheral_hr -- -DCONF_FILE=prj_minimal.conf -DEXTRA_CONF_FILE=overlay-bt_ll_sw_split-minimal.conf
```

> 译注：代码中的注释表示“从Zephyr仓库根目录执行”。两个原命令只执行构建，分别使用 `qemu_cortex_m3` 和 `bbc_microbit`；本页没有额外提供烧录或模拟运行命令，不能把构建成功当成设备已经运行。
