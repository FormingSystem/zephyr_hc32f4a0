# 第63章\_等时广播基准测试（Isochronous Broadcaster Benchmark）

原文：[官方页面](https://docs.zephyrproject.org/latest/samples/bluetooth/iso_broadcast_benchmark/README.html)。快照读取日期：2026-10-15；来源摘要见[来源记录](../SOURCES.md)。

[在 GitHub 浏览源码（Browse source code on GitHub）](https://github.com/zephyrproject-rtos/zephyr/blob/main//samples/bluetooth/iso_broadcast_benchmark/README.rst/..)

ISO 广播基准测试示例测量并报告一个等时广播端与一个或多个等时广播接收端之间的丢包和失步情况。

<a id="overview"></a>

## 63.1 概述（Overview）

示例从广播端向接收端发送数据，并测量同步质量；可以使用多个接收端而不影响测试。

同一个应用既可作广播端，也可作接收端，角色可方便地切换。

<a id="requirements"></a>

## 63.2 前提条件（Requirements）

- 主机上运行 BlueZ；或者

- 一块支持 Bluetooth Low Energy 5.2 的开发板。

- 支持设置 CONFIG_BT_CTLR_ADV_ISO=y 的蓝牙控制器和开发板。

- 另一块运行相同示例、采用相反角色且支持设置 CONFIG_BT_CTLR_SYNC_ISO 的开发板。

<a id="building-and-running"></a>

## 63.3 构建与运行（Building and Running）

> 译注——执行环境：以下构建命令在读者自己的 Zephyr 源码根目录，用 UCRT64 Bash 或 Linux Bash 执行。先按[入门指南](../getting_started/大纲.md)准备工具链、west 工作区、板定义及控制器；`samples/...` 是官方已有目录，`<board>` 替换为实际目标。构建成功后按板文档烧录，分别核对对端角色、串口输出和本页预期结果；失败时先回查构建配置、烧录连接或角色与功能支持。本次仅翻译和核对来源，未执行构建、烧录或无线测试。

```text
west build -b <board> samples/bluetooth/iso_broadcast_benchmark
west flash
```

<a id="testing"></a>

### 63.3.1 测试（Testing）

> 译注——统计口径：本次官方 receiver.c 根据每次 ISO 接收回调的 `BT_ISO_FLAGS_VALID` 标记区分有效接收和丢失／无效项，每累计 100 项打印统计，多个 BIS 的事件可共同计入。Overall 是运行累计，Current Sync 是当前同步统计，Latest 1000 是最近最多 1000 项的环形窗口；百分比分母为有效项与丢失项之和，不是对空口全部物理发送次数的独立统计。

两块板均烧录示例后，按以下步骤测试：

1. 使用终端仿真器，例如 PuTTY 或 minicom，连接两块开发板。

2. 复位两块开发板。

3. 在其中一个终端仿真器中输入 r，使相应开发板以接收端角色启动。

4. 在另一个终端仿真器中输入 b，使相应开发板以广播端角色启动。

5. 可选：修改广播设置。

6. 观察接收端与广播端建立同步。

7. 观察各接收端的接收统计。

<a id="sample-output"></a>

### 63.3.2 输出示例（Sample output）

> 译注——交互参数：发送设置中的 interval 是 SDU 间隔，单位微秒；latency 单位毫秒，sdu 单位字节。phy 取物理层（PHY）枚举，packing 的 0／1 表示顺序／交错，framing 的 0／1 表示无成帧／成帧；rtn 是重传次数参数，bis_count 是 BIS 数量。输入范围由当前源码及控制器共同限制，不能将旧日志默认值视为所有硬件都支持的组合。

> 译注——历史日志与单位：以下为官方保留的 Zephyr 2.5 时期输出，并非本次运行结果。`Unknown handle 0x0000` 是原例中的错误行，不应作为成功条件。原例同时出现 `interval 7 ms` 与 `sdu_interval 7500 us`，两字段含义和打印精度不能混用；本次 receiver.c 已将 BIGinfo ISO interval 以微秒打印，诊断应核对实际版本。
