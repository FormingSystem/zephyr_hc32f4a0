<a id="overview"></a>

## 25.1\_概览（Overview）

本应用类似[基础外设示例](P005_基础蓝牙外设.md#ble_peripheral)，但专门提供设备信息服务（Device Information Service，DIS），它属于通用属性配置文件（Generic Attribute Profile，GATT）服务。

<a id="requirements"></a>

## 25.2\_要求（Requirements）

主机运行BlueZ，或者使用支持低功耗蓝牙（Bluetooth Low Energy，LE）的开发板。

<a id="building-and-running"></a>

## 25.3\_构建与运行（Building and Running）

将 `<board>` 替换为目标板，构建并烧录：

```bash
west build -b <board> samples/bluetooth/peripheral_dis
west flash
```

烧录后，用蓝牙扫描应用，例如nRF Connect，连接设备，读取DIS特征（Characteristic），如制造商名称、型号及固件修订版本。
