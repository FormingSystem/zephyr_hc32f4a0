# 第60章\_等时同步接收端（Synchronized Receiver）

原文：[官方页面](https://docs.zephyrproject.org/latest/samples/bluetooth/iso_receive/README.html)。快照读取日期：2026-10-15；来源摘要见[来源记录](../SOURCES.md)。

[在 GitHub 浏览源码（Browse source code on GitHub）](https://github.com/zephyrproject-rtos/zephyr/blob/main//samples/bluetooth/iso_receive/README.rst/..)

<a id="overview"></a>

## 60.1 概述（Overview）

> 译注——配对与同步：接收端先发现[等时广播端](P059_等时广播端.md)，再建立所需同步并接收 BIS。这里的等时同步不是与广播端建立普通的 GATT 业务连接；广播与接收两端控制器都要支持各自的 ISO 角色。

本简单应用演示低功耗蓝牙等时同步接收端功能。

<a id="requirements"></a>

## 60.2 前提条件（Requirements）

- 主机上运行 BlueZ；或者

- 一块支持 Bluetooth Low Energy 5.2 的开发板。

- 支持设置 CONFIG_BT_CTLR_SYNC_ISO=y 的蓝牙控制器和开发板。

<a id="building-and-running"></a>

## 60.3 构建与运行（Building and Running）

> 译注——执行环境：以下构建命令在读者自己的 Zephyr 源码根目录，用 UCRT64 Bash 或 Linux Bash 执行。先按[入门指南](../getting_started/大纲.md)准备工具链、west 工作区、板定义及控制器；`samples/...` 是官方已有目录，`<board>` 替换为实际目标。构建成功后按板文档烧录，分别核对对端角色、串口输出和本页预期结果；失败时先回查构建配置、烧录连接或角色与功能支持。本次仅翻译和核对来源，未执行构建、烧录或无线测试。

```text
west build -b <board> samples/bluetooth/iso_receive
west flash
```

烧录后，示例自动开始扫描等时广播端。

在支持的板上，使用 `-DEXTRA_CONF_FILE=overlay-bt_ll_sw_split.conf` 为 Zephyr 蓝牙控制器启用所需 ISO 功能。

在另一块开发板运行等时广播端示例，它启动周期广播并创建 BIG；本示例将建立周期广播同步，随后同步到广播等时流。 相关链接：[等时广播端（Isochronous Broadcaster）](P059_等时广播端.md#bluetooth_isochronous_broadcaster)。
