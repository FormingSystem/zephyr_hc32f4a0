# 第84章\_高级音频分发配置文件（Advanced Audio Distribution Profile，A2DP）音频源（Source）

原文：[官方页面](https://docs.zephyrproject.org/latest/samples/bluetooth/classic/a2dp_source/README.html)。快照读取日期：2026-10-15；来源摘要见[来源记录](../SOURCES.md)。

[在 GitHub 浏览源码（Browse source code on GitHub）](https://github.com/zephyrproject-rtos/zephyr/blob/main//samples/bluetooth/classic/a2dp_source/README.rst/..)

<a id="overview"></a>

## 84.1 概述（Overview）

本示例通过 Zephyr 的经典蓝牙 API 演示 A2DP 音频源功能。应用作为 A2DP 源设备，发现并连接蓝牙扬声器、耳机等 A2DP 接收设备，并自动向其发送音频数据。

> 译注——示例音频来源：本次 main.c 由正弦查找表生成 PCM 数据，再用 SBC 编码发送；它演示发送链路，并非默认读取音乐文件或麦克风。配套接收端见[A2DP 接收端](P083_A2DP接收端.md)，也可按原文使用兼容的扬声器或耳机。

<a id="requirements"></a>

## 84.2 前提条件（Requirements）

- 在支持蓝牙基本速率／增强数据速率（Basic Rate/Enhanced Data Rate，BR/EDR，即经典蓝牙）的主机上运行，或者

- 一块支持蓝牙 BR/EDR（经典蓝牙）的开发板。

<a id="building-and-running"></a>

## 84.3 构建与运行（Building and Running）

> 译注——执行环境：以下命令从读者自己的 Zephyr 源码根目录，在 UCRT64 Bash 或 Linux Bash 中执行；先准备[工具链和 west 工作区](../getting_started/大纲.md)、相应板定义及支持经典蓝牙的控制器。`samples/...` 为官方已有目录；`<board>` 和 `<sample_name>` 按实际目标及本目录示例替换，多个应用使用各自构建目录或重新配置。确认构建成功后再按板文档烧录，串口依次观察初始化、发现／连接、配置文件建立和数据／音频活动；失败时回查对应阶段。本次未构建、烧录、连接蓝牙或测试音频。

按以下方式构建并烧录示例，将 `<board>` 替换为目标开发板：

```text
west build -b <board> samples/bluetooth/classic/a2dp_source
west flash
```

烧录后，设备发现附近的 A2DP 接收设备，并自动开始发送音频流。

详情参见蓝牙示例（Bluetooth samples）。 相关链接：[蓝牙（Bluetooth）](P088_蓝牙示例总目录.md#bluetooth)。
