<a id="overview"></a>

## 1.1\_概览（Overview）

本应用通过广播指向Zephyr网站的Eddystone URL，演示通用访问配置文件（Generic Access Profile，GAP）的广播者（Broadcaster）角色。


<a id="requirements"></a>

## 1.2\_要求（Requirements）

主机上运行BlueZ，或使用支持低功耗蓝牙（Bluetooth Low Energy，LE）的开发板。


<a id="building-and-running"></a>

## 1.3\_构建与运行（Building and Running）

按下面命令构建和烧录，将 `<board>` 替换为目标开发板。

```bash
west build -b <board> samples/bluetooth/beacon
west flash
```

烧录后，使用兼容Eddystone的扫描应用，例如nRF Connect，观察指向Zephyr Project网站的Eddystone URL信标。


<a id="building-with-bluetooth-le-controller-coexistence-support"></a>

### 1.3.1\_启用LE控制器共存支持（Building with Bluetooth LE controller coexistence support）

如果开发板上的LE控制器需要与其他射频功能共用2.4GHz频段，例如802.15.4／Thread／Zigbee，则使用共存（Coexistence）配置构建：

```bash
west build -b nrf52840dk/nrf52840 samples/bluetooth/beacon -- -DCONF_FILE=prj-coex.conf
west flash
```
