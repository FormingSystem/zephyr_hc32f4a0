# 第62章\_等时外设（ISO / Peripheral）

原文：[官方页面](https://docs.zephyrproject.org/latest/samples/bluetooth/iso_peripheral/README.html)。快照读取日期：2026-10-15；来源摘要见[来源记录](../SOURCES.md)。

[在 GitHub 浏览源码（Browse source code on GitHub）](https://github.com/zephyrproject-rtos/zephyr/blob/main//samples/bluetooth/iso_peripheral/README.rst/..)

<a id="overview"></a>

## 62.1 概述（Overview）

> 译注——配对与日志：本页与[等时中心设备](P061_等时中心设备.md)配对。原文把部分输出排成普通段落或定义列表，译文保留相应英文日志并附中文说明；十六进制载荷、地址与指针保持原样，原有省略号仍表示省略内容，不是可复制的完整数据包。

本示例演示外设如何使用等时信道。它先开始广播，等待中心设备连接并建立等时信道；信道建立后，打印收到的等时数据。建议与[等时中心设备（ISO / Central）](P061_等时中心设备.md#ble_central_iso)示例配合运行。

<a id="requirements"></a>

## 62.2 前提条件（Requirements）

- 主机上运行 BlueZ；或者

- 一块支持 Bluetooth Low Energy 5.2 的开发板。

- 支持设置 CONFIG_BT_CTLR_PERIPHERAL_ISO=y 的蓝牙控制器和开发板。

<a id="building-and-running"></a>

## 62.3 构建与运行（Building and Running）

> 译注——执行环境：以下构建命令在读者自己的 Zephyr 源码根目录，用 UCRT64 Bash 或 Linux Bash 执行。先按[入门指南](../getting_started/大纲.md)准备工具链、west 工作区、板定义及控制器；`samples/...` 是官方已有目录，`<board>` 替换为实际目标。构建成功后按板文档烧录，分别核对对端角色、串口输出和本页预期结果；失败时先回查构建配置、烧录连接或角色与功能支持。本次仅翻译和核对来源，未执行构建、烧录或无线测试。

```text
west build -b <board> samples/bluetooth/iso_peripheral
west flash
```

烧录后，检查以下事项：

1. 启动应用，在终端窗口确认设备正在广播。

  > `Bluetooth initialized Advertising successfully started`。含义：蓝牙初始化完成，广播成功启动。

2. 观察中心设备连接并建立等时信道。

  > `Connected R:E8:DC:8D:B3:47:69 Incoming request from 0x20002260 ISO Channel 0x20000698 connected`。含义：对端已连接、收到所示连接对象的请求，随后所示 ISO 信道已连接。

3. 观察接收到的数据被打印。

  > `Incoming data channel 0x20000698 len 1`：该信道收到 1 字节。
