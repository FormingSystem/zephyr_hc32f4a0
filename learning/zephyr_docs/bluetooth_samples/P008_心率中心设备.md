<a id="overview"></a>

## 8.1\_概览（Overview）

本应用类似[基础中心设备示例](P006_基础蓝牙中心设备.md#ble_central)，但专门寻找心率监视器，连接后报告心率读数。

<a id="requirements"></a>

## 8.2\_要求（Requirements）

主机上运行BlueZ，或使用支持低功耗蓝牙（Bluetooth Low Energy，LE）的开发板。

<a id="building-and-running"></a>

## 8.3\_构建与运行（Building and Running）

构建和烧录如下，将 `<board>` 替换为目标开发板。

```bash
west build -b <board> samples/bluetooth/central_hr
west flash
```

烧录后，应用扫描广播心率服务（Heart Rate Service，HRS）的外设。找到后建立连接，并订阅心率测量（Heart Rate Measurement）通知。可在第二块板上运行[外设示例](P005_基础蓝牙外设.md#ble_peripheral)，或使用其他LE心率监视器作为外设。
