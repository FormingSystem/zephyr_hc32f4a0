<a id="overview"></a>

## 26.1\_概览（Overview）

本应用演示低功耗蓝牙（Bluetooth Low Energy，LE）中心设备（Central）的功能：扫描其他LE设备，并与信号足够强的外设（Peripheral）建立连接，最多可连接62个外设。

> 译注——62的范围：这是本示例的配置目标。所读取的[官方prj.conf](https://raw.githubusercontent.com/zephyrproject-rtos/zephyr/main/samples/bluetooth/central_multilink/prj.conf)设置 `CONFIG_BT_MAX_CONN=62`，[main.c](https://raw.githubusercontent.com/zephyrproject-rtos/zephyr/main/samples/bluetooth/central_multilink/src/main.c)把该值传给 `init_central()`。它不是对任意控制器、内存容量或目标板都能建立62条连接的实测保证。

<a id="requirements"></a>

## 26.2\_要求（Requirements）

主机运行BlueZ，或者使用支持Bluetooth LE的开发板。

<a id="building-and-running"></a>

## 26.3\_构建与运行（Building and Running）

将 `<board>` 替换为目标板，构建并烧录：

```bash
west build -b <board> samples/bluetooth/central_multilink
west flash
```

烧录后，示例扫描并连接近距离的LE外设。在一块或多块额外开发板上运行任意LE外设示例，为中心设备提供可连接的对端。
