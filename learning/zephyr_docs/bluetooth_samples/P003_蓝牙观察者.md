<a id="overview"></a>

## 3.1\_概览（Overview）

本应用演示LE观察者（Observer）角色，周期性扫描附近设备。发现设备后，向控制台打印设备地址、接收信号强度指示（Received Signal Strength Indicator，RSSI）、广播类型与广播数据长度。

若所用LE控制器支持扩展扫描（Extended Scanning），可在项目配置文件中启用 [`CONFIG_BT_EXT_ADV`](https://docs.zephyrproject.org/latest/kconfig.html#CONFIG_BT_EXT_ADV)，具体说明见该示例配置文件。


<a id="requirements"></a>

## 3.2\_要求（Requirements）

支持低功耗蓝牙的开发板。


<a id="building-and-running"></a>

## 3.3\_构建与运行（Building and Running）

构建和烧录如下，将 `<board>` 替换为目标开发板。

```bash
west build -b <board> samples/bluetooth/observer
west flash
```

示例在控制台输出附近LE设备的信息，包括地址、RSSI、广播类型和数据长度。


<a id="building-with-extended-scanning-support-zephyr-controller"></a>

### 3.3.1\_扩展扫描与Zephyr控制器（Building with Extended Scanning support (Zephyr Controller)）

```bash
west build -b nrf52840dk/nrf52840 samples/bluetooth/observer -- -DCONF_FILE=prj_extended.conf -DEXTRA_CONF_FILE=overlay-bt_ll_sw_split.conf
west flash
```


<a id="building-with-extended-scanning-support-for-bbc-micro-bit"></a>

### 3.3.2\_BBC Micro Bit扩展扫描（Building with Extended Scanning support for BBC Micro Bit）

```bash
west build -b bbc_microbit samples/bluetooth/observer -- -DCONF_FILE=prj_extended.conf -DEXTRA_CONF_FILE=overlay_bbc_microbit-bt_ll_sw_split.conf
west flash
```


<a id="thread-analysis-for-bbc-micro-bit-board"></a>

### 3.3.3\_BBC Micro Bit线程分析（Thread Analysis for BBC Micro Bit board）

BBC Micro Bit资源受限，可以启用线程分析（Thread Analysis）来评估RAM占用，确定成功构建和运行示例所需的线程栈大小。

```bash
west build -b bbc_microbit samples/bluetooth/observer -- -DCONF_FILE=prj_extended.conf "-DEXTRA_CONF_FILE=debug.conf;overlay_bbc_microbit-bt_ll_sw_split.conf"
west flash
```

> 译注：最后一条命令的 `EXTRA_CONF_FILE` 包含分号分隔的两个配置文件，原文用引号使其作为一个参数传入。各分支的目标板、主配置与附加配置按原文保留，不能混成一次构建。
