<a id="overview"></a>

## 2.1\_概览（Overview）

本应用演示LE广播者（Broadcaster）角色，周期性发送包含厂商数据项（Manufacturer Data Element）的广播包。数据内容为一个字节，表示设备已经发送的广播包数量；超过255后回到0。


<a id="requirements"></a>

## 2.2\_要求（Requirements）

主机上运行BlueZ，或使用支持低功耗蓝牙（Bluetooth Low Energy，LE）的开发板。


<a id="building-and-running"></a>

## 2.3\_构建与运行（Building and Running）

构建和烧录如下，将 `<board>` 替换为目标开发板。

```bash
west build -b <board> samples/bluetooth/broadcaster
west flash
```

验证时，用手机上的蓝牙扫描应用，例如nRF Connect或LightBlue，观察广播包；也可以在第二块板上烧录[观察者示例](P003_蓝牙观察者.md#bluetooth_observer)，查看控制台输出。
