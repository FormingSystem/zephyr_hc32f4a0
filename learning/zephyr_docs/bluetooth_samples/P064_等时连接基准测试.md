# 第64章\_等时连接信道基准测试（Isochronous Connected Channels Benchmark）

原文：[官方页面](https://docs.zephyrproject.org/latest/samples/bluetooth/iso_connected_benchmark/README.html)。快照读取日期：2026-10-15；来源摘要见[来源记录](../SOURCES.md)。

[在 GitHub 浏览源码（Browse source code on GitHub）](https://github.com/zephyrproject-rtos/zephyr/blob/main//samples/bluetooth/iso_connected_benchmark/README.rst/..)

ISO 连接信道基准测试示例测量并报告面向连接的 ISO 信道中的丢包和失步情况。

<a id="overview"></a>

## 64.1 概述（Overview）

示例在中心设备和外设之间传输数据，测量 ISO 信道质量。

同一个应用可作中心设备或外设，角色可方便地切换。

<a id="requirements"></a>

## 64.2 前提条件（Requirements）

- 主机上运行 BlueZ；或者

- 一块支持 Bluetooth Low Energy 5.2 的开发板。

- 支持设置 CONFIG_BT_CTLR_CENTRAL_ISO=y 的蓝牙控制器和开发板。

- 另一块运行相同示例、采用相反角色且支持设置 CONFIG_BT_CTLR_PERIPHERAL_ISO=y 的开发板。

<a id="building-and-running"></a>

## 64.3 构建与运行（Building and Running）

> 译注——执行环境：以下构建命令在读者自己的 Zephyr 源码根目录，用 UCRT64 Bash 或 Linux Bash 执行。先按[入门指南](../getting_started/大纲.md)准备工具链、west 工作区、板定义及控制器；`samples/...` 是官方已有目录，`<board>` 替换为实际目标。构建成功后按板文档烧录，分别核对对端角色、串口输出和本页预期结果；失败时先回查构建配置、烧录连接或角色与功能支持。本次仅翻译和核对来源，未执行构建、烧录或无线测试。

```text
west build -b <board> samples/bluetooth/iso_connected_benchmark
west flash
```

<a id="testing"></a>

### 64.3.1 测试（Testing）

> 译注——统计口径：本次 main.c 依据 ISO 接收回调的 `BT_ISO_FLAGS_VALID` 标记统计，多个 CIS 可共同计入；每 100 项打印 Overall（运行累计）、Current Conn（当前连接）和 Latest 1000（最近最多 1000 项）窗口。百分比不能直接当成全部空口发送的物理误包率，也不能把示例中的 100% 当成性能保证。

两块板均烧录示例后，按以下步骤测试：

1. 使用终端仿真器，例如 PuTTY 或 minicom，连接两块开发板。

2. 复位两块开发板。

3. 在其中一个终端仿真器中输入 c，使相应开发板以中心设备角色启动。

4. 在另一个终端仿真器中输入 p，使相应开发板以外设角色启动。

5. 可选：通过控制台修改中心设备的 ISO 设置。

6. 观察中心设备与外设建立连接。

7. 观察设备上的接收统计；面向连接的 ISO 信道可以是单向或双向。
