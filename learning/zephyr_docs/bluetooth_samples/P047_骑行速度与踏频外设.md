# 第47章\_骑行速度与踏频外设（Cycling Speed and Cadence，CSC）

原文：[官方页面](https://docs.zephyrproject.org/latest/samples/bluetooth/peripheral_csc/README.html)。快照读取日期：2026-10-15；来源摘要见[来源记录](../SOURCES.md)。

[在 GitHub 浏览源码（Browse source code on GitHub）](https://github.com/zephyrproject-rtos/zephyr/blob/main//samples/bluetooth/peripheral_csc/README.rst/..)

<a id="overview"></a>

## 47.1 概述（Overview）

本应用类似[基础外设（Peripheral）](P005_基础蓝牙外设.md#ble_peripheral)示例，但专门提供骑行速度与踏频（Cycling Speed and Cadence，CSC）GATT 服务。

<a id="requirements"></a>

## 47.2 前提条件（Requirements）

- 主机上运行 BlueZ；或者

- 一块支持 Bluetooth LE 的开发板。

<a id="building-and-running"></a>

## 47.3 构建与运行（Building and Running）

> 译注——执行环境：以下官方命令从读者自己的 Zephyr 源码根目录，在 UCRT64 Bash 或 Linux Bash 中执行。先按[入门文档](../getting_started/大纲.md)准备工具链、west工作区、板定义与所需蓝牙控制器；`samples/...` 是官方已有目录，`<board>` 需替换为实际板目标。构建成功后才按板文档烧录，并通过本页描述的连接、服务发现、订阅或配网步骤观察结果；失败时分别回查构建配置、烧录器或对端角色与功能支持。构建输出由工具生成，中文目录不作为固件工作目录。本次仅核对文档，未执行这些操作。

按以下方式构建并烧录，将 `<board>` 替换为目标开发板：

```text
west build -b <board> samples/bluetooth/peripheral_csc
west flash
```

烧录后，使用蓝牙扫描应用，例如 nRF Connect，连接设备并订阅 CSC Measurement（CSC 测量）特征，接收骑行速度与踏频通知。

> 译注——模拟运动数据：本次官方 main.c 在软件中推进累计车轮转数、曲柄转数和对应事件时间，并以 CSC 测量格式通知；没有读取真实自行车传感器。收到通知说明示例数据通路工作，不代表已测得真实速度或踏频。
