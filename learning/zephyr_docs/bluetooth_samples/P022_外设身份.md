<a id="overview"></a>

## 22.1\_概览（Overview）

本示例演示多个身份（Identity）的使用，以及同时接受多个中心设备（Central）连接的能力。

<a id="requirements"></a>

## 22.2\_要求（Requirements）

主机运行BlueZ，或者使用支持低功耗蓝牙（Bluetooth Low Energy，LE）的开发板。

<a id="building-and-running"></a>

## 22.3\_构建与运行（Building and Running）

将 `<board>` 替换为目标板，构建并烧录：

```bash
west build -b <board> samples/bluetooth/peripheral_identity
west flash
```

烧录后，设备一次使用一个身份广播。每当一个中心设备连接，应用就创建一个新身份并重新启动广播，使后续中心设备可以连接到不同身份。使用多个中心设备，例如运行nRF Connect的多部手机，建立多条同时存在的连接。
