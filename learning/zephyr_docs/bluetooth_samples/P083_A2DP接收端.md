# 第83章\_高级音频分发配置文件（Advanced Audio Distribution Profile，A2DP）接收端（Sink）

原文：[官方页面](https://docs.zephyrproject.org/latest/samples/bluetooth/classic/a2dp_sink/README.html)。快照读取日期：2026-10-15；来源摘要见[来源记录](../SOURCES.md)。

[在 GitHub 浏览源码（Browse source code on GitHub）](https://github.com/zephyrproject-rtos/zephyr/blob/main//samples/bluetooth/classic/a2dp_sink/README.rst/..)

<a id="overview"></a>

## 83.1 概述（Overview）

本示例通过 Zephyr 的经典蓝牙 API 演示高级音频分发配置文件（Advanced Audio Distribution Profile，A2DP）的接收端功能。应用作为 A2DP 接收设备，可被智能手机、平板电脑、计算机等 A2DP 源设备发现并连接，接收和处理源设备发出的音频流。

> 译注——传输与播放：A2DP 使用经典蓝牙 BR/EDR，与前面的 LE Audio 示例不同，只有低功耗蓝牙能力的控制器不能替代它。本次实现包含 SBC 音频解码、PCM 缓冲与板端编解码器播放路径；可发现和可连接只是前提，还要检查协商、流启动、数据接收及音频输出。配套源见[A2DP 音频源](P084_A2DP音频源.md)。

<a id="requirements"></a>

## 83.2 前提条件（Requirements）

- 在支持蓝牙基本速率／增强数据速率（Basic Rate/Enhanced Data Rate，BR/EDR，即经典蓝牙）的主机上运行，或者

- 一块支持蓝牙 BR/EDR（经典蓝牙）的开发板。

<a id="building-and-running"></a>

## 83.3 构建与运行（Building and Running）

> 译注——执行环境：以下命令从读者自己的 Zephyr 源码根目录，在 UCRT64 Bash 或 Linux Bash 中执行；先准备[工具链和 west 工作区](../getting_started/大纲.md)、相应板定义及支持经典蓝牙的控制器。`samples/...` 为官方已有目录；`<board>` 和 `<sample_name>` 按实际目标及本目录示例替换，多个应用使用各自构建目录或重新配置。确认构建成功后再按板文档烧录，串口依次观察初始化、发现／连接、配置文件建立和数据／音频活动；失败时回查对应阶段。本次未构建、烧录、连接蓝牙或测试音频。

```text
west build -b mimxrt1170_evk@B/mimxrt1176/cm7 samples/bluetooth/classic/a2dp_sink
west flash
```

烧录后，可以发现名为 `a2dp_sink` 的设备。使用 A2DP 源设备连接并向其发送音频流。

详情参见蓝牙示例（Bluetooth samples）。 相关链接：[蓝牙（Bluetooth）](P088_蓝牙示例总目录.md#bluetooth)。
