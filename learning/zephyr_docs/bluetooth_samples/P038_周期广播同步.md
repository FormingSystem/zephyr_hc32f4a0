# 第38章\_周期广播同步（Periodic Advertising Synchronization）

原文：[官方页面](https://docs.zephyrproject.org/latest/samples/bluetooth/periodic_sync/README.html)。快照读取日期：2026-10-15；来源摘要见[来源记录](../SOURCES.md)。

[在 GitHub 浏览源码（Browse source code on GitHub）](https://github.com/zephyrproject-rtos/zephyr/blob/main//samples/bluetooth/periodic_sync/README.rst/..)

<a id="overview"></a>

## 38.1 概述（Overview）

本简单应用演示 Bluetooth LE 周期广播同步功能。

> 译注——观察结果：本页对应[周期广播](P035_周期广播.md)。控制器必须具备周期广播同步能力；仅扫描到普通或扩展广播报告，不代表周期同步已经建立。应先确认广播源在运行，再查看本示例建立同步和接收数据的日志。

<a id="requirements"></a>

## 38.2 前提条件（Requirements）

- 一块支持 Bluetooth LE 的开发板。

<a id="building-and-running"></a>

## 38.3 构建与运行（Building and Running）

> 译注——构建位置与前提：以下是官方示例命令，在读者自己的 Zephyr 源码根目录中，使用 UCRT64 Bash 或 Linux Bash 执行；先完成[入门环境](../getting_started/大纲.md)，并确认所选板及控制器支持本文所需蓝牙能力。`samples/...` 是官方已有示例目录，`<board>` 是须替换的板目标占位符；构建输出由工具生成，不在本中文目录创建同名源码。先检查构建成功及板目标，再按板文档烧录并观察本文行为或日志；构建、烧录或通信失败时，分别回查工具链／板配置、烧录器和两端角色／控制器能力。本次未构建或运行示例。

按以下方式构建并烧录，将 `<board>` 替换为目标开发板：

```text
west build -b <board> samples/bluetooth/periodic_sync
west flash
```

烧录后，设备扫描周期广播端，并建立周期广播同步。

在第二块开发板上运行周期广播示例以启动周期广播，本设备将与其同步。 相关链接：[周期广播（Periodic Advertising）](P035_周期广播.md#ble_periodic_adv)。
