<a id="overview"></a>

## 23.1\_概览（Overview）

本应用类似[基础外设示例](P005_基础蓝牙外设.md#ble_peripheral)，区别是启用仅安全连接（Secure Connections Only，SC-only）模式，只接受使用安全等级4保护的连接，即经过认证的低功耗蓝牙安全连接（Authenticated LE Secure Connections）。

<a id="requirements"></a>

## 23.2\_要求（Requirements）

主机运行BlueZ，或者使用支持低功耗蓝牙（Bluetooth Low Energy，LE）的开发板。

<a id="building-and-running"></a>

## 23.3\_构建与运行（Building and Running）

将 `<board>` 替换为目标板，构建并烧录：

```bash
west build -b <board> samples/bluetooth/peripheral_sc_only
west flash
```

烧录后，用中心设备（Central）连接外设并配对（Pairing）。连接建立时，外设请求安全等级4，即经过认证的LE安全连接。如果中心设备不支持LE Secure Connections，配对将失败，连接随之终止。中心端可以使用Linux上的BlueZ，也可以使用现代智能手机。

> 译注——阶段区别：原文“只接受”描述的是最终安全要求，不代表无线链路在配对前已经具有等级4。连接、请求安全等级、配对认证与失败断开是先后发生的动作；对端仅支持LE Secure Connections，也不能替代“经过认证”的要求。
