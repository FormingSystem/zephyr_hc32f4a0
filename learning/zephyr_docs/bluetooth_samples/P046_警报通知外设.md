# 第46章\_警报通知服务外设（Peripheral ANS）

原文：[官方页面](https://docs.zephyrproject.org/latest/samples/bluetooth/peripheral_ans/README.html)。快照读取日期：2026-10-15；来源摘要见[来源记录](../SOURCES.md)。

[在 GitHub 浏览源码（Browse source code on GitHub）](https://github.com/zephyrproject-rtos/zephyr/blob/main//samples/bluetooth/peripheral_ans/README.rst/..)

<a id="overview"></a>

## 46.1 概述（Overview）

本示例作为外设，定期向已连接的远端设备发送通知，演示警报通知服务（Alert Notification Service，ANS）的用法。

<a id="requirements"></a>

## 46.2 前提条件（Requirements）

- 一块支持 Bluetooth LE 的开发板。

- 安装 Bluetooth LE 应用的智能手机，例如 ADI Attach、nRF Connect 等；或专用 Bluetooth LE 嗅探器（Sniffer）。

<a id="building-and-running"></a>

## 46.3 构建与运行（Building and Running）

> 译注——执行环境：以下官方命令从读者自己的 Zephyr 源码根目录，在 UCRT64 Bash 或 Linux Bash 中执行。先按[入门文档](../getting_started/大纲.md)准备工具链、west工作区、板定义与所需蓝牙控制器；`samples/...` 是官方已有目录，`<board>` 需替换为实际板目标。构建成功后才按板文档烧录，并通过本页描述的连接、服务发现、订阅或配网步骤观察结果；失败时分别回查构建配置、烧录器或对端角色与功能支持。构建输出由工具生成，中文目录不作为固件工作目录。本次仅核对文档，未执行这些操作。

按以下方式构建并烧录，将 `<board>` 替换为目标开发板：

```text
west build -b <board> samples/bluetooth/peripheral_ans
west flash
```

烧录后，使用蓝牙扫描应用，例如 nRF Connect，连接设备。先启用 New Alert（新警报）和 Unread Alert Status（未读警报状态）特征的通知，再写入 Alert Notification Control Point（警报通知控制点）以启用所需警报类别。示例周期性发送 Simple Alert（简单警报）和 High Priority Alert（高优先级警报）通知。

> 译注——两层启用条件：通知订阅与警报类别启用是两项操作；只连接设备或只打开通知，不等于控制点已启用目标类别。嗅探器可观察无线报文，但不能代替客户端完成连接、订阅和控制点写入。
