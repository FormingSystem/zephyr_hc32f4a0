# 第88章\_蓝牙（Bluetooth）

原文：[官方页面](https://docs.zephyrproject.org/latest/samples/bluetooth/bluetooth.html)。快照读取日期：2026-10-15；来源摘要见[来源记录](../SOURCES.md)。

这些示例演示 Zephyr 中蓝牙的使用方法。

> 译注——阅读范围：本页是官方蓝牙示例入口，详细 API 仍独立计入[全站进度](../PROGRESS.md)。源码跟踪和技术边界以明确标注的译注保留，项目实验环境另外安置；以下章节和源码均使用相对链接。

构建任意蓝牙示例的步骤与构建其他 Zephyr 应用相同。更多信息请参阅[应用开发（Application Development）](../bluetooth/P006_蓝牙应用开发.md#bluetooth-dev)。

许多蓝牙示例可以在 QEMU 或 [native_sim](../native_reference/P004_Native_Simulator本机模拟器.md#native_sim) 上运行，并支持外部蓝牙控制器。更多信息请参阅[硬件设置（Hardware setup）](../bluetooth/P006_蓝牙应用开发.md#bluetooth-hw-setup)一节。

部分蓝牙示例会构建基于 Zephyr 的控制器，随后可配合任何外部主机使用，包括原生运行或在 QEMU／`native_sim` 上运行的 Zephyr。这些示例在文档中采用 HCI 前缀，目录名以 `hci_` 开头。

注意（Note）

若要在 nRF5340 设备上运行任意蓝牙示例，即使用 `-DBOARD=nrf5340dk/nrf5340/cpuapp` 或 `-DBOARD=nrf5340dk/nrf5340/cpuapp/ns` 构建，还必须为 nRF5340 网络核构建并烧录相应的 HCI IPC 示例，它实现 Bluetooth Low Energy 控制器。 相关链接：[HCI 核间通信（HCI IPC）](../intercore_reference/P189_蓝牙HCI的IPC示例.md#bluetooth_hci_ipc)。

> 译注——双核与功能边界：这段描述 nRF5340 的低功耗蓝牙应用／控制器组合，不能扩展为该芯片支持本目录中的全部 BR/EDR 示例。使用 sysbuild 的示例可按其正文管理两核镜像；手工分开构建时仍须核对应用核和网络核版本、配置与烧录目标。

注意（Note）

主机与设备配对期间生成的共享加密密钥，在反复测试后可能变旧，导致后续连接失败。此时可在主机的关联设备列表中移除该设备，强制重新配对并生成新密钥。

> 译注——密钥状态：这里的“变旧”应结合反复烧录、清除设置或两端绑定记录不一致理解，不表示加密密钥必然按测试次数失效。先确认失败发生在配对／认证阶段，再按原文处理相关设备的绑定记录；此操作会移除该设备已保存的信任关系。
