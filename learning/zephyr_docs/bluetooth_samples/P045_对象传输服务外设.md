# 第45章\_对象传输服务外设（Peripheral Object Transfer Service，OTS）

原文：[官方页面](https://docs.zephyrproject.org/latest/samples/bluetooth/peripheral_ots/README.html)。快照读取日期：2026-10-15；来源摘要见[来源记录](../SOURCES.md)。

[在 GitHub 浏览源码（Browse source code on GitHub）](https://github.com/zephyrproject-rtos/zephyr/blob/main//samples/bluetooth/peripheral_ots/README.rst/..)

<a id="overview"></a>

## 45.1 概述（Overview）

本应用类似[基础外设（Peripheral）](P005_基础蓝牙外设.md#ble_peripheral)示例，但专门提供对象传输（Object Transfer，OTS）GATT 服务。

> 译注——对象存储边界：本次官方 main.c 用内存中的对象池存储内容，单个对象最大值 `OBJ_MAX_SIZE` 为 100 字节，数量受 `CONFIG_BT_OTS_MAX_OBJ_CNT` 限制。这是示例实现限制，不是 OTS 协议的通用对象大小上限；也不能把本例当作已实现持久文件存储。

<a id="requirements"></a>

## 45.2 前提条件（Requirements）

- 主机上运行 BlueZ；或者

- 一块支持 Bluetooth LE 的开发板。

<a id="building-and-running"></a>

## 45.3 构建与运行（Building and Running）

> 译注——执行环境：以下官方命令从读者自己的 Zephyr 源码根目录，在 UCRT64 Bash 或 Linux Bash 中执行。先按[入门文档](../getting_started/大纲.md)准备工具链、west工作区、板定义与所需蓝牙控制器；`samples/...` 是官方已有目录，`<board>` 需替换为实际板目标。构建成功后才按板文档烧录，并通过本页描述的连接、服务发现、订阅或配网步骤观察结果；失败时分别回查构建配置、烧录器或对端角色与功能支持。构建输出由工具生成，中文目录不作为固件工作目录。本次仅核对文档，未执行这些操作。

按以下方式构建并烧录，将 `<board>` 替换为目标开发板：

```text
west build -b <board> samples/bluetooth/peripheral_ots
west flash
```

烧录后，在第二块开发板上运行 Central OTC 示例，连接并操作 OTS；也可使用支持 OTS 客户端的蓝牙扫描应用，例如 nRF Connect。 相关链接：[对象传输客户端中心设备（Central OTC）](P044_对象传输客户端.md#ble_central_otc)。

> 译注——客户端能力：原文列出的手机应用仍须具备实际所需的 OTS 客户端能力。能连接或浏览 GATT 特征不代表支持对象列表、控制点和数据传输的完整流程；优先用[配套中心设备](P044_对象传输客户端.md)验证示例交互。
