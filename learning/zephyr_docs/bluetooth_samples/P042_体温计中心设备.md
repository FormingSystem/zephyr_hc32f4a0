# 第42章\_体温计中心设备（Health Thermometer / Central）

原文：[官方页面](https://docs.zephyrproject.org/latest/samples/bluetooth/central_ht/README.html)。快照读取日期：2026-10-15；来源摘要见[来源记录](../SOURCES.md)。

[在 GitHub 浏览源码（Browse source code on GitHub）](https://github.com/zephyrproject-rtos/zephyr/blob/main//samples/bluetooth/central_ht/README.rst/..)

<a id="overview"></a>

## 42.1 概述（Overview）

本应用类似[基础中心设备（Central）](P006_基础蓝牙中心设备.md#ble_central)示例，但专门寻找健康温度计传感器，连接后报告芯片温度读数。

> 译注——读数来源：原文概述称芯片温度，但中心设备接收到的实际数值取决于外设实现。[配套外设](P043_体温计外设.md)可能读取环境传感器、片内 TEMP 或生成模拟值；服务名本身不能证明数据来自人体测量。这里按官方协议名称翻译，不把示例当作医疗测量结果。

<a id="requirements"></a>

## 42.2 前提条件（Requirements）

- 主机上运行 BlueZ；或者

- 一块支持 Bluetooth LE 的开发板。

<a id="building-and-running"></a>

## 42.3 构建与运行（Building and Running）

> 译注——执行环境：以下官方命令从读者自己的 Zephyr 源码根目录，在 UCRT64 Bash 或 Linux Bash 中执行。先按[入门文档](../getting_started/大纲.md)准备工具链、west工作区、板定义与所需蓝牙控制器；`samples/...` 是官方已有目录，`<board>` 需替换为实际板目标。构建成功后才按板文档烧录，并通过本页描述的连接、服务发现、订阅或配网步骤观察结果；失败时分别回查构建配置、烧录器或对端角色与功能支持。构建输出由工具生成，中文目录不作为固件工作目录。本次仅核对文档，未执行这些操作。

按以下方式构建并烧录，将 `<board>` 替换为目标开发板：

```text
west build -b <board> samples/bluetooth/central_ht
west flash
```

烧录后，示例扫描广播健康温度计服务（Health Thermometer Service，HTS）的外设。发现后，与之连接并订阅温度测量（Temperature Measurement）指示（Indication）。在第二块开发板上运行[体温计外设（Health Thermometer / Peripheral）](P043_体温计外设.md#ble_peripheral_ht)示例作为对端。
