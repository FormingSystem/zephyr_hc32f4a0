# 第61章\_等时中心设备（ISO / Central）

原文：[官方页面](https://docs.zephyrproject.org/latest/samples/bluetooth/iso_central/README.html)。快照读取日期：2026-10-15；来源摘要见[来源记录](../SOURCES.md)。

[在 GitHub 浏览源码（Browse source code on GitHub）](https://github.com/zephyrproject-rtos/zephyr/blob/main//samples/bluetooth/iso_central/README.rst/..)

<a id="overview"></a>

## 61.1 概述（Overview）

> 译注——配对与链路：本页与[等时外设](P062_等时外设.md)配对。连接等时流（Connected Isochronous Stream，CIS）属于连接等时组（Connected Isochronous Group，CIG）；建立底层 ACL 连接后仍需成功建立 CIS，不能用普通蓝牙连接成功代替 ISO 数据通路成功。

本示例演示中心设备如何使用等时信道。它扫描外设，建立连接，并建立面向连接的等时信道。信道连接成功后，每十毫秒向对端传输等时数据。建议与[等时外设（ISO / Peripheral）](P062_等时外设.md#ble_peripheral_iso)示例配合运行。

<a id="requirements"></a>

## 61.2 前提条件（Requirements）

- 主机上运行 BlueZ；或者

- 一块支持 Bluetooth Low Energy 5.2 的开发板。

- 支持设置 [`CONFIG_BT_CTLR_CENTRAL_ISO`](https://docs.zephyrproject.org/latest/kconfig.html#CONFIG_BT_CTLR_CENTRAL_ISO) 的蓝牙控制器和开发板。

<a id="building-and-running"></a>

## 61.3 构建与运行（Building and Running）

> 译注——执行环境：以下构建命令在读者自己的 Zephyr 源码根目录，用 UCRT64 Bash 或 Linux Bash 执行。先按[入门指南](../getting_started/大纲.md)准备工具链、west 工作区、板定义及控制器；`samples/...` 是官方已有目录，`<board>` 替换为实际目标。构建成功后按板文档烧录，分别核对对端角色、串口输出和本页预期结果；失败时先回查构建配置、烧录连接或角色与功能支持。本次仅翻译和核对来源，未执行构建、烧录或无线测试。

```text
west build -b <board> samples/bluetooth/iso_central
west flash
```

在支持的板上，使用 `-DEXTRA_CONF_FILE=overlay-bt_ll_sw_split.conf` 为 Zephyr 蓝牙控制器启用所需 ISO 功能。

烧录后，检查以下事项：

1. 启动应用，在终端窗口确认设备正在扫描其他设备。

  > `Bluetooth initialized Scanning successfully started Device found: R:D3:3A:5D:F5:73:33 (RSSI -78) Device found: R:70:7B:F4:2B:76:AD (RSSI -68) Device found: R:65:CF:20:0D:CB:9D (RSSI -82)`。含义：蓝牙初始化完成、扫描已启动，并发现三个带地址及接收信号强度（RSSI）的设备。

2. 观察设备建立连接。

  > `Connected: R:65:CF:20:0D:CB:9D`。含义：已连接到所示对端。

3. 观察 ISO 信道建立连接。

  > `ISO Channel 0x200048f8 connected`。含义：所示 ISO 信道对象已连接。

更多详情参见[蓝牙示例（Bluetooth samples）](https://docs.zephyrproject.org/latest/samples/bluetooth/bluetooth.html#bluetooth)。
