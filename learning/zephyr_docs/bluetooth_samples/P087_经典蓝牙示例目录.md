# 第87章\_经典蓝牙（Bluetooth Classic）

原文：[官方页面](https://docs.zephyrproject.org/latest/samples/bluetooth/classic/index.html)。快照读取日期：2026-10-15；来源摘要见[来源记录](../SOURCES.md)。

这些示例演示 Zephyr 中经典蓝牙的使用方法。

> 译注——经典蓝牙与 LE：本目录要求控制器具有 BR/EDR 能力，不能仅凭支持 Bluetooth LE、Mesh 或 LE Audio 判断可运行。四篇正文见[A2DP 接收端](P083_A2DP接收端.md)、[A2DP 源](P084_A2DP音频源.md)、[免提单元](P085_免提单元.md)与[免提音频网关](P086_免提音频网关.md)。

- A2DP 接收端（A2DP Sink）：使用高级音频分发配置文件的接收端功能。 相关链接：[高级音频分发配置文件（Advanced Audio Distribution Profile，A2DP）接收端（Sink）](P083_A2DP接收端.md#bluetooth_a2dp_sink)。

- A2DP 音频源（A2DP Source）：使用高级音频分发配置文件的源端功能。 相关链接：[高级音频分发配置文件（Advanced Audio Distribution Profile，A2DP）音频源（Source）](P084_A2DP音频源.md#bluetooth_a2dp_source)。

- [免提单元（Hands-free）](P085_免提单元.md#bluetooth_handsfree)：使用免提配置文件（HFP）API。

- [免提音频网关（Hands-free Audio Gateway，AG）](P086_免提音频网关.md#bluetooth_handsfree_ag)：使用免提配置文件音频网关 API。

<a id="prerequisites"></a>

## 87.1 必备条件（Prerequisites）

- 一块支持经典蓝牙的开发板。

- 推荐开发板：

  - [mimxrt1170_evk@B/mimxrt1176/cm7](https://docs.zephyrproject.org/latest/boards/nxp/mimxrt1170_evk/doc/index.html#mimxrt1170_evk)

<a id="building-the-samples"></a>

## 87.2 构建示例（Building the Samples）

> 译注——执行环境：以下命令从读者自己的 Zephyr 源码根目录，在 UCRT64 Bash 或 Linux Bash 中执行；先准备[工具链和 west 工作区](../getting_started/大纲.md)、相应板定义及支持经典蓝牙的控制器。`samples/...` 为官方已有目录；`<board>` 和 `<sample_name>` 按实际目标及本目录示例替换，多个应用使用各自构建目录或重新配置。确认构建成功后再按板文档烧录，串口依次观察初始化、发现／连接、配置文件建立和数据／音频活动；失败时回查对应阶段。本次未构建、烧录、连接蓝牙或测试音频。

构建任意经典蓝牙示例时，使用以下命令：

```text
west build -p auto -b <board> samples/bluetooth/classic/<sample_name>
```

例如，为 [mimxrt1170_evk@B/mimxrt1176/cm7](https://docs.zephyrproject.org/latest/boards/nxp/mimxrt1170_evk/doc/index.html#mimxrt1170_evk) 构建：

```text
west build -p auto -b mimxrt1170_evk@B/mimxrt1176/cm7 samples/bluetooth/classic/<sample_name>
```

更多信息请参阅[应用开发（Application Development）](../bluetooth/P006_蓝牙应用开发.md#bluetooth-dev)。

<a id="configuration"></a>

## 87.3 配置（Configuration）

使用经典蓝牙功能时，必须启用以下 Kconfig 选项：

> 译注——配置写入位置：下面是 Kconfig 配置文件内容，不是终端命令。先检查应用已有的 `prj.conf`；必要的修改写入应用配置或读者创建的附加 `.conf` 文件，并由构建系统加载。仅设置这两个符号不等于控制器、传输驱动和音频硬件已具备功能。

```text
CONFIG_BT=y
CONFIG_BT_CLASSIC=y
```

启用详细的蓝牙日志：

> 译注——日志占位符：`<log level>` 必须替换为当前配置支持的日志级别数值，不能原样写入配置。`CONFIG_LOG_DEFAULT_LEVEL` 设置默认日志等级，具体模块的编译期／运行期过滤仍可能影响能看到的蓝牙输出。

```text
CONFIG_LOG=y
CONFIG_LOG_DEFAULT_LEVEL=<log level>
```
