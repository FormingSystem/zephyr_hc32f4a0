<a id="overview"></a>

## 4.1\_概览（Overview）

本应用同时演示LE广播者（Broadcaster）与观察者（Observer）角色，周期性发送包含厂商数据项的广播包。该数据只有一个字节，表示设备已经**接收**的广播包数量，超过255后回到0。


<a id="requirements"></a>

## 4.2\_要求（Requirements）

主机上运行BlueZ，或使用支持低功耗蓝牙（Bluetooth Low Energy，LE）的开发板。


<a id="building-and-running"></a>

## 4.3\_构建与运行（Building and Running）

构建和烧录如下，将 `<board>` 替换为目标开发板。

```bash
west build -b <board> samples/bluetooth/scan_adv
west flash
```

示例交错执行广播与附近设备扫描。发出的厂商数据字节反映接收到的广播包数量。可使用nRF Connect等扫描应用观察广播包，留意设备收到附近广播时该字节递增。

> 译注：本页计数的是接收包，与[广播者示例](P002_蓝牙广播者.md)的发送计数不同。
