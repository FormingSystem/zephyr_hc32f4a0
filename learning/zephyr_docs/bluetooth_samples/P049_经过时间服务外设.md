# 第49章\_经过时间服务外设（Elapsed Time Service，ETS）

原文：[官方页面](https://docs.zephyrproject.org/latest/samples/bluetooth/peripheral_ets/README.html)。快照读取日期：2026-10-15；来源摘要见[来源记录](../SOURCES.md)。

[在 GitHub 浏览源码（Browse source code on GitHub）](https://github.com/zephyrproject-rtos/zephyr/blob/main//samples/bluetooth/peripheral_ets/README.rst/..)

<a id="overview"></a>

## 49.1 概述（Overview）

本应用类似[基础外设（Peripheral）](P005_基础蓝牙外设.md#ble_peripheral)示例，但专门提供经过时间服务（Elapsed Time Service，ETS）的 GATT 服务。

本示例使用系统实时时钟 `SYS_CLOCK_REALTIME` 演示日内时间模式（Time-of-day mode）。支持 UTC 时间，默认为此模式；也支持带时区／夏令时偏移（TZ/DST offset）的本地时间，通过 overlay 启用。所有 Unix 纪元（1970）与 ETS 纪元（2000）之间的时间转换，均通过 ETS 辅助 API 完成。

> 译注——时钟与纪元：这里的系统实时时钟是墙上时间接口，不等同于开机时长，也不保证已有正确日历时间。本次 main.c 若读到的 Unix 时间早于 ETS 纪元，会以 2000-01-01 作为默认值；客户端成功写入时间后才更新系统时间并清除“时钟需设置”标记。时区／夏令时偏移以十五分钟为单位保存。

<a id="requirements"></a>

## 49.2 前提条件（Requirements）

- 主机上运行 BlueZ；或者

- 一块支持 Bluetooth LE 的开发板。

<a id="building-and-running"></a>

## 49.3 构建与运行（Building and Running）

> 译注——执行环境：以下官方命令从读者自己的 Zephyr 源码根目录，在 UCRT64 Bash 或 Linux Bash 中执行。先按[入门文档](../getting_started/大纲.md)准备工具链、west工作区、板定义与所需蓝牙控制器；`samples/...` 是官方已有目录，`<board>` 需替换为实际板目标。构建成功后才按板文档烧录，并通过本页描述的连接、服务发现、订阅或配网步骤观察结果；失败时分别回查构建配置、烧录器或对端角色与功能支持。构建输出由工具生成，中文目录不作为固件工作目录。本次仅核对文档，未执行这些操作。

本示例位于 Zephyr 源码树的 [samples/bluetooth/peripheral_ets](https://github.com/zephyrproject-rtos/zephyr/blob/main/samples/bluetooth/peripheral_ets) 目录。

<a id="building-with-utc-time-mode-default"></a>

### 49.3.1 构建 UTC 时间模式：默认模式（Building with UTC time mode）

```text
# From the root of the zephyr repository
west build -b <board> samples/bluetooth/peripheral_ets
west flash
```

<a id="building-with-local-time-mode"></a>

### 49.3.2 构建本地时间模式（Building with local time mode）

> 译注——附加配置文件：`overlay-local-time.conf` 是示例随附的 Kconfig 配置片段，不是设备树 overlay。它关闭 UTC 支持并开启本地时间支持，由 `EXTRA_CONF_FILE` 传给构建系统；本地文件见[原始配置](../../../samples/bluetooth/peripheral_ets/overlay-local-time.conf)。两种模式是替代构建配置，切换时应重新配置或使用各自的构建目录，避免沿用旧缓存。

```text
# From the root of the zephyr repository
west build -b <board> samples/bluetooth/peripheral_ets -- -DEXTRA_CONF_FILE=overlay-local-time.conf
west flash
```

详情参见[蓝牙示例（Bluetooth samples）](https://docs.zephyrproject.org/latest/samples/bluetooth/bluetooth.html#bluetooth)。
