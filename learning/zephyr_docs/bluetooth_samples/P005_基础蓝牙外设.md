<a id="overview"></a>

## 5.1\_概览（Overview）

本应用演示LE外设（Peripheral）角色，提供多个通用及厂商专用的通用属性配置文件（Generic Attribute Profile，GATT）服务。


<a id="requirements"></a>

## 5.2\_要求（Requirements）

主机上运行BlueZ，或使用支持低功耗蓝牙（Bluetooth Low Energy，LE）的开发板。


<a id="building-and-running"></a>

## 5.3\_构建与运行（Building and Running）

构建和烧录如下，将 `<board>` 替换为目标开发板。

```bash
west build -b <board> samples/bluetooth/peripheral
west flash
```

烧录后，可以使用nRF Connect等扫描应用、第二块板上的[中心设备示例](P006_基础蓝牙中心设备.md#ble_central)，或其他LE设备发起连接。示例提供电池服务（Battery Service，BAS）、当前时间服务（Current Time Service，CTS）、心率服务（Heart Rate Service，HRS）、即时警报服务（Immediate Alert Service，IAS），以及一个厂商专用服务。
