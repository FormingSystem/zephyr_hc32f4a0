<a id="overview"></a>

## 14.1\_概览（Overview）

本应用演示LE广播接受过滤列表（Advertising Accept Filter List）。外设尚未与任何设备绑定（Bonding）时进行普通广播；完成绑定后，在后续启动中只接受列表内中心设备（Central）的连接请求，也只向列表内设备发送扫描响应（Scan Response）。因此，不在列表内的某些中心设备，例如Android手机，可能不会在扫描结果中显示它。

示例还提供两个LE特征（Characteristic）：写入要求设备已经绑定，读取则可在连接后立即执行，无需绑定。

<a id="requirements"></a>

## 14.2\_要求（Requirements）

支持LE的开发板，以及充当中心设备的第二个LE设备，例如另一块Zephyr开发板或手机。

<a id="building-and-running"></a>

## 14.3\_构建与运行（Building and Running）

构建和烧录如下，将 `<board>` 替换为目标开发板。

```bash
west build -b <board> samples/bluetooth/peripheral_accept_list
west flash
```

首次启动时，设备公开广播；使用手机或另一块板与它绑定。在后续启动中，只接受已绑定设备；其他中心设备得不到扫描响应，其连接请求也会被拒绝。

> 译注：此处“看不到扫描响应”不等同于空口上没有任何广播。正文保留官方对部分中心设备扫描界面的说明；不将过滤列表描述为隐藏所有射频活动的机制。
