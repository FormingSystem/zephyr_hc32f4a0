## 4.2\_源码定位与版本边界

公共入口位于[sys/atomic.h](../../../include/zephyr/sys/atomic.h)，类型与后端通过该文件选入；本次核对[官方公共头文件](https://github.com/zephyrproject-rtos/zephyr/blob/main/include/zephyr/sys/atomic.h)、[C实现](https://github.com/zephyrproject-rtos/zephyr/blob/main/lib/os/atomic_c.c)与[配置定义](https://github.com/zephyrproject-rtos/zephyr/blob/main/lib/os/Kconfig.atomics)，摘要见[来源记录](../SOURCES.md)。仓库源码、滚动更新的main和latest网页不能自动视为同一版本。

四种类型的公共说明见[原子操作公共接口](P001_原子操作公共接口.md)。类型定义不单独构成同步机制，实际typedef及包含约束见[类型源码](P005_原子操作类型头文件源码.md)。

本批完成文档与源码核对，未构建或运行并发、内存顺序及实板实验。
