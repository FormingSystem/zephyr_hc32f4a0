# 设备树中断与唤醒参考大纲

本册收录设备树（Devicetree）的中断描述符（Interrupt Specifier）、控制器层级（Aggregator Level）和唤醒控制器（Wake-Up Controller，WUC）宏，并提供中断控制器与唤醒控制器两份头文件参考和源码。字段值、节点标识、中断号和唤醒id的用途各不相同。

保留原始声明、宏展开、C／设备树／绑定示例、注释和许可证。译注解释多级中断编码、存在性检查、控制器解析与原例差异。厂商子主题按官方页面保留导航与简介，不把未译链接页计为完成；本地源码定位均为相对链接。完整范围见[全站进度](../PROGRESS.md)。
