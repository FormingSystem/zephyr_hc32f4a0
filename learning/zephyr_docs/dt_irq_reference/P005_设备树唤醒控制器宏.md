DT_WUC_BY_IDX(DT_NODELABEL(n), 0) // DT_NODELABEL(wuc1)

| `idx` | `wakeup-ctrls` 属性中的逻辑索引。 |
| `cell` | 单元名称，使用小写字母和下划线形式。 |

## 5.3\_源码定位与版本边界

本册收录中断属性、中断控制器层级、唤醒控制器三组宏及两份头文件的参考与源码。相对源码定位：[devicetree.h](../../../include/zephyr/devicetree.h)、[interrupt_controller.h](../../../include/zephyr/devicetree/interrupt_controller.h)、[wuc.h](../../../include/zephyr/devicetree/wuc.h)、[生成脚本](../../../scripts/dts/gen_defines.py)和[解析器](../../../scripts/dts/python-devicetree/src/devicetree/edtlib.py)。本次官方文件摘要见[来源记录](../SOURCES.md)。

> 译注——源码核对：返回对象：DT_WUC_BY_IDX返回wakeup-ctrls条目引用的控制器节点标识，DT_WUC_CELL_BY_IDX返回指定单元值；ID版本固定读取名为id的单元。节点标识、id数值和运行时设备指针是不同对象。宏展开不会启用唤醒源、配置电源状态或证明控制器已就绪。

> 译注——源码核对：绑定布局：设备树属性wakeup-ctrls在C宏中写为wakeup_ctrls；控制器#wakeup-ctrl-cells给出每个描述符的数据单元数，绑定wakeup-ctrl-cells列表给出单元名称。原例的10／20是绑定定义的id值，不能从通用宏推断为CPU中断号、GPIO编号或固定寄存器位。

> 译注——源码核对：索引与实例：idx从0开始计数完整phandle-array条目，不计数其中的32位单元；无_BY_IDX版本固定索引0。INST系列先按DT_DRV_COMPAT将inst转为消费节点；inst不是wakeup控制器编号，也不等于设备树单元id。使用前保证属性、条目和对应单元存在，宏没有运行时错误返回或自动回退。

> 译注——源码核对：示例范围：vnd,wuc与地址中的...是官方演示占位内容，需要真实控制器绑定和完整DTS上下文。公共头文件由devicetree.h包含；本批仅翻译设备树宏，不将它称为完整唤醒驱动或已完成低功耗实板验证。

> 译注——源码核对：版本边界：本次官方devicetree.h、interrupt_controller.h、wuc.h、gen_defines.py和edtlib.py登记摘要；两份源码浏览页的非注释代码与对应原始头文件一致。滚动main和本仓库参照基线不自动视为同版本，源码链接使用相对路径。本批未编译示例或执行中断注册、优先级修改、唤醒和实板实验。

本次验证范围为文档与源码对照，未编译示例或执行中断注册、优先级修改、唤醒及实板实验。
