| --- | --- |

<a id="ga3779b2115eac60ab32adfc8d212e973f"></a>

### `DT_IRQ_BY_IDX`

```c
#define DT_IRQ_BY_IDX ( node_id, idx, cell )
```

```c
#include <zephyr/devicetree.h>
```

展开值（Value）：

```c
DT_CAT5(node_id, _IRQ_IDX_, idx, _VAL_, cell)
```

按索引获取中断描述符（Interrupt Specifier）中的一个值。

可以将参数顺序理解为类似于 `node->interrupts[index].cell`。

当设备产生多个中断时，可用此宏获取其中一个中断的信息。

设备树（Devicetree）片段示例：

原始示例（Example）：

```dts
my-serial: serial@abcd1234 {
        interrupts = <33 0>, <34 1>;
};
```

假设节点的中断域（Interrupt Domain）具有 `#interrupt-cells = <2>;`，且节点绑定（Binding）将每个中断描述符的单元分别命名为 `irq` 和 `priority`，则有以下示例：

原始示例（Example）：

```text
#define SERIAL DT_NODELABEL(my_serial)

Example usage                       Value
-------------                       -----
DT_IRQ_BY_IDX(SERIAL, 0, irq)          33
DT_IRQ_BY_IDX(SERIAL, 0, priority)      0
DT_IRQ_BY_IDX(SERIAL, 1, irq,          34
DT_IRQ_BY_IDX(SERIAL, 1, priority)      1
```

**参数（Parameters）**

| 名称／方向 | 说明 |
| --- | --- |
| `node_id` | 节点标识符（Node Identifier）。 |
| `idx` | 中断描述符数组中的逻辑索引（Logical Index）。 |
| `cell` | 单元名称描述符。 |

返回（Returns）：由索引指定的描述符中，指定名称的值。

> 译注——源码核对：原始表格：Example usage／Value分别为“用法示例／值”；其中DT_IRQ_BY_IDX(SERIAL, 1, irq,末尾误写逗号且缺右括号，预期为DT_IRQ_BY_IDX(SERIAL, 1, irq)。设备树标签my-serial应使用合法的下划线形式my_serial；原片段和表格照录，不能直接视为可编译示例。

### `DT_IRQ_BY_NAME`

```c
#define DT_IRQ_BY_NAME ( node_id, name, cell )
```

```c

```

| `cell` | 单元名称描述符。 |

返回（Returns）：由索引指定的描述符中，指定名称的值。

### `DT_IRQ_HAS_CELL_AT_IDX`

```c
#define DT_IRQ_HAS_CELL_AT_IDX ( node_id, idx, cell )
```

```c
#include <zephyr/devicetree.h>
```

展开值（Value）：

```c
IS_ENABLED(DT_CAT6(node_id, _IRQ_IDX_, idx, _VAL_, cell, _EXISTS))
```

判断 `interrupts` 属性在指定索引处是否具有指定名称的单元描述符（Cell Specifier）。

若返回 1，则 `DT_IRQ_BY_IDX(node_id, idx, cell)` 有效。若返回 0，则使用该宏会出错。

**参数（Parameters）**

| 名称／方向 | 说明 |
| --- | --- |
| `node_id` | 节点标识符（Node Identifier）。 |
| `idx` | 要检查的索引。 |
| `cell` | 要检查是否存在的具名单元值。 |

返回（Returns）：若索引 `idx` 处的中断描述符具有该具名单元，则为 1；否则为 0。

<a id="ga238a290dc6cea9479104ff8f95de1c4c"></a>

### `DT_IRQ_HAS_IDX`

```c
#define DT_IRQ_HAS_IDX ( node_id, idx )
```

```c
#include <zephyr/devicetree.h>
```

展开值（Value）：

```c
IS_ENABLED(DT_CAT4(node_id, _IRQ_IDX_, idx, _EXISTS))
```

判断 `idx` 是否为有效的中断索引。

若返回 1，则 `DT_IRQ_BY_IDX(node_id, idx)` 有效。若返回 0，则使用该索引调用此宏会出错。

**参数（Parameters）**

| 名称／方向 | 说明 |
| --- | --- |
| `node_id` | 节点标识符（Node Identifier）。 |
| `idx` | 要检查的索引。 |

返回（Returns）：若 `idx` 对中断属性有效则为 1，否则为 0。

> 译注——源码核对：存在检查：DT_IRQ_HAS_IDX的原文漏写DT_IRQ_BY_IDX的第三个cell参数；完整调用需要node_id、idx、cell。索引存在只表明该描述符有生成字段，欲读取特定字段还应核对HAS_CELL_AT_IDX。DT_IRQ_HAS_NAME实际检查该名称下irq单元的_EXISTS，不保证priority等任意单元存在，也不是仅判断interrupt-names字符串存在。

### `DT_IRQ_INTC`

```c
#define DT_IRQ_INTC ( node_id)
```


用法示例：

原始示例（Example）：

```c
DT_IRQ_INTC(DT_NODELABEL(foo)) // &gpio0
DT_IRQ_INTC(DT_NODELABEL(bar)) // &gpio0

```

| 名称／方向 | 说明 |
| --- | --- |
| `node_id` | 节点标识符（Node Identifier）。 |

### `DT_IRQN`

```c
#define DT_IRQN ( node_id)
```

```c
#include <zephyr/devicetree.h>
```

展开值（Value）：

```c
DT_IRQN_BY_IDX(node_id, 0)
```

获取节点（唯一）的中断请求号（Interrupt Request Number，IRQ Number）。

等价于 `DT_IRQ(node_id, irq)`。此宏为常见情形提供便利：节点恰好产生一个中断，且中断号位于名为 `irq` 的单元中。

**参数（Parameters）**

| 名称／方向 | 说明 |
| --- | --- |

## 1.3\_源码定位与版本边界

本册收录中断属性、中断控制器层级、唤醒控制器三组宏及两份头文件的参考与源码。相对源码定位：[devicetree.h](../../../include/zephyr/devicetree.h)、[interrupt_controller.h](../../../include/zephyr/devicetree/interrupt_controller.h)、[wuc.h](../../../include/zephyr/devicetree/wuc.h)、[生成脚本](../../../scripts/dts/gen_defines.py)和[解析器](../../../scripts/dts/python-devicetree/src/devicetree/edtlib.py)。本次官方文件摘要见[来源记录](../SOURCES.md)。

> 译注——源码核对：描述符与控制器：DT_IRQ_BY_IDX／BY_NAME读取命名字段，DT_IRQ_INTC系列返回控制器节点标识，DT_IRQN系列返回Zephyr使用的中断号；三者不能互换为struct device指针。解析器先处理interrupts-extended，否则处理interrupts，并可经interrupt-map得到最终控制器，所以控制器不一定是设备树直接父节点。

> 译注——源码核对：名称来源：irq、priority等单元名称由中断控制器绑定的interrupt-cells定义，interrupt-names为消费节点的各中断描述符命名。原文笼统称“节点绑定为每个描述符指定名称”，这里应区分单元名称与描述符名称；BY_NAME的返回说明仍写“由索引指定”，实际按name选择。参数写小写加下划线标记，不是带引号的运行时字符串。

> 译注——源码核对：层级含义：DT_IRQ_LEVEL是中断拓扑层数，不是优先级、触发沿或高低电平。生成器从节点的第一个中断开始沿控制器的第一个中断追溯，形成每节点一个_IRQ_LEVEL；不能据此断言节点所有中断分支均经过独立层级计算。没有中断时生成值为0。

> 译注——源码核对：生成值与原单元：DT_IRQ_BY_IDX读取生成器字段，不保证与DTS的irq原始单元逐字相同。本次生成器对兼容arm,gic的控制器按type把共享外设中断（Shared Peripheral Interrupt，SPI）编号加32、私有外设中断（Private Peripheral Interrupt，PPI）编号加16。必须按目标控制器绑定及架构解释，不能将该偏移应用到所有芯片。

> 译注——源码核对：节点标签：DT_NUM_NODELABELS虽然位于本页官方分组，计数的是foo:这样的节点标签数量，不是中断数量、aliases数量或label字符串长度。一个节点可有多个标签；示例中的baz和baz2是同一节点的两个标签。

> 译注——源码核对：版本边界：本次官方devicetree.h、interrupt_controller.h、wuc.h、gen_defines.py和edtlib.py登记摘要；两份源码浏览页的非注释代码与对应原始头文件一致。滚动main和本仓库参照基线不自动视为同版本，源码链接使用相对路径。本批未编译示例或执行中断注册、优先级修改、唤醒和实板实验。

本次验证范围为文档与源码对照，未编译示例或执行中断注册、优先级修改、唤醒及实板实验。
