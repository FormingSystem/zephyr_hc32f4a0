## 2.3\_详细说明（Detailed Documentation）

<a id="ga914952a10c55fecc1f6e7c0cc3685b1b"></a>

### `DT_INST_INTC_GET_AGGREGATOR_LEVEL`

```c
#define DT_INST_INTC_GET_AGGREGATOR_LEVEL ( inst)
```

```c
#include <zephyr/devicetree/interrupt_controller.h>
```

展开值（Value）：

```c
DT_INTC_GET_AGGREGATOR_LEVEL(DT_DRV_INST(inst))
```

获取 `DT_DRV_COMPAT` 中断控制器的聚合器层级。

**参数（Parameters）**

| 名称／方向 | 说明 |
| --- | --- |
| `inst` | 中断控制器实例。 |

说明（Note）：聚合器层级等于 `IRQ_LEVEL + 1`；二级聚合器具有 Zephyr 的一级 IRQ 编码。

返回（Returns）：中断控制器的层级。

<a id="ga4eebef2c5e75d6a6c87d0cea03ac1bee"></a>

### `DT_INTC_GET_AGGREGATOR_LEVEL`

```c
#define DT_INTC_GET_AGGREGATOR_LEVEL ( node_id)
```

```c
#include <zephyr/devicetree/interrupt_controller.h>
```

展开值（Value）：

```c
UTIL_INC(DT_IRQ_LEVEL(node_id))
```

获取中断控制器的聚合器层级（Aggregator Level）。

**参数（Parameters）**

| 名称／方向 | 说明 |
| --- | --- |
| `node_id` | 中断控制器的节点标识符。 |

说明（Note）：聚合器层级等于 `IRQ_LEVEL + 1`；二级聚合器具有 Zephyr 的一级 IRQ 编码。

返回（Returns）：中断控制器的层级。

## 2.4\_源码定位与版本边界

本册收录中断属性、中断控制器层级、唤醒控制器三组宏及两份头文件的参考与源码。相对源码定位：[devicetree.h](../../../include/zephyr/devicetree.h)、[interrupt_controller.h](../../../include/zephyr/devicetree/interrupt_controller.h)、[wuc.h](../../../include/zephyr/devicetree/wuc.h)、[生成脚本](../../../scripts/dts/gen_defines.py)和[解析器](../../../scripts/dts/python-devicetree/src/devicetree/edtlib.py)。本次官方文件摘要见[来源记录](../SOURCES.md)。

> 译注——源码核对：两个层级：DT_INTC_GET_AGGREGATOR_LEVEL实现为UTIL_INC(DT_IRQ_LEVEL(node_id))。一级控制器自身无上级中断时IRQ_LEVEL为0，聚合器层级为1；二级聚合器自身连到一级控制器，IRQ_LEVEL为1而聚合器层级为2。不要将控制器层级和由该控制器产生的Zephyr编码层数混为同一参数。

> 译注——源码核对：实例与用途：DT_INST_INTC_GET_AGGREGATOR_LEVEL先使用DT_DRV_INST(inst)，需要正确的DT_DRV_COMPAT及实例上下文。它是预处理期宏，不遍历硬件、不配置路由、不注册或使能中断；返回值也不是中断优先级。原页厂商子主题属于官方导航，仅翻译主题名称与简介，不把链接目标计作本批完成。

> 译注——源码核对：版本边界：本次官方devicetree.h、interrupt_controller.h、wuc.h、gen_defines.py和edtlib.py登记摘要；两份源码浏览页的非注释代码与对应原始头文件一致。滚动main和本仓库参照基线不自动视为同版本，源码链接使用相对路径。本批未编译示例或执行中断注册、优先级修改、唤醒和实板实验。

本次验证范围为文档与源码对照，未编译示例或执行中断注册、优先级修改、唤醒及实板实验。
