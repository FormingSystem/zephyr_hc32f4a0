# 蓝牙HCI命令事件与驱动数据结构参考大纲

本册完整翻译官方蓝牙主机控制器接口（Host Controller Interface，HCI）的450份结构体页面，覆盖命令参数、事件参数、返回参数、信道探测（Channel Sounding，CS）、等时传输、厂商扩展及驱动数据。结构体名与成员声明保留源码标识，原文已有的文字说明逐项翻译；原页只列出成员、未解释字段的页面不另行编造协议语义。

驱动回调、公共地址、锁步命令辅助接口（Lockstep Command Helper）和响应解码的并发约束、生命周期、错误值及弃用说明完整保留。所有原始锚点及交叉引用可追溯；已译页优先使用相对链接。头文件、源码浏览页和其他独立API主题仍各自按全站清单记录状态。
