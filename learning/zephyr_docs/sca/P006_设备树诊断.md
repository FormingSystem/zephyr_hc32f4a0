# 第6章\_设备树诊断

原文：[Devicetree diagnostics (dtdoctor)](https://docs.zephyrproject.org/latest/develop/sca/dtdoctor.html)。读取日期：2026-10-12，`latest`。

`dtdoctor` 是帮助诊断**设备树（Devicetree）**相关构建错误的静态分析工具。

它拦截编译器和链接器错误。当消息涉及未解析的设备树设备符号，例如 `__device_dts_ord_*`，就给出可能原因及修复方法的详细信息。

## 6.1\_启用诊断工具

构建时设置 `-DZEPHYR_SCA_VARIANT=dtdoctor`，例如：

```sh
west build -b reel_board samples/basic/blinky -- -DZEPHYR_SCA_VARIANT=dtdoctor
```

> 译注：在准备好工具链和依赖的 Zephyr 源码根，用 Bash 执行。`reel_board` 与 `samples/basic/blinky` 是官方板与示例，命令用于启用诊断，不是故意制造故障；成功构建时未必产生设备树错误提示。`__device_dts_ord_*` 是设备对象符号的一类名称，`*` 表示不同序号后缀；出现未解析引用时仍需按诊断核对设备节点、驱动与配置，工具不会自动完成板级移植。
