# 第5章\_头文件依赖检查

原文：[include-what-you-use (IWYU) support](https://docs.zephyrproject.org/latest/develop/sca/iwyu.html)。读取日期：2026-10-12，`latest`。

**按使用关系包含头文件（include-what-you-use，IWYU）**是基于 Clang 与 LLVM 的工具，分析 C/C++ 源文件的 `#include` 指令。对每个**翻译单元（Translation Unit）**，它报告未使用的头文件，以及使用了符号、却仅通过其他头文件间接取得其定义的情况。

> 译注：翻译单元是单个源码文件经过包含和预处理后交给编译器的内容。头文件的间接包含称为**传递包含（Transitive Include）**；根据 IWYU 建议改动，可以让依赖更小且更明确，但建议仍需结合实际接口语义审查。

## 5.1\_安装IWYU

多数 Linux 发行版提供该软件包。在 Ubuntu 的 Bash 终端、任意目录执行：

```sh
sudo apt-get install iwyu
```

确保 `include-what-you-use` 可执行程序位于 [`PATH`命令搜索路径](https://docs.zephyrproject.org/latest/develop/env_vars.html#envvar-PATH)中。

## 5.2\_伴随构建检查

IWYU 建立在 Clang 上，原文说明使用 LLVM 工具链构建能取得最准确的结果。启用参数是 `-DZEPHYR_SCA_VARIANT=iwyu`：

```sh
west build -b native_sim samples/hello_world -- -DZEPHYR_SCA_VARIANT=iwyu
```

> 译注：该命令在 Linux 的 Zephyr 源码根用 Bash 执行，使用主机原生模拟目标 `native_sim`；它没有显式切换 LLVM，实际编译器仍由当前工具链配置决定。先准备主机目标依赖与 IWYU，配置失败则返回核对工具链和命令搜索路径。

分析随每个源码文件的编译执行，建议的头文件改动打印到构建的**标准错误输出（Standard Error，stderr）**。

## 5.3\_传入检查选项

完整选项见 [IWYU文档](https://github.com/include-what-you-use/include-what-you-use/blob/master/README.md)。`IWYU_OPTS` 为分号分隔列表，每一项会自动带上所需的 `-Xiwyu` 前缀再转发给工具。

可以在 CMake 命令行或环境变量中设置，例如：

```sh
west build -b native_sim samples/hello_world -- -DZEPHYR_SCA_VARIANT=iwyu -DIWYU_OPTS="--no_comments;--verbose=3"
```

这里请求省略注释并调整详细程度。工具项目入口见 [include-what-you-use官网](https://include-what-you-use.org/)。本次没有安装工具或应用其修改建议。
