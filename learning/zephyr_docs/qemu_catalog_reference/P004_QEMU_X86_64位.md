# 第4章\_QEMU\_X86\_64位

原文：[官方页面](https://docs.zephyrproject.org/latest/boards/qemu/x86_64/doc/index.html)。读取日期：2026-10-15；来源摘要见[来源记录](../SOURCES.md)。

<a id="qemu_x86_64"></a>

## 4.1\_开发板概况与概述

名称：`qemu_x86_64`。厂商：[Intel Corporation](https://docs.zephyrproject.org/latest/boards/index.html#vendor=intel)。状态：未积极维护（Not Actively Maintained）。架构（Architecture）：[x86](https://docs.zephyrproject.org/latest/boards/index.html#arch=x86)；片上系统（SoC）：[atom](https://docs.zephyrproject.org/latest/boards/index.html#soc=atom)。

<a id="board-github-link"></a>

[浏览开发板源码](https://github.com/zephyrproject-rtos/zephyr/tree/main/boards/qemu/x86_64)。

<a id="overview"></a>

X86_64 QEMU 开发板配置用于仿真在64位长模式（Long Mode）下运行的 x86 架构。

它使用与 [X86 QEMU](P003_QEMU_X86.md#qemu_x86)相同的 q35 仿真机器，增加第二个 CPU 用于对称多处理（SMP）测试，并增加仿真的 Intel 平台控制器集线器（PCH）系统管理总线（SMBus）控制器。`qemu_x86_64/atom/nokpti` 变体使用同一配置，但禁用内核页表隔离（Kernel Page Table Isolation，KPTI）。

## 4.3\_编程与调试

原页列出 `qemu_x86_64` 支持的运行器（Runner）及关联 west 命令：

| 运行器 | `west flash` | `west debug` | `west debugserver` |
| --- | --- | --- | --- |
| `qemu` | 支持，默认 | 支持，默认 | 支持 |

应用可按仿真开发板的通常方式构建和运行，详见[构建应用](../application/P001_应用开发.md#build-an-application)和[运行应用](https://docs.zephyrproject.org/latest/develop/application/index.html#application-run)。

<a id="flashing"></a>

虽然该开发板是仿真的，不能实际“烧写”（Flash），但可用此配置运行基本 Zephyr 应用及内核测试。

以[基础同步示例（Basic Synchronization）](../basic_samples/P029_基本同步示例.md#synchronization)为例，下面的命令从 Zephyr 仓库根目录执行，原代码注释也表示这一位置。

```shell
# From the root of the zephyr repository
west build -b qemu_x86_64 samples/synchronization
west build -t run
```

按 `CTRL+A`，再按 `x` 退出 QEMU。

<a id="uefi-boot"></a>

### 4.3.1\_UEFI启动

`qemu_x86_64` 平台也支持通过统一可扩展固件接口（Unified Extensible Firmware Interface，UEFI）启动 Zephyr 应用及内核测试，需要完成以下环境配置。

先按照 [uefi-run 项目说明](https://github.com/Richard-W/uefi-run)安装 `uefi-run`。由于 snap 的严格隔离（Strict Confinement），来自 Snap Store 的 `uefi-run` 可能无法工作；推荐使用 cargo 安装。

再按照 [OVMF 说明](https://github.com/tianocore/tianocore.github.io/wiki/OVMF)安装开放虚拟机固件（Open Virtual Machine Firmware，OVMF）。最简单的方法是安装许多发行版提供的 `ovmf` 软件包，例如在 Ubuntu 中执行：

```shell
sudo apt install ovmf
```

设置系统环境变量 `OVMF_FD_PATH`，例如：

```shell
export OVMF_FD_PATH=/usr/share/OVMF/OVMF_CODE.fd
```

译注：上面的路径是官方 Ubuntu 软件包安装位置示例，应与读者实际安装的 OVMF 固件文件对应，不是本仓库所在目录。

现在可以构建应用，例如位于 [`tests/boot/uefi`](https://github.com/zephyrproject-rtos/zephyr/blob/main/tests/boot/uefi) 的 UEFI 启动测试示例。从 Zephyr 仓库根目录执行：

```shell
# From the root of the zephyr repository
west build -b qemu_x86_64 tests/boot/uefi
west build -t run
```

这会构建包含 UEFI 启动测试应用的镜像，通过 UEFI 在 `qemu_x86_64` 上启动，并显示以下控制台输出：

<a id="networking"></a>

网络（Networking）：此开发板支持通过仿真串口使用 SLIP 网络（`CONFIG_NET_SLIP_TAP=y`），配置详见[QEMU 联网](../networking/P009_QEMU联网概览.md#networking-with-qemu)。

也可使用 QEMU 内置以太网适配器连接宿主系统；这比 SLIP 更快，也是优先推荐的方式，详见[QEMU 以太网联网](../networking/P010_QEMU以太网联网.md#networking-with-eth-qemu)。
