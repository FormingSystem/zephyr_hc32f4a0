## 概述（Overview）

nRF21540 DK（PCA10112）展示了Nordic Semiconductor nRF21540前端模块（Front End Module）连接nRF52840 ARM Cortex-M4F CPU的能力。

<a id="id5"></a>

<a id="id10"></a>

开发板更多信息见[nRF21540网站](https://www.nordicsemi.com/Products/Low-power-short-range-wireless/nRF21540) [注2](#id4)；[nRF21540产品规格书（Product Specification）](https://docs.nordicsemi.com/bundle/ps_nrf21540/page/keyfeatures_html5.html)[注4](#id9) 提供处理器及前端模块信息和数据手册。

<a id="hardware"></a>

## 硬件（Hardware）

The nRF52840 on the nRF21540 DK有两个外部振荡器，低速时钟频率32.768 kHz，主时钟频率32 MHz。

<a id="supported-features"></a>

- 接收使能（RXEN）= P0.19

<a id="changing-uart1-pins"></a>

## 更改UART1引脚（Pins）

应用需要为UART1使用另一组引脚时，可采用以下方法：


1. 在应用主目录中添加设备树覆盖文件（Devicetree Overlay）：

  ```text
  &pinctrl {
     uart1_default_alt: uart1_default_alt {
        group1 {
           psels = <NRF_PSEL(UART_TX, 0, 14)>,
                   <NRF_PSEL(UART_RX, 0, 16)>;
        };
     };
     /* required if CONFIG_PM_DEVICE=y */
     uart1_sleep_alt: uart1_sleep_alt {
        group1 {
           psels = <NRF_PSEL(UART_TX, 0, 14)>,
                   <NRF_PSEL(UART_RX, 0, 16)>;
           low-power-enable;
        };
     };
  };

  &uart1 {
    pinctrl-0 = <&uart1_default_alt>;
    /* if sleep state is not used, use /delete-property/ pinctrl-1; and
     * skip the "sleep" entry.
     */
    pinctrl-1 = <&uart1_sleep_alt>;
    pinctrl-names = "default", "sleep";
  };
  ```

  上述覆盖文件使用P0.16作为RX、P0.14作为TX。

更多细节见[设置设备树覆盖文件（Set Devicetree Overlays）](../devicetree/P006_设备树操作指南.md#set-devicetree-overlays)。

<a id="selecting-the-pins"></a>

### 选择引脚（Selecting the Pins）

<a id="id8"></a>

可在开发板的引脚控制（Pinctrl）文件中配置引脚。查看可用映射时，打开[nRF52840产品规范（Product Specification）](https://docs.nordicsemi.com/bundle/ps_nrf52840/page/keyfeatures_html5.html)[注3](#id6)中的第7章“Hardware and Layout（硬件与布局）”，在表7.1.1“aQFN73 ball assignments（aQFN73焊球分配）”中选择标为“General purpose I/O（通用输入输出）”的引脚。标为“low frequency I/O only（仅限低频I/O）”的引脚只能用于低于10 kHz的应用，不适合115200速率的UART。
