## 概述（Overview）

nRF9131 EK（PCA10165）是用于nRF9131系统级封装（SiP）的单板评估套件，支持DECT NR+、LTE-M／NB-IoT及全球导航卫星系统（GNSS）。nrf9131ek/nrf9131开发板配置支持Nordic Semiconductor nRF9131 ARM Cortex-M33F CPU及ARMv8-M安全扩展。

<a id="id5"></a>

原文称，[Nordic Semiconductor技术文档（TechDocs）](https://docs.nordicsemi.com/)[注2](#id4) 即将提供处理器信息及数据手册。

## 硬件（Hardware）

nRF9131 EK有两个外部振荡器，低速时钟频率32.768 kHz，主时钟频率32 MHz。

<a id="security-components"></a>

### 安全组件（Security Components）


- <a id="id3"></a>

  实现定义的归属单元（[IDAU](https://developer.arm.com/docs/100690/latest/attribution-units-sau-and-idau) / Implementation Defined Attribution Unit）[注1](#id2)。IDAU由系统保护单元（SPU / System Protection Unit）实现，用于定义安全与非安全存储器映射（Secure / Non-secure Memory Maps）。默认情况下，整个存储空间，包括Flash、SRAM及外设地址空间，都被定义为仅允许安全访问（Secure Access）。
- 安全启动（Secure Boot）。

<a id="building-secure-non-secure-zephyr-applications-with-arm-trustzone"></a>

### 使用Arm® TrustZone®构建安全／非安全Zephyr应用

<a id="id7"></a>

nRF9131应用可包含安全及非安全固件镜像。安全镜像可用Zephyr或Trusted Firmware-M（TF-M）[注3](#id6) 构建，非安全镜像始终使用Zephyr。以下分别介绍两种方案。（[可信固件M（TF-M / Trusted Firmware M）](https://www.trustedfirmware.org/projects/tf-m/)）

注意（Note）

默认使用TF-M构建nRF9131安全镜像。

<a id="building-the-secure-firmware-using-zephyr"></a>

#### 使用Zephyr构建安全固件

该过程包含以下步骤：


1. 使用-DBOARD=nrf9131ek/nrf9131，并在应用项目配置文件中设置CONFIG_TRUSTED_EXECUTION_SECURE=y，构建安全Zephyr应用。
2. 使用-DBOARD=nrf9131ek/nrf9131/ns构建非安全Zephyr应用。
3. 将两个二进制文件合并。

<a id="building-the-secure-firmware-with-tf-m"></a>

#### 使用TF-M构建安全固件（Secure Firmware）

使用TF-M构建安全镜像、使用Zephyr构建非安全镜像的过程如下：


1. 使用-DBOARD=nrf9131ek/nrf9131/ns构建非安全Zephyr应用。Zephyr构建系统要求启用Kconfig选项BUILD_WITH_TFM才会构建TF-M；构建非安全应用时默认启用。构建系统会自动执行以下步骤：

  > - 按常规Zephyr应用构建非安全固件镜像
  > - 构建TF-M安全固件镜像（Secure Firmware Image）
  > - 合并输出的二进制文件
  > - 按需构建引导加载程序镜像（MCUboot）

注意（Note）

根据TF-M配置，可能需要应用设备树覆盖文件（DTS Overlay）来调整非安全镜像的闪存及SRAM起始地址与大小。

构建安全／非安全应用（Secure / Non-Secure Application）时，安全应用必须配置IDAU（SPU），使非安全应用固件用到的所有CPU资源允许非安全访问（Non-Secure Access）。SPU配置必须在跳转到非安全应用之前完成。
