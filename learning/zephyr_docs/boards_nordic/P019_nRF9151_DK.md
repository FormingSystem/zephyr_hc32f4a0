## 概述（Overview）

nRF9151 DK（PCA10171）是用于评估和开发nRF9151 SiP的单板开发套件，支持DECT NR+、LTE-M／NB-IoT及GNSS。nrf9151dk/nrf9151开发板配置支持Nordic Semiconductor nRF9151 ARM Cortex-M33F CPU及ARMv8-M安全扩展。

<a id="id5"></a>

开发板更多信息见[nRF9151网站](https://www.nordicsemi.com/Products/nRF9151) [注2](#id4)。

<a id="hardware"></a>

## 硬件（Hardware）

nRF9151 DK有两个外部振荡器，低速时钟频率32.768 kHz，主时钟频率32 MHz。

<a id="security-components"></a>

### 安全组件（Security Components）


- <a id="id3"></a>

  实现定义的归属单元（[IDAU](https://developer.arm.com/docs/100690/latest/attribution-units-sau-and-idau) / Implementation Defined Attribution Unit）[注1](#id2)。IDAU由系统保护单元（SPU / System Protection Unit）实现，用于定义安全与非安全存储器映射（Secure / Non-secure Memory Maps）。默认情况下，整个存储空间，包括Flash、SRAM及外设地址空间，都被定义为仅允许安全访问（Secure Access）。
- 安全启动（Secure Boot）。

<a id="building-secure-non-secure-zephyr-applications-with-arm-trustzone"></a>

### 使用Arm® TrustZone®构建安全／非安全Zephyr应用

该过程包含以下步骤：


1. 使用-DBOARD=nrf9151dk/nrf9151，并在应用项目配置文件中设置CONFIG_TRUSTED_EXECUTION_SECURE=y，构建安全Zephyr应用。
2. 使用-DBOARD=nrf9151dk/nrf9151/ns构建非安全Zephyr应用。
3. 将两个二进制文件合并。

构建安全／非安全应用（Secure / Non-Secure Application）时，安全应用必须配置IDAU（SPU），使非安全应用固件用到的所有CPU资源允许非安全访问（Non-Secure Access）。SPU配置必须在跳转到非安全应用之前完成。

<a id="building-a-secure-only-application"></a>

### 构建仅安全态应用（Building a Secure Only Application）

<a id="flashing"></a>

### 烧录（Flashing）

按照[Nordic nRF5x Segger J-Link](../debugging/P005_Nordic_Segger_JLink.md#nordic-segger)页面安装并配置所需软件，更多信息见[烧录（Flashing）](../debugging/P005_Nordic_Segger_JLink.md#nordic-segger-flashing)。随后按常规方式构建和烧录应用；详见[构建应用（Building an Application）](../application/P001_应用开发.md#build-an-application)和[运行应用（Run an Application）](https://docs.zephyrproject.org/latest/develop/application/index.html#application-run)。

下面以[Hello World](../getting_started/P005_HelloWorld示例.md#hello_world)应用为例。

首先运行常用终端程序查看输出。

```text
$ minicom -D <tty_device> -b 115200
```

将`<tty_device>`替换为nRF9151 DK所在串口，例如Linux下的/dev/ttyACM0。

随后按通常方式构建并烧录应用。

```text
# From the root of the zephyr repository
west build -b nrf9151dk/nrf9151 samples/hello_world
west flash
```
