## 概述（Overview）

nRF52833开发套件PCA10100支持Nordic Semiconductor nRF52833 ARM Cortex-M4F CPU。

<a id="id3"></a>

<a id="id6"></a>

开发板更多信息见[nRF52833 DK网站](https://www.nordicsemi.com/Software-and-Tools/Development-Kits/nRF52833-DK) [注1](#id2)；nRF52833产品规格书 [注2](#id5) 提供处理器信息及数据手册。（[nRF52833产品规范（Product Specification）](https://docs.nordicsemi.com/bundle/ps_nrf52833/page/keyfeatures_html5.html)）

<a id="hardware"></a>

## 硬件（Hardware）

nRF52833 DK有两个外部振荡器，低速时钟频率32.768 kHz，主时钟频率32 MHz。

<a id="supported-features"></a>

### 支持的功能（Supported Features）

片上／板载（On-Chip / On-Board）

功能集成在片上系统（SoC）内／位于开发板上。

与此功能匹配的设备树绑定兼容字符串（Compatible String）；点击链接可查看绑定文档。

<a id="changing-uart1-pins"></a>

## 更改UART1引脚（Pins）

应用需要为UART1使用另一组引脚时，可采用以下方法：


1. 在应用主目录中添加设备树覆盖文件（Devicetree Overlay）：

  ```text
  &pinctrl {
     uart1_default_alt: uart1_default_alt {
        group1 {
           psels = <NRF_PSEL(UART_TX, 0, 14)>,
                   <NRF_PSEL(UART_RX, 0, 16)>;
        };
     };
     /* required if CONFIG_PM_DEVICE=y */
     uart1_sleep_alt: uart1_sleep_alt {
        group1 {
           psels = <NRF_PSEL(UART_TX, 0, 14)>,
                   <NRF_PSEL(UART_RX, 0, 16)>;
           low-power-enable;
        };
     };
  };

  &uart1 {
    pinctrl-0 = <&uart1_default_alt>;
    /* if sleep state is not used, use /delete-property/ pinctrl-1; and
     * skip the "sleep" entry.
     */
    pinctrl-1 = <&uart1_sleep_alt>;
    pinctrl-names = "default", "sleep";
  };
  ```

  上述覆盖文件使用P0.16作为RX、P0.14作为TX。

更多细节见[设置设备树覆盖文件（Set Devicetree Overlays）](../devicetree/P006_设备树操作指南.md#set-devicetree-overlays)。

<a id="selecting-the-pins"></a>

### 选择引脚（Selecting the Pins）

<a id="id7"></a>

可在开发板的引脚控制文件（pinctrl）中配置引脚。要查看可用映射，打开nRF52833产品规范[注2](#id5)的第7章“Hardware and Layout（硬件与布局）”，在表7.1.1“aQFN73 ball assignments（aQFN73焊球分配）”中选择标为“General purpose I/O（通用I/O）”的引脚。标为“low frequency I/O only（仅低频I/O）”的引脚只能用于低于10 kHz的应用，不适合115200波特率UART。（[nRF52833产品规范（Product Specification）](https://docs.nordicsemi.com/bundle/ps_nrf52833/page/keyfeatures_html5.html)）
