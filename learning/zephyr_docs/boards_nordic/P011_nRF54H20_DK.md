## 概述（Overview）

注意（Note）

原文说明：nRF54H20 SoC的全部软件仍属试验性（Experimental），硬件仅向有限样片计划的参与者提供。

nRF54H20 DK是用于评估和开发Nordic nRF54H20 SoC的单板开发套件。

nRF54H20是多核SoC，包含：


- Arm Cortex-M33内核，支持DSP指令、浮点单元（FPU）及Armv8-M安全扩展，最高运行频率320 MHz，称为应用核（Application Core）。
- Arm Cortex-M33内核，支持DSP指令、FPU及Armv8-M安全扩展，最高运行频率256 MHz，称为无线核（Radio Core）。
- Nordic VPR RISC-V内核，称为ppr核，即外设处理器（Peripheral Processor）。

nrf54h20dk/nrf54h20/cpuapp构建目标支持应用核；nrf54h20dk/nrf54h20/cpurad支持无线核；nrf54h20dk/nrf54h20/cpuppr支持从RAM执行的PPR核；nrf54h20dk/nrf54h20/cpuppr/xip支持从磁阻随机存储器（MRAM）执行的PPR核。

## 硬件（Hardware）

nRF54H20 DK有两个晶体振荡器：


- 32 MHz高频晶体振荡器（HFXO）
- 32.768 kHz低频晶体振荡器（LFXO）

<a id="flashing"></a>

### 烧录（Flashing）

本节以[Hello World](../getting_started/P005_HelloWorld示例.md#hello_world)应用为例说明如何构建和烧录。

构建并将示例写入nRF54H20 DK时，按以下步骤操作：


1. 使用DK的IMCU USB端口，将nRF54H20 DK连接到计算机。
2. 安装[nRF Util](https://www.nordicsemi.com/Products/Development-tools/nrf-util)
3. 运行以下命令构建示例：

  ```text
  # From the root of the zephyr repository
  west build -b nrf54h20dk/nrf54h20/cpuapp samples/hello_world
  west flash
  ```
