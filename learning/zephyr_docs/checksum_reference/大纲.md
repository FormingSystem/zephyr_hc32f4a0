# 校验和目录与位反转参考大纲

本册翻译官方校验和（Checksum）主题目录、UBX编译期校验和头文件的参考与源码、位反转（Bit Reversal）接口及其头文件的参考与源码，共六份官方页面。校验和目录本身只有CRC主题入口，实际CRC说明沿用已有译文，未给目录页补造算法正文。

UBX校验和宏与CRC算法不同；位反转也不同于字节序交换。译文保留宏参数、原始展开、函数声明和返回值；源码跟踪译注说明宏参数数量、表达式使用边界，以及编译器内建、架构与通用C实现的选择顺序。

两个源码浏览页保留全部可见代码、注释、许可证、符号提示和对应行号锚点，中文对照另列。完整范围与待译状态见[全站进度](../PROGRESS.md)，相关资料见[数据工具主线](../data_utilities/大纲.md)。
