# 第129章\_nPM6001评估套件（EK）

原文：[官方页面](https://docs.zephyrproject.org/latest/boards/shields/npm6001_ek/doc/index.html)。读取日期：2026-10-16；来源摘要见[来源记录](../SOURCES.md)。

<a id="overview"></a>

## 概述（Overview）

nPM6001 EK可测试nPM6001电源管理集成电路PMIC的各种功能。

<a id="id2"></a>

![官方原图：nPM6001 EK](images/npm6001_ek.jpg)

nPM6001评估套件（EK）

<a id="requirements"></a>

## 前置要求（Requirements）

nPM6001 EK不能直接插入Arduino接口，但Zephyr定义按连接Arduino扩展接口设计；例如I2C线须接arduino_i2c总线，因此可配合任意支持Arduino接口的主板。

<a id="usage"></a>

## 用途（Usage）

调用west build时设置--shield npm6001_ek即可使用，完整示例见[nPM6001 EK](../shield_samples/P006_nPM6001电源评估套件示例.md#npm6001_ek)。
