# 第125章\_nPM1100评估套件（EK）

原文：[官方页面](https://docs.zephyrproject.org/latest/boards/shields/npm1100_ek/doc/index.html)。读取日期：2026-10-16；来源摘要见[来源记录](../SOURCES.md)。

<a id="overview"></a>

## 概述（Overview）

nPM1100 EK可测试nPM1100电源管理集成电路（PMIC）的各种功能。

<a id="id2"></a>

![官方原图：nPM1100 EK](images/npm1100_ek.jpg)

nPM1100评估套件（EK）

<a id="requirements"></a>

## 前置要求（Requirements）

nPM1100 EK不能直接插入Arduino接口，但Zephyr定义按连接Arduino扩展引脚设计，因此可配合任意支持Arduino连接器的主板，接线如下：

<table>
<tr>
<th>电源管理芯片PMIC引脚</th>
<th>Arduino引脚</th>
</tr>
<tr>
<td>ISET及MODE</td>
<td>D2及D3</td>
</tr>
</table>

<a id="usage"></a>

## 用途（Usage）

调用west build时设置--shield npm1100_ek，即可在应用中使用。
