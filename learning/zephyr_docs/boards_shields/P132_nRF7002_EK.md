# 第132章\_nRF7002评估套件（EK）

原文：[官方页面](https://docs.zephyrproject.org/latest/boards/shields/nrf7002ek/doc/index.html)。读取日期：2026-10-16；来源摘要见[来源记录](../SOURCES.md)。

<a id="overview"></a>

## 概述（Overview）

nRF7002 EK采用Arduino扩展板形态，兼容Nordic及其他厂商的主板。

nRF7002 EK基于nRF7002 SoC，为主机提供低功耗Wi-Fi 6及2.4／5 GHz双频，可接入Wi-Fi并用于Wi-Fi定位，例如嗅探附近热点SSID。

<a id="id1"></a>

![官方原图：nRF7002 EK](images/nrf7002ek.png)

nRF7002评估套件（EK）

<a id="requirements"></a>

## 前置要求（Requirements）

nRF7002 EK可直接插入Arduino连接器，以SPI通信，可配合任意支持此连接器的主板。

<a id="prerequisites"></a>

### 前置条件（Prerequisites）

nRF70驱动需要二进制固件才能运行Wi-Fi，执行以下命令取得文件。

```text
west update
west blobs fetch nrf_wifi
```

<a id="usage"></a>

## 用途（Usage）

调用west build时设置--shield nrf7002ek，即可在应用中使用。

<a id="sr-co-existence"></a>

## 短距离无线共存（SR Co-existence）

主板支持时，nRF7002 EK可使用SR共存，相关引脚连接主板GPIO；构建时设置--shield nrf7002ek_coex选择此接口。

可用以下2个Kconfig选项启用SR共存：


- [CONFIG_NRF70_SR_COEX](https://docs.zephyrproject.org/latest/kconfig.html#CONFIG_NRF70_SR_COEX)：启用SR共存驱动
- [CONFIG_NRF70_SR_COEX_RF_SWITCH](https://docs.zephyrproject.org/latest/kconfig.html#CONFIG_NRF70_SR_COEX_RF_SWITCH)：控制SR侧射频开关

<a id="shield-variants"></a>

## 扩展板变体（Shield Variants）

nRF7002 EK有4种变体：


- nrf7002ek：默认变体
- nrf7002ek_nrf7001：用于nRF7001或模拟nRF7001的nRF7002，仅支持2.4 GHz Wi-Fi
- nrf7002ek_nrf7000：用于nRF7000或模拟nRF7000的nRF7002，原文说明仅支持2.4 GHz Wi-Fi
- nrf7002ek_coex：SR共存接口变体
