# 第126章\_nPM1300评估套件（EK）

原文：[官方页面](https://docs.zephyrproject.org/latest/boards/shields/npm1300_ek/doc/index.html)。读取日期：2026-10-16；来源摘要见[来源记录](../SOURCES.md)。

<a id="overview"></a>

## 概述（Overview）

nPM1300 EK可测试nPM1300电源管理集成电路PMIC的各种功能。

<a id="requirements"></a>

## 前置要求（Requirements）

nPM1300 EK不能直接插入Arduino接口，但Zephyr定义按连接Arduino扩展接口设计；例如I2C线须接arduino_i2c总线，因此可配合任意支持Arduino接口的主板。

<a id="usage"></a>

## 用途（Usage）

调用west build时设置--shield npm1300_ek即可使用，完整示例见[nPM13xx EK](../shield_samples/P004_nPM13xx电源评估套件示例.md#npm13xx_ek)。
