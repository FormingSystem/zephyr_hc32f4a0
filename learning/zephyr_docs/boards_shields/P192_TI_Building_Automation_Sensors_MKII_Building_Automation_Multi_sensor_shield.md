# 第192章\_TI Building Automation Sensors MKII：楼宇自动化多传感器扩展板

原文：[官方页面](https://docs.zephyrproject.org/latest/boards/shields/ti_bp_bassensorsmkii/doc/index.html)。读取日期：2026-10-16；来源摘要见[来源记录](../SOURCES.md)。

<a id="overview"></a>

## 概述（Overview）

BP-BASSENSORSMKII是采用TI BoosterPack扩展板布局的运动MEMS及环境传感器扩展板。

<a id="id2"></a>

更多信息见TI BP-BASSENSORSMKII网站[注1](#id1)。（[TI BP-BASSENSORSMKII 网站](https://www.ti.com/tool/BP-BASSENSORSMKII)）

<a id="hardware-description"></a>

## 硬件说明（Hardware Description）

BP-BASSENSORSMKII主要特性：

> - BMI160六轴惯性测量单元（IMU）
> - BMM150连接BMI160，用于传感器集线器（Sensor Hub）
> - TI OP3001环境光传感器
> - TI DR5055霍尔效应传感器（Hall Effect Sensor）
> - TI HDC2080温湿度传感器
> - TI TMP117超高精度温度传感器，带可分离子板
> - 支持TI LaunchPad
> - 符合RoHS
