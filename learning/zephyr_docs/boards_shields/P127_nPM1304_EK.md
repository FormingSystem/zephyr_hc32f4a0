# 第127章\_nPM1304评估套件（EK）

原文：[官方页面](https://docs.zephyrproject.org/latest/boards/shields/npm1304_ek/doc/index.html)。读取日期：2026-10-16；来源摘要见[来源记录](../SOURCES.md)。

<a id="overview"></a>

## 概述（Overview）

nPM1304 EK可测试nPM1304电源管理集成电路PMIC的各种功能。

<a id="requirements"></a>

## 前置要求（Requirements）

nPM1304 EK不能直接插入Arduino接口，但Zephyr定义要求连接Arduino扩展接口，即将I2C线接arduino_i2c总线，因此可配合任意支持Arduino接口的主板。

<a id="usage"></a>

## 用途（Usage）

在应用中使用时，按以下命令构建：

```text
west build -b your_board --shield npm1304_ek
```

完整示例见[nPM13xx EK](../shield_samples/P004_nPM13xx电源评估套件示例.md#npm13xx_ek)。
