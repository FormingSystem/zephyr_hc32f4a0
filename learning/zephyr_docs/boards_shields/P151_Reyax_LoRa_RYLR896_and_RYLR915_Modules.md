# 第151章\_Reyax LoRa RYLR896及RYLR915模块

原文：[官方页面](https://docs.zephyrproject.org/latest/boards/shields/reyax_lora/doc/index.html)。读取日期：2026-10-16；来源摘要见[来源记录](../SOURCES.md)。

<a id="overview"></a>

## 概述（Overview）

这些模块为实现LoRa物理层（PHY）的Semtech SX1276提供简单的UART接口。

<a id="id2"></a>

更多信息见[Reyax RYLR页面](https://reyax.com/products/RYLR896)[注1](#id1)。

<a id="hardware-description"></a>

## 硬件说明（Hardware Description）

原文称模块有4个引脚；下列清单实际列出5个：


- VDD：电源
- NRST：低有效复位
- RXD：串行数据输入
- TXD：串行数据输出
- GND：地
