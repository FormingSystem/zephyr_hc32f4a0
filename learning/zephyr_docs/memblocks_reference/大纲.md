# 内存块分配器参考大纲

本册翻译内存块分配器（Memory Blocks Allocator）公共API及头文件参考。使用外部位图管理固定大小块，既支持普通多块请求，也支持连续块和指定地址占用；多分配器组的选择回调只返回分配器，随后由包装执行分配。

先读[内存块分配器指南](../kernel/P025_内存块分配器.md)。原始声明、宏展开、参数和返回值完整保留；源码译注分别说明失败回滚、输出指针、部分释放及组配置边界。仓库链接使用相对路径；源码浏览另见[内存块头文件源码](../memory_source_reference/P002_内存块头文件源码.md)，逐页覆盖状态见[全站进度](../PROGRESS.md)。
