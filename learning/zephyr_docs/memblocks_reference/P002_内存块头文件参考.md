## 2.4\_详细说明（Detailed Documentation）

<a id="a0a18ac0266ab6532cdd93302ca012112"></a>

### `MAX_MULTI_ALLOCATORS`

```c
#define MAX_MULTI_ALLOCATORS 8
```

> 译注——源码核对：当前值为8，是一个分配器组可保存的成员指针数量，不是一个分配器的内存块数量。超过组容量触发添加函数中的断言，不是动态扩容。

## 2.5\_源码定位与版本边界

先读[内存块分配器指南](../kernel/P025_内存块分配器.md)，再与[固定块内存池Slab接口](../heap_reference/P003_固定块内存池公共接口.md)对照。块数、字节数、连续性及位图状态是不同概念。

源码定位：[mem_blocks.h](../../../include/zephyr/sys/mem_blocks.h)、[mem_blocks.c](../../../lib/mem_blocks/mem_blocks.c)、[bitarray.h](../../../include/zephyr/sys/bitarray.h)、[bitarray.c](../../../lib/utils/bitarray.c)及[util.h](../../../include/zephyr/sys/util.h)；官方依据为[内存块头文件](https://github.com/zephyrproject-rtos/zephyr/blob/main/include/zephyr/sys/mem_blocks.h)、[内存块实现](https://github.com/zephyrproject-rtos/zephyr/blob/main/lib/mem_blocks/mem_blocks.c)、[位图头文件](https://github.com/zephyrproject-rtos/zephyr/blob/main/include/zephyr/sys/bitarray.h)、[位图实现](https://github.com/zephyrproject-rtos/zephyr/blob/main/lib/utils/bitarray.c)和[取整工具](https://github.com/zephyrproject-rtos/zephyr/blob/main/include/zephyr/sys/util.h)。

CONFIG_SYS_MEM_BLOCKS启用实现，运行时统计和通知分别受CONFIG_SYS_MEM_BLOCKS_RUNTIME_STATS、CONFIG_SYS_MEM_BLOCKS_LISTENER控制。配置及编译依据见[仓库Kconfig](../../../lib/mem_blocks/Kconfig)、[CMakeLists.txt](../../../lib/mem_blocks/CMakeLists.txt)和[官方Kconfig](https://github.com/zephyrproject-rtos/zephyr/blob/main/lib/mem_blocks/Kconfig)、[官方构建文件](https://github.com/zephyrproject-rtos/zephyr/blob/main/lib/mem_blocks/CMakeLists.txt)。

> 译注——同步与事件边界：底层位图的分配、释放和测试设置在自身自旋锁内进行；启用统计时，内存块层还有统计更新锁。这不把普通多块循环变成一个不可分割的事务，也不保护分配器组的任意并发重配置。分配失败回滚可能产生配对通知，事件不能直接等同于成功的应用请求。监听规则见[堆事件监听接口](../lowheap_reference/P003_堆事件监听接口.md)。
