# 驱动与工作队列跟踪接口大纲

本册完整翻译RTIO、GPIO、设备运行时电源管理、系统电源管理及四类工作项／工作队列跟踪接口，共八份官方页面。跟踪钩子（Tracing Hooks）用于记录API入口、阻塞、出口和生命周期事件，具体记录行为由后端实现。

各页保留宏签名、摘要、完整参数说明与交叉引用。源码译注说明配置与后端、事件位置、返回值语义及原文和调用点的差异，避免把API返回误认作硬件完成，或把所有钩子当成必然成对出现的计时记录。

本地源码使用相对链接，保留中英文术语和原始许可证；本册不加入作者机器的采集环境或实板步骤。完整范围见[全站进度](../PROGRESS.md)。
