## 概述（Overview）

ACP 7.0是AMD片上系统（SoC）中的音频协处理器，基于HiFi5 DSP Xtensa架构。Zephyr OS已移植到该平台，用于在基于Sound Open Firmware（SOF）的框架上运行各种音频与语音用例。

SOF可以使用Zephyr或XCC工具链构建，并在AMD ACP 7.0平台上运行。

<a id="hardware"></a>

## 硬件（Hardware）


- 开发板特性（Board Features）：


  - RAM：2.5 MB高性能SRAM（HP SRAM），以及512 KB可配置指令／数据RAM（IRAM/DRAM）
  - 音频接口（Audio Interfaces）：

    > - 一路SoundWire（SDW）
    > - 一路HS，支持I2S和脉冲编码调制（PCM）
    > - 数字麦克风接口（DMIC）

<a id="xtensa-toolchain-optional"></a>

### Xtensa工具链（Toolchain），可选

Zephyr SDK提供基于GCC的工具链，可用于为AMD ACP开发板构建Zephyr。若需要更高程度的优化，也可考虑使用Cadence专有的Xtensa工具链。

以下说明假定已按照Xtensa文档，为开发板购买并安装所需工具链（Toolchains）和内核配置（Cores）。

若选择Xtensa工具链构建，而不是Zephyr SDK，除下列Xtensa工具链环境变量外，还需要设置针对开发板的环境变量。

首先，确保已从Cadence取得所需许可证（License），并按照Cadence说明设置许可证变量。然后设置以下环境变量：

最后三个变量是`acp_7_0`专用的。

```text
export XTENSA_TOOLCHAIN_PATH="tools installed path"
export XTENSA_BUILDS_DIR="user build directory path"
export ZEPHYR_TOOLCHAIN_VARIANT=Zephyr GCC
export TOOLCHAIN_VER=RI-2023.11-linux
export XTENSA_CORE=ACP_7_0_HiFi5_NNE_PROD
```

<a id="flashing"></a>

### 烧录（Flashing）

AMD仅支持通过ACP Linux驱动，在ACP 7.0平台烧录已签名的镜像（Signed Images）。

可在`dmesg`中观察到以下启动顺序消息：

> - `booting DSP firmware`
> - `ACP_DSP0_RUNSTALL : 0x0`
> - `ipc rx: 0x70000000`
> - `Firmware info: version 2:14:99-b5961`
> - `Firmware: ABI 3:29:1 Kernel ABI 3:23:0`
> - `mailbox upstream 0x0 - size 0x400`
> - `mailbox downstream 0x400 - size 0x400`
> - `stream region 0x1000 - size 0x400`
> - `debug region 0x800 - size 0x400`
> - `fw_state change: 3 -> 6`
> - `ipc rx done: 0x70000000`
> - `firmware boot complete`
