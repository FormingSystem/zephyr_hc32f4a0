# 第33章\_zephyr_sensing

原文：[官方页面](https://docs.zephyrproject.org/latest/build/dts/api/bindings/sensor/zephyr,sensing.html)。读取日期：2026-10-16；来源摘要见[来源记录](../SOURCES.md)。

<a id="zephyr-sensing"></a>
<a id="dtbinding-zephyr-sensing"></a>
<a id="std-dtcompatible-zephyr-sensing"></a>

兼容字符串（Compatible String）：`zephyr,sensing`。厂商：[ Zephyr Project ](https://docs.zephyrproject.org/latest/build/dts/api/bindings.html#dt-vendor-zephyr)。

采用此设备树绑定（Devicetree Binding）的开发板见[官方筛选目录](https://docs.zephyrproject.org/latest/boards/index.html#compatibles=zephyr,sensing)。

<a id="description"></a>

感知子系统（Sensing Subsystem）。

<a id="properties"></a>

属性类型：`int` 为整数，`boolean` 为布尔属性，`string` 为字符串，`string-array` 为字符串数组，`array` 为数值数组，`uint8-array` 为8位无符号整数数组，`compound` 为复合类型；`phandle` 为节点引用（Phandle），`phandles` 为节点引用列表，`phandle-array` 为节点引用与说明符单元数组。
