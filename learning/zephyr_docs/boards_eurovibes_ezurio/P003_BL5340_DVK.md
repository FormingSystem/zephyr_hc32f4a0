## 概述（Overview）

BL5340开发套件支持Ezurio BL5340模块，该模块采用Nordic Semiconductor nRF5340双核Arm Cortex-M33F CPU。BL5340中的nRF5340是基于Arm Cortex-M33架构的双核片上系统（SoC），包括：


- 功能完整的Arm Cortex-M33F内核，支持数字信号处理指令（DSP）、浮点单元（FPU）和Armv8-M安全扩展（Security Extension），最高128 MHz，称为应用核（Application Core）。
- 功能精简的次级Arm Cortex-M33内核，固定运行于64 MHz，称为网络核（Network Core）。

`bl5340_dvk/nrf5340/cpuapp`构建目标支持BL5340模块的应用核，`bl5340_dvk/nrf5340/cpunet`支持网络核。若使用Arm TrustZone，原文称`bl5340_dvk/nrf5340/cpuapp`目标支持应用核的非安全分区（Non-Secure Partition）；实际非安全构建目标见后文的`/ns`说明。

该开发套件（Development Kit）具有以下特性：


- 模数转换器（ADC）
- 时钟（CLOCK）
- 闪存（FLASH）
- 通用输入输出（GPIO）
- 实现定义的归属单元（IDAU）
- 集成电路间总线（I2C）
- 集成电路间音频总线（I2S）
- 存储器保护单元（MPU）
- 嵌套向量中断控制器（NVIC）
- 脉宽调制（PWM）
- 四线串行外设接口（QSPI）
- 无线电（RADIO），支持低功耗蓝牙（Bluetooth Low Energy）和IEEE 802.15.4
- 实时时钟（RTC）
- Segger实时传输（RTT，RTT控制台 / RTT Console）
- 串行外设接口（SPI）
- 带EasyDMA的通用异步收发器（UARTE）
- 通用串行总线（USB）
- 看门狗定时器（WDT）

### 连接与输入输出（Connections and IOs）

一个8引脚GPIO端口扩展器（Port Expander）为BL5340模块提供额外输入输出。

<a id="id11"></a>

更多细节见TI TCA9538数据手册[注4](#id10)。（[TI TCA9538数据手册（Datasheet）](https://www.ti.com/lit/gpn/TCA9538)）

<a id="leds"></a>

#### 发光二极管（LEDs）


- LED1 （蓝色 / blue） = 通过TCA9538端口扩展器通道 P4 （低电平有效 / active low）
- LED2 （蓝色 / blue） = 通过TCA9538端口扩展器通道 P5 （低电平有效 / active low）
- LED3 （蓝色 / blue） = 通过TCA9538端口扩展器通道 P6 （低电平有效 / active low）
- LED4 （蓝色 / blue） = 通过TCA9538端口扩展器通道 P7 （低电平有效 / active low）

<a id="push-buttons"></a>

#### 按键（Push Buttons）


- BUTTON1 = SW1 = 通过TCA9538端口扩展器通道 P0 （低电平有效 / active low）
- BUTTON2 = SW2 = 通过TCA9538端口扩展器通道 P1 （低电平有效 / active low）
- BUTTON3 = SW3 = 通过TCA9538端口扩展器通道 P2 （低电平有效 / active low）
- BUTTON4 = SW4 = 通过TCA9538端口扩展器通道 P3 （低电平有效 / active low）
- BOOT = 启动（Boot），低电平有效（Active Low）

BL5340应用核支持Armv8-M安全扩展。为`bl5340_dvk/nrf5340/cpuapp`开发板构建的应用默认以安全状态（Secure State）启动。

<a id="building-secure-non-secure-zephyr-applications-with-arm-trustzone"></a>

### 使用Arm® TrustZone®构建安全／非安全Zephyr应用

<a id="id33"></a>

BL5340模块的应用可为应用核包含安全（Secure）和非安全（Non-Secure）两个固件镜像。安全镜像可用Zephyr或可信固件M（TF-M / [Trusted Firmware M](https://www.trustedfirmware.org/projects/tf-m/)，[注15](#id32)）构建，非安全镜像始终使用Zephyr构建。下文分别说明这两种方案。

注意（Note）

BL5340应用核的安全镜像默认使用TF-M构建。

<a id="building-the-secure-firmware-with-tf-m"></a>

#### 使用TF-M构建安全固件（Secure Firmware）

用TF-M构建安全镜像、用Zephyr构建非安全镜像，需要以下步骤：


1. 使用`-DBOARD=bl5340_dvk/nrf5340/cpuapp/ns`构建应用核的非安全Zephyr应用。要触发TF-M构建，Zephyr构建系统要求启用Kconfig选项`BUILD_WITH_TFM`；将Zephyr构建为非安全应用时默认启用此选项。构建系统会自动执行以下步骤：

  > - 按常规Zephyr应用构建非安全固件镜像
  > - 构建TF-M安全固件镜像（Secure Firmware Image）
  > - 合并生成的二进制镜像
  > - 按需构建引导加载程序镜像（MCUboot）

注意（Note）

根据TF-M配置，可能需要应用设备树覆盖文件（DTS Overlay）来调整非安全镜像的闪存及SRAM起始地址与大小。


1. 使用`-DBOARD=bl5340_dvk/nrf5340/cpunet`构建网络核的应用固件。

<a id="building-the-secure-firmware-using-zephyr"></a>

#### 使用Zephyr构建安全固件

使用Zephyr同时构建安全及非安全固件镜像，需要以下步骤：


1. 使用`-DBOARD=bl5340_dvk/nrf5340/cpuapp`构建应用核的安全Zephyr应用，并在应用工程配置文件中设置`CONFIG_TRUSTED_EXECUTION_SECURE=y`和`CONFIG_BUILD_WITH_TFM=n`。
2. 使用`-DBOARD=bl5340_dvk/nrf5340/cpuapp/ns`构建应用核的非安全Zephyr应用。
3. 将两个二进制文件合并。
4. 使用`-DBOARD=bl5340_dvk/nrf5340/cpunet`构建网络核的应用固件。

为BL5340应用核构建安全／非安全应用时，安全应用必须配置IDAU（SPU），允许非安全固件以非安全方式访问其使用的全部CPU资源。必须先完成SPU配置，再跳转到非安全应用。

<a id="building-a-secure-only-application"></a>

### 构建仅安全态应用（Building a Secure Only Application）

按常规方法构建Zephyr应用，详见构建应用及运行应用。应用核运行的固件使用`-DBOARD=bl5340_dvk/nrf5340/cpuapp`，网络核固件使用`-DBOARD=bl5340_dvk/nrf5340/cpunet`。（[构建应用（Building an Application）](../application/P001_应用开发.md#build-an-application)；[运行应用（Run an Application）](https://docs.zephyrproject.org/latest/develop/application/index.html#application-run)）

<a id="flashing"></a>

### 烧录（Flashing）

按照[Nordic nRF5x Segger J-Link](../debugging/P005_Nordic_Segger_JLink.md#nordic-segger)页面安装并配置所需软件；更多信息见[烧录（Flashing）](../debugging/P005_Nordic_Segger_JLink.md#nordic-segger-flashing)。随后即可按常规方式构建和烧录应用，详见构建应用及运行应用。（[构建应用（Building an Application）](../application/P001_应用开发.md#build-an-application)；[运行应用（Run an Application）](https://docs.zephyrproject.org/latest/develop/application/index.html#application-run)）

警告（Warning）

BL5340具有闪存读回保护（Flash Read-Back Protection）。启用保护时，重新烧录前必须恢复芯片（Recover）。使用[west](https://docs.zephyrproject.org/latest/develop/west/build-flash-debug.html#west-build-flash-debug)烧录时，运行以下命令查看相关`--recover`选项的详细信息：

```text
west flash -H -r nrfjprog --no-rebuild
```

注意（Note）

烧录及调试BL5340 DVK上的应用，需要将nRF命令行工具（nRF Command Line Tools）升级至10.12.0或更新版本，安装方法见烧录章节。（[烧录（Flashing）](../debugging/P005_Nordic_Segger_JLink.md#nordic-segger-flashing)）

下面以运行在BL5340应用核上的[Hello World](../getting_started/P005_HelloWorld示例.md#hello_world)应用为例。

首先运行常用终端程序查看输出。

```text
$ minicom -D <tty_device> -b 115200
```

将`<tty_device>`替换为BL5340 DVK对应的串口，例如Linux下的`/dev/ttyACM0`。

随后按通常方式构建并烧录应用。

```text
# From the root of the zephyr repository
west build -b bl5340_dvk/nrf5340/cpuapp samples/hello_world
west flash
```
