# 蓝牙经典音频与遥控数据结构参考大纲

本册完整翻译A2DP（高级音频分发配置文件，Advanced Audio Distribution Profile）、AVDTP（音视频分发传输协议，Audio/Video Distribution Transport Protocol）、AVRCP（音视频远程控制配置文件，Audio/Video Remote Control Profile）及蓝牙地址的72份官方结构体页面。包括音频流与端点、控制端（Controller，CT）、目标端（Target，TG）、封面图（Cover Art）、浏览与播放器命令、事件和响应数据。

成员符号与声明保留原名，正文保留必需的参数约束、回调时机、错误状态和大端字节序（Big-endian）要求。尚未完成的独立协议主题和头文件继续在全站清单中标为待译。
