# RTIO寄存器访问与工作队列参考大纲

本册完整翻译实时输入输出（Real-Time I/O，RTIO）的寄存器映射（Register Map）与工作队列（Work Queue）相关七份官方页面：两个头文件各自的参考和源码浏览页，以及寄存器配置、寄存器列表和工作请求三个结构体页。

前半册追踪如何把非连续寄存器列表转换为总线请求链，后半册说明如何在工作线程中执行阻塞操作。各页保留原始声明、示例、代码与交叉引用，源码页附注释和符号提示的中文对照。

明确标注的译注说明地址与缓冲区、请求池容量、异步生命周期、回调及调度边界；官方示例拼写差异原样保留并说明。本地源码与媒体链接遵循相对路径要求，不加入本机实验步骤。相关概念见[RTIO核心接口](../rtio_core_reference/大纲.md)，完整范围见[全站进度](../PROGRESS.md)。
