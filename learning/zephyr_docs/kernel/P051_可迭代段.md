# 第51章\_可迭代段

原文：[Iterable Sections](https://docs.zephyrproject.org/latest/kernel/iterable_sections/index.html)。读取日期：2026-10-12，`latest`。

**可迭代段（Iterable Section）**接口用于定义由等大小结构实例组成的区域，并通过 `STRUCT_SECTION_FOREACH` 遍历。

## 51.1\_概述

可迭代段由同一种结构的静态实例组成，链接器把它们放进一个连续输出段。运行时便可遍历全部实例，无须维护显式列表。

Zephyr 当前有两条链接脚本处理路径：模板路径消费通过 `zephyr_linker_sources()` 登记的 `.ld` 脚本；CMake 生成路径消费 `zephyr_iterable_section()` 调用。要兼容全部支持的工具链，新可迭代段目前必须在两处都声明。

`CONFIG_CMAKE_LINKER_GENERATOR=y` 时，可迭代输出段由 `zephyr_iterable_section()` 生成，忽略已登记 `.ld` 片段中的 `ITERABLE_SECTION_RAM/ROM` 定义；该配置为 `n` 时相反，由 `.ld` 提供定义，不消费前一种 CMake 声明。上游 Zephyr 必须在两种配置下构建，因此不能只写其中一份。

需要协调三部分内容，它们的结构名称和 **随机存取存储器（Random Access Memory，RAM）**/**只读存储器（Read-Only Memory，ROM）** 放置必须一致：C 代码定义结构并用 `STRUCT_SECTION_ITERABLE` 创建实例；CMake 用 `zephyr_iterable_section()` 指定输出位置；链接脚本用 `ITERABLE_SECTION_RAM/ROM` 定义段并通过 `zephyr_linker_sources()` 登记。

## 51.2\_第一步：在C中定义数据

在公共头文件定义结构和实例声明辅助宏：

```c
struct my_data {
         int a, b;
};

#define DEFINE_DATA(name, _a, _b) \
         STRUCT_SECTION_ITERABLE(my_data, name) = { \
                 .a = _a, \
                 .b = _b, \
         }

...

DEFINE_DATA(d1, 1, 2);
DEFINE_DATA(d2, 3, 4);
DEFINE_DATA(d3, 5, 6);
```

若实例常驻 ROM，必须声明为 `const`，让编译器生成只读输入段。C 声明与后续 CMake 放置必须一致选择 RAM 或 ROM。

## 51.3\_第二步：在CMake中声明段

`zephyr_iterable_section()` 的 `NAME` 必须与传给 `STRUCT_SECTION_ITERABLE` 的结构名称一致；`GROUP` 选择输出段所在的链接组。

RAM 常驻示例：

```cmake
# CMakeLists.txt
zephyr_iterable_section(NAME my_data GROUP DATA_REGION ${XIP_ALIGN_WITH_INPUT})
```

ROM 常驻示例，对应 C 实例声明为 `const`：

```cmake
# CMakeLists.txt
zephyr_iterable_section(NAME my_data GROUP RODATA_REGION)
```

完整参数及可用 `GROUP` 说明见 `cmake/modules/extensions.cmake` 中的 `zephyr_iterable_section()`。

## 51.4\_第三步：提供链接脚本

模板链接路径使用 `ITERABLE_SECTION_RAM` 或 `ITERABLE_SECTION_ROM` 生成实际段。RAM 示例：

```c
/* sections-ram.ld */
#include <zephyr/linker/iterable_sections.h>

ITERABLE_SECTION_RAM(my_data, Z_LINK_ITERABLE_SUBALIGN)
```

ROM 示例：

```c
/* sections-rom.ld */
#include <zephyr/linker/iterable_sections.h>

ITERABLE_SECTION_ROM(my_data, Z_LINK_ITERABLE_SUBALIGN)
```

> 译注——当前源码的对齐参数：本次官方头文件中，六个 `ITERABLE_SECTION_ROM／RAM` 公共输出段宏保留 `subalign` 形参，但宏体未使用它。上方官方示例原样保留；不能仅凭传入 `Z_LINK_ITERABLE_SUBALIGN` 就推断已设置相应子段对齐。对象声明、链接段地址及输入布局应分别核对，参见[可遍历段接口参考](../iterable_reference/P001_可遍历段公共接口.md)。

在 `CMakeLists.txt` 登记链接脚本：

```cmake
zephyr_linker_sources(<location> <path-to-ld-file>)
```

完整参数及 `<location>` 的可用位置见 `cmake/modules/extensions.cmake` 中的 `zephyr_linker_sources()`。原例中的位置和路径是占位符，需替换为实际选择。

## 51.5\_遍历条目

段设置完成后，通过 `STRUCT_SECTION_FOREACH` 逐项访问：

```c
STRUCT_SECTION_FOREACH(my_data, data) {
        printk("%p: a: %d, b: %d\n", data, data->a, data->b);
}
```

链接器按条目名称排序。因此不论实例在源码中怎样排列，此例都会依次访问 `d1`、`d2`、`d3`。
