# 第67章\_自旋锁头文件参考

原文：[spinlock_8h](https://docs.zephyrproject.org/latest/doxygen/html/spinlock_8h.html)。读取日期：2026-10-13，`latest`。

`zephyr/spinlock.h`提供自旋锁（Spinlock）的公共接口。原文件参考列出的包含项如下：

```c
#include <errno.h>
#include <stdbool.h>
#include <zephyr/arch/cpu.h>
#include <zephyr/sys/atomic.h>
#include <zephyr/sys/__assert.h>
#include <zephyr/sys/time_units.h>
```

## 67.1\_结构与锁键

`struct k_spinlock`为内核自旋锁（Kernel Spin Lock），见[结构参考](P066_自旋锁结构参考.md)。`k_spinlock_key_t`为自旋锁键类型（Spinlock Key Type），声明为：

```c
typedef struct z_spinlock_key k_spinlock_key_t;
```

## 67.2\_两个代码块宏

| 宏 | 原页用途 |
| --- | --- |
| `K_SPINLOCK(lck)` | 使用给定自旋锁保护代码块，在执行前自动取得锁。 |
| `K_SPINLOCK_BREAK` | 在释放锁之后离开受保护代码块；原展开为`continue`。 |

详细展开式、原用例和退出限制见[公共接口](P065_自旋锁公共接口.md)。

## 67.3\_三个函数

原声明的`static ALWAYS_INLINE`属性完整保留：

```c
static ALWAYS_INLINE k_spinlock_key_t k_spin_lock(struct k_spinlock *l);
static ALWAYS_INLINE int k_spin_trylock(struct k_spinlock *l, k_spinlock_key_t *k);
static ALWAYS_INLINE void k_spin_unlock(struct k_spinlock *l,
                                        k_spinlock_key_t key);
```

`k_spin_lock`取得自旋锁；`k_spin_trylock`尝试取得锁；`k_spin_unlock`释放锁。完整参数、返回值及嵌套约束见[公共接口](P065_自旋锁公共接口.md)，所有条件编译与实现见[源码页](P068_自旋锁头文件源码.md)。
