# 第33章\_线程局部存储

原文：[Thread Local Storage (TLS)](https://docs.zephyrproject.org/latest/kernel/services/other/thread_local_storage.html)。读取日期：2026-10-12，`latest`。

线程局部存储（Thread Local Storage，TLS）让变量按线程分别分配。变量存放在线程栈区域，每个线程都有自己的副本。Zephyr 当前要求工具链支持 TLS。

## 33.1\_配置

启用 `CONFIG_THREAD_LOCAL_STORAGE` 后可使用线程局部存储。若架构或 **片上系统（System on Chip，SoC）** 未启用隐藏选项 `CONFIG_ARCH_HAS_THREAD_LOCAL_STORAGE`，该选项可能不可见；这表示缺少相应架构/SoC 支持代码，或者工具链不支持 TLS。

同时启用 `CONFIG_ERRNO` 和 `CONFIG_ERRNO_IN_TLS`，可使 `errno` 成为线程局部变量，让用户线程无须系统调用即可读取自己的错误值。

## 33.2\_声明与使用

使用 `Z_THREAD_LOCAL` 宏声明。头文件中的外部声明可写为：

```c
extern Z_THREAD_LOCAL int i;
```

对应源文件中的实际定义为：

```c
Z_THREAD_LOCAL int i;
```

也可以加 `static`，把符号可见性限制在当前源文件：

```c
static Z_THREAD_LOCAL int j;
```

访问方式与普通变量相同，但每个线程读写的是自己的副本：

```c
void testing(void) {
    i = 10;
}
```
