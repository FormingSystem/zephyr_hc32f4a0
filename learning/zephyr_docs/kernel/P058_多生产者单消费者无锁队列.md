# 第58章\_多生产者单消费者无锁队列

原文：[Multi Producer Single Consumer Lock Free Queue](https://docs.zephyrproject.org/latest/kernel/data_structures/mpsc_lockfree.html)。读取日期：2026-10-12，`latest`。

多生产者单消费者无锁队列（Multi Producer Single Consumer，MPSC）是一种基于原子指针交换的侵入式无锁队列，采用 Dmitry Vyukov 在 [1024cores](https://www.1024cores.net/home/lock-free-algorithms/queues/intrusive-mpsc-node-based-queue) 描述的方法。

原页接口入口为[MPSC 无锁队列参考](../intercore_reference/P158_MPSC无锁队列接口.md)。

> 译注：原页只有上述概述及接口外链。本页完成的是该入口正文，**应用程序编程接口（Application Programming Interface，API）** 逐项参考仍作为独立待译页面。名称限定了生产者/消费者模型，不能直接扩展成多个并发消费者。
