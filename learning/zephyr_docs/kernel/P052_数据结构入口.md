# 第52章\_数据结构入口

原文：[Data Structures](https://docs.zephyrproject.org/latest/kernel/data_structures/index.html)。读取日期：2026-10-12，`latest`。

Zephyr 提供内核内部使用的通用**数据结构（Data Structure）**库，应用代码同样可以使用。它们包括保存有序数据的链表和平衡树，以及用于管理字节流的环形缓冲区。

这些容器通常采用侵入式设计：库只操作节点结构，节点不额外保存“它属于哪个用户数据对象”的指针或元数据。开发者将节点嵌入自定义结构，再借助宏从节点指针恢复外层结构地址。这样节点存储由使用者提供，容器也能用于禁止动态分配的场景。

这些库通常不提供同步，默认访问并非线程安全；它们是数据结构，所需锁由使用者提供。某些结构在限定使用场景下具有线程安全性，例如下列单生产者单消费者和多生产者单消费者无锁队列。
