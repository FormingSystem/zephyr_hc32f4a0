# 第57章\_环形队列

原文：[sys_ringq Data Structure](https://docs.zephyrproject.org/latest/kernel/data_structures/ringq.html)。读取日期：2026-10-12，`latest`。

**环形队列（Ring Queue）**把一个固定大小缓冲区视为首尾相接，用于按顺序缓存数据项。

## 57.1\_用途与并发

`sys_ringq` 面向固定大小的离散数据项，用于解耦生产者和消费者，不必处理部分读取或变长负载；它与面向字节流的[环形缓冲区](P019_环形缓冲区.md)用途不同。

`sys_ringq` 接口不提供并发控制。多个线程访问时，应用需要根据使用方式，通过互斥量、信号量等同步机制保护队列结构。

> 译注——源码对照：完整声明、宏、参数、返回值和源码见[环形队列参考册](../ringq_reference/大纲.md)。当前包装把字节环形缓冲区按item_size划分为固定项；容量／空闲量／有效量以项数返回，初始化区域与每项大小以字节给出。初始化会向下舍弃不足一项的尾部，舍入后须至少容纳一项。

> 译注——整项与同步：不要绕过包装向内部rb混入任意长度的字节流。当前put／get／peek只根据底层返回量是否为0判断成功，完整项边界依赖有效初始化及正确访问纪律；包装没有额外锁、等待或通知。默认新版底层get不支持NULL目标丢弃数据，目标区域应有效且至少容纳一项。源码依据与配置／版本边界见参考册，未执行实板或并发验证。

## 57.2\_实例化与使用

可通过 `SYS_RINGQ_DEFINE(name, item_size, item_capacity)` 静态定义，也可调用 `sys_ringq_init(struct sys_ringq *ringq, uint8_t *data, size_t data_size, size_t item_size)` 在运行时初始化：

```c
SYS_RINGQ_DEFINE(my_ringq, item_size, item_capacity);
/* equivalent to */

static struct sys_ringq my_ringq;
static uint8_t buffer[item_size * item_capacity];
void init_fn (void) {
   sys_ringq_init(&my_ringq, buffer, sizeof(buffer), item_size);
   ....
}
```

初始化后，`sys_ringq_put()` 添加一项，`sys_ringq_get()` 取出一项。队列保持数据项顺序，并检查底层缓冲区边界：

```c
struct my_item item_to_add = { ... };
struct my_item item_removed;

/* Add an item to the queue */
if (sys_ringq_put(&my_ringq, &item_to_add) == 0) {
    // Item added successfully
} else {
    // ringq is full
}

/* Remove an item from the queue */
if (sys_ringq_get(&my_ringq, &item_removed) == 0) {
    // Item removed successfully
} else {
    // ringq is empty
}
```

> 译注：例中 `item_size`、`item_capacity`、`struct my_item` 和省略号均为示意。实际条目大小应与输入输出对象可用存储一致；队列按配置大小复制，不会根据指针自动识别结构大小。

## 57.3\_状态接口

| 接口 | 含义 |
| --- | --- |
| `sys_ringq_capacity()` | 总容量，单位为数据项数量。 |
| `sys_ringq_empty()` | 无数据项时返回真。 |
| `sys_ringq_full()` | 无法再接收数据项时返回真。 |
| `sys_ringq_space()` | 剩余空槽数量。 |
| `sys_ringq_size()` | 当前已保存的数据项数量。 |
| `sys_ringq_reset()` | 将队列重置为空。 |
