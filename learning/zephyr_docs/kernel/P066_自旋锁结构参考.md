# 第66章\_自旋锁结构参考

原文：[structk__spinlock](https://docs.zephyrproject.org/latest/doxygen/html/structk__spinlock.html)。读取日期：2026-10-13，`latest`。

`struct k_spinlock`表示内核自旋锁（Kernel Spin Lock），定义于`zephyr/spinlock.h`。

## 66.1\_锁记录

此结构定义一个自旋锁记录（Spin Lock Record），中央处理器（Central Processing Unit，CPU）可通过`k_spin_lock()`在该锁上等待。应用代码可以定义任意数量的自旋锁。

## 66.2\_相关接口与实际布局

原结构参考页没有列出成员字段。实际布局随对称多处理（Symmetric Multiprocessing，SMP）、票据自旋锁（Ticket Spinlock）和校验配置而变化，完整条件定义见[头文件源码](P068_自旋锁头文件源码.md)。

加锁、尝试加锁、解锁及键值规则见[公共接口](P065_自旋锁公共接口.md)。本页保留原结构参考的范围，没有把某一个配置下的字段当作所有构建的固定布局。
