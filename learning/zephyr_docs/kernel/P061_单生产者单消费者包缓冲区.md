# 第61章\_单生产者单消费者包缓冲区

原文：[Single Producer Single Consumer Packet Buffer](https://docs.zephyrproject.org/latest/kernel/data_structures/spsc_pbuf.html)。读取日期：2026-10-12，`latest`。

单生产者单消费者包缓冲区（Single Producer Single Consumer Packet Buffer，SPSC_PBUF）使用环形缓冲区，以先进先出顺序保存变长包。使用前提是只有一个上下文生产包、一个上下文消费数据。

实现侧重性能与内存占用。`spsc_pbuf_write()` 把数据复制进缓冲区，缓冲区已满时返回错误；`spsc_pbuf_read()` 把包复制出缓冲区。

对应接口见[单生产者单消费者包缓冲区参考](../intercore_reference/P150_SPSC数据包缓冲区接口.md)。
