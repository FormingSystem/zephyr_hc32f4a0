# 第38章\_用户模式入口

原文：[User Mode](https://docs.zephyrproject.org/latest/kernel/usermode/index.html)。读取日期：2026-10-12，`latest`。

Zephyr 可让线程在较低特权级运行，称为**用户模式（User Mode）**。原页说明其设计面向具有**内存保护单元（Memory Protection Unit，MPU）**硬件的设备。创建用户模式线程的方法见[线程生命周期](P002_线程.md)。

本节官方目录包含以下内容：

- [用户模式概述](P039_用户模式概述.md)：威胁模型、高层策略、约束。
- [内存保护与内存域](P041_内存保护与内存域.md)：启动内存配置、硬件栈溢出检测、线程栈、线程资源池、内存域、配置与接口。
- [用户模式内核对象](P040_用户模式内核对象.md)：对象放置、动态对象、监督线程和用户线程权限、初始化、新对象类型、配置与接口。
- [系统调用](P044_系统调用.md)：组成、C 原型、实现函数、验证函数、配置与接口。
- [MPU栈对象](P042_MPU栈对象.md)：线程栈创建、保护区及内存放置。
- [MPU用户空间实现](P043_MPU用户空间实现.md)。

> 译注：原页是分类入口，详细子页面独立记录完成状态；后文也讨论了使用 **内存管理单元（Memory Management Unit，MMU）** 的架构，不应把开头的设计背景理解为所有用户模式支持仅限 MPU。
