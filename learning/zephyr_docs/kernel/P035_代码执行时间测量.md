# 第35章\_代码执行时间测量

原文：[Executing Time Functions](https://docs.zephyrproject.org/latest/kernel/timing_functions/index.html)。读取日期：2026-10-12，`latest`。

**计时函数（Timing Function）**可测量一段代码的执行时间，辅助分析和优化。使用的计时器可能不同于默认内核定时器，由架构、**片上系统（System on Chip，SoC）** 或开发板配置决定。

## 35.1\_配置与使用顺序

启用 `CONFIG_TIMING_FUNCTIONS` 后，可按以下步骤收集时间信息：

1. `timing_init()` 初始化计时器。
2. `timing_start()` 开始采集，通常会启动计时器。
3. `timing_counter_get()` 记录待测代码开始时的计数。
4. 执行代码后，再用 `timing_counter_get()` 记录结束计数。
5. `timing_cycles_get()` 计算两次计数之间的计时器周期数。
6. `timing_cycles_to_ns()` 将周期总数换算成纳秒。
7. 如需测量其他代码段，从第 3 步重复。
8. `timing_stop()` 结束采集，通常会停止计时器。

## 35.2\_示例

下面展示完整调用顺序，待测函数由应用提供：

```c
#include <zephyr/timing/timing.h>

void gather_timing(void)
{
    timing_t start_time, end_time;
    uint64_t total_cycles;
    uint64_t total_ns;

    timing_init();
    timing_start();

    start_time = timing_counter_get();

    code_execution_to_be_measured();

    end_time = timing_counter_get();

    total_cycles = timing_cycles_get(&start_time, &end_time);
    total_ns = timing_cycles_to_ns(total_cycles);

    timing_stop();
}
```
