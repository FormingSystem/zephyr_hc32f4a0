# 第28章\_通用队列与取消等待

原文：[Queues](https://docs.zephyrproject.org/latest/kernel/services/data_passing/queues.html)。读取日期：2026-10-12，`latest`。

Zephyr 的 Queue 是实现传统队列的内核对象，允许线程和中断服务例程加入或取出任意大小的数据项。它类似 **先进先出（First In, First Out，FIFO）**，并作为 `k_fifo`、`k_lifo` 的底层实现。基本用法参见[FIFO](P014_FIFO先进先出队列.md)。

## 28.1\_取消等待

另一个线程或中断服务例程可调用 `k_queue_cancel_wait()`，让正在等待取队列数据的线程在没有取得数据时返回。队列上第一个等待线程的 `k_queue_get()` 返回 `NULL`，与等待超时相同。

如果线程通过 `k_poll()` 等待该队列，取消后轮询调用返回 `-EINTR`，对应事件进入取消状态。

基于队列的其他原语也提供这一机制，分别为 `k_fifo_cancel_wait()` 与 `k_lifo_cancel_wait()`。

## 28.2\_配置与接口

原文相关配置选项列为“无”。完整声明见[Queue APIs](../queue_reference/P001_通用队列公共接口.md)。
