# 内核官方译文大纲

1. [中断](P001_中断.md)：中断上下文、级联编码、IRQ 锁、零延迟、工作下放、共享、动态连接和中断表生成。
2. [线程](P002_线程.md)：生命周期、栈、优先级、meta-IRQ、权限、名称与运行时检查。

4. [无线程运行](P004_无线程运行.md)：关闭多线程后的内核和外设支持边界。
5. [调度与CPU空闲](P005_调度与CPU空闲.md)：就绪/等待队列、协作与抢占、时间片、调度锁和原子空闲。
6. [定时器](P006_定时器.md)：周期时间基准、到期回调、观察者、状态读取与同步。

7. [工作队列线程](P007_工作队列线程.md)：生命周期、延迟与触发工作、取消/刷新、并发和错误处理。
8. [内核计时](P008_内核计时.md)：周期、tick、超时后端、运行时频率更新与 timepoint。

9. [系统定时器驱动](P009_系统定时器驱动.md)：tick 报告、空闲钩子、统一锁、SMP 与通用 tickless 核心。
10. [信号量](P010_信号量.md)：计数、上限、给出/获取和用户模式信号量。
11. [互斥量](P011_互斥量.md)：递归加锁、优先级继承、futex 与用户模式互斥量。
12. [事件](P012_事件.md)：设置/投递、任意/全部等待和原子移除。
13. [条件变量](P013_条件变量.md)：互斥量释放/重获、通知与共享条件。

14. [FIFO先进先出队列](P014_FIFO先进先出队列.md)：数据项链接字段、对象寿命、批量入队和分配型入队。
15. [LIFO后进先出队列](P015_LIFO后进先出队列.md)：后进先出数据顺序、等待者选择与对象复用。
16. [消息队列](P016_消息队列.md)：固定大小复制、容量、清空、窥视和返回值。
17. [管道](P017_管道.md)：字节流、部分读写、重置及原例协议边界。
18. [邮箱](P018_邮箱.md)：线程匹配、同步/异步流控、描述符与延迟取数据。
19. [环形缓冲区](P019_环形缓冲区.md)：复制与零复制接口、并发、回绕和旧 API 迁移。
20. [轮询API](P020_轮询API.md)：多条件等待、只通知模式、信号重置和竞态。

21. [内存管理入口](P021_内存管理入口.md)：官方内存管理分类与子主题。
22. [固定块内存池](P022_固定块内存池.md)：固定大小分配、等待、释放及峰值统计。
23. [内存堆](P023_内存堆.md)：同步堆、底层堆、多堆、系统堆与容量约束。
24. [共享多堆](P024_共享多堆.md)：按内存属性选择受管理区域。

28. [通用队列与取消等待](P028_通用队列与取消等待.md)：底层队列及等待取消语义。
29. [整数数据栈](P029_整数数据栈.md)：机器字数据容器、容量和对象地址池。

30. [致命错误处理](P030_致命错误处理.md)：oops/panic、栈保护、异常与策略覆盖。
31. [断言](P031_断言.md)：模块等级、运行时/构建断言及旧配置兼容。
