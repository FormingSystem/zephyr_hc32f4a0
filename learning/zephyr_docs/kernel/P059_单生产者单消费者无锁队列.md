# 第59章\_单生产者单消费者无锁队列

原文：[Single Producer Single Consumer Lock Free Queue](https://docs.zephyrproject.org/latest/kernel/data_structures/spsc_lockfree.html)。读取日期：2026-10-12，`latest`。

单生产者单消费者无锁队列（Single Producer Single Consumer，SPSC）是基于原子环形缓冲区的无锁队列。

原页接口入口为[SPSC 接口参考](../intercore_reference/P163_SPSC无锁队列接口.md)。

> 译注：原页只有一句说明和接口外链。单生产者、单消费者是使用前提；本页完成不代表外链 **应用程序编程接口（Application Programming Interface，API）** 参考已经逐项翻译。
