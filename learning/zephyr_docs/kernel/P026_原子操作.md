# 第26章\_原子操作

原文：[Atomic Services](https://docs.zephyrproject.org/latest/kernel/services/other/atomic.html)。读取日期：2026-10-12，`latest`。

**原子变量（Atomic Variable）**可以由线程和**中断服务例程（Interrupt Service Routine，ISR）**以不可分割的方式读取或修改。32 位机器上为 32 位变量，64 位机器上为 64 位变量。

## 26.1\_概念

原子变量数量仅受可用内存等资源限制。使用内核原子接口操作它，可以保证即使更高优先级执行上下文也修改同一变量，该操作仍正确完成。内核还支持对原子变量数组中的单个位进行原子操作。

## 26.2\_定义原子变量

类型为 `atomic_t`。原文说明默认初始化为 0，也可以通过 `ATOMIC_INIT` 指定其他初值：

```c
atomic_t flags = ATOMIC_INIT(0xFF);
```

> 译注：“默认为 0”适用于静态存储期的零初始化规则；未初始化的自动局部变量不会因为类型是 `atomic_t` 就自动清零。局部对象应显式初始化。

## 26.3\_修改原子变量

下面通过 `atomic_inc()` 记录函数调用次数。增加操作是原子的，即使调用途中被更高优先级上下文打断，而后者又调用同一函数，也不会因交叉递增而破坏计数：

```c
atomic_t call_count;

int call_counting_routine(void)
{
    /* increment invocation counter */
    atomic_inc(&call_count);

    /* do rest of routine's processing */
    ...
}
```

原例省略了函数其余处理；它声明返回 `int`，完整实现也应提供相应返回值。

## 26.4\_原子位数组

可以像普通数组那样定义多个原子变量，或用 `ATOMIC_DEFINE` 按所需位数定义数组。以 `_bit()` 结尾的相关接口用于操作其中单个位。

下例定义 200 个标志位，并尝试设置指定位、返回原值：

```c
#define NUM_FLAG_BITS 200

ATOMIC_DEFINE(flag_bits, NUM_FLAG_BITS);

/* set specified flag bit & return its previous value */
int set_flag_bit(int bit_position)
{
    return (int)atomic_set_bit(flag_bits, bit_position);
}
```

> 译注：原例与 **应用程序编程接口（Application Programming Interface，API）** 不一致：`atomic_set_bit()` 返回 `void`，不能强制转成 `int` 返回。若要“设置并返回原值”，应使用 `atomic_test_and_set_bit()`，它返回原先的位值。本次读取的[官方公共头文件源码](../atomic_reference/P003_原子操作公共头文件源码.md)可确认这一区别。原文数组段仍用“32 位原子变量”措辞，应结合页首机器字宽说明理解，不能假定所有平台都是 32 位。

## 26.5\_内存顺序

为保证一致性与正确性，Zephyr 原子接口要求在硬件需要时包含完整内存屏障，确保跨执行上下文观察可靠。这相当于 x86 的相应串行化行为、Arm 的数据存储器屏障（Data Memory Barrier，DMB），或 C++ 内存模型中的顺序一致操作。架构相关实现负责满足这一约定。

> 译注：单次原子操作的保证，不会自动把“读状态—修改其他对象—写状态”等多个步骤合成一个不可分割事务。跨变量不变量仍须选择适当同步协议。

## 26.6\_用途、配置与接口

只需修改一个机器字值的临界操作可用原子变量。超过一个机器字的标志位集合，可用多个原子变量构成位数组。原文用单个 32 位值和超过 32 位的数组作为例子，实际宽度取决于架构。

原子操作通常比互斥量、显式锁中断等临界区机制更高效。全部原子服务接口均可在线程和 ISR 中使用。

> 译注——后端选择的边界：当前通用C实现的读改写使用全局自旋锁（Spinlock），并在`z_impl_atomic_cas()`中通过编译断言禁止SMP，避免锁实现与CAS相互调用；它不是所有架构上的无需锁（Lock-Free）实现。内建后端显式使用顺序一致参数。具体依据见[原子操作参考册](../atomic_reference/大纲.md)及[C接口源码跟踪](../atomic_reference/P009_通用C原子操作接口源码.md)。

相关 Kconfig 选项为 `CONFIG_ATOMIC_OPERATIONS_BUILTIN`、`CONFIG_ATOMIC_OPERATIONS_ARCH`、`CONFIG_ATOMIC_OPERATIONS_C`。完整接口见[Atomic Services APIs](../atomic_reference/P001_原子操作公共接口.md)。
