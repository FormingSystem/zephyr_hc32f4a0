# 第22章\_固定块内存池

原文：[Memory Slabs](https://docs.zephyrproject.org/latest/kernel/memory_management/slabs.html)。读取日期：2026-10-12，`latest`。

**固定块内存池（Memory Slab）**是从指定内存区域动态分配内存块的内核对象。一个 slab 中所有块大小相同，因此能高效分配、释放，并避免不同大小块带来的内存碎片问题。

## 22.1\_概念与对齐

slab 数量仅受可用内存等资源限制，通过内存地址引用。对象的关键属性包括块大小、块数量及承载全部块的缓冲区。

块大小以字节表示。原文要求 32 位平台按 `4N` 字节、64 位平台按 `8N` 字节粒度取正值，其中 N 大于 0。块数量必须大于 0，缓冲区至少容纳“块大小 × 块数量”字节。

缓冲区必须按 N 字节边界对齐，这里的 N 为 2 的幂，32 位平台至少为 4，64 位平台至少为 8。块大小也必须是该对齐值的整数倍，以保证每个块都满足同样的对齐。

使用前初始化，将全部块标记为空闲。线程需要时分配，使用结束后必须归还，供再次使用。如果所有块都在用，线程可选择等待。多个线程可以同时等待；块释放后优先交给最高优先级线程，同优先级时交给等待最久者。

可以定义多个 slab，分别管理小块、大块。原文还提到可选择 memory pool 对象；具体可用分配器应结合目标版本及[内存堆](P023_内存堆.md)说明。

## 22.2\_内部实现

缓冲区是一组紧密排列的固定大小块，块之间没有额外空隙。slab 用链表跟踪空闲块：32 位平台使用每个空闲块开头 4 字节作为链接，64 位平台使用开头 8 字节。

> 译注：这些链接位于空闲块内部。归还后不能继续把原数据视为有效；固定块也不代表自动清零，下面示例显式调用 `memset()`。

## 22.3\_定义slab

定义 `struct k_mem_slab`，再调用 `k_mem_slab_init()`。下面包含 6 个块，每块 400 字节、按 8 字节对齐：

```c
struct k_mem_slab my_slab;
char __aligned(8) my_slab_buffer[6 * 400];

k_mem_slab_init(&my_slab, my_slab_buffer, 400, 6);
```

使用 `K_MEM_SLAB_DEFINE` 可在编译时同时定义 slab 与缓冲区，效果相同：

```c
K_MEM_SLAB_DEFINE(my_slab, 400, 6, 8);
```

私有作用域可使用：

```c
K_MEM_SLAB_DEFINE_STATIC(my_slab, 400, 6, 8);
```

## 22.4\_分配与释放

`k_mem_slab_alloc()` 分配一个块。下例最多等待 100 毫秒，成功后清零 400 字节，否则输出警告：

```c
char *block_ptr;

if (k_mem_slab_alloc(&my_slab, (void **)&block_ptr, K_MSEC(100)) == 0) {
    memset(block_ptr, 0, 400);
    ...
} else {
    printf("Memory allocation time-out");
}
```

`k_mem_slab_free()` 归还块。下例先无限等待分配，使用后再释放：

```c
char *block_ptr;

k_mem_slab_alloc(&my_slab, (void **)&block_ptr, K_FOREVER);
... /* use memory block pointed at by block_ptr */
k_mem_slab_free(&my_slab, (void *)block_ptr);
```

## 22.5\_查询使用情况

可在运行时查询使用率：`k_mem_slab_num_used_get()` 返回已分配块数，`k_mem_slab_num_free_get()` 返回剩余空闲块数。

启用 `CONFIG_MEM_SLAB_TRACE_MAX_UTILIZATION` 后，`k_mem_slab_max_used_get()` 报告同时分配块数的历史峰值，`k_mem_slab_runtime_stats_get()` 将相关统计一起写入 `struct sys_memory_stats`。

## 22.6\_用途、配置与接口

slab 适合固定大小内存块的分配与释放。在线程间传递大量数据时，可传递 slab 块的所有权或地址，减少不必要的数据复制。

相关 Kconfig 选项为 `CONFIG_MEM_SLAB_TRACE_MAX_UTILIZATION`。完整接口见[Memory Slab APIs](../heap_reference/P003_固定块内存池公共接口.md)。

> 译注——块大小与失败输出：本次定义宏以WB_UP补齐机器字边界，实际块大小可能大于请求值；运行时init不会替调用者补齐。alloc等待超时不保证清空输出指针，必须先检查返回值；free可直接交给等待者，已用块数不一定下降。详见[固定块内存池公共接口](../heap_reference/P003_固定块内存池公共接口.md)。
