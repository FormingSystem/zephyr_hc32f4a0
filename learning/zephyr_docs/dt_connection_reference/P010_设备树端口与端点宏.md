## 10.2\_详细说明（Detailed Documentation）

<a id="ga0d2315ddc63c986da0e90177e8d8eab8"></a>

### `DT_INST_ENDPOINT_BY_ID`

```c
#define DT_INST_ENDPOINT_BY_ID ( inst, pid, eid )
```

```c
#include <zephyr/devicetree/port-endpoint.h>
```

展开值（Value）：

```c
COND_CODE_1(DT_NODE_EXISTS(_DT_INST_ENDPOINT_BY_ID(inst, pid, eid)),                       \
        (_DT_INST_ENDPOINT_BY_ID(inst, pid, eid)),                                         \
                (DT_CHILD(DT_INST_PORT_BY_ID(inst, pid), endpoint)))
```

按端点ID及其父端口ID取得端点（Endpoint）节点。

给定设备实例编号、端口ID和端点ID，返回端点节点。支持DT_INST_PORT_BY_ID及下文描述的多种端口、端点定义方式。

使用DT_INST_ENDPOINT_BY_ID()取得endpoint或endpoint@0节点的示例：

原始示例（Example）：

```c
DT_INST_ENDPOINT_BY_ID(inst, 0, 0)
```

设备树（Devicetree）片段示例：

原始示例（Example）：

```dts
&device {
   port {
           endpoint {
           };
   };
};
```

原始示例（Example）：

```dts
&device {
   port {
           #address-cells = <1>;
           #size-cells = <0>;
           endpoint@0 {
                   reg = <0x0>;
           };
   };
};
```

原始示例（Example）：

```dts
&device {
   ports {
           #address-cells = <1>;
           #size-cells = <0>;
           port@0 {
                   reg = <0x0>;
                   #address-cells = <1>;
                   #size-cells = <0>;
                   endpoint@0 {
                           reg = <0x0>;
                   };
           };
   };
};
```

**参数（Parameters）**

| 名称／方向 | 说明 |
| --- | --- |
| `inst` | 实例编号（Instance Number）。 |
| `pid` | 端口ID。 |
| `eid` | 端点ID。 |

返回（Returns）：与eid和pid关联的端点节点。

```c
#define DT_INST_PORT_BY_ID ( inst, pid )
```

```c
#include <zephyr/devicetree/port-endpoint.h>
```


给定设备实例编号，返回指定ID的端口节点。支持多种端口定义方式。

原始示例（Example）：

```dts
&device {
   ports {
           #address-cells = <1>;
           #size-cells = <0>;
           port@0 {
                   reg = <0x0>;
           };
   };
};
```

原始示例（Example）：

```dts
&device {
   #address-cells = <1>;
   #size-cells = <0>;
   port@0 {
           reg = <0x0>;
   };
};
```

原始示例（Example）：

```dts
&device {
   port {
   };
};
```

**参数（Parameters）**

| 名称／方向 | 说明 |

| `pid` | 端口ID。 |

### `DT_NODE_BY_ENDPOINT`

```c
#define DT_NODE_BY_ENDPOINT ( ep)
```

```c
#include <zephyr/devicetree/port-endpoint.h>
```

展开值（Value）：

```c
COND_CODE_1(DT_NODE_EXISTS(DT_CHILD(DT_PARENT(DT_GPARENT(ep)), ports)),                    \
        (DT_PARENT(DT_GPARENT(ep))), (DT_GPARENT(ep)))
```

从端点节点取得设备节点。

给定端点节点标识符，返回其设备节点标识符。支持DT_NODE_BY_ENDPOINT中描述的多种端口与端点定义方式。

使用DT_NODE_BY_ENDPOINT()从ep0节点取得&device设备节点的示例：

原始示例（Example）：

```c
DT_NODE_BY_ENDPOINT(DT_NODELABEL(ep0))
```

设备树（Devicetree）片段示例：

原始示例（Example）：

```dts
&device {
   port {
           #address-cells = <1>;
           #size-cells = <0>;
           ep0: endpoint@0 {
                   reg = <0x0>;
           };
   };
};
```

原始示例（Example）：

```dts
&device {
   ports {
           #address-cells = <1>;
           #size-cells = <0>;
           port@0 {
                   reg = <0x0>;
                   #address-cells = <1>;
                   #size-cells = <0>;
                   ep0: endpoint@0 {
                           reg = <0x0>;
                   };
           };
   };
};
```

**参数（Parameters）**

| 名称／方向 | 说明 |
| --- | --- |
| `ep` | 端点节点。 |

返回（Returns）：与ep关联的设备节点。

<a id="gaf1261a1a110fc0b164e6eafbaf885f7d"></a>

### `DT_NODE_REMOTE_DEVICE`

```c
#define DT_NODE_REMOTE_DEVICE ( ep)
```

```c
#include <zephyr/devicetree/port-endpoint.h>
```

展开值（Value）：

```c
DT_NODE_BY_ENDPOINT(DT_NODELABEL(DT_STRING_TOKEN(ep, remote_endpoint_label)))
```

从本地端点节点取得远端设备节点。

给定端点节点标识符，返回通过该本地端点与本设备连接的远端设备节点。支持DT_INST_PORT_BY_ID与DT_INST_ENDPOINT_BY_ID中描述的多种端口与端点定义方式。

使用DT_NODE_REMOTE_DEVICE()从&device0设备的本地endpoint@0端点取得远端&device1设备节点的示例：

原始示例（Example）：

```c
DT_NODE_REMOTE_DEVICE(DT_NODELABEL(device0_ep_out))
```

设备树（Devicetree）片段示例：

原始示例（Example）：

```dts
&device0 {
   port {
           #address-cells = <1>;
           #size-cells = <0>;
           device0_ep_out: endpoint@0 {
                   reg = <0x0>;
                   remote-endpoint-label = "device1_ep_in";
           };
   };
};

&device1 {
   ports {
           #address-cells = <1>;
           #size-cells = <0>;
           port@0 {
                   reg = <0x0>;
                   device1_ep_in: endpoint {
                           remote-endpoint-label = "device0_ep_out";
                   };
           };
   };
};
```

**参数（Parameters）**

| 名称／方向 | 说明 |
| --- | --- |
| `ep` | 端点节点。 |

返回（Returns）：通过ep与本设备连接的远端设备节点。

> 译注——源码核对：远端属性：本次DT_NODE_REMOTE_DEVICE使用remote-endpoint-label字符串，经DT_STRING_TOKEN和DT_NODELABEL找到远端端点，再取得其所属设备。它没有读取标准remote-endpoint句柄属性；不能直接把字符串改为phandle还期待同一宏工作。缺少属性或目标标签时没有运行时错误返回，源和目标节点、名称及拓扑须有效。

## 10.3\_源码定位与版本边界

本册收录I/O通道、描述符映射、多路复用器及端口／端点宏。相对源码定位：[I/O通道](../../../include/zephyr/devicetree/io-channels.h)、[映射](../../../include/zephyr/devicetree/map.h)、[MUX](../../../include/zephyr/devicetree/mux.h)、[端口／端点](../../../include/zephyr/devicetree/port-endpoint.h)、[MUX驱动](../../../include/zephyr/drivers/mux.h)、[生成脚本](../../../scripts/dts/gen_defines.py)和[解析器](../../../scripts/dts/python-devicetree/src/devicetree/edtlib.py)。本次官方文件摘要见[来源记录](../SOURCES.md)。

> 译注——源码核对：节点查找规则：先尝试ports容器内或设备直接子节点中的port_<pid>，不存在时回退到不带地址的port；端点同样先尝试endpoint_<eid>，再回退到endpoint。实现拼接的是规范化后的节点名称标记，不遍历reg值进行整数比较。pid／eid要与节点名称对应，不能传运行时变量或期待自动计算表达式。

> 译注——源码核对：回退的限制：即使传入的pid／eid对应具名节点不存在，只要无地址port／endpoint存在也可能选中它；宏不会验证回退节点的ID一定等于调用者传入的值。BY_ENDPOINT依据规定的两层或三层父子结构返回设备，未做任意层级图遍历或绑定语义验证。

> 译注——源码核对：远端属性：本次DT_NODE_REMOTE_DEVICE使用remote-endpoint-label字符串，经DT_STRING_TOKEN和DT_NODELABEL找到远端端点，再取得其所属设备。它没有读取标准remote-endpoint句柄属性；不能直接把字符串改为phandle还期待同一宏工作。缺少属性或目标标签时没有运行时错误返回，源和目标节点、名称及拓扑须有效。

> 译注——源码核对：返回值与连接：所有端口／端点宏返回节点标识，不是struct device指针，不会建立数据流或证明双方驱动已初始化。原例中的&device、&device0、&device1是DTS节点引用，C端需使用适当设备模型接口再取得设备对象。

> 译注——源码核对：版本边界：本次四份设备树头文件、MUX驱动头文件、gen_defines.py和edtlib.py登记摘要；四份源码浏览页的非注释代码与对应头文件一致。滚动main与本仓库参照基线不自动视为同版本；本批未编译示例、构建固件、采样、配置MUX或执行硬件实验。

本次验证范围为文档与源码对照，未编译宏／DTS示例、构建固件或操作硬件。
