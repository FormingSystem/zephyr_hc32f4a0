### `DT_IO_CHANNELS_INPUT_BY_IDX`

```c
#define DT_IO_CHANNELS_INPUT_BY_IDX ( node_id, idx )
```

```c
#include <zephyr/devicetree/io-channels.h>
```

展开值（Value）：

```c
DT_PHA_BY_IDX(node_id, io_channels, idx, input)
```

按索引取得io-channels描述符（Specifier）的input单元（Cell）。

此宏仅适用于包含名为input的单元的io-channels描述符。必要时参阅节点的绑定（Binding）进行核对。

设备树（Devicetree）片段示例：

原始示例（Example）：

```dts
adc1: adc@... {
        compatible = "vnd,adc";
        #io-channel-cells = <1>;
};

adc2: adc@... {
        compatible = "vnd,adc";
        #io-channel-cells = <1>;
};

n: node {
        io-channels = <&adc1 10>, <&adc2 20>;
};
```

vnd,adc兼容字符串（Compatible）对应的绑定片段：

io-channel-cells：

- `input`（输入）。

用法示例：

原始示例（Example）：

```c
DT_IO_CHANNELS_INPUT_BY_IDX(DT_NODELABEL(n), 0) // 10
DT_IO_CHANNELS_INPUT_BY_IDX(DT_NODELABEL(n), 1) // 20
```

**参数（Parameters）**

| 名称／方向 | 说明 |
| --- | --- |
| `node_id` | 具有io-channels属性的节点的节点标识符。 |
| `idx` | io-channels属性中的逻辑索引（Logical Index）。 |

返回（Returns）：索引idx处描述符中的input单元。

另见（See Also）：`DT_PHA_BY_IDX()`。

此宏仅适用于包含名为input的单元的io-channels描述符。必要时参阅节点的绑定（Binding）进行核对。

设备树（Devicetree）片段示例：

原始示例（Example）：

```dts
adc1: adc@... {
        compatible = "vnd,adc";
        #io-channel-cells = <1>;
};

adc2: adc@... {
        compatible = "vnd,adc";
        #io-channel-cells = <1>;
};

n: node {
        io-channels = <&adc1 10>, <&adc2 20>;
        io-channel-names = "SENSOR", "BANDGAP";
};
```

vnd,adc兼容字符串（Compatible）对应的绑定片段：

io-channel-cells：

- `input`（输入）。

用法示例：

原始示例（Example）：

```c
DT_IO_CHANNELS_INPUT_BY_NAME(DT_NODELABEL(n), sensor) // 10
DT_IO_CHANNELS_INPUT_BY_NAME(DT_NODELABEL(n), bandgap) // 20
```

**参数（Parameters）**

| 名称／方向 | 说明 |
| --- | --- |
| `node_id` | 具有io-channels属性的节点的节点标识符。 |
| `name` | 节点io-channel-names属性定义的io-channels元素名称，使用小写加下划线形式。 |

返回（Returns）：具名元素描述符中的input单元。

## 1.3\_源码定位与版本边界

本册收录I/O通道、描述符映射、多路复用器及端口／端点宏。相对源码定位：[I/O通道](../../../include/zephyr/devicetree/io-channels.h)、[映射](../../../include/zephyr/devicetree/map.h)、[MUX](../../../include/zephyr/devicetree/mux.h)、[端口／端点](../../../include/zephyr/devicetree/port-endpoint.h)、[MUX驱动](../../../include/zephyr/drivers/mux.h)、[生成脚本](../../../scripts/dts/gen_defines.py)和[解析器](../../../scripts/dts/python-devicetree/src/devicetree/edtlib.py)。本次官方文件摘要见[来源记录](../SOURCES.md)。

> 译注——源码核对：返回对象：CTLR系列返回io-channels句柄引用的控制器节点标识，INPUT／OUTPUT读取名为input／output的单元值。示例中的10与20是绑定定义的通道参数，不是采样结果、电压或已设置的DAC输出值；这些宏不会配置ADC／DAC，也不会触发转换。

> 译注——源码核对：绑定与名称：#io-channel-cells给出单个描述符的数据单元数，绑定中的io-channel-cells列表为单元命名；原文input／output列表分别表示一个名为input／output的单元。io-channel-names给消费节点的完整条目命名，SENSOR、BANDGAP在宏实参中写为sensor、bandgap。INPUT与OUTPUT要求对应控制器绑定确有该名称，不能因属性都叫io-channels就互换。

> 译注——源码核对：索引与实例：idx从0开始计数完整条目，不计数其32位单元；无_BY_IDX／BY_NAME版本固定索引0。INST系列首先以DT_DRV_COMPAT取得消费节点，不是按ADC或DAC控制器编号寻址。示例的...与vnd,adc／vnd,dac是占位内容，使用前须补齐真实绑定和节点。

> 译注——源码核对：版本边界：本次四份设备树头文件、MUX驱动头文件、gen_defines.py和edtlib.py登记摘要；四份源码浏览页的非注释代码与对应头文件一致。滚动main与本仓库参照基线不自动视为同版本；本批未编译示例、构建固件、采样、配置MUX或执行硬件实验。

本次验证范围为文档与源码对照，未编译宏／DTS示例、构建固件或操作硬件。
