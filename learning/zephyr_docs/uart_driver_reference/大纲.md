# UART驱动头文件参考大纲

本册完整翻译UART（通用异步收发器，Universal Asynchronous Receiver/Transmitter）公共头文件、内部头文件各自的参考页与源码浏览页。公共头文件定义配置、事件和接口，内部头文件保存驱动函数表及内联分派实现。详细接口约定可分别进入[公共API](../hardware/P330_UART公共接口.md)、[轮询接口](../hardware/P332_UART轮询接口.md)、[中断驱动接口](../hardware/P333_UART中断驱动接口.md)和[异步接口](../hardware/P334_UART异步接口.md)。

参考页保留官方实际展示的声明和摘要；内部参考页按官方隐藏规则仅展示文件说明，源码页保留全部可见代码、注释、行号定位和符号提示。源码跟踪译注区分接口是否启用、驱动是否实现、数据就绪与缓冲区释放、字节与宽数据项以及用户态校验边界。原代码、许可证与中英文术语保留，仓库定位使用相对路径。完整范围见[全站进度](../PROGRESS.md)。
