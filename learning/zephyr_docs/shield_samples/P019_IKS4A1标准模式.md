# 第19章\_X-NUCLEO-IKS4A1 扩展板：标准模式（Standard，Mode 1）

原文：[官方页面](https://docs.zephyrproject.org/latest/samples/shields/x_nucleo_iks4a1/standard/README.html)。快照读取日期：2026-10-15；来源摘要见[来源记录](../SOURCES.md)。

[在 GitHub 浏览源码（Browse source code on GitHub）](https://github.com/zephyrproject-rtos/zephyr/blob/main//samples/shields/x_nucleo_iks4a1/standard/README.rst/..)

<a id="overview"></a>

## 19.1 概述（Overview）

本示例用于测试配置为标准模式（Standard，Mode 1）的 X-NUCLEO-IKS4A1。该配置的更多说明见“模式 1：标准模式（Mode 1: Standard Mode）”。 相关链接：[模式 1：标准模式（Standard Mode）](https://docs.zephyrproject.org/latest/boards/shields/x_nucleo_iks4a1/doc/index.html#x-nucleo-iks4a1-mode-1)。

本示例启用 X-NUCLEO-IKS4A1 扩展板上的以下四种传感器，然后周期性读取并显示其数据：

> 译注——原文计数差异：本段写“四种”，下方实际列了五种；当前源码与 overlay 则访问六种器件，即这五种加上 LIS2MDL 磁力计。原文列表保留，完整运行对象应按 main.c 的设备获取与就绪检查核对。

- LSM6DSV16X：六轴加速度与角速度（6-Axis Acceleration and Angular Velocity）

- LSM6DSO16IS：六轴加速度与角速度（6-Axis Acceleration and Angular Velocity）

- LPS22DF：环境温度与大气压力（Ambient Temperature and Atmospheric Pressure）

- STTS22H：环境温度（Ambient Temperature）

- LIS2MDL：三轴磁场强度（3-Axis Magnetic Field Intensity）

- LIS2DUXS12：三轴加速度（3-Axis Acceleration）

<a id="requirements"></a>

## 19.2 硬件与配置要求（Requirements）

本示例通过 I2C 与叠接在 Arduino 接口开发板上的 X-NUCLEO-IKS4A1 通信，例如 [Nucleo F411RE](https://docs.zephyrproject.org/latest/boards/st/nucleo_f411re/doc/index.html#nucleo_f411re)。

<a id="building-and-running"></a>

## 19.3 构建与运行（Building and Running）

> 译注——执行前提：主机命令从读者自己的 Zephyr 源码根目录，用 UCRT64 Bash 或 Linux Bash 执行；先按[入门指南](../getting_started/大纲.md)准备模块、工具链和目标板。CMakeLists.txt 已选择 SHIELD=x_nucleo_iks4a1，所以原命令不必重复指定 --shield。先按本页链接核对扩展板硬件模式、供电和连接，再构建对应应用；设备不就绪时回查模式、总线、设备树与中断接线。下方是原文预期输出，本次未构建、烧录或实测。

本示例可在具有匹配 Arduino 接口并叠接 X-NUCLEO-IKS4A1 的开发板上运行。这里采用 [Nucleo F411RE](https://docs.zephyrproject.org/latest/boards/st/nucleo_f411re/doc/index.html#nucleo_f411re) 开发板。

> 译注——总线选择：本页的 prj.conf 使用 CONFIG_I2C=y，CMake 选择 x_nucleo_iks4a1。官方另有 Standard（Mode 1 + I3C）示例，已在既有驱动专题提供译文；模式 1 的硬件布局本身并不表示当前程序已经使用 I3C。

```text
west build -b nucleo_f411re samples/shields/x_nucleo_iks4a1/standard/
west flash
```
