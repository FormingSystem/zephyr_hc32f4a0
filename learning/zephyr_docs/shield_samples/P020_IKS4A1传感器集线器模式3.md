# 第20章\_X-NUCLEO-IKS4A1 扩展板：传感器集线器模式（SensorHub，Mode 3）

原文：[官方页面](https://docs.zephyrproject.org/latest/samples/shields/x_nucleo_iks4a1/sensorhub1/README.html)。快照读取日期：2026-10-15；来源摘要见[来源记录](../SOURCES.md)。

[在 GitHub 浏览源码（Browse source code on GitHub）](https://github.com/zephyrproject-rtos/zephyr/blob/main//samples/shields/x_nucleo_iks4a1/sensorhub1/README.rst/..)

<a id="overview"></a>

## 20.1 概述（Overview）

本示例用于测试配置为 SHUB1（Mode 3）的 X-NUCLEO-IKS4A1。该配置的更多说明见“模式 3：LSM6DSV16X 传感器集线器模式（Mode 3: LSM6DSV16X SensorHub Mode，SHUB1）”。 相关链接：[模式 3：LSM6DSV16X 传感器集线器模式（SHUB1）](https://docs.zephyrproject.org/latest/boards/shields/x_nucleo_iks4a1/doc/index.html#x-nucleo-iks4a1-mode-3)。

> 译注——模式编号：sensorhub1 路径和 x_nucleo_iks4a1_shub1 对应 Mode 3，其主设备为 LSM6DSV16X；不要根据目录名中的 1 推断它是 Mode 1。主机 I2C 节点地址为 0x6b，外部磁场及压力数据通过该 IMU 读取。

本示例将 LSM6DSV16X 惯性测量单元（Inertial Measurement Unit，IMU）配置为传感器集线器模式，连接 LIS2MDL 磁力计以及 LPS22DF 压力与温度传感器。

随后周期性显示传感器数据。

- LSM6DSV16X：六轴加速度与角速度（6-Axis Acceleration and Angular Velocity）

- LSM6DSV16X：来自 LIS2MDL 的三轴磁场强度。

- LSM6DSV16X：来自 LPS22DF 的环境温度与大气压力。

<a id="requirements"></a>

## 20.2 硬件与配置要求（Requirements）

本示例通过 I2C 与叠接在 Arduino 接口开发板上的 X-NUCLEO-IKS4A1 通信，例如 [Nucleo F411RE](https://docs.zephyrproject.org/latest/boards/st/nucleo_f411re/doc/index.html#nucleo_f411re)。

<a id="building-and-running"></a>

## 20.3 构建与运行（Building and Running）

> 译注——执行前提：主机命令从读者自己的 Zephyr 源码根目录，用 UCRT64 Bash 或 Linux Bash 执行；先按[入门指南](../getting_started/大纲.md)准备模块、工具链和目标板。CMakeLists.txt 已选择 SHIELD=x_nucleo_iks4a1_shub1，所以原命令不必重复指定 --shield。先按本页链接核对扩展板硬件模式、供电和连接，再构建对应应用；设备不就绪时回查模式、总线、设备树与中断接线。下方是原文预期输出，本次未构建、烧录或实测。

本示例可在具有匹配 Arduino 接口并叠接 X-NUCLEO-IKS4A1 的开发板上运行。这里采用 [Nucleo F411RE](https://docs.zephyrproject.org/latest/boards/st/nucleo_f411re/doc/index.html#nucleo_f411re) 开发板。

```text
west build -b nucleo_f411re samples/shields/x_nucleo_iks4a1/sensorhub1/
west flash
```

<a id="sample-output"></a>

### 20.3.1 示例输出（Sample Output）

> 译注——标签差异：原文日志和当前 main.c 的标题都写 X-NUCLEO-IKS01A4，这是该示例中的历史标签；本页目标仍是 X-NUCLEO-IKS4A1。日志以 LSM6DSV16X 为前缀的压力及环境温度来自 LPS22DF，不是 IMU 自身的压力测量。

> 译注——读数单位：m/s^2 表示加速度，G 表示磁场高斯（Gauss），不是重力加速度单位 g；rad/s 表示角速度弧度每秒，温度用摄氏度、压力用 kPa。源码在一轮显示后休眠 2000 ms；传感器内部采样、触发更新和控制台刷新是不同节奏，日志数值不表示本次已完成标定或精度验收。

> ```text

>
> LSM6DSV16X: Accel (m/s^2): x: 0.081, y: -0.177, z: 9.945
> LSM6DSV16X: Gyro (rad/s): x: 0.001, y: -0.000, z: 0.004
> LSM6DSV16X: Magn (G): x: 0.217, y: 0.015, z: -0.415
> LSM6DSV16X: Temperature: 19.8 C
> LSM6DSV16X: Pressure:99.655 kPa
> 16:: lsm6dso16is acc trig 6432
>
> <updated endlessly every 2 seconds>
> ```
