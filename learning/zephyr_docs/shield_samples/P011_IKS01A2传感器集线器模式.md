# 第11章\_X-NUCLEO-IKS01A2 扩展板：传感器集线器模式（SensorHub，Mode 2）

原文：[官方页面](https://docs.zephyrproject.org/latest/samples/shields/x_nucleo_iks01a2/sensorhub/README.html)。快照读取日期：2026-10-15；来源摘要见[来源记录](../SOURCES.md)。

[在 GitHub 浏览源码（Browse source code on GitHub）](https://github.com/zephyrproject-rtos/zephyr/blob/main//samples/shields/x_nucleo_iks01a2/sensorhub/README.rst/..)

<a id="overview"></a>

## 11.1 概述（Overview）

本示例用于测试配置为传感器集线器模式（Sensor Hub，Mode 2）的 X-NUCLEO-IKS01A2。该配置的更多说明见《[X-NUCLEO-IKS01A2：MEMS 惯性与环境多传感器扩展板](https://docs.zephyrproject.org/latest/boards/shields/x_nucleo_iks01a2/doc/index.html#x-nucleo-iks01a2)》。

本示例启用 LSM6DSL 传感器。由于扩展板上的其他器件都连接到 LSM6DSL，LSM6DSL 驱动配置为传感器集线器模式（CONFIG_LSM6DSL_SENSORHUB=y），并在 LPS22HB 与 LSM303AGR 中只选择一个从设备，默认选择 LSM303AGR。

> 译注——实际配置与数据路径：当前 prj.conf 设置 CONFIG_LSM6DSL_EXT0_LIS2MDL=y、CONFIG_LSM6DSL_EXT0_LPS22HB=n，前者对应此板 LSM303AGR 的磁场功能。主机侧设备树只声明 LSM6DSL，应用通过其 SENSOR_CHAN_MAGN_XYZ 读取外部磁场；默认不同时输出 LPS22HB 温度和压力，也不会覆盖板上的所有传感器功能。

随后周期性显示传感器数据。

> 译注——采集与显示：main.c 将 LSM6DSL 加速度和陀螺仪输出数据率（Output Data Rate，ODR）设为 104 Hz，默认用数据就绪（Data Ready）触发更新缓存。两秒一次的控制台显示不是 104 Hz 原始采样流，触发计数也不是当前一行数据的时间戳。

- LSM6DSL：六轴加速度与角速度（6-Axis Acceleration and Angular Velocity）

- LSM6DSL：三轴磁场强度，数据来自 LSM303AGR 磁力计（Magnetometer）；这是首选项。

- LSM6DSL：环境温度与大气压力，数据来自 LPS22HB；这是备选项。

<a id="requirements"></a>

## 11.2 硬件与配置要求（Requirements）

本示例通过 I2C 与叠接在 Arduino 接口开发板上的 X-NUCLEO-IKS01A2 通信；扩展板必须配置为 Mode 2。

原文指出，不能在已支持扩展板上某种传感器的开发板上运行本示例，例如 disco_l475_iot1，因为 Zephyr 尚不支持同类传感器的多个实例。

> 译注——多实例说明的版本边界：不能把原文表述泛化为当前 Zephyr 传感器框架的统一限制。当前 DEVICE_DT_GET_ONE() 在多个匹配节点中返回任意一个设备，示例没有明确区分板载与扩展板实例；例如当前 LSM6DSO 驱动已按每个启用节点生成设备。移植时仍需核对驱动能力、总线地址与选定节点，避免程序读到另一颗同型号传感器。

<a id="building-and-running"></a>

## 11.4 构建与运行（Building and Running）

> 译注——执行前提：主机命令从读者自己的 Zephyr 源码根目录，用 UCRT64 Bash 或 Linux Bash 执行；先按[入门指南](../getting_started/大纲.md)准备模块、工具链和目标板。CMakeLists.txt 已选择 SHIELD=x_nucleo_iks01a2_shub，所以原命令不必重复指定 --shield。先按本页链接核对扩展板硬件模式、供电和连接，再构建对应应用；设备不就绪时回查模式、总线、设备树与中断接线。下方是原文预期输出，本次未构建、烧录或实测。

本示例可在具有匹配 Arduino 接口并叠接 X-NUCLEO-IKS01A2 的开发板上运行。这里采用 [Nucleo F401RE](https://docs.zephyrproject.org/latest/boards/st/nucleo_f401re/doc/index.html#nucleo_f401re) 开发板。

```text
west build -b nucleo_f401re samples/shields/x_nucleo_iks01a2/sensorhub
```

<a id="sample-output"></a>

### 11.4.1 示例输出（Sample Output）

> 译注——读数单位：m/s^2 表示加速度，G 表示磁场高斯（Gauss），不是重力加速度单位 g；rad/s 表示角速度弧度每秒，温度用摄氏度、压力用 kPa。源码在一轮显示后休眠 2000 ms；传感器内部采样、触发更新和控制台刷新是不同节奏，日志数值不表示本次已完成标定或精度验收。

> ```text
> X-NUCLEO-IKS01A2 sensor dashboard
>
> LSM6DSL: Accel (m/s^2): x: 0.0, y: 0.2, z: 10.0
> LSM6DSL: Gyro (rad/s): x: 0.029, y: -0.030, z: 0.016
> LSM6DSL: Magn (G): x: 0.363, y: -0.002, z: -0.559
> 9:: lsm6dsl acc trig 1668
>
> <updated endlessly every 2 seconds>
> ```
