# 第22章\_X-NUCLEO-IKS4A1 扩展板（Shield）

原文：[官方页面](https://docs.zephyrproject.org/latest/samples/shields/x_nucleo_iks4a1/README.html)。快照读取日期：2026-10-15；来源摘要见[来源记录](../SOURCES.md)。

以下示例展示 X-NUCLEO-IKS4A1 扩展板的多种功能。

> 译注——模式对应：Mode 1 为标准模式，Mode 2 为 LSM6DSO16IS／SHUB2，Mode 3 为 LSM6DSV16X／SHUB1。I3C 标准模式沿用既有译文；其余三篇在本册分别翻译，按各页的硬件配置、总线和 CMake 选择使用。

- [X-NUCLEO-IKS4A1 扩展板：传感器集线器模式（SensorHub，Mode 2）](P021_IKS4A1传感器集线器模式2.md#x-nucleo-iks4a1-shub2)——通过 SHUB2（模式 2）访问扩展板上的全部传感器。

- [X-NUCLEO-IKS4A1 扩展板：传感器集线器模式（SensorHub，Mode 3）](P020_IKS4A1传感器集线器模式3.md#x-nucleo-iks4a1-shub1)——通过 SHUB1（模式 3）访问扩展板上的全部传感器。

- X-NUCLEO-IKS4A1 扩展板：标准模式（Standard，Mode 1 + I3C）——通过 I3C 总线上的标准模式访问扩展板上的全部传感器。 相关链接：[X-NUCLEO-IKS4A1：I3C 标准模式（Mode 1 + I3C）](../hardware/P433_IKS4A1标准I3C示例.md#x-nucleo-iks4a1-std-i3c)。

- [X-NUCLEO-IKS4A1 扩展板：标准模式（Standard，Mode 1）](P019_IKS4A1标准模式.md#x-nucleo-iks4a1-std)——通过标准模式访问扩展板上的全部传感器。
