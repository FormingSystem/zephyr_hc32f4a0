# 第21章\_X-NUCLEO-IKS4A1 扩展板：传感器集线器模式（SensorHub，Mode 2）

原文：[官方页面](https://docs.zephyrproject.org/latest/samples/shields/x_nucleo_iks4a1/sensorhub2/README.html)。快照读取日期：2026-10-15；来源摘要见[来源记录](../SOURCES.md)。

<a id="overview"></a>

## 21.1 概述（Overview）

本示例用于测试配置为传感器集线器模式（Sensor Hub，Mode 2）的 X-NUCLEO-IKS4A1。该配置的更多说明见“模式 2：LSM6DSO16IS 传感器集线器模式（Mode 2: LSM6DSO16IS SensorHub Mode，SHUB2）”。 相关链接：[模式 2：LSM6DSO16IS 传感器集线器模式（SHUB2）](https://docs.zephyrproject.org/latest/boards/shields/x_nucleo_iks4a1/doc/index.html#x-nucleo-iks4a1-mode-2)。

> 译注——模式编号：sensorhub2 路径和 x_nucleo_iks4a1_shub2 对应 Mode 2，其主设备为 LSM6DSO16IS，主机 I2C 地址为 0x6a。它与前章 SHUB1 使用不同 IMU 与中断连接；不是同一配置只改一个名称。

本示例将 LSM6DSO16IS 惯性测量单元（Inertial Measurement Unit，IMU）配置为传感器集线器模式，连接 LIS2MDL 磁力计以及 LPS22DF 压力与温度传感器。

随后周期性显示传感器数据。

- LSM6DSO16IS：六轴加速度与角速度（6-Axis Acceleration and Angular Velocity）

- LSM6DSO16IS：来自 LIS2MDL 的三轴磁场强度。

- LSM6DSO16IS：来自 LPS22DF 的环境温度与大气压力。

<a id="requirements"></a>

## 21.2 硬件与配置要求（Requirements）

本示例通过 I2C 与叠接在 Arduino 接口开发板上的 X-NUCLEO-IKS4A1 通信，例如 [Nucleo F411RE](https://docs.zephyrproject.org/latest/boards/st/nucleo_f411re/doc/index.html#nucleo_f411re)。

<a id="building-and-running"></a>

## 21.3 构建与运行（Building and Running）

> 译注——执行前提：主机命令从读者自己的 Zephyr 源码根目录，用 UCRT64 Bash 或 Linux Bash 执行；先按[入门指南](../getting_started/大纲.md)准备模块、工具链和目标板。CMakeLists.txt 已选择 SHIELD=x_nucleo_iks4a1_shub2，所以原命令不必重复指定 --shield。先按本页链接核对扩展板硬件模式、供电和连接，再构建对应应用；设备不就绪时回查模式、总线、设备树与中断接线。下方是原文预期输出，本次未构建、烧录或实测。

本示例可在具有匹配 Arduino 接口并叠接 X-NUCLEO-IKS4A1 的开发板上运行。这里采用 [Nucleo F411RE](https://docs.zephyrproject.org/latest/boards/st/nucleo_f411re/doc/index.html#nucleo_f411re) 开发板。

```text
west build -b nucleo_f411re samples/shields/x_nucleo_iks4a1/sensorhub2/
west flash
```

<a id="sample-output"></a>

### 21.3.1 示例输出（Sample Output）

> 译注——数据来源与标签：prj.conf 关闭 LSM6DSO16IS 的芯片温度通道，日志中的 Temperature 来自外接 LPS22DF。标题 X-NUCLEO-IKS01A4 同时存在于官方日志与当前源码，是历史标签；不能因此改用另一块扩展板。

> 译注——读数单位：m/s^2 表示加速度，G 表示磁场高斯（Gauss），不是重力加速度单位 g；rad/s 表示角速度弧度每秒，温度用摄氏度、压力用 kPa。源码在一轮显示后休眠 2000 ms；传感器内部采样、触发更新和控制台刷新是不同节奏，日志数值不表示本次已完成标定或精度验收。

> ```text

>

> LSM6DSO16IS: Magn (G): x: 0.217, y: 0.015, z: -0.415
> LSM6DSO16IS: Temperature: 20.8 C
> LSM6DSO16IS: Pressure:99.756 kPa

>

> ```
