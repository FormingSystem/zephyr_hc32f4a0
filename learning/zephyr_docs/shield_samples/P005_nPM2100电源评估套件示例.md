# 第5章\_nPM2100 评估套件（nPM2100 EK）

原文：[官方页面](https://docs.zephyrproject.org/latest/samples/shields/npm2100_ek/index.html)。快照读取日期：2026-10-15；来源摘要见[来源记录](../SOURCES.md)。

[在 GitHub 浏览源码（Browse source code on GitHub）](https://github.com/zephyrproject-rtos/zephyr/blob/main//samples/shields/npm2100_ek/index.rst/..)

<a id="overview"></a>

## 5.1 概述（Overview）

本示例用于评估 nPM2100 EK，展示如何利用 nPM2100 的 GPIO 引脚和 Shell 接口控制以下功能： 相关链接：[nPM2100 评估套件（nPM2100 EK）](https://docs.zephyrproject.org/latest/boards/shields/npm2100_ek/doc/index.html#npm2100-ek)。

> - 稳压器（Regulators）：BOOST、LDOSW
>
> - 通用输入输出（GPIO）

<a id="requirements"></a>

## 5.2 硬件与配置要求（Requirements）

示例支持以下开发板：[nRF52840 DK](https://docs.zephyrproject.org/latest/boards/nordic/nrf52840dk/doc/index.html#nrf52840dk)、[nRF5340 DK](https://docs.zephyrproject.org/latest/boards/nordic/nrf5340dk/doc/index.html#nrf5340dk)。

还需要一套 nPM2100 评估套件（Evaluation Kit，EK），并按接线一节连接到开发套件。 相关链接：[接线（Wiring）](#wiring)。

<a id="wiring"></a>

## 5.3 接线（Wiring）

该配置由 nPM2100 EK 为 DK 供电，使双线接口（Two-Wire Interface，TWI）通信采用兼容电平，同时体现 nPM2100 PMIC 的实际使用场景。

注意（Note）

为避免漏电流并能够对 DK 编程，请保留 USB 连接。

> 译注——接线对象：这里要求保留的是主开发套件 DK 的 USB；后文移除 J4 USB 供电指 nPM2100 EK。两块板的接口不能混为一处。按原文先断开电池并关闭 DK 开关，再完成供电和信号连接。

接线时，从 nPM2100 EK 拔下电池，并将 DK 电源开关设为 OFF。接线后若无法与 DK 通信或编程，可尝试对 DK 和 EK 重新上电。

按以下步骤将 DK 连接到 nPM2100 EK：

1. 为 DK 由 nPM2100 EK 供电做好准备：

  - 将 SW9 开关“nRF power source”置于 VDD。

  - 将 SW10 开关“VEXT -> VnRF”置于 ON。

2. 按下表连接所选 DK 与 nPM2100 EK 的 TWI 接口和电源：

  | nPM2100 EK 引脚 | SDA | SCL | VOUT | GND |
| --- | --- | --- | --- | --- |
| nRF52840 DK 引脚 | P0.26 | P0.27 | P21 External supply +，外部电源正端 | GND |
| nRF5340 DK 引脚 | P1.02 | P1.03 | P21 External supply +，外部电源正端 | GND |

3. 在 nPM2100 EK 上完成以下连接：

  - 移除 J4 连接器上的 USB 供电。

  - 在 P6 排针上，用跳线连接 1、2 脚。

  - 在 BOOTMON 排针上，用跳线选择 OFF。

  - 在 VSET 排针上，用跳线选择 3.0V。

  - 将 VBAT SEL 开关置于 VBAT。

  - 将电池板连接到 BATTERY INPUT 连接器。

<a id="building-and-running"></a>

## 5.4 构建与运行（Building and Running）

> 译注——执行前提：主机命令在读者自己的 Zephyr 源码根目录，使用 UCRT64 Bash 或 Linux Bash 执行；先按[入门指南](../getting_started/大纲.md)准备模块和工具链，再核对本页指定主开发板、扩展板、接线与配置。设备 Shell 命令在目标板串口执行。遇到构建或设备就绪错误，先回查所选 board／shield 与接线；下方日志是官方预期示例。本次仅核对文档与源码，未构建、烧录、擦写存储或进行实板测量。

使用以下命令构建示例：

```text
west build -b nrf52840dk/nrf52840 samples/shields/npm2100_ek
```

注意（Note）

本示例自动将 `SHIELD` 设置为 `npm2100_ek`。烧录后进入 Shell 接口，通过 `regulator` 命令测试 PMIC；各子命令见下一节。

<a id="regulator-control"></a>

## 5.5 稳压器控制（Regulator control）

初始化成功时，终端显示以下状态信息：

```text
PMIC device ok
```

示例还会每两秒报告一次电池电压、升压输出电压及芯片内部温度（Die temperature）。

使用 EK 上的按钮控制稳压器，行为如下：

| 操作 | 结果 |
| --- | --- |
| 按下 GPIO0 按钮 | BOOST 输出强制进入高功率（High Power，HP）模式 |
| 释放 GPIO0 按钮 | BOOST 输出采用低功耗（Low Power，LP）模式 |
| 按下 GPIO1 按钮 | 负载开关（Load Switch）开启 |
| 释放 GPIO1 按钮 | 负载开关（Load Switch）关闭 |

`regulator` Shell 接口提供多个子命令，用于测试 PMIC 内部稳压器。

列出某个稳压器支持的全部电压：

```text
uart:~$ regulator vlist BOOST
1.800000 V
1.850000 V
...
```

启用或禁用稳压器：

```text
uart:~$ regulator enable LDOSW
uart:~$ regulator disable LDOSW
```

注意（Note）

BOOST 稳压器始终启用。

> 译注——控制路径：主程序将 BOOST 和 LDOSW 的模式控制源设为外部引脚，因此 GPIO0／GPIO1 按钮直接影响 PMIC 模式，不是 MCU 反复读取按钮再发 Shell 命令。BOOST 是升压转换器（Boost Converter），LDOSW 此处作为负载开关（Load Switch）使用。

设置稳压器输出电压：

```text
uart:~$ regulator vset BOOST 2.5v
uart:~$ regulator vget BOOST
2.500000 V
```

注意（Note）

BOOST 稳压器不能提供低于电池电压的输出。

> 译注——读数含义：电压设定值与真实输出电压是不同对象。当前主程序读取 VBAT、VOUT 和芯片温度后休眠两秒；应结合这些状态与实际供电条件判断，不能只根据 regulator vget 就断言外部电压已经达到目标。

获取 GPIO 状态：

```text
uart:~$ gpio get npm2100_gpio 0
0
```
