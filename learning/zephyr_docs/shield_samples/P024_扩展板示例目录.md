# 第24章\_扩展板（Shields）

原文：[官方页面](https://docs.zephyrproject.org/latest/samples/shields/shields.html)。快照读取日期：2026-10-15；来源摘要见[来源记录](../SOURCES.md)。

以下示例演示 Zephyr 中扩展板（Shield）的使用方式。

> 译注——阅读范围：目录条目保持官方顺序，每个本地链接指向已译正文。条目中的功能概括不替代正文的适用板卡、构建配置和限制；独立开发板说明、芯片绑定与API按全站清单另行统计。

- B-M2MEM-PACK1 扩展板（Shield）：按照标识 EEPROM 中保存的信息检查存储模块。 相关链接：[B-M2MEM-PACK1 扩展板（Shield）（B-M2MEM-PACK1 shield）](P001_B_M2MEM_PACK1存储扩展板.md#b-m2mem-pack1)。

- nPM13xx 评估套件（EK）：通过 Shell 接口与按钮操作 nPM1300 或 nPM1304 电源管理集成电路（PMIC）。 相关链接：[nPM13xx 评估套件（nPM13xx EK）](P004_nPM13xx电源评估套件示例.md#npm13xx_ek)。

- nPM2100 评估套件（EK）：通过评估套件按钮和 Shell 接口操作 nPM2100 PMIC。 相关链接：[nPM2100 评估套件（nPM2100 EK）](P005_nPM2100电源评估套件示例.md#npm2100_ek)。

- nPM6001 评估套件（EK）：通过 Shell 接口操作 nPM6001 PMIC。 相关链接：[nPM6001 评估套件（nPM6001 EK）](P006_nPM6001电源评估套件示例.md#npm6001_ek)。

- RTK0EG0019B01002BJ 电容触摸应用扩展板（Capacitive Touch Application Shield）：操作板上的电容触摸传感器与 LED 矩阵。 相关链接：[RTK0EG0019B01002BJ 电容触摸应用扩展板（Capacitive Touch Application Shield）（RTK0EG0019B01002BJ Capacitive Touch Application Shield）](P007_Renesas电容触摸扩展板.md#rtk0eg0019b01002bj)。

- X-NUCLEO-53L0A1 扩展板（Shield）：操作七段显示器与 VL53L0X 测距传感器。 相关链接：[X-NUCLEO-53L0A1 扩展板（Shield）（X-NUCLEO-53L0A1 shield）](P008_X_NUCLEO_53L0A1测距扩展板.md#x-nucleo-53l0a1)。

- X-NUCLEO-IKS01A1 扩展板（Shield）：访问扩展板上的全部传感器。 相关链接：[X-NUCLEO-IKS01A1 扩展板（Shield）（X-NUCLEO-IKS01A1 shield）](P009_X_NUCLEO_IKS01A1传感器示例.md#x-nucleo-iks01a1)。

- X-NUCLEO-PGEEZ1 M95P32 扩展操作（Extended Operations）：访问 M95P32 标识页并执行带缓冲的页编程。 相关链接：[X-NUCLEO-PGEEZ1：M95P32 扩展操作（X-NUCLEO-PGEEZ1 M95P32 extended operations）](P023_PGEEZ1扩展存储操作.md#x-nucleo-pgeez1)。
