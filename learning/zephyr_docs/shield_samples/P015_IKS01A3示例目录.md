# 第15章\_X-NUCLEO-IKS01A3 扩展板（Shield）

原文：[官方页面](https://docs.zephyrproject.org/latest/samples/shields/x_nucleo_iks01a3/README.html)。快照读取日期：2026-10-15；来源摘要见[来源记录](../SOURCES.md)。

以下示例展示 X-NUCLEO-IKS01A3 扩展板的多种功能。

> 译注——选择模式：标准模式由主机分别访问板上器件；SensorHub 模式由 LSM6DSO 代读选定外部传感器，默认外部组合为 LIS2MDL 与 LPS22HH。目录中的“全部传感器”是原文概括，具体可读通道以正文为准。

- [X-NUCLEO-IKS01A3 扩展板：传感器集线器模式（SensorHub，Mode 2）](P014_IKS01A3传感器集线器模式.md#x-nucleo-iks01a3-shub)——通过 Sensor Hub 模式访问扩展板上的全部传感器。

- [X-NUCLEO-IKS01A3 扩展板：标准模式（Standard，Mode 1）](P013_IKS01A3标准模式.md#x-nucleo-iks01a3-std)——通过标准模式访问扩展板上的全部传感器。
