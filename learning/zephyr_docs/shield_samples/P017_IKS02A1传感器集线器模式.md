# 第17章\_X-NUCLEO-IKS02A1 扩展板：传感器集线器模式（SensorHub，Mode 2）

原文：[官方页面](https://docs.zephyrproject.org/latest/samples/shields/x_nucleo_iks02a1/sensorhub/README.html)。快照读取日期：2026-10-15；来源摘要见[来源记录](../SOURCES.md)。

[在 GitHub 浏览源码（Browse source code on GitHub）](https://github.com/zephyrproject-rtos/zephyr/blob/main//samples/shields/x_nucleo_iks02a1/sensorhub/README.rst/..)

<a id="overview"></a>

## 17.1 概述（Overview）

本示例用于测试配置为传感器集线器模式（Sensor Hub，Mode 2）的 X-NUCLEO-IKS02A1。该配置的更多说明见《[X-NUCLEO-IKS02A1：MEMS 惯性与环境多传感器扩展板](https://docs.zephyrproject.org/latest/boards/shields/x_nucleo_iks02a1/doc/index.html#x-nucleo-iks02a1)》。

本示例启用 IIS2DLPC 与 ISM330DHCX 传感器。由于扩展板上的其他器件都连接到 ISM330DHCX，ISM330DHCX 驱动配置为传感器集线器模式（CONFIG_ISM330DHCX_SENSORHUB=y），以 IIS2MDC 磁力计（Magnetometer）作为外部从设备。

> 译注——两层总线：当前 _shub.overlay 注释明确把 JP7、JP8 设为 2–3，使 IIS2MDC 连接到 ISM330DHCX 的外部传感器总线。主机侧只声明 IIS2DLPC 和 ISM330DHCX；应用通过后者的 SENSOR_CHAN_MAGN_XYZ 读取 IIS2MDC。按本页链接核对扩展板版本与跳线，再配合该 overlay 使用。

随后周期性显示传感器数据。

- IIS2DLPC：三轴加速度（3-Axis Acceleration）

- ISM330DHCX：六轴加速度与角速度（6-Axis Acceleration and Angular Velocity）

- ISM330DHCX：来自 IIS2MDC 的三轴磁场强度。

<a id="requirements"></a>

## 17.2 硬件与配置要求（Requirements）

本示例通过 I2C 与叠接在 Arduino 接口开发板上的 X-NUCLEO-IKS02A1 通信。开发板必须为 Arduino 接口配置 I2C，包括引脚复用（Pin Muxing）与设备树（Devicetree）。可参考 [Nucleo F401RE](https://docs.zephyrproject.org/latest/boards/st/nucleo_f401re/doc/index.html#nucleo_f401re) 的开发板源码：

- [boards/st/nucleo_f401re/nucleo_f401re.dts](https://github.com/zephyrproject-rtos/zephyr/blob/main/boards/st/nucleo_f401re/nucleo_f401re.dts)

原文指出，不能在已支持扩展板上某种传感器的开发板上运行本示例，例如 disco_l475_iot1，因为不支持同类传感器的多个实例。

> 译注——多实例说明的版本边界：不能把原文表述泛化为当前 Zephyr 传感器框架的统一限制。当前 DEVICE_DT_GET_ONE() 在多个匹配节点中返回任意一个设备，示例没有明确区分板载与扩展板实例；例如当前 LSM6DSO 驱动已按每个启用节点生成设备。移植时仍需核对驱动能力、总线地址与选定节点，避免程序读到另一颗同型号传感器。

<a id="building-and-running"></a>

## 17.4 构建与运行（Building and Running）

> 译注——执行前提：主机命令从读者自己的 Zephyr 源码根目录，用 UCRT64 Bash 或 Linux Bash 执行；先按[入门指南](../getting_started/大纲.md)准备模块、工具链和目标板。CMakeLists.txt 已选择 SHIELD=x_nucleo_iks02a1_shub，所以原命令不必重复指定 --shield。先按本页链接核对扩展板硬件模式、供电和连接，再构建对应应用；设备不就绪时回查模式、总线、设备树与中断接线。下方是原文预期输出，本次未构建、烧录或实测。

本示例可在具有匹配 Arduino 接口并叠接 X-NUCLEO-IKS02A1 的开发板上运行。这里采用 [Nucleo F401RE](https://docs.zephyrproject.org/latest/boards/st/nucleo_f401re/doc/index.html#nucleo_f401re) 开发板。

```text
west build -b nucleo_f401re samples/shields/x_nucleo_iks02a1/sensorhub/
```

<a id="sample-output"></a>

### 17.4.1 示例输出（Sample Output）

> 译注——读数单位：m/s^2 表示加速度，G 表示磁场高斯（Gauss），不是重力加速度单位 g；rad/s 表示角速度弧度每秒，温度用摄氏度、压力用 kPa。源码在一轮显示后休眠 2000 ms；传感器内部采样、触发更新和控制台刷新是不同节奏，日志数值不表示本次已完成标定或精度验收。

> ```text
> X-NUCLEO-IKS02A1 sensor Mode 2 dashboard
>
> IIS2DLPC: Accel (m/s^2): x: 0.077, y: -0.766, z: 9.878
> ISM330DHCX: Accel (m/s^2): x: 0.383, y: -0.234, z: 9.763
> ISM330DHCX: Gyro (rad/s): x: 0.004, y: 0.003, z: -0.005
> ISM330DHCX: Magn (G): x: 0.171, y: 0.225, z: -0.363
> 7:: iis2dlpc trig 1215
> 7:: ism330dhcx acc trig 2494
> 7:: ism330dhcx gyr trig 2494
>
> <updated endlessly every 2 seconds>
> ```
