# 第2章\_LMP90100 传感器模拟前端评估板：电阻温度检测示例（RTD Sample）

原文：[官方页面](https://docs.zephyrproject.org/latest/samples/shields/lmp90100_evb/rtd/README.html)。快照读取日期：2026-10-15；来源摘要见[来源记录](../SOURCES.md)。

<a id="overview"></a>

## 2.1 概述（Overview）

本示例展示如何通过 LMP90100 传感器模拟前端（Analog Front End，AFE）评估板扩展板读取电阻温度检测器（Resistance Temperature Detector，RTD）的温度，针对三线制 PT100 传感器设计。

> 译注——换算依据：main.c 使用 100 Ω 标称电阻与 2000 Ω 参考电阻，按有符号 ADC 有效最大值换算电阻，再求解含一阶、二阶系数的温度公式。它是电阻温度检测（Resistance Temperature Detection）的演示，没有给出完整校准和全温区误差验证；下方电阻／温度日志也不是本次实测。

该扩展板的更多信息见 [LMP90100 传感器 AFE 评估板（LMP90100 Sensor AFE Evaluation Board）](https://docs.zephyrproject.org/latest/boards/shields/lmp90100_evb/doc/index.html#lmp90100-evb-shield)。

<a id="requirements"></a>

## 2.2 硬件与配置要求（Requirements）

运行前，必须按[《LMP90100 传感器 AFE 评估板用户指南》（LMP90100 Sensor AFE Evaluation Board User’s Guide）](http://www.ti.com/lit/pdf/snau028)示例 3“三线制 RTD 应用”（3-wire RTD Application），将 LMP90100 EVB 接到开发板。

<a id="building-and-running"></a>

> 译注——外部资料可用性：本次核对时，前述 TI 用户指南原链接返回 404，HTTPS 入口也未能确认可访问。原链接与文档编号 SNAU028 保留供追溯；接线须取得对应官方指南后核对，本译文不推测缺失资料中的端子连接。

## 2.3 构建与运行（Building and Running）

> 译注——执行前提：主机命令在读者自己的 Zephyr 源码根目录，使用 UCRT64 Bash 或 Linux Bash 执行；先按[入门指南](../getting_started/大纲.md)准备模块和工具链，再核对本页指定主开发板、扩展板、接线与配置。设备 Shell 命令在目标板串口执行。遇到构建或设备就绪错误，先回查所选 board／shield 与接线；下方日志是官方预期示例。本次仅核对文档与源码，未构建、烧录、擦写存储或进行实板测量。

本示例可在连接 LMP90100 EVB、具有匹配 Arduino 接口的开发板上运行。这里采用 [FRDM-K64F](https://docs.zephyrproject.org/latest/boards/nxp/frdm_k64f/doc/index.html#frdm_k64f)。

> 译注——扩展板选择：CMakeLists.txt 已设置 SHIELD=lmp90100_evb，因此下方命令没有另写 --shield。测量通道配置见 app.overlay；源码每次读取和输出后再休眠一秒，不能把它理解为精确的一秒采样时基。

```text
west build -b frdm_k64f samples/shields/lmp90100_evb/rtd
```
