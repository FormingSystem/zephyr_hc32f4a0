# 第10章\_X-NUCLEO-IKS01A2 扩展板：标准模式（Standard，Mode 1）

原文：[官方页面](https://docs.zephyrproject.org/latest/samples/shields/x_nucleo_iks01a2/standard/README.html)。快照读取日期：2026-10-15；来源摘要见[来源记录](../SOURCES.md)。

[在 GitHub 浏览源码（Browse source code on GitHub）](https://github.com/zephyrproject-rtos/zephyr/blob/main//samples/shields/x_nucleo_iks01a2/standard/README.rst/..)

<a id="overview"></a>

## 10.1 概述（Overview）

本示例启用 X-NUCLEO-IKS01A2 扩展板上的全部传感器，然后周期性读取并显示以下传感器数据：

- HTS221：环境温度与相对湿度（Ambient Temperature and Relative Humidity）

- LPS22HB：大气压力与环境温度（Atmospheric Pressure and Ambient Temperature）

- LSM6DSL：三轴加速度与三轴角速度（3-Axis Acceleration and Angular Velocity）

- LSM303AGR：三轴加速度与三轴磁场强度（3-Axis Acceleration and Magnetic Field Intensity）

> 译注——组合器件的接口：main.c 分别通过 st_lis2dh 与 st_lis2mdl 两个兼容标识获取 LSM303AGR 的加速度与磁场功能，并通过 LSM6DSL 获取另一组加速度和角速度。日志中的两组加速度属于不同器件，不是同一读数的重复打印。

<a id="requirements"></a>

## 10.2 硬件与配置要求（Requirements）

本示例通过 I2C 与叠接在 Arduino 接口开发板上的 X-NUCLEO-IKS01A2 通信。开发板必须在设备树中为 Arduino 接口配置 I2C。可参考 [Nucleo F401RE](https://docs.zephyrproject.org/latest/boards/st/nucleo_f401re/doc/index.html#nucleo_f401re) 的开发板源码：

- [boards/st/nucleo_f401re/nucleo_f401re.dts](https://github.com/zephyrproject-rtos/zephyr/blob/main/boards/st/nucleo_f401re/nucleo_f401re.dts)

- [boards/st/nucleo_f401re/arduino_r3_connector.dtsi](https://github.com/zephyrproject-rtos/zephyr/blob/main/boards/st/nucleo_f401re/arduino_r3_connector.dtsi)

原文指出，不能在已支持扩展板上某种传感器的开发板上运行本示例，例如 disco_l475_iot1，因为 Zephyr 尚不支持同类传感器的多个实例。

> 译注——多实例说明的版本边界：不能把原文表述泛化为当前 Zephyr 传感器框架的统一限制。当前 DEVICE_DT_GET_ONE() 在多个匹配节点中返回任意一个设备，示例没有明确区分板载与扩展板实例；例如当前 LSM6DSO 驱动已按每个启用节点生成设备。移植时仍需核对驱动能力、总线地址与选定节点，避免程序读到另一颗同型号传感器。

<a id="building-and-running"></a>

## 10.4 构建与运行（Building and Running）

> 译注——执行前提：主机命令从读者自己的 Zephyr 源码根目录，用 UCRT64 Bash 或 Linux Bash 执行；先按[入门指南](../getting_started/大纲.md)准备模块、工具链和目标板。CMakeLists.txt 已选择 SHIELD=x_nucleo_iks01a2，所以原命令不必重复指定 --shield。先按本页链接核对扩展板硬件模式、供电和连接，再构建对应应用；设备不就绪时回查模式、总线、设备树与中断接线。下方是原文预期输出，本次未构建、烧录或实测。

本示例可在具有匹配 Arduino 接口并叠接 X-NUCLEO-IKS01A2 的开发板上运行。这里采用 [Nucleo F401RE](https://docs.zephyrproject.org/latest/boards/st/nucleo_f401re/doc/index.html#nucleo_f401re) 开发板。

```text
west build -b nucleo_f401re samples/shields/x_nucleo_iks01a2/standard
```

<a id="sample-output"></a>

### 10.4.1 示例输出（Sample Output）

> 译注——读数单位：m/s^2 表示加速度，G 表示磁场高斯（Gauss），不是重力加速度单位 g；rad/s 表示角速度弧度每秒，温度用摄氏度、压力用 kPa。源码在一轮显示后休眠 2000 ms；传感器内部采样、触发更新和控制台刷新是不同节奏，日志数值不表示本次已完成标定或精度验收。

> ```text
> X-NUCLEO-IKS01A2 sensor dashboard
>
> HTS221: Temperature: 26.3 C
> HTS221: Relative Humidity: 44.5%
> LPS22HB: Pressure:99.220 kPa
> LPS22HB: Temperature: 26.1 C
> LSM6DSL: Accel (m/s^2): x: -0.0, y: -0.1, z: 10.0
> LSM6DSL: Gyro (rad/s): x: 0.028, y: -0.025, z: 0.014
> LSM303AGR: Accel (m/s^2): x: 0.3, y: -0.1, z: 9.7
> LSM303AGR: Magn (G): x: -0.221, y: -0.042, z: -0.458
>
> <updated endlessly every 2 seconds>
> ```
