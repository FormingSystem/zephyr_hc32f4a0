# 第18章\_X-NUCLEO-IKS02A1 扩展板（Shield）

原文：[官方页面](https://docs.zephyrproject.org/latest/samples/shields/x_nucleo_iks02a1/README.html)。快照读取日期：2026-10-15；来源摘要见[来源记录](../SOURCES.md)。

以下示例展示 X-NUCLEO-IKS02A1 扩展板的多种功能。

> 译注——独立功能：MEMS 麦克风沿用已有音频译文，不重复计数；标准模式与 SensorHub 模式分别说明运动／磁场器件的直连与转读。这三页的完成不代表扩展板说明书或全部传感器 API 已译完。

- X-NUCLEO-IKS02A1 扩展板：MEMS 麦克风（Microphone）——通过扩展板上的数字 MEMS 麦克风采集音频。 相关链接：[X-NUCLEO-IKS02A1：MEMS 麦克风（Microphone）](../hardware/P082_扩展板MEMS麦克风示例.md#x-nucleo-iks02a1-mic)。

- [X-NUCLEO-IKS02A1 扩展板：传感器集线器模式（SensorHub，Mode 2）](P017_IKS02A1传感器集线器模式.md#x-nucleo-iks02a1-shub)——通过 Sensor Hub 模式访问扩展板上的全部传感器。

- [X-NUCLEO-IKS02A1 扩展板：标准模式（Standard，Mode 1）](P016_IKS02A1标准模式.md#x-nucleo-iks02a1-std)——通过标准模式访问扩展板上的全部传感器。
