## 12.1 漏洞记录（CVE 2017-14199）

官方编号：[CVE 2017-14199](https://www.cve.org/CVERecord?id=CVE-2017-14199)。

`getaddrinfo()` 中存在缓冲区溢出（buffer overflow）。

[Zephyr 项目缺陷跟踪（bug tracker）：ZEPSEC-12](https://zephyrprojectsec.atlassian.net/browse/ZEPSEC-12)。

[PR6158：针对 1.11.0 的修复](https://github.com/zephyrproject-rtos/zephyr/pull/6158)。

<a id="cve-2017-14201"></a>

<a id="index-1"></a>

## 12.2 漏洞记录（CVE 2017-14201）

官方编号：[CVE 2017-14201](https://www.cve.org/CVERecord?id=CVE-2017-14201)。

Shell 的域名系统（Domain Name System，DNS）命令错误使用栈变量，可能产生不可预测的结果。

Zephyr Shell 中的释放后使用（Use After Free）漏洞，使通过串口或 Telnet 连接的用户能够造成拒绝服务（denial of service），并可能导致远程代码执行（remote code execution）。

此问题已在发行版 v1.14.0 中修复。

[Zephyr 项目缺陷跟踪（bug tracker）：ZEPSEC-17](https://zephyrprojectsec.atlassian.net/browse/ZEPSEC-17)。

[PR13260：针对 v1.14.0 的修复](https://github.com/zephyrproject-rtos/zephyr/pull/13260)。

<a id="cve-2017-14202"></a>

<a id="index-2"></a>

## 12.3 漏洞记录（CVE 2017-14202）

官方编号：[CVE 2017-14202](https://www.cve.org/CVERecord?id=CVE-2017-14202)。

Shell 实现未防止缓冲区越界（buffer overrun），从而产生不可预测的行为。

Zephyr Shell 组件对内存缓冲区边界内操作的限制不当，使通过串口或 Telnet 连接的用户能够引发崩溃，并可能导致任意代码执行（arbitrary code execution）。

此问题已在发行版 v1.14.0 中修复。

[Zephyr 项目缺陷跟踪（bug tracker）：ZEPSEC-18](https://zephyrprojectsec.atlassian.net/browse/ZEPSEC-18)。

[PR13048：针对 v1.14.0 的修复](https://github.com/zephyrproject-rtos/zephyr/pull/13048)。
