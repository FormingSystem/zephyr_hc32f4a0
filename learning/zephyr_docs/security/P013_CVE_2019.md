## 13.1 漏洞记录（CVE 2019-9506）

官方编号：[CVE 2019-9506](https://www.cve.org/CVERecord?id=CVE-2019-9506)。

截至并包括 5.1 版的蓝牙基本速率／增强数据速率（Bluetooth BR/EDR）规范允许使用足够短的加密密钥，也没有阻止攻击者影响密钥长度协商。这使实际可行的暴力破解攻击（brute-force attack，亦称“KNOB”）成为可能，攻击者可以在受害方不知情的情况下解密通信流量并注入任意密文（ciphertext）。

[Zephyr 项目缺陷跟踪（bug tracker）：ZEPSEC-20](https://zephyrprojectsec.atlassian.net/browse/ZEPSEC-20)。

[PR18702：针对 v1.14.0 的修复](https://github.com/zephyrproject-rtos/zephyr/pull/18702)。

[PR18659：针对 v2.0.0 的修复](https://github.com/zephyrproject-rtos/zephyr/pull/18659)。
