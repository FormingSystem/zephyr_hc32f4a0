# 第18章\_CVE\_2024

原文：[官方页面](https://docs.zephyrproject.org/latest/security/vulnerabilities/2024.html)。读取日期：2026-10-14；保存的 latest 页面及 HTML 摘要见[来源记录](../SOURCES.md)。

## 18.1 漏洞记录（CVE 2024-1638）

官方编号：[CVE 2024-1638](https://www.cve.org/CVERecord?id=CVE-2024-1638)。

没有额外标志时，蓝牙特征（characteristic）的低功耗安全连接（LE Secure Connections，LESC）安全要求未被强制执行。

[Zephyr 项目缺陷跟踪（bug tracker）：GHSA-p6f3-f63q-5mc2](https://github.com/zephyrproject-rtos/zephyr/security/advisories/GHSA-p6f3-f63q-5mc2)。

此问题已在 main 分支中修复，面向 v3.6.0。

[PR 69170：针对 main 的修复](https://github.com/zephyrproject-rtos/zephyr/pull/69170)。

<a id="cve-2024-3077"></a>

<a id="index-1"></a>

## 18.2 漏洞记录（CVE 2024-3077）

官方编号：[CVE 2024-3077](https://www.cve.org/CVERecord?id=CVE-2024-3077)。

蓝牙：`gatt_find_info_rsp` 中发生整数下溢。恶意蓝牙低功耗（Bluetooth LE）设备可以通过发送畸形 GATT 数据包使受害设备崩溃。

[Zephyr 项目缺陷跟踪（bug tracker）：GHSA-gmfv-4vfh-2mh8](https://github.com/zephyrproject-rtos/zephyr/security/advisories/GHSA-gmfv-4vfh-2mh8)。

此问题已在 main 分支中修复，面向 v3.7.0。

[PR 69396：针对 main 的修复](https://github.com/zephyrproject-rtos/zephyr/pull/69396)。

<a id="cve-2024-3332"></a>

<a id="index-2"></a>

## 18.3 漏洞记录（CVE 2024-3332）

官方编号：[CVE 2024-3332](https://www.cve.org/CVERecord?id=CVE-2024-3332)。

蓝牙：空指针解引用（null pointer dereference）导致拒绝服务（DoS）。

恶意蓝牙低功耗设备可以按特定顺序发送数据包，对受害蓝牙低功耗设备实施拒绝服务攻击。

[Zephyr 项目缺陷跟踪（bug tracker）：GHSA-jmr9-xw2v-5vf4](https://github.com/zephyrproject-rtos/zephyr/security/advisories/GHSA-jmr9-xw2v-5vf4)。

此问题已在 main 分支中修复，面向 v3.7.0。

[PR 71030：针对 main 的修复](https://github.com/zephyrproject-rtos/zephyr/pull/71030)。

## 18.15 漏洞记录（CVE 2024-10395）

官方编号：[CVE 2024-10395](https://www.cve.org/CVERecord?id=CVE-2024-10395)。

网络 HTTP 服务端：缓冲区前向越界读取（buffer under-read）。

`http_server_get_content_type_from_extension` 未正确验证用户输入长度，可能在缓冲区边界之外读取内存，导致段错误（segmentation fault）或崩溃。

[Zephyr 项目缺陷跟踪（bug tracker）：GHSA-hfww-j92m-x8fv](https://github.com/zephyrproject-rtos/zephyr/security/advisories/GHSA-hfww-j92m-x8fv)。

[PR 80396：针对 main 的修复](https://github.com/zephyrproject-rtos/zephyr/pull/80396)。

## 18.16 漏洞记录（CVE 2024-11263）

官方编号：[CVE 2024-11263](https://www.cve.org/CVERecord?id=CVE-2024-11263)。

RISC-V 架构的用户空间：`CONFIG_RISCV_GP=y` 时存在潜在安全风险。

恶意线程可以破坏全局指针寄存器（gp register）；较轻的后果是使整个系统发生硬故障（hard fault），更严重时可能诱使系统访问另一组随机的全局符号（global symbols）。

[Zephyr 项目缺陷跟踪（bug tracker）：GHSA-jjf3-7x72-pqm9](https://github.com/zephyrproject-rtos/zephyr/security/advisories/GHSA-jjf3-7x72-pqm9)。

此问题已在 main 分支中修复，面向 v4.0.0。

[PR 81155：针对 main 的修复](https://github.com/zephyrproject-rtos/zephyr/pull/81155)。

[PR 81370：针对 3.7 的修复](https://github.com/zephyrproject-rtos/zephyr/pull/81370)。
