# 第9章\_安全标准与Zephyr

原文：[官方页面](https://docs.zephyrproject.org/latest/security/standards/index.html)。读取日期：2026-10-14；保存的 latest 页面及 HTML 摘要见[来源记录](../SOURCES.md)。

过去，组织通常各自管理网络安全（cybersecurity），自行制定评估与响应规程。如今，各国政府越来越多地通过新的强制要求和安全标准监管这一领域。这些标准为联网产品规定具体指南与合规要求。

本节评估这些安全标准对 Zephyr 项目本身及下游产品开发者的影响，目标是提供开发者使用 Zephyr 构建可认证、符合要求的产品所需的信息。

- [欧盟网络韧性法案（EU Cyber Resilience Act，CRA）](P010_欧盟网络韧性法案CRA.md)。
- [ETSI 303-645 标准](P011_ETSI_303645.md)。


对应官方文档源码：[doc/security/standards/index.rst](https://raw.githubusercontent.com/zephyrproject-rtos/zephyr/main/doc/security/standards/index.rst)。
