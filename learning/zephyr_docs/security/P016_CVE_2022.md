# 第16章\_CVE\_2022

原文：[官方页面](https://docs.zephyrproject.org/latest/security/vulnerabilities/2022.html)。读取日期：2026-10-14；保存的 latest 页面及 HTML 摘要见[来源记录](../SOURCES.md)。

> 译注——历史记录与版本：本页按官方年份归档翻译通用漏洞与披露（Common Vulnerabilities and Exposures，CVE）记录。下文“已修复”“尚未修复”“将纳入”等均为原页记载；版本号、PR、提交和公告链接照原文保留，不代表本仓库已验证修复或当前产品一定受影响。拉取请求（pull request，PR）与 GitHub 安全公告（GitHub Security Advisory，GHSA）用于追溯修复和披露。

## 16.1 漏洞记录（CVE 2022-0553）

官方编号：[CVE 2022-0553](https://www.cve.org/CVERecord?id=CVE-2022-0553)。

可能取得未加密的固件镜像（firmware image）。

此问题已在 main 分支中修复，面向 v3.0.0。

[Zephyr 项目缺陷跟踪（bug tracker）：GHSA-wrj2-9vj9-rrcp](https://github.com/zephyrproject-rtos/zephyr/security/advisories/GHSA-wrj2-9vj9-rrcp)。

[PR 42424：针对 main 的修复](https://github.com/zephyrproject-rtos/zephyr/pull/42424)。

<a id="cve-2022-1041"></a>

<a id="index-1"></a>

## 16.2 漏洞记录（CVE 2022-1041）

官方编号：[CVE 2022-1041](https://www.cve.org/CVERecord?id=CVE-2022-1041)。

蓝牙网状网络（Bluetooth Mesh）核心协议栈中的越界写入漏洞可在配网（provisioning）过程中触发。

此问题已在 main 分支中修复，面向 v3.1.0。

[Zephyr 项目缺陷跟踪（bug tracker）：GHSA-p449-9hv9-pj38](https://github.com/zephyrproject-rtos/zephyr/security/advisories/GHSA-p449-9hv9-pj38)。

[PR 45136：针对 main 的修复](https://github.com/zephyrproject-rtos/zephyr/pull/45136)。

[PR 45188：针对 v3.0.0 的修复](https://github.com/zephyrproject-rtos/zephyr/pull/45188)。

[PR 45187：针对 v2.7.0 的修复](https://github.com/zephyrproject-rtos/zephyr/pull/45187)。

## 16.4 漏洞记录（CVE 2022-1841）

官方编号：[CVE 2022-1841](https://www.cve.org/CVERecord?id=CVE-2022-1841)。

`tcp_flags` 中存在越界写入（out-of-bounds write）。

此问题已在 main 分支中修复，面向 v3.1.0。

[Zephyr 项目缺陷跟踪（bug tracker）：GHSA-5c3j-p8cr-2pgh](https://github.com/zephyrproject-rtos/zephyr/security/advisories/GHSA-5c3j-p8cr-2pgh)。

[PR 45796：针对 main 的修复](https://github.com/zephyrproject-rtos/zephyr/pull/45796)。

## 16.5 漏洞记录（CVE 2022-2741）

官方编号：[CVE 2022-2741](https://www.cve.org/CVERecord?id=CVE-2022-2741)。

控制器局域网（CAN）：特制 CAN 帧可以触发拒绝服务（denial of service）。

此问题已在 main 分支中修复，面向 v3.2.0。
