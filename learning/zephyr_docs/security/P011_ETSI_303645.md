# 第11章\_ETSI\_303645

原文：[官方页面](https://docs.zephyrproject.org/latest/security/standards/etsi-303645.html)。读取日期：2026-10-14；保存的 latest 页面及 HTML 摘要见[来源记录](../SOURCES.md)。

**ETSI EN 303 645**，也称《消费物联网网络安全：基线要求》（Cyber Security for Consumer Internet of Things: Baseline Requirements），是欧洲电信标准协会（European Telecommunications Standards Institute，ETSI）制定的一项标准。

该标准包含安全软件更新、数据保护、安全通信、尽量缩小暴露的攻击面（attack surface）等条款，是应对物联网（Internet of Things，IoT）设备相关挑战和风险的更广泛工作的一部分。

完整标准可从[官方 PDF](https://www.etsi.org/deliver/etsi_en/303600_303699/303645/02.01.01_60/en_303645v020101p.pdf)获取。

<a id="terminology"></a>

## 11.1 术语（Terminology）

<a id="id2"></a>

**ETSI 303645 术语（ETSI 303645 terminology）**：

| 术语（Term） | 定义（Definition） |
| --- | --- |
| 管理员（administrator） | 在设备用户中拥有最高权限的用户，可能可以修改与预期功能有关的任何配置。 |
| 关联服务（associated services） | 与设备共同组成整个消费物联网产品的数字服务，通常是提供产品预期功能所必需的。 |
| 认证机制（authentication mechanism） | 用于证明实体真实性的方法。 |
| 认证值（authentication value） | 认证机制所使用的某个属性的具体值。 |
| 最佳实践密码技术（best practice cryptography） | 适用于相应用例，而且没有迹象表明能够利用当前容易获取的技术对其实施可行攻击的密码技术。 |
| 受限设备（constrained device） | 由于预期用途带来的限制，在数据处理、数据通信、数据存储或与用户交互能力方面存在物理限制的设备。 |
| 消费者（consumer） | 为其贸易、经营、手工业或职业活动范围之外的目的行事的自然人。 |
| 消费物联网设备（consumer IoT device） | 已联网或能够联网、与关联服务存在关系的设备，消费者通常在家中使用，或将其作为可穿戴电子设备使用。 |
| 关键安全参数（critical security parameter） | 与安全有关的秘密信息；其泄露或被修改可能破坏安全模块的安全性。 |
| 调试接口（debug interface） | 制造商在开发期间用于与设备通信或排查设备问题的物理接口，不属于面向消费者的功能。 |
| 规定支持期（defined support period） | 制造商提供安全更新的最短时间，以持续时长或截止日期表示。 |
| 设备制造商（device manufacturer） | 将产品组装成最终消费物联网产品的实体；产品很可能包含许多其他供应商的产品和组件。 |
| 出厂默认状态（factory default） | 设备恢复出厂设置后，或最终生产／组装完成后的状态。 |
| 初始化（initialization） | 激活设备网络连接使其投入运行的过程，还可以为用户或网络访问设置认证功能。 |
| 已初始化状态（initialized state） | 设备完成初始化后的状态。 |
| 物联网产品（IoT product） | 消费物联网设备及其关联服务。 |
| 可隔离（isolable） | 能够从其所连接的网络移除，且由此导致的功能损失仅涉及连接能力、不影响主要功能；或者能够与其他设备一起置于自包含环境中，但前提是能够保证该环境中设备的完整性。 |
| 逻辑接口（logical interface） | 利用网络接口，通过通道或端口在网络上通信的软件实现。 |
| 制造商（manufacturer） | 供应链中的相关经济运营者，包括设备制造商。 |
| 网络接口（network interface） | 可通过网络访问消费物联网功能的物理接口。 |
| 所有者（owner） | 拥有或购买了设备的用户。 |
| 个人数据（personal data） | 与已识别或可识别的自然人有关的任何信息。 |
| 物理接口（physical interface） | 在物理层用于与设备通信的物理端口或空中接口，例如无线电、音频或光学接口。 |
| 公开安全参数（public security parameter） | 与安全有关的公开信息；其被修改可能破坏安全模块的安全性。 |
| 可远程访问（remotely accessible） | 预期可以从本地网络之外访问。 |
| 安全模块（security module） | 实现安全功能的一组硬件、软件和／或固件。 |
| 安全更新（security update） | 用于处理制造商发现或收到报告的安全漏洞的软件更新。 |
| 敏感安全参数（sensitive security parameters） | 关键安全参数与公开安全参数。 |
| 软件服务（software service） | 设备中用于支持某种功能的软件组件。 |
| 遥测（telemetry） | 来自设备的数据，可提供帮助制造商识别问题的信息，或有关设备使用情况的信息。 |
| 每设备唯一（unique per device） | 对于某一产品类别或类型中的每个具体设备都唯一。 |
| 用户（user） | 自然人或组织。 |

## 11.2 条款评估（Provisions Assessment）

下表使用 ETSI EN 303 645 的表 B.1 进行自我评估，特别关注作为物联网产品组件的 Zephyr 实时操作系统（Real-Time Operating System，RTOS）。

按照 ETSI 303 645，表 B.1 提供了一种说明标准条款实现情况的机制。Zephyr 采用了标准中的以下记号。

**ETSI 303645 表 B.1 记号（ETSI 303645 Table B.1 notations）**：

| 记号（Notation） | 含义（Meaning） |
| --- | --- |

| R | 条款是建议（recommendation）。 |
| M C | 条款是有条件的强制要求（mandatory and conditional）。 |
| R C | 条款是有条件的建议（recommendation and conditional）。 |
| Y | Zephyr 支持此条款（supported）。 |
| N | Zephyr 不支持此条款（not supported）。 |
| N/A | 此条款不适用于 Zephyr，或由产品制造商负责（not applicable / product maker responsibility）。 |
