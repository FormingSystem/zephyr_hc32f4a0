# 安全官方译文大纲

本册涵盖 Zephyr 官方安全开发流程、编码原则、控制流保护、配置加固、传感器威胁模型与漏洞报告。专有名词保留中英文对照；原图按原始格式保存，源码跟踪使用相对链接。流程要求和历史规划按原文翻译，源码核对及版本边界单独标为译注。

1. [安全文档入口](P001_安全文档入口.md)：官方安全文档分类。
2. [Zephyr安全概览](P002_Zephyr安全概览.md)：开发、安全设计、架构、威胁建模、质量保证和认证流程。
3. [安全编码](P003_安全编码.md)：设计原则、开发者知识、代码审查和敏感问题管理。
4. [控制流完整性](P004_控制流完整性.md)：前向边、返回边、影子栈、Intel CET、ARM PAC 与 BTI。
5. [安全加固工具](P005_安全加固工具.md)：hardenconfig、配置档、分散规则数据库和树外扩展。
6. [传感器设备威胁模型](P006_传感器设备威胁模型.md)：资产、Flash 分区、云通信、密钥、时间与生命周期。
7. [安全漏洞报告](P007_安全漏洞报告.md)：报告内容、私密公告、披露、通知和修复回移。

9. [安全标准与Zephyr](P009_安全标准与Zephyr.md)：标准背景与两份官方说明入口。
10. [欧盟网络韧性法案CRA](P010_欧盟网络韧性法案CRA.md)：产品类别、评估路径、制造商与管理者义务、报告时间表及外部依据。
