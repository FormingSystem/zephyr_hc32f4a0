# 第8章\_安全文献引用

原文：[官方页面](https://docs.zephyrproject.org/latest/security/security-citations.html)。读取日期：2026-10-14；保存的 latest 页面及 HTML 摘要见[来源记录](../SOURCES.md)。

## 8.1\_安全文献引用（Security Document Citations）

以下保留原文引用标识、作者、年份、版本及链接；标题提供中英文对照。

<a id="salt75"></a>

### 8.1.1\_SALT75

J. H. Saltzer 与 M. D. Schroeder，《计算机系统中的信息保护》（The protection of information in computer systems），《IEEE 会刊》（Proceedings of the IEEE），第 63 卷第 9 期，第 1278–1308 页，1975 年 9 月。在线来源：[MIT 保存的论文](https://web.mit.edu/Saltzer/www/publications/protection/)。

<a id="paul09"></a>

### 8.1.2\_PAUL09

M. Paul，《安全软件开发的十大最佳实践》（The Ten Best Practices for Secure Software Development），国际信息系统安全认证联盟（International Information Systems Security Certification Consortium, Inc.，[(ISC)2®]），美国佛罗里达州 Palm Harbor，2009 年。

<a id="ms12"></a>

### 8.1.3\_MS12

Microsoft Corporation，《安全开发生命周期——SDL 流程指南》（Security Development Lifecycle - SDL Process Guidance），版本 5.2，2012 年。

<a id="ccitse12"></a>

### 8.1.4\_CCITSE12

《信息技术安全评估通用准则》（Common Criteria for Information Technology Security Evaluation），版本 3.1、修订 4，2012 年。

<a id="micr16"></a>

### 8.1.5\_MICR16

Micrium，《认证套件》（Certification Kits），2016 年。在线来源：[Micrium Certification Kits](https://www.micrium.com/certification/certification-kits/)。

<a id="nist02"></a>

### 8.1.6\_NIST02

美国国家标准与技术研究院（National Institute of Standards and Technology，NIST），FIPS PUB 140-2，2002 年，Gaithersburg。原文所列题名为 `Security Requirements for COMPANY PUBLIC Application note Cryptographic Modules`。

> 译注：其主题为“密码模块安全要求”；原题名中夹有 `COMPANY PUBLIC Application note` 字样，这里完整保留以便溯源。

<a id="ghs10"></a>

### 8.1.7\_GHS10

Green Hills Software，《INTEGRITY-178B 隔离内核安全目标 v4.2》（INTEGRITY-178B Separation Kernel Security Target v4.2），2010 年。

<a id="rfc2119"></a>

### 8.1.8\_RFC2119

S. Bradner，《RFC 中表示要求级别的关键词》（Key words for use in RFCs to Indicate Requirement Levels），BCP 14、RFC 2119，DOI `10.17487/RFC2119`，1997 年 3 月。在线来源：[RFC 2119](https://www.rfc-editor.org/info/rfc2119)。

<a id="stride09"></a>

### 8.1.9\_STRIDE09

Microsoft Corporation，《STRIDE 威胁模型》（The STRIDE Threat Model），2009 年。在线来源：[原文 MSDN 引用](https://msdn.microsoft.com/en-us/library/ee823878%28v=cs.20%29.aspx)。

<a id="cvss"></a>

### 8.1.10\_CVSS

事件响应与安全团队论坛（Forum of Incident Response and Security Teams，FIRST），《通用漏洞评分系统 v3.0：规范文档》（Common Vulnerability Scoring System v3.0: Specification Document）。在线来源：[CVSS 规范页面](https://www.first.org/cvss/specification-document)。

<a id="owasp"></a>

### 8.1.11\_OWASP

开放 Web 应用安全项目（Open Web Application Security Project，OWASP），《应用威胁建模》（Application Threat Modeling）。在线来源：[原文 OWASP 引用](https://www.owasp.org/index.php/Application_Threat_Modeling)。

> 译注：该历史地址本次返回404。OWASP 的应用威胁建模入口已指向[当前威胁建模页面](https://community.owasp.org/Threat_Modeling)；保留旧引用，并提供当前阅读入口。

<a id="ciibpb"></a>

### 8.1.12\_CIIBPB

核心基础设施倡议最佳实践徽章（Core Infrastructure Initiative Best Practices Badge）。在线来源：[原文项目仓库](https://github.com/linuxfoundation/cii-best-practices-badge)。

<a id="cra24"></a>

### 8.1.13\_CRA24

欧洲议会与理事会于 2024 年 10 月 23 日制定的条例（EU）2024/2847，规定含数字要素产品的横向网络安全要求，即《网络韧性法案》（Cyber Resilience Act，CRA）。在线来源：[欧盟条例原文](https://eur-lex.europa.eu/legal-content/EN/TXT/HTML/?uri=OJ:L_202402847)。

> 译注：本页是官方文献目录的翻译。引用中的年份和版本是被引用文献的标识，不表示它们都是当前最新版本；部分历史链接可能重定向或失效，访问结果见本集验证记录。


对应官方文档源码：[doc/security/security-citations.rst](https://raw.githubusercontent.com/zephyrproject-rtos/zephyr/main/doc/security/security-citations.rst)。
