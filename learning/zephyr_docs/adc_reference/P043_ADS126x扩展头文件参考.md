# 第43章\_ADS126x扩展头文件参考

原文：[ads126x_8h](https://docs.zephyrproject.org/latest/doxygen/html/ads126x_8h.html)。读取日期：2026-10-13，`latest`。

`zephyr/drivers/adc/ads126x.h` 是Texas Instruments（德州仪器）ADS126X模数转换器（Analog-to-Digital Converter，ADC）的驱动应用程序接口（Application Programming Interface，API）头文件。

原文件说明将ADS126X描述为32位、10通道、低功耗Σ-Δ模数转换器（Delta-Sigma ADC），集成可编程增益放大器（Programmable Gain Amplifier，PGA）、参考电压（Reference Voltage，VREF）、串行外设接口（Serial Peripheral Interface，SPI）以及两个电流输出数模转换器（Current-Output Digital-to-Analog Converter，IDAC）。

## 43.1\_模拟多路复用输入枚举

枚举（Enumeration）`enum ads126x_mux_input` 定义模拟多路复用器（Analog Multiplexer，MUX）的输入选择。原文件参考页列出全部名称与显式编码；中文输入说明与对应[ADS126X驱动接口](../hardware/P472_ADS126X驱动接口.md)衔接。

| 枚举项 | 原始值 | 输入含义 |
| --- | --- | --- |
| `ADS126X_MUX_AIN0` | `0x00` | 模拟输入（Analog Input）AIN0 |
| `ADS126X_MUX_AIN1` | `0x01` | 模拟输入（Analog Input）AIN1 |
| `ADS126X_MUX_AIN2` | `0x02` | 模拟输入（Analog Input）AIN2 |
| `ADS126X_MUX_AIN3` | `0x03` | 模拟输入（Analog Input）AIN3 |
| `ADS126X_MUX_AIN4` | `0x04` | 模拟输入（Analog Input）AIN4 |
| `ADS126X_MUX_AIN5` | `0x05` | 模拟输入（Analog Input）AIN5 |
| `ADS126X_MUX_AIN6` | `0x06` | 模拟输入（Analog Input）AIN6 |
| `ADS126X_MUX_AIN7` | `0x07` | 模拟输入（Analog Input）AIN7 |
| `ADS126X_MUX_AIN8` | `0x08` | 模拟输入（Analog Input）AIN8 |
| `ADS126X_MUX_AIN9` | `0x09` | 模拟输入（Analog Input）AIN9 |
| `ADS126X_MUX_AINCOM` | `0x0A` | 公共模拟输入（Common Analog Input） |
| `ADS126X_MUX_TEMP` | `0x0B` | 内部温度传感器（Internal Temperature Sensor） |
| `ADS126X_MUX_AVDD` | `0x0C` | AVDD供电监视（Supply Monitor） |
| `ADS126X_MUX_DVDD` | `0x0D` | DVDD供电监视 |
| `ADS126X_MUX_TDAC` | `0x0E` | TDAC输出（TDAC Output） |
| `ADS126X_MUX_OPEN` | `0x0F` | 开路输入选择（Open Input Selection） |

## 43.2\_参考范围

AVDD、DVDD、TDAC保留器件内部电源或信号源名称；不根据宏后缀额外推定量程。本文件参考页列出上述一个枚举，没有额外的函数声明。完整可见定义见[源码页](P044_ADS126x扩展头文件源码.md)。
