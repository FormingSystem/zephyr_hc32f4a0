# 第5章\_AD4170设备树常量参考

原文：[ad4170-adc_8h](https://docs.zephyrproject.org/latest/doxygen/html/ad4170-adc_8h.html)。读取日期：2026-10-13，`latest`。

`zephyr/dt-bindings/adc/ad4170-adc.h` 为模数转换器（Analog-to-Digital Converter，ADC）定义输入映射、工作模式、时钟选择和滤波器类型常量。设备树（Devicetree）绑定使用这些宏（Macro）表达硬件配置；原始声明见[源码页](P006_AD4170设备树常量源码.md)。

```c
#include <zephyr/dt-bindings/dt-util.h>
```

译注：原页除AIN9至AIN15的型号限制外，主要列宏名及其数值。以下中文释义用于阅读标识符，不额外承诺器件支持范围；具体属性限制见[AD4170绑定](../hardware/P915_ADIAD4170模数转换器绑定.md)。

## 5.1\_输入映射

原文明确指出：**AIN9至AIN15仅供AD4195-8／AD4190-8使用**。这些宏出现在AD4170命名的头文件中，并不表示AD4170本身拥有这些额外输入。AVDD、AVSS、IOVDD保留原电源节点标识。

## 5.2\_工作模式

| 宏 | 原始值 | 中文释义 |
| --- | --- | --- |
| `AD4170_CONTINUOUS_MODE` | `0` | 连续模式（Continuous Mode） |
| `AD4170_SINGLE_MODE` | `4` | 单次模式（Single Mode） |
| `AD4170_STANDBY_MODE` | `5` | 待机模式（Standby Mode） |
| `AD4170_POWER_DOWN_MODE` | `6` | 掉电模式（Power-Down Mode） |
| `AD4170_IDLE_MODE` | `7` | 空闲模式（Idle Mode） |

这些值是工作模式（Operating Mode）编码，不按表中行号重排。

## 5.3\_时钟选择

| 宏 | 原始值 | 中文释义 |
| --- | --- | --- |
| `AD4170_CLKSEL_INT` | `0` | 内部时钟（Internal Clock） |
| `AD4170_CLKSEL_INT_OUT` | `1` | 内部时钟并输出（Internal Clock Output） |
| `AD4170_CLKSEL_EXT` | `2` | 外部时钟（External Clock） |
| `AD4170_CLKSEL_EXT_XTAL` | `3` | 外部晶体（External Crystal） |

时钟选择（Clock Select）的内部、外部及外部晶体选项保留为不同编码。

## 5.4\_滤波器类型

| 宏 | 原始值 | 中文释义 |
| --- | --- | --- |
| `AD4170_SINC5_AVG` | `0` | sinc⁵滤波并平均（sinc5 with Averaging） |
| `AD4170_SINC5` | `1` | sinc⁵滤波（sinc5 Filter） |
| `AD4170_SINC3` | `2` | sinc³滤波（sinc3 Filter） |

滤波器类型（Filter Type）中的sinc名称保持原样。本文件没有给出采样率、平均次数或建立时间的数值表，不能从这些编码本身推定。
