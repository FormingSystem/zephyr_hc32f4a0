# 第3章\_AD4130设备树常量参考

原文：[ad4130-adc_8h](https://docs.zephyrproject.org/latest/doxygen/html/ad4130-adc_8h.html)。读取日期：2026-10-13，`latest`。

`zephyr/dt-bindings/adc/ad4130-adc.h` 为AD4130模数转换器（Analog-to-Digital Converter，ADC）提供输入选择常量。设备树（Devicetree）中的输入编号必须与头文件定义一致，不能按名称顺序重新编号。原页包含以下头文件，并列出30个宏（Macro）；对应[源码页](P004_AD4130设备树常量源码.md)保留全部可见定义。

```c
#include <zephyr/dt-bindings/dt-util.h>
```

## 3.1\_输入选择常量

原页只有宏名称及数值，没有逐项说明；表中中文释义为帮助阅读标识符而补充的译注，不扩展为芯片电气规格。AVDD、AVSS、IOVDD保留原电源节点名称；ALDO和DLDO分别指模拟、数字低压差稳压器（Analog／Digital Low-Dropout Regulator）相关节点，实际连接以器件资料为准。

## 3.2\_与设备树配置衔接

AIN0至AIN15表示外部模拟输入选择；其后的常量为温度、参考、电源或内部节点选择。表中数值是选择编码，不是引脚号，也不是电压值。设备树属性与正负输入的配置要求见[AD4130绑定](../hardware/P914_ADIAD4130模数转换器绑定.md)。本文件参考页没有函数、数据结构或额外的运行时接口。
