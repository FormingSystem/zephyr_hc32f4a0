# 第7章\_AD7124设备树常量参考

原文：[ad7124-adc_8h](https://docs.zephyrproject.org/latest/doxygen/html/ad7124-adc_8h.html)。读取日期：2026-10-13，`latest`。

`zephyr/dt-bindings/adc/ad7124-adc.h` 提供AD7124模数转换器（Analog-to-Digital Converter，ADC）的输入选择、电流输出和输出通道常量。设备树（Devicetree）通过这些宏（Macro）表达选择编码。原页列出54项定义，完整可见源码见[源码页](P008_AD7124设备树常量源码.md)。

```c
#include <zephyr/dt-bindings/dt-util.h>
```

原参考页没有逐项解释性段落。下表中文释义为依据宏名称补充的译注，原始值列逐字保留。AVDD、AVSS、IOVDD为原电源节点名称；ALDO和DLDO分别为模拟、数字低压差稳压器（Analog／Digital Low-Dropout Regulator）相关节点。

## 7.2\_电流输出选择

两个电流输出分别使用IOUT0和IOUT1命名。下面保留原文的前导零和字母，不能把原始编码当成电流的数值。

| 宏 | 原始值 | 中文释义 |
| --- | --- | --- |
| `AD7124_IOUT0_OFF` | `00` | 电流输出0（Current Output 0）：关闭（Off） |
| `AD7124_IOUT0_50_UA` | `01` | 电流输出0（Current Output 0）：50微安（Microampere，µA） |
| `AD7124_IOUT0_100_UA` | `02` | 电流输出0（Current Output 0）：100微安（Microampere，µA） |
| `AD7124_IOUT0_250_UA` | `03` | 电流输出0（Current Output 0）：250微安（Microampere，µA） |
| `AD7124_IOUT0_500_UA` | `04` | 电流输出0（Current Output 0）：500微安（Microampere，µA） |
| `AD7124_IOUT0_750_UA` | `05` | 电流输出0（Current Output 0）：750微安（Microampere，µA） |
| `AD7124_IOUT0_1000_UA` | `06` | 电流输出0（Current Output 0）：1000微安（Microampere，µA） |
| `AD7124_IOUT0_0_1_UA` | `07` | 电流输出0（Current Output 0）：0.1微安（Microampere，µA） |
| `AD7124_IOUT1_OFF` | `08` | 电流输出1（Current Output 1）：关闭（Off） |
| `AD7124_IOUT1_50_UA` | `09` | 电流输出1（Current Output 1）：50微安（Microampere，µA） |
| `AD7124_IOUT1_100_UA` | `0A` | 电流输出1（Current Output 1）：100微安（Microampere，µA） |
| `AD7124_IOUT1_250_UA` | `0B` | 电流输出1（Current Output 1）：250微安（Microampere，µA） |
| `AD7124_IOUT1_500_UA` | `0C` | 电流输出1（Current Output 1）：500微安（Microampere，µA） |
| `AD7124_IOUT1_750_UA` | `0D` | 电流输出1（Current Output 1）：750微安（Microampere，µA） |
| `AD7124_IOUT1_1000_UA` | `0E` | 电流输出1（Current Output 1）：1000微安（Microampere，µA） |
| `AD7124_IOUT1_0_1_UA` | `0F` | 电流输出1（Current Output 1）：0.1微安（Microampere，µA） |

**译注：原页和对应源码确实写成 `08`、`09`、`0A` 至 `0F`，没有 `0x` 前缀。** 按C整数常量语法，`08`、`09` 不是有效的八进制整数，`0A` 至 `0F` 也不是合法的十六进制整数写法。因此，本页记录的是上游快照中的定义，不将这些可疑字面量改写成假定的正确值，也不声称直接展开它们参与C表达式能通过编译。使用时需要核对目标源码版本。

## 7.3\_电流输出通道

| 宏 | 原始值 | 中文释义 |
| --- | --- | --- |
| `AD7124_IOUT_CH_AIN0` | `00` | 电流输出路由到模拟输入AIN0 |
| `AD7124_IOUT_CH_AIN1` | `01` | 电流输出路由到模拟输入AIN1 |
| `AD7124_IOUT_CH_AIN2` | `04` | 电流输出路由到模拟输入AIN2 |
| `AD7124_IOUT_CH_AIN3` | `05` | 电流输出路由到模拟输入AIN3 |
| `AD7124_IOUT_CH_AIN4` | `0A` | 电流输出路由到模拟输入AIN4 |
| `AD7124_IOUT_CH_AIN5` | `0B` | 电流输出路由到模拟输入AIN5 |
| `AD7124_IOUT_CH_AIN6` | `0E` | 电流输出路由到模拟输入AIN6 |
| `AD7124_IOUT_CH_AIN7` | `0F` | 电流输出路由到模拟输入AIN7 |

通道选择编码不连续，例如AIN2对应原始值 `04`，不能按AIN后的数字替换。设备树属性及参考缓冲器等配置要求见[AD7124绑定](../hardware/P921_ADIAD7124模数转换器绑定.md)。本文件参考页没有函数或数据结构。
