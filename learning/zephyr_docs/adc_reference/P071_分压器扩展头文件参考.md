# 第71章\_分压器扩展头文件参考

原文：[voltage__divider_8h](https://docs.zephyrproject.org/latest/doxygen/html/voltage__divider_8h.html)。读取日期：2026-10-13，`latest`。

`zephyr/drivers/adc/voltage_divider.h` 提供分压器（Voltage Divider）的扩展应用程序接口（Application Programming Interface，API），用于由测量电压还原实际电压。它包含模数转换器（Analog-to-Digital Converter，ADC）声明：

```c
#include <zephyr/drivers/adc.h>
```

## 71.1\_设备树规格与构造宏

结构体 `voltage_divider_dt_spec` 保存分压器的设备树（Devicetree，DT）规格，详见[分压器设备树规格](../hardware/P462_ADC分压器设备树规格.md)。

`VOLTAGE_DIVIDER_DT_SPEC_GET(node_id)` 从设备树取得分压器信息。`node_id` 指定节点；源码中 `full_ohms` 未指定时取0，完整初始化表达式见[源码页](P072_分压器扩展头文件源码.md)。

## 71.2\_32位与64位换算

两个函数均根据测量电压计算实际电压，通过 `v_to_v` 指针原地更新结果：

```c
static int voltage_divider_scale_dt(const struct voltage_divider_dt_spec *spec, int32_t *v_to_v);
static int voltage_divider_scale64_dt(const struct voltage_divider_dt_spec *spec, int64_t *v_to_v);
```

`voltage_divider_scale_dt` 操作32位有符号值，`voltage_divider_scale64_dt` 操作64位有符号值。两者的返回类型都是 `int`，返回状态而非电压。源码在 `full_ohms == 0` 时返回 `-ENOTSUP`（不支持，Not Supported），成功换算后返回0；完整接口说明见[分压器接口](../hardware/P459_ADC分压器接口.md)。
