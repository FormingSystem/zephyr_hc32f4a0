# 第45章\_ADS131M02扩展头文件参考

原文：[ads131m02_8h](https://docs.zephyrproject.org/latest/doxygen/html/ads131m02_8h.html)。读取日期：2026-10-13，`latest`。

`zephyr/drivers/adc/ads131m02.h` 是ADS131M02模数转换器（Analog-to-Digital Converter，ADC）的扩展应用程序接口（Application Programming Interface，API）头文件，包含设备声明：

```c
#include <zephyr/device.h>
```

## 45.1\_转换、功耗与全局斩波延迟枚举

原页列出三个枚举（Enumeration）。以下按源码声明顺序保留全部枚举项；它们没有显式赋值，**名称中的延迟数字不是写入C声明的枚举值**。各项中文含义与[ADS131M02扩展接口](../hardware/P467_ADS131M02扩展接口.md)对应。

枚举类型 `ads131m02_adc_mode`：

| 枚举项 | 中文含义 |
| --- | --- |
| `ADS131M02_CONTINUOUS_MODE` | 连续转换模式（Continuous Conversion Mode） |
| `ADS131M02_GLOBAL_CHOP_MODE` | 全局斩波模式（Global-Chop Mode） |

枚举类型 `ads131m02_adc_power_mode`：

| 枚举项 | 中文含义 |
| --- | --- |
| `ADS131M02_VLP` | 极低功耗（Very Low Power，VLP） |
| `ADS131M02_LP` | 低功耗（Low Power，LP） |
| `ADS131M02_HR` | 高分辨率（High Resolution，HR） |

枚举类型 `ads131m02_gc_delay`：

| 枚举项 | 中文含义 |
| --- | --- |
| `ADS131M02_GC_DELAY_2` | 全局斩波延迟2个采样（Samples） |
| `ADS131M02_GC_DELAY_4` | 全局斩波延迟4个采样（Samples） |
| `ADS131M02_GC_DELAY_8` | 全局斩波延迟8个采样（Samples） |
| `ADS131M02_GC_DELAY_16` | 全局斩波延迟16个采样（Samples） |
| `ADS131M02_GC_DELAY_32` | 全局斩波延迟32个采样（Samples） |
| `ADS131M02_GC_DELAY_64` | 全局斩波延迟64个采样（Samples） |
| `ADS131M02_GC_DELAY_128` | 全局斩波延迟128个采样（Samples） |
| `ADS131M02_GC_DELAY_256` | 全局斩波延迟256个采样（Samples） |
| `ADS131M02_GC_DELAY_512` | 全局斩波延迟512个采样（Samples） |
| `ADS131M02_GC_DELAY_1024` | 全局斩波延迟1024个采样（Samples） |
| `ADS131M02_GC_DELAY_2048` | 全局斩波延迟2048个采样（Samples） |
| `ADS131M02_GC_DELAY_4096` | 全局斩波延迟4096个采样（Samples） |

全局斩波延迟用于斩波开关切换后等待外部输入电路稳定（Settling）；详细说明见上述接口页。

## 45.2\_设置ADC模式

```c
int ads131m02_set_adc_mode(const struct device *dev,
                          enum ads131m02_adc_mode mode,
                          enum ads131m02_gc_delay gc_delay);
```

函数 `ads131m02_set_adc_mode()` 设置ADS131M02的ADC模式。`dev` 指向设备实例，`mode` 指定目标模式；全局斩波模式使用 `gc_delay` 参数。参数细节及返回值约定见[扩展接口](../hardware/P467_ADS131M02扩展接口.md)。

## 45.3\_设置功耗模式

```c
int ads131m02_set_power_mode(const struct device *dev,
                            enum ads131m02_adc_power_mode mode);
```

函数 `ads131m02_set_power_mode()` 设置ADS131M02的功耗模式（Power Mode）。`dev` 指向设备实例，`mode` 为目标功耗模式。完整原始声明见[源码页](P046_ADS131M02扩展头文件源码.md)。本页保留文件参考层的三个枚举与两个函数入口，完整接口说明仍可沿本地链接阅读。
