# 第13章\_B91ADC设备树常量参考

原文：[b91-adc_8h](https://docs.zephyrproject.org/latest/doxygen/html/b91-adc_8h.html)。读取日期：2026-10-13，`latest`。

`zephyr/dt-bindings/adc/b91-adc.h` 定义Telink B91模数转换器（Analog-to-Digital Converter，ADC）的输入选择常量。原页列出11个宏（Macro）；下表按宏名补充中文含义，原始十六进制值及大小写保留。

## 13.1\_引脚与电池输入选择

| 宏 | 原始值 | 中文释义 |
| --- | --- | --- |
| `DT_ADC_GPIO_PB0` | `0x01` | 通用输入输出（General-Purpose Input/Output，GPIO）PB0引脚输入 |
| `DT_ADC_GPIO_PB1` | `0x02` | 通用输入输出（General-Purpose Input/Output，GPIO）PB1引脚输入 |
| `DT_ADC_GPIO_PB2` | `0x03` | 通用输入输出（General-Purpose Input/Output，GPIO）PB2引脚输入 |
| `DT_ADC_GPIO_PB3` | `0x04` | 通用输入输出（General-Purpose Input/Output，GPIO）PB3引脚输入 |
| `DT_ADC_GPIO_PB4` | `0x05` | 通用输入输出（General-Purpose Input/Output，GPIO）PB4引脚输入 |
| `DT_ADC_GPIO_PB5` | `0x06` | 通用输入输出（General-Purpose Input/Output，GPIO）PB5引脚输入 |
| `DT_ADC_GPIO_PB6` | `0x07` | 通用输入输出（General-Purpose Input/Output，GPIO）PB6引脚输入 |
| `DT_ADC_GPIO_PB7` | `0x08` | 通用输入输出（General-Purpose Input/Output，GPIO）PB7引脚输入 |
| `DT_ADC_GPIO_PD0` | `0x09` | 通用输入输出（General-Purpose Input/Output，GPIO）PD0引脚输入 |
| `DT_ADC_GPIO_PD1` | `0x0a` | 通用输入输出（General-Purpose Input/Output，GPIO）PD1引脚输入 |
| `DT_ADC_VBAT` | `0x0f` | 电池电压（Battery Voltage，VBAT）输入 |

## 13.2\_编码与设备树配置

这些是设备树（Devicetree）ADC输入选择编码。例如PB0对应 `0x01`，并非0；电池电压选择值为 `0x0f`。原页没有头文件包含项，也没有对采集时间、量程或分压比例作额外说明。完整可见代码见[源码页](P014_B91ADC设备树常量源码.md)，设备树属性见[B91绑定](../hardware/P903_TelinkB91模数转换器绑定.md)。
