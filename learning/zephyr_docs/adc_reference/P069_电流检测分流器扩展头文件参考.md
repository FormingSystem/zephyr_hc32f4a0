# 第69章\_电流检测分流器扩展头文件参考

原文：[current__sense__shunt_8h](https://docs.zephyrproject.org/latest/doxygen/html/current__sense__shunt_8h.html)。读取日期：2026-10-13，`latest`。

`zephyr/drivers/adc/current_sense_shunt.h` 是电流检测分流器（Current Sense Shunt）的模数转换器（Analog-to-Digital Converter，ADC）扩展应用程序接口（Application Programming Interface，API）头文件。它包含公共ADC声明：

```c
#include <zephyr/drivers/adc.h>
```

## 69.1\_设备树规格

结构体 `current_sense_shunt_dt_spec` 保存分流器的设备树（Devicetree，DT）规格，字段解释见[分流器设备树规格](../hardware/P461_ADC分流器设备树规格.md)。

宏 `CURRENT_SENSE_SHUNT_DT_SPEC_GET(node_id)` 从设备树取得电流传感器信息。`node_id` 指定节点，初始化表达式见[源码页](P070_电流检测分流器扩展头文件源码.md)。

## 69.2\_测量值换算

下列函数根据测得的电压计算实际电流，通过 `v_to_i` 传入测量值并写回换算结果：

```c
static void current_sense_shunt_scale_dt(const struct current_sense_shunt_dt_spec *spec, int32_t *v_to_i);
```

参数的单位及使用要求见[电流检测分流器接口](../hardware/P458_ADC电流检测分流器接口.md)。源码使用64位临时变量计算，最后转回32位整数；该实现细节不应被误写成函数返回64位结果。
