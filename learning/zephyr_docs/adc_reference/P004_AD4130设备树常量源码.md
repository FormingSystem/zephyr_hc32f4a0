本页保留官方源码浏览器显示的 `zephyr/dt-bindings/adc/ad4130-adc.h` 内容。模数转换器（Analog-to-Digital Converter，ADC）的设备树（Devicetree）常量说明见[对应参考页](P003_AD4130设备树常量参考.md)。
