# 第9章\_MCP356xR设备树常量参考

原文：[mcp356xr-adc_8h](https://docs.zephyrproject.org/latest/doxygen/html/mcp356xr-adc_8h.html)。读取日期：2026-10-13，`latest`。

`zephyr/dt-bindings/adc/mcp356xr-adc.h` 定义MCP356xR模数转换器（Analog-to-Digital Converter，ADC）的输入、模拟时钟与偏置电流常量。原页只有宏（Macro）定义，表中中文含义为按标识符补充的译注；原始值包括括号在内保留。其包含的设备树（Devicetree）通用ADC头文件已在[本册第1章](P001_ADC通用设备树常量参考.md)说明：

```c
#include <zephyr/dt-bindings/adc/adc.h>
```

## 9.1\_输入常量

| 宏 | 原始值 | 中文释义 |
| --- | --- | --- |
| `MCP356XR_INPUT_INTERNAL_VCM` | `(15)` | 内部共模电压（Internal Common-Mode Voltage，VCM） |
| `MCP356XR_INPUT_INTERNAL_TEMPERATURE_SENSOR_DIODE_M` | `(14)` | 内部温度传感器二极管（Internal Temperature Sensor Diode）负端 |
| `MCP356XR_INPUT_INTERNAL_TEMPERATURE_SENSOR_DIODE_P` | `(13)` | 内部温度传感器二极管正端 |
| `MCP356XR_INPUT_REFIN_NEGATIVE` | `(12)` | 参考输入（Reference Input）负端 |
| `MCP356XR_INPUT_REFIN_POSITIVE` | `(11)` | 参考输入正端 |
| `MCP356XR_INPUT_RESERVED_DO_NOT_USE` | `(10)` | 保留，不得使用（Reserved, Do Not Use） |
| `MCP356XR_INPUT_AVDD` | `(9)` | AVDD模拟电源节点 |
| `MCP356XR_INPUT_AGND` | `(8)` | 模拟地（Analog Ground） |
| `MCP356XR_INPUT_CH7` | `(7)` | 模拟输入通道（Analog Input Channel）CH7 |
| `MCP356XR_INPUT_CH6` | `(6)` | 模拟输入通道（Analog Input Channel）CH6 |
| `MCP356XR_INPUT_CH5` | `(5)` | 模拟输入通道（Analog Input Channel）CH5 |
| `MCP356XR_INPUT_CH4` | `(4)` | 模拟输入通道（Analog Input Channel）CH4 |
| `MCP356XR_INPUT_CH3` | `(3)` | 模拟输入通道（Analog Input Channel）CH3 |
| `MCP356XR_INPUT_CH2` | `(2)` | 模拟输入通道（Analog Input Channel）CH2 |
| `MCP356XR_INPUT_CH1` | `(1)` | 模拟输入通道（Analog Input Channel）CH1 |
| `MCP356XR_INPUT_CH0` | `(0)` | 模拟输入通道（Analog Input Channel）CH0 |

`MCP356XR_INPUT_RESERVED_DO_NOT_USE` 是保留选择项，不能当成额外可用通道。通道编号与板上引脚分配不是同一概念。

## 9.2\_模拟时钟分频

| 宏 | 原始值 | 中文释义 |
| --- | --- | --- |
| `MCP356XR_ANALOG_CLOCK_NO_DIV` | `(0)` | 模拟时钟不分频（No Division） |
| `MCP356XR_ANALOG_CLOCK_DIV_2` | `(1)` | 模拟时钟2分频（Clock Division） |
| `MCP356XR_ANALOG_CLOCK_DIV_4` | `(2)` | 模拟时钟4分频（Clock Division） |
| `MCP356XR_ANALOG_CLOCK_DIV_8` | `(3)` | 模拟时钟8分频（Clock Division） |

原始值0、1、2、3是选择编码，分别对应不分频、2分频、4分频、8分频，不表示同数值的频率。

## 9.3\_偏置电流调节

偏置电流（Bias Current）的调节选项使用下列编码：

| 宏 | 原始值 | 中文释义 |
| --- | --- | --- |
| `MCP356XR_BOOST_CURRENT_BIAS_DIV_2` | `(0)` | 偏置电流除以2 |
| `MCP356XR_BOOST_CURRENT_BIAS_MUL_0_66` | `(1)` | 偏置电流乘以0.66 |
| `MCP356XR_BOOST_CURRENT_BIAS_MUL_1` | `(2)` | 偏置电流乘以1 |
| `MCP356XR_BOOST_CURRENT_BIAS_MUL_2` | `(3)` | 偏置电流乘以2 |

设备树属性如何使用这些常量，见[MCP356xR绑定](../hardware/P940_MCP356xR模数转换器绑定.md)。原始头文件内容见[源码页](P010_MCP356xR设备树常量源码.md)。
