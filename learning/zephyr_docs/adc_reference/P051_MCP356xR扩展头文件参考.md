# 第51章\_MCP356xR扩展头文件参考

原文：[mcp356xr_8h](https://docs.zephyrproject.org/latest/doxygen/html/mcp356xr_8h.html)。读取日期：2026-10-13，`latest`。

`zephyr/drivers/adc/mcp356xr.h` 是MCP356xR模数转换器（Analog-to-Digital Converter，ADC）驱动目录中的头文件。官方文件参考页的内容只有下面的包含项以及源码入口：

## 51.1\_包含设备树常量头文件

```c
#include <zephyr/dt-bindings/adc/mcp356xr-adc.h>
```

所包含的设备树（Devicetree）常量定义已在[MCP356xR设备树常量参考](P009_MCP356xR设备树常量参考.md)完整翻译，包括输入选择、模拟时钟分频和偏置电流编码。

## 51.2\_文件范围

该文件没有另行定义函数、结构、枚举或宏。完整可见内容见[源码页](P052_MCP356xR扩展头文件源码.md)；本页的完成范围仅对应这个包含入口，不把它当成整个MCP356xR驱动的功能说明。
