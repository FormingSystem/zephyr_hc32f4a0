# 第67章\_电流检测放大器扩展头文件参考

原文：[current__sense__amplifier_8h](https://docs.zephyrproject.org/latest/doxygen/html/current__sense__amplifier_8h.html)。读取日期：2026-10-13，`latest`。

`zephyr/drivers/adc/current_sense_amplifier.h` 提供电流检测放大器（Current Sense Amplifier）的模数转换器（Analog-to-Digital Converter，ADC）扩展应用程序接口（Application Programming Interface，API）。它包含ADC与通用输入输出（General-Purpose Input/Output，GPIO）声明：

```c
#include <zephyr/drivers/adc.h>
#include <zephyr/drivers/gpio.h>
```

## 67.1\_设备树规格与构造宏

结构体 `current_sense_amplifier_dt_spec` 保存电流检测放大器的设备树（Devicetree，DT）规格；各字段见[放大器设备树规格](../hardware/P460_ADC电流放大器设备树规格.md)。

`CURRENT_SENSE_AMPLIFIER_DT_SPEC_GET(node_id)` 从设备树取得电流传感器信息，`node_id` 是节点标识。该宏的完整初始化表达式保存在[源码页](P068_电流检测放大器扩展头文件源码.md)。

## 67.2\_电压到电流的换算

两个函数都根据测得的电压计算实际电流。参考页的完整签名如下：

```c
static void current_sense_amplifier_scale_dt(const struct current_sense_amplifier_dt_spec *spec, int32_t *v_to_i);
static int32_t current_sense_amplifier_scale_ua_dt(const struct current_sense_amplifier_dt_spec *spec, int32_t microvolts);
```

第一项通过 `v_to_i` 指针原地换算；第二项接收微伏（Microvolt，µV）值 `microvolts` 并返回换算结果。输入输出单位和参数要求详见[电流检测放大器接口](../hardware/P457_ADC电流检测放大器接口.md)。不要因两个函数的简介相同而混用其参数形式。
