# 第44章\_插桩头文件

原文：[instrumentation_8h](https://docs.zephyrproject.org/latest/doxygen/html/instrumentation_8h.html)。读取日期：2026-10-13，`latest`。

## 44.1\_用途与包含关系

`zephyr/instrumentation/instrumentation.h` 是代码插桩（Instrumentation）子系统的应用程序编程接口（Application Programming Interface，API）头文件。跟踪（Tracing）和性能分析（Profiling）数据可经通用异步收发器（Universal Asynchronous Receiver/Transmitter，UART）导出。

官方页面列出的包含项如下：

```c
#include <zephyr/kernel.h>
```

[查看官方头文件源码](../cpu_runtime_reference/P007_函数插桩头文件源码.md)。

## 44.2\_数据结构与事件枚举

| 数据结构 | 说明 |
| --- | --- |
| [`struct instr_header`](P033_插桩事件头.md) | 事件记录头 |
| [`struct instr_event_context`](P034_插桩事件上下文.md) | 事件的上下文专有数据 |
| [`struct instr_record`](P035_插桩事件记录.md) | 事件记录及关联载荷（Payload） |

枚举 [`instr_event_types`](https://docs.zephyrproject.org/latest/doxygen/html/group__instrumentation__api.html#ga469cc43e8e444c05286ebba0d144460c) 定义插桩事件记录类型：

```c
enum instr_event_types {
    INSTR_EVENT_ENTRY = 0,
    INSTR_EVENT_EXIT,
    INSTR_EVENT_PROFILE,
    INSTR_EVENT_SCHED_IN,
    INSTR_EVENT_SCHED_OUT,
    INSTR_EVENT_NUM,
    INSTR_EVENT_INVALID
};
```

## 44.3\_函数声明

以下声明与官方头文件参考页对应，完整参数和返回值见[对应接口说明](P025_插桩接口参考.md)。

| 声明 | 说明 |
| --- | --- |
| `bool instr_tracing_supported(void);` | 检查跟踪功能是否可用 |
| `bool instr_profiling_supported(void);` | 检查性能分析功能是否可用 |
| `bool instr_dynamic_trigger_supported(void);` | 检查动态触发配置功能是否可用 |
| `bool instr_fundamentals_initialized(void);` | 检查子系统是否具备初始化条件 |
| `int instr_init(void);` | 执行系统需要的初始化 |
| `bool instr_initialized(void);` | 查询插桩子系统是否正确初始化 |
| `bool instr_enabled(void);` | 查询插桩是否已启用，即是否允许开启 |
| `int instr_enable(void);` | 启用插桩 |
| `int instr_disable(void);` | 禁用插桩 |
| `int instr_turn_on(void);` | 开启插桩，开始记录事件 |
| `int instr_turn_off(void);` | 关闭插桩，停止记录事件 |
| `bool instr_turned_on(void);` | 查询插桩是否已开启 |
| `bool instr_trace_enabled(void);` | 查询是否可以收集跟踪数据 |
| `bool instr_profile_enabled(void);` | 查询是否可以收集性能分析信息 |
| `void instr_dump_buffer_uart(void);` | 通过UART导出跟踪缓冲区内容 |
| `void instr_dump_deltas_uart(void);` | 通过UART导出性能分析的时间差累加数组 |
| `void instr_event_handler(enum instr_event_types opcode, void *func, void *caller);` | 处理函数进入/退出事件的公共回调处理函数 |
| `void instr_set_trigger_func(void *callee);` | 将给定函数地址设为触发函数 |
| `void instr_set_stop_func(void *callee);` | 将给定函数地址设为停止函数 |
| `void * instr_get_trigger_func(void);` | 取得触发函数地址 |
| `void * instr_get_stop_func(void);` | 取得停止函数地址 |
