# 第51章\_符号表接口

原文：[group__symtab__apis](https://docs.zephyrproject.org/latest/doxygen/html/group__symtab__apis.html)。读取日期：2026-10-13，`latest`。

## 51.1\_头文件与数据类型

**符号表（Symbol Table）**接口使用 [`struct symtab_info`](P056_符号表信息结构.md)描述符号表信息。

```c
#include <zephyr/debug/symtab.h>
```

## 51.2\_取得符号表

```c
const struct symtab_info *symtab_get(void);
```

无参数，返回符号表指针。

## 51.3\_按地址查找名称

```c
const char *symtab_find_symbol_name(uintptr_t addr, uint32_t *offset);
```

使用**二分查找（Binary Search）**寻找符号名称。

| 参数 | 方向 | 含义 |
| --- | --- | --- |
| `addr` | 输入 | 待查找的符号地址 |
| `offset` | 输出 | 待查地址相对最近符号的偏移量（Offset）；找不到符号时写入0 |

找到时返回最近符号的名称，否则返回字符串 `"?"`。
