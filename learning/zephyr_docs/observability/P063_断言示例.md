# 第63章\_断言示例

原文：[Assertions](https://docs.zephyrproject.org/latest/samples/subsys/debug/asserts/README.html)。读取日期：2026-10-13，`latest`。

## 63.1\_概述

本示例演示如何配置和使用具名断言（Assertion）模块，所用应用程序编程接口（Application Programming Interface，API）在 [include/zephyr/sys/zassert.h](https://github.com/zephyrproject-rtos/zephyr/blob/main/include/zephyr/sys/zassert.h) 中声明。

示例的 Kconfig 配置文件通过引入 [subsys/debug/zassert/Kconfig.template.assert](https://github.com/zephyrproject-rtos/zephyr/blob/main/subsys/debug/zassert/Kconfig.template.assert) 定义 `MYMODULE` 断言模块。模板建立一个选择项（Choice），包含以下互斥选项：

| Kconfig 选项 | 级别 | 编译与失败行为 |
| --- | --- | --- |
| `CONFIG_ASSERT_MODULE_MYMODULE_LEVEL_OFF=y` | `ZASSERT_LEVEL_OFF` | 该模块的 [`ZASSERT`](https://docs.zephyrproject.org/latest/doxygen/html/group__zassert.html#gacb48ee150ebe9d7b2a415ec8bee79cb7) 调用在编译时移除 |
| `CONFIG_ASSERT_MODULE_MYMODULE_LEVEL_TERSE=y` | `ZASSERT_LEVEL_TERSE` | 检查条件，但位置、消息及参数不编入程序；失败只输出固定的 `ASSERTION FAIL` 提示 |
| `CONFIG_ASSERT_MODULE_MYMODULE_LEVEL_NORMAL=y` | `ZASSERT_LEVEL_NORMAL` | 检查条件，但格式字符串和参数不编入程序；失败只报告源码位置 |
| `CONFIG_ASSERT_MODULE_MYMODULE_LEVEL_VERBOSE=y` | `ZASSERT_LEVEL_VERBOSE` | 检查条件，格式字符串及参数编入程序；失败报告源码位置及可选的格式化字符串 |

这一选择项生成不能直接赋值的整数符号 `CONFIG_ASSERT_MODULE_MYMODULE_LEVEL`，其值分别为 `ZASSERT_LEVEL_OFF`（0）、`ZASSERT_LEVEL_TERSE`（1）、`ZASSERT_LEVEL_NORMAL`（2）或 `ZASSERT_LEVEL_VERBOSE`（3）。默认选择 `ZASSERT_LEVEL_VERBOSE`；本示例在 `prj.conf` 中选择详细级别，保留这一默认行为。

还必须启用断言总开关 [`CONFIG_ASSERT`](https://docs.zephyrproject.org/latest/kconfig.html#CONFIG_ASSERT)。总开关禁用时，无论各模块配置什么级别，所有模块断言都会在编译时移除。

在文件作用域使用 `ZASSERT_MODULE(MYMODULE)`，会让 `src/main.c` 中的 [`ZASSERT`](https://docs.zephyrproject.org/latest/doxygen/html/group__zassert.html#gacb48ee150ebe9d7b2a415ec8bee79cb7) 调用采用推导出的 `MYMODULE` 级别。第一次调用的条件为真，不产生断言输出；第二次条件为假，因此详细失败输出包含 `x == 3`、源码位置和 `x` 的格式化值。默认的断言后续动作随后触发致命错误（Fatal Error），程序不会越过失败的断言继续执行。

## 63.2\_构建与运行

```shell
west build -b native_sim samples/subsys/debug/asserts
west build -t run
```

预期输出：

```text
Granular assert sample
MYMODULE assert level = 3
Passed module ZASSERT(1 == 1)
Triggering a failing module ZASSERT() ...
ASSERTION FAIL [x == 3] @ .../src/main.c:...
x was 2, expected 3
```
