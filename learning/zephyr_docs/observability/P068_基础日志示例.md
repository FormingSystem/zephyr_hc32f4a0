# 第68章\_基础日志示例

原文：[官方页面](https://docs.zephyrproject.org/latest/samples/subsys/logging/logger/README.html)。读取日期：2026-10-14；保存的 latest 页面及 HTML 摘要见[来源记录](../SOURCES.md)。

## 68.1\_概述

这个简单应用演示日志子系统的主要特性：严重性级别（Severity Levels）、时间戳（Timestamping）、模块级过滤（Module-level Filtering）与实例级过滤（Instance-level Filtering），也展示日志记录的性能能力。

## 68.2\_构建与运行

本项目向控制台输出多条日志，可用 QEMU 构建并运行：

译注：主机终端位于已具备工具链和依赖模块的 Zephyr 源码根目录，构建的是官方已有的 `samples/subsys/logging/logger`。构建成功后运行下一条命令；本批没有实际运行 QEMU。

```sh
west build -b qemu_x86 samples/subsys/logging/logger
west build -t run
```

按 Ctrl+A，再按 x，退出 QEMU。

输出依次展示：模块日志以及关闭模块过滤后的行为；两个实例的独立过滤；把 `inst1` 调为警告级别后仍保留 `inst2` 的信息消息；关闭两个实例；临时字符串（Transient String）；错误、警告和信息级别；日志性能估算；外部日志系统（External Logging System）接入。`<err>`、`<wrn>`、`<inf>` 分别表示错误（Error）、警告（Warning）和信息（Info）；十六进制转储（Hexdump）保留原始字节。

> 译注：原输出的 `42000000 messages/second` 是特定运行条件下的估算示例，不是对任意开发板、UART 或后端吞吐量的承诺。当前实现按时间窗口和记录条数估算，并依据立即处理／延迟处理模式及日志缓冲区确定测试上限；应区分日志调用生成速度与后端实际输出速度。时间戳、条数和可见严重性级别也会随配置变化。
