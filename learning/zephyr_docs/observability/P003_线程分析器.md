# 第3章\_线程分析器

原文：[Thread analyzer](https://docs.zephyrproject.org/latest/services/debugging/thread-analyzer.html)。读取日期：2026-10-12，`latest`。

**线程分析器（Thread Analyzer）**会启用追踪线程信息所需的 Zephyr 配置，例如线程栈使用量及运行时统计。应用调用 `thread_analyzer_run()` 或 `thread_analyzer_print()` 时按需分析。

## 3.1\_示例

以启用分析器构建同步示例为例：

```shell
# From the root of the zephyr repository
west build -b qemu_x86 samples/synchronization/ -- -DCONFIG_QEMU_ICOUNT=n -DCONFIG_THREAD_ANALYZER=y \
-DCONFIG_THREAD_ANALYZER_USE_PRINTK=y -DCONFIG_THREAD_ANALYZER_AUTO=y \
-DCONFIG_THREAD_ANALYZER_AUTO_INTERVAL=5
```

在 QEMU 运行后，原例输出中增加线程分析信息：

## 3.2\_配置

| Kconfig 配置项 | 作用 |
| --- | --- |
| `CONFIG_THREAD_ANALYZER` | 启用模块 |
| `CONFIG_THREAD_ANALYZER_USE_PRINTK` | 用 `printk` 输出统计 |
| `CONFIG_THREAD_ANALYZER_USE_LOG` | 用日志系统输出统计 |
| `CONFIG_THREAD_ANALYZER_AUTO` | 自动运行，应用无须增加调用代码 |
| `CONFIG_THREAD_ANALYZER_AUTO_INTERVAL` | 自动模式两次分析输出之间的睡眠时间 |
| `CONFIG_THREAD_ANALYZER_AUTO_STACK_SIZE` | 自动分析线程的栈大小 |
| `CONFIG_THREAD_NAME` | 输出线程名称而非 ID |
| `CONFIG_THREAD_RUNTIME_STATS` | 输出利用率等运行数据；由 `CONFIG_THREAD_ANALYZER` 自动选中 |
| `CONFIG_THREAD_ANALYZER_LONG_FRAME_PER_INTERVAL` | 使用 `SCHED_THREAD_USAGE_ANALYSIS` 获取平均及最长运行片段统计时，每次输出后将最长值清零，从而观察最近区间，而非启动以来的最长值 |
| `CONFIG_THREAD_ANALYZER_PRINT_THREAD_PRIORITY` | 输出各线程优先级 |
