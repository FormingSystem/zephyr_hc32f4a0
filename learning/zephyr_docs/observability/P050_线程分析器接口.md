# 第50章\_线程分析器接口

原文：[group__thread__analyzer](https://docs.zephyrproject.org/latest/doxygen/html/group__thread__analyzer.html)。读取日期：2026-10-13，`latest`。

## 50.1\_模块与头文件

**线程分析器（Thread Analyzer）**提供简化线程分析的函数和配置，关联结果结构为 [`thread_analyzer_info`](P055_线程分析结果结构.md)。

```c
#include <zephyr/debug/thread_analyzer.h>
```

## 50.3\_回调类型

线程栈大小分析回调（Callback）接收线程分析信息：

<a id="ga7ac3e88ca6d905ba0efe4afe5822485c"></a>

```c
typedef void (*thread_analyzer_cb)(struct thread_analyzer_info *info);
```

参数 `info` 指向线程分析信息。栈安全回调的签名为：

<a id="ga8646820efa57f6e8d9ec54cf1dde4e10"></a>

```c
typedef void (*thread_analyzer_stack_safety_handler)(struct k_thread *thread,
                                                    size_t unused_space,
                                                    uint32_t *stack_issue);
```

| 参数 | 含义 |
| --- | --- |
| `thread` | 被分析线程的指针 |
| `unused_space` | 未使用的栈空间大小 |
| `stack_issue` | 用于保存栈安全问题码的变量指针 |

## 50.4\_运行分析与打印

<a id="gad95f59d773da7db0ffa16b06b155f655"></a>

<a id="ga4b7e9fb25842e55d7072c271b54e2769"></a>

```c
void thread_analyzer_run(thread_analyzer_cb cb, unsigned int cpu);
void thread_analyzer_print(unsigned int cpu);
```

[`thread_analyzer_run()`](https://docs.zephyrproject.org/latest/doxygen/html/group__thread__analyzer.html#gad95f59d773da7db0ffa16b06b155f655) 分析所有线程的当前状态，并对找到的每个线程调用 `cb`。[`thread_analyzer_print()`](https://docs.zephyrproject.org/latest/doxygen/html/group__thread__analyzer.html#ga4b7e9fb25842e55d7072c271b54e2769) 运行分析器，以标准格式打印栈大小统计。

特殊情况下，如果启用了Kconfig选项 `THREAD_ANALYZER_AUTO_SEPARATE_CORES`，两者仅分析指定**中央处理器（Central Processing Unit，CPU）**上运行的线程。参数 `cpu` 是要分析的CPU；若该选项为 `n`，忽略此参数。

## 50.5\_更换栈安全处理函数

<a id="ga4305de4ac63b112fdfd430407c8b257c"></a>

```c
void thread_analyzer_stack_safety_handler_set(thread_analyzer_stack_safety_handler handler);
```

更换线程分析器的栈安全处理函数，以便在线程未使用栈空间降到所配阈值以下时自定义应用行为。参数 `handler` 指向新处理函数，传入 `NULL` 恢复默认处理。
