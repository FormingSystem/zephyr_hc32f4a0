# 第59章\_核心转储驱动操作表

原文：[structcoredump__driver__api](https://docs.zephyrproject.org/latest/doxygen/html/structcoredump__driver__api.html)。读取日期：2026-10-13，`latest`。

## 59.1\_用途与头文件

结构 [`coredump_driver_api`](https://docs.zephyrproject.org/latest/doxygen/html/structcoredump__driver__api.html) 是**核心转储伪设备（Core Dump Pseudo-device）**驱动必须定义的操作表，包含驱动实现的函数指针，以及其他驱动专有常量数据。

```c
#include <zephyr/drivers/coredump.h>
```

原文标记 `REQ` 表示必需（Required），驱动**必须**设置；`OPT` 表示可选（Optional）。本页列出的四个操作均为必需项。

## 59.2\_操作字段
