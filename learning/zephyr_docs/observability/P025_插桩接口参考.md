# 第25章\_插桩接口参考

原文：[group__instrumentation__api](https://docs.zephyrproject.org/latest/doxygen/html/group__instrumentation__api.html)。读取日期：2026-10-13，`latest`。

## 25.1\_头文件与记录结构

本页为**插桩（Instrumentation）**子系统的**应用程序编程接口（Application Programming Interface，API）**参考。头文件 `instrumentation.h` 声明代码插桩子系统接口：

```c
#include <zephyr/instrumentation/instrumentation.h>
```

| 数据结构 | 用途 |
| --- | --- |
| [`struct instr_header`](P033_插桩事件头.md) | 事件记录头（Event Record Header） |
| [`struct instr_event_context`](P034_插桩事件上下文.md) | 事件的上下文专有数据（Context-specific Data） |
| [`struct instr_record`](P035_插桩事件记录.md) | 事件记录及其关联载荷（Payload） |

## 25.2\_事件类型

枚举 [`instr_event_types`](https://docs.zephyrproject.org/latest/doxygen/html/group__instrumentation__api.html#ga469cc43e8e444c05286ebba0d144460c) 定义插桩事件记录类型：

<a id="ga469cc43e8e444c05286ebba0d144460c"></a>

```c
enum instr_event_types {
    INSTR_EVENT_ENTRY = 0,
    INSTR_EVENT_EXIT,
    INSTR_EVENT_PROFILE,
    INSTR_EVENT_SCHED_IN,
    INSTR_EVENT_SCHED_OUT,
    INSTR_EVENT_NUM,
    INSTR_EVENT_INVALID
};
```

| 枚举项 | 含义 |
| --- | --- |
| <a id="gga469cc43e8e444c05286ebba0d144460caf9491bb7bcc5e3b90f4cc7e2d6976bcd"></a>[`INSTR_EVENT_ENTRY`](https://docs.zephyrproject.org/latest/doxygen/html/group__instrumentation__api.html#gga469cc43e8e444c05286ebba0d144460caf9491bb7bcc5e3b90f4cc7e2d6976bcd) | 被调用函数进入事件记录，原文注明后接 `instr_event` |
| <a id="gga469cc43e8e444c05286ebba0d144460ca8fb728afba254caf3e454409ad90e8f2"></a>[`INSTR_EVENT_EXIT`](https://docs.zephyrproject.org/latest/doxygen/html/group__instrumentation__api.html#gga469cc43e8e444c05286ebba0d144460ca8fb728afba254caf3e454409ad90e8f2) | 被调用函数退出事件记录，原文注明后接 `instr_event` |
| <a id="gga469cc43e8e444c05286ebba0d144460ca75e414c2950978ab683363a847ea8a0c"></a>[`INSTR_EVENT_PROFILE`](https://docs.zephyrproject.org/latest/doxygen/html/group__instrumentation__api.html#gga469cc43e8e444c05286ebba0d144460ca75e414c2950978ab683363a847ea8a0c) | 性能分析（Profiling）事件 |
| <a id="gga469cc43e8e444c05286ebba0d144460cae20226480e25e1818b8e098c773a73b5"></a>[`INSTR_EVENT_SCHED_IN`](https://docs.zephyrproject.org/latest/doxygen/html/group__instrumentation__api.html#gga469cc43e8e444c05286ebba0d144460cae20226480e25e1818b8e098c773a73b5) | 调度器将线程切入的事件 |
| <a id="gga469cc43e8e444c05286ebba0d144460ca032d1a40772fff602cf50ad45f022c24"></a>[`INSTR_EVENT_SCHED_OUT`](https://docs.zephyrproject.org/latest/doxygen/html/group__instrumentation__api.html#gga469cc43e8e444c05286ebba0d144460ca032d1a40772fff602cf50ad45f022c24) | 调度器将线程切出的事件 |
| <a id="gga469cc43e8e444c05286ebba0d144460ca4ff7bca2074b10173d5a45af222c03bd"></a>[`INSTR_EVENT_NUM`](https://docs.zephyrproject.org/latest/doxygen/html/group__instrumentation__api.html#gga469cc43e8e444c05286ebba0d144460ca4ff7bca2074b10173d5a45af222c03bd) | 新事件应添加到此项之前 |

## 25.3\_能力与初始化状态

以下函数查询功能是否可用以及初始化状态，均无参数：

```c
bool instr_tracing_supported(void);
bool instr_profiling_supported(void);
bool instr_dynamic_trigger_supported(void);
bool instr_fundamentals_initialized(void);
int instr_init(void);
bool instr_initialized(void);
```

| 函数 | 行为与返回值 |
| --- | --- |
| <a id="ga4644a5ae2a95db35896eb0007dffffac"></a>[`instr_tracing_supported()`](https://docs.zephyrproject.org/latest/doxygen/html/group__instrumentation__api.html#ga4644a5ae2a95db35896eb0007dffffac) | 检查是否支持跟踪（Tracing）；支持返回 `true`，否则 `false` |
| <a id="gae4d79f7bddd5925282491230dcbdafcd"></a>[`instr_profiling_supported()`](https://docs.zephyrproject.org/latest/doxygen/html/group__instrumentation__api.html#gae4d79f7bddd5925282491230dcbdafcd) | 检查性能分析是否可用；可用返回 `true`，否则 `false` |
| <a id="gadf6d982722da34e0ef1fc0caa9ec5360"></a>[`instr_dynamic_trigger_supported()`](https://docs.zephyrproject.org/latest/doxygen/html/group__instrumentation__api.html#gadf6d982722da34e0ef1fc0caa9ec5360) | 检查动态触发配置（Dynamic Trigger Configuration）是否可用；支持返回 `true`，否则 `false` |
| <a id="gaae69ccca44c9795d520ff88dd16ad270"></a>[`instr_fundamentals_initialized()`](https://docs.zephyrproject.org/latest/doxygen/html/group__instrumentation__api.html#gaae69ccca44c9795d520ff88dd16ad270) | 检查子系统是否具备初始化条件；具备返回 `true`，否则 `false`。**必须在 [`instr_init()`](https://docs.zephyrproject.org/latest/doxygen/html/group__instrumentation__api.html#gabfe70f8b42bd46a7670c0caf19ecf9d6) 之前调用** |
| <a id="gabfe70f8b42bd46a7670c0caf19ecf9d6"></a>[`instr_init()`](https://docs.zephyrproject.org/latest/doxygen/html/group__instrumentation__api.html#gabfe70f8b42bd46a7670c0caf19ecf9d6) | 执行系统要求的初始化，始终返回 `0` |
| <a id="ga6a50c0f38ce42543ffffe36e8fa66cad"></a>[`instr_initialized()`](https://docs.zephyrproject.org/latest/doxygen/html/group__instrumentation__api.html#ga6a50c0f38ce42543ffffe36e8fa66cad) | 检查插桩子系统是否正确初始化；已初始化返回 `true`，否则 `false` |

## 25.4\_启用状态与记录开关

“启用”（Enabled）表示允许开启插桩；“开启”（Turned On）表示开始记录事件。以下接口分别控制和查询这两层状态：

```c
bool instr_enabled(void);
int instr_enable(void);
int instr_disable(void);
int instr_turn_on(void);
int instr_turn_off(void);
bool instr_turned_on(void);
bool instr_trace_enabled(void);
bool instr_profile_enabled(void);
```

| 函数 | 行为与返回值 |
| --- | --- |
| <a id="ga18b2ab24755c20195625fc0c1a940cdf"></a>[`instr_enabled()`](https://docs.zephyrproject.org/latest/doxygen/html/group__instrumentation__api.html#ga18b2ab24755c20195625fc0c1a940cdf) | 是否已启用，即是否可以开启插桩；是为 `true`，否则 `false` |
| <a id="gab75168585bb4dfa4ad61bc61d6d13139"></a>[`instr_enable()`](https://docs.zephyrproject.org/latest/doxygen/html/group__instrumentation__api.html#gab75168585bb4dfa4ad61bc61d6d13139) | 启用插桩，始终返回 `0` |
| <a id="ga9cbb034bc9515bbe73db65786aee2883"></a>[`instr_disable()`](https://docs.zephyrproject.org/latest/doxygen/html/group__instrumentation__api.html#ga9cbb034bc9515bbe73db65786aee2883) | 禁用插桩，始终返回 `0` |
| <a id="ga4b0236b900f4b6ad17f5e76553182c7c"></a>[`instr_turn_on()`](https://docs.zephyrproject.org/latest/doxygen/html/group__instrumentation__api.html#ga4b0236b900f4b6ad17f5e76553182c7c) | 开启插桩，开始记录事件，始终返回 `0` |
| <a id="ga047f5ae434a533de2c417b283fa4507b"></a>[`instr_turn_off()`](https://docs.zephyrproject.org/latest/doxygen/html/group__instrumentation__api.html#ga047f5ae434a533de2c417b283fa4507b) | 关闭插桩，停止记录事件，始终返回 `0` |
| <a id="gaefe08795d416d7348678554d3a78a72f"></a>[`instr_turned_on()`](https://docs.zephyrproject.org/latest/doxygen/html/group__instrumentation__api.html#gaefe08795d416d7348678554d3a78a72f) | 是否已经开启；是为 `true`，否则 `false` |
| <a id="ga6f11997e33209ae444f26c7ccf7448a0"></a>[`instr_trace_enabled()`](https://docs.zephyrproject.org/latest/doxygen/html/group__instrumentation__api.html#ga6f11997e33209ae444f26c7ccf7448a0) | 是否能够收集跟踪数据；能则返回 `true`，否则 `false` |
| <a id="ga4197c8d96b8679484ff7f03c5ea189fa"></a>[`instr_profile_enabled()`](https://docs.zephyrproject.org/latest/doxygen/html/group__instrumentation__api.html#ga4197c8d96b8679484ff7f03c5ea189fa) | 是否能够收集性能信息；能则返回 `true`，否则 `false` |

## 25.5\_数据导出与事件处理

以下两个无参数函数通过**通用异步收发器（Universal Asynchronous Receiver/Transmitter，UART）**导出数据：

<a id="ga1ce7ffd9ef1a74c0f1b17d91bcf85b8f"></a>

<a id="ga1881790320b21092700a470b20fd3291"></a>

```c
void instr_dump_buffer_uart(void);
void instr_dump_deltas_uart(void);
```

[`instr_dump_buffer_uart()`](https://docs.zephyrproject.org/latest/doxygen/html/group__instrumentation__api.html#ga1ce7ffd9ef1a74c0f1b17d91bcf85b8f) 导出跟踪缓冲区内容；[`instr_dump_deltas_uart()`](https://docs.zephyrproject.org/latest/doxygen/html/group__instrumentation__api.html#ga1881790320b21092700a470b20fd3291) 导出性能分析使用的时间差累加数组（Delta Accumulator Array）。两者均无返回值。

处理进入/退出事件的公共回调处理函数为：

<a id="ga898bf91eca9e1b79c67533aeb21f6bf5"></a>

```c
void instr_event_handler(enum instr_event_types opcode, void *func, void *caller);
```

| 参数 | 含义 |
| --- | --- |
| `opcode` | 待处理事件类型 |
| `func` | 被调用函数地址 |
| `caller` | 调用方地址 |

## 25.6\_触发与停止函数

下列接口设置或读取记录区间的函数地址：

<a id="gab2e8c42b53d635c7c5aa256fbf827277"></a>

<a id="ga0303b08c48819229833dcce7c19fc55c"></a>

<a id="ga8ba100c1d94dc45b3a6d17f36c2bf583"></a>

<a id="ga275febe8ffcca4ee03197e9f3bc2d225"></a>

```c
void instr_set_trigger_func(void *callee);
void instr_set_stop_func(void *callee);
void *instr_get_trigger_func(void);
void *instr_get_stop_func(void);
```

[`instr_set_trigger_func()`](https://docs.zephyrproject.org/latest/doxygen/html/group__instrumentation__api.html#gab2e8c42b53d635c7c5aa256fbf827277) 将参数 `callee` 指向的函数设为触发函数（Trigger Function），调用该函数时开启插桩。[`instr_set_stop_func()`](https://docs.zephyrproject.org/latest/doxygen/html/group__instrumentation__api.html#ga0303b08c48819229833dcce7c19fc55c) 将其设为停止函数（Stopper Function），该函数退出时关闭插桩。两者的参数均为函数地址，无返回值。

[`instr_get_trigger_func()`](https://docs.zephyrproject.org/latest/doxygen/html/group__instrumentation__api.html#ga8ba100c1d94dc45b3a6d17f36c2bf583) 和 [`instr_get_stop_func()`](https://docs.zephyrproject.org/latest/doxygen/html/group__instrumentation__api.html#ga275febe8ffcca4ee03197e9f3bc2d225) 均无参数，分别返回触发函数与停止函数的地址。
