# 第62章\_调试示例目录

本组示例展示高级调试（Debugging）功能。

## 62.1\_示例入口

| 示例 | 展示内容 |
| --- | --- |
| [断言（Assertions）](P063_断言示例.md) | 启用断言总开关后，通过断言模块为单个源文件启用详细断言 |
| [调试监视器（Debug Monitor）](P065_调试监视器示例.md) | 配置 Cortex-M 处理器的调试监视器功能 |
| [模糊测试（Fuzzing）](P066_模糊测试示例.md) | 将模糊测试与 Zephyr 应用集成 |
| [通过命令解释器（Shell）传输核心转储（Core Dump）](P064_UDP核心转储命令示例.md) | 从 Zephyr shell 触发故障，将核心转储同时输出为通用异步收发器（Universal Asynchronous Receiver/Transmitter，UART）上的 `#CD:` 十六进制文本及分帧的用户数据报协议（User Datagram Protocol，UDP）数据 |
