# 第65章\_调试监视器示例

原文：[Debug Monitor](https://docs.zephyrproject.org/latest/samples/subsys/debug/debugmon/README.html)。读取日期：2026-10-13，`latest`。

## 65.1\_概述

调试监视器（Debug Monitor）示例展示该功能的基本配置。源码演示如何设置寄存器以启用调试监视器模式，以及如何指定进入断点（Breakpoint）时执行的自定义中断（Interrupt）。

## 65.2\_要求

开发板必须满足以下条件：

- 支持调试监视器功能；原文说明该功能适用于 Cortex-M 处理器，但不包括 Cortex-M0。
- 有通过通用输入输出（General-Purpose Input/Output，GPIO）引脚连接的发光二极管（Light-Emitting Diode，LED）；许多 [Zephyr 支持的开发板和扩展板](https://docs.zephyrproject.org/latest/boards/index.html#boards)称其为用户 LED（User LED）。
- 通过设备树（Devicetree）别名 `led0` 配置该 LED。

## 65.3\_构建与运行

按下面的命令构建并烧录，将 `reel_board` 替换为自己的开发板：

```shell
west build -b reel_board samples/subsys/debug/debugmon
west flash
```

烧录后，开发板进入断点并执行调试监视器异常（Exception）处理代码。LED 开始闪烁，表明即使处理器在调试监视器中断中循环，更高优先级的其他中断仍能继续执行。
