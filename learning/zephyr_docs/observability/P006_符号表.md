# 第6章\_符号表

原文：[Symbol Table (Symtab)](https://docs.zephyrproject.org/latest/services/debugging/symtab.html)。读取日期：2026-10-12，`latest`。

**符号表（Symbol Table，Symtab）**模块在 Zephyr 链接阶段生成完整的函数名与地址表。函数数量很多的复杂应用可能因此占用相当数量的 **只读存储器（Read-Only Memory，ROM）**。目前，在支持的架构上，它用于栈回溯时查找函数名。

## 6.1\_使用

应用包含 `symtab.h`，调用 `symtab_get()` 即可访问符号表数据结构。目前提供 `symtab_find_symbol_name()`，根据地址查找符号名及偏移；更复杂的操作可直接访问数据结构成员。

## 6.2\_配置与API

启用 Kconfig 配置项 `CONFIG_SYMTAB` 生成符号表。接口见[符号表 API](P051_符号表接口.md)。
