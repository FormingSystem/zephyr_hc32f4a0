# 第70章\_多域日志示例

原文：[官方页面](https://docs.zephyrproject.org/latest/samples/subsys/logging/multidomain/README.html)。读取日期：2026-10-14；保存的 latest 页面及 HTML 摘要见[来源记录](../SOURCES.md)。

## 70.1\_概述

本示例在双核片上系统（System on Chip，SoC）上演示 Zephyr 多域日志（Multidomain Logging）。它采用 HOST／REMOTE 架构：HOST 核通过核间通信（Inter-Processor Communication，IPC）服务汇聚 REMOTE 核的日志，使两个核的输出出现在同一个终端。

## 70.2\_要求

需要支持双核并具备 IPC 能力的开发板。原页列出以下目标：

- `nrf5340dk/nrf5340/cpuapp`
- `nrf5340bsim/nrf5340/cpuapp`

## 70.3\_构建与运行

可按以下原始命令为 nRF5340 DK 构建并烧录。主机终端位于已具备工具链、模块及目标烧录工具的 Zephyr 源码根目录：

```sh
west build -b nrf5340dk/nrf5340/cpuapp --sysbuild samples/subsys/logging/multidomain
west flash
```

译注：`--sysbuild` 会按本示例的系统构建配置纳入远程核映像。当前 `sysbuild.cmake` 要求 `SB_CONFIG_NET_CORE_BOARD` 非空，并使用 `ExternalZephyrProject_Add()` 添加 `remote` 应用；仅有 HOST 工程的日志开关不能代替 REMOTE 映像和 IPC 配置。

## 70.4\_示例输出

HOST UART 预期出现以下内容，顺序可能变化：

```text
Hello World! nrf5340dk
<inf> app: Multidomain logging HOST demo started
<inf> app: loop: 0
<inf> app: wait for bound
<inf> app: bounded
<inf> app: REMOTE [1]: 0
<inf> app: HOST [1]: 1
...
<inf> app: Multidomain logging HOST demo ended.
```

输出显示主机域日志演示开始、循环计数、等待 IPC 绑定（Bound）、完成绑定、REMOTE／HOST 消息，以及演示结束。`...` 是原文对中间输出的省略，不是实际日志内容。

译注：当前 HOST 配置启用 `CONFIG_LOG_MULTIDOMAIN` 和 `CONFIG_LOG_LINK_IPC_SERVICE`，并设置处理延迟；这与把两个核的串口线直接接到同一终端不同。原文已说明消息顺序可能变化，不能把样例排列当作跨核执行顺序或时间同步的证明。
