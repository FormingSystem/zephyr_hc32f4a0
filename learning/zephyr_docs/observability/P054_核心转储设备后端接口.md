# 第54章\_核心转储设备后端接口

原文：[group__coredump__device__interface__backend](https://docs.zephyrproject.org/latest/doxygen/html/group__coredump__device__interface__backend.html)。读取日期：2026-10-13，`latest`。

## 54.1\_用途与头文件

本组包含实现**核心转储伪设备（Core Dump Pseudo-device）**驱动所需的应用程序编程接口（Application Programming Interface，API）类型、回调（Callback）签名及其他辅助定义。

```c
#include <zephyr/drivers/coredump.h>
```

驱动操作（Driver Operations）由 [`struct coredump_driver_api`](P059_核心转储驱动操作表.md)描述。

## 54.2\_设备转储回调

<a id="ga29e247a331530605d07e455b7c4d5bbe"></a>

```c
typedef void (*coredump_device_dump_t)(const struct device *dev);
```

将设备数据加入正在生成的核心转储。核心转储子系统在转储期间调用此回调，使设备可以复制已注册内存区域及回调数据到转储中。

## 54.3\_内存注册与注销回调

<a id="ga3636c9a9a8a4ed5c69f4bc8167f56a6f"></a>

<a id="gac8fc902abc6f3df30bc67e6836a56751"></a>

```c
typedef bool (*coredump_device_register_memory_t)(const struct device *dev,
                                                 struct coredump_mem_region_node *region);
typedef bool (*coredump_device_unregister_memory_t)(const struct device *dev,
                                                   struct coredump_mem_region_node *region);
```

前者注册要保存到核心转储的内存区域；后者取消该内存区域的保存注册。参数说明分别见[设备接口](P053_核心转储设备接口.md)中的 [`coredump_device_register_memory()`](https://docs.zephyrproject.org/latest/doxygen/html/group__coredump__device__interface.html#ga14ccecab2b077a32a0bc3bf4ec5df909) 和 [`coredump_device_unregister_memory()`](https://docs.zephyrproject.org/latest/doxygen/html/group__coredump__device__interface.html#gafd4e43696175eeb3ad1a2894df945530)。

## 54.4\_转储回调的注册操作

<a id="gaa7a38c4ce30fe0742f36d9bd7c96f73b"></a>

```c
typedef bool (*coredump_device_register_callback_t)(const struct device *dev,
                                                   coredump_dump_callback_t callback);
```

注册将在转储期间调用的回调。参数说明见[设备接口](P053_核心转储设备接口.md)中的 [`coredump_device_register_callback()`](https://docs.zephyrproject.org/latest/doxygen/html/group__coredump__device__interface.html#ga9a59905e1440bdc78aa115645d85d363)。
