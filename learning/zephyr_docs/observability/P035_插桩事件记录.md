# 第35章\_插桩事件记录

原文：[structinstr__record](https://docs.zephyrproject.org/latest/doxygen/html/structinstr__record.html)。读取日期：2026-10-13，`latest`。

## 35.1\_类型与头文件

结构 [`instr_record`](https://docs.zephyrproject.org/latest/doxygen/html/structinstr__record.html) 保存插桩事件记录及其关联载荷（Event Record and Payload）。

```c
#include <zephyr/instrumentation/instrumentation.h>
```

## 35.2\_字段

位宽列为原文明确列出的位域（Bit-field）宽度；“—”表示本表未给位域宽度。

载荷根据代码以及记录头中的其他字段确定。原文中的事件载荷使用匿名联合体（Anonymous Union），其成员为 `struct instr_event_context context`；`context` 不是联合体之外的另一个独立载荷字段。
