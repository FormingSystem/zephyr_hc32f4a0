# 第66章\_模糊测试示例

原文：[Fuzzing](https://docs.zephyrproject.org/latest/samples/subsys/debug/fuzz/README.html)。读取日期：2026-10-13，`latest`。

## 66.1\_概述

这是将模糊测试（Fuzz Testing）集成到 Zephyr 应用中的简单示例，展示 LLVM libFuzzer 最重要的一项能力：利用插桩（Instrumentation）后的二进制程序收集到的覆盖率（Coverage）信息，发现并探索深层、复杂的调用树（Call Tree）。

## 66.2\_构建与运行

原文说明，目前唯一能配合 libFuzzer 使用的工具链（Toolchain）是较新的64位 clang；开发此示例时使用 clang 14。确保主机环境安装了这样的工具链，然后执行。命令中的环境变量 `ZEPHYR_TOOLCHAIN_VARIANT` 选择工具链变体：

```shell
$ clang --version
clang version 14.0.6
Target: x86_64-pc-linux-gnu
Thread model: posix
InstalledDir: /usr/bin
$ export ZEPHYR_TOOLCHAIN_VARIANT=host/llvm
$ west build -t run -b native_sim/native/64 samples/subsys/debug/fuzz
```

经过约10～20秒（实际运行时间可能变化较大），可以看到它发现并递归进入测试专门构造的调用树深处，最终到达终态时崩溃并报告失败。
