# 第52章\_核心转储接口

原文：[group__coredump__apis](https://docs.zephyrproject.org/latest/doxygen/html/group__coredump__apis.html)。读取日期：2026-10-13，`latest`。

## 52.1\_头文件与版本

本页为**核心转储（Core Dump）**应用程序编程接口（Application Programming Interface，API），自Zephyr 2.4提供，接口版本为1.0.0。

<a id="gab97503d4de13bdde139fe0880947379a"></a>

```c
#include <zephyr/debug/coredump.h>
```

复制已保存转储的命令参数由 [`struct coredump_cmd_copy_arg`](P057_核心转储复制参数.md)定义，供 [`COREDUMP_CMD_COPY_STORED_DUMP`](https://docs.zephyrproject.org/latest/doxygen/html/group__coredump__apis.html#gga48765a88d430aaec373a2ce6e4796578a0cc9387829efa1f3c6f802217adc3819) 使用。

## 52.2\_查询标识符

枚举 [`coredump_query_id`](https://docs.zephyrproject.org/latest/doxygen/html/group__coredump__apis.html#ga26360cadb6b43f5c86b59332e66008f5) 定义**查询标识符（Query ID）**：

<a id="ga26360cadb6b43f5c86b59332e66008f5"></a>

```c
enum coredump_query_id {
    COREDUMP_QUERY_GET_ERROR,
    COREDUMP_QUERY_HAS_STORED_DUMP,
    COREDUMP_QUERY_GET_STORED_DUMP_SIZE,
    COREDUMP_QUERY_MAX
};
```

| 查询 | 行为与返回值 |
| --- | --- |
| <a id="gga26360cadb6b43f5c86b59332e66008f5afa7363b57e57c55fffa8cc9e9050d6cb"></a>[`COREDUMP_QUERY_GET_ERROR`](https://docs.zephyrproject.org/latest/doxygen/html/group__coredump__apis.html#gga26360cadb6b43f5c86b59332e66008f5afa7363b57e57c55fffa8cc9e9050d6cb) | 返回后端（Backend）的错误码 |
| <a id="gga26360cadb6b43f5c86b59332e66008f5a89f3cc157e790b8aa324d76a01b73e83"></a>[`COREDUMP_QUERY_HAS_STORED_DUMP`](https://docs.zephyrproject.org/latest/doxygen/html/group__coredump__apis.html#gga26360cadb6b43f5c86b59332e66008f5a89f3cc157e790b8aa324d76a01b73e83) | 查询后端是否有已保存转储；有则返回1，无则0；不支持返回 `-ENOTSUP`，其他情况返回后端错误码 |
| <a id="gga26360cadb6b43f5c86b59332e66008f5ac3e34206cd358efdc1ed7a2996b98483"></a>[`COREDUMP_QUERY_GET_STORED_DUMP_SIZE`](https://docs.zephyrproject.org/latest/doxygen/html/group__coredump__apis.html#gga26360cadb6b43f5c86b59332e66008f5ac3e34206cd358efdc1ed7a2996b98483) | 返回后端中原始转储大小，无转储时返回0；不支持返回 `-ENOTSUP`，其他情况返回后端错误码 |

## 52.3\_命令标识符

枚举 [`coredump_cmd_id`](https://docs.zephyrproject.org/latest/doxygen/html/group__coredump__apis.html#ga48765a88d430aaec373a2ce6e4796578) 定义**命令标识符（Command ID）**：

<a id="ga48765a88d430aaec373a2ce6e4796578"></a>

```c
enum coredump_cmd_id {
    COREDUMP_CMD_CLEAR_ERROR,
    COREDUMP_CMD_VERIFY_STORED_DUMP,
    COREDUMP_CMD_ERASE_STORED_DUMP,
    COREDUMP_CMD_COPY_STORED_DUMP,
    COREDUMP_CMD_INVALIDATE_STORED_DUMP,
    COREDUMP_CMD_MAX
};
```

| 命令 | 行为与返回值 |
| --- | --- |
| <a id="gga48765a88d430aaec373a2ce6e4796578aef8cf1d85b2dfb2c911cb2abb7e3b38f"></a>[`COREDUMP_CMD_CLEAR_ERROR`](https://docs.zephyrproject.org/latest/doxygen/html/group__coredump__apis.html#gga48765a88d430aaec373a2ce6e4796578aef8cf1d85b2dfb2c911cb2abb7e3b38f) | 清除后端错误码；成功返回0，其他值表示失败 |
| <a id="gga48765a88d430aaec373a2ce6e4796578ab8f6dd3e8062175c9790bfe5d2b2aeaa"></a>[`COREDUMP_CMD_VERIFY_STORED_DUMP`](https://docs.zephyrproject.org/latest/doxygen/html/group__coredump__apis.html#gga48765a88d430aaec373a2ce6e4796578ab8f6dd3e8062175c9790bfe5d2b2aeaa) | 验证已保存转储；有效返回1，无效或不存在返回0；不支持返回 `-ENOTSUP`，其他情况返回后端错误码 |
| <a id="gga48765a88d430aaec373a2ce6e4796578ab46f9f907e75e1187a6b7a2efd7e54f6"></a>[`COREDUMP_CMD_ERASE_STORED_DUMP`](https://docs.zephyrproject.org/latest/doxygen/html/group__coredump__apis.html#gga48765a88d430aaec373a2ce6e4796578ab46f9f907e75e1187a6b7a2efd7e54f6) | 擦除已保存转储；成功返回0，不支持返回 `-ENOTSUP`，其他情况返回后端错误码 |
| <a id="gga48765a88d430aaec373a2ce6e4796578a0cc9387829efa1f3c6f802217adc3819"></a>[`COREDUMP_CMD_COPY_STORED_DUMP`](https://docs.zephyrproject.org/latest/doxygen/html/group__coredump__apis.html#gga48765a88d430aaec373a2ce6e4796578a0cc9387829efa1f3c6f802217adc3819) | 复制已保存的原始转储；成功返回复制大小，找不到转储返回0；不支持返回 `-ENOTSUP`，其他情况返回后端错误码 |

## 52.4\_生成核心转储

```c
static inline void coredump(unsigned int reason, const struct arch_esf *esf,
                            struct k_thread *thread);
```

执行核心转储。通常在遇到致命错误（Fatal Error）时，由 `z_fatal_error()` 内部调用；也可在需要时按需调用。

| 参数 | 含义 |
| --- | --- |
| `reason` | 致命错误原因 |
| `esf` | 异常上下文（Exception Context） |
| `thread` | 要转储的线程信息 |

## 52.5\_内存区域与缓冲区输出

<a id="gab8823860579eee41380da8b7a4d93cd0"></a>

<a id="gabe58e47cc733572a6650d3fd2cfc7d9d"></a>

```c
static inline void coredump_memory_dump(uintptr_t start_addr, uintptr_t end_addr);
static inline void coredump_buffer_output(uint8_t *buf, size_t buflen);
```

[`coredump_memory_dump()`](https://docs.zephyrproject.org/latest/doxygen/html/group__coredump__apis.html#gab8823860579eee41380da8b7a4d93cd0) 转储一段内存，`start_addr` 为起始地址，`end_addr` 为结束地址。原文未在本页进一步说明结束地址是否包含在区域内。

[`coredump_buffer_output()`](https://docs.zephyrproject.org/latest/doxygen/html/group__coredump__apis.html#gabe58e47cc733572a6650d3fd2cfc7d9d) 向核心转储后端输出字节数组缓冲区，可用于输出寄存器部分或内存转储部分。`buf` 是待输出缓冲区，`buflen` 为其长度。

## 52.6\_执行查询与命令

<a id="ga772697785da4247a7a8c3fccdbe921ce"></a>

<a id="ga5c7f6fb24c724ede550d2c54f7ce2336"></a>

```c
static inline int coredump_query(enum coredump_query_id query_id, void *arg);
static inline int coredump_cmd(enum coredump_cmd_id cmd_id, void *arg);
```

[`coredump_query()`](https://docs.zephyrproject.org/latest/doxygen/html/group__coredump__apis.html#ga772697785da4247a7a8c3fccdbe921ce) 查询核心转储子系统信息，例如是否存在错误。输入参数 `query_id` 为查询标识符；输入/输出参数 `arg` 指向交换信息的参数。返回值取决于所选查询，见查询表。

[`coredump_cmd()`](https://docs.zephyrproject.org/latest/doxygen/html/group__coredump__apis.html#ga5c7f6fb24c724ede550d2c54f7ce2336) 执行核心转储命令，例如通过日志输出已保存转储。输入参数 `cmd_id` 为命令标识符，输入/输出参数 `arg` 同样用于交换信息。返回值取决于所选命令，见命令表。

> 译注：原文顶部简表将 `coredump_cmd()` 的首参数名写作 `query_id`，详细接口段使用 `cmd_id`。这里采用详细段的名称，类型保持 `enum coredump_cmd_id`。
