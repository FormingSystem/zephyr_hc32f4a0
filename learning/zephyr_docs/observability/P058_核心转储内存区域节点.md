# 第58章\_核心转储内存区域节点

原文：[structcoredump__mem__region__node](https://docs.zephyrproject.org/latest/doxygen/html/structcoredump__mem__region__node.html)。读取日期：2026-10-13，`latest`。

## 58.1\_用途与头文件

结构 [`coredump_mem_region_node`](https://docs.zephyrproject.org/latest/doxygen/html/structcoredump__mem__region__node.html) 描述生成**核心转储（Core Dump）**时可以保存的一段内存区域（Memory Region）。将该结构实例传给 [`coredump_device_register_memory()`](https://docs.zephyrproject.org/latest/doxygen/html/group__coredump__device__interface.html#ga14ccecab2b077a32a0bc3bf4ec5df909) 或 [`coredump_device_unregister_memory()`](https://docs.zephyrproject.org/latest/doxygen/html/group__coredump__device__interface.html#gafd4e43696175eeb3ad1a2894df945530)，可增加或移除待捕获区域；函数说明见[核心转储设备接口](P053_核心转储设备接口.md)。

```c
#include <zephyr/drivers/coredump.h>
```
