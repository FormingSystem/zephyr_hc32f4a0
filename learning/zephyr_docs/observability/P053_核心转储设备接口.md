# 第53章\_核心转储设备接口

原文：[group__coredump__device__interface](https://docs.zephyrproject.org/latest/doxygen/html/group__coredump__device__interface.html)。读取日期：2026-10-13，`latest`。

## 53.1\_伪设备与头文件

本页提供**核心转储伪设备（Core Dump Pseudo-device）**驱动的应用程序编程接口（Application Programming Interface，API）。自Zephyr 3.2提供，接口版本为0.1.0。驱动实现参见[后端接口](P054_核心转储设备后端接口.md)。

```c
#include <zephyr/drivers/coredump.h>
```

[`struct coredump_mem_region_node`](P058_核心转储内存区域节点.md)描述生成核心转储时可以保存的内存区域（Memory Region）。

## 53.2\_转储时回调

回调（Callback）类型为：

<a id="ga47ab4c7475a938c294d65dd7bd0197eb"></a>

```c
typedef void (*coredump_dump_callback_t)(uintptr_t dump_area, size_t dump_area_size);
```

在生成转储时调用；复制到 `dump_area` 的数据将被纳入转储。参数 `dump_area` 是目标区域地址，`dump_area_size` 是该区域可用内存大小。

## 53.3\_注册和注销内存区域

<a id="ga14ccecab2b077a32a0bc3bf4ec5df909"></a>

<a id="gafd4e43696175eeb3ad1a2894df945530"></a>

```c
static inline bool coredump_device_register_memory(const struct device *dev,
                                                   struct coredump_mem_region_node *region);
static inline bool coredump_device_unregister_memory(const struct device *dev,
                                                     struct coredump_mem_region_node *region);
```

注册函数将一段内存加入生成核心转储时保存的区域；注销函数取消该区域的注册。两者参数含义相同：`dev` 指向驱动实例的设备结构，`region` 指向描述待收集内存的结构。

注册函数成功返回 `true`、失败返回 `false`；注销函数同样以 `true` 表示注销成功、`false` 表示注销失败。

## 53.4\_注册回调

<a id="ga9a59905e1440bdc78aa115645d85d363"></a>

```c
static inline bool coredump_device_register_callback(const struct device *dev,
                                                     coredump_dump_callback_t callback);
```

注册生成转储时要调用的回调。`dev` 指向驱动实例的设备结构，`callback` 为该回调。注册成功返回 `true`，失败返回 `false`。
