# 总线实时输入输出头文件参考大纲

本册完整翻译I2C与I3C驱动的RTIO（实时输入输出，Real-Time I/O）头文件参考及源码浏览页。内容包括上下文定义、消息转提交队列项、事务推进、同步兼容包装，以及I2C同步／异步推进回调和I3C公共命令码（Common Command Code，CCC）包装。

原始声明、展开值、参数、返回说明、代码、注释与符号提示保留。源码译注单独说明缓冲区生存期、队列清理范围、提交与完成区别、阻塞等待、设备绑定及驱动能力。进一步参阅[I2C公共接口](../hardware/P305_I2C公共接口.md)、[I3C公共接口](../hardware/P425_I3C公共接口参考.md)。本地定位使用相对链接，整站尚未完成，见[全站进度](../PROGRESS.md)。
