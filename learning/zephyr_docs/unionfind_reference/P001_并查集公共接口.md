## 1.4\_详细说明（Detailed Documentation）

<a id="ga2dd615047d421a97a8cc1ff412cf024d"></a>

### `sys_set_find()`

```c
struct sys_set_node * sys_set_find ( struct sys_set_node * node)
```

```c
#include <zephyr/sys/set.h>
```

查找不相交集合的根节点（Root Node）。

**参数（Parameters）**

| 名称／方向 | 说明 |
| --- | --- |
| `node` | 指向sys_set_node结构的指针。 |

**返回（Returns）**：包含node的集合所对应的根sys_set_node指针。

> 译注——源码核对：while循环检查node是否等于node->parent；每步先保存原父节点，再把当前parent指向祖父，随后移动到原父。没有递归或额外分配，但会修改经过的路径，不能以const查询或无同步读操作对待。

<a id="gae88559a39874fcdc4f8a4a1aa09cfaaa"></a>

### `sys_set_makeset()`

```c
void sys_set_makeset ( struct sys_set_node * node, uint16_t rank )
```

声明属性：`inline`、`static`。

```c
#include <zephyr/sys/set.h>
```

初始化一个不相交集合。

**参数（Parameters）**

| 名称／方向 | 说明 |
| --- | --- |
| `node` | 指向sys_set_node结构的指针。 |
| `rank` | 初始秩（Rank），通常设置为0。 |

> 译注——源码核对：仅执行node->parent=node与node->rank=rank。普通使用传0；rank为uint16_t，任意给很大的初始值后在等秩合并中自增可能回绕，接口没有溢出检查。先初始化每个节点，再参与find或union。

<a id="gadc4cda883c44c79e3a143a8d5585c011"></a>

### `sys_set_union()`

```c
void sys_set_union ( struct sys_set_node * node1, struct sys_set_node * node2 )
```

```c
#include <zephyr/sys/set.h>
```

将两个节点合并到同一个不相交集合中。

此函数把秩较小的节点连接到秩较大的节点。也就是说，如果node1的秩小于node2，它会连接到node2。

**参数（Parameters）**

| 名称／方向 | 说明 |
| --- | --- |
| `node1` | 指向sys_set_node结构的指针。 |
| `node2` | 指向sys_set_node结构的指针。 |

> 译注——源码核对：原说明以node1／node2描述秩比较，当前源码实际比较find得到的root1／root2，传入参数无需本身就是根。若根相同便返回，集合关系不变，但前面的两次find仍可能压缩路径。等秩时root2接到root1，只有root1的秩增加。

## 1.5\_源码定位与版本边界

对照[公共API](P001_并查集公共接口.md)、[节点](P002_并查集节点.md)、[头文件参考](P003_并查集头文件参考.md)与[源码浏览](P004_并查集头文件源码.md)。相对定位：[set.h](../../../include/zephyr/sys/set.h)、[set.c](../../../lib/utils/set.c)及[库构建规则](../../../lib/utils/CMakeLists.txt)。

本次依据为[官方头文件](https://github.com/zephyrproject-rtos/zephyr/blob/main/include/zephyr/sys/set.h)与[官方实现](https://github.com/zephyrproject-rtos/zephyr/blob/main/lib/utils/set.c)，摘要见[来源记录](../SOURCES.md)。

> 译注——源码核对：用途与所有权：并查集（Disjoint-set／Union-Find）维护节点所属集合，适合通过比较根代表判断是否属于同一分组；它不是保存任意键值的哈希集合。节点由应用分配并管理生命周期，接口只修改parent与rank，不分配或释放节点，也不提供删除、拆分或枚举全部成员的接口。

> 译注——源码核对：初始化：每个新节点先以makeset(node, 0)建立独立集合，parent指向节点自身。初始化后节点地址应保持稳定；把已初始化节点按字节复制到新地址不会自动修复自引用或其他节点指向它的关系。不能把对已入集合节点再次makeset当作通用删除或拆分操作。

> 译注——源码核对：路径与秩：find采用路径分裂（Path Splitting），沿途把当前节点的parent改为祖父，再移动到原父节点。union先找两个根，再按根的秩合并；秩相等时把第二个根接到第一个根并增加第一个根的秩。秩是合并策略的辅助量，不是集合成员数，路径压缩后也不等于精确树高。

> 译注——源码核对：复杂度边界：原文O(alpha(n))对应并查集操作序列的摊销界（Amortized Bound），alpha为反阿克曼函数（Inverse Ackermann Function）；不能把它理解为每次find只执行固定次数的循环。通常从秩0的独立集合开始并按接口合并，不能任意篡改秩后仍沿用这一分析。

> 译注——源码核对：并发与有效性：find会写父指针，因此查询也需纳入调用者的同步方案。接口没有空指针、节点归属或损坏环路检查；父链必须经过有效节点并最终到达自指的根。仍被其他节点引用的对象不能提前释放，返回的根代表也可能在后续union后改变。

本次验证范围为文档与源码对照，未构建或执行并查集及实板实验。
