# 并查集参考大纲

不相交集合／并查集（Disjoint-set／Union-Find）用于维护节点之间的分组关系：makeset把节点初始化为独立集合，find返回集合的根代表，union合并两个节点所在集合。在同一稳定状态下比较两个节点的根代表，可以判断它们是否属于同一组。

本册保留官方接口、节点说明、声明、参数及头文件可见源码。单独标注的源码译注说明路径分裂（Path Splitting）、按秩合并（Union by Rank）和生命周期前提；find也会写父指针，接口不自行同步。它与[哈希映射](../hashmap_reference/大纲.md)的键值查找用途不同，不能用来删除或枚举集合成员。全部本地定位采用相对路径，完整范围见[全站进度](../PROGRESS.md)。
