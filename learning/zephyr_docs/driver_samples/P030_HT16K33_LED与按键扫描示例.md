# 第30章\_HT16K33\_LED与按键扫描示例

原文：[官方页面](https://docs.zephyrproject.org/latest/samples/drivers/ht16k33/README.html)。读取日期：2026-10-14；保存的latest页面及HTML摘要见[来源记录](../SOURCES.md)。

<a id="overview"></a>

## 30.1\_概览（Overview）

<a id="id2"></a>

本例控制连接到[Holtek HT16K33](https://www.holtek.com/page/vg/HT16K33A)驱动器的发光二极管（Light-emitting Diode，LED），最多支持连接在器件行／列（Row/Column）上的128个LED。器件资料见参考文献[[1]](#id1)。

按以下顺序控制LED：

1. 逐个点亮所有已连接的LED，最多128个。
2. 依次以2 Hz、1 Hz和0.5 Hz闪烁。
3. 将亮度从100%逐渐降低到0%。
4. 关闭全部LED，恢复100%亮度，然后重新开始。

示例还会在控制台记录按键扫描（Keyscan）事件。

> 译注——LED与输入两条路径：所读[main.c](https://raw.githubusercontent.com/zephyrproject-rtos/zephyr/main/samples/drivers/ht16k33/src/main.c)执行LED循环；[prj.conf](https://raw.githubusercontent.com/zephyrproject-rtos/zephyr/main/samples/drivers/ht16k33/prj.conf)启用INPUT、INPUT_EVENT_DUMP和HT16K33_KEYSCAN，使输入事件也能输出。闪烁周期500、1000、2000毫秒分别对应2、1、0.5 Hz，不要把周期数值直接当作频率。

<a id="building-and-running"></a>

## 30.2\_构建与运行（Building and Running）

为[nRF52840 DK开发板](https://docs.zephyrproject.org/latest/boards/nordic/nrf52840dk/doc/index.html#nrf52840dk)构建应用，并把地址为0x70的HT16K33 LED驱动器连接到I2C-0总线。

> 译注——执行位置：以下原命令在已配置Zephyr环境的终端、Zephyr源码根目录运行。官方随附的[板级覆盖文件](https://raw.githubusercontent.com/zephyrproject-rtos/zephyr/main/samples/drivers/ht16k33/boards/nrf52840dk_nrf52840.overlay)描述该器件节点；具体引脚与电气连接按相应板和器件资料确认。构建失败时先核对板目标、覆盖文件与驱动配置。

```bash
west build -b nrf52840dk/nrf52840 samples/drivers/ht16k33
```

烧录方法见[nRF52840 DK开发板文档](https://docs.zephyrproject.org/latest/boards/nordic/nrf52840dk/doc/index.html#nrf52840dk)中的Flashing（烧录）章节。
