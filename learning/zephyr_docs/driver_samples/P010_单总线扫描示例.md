# 第10章\_单总线扫描示例

原文：[官方页面](https://docs.zephyrproject.org/latest/samples/drivers/w1/scanner/README.html)。读取日期：2026-10-14；保存的latest页面及HTML摘要见[来源记录](../SOURCES.md)。

<a id="overview"></a>

## 10.1\_概览（Overview）

本例演示扫描单总线（1-Wire）器件。程序执行一次扫描例程（Scan Routine），输出发现器件的系列标识（Family ID）及序列号（Serial Number）。

<a id="building-and-running"></a>

## 10.2\_构建与运行（Building and Running）

将 `DTC_OVERLAY_FILE` 设为 `ds2484.overlay` 或 `w1_serial.overlay`，以启用和配置相应驱动。

```bash
west build -b nrf52840dk/nrf52840 samples/drivers/w1/scanner -- -DDTC_OVERLAY_FILE=w1_serial.overlay
west flash
```

> 译注——覆盖文件区别：随例提供的[ds2484.overlay](https://raw.githubusercontent.com/zephyrproject-rtos/zephyr/main/samples/drivers/w1/scanner/ds2484.overlay)在arduino_i2c下声明地址0x18的maxim,ds2484桥接器；[w1_serial.overlay](https://raw.githubusercontent.com/zephyrproject-rtos/zephyr/main/samples/drivers/w1/scanner/w1_serial.overlay)在arduino_serial下启用zephyr,w1-serial。两者对应不同硬件接入方式，不能只按文件名随意选择。命令从Zephyr源码根执行，目标板的相关节点及实际接线需匹配所选覆盖文件。

<a id="sample-output"></a>

### 10.2.1\_示例输出（Sample Output）

```text
[00:00:00.392,272] <inf> main: Device found; family: 0x3a, serial: 0x3af9985800000036
[00:00:00.524,169] <inf> main: Device found; family: 0x3a, serial: 0x3a6ea2580000003b
[00:00:00.656,097] <inf> main: Device found; family: 0x28, serial: 0x2856fb470d000022
[00:00:00.656,097] <inf> main: Number of devices found on bus: 3
```

> 译注——数字含义：原例发现3个器件，系列标识分别为0x3a、0x3a和0x28。所读[main.c](https://raw.githubusercontent.com/zephyrproject-rtos/zephyr/main/samples/drivers/w1/scanner/src/main.c)的serial输出实际来自w1_rom_to_uint64，即完整64位ROM值；不应把该字段误认为去掉系列码与校验字段后的独立48位序列号。扫描只执行一次，若设备未就绪或数量异常，先核对驱动、覆盖文件和总线连接，再重新运行。
