## 12.1\_示例范围

这组示例演示如何使用集成电路间音频总线（Inter-IC Sound，I2S）驱动API。

| 示例 | 功能 |
| --- | --- |
| [I2S编解码器（Codec）](../hardware/P083_I2S编解码器示例.md#i2s_codec) | 处理发往编解码器的音频流 |
| [I2S回声（Echo）](../hardware/P084_I2S回声示例.md#i2s-echo) | 为音频流加入回声效果 |
| [I2S输出（Output）](../hardware/P085_I2S输出示例.md#i2s-output) | 发送I2S输出流 |

> 译注——目录页：原文只有这三项入口。三个详细示例已分别翻译，链接指向对应正文；本页不重复说明硬件接线和构建分支，也不把入口当作新的实测结果。
