# 第49章\_TMC6460电压模式示例

原文：[官方页面](https://docs.zephyrproject.org/latest/samples/drivers/misc/tmc6460/README.html)。读取日期：2026-10-14；保存的latest页面及HTML摘要见[来源记录](../SOURCES.md)。

<a id="overview"></a>

## 49.1\_概览（Overview）

本例完成TMC6460硬件初始化（Hardware Bring-up），包括提交时钟有限状态机（Finite State Machine，FSM）配置、复位模数转换器（Analog-to-Digital Converter，ADC）和启用栅极驱动器（Gate Driver），随后以开环电压模式（Open-loop Voltage Mode）驱动无刷直流电机（Brushless DC Motor，BLDC）。它显式执行通常由评估板固件完成的初始化。

<a id="requirements"></a>

## 49.2\_要求（Requirements）

- 一块具有可用SPI或UART总线的开发板。
- 一块连接BLDC电机的TMC6460评估板，以及适合该电机的电源。
- 两个分别接到TMC6460 `DRV_EN`和`SLEEPN`引脚的GPIO，并通过`tmc6460-drv-en`、`tmc6460-sleepn`设备树别名提供访问。

电机极对数（Pole-pair Count）从设备树属性`pole-pairs`读取，因此更换电机时，可通过修改开发板覆盖文件（Overlay）调整这一参数。

> 译注——参数范围：原文“只修改覆盖文件即可支持不同电机”对应极对数配置。所读[main.c](https://raw.githubusercontent.com/zephyrproject-rtos/zephyr/main/samples/drivers/misc/tmc6460/src/main.c)还包含固定的开环速度、开环电压和运行时间等演示设定；它们不是自动根据电机推导出的值，不能仅凭极对数正确认定所有电机与供电条件均适用。

<a id="building-and-running"></a>

## 49.3\_构建与运行（Building and Running）

> 译注——命令前提：在已配置Zephyr环境的终端、Zephyr源码根目录执行以下原命令。先确认目标板、总线、使能GPIO、极对数和电机连接；构建成功后再烧录，配置错误时返回相应覆盖文件检查。

```bash
west build -b nucleo_f413zh samples/drivers/misc/tmc6460
west flash
```

把`nucleo_f413zh`替换为实际目标板。如果示例`boards/`目录下尚无该板的覆盖文件，应创建一个，把`tmc6460`节点放在正确的SPI总线上，并定义`tmc6460-drv-en`和`tmc6460-sleepn`两个GPIO别名。

<a id="uart-transport"></a>

### 49.3.1\_UART传输（UART transport）

构建UART变体时，同时提供UART设备树覆盖文件和传输配置覆盖文件：

```bash
west build -b nucleo_f413zh samples/drivers/misc/tmc6460 \
  -- -DDTC_OVERLAY_FILE=uart.overlay -DEXTRA_CONF_FILE=overlay-uart.conf
west flash
```

不提供这些参数时，示例默认采用SPI。`uart.overlay`把`tmc6460`节点放到UART总线，`overlay-uart.conf`把驱动传输方式从SPI切换到UART。

> 译注——文件来源：这两个文件均为示例随附配置。所读[uart.overlay](https://raw.githubusercontent.com/zephyrproject-rtos/zephyr/main/samples/drivers/misc/tmc6460/uart.overlay)面向Nucleo F413ZH的USART6及指定GPIO，并不自动适配所有替换板；[overlay-uart.conf](https://raw.githubusercontent.com/zephyrproject-rtos/zephyr/main/samples/drivers/misc/tmc6460/overlay-uart.conf)关闭SPI传输并启用UART。两者分别配置硬件描述和驱动选项，缺一不可。

**警告：**本例运行时电机会转动。运行前必须确认机械条件允许其安全旋转。

> 译注——验证边界：本批只翻译并核对上述接口和配置，未构建、烧录、给电机上电或运行电机。
