# 第29章\_触觉反馈示例目录

原文：[官方页面](https://docs.zephyrproject.org/latest/samples/drivers/haptics/README.html)。读取日期：2026-10-14；保存的latest页面及HTML摘要见[来源记录](../SOURCES.md)。

## 29.1\_示例范围

这些示例演示如何使用[触觉反馈（Haptics）](../hardware/P125_触觉反馈.md#haptics-api)驱动API。

| 示例 | 功能 |
| --- | --- |
| [CS40L26触觉驱动](../hardware/P160_CS40L26触觉驱动示例.md#cs40l26) | 通过CS40L26／27触觉驱动芯片驱动线性谐振执行器（Linear Resonant Actuator，LRA） |
| [CS40L5x触觉驱动](../hardware/P161_CS40L5x触觉驱动示例.md#cs40l5x) | 通过CS40L5x触觉驱动芯片驱动LRA |
| [DRV2605触觉驱动](../hardware/P162_DRV2605触觉驱动示例.md#drv2605) | 通过DRV2605触觉驱动芯片驱动LRA |
| [TM6605触觉驱动](../hardware/P163_TM6605触觉驱动示例.md#tm6605) | 通过Titan Micro Electronics TM6605触觉驱动芯片驱动LRA |

> 译注——目录边界：本页虽采用README文件名，实际是四个触觉示例的官方目录。四个子示例在各自译文中说明配置和运行；此处保留官方芯片名称用于辨认驱动对象，不扩展翻译厂商整套资料。


对应官方文档源码：[samples/drivers/haptics/README.rst](https://raw.githubusercontent.com/zephyrproject-rtos/zephyr/main/samples/drivers/haptics/README.rst)。
