# 第28章\_电量计示例

原文：[官方页面](https://docs.zephyrproject.org/latest/samples/drivers/fuel_gauge/README.html)。读取日期：2026-10-14；保存的latest页面及HTML摘要见[来源记录](../SOURCES.md)。

<a id="overview"></a>

## 28.1\_概览（Overview）

本例演示如何使用Zephyr的[电量计（Fuel Gauge）](../hardware/P108_电量计.md#fuel-gauge-api)驱动API。

首先，示例尝试读取所有公开的电量计属性（Property），确认所用驱动支持哪些属性。随后，通过`FUEL_GAUGE_RELATIVE_STATE_OF_CHARGE_PCT`和`FUEL_GAUGE_VOLTAGE_UV`属性，周期性读取电池剩余电量百分比和电压。

**注意：**为避免错误配置芯片（Integrated Circuit，IC），示例不会设置或写入任何属性。

<a id="building-and-running"></a>

## 28.2\_构建与运行（Building and Running）

可以通过配置让示例支持某个电量计。

> 译注——设备选择与原文范围：原页没有给出通用构建命令。所读[main.c](https://raw.githubusercontent.com/zephyrproject-rtos/zephyr/main/samples/drivers/fuel_gauge/src/main.c)使用fuel_gauge0设备树别名，因此先核对所用板的电量计器件、总线连接、驱动及该别名；不能仅从下面lc709203f日志推断任意板均可直接运行。

<a id="features"></a>

## 28.3\_功能（Features）

通过本例可获取以下信息：

- 读取所有公开电量计属性。
- 周期性读取电池电量百分比。
- 周期性读取电池电压。
