## 46.1\_示例范围

这些示例演示如何使用杂项驱动（Miscellaneous Driver）API。

| 示例 | 功能 |
| --- | --- |
| [FT800](P047_FT800图形控制器示例.md#ft800) | 使用FT800嵌入式视频引擎显示各种图形和文字 |
| [Grove液晶显示](P048_Grove液晶显示示例.md#grove-lcd) | 显示递增计数器并改变背光颜色 |
| [TMC6460电压模式（Voltage Mode）](P049_TMC6460电压模式示例.md#tmc6460) | 使用Trinamic TMC6460，以开环电压模式驱动无刷直流电机 |
