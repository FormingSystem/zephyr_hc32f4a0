# 第7章\_JESD216闪存参数示例

原文：[官方页面](https://docs.zephyrproject.org/latest/samples/drivers/jesd216/README.html)。读取日期：2026-10-14；保存的latest页面及HTML摘要见[来源记录](../SOURCES.md)。

<a id="overview"></a>

## 7.1\_概览（Overview）

本例通过JESD216闪存API从兼容串行器件中提取信息，也可作为工具，为该器件生成 `jedec,spi-nor` 设备树属性值。

<a id="building-and-running"></a>

## 7.2\_构建与运行（Building and Running）

目标必须有兼容字符串为jedec,spi-nor的设备树节点，并且驱动支持 [`CONFIG_FLASH_JESD216_API`](https://docs.zephyrproject.org/latest/kconfig.html#CONFIG_FLASH_JESD216_API)，应用才能构建。

```bash
west build -b sltb004a samples/drivers/jesd216
west flash
```

> 译注——操作位置：从已准备工具链与模块的Zephyr源码根执行，原例使用sltb004a目标。换板前先核对设备树节点、总线配置及驱动是否支持所需参数读取API；本例输出的信息属于实际连接的器件，不能把下列数据原样当作其他闪存的参数。
