# 第45章\_HD44780液晶控制器示例

原文：[官方页面](https://docs.zephyrproject.org/latest/samples/drivers/lcd_hd44780/README.html)。读取日期：2026-10-14；保存的latest页面及HTML摘要见[来源记录](../SOURCES.md)。

<a id="overview"></a>

## 45.1\_概览（Overview）

本例使用GPIO引脚，把Arduino Due（SAM3）连接到采用并行接口（Parallel Interface）的通用HD44780液晶显示（Liquid Crystal Display，LCD）控制器，并显示文本字符串。

<a id="building-and-running"></a>

## 45.2\_构建与运行（Building and Running）

可以按以下方式构建并运行：

> 译注——操作前提：在已配置Zephyr环境的终端、Zephyr源码根目录执行原命令。先按示例实现与板卡资料核对GPIO和LCD连接；构建成功后再烧录。若设备未就绪或显示不符合预期，先返回接线与控制器配置检查，不能仅凭烧录完成认定显示成功。

```bash
west build -b arduino_due samples/drivers/lcd_hd44780
west flash
```

<a id="sample-output"></a>

### 45.2.1\_示例输出（Sample Output）

```text
LCD Init
Page 1: message
Page 2: message
Page 3: message
```

<a id="display-output"></a>

### 45.2.2\_显示内容（Display output）

第一页：

```text
********************
Arduino Due
yalpsiD DCL 4x02
********************
```

第二页：

```text
-------------------
Zephyr Rocks!
My super RTOS
-------------------
```

第三页：

```text
--------------------
--------HOME--------
I am home!
```

> 译注——原字符串与显示方向：所读[main.c](https://raw.githubusercontent.com/zephyrproject-rtos/zephyr/main/samples/drivers/lcd_hd44780/src/main.c)使用20列、4行配置，并在第一页调用从右到左（Right-to-left）的写入控制，再写入yalpsiD DCL 4x02。这里保留原文和源码中的反向字符串，不把它作为拼写错误改写。后续页面演示滚动及回到起始位置，本批没有运行LCD显示实验。
