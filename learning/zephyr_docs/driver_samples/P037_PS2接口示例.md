# 第37章\_PS2接口示例

原文：[官方页面](https://docs.zephyrproject.org/latest/samples/drivers/ps2/README.html)。读取日期：2026-10-14；保存的latest页面及HTML摘要见[来源记录](../SOURCES.md)。

<a id="overview"></a>

## 37.1\_概览（Overview）

本例演示[PS/2接口API](../hardware/P137_PS2接口.md#ps2-api)的使用。它注册回调（Callback），在控制台输出PS/2事件，反映鼠标配置响应和鼠标交互。

<a id="building-and-running"></a>

## 37.2\_构建与运行（Building and Running）

示例可在支持PS/2的开发板上构建并执行，但需要正确的测试夹具（Fixture）设置。请连接一只PS/2鼠标来验证功能。

为了在Twister中正确执行本例，原文要求在板卡映射文件（Map File）中加入以下夹具设置：

```yaml
- fixture: fixture_connect_mouse
```

> 译注——测试声明与硬件映射的区别：以上是原文片段。当前[tests.yaml](https://raw.githubusercontent.com/zephyrproject-rtos/zephyr/main/samples/drivers/ps2/tests.yaml)在harness_config中用单数fixture声明fixture_connect_mouse；但[硬件映射模式](https://raw.githubusercontent.com/zephyrproject-rtos/zephyr/main/scripts/schemas/twister/hwmap-schema.yaml)要求每个板条目使用复数fixtures字符串列表。若编辑当前格式的硬件映射，应在对应板条目内加入下面的字段，保留该条目已有的id、platform、串口等信息，不把它作为完整映射文件替换原内容：

```yaml
fixtures:
  - fixture_connect_mouse
```

> 译注——设备条件：所读[main.c](https://raw.githubusercontent.com/zephyrproject-rtos/zephyr/main/samples/drivers/ps2/src/main.c)使用ps2-port0设备树别名，其C宏写作DT_ALIAS(ps2_port0)。本页没有提供通用构建命令；应结合所用板的PS/2引脚、驱动和测试配置准备环境。本批没有运行Twister、配置真实鼠标或执行板卡操作。

<a id="sample-output"></a>

### 37.2.1\_示例输出（Sample output）

```text
PS/2 test with mouse
Note: You are expected to see several interrupts
as you configure/move the mouse!
```

这段提示表示：在配置或移动鼠标时，应当观察到若干中断（Interrupt）触发。具体接收数据还会通过回调和控制台日志显示。
