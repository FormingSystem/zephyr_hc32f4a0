# 第38章\_PSI5接口示例

原文：[官方页面](https://docs.zephyrproject.org/latest/samples/drivers/psi5/README.html)。读取日期：2026-10-14；保存的latest页面及HTML摘要见[来源记录](../SOURCES.md)。

<a id="overview"></a>

## 38.1\_概览（Overview）

本例演示[外设传感器接口（Peripheral Sensor Interface，PSI5）API](../hardware/P138_外围传感器接口.md#psi5-api)，包含数据接收（Receive）和发送（Transmit）。

<a id="requirements"></a>

## 38.2\_要求（Requirements）

需要连接一个PSI5传感器，并通过`psi5-0`设备树（Devicetree）别名提供访问。

> 译注——设备树名称：在C代码中，该别名对应DT_ALIAS(psi5_0)，连字符在宏标识中转换为下划线。具体总线控制器、传感器连接与通道配置仍须由所用板的设备树和硬件提供。

<a id="building-flashing-and-running"></a>

## 38.3\_构建、烧录与运行（Building, Flashing and Running）

> 译注——命令前提：从已配置Zephyr环境的终端、Zephyr源码根目录执行以下原命令。先核对s32z2xxdc2/s32z270/rtu0目标的传感器连接和配置，构建成功后再烧录；编译或设备配置失败时返回相应板级条件检查。

```bash
# From the root of the zephyr repository
west build -b s32z2xxdc2/s32z270/rtu0 samples/drivers/psi5
west flash
```

原示例输出：

```text
Transmitted data on channel 1

Received a frame on channel 1
```

> 译注——通道与当前输出：所读[main.c](https://raw.githubusercontent.com/zephyrproject-rtos/zephyr/main/samples/drivers/psi5/src/main.c)在通道1注册串行帧和数据帧接收回调，启动同步并请求发送0x1234。当前回调还能打印数据、时间戳及部分帧字段；上面的短日志按原页保留，不代表已在本仓库完成收发验证。
