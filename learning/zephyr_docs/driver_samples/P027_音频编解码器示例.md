# 第27章\_音频编解码器示例

原文：[官方页面](https://docs.zephyrproject.org/latest/samples/drivers/audio/codec/README.html)。读取日期：2026-10-14；保存的latest页面及HTML摘要见[来源记录](../SOURCES.md)。

<a id="overview"></a>

## 27.1\_概览（Overview）

这是一个简单示例，演示扬声器播放（Speaker Playback），以及从麦克风到扬声器的回环（Microphone-to-speaker Loopback）。

它以16位采样宽度和16 kSPS采样率播放1 kHz正弦波音调。这里kSPS表示每秒千次采样（kilo Samples Per Second）。

<a id="building-and-running"></a>

## 27.2\_构建与运行（Building and Running）

可以按以下方式为开发板构建并运行应用：

> 译注——执行环境与设备条件：原命令从已配置Zephyr开发环境的终端、Zephyr源码根目录执行。所读[main.c](https://raw.githubusercontent.com/zephyrproject-rtos/zephyr/main/samples/drivers/audio/codec/src/main.c)使用codec0别名，要求该设备支持相应音频配置和回调；别名不存在时会打印跳过测试的消息。因此能够编译或正常退出都不等于播放成功。run目标是否可用还取决于板卡运行支持，执行失败时应回到该版本的板卡文档核对启动方式。

```bash
west build -b sf32lb52_devkit_lcd samples/drivers/audio/codec
west build -t run
```

若要为其他开发板构建，把上面的“sf32lb52_devkit_lcd”改成对应板名。

> 译注——更换目标：原文这句话省略了硬件适配前提；读者所选板还需要实际的编解码器、麦克风／扬声器连接，以及设备树和驱动支持，不能只替换板名便假定功能存在。

<a id="sample-output"></a>

### 27.2.1\_示例输出（Sample Output）

```text
Audio codec sample
codec device is ready
codec playback example
playback started
codec transfer stopped
codec loopback example
loopback started
loopback stopped
Exiting
```

> 译注——播放顺序：所读实现先进行约15秒单向播放，再进行约15秒收发回环；使用单声道、16位、16 kHz的脉冲编码调制（Pulse Code Modulation，PCM）配置。原日志按示例阶段依次保留，本批没有构建、接线或验证实际音频输出。
