# 第32章\_指纹传感器示例

原文：[官方页面](https://docs.zephyrproject.org/latest/samples/drivers/biometrics/fingerprint/README.html)。读取日期：2026-10-14；保存的latest页面及HTML摘要见[来源记录](../SOURCES.md)。

<a id="overview"></a>

## 32.1\_概览（Overview）

本例演示指纹传感器（Fingerprint Sensor）的生物识别（Biometrics）驱动API，包括录入（Enrollment）、验证（Verification）、识别（Identification）和模板管理（Template Management）。

<a id="requirements"></a>

## 32.2\_要求（Requirements）

- 指纹传感器模块，例如ZFM-20、ZFM-60、ZFM-70、R30x、JM-101、DY-50、FPM10A或兼容模块。
- 与传感器相适配的连接方式，依具体器件采用UART、I2C或SPI。

<a id="building-and-running"></a>

## 32.3\_构建与运行（Building and Running）

> 译注——前提与位置：从已配置Zephyr开发环境的终端、Zephyr源码根目录执行，将原占位符`<your_board>`换成实际目标。先完成下方设备树配置和所用器件的驱动选择，再构建；构建成功后才烧录，设备树或设备未就绪错误应返回对应配置检查。示例会录入模板并删除模板ID 1，因此是会改变传感器模板库的演示，不是仅查询传感器状态。

```bash
west build -b <your_board> samples/drivers/biometrics/fingerprint
west flash
```

<a id="features-demonstrated"></a>

## 32.5\_演示功能（Features Demonstrated）

- 查询传感器能力，包括最大模板数量和样本要求。
- 录入两个手指的指纹，每个指纹采用两次采样过程。
- 列出已存储的模板。
- 针对指定ID验证指纹，即一对一匹配（1:1 Match）。
- 在已录入指纹中识别任意手指，即一对多搜索（1:N Search）。
- 删除一个模板。

> 译注——实现与能力：所读[main.c](https://raw.githubusercontent.com/zephyrproject-rtos/zephyr/main/samples/drivers/biometrics/fingerprint/src/main.c)实际根据enrollment_samples_required控制采集次数，而不是对所有设备固定为两次。它依次请求录入ID 1、ID 2，列出模板，验证ID 1，执行识别，删除ID 1后再列出模板；这说明示例设计流程，不代表本批已经在设备上完成这些操作。

<a id="device-tree-configuration"></a>

## 32.6\_设备树配置（Device Tree Configuration）

把指纹传感器加入设备树，并定义`fingerprint`别名。下面是通过UART连接的ZFM-x0系列示例：

> 译注——配置文件用途：这是设备树源片段，不是终端命令。按所选板的覆盖规则把它放入该应用的覆盖文件，例如自行创建或编辑应用目录中的app.overlay；已有文件时合并相关节点。uart1是否存在、是否可用以及引脚复用设置均取决于实际板卡，需要先核对，不能把示例节点名当作所有板的默认连接。

```dts
/ {
    aliases {
        fingerprint = &fingerprint_sensor;
    };
};

&uart1 {
    status = "okay";
    current-speed = <57600>;

    fingerprint_sensor: fingerprint0 {
        compatible = "zhiantec,zfm-x0";
        comm-addr = <0xffffffff>;
    };
};
```

其他传感器应使用相应的compatible字符串和总线配置。
