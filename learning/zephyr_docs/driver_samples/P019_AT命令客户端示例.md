# 第19章\_AT命令客户端示例

原文：[官方页面](https://docs.zephyrproject.org/latest/samples/drivers/modem/at_client/README.html)。读取日期：2026-10-14；保存的latest页面及HTML摘要见[来源记录](../SOURCES.md)。

<a id="overview"></a>

## 19.1\_概览（Overview）

本例演示建立AT命令客户端（AT Command Client），桥接主机控制台（Host Console）与蜂窝调制解调器（Cellular Modem）之间的通信。它使用Zephyr调制解调器子系统，通过`uart_pipe`与控制台通信，通过`modem_pipe`与调制解调器通信。

本例提供透明双向桥接（Transparent Bidirectional Bridge）：

- 把控制台输入的命令转发给调制解调器。
- 在控制台显示调制解调器返回的响应。
- 支持AT命令交互，以及通过XMODEM协议更新固件（Firmware）。

<a id="requirements"></a>

## 19.2\_要求（Requirements）

- 一块带有两个通用异步收发器（Universal Asynchronous Receiver/Transmitter，UART）外设的开发板。
- 一个UART连接主机控制台，通常通过USB CDC-ACM或ST-LINK连接。
- 另一个UART连接蜂窝调制解调器。
- 在设备树（Devicetree）中配置两个UART。

<a id="wiring"></a>

## 19.3\_接线（Wiring）

需要在设备树中定义两个UART连接：

- `zephyr,console`：与主机通信的控制台UART。
- `zephyr,modem-uart`：与蜂窝调制解调器通信的UART。

> 译注——选择设备：这两个名称是设备树chosen节点中的属性，用于选出实际UART实例；名称本身不是物理引脚编号。所用板应提供对应UART设备及引脚配置，按板卡与模块资料核对连接。

<a id="building-and-running"></a>

## 19.4\_构建与运行（Building and Running）

按下列方式构建并烧录本例：

> 译注——命令前提：在已配置Zephyr开发环境的终端中，从Zephyr源码根目录执行。先将`<your_board>`替换为具备上述设备树和硬件配置的实际板目标；这是原文占位符，不能直接照抄作为目标。第一条构建成功后才执行烧录，失败时先返回核对板目标、UART配置及工具链。

```bash
west build -b <your_board> samples/drivers/modem/at_client
west flash
```

烧录后，用串口终端打开控制台UART。输入的AT命令会转发给调制解调器，返回的响应会显示在终端中。

<a id="usage-example"></a>

### 19.4.2\_用法示例（Usage Example）

程序运行后，可以直接在终端发送AT命令：

```text
AT+CGSN                  # Query modem IMEI
AT+CSQ                   # Check signal quality
AT+COPS?                 # Query operator
AT+CGDCONT=1,"IP","apn"  # Configure APN
```

> 译注——命令含义与输入：四行分别查询国际移动设备识别码（International Mobile Equipment Identity，IMEI）、查询信号质量、查询运营商，以及配置接入点名称（Access Point Name，APN）。原示例`#`之后的英文是解释文字，实际发送时只输入前面的AT命令；所读[main.c](https://raw.githubusercontent.com/zephyrproject-rtos/zephyr/main/samples/drivers/modem/at_client/src/main.c)直接转发字节，不会剥离这些注释。最后一行中的apn应替换为所用网络的实际APN。

<a id="firmware-update"></a>

### 19.4.3\_固件更新（Firmware Update）

本例支持通过XMODEM协议更新调制解调器固件。原文要求使用配套Python脚本`hl78xx_firmware_update.py`，通过AT客户端桥接完成更新，并指出详情见`scripts/hl78xx_firmware_update.py`。

> 译注——原文文件名与当前源码不同：核对时实际存在的是示例目录下的[script/hl78xx_firmware_update_xmodem_1k.py](https://raw.githubusercontent.com/zephyrproject-rtos/zephyr/main/samples/drivers/modem/at_client/script/hl78xx_firmware_update_xmodem_1k.py)，配套说明为[script/README_hl78xx_fw_update.md](https://raw.githubusercontent.com/zephyrproject-rtos/zephyr/main/samples/drivers/modem/at_client/script/README_hl78xx_fw_update.md)。原文的scripts复数目录及短脚本名与当前树不一致；配套说明中还出现了另一旧名称hl78xx_firmware_update_direct.py，不能据此假定该文件存在。请按所使用版本的实际文件核对入口，本文保留原说明并明确标出差异，没有执行更新脚本。
