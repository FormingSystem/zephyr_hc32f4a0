# 第41章\_脉冲IO字节传输示例

原文：[官方页面](https://docs.zephyrproject.org/latest/samples/drivers/pulse_io/byte_transfer/README.html)。读取日期：2026-10-14；保存的latest页面及HTML摘要见[来源记录](../SOURCES.md)。

<a id="overview"></a>

## 41.1\_概览（Overview）

本例用[`pulse_io_encode_bytes()`](https://docs.zephyrproject.org/latest/doxygen/html/group__pulse__io__interface.html#gaca42826a8404d4e5e1eacefc5f17debf)把字节编码为具有指定时长的脉冲（Timed Pulse），在一个pulse_io通道上发送，并通过同一控制器的另一个通道接收。收到的符号（Symbol）用[`pulse_io_decode_bytes()`](https://docs.zephyrproject.org/latest/doxygen/html/group__pulse__io__interface.html#ga05add5c7dc934ad84ddafbfe4c08d2a6)解码，再与发送值比较。

开发板覆盖文件（Overlay）把两个通道路由到同一个焊盘（Pad），并启用输入路径，因此信号可以在内部回环（Internal Loopback），无需外部接线。换用其他开发板时，需要覆盖文件选择相应通道和引脚：可以共享同一个焊盘，也可以把发送引脚接到接收引脚。

> 译注——原板配置：所读[esp32s3_devkitc_procpu.overlay](https://raw.githubusercontent.com/zephyrproject-rtos/zephyr/main/samples/drivers/pulse_io/byte_transfer/boards/esp32s3_devkitc_procpu.overlay)在GPIO8上配置RMT_OUT3和RMT_IN3，接收引脚组启用input-enable，并提供pulse-io0别名。无需外接线是这份配置的条件，不是对任意板或任意引脚的保证。

<a id="building-and-running"></a>

## 41.2\_构建与运行（Building and Running）

> 译注——执行位置与前提：在已配置Zephyr环境的终端、Zephyr源码根目录执行以下原命令，先确认所用板目标和覆盖文件的通道配置。构建成功后再烧录；设备未就绪或通道配置失败时，先核对别名、控制器状态和引脚配置。

```bash
west build -b esp32s3_devkitc/esp32s3/procpu samples/drivers/pulse_io/byte_transfer
west flash
```

<a id="sample-output"></a>

### 41.2.1\_示例输出（Sample Output）

```text
pulse_io byte transfer: TX channel 3, RX channel 7
sent 0x00 received 0x00
sent 0x01 received 0x01
sent 0x02 received 0x02
sent 0x03 received 0x03
sent 0x04 received 0x04
byte transfer done
```

> 译注——编码与通道编号：所读[main.c](https://raw.githubusercontent.com/zephyrproject-rtos/zephyr/main/samples/drivers/pulse_io/byte_transfer/src/main.c)使用1 MHz时间分辨率，0编码为25个高电平计时单位加75个低电平单位，1编码为75个高电平单位加25个低电平单位，并采用最高位优先（Most Significant Bit First，MSB First）。程序根据能力掩码选择可用发送和接收通道，连续验证0x00—0x04；原日志中的通道3、7是该运行配置的结果，不是所有控制器的固定编号。本批没有执行回环收发。
