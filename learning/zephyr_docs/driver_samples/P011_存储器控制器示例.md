# 第11章\_存储器控制器示例

原文：[官方页面](https://docs.zephyrproject.org/latest/samples/drivers/memc/README.html)。读取日期：2026-10-14；保存的latest页面及HTML摘要见[来源记录](../SOURCES.md)。

<a id="overview"></a>

## 11.1\_概览（Overview）

本例演示通过存储器控制器（Memory Controller，MEMC）驱动读写外部存储器。既适用于内存映射（Memory-mapped）驱动，也适用于实现MEMC子系统API的驱动，接口头文件为 `<zephyr/drivers/memc.h>`。

存储区域通过设备树别名 `sram-ext` 或 `psram0` 引用，并且不得与应用正在使用的内存重叠。

> 译注——两种访问方式：所读[main.c](https://raw.githubusercontent.com/zephyrproject-rtos/zephyr/main/samples/drivers/memc/src/main.c)通过DEVICE_API_IS判断MEMC API设备，分别调用memc_read／memc_write；其他分支对映射地址使用memcpy。两种方式都实际写入测试区域，“可映射”不等于该区域可以覆盖应用数据。

<a id="building-and-running"></a>

## 11.2\_构建与运行（Building and Running）

在RT595 EVK上构建并运行：

```bash
west build -b mimxrt595_evk/mimxrt595s/cm33 samples/drivers/memc
west build -t run
```

为其他板构建时，将命令中的mimxrt595_evk/mimxrt595s/cm33改为对应板名。

> 译注——换板前提：从Zephyr源码根使用已配置的工具环境执行。替换板名还要求设备树别名、驱动、外部存储容量和测试地址正确，且测试区不与应用重叠；原页的run目标也应按所选板的运行支持核对。本批没有构建或写入外部存储器。
