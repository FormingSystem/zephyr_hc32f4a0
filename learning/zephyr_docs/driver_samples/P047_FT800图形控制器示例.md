# 第47章\_FT800图形控制器示例

原文：[官方页面](https://docs.zephyrproject.org/latest/samples/drivers/misc/ft800/README.html)。读取日期：2026-10-14；保存的latest页面及HTML摘要见[来源记录](../SOURCES.md)。

<a id="overview"></a>

## 47.1\_概览（Overview）

本例使用FT800嵌入式视频引擎（Embedded Video Engine，EVE），显示问候消息和递增计数器。

<a id="requirements"></a>

## 47.2\_要求（Requirements）

需要以下硬件：

- 一块支持串行外设接口（Serial Peripheral Interface，SPI）的开发板。
- 采用[FT800 EVE](https://www.ftdichip.com/old2020/Products/ICs/FT800.html)的显示器，例如[VM800C开发板](https://www.ftdichip.com/old2020/Products/Modules/VM800C.html)。

<a id="wiring"></a>

> 译注——旧厂商入口：2026-10-14检查时，两条FTDI旧地址的直接请求均返回403，FT800地址经网页工具打开后指向厂商首页。原引用保留供追溯；可另从Bridgetek的[FT800产品入口](https://brtchip.com/product/ft800/)及[VM800C43A-N具体型号入口](https://brtchip.com/product/vm800c43a-n/)查找资料。后者是系列中的一个型号，实际显示组件和接线仍须按所用型号核对；本批不扩展翻译厂商整套资料。

## 47.3\_接线（Wiring）

把FT800 EVE的SPI接口连接到支持Arduino扩展板（Shield）的开发板。

<a id="building-and-running"></a>

## 47.4\_构建与运行（Building and Running）

本例应可用于启用SPI并具备Arduino扩展板接口的开发板。例如，可以按以下方式在nRF52840-DK上运行：

> 译注——前提与位置：以下原命令从已配置Zephyr环境的终端、Zephyr源码根目录执行。所读[main.c](https://raw.githubusercontent.com/zephyrproject-rtos/zephyr/main/samples/drivers/misc/ft800/src/main.c)使用DEVICE_DT_GET_ONE(ftdi_ft800)选择设备，因而除SPI可用外，还须在设备树中具备对应FT800设备描述和驱动支持。构建失败时先检查这些配置，成功后再烧录。

```bash
west build -b nrf52840dk/nrf52840 samples/drivers/misc/ft800
west flash
```

若为VM800C板配置构建，需要按下列方式指定扩展板：

```bash
west build -b nrf52840dk/nrf52840 --shield ftdi_vm800c samples/drivers/misc/ft800
west flash
```

> 译注——两种命令的关系：第二组命令显式选择ftdi_vm800c扩展板，补充相应硬件描述；它不是对任何裸板都可以省略的装饰参数。第一组命令能否成立取决于所选板或已有覆盖配置是否已经提供FT800节点。本批未构建、烧录或验证图形显示。
