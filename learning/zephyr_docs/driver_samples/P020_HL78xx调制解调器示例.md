# 第20章\_HL78xx调制解调器示例

原文：[官方页面](https://docs.zephyrproject.org/latest/samples/drivers/modem/hello_hl78xx/README.html)。读取日期：2026-10-14；保存的latest页面及HTML摘要见[来源记录](../SOURCES.md)。

<a id="overview"></a>

## 20.1\_概览（Overview）

这是一个仅适用于Sierra Wireless HL78XX系列调制解调器（Modem）的简单示例。

<a id="notes"></a>

## 20.2\_说明（Notes）

本例通过设备树别名（Devicetree Alias）`modem`识别要使用的调制解调器实例。

<a id="building-and-running"></a>

## 20.3\_构建与运行（Building and Running）

原文说明：可以按如下方式在QEMU上构建并执行此应用。

```bash
west build -b None samples/drivers/modem/hello_hl78xx
west flash
```

原文随后说明：若要为其他开发板构建，把上面的“qemu_x86”改成该开发板的名称。

> 译注——原构建示例不完整：网页实际输出的是`-b None`，并未给出qemu_x86目标。所读[README.rst](https://raw.githubusercontent.com/zephyrproject-rtos/zephyr/main/samples/drivers/modem/hello_hl78xx/README.rst)的命令指令缺少board参数，因此不能把这段生成命令当作可直接执行的配置，也不能据此认定QEMU具有HL78xx设备。这里完整保留原代码与文字，以便识别上游问题。

> 译注——可跟踪的目标依据：当前[tests.yaml](https://raw.githubusercontent.com/zephyrproject-rtos/zephyr/main/samples/drivers/modem/hello_hl78xx/tests.yaml)要求存在modem别名，并列出nucleo_u575zi_q开发板与swir_hl78xx_ev_kit扩展板（Shield）的组合。应从所用版本的这份配置和相应板卡文档确认硬件、设备树及构建目标；本页没有进行该组合的构建、烧录或网络验证。

启动后，代码执行以下操作：

1. 检查调制解调器就绪状态并上电。
2. 通过Zephyr连接管理器（Connection Manager）设置网络接口。
3. 查询调制解调器的制造商、固件版本、接入点名称（Access Point Name，APN）、国际移动设备识别码（International Mobile Equipment Identity，IMEI）、信号强度等信息。
4. 检查网络注册状态和信号强度。
5. 设置并验证新的APN。
6. 发送AT命令，验证通信。

> 译注——阅读日志：RAT为无线接入技术（Radio Access Technology），RSRP为参考信号接收功率（Reference Signal Received Power）。原日志先报告IP Up，后来又打印Not Registered、IP down和空的新APN；这些内容按原样保留，不据最初的一条连接消息宣称整个流程持续联网成功。APN、IMEI、地址和固件版本均属于官方示例输出，不是读者必须采用的配置，也不是本仓库实测结果。当前main分支实现可能继续变化，应将网页示例与具体源码版本分开对照。
