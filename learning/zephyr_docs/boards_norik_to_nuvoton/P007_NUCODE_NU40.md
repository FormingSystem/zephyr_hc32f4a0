## 概述（Overview）

NUCODE NU40是基于Nordic Semiconductor nRF52840 ARM Cortex-M4F SoC的开发套件，板载UF2引导加载程序，源自Adafruit nRF52分支，可通过USB拖放文件烧录固件；还支持BLE 5.4、IEEE 802.15.4（Thread／Zigbee）及USB 2.0全速（Full Speed）。

<a id="id2"></a>

开发板更多信息见[NUCODE NU40网站](https://nuworks.io) [注1](#id1)。

<a id="hardware"></a>

## 硬件（Hardware）

nucode_nu40/nrf52840目标有两个外部振荡器，低速时钟32.768 kHz，主时钟32 MHz。

<a id="leds"></a>

#### 发光二极管（LEDs）


- LED0 = P0.13，高电平有效（Active High）
- LED1 = P0.14，高电平有效（Active High）
- LED2 = P0.15，高电平有效（Active High）
- LED3 = P0.16，高电平有效（Active High）

<a id="push-buttons"></a>

#### 按键（Push Buttons）


- 按键0（BUTTON0）= SW0 = P0.11，低电平有效、上拉
- 按键1（BUTTON1）= SW1 = P0.12，低电平有效、上拉
- 按键2（BUTTON2）= SW2 = P0.24，低电平有效、上拉
- 按键3（BUTTON3）= SW3 = P0.25，低电平有效、上拉

<a id="uart"></a>

#### 通用异步收发器（UART）


- UART0：TX = P0.6，RX = P0.8，RTS = P0.5，CTS = P0.7
- UART1：TX = P1.2，RX = P1.1

<a id="i2c"></a>

#### 集成电路间总线（I2C）


- I2C0，Arduino接口：SDA = P0.26，SCL = P0.27
- I2C1：SDA = P0.30，SCL = P0.31

<a id="spi"></a>

#### 串行外设接口（SPI）


- SPI1：SCK = P0.31，MOSI = P0.30，MISO = P1.8
- SPI3，Arduino接口：SCK = P1.15，MOSI = P1.13，MISO = P1.14

<a id="flashing"></a>

### 烧录（Flashing）

开发板支持以下编程方式：


1. 使用内置UF2引导加载程序（Bootloader）
2. 使用外部调试探针（External Debug Probe）（[调试探针（Debug Probe）](https://docs.zephyrproject.org/latest/develop/flash_debug/probes.html#debug-probes)）

<a id="option-1-using-the-built-in-uf2-bootloader"></a>

#### 选项1：使用内置UF2引导加载程序

开发板出厂时已写入UF2引导加载程序，由chcbaram维护的Adafruit nRF52分支提供。进入该模式时，开发板枚举为USB大容量存储设备（Mass-storage Device）。


1. 连续按两次RESET，或按住BUTTON0连接USB，即可进入引导加载程序；挂载磁盘名为BARAM-NU40。
2. 构建示例应用：

  ```text
  # From the root of the zephyr repository
  west build -b nucode_nu40/nrf52840 samples/hello_world
  ```
3. 将生成的zephyr.uf2复制到BARAM-NU40磁盘：

  ```text
  cp build/zephyr/zephyr.uf2 /run/media/$USER/BARAM-NU40/
  ```

  开发板自动复位并运行新固件。

<a id="option-2-using-an-external-debug-probe"></a>

#### 方案2：使用外部调试探针（External Debug Probe）

也可通过连接SWD焊盘的J-Link或其他兼容调试探针烧录及调试。

```text
west flash
```
