## 概述（Overview）

Octopus SoM是基于nRF9160 SiP的系统模块（System on Module），提供NB-IoT、LTE-M连接、GPS及加速度计，支持板载eSIM和外部Nano SIM连接器，旨在为物联网应用提供灵活硬件平台。

nRF9160 SiP包含ARM Cortex-M33应用处理器及以下设备：


- 模数转换器（ADC）
- 时钟（CLOCK）
- 闪存（FLASH）
- 通用输入输出（GPIO）
- 集成电路间总线（I2C）
- 存储器保护单元（MPU）
- 嵌套向量中断控制器（NVIC）
- 脉宽调制（PWM）
- 实时时钟（RTC）
- Segger实时传输（RTT，RTT控制台 / RTT Console）
- 串行外设接口（SPI）
- 带EasyDMA的通用异步收发器（UARTE）
- 看门狗定时器（WDT）
- 实现定义的归属单元（IDAU）

<a id="connections-and-ios"></a>

### 连接与输入输出（Connections and IOs）

<a id="accelerometer"></a>

#### 加速度计（Accelerometer）


- 主入从出（MISO）= P0.05
- 主出从入（MOSI）= P0.09
- 串行时钟（SCK）= P0.10
- 片选（CS）= P0.05
- 中断1（INT1）= P0.12

<a id="led"></a>

#### 发光二极管（LED）


- LED1（绿色）= P0.07

<a id="sim-select-switch"></a>

#### SIM选择开关（Select Switch）


- 选择（Select）= P0.25

<a id="flashing"></a>

### 烧录（Flashing）

按[Nordic nRF5x Segger J-Link](../debugging/P005_Nordic_Segger_JLink.md#nordic-segger)页面说明安装及配置所需软件。

用[Blinky](../getting_started/P004_LED闪烁示例.md#blinky)示例测试Zephyr能否在开发板上正常运行。

```text
# From the root of the zephyr repository
west build -b octopus_som/nrf9160 samples/basic/blinky
west flash
```
