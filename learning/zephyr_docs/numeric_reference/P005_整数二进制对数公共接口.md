## 5.2\_详细说明（Detailed Documentation）

<a id="ga2696c6303d4c53b65a3a7f7ff771d5eb"></a>

### `ilog2`

```c
#define ilog2 ( n)
```

```c
#include <zephyr/math/ilog2.h>
```

展开值（Value）：

```c
(                                               \
        __builtin_constant_p(n) ?               \
        ilog2_compile_time_const_u32(n) :       \
        find_msb_set(n) - 1                     \
)
```

计算整数形式的 log2。

计算 log2 的向下取整值，即整数对数。

**参数（Parameters）**

| 名称／方向 | 说明 |
| --- | --- |
| `n` | 输入值。 |

**警告（Warning）**：警告：输入值为 0 时返回 0，但 log2 在 0 处没有有效定义。

**返回（Returns）**：返回值：n 的整数 log2。

> 译注——源码核对：输入范围：当前实现面向非零32位无符号整数。常量分支从第31位向下判断，运行时分支调用参数类型为uint32_t的find_msb_set；不能把它当成任意64位数或负数的通用对数函数。对正数，它返回最高置位位的零基索引，即floor(log2(n))。 零输入差异：原文称输入0返回0，常量展开分支确实如此；但运行时分支计算find_msb_set(n)-1，函数返回unsigned int。运行时零值使其从0无符号减1，结果为UINT_MAX，而不是统一返回0或有符号-1。是否走常量分支由__builtin_constant_p及编译器的常量识别决定，不能只按“写成变量”判断。调用前应排除0。


对编译期常量（Compile-time Constant）计算 log2 的向下取整值。

对 32 位无符号整数计算 log2 的向下取整值，即整数对数。

**参数（Parameters）**

| 名称／方向 | 说明 |
| --- | --- |
| `n` | 输入值。 |

**说明（Note）**：注意：仅应在数值于预处理阶段已知时，将此宏用于编译期常量。由于其展开形成很大的嵌套 if-else 分支树，不要将它用于运行时代码。

**警告（Warning）**：警告：输入值为 0 时返回 0，但 log2 在 0 处没有有效定义。

**返回（Returns）**：返回值：整数 log2，原文此处未显示输入对象。

> 译注——源码核对：常量识别阶段：原文用“预处理阶段已知”描述使用条件；实际__builtin_constant_p由编译器识别表达式是否可视为常量，并不等同于预处理器执行完整的C常量求值。ilog2_compile_time_const_u32直接展开很长的条件链，会多次出现n，不应传入带副作用的运行时表达式。 返回说明缺字：官方源码把常量版本的返回说明写为“Integer log2 of @n”；Doxygen把@n解释为换行命令，因此网页只显示“Integer log2 of”而没有输入对象。译文保留缺字事实；根据函数声明和宏体，所指输入是n。
