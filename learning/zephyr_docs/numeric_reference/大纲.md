# 数值比较与整数对数参考大纲

本册涵盖小写最小／最大值与限幅宏（Min/Max/Clamp）、整数二进制对数（Integer Log2），以及最高／最低置位扫描（Most/Least Significant Set Bit）。这些接口在求值次数、常量表达式适用范围、输入位宽和返回编号上各有约定，使用时需区分。

保留完整宏展开、接口说明、三份源码浏览页的可见代码及法律注释。源码译注解释C++条件、临时变量和类型转换、ilog2零输入的分支差异、一基位编号，以及原注释与实现的差异。所有本地定位使用相对路径，完整范围见[全站进度](../PROGRESS.md)。
