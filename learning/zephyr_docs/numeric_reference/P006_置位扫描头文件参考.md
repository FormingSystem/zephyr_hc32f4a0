## 6.2\_详细说明（Detailed Documentation）

<a id="a860b01217c1d5eb5f416272c3b719113"></a>

### `find_lsb_set()`

```c
ALWAYS_INLINE unsigned int find_lsb_set ( uint32_t op)
```

声明属性：`static`。

查找 32 位字中最低的已置位位（Least Significant Set Bit）。

从传入参数的最低有效位开始，查找第一个已置位位并返回其索引。位编号从最低有效位起按 1 开始计数；返回 0 表示传入值为 0。

**返回（Returns）**：返回值：最低已置位位的编号；op 为 0 时返回 0。

> 译注——源码核对：位编号：find_msb_set和find_lsb_set返回从最低位开始的一基编号（One-based Index），范围1至32；返回0单独表示输入为0。它们不返回掩码，也不是零基索引；非零结果减1后才是相应位的零基索引。 原注释名称：后备分支注释写“利用find_lsb_set”，但实际代码在隔离最低置位位后调用的是find_msb_set；它不是递归调用自身。原文与实现差异在此标明，代码保持原样。

<a id="a088db7d02e8f1fc559cbe1ec048494e8"></a>

### `find_msb_set()`

```c
ALWAYS_INLINE unsigned int find_msb_set ( uint32_t op)
```

声明属性：`static`。

查找 32 位字中最高的已置位位（Most Significant Set Bit）。

从传入参数的最高有效位开始，查找第一个已置位位并返回其索引。位编号仍从最低有效位起按 1 开始计数；返回 0 表示传入值为 0。

**返回（Returns）**：返回值：最高已置位位的编号；op 为 0 时返回 0。

> 译注——源码核对：位编号：find_msb_set和find_lsb_set返回从最低位开始的一基编号（One-based Index），范围1至32；返回0单独表示输入为0。它们不返回掩码，也不是零基索引；非零结果减1后才是相应位的零基索引。 零值与内建函数：find_msb_set先检查0，再调用__builtin_clz，因此不会将0交给该内建函数。find_lsb_set可使用__builtin_ffs，或在无内建支持时保留最低置位位后调用find_msb_set；两条路径都约定零输入返回0。
