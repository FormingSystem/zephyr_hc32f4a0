## 1.2\_详细说明（Detailed Documentation）

<a id="a04e8e3eede9e473bd18f298fddd67b46"></a>

### `clamp`

```c
#define clamp ( val, low, high )
```

展开值（Value）：

```c
        ({                                               \
        /* random suffix to avoid naming conflict */                   \
        __typeof__(val) _value_val_ = (val);                           \
        __typeof__(low) _value_low_ = (low);                           \
        __typeof__(high) _value_high_ = (high);                        \
        (_value_val_ < _value_low_)  ? _value_low_ :                   \
        (_value_val_ > _value_high_) ? _value_high_ :                  \
                                       _value_val_;                    \
})
```

返回限制在给定范围内的值，即限幅（Clamp）结果。

宏保证各表达式仅求值一次。有关使用限制，参见 max。

> 译注——源码核对：比较类型：各临时值保留各自操作数类型，比较和条件表达式仍遵循C/C++的类型转换规则。混合有符号／无符号值可能改变比较结果；“只求值一次”不等于类型安全或自动校验范围。clamp应满足low<=high，宏不会报错或交换反向边界。 变量名称：min/max系列用__COUNTER__生成临时名称；clamp的原注释写“random suffix”，但实际使用固定名称_value_val_、_value_low_、_value_high_，不是每次随机生成。不要以相同内部变量名作为实参，避免展开后的遮蔽；原注释和代码均保留。

<a id="affe776513b24d84b39af8ab0930fef7f"></a>

### `max`

```c
#define max ( a, b )
```

展开值（Value）：

```c
_minmax_cnt(Z_INTERNAL_MAX, a, b, __COUNTER__)
```

返回两个给定表达式中较大的值。

宏保证各表达式仅求值一次。

**说明（Note）**：注意：与常规宏相比，此宏的适用范围有限，不能用于生成整数常量，例如 __aligned(max(4,5))；也不能用于需要常量的静态变量定义，例如 static uint8_t array[max(...)]; 这样的数组。

> 译注——源码核对：一次求值的实现：小写宏使用GNU语句表达式（Statement Expression）和__typeof__临时变量先保存操作数，再比较临时值。它们不适合文件作用域的常量初始化、静态数组长度或对齐属性等要求整数常量表达式的位置，不能把“传入常量”当作“展开结果也是整数常量表达式”。 C++边界：当前头文件通过#ifndef __cplusplus排除min、max和clamp的定义，max3与min3仍在该条件之外。extern "C"块不会让这些宏成为标准C++模板，也不意味着所有GNU扩展可在任意编译器下使用。
