# 第3章\_消息队列属性结构

原文：[官方页面](https://docs.zephyrproject.org/latest/doxygen/html/structk__msgq__attrs.html)。读取日期：2026-10-15；来源摘要见[来源记录](../SOURCES.md)。

> 译注——阅读位置：本册覆盖消息队列（Message Queue）、消息队列属性及整数数据栈（Stack）的公共接口。消息队列按固定字节数复制消息，整数数据栈保存stack_data_t值；均须区别于以链接节点传递对象的通用队列。原始声明、宏展开、参数和返回值完整保留，源码说明另作译注。

## 3.3\_源码定位与版本边界

> 译注——阅读与源码边界：msg_size以字节计，max_msgs与used_msgs以消息条数计。当前k_msgq_get_attrs把三个字段复制到这个结果结构；修改结果结构不会改变原队列容量或使用量。

仓库相对定位：[kernel.h](../../../include/zephyr/kernel.h)、[kernel/msg_q.c](../../../kernel/msg_q.c)与[kernel/stack.c](../../../kernel/stack.c)。本次依据为[官方内核头文件](https://github.com/zephyrproject-rtos/zephyr/blob/main/include/zephyr/kernel.h)、[官方消息队列实现](https://github.com/zephyrproject-rtos/zephyr/blob/main/kernel/msg_q.c)及[官方栈实现](https://github.com/zephyrproject-rtos/zephyr/blob/main/kernel/stack.c)，摘要见[来源记录](../SOURCES.md)。
