## 1.4\_详细说明（Detailed Documentation）

<a id="ga95ef93002766901511d09c8cd8f8293b"></a>

### `K_MSGQ_DEFINE`

```c
#define K_MSGQ_DEFINE ( q_name, q_msg_size, q_max_msgs, q_align )
```

```c
#include <zephyr/kernel.h>
```

展开值（Value）：

```c
static char __noinit __aligned(q_align)                         \
        _k_fifo_buf_##q_name[(q_max_msgs) * (q_msg_size)];      \
STRUCT_SECTION_ITERABLE(k_msgq, q_name) =                       \
       Z_MSGQ_INITIALIZER(q_name, _k_fifo_buf_##q_name, \
                          (q_msg_size), (q_max_msgs))
```

静态定义并初始化一个消息队列。

消息队列的环形缓冲区（Ring Buffer）可容纳q_max_msgs条消息，每条消息长q_msg_size字节。环形缓冲区无须特殊对齐，将q_align设为1即可。

可使用以下声明，在定义消息队列的模块之外访问它：

原始示例（Example）：

```c
extern struct k_msgq <name>;
```

**参数（Parameters）**

| 名称／方向 | 说明 |
| --- | --- |
| `q_name` | 消息队列名称。 |
| `q_msg_size` | 消息大小，以字节为单位。 |
| `q_max_msgs` | 队列最多可容纳的消息数量。 |
| `q_align` | 消息队列环形缓冲区的对齐值，必须是2的幂。 |

**说明（Note）**：此宏不能与static关键字一起使用。如需这种用法，请改用K_MSGQ_DEFINE_STATIC。

> 译注——源码核对：宏同时定义环形缓冲区和可遍历段（Iterable Section）中的队列对象。extern示例中的<name>是待替换的标识符；不要在宏前再加static。缓冲区以memcpy访问消息字节，不要求应用数据像k_queue普通入队那样预留链接字段。

<a id="gabe7305b8f442ebdc147dbbc6e8cf92fc"></a>

### `k_msgq_alloc_init()`

```c
int k_msgq_alloc_init ( struct k_msgq * msgq, size_t msg_size, uint32_t max_msgs )
```

```c
#include <zephyr/kernel.h>
```

初始化消息队列。

本例程在消息队列对象首次使用之前初始化它，并从调用线程的资源池（Resource Pool）分配内部环形缓冲区。

可以调用k_msgq_cleanup()释放环形缓冲区所占的内存；启用用户空间（Userspace）时，msgq对象失去全部引用后也会释放这部分内存。

**参数（Parameters）**

| 名称／方向 | 说明 |
| --- | --- |
| `msgq` | 消息队列的地址。 |
| `msg_size` | 消息大小，以字节为单位。 |
| `max_msgs` | 队列最多可容纳的消息数量。 |

**返回（Returns）**：成功返回0；线程资源池内存不足时返回-ENOMEM；大小参数导致整数溢出时返回-EINVAL。

> 译注——源码核对：当前实现先检查msg_size乘max_msgs是否溢出，再用z_thread_malloc分配环形缓冲区；溢出返回-EINVAL，分配失败返回-ENOMEM。它分配的是队列存储，不为消息内的指针所指对象分配内存。

<a id="gafda4399aa9b8f1e44bdf752e00ea787b"></a>

### `k_msgq_cleanup()`

```c
int k_msgq_cleanup ( struct k_msgq * msgq)
```

```c
#include <zephyr/kernel.h>
```

释放为队列分配的缓冲区。

释放为环形缓冲区分配的内存。仅当缓冲区由k_msgq_alloc_init()分配时才释放；若缓冲区由调用者提供，则调用成功但不释放任何内存。队列中尚存的消息会随缓冲区一起丢弃。

**参数（Parameters）**

| 名称／方向 | 说明 |
| --- | --- |
| `msgq` | 待清理的消息队列。 |

**返回值（Return Values）**

| 名称／方向 | 说明 |
| --- | --- |
| `0` | 成功。 |
| `-EBUSY` | 有线程正在消息队列上等待。 |

> 译注——源码核对：当前清理路径检查等待队列，并只在K_MSGQ_FLAG_ALLOC标志存在时释放缓冲区、清除该标志；有等待者的错误为-EBUSY。它没有重置used_msgs、read_ptr或write_ptr：动态缓冲区释放后不能继续收发，须完成生命周期管理并重新初始化。调用者提供缓冲区时，该调用不等于purge，也不会自动清空已有消息。

<a id="gae67f2ced2df1f9c290ae15dab9097cb7"></a>

### `k_msgq_get()`

```c
int k_msgq_get ( struct k_msgq * msgq, void * data, k_timeout_t timeout )
```

声明属性：`isr-ok`（允许从中断服务程序ISR调用）。

```c
#include <zephyr/kernel.h>
```

从消息队列接收一条消息。

本例程按先进先出（First In, First Out，FIFO）顺序，从消息队列q接收一条消息。

**参数（Parameters）**

| 名称／方向 | 说明 |
| --- | --- |
| `msgq` | 消息队列的地址。 |
| `data` | 用于保存接收消息的区域地址。 |
| `timeout` | 等待接收消息的时间，或特殊值K_NO_WAIT、K_FOREVER之一。 |

**返回值（Return Values）**

| 名称／方向 | 说明 |
| --- | --- |
| `0` | 消息已接收。 |
| `-ENOMSG` | 未等待即返回，或队列被清空。 |
| `-EAGAIN` | 等待超时。 |

**说明（Note）**：从中断服务程序（Interrupt Service Routine，ISR）调用时，timeout必须设为K_NO_WAIT。

> 译注——源码核对：成功时复制msg_size字节到调用者缓冲区。当前实现取出一条消息后，如果有阻塞发送者，会立刻把其待发消息复制进腾出的槽位，再唤醒发送者，因此get成功不保证used_msgs随即减少。等待接收期间目标缓冲区也必须保持有效，直到调用完成。

### `k_msgq_init()`

```c
void k_msgq_init ( struct k_msgq * msgq, char * buffer, size_t msg_size, uint32_t max_msgs )
```

```c
#include <zephyr/kernel.h>
```

初始化消息队列。

本例程在消息队列对象首次使用之前初始化它。

消息队列的环形缓冲区必须能够容纳max_msgs条消息，每条消息长msg_size字节。环形缓冲区无须特殊对齐。

**参数（Parameters）**

| 名称／方向 | 说明 |
| --- | --- |
| `msgq` | 消息队列的地址。 |
| `buffer` | 指向存放排队消息的环形缓冲区的指针。 |
| `msg_size` | 消息大小，以字节为单位。 |
| `max_msgs` | 队列最多可容纳的消息数量。 |

> 译注——源码核对：调用者须保证缓冲区至少容纳msg_size乘max_msgs字节，并在队列使用期间保持有效。当前实现以断言检查乘法及地址加法溢出；本函数没有错误返回值，不能依赖关闭断言后的输入校验。它用于初始设置，不是有等待者或动态缓冲区时的清理接口。


窥视／读取消息队列中的一条消息。

### `k_msgq_purge()`

```c
void k_msgq_purge ( struct k_msgq * msgq)
```

```c
#include <zephyr/kernel.h>
```

清空消息队列。

本例程丢弃消息队列环形缓冲区中所有尚未接收的消息。因等待向该队列发送消息而阻塞的线程都会解除阻塞，并得到-ENOMSG错误码。

**参数（Parameters）**

| 名称／方向 | 说明 |
| --- | --- |
| `msgq` | 消息队列的地址。 |

> 译注——源码核对：原文重点描述阻塞发送者；当前实现遍历同一个wait_q唤醒所有等待者并令其返回-ENOMSG，没有区分发送与接收。因此在空队列上等待的接收者也可能因purge返回。随后used_msgs置0，read_ptr设为write_ptr；缓冲区不释放，历史字节不擦除，消息内指针指向的资源也不会自动回收。

### `k_msgq_put()`

```c
int k_msgq_put ( struct k_msgq * msgq, const void * data, k_timeout_t timeout )
```

声明属性：`isr-ok`（允许从中断服务程序ISR调用）。

```c
#include <zephyr/kernel.h>
```

向消息队列末尾发送一条消息。

本例程向消息队列q发送一条消息。

**参数（Parameters）**

| 名称／方向 | 说明 |
| --- | --- |
| `msgq` | 消息队列的地址。 |
| `data` | 指向消息的指针。 |
| `timeout` | 等待向队列加入消息的时间，或特殊值K_NO_WAIT、K_FOREVER之一。 |

**返回值（Return Values）**

| 名称／方向 | 说明 |
| --- | --- |
| `0` | 消息已发送。 |
| `-ENOMSG` | 未等待即返回，或队列被清空。 |
| `-EAGAIN` | 等待超时。 |

**说明（Note）**：消息内容从data复制到msgq，data指针不会被保留，因此本函数不会修改消息内容。

### `k_msgq_put_front()`

```c
int k_msgq_put_front ( struct k_msgq * msgq, const void * data )
```

声明属性：`isr-ok`（允许从中断服务程序ISR调用）。

```c
#include <zephyr/kernel.h>
```

向消息队列头部发送一条消息。

本例程向消息队列q的起始位置（头部）发送一条消息。用这种方式发送的消息，会先于队列中此前已有的所有消息被取出。

**参数（Parameters）**

| 名称／方向 | 说明 |
| --- | --- |
| `msgq` | 消息队列的地址。 |
| `data` | 指向消息的指针。 |

**返回值（Return Values）**

| 名称／方向 | 说明 |
| --- | --- |
| `0` | 消息已发送。 |
| `-ENOMSG` | 未等待即返回，或队列被清空。 |

**说明（Note）**：消息队列没有剩余空间时，本函数的行为与k_msgq_put相同。消息内容从data复制到msgq，data指针不会被保留，因此本函数不会修改消息内容。k_msgq_put_front()不会阻塞。
