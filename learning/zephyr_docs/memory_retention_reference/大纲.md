# NVMEM与数据保留源码参考大纲

本册补齐非易失性存储器（Non-Volatile Memory，NVMEM）、保留内存（Retained Memory）与数据保留服务（Retention Service）的官方源码浏览页，并收录NVMEM设备树头文件参考。三者分别处理数据单元描述与后端读写、底层保留区域访问，以及分区与可选有效性校验，不能只凭名称互换使用。

完整接口契约已译于[NVMEM接口](../storage/P013_NVMEM接口参考.md)、[设备树辅助宏](../storage/P018_NVMEM设备树辅助宏.md)、[保留内存接口](../hardware/P630_保留内存接口.md)和[数据保留接口](../storage/P014_数据保留接口参考.md)。本册继续保留代码、版权、可见注释及符号提示，源码译注解释字节序、长度、只读、元数据和平台配置边界。Nordic扩展属于官方页面范围，不表示HC32实现了该接口。
