## 4.4\_源码跟踪译注

> 译注——存储层次：保留内存（Retained Memory）驱动提供按字节读取、写入和清零，能否跨复位或低功耗保留取决于供电与硬件；不能仅凭接口名称认定掉电后仍保留。数据保留服务（Retention Service）建立在此类设备之上，增加分区和可选有效性标记，两层接口不能互换。

> 译注——边界检查顺序：当前read／write包装器先取得API表，size为0时直接返回0，不继续调用size回调或验证offset；这不保证无效设备指针可用。非零长度先取得区域大小，再检查负偏移、请求长度大于区域，以及offset超过area_size-size。先比较长度再相减避免无符号下溢，但驱动仍须返回正确大小。

> 译注——大小返回值：size回调类型是ssize_t，而read／write把其返回结果直接赋给size_t的area_size，没有先检查负错误。因而不能把这两个包装器描述为能正确传播size回调的所有失败；驱动返回负值时会先发生无符号转换。本页照实保留源码，未修改或运行该异常分支。

> 译注——操作与校验：四个回调均为必选（Required），包装器不做回调为空时的-ENOSYS回退。用户空间（Userspace）校验器先检查设备对象，再按读取／写入方向检查缓冲区的可写／可读权限，失败通过K_OOPS处理；这与普通-EINVAL边界错误不同。clear把数据置0x00，不是Flash擦除为0xFF，也不附带保留服务的有效性校验。
