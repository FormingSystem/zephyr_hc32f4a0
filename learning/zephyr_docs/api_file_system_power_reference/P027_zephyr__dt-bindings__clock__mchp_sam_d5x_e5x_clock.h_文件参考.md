### `MCHP_CLOCK_DERIVE_ID`

```c
#define MCHP_CLOCK_DERIVE_ID ( type, mclkbus, mclkmaskbit, gclkperiph, inst )
```

展开值（Value）：

```c
(((type) << 26) | ((mclkbus) << 20) | ((mclkmaskbit) << 14) | ((gclkperiph) << 8) | inst)
```

将时钟类型（Clock Type）、MCLK 总线（Bus）、MCLK 掩码位（Mask Bit）、GCLK PCH 和实例编号（Instance Number）编码为时钟子系统（Clock Subsystem）。

- 位 `00..07`（8 位）：`inst`（实例）。
- 位 `08..13`（6 位）：`gclkperiph`（GCLK 外设），取值 `0–47`。
- 位 `14..19`（6 位）：`mclkmaskbit`（MCLK 掩码位），取值 `0–31`。
- 位 `20..25`（6 位）：`mclkbus`（MCLK 总线），取值为 `MBUS_AHB (0)`、`MBUS_APBA (1)`、`MBUS_APBB (2)`、`MBUS_APBC (3)`、`MBUS_APBD (4)`。
- 位 `26..31`（6 位）：`type`（类型），取值为 `SUBSYS_TYPE_XOSC (0)`、`SUBSYS_TYPE_DFLL (1)`、`SUBSYS_TYPE_FDPLL (2)`、`SUBSYS_TYPE_RTC (3)`、`SUBSYS_TYPE_XOSC32K (4)`、`SUBSYS_TYPE_GCLKGEN (5)`、`SUBSYS_TYPE_GCLKPERIPH (6)`、`SUBSYS_TYPE_MCLKCPU (7)`、`SUBSYS_TYPE_MCLKPERIPH (8)`。

**参数（Parameters）**

| 名称／方向 | 说明 |
| --- | --- |
| `type` | 时钟子系统类型（Clock Subsystem Type）。 |
| `mclkbus` | 从 AHBx 和 APBx 总线（Buses）中选择。 |
| `mclkmaskbit` | 选择连接到 AHBx 或 APBx 总线的模块（Module），范围 `0–31`。 |
| `gclkperiph` | `PCHTRLm` 中的 GCLK 外设通道编号（Peripheral Channel Number）`m`，范围 `0–47`。 |
| `inst` | 指定时钟类型（Clock Type）的实例编号（Instance Number）。 |
