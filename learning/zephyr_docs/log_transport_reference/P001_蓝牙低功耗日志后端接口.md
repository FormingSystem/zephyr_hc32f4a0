## 1.5\_详细说明（Detailed Documentation）

<a id="ga35e6ef530516c345125da273d06e359d"></a>

### `LOGGER_BACKEND_BLE_ADV_UUID_DATA`

```c
#define LOGGER_BACKEND_BLE_ADV_UUID_DATA
```

```c
#include <zephyr/logging/log_backend_ble.h>
```

展开值（Value）：

```c
0x9E, 0xCA, 0xDC, 0x24, 0x0E, 0xE5, 0xA9, 0xE0, 0x93, 0xF3, 0xA3, 0xB5, 0x01, 0x00, 0x40,  \
        0x6E
```

用于广播（Advertising）的原始UUID数据，使蓝牙后端可与NRF Toolbox等应用配合使用。

<a id="ga54f16cb2a3e183f47110b49af97c6062"></a>

### `logger_backend_ble_hook`

```c
typedef void(* logger_backend_ble_hook) (bool backend_status, void *ctx)
```

```c
#include <zephyr/logging/log_backend_ble.h>
```

供应用获知蓝牙后端启用或禁用状态的钩子（Hook）。

**参数（Parameters）**

| 名称／方向 | 说明 |
| --- | --- |
| `backend_status` | 后端已启用时为true，禁用时为false。 |
| `ctx` | 用户上下文（User Context）。 |

<a id="ga324e2709a95362f3c83aaa89facca2cc"></a>

### `logger_backend_ble_set_hook()`

```c
void logger_backend_ble_set_hook ( logger_backend_ble_hook hook, void * ctx )
```

```c
#include <zephyr/logging/log_backend_ble.h>
```

允许应用为蓝牙日志后端状态添加钩子（Hook）。

蓝牙日志后端会根据对此蓝牙日志服务中通知特征（Notification Characteristic）的订阅情况自动启用或禁用。

**参数（Parameters）**

| 名称／方向 | 说明 |
| --- | --- |
| `hook` | 后端状态改变时调用的钩子。 |
| `ctx` | 每次调用钩子时传入的用户上下文。 |

## 1.6\_源码定位与版本边界

源码定位：[include/zephyr/logging/log_backend_ble.h](../../../include/zephyr/logging/log_backend_ble.h)、[subsys/logging/backends/log_backend_ble.c](../../../subsys/logging/backends/log_backend_ble.c)。官方源码摘要见[来源记录](../SOURCES.md)。

> 译注——源码核对：以下源码跟踪译注独立于官方正文，依据来源记录中的官方main文件；所有本地链接均为相对路径。

> 译注——源码核对：广播UUID数据（Advertising UUID Data）是供广播数据结构使用的字节序列；仅引用该宏不会自动启动广播或建立蓝牙连接。服务通知订阅状态才决定本后端的启用与停用。

> 译注——源码核对：状态钩子（Status Hook）保存应用回调和用户上下文，后端状态改变时才调用；它不是每条日志的发送完成回调。注册钩子不能替代蓝牙服务订阅流程。

> 译注——源码核对：本次实现按ATT MTU与缓冲区大小限制一次通知长度，并忽略bt_gatt_notify_cb的返回结果；不能把后端已激活或状态钩子收到true当成每条消息已送达的保证。panic路径设置标志后直接跳过后续日志处理。

本次验证范围为文档与源码对照，未构建固件、配置实板引脚或操作硬件。
