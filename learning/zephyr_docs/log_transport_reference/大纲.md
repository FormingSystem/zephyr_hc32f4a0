# 日志传输后端参考大纲

本册翻译蓝牙低功耗（Bluetooth LE）、MQTT、网络syslog与WebSocket四种日志后端的API、头文件参考和源码，共十二份官方页面。每组按接口、参考、源码顺序阅读。

保留广播UUID宏、状态钩子、MQTT客户端与主题生命周期、IPv4／IPv6地址设置、主机名以及套接字注册和注销的全部原文要求。源码跟踪译注独立说明初始化顺序、失败副作用和实际发送保证，未把日志处理完成当成网络交付确认。
