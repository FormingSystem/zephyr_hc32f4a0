# 日志前端与内部接口参考大纲

本册翻译日志前端API、前端头文件参考与源码，以及日志内部头文件参考和源码，共五份官方页面。前端直接从日志调用路径接收消息，通用入口与常见消息优化入口的参数、配置和时间戳要求完整保留。

内部头文件明确限定为日志子系统内部使用，官方隐藏的详细条目不补造成公共API；源码浏览页实际可见代码、注释和符号提示照常完整保留。源码跟踪译注说明前后端区别、栈上包的生命周期、过滤、丢弃计数与链路激活位掩码。
