## 12.1\_简介（Introduction）

<a id="id2"></a>

[safety_iec60730b](https://github.com/nxp-mcuxpresso/mcux-safety-iec60730b) 是Zephyr[模块](../modules/P001_模块与外部项目.md#modules)，提供测试子系统，用于从Zephyr应用运行IEC 60730 B类安全自检（Class B Safety Self-test）。

<a id="id4"></a>

[IEC 60730-1](https://webstore.iec.ch/publication/66089) 是国际标准，规定家用电器及类似设备自动电气控制装置的安全要求。附录H的B类规定控制装置需实现的软件故障／错误检测措施，用于发现可能引起危险失效的随机硬件故障。

<a id="id6"></a>

子系统通过统一、与厂商无关的API开放这些持续执行的自检，经Kconfig和设备驱动模型接入Zephyr，并把实际执行委派给可选后端（Backend）。NXP片上系统（System on Chip，SoC）默认使用 [NXP IEC 60730 B类安全库](https://www.nxp.com/applications/technologies/functional-safety/iec-60730-safety-standard-for-household-appliances:APIEC60730)。

下列测试可分别通过Kconfig选择：

| 测试 | Kconfig符号 | 检测的故障 |
| --- | --- | --- |
| CPU寄存器 | `CONFIG_IEC60730B_TEST_CPU` | 内核寄存器的固定值故障（Stuck-at Fault）。 |
| 浮点单元（Floating-Point Unit，FPU）寄存器 | `CONFIG_IEC60730B_TEST_FPU` | 浮点寄存器固定值故障。 |
| 程序计数器（Program Counter，PC） | `CONFIG_IEC60730B_TEST_PC` | 程序计数器损坏、非法执行流。 |
| 随机存取存储器（Random Access Memory，RAM） | `CONFIG_IEC60730B_TEST_RAM` | 用March C／March X算法检测RAM单元故障。 |
| 闪存／只读存储器（Flash／Read-Only Memory，ROM） | `CONFIG_IEC60730B_TEST_FLASH` | 用循环冗余校验（Cyclic Redundancy Check，CRC16／CRC32）检测不变存储内容损坏。 |
| 栈（Stack） | `CONFIG_IEC60730B_TEST_STACK` | 栈上溢和下溢。 |
| 时钟（Clock） | `CONFIG_IEC60730B_TEST_CLOCK` | 相对独立计数器测量系统时钟漂移。 |
| 模拟输入输出（Analog I/O） | `CONFIG_IEC60730B_TEST_AIO` | 用已知内部参考检测模数转换器（Analog-to-Digital Converter，ADC）信号路径故障。 |
| 数字输入输出（Digital I/O） | `CONFIG_IEC60730B_TEST_DIO` | 通用输入输出（General-Purpose Input/Output，GPIO）固定值故障及短路。 |
| 看门狗（Watchdog） | `CONFIG_IEC60730B_TEST_WDOG` | 看门狗超时与复位生成。 |

API后面的例程由三种可互换硬件抽象层（Hardware Abstraction Layer，HAL）后端之一提供：

- **NXP HAL，`CONFIG_IEC60730B_HAL_NXP`**：调用同仓库随附、已经预认证的NXP IEC 60730 B类裸机安全库。在NXP SoC上默认选中，背后是经认证的实现。
- **Zephyr HAL，`CONFIG_IEC60730B_HAL_ZEPHYR`**：基于标准Zephyr驱动API实现相同测试，使子系统可以用于Zephyr支持的平台；非NXP SoC默认选用它。
- **无HAL，`CONFIG_IEC60730B_HAL_NONE`**：只构建弱符号桩（Weak Stub），所有测试返回 `IEC60730B_TEST_NOT_SUPPORTED`。可作为自定义后端起点：实现公开头文件声明的函数，在链接阶段覆盖弱实现。

**原文警告：Zephyr HAL处于实验阶段（EXPERIMENTAL）。**它没有使用厂商认证库，其中代码均未通过IEC 60730 B类认证。用于任何安全关键产品之前，使用者须自行负责针对具体应用及目标平台评估、验证和认证全部代码。

测试子系统、HAL后端、示例及模块元数据，即 `zephyr/` 下的内容，采用Apache-2.0许可证。用作后端的NXP安全库，即 `source/` 下的内容，按 `LA_OPT_Online Code Hosting NXP_Software_License` 发布；完整文本见该模块仓库的 `IEC60730-LICENSE.txt`。

<a id="usage-with-zephyr"></a>

## 12.2\_在Zephyr中使用（Usage with Zephyr）

<a id="adding-the-module-to-an-existing-workspace"></a>

### 12.2.1\_加入现有工作区（Adding the module to an existing workspace）

在自己的 `west.yml` 中添加west项目，或通过子清单引入，例如 `zephyr/submanifests/iec60730b.yaml`：

```yaml
manifest:
  projects:
    - name: safety_iec60730b
      url: https://github.com/nxp-mcuxpresso/mcux-safety-iec60730b
      revision: main_github
      path: modules/safety/iec60730b # adjust the path as needed
```

原代码注释允许按需调整模块相对路径。随后获取模块：

```bash
west update safety_iec60730b
```

<a id="creating-a-freestanding-workspace"></a>

### 12.2.2\_建立独立工作区（Creating a freestanding workspace）

模块仓库也自带清单，会拉取Zephyr本身及模块需要的HAL：

```bash
west init -m https://github.com/nxp-mcuxpresso/mcux-safety-iec60730b <workspace>
cd <workspace>
west update
```

> 译注——分支选择：此段只适用于选择新建独立工作区的读者，`<workspace>`替换为自己选择的位置；已有工作区使用上一小节，不重复初始化，也不删除已有 `.west`。

<a id="configuration"></a>

## 12.3\_配置（Configuration）

在应用的 `prj.conf` 启用测试子系统：

```kconfig
CONFIG_IEC60730B=y
```

所有测试例程默认启用。按需要关闭不用的测试，并在有必要时覆盖自动HAL选择。

<a id="application-interface"></a>

## 12.4\_应用接口（Application interface）

公开API声明在 `iec60730b_test.h`，模块会把它加入应用头文件搜索路径。包含该头文件后直接调用测试函数，通常划分为应用启动前运行一次的启动测试（Start-up Test），以及由专用安全线程或中断周期性执行的运行时测试（Run-time Test）。

每个函数成功返回0，发现故障返回负错误码；测试被禁用或目标不支持时，返回 `IEC60730B_TEST_NOT_SUPPORTED`。

<a id="sample-application"></a>

## 12.5\_示例应用（Sample application）

模块中的 `zephyr/samples/safety/` 是参考集成。它执行完整启动和运行时测试，在控制台报告每项结果，喂Zephyr任务看门狗（Task Watchdog）信道，并在安全线程存活时闪烁发光二极管（Light-Emitting Diode，LED）。

从工作区根目录为受支持的开发板构建并烧录：

```bash
west build -p -b frdm_mcxa266 modules/safety/iec60730b/zephyr/samples/safety
west flash
```

示例故意让看门狗超时，作为看门狗测试的一部分，因此板子会复位一次，启动横幅和启动测试结果会出现两遍。

> 译注——验证范围：`frdm_mcxa266`是原文示例目标。这里保留原文的行为和认证边界，没有对本仓库目标板运行测试，也没有据此认定HC32平台满足B类认证。
