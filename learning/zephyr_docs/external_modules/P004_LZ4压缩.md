## 4.1\_简介（Introduction）

LZ4是无损压缩（Lossless Compression）算法。原文介绍其单核压缩速度可超过500 MB/s，并能利用多核CPU扩展；解码器每核可达到数GB/s，在多核系统中通常接近随机存取存储器（Random Access Memory，RAM）的速度上限。

可以动态选择加速因子（Acceleration Factor），以压缩率换取速度。另一端提供高压缩率衍生版本 `LZ4_HC`，投入更多CPU时间提高压缩率。各版本保持相同的解压速度。

LZ4在应用编程接口（Application Programming Interface，API）和命令行界面（Command-Line Interface，CLI）层面都支持字典压缩（Dictionary Compression）。任意输入文件都可作为字典，但实际只使用最后64 KB。

> 译注——原文边界：官方这一段最后停在“This capability can be combined”，没有给出组合对象，译文不补写缺失结论。上面的速度是原页介绍，不是本仓库微控制器的实测性能。

<a id="usage-with-zephyr"></a>

## 4.2\_在Zephyr中使用（Usage with Zephyr）

要把lz4作为Zephyr模块引入，可在原文所称的 `west.yaml` 中添加west项目，或新建子清单，例如 `zephyr/submanifests/lz4.yaml`，写入以下内容后运行 `west update`：

```yaml
manifest:
  projects:
    - name: lz4
      url: https://github.com/zephyrproject-rtos/lz4
      revision: zephyr
      path: modules/lib/lz4 # adjust the path as needed
```

> 译注：原代码注释允许按需调整 `modules/lib/lz4` 这一工作区相对路径。

详细用法和API说明见 [LZ4文档](https://github.com/lz4/lz4/tree/dev/doc)及 [LZ4示例](https://github.com/zephyrproject-rtos/lz4/tree/zephyr/zephyr/samples)。
