# 官方外部模块介绍译文大纲

本册翻译Zephyr官网外部模块（External Module）目录中的介绍页，说明各项目用途、依赖、许可和west接入方式。列入官网介绍不等于已加入读者的活动清单，也不表示当前目标板已验证所有功能。模块整体规则见[模块指南](../modules/大纲.md)。

1. [CANnectivity_USB转CAN固件](P001_CANnectivity_USB转CAN固件.md)：USB转CAN协议与组件复用。
2. [CANopenNode协议栈](P002_CANopenNode协议栈.md)：Zephyr衔接仓库和Git子模块。
3. [设备树Shell_DTSh](P003_设备树Shell_DTSh.md)：设备树交互查看、west扩展及树形输出。
4. [LZ4压缩](P004_LZ4压缩.md)：压缩率、速度、字典及模块接入。
5. [Requests_HTTP客户端](P005_Requests_HTTP客户端.md)：Zephyr HTTP(S)客户端和Shell命令。
6. [Memfault固件SDK](P006_Memfault固件SDK.md)：远程调试、设备群指标、OTA与独立许可。
7. [Mender_MCU客户端](P007_Mender_MCU客户端.md)：MCUboot A/B更新、服务端和cJSON依赖。
8. [wolfSSL](P008_wolfSSL.md)：TLS、DTLS、密码能力及双重许可。
9. [wolfMQTT](P009_wolfMQTT.md)：MQTT版本、QoS、LWT及TLS依赖。
10. [wolfSSH](P010_wolfSSH.md)：SSH、SCP、SFTP及密码依赖。
11. [wolfTPM](P011_wolfTPM.md)：TPM、I2C、示例和项目配置。
12. [IEC60730_B类安全测试](P012_IEC60730_B类安全测试.md)：十项自检、三种HAL、认证边界及运行流程。

13. [Arduino核心API](P013_Arduino核心API.md)：两层Arduino API、许可、开发板变体和库接入。
14. [上下文中心运行时CHRE](P014_上下文中心运行时CHRE.md)：CHRE事件循环、C++运行环境与PAL支持范围。
15. [CLUTGen标定查找表生成器](P015_CLUTGen标定查找表生成器.md)：标定查找表生成、插值及空间与计算取舍。
16. [Edge_Impulse_SDK](P016_Edge_Impulse_SDK.md)：Edge Impulse推理SDK与west扩展。
17. [emlearn机器学习](P017_emlearn机器学习.md)：嵌入式机器学习和模型推理。
18. [ESP串口烧录器](P018_ESP串口烧录器.md)：主机MCU烧录ESP目标、接口与Shell操作。
19. [ExecuTorch](P019_ExecuTorch.md)：CPU／NPU推理、FVP、模型导出及各系统构建流程。
20. [Greybus](P020_Greybus.md)：设备协议、TCP后端及演示平台。
21. [grvl图形库](P021_grvl图形库.md)：图形组件、资源与依赖许可。
22. [立方星空间协议libcsp](P022_立方星空间协议libcsp.md)：立方星通信、路由与缓冲池。

31. [Zephyr科学计算库](P031_Zephyr科学计算库.md)：科学计算功能、矩阵示例与测试。

当前覆盖清单中的32个官方外部模块介绍页面均已翻译；清单索引和其他指南、各组件API等页面仍按[全站进度](../PROGRESS.md)独立登记。各页保留完整官方片段，原文缩进、名称或版本差异用译注解释；组件许可证单独保留，不能套用翻译文档许可证。

本地源码与文档使用相对链接，命令以读者实际工作区解析。源码对照保留为译注，项目环境和实验路线见独立的[项目实验补充](../../zephyr_project_notes/README.md)。本批未更改活动清单、下载模块、安装工具、构建、烧录、运行更新或安全测试。
