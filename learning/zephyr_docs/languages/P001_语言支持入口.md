# 第1章\_语言支持入口

原文：[Language Support](https://docs.zephyrproject.org/latest/develop/languages/index.html)。读取日期：2026-10-12，`latest`。

官方本页是语言支持的分类入口，按以下三个方向组织文档。

## 1.1\_C语言

[C语言支持](P002_C语言支持.md)介绍语言标准、标准库、格式化输出与动态内存管理。不同运行库另见：

- [C库公共代码](P003_C库公共代码.md)。
- [最小C库](P004_最小C库.md)。
- [Newlib](P005_Newlib_C库.md)。
- [Picolibc](P006_Picolibc_C库.md)。

## 1.2\_C++语言

[C++语言支持](P007_C加加语言支持.md)介绍启用方法、语言特性、Zephyr 最小 C++ 库、完整标准库，以及 C/C++ 共享头文件时的不兼容问题。

## 1.3\_Rust语言

[Rust语言支持](P008_Rust语言支持.md)介绍可选模块的启用和 **应用程序编程接口（Application Programming Interface，API）**文档生成。

> 译注：本页仅登记官方分类，不代表各运行库的全部 API、外部 Rust 模块文档或语言标准全文已经译完。
