# 第4章\_最小C库

原文：[Minimal libc](https://docs.zephyrproject.org/latest/develop/languages/c/minimal_libc.html)。读取日期：2026-10-12，`latest`。

**最小C库（Minimal libc）**位于 Zephyr 源码中，只提供内核和子系统所需的最小标准库子集，主要用于字符串操作和显示输出。

它的**资源占用（Footprint）**很小，适合不依赖 ISO C 标准库较少使用部分的项目，也支持多种工具链。实现位于官方源码树的 `lib/libc/minimal`。

## 4.1\_函数范围

该库实现 ISO/IEC 9899:2011 标准库中满足 Zephyr 内核需要的最小函数集合，范围按[编码规范规则A.4](../contributing/P009_编码准则.md#coding-guideline-libc-usage-restrictions-in-zephyr-kernel)界定。

## 4.2\_格式化输出

最小 C 库没有独立的**格式化输出处理器（Formatted Output Processor）**，而是把 `printf`、`sprintf` 等标准函数映射到 [cbprintf()](../cbprintf_reference/P001_回调格式化输出接口.md#ga0cebdbf4f142ee28c5bd80a1615647da)。后者是 Zephyr 自己的 C99 兼容格式化输出实现。

详细说明见[格式化输出服务](https://docs.zephyrproject.org/latest/services/formatted_output.html#formatted-output)。

## 4.3\_动态内存管理

最小 C 库使用[C库公共代码](P003_C库公共代码.md)提供的 `malloc` 函数族，其底层建立在[内核内存堆接口](https://docs.zephyrproject.org/latest/kernel/memory_management/heap.html#heap-v2)之上。

## 4.4\_错误编号

Zephyr 的 **应用程序编程接口（Application Programming Interface，API）**通过函数返回值报告**错误编号（Error Number）**，通常返回 `errno.h` 中定义的整数常量的负值。

最小 C 库收录了[可移植操作系统接口（Portable Operating System Interface，POSIX）的errno.h规范](https://pubs.opengroup.org/onlinepubs/9699919799/basedefs/errno.h.html)及其他事实标准来源中的一部分错误编号。

Zephyr 尽量保持最小 C 库的错误编号值与它支持的其他 C 标准库一致，会用 [Newlib](P005_Newlib_C库.md) 的 `errno.h` 核对最小库版本，确保编号对齐。

原文提供[错误编号API定义列表](../error_reference/P003_系统错误号公共接口.md)；实际数值见官方 [errno.h源码](https://github.com/zephyrproject-rtos/zephyr/blob/main/lib/libc/minimal/include/errno.h)。

> 译注：本页原文链接到独立生成的 API 参考，并未在正文逐项展开所有错误编号，因此这里不把该独立 API 页面登记为已翻译。错误常量、返回负错误码与 C 库的线程局部 `errno` 是有关联但不同的概念，具体函数仍按各自接口契约处理。
