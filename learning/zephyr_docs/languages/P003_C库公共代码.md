# 第3章\_C库公共代码

原文：[Common C library code](https://docs.zephyrproject.org/latest/develop/languages/c/common_libc.html)。读取日期：2026-10-12，`latest`。

**C库公共代码（Common C Library Code）**提供可与多种 C 标准库配合的实现。一部分补充这些库缺少的函数，另一部分用更适合 Zephyr 环境的代码替代库中原有功能。

## 3.1\_时间函数

公共代码实现标准 C 函数 [time()](https://docs.zephyrproject.org/latest/doxygen/html/lib_2libc_2minimal_2include_2time_8h.html#a99ef1cb2c789827dd5db3886dccf9067)，内部依赖 Zephyr 的 [sys_clock_gettime()](../timer_reference/P086_系统时钟公共接口.md)。通过 Kconfig 符号 `COMMON_LIBC_TIME` 选择该实现；应用配置文件中的形式为 `CONFIG_COMMON_LIBC_TIME`。

## 3.2\_动态内存管理

在应用配置中启用 Kconfig 选项 [CONFIG_COMMON_LIBC_MALLOC](https://docs.zephyrproject.org/latest/kconfig.html#CONFIG_COMMON_LIBC_MALLOC)，可使用公共**动态内存管理（Dynamic Memory Management）**实现。

它内部使用[内核内存堆接口](https://docs.zephyrproject.org/latest/kernel/memory_management/heap.html#heap-v2)，为标准函数 [malloc()](https://docs.zephyrproject.org/latest/doxygen/html/stdlib_8h.html#a9c36d0fe3ec4675cbffdc9b52f5fb399)、[free()](https://docs.zephyrproject.org/latest/doxygen/html/stdlib_8h.html#afbedc913aa4651b3c3b4b3aecd9b4711) 等管理堆。

内部堆通常位于 `.bss` 段，即保存零初始化静态存储对象的内存段。启用**用户空间（Userspace）**时，堆放入专用内存分区 `z_malloc_partition`，以便用户态线程访问。堆大小由 Kconfig 选项 [CONFIG_COMMON_LIBC_MALLOC_ARENA_SIZE](https://docs.zephyrproject.org/latest/kconfig.html#CONFIG_COMMON_LIBC_MALLOC_ARENA_SIZE) 指定。

原文称，使用公共 C 库的应用默认堆大小为零，即没有堆；其他 C 库用户在具有**内存管理单元（Memory Management Unit，MMU）**时默认分配 16 kB，否则使用全部可用内存。

> 译注：这段原文对“公共 C 库用户”的概括不够精确。本仓库 `lib/libc/common/Kconfig` 实际按所选 C 库与系统配置确定默认值：`MINIMAL_LIBC` 时为 0，MMU 时为 16384 字节，用户空间且保护单元要求2的幂次对齐时为2048字节，`ARCH_POSIX` 时为16384字节，其余为 `-1`。`-1` 表示使用剩余系统内存，并不是分配负字节。应以最终配置为准，不能将上段理解为所有调用公共分配器的应用都默认无堆。

另有独立选项控制 [calloc()](https://docs.zephyrproject.org/latest/doxygen/html/stdlib_8h.html#a2807e26a012717736641384f91ab2563) 和 [reallocarray()](https://docs.zephyrproject.org/latest/doxygen/html/stdlib_8h.html#aa34babf7c7883ba6714ac6d010952465)，分别为 Kconfig 符号 `COMMON_LIBC_CALLOC`、`COMMON_LIBC_REALLOCARRAY`。原文说两者默认启用，因为未使用这些函数的应用不会因此增加内存占用。

> 译注：本仓库配置对最小 C 库另有默认关闭等条件，不能把“默认启用”视为任意库配置下都成立。`calloc()` 分配并清零元素数组，`reallocarray()` 调整数组分配大小；实际能否使用应查看最终 Kconfig 结果。

公共代码实现的标准动态内存函数具备**线程安全性（Thread Safety）**，可由多个线程同时调用。实现位于官方源码 `lib/libc/common/source/stdlib/malloc.c`。
