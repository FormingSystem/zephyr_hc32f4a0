跟踪子系统（Tracing Subsystem）的接口。

<a id="details"></a>

跟踪子系统（Tracing Subsystem）的接口。跟踪子系统允许从应用中收集数据，并让主机上运行的工具可视化内核及其他各子系统的内部运行情况。

自版本（Since）：1.13。

版本（Version）：0.8.0。
