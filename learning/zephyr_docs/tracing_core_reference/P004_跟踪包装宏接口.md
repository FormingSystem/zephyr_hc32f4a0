## 4.3\_详细说明（Detailed Documentation）

<a id="gadce691eea44f211b804ce44b51b2e71d"></a>

### `SYS_PORT_TRACING_FUNC`

```c
#define SYS_PORT_TRACING_FUNC ( type, func, ... )
```

```c
#include <zephyr/tracing/tracing_macros.h>
```

展开值（Value）：

```c
_SYS_PORT_TRACE_IF_NOT_DISABLED(type, _SYS_PORT_TRACING_FUNC(type, func), __VA_ARGS__)
```

用于不直接关联特定对象类型的函数调用的跟踪宏。

**参数（Parameters）**

| 名称／方向 | 说明 |
| --- | --- |
| `type` | 跟踪事件类型或对象类型（Tracing Event or Object Type） |
| `func` | 负责此调用的函数名称。此名称不必与函数的实际名称完全一致；对于系统调用等情形，应匹配用户调用的名称。也就是说，通常可以省略名称中的z_vrfy／z_impl部分。 |
| `...` | 与此跟踪调用相关的其他参数 |

### `SYS_PORT_TRACING_OBJ_FUNC`



```c

        SYS_PORT_TRACING_TYPE_MASK(obj_type, \
                _SYS_PORT_TRACING_OBJ_FUNC(obj_type, func)(obj, ##__VA_ARGS__)); \
```

| `obj` | 对象（Object） |

> 译注——源码核对：官方接口正文、原始宏展开与源码译注分别保留。来源记录固定本次官方页面及源码的摘要；仓库文件通过相对链接定位，读者使用的源码版本可能不同。

> 译注——源码核对：SYS_PORT_TRACING_FUNC系列通过type与func拼接具体sys_port_trace_*钩子名称；对象系列额外通过sys_port_trace_type_mask_*过滤对象类型。普通函数包装检查相应is_disabled标记，未识别的禁用标记不会自动按对象掩码过滤；两类包装不能随意互换。

> 译注——源码核对：CONFIG_TRACING关闭时，实际事件包装宏展开为空do／while语句，不求值被去掉的业务参数。不要把必须执行的计数递增、释放资源等副作用只放在跟踪参数中。原页的宏展开来自文档分支，不能据此忽略实际编译配置。

> 译注——源码核对：SYS_PORT_TRACING_TYPE_MASK是底层辅助入口：本次头文件只在启用跟踪或__DOXYGEN__分支定义它；关闭跟踪时各事件包装宏直接为空操作。官方“所有宏均为空操作”的概括应结合此区别理解，不应在任意配置下直接依赖TYPE_MASK作为独立公共操作。

> 译注——源码核对：Enter、Blocking和Exit包装只生成对应钩子调用，不自动建立配对、测量时长或改变线程状态。OBJ_FUNC_BLOCKING会把obj、timeout与附加参数按顺序传入钩子；返回值需要调用点主动传给出口，宏不会自动捕获原函数返回值。

> 译注——源码核对：本次验证限于官方文档与源码对照，未配置采集后端、运行事件采集或测量时序。
