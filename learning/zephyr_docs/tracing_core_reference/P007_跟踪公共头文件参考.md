## 7.1\_宏定义（Macros）

```c
#define sys_trace_sys_init_enter(entry, level)
```

相关声明：[sys_trace_sys_init_enter](P002_跟踪API总览.md#ga9b5a02fc57b86d38f857597c7a2553f6)。

相关声明：[sys_trace_sys_init_exit](P002_跟踪API总览.md#gacd56f9b376b4639cbe21e12055ca74c7)。

> 译注——源码核对：本次tracing.h按配置选择SystemView、CTF、测试、用户或自定义格式，树外格式可通过CONFIG_TRACING_FORMAT_HEADER提供头文件名。自定义／树外分支随后包含tracing_hooks.h，用每个宏的#ifndef回退填补未定义项，不覆盖已有宏定义。

> 译注——源码核对：文件参考页展示的空宏属于未选择相应格式的文档分支；实际后端可实现命名事件及其他入口。tracing_none.c提供的弱ISR／idle函数还可能用于CPU负载统计，不能把“未输出跟踪事件”理解成调用一定没有其他用途。

> 译注——源码核对：低层钩子完整说明见[跟踪API总览](P002_跟踪API总览.md)，命名事件的函数式后端实现与参数边界见[命名事件跟踪接口](../network_thread_trace_reference/P004_命名事件跟踪接口.md)。
