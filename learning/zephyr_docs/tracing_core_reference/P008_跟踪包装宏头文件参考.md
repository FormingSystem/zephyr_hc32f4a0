## 8.1\_宏定义（Macros）

<a id="r_ga7c3ff6c93f71cdd1a35e3a656885fb50"></a>

```c
#define SYS_PORT_TRACING_TYPE_MASK(type, trace_call)
```

相关声明：[SYS_PORT_TRACING_TYPE_MASK](P004_跟踪包装宏接口.md#ga7c3ff6c93f71cdd1a35e3a656885fb50)。

检查是否应跟踪某种对象类型（Object Type）。

<a id="r_gadce691eea44f211b804ce44b51b2e71d"></a>

```c
#define SYS_PORT_TRACING_FUNC(type, func, ...)
```

相关声明：[SYS_PORT_TRACING_FUNC](P004_跟踪包装宏接口.md#gadce691eea44f211b804ce44b51b2e71d)。

用于不直接关联特定对象类型的函数调用的跟踪宏。

<a id="r_ga445bcac4cec53d560ddca757de17e1e3"></a>

```c
#define SYS_PORT_TRACING_FUNC_ENTER(type, func, ...)
```

相关声明：[SYS_PORT_TRACING_FUNC_ENTER](P004_跟踪包装宏接口.md#ga445bcac4cec53d560ddca757de17e1e3)。

用于函数入口的跟踪宏，函数可以有返回值，也可以没有返回值。

<a id="r_ga17c6029a89e3e1539dbac019dc9ee50b"></a>

```c
#define SYS_PORT_TRACING_FUNC_BLOCKING(type, func, ...)
```

相关声明：[SYS_PORT_TRACING_FUNC_BLOCKING](P004_跟踪包装宏接口.md#ga17c6029a89e3e1539dbac019dc9ee50b)。

用于函数执行期间发生阻塞（Blocking）时的跟踪宏。

<a id="r_gab0350eef3ed26733e57505ee2d0487cb"></a>

```c
#define SYS_PORT_TRACING_FUNC_EXIT(type, func, ...)
```

相关声明：[SYS_PORT_TRACING_FUNC_EXIT](P004_跟踪包装宏接口.md#gab0350eef3ed26733e57505ee2d0487cb)。

用于函数执行结束时的跟踪宏。

<a id="r_ga19606657deb4b8902314fe11eb8bfb24"></a>

```c
#define SYS_PORT_TRACING_OBJ_INIT(obj_type, obj, ...)
```

相关声明：[SYS_PORT_TRACING_OBJ_INIT](P004_跟踪包装宏接口.md#ga19606657deb4b8902314fe11eb8bfb24)。

用于对象初始化（Object Initialization）的跟踪宏。

<a id="r_gaca007b62a20872de436533f26e5b1c55"></a>

```c
#define SYS_PORT_TRACING_OBJ_FUNC(obj_type, func, obj, ...)
```

相关声明：[SYS_PORT_TRACING_OBJ_FUNC](P004_跟踪包装宏接口.md#gaca007b62a20872de436533f26e5b1c55)。

用于简单对象函数调用的跟踪宏，这类调用通常没有返回值或分支。

<a id="r_ga4ce3846263099a197c043f25ebe4a253"></a>

```c
#define SYS_PORT_TRACING_OBJ_FUNC_ENTER(obj_type, func, obj, ...)
```

相关声明：[SYS_PORT_TRACING_OBJ_FUNC_ENTER](P004_跟踪包装宏接口.md#ga4ce3846263099a197c043f25ebe4a253)。

用于函数入口的跟踪宏，函数可以有返回值，也可以没有返回值。

<a id="r_ga8e98afd586a77d158acb103b94d9cd3f"></a>

```c
#define SYS_PORT_TRACING_OBJ_FUNC_BLOCKING(obj_type, func, obj, timeout, ...)
```

相关声明：[SYS_PORT_TRACING_OBJ_FUNC_BLOCKING](P004_跟踪包装宏接口.md#ga8e98afd586a77d158acb103b94d9cd3f)。

用于函数执行期间发生阻塞（Blocking）时的跟踪宏。

<a id="r_ga94bd54c03c68d60e1c0879ce43e08730"></a>

```c
#define SYS_PORT_TRACING_OBJ_FUNC_EXIT(obj_type, func, obj, ...)
```

相关声明：[SYS_PORT_TRACING_OBJ_FUNC_EXIT](P004_跟踪包装宏接口.md#ga94bd54c03c68d60e1c0879ce43e08730)。

用于函数执行结束时的跟踪宏。

## 8.2\_源码定位与版本边界

相对源码定位：[跟踪入口](../../../include/zephyr/tracing/tracing.h)、[钩子声明](../../../include/zephyr/tracing/tracing_hooks.h)、[包装宏](../../../include/zephyr/tracing/tracing_macros.h)、[格式接口](../../../include/zephyr/tracing/tracing_format.h)、[默认底层钩子](../../../include/zephyr/tracing/tracing_default_hooks.h)、[跟踪配置](../../../subsys/tracing/Kconfig)、[构建选择](../../../subsys/tracing/CMakeLists.txt)、[公共格式处理](../../../subsys/tracing/tracing_format_common.c)、[同步格式处理](../../../subsys/tracing/tracing_format_sync.c)、[异步格式处理](../../../subsys/tracing/tracing_format_async.c)、[跟踪核心](../../../subsys/tracing/tracing_core.c)、[跟踪缓冲区](../../../subsys/tracing/tracing_buffer.c)、[默认弱钩子](../../../subsys/tracing/tracing_none.c)。官方源码摘要见[来源记录](../SOURCES.md)。

> 译注——源码核对：官方接口正文、原始宏展开与源码译注分别保留。来源记录固定本次官方页面及源码的摘要；仓库文件通过相对链接定位，读者使用的源码版本可能不同。

> 译注——源码核对：SYS_PORT_TRACING_FUNC系列通过type与func拼接具体sys_port_trace_*钩子名称；对象系列额外通过sys_port_trace_type_mask_*过滤对象类型。普通函数包装检查相应is_disabled标记，未识别的禁用标记不会自动按对象掩码过滤；两类包装不能随意互换。

> 译注——源码核对：CONFIG_TRACING关闭时，实际事件包装宏展开为空do／while语句，不求值被去掉的业务参数。不要把必须执行的计数递增、释放资源等副作用只放在跟踪参数中。原页的宏展开来自文档分支，不能据此忽略实际编译配置。

> 译注——源码核对：SYS_PORT_TRACING_TYPE_MASK是底层辅助入口：本次头文件只在启用跟踪或__DOXYGEN__分支定义它；关闭跟踪时各事件包装宏直接为空操作。官方“所有宏均为空操作”的概括应结合此区别理解，不应在任意配置下直接依赖TYPE_MASK作为独立公共操作。

> 译注——源码核对：Enter、Blocking和Exit包装只生成对应钩子调用，不自动建立配对、测量时长或改变线程状态。OBJ_FUNC_BLOCKING会把obj、timeout与附加参数按顺序传入钩子；返回值需要调用点主动传给出口，宏不会自动捕获原函数返回值。

> 译注——源码核对：本头文件参考页保留全部摘要声明；完整宏展开、参数表及对象／非对象包装的接口说明见[跟踪包装宏接口](P004_跟踪包装宏接口.md)。

> 译注——源码核对：本次验证限于官方文档与源码对照，未配置采集后端、运行事件采集或测量时序。

本次验证范围为文档与源码对照，未构建固件、配置实板引脚或操作硬件。
