<a id="details"></a>

用于表示跟踪数据格式（Tracing Data Format）的结构体。此结构体表示要通过跟踪子系统输出的一段数据。它通常与TRACING_FORMAT_DATA和TRACING_DATA配合使用，将原始值或内存区域包装成后端可使用的统一格式。

> 译注——源码核对：本结构体包含uint8_t *data与uint32_t length，并以__packed定义tracing_data_t。data是待输出内存的地址，length是要读出的字节数；结构体不拥有缓冲区，不自动分配或释放内存。

> 译注——源码核对：公共格式实现消费描述符所指的各段数据，而非直接把描述符中的指针值和长度字段作为一个固定协议发送。若用TRACING_FORMAT_DATA包装指针变量，得到的却是该指针变量自身的字节描述，应与手工提供缓冲区地址和长度区分。

> 译注——源码核对：本次异步格式实现会在返回前尝试把描述的数据复制到内部缓冲区；同步原始数据入口直接调用后端处理。能否保留内存、何时可改写，仍应以所用接口及后端实现为依据，不把结构体指针误当成自动延长对象生命周期。

> 译注——源码核对：本次验证限于官方文档与源码对照，未配置采集后端、运行事件采集或测量时序。
