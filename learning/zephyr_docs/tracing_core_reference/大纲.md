# 跟踪核心接口大纲

本册完整翻译跟踪子系统总览、钩子总览、格式接口、包装宏接口、格式头文件、数据结构、公共头文件及包装宏头文件，共八份官方页面。跟踪钩子（Tracing Hooks）用于记录API入口、阻塞、出口和生命周期事件，具体记录行为由后端实现。

各页保留宏签名、摘要、完整参数说明与交叉引用。源码译注说明配置与后端、事件位置、返回值语义及原文和调用点的差异，说明格式描述符、同步／异步输出、丢包处理与编译期过滤边界。官方宏展开按原文保留。

本地源码使用相对链接，保留中英文术语和原始许可证；本册不加入作者机器的采集环境或实板步骤。完整范围见[全站进度](../PROGRESS.md)。
