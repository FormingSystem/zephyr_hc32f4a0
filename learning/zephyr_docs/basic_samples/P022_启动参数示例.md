# 第22章\_启动参数示例

原文：[官方页面](https://docs.zephyrproject.org/latest/samples/kernel/bootargs/README.html)。读取日期：2026-10-14；保存的latest页面及HTML摘要见[来源记录](../SOURCES.md)。

<a id="overview"></a>

## 22.1 概述（Overview）

本示例通过把`main`的每个参数打印到控制台，展示如何使用传递给Zephyr的启动参数（Boot Arguments，bootargs）。

Zephyr同时支持由受支持的引导加载程序（Bootloader）传入的动态启动参数，以及嵌入二进制镜像中的静态启动参数。

<a id="requirements"></a>

## 22.2 要求（Requirements）

静态启动参数没有特殊要求。

动态启动参数适用于通过Multiboot或可扩展固件接口（Extensible Firmware Interface，EFI）启动Zephyr的平台。

<a id="building-and-running"></a>

## 22.3 构建与运行（Building and Running）

> 译注——操作前提：下列三种配置是独立分支。在UCRT64 Bash或Linux Bash的Zephyr源码根目录执行对应主机构建命令，先准备目标工具链、模块和模拟器；EFI分支还需相应固件启动环境。更换配置时使用独立构建目录或按[west说明](../west/P007_构建烧录与调试.md)清理构建缓存。构建失败先处理错误，不继续运行旧镜像。

<a id="static-bootargs"></a>

### 22.3.1 静态启动参数（Static bootargs）

可以使用`CONFIG_BOOTARGS_STRING`配置静态启动参数。

```sh
west build -b qemu_x86 samples/kernel/bootargs -- -DCONF_FILE=prj_static_bootargs.conf
west build -t run
```

输出：

```text
*** Booting Zephyr OS build v3.7.0-514-gd4490bc739d1 ***
argv[0] = appname
argv[1] = This
argv[2] = is
argv[3] = a list of
argv[4] = arguments
```

<a id="multiboot"></a>

### 22.3.2 Multiboot（Multiboot）

```sh
west build -b qemu_x86 samples/kernel/bootargs -- -DCONF_FILE=prj_multiboot.conf
west build -t run
```

输出：

```text
*** Booting Zephyr OS build v3.7.0-rc2-421-g3cf718e6dabc ***
argv[0] = /home/user/zephyr/samples/kernel/bootargs/build/zephyr/zephyr.elf
```

> 译注——日志中的路径：上面的`/home/user/...`是官方原始输出中的通用示例路径，表示当时加载的ELF文件，不是读者必须创建的目录，也不是本仓库的执行位置。实际路径由自己的构建位置决定；本文的仓库内链接均使用相对路径。

要传入自己的参数，可手动调用QEMU并使用`-append "your args"`，例如：

```sh
qemu-system-x86_64 -kernel ./build/zephyr/zephyr.elf -nographic -append "This is 'a list of' arguments"
```

由此得到以下输出：

```text
*** Booting Zephyr OS build v3.7.0-rc2-421-g3cf718e6dabc ***
argv[0] = ./build/zephyr/zephyr.elf
argv[1] = This
argv[2] = is
argv[3] = a list of
argv[4] = arguments
```

<a id="efi"></a>

### 22.3.3 EFI（Efi）

```sh
west build -b qemu_x86_64 samples/kernel/bootargs -- -DCONF_FILE=prj_efi.conf
west build -t run
```

输出：

```text
*** Zephyr EFI Loader ***
RSDP found at 0xbf7e014
Zeroing 501792 bytes of memory at 0x163000
Copying 16384 data bytes to 0x1000 from image offset
Copying 405504 data bytes to 0x100000 from image offset 16384
Copying 30688 data bytes to 0x1dd820 from image offset 421888
Jumping to Entry Point: 0x1137 (48 31 c0 48 31 d2 48)

*** Booting Zephyr OS build v3.7.0-rc2-421-g3cf718e6dabc ***
argv[0] = run.efi
```

要传入自己的参数，可按`ESC`，在Zephyr EFI二进制文件名之后写入参数，例如：

```text
Press ESC in 5 seconds to skip startup.nsh or any other key to continue.
Shell> run.efi This is 'a list of' arguments
*** Zephyr EFI Loader ***
RSDP found at 0xbf7e014
Zeroing 501792 bytes of memory at 0x163000
Copying 16384 data bytes to 0x1000 from image offset
Copying 405504 data bytes to 0x100000 from image offset 16384
Copying 30688 data bytes to 0x1dd820 from image offset 421888
Jumping to Entry Point: 0x1137 (48 31 c0 48 31 d2 48)

*** Booting Zephyr OS build v3.7.0-rc2-421-g3cf718e6dabc ***
argv[0] = run.efi
argv[1] = This
argv[2] = is
argv[3] = a list of
argv[4] = arguments
```

> 译注——终端与参数边界：最后一段的`Shell>`是模拟环境里的EFI Shell，不是主机Bash或PowerShell；`a list of`因引号作为一个参数传入。`argv[0]`由启动方式决定，后续元素才是解析得到的其他参数。版本号、地址和路径均为原文日志，未在本次运行复现。
