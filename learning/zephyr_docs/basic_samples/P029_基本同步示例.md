# 第29章\_基本同步示例

原文：[官方页面](https://docs.zephyrproject.org/latest/samples/synchronization/README.html)。读取日期：2026-10-14；保存的latest页面及HTML摘要见[来源记录](../SOURCES.md)。

<a id="overview"></a>

## 29.1 概述（Overview）

这个简单应用展示内核基本功能是否正常。线程A和B轮流向控制台打印问候消息，并使用睡眠请求（Sleep Request）与信号量（Semaphore）控制消息产生的速率，从而展示内核调度、通信和计时的正常运作。

<a id="building-and-running"></a>

## 29.2 构建与运行（Building and Running）

本项目向控制台输出，可以按以下方式在QEMU上构建并执行：

> 译注——命令环境：在UCRT64 Bash或Linux Bash的Zephyr源码根目录执行，先准备命令中QEMU目标的工具链、模块和模拟器。构建成功后再运行；失败时先检查对应目标与依赖，不把下面的原文输出当作本次执行记录。

```sh
west build -b qemu_x86 samples/synchronization
west build -t run
```

<a id="sample-output"></a>

### 29.2.1 示例输出（Sample Output）

```text

thread_b: Hello World from cpu 0 on qemu_x86!
thread_a: Hello World from cpu 0 on qemu_x86!
thread_b: Hello World from cpu 0 on qemu_x86!
thread_a: Hello World from cpu 0 on qemu_x86!
thread_b: Hello World from cpu 0 on qemu_x86!
thread_a: Hello World from cpu 0 on qemu_x86!
thread_b: Hello World from cpu 0 on qemu_x86!
thread_a: Hello World from cpu 0 on qemu_x86!
thread_b: Hello World from cpu 0 on qemu_x86!

<repeats endlessly>
```

按`Ctrl+A`后再按`x`退出QEMU。
