# 第21章\_内核与调度器示例目录

原文：[官方页面](https://docs.zephyrproject.org/latest/samples/kernel/index.html)。读取日期：2026-10-14；保存的latest页面及HTML摘要见[来源记录](../SOURCES.md)。

这些示例展示如何使用各种内核与调度器（Kernel and Scheduler）功能。

- [启动参数（Bootargs）](P022_启动参数示例.md#bootargs)：把接收到的启动参数打印到控制台。
- [条件变量（Condition Variables）](P024_条件变量协作示例.md#kernel-condvar)：在多线程应用中操作条件变量。
- [消息队列（Message Queue）](P026_消息队列示例.md#msg_queue)：实现一个基本的消息队列生产者／消费者线程对。
- [元中断线程优先级（Meta-IRQ Thread Priority）](P025_元中断优先级分派示例.md#Meta-IRQ_dispatch)：实现运行在Meta-IRQ优先级的线程。
- [对象核心（Object Cores）](P027_对象核心示例.md#object_cores)：枚举运行系统中的内核对象，并查询其统计信息。
- [对象监视器（Object Monitor）](P028_对象监视器示例.md#object_monitor)：观察应用运行期间内核对象的出现与消失。


对应官方文档源码：[samples/kernel/index.rst](https://raw.githubusercontent.com/zephyrproject-rtos/zephyr/main/samples/kernel/index.rst)。
