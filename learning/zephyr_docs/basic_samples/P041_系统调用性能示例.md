## 41.1 系统调用性能（Syscall performances）

本示例测量用户线程（User Thread）必须经过系统调用（System Call）时，相对于特权线程（Supervisor Thread）直接调用函数所产生的性能损失。

<a id="overview"></a>

### 41.1.1 概述（Overview）

应用创建一个特权线程和一个用户线程。两个线程都调用[`k_sched_current_thread_query()`](../thread_core_reference/P001_线程公共接口.md#gac3b994b90b5bccded0895304f6b20c5d)，该函数返回当前线程的引用；用户线程需要通过系统调用完成此操作。

两个线程都会显示调用[`k_sched_current_thread_query()`](../thread_core_reference/P001_线程公共接口.md#gac3b994b90b5bccded0895304f6b20c5d)时消耗的处理器核心时钟周期数（Core Clock Cycles）以及执行的指令数（Instructions）。

> 译注——测量平台与接口选择：当前官方测试配置限定RISC-V架构，并要求架构支持用户空间。实现读取`cycle`／`instret`及`mcycle`／`minstret`控制与状态寄存器（Control and Status Register，CSR）。它专门使用[`k_sched_current_thread_query()`](../thread_core_reference/P001_线程公共接口.md#gac3b994b90b5bccded0895304f6b20c5d)；若换成可从线程局部存储获取线程标识的`k_current_get()`，可能绕过要测量的系统调用路径。下面的数值属于官方示例日志，不能直接作为其他架构或当前工程的开销结论。

<a id="sample-output"></a>

### 41.1.2 示例输出（Sample Output）

```text
Supervisor thread:         7 cycles        4 instructions
User thread:                   20136 cycles      748 instructions
Supervisor thread:         7 cycles        4 instructions
User thread:                   18014 cycles      748 instructions
Supervisor thread:         7 cycles        4 instructions
```

> 译注——输出格式：当前实现还在输出中包含`thread(%p)`形式的线程指针，网页保留的是另一版输出格式。指针、周期数和具体开销均应以所用版本及实际平台为准。
