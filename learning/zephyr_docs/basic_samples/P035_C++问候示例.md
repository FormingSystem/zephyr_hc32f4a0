## 35.1 概述（Overview）

这是一个简单的[C++](../languages/P007_C加加语言支持.md#language-cpp)示例，可用于多种受支持的开发板，并向控制台打印“Hello, C++ world!”。

<a id="building-and-running"></a>

## 35.2 构建与运行（Building and Running）

可以按以下方式在QEMU上构建并执行此配置：

> 译注——命令环境：在UCRT64 Bash或Linux Bash的Zephyr源码根目录执行，先准备命令中QEMU目标的工具链、模块和模拟器。构建成功后再运行；失败时先检查对应目标与依赖，不把下面的原文输出当作本次执行记录。

```sh
west build -b qemu_riscv32 samples/cpp/hello_world
west build -t run
```

要为另一块开发板构建，把上面的`qemu_riscv32`替换为该板名称。

<a id="sample-output"></a>

### 35.2.1 示例输出（Sample Output）

```text
Hello C++, world! qemu_riscv32
```

按`Ctrl+C`退出QEMU。

> 译注——字面输出：上方原日志的逗号位置与概述不同；当前`main.cpp`使用`std::cout`打印`Hello, C++ world! `及`CONFIG_BOARD`。这里没有为统一标点改写原日志，板名也应按自己的实际构建目标读取。
