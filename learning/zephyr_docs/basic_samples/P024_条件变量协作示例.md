# 第24章\_条件变量协作示例

原文：[官方页面](https://docs.zephyrproject.org/latest/samples/kernel/condition_variables/condvar/README.html)。读取日期：2026-10-14；保存的latest页面及HTML摘要见[来源记录](../SOURCES.md)。

<a id="overview"></a>

## 24.1 概述（Overview）

本示例展示多线程应用中[条件变量（Condition Variables）](../kernel/P013_条件变量.md#condvar)的用法。条件变量与互斥锁（Mutex）一起，把状态或条件的变化从一个线程通知给另一个线程。线程使用条件变量等待条件成立；不同线程向正在条件变量上等待的另一线程发出通知后，根据通知时机交替执行各自的入口函数。

本示例可用于任意[受支持的开发板](https://docs.zephyrproject.org/latest/boards/index.html#boards)，并在控制台打印下面所示的输出。

> 译注——三个线程的分工：当前源码中两个`inc_count()`线程各递增计数10次，在计数达到`COUNT_LIMIT=12`时发出通知；`watch_count()`线程在持锁的循环中等待阈值，条件满足后把计数再增加125。主线程等待三个线程结束，所以默认最终计数为145；条件变量没有代替互斥锁保护计数。

<a id="building-and-running"></a>

## 24.2 构建与运行（Building and Running）

可以按以下方式在[原生模拟器（native_sim）](../native_reference/P004_Native_Simulator本机模拟器.md#native_sim)上构建并执行：

> 译注——命令环境：在已准备native_sim依赖的Linux Bash中，从Zephyr源码根目录执行。构建成功后再运行；主机依赖或配置出错时先返回构建步骤排查。

```sh
west build -b native_sim samples/kernel/condition_variables/condvar
west build -t run
```

要为另一块开发板构建，把上面的[`native_sim`](../native_reference/P004_Native_Simulator本机模拟器.md#native_sim)替换为该板名称。
