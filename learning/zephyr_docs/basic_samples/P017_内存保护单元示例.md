# 第17章\_内存保护单元示例

原文：[官方页面](https://docs.zephyrproject.org/latest/samples/arch/mpu/mpu_test/README.html)。读取日期：2026-10-14；保存的latest页面及HTML摘要见[来源记录](../SOURCES.md)。

<a id="overview"></a>

## 17.1 概述（Overview）

此应用提供一组选项，用于针对以下安全问题检查内存保护单元（Memory Protection Unit，MPU）的配置是否正确：

- 读取内存映射中的保留地址。
- 写入启动Flash／只读存储器（Read-Only Memory，ROM）。
- 执行位于静态随机存取存储器（Static Random-Access Memory，SRAM）中的代码。

原文说明，如果MPU配置正确，选中的每项操作最终都会引发MPU故障（MPU Fault）。

> 译注——故障名称与测试假设：下方原日志的保留地址读取表现为总线故障（Bus Fault），其他架构还可能报告硬故障（Hard Fault），不能仅凭日志是否出现“MPU FAULT”判断测试成败。当前[实现](../../../samples/arch/mpu/mpu_test/src/main.c)把所选SRAM起址加`0x4000000`作为保留地址，并注明设备存储空间小于64 MB的假设；这不是对所有芯片都成立的通用保留地址。具体故障应结合目标内存映射和保护配置解释。

<a id="building-and-running"></a>

## 17.2 构建与运行（Building and Running）

此项目可以按以下方式构建和执行：

> 译注——操作前提：在UCRT64 Bash或Linux Bash的Zephyr源码根目录选择下面一种配置路线；需要匹配的板目标、工具链、模块和运行／烧录工具。构建成功后才进入后续步骤；构建失败先处理错误。此示例有意触发处理器故障，下面的UART提示符属于目标板Shell，不是主机终端。

```sh
west build -b v2m_beetle samples/arch/mpu/mpu_test
west flash
```

要构建单线程版本，使用示例随附的单线程配置文件`prj_single.conf`：

```sh
west build -b v2m_beetle samples/arch/mpu/mpu_test -- -DCONF_FILE=prj_single.conf
west build -t run
```

> 译注——配置分支：`prj_single.conf`设置`CONFIG_MULTITHREADING=n`。上面两个构建命令是不同配置，不应无条件顺次执行并复用旧缓存；更换配置时应按[west构建说明](../west/P007_构建烧录与调试.md)选择独立构建目录或干净构建。原文第二组使用`run`目标，实际可用性取决于所选平台，不能把它视作所有实板的烧录方式。

要构建允许写入Flash设备的版本，请编辑`prj.conf`，按其中注释启用相应配置。

> 译注——写入分支：当前[配置注释](../../../samples/arch/mpu/mpu_test/prj.conf)涉及`CONFIG_MPU_ALLOW_FLASH_WRITE`及Flash驱动。实现会按驱动选择直接内存写入或`flash_write()`调用；允许Flash写入会改变原测试的保护条件，不能同时要求该分支必定产生与禁止写入时相同的故障。

在ARMv6 CPU上，尤其是Cortex-M0+上运行本测试时，输出有所不同，因为ARMv6把MPU故障作为通用硬故障处理。此外，执行`mpu run`命令时，Zephyr的AArch32硬故障处理程序会尝试对异常栈帧中的程序计数器地址进行解引用，从而引发第二次故障，使处理器静默进入锁死状态（Lockup）。

为了专门检查`mpu run`测试是否按预期运行，可以：

1. 使用`west debug`在GDB下启动MPU测试。
2. 通过UART执行`mpu run`。
3. 然后按`Ctrl-C`中断GDB，并按原文所述在GDB中运行`l`查看程序计数器。

原文说明，程序计数器应显示为`0xfffffffe`，表示锁死状态。

> 译注——GDB命令纠正：原文的`l`是`list`缩写，用于显示源码，不是直接读取程序计数器。暂停目标后，在GDB提示符下可使用`p/x $pc`或`info registers pc`查看程序计数器；必要时先用`frame 0`选择最内层栈帧。依据为[GDB源码列表说明](https://sourceware.org/gdb/current/onlinedocs/gdb.html/List.html)和[寄存器说明](https://sourceware.org/gdb/current/onlinedocs/gdb.html/Registers.html)。这里保留的锁死过程与数值是原文描述，未在本次或其他芯片上实测。
