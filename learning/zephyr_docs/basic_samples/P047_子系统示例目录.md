# 第47章\_子系统示例目录

原文：[官方页面](https://docs.zephyrproject.org/latest/samples/subsys/subsys.html)。读取日期：2026-10-14；保存的latest页面及HTML摘要见[来源记录](../SOURCES.md)。

这些示例展示如何使用Zephyr支持的各种子系统（Subsystem）。

> 译注——目录与完成状态：本页逐项翻译官方目录及简介，不代表每个链接目标已完成翻译。已译目标使用仓库内相对链接，未译目标仍指向官方页面；逐页状态见[覆盖进度](../PROGRESS.md)。

- [Intel Agilex SoC FPGA上的Arm SiP服务（Arm SiP Services on Intel Agilex SoC FPGA）](P061_ArmSiP服务示例.md#sip_svc)：通过SiP SVC子系统与Intel Agilex SoC FPGA上的安全设备管理器（Secure Device Manager）交互。

- [CMSIS-DAP调试探针（CMSIS-DAP）](../observability/P073_CMSIS-DAP调试探针示例.md#cmsis-dap)：通过SWDP接口驱动实现自定义CMSIS-DAP控制器。

- [循环冗余校验子系统（Cyclic Redundancy Check Subsystem (CRC Subsys)）](../data_utilities/P002_CRC子系统示例.md#crc_subsys)：通过CRC子系统API计算并验证循环冗余校验（Cyclic Redundancy Check，CRC）。

- [按需分页（Demand paging）](P042_按需分页示例.md#demand-paging)：使用按需分页（Demand Paging）处理代码大于可用RAM的情况。

- [EDAC命令行（EDAC shell）](../hardware/P119_EDAC命令行示例.md#edac)：使用Shell命令测试错误检测与纠正（Error Detection and Correction，EDAC）。

- [插桩（Instrumentation）](../observability/P019_函数插桩示例.md#instrumentation)：展示插桩（Instrumentation）子系统的跟踪与性能分析功能。

- [精确定时（Precision timing）](P043_精确定时示例.md#precision_timing)：使用带检查的精密时间运算、精密时钟适配器和比例积分（PI）控制器。

- [设置API（Settings API）](../storage/P086_设置子系统示例.md#settings)：通过设置API（Settings API）加载和保存配置值。

- [任务看门狗（Task watchdog）](../power/P011_任务看门狗示例.md#task-wdt)：通过任务看门狗（Task Watchdog）监视线程。

- [通用唯一标识符（UUID）](../data_utilities/P015_UUID生成示例.md#uuid)：操作符合IETF RFC 9562的UUID v4和v5。
