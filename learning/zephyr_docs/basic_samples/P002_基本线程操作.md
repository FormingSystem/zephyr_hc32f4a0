## 2.1\_概述

本示例演示使用[`K_THREAD_DEFINE()`](../thread_core_reference/P001_线程公共接口.md#gab3ced58648ca35788a40676e8478ecd2)创建多个线程（Thread）。示例创建三个线程，每个线程均使用`K_THREAD_DEFINE`在编译时定义。

前两个线程各控制一个LED，即`led0`和`led1`。它们的循环控制与时序逻辑由不同函数负责：

- `blink0()`控制`led0`，睡眠周期为100 ms。
- `blink1()`控制`led1`，睡眠周期为1000 ms。

任一线程切换其LED状态时，还会向[先进先出队列（FIFO）](https://docs.zephyrproject.org/latest/kernel/services/data_passing/fifos.html#fifos-v2)放入信息，标识对应线程／LED及其已经切换的次数。

第三个线程使用[`printk()`](https://docs.zephyrproject.org/latest/doxygen/html/printk_8h.html#a1bce54a738ce2d9dd6d95ee842ec237c)，将加入FIFO的信息打印到设备控制台。

<a id="requirements"></a>

## 2.2\_要求

开发板必须有两个通过通用输入／输出（General-purpose Input/Output，GPIO）引脚连接的LED。在许多Zephyr[支持的开发板和扩展板](https://docs.zephyrproject.org/latest/boards/index.html#boards)上，它们被称为“用户LED”（User LEDs）。必须使用`led0`和`led1`[设备树（Devicetree）别名](https://docs.zephyrproject.org/latest/build/dts/index.html#dt-guide)配置LED，通常位于[`BOARD.dts`文件](https://docs.zephyrproject.org/latest/build/dts/intro-input-output.html#devicetree-in-out-files)中。

为不支持的开发板构建该示例时，会看到以下错误之一：

```text
Unsupported board: led0 devicetree alias is not defined
Unsupported board: led1 devicetree alias is not defined
```

<a id="building"></a>

## 2.3\_构建

例如，为[96Boards Carbon](https://docs.zephyrproject.org/latest/boards/96boards/carbon/doc/stm32f401xe.html#b-carbon-board)构建：

```shell
west build -b 96b_carbon/stm32f401xe samples/basic/threads
west flash
```

其他受支持开发板应相应替换`96b_carbon/stm32f401xe`。
