# 第32章\_最小堆示例

原文：[官方页面](https://docs.zephyrproject.org/latest/samples/data_structures/min-heap/README.html)。读取日期：2026-10-14；保存的latest页面及HTML摘要见[来源记录](../SOURCES.md)。

<a id="overview"></a>

## 32.1 概述（Overview）

本示例展示在Zephyr应用中，把最小堆数据结构（Min-Heap Data Structure）实现用作优先队列（Priority Queue）。

示例介绍插入（Insert）、删除（Remove）、弹出（Pop）和判空（Empty Check）等基本堆操作。

<a id="building-and-running"></a>

## 32.2 构建与运行（Building and Running）

要在受支持的开发板上构建和运行本示例：

```sh
west build -b <your_board> samples/data_structures/min_heap
west flash
```

将`<your_board>`替换为实际板名称，例如`native_sim`。

> 译注——原命令路径纠正：官方源码目录是`samples/data_structures/min-heap`，原命令却写成了`min_heap`。应使用连字符目录；`<your_board>`也必须替换。下面给出native_sim分支的更正，在具备依赖的Linux Bash、Zephyr源码根目录执行；先构建成功，再运行。模拟器使用`run`目标，不执行原文面向实板的`west flash`。

```sh
# 终端：Linux Bash；目录：Zephyr源码根目录；前提：native\_sim主机依赖已准备好
west build -b native_sim samples/data_structures/min-heap
west build -t run
```

<a id="sample-output"></a>

## 32.3 示例输出（Sample Output）

启动后，示例应用执行一系列堆操作并打印结果，预期输出类似如下：

```text
*** Booting Zephyr OS build 9c0c063db09d ***
Min-heap sample using static storage
Heap elements by order of priority:
key=2 value=400
key=5 value=200
key=30 value=300
key=10 value=100
Top of heap: key=2 value=400
Found element with key 5 at index 1,removing it...
Heap after removal:
key=2 value=400
key=10 value=100
key=30 value=300
```

> 译注——堆遍历不是全序排序：原日志写“按优先级顺序”，但`MIN_HEAP_FOREACH`实际上按底层存储下标遍历，可能显示`2, 5, 30, 10`。最小堆保证堆顶最小，不保证整个数组递增。当前示例调用push、peek、find和remove，概述提及的pop及判空不应理解成这份`main.c`已逐项演示。
