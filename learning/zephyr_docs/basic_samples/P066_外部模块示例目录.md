# 第66章\_外部模块示例目录

原文：[官方页面](https://docs.zephyrproject.org/latest/samples/modules/index.html)。读取日期：2026-10-14；保存的latest页面及HTML摘要见[来源记录](../SOURCES.md)。

这些示例演示Zephyr中外部模块（External modules）的用法。

- [Nanopb](../serialization/P005_Nanopb示例.md#nanopb)：使用nanopb模块序列化（Serialize）与反序列化（Deserialize）结构化数据。

<a id="cmsis_dsp"></a>

## 66.1 CMSIS-DSP（CMSIS-DSP）

模块目录：[CMSIS-DSP](../dsp/P002_CMSISDSP示例目录.md)。

- [CMSIS-DSP移动平均（CMSIS-DSP moving average）](../dsp/P003_CMSISDSP移动平均示例.md#cmsis-dsp-moving-average)：使用CMSIS-DSP库计算信号的移动平均值。

<a id="lvgl"></a>

## 66.2 LVGL（LVGL）

模块目录：[LVGL](P067_LVGL示例目录.md)。

- [LVGL演示合集（LVGL demos）](P069_LVGL演示合集.md#lvgl-demos)：运行LVGL内置演示。
- [LVGL加速度数据折线图（LVGL line chart with accelerometer data）](P068_LVGL加速度曲线示例.md#lvgl-accelerometer-chart)：通过LVGL实时图表显示加速度数据。
- [LVGL多显示器（LVGL Multi-display）](P070_LVGL多显示器示例.md#lvgl-multi-display)：在多块显示器上运行不同的LVGL演示。
- [LVGL屏幕透明度（LVGL screen transparency）](P071_LVGL屏幕透明度示例.md#lvgl-screen-transparency)：使用LVGL向支持透明度的屏幕渲染。

<a id="tflite-micro"></a>

## 66.3 微控制器版TensorFlow Lite（TensorFlow Lite for Microcontrollers）

模块目录：[TensorFlow Lite for Microcontrollers](P072_TensorFlowLiteMicro示例目录.md)。

- [问候示例（Hello World）](P073_TensorFlowLiteMicro问候示例.md#tflite-hello-world)：使用微控制器版TensorFlow Lite（TensorFlow Lite for Microcontrollers）拟合正弦波。
- [魔杖（Magic Wand）](P074_TensorFlowLiteMicro魔杖示例.md#tflite-magicwand)：使用微控制器版TensorFlow Lite及20KB神经网络，根据加速度计数据识别手势。
- [Arm(R) Ethos(TM)-U55、U65与U85神经网络处理器上的TensorFlow Lite for Microcontrollers（TensorFlow Lite for Microcontrollers on Arm(R) Ethos(TM)-U55, U65, and U85 NPUs）](P075_TensorFlowLiteMicro与EthosU示例.md#tflite-ethosu)：在Arm Ethos-U神经网络处理器（NPU）上，使用优化后的TFLite模型执行推理。


对应官方文档源码：[samples/modules/index.rst](https://raw.githubusercontent.com/zephyrproject-rtos/zephyr/main/samples/modules/index.rst)。
