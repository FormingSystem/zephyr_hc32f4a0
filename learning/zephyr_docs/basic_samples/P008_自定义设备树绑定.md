## 8.1\_概述

在Zephyr中，所有与硬件有关的配置都在设备树（Devicetree）中描述。因此，GPIO引脚也在设备树中配置，并通过兼容标识符（Compatible）指定其用途。

这与Arduino等其他嵌入式环境不同；在那些环境中，GPIO引脚的输入／输出方向等属性在应用固件中配置。

对于LED、按钮等典型用途，可使用已有的[`gpio-leds`](https://docs.zephyrproject.org/latest/build/dts/api/bindings/led/gpio-leds.html#std-dtcompatible-gpio-leds)或[`gpio-keys`](https://docs.zephyrproject.org/latest/build/dts/api/bindings/input/gpio-keys.html#std-dtcompatible-gpio-keys)兼容标识符。

本示例展示如何通过自定义设备树绑定（Custom Devicetree Binding），将GPIO引脚用于其他目的。

假设需要通过金属氧化物半导体场效应晶体管（Metal-Oxide-Semiconductor Field-Effect Transistor，MOSFET）接通或切断一个大电流负载。GPIO控制的电源输出所使用的自定义设备树绑定定义在[samples/basic/custom_dts_binding/dts/bindings/power-switch.yaml](https://github.com/zephyrproject-rtos/zephyr/blob/main/samples/basic/custom_dts_binding/dts/bindings/power-switch.yaml)中。MOSFET的栅极驱动器应连接到`boards`文件夹中`.overlay`文件指定的引脚。

<a id="building-and-running"></a>

## 8.2\_构建与运行

对每个需要支持的开发板，都必须在`boards`子文件夹中定义一个`.overlay`文件。随后可按下列方式为`<board>`构建并执行示例：

```shell
west build -b <board> samples/basic/custom_dts_binding
west flash
```

出于演示目的，部分开发板使用板载LED的GPIO引脚。

在[原生模拟器native_sim（Native simulator）](../native_reference/P004_Native_Simulator本机模拟器.md#native_sim)上，该引脚由模拟GPIO控制器提供，因此无需硬件即可运行。

<a id="sample-output"></a>

### 示例输出（Sample output）

GPIO引脚应在一秒后切换到有效电平（Active Level）。打印输出如下：

```text
Initializing pin with inactive level.
Waiting one second.
Setting pin to active level.
```
