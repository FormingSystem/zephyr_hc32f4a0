# 第44章\_实时IO示例目录

原文：[官方页面](https://docs.zephyrproject.org/latest/samples/subsys/rtio/rtio.html)。读取日期：2026-10-14；保存的latest页面及HTML摘要见[来源记录](../SOURCES.md)。

本组示例展示[实时输入／输出（Real Time I/O，RTIO）](../io_services/P001_实时输入输出.md#rtio)子系统。

- [生产者／消费者（Producer Consumer）](P045_实时IO生产者消费者示例.md#producer_consumer)：使用RTIO实现从生产者到消费者的管道（Producer-to-consumer Pipe）。
