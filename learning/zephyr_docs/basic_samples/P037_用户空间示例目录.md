# 第37章\_用户空间示例目录

原文：[官方页面](https://docs.zephyrproject.org/latest/samples/userspace/index.html)。读取日期：2026-10-14；保存的latest页面及HTML摘要见[来源记录](../SOURCES.md)。

本组示例展示如何在[用户模式（User Mode）](../kernel/P038_用户模式入口.md#usermode-api)下运行代码。

- [问候示例（Hello World）](P038_用户模式问候示例.md#helloworld_user)：从用户空间（Userspace）打印一条简单的“Hello World”消息。
- [生产者／消费者（Producer/consumer）](P039_用户空间生产者消费者示例.md#userspace_prod_consumer)：演示用户模式的基本概念与操作。
- [系统调用性能（Syscall performance）](P041_系统调用性能示例.md#syscall_perf)：测量系统调用相对于直接函数调用的性能开销。
- [用户空间受保护内存（Userspace Protected Memory）](P040_用户空间受保护内存示例.md#userspace_protected_memory)：使用内存分区（Memory Partitioning）在线程之间保护内存。


对应官方文档源码：[samples/userspace/index.rst](https://raw.githubusercontent.com/zephyrproject-rtos/zephyr/main/samples/userspace/index.rst)。
