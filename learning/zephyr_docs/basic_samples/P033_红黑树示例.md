# 第33章\_红黑树示例

原文：[官方页面](https://docs.zephyrproject.org/latest/samples/data_structures/rbtree/README.html)。读取日期：2026-10-14；保存的latest页面及HTML摘要见[来源记录](../SOURCES.md)。

<a id="overview"></a>

## 33.1 概述（Overview）

本示例展示如何在Zephyr应用中使用红黑树（Red-Black Tree，rbtree）数据结构。

示例展示插入（Insert）、删除（Remove）和遍历（Foreach）等基本红黑树操作。

<a id="building-and-running"></a>

## 33.2 构建与运行（Building and Running）

要在受支持的开发板上构建并运行本示例：

```sh
west build -b <your_board> samples/data_structures/rbtree
west flash
```

将`<your_board>`替换为实际板名称，例如`native_sim`。

> 译注——运行分支：实际板使用其工具链和烧录工具，在UCRT64 Bash或Linux Bash的Zephyr源码根目录构建，成功后再烧录；`native_sim`则需要合适的Linux主机环境，构建成功后用`west build -t run`运行，不能套用实板烧录步骤。构建失败先处理错误，不继续使用旧固件。

<a id="sample-output"></a>

## 33.3 示例输出（Sample Output）

启动后，应用执行一系列红黑树操作并打印结果，预期输出类似如下：

```text
*** Booting Zephyr OS build gd2a5c1ca82f0 ***
insert n=1 rb=0x105004
insert n=3 rb=0x105010
insert n=2 rb=0x10501c
insert n=5 rb=0x105028
insert n=4 rb=0x105034
max=1 min=5
rbtree elements:
n=5
n=4
n=3
n=2
n=1
removed max=1
removed min=5
rbtree after removal:
n=4
n=3
n=2
Done
```

> 译注——比较函数与旧日志：原日志为`max=1 min=5`，遍历从5降到1；当前官方示例的`user_data_lessthan_func()`却返回`n1->n < n2->n`。按当前树接口的最小／最大语义，应对应`min=1`、`max=5`及升序遍历。这里保留原日志，明确它与当前源码的比较规则不一致；实际节点地址也随链接和运行环境变化。
