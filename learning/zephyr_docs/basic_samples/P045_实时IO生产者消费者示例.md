<a id="overview"></a>

## 45.1 概述（Overview）

这是一个可以在任意[受支持开发板](https://docs.zephyrproject.org/latest/boards/index.html#boards)上使用的简单示例，展示通过实时输入／输出（Real Time I/O，RTIO）实现生产者／消费者模式（Producer and Consumer Pattern）。在本例中，生产者是一个`k_timer`，生成精确到周期的时间戳，用来记录定时器回调在中断服务程序（Interrupt Service Routine，ISR）中运行的时刻。

<a id="building-and-running"></a>

## 45.2 构建与运行（Building and Running）

可以按以下方式为`native_sim`目标构建并运行本示例：

> 译注——命令前提：在已经准备Zephyr开发依赖和native_sim构建依赖的Linux Bash环境中，以Zephyr源码根目录为当前目录执行。构建成功后再运行，出现控制台输出表示进入示例；构建失败时先处理错误，避免运行旧产物。本文保留官方输出，未实际执行构建或模拟运行。

```sh
west build -b native_sim samples/subsys/rtio/producer_consumer
west build -t run
```

运行时，控制台输出展示数据请求的提交（Submit）、数据的消费（Consume）和处理（Process）操作。

> 译注——时间戳含义：当前定时器回调通过`k_cycle_get_64()`读取周期计数。它记录的是回调实际执行时刻，不是定时器的理想到期时刻，也不是协调世界时（Coordinated Universal Time，UTC）或日历时间。消费者准备带`RTIO_SQE_MULTISHOT`标志的读取请求，使同一请求能够连续产生完成事件；此例的`main()`没有实际进入用户模式，源码中相应调用仅作为注释示意。
