<a id="overview"></a>

## 38.1 概述（Overview）

这是一个简单的问候示例（Hello World），可用于任意受支持的开发板，在控制台打印`Hello World from UserSpace!`。如果用户空间不可用或尚未配置，则改为打印`Hello World from privileged mode.`。

该应用可以构建为以下模式：

- 单线程（Single Thread）。
- 多线程（Multi Threading）。

> 译注——网页与源码版本差异：以上是官方页面原有说明。当前核对的官方`src/main.c`在未启用`CONFIG_USERSPACE`时通过`#error`拒绝编译，并创建带`K_USER`标志的线程，在线程中断言正在用户模式执行。因此，不能把页面中的特权模式回退和单线程描述当作当前源码已支持的构建方式。阅读或复现实验时，应对照实际使用版本的源码与配置。

<a id="building-and-running"></a>

## 38.2 构建与运行（Building and Running）

本工程向控制台输出`Hello World from UserSpace!`。可以按以下方式在QEMU中构建和执行：

> 译注——命令前提：先按所用Zephyr版本准备Python依赖、对应目标工具链和QEMU，并确认当前终端可以调用west。在UCRT64 Bash或Linux Bash中，以Zephyr源码根目录为当前目录执行；只有构建成功后才执行运行命令。若构建失败，先处理构建错误；若QEMU启动失败，检查该版本的模拟器和目标配置。下面的日志是官方示例输出，本文未执行构建或模拟运行。

```sh
west build -b qemu_riscv32 samples/userspace/hello_world_user
west build -t run
```
