<a id="overview"></a>

## 11.1\_概述

这是一个简单示例，可用于任意[受支持开发板](https://docs.zephyrproject.org/latest/boards/index.html#boards)，向控制台打印系统堆（System Heap）的使用情况。

<a id="building"></a>

## 11.2\_构建

可为[native_sim](../native_reference/P004_Native_Simulator本机模拟器.md#native_sim)构建该应用：

```shell
west build -b native_sim samples/basic/sys_heap
```

为其他开发板构建时，将上述`native_sim`替换为对应开发板名称。

<a id="running"></a>

## 11.3\_运行

运行`build/zephyr/zephyr.exe`。
