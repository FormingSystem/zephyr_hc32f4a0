# 第23章\_条件变量等待示例

原文：[官方页面](https://docs.zephyrproject.org/latest/samples/kernel/condition_variables/simple/README.html)。读取日期：2026-10-14；保存的latest页面及HTML摘要见[来源记录](../SOURCES.md)。

<a id="overview"></a>

## 23.1 概述（Overview）

本示例展示多线程应用中条件变量（Condition Variable）的用法。条件变量与互斥锁（Mutex）配合使用，把工作线程中状态或条件的变化通知给主线程。主线程通过条件变量等待某个条件成立。工作线程向正在条件变量上等待的主线程发送通知后，主线程和工作线程根据通知时机交替执行。

本示例可用于任意[受支持的开发板](https://docs.zephyrproject.org/latest/boards/index.html#boards)，并在控制台打印下面所示的输出。

> 译注——等待的是状态：当前实现创建20个工作线程，每个线程完成5轮工作后，在持有互斥锁时递增`done`并调用`k_condvar_signal()`。主线程在`while (done < NUM_THREADS)`中调用`k_condvar_wait()`，等待时释放互斥锁，返回前重新获得锁，再次检查条件。信号本身不是“所有工作都已完成”的计数，不能用一次唤醒替代循环检查。

<a id="building-and-running"></a>

## 23.2 构建与运行（Building and Running）

可以按以下方式在[原生模拟器（native_sim）](../native_reference/P004_Native_Simulator本机模拟器.md#native_sim)上构建并执行：

> 译注——命令环境：在具备native_sim主机依赖的Linux Bash中，从Zephyr源码根目录执行。先确认构建成功，再运行；失败时检查主机依赖和目标配置。Windows读者需使用适合native_sim的Linux环境，不能仅把终端名字换成PowerShell就认为可原生运行。

```sh
west build -b native_sim samples/kernel/condition_variables/simple
west build -t run
```

要为另一块开发板构建，把上面的[`native_sim`](../native_reference/P004_Native_Simulator本机模拟器.md#native_sim)替换为该板名称。
