# 第72章\_TensorFlowLiteMicro示例目录

原文：[官方页面](https://docs.zephyrproject.org/latest/samples/modules/tflite-micro/tflite-micro.html)。读取日期：2026-10-14；保存的latest页面及HTML摘要见[来源记录](../SOURCES.md)。

这些示例演示如何在Zephyr中使用微控制器版TensorFlow Lite（TensorFlow Lite for Microcontrollers）。

- [问候示例（Hello World）](P073_TensorFlowLiteMicro问候示例.md#tflite-hello-world)：使用微控制器版TensorFlow Lite（TensorFlow Lite for Microcontrollers）拟合正弦波。
- [魔杖（Magic Wand）](P074_TensorFlowLiteMicro魔杖示例.md#tflite-magicwand)：使用微控制器版TensorFlow Lite及20KB神经网络，根据加速度计数据识别手势。
- [Arm(R) Ethos(TM)-U55、U65与U85神经网络处理器上的TensorFlow Lite for Microcontrollers（TensorFlow Lite for Microcontrollers on Arm(R) Ethos(TM)-U55, U65, and U85 NPUs）](P075_TensorFlowLiteMicro与EthosU示例.md#tflite-ethosu)：在Arm Ethos-U神经网络处理器（NPU）上，使用优化后的TFLite模型执行推理。


对应官方文档源码：[samples/modules/tflite-micro/tflite-micro.rst](https://raw.githubusercontent.com/zephyrproject-rtos/zephyr/main/samples/modules/tflite-micro/tflite-micro.rst)。
