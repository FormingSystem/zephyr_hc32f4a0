## 3.1\_概述

这是一个简单的按钮演示，展示如何通过[输入API（Input APIs）](https://docs.zephyrproject.org/latest/services/input/index.html#input)使用按钮。每次按下按钮，示例都会向控制台打印一条消息。

<a id="requirements"></a>

## 3.2\_要求

开发板硬件必须有一个能够产生输入`KEY`事件的设备节点（Device Node）。通常是通过GPIO引脚连接的按钮，并定义在`gpio-keys`节点中。在许多Zephyr[支持的开发板和扩展板](https://docs.zephyrproject.org/latest/boards/index.html#boards)上，这些按钮称为“用户按钮”（User Buttons）。

示例还支持可选的`led0`设备树别名（Devicetree Alias）。如果提供此别名，按下按钮时LED点亮，松开时LED熄灭。

<a id="building-and-running"></a>

## 3.3\_构建与运行

该示例可为多种开发板构建。下面以`nucleo_f103rb`为例：

```shell
west build -b nucleo_f103rb samples/basic/button
```
