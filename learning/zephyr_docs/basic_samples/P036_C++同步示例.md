# 第36章\_C++同步示例

原文：[官方页面](https://docs.zephyrproject.org/latest/samples/cpp/cpp_synchronization/README.html)。读取日期：2026-10-14；保存的latest页面及HTML摘要见[来源记录](../SOURCES.md)。

<a id="overview"></a>

## 36.1 概述（Overview）

本示例展示纯虚类（Pure Virtual Class）、具有不同参数类型的成员函数（Member Function），以及全局对象构造函数（Global Object Constructor）的调用。

这个简单应用展示内核基本功能是否正常。主线程和一个协作式线程（Cooperative Thread）轮流向控制台打印问候消息，使用定时器（Timer）和信号量（Semaphore）控制消息产生的速率，从而展示内核调度、通信和计时的正常运作。

> 译注——封装与内核对象：这里的“纯虚类”是具有纯虚成员函数的抽象接口类；当前`cpp_semaphore`派生类在全局对象构造时调用`k_sem_init()`，在成员函数中调用Zephyr信号量接口。它展示的是C++对内核同步对象的封装，不是通过C++标准线程库另建一套调度器。

<a id="building-and-running"></a>

## 36.2 构建与运行（Building and Running）

这个内核示例向控制台输出，可以按以下方式在QEMU上构建并执行：

> 译注——命令环境：在UCRT64 Bash或Linux Bash的Zephyr源码根目录执行，先准备命令中QEMU目标的工具链、模块和模拟器。构建成功后再运行；失败时先检查对应目标与依赖，不把下面的原文输出当作本次执行记录。

```sh
west build -b qemu_x86 samples/cpp/cpp_synchronization
west build -t run
```
