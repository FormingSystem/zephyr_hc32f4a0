# 第12章\_应用开发示例目录

原文：[官方页面](https://docs.zephyrproject.org/latest/samples/application_development/application_development.html)。读取日期：2026-10-14；保存的latest页面及HTML摘要见[来源记录](../SOURCES.md)。

这些示例展示一些有用的应用开发模式与技巧。

- [不复制代码重定位（Code relocation nocopy）](P013_不复制代码重定位示例.md#code_relocation_nocopy)：使用自定义链接器脚本（Linker Script）重定位代码、数据或BSS段。
- [外部库（External Library）](P014_外部库示例.md#external_library)：将外部静态库集成到Zephyr构建系统中。

进行应用开发时，还应参考[官方示例应用仓库（example-application）](https://github.com/zephyrproject-rtos/example-application)，其中包括树外驱动与开发板等示例。


对应官方文档源码：[samples/application_development/application_development.rst](https://raw.githubusercontent.com/zephyrproject-rtos/zephyr/main/samples/application_development/application_development.rst)。

> 译注——源码跟踪：本仓库的[对应源码](../../../samples/application_development/application_development.rst)可用于对照，版本可能与网页不同。源码跟踪和实现依据不绑定作者机器目录；项目环境与实验路线另见[项目实验补充](../../zephyr_project_notes/README.md)。
