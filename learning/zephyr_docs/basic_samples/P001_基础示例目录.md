# 第1章\_基础示例目录

原文：[官方页面](https://docs.zephyrproject.org/latest/samples/basic/basic.html)。本次读取日期：2026-10-14；基线为保存的`latest`页面，HTML摘要见[来源记录](../SOURCES.md)。

<a id="basic"></a>

这些示例演示Zephyr内核的基本功能。

| 示例 | 说明 |
| --- | --- |
| [基本线程操作（Basic thread manipulation）](P002_基本线程操作.md#multi-thread-blinky) | 创建多个线程，使LED闪烁并向控制台打印信息。 |
| [Blinky](https://docs.zephyrproject.org/latest/samples/basic/blinky/README.html#blinky) | 使用GPIO API持续闪烁LED。 |
| [按钮（Button）](P003_按钮输入.md#button) | 使用输入子系统（Input Subsystem）处理GPIO按钮输入。 |
| [LED渐变（Fade LED）](P005_LED渐变.md#fade-led) | 使用PWM API使LED亮度渐变。 |
| [使用自定义设备树绑定的GPIO（GPIO with custom Devicetree binding）](P008_自定义设备树绑定.md#gpio-custom-dts-binding) | 使用自定义设备树绑定控制GPIO。 |
| [最小占用（Minimal footprint）](P010_最小应用.md#minimal) | 测量不同配置下Zephyr的最小ROM占用。 |
| [PWM闪烁LED（PWM Blinky）](P004_PWM闪烁LED.md#pwm-blinky) | 使用PWM API闪烁LED。 |
| [PWM RGB LED](P006_RGB_LED.md#rgb-led) | 使用PWM API驱动RGB LED。 |
| [舵机（Servomotor）](P007_舵机控制.md#servo-motor) | 使用PWM API驱动舵机。 |
| [系统哈希映射（System hashmap）](P009_哈希映射.md#system_hashmap) | 在哈希映射中插入、替换和删除条目。 |
| [系统堆（System heap）](P011_系统堆.md#sys-heap) | 向控制台打印系统堆的使用情况。 |
