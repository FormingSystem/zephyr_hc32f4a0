# 第14章\_外部库示例

原文：[官方页面](https://docs.zephyrproject.org/latest/samples/application_development/external_lib/README.html)。读取日期：2026-10-14；保存的latest页面及HTML摘要见[来源记录](../SOURCES.md)。

<a id="overview"></a>

## 14.1 概述（Overview）

这是一个将外部静态库（External Static Library）集成到Zephyr构建系统的简单示例。

本示例同时展示如何使用另一套构建系统编译外部库，以及如何把已经构建好的静态库纳入Zephyr应用。

> 译注——“外部”的含义：本例的库源码已经随官方示例放在`mylib`目录，不需要另行下载。[CMakeLists.txt](../../../samples/application_development/external_lib/CMakeLists.txt)通过`ExternalProject_Add`调用该库的[Makefile](../../../samples/application_development/external_lib/mylib/Makefile)，传入Zephyr所用编译器、归档器及编译选项，再用导入静态库目标（Imported Static Library Target）把`libmylib.a`链接到应用。“外部”指构建方式独立，不代表使用主机编译器生成的任意库都能直接用于目标芯片。

<a id="windows-note"></a>

## 14.2 Windows说明（Windows Note）

在Windows主机上使用此示例，需要让GNU Make位于`PATH`中。可以通过Chocolatey安装，也可以手动安装。

<a id="manual-install-method"></a>

### 14.2.2 手动安装方式（Manual Install Method）

可从[GNUWin32 Make下载页](https://gnuwin32.sourceforge.net/packages/make.htm)获取预编译的Make程序。可以同时下载Binaries（二进制文件）和Dependencies（依赖项），并解压到同一个文件夹；也可以下载Complete package（完整安装包）。安装完成并加入`PATH`后，按通常方式构建应用。

> 译注——适用范围：上面保留官方页面列出的下载渠道；该页面没有固定主机工具版本，也未给出完整应用构建命令。构建入口与目标板选择见[应用开发](../application/P001_应用开发.md)。Make是本例外部库的构建依赖，即使Zephyr主构建使用Ninja，也不能据此忽略该依赖。
