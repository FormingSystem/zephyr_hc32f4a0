# 第19章\_多核圆周率计算示例

原文：[官方页面](https://docs.zephyrproject.org/latest/samples/arch/smp/pi/README.html)。读取日期：2026-10-14；保存的latest页面及HTML摘要见[来源记录](../SOURCES.md)。

<a id="overview"></a>

## 19.1 概述（Overview）

此示例应用在多个线程中分别独立计算圆周率（Pi），展示当计算密集型任务可以并行运行、没有相互依赖或共享资源时，多个执行单元（CPU核心）带来的收益。

在对称多处理（Symmetric Multiprocessing，SMP）系统上改变`CONFIG_MP_MAX_NUM_CPUS`的值，可以观察到：使用更多核心时，完成计算任务所需的时间几乎按反比缩短。

还可以编辑示例源码，修改计算位数`DIGITS_NUM`和使用的线程数`THREADS_NUM`。

> 译注——并行的单位：每个工作线程独立计算完整的指定精度Pi，不是把同一次Pi计算拆成不同位数交给不同核心。当前源码使用16个线程、240位，计算位数要求是4的倍数；结果缓冲区按线程分开，结束通知仍使用原子计数和信号量。“几乎线性”的表述是原文对该工作负载的描述，不能保证任意平台、核心数和负载都有相同加速比。

<a id="building-and-running"></a>

## 19.2 构建与运行（Building and Running）

项目输出每个线程计算得到的Pi值，最后输出完成全部计算所需的总时间。原文说明可在Synopsys ARC HSDK开发板上按以下方式构建并执行：

> 译注——原文目标不一致：上述文字写的是Synopsys ARC HSDK，但紧接的实际命令指定`qemu_x86_64`，两者不是同一个目标。下面完整保留原命令；它应按QEMU目标准备工具链和模拟器，在UCRT64 Bash或Linux Bash的Zephyr源码根目录执行。构建成功后再运行；失败时先检查对应目标及依赖，不把板名与命令混用。

```sh
west build -b qemu_x86_64 samples/arch/smp/pi
west build -t run
```

> 译注——计时：当前源码在创建工作线程前开始计时，在等到完成信号量后停止计时，随后才打印各线程的Pi字符串。因此该时间包括线程创建与完成同步，不只是算术循环；原日志的28 ms不是本次测量或其他目标的性能承诺。
