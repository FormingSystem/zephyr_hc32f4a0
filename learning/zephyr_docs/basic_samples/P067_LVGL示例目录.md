# 第67章\_LVGL示例目录

原文：[官方页面](https://docs.zephyrproject.org/latest/samples/modules/lvgl/lvgl.html)。读取日期：2026-10-14；保存的latest页面及HTML摘要见[来源记录](../SOURCES.md)。

这些示例演示如何在Zephyr中使用LVGL构建图形用户界面（Graphical user interface，GUI）。

- [LVGL演示合集（LVGL demos）](P069_LVGL演示合集.md#lvgl-demos)：运行LVGL内置演示。
- [LVGL加速度数据折线图（LVGL line chart with accelerometer data）](P068_LVGL加速度曲线示例.md#lvgl-accelerometer-chart)：通过LVGL实时图表显示加速度数据。
- [LVGL多显示器（LVGL Multi-display）](P070_LVGL多显示器示例.md#lvgl-multi-display)：在多块显示器上运行不同的LVGL演示。
- [LVGL屏幕透明度（LVGL screen transparency）](P071_LVGL屏幕透明度示例.md#lvgl-screen-transparency)：使用LVGL向支持透明度的屏幕渲染。


对应官方文档源码：[samples/modules/lvgl/lvgl.rst](https://raw.githubusercontent.com/zephyrproject-rtos/zephyr/main/samples/modules/lvgl/lvgl.rst)。
