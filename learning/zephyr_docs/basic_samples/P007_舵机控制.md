<a id="servo-motor"></a>
<a id="overview"></a>

## 7.1\_概述

本示例使用[脉宽调制（Pulse Width Modulation，PWM）API](https://docs.zephyrproject.org/latest/hardware/peripherals/pwm.html#pwm-api)驱动舵机（Servomotor），通过PWM控制信号让舵机在180度范围内往复转动。

本应用面向ROB-09065舵机。原文说明，0至180度分别对应700至2300微秒的PWM脉宽。不同舵机可能需要不同的PWM脉宽，使用其他舵机时可能需要修改源码。

<a id="requirements"></a>

## 7.2\_要求

需要一台舵机，其信号引脚连接到由PWM驱动的引脚。必须在设备树（Devicetree）中使用本示例提供的`pwm-servo`兼容标识符（Compatible）定义舵机，并将节点标签（Node Label）设置为`servo`。配置形式如下：

```dts
/ {
    servo: servo {
        compatible = "pwm-servo";
        pwms = <&pwm0 1 PWM_MSEC(20) PWM_POLARITY_NORMAL>;
        min-pulse = <PWM_USEC(700)>;
        max-pulse = <PWM_USEC(2500)>;
    };
};
```

常用周期值为20 ms，可参考[samples/basic/servo_motor/boards/bbc_microbit.overlay](https://github.com/zephyrproject-rtos/zephyr/blob/main/samples/basic/servo_motor/boards/bbc_microbit.overlay)。

> 译注：原文概述中的最大脉宽是2300 µs，而上述代码的`max-pulse`为2500 µs。两处原值均保留；使用时应依据具体舵机的规格确定行程对应的脉宽，不能将两者视为同一参数值。

<a id="wiring"></a>

## 7.3\_接线

<a id="bbc-micro-bit"></a>

### BBC micro:bit

将舵机红线连接到外部5 V电源，黑线接地，白线连接SCL引脚，即边缘连接器上的P19。

<a id="building-and-running"></a>

## 7.4\_构建与运行

本示例提供用于micro:bit的设备树覆盖文件（Devicetree Overlay）。它可以为多种开发板构建，下面以[bbc_microbit](https://docs.zephyrproject.org/latest/boards/bbc/microbit/doc/index.html#bbc_microbit)为例：

```shell
west build -b bbc_microbit samples/basic/servo_motor
west flash
```
