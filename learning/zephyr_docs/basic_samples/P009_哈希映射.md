## 9.1\_概述

这是一个简单的哈希映射（Hashmap）示例，反复执行以下操作：

- 插入条目，最多达到`CONFIG_TEST_LIB_HASH_MAP_MAX_ENTRIES`个。
- 替换条目，最多替换此前插入的相同数量。
- 移除所有此前插入的键（Key）。

> 译注——接口与源码：通用API、运行结构、三种实现、哈希函数及六份头文件源码见[哈希映射参考册](../hashmap_reference/大纲.md)。键和值均为uint64_t；内部条目释放不等于自动释放它们编码的外部对象。insert声明返回0表示替换、1表示新增，负数表示失败；当前后端的替换、容量限制与失败路径差异在对应参考页单独说明。

> 译注——配置与遍历：哈希表实现和32位哈希函数分别由SYS_HASH_MAP_CHOICE、SYS_HASH_FUNC32_CHOICE选择。STATIC声明不代表操作期间不分配内存；foreach也不提供并发保护或排序保证。这里保留的是官方示例及输出，不能把示例中的success当作本次已编译、运行或覆盖了所有异常分支。

<a id="building"></a>

## 9.2\_构建

可为[native_sim](../native_reference/P004_Native_Simulator本机模拟器.md#native_sim)构建该应用：

```shell
west build -b native_sim samples/basic/hash_map
```

为其他开发板构建时，将上述`native_sim`改为对应开发板名称。

也可指定下列配置，选用其他哈希映射实现：

- `CONFIG_SYS_HASH_MAP_CHOICE_SC=y`：分离链接法（Separate Chaining）。
- `CONFIG_SYS_HASH_MAP_CHOICE_OA_LP=y`：开放寻址／线性探测（Open Addressing / Linear Probe）。
- `CONFIG_SYS_HASH_MAP_CHOICE_CXX=y`：对C++ `std::unordered_map`的C语言封装（C Wrapper）。

调整`CONFIG_TEST_LIB_HASH_MAP_MAX_ENTRIES`，可以对哈希映射实现施加压力。

<a id="running"></a>

## 9.3\_运行

运行`build/zephyr/zephyr.exe`。
