# 日志核心与实例头文件参考大纲

本册翻译日志核心（Logging Core）与日志实例（Logging Instance）两个头文件的参考和源码，共四份官方页面。公共日志调用的完整说明见[日志公共接口与控制参考](../log_core_reference/大纲.md)。

核心头文件展示级别过滤、日志消息创建、最小日志、十六进制转储及源编号计算；实例头文件展示独立过滤对象的声明、注册和指针初始化。源码页保留全部可见代码、注释、许可证、符号提示和原始行号锚点，中文对照另列。

源码跟踪译注独立说明过滤条件、参数检查、链接段编号、实例指针类型与关闭日志后的占位字段。原始注释与源码不同之处明确标注。完整覆盖状态见[全站进度](../PROGRESS.md)。
