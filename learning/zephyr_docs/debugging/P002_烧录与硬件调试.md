# 第2章\_烧录与硬件调试

原文：[Flashing and Hardware Debugging](https://docs.zephyrproject.org/latest/develop/flash_debug/index.html)。读取日期：2026-10-12，`latest`。

## 2.1\_官方文档分类

- [烧录与调试主机工具（Flash & Debug Host Tools）](P004_烧录与调试主机工具.md)。
- [调试探针（Debug Probes）](P003_调试探针.md)。

> 译注：主机工具是开发电脑上运行的软件；调试探针是连接开发电脑与目标板的硬件。**烧录（Flashing）**负责把镜像写入目标存储器，**硬件调试（Hardware Debugging）**负责控制目标执行并观察状态。本页原文仅为上述两个分支的导航入口。
