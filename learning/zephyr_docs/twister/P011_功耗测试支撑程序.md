# 第11章\_功耗测试支撑程序

原文：[Power](https://docs.zephyrproject.org/latest/develop/twister/harness/power.html)。读取日期：2026-10-12，`latest`。

`power` **测试支撑程序（Harness）**测量并验证电流消耗，与 pytest 集成，通过硬件功耗监测设备自动收集、分析数据。

## 11.1\_测量流程

1. 通过 `PowerMonitor` 抽象接口初始化监测设备，例如 `stm_powershield`。
2. 按 `measurement_duration` 指定的时间开始电流测量。
3. 收集原始电流波形。
4. 通过**峰值检测（Peak Detection）**识别功耗转换，将数据划分成执行阶段。
5. 为每个阶段计算电流的**均方根（Root Mean Square，RMS）**值。
6. 将各阶段结果与用户定义的预期 RMS 值比较。

> 译注：虽然机制名为功耗测试，本页列出的直接测量和判定量是电流，不能未经电压等条件换算就当作功率数值。RMS 表示平方取均值后再开方的有效值。

## 11.2\_配置与单位

以下 **YAML（YAML Ain't Markup Language，配置数据格式）**选择支撑程序、声明 `pm_probe` 硬件测试装置，并在 `power_measurements` 中设置测量参数：

```yaml
harness: power
harness_config:
  fixture: pm_probe
  power_measurements:
    elements_to_trim: 100
    min_peak_distance: 40
    min_peak_height: 0.008
    peak_padding: 40
    measurement_duration: 6
    num_of_transitions: 4
    expected_rms_values: [56.0, 4.0, 1.2, 0.26, 140]
    tolerance_percentage: 20
```

| 字段 | 解释 |
| --- | --- |
| `elements_to_trim` | 丢弃测量开始的多少个采样点，以去除初期噪声。 |
| `min_peak_distance` | 检测到的电流峰之间的最小间距，用于区分独立转换。 |
| `min_peak_height` | 认定峰值的最低电流阈值，单位为安培。 |
| `peak_padding` | 在每个峰周围扩展的采样点数。 |
| `measurement_duration` | 记录电流数据的总时间，单位为秒。 |
| `num_of_transitions` | **被测设备（Device Under Test，DUT）**执行期间预期发生的功耗状态转换次数。 |
| `expected_rms_values` | 各识别阶段的目标 RMS 电流，单位为毫安。 |
| `tolerance_percentage` | 相对预期 RMS 值所允许的百分比偏差。 |

> 译注：示例的峰值阈值用安培，而预期阶段电流用毫安，二者相差千倍，填值时应按字段单位分别换算。监测设备、供电接线和 `pm_probe` 装置需实际就绪，译文没有创建或测量该硬件环境。
