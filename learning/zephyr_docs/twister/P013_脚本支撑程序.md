# 第13章\_脚本支撑程序

原文：[Script](https://docs.zephyrproject.org/latest/develop/twister/harness/script.html)。读取日期：2026-10-12，`latest`。

`script` **测试支撑程序（Script Harness）**将 Shell 脚本作为测试用例。它从 `tests_scripts` 配置解析脚本，逐一作为**子进程（Subprocess）**执行，并根据各脚本的**退出码（Exit Code）**分别报告通过或失败。

它也是 [BabbleSim](P014_BabbleSim支撑程序.md)、[Pytest](P008_Pytest支撑程序.md)和 [Ctest](P006_Ctest支撑程序.md)支撑程序的基类，提供共享的子进程执行、实时输出及日志处理。

## 13.1\_选择脚本

`harness_config.tests_scripts` 是脚本路径列表，默认 `tests_scripts` 目录，相对路径以测试源码目录为基准。每项可以是单个文件、目录或 **通配路径模式（Glob Pattern）**。

指定目录时，递归收集其中及子目录的全部 `.sh` 文件，但排除以下划线 `_` 开头的文件。示例中的 `ENV_VAR` 是自定环境变量，用于定位脚本根目录：

```yaml
harness: script
harness_config:
  tests_scripts:
    - tests_scripts/test_a.sh
    - ../../test/test_b.sh
    - $ENV_VAR/tests_scripts
```

> 译注：`ENV_VAR` 是示例环境变量，占位指向使用者提供的脚本根；先设置实际值，不能假设 Zephyr 自动定义它。脚本文件由测试提供，本译文没有创建这些脚本。

## 13.2\_传递脚本参数

Twister 命令行分隔符 `--` 之后的所有额外参数，都会作为附加**位置参数（Positional Argument）**传给每个脚本。它们不再由 Twister 本身解释，应按测试脚本的参数约定填写。
