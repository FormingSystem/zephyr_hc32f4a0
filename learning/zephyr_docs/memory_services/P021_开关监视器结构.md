# 第21章\_开关监视器结构

原文：[官方页面](https://docs.zephyrproject.org/latest/doxygen/html/structonoff__monitor.html)。读取日期：2026-10-14；保存的 latest 页面及 HTML 摘要见[来源记录](../SOURCES.md)。

## 21.1\_概述

开关服务转换通知的注册状态。

```c
#include <zephyr/sys/onoff.h>
```

## 21.2\_使用约定

任一给定的 `onoff_monitor` 结构体，最多只能关联一个 `onoff_manager` 实例。

## 21.3\_结构声明

```c
struct onoff_monitor {
        sys_snode_t node;

        onoff_monitor_callback callback;
};
```

## 21.4\_callback

<a id="ab26d8ae8a0dac5e03549e2d9aca243a4"></a>
<a id="r_ab26d8ae8a0dac5e03549e2d9aca243a4"></a>

```c
onoff_monitor_callback onoff_monitor::callback
```

状态变化时调用的回调。

不得为空。

## 21.5\_node

<a id="a732a81eb0d9b36376b39b1a340fd1fe6"></a>
<a id="r_a732a81eb0d9b36376b39b1a340fd1fe6"></a>

```c
sys_snode_t onoff_monitor::node
```

原文说明：将客户端链接到等待服务的使用者集合中。

必须先零初始化（Zero-initialization）。

> 译注：该成员属于监视器结构，官方实现把它接入管理器的 monitors 列表；原文的“客户端／等待使用者”措辞是遗留描述，不应把该节点当作客户端请求。
