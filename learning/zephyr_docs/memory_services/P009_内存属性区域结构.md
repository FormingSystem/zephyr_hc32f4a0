# 第9章\_内存属性区域结构

原文：[官方页面](https://docs.zephyrproject.org/latest/doxygen/html/structmem__attr__region__t.html)。读取日期：2026-10-14；保存的 latest 页面及 HTML 摘要见[来源记录](../SOURCES.md)。

## 9.1\_概述

内存属性区域结构体（Memory-attr Region Structure）。此结构保存设备树中带有内存属性标记的内存区域信息。

```c
#include <zephyr/mem_mgmt/mem_attr.h>
```

```c
struct mem_attr_region_t {
        const char *dt_name;
        uintptr_t dt_addr;
        size_t dt_size;
        uint32_t dt_attr;
};
```
