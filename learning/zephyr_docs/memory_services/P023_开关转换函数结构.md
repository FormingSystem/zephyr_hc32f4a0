# 第23章\_开关转换函数结构

原文：[官方页面](https://docs.zephyrproject.org/latest/doxygen/html/structonoff__transitions.html)。读取日期：2026-10-14；保存的 latest 页面及 HTML 摘要见[来源记录](../SOURCES.md)。

## 23.1\_概述

开关服务转换函数。

```c
#include <zephyr/sys/onoff.h>
```

## 23.2\_结构声明

```c
struct onoff_transitions {
        onoff_transition_fn start;

        onoff_transition_fn stop;

        onoff_transition_fn reset;
};
```

## 23.3\_reset

<a id="a335d7d2f8418e78b237cfb4199b6f6aa"></a>
<a id="r_a335d7d2f8418e78b237cfb4199b6f6aa"></a>

```c
onoff_transition_fn onoff_transitions::reset
```

在支持时，用于强制复位服务状态的函数。

## 23.4\_start

<a id="a86417dd542c8f259ad1fc1c7d3c26545"></a>
<a id="r_a86417dd542c8f259ad1fc1c7d3c26545"></a>

```c
onoff_transition_fn onoff_transitions::start
```

将服务转换为开启状态时调用的函数。

## 23.5\_stop

<a id="a91a1805daabae70d362441634bfa508d"></a>
<a id="r_a91a1805daabae70d362441634bfa508d"></a>

```c
onoff_transition_fn onoff_transitions::stop
```

将服务转换为关闭状态时调用的函数。
