# 第20章\_开关管理器结构

原文：[官方页面](https://docs.zephyrproject.org/latest/doxygen/html/structonoff__manager.html)。读取日期：2026-10-14；保存的 latest 页面及 HTML 摘要见[来源记录](../SOURCES.md)。

## 20.1\_概述

开关管理器关联的状态。

```c
#include <zephyr/sys/onoff.h>
```

## 20.2\_使用约定

此结构体中的字段均不供服务提供者或客户端直接使用。服务提供者初始化时，应使用 `onoff_manager_init()` 将此状态初始化一次。发生错误时，可以通过 `onoff_reset()` API 复位。

## 20.3\_结构声明

```c
struct onoff_manager {
        sys_slist_t clients;

        sys_slist_t monitors;

        const struct onoff_transitions *transitions;

        struct k_spinlock lock;

        int last_res;

        uint16_t flags;

        uint16_t refs;
};
```

## 20.4\_clients

<a id="a3eb50568d4b7c83597a194c7facd383b"></a>
<a id="r_a3eb50568d4b7c83597a194c7facd383b"></a>

```c
sys_slist_t onoff_manager::clients
```

等待请求或复位完成通知的客户端列表。

## 20.5\_flags

<a id="a50d51cd3700e610b2f650607373afeb4"></a>
<a id="r_a50d51cd3700e610b2f650607373afeb4"></a>

```c
uint16_t onoff_manager::flags
```

标识服务状态的标志。

## 20.6\_last\_res

<a id="a5f555de973d72ba1889655c3342c8dc7"></a>
<a id="r_a5f555de973d72ba1889655c3342c8dc7"></a>

```c
int onoff_manager::last_res
```

上一次转换的结果。

## 20.7\_lock

<a id="af87f180f0494f02054e33086ee940493"></a>
<a id="r_af87f180f0494f02054e33086ee940493"></a>

```c
struct k_spinlock onoff_manager::lock
```

为其他字段提供互斥保护（Mutex Protection）。

> 译注：原文称 Mutex protection，但字段实际类型为 k_spinlock，即自旋锁（Spinlock），不是内核互斥量 k_mutex。此处表达对其他字段的互斥访问保护。

## 20.8\_monitors

<a id="a501bb2c1c84293b1e4fbd011c62f5c69"></a>
<a id="r_a501bb2c1c84293b1e4fbd011c62f5c69"></a>

```c
sys_slist_t onoff_manager::monitors
```

接收状态变化通知的监视器列表，通知包括错误及转换完成。

## 20.9\_refs

<a id="a43c40829b6acd4c91517a34ebd371dd9"></a>
<a id="r_a43c40829b6acd4c91517a34ebd371dd9"></a>

```c
uint16_t onoff_manager::refs
```

该服务的活动客户端数量。
