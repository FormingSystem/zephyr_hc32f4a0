# 第4章\_内存属性堆接口

原文：[官方页面](https://docs.zephyrproject.org/latest/doxygen/html/group__memory__attr__heap.html)。读取日期：2026-10-14；保存的 latest 页面及 HTML 摘要见[来源记录](../SOURCES.md)。

## 4.1\_概述

基于内存属性的内存堆（Memory Heaps Based on Memory Attributes）提供初始化、普通分配、对齐分配、释放和所属区域查询接口。

```c
#include <zephyr/mem_mgmt/mem_attr_heap.h>
```

## 4.2\_mem\_attr\_heap\_aligned\_alloc()

<a id="ga6ef058b960a23ae8c0e57a71f5518dab"></a>
<a id="r_ga6ef058b960a23ae8c0e57a71f5518dab"></a>

```c
void * mem_attr_heap_aligned_alloc ( uint32_t attr, size_t align, size_t bytes )
```

```c
#include <zephyr/mem_mgmt/mem_attr_heap.h>
```

按指定属性、大小和对齐要求分配内存。

分配具有指定能力／属性、指定字节数的内存块；另一个参数指定以字节为单位的对齐值（Alignment），其值必须是 2 的幂。

**参数（Parameters）**

| 名称／方向 | 说明 |
| --- | --- |
| `attr` | 内存块所需的能力／属性。 |
| `align` | 返回指针的对齐值，以字节为单位，必须是 2 的幂。 |
| `bytes` | 请求分配的大小，以字节为单位。 |

**返回值（Return Values）**

| 名称／方向 | 说明 |
| --- | --- |
| `ptr` | 指向已分配内存的有效指针。 |
| `NULL` | 没有满足该属性及大小要求的可用内存。 |

> 译注：参数顺序为 attr、align、bytes。指南原例的注释与参数不一致，修正对照见[内存属性](P001_内存属性.md)。

## 4.3\_mem\_attr\_heap\_alloc()

<a id="gac03747a12f19735fc1a66d324b19f367"></a>
<a id="r_gac03747a12f19735fc1a66d324b19f367"></a>

```c
void * mem_attr_heap_alloc ( uint32_t attr, size_t bytes )
```

```c
#include <zephyr/mem_mgmt/mem_attr_heap.h>
```

按指定属性和大小分配内存。

分配具有指定能力／属性、指定字节数的内存块。属性用于选择正确的内存堆（Memory Heap），然后从该堆分配内存。

**参数（Parameters）**

| 名称／方向 | 说明 |
| --- | --- |
| `attr` | 内存块所需的能力／属性。 |
| `bytes` | 请求分配的大小，以字节为单位。 |

**返回值（Return Values）**

| 名称／方向 | 说明 |
| --- | --- |
| `ptr` | 指向已分配内存的有效指针。 |
| `NULL` | 没有满足该属性及大小要求的可用内存。 |

> 译注：不要将本接口的堆选择规则与 mem_attr_check_buf 的按位与检查混为一谈。当前官方实现对堆的软件属性作精确相等比较；指南原文与源码差异见[内存属性](P001_内存属性.md)。

## 4.4\_mem\_attr\_heap\_free()

<a id="ga2a7ef3301abfdd263d86f529dc1ea0f8"></a>
<a id="r_ga2a7ef3301abfdd263d86f529dc1ea0f8"></a>

```c
void mem_attr_heap_free ( void * block)
```

```c
#include <zephyr/mem_mgmt/mem_attr_heap.h>
```

释放已分配的内存。

释放传入的内存块；该内存块必须来自先前调用 [`mem_attr_heap_alloc`](#gac03747a12f19735fc1a66d324b19f367) 或 [`mem_attr_heap_aligned_alloc`](#ga6ef058b960a23ae8c0e57a71f5518dab) 的返回值。

**参数（Parameters）**

| 名称／方向 | 说明 |
| --- | --- |
| `block` | 要释放的内存块指针，必须指向通过 [`mem_attr_heap_alloc`](#gac03747a12f19735fc1a66d324b19f367) 或 [`mem_attr_heap_aligned_alloc`](#ga6ef058b960a23ae8c0e57a71f5518dab) 分配的内存块。 |

## 4.5\_mem\_attr\_heap\_get\_region()

<a id="gac0d2db398f90a5bc76677c23552fba99"></a>
<a id="r_gac0d2db398f90a5bc76677c23552fba99"></a>

```c
const struct mem_attr_region_t * mem_attr_heap_get_region ( void * addr)
```

```c
#include <zephyr/mem_mgmt/mem_attr_heap.h>
```

取得指定地址对应的内存区域描述符（Memory Region Descriptor）。

查找管理给定指针的内存区域描述符结构体。

**参数（Parameters）**

| 名称／方向 | 说明 |
| --- | --- |
| `addr` | 要查找的地址，必须指向通过 [`mem_attr_heap_alloc`](#gac03747a12f19735fc1a66d324b19f367) 或 [`mem_attr_heap_aligned_alloc`](#ga6ef058b960a23ae8c0e57a71f5518dab) 分配的内存块。 |

**返回值（Return Values）**

| 名称／方向 | 说明 |
| --- | --- |
| `str` | 指向该地址所属内存区域结构体的指针。 |

> 译注：这里要求传入有效的已分配块指针；原文没有承诺对任意无效地址返回 NULL。返回值表中的 str 是原文标签，不是字符串返回类型。

## 4.6\_mem\_attr\_heap\_pool\_init()

<a id="ga85301dfc19493a84e89f965ed793d576"></a>
<a id="r_ga85301dfc19493a84e89f965ed793d576"></a>

```c
int mem_attr_heap_pool_init ( void )
```

```c
#include <zephyr/mem_mgmt/mem_attr_heap.h>
```

初始化内存池（Memory Pool）。

必须先调用此函数，将所有具有软件属性（Software Attribute）的内存区域初始化为内存池。

**返回值（Return Values）**

| 名称／方向 | 说明 |
| --- | --- |
| `0` | 成功。 |
| `-EALREADY` | 内存池已经初始化。 |
| `-ENOMEM` | 已分配的区域数量过多。 |
