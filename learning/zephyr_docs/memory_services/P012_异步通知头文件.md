## 12.6\_SYS\_NOTIFY\_EXTENSION\_POS

<a id="aa22143622004e478668cdd98a2e04357"></a>
<a id="r_aa22143622004e478668cdd98a2e04357"></a>

```c
#define SYS_NOTIFY_EXTENSION_POS 2
```

标识 [`sys_notify`](P014_异步通知结构.md) 标志中可供外层服务使用的位区域。

[`sys_notify`](P014_异步通知结构.md) 结构体 `flags` 字段中，从此位置开始及更高位置的位，可用于扩展 [`sys_notify`](P014_异步通知结构.md) 结构体。

这些位供外层服务的实现记录客户端专用信息。原文说明这些位由 [`sys_notify_validate`](P011_异步通知接口.md#ga71a9ccb690151020a6abea2ec9ffc667)() 清除。使用这些位并不意味着 `flags` 字段成为公共 API。


> 译注：此处原文称 sys_notify_validate() 清除扩展位，但该函数的详细说明又明确表示不校验扩展位。本轮官方[实现](https://github.com/zephyrproject-rtos/zephyr/blob/main/lib/utils/notify.c)中，validate 成功时只清除 result，不清除 flags；初始化函数清零扩展位，finalize 将整个 flags 置为 COMPLETED。原文保留，实际使用须核对对应版本。
