# 第3章\_内存属性接口

原文：[官方页面](https://docs.zephyrproject.org/latest/doxygen/html/group__memory__attr__interface.html)。读取日期：2026-10-14；保存的 latest 页面及 HTML 摘要见[来源记录](../SOURCES.md)。

## 3.1\_概述

内存属性接口（Memory Attribute Interface）用于从设备树取得区域信息、查找区域并检查缓冲区属性。

```c
#include <zephyr/mem_mgmt/mem_attr.h>
```

## 3.2\_声明与简介

<a id="r_mem_5Fattr_5Fregion_5Ft"></a>

```c
struct mem_attr_region_t
```

内存属性区域结构体（Memory-attr Region Structure）。

[详细说明](P009_内存属性区域结构.md)。

## 3.3\_DT\_MEMORY\_ATTR\_FOREACH\_STATUS\_OKAY\_NODE

<a id="ga316e41444a0db6bb78ec0c1c4bdc832b"></a>
<a id="r_ga316e41444a0db6bb78ec0c1c4bdc832b"></a>

```c
#define DT_MEMORY_ATTR_FOREACH_STATUS_OKAY_NODE( fn)
```

```c
#include <zephyr/mem_mgmt/mem_attr.h>
```

对设备树中每个状态为 `okay` 且具有 `zephyr,memory-attr` 属性的节点调用 `fn`。

宏 `fn` 必须接受一个参数，即具有 `zephyr,memory-attr` 属性的节点标识符（Node Identifier）。对树中每个符合上述条件、状态为 `okay` 的节点，宏展开一次；节点的访问顺序未作规定。

展开值（Value）：

```c
DT_FOREACH_STATUS_OKAY_NODE_VARGS(_FILTER, fn)
```

**参数（Parameters）**

| 名称／方向 | 说明 |
| --- | --- |
| `fn` | 要调用的宏。 |

## 3.4\_mem\_attr\_check\_buf()

<a id="gac599eafdb0be231c0105b05eb76b657b"></a>
<a id="r_gac599eafdb0be231c0105b05eb76b657b"></a>

```c
int mem_attr_check_buf ( void * addr, size_t size, uint32_t attr )
```

```c
#include <zephyr/mem_mgmt/mem_attr.h>
```

检查缓冲区的大小和属性是否正确。

此函数检查具有指定属性集合的缓冲区，在大小和属性方面是否完全符合某个内存区域的要求。

通常用于验证缓冲区具有预期属性，例如可缓存／不可缓存（Cacheable / Non-cacheable）、属于 RAM／Flash 等，并且已经正确分配。

将缓冲区的预期属性集合与其所属内存区域的完整属性集合按位与（Bitwise AND）匹配。因此，只要区域至少具有所要求的全部属性，缓冲区就算匹配；该区域还可以具有参数未要求的其他属性。

**参数（Parameters）**

| 名称／方向 | 说明 |
| --- | --- |
| `addr` | 用户缓冲区的虚拟地址（Virtual Address）。 |
| `size` | 用户缓冲区的大小。 |
| `attr` | 缓冲区的预期／所需属性。 |

**返回值（Return Values）**

| 名称／方向 | 说明 |
| --- | --- |
| `0` | 缓冲区具有正确的大小和属性。 |
| `-ENOSYS` | 操作不受支持，例如启用了内存管理单元（Memory Management Unit，MMU）。 |
| `-ENOTSUP` | 传入了错误的参数。 |
| `-EINVAL` | 缓冲区的属性集合不正确。 |
| `-ENOSPC` | 缓冲区过大，超出所属区域。 |
| `-ENOBUFS` | 整个缓冲区都分配在内存区域之外。 |

## 3.5\_mem\_attr\_get\_region\_index\_by\_name()

<a id="gac0fe1546b44ba112c55398296927d72c"></a>
<a id="r_gac0fe1546b44ba112c55398296927d72c"></a>

```c
int mem_attr_get_region_index_by_name ( const char * target_name)
```

```c
#include <zephyr/mem_mgmt/mem_attr.h>
```

根据节点名称查找内存区域的索引（Index）。

**参数（Parameters）**

| 名称／方向 | 说明 |
| --- | --- |
| `target_name` | 要查找的内存节点完整名称。 |

**返回值（Return Values）**

| 名称／方向 | 说明 |
| --- | --- |
| `-ENOENT` | 未找到该区域。 |

**返回（Returns）**：返回内存区域在区域数组中的索引。

## 3.6\_mem\_attr\_get\_regions()

<a id="gadcf93c67fe564d65064f5f6175d7089f"></a>
<a id="r_gadcf93c67fe564d65064f5f6175d7089f"></a>

```c
size_t mem_attr_get_regions ( const struct mem_attr_region_t ** region)
```

```c
#include <zephyr/mem_mgmt/mem_attr.h>
```

取得内存区域列表。

取得从设备树（Devicetree，DT）收集的已启用内存区域及其内存属性列表。

**参数（Parameters）**

| 名称／方向 | 说明 |
| --- | --- |
| `region` | 指向内存区域列表指针的指针。 |

**返回（Returns）**：返回通过参数提供的内存区域数量。
