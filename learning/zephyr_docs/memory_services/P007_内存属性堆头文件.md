## 7.2\_声明与简介

<a id="r_ga85301dfc19493a84e89f965ed793d576"></a>

```c
int mem_attr_heap_pool_init (void)
```

初始化内存池（Memory Pool）。

[详细说明](P004_内存属性堆接口.md#ga85301dfc19493a84e89f965ed793d576)。

<a id="r_gac03747a12f19735fc1a66d324b19f367"></a>

```c
void * mem_attr_heap_alloc (uint32_t attr, size_t bytes)
```

按指定属性和大小分配内存。

[详细说明](P004_内存属性堆接口.md#gac03747a12f19735fc1a66d324b19f367)。

<a id="r_ga6ef058b960a23ae8c0e57a71f5518dab"></a>

```c
void * mem_attr_heap_aligned_alloc (uint32_t attr, size_t align, size_t bytes)
```

按指定属性、大小和对齐要求分配内存。

[详细说明](P004_内存属性堆接口.md#ga6ef058b960a23ae8c0e57a71f5518dab)。

<a id="r_ga2a7ef3301abfdd263d86f529dc1ea0f8"></a>

```c
void mem_attr_heap_free (void *block)
```

释放已分配的内存。

[详细说明](P004_内存属性堆接口.md#ga2a7ef3301abfdd263d86f529dc1ea0f8)。

<a id="r_gac0d2db398f90a5bc76677c23552fba99"></a>

```c
const struct mem_attr_region_t * mem_attr_heap_get_region (void *addr)
```

取得指定地址对应的内存区域描述符（Memory Region Descriptor）。

[详细说明](P004_内存属性堆接口.md#gac0d2db398f90a5bc76677c23552fba99)。
