# 第19章\_开关客户端结构

原文：[官方页面](https://docs.zephyrproject.org/latest/doxygen/html/structonoff__client.html)。读取日期：2026-10-14；保存的 latest 页面及 HTML 摘要见[来源记录](../SOURCES.md)。

## 19.1\_概述

开关服务客户端关联的状态。

```c
#include <zephyr/sys/onoff.h>
```

## 19.2\_使用约定

此类对象由客户端分配。客户端负责将 `node` 字段零初始化，并调用适当的 [`sys_notify` 初始化函数](P011_异步通知接口.md)配置通知。

将对象指针传给任一开关管理器函数时，对象内容的控制权会转交服务提供者（Service Provider）。服务提供者持有控制权期间，客户端不得修改任何字段。控制权在内含 `sys_notify` 结构体被交还时同步归还客户端，或者按 `onoff_cancel()` 返回值所指示的条件归还。

控制权归还客户端后，`notify` 字段必须重新初始化，才能用于下一次操作。

译注：原字段参考只列出 `notify`；下方声明按同批官方源码浏览页补全，保留内部链表节点 `node`。有关回调被调用前不能提前复用外层对象的规则，见[异步通知结构](P014_异步通知结构.md)。

## 19.3\_结构声明

```c
struct onoff_client {
        sys_snode_t node;

        struct sys_notify notify;
};
```
