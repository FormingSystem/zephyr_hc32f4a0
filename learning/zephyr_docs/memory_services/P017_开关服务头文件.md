# 第17章\_开关服务头文件

原文：[官方页面](https://docs.zephyrproject.org/latest/doxygen/html/onoff_8h.html)。读取日期：2026-10-14；保存的 latest 页面及 HTML 摘要见[来源记录](../SOURCES.md)。

## 17.1\_概述

用于管理共享资源（Shared Resources）的开关服务头文件。

```c
#include <zephyr/kernel.h>
#include <zephyr/types.h>
#include <zephyr/sys/notify.h>
```

[源码浏览译页](P018_开关服务头文件源码.md)。

## 17.2\_声明与简介

<a id="r_onoff_5Ftransitions"></a>

```c
struct onoff_transitions
```

开关服务转换函数。

[详细说明](P023_开关转换函数结构.md)。

<a id="r_onoff_5Fmanager"></a>

```c
struct onoff_manager
```

开关管理器关联的状态。

[详细说明](P020_开关管理器结构.md)。

<a id="r_onoff_5Fclient"></a>

```c
struct onoff_client
```

开关服务客户端关联的状态。

[详细说明](P019_开关客户端结构.md)。

<a id="r_onoff_5Fmonitor"></a>

```c
struct onoff_monitor
```

开关服务转换通知的注册状态。

[详细说明](P021_开关监视器结构.md)。

<a id="r_onoff_5Fsync_5Fservice"></a>

```c
struct onoff_sync_service
```

驱动使用开关服务 API 执行同步操作时的状态。

[详细说明](P022_同步开关服务结构.md)。

## 17.3\_声明与简介

<a id="r_ga9ae0c3528254b10f5e1a9743aea234dd"></a>

```c
#define ONOFF_FLAG_ERROR BIT(0)
```

表示错误状态（Error State）的标志。

[详细说明](P016_开关服务接口.md#ga9ae0c3528254b10f5e1a9743aea234dd)。

<a id="r_ga0e06eafdf5021ce970027f20fc001acc"></a>

```c
#define ONOFF_STATE_MASK
```

用于提取服务状态位的掩码（Mask）。

[详细说明](P016_开关服务接口.md#ga0e06eafdf5021ce970027f20fc001acc)。

<a id="r_gab9e5380dce026a5dfea770f999400484"></a>

```c
#define ONOFF_STATE_OFF 0U
```

服务关闭时，经 [`ONOFF_STATE_MASK`](P016_开关服务接口.md#ga0e06eafdf5021ce970027f20fc001acc) 提取的状态值。

[详细说明](P016_开关服务接口.md#gab9e5380dce026a5dfea770f999400484)。

<a id="r_ga7cd0fba52afba2e337ab7c830d3058d7"></a>

```c
#define ONOFF_STATE_ON ONOFF_FLAG_ONOFF
```

服务开启时，经 [`ONOFF_STATE_MASK`](P016_开关服务接口.md#ga0e06eafdf5021ce970027f20fc001acc) 提取的状态值。

[详细说明](P016_开关服务接口.md#ga7cd0fba52afba2e337ab7c830d3058d7)。

<a id="r_gac005a25d149568208a6fbaa2ceaa1ac6"></a>

```c
#define ONOFF_STATE_ERROR ONOFF_FLAG_ERROR
```

服务处于错误状态、且未正在复位时，经 [`ONOFF_STATE_MASK`](P016_开关服务接口.md#ga0e06eafdf5021ce970027f20fc001acc) 提取的状态值。

[详细说明](P016_开关服务接口.md#gac005a25d149568208a6fbaa2ceaa1ac6)。

<a id="r_gac4a0d8a7b501adb011aa1c4c4da3f2a3"></a>

```c
#define ONOFF_STATE_TO_ON (ONOFF_FLAG_TRANSITION | ONOFF_STATE_ON)
```

服务正在向开启状态转换时，经 [`ONOFF_STATE_MASK`](P016_开关服务接口.md#ga0e06eafdf5021ce970027f20fc001acc) 提取的状态值。

[详细说明](P016_开关服务接口.md#gac4a0d8a7b501adb011aa1c4c4da3f2a3)。

<a id="r_ga235a04122763f1a2cbb849c56df65d26"></a>

```c
#define ONOFF_STATE_TO_OFF (ONOFF_FLAG_TRANSITION | ONOFF_STATE_OFF)
```

服务正在向关闭状态转换时，经 [`ONOFF_STATE_MASK`](P016_开关服务接口.md#ga0e06eafdf5021ce970027f20fc001acc) 提取的状态值。

[详细说明](P016_开关服务接口.md#ga235a04122763f1a2cbb849c56df65d26)。

<a id="r_gacc0438b5c81c639e0035ada5caec940b"></a>

```c
#define ONOFF_STATE_RESETTING (ONOFF_FLAG_TRANSITION | ONOFF_STATE_ERROR)
```

服务正在复位时，经 [`ONOFF_STATE_MASK`](P016_开关服务接口.md#ga0e06eafdf5021ce970027f20fc001acc) 提取的状态值。

[详细说明](P016_开关服务接口.md#gacc0438b5c81c639e0035ada5caec940b)。

<a id="r_ga8c1171a844ef1d9d6541d342124492ff"></a>

```c
#define ONOFF_TRANSITIONS_INITIALIZER(_start, _stop, _reset)
```

[`onoff_transitions`](P023_开关转换函数结构.md) 对象的初始化器（Initializer）。

[详细说明](P016_开关服务接口.md#ga8c1171a844ef1d9d6541d342124492ff)。

<a id="r_gad61d053ae4e9ee12efe8d37372a16c63"></a>

```c
#define ONOFF_CLIENT_EXTENSION_POS SYS_NOTIFY_EXTENSION_POS
```

标识 [`sys_notify`](P014_异步通知结构.md) 标志中可供外层服务使用的位区域。

[详细说明](P016_开关服务接口.md#gad61d053ae4e9ee12efe8d37372a16c63)。

## 17.4\_声明与简介

<a id="r_gac05f7946a14fa23ef67212eba30c98ac"></a>

```c

```

用于通知开关管理器（On-Off Manager）状态转换已经完成的函数签名。

[详细说明](P016_开关服务接口.md#gac05f7946a14fa23ef67212eba30c98ac)。

<a id="r_ga51fdf83642c5fa16112ce143382ec5d1"></a>

```c

```

服务实现用于执行状态转换的函数签名。

[详细说明](P016_开关服务接口.md#ga51fdf83642c5fa16112ce143382ec5d1)。

<a id="r_ga41b94526182c5772d7adebb1d1745068"></a>


用于通知开关服务客户端操作完成的函数签名（Function Signature）。

[详细说明](P016_开关服务接口.md#ga41b94526182c5772d7adebb1d1745068)。

<a id="r_gaee41b38d408cf5f5efc9cd007f377545"></a>


用于通知开关服务监视器（Monitor）发生错误或状态转换完成的函数签名。

[详细说明](P016_开关服务接口.md#gaee41b38d408cf5f5efc9cd007f377545)。

<a id="r_gaf7b46a5f2e43d1bab193c18b8f6c8ba8"></a>

清除开关服务错误，并将其复位到关闭状态。
