# 第1章\_设备管理概览

原文：[Device Management](https://docs.zephyrproject.org/latest/services/device_mgmt/index.html)。读取日期：2026-10-12，`latest`。

本节介绍覆盖设备整个生命周期的**设备管理（Device Management）**服务，例如更新固件，以及查询嵌入在固件镜像中的元数据。
