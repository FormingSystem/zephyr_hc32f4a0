# 第21章\_管理示例入口

原文：[Management](https://docs.zephyrproject.org/latest/samples/subsys/mgmt/mgmt.html)。读取日期：2026-10-13，`latest`。

## 21.1\_管理功能示例

官方管理示例入口列出以下四类应用，演示设备管理功能。本表保留原入口的范围；相邻的OSDP页面另行翻译，不擅自加入原列表。

| 官方示例 | 功能与中文译文 |
| --- | --- |
| Eclipse hawkBit Direct Device Integration API | 使用hawkBit的**直接设备集成（Direct Device Integration，DDI）**接口更新设备，见[hawkBit升级示例](P024_hawkBit升级示例.md)。 |
| Firmware Over-the-Air over HTTP | 经 **超文本传输协议（Hypertext Transfer Protocol，HTTP）**把签名固件下载到MCUboot次槽并切换运行，见[HTTP固件升级示例](P023_HTTP固件升级示例.md)。 |
| SMP Server | 实现 **简单管理协议（Simple Management Protocol，SMP）**服务器，见[SMP服务器示例](P022_SMP服务器示例.md)。 |
| UpdateHub embedded Firmware Over-The-Air Update | 使用UpdateHub执行 **空中固件升级（Firmware Over-The-Air，FOTA）**，见[UpdateHub升级示例](P025_UpdateHub升级示例.md)。 |

表中API指 **应用程序编程接口（Application Programming Interface）**，用于设备与管理服务交互；产品和项目名称保持官方写法。
