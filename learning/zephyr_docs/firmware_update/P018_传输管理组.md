# 第18章\_传输管理组

原文：[Transport Management Group](https://docs.zephyrproject.org/latest/services/device_mgmt/smp_groups/smp_group_11.html)。读取日期：2026-10-12，`latest`。

本章使用**简单管理协议（Simple Management Protocol，SMP）**；载荷采用**简洁二进制对象表示（Concise Binary Object Representation，CBOR）**。下列原文结构记号不是可以直接发送的 **JavaScript对象表示法（JavaScript Object Notation，JSON）**文本：`str` 为字符串，`uint` 为无符号整数，`int` 为整数，`bool` 为布尔值，`bstr` / `byte str` 为字节串，`opt` 表示可选。头字段 `OP` 为操作码，`Group ID` 为组标识，`Command ID` 为命令标识；0/1分别为读请求/响应，2/3分别为写请求/响应。

各命令的第2版组错误以 `err.group` 给出枚举 [`mcumgr_group_t`](https://docs.zephyrproject.org/latest/doxygen/html/group__mcumgr__mgmt__api.html#ga81f98b9a0c3810f7d607b783f8e259b5) 所属组、以 `err.rc` 给出非零组内错误码。第1版错误及第2版的通用SMP错误以顶层 `rc` 给出枚举 [`mcumgr_err_t`](https://docs.zephyrproject.org/latest/doxygen/html/group__mcumgr__mgmt__api.html#gac5d8757a7ca945c77f405764b85ad5c5) 的非零错误码；成功时不必携带这些错误字段。后面保留每个命令的原始结构，通用编码规则见[SMP协议规范](P009_SMP协议规范.md)。

## 18.1\_传输桥接管理

**传输（Transport）**管理组编号11，控制接收管理报文的传输与其他传输之间的**桥接（Bridge）**。

**原文注意：**此管理功能处于**实验阶段（Experimental）**，可能不经预告发生变化。

| 命令编号 | 用途 |
| --- | --- |
| 0 | 连接传输，建立桥接。 |
| 1 | 断开已桥接的传输。 |
| 2 | 查询桥接/传输状态。 |
| 6 | 列出传输。 |
| 7 | 查询传输模式详情。 |
| 8 | 查询传输配置详情。 |

## 18.2\_建立桥接

将收到本MCUmgr请求的传输桥接到另一MCUmgr传输。请求头 `OP=2, Group ID=11, Command ID=0`：

```text
{
    (str)"transport" : (uint)
    (str,opt)"mode"  : (uint)
    ...
}
```

`transport` 为枚举 [`smp_transport_type`](https://docs.zephyrproject.org/latest/doxygen/html/group__mcumgr__transport__smp.html#ga5d886a11df0c49ca18e23e246ab2fab9) 表示的目标传输类型；可选 `mode` 为使用的配置模式，省略时默认0。省略号表示传输可能需要额外连接参数，参数依传输而定，本页不逐项定义。

响应头 `OP=3, Group ID=11, Command ID=0`，成功载荷为空CBOR映射。

失败响应（第2版组错误）：

```text
{
    (str)"err" : {
        (str)"group"    : (uint)
        (str)"rc"       : (uint)
    }
}
```

第1版错误或第2版通用SMP错误：

```text
{
    (str)"rc"       : (int)
}
```

字段的出现条件与本章开头相同。

## 18.3\_断开桥接

可断开当前传输的桥接、指定活动桥接，或全部桥接。请求头 `OP=2, Group ID=11, Command ID=1`。

断开当前传输时发送空CBOR映射。断开指定桥接时，`transport` 为枚举 [`smp_transport_type`](https://docs.zephyrproject.org/latest/doxygen/html/group__mcumgr__transport__smp.html#ga5d886a11df0c49ca18e23e246ab2fab9) 指定的源传输类型：

```text
{
    (str)"transport" : (uint)
}
```

断开全部活动桥接时令布尔字段 `all=true`：

```text
{
    (str)"all" :       (bool)
}
```

`transport` 与 `all` **不能同时提供**。响应头 `OP=3, Group ID=11, Command ID=1`，成功载荷为空CBOR映射。

失败响应（第2版组错误）：

```text
{
    (str)"err" : {
        (str)"group"    : (uint)
        (str)"rc"       : (uint)
    }
}
```

第1版错误或第2版通用SMP错误：

```text
{
    (str)"rc"       : (int)
}
```

字段的出现条件与本章开头相同。

## 18.4\_桥接与传输状态

查询设备支持的桥接能力和当前状态。请求头 `OP=0, Group ID=11, Command ID=2`，载荷为空CBOR映射。响应头 `OP=1, Group ID=11, Command ID=2`：

```text
{
    (str)"supported"      : (uint)
    (str)"active"         : (uint)
    (str,opt)"bridged"    : (bool)
    (str,opt)"transport"  : (uint)
}
```

| 字段 | 含义 |
| --- | --- |
| `supported` | 同时可以活动的桥接数量。 |
| `active` | 当前活动的桥接数量。 |
| `bridged` | 当前传输已桥接时出现且为真，否则省略。 |
| `transport` | 当前传输所桥接到的目标MCUmgr传输编号，仅已桥接时出现。 |

失败响应（第2版组错误）：

```text
{
    (str)"err" : {
        (str)"group"    : (uint)
        (str)"rc"       : (uint)
    }
}
```

第1版错误或第2版通用SMP错误：

```text
{
    (str)"rc"       : (int)
}
```

字段的出现条件与本章开头相同。

## 18.5\_列出传输

请求头 `OP=0, Group ID=11, Command ID=6`，载荷为空CBOR映射。响应头 `OP=1, Group ID=11, Command ID=6`：

```text
{
    (str)"transports" : [
        {
            (str)"id"         : (uint)
            (str,opt)"name"   : (str)
        }
        ...
    ]
}
```

`transports` 列出设备支持的传输；每项 `id` 为支持桥接的MCUmgr传输编号，`name` 是可用时返回的可选传输名称。

失败响应（第2版组错误）：

```text
{
    (str)"err" : {
        (str)"group"    : (uint)
        (str)"rc"       : (uint)
    }
}
```

第1版错误或第2版通用SMP错误：

```text
{
    (str)"rc"       : (int)
}
```

字段的出现条件与本章开头相同。

## 18.6\_查询传输模式

请求头 `OP=0, Group ID=11, Command ID=7`，`transport` 指定要查询的传输类型：

```text
{
    (str)"transport" : (uint)
}
```

响应头 `OP=1, Group ID=11, Command ID=7`：

```text
{
    (str)"modes" : [
        {
            (str)"id"            : (uint)
            (str)"description"   : (str)
            (str,opt)"incoming"  : (bool)
            (str,opt)"outgoing"  : (bool)
        }
        ...
    ]
}
```

`modes` 是支持模式的列表。每项 `id` 是模式编号，`description` 为描述；支持入站桥接连接时 `incoming=true`，支持出站桥接连接时 `outgoing=true`，两者在结构中均为可选字段。

失败响应（第2版组错误）：

```text
{
    (str)"err" : {
        (str)"group"    : (uint)
        (str)"rc"       : (uint)
    }
}
```

第1版错误或第2版通用SMP错误：

```text
{
    (str)"rc"       : (int)
}
```

字段的出现条件与本章开头相同。

## 18.7\_查询配置参数

请求头 `OP=0, Group ID=11, Command ID=8`；`transport` 指定传输类型，`mode` 指定要查询的配置模式：

```text
{
    (str)"transport" : (uint)
    (str)"mode"      : (uint)
}
```

响应头 `OP=1, Group ID=11, Command ID=8`：

```text
{
    (str)"configs" : [
        {
            (str)"name"          : (str)
            (str)"type"          : (uint)
            (str,opt)"required"  : (bool)
        }
        ...
    ]
}
```

`configs` 中每项的 `name` 为参数名称，`type` 为下表的类型编号；必需参数的 `required` 字段出现且为真。

| `type` 值 | 数据类型 |
| --- | --- |
| 0 | 无符号整数（Unsigned Integer），`uint`。 |
| 1 | 整数（Integer），`int`。 |
| 2 | 布尔值（Boolean），`bool`。 |
| 3 | 字符串（String）。 |
| 4 | 字节串（Byte String）。 |

失败响应（第2版组错误）：

```text
{
    (str)"err" : {
        (str)"group"    : (uint)
        (str)"rc"       : (uint)
    }
}
```

第1版错误或第2版通用SMP错误：

```text
{
    (str)"rc"       : (int)
}
```

字段的出现条件与本章开头相同。
