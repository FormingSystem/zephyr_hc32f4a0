# 第3章\_空中升级

原文：[Over-the-Air Update](https://docs.zephyrproject.org/latest/services/device_mgmt/ota.html)。读取日期：2026-10-12，`latest`。

## 3.1\_网络交付固件

**空中升级（Over-the-Air Update，OTA）**通过网络连接向远端设备交付固件。虽然名称暗示无线连接，经以太网等有线网络收到的更新通常也称为 OTA。它需要服务端保存固件文件，并提供“有新版本”的通知机制。原文强调固件应进行密码学签名，并在升级前验证。

[设备固件升级](P002_设备固件升级.md)中使用 MCUboot 的方法也可以成为 OTA 流程的一部分：先把二进制镜像下载到未占用的代码分区，通常名为 `slot1_partition`，再按 MCUboot 流程升级。

## 3.2\_Golioth

[Golioth](https://golioth.io/) 是带 OTA 功能的**物联网（Internet of Things，IoT）**管理平台。设备观察云端可用固件版本，发现更新后下载并写入。其实现通过**传输层安全（Transport Layer Security，TLS）**或**数据报传输层安全（Datagram Transport Layer Security，DTLS）**保护云与设备的连接，MCUboot 在升级前验证已签名镜像。

工作示例见 [Golioth固件SDK示例](https://github.com/golioth/golioth-firmware-sdk/tree/main/examples/zephyr/fw_update)，版本管理流程见 [Golioth OTA文档](https://docs.golioth.io/device-management/ota)。SDK 是**软件开发工具包（Software Development Kit）**的简称。

## 3.3\_直接通过HTTP下载

[HTTP固件升级库](P004_HTTP固件升级.md)可以从任意**超文本传输协议（Hypertext Transfer Protocol，HTTP）**服务器下载已签名镜像，写入次槽并请求交换，无需设备管理协议或专用升级服务器。MCUboot 在升级前验证镜像签名。Zephyr 提供 [HTTP固件升级示例](P023_HTTP固件升级示例.md)。

## 3.4\_Eclipse hawkBit与UpdateHub

[Eclipse hawkBit™](https://www.eclipse.org/hawkbit/) 是升级服务器框架，通过轮询采用**表述性状态转移（Representational State Transfer，REST）**风格的**应用程序编程接口（Application Programming Interface，API）**发现更新。发现后下载并安装二进制文件，可使用 MCUboot 验证签名。参阅 [hawkBit直接设备集成接口示例](P024_hawkBit升级示例.md)。

[UpdateHub](https://updatehub.io/) 是远程更新嵌入式设备的平台，可手动触发，也可轮询监测。发现新版本后下载并安装，同样可由 MCUboot 在升级前验证签名。参阅 [UpdateHub固件空中升级示例](P025_UpdateHub升级示例.md)。

## 3.5\_SMP服务器

**简单管理协议（Simple Management Protocol，SMP）**服务器可通过**蓝牙低功耗（Bluetooth Low Energy，LE）**或**用户数据报协议（User Datagram Protocol，UDP）**更新固件。[MCUmgr](https://docs.zephyrproject.org/latest/services/device_mgmt/mcumgr.html#mcu-mgr) 把签名固件发送到远端设备，MCUboot 在升级前验证。参阅 [SMP服务器示例](P022_SMP服务器示例.md)。

## 3.6\_LwM2M

**轻量级机器到机器通信（Lightweight Machine-to-Machine，LwM2M）**协议通过 Kconfig 配置项 [`CONFIG_LWM2M_FIRMWARE_UPDATE_OBJ_SUPPORT`](https://docs.zephyrproject.org/latest/kconfig.html#CONFIG_LWM2M_FIRMWARE_UPDATE_OBJ_SUPPORT) 提供固件升级支持。设备使用 DTLS 安全连接服务器。官方有 [LwM2M接口说明](https://docs.zephyrproject.org/latest/services/connectivity/networking/api/lwm2m.html#lwm2m-interface)和[客户端示例](https://docs.zephyrproject.org/latest/samples/net/lwm2m_client/README.html#lwm2m-client)，但原文明确指出该客户端示例没有演示固件升级功能。

## 3.7\_mender-mcu

[mender-mcu](https://github.com/mendersoftware/mender-mcu) 通过与 Zephyr 集成，为资源受限设备提供可靠固件升级。它实现 Update Module（升级模块）接口，默认模块与 MCUboot 集成以提供 **A/B双镜像更新（A/B Update）**，使**微控制器（Microcontroller Unit，MCU）**能够执行原子性升级并在失败时自动回退。集成细节与示例见 [mender-mcu外部模块说明](../external_modules/P007_Mender_MCU客户端.md#external-module-mender-mcu)。

> 译注：原文描述的是该集成支持的能力，仍需所选分区、引导模式和更新模块配套，不能据此断言任意覆盖写入模式都能保留旧镜像回退。

## 3.8\_Memfault及其支持的nRF Cloud

[Memfault](https://memfault.com/) 是包含 OTA 管理的物联网可观测性平台。设备周期性连接服务检查更新，发现更新后下载并安装。总体集成细节与示例见 [memfault-firmware-sdk](../external_modules/P006_Memfault固件SDK.md#external-module-memfault-firmware-sdk)。

以上为原文列举的服务和示例，管理类示例总入口见[官方目录](P021_管理示例入口.md)。本次未开通任何云服务、上传固件或执行设备更新。
