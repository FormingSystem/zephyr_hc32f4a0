# 第13章\_统计管理组

原文：[Statistics management](https://docs.zephyrproject.org/latest/services/device_mgmt/smp_groups/smp_group_2.html)。读取日期：2026-10-12，`latest`。

本章使用**简单管理协议（Simple Management Protocol，SMP）**；载荷采用**简洁二进制对象表示（Concise Binary Object Representation，CBOR）**。下列原文结构记号不是可以直接发送的 **JavaScript对象表示法（JavaScript Object Notation，JSON）**文本：`str` 为字符串，`uint` 为无符号整数，`int` 为整数，`bool` 为布尔值，`bstr` / `byte str` 为字节串，`opt` 表示可选。头字段 `OP` 为操作码，`Group ID` 为组标识，`Command ID` 为命令标识；0/1分别为读请求/响应，2/3分别为写请求/响应。

各命令的第2版组错误以 `err.group` 给出枚举 [`mcumgr_group_t`](https://docs.zephyrproject.org/latest/doxygen/html/group__mcumgr__mgmt__api.html#ga81f98b9a0c3810f7d607b783f8e259b5) 所属组、以 `err.rc` 给出非零组内错误码。第1版错误及第2版的通用SMP错误以顶层 `rc` 给出枚举 [`mcumgr_err_t`](https://docs.zephyrproject.org/latest/doxygen/html/group__mcumgr__mgmt__api.html#gac5d8757a7ca945c77f405764b85ad5c5) 的非零错误码；成功时不必携带这些错误字段。后面保留每个命令的原始结构，通用编码规则见[SMP协议规范](P009_SMP协议规范.md)。

## 13.1\_统计管理入口

**统计（Statistics）**管理读取Zephyr统计子系统收集的数据，子系统由Kconfig配置项 [`CONFIG_STATS`](https://docs.zephyrproject.org/latest/kconfig.html#CONFIG_STATS) 启用。SMP统计管理组编号2，命令0查询某统计组的数据，命令1列出统计组。

统计组名由收集统计的模块通过宏 [`STATS_INIT_AND_REG`](https://docs.zephyrproject.org/latest/doxygen/html/group__stats__apis.html#ga7a3f6d5dc044e6948998b8bc19efa493) 或函数 [`stats_init_and_reg()`](https://docs.zephyrproject.org/latest/doxygen/html/group__stats__apis.html#ga687b3da8d0e3e0f55e8ea8d5e47eaf2a) 注册。这里的“统计组”是按名称组织的统计集合，与SMP头部编号为2的“管理组”层次不同。

## 13.2\_读取指定统计组

请求头 `OP=0, Group ID=2, Command ID=0`，字段 `name` 为注册时使用的统计组名称：

```text
{
    (str)"name" :  (str)
}
```

响应头 `OP=1, Group ID=2, Command ID=0`，成功载荷为：

```text
{
    (str)"name"     : (str)
    (str)"fields"   : {
        (str)<entry_name> : (uint)
        ...
    }
}
```

`name` 是本响应所属统计组的名称；`fields` 将每个统计条目的名称 `<entry_name>` 映射到其数值。该值在CBOR层面固定为无符号整数类型。

失败响应（第2版组错误）：

```text
{
    (str)"err" : {
        (str)"group"    : (uint)
        (str)"rc"       : (uint)
    }
}
```

第1版错误或第2版通用SMP错误：

```text
{
    (str)"rc"       : (int)
}
```

字段的出现条件与本章开头相同。

## 13.3\_列出统计组

该命令列出设备正在收集的统计组，名称与宏或函数注册时一致。组集合在编译阶段通常已知，因此该查询可视为可选；客户端不必先列组才能查询已知组。

请求头 `OP=0, Group ID=2, Command ID=1`，载荷为空CBOR映射；响应头 `OP=1, Group ID=2, Command ID=1`：

```text
{
    (str)"stat_list" :  [
        (str)<stat_group_name>, ...
    ]
}
```

`stat_list` 是统计组名称字符串数组；没有组时可以为空。

失败响应（第2版组错误）：

```text
{
    (str)"err" : {
        (str)"group"    : (uint)
        (str)"rc"       : (uint)
    }
}
```

第1版错误或第2版通用SMP错误：

```text
{
    (str)"rc"       : (int)
}
```

字段的出现条件与本章开头相同。
