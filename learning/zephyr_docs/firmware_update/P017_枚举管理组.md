# 第17章\_枚举管理组

原文：[Enumeration Management Group](https://docs.zephyrproject.org/latest/services/device_mgmt/smp_groups/smp_group_10.html)。读取日期：2026-10-12，`latest`。

本章使用**简单管理协议（Simple Management Protocol，SMP）**；载荷采用**简洁二进制对象表示（Concise Binary Object Representation，CBOR）**。下列原文结构记号不是可以直接发送的 **JavaScript对象表示法（JavaScript Object Notation，JSON）**文本：`str` 为字符串，`uint` 为无符号整数，`int` 为整数，`bool` 为布尔值，`bstr` / `byte str` 为字节串，`opt` 表示可选。头字段 `OP` 为操作码，`Group ID` 为组标识，`Command ID` 为命令标识；0/1分别为读请求/响应，2/3分别为写请求/响应。

各命令的第2版组错误以 `err.group` 给出枚举 [`mcumgr_group_t`](https://docs.zephyrproject.org/latest/doxygen/html/group__mcumgr__mgmt__api.html#ga81f98b9a0c3810f7d607b783f8e259b5) 所属组、以 `err.rc` 给出非零组内错误码。第1版错误及第2版的通用SMP错误以顶层 `rc` 给出枚举 [`mcumgr_err_t`](https://docs.zephyrproject.org/latest/doxygen/html/group__mcumgr__mgmt__api.html#gac5d8757a7ca945c77f405764b85ad5c5) 的非零错误码；成功时不必携带这些错误字段。后面保留每个命令的原始结构，通用编码规则见[SMP协议规范](P009_SMP协议规范.md)。

## 17.1\_枚举管理命令

**枚举（Enumeration）**管理组编号10，用来发现设备支持的MCUmgr管理组：

| 命令编号 | 用途 |
| --- | --- |
| 0 | 获取支持组的数量。 |
| 1 | 列出支持组。 |
| 2 | 逐个获取组标识。 |
| 3 | 获取支持组的详细信息。 |

## 17.2\_查询组数量

请求头 `OP=0, Group ID=10, Command ID=0`，载荷为空CBOR映射。响应头 `OP=1, Group ID=10, Command ID=0`：

```text
{
    (str)"count"        : (uint)
}
```

`count` 为设备支持的MCUmgr命令组总数。

失败响应（第2版组错误）：

```text
{
    (str)"err" : {
        (str)"group"    : (uint)
        (str)"rc"       : (uint)
    }
}
```

第1版错误或第2版通用SMP错误：

```text
{
    (str)"rc"       : (int)
}
```

字段的出现条件与本章开头相同。

## 17.3\_列出组标识

请求头 `OP=0, Group ID=10, Command ID=1`，载荷为空CBOR映射。响应头 `OP=1, Group ID=10, Command ID=1`：

```text
{
    (str)"groups" : [
        (uint)
        ...
    ]
}
```

字段 `groups` 包含设备支持的管理组编号列表。

失败响应（第2版组错误）：

```text
{
    (str)"err" : {
        (str)"group"    : (uint)
        (str)"rc"       : (uint)
    }
}
```

第1版错误或第2版通用SMP错误：

```text
{
    (str)"rc"       : (int)
}
```

字段的出现条件与本章开头相同。

## 17.4\_逐个查询组

请求头 `OP=0, Group ID=10, Command ID=2`：

```text
{
    (str,opt)"index" : (uint)
}
```

可选字段 `index` 是从0开始的枚举索引，省略时返回第一个组的信息。响应头 `OP=1, Group ID=10, Command ID=2`：

```text
{
    (str)"group"    : (uint)
    (str,opt)"end"  : (bool)
}
```

`group` 为该索引对应的管理组编号。若这是设备支持的最后一个组，`end` 出现且为真；否则省略。

**译注：**原文字段说明把 `group` 称为“编号列表”，但结构为单个无符号整数，命令也明确逐项返回，故按单个编号理解。`index` 是枚举位置，不等于组编号。

失败响应（第2版组错误）：

```text
{
    (str)"err" : {
        (str)"group"    : (uint)
        (str)"rc"       : (uint)
    }
}
```

第1版错误或第2版通用SMP错误：

```text
{
    (str)"rc"       : (int)
}
```

字段的出现条件与本章开头相同。

## 17.5\_查询组详情

详情包括组名称和**处理器（Handler）**数量，可查询全部组，也可用允许列表选出需要的组。Kconfig配置项 [`CONFIG_MCUMGR_GRP_ENUM_DETAILS`](https://docs.zephyrproject.org/latest/kconfig.html#CONFIG_MCUMGR_GRP_ENUM_DETAILS) 启用可选详情命令；[`CONFIG_MCUMGR_GRP_ENUM_DETAILS_NAME`](https://docs.zephyrproject.org/latest/kconfig.html#CONFIG_MCUMGR_GRP_ENUM_DETAILS_NAME) 与 [`CONFIG_MCUMGR_GRP_ENUM_DETAILS_HANDLERS`](https://docs.zephyrproject.org/latest/kconfig.html#CONFIG_MCUMGR_GRP_ENUM_DETAILS_HANDLERS) 分别决定是否返回名称和处理器数量。

请求头 `OP=0, Group ID=10, Command ID=3`。查询全部组发送空CBOR映射；查询指定组则使用以下结构，`groups` 为待查询管理组编号列表：

```text
{
    (str)"groups" : [
        (uint)
        ...
    ]
}
```

响应头 `OP=1, Group ID=10, Command ID=3`：

```text
{
    (str)"groups" : [
        {
            (str)"group"          : (uint)
            (str,opt)"name"       : (str)
            (str,opt)"handlers"   : (uint)
        }
        ...
    ]
}
```

每项的 `group` 为管理组编号，`name` 为可选名称，`handlers` 为可选处理器数量。

失败响应（第2版组错误）：

```text
{
    (str)"err" : {
        (str)"group"    : (uint)
        (str)"rc"       : (uint)
    }
}
```

第1版错误或第2版通用SMP错误：

```text
{
    (str)"rc"       : (int)
}
```

字段的出现条件与本章开头相同。

## 17.6\_扩展详情响应的回调

应用或模块可通过MCUmgr回调增加响应字段。Kconfig配置项 [`CONFIG_MCUMGR_GRP_ENUM_DETAILS_HOOK`](https://docs.zephyrproject.org/latest/kconfig.html#CONFIG_MCUMGR_GRP_ENUM_DETAILS_HOOK) 启用钩子，注册事件 [`MGMT_EVT_OP_ENUM_MGMT_DETAILS`](https://docs.zephyrproject.org/latest/doxygen/html/group__mcumgr__callback__api__enum__mgmt.html#gga7ddc4c031948a2fee56fcbdb7d675a1da749daeaef01327a881f91671b9222abf)，回调数据结构为 [`enum_mgmt_detail_output`](https://docs.zephyrproject.org/latest/doxygen/html/structenum__mgmt__detail__output.html)。

每增加若干字段，都须按新增字段数量相应增加Kconfig配置项 [`CONFIG_MCUMGR_GRP_ENUM_DETAILS_STATES`](https://docs.zephyrproject.org/latest/kconfig.html#CONFIG_MCUMGR_GRP_ENUM_DETAILS_STATES)，为编解码状态预留空间。注册方法见[管理回调](P008_管理回调.md)。
