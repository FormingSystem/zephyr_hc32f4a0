# 第4章\_密码驱动测试示例

原文：[官方页面](https://docs.zephyrproject.org/latest/samples/drivers/crypto/README.html)。读取日期：2026-10-14；保存的 latest 页面及 HTML 摘要见[来源记录](../SOURCES.md)。

## 4.1\_概述（Overview）

本示例演示[密码学 API（Crypto APIs）](P002_密码学接口指南.md#crypto-api) 的使用，通过加密和解密操作说明接口调用。

## 4.2\_构建与运行（Building and Running）

本工程向控制台输出信息。可按以下方式在 QEMU 上构建和运行：

```shell
west build -b qemu_x86 samples/drivers/crypto
west build -t run
```

## 4.3\_示例输出（Sample Output）

```console
[general] [INF] main: Encryption Sample

[general] [INF] cbc_mode: CBC Mode

[general] [INF] cbc_mode: cbc mode ENCRYPT - Match

[general] [INF] cbc_mode: cbc mode DECRYPT - Match

[general] [INF] ctr_mode: CTR Mode

[general] [INF] ctr_mode: ctr mode ENCRYPT - Match

[general] [INF] ctr_mode: ctr mode DECRYPT - Match

[general] [INF] ccm_mode: CCM Mode

[general] [INF] ccm_mode: CCM mode ENCRYPT - Match

[general] [INF] ccm_mode: CCM mode DECRYPT - Match
```

日志术语：密文分组链接（Cipher Block Chaining，CBC）、计数器模式（Counter Mode，CTR）与 CCM 模式（Counter with CBC-MAC）；`ENCRYPT` 表示加密，`DECRYPT` 表示解密，`Match` 表示与预期数据匹配。

按 `CTRL+A x` 退出 QEMU。

译注（源码核对）：原文命令和旧式日志原样保留。当前源码还列出 ECB、CFB、OFB、GCM 等模式，实际驱动不一定支持全部模式；`tests.yaml` 的 Mbed TLS 测试项通过 `prj_mtls_shim.conf` 选择软件适配后端。当前基础 `prj.conf` 只启用通用密码驱动与日志，不能据原文简短命令推断所有 QEMU 配置都已有可用密码设备；使用当前版本时应核对对应测试项、后端配置及设备就绪情况。

译注：扩展模式名称分别为电子密码本（Electronic Codebook，ECB）、密码反馈（Cipher Feedback，CFB）、输出反馈（Output Feedback，OFB）和伽罗瓦／计数器模式（Galois/Counter Mode，GCM）。本示例用于接口与测试向量核对，不是为应用选择密码模式的完整指南。
