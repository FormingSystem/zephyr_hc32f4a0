### `CAP_NO_IV_PREFIX`

```c
#define CAP_NO_IV_PREFIX BIT(8)
```

```c
#include <zephyr/crypto/crypto.h>
```

密码输出不包含作为前缀的初始化向量（Initialization Vector，IV）。

> 译注（源码核对）：此能力用于控制输出是否带 IV 前缀，并非关闭 IV／nonce 的密码学用途。当前 Mbed TLS 适配驱动的 CBC 路径在未设置此标志时，会在加密输出前添加 IV；解密路径相应跳过此前缀，实际输出容量须按所选后端和模式计算。

<a id="gadb2c24136bb56927bb14d4cfffdd5d80"></a>

### `crypto_query_hwcaps()`

```c
int crypto_query_hwcaps ( const struct device * dev) inlinestatic
```

```c
#include <zephyr/crypto/crypto.h>
```

查询密码硬件能力（Hardware Capabilities）。

应用使用此 API 查询密码设备支持的能力，据此在调用 `cipher_begin_session()` 时，为会话指定一组受支持的选项。

**参数（Parameters）**

| 名称／方向 | 说明 |
| --- | --- |
| `dev` | 指向驱动实例的设备结构的指针。 |

**返回（Returns）**：受支持选项的位掩码（Bitmask）。
