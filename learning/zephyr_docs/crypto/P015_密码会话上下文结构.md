## 15.3\_详细说明（Detailed Documentation）

<a id="a0439c7f7c300a59296d353e76132c028"></a>

### `app_sessn_state`

```c
void* cipher_ctx::app_sessn_state
```

供应用保存异步操作完成回调时恢复处理所需的相关信息。

完全由应用管理。

<a id="abc8f2818fcb3a83c3c00805a55e5805d"></a>

### `bit_stream`

```c
const uint8_t* cipher_ctx::bit_stream
```

原始密码密钥字节。

缓冲区必须在会话活动期间保持有效。

<a id="a3b6f3cdda6344880f3dcc3e2c8246b15"></a>

### `ccm_info`

```c
struct ccm_params cipher_ctx::ccm_info
```

CCM 会话使用的 CCM 参数。

<a id="a8a7b59087bd474eaad8d996e1600e757"></a>

### `ctr_info`

```c
struct ctr_params cipher_ctx::ctr_info
```

CTR 会话使用的 CTR 参数。

<a id="a44842ea8ece2aaea4d757137cdb67b52"></a>

### `device`

```c
const struct device* cipher_ctx::device
```

此密码上下文所属的设备驱动实例。

由 `begin_session()` API 填写。

<a id="a624cf985cf35b3aa8681c3892fd67429"></a>

### `drv_sessn_state`

```c
void* cipher_ctx::drv_sessn_state
```

如果驱动支持多个并行密码会话，此字段用于标识本会话对应的特定驱动状态。

由于不能进行动态内存分配，建议驱动在构建时为计划支持的最大并行会话数分配空间。在 `begin_session()` 返回时由驱动填写。

<a id="a5745811b9b08e6df51f9b8f8b14ceae7"></a>

### `flags`

```c
uint16_t cipher_ctx::flags
```

规定本会话如何解释某些字段。

这是下列 `CAP_*` 的位掩码。应用应在调用 `begin_session()` 前填写；可通过 `crypto_query_hwcaps()` 获取硬件／驱动支持的能力标志。

<a id="a995276020bd2ef77451d941fa3b238d2"></a>

### `gcm_info`

```c
struct gcm_params cipher_ctx::gcm_info
```

GCM 会话使用的 GCM 参数。

<a id="a81dfa0793e62065a247bd3d5b5bdc903"></a>

### `handle`

```c
void* cipher_ctx::handle
```

受保护密钥的驱动专用句柄；应用无法直接取得这些密钥。

<a id="a441096f011ad26e2ba6411bdd98eb0a2"></a>

### `[union]`

```c
union { ... } cipher_ctx::key
```

会话使用的密钥材料。

应用在调用 `cipher_begin_session()` 前填写选中的成员。

<a id="a10dbfc431a748118c186099c249ed5e4"></a>

### `keylen`

```c
uint16_t cipher_ctx::keylen
```

密码密钥长度，单位为字节。

应用应在调用 `begin_session()` 前填写。

> 译注（源码核对）：此字段明确以字节计；例如 AES-128 的密钥长度为 16 字节。不要与当前若干驱动按位解释的 `ctr_len` 混用单位。

<a id="aa0f89473a5d1d6417a128bb452982db7"></a>

### `[union]`

```c
union { ... } cipher_ctx::mode_params
```

密码模式参数，在会话内的全部操作期间保持不变。

应用应在调用 `begin_session()` 前填写。

<a id="ae3eb86d5be42450b761f89114723b682"></a>

### `ops`

```c
struct cipher_ops cipher_ctx::ops
```

供驱动返回各次密码操作应调用的函数指针的位置。

密码驱动在 `begin_session()` 返回时，按应用选择的算法／模式填写。

## 15.4\_相关源码与使用边界

本仓库的[公共头文件](../../../include/zephyr/crypto/crypto.h)与[密码结构头文件](../../../include/zephyr/crypto/cipher.h)可用于源码追踪，版本可能与官网 `latest` 不同。译注核对依据为保存的[官方公共头文件](https://github.com/zephyrproject-rtos/zephyr/blob/main/include/zephyr/crypto/crypto.h)、[官方结构头文件](https://github.com/zephyrproject-rtos/zephyr/blob/main/include/zephyr/crypto/cipher.h)和[Mbed TLS 适配驱动](https://github.com/zephyrproject-rtos/zephyr/blob/main/drivers/crypto/crypto_mbedtls_shim.c)，摘要见[来源记录](../SOURCES.md)。

> 译注——联合体成员路径：原生成页把匿名联合体内部成员展开显示。实际密钥字段为 `ctx.key.bit_stream` 或 `ctx.key.handle`，按密钥表示选用其一；模式参数为 `ctx.mode_params.ccm_info`、`ctx.mode_params.ctr_info` 或 `ctx.mode_params.gcm_info`，按会话模式选用其一。它们不是可以同时独立存放多份参数的普通成员。
