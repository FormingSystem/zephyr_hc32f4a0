### `cipher_completion_cb`

```c
typedef void(* cipher_completion_cb) (struct cipher_pkt *completed, int status)
```

```c
#include <zephyr/crypto/cipher.h>
```

处理异步密码请求的完成事件。

应用可以从已完成数据包的 `ctx` 字段取得会话上下文。对于 AEAD 操作，可以通过 `container_of()` 访问外层 AEAD 数据包。数据包类型可以根据会话密码模式确定。

**参数（Parameters）**

| 名称／方向 | 说明 |
| --- | --- |
| `completed` | 已完成的密码数据包。 |
| `status` | 完成状态。`0` 表示成功，负的 `errno` 错误码表示失败。 |

> 译注（源码核对）：原文关于 `container_of()` 的说法需要结合实际布局使用。`struct cipher_aead_pkt` 的 `pkt` 是指向独立 `struct cipher_pkt` 的指针，不是内嵌对象，因此不能直接把 `completed` 当作 `cipher_aead_pkt` 的内嵌成员地址反推外层结构。应用可以自建确实内嵌数据包的请求结构，或在 `ctx->app_sessn_state` 中保存关联状态；必须按真实对象布局恢复。

### `cipher_begin_session()`

```c
int cipher_begin_session ( const struct device * dev, struct cipher_ctx * ctx, enum cipher_algo algo, enum cipher_mode mode, enum cipher_op optype ) inlinestatic
```

```c
#include <zephyr/crypto/crypto.h>
```

建立密码会话（Crypto Session）。

初始化会话密钥、算法和密码模式等一次性参数；这些参数可以在会话的全部操作中保持不变。状态可以缓存在硬件中，也可以保存在驱动的数据状态变量中。

**参数（Parameters）**

| 名称／方向 | 说明 |
| --- | --- |

| `mode` | 本会话使用的密码模式，例如 CBC、CTR。 |

> 译注（源码核对）：先查询设备能力，再由应用填写 `key`、`keylen`、`mode_params` 和 `flags`。当前包装层分别断言密钥表示、缓冲区形式及同步／异步三组选项恰选一种，随后把请求交给驱动；断言不能代替应用错误处理，也不表示查询到的每个模式组合都一定支持。初始化失败时不能继续把上下文当作有效会话使用。

### `cipher_ctr_op()`

```c
int cipher_ctr_op ( struct cipher_ctx * ctx, struct cipher_pkt * pkt, uint8_t * iv ) inlinestatic
```

```c
#include <zephyr/crypto/crypto.h>
```

执行计数器（Counter，CTR）模式操作。

**参数（Parameters）**

| 名称／方向 | 说明 |
| --- | --- |
| `ctx` | 指向本次操作密码上下文的指针。 |
| `pkt` | 保存输入／输出缓冲区指针的结构。 |
| `iv` | 本次操作的初始化向量（IV）。使用由 IV 与 ctr 拼接而成的分段计数器，因此 `ivlen = keylen - ctrlen`。`ctrlen` 在会话建立时通过 `ctx.mode_params.ctr_params.ctr_len` 指定。出于安全原因，不应在同一会话上下文的多次操作间复用 IV。分段计数器中非 IV 的部分对调用者透明，由密码提供方完全管理。 |

**返回（Returns）**：成功时为 `0`，失败时为负的 `errno` 错误码。

> 译注（源码核对）：原文存在三处需按当前源码核对的差异：实际成员路径是 `ctx.mode_params.ctr_info.ctr_len`；参数页写“字节”，但本批保存的 ESP32 与 Infineon MXCRYPTO 官方驱动将它解释为位并除以 8；这些实现使用 16 字节 AES 分组长度减去计数器字节数得到 IV 长度，而不是用 AES 密钥长度相减。例如 `ctr_len = 32` 表示 4 字节计数器，对应 12 字节 IV。原公式和单位照实保留，不能据此把 AES-192／256 的密钥字节数当作计数器块大小。使用其他后端时仍须核对其实际支持范围。
