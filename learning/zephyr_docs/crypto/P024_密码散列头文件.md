# 第24章\_密码散列头文件

原文：[官方页面](https://docs.zephyrproject.org/latest/doxygen/html/hash_8h.html)。读取日期：2026-10-14；基线为保存的 `latest` 页面，HTML 摘要见[来源记录](../SOURCES.md)。

## 24.1\_阅读说明与来源

译注：本组补齐密码散列（Cryptographic Hash）的会话、分段处理（Multipart Operation）、上下文与数据包参考。SHA 表示安全散列算法（Secure Hash Algorithm）。配合[通用密码能力](P008_密码驱动通用接口.md)与[驱动后端接口](P009_密码驱动后端接口.md)阅读；这里不是键值容器中的普通哈希映射（Hash Map）。

本组：[密码散列会话接口](P023_密码散列会话接口.md) · [密码散列头文件](P024_密码散列头文件.md) · [密码散列头文件源码](P025_密码散列头文件源码.md) · [散列会话上下文结构](P026_散列会话上下文结构.md) · [散列数据包结构](P027_散列数据包结构.md)。
