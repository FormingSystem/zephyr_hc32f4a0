# 第13章\_密码算法头文件

原文：[官方页面](https://docs.zephyrproject.org/latest/doxygen/html/cipher_8h.html)。读取日期：2026-10-14；基线为保存的 `latest` 页面，HTML 摘要见[来源记录](../SOURCES.md)。

## 13.1\_阅读说明与来源

译注：先读[密码学指南](P001_密码学服务概览.md)、[API 指南](P002_密码学接口指南.md)和[密码驱动示例](P004_密码驱动测试示例.md)。本组说明通用密码驱动、会话（Session）、密码模式（Cipher Mode）及数据包（Packet）；与 PSA Crypto 的密钥标识符接口区分使用。

本组：[密码驱动通用接口](P008_密码驱动通用接口.md) · [密码驱动后端接口](P009_密码驱动后端接口.md) · [密码驱动公共头文件](P010_密码驱动公共头文件.md) · [密码驱动公共头文件源码](P011_密码驱动公共头文件源码.md) · [密码算法会话接口](P012_密码算法会话接口.md) · [密码算法头文件](P013_密码算法头文件.md) · [密码算法头文件源码](P014_密码算法头文件源码.md) · [密码会话上下文结构](P015_密码会话上下文结构.md) · [密码操作函数结构](P016_密码操作函数结构.md) · [密码数据包结构](P017_密码数据包结构.md) · [认证加密数据包结构](P018_认证加密数据包结构.md) · [密码驱动API结构](P019_密码驱动API结构.md) · [CCM模式参数结构](P020_CCM模式参数结构.md) · [CTR模式参数结构](P021_CTR模式参数结构.md) · [GCM模式参数结构](P022_GCM模式参数结构.md)。

密码算法结构定义（Crypto Cipher Structure Definitions）。

```c
#include <zephyr/device.h>
```

```c
#include <zephyr/sys/util.h>
```

密码算法结构定义。本文件包含密码抽象层（Crypto Abstraction Layer）结构。[实验性（Experimental）] 这些结构可能随持续开发而变化，使用者应注意。

## 13.2\_数据结构（Data Structures）

<a id="r_cipher_5Fops"></a>

```c
struct cipher_ops
```

为会话选定的密码操作处理函数（Operation Handlers）。

相关声明：[cipher_ops](P016_密码操作函数结构.md)。

<a id="r_ccm_5Fparams"></a>

```c
struct ccm_params
```

CCM 模式会话参数。

相关声明：[ccm_params](P020_CCM模式参数结构.md)。

<a id="r_ctr_5Fparams"></a>

```c
struct ctr_params
```

CTR 模式会话参数。

相关声明：[ctr_params](P021_CTR模式参数结构.md)。

<a id="r_gcm_5Fparams"></a>

```c
struct gcm_params
```

GCM 模式会话参数。

相关声明：[gcm_params](P022_GCM模式参数结构.md)。

<a id="r_cipher_5Fctx"></a>

```c
struct cipher_ctx
```

用于表示会话参数的结构。

相关声明：[cipher_ctx](P015_密码会话上下文结构.md)。

<a id="r_cipher_5Fpkt"></a>

```c
struct cipher_pkt
```

用于表示一次密码操作（如加密／解密）输入输出参数的结构。

相关声明：[cipher_pkt](P017_密码数据包结构.md)。

<a id="r_cipher_5Faead_5Fpkt"></a>

```c
struct cipher_aead_pkt
```

用于表示 CCM 等带关联数据的认证加密（Authenticated Encryption with Associated Data，AEAD）场景中输入输出参数的结构。

相关声明：[cipher_aead_pkt](P018_认证加密数据包结构.md)。
