## 5.1\_PSA 示例（PSA Samples）

以下示例展示[平台安全架构（Platform Security Architecture，PSA）认证 API](https://arm-software.github.io/psa-api/) 的多种用法。

- [PSA Crypto 持久密钥（Persistent Key）](P007_PSA持久密钥示例.md#persistent_key)：通过 PSA Crypto API 管理和使用持久密钥。
- [PSA 内部可信存储（Internal Trusted Storage，ITS）API](P006_PSA内部可信存储示例.md#psa_its)：使用 PSA ITS API。

译注：这里的 Certified 是官方 API 系列名称的一部分，运行这些示例本身不等于整个产品已获得 PSA 认证。
