## 17.3\_详细说明（Detailed Documentation）

<a id="a26fb877d705580648da03ce95264d100"></a>

### `ctx`

```c
struct cipher_ctx* cipher_pkt::ctx
```

此数据包关联的上下文。

可用于获取会话详细信息，尤其适用于异步操作。`cipher_xxx_op()` API 根据其 `ctx` 参数填写该字段。

<a id="a56d2de56d9efc153032eb7f6503748ba"></a>

### `in_buf`

```c
uint8_t* cipher_pkt::in_buf
```

输入缓冲区的起始地址。

缓冲区由应用分配，必须在整个操作期间保持有效。

<a id="ac5c98e7edafb4b61e01f707c785afbea"></a>

### `in_len`

```c
int cipher_pkt::in_len
```

要处理的输入字节数。

<a id="ab95bae428d3d3c80b1b8ee6ea03a05d0"></a>

### `out_buf`

```c
uint8_t* cipher_pkt::out_buf
```

输出缓冲区的起始地址。

缓冲区由应用分配，必须在整个操作期间保持有效。原地操作时可为 `NULL`，此时驱动将结果写入 `in_buf`。

> 译注（源码核对）：是否可原地处理取决于会话所选能力标志及驱动支持。`out_buf = NULL` 不是任意会话均可使用的省略输出方式。

<a id="a6e51f941334e87cc966f5a37e783d1fc"></a>

### `out_buf_max`

```c
int cipher_pkt::out_buf_max
```

输出缓冲区的大小，单位为字节。

驱动不得写入超过此缓冲区大小的范围。

<a id="abc9588a5f84f9daa13ce4aec965f0a91"></a>

### `out_len`

```c
int cipher_pkt::out_len
```

驱动在 `cipher_xxx_op()` 返回时填写，保存实际结果的大小。

> 译注（源码核对）：对于异步操作，应在收到成功完成通知后再读取有效结果并回收缓冲区；提交函数返回不等于硬件操作已经完成。缓冲区、数据包与上下文均须保持有效。
