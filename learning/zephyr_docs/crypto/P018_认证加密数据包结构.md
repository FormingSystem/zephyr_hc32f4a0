# 第18章\_认证加密数据包结构

原文：[官方页面](https://docs.zephyrproject.org/latest/doxygen/html/structcipher__aead__pkt.html)。读取日期：2026-10-14；基线为保存的 `latest` 页面，HTML 摘要见[来源记录](../SOURCES.md)。

## 18.1\_阅读说明与来源

译注：先读[密码学指南](P001_密码学服务概览.md)、[API 指南](P002_密码学接口指南.md)和[密码驱动示例](P004_密码驱动测试示例.md)。本组说明通用密码驱动、会话（Session）、密码模式（Cipher Mode）及数据包（Packet）；与 PSA Crypto 的密钥标识符接口区分使用。

本组：[密码驱动通用接口](P008_密码驱动通用接口.md) · [密码驱动后端接口](P009_密码驱动后端接口.md) · [密码驱动公共头文件](P010_密码驱动公共头文件.md) · [密码驱动公共头文件源码](P011_密码驱动公共头文件源码.md) · [密码算法会话接口](P012_密码算法会话接口.md) · [密码算法头文件](P013_密码算法头文件.md) · [密码算法头文件源码](P014_密码算法头文件源码.md) · [密码会话上下文结构](P015_密码会话上下文结构.md) · [密码操作函数结构](P016_密码操作函数结构.md) · [密码数据包结构](P017_密码数据包结构.md) · [认证加密数据包结构](P018_认证加密数据包结构.md) · [密码驱动API结构](P019_密码驱动API结构.md) · [CCM模式参数结构](P020_CCM模式参数结构.md) · [CTR模式参数结构](P021_CTR模式参数结构.md) · [GCM模式参数结构](P022_GCM模式参数结构.md)。

用于表示 CCM 等带关联数据的认证加密（Authenticated Encryption with Associated Data，AEAD）场景中输入输出参数的结构。

```c
#include <zephyr/crypto/cipher.h>
```

用于表示 CCM 等 AEAD（带关联数据的认证加密）场景中输入输出参数的结构。应用必须在调用 `cipher_ccm_op()` 前提供有效内容。

## 18.3\_详细说明（Detailed Documentation）

<a id="a1b00939c8409041b8202ae90ee01a41c"></a>

### `ad`

```c
uint8_t* cipher_aead_pkt::ad
```

关联数据的起始地址。

缓冲区由应用提供，必须在整个操作期间保持有效。

<a id="a2964d6ffbe02b7088be9a2d5c21a2f9c"></a>

### `ad_len`

```c
uint32_t cipher_aead_pkt::ad_len
```

关联数据大小，单位为字节。

<a id="a4953711ca04b1c1d17980fff03561d03"></a>

### `pkt`

```c
struct cipher_pkt* cipher_aead_pkt::pkt
```

包含输入与输出缓冲区的数据包（Packet）。

由应用提供，必须在整个操作期间保持有效。

<a id="a3c7a3e72c7d21ec574dd777ac0bdf3c4"></a>

### `tag`

```c
uint8_t* cipher_aead_pkt::tag
```

认证标签缓冲区的起始地址。

加密时，驱动在操作完成前将标签写入这个由应用分配的缓冲区；解密时，应用在此缓冲区中提供预期标签。
