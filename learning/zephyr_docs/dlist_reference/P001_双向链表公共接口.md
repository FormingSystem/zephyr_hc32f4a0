原文：[官方页面](https://docs.zephyrproject.org/latest/doxygen/html/group__doubly-linked-list__apis.html)。读取日期：2026-10-15；来源摘要见[来源记录](../SOURCES.md)。

> 译注——阅读位置：先读[双向链表指南](../kernel/P053_双向链表.md)，再查公共API及头文件。源码跟踪译注说明循环哨兵、节点状态和原文边界差异。

双向链表（Doubly-linked List）实现。

<a id="details"></a>

双向链表实现。自1.0版本提供（Since），接口版本为1.0.0（Version）。实现使用内联宏／函数。此API不具备线程安全性（Thread Safety）；若链表跨线程使用，必须用同步原语（Synchronization Primitives）保护函数调用。初始化时，链表的head与tail指针都应指向链表自身；这种初始化方式可简化向链表添加节点和从中删除节点的操作。

## 1.5\_详细说明（Detailed Documentation）

<a id="ga33a8bf65e8095e3b4dcee0b005b79170"></a>

### `SYS_DLIST_CONTAINER`

```c
#define SYS_DLIST_CONTAINER ( __dn, __cn, __n )
```

```c
#include <zephyr/sys/dlist.h>
```

展开值（Value）：

```c
(((__dn) != NULL) ? CONTAINER_OF(__dn, __typeof__(*(__cn)), __n) : NULL)
```

提供从链表节点取得所属容器（Container）的基本操作。注意：节点指针为NULL时也可安全使用。

**参数（Parameters）**

| 名称／方向 | 说明 |
| --- | --- |
| `__dn` | 指向sys_dnode_t的指针，用于取得其所属容器。 |
| `__cn` | 容器结构类型的指针。 |
| `__n` | 容器结构中sys_dnode_t成员的字段名。 |

> 译注——源码核对：__cn提供容器指针类型，__n为嵌入节点成员名。NULL节点返回NULL；哨兵地址虽非NULL，却不是应用容器节点，不能拿它做容器反算。

<a id="gaf9eeb36eef731248c2f57c603feb1b20"></a>

### `SYS_DLIST_FOR_EACH_CONTAINER`

```c
#define SYS_DLIST_FOR_EACH_CONTAINER ( __dl, __cn, __n )
```

```c
#include <zephyr/sys/dlist.h>
```

展开值（Value）：

```c
for ((__cn) = SYS_DLIST_PEEK_HEAD_CONTAINER(__dl, __cn, __n);     \
     (__cn) != NULL;                                              \
     (__cn) = SYS_DLIST_PEEK_NEXT_CONTAINER(__dl, __cn, __n))
```

提供以容器形式遍历链表的基本操作。注意：此循环不支持安全摘除当前容器，因此不应摘除__cn。

用户必须为循环语句添加花括号，以包围自己的代码：

原始示例（Example）：

```c
SYS_DLIST_FOR_EACH_CONTAINER(l, c, n) {
    <user code>
}
```

**参数（Parameters）**

| 名称／方向 | 说明 |
| --- | --- |
| `__dl` | 指向待遍历sys_dlist_t的指针。 |
| `__cn` | 用于逐一查看链表条目的容器结构类型指针。 |
| `__n` | 容器结构中sys_dnode_t成员的字段名。 |

<a id="gaf07e09986c950b0dd1a0c89d4348f858"></a>

### `SYS_DLIST_FOR_EACH_CONTAINER_SAFE`

```c
#define SYS_DLIST_FOR_EACH_CONTAINER_SAFE ( __dl, __cn, __cns, __n )
```

```c
#include <zephyr/sys/dlist.h>
```

展开值（Value）：

```c
for ((__cn) = SYS_DLIST_PEEK_HEAD_CONTAINER(__dl, __cn, __n),   \
     (__cns) = SYS_DLIST_PEEK_NEXT_CONTAINER(__dl, __cn, __n);    \
```

## 1.6\_源码定位与版本边界

对照[公共API](P001_双向链表公共接口.md)、[头文件参考](P002_双向链表头文件参考.md)和[源码浏览](P003_双向链表头文件源码.md)。

相对源码定位：[dlist.h](../../../include/zephyr/sys/dlist.h)及容器宏定义所在的[util.h](../../../include/zephyr/sys/util.h)；本次依据为[官方dlist.h](https://github.com/zephyrproject-rtos/zephyr/blob/main/include/zephyr/sys/dlist.h)和[官方util.h](https://github.com/zephyrproject-rtos/zephyr/blob/main/include/zephyr/sys/util.h)，摘要见[来源记录](../SOURCES.md)。

> 译注——源码核对：循环哨兵（Circular Sentinel）：sys_dlist_t与sys_dnode_t都是_dnode的别名，head／next和tail／prev分别共享联合体存储。初始化后的空链表两端指向自身，单纯把链表清零不是合法空链表；列表对象地址改变或按字节复制到新位置也不会自动修复这些自引用。

> 译注——源码核对：节点与所有权：应用通常把节点嵌入容器，负责其分配与生命周期。链表只修改链接，不复制或释放容器。同一节点不能重复入链或同时加入多条链；节点初始化清空其指针，不等价于把已入链节点从相邻节点中摘除。

> 译注——源码核对：同步与遍历：所有宏和函数不自行加锁。SAFE遍历只提前保存后继，允许处理当前节点，不保护其他线程或被预存对象的生命周期；ITERATE_FROM_NODE在非NULL起始节点上先前进一步。容器宏使用指针类型和成员偏移，不提供运行时类型检查。

> 译注——源码核对：复杂度：已知节点的摘链和已知位置的插入为O(1)，条件插入需线性扫描，len也为O(n)。指针状态查询不是链表结构校验，更不是与随后操作合并的原子事务。

本次未构建或运行并发遍历、节点生命周期、性能及实板实验。
