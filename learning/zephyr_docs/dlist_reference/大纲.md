# 双向链表参考大纲

双向链表（Doubly-linked List）为节点保存前驱和后继，以链表自身作为循环哨兵（Circular Sentinel）。先读[双向链表指南](../kernel/P053_双向链表.md)，再从公共API查到头文件源码。相关结构另见[单向链表参考](../slist_reference/大纲.md)和[带标志单向链表参考](../sflist_reference/大纲.md)。

本册保留声明、宏展开、循环示例、参数、返回值和法律注释。源码译注区分空链表与未入链节点、remove与dequeue、前驱查询的原文边界错误，以及条件插入和区间搬移的前提。所有仓库定位使用相对路径，完整范围见[全站进度](../PROGRESS.md)。
