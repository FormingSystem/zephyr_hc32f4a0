## 2.1\_宏定义（Macros）

<a id="r_ga3788b5bbd11acc885e7378800a8cf974"></a>

```c
#define SYS_DLIST_FOR_EACH_NODE(__dl, __dn)
```

相关声明：[SYS_DLIST_FOR_EACH_NODE](P001_双向链表公共接口.md#ga3788b5bbd11acc885e7378800a8cf974)。

提供遍历链表的基本操作。注意：此循环不支持安全删除当前节点，因此不应移除__dn。

<a id="r_ga2bda6ba927f32e1d0b71ad63781b9909"></a>

```c
#define SYS_DLIST_ITERATE_FROM_NODE(__dl, __dn)
```

相关声明：[SYS_DLIST_ITERATE_FROM_NODE](P001_双向链表公共接口.md#ga2bda6ba927f32e1d0b71ad63781b9909)。

提供从链表中某个节点继续遍历的基本操作。注意：此循环不支持安全删除当前节点，因此不应移除__dn。

<a id="r_ga21c5c7dc311eaba99f00fb2eeca736d9"></a>

```c
#define SYS_DLIST_FOR_EACH_NODE_SAFE(__dl, __dn, __dns)
```

相关声明：[SYS_DLIST_FOR_EACH_NODE_SAFE](P001_双向链表公共接口.md#ga21c5c7dc311eaba99f00fb2eeca736d9)。

提供安全遍历链表的基本操作。注意：可以移除__dn，不会破坏循环。

<a id="r_ga33a8bf65e8095e3b4dcee0b005b79170"></a>

```c
#define SYS_DLIST_CONTAINER(__dn, __cn, __n)
```

相关声明：[SYS_DLIST_CONTAINER](P001_双向链表公共接口.md#ga33a8bf65e8095e3b4dcee0b005b79170)。

提供从链表节点取得所属容器（Container）的基本操作。注意：节点指针为NULL时也可安全使用。

相关声明：[SYS_DLIST_PEEK_NEXT_CONTAINER](P001_双向链表公共接口.md#gaffb72234c90286ecf382b93d4db50a19)。


相关声明：[SYS_DLIST_FOR_EACH_CONTAINER](P001_双向链表公共接口.md#gaf9eeb36eef731248c2f57c603feb1b20)。

提供以容器形式遍历链表的基本操作。注意：此循环不支持安全摘除当前容器，因此不应摘除__cn。

相关声明：[SYS_DLIST_FOR_EACH_CONTAINER_SAFE](P001_双向链表公共接口.md#gaf07e09986c950b0dd1a0c89d4348f858)。

## 2.4\_源码定位与版本边界

对照[公共API](P001_双向链表公共接口.md)、[头文件参考](P002_双向链表头文件参考.md)和[源码浏览](P003_双向链表头文件源码.md)。

相对源码定位：[dlist.h](../../../include/zephyr/sys/dlist.h)及容器宏定义所在的[util.h](../../../include/zephyr/sys/util.h)；本次依据为[官方dlist.h](https://github.com/zephyrproject-rtos/zephyr/blob/main/include/zephyr/sys/dlist.h)和[官方util.h](https://github.com/zephyrproject-rtos/zephyr/blob/main/include/zephyr/sys/util.h)，摘要见[来源记录](../SOURCES.md)。

> 译注——源码核对：循环哨兵（Circular Sentinel）：sys_dlist_t与sys_dnode_t都是_dnode的别名，head／next和tail／prev分别共享联合体存储。初始化后的空链表两端指向自身，单纯把链表清零不是合法空链表；列表对象地址改变或按字节复制到新位置也不会自动修复这些自引用。

> 译注——源码核对：节点与所有权：应用通常把节点嵌入容器，负责其分配与生命周期。链表只修改链接，不复制或释放容器。同一节点不能重复入链或同时加入多条链；节点初始化清空其指针，不等价于把已入链节点从相邻节点中摘除。

> 译注——源码核对：同步与遍历：所有宏和函数不自行加锁。SAFE遍历只提前保存后继，允许处理当前节点，不保护其他线程或被预存对象的生命周期；ITERATE_FROM_NODE在非NULL起始节点上先前进一步。容器宏使用指针类型和成员偏移，不提供运行时类型检查。

> 译注——源码核对：复杂度：已知节点的摘链和已知位置的插入为O(1)，条件插入需线性扫描，len也为O(n)。指针状态查询不是链表结构校验，更不是与随后操作合并的原子事务。

本次未构建或运行并发遍历、节点生命周期、性能及实板实验。
