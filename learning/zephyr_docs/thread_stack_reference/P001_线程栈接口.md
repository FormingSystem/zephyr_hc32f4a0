### `K_KERNEL_STACK_DEFINE`

```c
#define K_KERNEL_STACK_DEFINE ( sym, size )
```

```c
#include <zephyr/kernel/thread_stack.h>
```

展开值（Value）：

```c
Z_KERNEL_STACK_DEFINE_IN(sym, size, __kstackmem); \
K_THREAD_HW_SHADOW_STACK_DEFINE(sym, \
                                K_THREAD_HW_SHADOW_STACK_SIZE(size))
```

定义顶层内核栈内存区域（Kernel Stack Memory Region）。

定义一块用作线程栈的内存区域，供始终在监督模式（Supervisor Mode）运行的线程使用；也适合声明中断或异常处理所需的专用栈。

使用此宏定义的栈不能承载用户模式线程（User Mode Thread）。

可以在此定义之前加上 `static` 关键字。

不得把 `sizeof(sym)` 的结果作为 `stackSize` 参数传给 `k_thread_create()`，因为它可能与 `size` 参数不同。应改用 `K_KERNEL_STACK_SIZEOF()`。

为容纳固定大小的栈溢出保护区（Stack Overflow Guard），实际分配的总内存可能增加。

**参数（Parameters）**

| 名称／方向 | 说明 |
| --- | --- |
| `sym` | 线程栈符号名称。 |
| `size` | 栈内存区域大小。 |

### `K_THREAD_STACK_DEFINE`

```c
#define K_THREAD_STACK_DEFINE ( sym, size )
```

```c
#include <zephyr/kernel/thread_stack.h>
```

展开值（Value）：

```c
Z_THREAD_STACK_DEFINE_IN(sym, size, __stackmem)
```

定义顶层线程栈内存区域（Thread Stack Memory Region）。

定义一块适合用作线程栈的内存区域。

这是通用的历史定义方式：按 `Z_THREAD_STACK_OBJ_ALIGN` 对齐，并放入 `noinit` 段，使其不会在启动时清零。

所定义的符号始终具有 `k_thread_stack_t` 类型，可传给 `k_thread_create()`，但不应以其他方式操作。如果需要检查内部缓冲区，应查看关联线程对象的 `thread->stack_info`，从中取得边界。

可以在此定义之前加上 `static` 关键字。

不得把 `sizeof(sym)` 的结果作为 `stackSize` 参数传给 `k_thread_create()`，因为它可能与 `size` 参数不同。应改用 `K_THREAD_STACK_SIZEOF()`。

某些架构可能为满足对齐约束而将可用栈区域大小向上取整；`K_THREAD_STACK_SIZEOF()` 返回对齐后的大小。

**参数（Parameters）**

| 名称／方向 | 说明 |
| --- | --- |
| `sym` | 线程栈符号名称。 |
| `size` | 栈内存区域大小。 |

### `K_THREAD_STACK_LEN`

```c
#define K_THREAD_STACK_LEN ( size)
```

```c
#include <zephyr/kernel/thread_stack.h>
```

展开值（Value）：

```c
ROUND_UP(Z_THREAD_STACK_SIZE_ADJUST(size), \
         Z_THREAD_STACK_OBJ_ALIGN(size))
```

计算栈数组中各栈需要分配的大小。

此宏计算栈数组中每个栈需要分配的大小。它接收指定的 `size`，并在需要时填充额外字节（例如 MPU 场景）。用法参阅 `K_THREAD_STACK_ARRAY_DEFINE` 的定义。返回的大小确保每个数组成员都满足所要求的栈基址对齐。

**参数（Parameters）**

| 名称／方向 | 说明 |
| --- | --- |
| `size` | 栈内存区域大小。 |

返回（Returns）：适合数组成员的大小。

<a id="ga775f8e6b4144cfdd24f3261b6db64150"></a>

### `K_THREAD_STACK_SIZEOF`

```c
#define K_THREAD_STACK_SIZEOF ( sym)
```

```c
#include <zephyr/kernel/thread_stack.h>
```

展开值（Value）：

```c
(sizeof(sym) - K_THREAD_STACK_RESERVED)
```

返回栈内存区域的大小，单位为字节。

便于向 `k_thread_create()` 传入所需栈大小的宏，因为底层实现可能实际创建更大的对象，例如包含保护区。

此处返回的值不保证与传给 `K_THREAD_STACK_DEFINE` 的 `size` 参数一致，可能更大；但对于关联栈对象，始终可安全地把该值传给 `k_thread_create()`。

**参数（Parameters）**

| 名称／方向 | 说明 |
| --- | --- |
| `sym` | 栈内存符号。 |

返回（Returns）：栈缓冲区大小。

## 1.3\_源码定位与版本边界

源码定位：[include/zephyr/kernel/thread_stack.h](../../../include/zephyr/kernel/thread_stack.h)、[kernel/thread.c](../../../kernel/thread.c)、[arch/arm/core/cortex_m/thread.c](../../../arch/arm/core/cortex_m/thread.c)。官方源码摘要见[来源记录](../SOURCES.md)。

> 译注——源码核对：以下源码跟踪译注独立于官方正文，依据来源记录中保存摘要的官方main文件。仓库源码定位使用相对链接；代码对照不代表已验证具体开发板的栈保护、线程切换或回溯能力。

> 译注——源码核对：栈对象（Stack Object）、可用栈缓冲区（Stack Buffer）和初始栈指针（Stack Pointer）是不同概念。sizeof得到整个对象大小，K_*_STACK_SIZEOF按宏定义扣除固定保留区，K_*_STACK_BUFFER返回非固定保留区的起点；后者仍可能包含架构随后划出的保护区域。实际线程边界应结合stack_info及其delta理解。

> 译注——源码核对：K_KERNEL_STACK_*只面向监督模式线程或专用中断／异常栈，不能用它承载用户线程。未启用CONFIG_USERSPACE时，K_THREAD_STACK_*在本次头文件中映射到内核栈宏；这只是当前配置下的展开关系，不意味着开启用户模式后两类栈仍可互换。

> 译注——源码核对：数组宏额外把每个成员长度向上对齐，保证后续成员也满足栈对象基址约束。声明应与实际定义采用相同元素数量和请求大小，不应以普通char数组替代不透明的k_thread_stack_t对象，再自行猜测MPU或ABI对齐。

> 译注——源码核对：本次内核线程创建路径先计算栈布局，按配置填充初值、设置栈哨兵（Stack Sentinel）、预留线程局部存储与随机化空间，并设置stack_info。noinit段避免启动时一般清零，不代表线程创建期间不会初始化栈，也不保证栈中旧数据仍可使用。

> 译注——源码核对：Cortex-M在用户可用栈或浮点上下文需要额外MPU保护时，可能从缓冲区划出保护空间并调整stack_info.start／size。这类按上下文借用的空间不全计入K_THREAD_STACK_RESERVED，因此不能仅用对象起点加固定保留量得到最终可写边界。

> 译注——源码核对：启用CONFIG_HW_SHADOW_STACK时，头文件还生成硬件影子栈（Hardware Shadow Stack）及映射信息；它服务于所支持架构的控制流保护，不等于普通线程栈或MPU溢出保护区。源码中可见的内部映射结构不因此成为应用稳定接口。
