# 线程栈与架构线程参考大纲

本册翻译线程栈（Thread Stack）接口、头文件参考与完整可见源码，以及架构线程（Architecture Threads）和栈遍历（Stack Walk）接口，共五份官方页面。保留声明、参数、返回值、原始宏展开与切换伪代码；源码页保留原始代码、许可证、注释、符号提示及行号锚点，中文说明另列。

栈对象、栈缓冲区与初始栈指针不能混用。阅读时分别核对用户线程与内核专用栈、对象和指针对齐、固定保留区与按上下文划出的保护区。架构切换接口还包含SMP同步约束，不能只根据单核示例判断多核实现正确。

源码跟踪译注独立标示，并指出当前源码与官方旧措辞存在差异的地方；代码示例保留其伪代码性质，不宣称已在目标硬件验证。仓库源码及译文采用相对链接，完整范围与待译状态见[全站进度](../PROGRESS.md)。
