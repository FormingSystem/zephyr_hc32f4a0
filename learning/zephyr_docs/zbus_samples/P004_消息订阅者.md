# 第4章\_消息订阅者

原文：[Message subscriber](https://docs.zephyrproject.org/latest/samples/subsys/zbus/msg_subscriber/README.html)。读取日期：2026-10-12，`latest`。

## 4.1\_概述

本示例展示 **消息订阅者（Message Subscriber）**与其他**观察者（Observer）**一起使用的方式。消息订阅者接收消息副本，普通订阅者接收通道引用。通过设置内存池大小，以及 Kconfig 选择项 [`CONFIG_ZBUS_MSG_SUBSCRIBER_BUF_ALLOC`](https://docs.zephyrproject.org/latest/kconfig.html#CONFIG_ZBUS_MSG_SUBSCRIBER_BUF_ALLOC)对应的静态或动态分配方式，可以探索**池隔离（Pool Isolation）**功能。

> 译注：静态/动态决定消息数据缓冲区怎样分配，不等于已为每个通道分配独立池。专用池还涉及总线配置和通道绑定，见[消息交付与配置说明](../io_services/P003_消息总线zbus.md)。

## 4.2\_构建与运行

程序向控制台输出，可在 QEMU 上构建并执行。

> 译注：前提是已按[入门指南](../getting_started/P002_入门指南.md)准备 west、Zephyr 工作区、目标工具链及 QEMU 模拟器。在已激活开发环境的终端中操作，当前位置为实验用 Zephyr 源码根。以下是官方构建及启动命令；Windows 使用已配置的开发终端，Linux/macOS 使用对应终端。`-b` 选择模拟板目标，`-t run` 执行构建系统的运行目标。切换示例时应使用独立构建目录或按 [west 构建说明](../west/P007_构建烧录与调试.md)清理旧配置，避免复用其他应用的缓存。

```sh
# From the root of the zephyr repository
west build -b qemu_x86 samples/subsys/zbus/msg_subscriber
west build -t run
```

构建成功后应启动模拟器并出现下一节日志。若在构建前失败，返回入门环境检查；若提示应用或板目标不一致，检查源码位置与旧构建目录。退出时先按 `Ctrl+A`，再按 `x`。
