# 第6章\_动态消息

原文：[Dynamic channel](https://docs.zephyrproject.org/latest/samples/subsys/zbus/dyn_channel/README.html)。读取日期：2026-10-12，`latest`。

## 6.1\_概述

本示例演示通过 zbus 通道交换**动态分配的消息（Dynamically Allocated Message）**。原概述也使用“动态分配的通道”这一说法。

> 译注：所核对的 `samples/subsys/zbus/dyn_channel/src/main.c` 用静态宏定义通道，消息结构体保存外部动态内存的引用与长度。因此这里主要展示动态消息存储，不应与“运行时创建通道对象”的接口混同。外部数据的所有权与释放时机仍由示例中的生产、过滤、消费和确认流程协调。

## 6.2\_构建与运行

程序向控制台输出，可在 QEMU 上构建并执行。

> 译注：前提是已按[入门指南](../getting_started/P002_入门指南.md)准备 west、Zephyr 工作区、目标工具链及 QEMU 模拟器。在已激活开发环境的终端中操作，当前位置为实验用 Zephyr 源码根。以下是官方构建及启动命令；Windows 使用已配置的开发终端，Linux/macOS 使用对应终端。`-b` 选择模拟板目标，`-t run` 执行构建系统的运行目标。切换示例时应使用独立构建目录或按 [west 构建说明](../west/P007_构建烧录与调试.md)清理旧配置，避免复用其他应用的缓存。

```sh
# From the root of the zephyr repository
west build -b qemu_x86 samples/subsys/zbus/dyn_channel
west build -t run
```

构建成功后应启动模拟器并出现下一节日志。若在构建前失败，返回入门环境检查；若提示应用或板目标不一致，检查源码位置与旧构建目录。退出时先按 `Ctrl+A`，再按 `x`。
