# 第10章\_运行时观察关系

原文：[Runtime observer registration](https://docs.zephyrproject.org/latest/samples/subsys/zbus/runtime_obs_registration/README.html)。读取日期：2026-10-12，`latest`。

## 10.1\_概述

本示例说明如何配合使用静态和**运行时观察者注册（Runtime Observer Registration）**。通信两端是**生产者（Producer）**线程与**消费者（Consumer）**线程，中间由**过滤器（Filter）**处理生产者生成的数据。

程序循环启用过滤器；五秒后关闭过滤器并启用**旁路（Bypass）**，让数据绕过过滤处理；再过五秒关闭旁路，随后重复循环。

## 10.2\_构建与运行

程序向控制台输出，可在 QEMU 上构建并执行。

> 译注：前提是已按[入门指南](../getting_started/P002_入门指南.md)准备 west、Zephyr 工作区、目标工具链及 QEMU 模拟器。在已激活开发环境的终端中操作，当前位置为实验用 Zephyr 源码根。以下是官方构建及启动命令；Windows 使用已配置的开发终端，Linux/macOS 使用对应终端。`-b` 选择模拟板目标，`-t run` 执行构建系统的运行目标。切换示例时应使用独立构建目录或按 [west 构建说明](../west/P007_构建烧录与调试.md)清理旧配置，避免复用其他应用的缓存。

```sh
# From the root of the zephyr repository
west build -b qemu_x86 samples/subsys/zbus/runtime_obs_registration
west build -t run
```

构建成功后应启动模拟器并出现下一节日志。若在构建前失败，返回入门环境检查；若提示应用或板目标不一致，检查源码位置与旧构建目录。退出时先按 `Ctrl+A`，再按 `x`。

## 10.3\_示例输出

原输出先显示 Activating filter（启用过滤），每次 Raw data fetched（取得原始数据）之后出现 Filtering data（过滤数据）和 Consuming data（消费数据）。进入 Bypass filter（旁路过滤）阶段后，不再打印过滤动作；Disable bypass filter（关闭旁路）之后的一段输出只有生产动作。

```text

I: Activating filter
I:  >-- Raw data fetched
I:  -|- Filtering data
I:  --> Consuming data: Acc x=0, y=0, z=0
I:  >-- Raw data fetched
I:  -|- Filtering data
I:  --> Consuming data: Acc x=2, y=2, z=2
I:  >-- Raw data fetched
I:  -|- Filtering data
I:  --> Consuming data: Acc x=0, y=0, z=0
I:  >-- Raw data fetched
I:  -|- Filtering data
I:  --> Consuming data: Acc x=4, y=4, z=4
I:  >-- Raw data fetched
I:  -|- Filtering data
I:  --> Consuming data: Acc x=0, y=0, z=0
I: Deactivating filter
I: Bypass filter
I:  >-- Raw data fetched
I:  --> Consuming data: Acc x=6, y=6, z=6
I:  >-- Raw data fetched
I:  --> Consuming data: Acc x=7, y=7, z=7
I:  >-- Raw data fetched
I:  --> Consuming data: Acc x=8, y=8, z=8
I:  >-- Raw data fetched
I:  --> Consuming data: Acc x=9, y=9, z=9
I:  >-- Raw data fetched
I:  --> Consuming data: Acc x=10, y=10, z=10
I: Disable bypass filter
I:  >-- Raw data fetched
I:  >-- Raw data fetched
I:  >-- Raw data fetched
I:  >-- Raw data fetched
I:  >-- Raw data fetched

<continues>
```

> 译注：原文概述没有详细说明关闭旁路到下一轮之间的间隔；输出中只见生产、不见消费的阶段按原样保留，不补造额外计时结论。
