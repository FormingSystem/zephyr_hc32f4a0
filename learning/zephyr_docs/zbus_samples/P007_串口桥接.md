# 第7章\_串口桥接

原文：[UART bridge](https://docs.zephyrproject.org/latest/samples/subsys/zbus/uart_bridge/README.html)。读取日期：2026-10-12，`latest`。

## 7.1\_概述

本应用通过**通用异步收发器（Universal Asynchronous Receiver/Transmitter，UART）**把全部通道事件重定向到主机。设备向主机计算机上的脚本发送信息，脚本解码后打印到**标准输出（Standard Output，stdout）**。

## 7.2\_构建并启动设备端

本项目向控制台输出，可在 native_sim 上构建并执行。

> 译注：下列 `native_sim` 命令面向准备好开发环境的 Linux 终端；Windows 读者需使用满足要求的 Linux 环境，不能直接把 Linux 设备节点交给 PowerShell。先按[入门指南](../getting_started/P002_入门指南.md)准备依赖，再核对 [native_sim 平台说明](../native_reference/P004_Native_Simulator本机模拟器.md#native_sim)。当前位置为实验用 Zephyr 源码根，west 的 `-b` 指定平台，`-t run` 启动已构建程序。不同示例应使用独立构建目录或清理旧缓存。

```sh
# From the root of the zephyr repository
west build -b native_sim samples/subsys/zbus/uart_bridge
west build -t run
```

设备日志显示 Core（核心逻辑）触发测量、Peripheral（外设逻辑）发送传感数据，以及 Bridge（桥接逻辑）占用通道、读取并发送的过程。启动行 OS 表示**操作系统（Operating System，OS）**，START/FINISH 分别是开始/结束处理的日志标签。这是官方示例输出：


> 译注：原输出开头的 `.../zephyr/` 是位置省略标记，不是要逐字执行的目录。输出中的旧版本标识也只是原示例记录，并非本次使用的版本。若没有出现启动日志，先核对构建和运行目标。按 `Ctrl+C` 可结束运行。

## 7.3\_运行主机脚本

保持设备端运行，另开终端并同样进入 Zephyr 源码根，运行 `decoder.py` 脚本。需使用能导入串口库 pySerial 的 Python 环境，脚本随示例源码提供；原命令使用 `python3.8`，这是原例解释器名，不是要求为当前 Zephyr 降级 Python。实际使用兼容当前工程及脚本依赖的 Python 解释器。

```sh
python3.8 samples/subsys/zbus/uart_bridge/decoder.py /dev/pts/2
```

因为设备运行于 native_sim，启动命令会打印**伪终端（Pseudoterminal）**端口。查找 `uart_1 connected to pseudotty` 对应的设备节点，例中是 `/dev/pts/2`，实际可能不同。实板应按板卡说明选择端口：Linux 通常类似 `/dev/tty...`，Windows 类似 `COM...`。这些是操作系统设备标识，不是仓库或个人文件路径。

脚本输出中 PUB 是发布事件标签，通道名 `sensor_data` 表示传感数据，`start_measurement` 表示启动测量。`b'...'` 是 Python 字节串表示，保留原始载荷内容。

```text
PUB [start_measurement] -> b'\x01'
PUB [sensor_data] -> b'\xc7\x01\x00\x00\xc6\x11\x00\x00'
PUB [start_measurement] -> b'\x00'
PUB [sensor_data] -> b'\xc8\x01\x00\x00\xd0\x11\x00\x00'
PUB [start_measurement] -> b'\x01'
PUB [sensor_data] -> b'\xc9\x01\x00\x00\xda\x11\x00\x00'
PUB [start_measurement] -> b'\x00'
PUB [sensor_data] -> b'\xca\x01\x00\x00\xe4\x11\x00\x00'
PUB [start_measurement] -> b'\x01'
PUB [sensor_data] -> b'\xcb\x01\x00\x00\xee\x11\x00\x00'
PUB [start_measurement] -> b'\x00'
PUB [sensor_data] -> b'\xcc\x01\x00\x00\xf8\x11\x00\x00'
```

如果脚本打不开端口，核对当前进程打印的端口、访问权限和是否被其他终端占用；如果缺少 `serial` 模块，返回 Python 依赖准备。按 `Ctrl+C` 结束主机脚本。两端要同时运行才能完成交换。
