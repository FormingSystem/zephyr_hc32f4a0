# 第2章\_基础通信

原文：[zbus Hello World](https://docs.zephyrproject.org/latest/samples/subsys/zbus/hello_world/README.html)。读取日期：2026-10-12，`latest`。

## 2.1\_概述

本示例使用 **消息总线（Message Bus）**子系统 zbus 实现简单的 Hello World 应用，让线程相互通信。原目录概述称它展示三个线程通信；具体输出同时列出**监听器（Listener）**、**异步监听器（Async Listener）**和**订阅者（Subscriber）**，分别演示回调、工作队列回调和订阅线程处理。

## 2.2\_构建与运行

程序向控制台输出，可在 QEMU 上构建并执行。

> 译注：前提是已按[入门指南](../getting_started/P002_入门指南.md)准备 west、Zephyr 工作区、目标工具链及 QEMU 模拟器。在已激活开发环境的终端中操作，当前位置为实验用 Zephyr 源码根。以下是官方构建及启动命令；Windows 使用已配置的开发终端，Linux/macOS 使用对应终端。`-b` 选择模拟板目标，`-t run` 执行构建系统的运行目标。切换示例时应使用独立构建目录或按 [west 构建说明](../west/P007_构建烧录与调试.md)清理旧配置，避免复用其他应用的缓存。

```sh
# From the root of the zephyr repository
west build -b qemu_x86 samples/subsys/zbus/hello_world
west build -t run
```

构建成功后应启动模拟器并出现下一节日志。若在构建前失败，返回入门环境检查；若提示应用或板目标不一致，检查源码位置与旧构建目录。退出时先按 `Ctrl+A`，再按 `x`。

## 2.3\_示例输出

输出先列出通道及观察者，再显示两组三轴加速度值。`acc_data_chan`、`simple_chan`、`version_chan` 是示例通道名；`foo_lis`、`bar_sub`、`baz_async_lis` 是对应观察者对象名。日志里的 `I:` 表示信息级日志。

```text
I: Sensor sample started raw reading, version 0.1-2!
I: Channel list:
I: 0 - Channel acc_data_chan:
I:       Message size: 12
I:       Observers:
I:       - foo_lis
I:       - bar_sub
I:       - baz_async_lis
I: 1 - Channel simple_chan:
I:       Message size: 4
I:       Observers:
I: 2 - Channel version_chan:
I:       Message size: 4
I:       Observers:
I: Observers list:
I: 0 - Subscriber bar_sub
I: 1 - Subscriber baz_async_lis
I: 2 - Listener foo_lis
I: From listener -> Acc x=1, y=1, z=1
I: From async listener -> Acc x=1, y=1, z=1
I: From subscriber -> Acc x=1, y=1, z=1
I: From listener -> Acc x=2, y=2, z=2
I: From async listener -> Acc x=2, y=2, z=2
I: From subscriber -> Acc x=2, y=2, z=2
I: Pub a valid value to a channel with validator successfully.
I: Pub an invalid value to a channel with validator successfully.
```

> 译注：最后一句英文称“成功发布无效值”，不能据此认为校验器允许无效值。所核对的 `samples/subsys/zbus/hello_world/src/main.c` 在返回错误 `-ENOMSG` 时才打印该句，实际表示测试观察到了拒绝无效值。原输出按原样保留。
