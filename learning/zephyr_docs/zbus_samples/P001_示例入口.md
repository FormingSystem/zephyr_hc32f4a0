# 第1章\_示例入口

原文：[zbus](https://docs.zephyrproject.org/latest/samples/subsys/zbus/zbus.html)。读取日期：2026-10-12，`latest`。

本组示例演示 **消息总线（Message Bus）**子系统 zbus 的用法。总线让线程围绕通道交换消息；详细机制见[子系统译文](../io_services/P003_消息总线zbus.md)。

## 1.2\_阅读与执行边界

> 译注：可以从基础通信开始，再比较观察者与工作队列；需要主机测试时阅读串口桥接和远端模拟；需要时延分析时阅读优先级提升和性能基准。跨核代理要求相应多核平台。各页保留官方目标、命令和输出，不代表已在当前板运行。示例中的通道名、线程名和对象名保留英文，概念与操作在正文给出中文说明。
