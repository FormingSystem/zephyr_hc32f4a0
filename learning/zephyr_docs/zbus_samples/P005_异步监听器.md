# 第5章\_异步监听器

原文：[zbus Async Listeners](https://docs.zephyrproject.org/latest/samples/subsys/zbus/async_listeners/README.html)。读取日期：2026-10-12，`latest`。

## 5.1\_概述

本示例用简单应用演示 **异步监听器（Asynchronous Listener）**。主线程向一个通道提交事件，这个通道有三类监听器：普通监听器、使用系统工作队列的异步监听器，以及使用独立工作队列的异步监听器。

## 5.2\_构建与运行

程序向控制台输出，可在 QEMU 上构建并执行。

> 译注：前提是已按[入门指南](../getting_started/P002_入门指南.md)准备 west、Zephyr 工作区、目标工具链及 QEMU 模拟器。在已激活开发环境的终端中操作，当前位置为实验用 Zephyr 源码根。以下是官方构建及启动命令；Windows 使用已配置的开发终端，Linux/macOS 使用对应终端。`-b` 选择模拟板目标，`-t run` 执行构建系统的运行目标。切换示例时应使用独立构建目录或按 [west 构建说明](../west/P007_构建烧录与调试.md)清理旧配置，避免复用其他应用的缓存。

```sh
# From the root of the zephyr repository
west build -b qemu_x86 samples/subsys/zbus/async_listeners/
west build -t run
```

构建成功后应启动模拟器并出现下一节日志。若在构建前失败，返回入门环境检查；若提示应用或板目标不一致，检查源码位置与旧构建目录。退出时先按 `Ctrl+A`，再按 `x`。

## 5.3\_示例输出

输出两列分别是 Output（处理结果）与 Thread Context（线程上下文）。事件字段 `Evt` 从 0 到 3；线程名 `main` 表示主线程，`sysworkq` 表示系统工作队列线程，`My work queue` 表示示例自己的工作队列。相同事件在三种上下文中处理，体现异步回调与发布者的执行位置不同。

```text
I: Output                       | Thread Context
I: =============================================
I: From listener -> Evt=0       | main
I: From async listener -> Evt=0 | sysworkq
I: From async listener -> Evt=0 | My work queue
I: From listener -> Evt=1       | main
I: From async listener -> Evt=1 | sysworkq
I: From async listener -> Evt=1 | My work queue
I: From listener -> Evt=2       | main
I: From async listener -> Evt=2 | sysworkq
I: From async listener -> Evt=2 | My work queue
I: From listener -> Evt=3       | main
I: From async listener -> Evt=3 | sysworkq
I: From async listener -> Evt=3 | My work queue
I: =============================================
I: From listener -> Evt=0       | main
I: From async listener -> Evt=0 | sysworkq
I: From async listener -> Evt=0 | My work queue
I: From listener -> Evt=1       | main
I: From async listener -> Evt=1 | sysworkq
I: From async listener -> Evt=1 | My work queue
I: From listener -> Evt=2       | main
I: From async listener -> Evt=2 | sysworkq
I: From async listener -> Evt=2 | My work queue
I: From listener -> Evt=3       | main
I: From async listener -> Evt=3 | sysworkq
I: From async listener -> Evt=3 | My work queue
```

原输出重复两组事件。工作队列名称是示例设置的线程名，不是某个固定物理设备。
