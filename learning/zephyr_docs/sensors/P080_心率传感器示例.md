# 第80章\_心率传感器示例

原文：[官方页面](https://docs.zephyrproject.org/latest/samples/sensor/heart_rate/README.html)。读取日期：2026-10-14；保存的latest页面及HTML摘要见[来源记录](../SOURCES.md)。

<a id="overview"></a>

## 80.1 概述（Overview）

本传感器应用演示如何通过轮询（Polling）或中断（Interrupt）取得心率传感器的数据。

<a id="requirements"></a>

## 80.2 要求（Requirements）

需要受支持的心率传感器，例如MAX30101或BH1790，并通过设备树别名`heart-rate-sensor`指向该设备。

<a id="building-and-running"></a>

## 80.3 构建与运行（Building and Running）

> 译注——执行位置：主机构建命令从读者自己的Zephyr源码根目录执行；Windows使用UCRT64 Bash，Linux使用原生Bash，先按官方入门说明准备主机工具、模块与目标工具链。原生模拟目标还须满足相应主机环境要求；硬件分支需要目标板、设备树节点和接线。下方命令及日志来自官方文档，本次没有运行模拟器或硬件实验。

项目配置板上传感器，启用绿色LED，并使用光电二极管（Photodiode）测量反射光。控制台打印的是原始数据（Raw data）；从光测量中提取心率信号，还需要本示例未包含的进一步处理。

```sh
west build -b hexiwear/mk64f12 samples/sensor/heart_rate
```

<a id="sample-output"></a>

### 80.3.1 示例输出（Sample Output）

```text
GREEN=5731
GREEN=5750
GREEN=5748
GREEN=5741
GREEN=5735
GREEN=5737
GREEN=5736
GREEN=5748
```

上述输出持续重复（`<repeats endlessly>`）。

> 译注——读数与触发：`GREEN`是绿色光通道的原始测量值，不是每分钟心跳次数（Beats per minute，bpm）。当前轮询分支每次处理后休眠20 ms；中断分支由`CONFIG_MAX30101_TRIGGER`控制，注册数据就绪触发（Data-ready trigger）后在回调中读取。其他器件能否采用触发方式须核对其驱动与配置，不能仅凭概述推断。原命令只执行构建。
