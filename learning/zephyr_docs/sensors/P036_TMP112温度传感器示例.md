# 第36章\_TMP112温度传感器示例

原文：[官方页面](https://docs.zephyrproject.org/latest/samples/sensor/tmp112/README.html)。读取日期：2026-10-14；保存的latest页面及HTML摘要见[来源记录](../SOURCES.md)。

<a id="overview"></a>

## 36.1 概述（Overview）

本示例演示[ti,tmp112](../sensor_ti_vishay_wurth_sensing_binding_reference/P007_ti_tmp112.md#std-dtcompatible-ti-tmp112)温度传感器的使用。

<a id="requirements"></a>

## 36.2 要求（Requirements）

开发板的[设备树（Devicetree）](../devicetree/P013_设备树文档入口.md#dt-guide)中应已有该传感器节点，或者通过设备树覆盖文件添加它。

<a id="building-and-running"></a>

## 36.3 构建与运行（Building and Running）

> 译注——执行位置：主机构建命令从读者自己的Zephyr源码根目录执行，使用已完成官方入门配置的UCRT64 Bash或Linux Bash终端。构建成功只表示固件生成；烧录和读取真实温湿度还需要正确的目标板、传感器节点及接线。若设备未就绪或读取失败，先检查节点状态、驱动配置和总线连接。

为[FRDM-K64F](https://docs.zephyrproject.org/latest/boards/nxp/frdm_k64f/doc/index.html#frdm_k64f)构建并烧录：

```sh
west build -b frdm_k64f samples/sensor/tmp112
west flash
```

> 译注——源码行为：当前应用取得一个[`ti,tmp112`](../sensor_ti_vishay_wurth_sensing_binding_reference/P007_ti_tmp112.md#std-dtcompatible-ti-tmp112)设备，检查就绪后先设置满量程（Full scale）属性为150、采样频率（Sampling frequency）为8，然后在循环中获取环境温度并每秒打印一次。传感器采样频率与控制台打印间隔是两个不同参数。原页面没有输出块；实际程序将整数部分和百万分之一小数部分分别打印为`temp is ... (... micro)`。
