# 第66章\_SM351LT磁阻传感器示例

原文：[官方页面](https://docs.zephyrproject.org/latest/samples/sensor/sm351lt/README.html)。读取日期：2026-10-14；保存的latest页面及HTML摘要见[来源记录](../SOURCES.md)。

<a id="overview"></a>

## 66.1 概述（Overview）

本示例周期性轮询（Polling）SM351LT磁阻传感器（Magnetoresistive sensor），通过控制台显示传感器附近是否有磁铁。

<a id="requirements"></a>

## 66.2 要求（Requirements）

示例使用Honeywell SM351LT传感器。

<a id="building-and-running"></a>

## 66.4 构建与运行（Building and Running）

> 译注——执行位置：主机构建命令从读者自己的Zephyr源码根目录执行，使用已完成官方入门配置的UCRT64 Bash或Linux Bash终端。读取真实传感器还需要对应目标板、设备树节点和接线；下面的命令与日志来自官方文档，本次没有执行硬件实验。

以下开发板具有SM351LT或兼容传感器：

- [Sentrius BT510 Sensor](https://docs.zephyrproject.org/latest/boards/ezurio/bt510/doc/bt510.html#bt510)。

<a id="building-on-bt510"></a>

### 66.4.1 在bt510上构建（Building on bt510）

[Sentrius BT510 Sensor](https://docs.zephyrproject.org/latest/boards/ezurio/bt510/doc/bt510.html#bt510)内置Honeywell SM351LT磁阻传感器。

```sh
west build -b bt510 samples/sensor/sm351lt
west flash
```

<a id="sample-output"></a>

### 66.4.2 示例输出（Sample Output）

```text
Polling at 0.5 Hz
#1 @ 6 ms: 1
#2 @ 2007 ms: 0
#3 @ 4009 ms: 0
#4 @ 6010 ms: 1
#5 @ 8012 ms: 1
```

> 译注——输出与可选触发：上述0.5 Hz输出对应每次读取后休眠2秒的轮询分支，行内依次给出次数、自启动以来的毫秒数和接近通道结果。当前代码也支持`CONFIG_SM351LT_TRIGGER`分支，设置双边沿GPIO中断（Both-edge interrupt）并注册接近／远离触发器；该模式由回调读取，主线程等待事件。这里是磁铁存在检测，不是连续磁场强度测量。
