# 第76章\_MTCH9010液体泄漏检测示例

原文：[官方页面](https://docs.zephyrproject.org/latest/samples/sensor/mtch9010/README.html)。读取日期：2026-10-14；保存的latest页面及HTML摘要见[来源记录](../SOURCES.md)。

<a id="description"></a>

## 76.1 说明（Description）

本示例将MTCH9010配置为电容式（Capacitive）或电导式（Conductive）检测模式，每秒触发一次采样并报告传感器节点返回的数据。更多说明见[应用笔记AN6386：在Zephyr RTOS中配置MTCH9010](https://www.microchip.com/en-us/application-notes/an6386)。

<a id="requirements"></a>

## 76.2 要求（Requirements）

本示例使用连接到EXT2排针的[MTCH9010评估板（Evaluation board，EV24U22A）](https://www.microchip.com/en-us/development-tool/EV24U22A)。设备配置必须提供有效的UART总线和`wake-gpios`。如果不指定`heartbeat-gpios`及`output-gpios`，会产生警告和／或使相应数值无效，但示例仍能运行。

<a id="mtch9010-evaluation-board-setup"></a>

## 76.3 MTCH9010评估板设置（MTCH9010 Evaluation Board Setup）

**重要：MTCH9010在每次上电复位（Power-on-Reset，POR）之后只能配置一次。复位MCU之前，先按下MTCH9010评估板上的RESET按钮。**

评估板通过拨码开关（DIP switch）支持不同评估条件。本示例面向SAM L21的开关及跳线设置如下。

<a id="id1"></a>

**拨码开关与跳线位置（DIP Switches and Jumper Positions）**

| 拨码开关或跳线（DIP Switch or Jumper） | 位置（Position） |
| --- | --- |
| 电源（Power Supply） | 3.3V |
| OUTPUT | N/A（不适用） |
| LOCK | OFF（关闭） |
| ECFG | ON（打开） |
| MODE | N/A（不适用） |
| USB桥接（USB Bridge） | OFF（关闭） |
| 休眠周期（Sleep Period） | N/A（不适用） |

各开关的具体功能见[用户手册（User Manual）](https://onlinedocs.microchip.com/oxy/GUID-346BCDAA-3BE2-4A0F-8F60-13EDF8CC90A1-en-US-1/index.html)。

<a id="wiring"></a>

## 76.4 接线（Wiring）

<a id="id2"></a>

**接线配置（Wiring Configuration）**

| MTCH9010信号（MTCH9010 Signal） | GPIO引脚（GPIO Pin） | 引脚方向（Pin Direction） | 示例是否必需（Required for example） |
| --- | --- | --- | --- |
| VDD | VCC | N/A（不适用） | Yes（是） |
| GND | GND | N/A（不适用） | Yes（是） |
| UART TX | PA18 | `GPIO_OUTPUT`（输出） | Yes（是） |
| UART RX | PA19 | `GPIO_INPUT`（输入） | Yes（是） |
| 唤醒（Wake） | PB14 | `GPIO_OUTPUT`（输出） | Yes（是） |
| 检测输出（Output） | PB15 | `GPIO_INPUT`（输入） | No（否） |
| 心跳（Heartbeat） | PA20 | `GPIO_INPUT`（输入） | No（否） |

> 译注——引脚方向：表格按原页保留，PA／PB名称是SAM L21一侧引脚；`GPIO_OUTPUT`／`GPIO_INPUT`应结合主机方向理解，UART发送与接收须交叉连接到对端。当前两份覆盖文件将唤醒设置为PB14低电平有效，将检测输出和心跳分别设置为PB15、PA20高电平有效。连接时同时核对评估板接口定义。

<a id="building-and-running"></a>

## 76.6 构建与运行（Building and Running）

> 译注——执行位置：主机构建命令从读者自己的Zephyr源码根目录执行；Windows使用UCRT64 Bash，Linux使用原生Bash，主机工具、模块与目标工具链先按官方入门说明准备。读取真实传感器还需要对应目标板、设备树节点和接线；下面的命令与日志来自官方文档，本次没有执行硬件实验。

需要将MTCH9010连接到开发板上**不承担控制台功能的UART总线**。示例为[SAM L21 Xplained Pro评估板](https://docs.zephyrproject.org/latest/boards/atmel/sam0/saml21_xpro/doc/index.html#saml21_xpro)提供两份覆盖文件，分别对应以下两种模式。

<a id="tab-0-0-0"></a>

<a id="panel-0-0-0"></a>

### 76.6.1 电容式液体检测（Capacitive Liquid Mode）

```sh
# From the root of the zephyr repository
west build -b saml21_xpro samples/sensor/mtch9010 -- -DDTC_OVERLAY_FILE=capacitive.overlay
west flash
```

<a id="tab-0-0-1"></a>

<a id="panel-0-0-1"></a>

### 76.6.2 电导式液体检测（Conductive Liquid Mode）

```sh
# From the root of the zephyr repository
west build -b saml21_xpro samples/sensor/mtch9010 -- -DDTC_OVERLAY_FILE=conductive.overlay
west flash
```

> 译注——配置与复位：两份覆盖文件采用38400波特率，启用UART配置及扩展输出，检测阈值均为100，区别在于检测模式。当前`prj.conf`关闭启动时复位选项，因此原文要求的传感器先复位不能被“只复位主控”替代。
