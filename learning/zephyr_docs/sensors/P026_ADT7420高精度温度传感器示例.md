# 第26章\_ADT7420高精度温度传感器示例

原文：[官方页面](https://docs.zephyrproject.org/latest/samples/sensor/adt7420/README.html)。读取日期：2026-10-14；保存的latest页面及HTML摘要见[来源记录](../SOURCES.md)。

<a id="description"></a>

## 26.1 说明（Description）

本示例以1 Hz周期测量环境温度（Ambient temperature），单位为摄氏度（Degrees Celsius），并将结果写到控制台。

配置为触发模式（Trigger mode）时，更新间隔为5秒；示例围绕最近一次温度维持±1 °C的窗口（Window）。温度一旦越过窗口边界，中断就使应用显示事件并更新窗口的上下限。

ADT7420属于ADT74XX器件系列。其他受支持的器件包括ADT7410及ADT7422，它们分别使用各自的设备树兼容标识（Devicetree compatible）配置硬件温度限值。

> 译注——窗口与当前实现：原文的±1 °C按原样保留；本次核对的`main.c`中`TEMP_WINDOW_HALF_UCEL=500000`对应±0.5 °C。当前代码还增加了采样频率、上下阈值、迟滞（Hysteresis）和告警状态的设置／读取，输出不再只有原文中的温度行。主循环1秒或5秒的等待也不等于传感器内部转换频率，当前代码另请求240 mHz的采样频率。

## 26.3 接线（Wiring）

示例通过I2C接口控制ADT7420。连接电源引脚`VDD`、`GND`和接口引脚`SDA`、`SCL`；可选地将`INT`连接到支持中断的GPIO。供电电压范围为2.7—5.5 V。根据所用底板，SDA和SCL可能需要上拉电阻（Pull-up resistor）。

<a id="building-and-running"></a>

## 26.4 构建与运行（Building and Running）

> 译注——执行位置：主机构建命令从读者自己的Zephyr源码根目录执行，使用已完成官方入门配置的UCRT64 Bash或Linux Bash终端。构建成功只表示固件生成；烧录和读取真实温湿度还需要正确的目标板、传感器节点及接线。若设备未就绪或读取失败，先检查节点状态、驱动配置和总线连接。

项目将传感器数据输出到控制台，需要实际ADT7420传感器。原文说明它应可用于具有I2C外设接口的平台，但不能在QEMU中运行。以下示例使用[nRF52 DK](https://docs.zephyrproject.org/latest/boards/nordic/nrf52dk/doc/index.html#nrf52dk)：

```sh
# From the root of the zephyr repository
west build -b nrf52dk/nrf52832 samples/sensor/adt7420
west flash
```

> 译注——源码核对边界：当前入口通过`temp-sensor`别名选择设备。当前代码将`T_HIGH_CEL`定义为15、`T_LOW_CEL`定义为40，并分别写入上／下阈值；触发分支重设窗口前，温度变量还被告警属性读取复用。这些行为与上方窗口描述并不完全一致，不能把保留的旧输出当作当前触发流程已经验证；本次仅记录差异，没有修改或执行该示例。
