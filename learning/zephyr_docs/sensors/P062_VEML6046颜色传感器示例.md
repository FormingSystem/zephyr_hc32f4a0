# 第62章\_VEML6046颜色传感器示例

原文：[官方页面](https://docs.zephyrproject.org/latest/samples/sensor/veml6046/README.html)。读取日期：2026-10-14；保存的latest页面及HTML摘要见[来源记录](../SOURCES.md)。

<a id="overview"></a>

## 62.1 概述（Overview）

本示例遍历传感器属性的所有可能组合，测量红、绿、蓝及红外光（Red, Green, Blue and Infrared，RGBIR）。属性包括：

- 积分时间（Integration time）。
- 有效光电二极管面积（Effective photodiode size）。
- 增益（Gain）。

这些属性用于让传感器工作在合适的测量范围内。光照读数达到最大原始值`0xFFFF`时，会返回错误，向应用表示超出范围。程序将原始值与属性一起输出，帮助选择合适的设置。

原文说明当时尚不支持中断和触发模式（Interrupt/Trigger mode），计划在后续开发中提供。

<a id="requirements"></a>

## 62.2 要求（Requirements）

示例通过Olimex-STM32-E407开发板的I2C-2接口控制VEML6046，使用原文所述Feather连接器上的PF0和PF1引脚。

> 译注——板级定义：当前覆盖文件将PF0用于SDA、PF1用于SCL，在`i2c2`下定义地址为`0x29`、标签为`rgbir`的节点。主函数使用这个节点标签；它与上一章VEML6031示例的`light`标签不同。

## 62.4 构建与运行（Building and Running）

> 译注——执行位置：主机构建命令从读者自己的Zephyr源码根目录执行，使用已完成官方入门配置的UCRT64 Bash或Linux Bash终端。读取真实传感器还需要对应目标板、设备树节点和接线；下面的命令与日志来自官方文档，本次没有执行硬件实验。

项目向控制台输出传感器数据，需要将VEML6046连接到目标板。

```sh
# From the root of the zephyr repository
west build -b olimex_stm32_e407 samples/sensor/veml6046/
west flash
```

### 62.4.1 示例输出（Sample Output）

```text
Test all attributes for a good guess of attribute usage away of saturation.
Red:     68 lx (    51) green:      68 lx (    84) blue:     68 lx (    51) IR:      68 lx (    27)   it: 0 pdd: 0 gain: 0  --
Red:    121 lx (   181) green:     121 lx (   347) blue:    121 lx (   240) IR:     121 lx (    53)   it: 0 pdd: 0 gain: 1  --
Red:    215 lx (   106) green:     215 lx (   226) blue:    215 lx (   160) IR:     215 lx (    19)   it: 0 pdd: 0 gain: 2  --
Red:    201 lx (    75) green:     201 lx (   156) blue:    201 lx (   112) IR:     201 lx (    14)   it: 0 pdd: 0 gain: 3  --
[...]
Test finished.
```

> 译注——读数与属性：每个颜色／红外通道显示换算值以及括号中的原始计数；`it`、`pdd`、`gain`是当前属性编码。`pdd`选择完整或一半光电二极管面积。当前源码分别读取红、绿、蓝和红外通道，原日志中各换算值相同不代表这些通道必然相等，也不应覆盖对应原始计数。

> 译注——运行范围：示例遍历属性组合后结束，`-E2BIG`会显示为`OVERFLOW`。原文的`[...]`是已经存在的输出省略标记；这里保留原输出范围，没有人为缩短或补造读数。
