# 第35章\_TMP108温度传感器示例

原文：[官方页面](https://docs.zephyrproject.org/latest/samples/sensor/tmp108/README.html)。读取日期：2026-10-14；保存的latest页面及HTML摘要见[来源记录](../SOURCES.md)。

<a id="description"></a>

## 35.1 说明（Description）

本示例每3秒向控制台输出一次温度。源码包含用于打开／关闭已配置告警的宏定义，以及低功耗单次转换模式（Low-power one-shot mode）的用法。

<a id="requirements"></a>

## 35.2 要求（Requirements）

开发板的[设备树（Devicetree）](../devicetree/P013_设备树文档入口.md#dt-guide)中应已包含[ti,tmp108](../sensor_ti_vishay_wurth_sensing_binding_reference/P006_ti_tmp108.md#std-dtcompatible-ti-tmp108)、[ams,as6212](../sensor_adi_accel_bioz_binding_reference/P029_ams_as6212.md#std-dtcompatible-ams-as6212)或[ams,as6221](../sensor_adi_accel_bioz_binding_reference/P030_ams_as6221.md#std-dtcompatible-ams-as6221)节点之一，或者通过设备树覆盖文件添加相应节点。

> 译注——当前配置入口：应用依次查找上述三种兼容设备。`CONFIG_APP_REPORT_TEMP_ALERTS`控制温度告警，`CONFIG_APP_ENABLE_ONE_SHOT`控制单次转换，两项默认都关闭。单次模式由获取请求启动转换，数据就绪回调输出温度；持续转换模式在主循环读取后休眠3秒。高／低温阈值选项为`CONFIG_APP_TEMP_ALERT_HIGH_THRESH`和`CONFIG_APP_TEMP_ALERT_LOW_THRESH`，默认26 °C及18 °C；其Kconfig提示里的`RH [%]`是标签错误，这里设置的是摄氏温度而非相对湿度。
