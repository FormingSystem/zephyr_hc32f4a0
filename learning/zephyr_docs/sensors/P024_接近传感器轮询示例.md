# 第24章\_接近传感器轮询示例

原文：[官方页面](https://docs.zephyrproject.org/latest/samples/sensor/proximity_polling/README.html)。读取日期：2026-10-14；保存的latest页面及HTML摘要见[来源记录](../SOURCES.md)。

<a id="overview"></a>

## 24.1 概述（Overview）

本示例演示一个或多个接近传感器（Proximity sensor）的使用。

<a id="building-and-running"></a>

## 24.2 构建与运行（Building and Running）

> 译注——命令位置：以下主机构建命令从读者自己的Zephyr源码根目录执行，使用已完成官方入门配置的UCRT64 Bash或Linux Bash终端。代码中的`<board to use>`、`<your_board>`等是待替换占位符；设备树片段属于覆盖文件内容，不是Shell命令。构建成功只说明固件生成，烧录和传感器输出需要实际目标硬件及接线。出现设备未就绪或读取错误时，先核对别名、节点启用状态、驱动配置及总线连接。

示例最多支持10个接近传感器。设备数量自动从设备树检测；原文要求设置`prox-sensor-0`至`prox-sensor-9`别名。例如：

```devicetree
/ {
           aliases {
                   prox-sensor0 = &tmd2620;
           };
};
```

> 译注——别名拼写：原文说明中的`prox-sensor-0`与代码块中的`prox-sensor0`不一致。当前实现以`DT_ALIAS(_CONCAT(prox_sensor, i))`枚举节点，实际需要的是`prox-sensor0`至`prox-sensor9`，数字前没有额外连字符。应采用原代码块中的拼写。

创建设备树覆盖文件后，构建示例：

```sh
west build -b <your_board> samples/sensor/proximity_polling
west flash
```

<a id="sample-output"></a>

### 24.2.1 示例输出（Sample Output）

```text
*** Booting Zephyr OS build zephyr-v3.2.0-210-gd95295f08646  ***
Proximity sensor sample application
Found 1 proximity sensor(s): tmd2620@29
Proximity on tmd2620@29: 202
Proximity on tmd2620@29: 205
Proximity on tmd2620@29: 204
Proximity on tmd2620@29: 60
Proximity on tmd2620@29: 1
```

> 译注——结果含义：当前程序每轮休眠2000毫秒，再读取`SENSOR_CHAN_PROX`并打印整数值。接近读数不等于以米表示的距离；解释其范围及含义应依据所选传感器驱动，不能直接与距离测量示例混用。
