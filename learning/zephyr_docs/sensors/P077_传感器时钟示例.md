# 第77章\_传感器时钟示例

原文：[官方页面](https://docs.zephyrproject.org/latest/samples/sensor/clock/README.html)。读取日期：2026-10-14；保存的latest页面及HTML摘要见[来源记录](../SOURCES.md)。

<a id="overview"></a>

## 77.1 概述（Overview）

本示例演示如何选择传感器时钟源（Sensor clock source），并使用传感器时钟API（Sensor Clock API）进行测试和调试。

<a id="building-and-running"></a>

## 77.2 构建与运行（Building and Running）

> 译注——执行位置：主机构建命令从读者自己的Zephyr源码根目录执行；Windows使用UCRT64 Bash，Linux使用原生Bash，先按官方入门说明准备主机工具、模块与目标工具链。原生模拟目标还须满足相应主机环境要求；硬件分支需要目标板、设备树节点和接线。下方命令及日志来自官方文档，本次没有运行模拟器或硬件实验。

以下示例使用[nRF52840 DK](https://docs.zephyrproject.org/latest/boards/nordic/nrf52840dk/doc/index.html#nrf52840dk)和[nRF52833 DK](https://docs.zephyrproject.org/latest/boards/nordic/nrf52833dk/doc/index.html#nrf52833dk)开发板。运行前，在下列Kconfig选项中选择一个：

- [`CONFIG_SENSOR_CLOCK_COUNTER`](https://docs.zephyrproject.org/latest/kconfig.html#CONFIG_SENSOR_CLOCK_COUNTER)：计数器时钟（Counter）。
- [`CONFIG_SENSOR_CLOCK_RTC`](https://docs.zephyrproject.org/latest/kconfig.html#CONFIG_SENSOR_CLOCK_RTC)：实时时钟（Real-Time Clock，RTC）。
- [`CONFIG_SENSOR_CLOCK_SYSTEM`](https://docs.zephyrproject.org/latest/kconfig.html#CONFIG_SENSOR_CLOCK_SYSTEM)：系统时钟（System clock）。

使用以下命令构建并运行示例：

```sh
# From the root of the zephyr repository
west build -b <board to use> samples/sensor/clock
west flash
```

> 译注——目标与时钟节点：`<board to use>`是原文占位符，应替换为实际目标，例如`nrf52840dk/nrf52840`。当前`prj.conf`默认选择计数器时钟；官方测试定义还为计数器／RTC分支组合板级覆盖文件和对应时钟覆盖文件，通过`zephyr,sensor-clock`分别选择`timer0`或`rtc0`。仅选择板名并不等于已经选定外设时钟节点，应按所选时钟分支配置。

<a id="sample-output"></a>

### 77.2.1 示例输出（Sample Output）

应用打印当前传感器时钟的周期计数（Cycles），以及换算后的纳秒（Nanoseconds）时间。

```text
Cycles: 143783087
Nanoseconds: 8986442937
Cycles: 159776386
Nanoseconds: 9986024125
Cycles: 175772543
Nanoseconds: 10985783937
Cycles: 191771203
Nanoseconds: 11985700187
Cycles: 207758870
Nanoseconds: 12984929375
Cycles: 223752074
Nanoseconds: 13984504625

...
```

> 译注——读数含义：当前程序每轮先休眠1000 ms，再调用`sensor_clock_get_cycles()`取得计数，并通过`sensor_clock_cycles_to_ns()`换算。输出是同一次计数对应的时间，不是每轮相邻两次读数之差；变量名`delta_ns`也不改变这一点。读取失败时报告错误并进入下一轮。
