# 第12章\_六自由度运动数据就绪示例

原文：[官方页面](https://docs.zephyrproject.org/latest/samples/sensor/6dof_motion_drdy/README.html)。读取日期：2026-10-14；保存的latest页面及HTML摘要见[来源记录](../SOURCES.md)。

<a id="overview"></a>

## 12.1 概述（Overview）

本示例周期性地以100 Hz测量六轴惯性测量单元（Inertial Measurement Unit，IMU）的温度、加速度与角速度，并在控制台显示数值及自启动以来的时间戳。触发选项可以通过Kconfig配置。

<a id="wiring"></a>

## 12.2 接线（Wiring）

示例使用外接传感器转接板（Breakout）。需要提供设备树覆盖文件（Devicetree overlay），描述六轴运动传感器、SPI或I2C总线接口，以及传感器中断所接的GPIO。

<a id="building-and-running"></a>

## 12.3 构建与运行（Building and Running）

> 译注——命令位置：以下主机构建命令从读者自己的Zephyr源码根目录执行，使用已完成官方入门配置的UCRT64 Bash或Linux Bash终端。设备树片段属于覆盖文件内容，不是Shell命令。构建成功只说明固件生成，烧录和传感器输出需要实际目标硬件及接线。出现设备未就绪或读取错误时，先核对别名、节点启用状态、驱动配置及总线连接。

本示例面向六轴IMU设备。原文要求为设备设置`6dof-motion-drdyN`别名，其中`N`从`0`到`9`。例如：

```devicetree
/ {
       aliases {
                       6dof-motion-drdy0 = &icm42670p;
               };
       };
```

确认设备树包含别名后，构建并运行：

```sh
# From the root of the zephyr repository
west build -b nrf52dk/nrf52832 samples/sensor/6dof_motion_drdy
west flash
```

> 译注——当前实例与采样节奏：当前`get_6dof_motion_device()`只取得`DT_ALIAS(6dof_motion_drdy0)`，没有遍历0—9的多实例数组，因此原文别名范围不能作为多设备已实现的证明。应用注册`SENSOR_TRIG_DATA_READY`回调，回调读取样本，主循环在标志置位后打印；100 Hz是原文说明，实际数据率还取决于所选传感器配置和事件处理，不是主循环里固定10毫秒的休眠。
