# 第84章\_TDK\_TAD2144隧道磁阻角度传感器示例

原文：[官方页面](https://docs.zephyrproject.org/latest/samples/sensor/tad2144/README.html)。读取日期：2026-10-14；保存的latest页面及HTML摘要见[来源记录](../SOURCES.md)。

<a id="overview"></a>

## 84.1 概述（Overview）

本示例演示TDK Invensense基于隧道磁阻（Tunnel Magneto Resistance，TMR）的TAD2144角度传感器。角度检测提供可配置的数字输出（Configurable digital outputs）：

- SPI：1 kHz～10 MHz。
- I2C：400 kHz或1 MHz。
- 编码器（Encoder）：A、B和Z信号。

SPI和I2C可读取角度及温度；编码器接口只提供角度数据。

<a id="wiring"></a>

## 84.2 接线（Wiring）

示例需要外接传感器转接板，并提供设备树覆盖文件定义SPI、I2C或编码器接口。

**情况1：I2C接口（I2C Interface）**

- `SDA/SCL`：I2C总线引脚。
- 中断GPIO（Interrupt GPIO）：数据就绪信号（Data Ready，DRDY）。
- `SA1/SA2` GPIO：设备地址选择引脚。

**情况2：SPI接口（SPI Interface）**

- `MOSI/MISO/SCK`：SPI总线引脚。
- `CS` GPIO：片选（Chip Select）引脚。
- 中断GPIO：DRDY信号。

**情况3：编码器接口（Encoder Interface）**

将A相`Phase A (MOSI)`、B相`Phase B (MISO)`及索引`Index Z (SCK)`连接到编码器输入引脚。

<a id="building-and-running"></a>

## 84.3 构建与运行（Building and Running）

> 译注——执行位置：主机构建命令从读者自己的Zephyr源码根目录执行；Windows使用UCRT64 Bash，Linux使用原生Bash，先按官方入门说明准备主机工具、模块与目标工具链。原生模拟目标还须满足相应主机环境要求；硬件分支需要目标板、设备树节点和接线。下方命令及日志来自官方文档，本次没有运行模拟器或硬件实验。

提供指定传感器位置的设备树覆盖文件后，用以下命令构建示例：

```sh
# From the root of the zephyr repository
west build -b nrf52840dk/nrf52840 samples/sensor/tad2144
west flash
```

> 译注——选择接口：随附覆盖文件分别以`_i2c.overlay`、`_spi.overlay`及`_enc.overlay`结尾。原命令没有显式选择其中之一；使用时应通过构建的覆盖文件选项选定与接线一致的文件，不能将三种接口配置同时照搬。当前代码尝试设置100 Hz输出数据率（Output Data Rate，ODR）及连续模式，属性值采用驱动枚举编码；编码器模式不支持这两项配置，会报告相应提示。

<a id="sample-output"></a>

### 84.3.1 示例输出（Sample Output）

```text
*** Booting Zephyr OS build v3.x.x ***
Found device "tad2144_encoder", getting sensor data
Angle: -101.43, Temp: 28.00 C
Angle: -101.42, Temp: 28.00 C
```

> 译注——原日志与当前转换：原日志设备名为`tad2144_encoder`，却同时打印温度；当前编码器轮询函数只打印角度，不能由这份旧日志推断编码器接口能测温。另一个源码差异是驱动按百万分之一构造`sensor_value.val2`，而示例以`100000.0f`为除数拼接角度和温度，小数部分会放大10倍。通用`sensor_value`定义使用百万分之一，应按当前驱动表示核对转换，不能直接把该示例打印值作为正确标定结果。本页保留原输出，未修改驱动或示例代码。
