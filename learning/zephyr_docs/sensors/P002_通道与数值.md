# 第2章\_通道与数值

原文：[Sensor Channels](https://docs.zephyrproject.org/latest/hardware/peripherals/sensor/channels.html)。读取日期：2026-10-12，`latest`。

## 2.1\_通道表示可测量的量

**通道（Channel）**由枚举类型 [`sensor_channel`](https://docs.zephyrproject.org/latest/doxygen/html/group__sensor__interface.html#gaaa1b502bc029b10d7b23b0a25ef4e934) 列出，表示传感器能够测量的物理量。

一个传感器可以有多个通道：有时对应同一物理量的不同轴，例如三个方向的加速度；有时对应完全不同的物理量，例如环境温度、压力和湿度。同一设备也可以有多个相同测量类型的通道，用于多路温度、光强、电流、电压或电容测量。

## 2.2\_类型与索引共同确定通道

Zephyr 用结构体 [`sensor_chan_spec`](https://docs.zephyrproject.org/latest/doxygen/html/structsensor__chan__spec.html) 指定通道，其中同时包含通道类型 `sensor_channel` 和通道索引。原文指出，Zephyr 3.7 引入该结构之后，只用类型枚举标识通道的接口应视作历史形式。

> 译注：索引是同一测量类型下的通道编号，不是物理引脚号，也不是总线地址。旧的 Fetch and Get 接口仍使用类型枚举；不能把一个结构体直接传给仍要求枚举的函数。应按实际使用的接口签名区分，见[获取与读取](P004_获取与读取.md)及[读取与解码](P006_读取与解码.md)。
