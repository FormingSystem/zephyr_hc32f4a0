# 第41章\_I3G4250D三轴陀螺仪示例

原文：[官方页面](https://docs.zephyrproject.org/latest/samples/sensor/i3g4250d/README.html)。读取日期：2026-10-14；保存的latest页面及HTML摘要见[来源记录](../SOURCES.md)。

<a id="description"></a>

## 41.1 说明（Description）

本示例将I3G4250D三轴陀螺仪（3-axis gyroscope）配置为固定采样率，以相同频率轮询（Polling）测量结果，并显示测量值及自启动以来的时间戳（Timestamp）。

> 译注——原文与当前实现：上面的“相同频率”是原文描述。当前`main.c`按`SAMPLING_INTERVAL_MS=10`请求100 Hz传感器采样率，但主循环按`DISPLAY_INTERVAL_MS=50`休眠，即约每50毫秒加上读取／打印耗时输出一次。主函数也没有处理采样率设置函数的返回值；请求设置不等于已经确认生效。下方旧日志中的200 Hz不能作为当前程序的实际频率依据。

<a id="requirements"></a>

## 41.2 要求（Requirements）

本示例使用通过SPI接口连接的I3G4250D。例如，`stm32f3_disco@E`开发板修订版的设备树（Devicetree）就是这种连接方式。

<a id="building-and-running"></a>

## 41.3 构建与运行（Building and Running）

> 译注——执行位置：主机构建命令从读者自己的Zephyr源码根目录执行，终端及工具链按官方入门说明准备。读取真实传感器还需要对应目标板、设备树节点和接线；下面的命令与日志来自官方文档，本次没有执行硬件实验。

构建应用时，必须选择通过SPI连接I3G4250D的开发板，或者提供自定义设备树覆盖文件（Devicetree overlay）。这里使用STM32F3 Discovery开发板：

```sh
# From the root of the zephyr repository
west build -b stm32f3_disco@E samples/sensor/i3g4250d
west flash
```

> 译注——开发板修订版：命令中的`@E`属于原文目标名称的一部分，表示板级修订版；它不是本仓库目录或任意可省略的后缀。应根据实际硬件选择相符的板目标及覆盖文件。
