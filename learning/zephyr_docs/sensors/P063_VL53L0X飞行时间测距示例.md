# 第63章\_VL53L0X飞行时间测距示例

原文：[官方页面](https://docs.zephyrproject.org/latest/samples/sensor/vl53l0x/README.html)。读取日期：2026-10-14；保存的latest页面及HTML摘要见[来源记录](../SOURCES.md)。

<a id="overview"></a>

## 63.1 概述（Overview）

本示例周期性测量VL53L0X飞行时间传感器（Time-of-Flight sensor，ToF）与目标之间的距离，并将结果显示到控制台。它演示全部可用通道（Channel），包括器件专用通道（Private channel）。

<a id="requirements"></a>

## 63.2 要求（Requirements）

示例通过I2C接口控制VL53L0X。

<a id="references"></a>

## 63.3 参考资料（References）

VL53L0X：[ST官方产品资料](https://www.st.com/en/imaging-and-photonics-solutions/vl53l0x.html)。

<a id="building-and-running"></a>

## 63.4 构建与运行（Building and Running）

> 译注——执行位置：主机构建命令从读者自己的Zephyr源码根目录执行，使用已完成官方入门配置的UCRT64 Bash或Linux Bash终端。读取真实传感器还需要对应目标板、设备树节点和接线；下面的命令与日志来自官方文档，本次没有执行硬件实验。

项目向控制台输出传感器数据，需要VL53L0X；`disco_l475_iot1`开发板具有该传感器。

```sh
# From the root of the zephyr repository
west build -b None samples/sensor/vl53l0x/
west flash
```

> 译注——目标板：原命令的`None`不是有效板名，应替换为实际目标。当前官方测试定义将`disco_l475_iot1`列为集成测试平台，并要求I2C及VL53L0X支持；构建前还需满足相应设备树配置和实物连接条件。

<a id="sample-output"></a>

### 63.4.1 示例输出（Sample Output）

```text
prox is 0
distance is 1874 mm
Max distance is 000 mm
Signal rate is 33435 Cps
Ambient rate is 17365 Cps
SPADs used: 195
Status: OK

prox is 0
distance is 1888 mm
Max distance is 000 mm
Signal rate is 20846 Cps
Ambient rate is 25178 Cps
SPADs used: 195
Status: OK

<repeats endlessly every 5 seconds>
```

以上输出每5秒不断重复（`<repeats endlessly every 5 seconds>`）。

> 译注——单位与状态：当前实现通过`sensor_value_to_milli()`将以米表示的距离转换成毫米后打印；`Cps`表示每秒计数（Counts per second），`SPADs used`表示本次测量使用的有效单光子雪崩二极管（Single-Photon Avalanche Diode，SPAD）数量。`Status: OK`对应`VL53L0X_RANGE_STATUS_RANGE_VALID`；其他状态打印错误码。`Max distance is 000 mm`是原日志内容，不能解释为该器件标称最大量程为零。
