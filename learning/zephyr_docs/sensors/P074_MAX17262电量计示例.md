# 第74章\_MAX17262电量计示例

原文：[官方页面](https://docs.zephyrproject.org/latest/samples/sensor/max17262/README.html)。读取日期：2026-10-14；保存的latest页面及HTML摘要见[来源记录](../SOURCES.md)。

<a id="overview"></a>

## 74.1 概述（Overview）

本示例周期性读取MAX17262的电压、电流及温度，分别使用`SENSOR_CHAN_GAUGE_VOLTAGE`、`SENSOR_CHAN_GAUGE_AVG_CURRENT`和`SENSOR_CHAN_GAUGE_TEMP`通道。

<a id="requirements"></a>

## 74.2 要求（Requirements）

MAX17262是实现Maxim ModelGauge m5算法的超低功耗电量计集成电路（Fuel-gauge IC）。它监测单节电池组（Single-cell battery pack），内部电流检测支持最高3.1 A脉冲电流；对容量100 mAhr至6 Ahr的电池可提供最佳性能。

开发板应具有Arduino连接器配置，并为I2C接口定义节点别名。节点结构可参阅官方[`samples/sensor/max17262/app.overlay`](https://github.com/zephyrproject-rtos/zephyr/blob/main/samples/sensor/max17262/app.overlay)。

<a id="building-and-running"></a>

## 74.3 构建与运行（Building and Running）

> 译注——执行位置：主机构建命令从读者自己的Zephyr源码根目录执行；Windows使用UCRT64 Bash，Linux使用原生Bash，主机工具、模块与目标工具链先按官方入门说明准备。读取真实传感器还需要对应目标板、设备树节点和接线；下面的命令与日志来自官方文档，本次没有执行硬件实验。

<a id="id2"></a>

通过I2C将MAX17262传感器连接到开发板；按[MAX17262数据手册](https://datasheets.maximintegrated.com/en/ds/MAX17262.pdf)中的连接图接线，见[注1](#id1)。

```sh
west build -b nrf52840dk/nrf52840 samples/sensor/max17262
west flash
```

<a id="sample-output"></a>

### 74.3.1 示例输出（Sample Output）

可以使用任意串口控制台程序检查输出。原文使用`picocom`连接串口`/dev/ttyUSB0`：

```sh
$ sudo picocom -D /dev/ttyUSB0
```

> 译注——串口命令：这一段是原文Linux串口示例，`/dev/ttyUSB0`是设备节点，不是作者仓库地址。当前[picocom官方手册](https://raw.githubusercontent.com/npat-efault/picocom/master/picocom.1.md)把设备名作为位置参数，未列出原命令中的`-D`选项；使用时按已安装版本的帮助选择实际设备和波特率。保留原命令供对照，不将它视为已经验证可运行的命令。

```text
V: 3.626406 V; I: -3.437500 mA; T: 28.011718 °C
V: 3.626406 V; I: -3.437500 mA; T: 28.011718 °C
V: 3.626406 V; I: -3.437500 mA; T: 28.011718 °C
```

> 译注——电流单位：当前MAX17262驱动将平均电流从nA换算为mA，示例按mA打印；这里不能直接套用其他电量计示例的A单位。主程序每次显示后休眠1秒。覆盖文件还包含电池设计参数，应按实际电池规格配置，不能将示例数值当作所有电池的通用值。
