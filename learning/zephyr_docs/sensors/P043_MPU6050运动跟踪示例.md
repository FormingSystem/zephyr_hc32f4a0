# 第43章\_MPU6050运动跟踪示例

原文：[官方页面](https://docs.zephyrproject.org/latest/samples/sensor/mpu6050/README.html)。读取日期：2026-10-14；保存的latest页面及HTML摘要见[来源记录](../SOURCES.md)。

<a id="description"></a>

## 43.1 说明（Description）

本示例以0.5 Hz周期测量MPU6050的传感器温度（Temperature）、加速度（Acceleration）和角速度（Angular velocity），在控制台显示读数及自启动以来的时间戳（Timestamp）。

启用触发模式（Triggered mode）后，原文说明测量值以32 Hz显示，该频率由传感器内部时钟和分频器（Divider）决定。

> 译注——默认模式与频率：当前`prj.conf`设置`CONFIG_MPU6050_TRIGGER_NONE=y`，主循环每次读取后休眠2秒。启用触发功能时则注册数据就绪触发器，回调读取传感器；主函数不再持续轮询。驱动从设备配置取得采样分频值并写入寄存器，32 Hz是原文所述配置下的频率，不能直接推广到所有设备树配置。

<a id="wiring"></a>

## 43.2 接线（Wiring）

示例使用外接传感器转接板（Breakout board）。必须提供设备树覆盖文件（Devicetree overlay），标识控制传感器使用的I2C总线及GPIO。

<a id="building-and-running"></a>

## 43.3 构建与运行（Building and Running）

> 译注——执行位置：主机构建命令从读者自己的Zephyr源码根目录执行，终端及工具链按官方入门说明准备。读取真实传感器还需要对应目标板、设备树节点和接线；下面的命令与日志来自官方文档，本次没有执行硬件实验。

提供说明传感器连接位置的设备树覆盖文件后，使用以下命令构建本示例应用：

```sh
# From the root of the zephyr repository
west build -b nrf52dk/nrf52832 samples/sensor/mpu6050
west flash
```
