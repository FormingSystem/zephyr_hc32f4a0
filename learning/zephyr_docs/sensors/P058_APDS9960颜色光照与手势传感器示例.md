# 第58章\_APDS9960颜色光照与手势传感器示例

原文：[官方页面](https://docs.zephyrproject.org/latest/samples/sensor/apds9960/README.html)。读取日期：2026-10-14；保存的latest页面及HTML摘要见[来源记录](../SOURCES.md)。

<a id="overview"></a>

## 58.1 概述（Overview）

本示例演示如何使用APDS9960传感器取得环境光（Ambient light）、红绿蓝（Red, Green, Blue，RGB）及接近度（Proximity）或手势（Gesture）数据。原文说明示例采用轮询模式（Polling mode），不使用中断触发。

<a id="building-and-running"></a>

## 58.2 构建与运行（Building and Running）

> 译注——执行位置：主机构建命令从读者自己的Zephyr源码根目录执行，使用已完成官方入门配置的UCRT64 Bash或Linux Bash终端。读取真实传感器还需要对应目标板、设备树节点和接线；下面的命令与日志来自官方文档，本次没有执行硬件实验。

示例需要将APDS9960连接到开发板；连接示例可参阅原文所引的[SparkFun APDS9960资料](https://www.sparkfun.com/products/12787)。

```sh
west build -b reel_board samples/sensor/apds9960
west flash
```

> 译注——当前实现与默认配置：当前源码还保留接近阈值触发分支，以及设备挂起／恢复（Suspend/Resume）分支；普通轮询分支每次读取前休眠5秒。随附`prj.conf`关闭全局线程触发、设备电源管理和手势功能，测试定义另有启用触发的配置。正文概述中的RGB能力不等于本应用已打印三个独立颜色通道：当前主函数读取的是环境光、接近度和手势通道。

<a id="sample-output"></a>

### 58.2.1 示例输出（Sample Output）

```text
ambient light intensity without trigger is 387
proxy without trigger is 115
ambient light intensity without trigger is 386
proxy without trigger is 112
ambient light intensity without trigger is 386
```

> 译注——输出版本：上述日志按原页保留。当前实现把环境光、接近度和手势名称合并到同一行；但默认配置关闭手势功能，而代码没有检查每次通道读取的返回值，不能仅凭存在手势列就认定该配置已经获得有效手势结果。
