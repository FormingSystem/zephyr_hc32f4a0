# 第34章\_温度计示例

原文：[官方页面](https://docs.zephyrproject.org/latest/samples/sensor/thermometer/README.html)。读取日期：2026-10-14；保存的latest页面及HTML摘要见[来源记录](../SOURCES.md)。

<a id="overview"></a>

## 34.1 概述（Overview）

本温度计（Thermometer）示例以1 Hz周期测量环境温度，并将结果写到控制台。

<a id="wiring"></a>

## 34.2 接线（Wiring）

- `VDD`接到2.3—5.5 V电源。
- `GND`接到0 V。
- `VOUT`接到模数转换器（ADC）的输入引脚。

示例为`nrf52840dk/nrf52840`提供了覆盖文件，传感器接到`AIN7`。

> 译注——适用器件：该覆盖文件描述的是`microchip,mcp970x`节点，`family`为`MCP9700/9700A`，通过`io-channels = <&adc 7>`接入ADC。上面的三引脚模拟接线属于此示例硬件，不能套用到所有提供环境温度通道的I2C或其他数字传感器。

<a id="building-and-running"></a>

## 34.3 构建与运行（Building and Running）

> 译注——执行位置：主机构建命令从读者自己的Zephyr源码根目录执行，使用已完成官方入门配置的UCRT64 Bash或Linux Bash终端。构建成功只表示固件生成；烧录和读取真实温湿度还需要正确的目标板、传感器节点及接线。若设备未就绪或读取失败，先检查节点状态、驱动配置和总线连接。

为`nrf52840dk/nrf52840`构建：

```sh
west build -b nrf52840dk/nrf52840 samples/sensor/thermometer
west flash
```

要使用其他开发板和环境温度传感器，启用支持`SENSOR_CHAN_AMBIENT_TEMP`的节点，通过覆盖文件创建`ambient-temp0`别名指向它。参考本示例的`boards/nrf52840dk_nrf52840.overlay`。

<a id="temperature-alert"></a>

### 34.3.1 温度告警（Temperature Alert）

如果连接的传感器支持温度超过上阈值或低于下阈值时发出告警，示例会启用传感器触发功能。这要求启用该传感器的`TRIGGER` Kconfig配置。`frdm_k22f`的示例配置见`boards/frdm_k22f.conf`。

> 译注——阈值参考点：当前实现先读取初始环境温度，再把下阈值设为初始温度加0.5 °C、上阈值设为加1.5 °C；不是围绕初始温度的对称窗口。程序尝试设置属性及触发回调，成功才打印相应启用消息。即使某传感器没有阈值触发支持，普通温度读取与告警能力也应分别判断。
