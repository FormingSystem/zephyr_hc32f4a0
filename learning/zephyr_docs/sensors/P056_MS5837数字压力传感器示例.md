# 第56章\_MS5837数字压力传感器示例

原文：[官方页面](https://docs.zephyrproject.org/latest/samples/sensor/ms5837/README.html)。读取日期：2026-10-14；保存的latest页面及HTML摘要见[来源记录](../SOURCES.md)。

<a id="overview"></a>

## 56.1 概述（Overview）

本示例每10秒从MS5837传感器读取压力（Pressure）与温度（Temperature），并将信息打印到UART串口控制台。

<a id="requirements"></a>

## 56.2 要求（Requirements）

<a id="id2"></a>

- [nRF52840开发套件（Development kit）](https://www.nordicsemi.com/Products/Development-hardware/nRF52840-DK)，见[参考资料1](#id1)。
- MS5837传感器。

<a id="wiring"></a>

## 56.3 接线（Wiring）

原文给出的nRF52840开发套件与MS5837连接关系如下：

| nRF52840引脚（Pin） | MS5837引脚（Pin） |
| --- | --- |
| `P0.3` | `SCL` |
| `P0.31` | `SDA` |

> 译注——原表与当前板级配置不一致：本次核对的示例覆盖文件启用`i2c1`。当前官方nRF52840 DK设备树将该控制器关联到`i2c1_default`，其引脚配置为SDA=P0.30、SCL=P0.31，与上表两项均不一致。上表为保留原文而列出；使用当前配置时应以实际合并后的设备树及板级引脚控制定义为准，不能直接照原表接线。SCL是串行时钟（Serial clock），SDA是串行数据（Serial data）。

<a id="building-and-running"></a>

## 56.4 构建与运行（Building and Running）

> 译注——执行位置：主机构建命令从读者自己的Zephyr源码根目录执行，终端及工具链按官方入门说明准备。读取真实传感器还需要对应目标板、设备树节点和接线；下面的命令与日志来自官方文档，本次没有执行硬件实验。

使用以下命令构建示例：

```sh
west build -b nrf52840dk/nrf52840 samples/sensor/ms5837
```

如何烧录生成的固件，参阅[nRF52840 DK](https://docs.zephyrproject.org/latest/boards/nordic/nrf52840dk/doc/index.html#nrf52840dk)文档。

> 译注——采样设置：当前实现先请求8192倍过采样（Oversampling），然后读取温度和压力，每轮休眠10000毫秒。原页面没有提供实际输出日志，本章不以人工生成的读数补齐它。
