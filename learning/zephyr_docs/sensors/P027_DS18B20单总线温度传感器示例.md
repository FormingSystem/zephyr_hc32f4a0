# 第27章\_DS18B20单总线温度传感器示例

原文：[官方页面](https://docs.zephyrproject.org/latest/samples/sensor/ds18b20/README.html)。读取日期：2026-10-14；保存的latest页面及HTML摘要见[来源记录](../SOURCES.md)。

<a id="overview"></a>

## 27.1 概述（Overview）

本示例说明如何使用Zephyr[传感器（Sensors）](P001_传感器驱动概览.md#sensor)API驱动访问[DS18B20](https://www.analog.com/en/products/ds18b20.html)单总线温度传感器（1-Wire temperature sensor）。

示例周期性读取系统中发现的第一个可用DS18B20设备，以轮询模式（Polling mode）检查传感器，不使用中断触发。

<a id="building-and-running"></a>

## 27.2 构建与运行（Building and Running）

> 译注——执行位置：主机构建命令从读者自己的Zephyr源码根目录执行，使用已完成官方入门配置的UCRT64 Bash或Linux Bash终端。构建成功只表示固件生成；烧录和读取真实温湿度还需要正确的目标板、传感器节点及接线。若设备未就绪或读取失败，先检查节点状态、驱动配置和总线连接。

设备树中必须存在已启用的节点，包含`compatible = "maxim,ds18b20";`。下方介绍常见配置。

如果开发板没有内置传感器，先按[DS18B20数据手册](https://www.analog.com/media/en/technical-documentation/data-sheets/ds18b20.pdf)第10页的硬件配置图（Hardware Configuration）连接传感器引脚。

<a id="boards-with-a-built-in-ds18b20-or-a-board-specific-overlay"></a>

### 27.2.1 内置传感器或提供专用覆盖文件的开发板（Boards with a built-in DS18B20 or a board-specific overlay）

开发板可能已经在默认设备树中配置DS18B20节点，也可能有包含该节点的板级覆盖文件。确认节点具有`status = "okay";`，然后构建并运行：

```sh
# From the root of the zephyr repository
west build -b nucleo_g0b1re samples/sensor/ds18b20
west flash
```

<a id="ds18b20-via-arduino-serial-pins"></a>

### 27.2.2 通过Arduino串口引脚连接DS18B20（DS18B20 via Arduino Serial pins）

必须准备外部电路，为1-Wire总线提供开漏接口（Open-drain interface）。将传感器和Arduino排针上的串口外设接入1-Wire总线后，原文给出的构建与烧录命令为：

```sh
# From the root of the zephyr repository
west build -b None samples/sensor/ds18b20 -- -DDTC_OVERLAY_FILE=arduino_serial.overlay
west flash
```

设备树覆盖文件[samples/sensor/ds18b20/arduino_serial.overlay](https://github.com/zephyrproject-rtos/zephyr/blob/main/samples/sensor/ds18b20/arduino_serial.overlay)应适用于已正确配置Arduino引脚兼容串口外设的开发板。

> 译注——原命令的板名：`-b None`是原页面生成命令中缺失板名的结果，`None`不是应填写的目标板。复现时必须把它替换为实际具有`arduino_serial`节点、且外部开漏电路已就绪的板目标。覆盖文件在该串口下创建`zephyr,w1-serial`总线和`maxim,ds18b20`设备；普通UART引脚不能仅靠这份覆盖文件就变成所需的电气接口。

<a id="sample-output"></a>

### 27.2.3 示例输出（Sample Output）

输出发送到串口控制台，同时记录DS18B20驱动消息。如何连接串口控制台，参阅所用开发板文档。

以下是默认应用配置下、标准Arduino串口引脚仅连接一个DS18B20时的输出：

```text
*** Booting Zephyr OS build zephyr-v2.6.0-1929-gf7abe4a6689e  ***
Found device "DS18B20", getting sensor data
[00:00:00.000,039] <dbg> w1_serial: w1_serial_init: w1-serial initialized, with 1 devices
[00:00:00.015,140] <dbg> DS18B20: ds18b20_init: Using external power supply: 1
[00:00:00.021,213] <dbg> DS18B20: ds18b20_init: Init DS18B20: ROM=28b1bb3f070000b9

Temp: 25.040000
Temp: 25.030000
```

> 译注——设备选择：当前源码使用`DEVICE_DT_GET_ANY(maxim_ds18b20)`取得一个已启用节点；多个节点同时存在时，不应依赖它代表物理总线上固定次序的第一只传感器。应用检查设备就绪后获取环境温度，每轮休眠2000毫秒。
