# 第59章\_ISL29035数字光照传感器示例

原文：[官方页面](https://docs.zephyrproject.org/latest/samples/sensor/isl29035/README.html)。读取日期：2026-10-14；保存的latest页面及HTML摘要见[来源记录](../SOURCES.md)。

<a id="overview"></a>

## 59.1 概述（Overview）

未启用触发（Trigger）时，原文说明示例每2秒显示一次测得的光照强度（Light intensity）。

启用触发后，若ISL29035的读数位于上次采样值上下50勒克斯（Lux，lx）的窗口内，示例每10秒显示一次。检测到窗口以外的光照强度时，应用被唤醒，显示新值，将窗口中心更新为该值，再按相同方式继续运行。

> 译注——轮询间隔：当前源码未启用触发时使用`k_sleep(K_SECONDS(1))`，即每次处理后休眠1秒，与原文2秒不同。触发模式等待信号量（Semaphore），超时为10秒；中断事件可提前唤醒。阈值窗口使用读数整数部分，低阈值还限制为不小于0，低照度下不一定形成对称的±50 lx窗口。

<a id="requirements"></a>

## 59.2 要求（Requirements）

示例使用外接传感器转接板（Breakout board）。必须提供设备树覆盖文件（Devicetree overlay），将传感器连接到I2C总线，并标识其中断信号。

> 译注——中断引脚注释：当前随附的nRF52 DK覆盖文件把`int-gpios`写为`gpio0`的11号引脚，即P0.11；同一文件注释却写`ALERT P1.11`。复现时应核对实际设备树定义与接线，不能只按这条旧注释接线。

<a id="building-and-running"></a>

## 59.3 构建与运行（Building and Running）

> 译注——执行位置：主机构建命令从读者自己的Zephyr源码根目录执行，使用已完成官方入门配置的UCRT64 Bash或Linux Bash终端。读取真实传感器还需要对应目标板、设备树节点和接线；下面的命令与日志来自官方文档，本次没有执行硬件实验。

```sh
west build -b nrf52dk/nrf52832 samples/sensor/isl29035
```
