# 第82章\_正交解码器传感器示例

原文：[官方页面](https://docs.zephyrproject.org/latest/samples/sensor/qdec/README.html)。读取日期：2026-10-14；保存的latest页面及HTML摘要见[来源记录](../SOURCES.md)。

<a id="overview"></a>

## 82.1 概述（Overview）

本示例读取配置为正交解码模式（Quadrature decoder mode）的计数器值。需要：

- 一个外接机械编码器（Mechanical encoder）。
- 在设备树中正确配置相关引脚。

<a id="building-and-running"></a>

## 82.2 构建与运行（Building and Running）

运行前，在开发板设备树或板级覆盖文件中启用正交解码器设备，并新增名为`qdec0`的别名，使其指向刚启用的解码器。

例如，STM32F401通过PA6和PA7使用TIM3解码器时，覆盖文件内容如下：

```dts
/ {
    aliases {
        qdec0 = &qdec;
    };
};

&timers3 {
    status = "okay";

    qdec: qdec {
        status = "okay";
        pinctrl-0 = <&tim3_ch1_pa6 &tim3_ch2_pa7>;
        pinctrl-names = "default";
        st,input-polarity-inverted;
        st,input-filter-level = <FDIV32_N8>;
        st,counts-per-revolution = <16>;
    };
};
```

> 译注——配置片段：上方是板级覆盖文件内容，不是终端命令。节点标签及引脚复用项来自对应板／SoC设备树；换板时须使用目标平台已有的节点和绑定属性。原页没有给出单独的构建命令。

<a id="sample-output"></a>

### 82.2.1 示例输出（Sample Output）

MCU启动后，每秒向控制台打印计数器对应的位置：

```text
Quadrature decoder sensor test
Position = 0 degrees
Position = 15 degrees
Position = 30 degrees
...
```

如果驱动支持速度（RPM）和转数（Revolution count）通道，也会显示这些数据。

设置`CONFIG_EQDC_MCUX_TRIGGER=y`时，例如在`frdm_mcxa153`上，示例还会在转数通道注册`SENSOR_TRIG_OVERFLOW`触发器，并在每轮输出触发次数：

```text
Quadrature decoder sensor test
Registered SENSOR_TRIG_OVERFLOW on SENSOR_CHAN_ENCODER_REVOLUTIONS
Position = 0 degrees
Revolutions = 0
Triggers = 0
Position = 180 degrees
Revolutions = 1
Triggers = 1
...
```

手动转动机械编码器后，读数随之变化。

> 原文提示（Note）：实际报告的增量或减量可能大于或小于上方示例，取决于所用机械编码器及`st,counts-per-revolution`的值。

> 译注——位置与事件计数：当前程序读取`SENSOR_CHAN_ROTATION`并显示角度的整数部分；`Triggers`是溢出回调累计执行次数，与位置读数不是同一个量。源码还提供由`qenca`、`qencb`别名启用的GPIO脉冲模拟分支；选择该分支时须按对应覆盖文件完成信号连接，不能把仅存在模拟输出代码当成已完成编码器输入验证。
