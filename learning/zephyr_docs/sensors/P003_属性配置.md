# 第3章\_属性配置

原文：[Sensor Attributes](https://docs.zephyrproject.org/latest/hardware/peripherals/sensor/attributes.html)。读取日期：2026-10-12，`latest`。

## 3.1\_属性的用途

**属性（Attribute）**由枚举类型 [`sensor_attribute`](https://docs.zephyrproject.org/latest/doxygen/html/group__sensor__interface.html#ga0dcb6842bc969492bd1c9eb49708940b) 列出，包括传感器及其通道的不可变和可变属性。它们既可用于取得元数据，也可用于改变配置。

常见配置有通道量程、采样频率、通道偏移、信号滤波、电源模式、片上缓冲区，以及事件处理选项。属性接口提供统一的检查和修改入口。函数 [`sensor_attr_get()`](https://docs.zephyrproject.org/latest/doxygen/html/group__sensor__interface.html#gaedfdfc71dce702dc1fb1c6e60ff0f73a) 读取属性，函数 [`sensor_attr_set()`](https://docs.zephyrproject.org/latest/doxygen/html/group__sensor__interface.html#gafbf65226a227e9f8824908bc38e336f5) 设置属性，调用时用枚举指定属性种类。

## 3.2\_读取与设置采样频率

以下保留官方示例。宏 `DT_ALIAS` 取得设备树别名 `accel0` 对应节点，宏 `DEVICE_DT_GET` 取得设备对象；通道枚举 `SENSOR_CHAN_ACCEL_XYZ` 表示三轴加速度，属性枚举 `SENSOR_ATTR_SAMPLING_FREQUENCY` 表示采样频率。结构体 `sensor_value` 保存带小数的数值。

```c
const struct device *accel_dev = DEVICE_DT_GET(DT_ALIAS(accel0));
struct sensor_value accel_sample_rate;
int rc;

rc = sensor_attr_get(accel_dev, SENSOR_CHAN_ACCEL_XYZ, SENSOR_ATTR_SAMPLING_FREQUENCY, &accel_sample_rate);
if (rc != 0) {
             printk("Failed to get sampling frequency\n");
}

printk("Sample rate for accel %p is %d.06%d\n", accel_dev, accel_sample_rate.val1, accel_sample_rate.val2*1000000);

accel_sample_rate.val1 = 2000;

rc = sensor_attr_set(accel_dev, SENSOR_CHAN_ACCEL_XYZ, SENSOR_ATTR_SAMPLING_FREQUENCY, accel_sample_rate);
if (rc != 0) {
             printk("Failed to set sampling frequency\n");
}
```

> 译注：这是一段放入应用函数内的片段，前提是设备树别名、驱动和属性都受支持，并检查设备就绪。原例有几处不能直接照抄：`sensor_attr_set()` 最后一个参数应是 `&accel_sample_rate`；精确设置 2000 时还应把 `val2` 清零；`sensor_value` 表示 `val1 + val2 × 10⁻⁶`，原打印格式 `%d.06%d` 和再乘 1000000 的表达式不正确。若读取失败，也不应继续打印尚未有效赋值的数据。这些结论依据所核对的 `include/zephyr/drivers/sensor.h`，原代码保留以便对照，本次没有编译或操作传感器。
