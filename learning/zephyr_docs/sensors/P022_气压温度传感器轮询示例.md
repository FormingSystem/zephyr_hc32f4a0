# 第22章\_气压温度传感器轮询示例

原文：[官方页面](https://docs.zephyrproject.org/latest/samples/sensor/pressure_polling/README.html)。读取日期：2026-10-14；保存的latest页面及HTML摘要见[来源记录](../SOURCES.md)。

<a id="overview"></a>

## 22.1 概述（Overview）

本示例周期性读取温度和气压（Barometric pressure），在控制台显示数值及自启动以来的时间戳。如果支持浮点数（Floating point），且传感器提供海拔数据，还会显示估算海拔（Estimated altitude）。

<a id="wiring"></a>

## 22.2 接线（Wiring）

示例使用外接传感器转接板。需要提供设备树覆盖文件，标明控制传感器所用的I2C／SPI接口。

<a id="building-and-running"></a>

## 22.3 构建与运行（Building and Running）

> 译注——命令位置：以下主机构建命令从读者自己的Zephyr源码根目录执行，使用已完成官方入门配置的UCRT64 Bash或Linux Bash终端。设备树片段属于覆盖文件内容，不是Shell命令。构建成功只说明固件生成，烧录和传感器输出需要实际目标硬件及接线。出现设备未就绪或读取错误时，先核对别名、节点启用状态、驱动配置及总线连接。

示例支持气压传感器设备，需设置`pressure-sensor`别名。例如：

```devicetree
/ {
        aliases {
                pressure-sensor = &icp201xx;
        };
};
```

确认别名已加入设备树后，构建并运行：

```sh
# From the root of the zephyr repository
west build -b nrf52dk/nrf52832 samples/sensor/pressure_polling
west flash
```

日志持续重复（`<repeats endlessly>`）。

> 译注——当前输出：原文提到时间戳，但当前`main.c`的`printf()`只打印温度、气压以及成功取得时的海拔，没有在每行前添加启动时间。程序读取`SENSOR_CHAN_ALTITUDE`并检查返回值，不是在应用中无条件从气压换算海拔。示例覆盖引用`icp201xx`，旧输出设备名为`icp101xx@63`，两者也不应当作必须完全一致的复现条件。
