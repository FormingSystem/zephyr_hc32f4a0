# 第83章\_多单元正交解码器示例

原文：[官方页面](https://docs.zephyrproject.org/latest/samples/sensor/qdec_multi/README.html)。读取日期：2026-10-14；保存的latest页面及HTML摘要见[来源记录](../SOURCES.md)。

<a id="overview"></a>

## 83.1 概述（Overview）

一些正交解码器外设在同一个硬件模块内提供多个计数单元（Counting unit）；例如ESP32脉冲计数器（Pulse Counter，PCNT）每个模块有4～8个单元。

旧的[`sensor_channel_get()`](https://docs.zephyrproject.org/latest/doxygen/html/group__sensor__interface.html#ga9e0e6c1408d32c52267984bae7cb268d) API对同一设备的同一种通道类型只能返回一个通道，因此多单元访问需要读取与解码API（Read-and-Decode API）：[`sensor_read()`](https://docs.zephyrproject.org/latest/doxygen/html/group__sensor__interface.html#gace7f20e29b302e607ba274fe40a2c2bd)将各单元值填入编码缓冲区，驱动的[`sensor_decoder_api`](https://docs.zephyrproject.org/latest/doxygen/html/structsensor__decoder__api.html)再将[`sensor_chan_spec.chan_idx`](https://docs.zephyrproject.org/latest/doxygen/html/structsensor__chan__spec.html#a00d4a927cfeae33b2beea8cdc415dda1)与各`unit@N`子节点的设备树`reg`值匹配，返回指定单元的读数。

板级覆盖文件需要：

- 提供指向多单元解码器节点的`qdec0`别名。
- 为每个单元声明`unit@N`子节点，并设置`reg = <N>`。

示例枚举`qdec0`的每个子节点，每秒输出各单元的旋转读数。若单元节点设置了`counts-per-revolution`，读数为以度为单位的q31定点角度（Fixed-point angle）；否则为原始计数（Raw count）。

<a id="requirements"></a>

## 83.2 要求（Requirements）

可使用任何受Zephyr支持、将多个单元表示为设备树子节点且实现[`sensor_decoder_api`](https://docs.zephyrproject.org/latest/doxygen/html/structsensor__decoder__api.html)的正交解码器驱动。原文编写时，ESP32 PCNT是上游唯一采用该模式的驱动。`boards/`下提供ESP32、ESP32-S2、ESP32-S3、ESP32-C5、ESP32-C6、ESP32-H2及ESP32-P4覆盖文件。

将两个旋转编码器（Rotary encoder），或其他正交脉冲源，接到相应`boards/<board>.overlay`列出的引脚；也可使用与实际接线一致的自定义覆盖文件。

<a id="building-and-running"></a>

## 83.3 构建与运行（Building and Running）

> 译注——执行位置：主机构建命令从读者自己的Zephyr源码根目录执行；Windows使用UCRT64 Bash，Linux使用原生Bash，先按官方入门说明准备主机工具、模块与目标工具链。原生模拟目标还须满足相应主机环境要求；硬件分支需要目标板、设备树节点和接线。下方命令及日志来自官方文档，本次没有运行模拟器或硬件实验。

```sh
west build -b esp32s3_devkitc/esp32s3/procpu samples/sensor/qdec_multi
west flash
```

<a id="sample-output"></a>

### 83.3.1 示例输出（Sample Output）

解码器输入引脚没有连接信号时，计数器保持零：

```text
*** Booting Zephyr OS build ... ***
qdec multi-unit sample: 2 units
unit 0: q31=0 shift=9
unit 1: q31=0 shift=9
...
```

转动单元0上的编码器时，其q31值增加；除以`2^(31 - shift)`即可得到角度：

```text
unit 0: q31=377487360 shift=9
unit 1: q31=0 shift=9
```

> 译注——数值换算与单元选择：上方`377487360 / 2^(31 - 9) = 90`，对应90度，前提是该单元配置了每圈计数。`shift`参与定点数缩放，不是每圈脉冲数；`chan_idx`取自设备树`reg`，不能简单用“遍历到第几个节点”替代。当前ESP32-S3覆盖文件的两个单元分别使用GPIO4／5和GPIO6／7，并都设置每圈400计数。
