# 第38章\_BMG160三轴陀螺仪示例

原文：[官方页面](https://docs.zephyrproject.org/latest/samples/sensor/bmg160/README.html)。读取日期：2026-10-14；保存的latest页面及HTML摘要见[来源记录](../SOURCES.md)。

<a id="overview"></a>

## 38.1 概述（Overview）

> 译注——链接状态：原文的Bosch BMG160存档链接本次请求返回429，网页工具也未能读取；链接按原样保留。下文单独列出的BMG160数据手册链接已由网页工具读取成功，不能将前一个存档链接也记为已验证可访问。

本示例说明如何使用Zephyr[传感器（Sensors）](P001_传感器驱动概览.md#sensor)API驱动读取[Bosch BMG160](https://web.archive.org/web/20181111220522/https://ae-bst.resource.bosch.com/media/_tech/media/datasheets/BST-BMG160-DS000-09.pdf)的数据。原文将它称为环境传感器（Environmental sensor）；这里实际演示的是BMG160三轴陀螺仪（3-axis gyroscope）。

示例先以轮询模式（Polling mode）运行15秒，再进入触发模式（Trigger mode），显示BMG160的温度（Temperature）与角速度（Angular velocity）数据。

> 译注——运行阶段：当前实现的轮询阶段读取三轴角速度和芯片温度；随后分别测试任意运动触发（Anymotion trigger）和数据就绪触发（Data-ready trigger），每个触发阶段各等待15秒，回调输出角速度。轮询阶段按300毫秒休眠累计到15秒，因此实际墙钟时间还包括读取和输出耗时。任意运动测试设置10 °/s的阈值并转换成传感器API所需的rad/s；数据就绪阶段请求100 Hz。

<a id="building-and-running"></a>

## 38.2 构建与运行（Building and Running）

> 译注——执行位置：主机构建命令从读者自己的Zephyr源码根目录执行，终端及工具链按官方入门说明准备。读取真实传感器还需要对应目标板、设备树节点和接线；下面的命令与日志来自官方文档，本次没有执行硬件实验。

示例可以配置为支持经I2C连接的BMG160。配置通过[设备树（Devicetree）](../devicetree/P013_设备树文档入口.md#dt-guide)完成：设备树必须包含已启用的节点，具有`compatible = "bosch,bmg160";`。设备树绑定（Devicetree binding）见[bosch,bmg160](../sensor_bosch_broadcom_espressif_binding_reference/P002_bosch_bmg160.md#std-dtcompatible-bosch-bmg160)，下面给出常见配置及输出。

如果开发板没有内置传感器，应先按照[BMG160数据手册](https://www.mouser.com/datasheet/2/783/BST-BMG160-DS000-1509613.pdf)第78页的连接图接线。

<a id="sample-output"></a>

### 38.2.1 示例输出（Sample Output）

示例向串口控制台（Serial console）打印输出，同时记录BMG160设备驱动消息。如何连接串口控制台，请参阅所用开发板的文档。

下列输出采用应用默认设置，并假设只有一个BMG160连接到标准Arduino I2C引脚：

```text
*** Booting Zephyr OS v3.7.0 ***
Testing the polling mode.
Gyro (rad/s): X=3.6, Y=14.0, Z=0.0f,
Temperature (Celsius): 29.4
Gyro (rad/s): X=5.1, Y=-9.0, Z=0.0f,
Temperature (Celsius): 29.5
...
Polling mode test finished.
Testing the trigger mode.
Gyro: Testing anymotion trigger.
Gyro: rotate the device and wait for events.
Gyro (rad/s): X=13.6, Y=14.0, Z=10.0f,
Gyro: Anymotion trigger test finished.
Gyro: Testing data ready trigger.
Gyro (rad/s): X=3.6, Y=5.4, Z=1.1f,
Gyro: Data ready trigger test finished.
Trigger mode test finished
```

> 译注——原始输出：日志中`Z=0.0f,`等末尾字符按原文保留，不能把字符`f`当作单位。角速度单位由行首`rad/s`给出，温度单位为摄氏度（Celsius）。
