# 第61章\_VEML6031高精度环境光传感器示例

原文：[官方页面](https://docs.zephyrproject.org/latest/samples/sensor/veml6031/README.html)。读取日期：2026-10-14；保存的latest页面及HTML摘要见[来源记录](../SOURCES.md)。

<a id="overview"></a>

## 61.1 概述（Overview）

本示例遍历传感器属性（Sensor attributes）的所有可能组合来测量环境光（Ambient light）。这些属性包括：

- 积分时间（Integration time）。
- 有效光电二极管面积（Effective photodiode size）。
- 增益（Gain）。

这些属性用于让传感器工作在适当的测量范围内。当光照读数达到最大原始值`0xFFFF`时，返回错误以向应用表明超出范围。程序同时打印原始值（Raw value）和所用属性，帮助选择合适的设置。

原文说明当时尚不支持中断及触发模式（Interrupt/Trigger mode），计划在后续开发中提供。

<a id="requirements"></a>

## 61.2 要求（Requirements）

示例通过Olimex-STM32-E407开发板的I2C-2接口控制VEML6031，使用原文所称Feather连接处的PF0和PF1引脚。

> 译注——节点与信号：当前板级覆盖文件将PF0用于SDA、PF1用于SCL，并在`i2c2`下建立名为`light`的节点，地址为`0x29`。主函数使用`DT_NODELABEL(light)`选择设备，因此换板时除了总线连接，也应保留或调整相应节点标签。

## 61.3 参考资料（References）

VEML6031：[Vishay官方数据手册](https://www.vishay.com/docs/80007/veml6031x00.pdf)。

<a id="building-and-running"></a>

## 61.4 构建与运行（Building and Running）

> 译注——执行位置：主机构建命令从读者自己的Zephyr源码根目录执行，使用已完成官方入门配置的UCRT64 Bash或Linux Bash终端。读取真实传感器还需要对应目标板、设备树节点和接线；下面的命令与日志来自官方文档，本次没有执行硬件实验。

项目向控制台输出传感器数据，需要将VEML6031连接到目标板。

```sh
# From the root of the zephyr repository
west build -b None samples/sensor/veml6031/
west flash
```

> 译注——原命令板名：`None`是原页面未填入具体板目标的结果。当前官方测试定义使用`olimex_stm32_e407`，且示例包含对应覆盖文件；应按实际板目标替换`None`，不能把它当作真实开发板名称。
