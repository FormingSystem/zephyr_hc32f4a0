# 第55章\_MH\_Z19B二氧化碳传感器示例

原文：[官方页面](https://docs.zephyrproject.org/latest/samples/sensor/mhz19b/README.html)。读取日期：2026-10-14；保存的latest页面及HTML摘要见[来源记录](../SOURCES.md)。

<a id="description"></a>

## 55.1 说明（Description）

本示例演示MH-Z19B二氧化碳（CO₂）传感器的配置，然后周期性读取CO₂数据。原文说明驱动当前只支持通用异步收发器（Universal Asynchronous Receiver/Transmitter，UART）的中断API。

<a id="requirements"></a>

## 55.2 要求（Requirements）

UART波特率（Baud rate）必须配置为9600，并且必须支持中断驱动API（Interrupt-driven API）。

<a id="building-and-running"></a>

## 55.3 构建与运行（Building and Running）

> 译注——执行位置：主机构建命令从读者自己的Zephyr源码根目录执行，终端及工具链按官方入门说明准备。读取真实传感器还需要对应目标板、设备树节点和接线；下面的命令与日志来自官方文档，本次没有执行硬件实验。

构建应用时，选择具有UART接口的开发板，或提供自定义设备树覆盖文件（Devicetree overlay）。这里使用Nucleo G0B1RE。

将Zephyr目标板的RX和TX连接到MH-Z19B传感器，并按器件数据手册供电。

```sh
west build -b nucleo_g0b1re samples/sensor/mhz19b
```

> 译注——配置依据：当前板级覆盖文件在`usart1`下创建`winsen,mhz19b`节点并设置`current-speed = <9600>`；应用配置启用`CONFIG_UART_INTERRUPT_DRIVEN`。RX是接收（Receive），TX是发送（Transmit），实际接线应按两端信号方向核对。

<a id="sample-output"></a>

### 55.3.1 示例输出（Sample Output）

应用先在运行时配置传感器，再读回其配置数据，然后每2秒读取CO₂数据。

```text
Winsen MH-Z19B CO2 sensor application
Configuring sensor - OK
Reading configurations from sensor:
Sensor range is set to 5000ppm
Sensor ABC is enabled
sensor: co2 reading: 758
sensor: co2 reading: 759
sensor: co2 reading: 762

<repeats endlessly every 2 seconds>
```

以上输出每2秒不断重复（`<repeats endlessly every 2 seconds>`）。

> 译注——量程与ABC：当前主函数将量程设为5000 ppm，并启用自动基线校正（Automatic Baseline Correction，ABC）自校准功能，随后读回这两项设置。随附覆盖文件的初始`maximum-range`是10000，不能据此认为应用运行后仍保持10000；运行时配置会提出5000的设置请求，且代码检查返回值。这里只翻译和核对示例，没有对真实器件进行配置或校准。
