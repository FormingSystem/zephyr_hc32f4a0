# 第51章\_CCS811室内空气质量传感器示例

原文：[官方页面](https://docs.zephyrproject.org/latest/samples/sensor/ccs811/README.html)。读取日期：2026-10-14；保存的latest页面及HTML摘要见[来源记录](../SOURCES.md)。

<a id="overview"></a>

## 51.1 概述（Overview）

CCS811数字气体传感器（Digital gas sensor）通过检测挥发性有机化合物（Volatile Organic Compounds，VOCs）测量室内空气质量（Indoor air quality）。VOC通常被归类为污染物和／或感官刺激物，其来源包括建筑材料，例如油漆和地毯；设备，例如复印机和处理设备；也包括人的呼吸和吸烟活动。

当VOC主要来自人的活动时，CCS811可据此估算二氧化碳（Carbon dioxide，CO₂）水平。

<a id="building-and-running-on-thingy52-nrf52832"></a>

### 51.2.1 在thingy52/nrf52832上构建和运行（Building and Running on thingy52/nrf52832）

```sh
west build -b thingy52/nrf52832 samples/sensor/ccs811
west flash
```

<a id="sample-output"></a>

### 51.2.2 示例输出（Sample Output）

原文描述的输出来自内置该传感器及其他传感器的[Nordic Thingy:52](https://www.nordicsemi.com/Software-and-tools/Prototyping-platforms/Nordic-Thingy-52)（`thingy52/nrf52832`）。软复位（Soft reset）后有5秒启动阶段，其间读数不稳定；随后可看到约400 ppm的等效二氧化碳（Equivalent CO₂，eCO₂）和0 ppb的等效总挥发性有机化合物（Equivalent Total Volatile Organic Compounds，eTVOC）稳定读数。

> 译注——输出材料：原页在此只有文字说明，没有实际日志块或图片；没有根据描述编造串口日志。原文写作`eC02`，这里按含义解释为eCO₂。ppm是百万分之一，ppb是十亿分之一；上述数值是原文示例条件下的观测，不是所有环境的预期测量结果。

> 译注——当前实现：示例还打印硬件／固件版本、电压和电流，并可显示基线（Baseline）寄存器。数据就绪（Data ready）触发安装成功时，主线程永久休眠，由回调读取；其他相应配置可走定时读取或阈值（Threshold）触发。`CONFIG_APP_USE_ENVDATA`可向驱动提供固定环境温湿度参数，不能把这些固定配置当成另一个温湿度传感器的实时测量值。
