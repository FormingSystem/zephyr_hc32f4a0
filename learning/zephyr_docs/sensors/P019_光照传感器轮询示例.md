# 第19章\_光照传感器轮询示例

原文：[官方页面](https://docs.zephyrproject.org/latest/samples/sensor/light_polling/README.html)。读取日期：2026-10-14；保存的latest页面及HTML摘要见[来源记录](../SOURCES.md)。

<a id="overview"></a>

## 19.1 概述（Overview）

本示例读取光照传感器输出，每秒向控制台打印一次照度（Illuminance），单位为勒克斯（Lux，lx）。

<a id="requirements"></a>

## 19.2 要求（Requirements）

需要以下硬件：

- 支持模数转换器（Analog-to-Digital Converter，ADC）的开发板。
- 受支持的光照传感器，例如[Grove光照传感器（Grove Light Sensor）](https://wiki.seeedstudio.com/Grove-Light_Sensor/)；通过设备树别名`light-sensor`提供设备。

<a id="wiring"></a>

## 19.3 接线（Wiring）

接线取决于所用传感器和开发板。提供设备树覆盖文件，描述实际硬件连接对应的传感器配置。

<a id="building-and-running"></a>

## 19.4 构建与运行（Building and Running）

> 译注——命令位置：以下主机构建命令从读者自己的Zephyr源码根目录执行，使用已完成官方入门配置的UCRT64 Bash或Linux Bash终端。设备树片段属于覆盖文件内容，不是Shell命令。构建成功只说明固件生成，烧录和传感器输出需要实际目标硬件及接线。出现设备未就绪或读取错误时，先核对别名、节点启用状态、驱动配置及总线连接。

按以下方式构建并烧录；原文要求将`nrf52dk/nrf52832`替换为实际板名：

```sh
west build -b mikroe_clicker_ra4m1 samples/sensor/light_polling
west flash
```

> 译注——板名差异：原文文字使用`nrf52dk/nrf52832`，实际代码块却指定`mikroe_clicker_ra4m1`。两处均按原文保留，复现时应使用实际板目标和相应覆盖文件。当前实现取得`DT_ALIAS(light_sensor)`并读取`SENSOR_CHAN_LIGHT`；成功路径每次休眠1000毫秒。
