# 第9章\_三轴加速度计轮询示例

原文：[官方页面](https://docs.zephyrproject.org/latest/samples/sensor/accel_polling/README.html)。读取日期：2026-10-14；保存的latest页面及HTML摘要见[来源记录](../SOURCES.md)。

<a id="overview"></a>

## 9.1 概述（Overview）

本示例演示如何通过基于[实时输入输出框架（RTIO）](../io_services/P001_实时输入输出.md#rtio)的[读取与解码方法（Read and Decode）](P006_读取与解码.md#sensor-read-and-decode)，以轮询模式（Polling mode）使用三轴加速度计（3-Axis accelerometer）；读取接口为`sensor_read`。

<a id="building-and-running"></a>

## 9.2 构建与运行（Building and Running）

> 译注——命令位置：以下主机构建命令从读者自己的Zephyr源码根目录执行，使用已完成官方入门配置的UCRT64 Bash或Linux Bash终端。代码中的`<board to use>`、`<your_board>`等是待替换占位符；设备树片段属于覆盖文件内容，不是Shell命令。构建成功只说明固件生成，烧录和传感器输出需要实际目标硬件及接线。出现设备未就绪或读取错误时，先核对别名、节点启用状态、驱动配置及总线连接。

示例支持最多10个三轴加速度计。每个加速度计须设置为`accelN`别名，其中`N`从`0`到`9`。例如，使用`x_nucleo_iks4a1`扩展板（Shield）时：

```devicetree
/ {
      aliases {
                      accel0 = &lsm6dso16is_6a_x_nucleo_iks4a1;
                      accel1 = &lsm6dsv16x_6b_x_nucleo_iks4a1;
                      accel2 = &lis2duxs12_1e_x_nucleo_iks4a1;
              };
      };
```

然后为该扩展板构建并运行：

```sh
west build -b <board to use> --shield x_nucleo_iks4a1 samples/sensor/accel_polling
west flash
```

> 译注——两条读取路径：当前`prj.conf`没有直接启用`CONFIG_SENSOR_ASYNC_API`。`main.c`在该选项开启时使用RTIO读取与解码，否则通过`sensor_sample_fetch()`和`sensor_channel_get()`轮询；下方原输出属于后一种格式。异步路径的`NUM_SENSORS`仍固定为1，而设备列表枚举10个别名，并存在内部循环与外部设备参数的对应关系，因此增加别名并不等于已经完整支持多个异步实例。扩展前应核对实际配置、IO设备数组和解码器对应关系。
