# 第67章\_S3KM1110毫米波传感器示例

原文：[官方页面](https://docs.zephyrproject.org/latest/samples/sensor/s3km1110/README.html)。读取日期：2026-10-14；保存的latest页面及HTML摘要见[来源记录](../SOURCES.md)。

<a id="overview"></a>

## 67.1 概述（Overview）

本示例从[`iclegend,s3km1110`](../sensor_espressif_honeywell_invensense_binding_reference/P015_iclegend_s3km1110.md#std-dtcompatible-iclegend-s3km1110)毫米波（Millimeter wave，mmWave）雷达传感器获取数据，并打印以下信息：

- 占用情况（Occupancy）与目标状态（Target status）：读取标准通道[`SENSOR_CHAN_PROX`](https://docs.zephyrproject.org/latest/doxygen/html/group__sensor__interface.html#ggaaa1b502bc029b10d7b23b0a25ef4e934abaec2c1347ef0035221dd4d9c34a4774)；自定义通道[`SENSOR_CHAN_S3KM1110_TARGET_STATUS`](https://docs.zephyrproject.org/latest/doxygen/html/group__s3km1110__interface.html#gga246184cf5aba644fdefa52d7eea07ee5a62d06b042d9e07e302ce21b6b48e80c1)还提供检测到静止目标、运动目标或两者同时存在的信息。
- 距离（Distance）：标准通道[`SENSOR_CHAN_DISTANCE`](https://docs.zephyrproject.org/latest/doxygen/html/group__sensor__interface.html#ggaaa1b502bc029b10d7b23b0a25ef4e934ad46d1495990a86fa7e2ab5bbe5338e08)给出检测距离；自定义通道[`SENSOR_CHAN_S3KM1110_MOVING_DISTANCE`](https://docs.zephyrproject.org/latest/doxygen/html/group__s3km1110__interface.html#gga246184cf5aba644fdefa52d7eea07ee5a49aeaaf493be20cd2ac70666344259a1)和[`SENSOR_CHAN_S3KM1110_STATIC_DISTANCE`](https://docs.zephyrproject.org/latest/doxygen/html/group__s3km1110__interface.html#gga246184cf5aba644fdefa52d7eea07ee5a5e9c481a82e32ffdc28f80558d2e9ee5)分别给出运动目标与静止目标距离。
- 能量（Energy）：自定义通道[`SENSOR_CHAN_S3KM1110_MOVING_ENERGY`](https://docs.zephyrproject.org/latest/doxygen/html/group__s3km1110__interface.html#gga246184cf5aba644fdefa52d7eea07ee5a2318a4db392087b678b04ce63f829ae9)和[`SENSOR_CHAN_S3KM1110_STATIC_ENERGY`](https://docs.zephyrproject.org/latest/doxygen/html/group__s3km1110__interface.html#gga246184cf5aba644fdefa52d7eea07ee5a16ee99536316fc8d26186fe4e6634f3d)分别给出运动及静止目标的能量值。

<a id="building-and-running"></a>

## 67.2 构建与运行（Building and Running）

> 译注——执行位置：主机构建命令从读者自己的Zephyr源码根目录执行，使用已完成官方入门配置的UCRT64 Bash或Linux Bash终端。读取真实传感器还需要对应目标板、设备树节点和接线；下面的命令与日志来自官方文档，本次没有执行硬件实验。

为连接[Seeed Studio XIAO用24 GHz毫米波传感器扩展板](https://docs.zephyrproject.org/latest/boards/shields/seeed_xiao_hsp24/doc/index.html#seeed-xiao-hsp24)的XIAO开发板构建：

```sh
# From the root of the zephyr repository
west build -b xiao_esp32c6/esp32c6/hpcore --shield seeed_xiao_hsp24 samples/sensor/s3km1110
west flash
```

<a id="sample-output"></a>

### 67.2.1 示例输出（Sample Output）

```text
mmWave Sensor Report
====================

  Presence            occupied
  Target              Static target
  Distances
  *********

  Detection           0.390 m
  Moving target       0.630 m
  Static target       0.630 m

  Energies
  ********

  Moving              0%
  Static              80%
```

> 译注——通道单位与缺失值：当前接口以米（m）表示距离，目标能量等级以0—100的百分数表示，不能当作焦耳（J）的物理能量。读取通道返回`-ENODATA`时显示`n/a`，其他错误显示错误码；“无数据”与有效读数0不同。样本获取成功后休眠1秒，获取失败则等待250毫秒重试。

> 译注——报告含义：`occupied`表示检测到目标存在，`Static target`表示静止目标。各通道的原始示例数值按原文保留，不依据其中某个距离字段自行推断所有目标状态。当前设备配置启用UART中断驱动接口，示例需要已启用的[`iclegend,s3km1110`](../sensor_espressif_honeywell_invensense_binding_reference/P015_iclegend_s3km1110.md#std-dtcompatible-iclegend-s3km1110)设备树节点。
