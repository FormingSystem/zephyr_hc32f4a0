# 第72章\_INA219双向电流与功率监测示例

原文：[官方页面](https://docs.zephyrproject.org/latest/samples/sensor/ina219/README.html)。读取日期：2026-10-14；保存的latest页面及HTML摘要见[来源记录](../SOURCES.md)。

<a id="overview"></a>

## 72.1 概述（Overview）

本示例应用每2秒测量一次分流电阻电压（Shunt voltage）、总线电压（Bus voltage）、功率（Power）和电流（Current），并打印到控制台。校准及配置参数可在设备树文件中设置。

<a id="references"></a>

## 72.2 参考资料（References）

[INA219传感器官方产品资料](https://www.ti.com/product/INA219)。

<a id="wiring"></a>

## 72.3 接线（Wiring）

INA219供电电压范围为3 V至5.5 V；被测总线的共模电压（Common-mode voltage）范围为0 V至26 V。

> 译注——电源与测量输入：3～5.5 V指器件供电，0～26 V指被测总线的共模范围，二者不能作为同一个引脚的供电范围使用。

<a id="building-and-running"></a>

## 72.4 构建与运行（Building and Running）

> 译注——执行位置：主机构建命令从读者自己的Zephyr源码根目录执行；Windows使用UCRT64 Bash，Linux使用原生Bash，主机工具、模块与目标工具链先按官方入门说明准备。读取真实传感器还需要对应目标板、设备树节点和接线；下面的命令与日志来自官方文档，本次没有执行硬件实验。

```sh
# From the root of the zephyr repository
west build -b blackpill_f411ce samples/sensor/ina219
west flash
```

<a id="sample-output"></a>

### 72.4.1 示例输出（Sample Output）

原文说明：使用0.1 Ω分流电阻监测3.3 V总线时，应得到类似下面的输出，每2秒重复一次：

```text
Shunt: 0.001570 [V] -- Bus: 3.224000 [V] -- Power: 0.504000 [W] -- Current: 0.157000 [A]
```

负号表示电流沿反方向流动：

```text
Shunt: -0.001560 [V] -- Bus: 3.224000 [V] -- Power: 0.502000 [W] -- Current: -0.156000 [A]
```

> 译注——原日志数值与当前实现：上述数值保持原样，但`0.001570 V / 0.157000 A = 0.01 Ω`，与原文所述0.1 Ω不一致。当前Black Pill覆盖文件设置`shunt-milliohm = <100>`，对应0.1 Ω；复现时应使校准参数与实装电阻一致，不能用该旧日志反推配置。当前主程序每轮休眠2秒，只读取和打印总线电压、功率及电流，已不输出这里展示的分流电压字段。
