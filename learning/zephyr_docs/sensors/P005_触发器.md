# 第5章\_触发器

原文：[Sensor Triggers](https://docs.zephyrproject.org/latest/hardware/peripherals/sensor/triggers.html)。读取日期：2026-10-12，`latest`。

## 5.1\_传感器产生的事件

**触发器（Trigger）**表示由传感器生成的事件，种类由枚举类型 [`sensor_trigger_type`](https://docs.zephyrproject.org/latest/doxygen/html/group__sensor__interface.html#ga08215279400e8c9eb05ce4e4f0898ffd) 列出。传感器通常可以配置为在事件发生时改变数字信号线，让微控制器容易捕获；之后读取寄存器，判断哪一种事件使信号线产生了通知。

## 5.2\_常见事件及接口差别

事件既包括**数据就绪（Data Ready）**这类信息性通知，也包括轻敲或步行等物理事件。

> 译注：信号线通常只提示“有事件”，不必然直接携带完整采样数据。旧接口通过[触发回调](P004_获取与读取.md)处理，新接口通过[流式读取与解码](P006_读取与解码.md)把事件排入队列；不能把两种使用方式混为同一个回调接口。
