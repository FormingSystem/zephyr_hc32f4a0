# 第20章\_磁力计轮询示例

原文：[官方页面](https://docs.zephyrproject.org/latest/samples/sensor/magn_polling/README.html)。读取日期：2026-10-14；保存的latest页面及HTML摘要见[来源记录](../SOURCES.md)。

<a id="overview"></a>

## 20.1 概述（Overview）

本示例周期性地从第一个实现`SENSOR_CHAN_MAGN_*`的可用设备读取磁力计（Magnetometer）的X、Y、Z数据；原文将设备选择描述为使用预定义设备名称数组。

> 译注——当前设备选择：当前`main.c`实际通过`DEVICE_DT_GET(DT_ALIAS(magn0))`选择单个设备，已经不是遍历预定义设备名数组。复现时需要确认`magn0`别名指向正确节点。应用获取样本后分别读取三个磁场通道，每轮休眠500毫秒。

<a id="board-specific-overlays"></a>

## 20.2 开发板专用覆盖文件（Board-specific overlays）

<a id="tmag5170-via-raspberry-pi-pico"></a>

### 20.2.1 通过Raspberry Pi Pico连接TMAG5170（TMAG5170 via Raspberry Pi Pico）

Zephyr中的`ti,tmag5170`驱动要求SPI驱动支持32位`SPI_WORD_SIZE`。在[Raspberry Pi Pico](https://docs.zephyrproject.org/latest/boards/raspberrypi/rpi_pico/doc/index.html#rpi_pico)上，[raspberrypi,pico-spi-pio](../spi_flexspi_nxp_renesas_binding_reference/P009_raspberrypi_pico-spi-pio.md#std-dtcompatible-raspberrypi-pico-spi-pio) SPI驱动提供此能力，示例见[samples/sensor/magn_polling/boards/rpi_pico.overlay](https://github.com/zephyrproject-rtos/zephyr/blob/main/samples/sensor/magn_polling/boards/rpi_pico.overlay)。

覆盖文件中的GPIO分配是示例选择。PIO SPI驱动允许使用任意四个GPIO构成SPI总线，但`pinctrl`块与`pio0_spi0`块中的引脚分配必须一致。

按选定引脚连接传感器后，构建并烧录：

```sh
# From the root of the zephyr repository
west build -b rpi_pico samples/sensor/magn_polling
west flash
```

> 译注——原文排版：网页将兼容标识显示为``ti,tmag5170` ``，末尾多出一个反引号；实际兼容字符串为`ti,tmag5170`。本节GPIO选择说明针对原文的Pico PIO SPI驱动，不意味着其他板或SPI控制器也支持任意引脚。
