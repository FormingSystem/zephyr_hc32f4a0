# 第29章\_HTS221温湿度传感器示例

原文：[官方页面](https://docs.zephyrproject.org/latest/samples/sensor/hts221/README.html)。读取日期：2026-10-14；保存的latest页面及HTML摘要见[来源记录](../SOURCES.md)。

<a id="overview"></a>

## 29.1 概述（Overview）

本示例周期性读取HTS221温湿度传感器（Temperature and humidity sensor），在控制台显示温度及湿度。

<a id="requirements"></a>

## 29.2 要求（Requirements）

示例使用通过I2C接口控制的HTS221传感器。

<a id="references"></a>

## 29.3 参考资料（References）

原文标为“HTS211”的链接：[HTS221官方产品资料](https://www.st.com/en/mems-and-sensors/hts221.html)。

> 译注——型号：参考条目中的“HTS211”为原文拼写；链接、正文和实现所指器件均为HTS221。

<a id="building-and-running"></a>

## 29.4 构建与运行（Building and Running）

> 译注——执行位置：主机构建命令从读者自己的Zephyr源码根目录执行，使用已完成官方入门配置的UCRT64 Bash或Linux Bash终端。构建成功只表示固件生成；烧录和读取真实温湿度还需要正确的目标板、传感器节点及接线。若设备未就绪或读取失败，先检查节点状态、驱动配置和总线连接。

项目将传感器数据输出到控制台，需要HTS221。`disco_l475_iot1`开发板上带有该传感器。

```sh
west build -b disco_l475_iot1 samples/sensor/hts221
```

<a id="sample-output"></a>

### 29.4.1 示例输出（Sample Output）

```text
Temperature:25.3 C
Relative Humidity:40%
Temperature:25.3 C
Relative Humidity:40%
Temperature:25.3 C
Relative Humidity:40%
Temperature:25.3 C
Relative Humidity:40%

<repeats endlessly every 2 seconds>
```

日志末尾的`<repeats endlessly every 2 seconds>`表示每2秒重复一次。

> 译注——触发与轮询：当前源码在`CONFIG_HTS221_TRIGGER`启用时注册数据就绪（Data ready）回调；否则每2秒读取一次。当前输出还包含`Observation`计数，并将相对湿度打印为一位小数。因此旧输出格式和2秒间隔不适用于所有触发配置。
