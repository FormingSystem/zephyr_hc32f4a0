# 第23章\_气压温度传感器中断示例

原文：[官方页面](https://docs.zephyrproject.org/latest/samples/sensor/pressure_interrupt/README.html)。读取日期：2026-10-14；保存的latest页面及HTML摘要见[来源记录](../SOURCES.md)。

<a id="overview"></a>

## 23.1 概述（Overview）

本示例通过气压传感器的中断线提供以下通知：

- 传感器FIFO中有可用测量值时，读取温度和气压并在终端显示；支持浮点数时还显示估算海拔。
- 气压越过指定阈值（Threshold）时，在终端打印消息。该阈值约对应海拔增加50厘米。
- 相邻两次采样之间的气压变化超过指定值时，在终端打印消息。这里的变化值对应手指按压传感器的示例情形。

<a id="wiring"></a>

## 23.2 接线（Wiring）

示例使用外接传感器转接板。需要提供设备树覆盖文件，标明控制传感器使用的I2C／SPI总线及GPIO。

<a id="building-and-running"></a>

## 23.3 构建与运行（Building and Running）

> 译注——命令位置：以下主机构建命令从读者自己的Zephyr源码根目录执行，使用已完成官方入门配置的UCRT64 Bash或Linux Bash终端。设备树片段属于覆盖文件内容，不是Shell命令。构建成功只说明固件生成，烧录和传感器输出需要实际目标硬件及接线。出现设备未就绪或读取错误时，先核对别名、节点启用状态、驱动配置及总线连接。

示例支持气压传感器设备，需设置`pressure-sensor`别名。例如：

```devicetree
/ {
        aliases {
                pressure-sensor = &icp201xx;
        };
};
```

确认别名已加入设备树后，构建并运行：

```sh
# From the root of the zephyr repository
west build -b nrf52dk/nrf52832 samples/sensor/pressure_interrupt
west flash
```

> 译注——三种事件配置：应用Kconfig默认启用`CONFIG_PRESSURE_DRDY`、`CONFIG_PRESSURE_THRESHOLD`和`CONFIG_PRESSURE_DELTA`，分别对应数据就绪、阈值及变化量事件。当前实现将低阈值设为初始气压减去5 Pa，并把相邻样本变化阈值设为0.01 kPa；“50厘米”是原文的近似说明。实际传感器驱动需要实现相应属性和触发器，单有`pressure-sensor`别名不能保证三种事件均受支持。
