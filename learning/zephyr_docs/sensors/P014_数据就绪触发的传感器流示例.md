# 第14章\_数据就绪触发的传感器流示例

原文：[官方页面](https://docs.zephyrproject.org/latest/samples/sensor/stream_drdy/README.html)。读取日期：2026-10-14；保存的latest页面及HTML摘要见[来源记录](../SOURCES.md)。

<a id="overview"></a>

## 14.1 概述（Overview）

本示例演示通过基于[实时输入输出框架（RTIO）](../io_services/P001_实时输入输出.md#rtio)的[读取与解码方法（Read and Decode）](P006_读取与解码.md#sensor-read-and-decode)流式读取加速度数据。

流通过`sensor_stream()`API启动，随后由数据就绪触发器`SENSOR_TRIG_DATA_READY`持续驱动。

目前示例只获取并打印加速度通道`SENSOR_CHAN_ACCEL_XYZ`。

<a id="building-and-running"></a>

## 14.2 构建与运行（Building and Running）

> 译注——命令位置：以下主机构建命令从读者自己的Zephyr源码根目录执行，使用已完成官方入门配置的UCRT64 Bash或Linux Bash终端。设备树片段属于覆盖文件内容，不是Shell命令。构建成功只说明固件生成，烧录和传感器输出需要实际目标硬件及接线。出现设备未就绪或读取错误时，先核对别名、节点启用状态、驱动配置及总线连接。

示例支持最多10个流式设备。每个设备需设置`streamN`别名，其中`N`从`0`到`9`。例如：

```devicetree
/ {
    aliases {
                 stream0 = &lsm6dsv16x_6b_x_nucleo_iks4a1;
            };
    };
```

`boards`目录已经为`sensortile_box_pro`、`nucleo_f401re`及`nucleo_h503rb`提供以下覆盖与配置示例：

- [samples/sensor/stream_drdy/boards/sensortile_box_pro.overlay](https://github.com/zephyrproject-rtos/zephyr/blob/main/samples/sensor/stream_drdy/boards/sensortile_box_pro.overlay)：`sensortile_box_pro`设备树覆盖。
- [samples/sensor/stream_drdy/boards/sensortile_box_pro.conf](https://github.com/zephyrproject-rtos/zephyr/blob/main/samples/sensor/stream_drdy/boards/sensortile_box_pro.conf)：`sensortile_box_pro`配置。
- [samples/sensor/stream_drdy/boards/nucleo_f401re.overlay](https://github.com/zephyrproject-rtos/zephyr/blob/main/samples/sensor/stream_drdy/boards/nucleo_f401re.overlay)：`nucleo_f401re`设备树覆盖。
- [samples/sensor/stream_drdy/boards/nucleo_f401re.conf](https://github.com/zephyrproject-rtos/zephyr/blob/main/samples/sensor/stream_drdy/boards/nucleo_f401re.conf)：`nucleo_f401re`配置。
- [samples/sensor/stream_drdy/boards/nucleo_h503rb.overlay](https://github.com/zephyrproject-rtos/zephyr/blob/main/samples/sensor/stream_drdy/boards/nucleo_h503rb.overlay)：`nucleo_h503rb`设备树覆盖。
- [samples/sensor/stream_drdy/boards/nucleo_h503rb.conf](https://github.com/zephyrproject-rtos/zephyr/blob/main/samples/sensor/stream_drdy/boards/nucleo_h503rb.conf)：`nucleo_h503rb`配置。

例如，为`sensortile_box_pro`构建并运行：

```sh
west build -b sensortile_box_pro samples/sensor/stream_drdy
west flash
```

> 译注——设备数与数据率：当前`NUM_SENSORS`为1。应用启动流后在内部循环消费完成结果，并使用调用时传入的设备获取解码器；不能仅增加别名就认为多设备关联已经处理。`check_sensor_is_off()`发现输出数据率为0或读取失败时只打印警告，不负责把传感器打开，实际数据率应在传感器配置中设置。
