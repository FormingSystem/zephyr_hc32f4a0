# 第21章\_磁力计触发器示例

原文：[官方页面](https://docs.zephyrproject.org/latest/samples/sensor/magn_trig/README.html)。读取日期：2026-10-14；保存的latest页面及HTML摘要见[来源记录](../SOURCES.md)。

<a id="overview"></a>

## 21.1 概述（Overview）

本示例从实现数据就绪触发器`SENSOR_TRIG_DATA_READY`及磁场通道`SENSOR_CHAN_MAGN_*`的可用设备，读取磁力计（Magnetometer）的X、Y、Z数据。

<a id="building-and-running"></a>

## 21.2 构建与运行（Building and Running）

> 译注——命令位置：以下主机构建命令从读者自己的Zephyr源码根目录执行，使用已完成官方入门配置的UCRT64 Bash或Linux Bash终端。代码中的`<board to use>`、`<your_board>`等是待替换占位符；设备树片段属于覆盖文件内容，不是Shell命令。构建成功只说明固件生成，烧录和传感器输出需要实际目标硬件及接线。出现设备未就绪或读取错误时，先核对别名、节点启用状态、驱动配置及总线连接。

设备树别名示例如下：

```devicetree
/ {
  aliases {
    magn0 = &fxos8700;
  };
};
```

确认设备树包含别名后，构建并运行：

```sh
west build -b <board to use> samples/sensor/magn_trig
west flash
```

> 译注——触发流程：当前实现选择`magn0`，将触发通道设为`SENSOR_CHAN_MAGN_XYZ`。回调调用`sensor_sample_fetch()`以获取数据并清除传感器的数据就绪中断，然后释放信号量；主循环等待信号量后读取并打印三轴数据。设备节点存在并不代表中断接线和驱动触发模式已经配置完成。
