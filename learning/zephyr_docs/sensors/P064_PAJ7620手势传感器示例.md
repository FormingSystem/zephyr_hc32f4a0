# 第64章\_PAJ7620手势传感器示例

原文：[官方页面](https://docs.zephyrproject.org/latest/samples/sensor/paj7620_gesture/README.html)。读取日期：2026-10-14；保存的latest页面及HTML摘要见[来源记录](../SOURCES.md)。

<a id="overview"></a>

## 64.1 概述（Overview）

本示例通过轮询（Polling）或触发器（Trigger）取得PAJ7620手势传感器（Gesture sensor）的输出，每检测到一种手势，就在控制台输出对应名称。

<a id="requirements"></a>

## 64.2 要求（Requirements）

使用本示例需要：

- 支持I2C的开发板；触发模式还需要GPIO来检测外部中断（External interrupt）。
- PAJ7620传感器。

<a id="building-and-running"></a>

## 64.3 构建与运行（Building and Running）

> 译注——执行位置：主机构建命令从读者自己的Zephyr源码根目录执行，使用已完成官方入门配置的UCRT64 Bash或Linux Bash终端。读取真实传感器还需要对应目标板、设备树节点和接线；下面的命令与日志来自官方文档，本次没有执行硬件实验。

示例向控制台输出数据，需要实际PAJ7620传感器。

<a id="polling-mode"></a>

### 64.3.1 轮询模式（Polling Mode）

```sh
west build -b nucleo_f334r8 samples/sensor/paj7620_gesture
```

<a id="trigger-mode"></a>

### 64.3.2 触发模式（Trigger Mode）

触发模式使用GPIO检测外部中断，因此必须启用GPIO支持。与支持触发的其他传感器相同，原文说明可选择全局线程（Global thread，`CONFIG_PAJ7620_TRIGGER_GLOBAL_THREAD`），或专用线程（Dedicated thread，`CONFIG_PAJ7620_TRIGGER_OWN_THREAD`）来处理中断。

```sh
west build -b nucleo_f334r8 samples/sensor/paj7620_gesture -- -DEXTRA_CONF_FILE=trigger.conf
```

> 译注——当前示例的配置边界：随附`trigger.conf`启用GPIO和专用线程。当前`trigger_main_loop()`只在`CONFIG_PAJ7620_TRIGGER_OWN_THREAD`条件下定义，但触发模式主分支会调用它；因此不能仅依据上面的驱动选项说明，就认定该示例可直接改成全局线程配置。本次只记录这处源码条件差异，没有修改示例或执行编译。

<a id="sample-output"></a>

### 64.3.3 示例输出（Sample Output）

```text
Gesture LEFT
Gesture RIGHT
Gesture UP
Gesture DOWN
```

输出依次表示左（Left）、右（Right）、上（Up）和下（Down）手势。

> 译注——读取流程：当前轮询分支每轮休眠100毫秒；触发回调先获取样本，再释放信号量，主循环读取手势标志并打印。代码还处理前进（Forward）、后退（Backward）、顺时针（Clockwise）及逆时针（Counterclockwise）标志，原页仅展示上述四条输出。
