# 第60章\_VCNL4040接近与环境光传感器示例

原文：[官方页面](https://docs.zephyrproject.org/latest/samples/sensor/vcnl4040/README.html)。读取日期：2026-10-14；保存的latest页面及HTML摘要见[来源记录](../SOURCES.md)。

<a id="overview"></a>

## 60.1 概述（Overview）

示例先在轮询模式（Polling mode）下每300毫秒测量一次接近度（Proximity）和光照，持续5秒。随后启用阈值触发模式（Threshold trigger mode），将高阈值设为127，依据中断获取数据。结果显示在控制台。

<a id="requirements"></a>

## 60.2 要求（Requirements）

示例通过I2C接口控制VCNL4040。使用Adafruit STM32F405 Feather时，将传感器的中断输出`INT`连接到Feather D5引脚。

## 60.3 参考资料（References）

VCNL4040：[Vishay官方数据手册](https://www.vishay.com/docs/84274/vcnl4040.pdf)。

<a id="building-and-running"></a>

## 60.4 构建与运行（Building and Running）

> 译注——执行位置：主机构建命令从读者自己的Zephyr源码根目录执行，使用已完成官方入门配置的UCRT64 Bash或Linux Bash终端。读取真实传感器还需要对应目标板、设备树节点和接线；下面的命令与日志来自官方文档，本次没有执行硬件实验。

项目向控制台输出传感器数据，需要将VCNL4040连接到目标板。

```sh
# From the root of the zephyr repository
west build -b None samples/sensor/vcnl4040/
west flash
```

> 译注——缺失的板目标：原命令的`-b None`没有给出实际板名，不能原样作为可运行目标。当前测试定义包含`adafruit_feather_stm32f405`，并提供该板的I2C及中断覆盖文件；使用其他板时，应选择实际目标并准备相应节点及接线。

<a id="sample-output"></a>

### 60.4.1 示例输出（Sample Output）

```text
get device vcnl4040
Testing the polling mode.
Proximity: 31
Light (lux): 288

<repeats for 5sec every 300ms>

Polling mode test finished.
Testing the trigger mode.
Testing proximity trigger.
...
Triggered.
Proximity: 122

<repeats whenever triggered for 5sec>

Threshold trigger test finished.
Trigger mode test finished.
```

轮询阶段每300毫秒重复，约持续5秒；触发阶段在约5秒测试窗口内，每次触发时输出接近度。

> 译注——阈值与测试长度：当前代码还设置低阈值122，环境光输出受`CONFIG_VCNL4040_ENABLE_ALS`控制。轮询阶段将5000毫秒计数每次减去300，实际有17次休眠，即5100毫秒，再加读取和打印时间；触发阶段则休眠5000毫秒后注销触发器。接近度数值没有距离单位，不能将127或122直接解释为毫米。
