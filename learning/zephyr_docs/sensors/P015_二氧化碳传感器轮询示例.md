# 第15章\_二氧化碳传感器轮询示例

原文：[官方页面](https://docs.zephyrproject.org/latest/samples/sensor/co2_polling/README.html)。读取日期：2026-10-14；保存的latest页面及HTML摘要见[来源记录](../SOURCES.md)。

<a id="overview"></a>

## 15.1 概述（Overview）

本传感器示例演示如何轮询二氧化碳（Carbon dioxide，CO2）传感器。

<a id="building-and-running"></a>

## 15.2 构建与运行（Building and Running）

> 译注——命令位置：以下主机构建命令从读者自己的Zephyr源码根目录执行，使用已完成官方入门配置的UCRT64 Bash或Linux Bash终端。代码中的`<board to use>`、`<your_board>`等是待替换占位符；设备树片段属于覆盖文件内容，不是Shell命令。构建成功只说明固件生成，烧录和传感器输出需要实际目标硬件及接线。出现设备未就绪或读取错误时，先核对别名、节点启用状态、驱动配置及总线连接。

示例连续读取CO2传感器并打印数值：

```sh
west build -b <board to use> samples/sensor/co2_polling
west flash
```

> 译注——设备入口：当前`main.c`通过`DT_ALIAS(co2)`取得设备，确认就绪后读取`SENSOR_CHAN_CO2`，每轮休眠1000毫秒。所选开发板或覆盖文件需要提供`co2`别名及对应驱动配置；这里的`<board to use>`须替换为实际板名。

<a id="sample-output"></a>

### 15.2.1 示例输出（Sample Output）

```text
CO2 940 ppm
CO2 950 ppm
```

以上输出不断重复（`<repeats endlessly>`）。`ppm`表示百万分之一（Parts per million）。
