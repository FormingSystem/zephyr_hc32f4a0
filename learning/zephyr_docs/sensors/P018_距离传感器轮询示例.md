# 第18章\_距离传感器轮询示例

原文：[官方页面](https://docs.zephyrproject.org/latest/samples/sensor/distance_polling/README.html)。读取日期：2026-10-14；保存的latest页面及HTML摘要见[来源记录](../SOURCES.md)。

<a id="overview"></a>

## 18.1 概述（Overview）

本示例周期性测量目标物体的距离（Distance），并通过控制台显示结果。

<a id="building-and-running"></a>

## 18.2 构建与运行（Building and Running）

> 译注——命令位置：以下主机构建命令从读者自己的Zephyr源码根目录执行，使用已完成官方入门配置的UCRT64 Bash或Linux Bash终端。代码中的`<board to use>`、`<your_board>`等是待替换占位符；设备树片段属于覆盖文件内容，不是Shell命令。构建成功只说明固件生成，烧录和传感器输出需要实际目标硬件及接线。出现设备未就绪或读取错误时，先核对别名、节点启用状态、驱动配置及总线连接。

示例支持最多5个距离传感器。每个传感器需要设置`distanceN`别名，其中`N`从`0`到`4`。例如：

```devicetree
/ {
        aliases {
                distance0 = &vl53l1x;
        };
};
```

确认设备树包含别名后，构建并运行：

```sh
west build -b <board to use> samples/sensor/distance_polling
west flash
```

<a id="sample-output"></a>

### 18.2.1 示例输出（Sample Output）

```text
vl53l1x: 0.153m
vl53l1x: 0.154m
vl53l1x: 0.154m
vl53l1x: 0.153m
```

> 译注——数值格式：当前源码通过`SENSOR_CHAN_DISTANCE`读取距离，却直接用`%d.%03d`拼接`val1`和`val2`。传感器API中的`val2`单位是百万分之一，`%03d`只是最小字段宽度，不会自动把微小数换算为三位小数。例如`val1=0, val2=153000`代表0.153米，当前拼接会输出`0.153000m`；若`val2=1000`则代表0.001米，直接拼接却成为`0.1000m`。因此须按`val1 + val2 / 1000000`解释数值，不能从原文的三位小数日志推断当前输出格式已正确处理所有数值。源码未在本次翻译中修改。
