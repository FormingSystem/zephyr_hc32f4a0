# 第7章\_设备树描述

原文：[Device Tree](https://docs.zephyrproject.org/latest/hardware/peripherals/sensor/device_tree.html)。读取日期：2026-10-12，`latest`。

## 7.1\_设备的初始配置

在传感器场景中，**设备树（Devicetree）**按设备描述初始硬件配置。每类设备必须有 Zephyr 设备树绑定，并应尽可能提供通道电源模式、数据率、滤波、抽取和量程等硬件配置选项。板级设备树使用这些选项，把传感器设为初始状态。

> 译注：**抽取（Decimation）**通常指按一定规则降低输出采样序列的速率；具体过滤和抽取方式由芯片及驱动决定。设备树给出启动配置，运行时能否改变相同设置还要看[属性接口](P003_属性配置.md)是否受支持。

## 7.2\_加速度计与陀螺仪示例

原例在 **串行外设接口（Serial Peripheral Interface，SPI）**总线节点 `spi0` 下定义 ICM42688 设备，使用 `compatible` 选择绑定、`reg` 指定片选索引。属性 `int-gpios` 描述中断信号使用的**通用输入输出（General-Purpose Input/Output，GPIO）**，属性 `spi-max-frequency` 限制总线时钟频率。

加速度和陀螺仪分别配置低噪声模式、采样率和量程；宏 `DT_FREQ_M(24)` 将 24 MHz 频率表示成对应整数值。原例宏 `GPIO_ACTIVE_HIGH` 指高电平有效；`ICM42688_ACCEL_LN` 与 `ICM42688_GYRO_LN` 表示两类通道的低噪声模式，`ICM42688_ACCEL_ODR_2000` 与 `ICM42688_GYRO_ODR_2000` 表示 2000 Hz 采样率。`ICM42688_ACCEL_FS_16` 表示加速度量程，`ICM42688_GYRO_FS_16` 是原文写法中有问题的陀螺仪量程宏；这些原名与所核对版本的差异见代码后译注。

原代码如下：

```dts
#include <zephyr/dt-bindings/icm42688.h>

&spi0 {
    /* SPI bus options here, not shown */

    accel_gyro0: icm42688p@0 {
        compatible = "invensense,icm42688", "invensense,icm4268x";
        reg = <0>;
        int-gpios = <&pioc 6 GPIO_ACTIVE_HIGH>; /* SoC specific pin to select for interrupt line */
        spi-max-frequency = <DT_FREQ_M(24)>; /* Maximum SPI bus frequency */
        accel-pwr-mode = <ICM42688_ACCEL_LN>; /* Low noise mode */
        accel-odr = <ICM42688_ACCEL_ODR_2000>; /* 2000 Hz sampling */
        accel-fs = <ICM42688_ACCEL_FS_16>; /* 16G scale */
        gyro-pwr-mode = <ICM42688_GYRO_LN>; /* Low noise mode */
        gyro-odr = <ICM42688_GYRO_ODR_2000>; /* 2000 Hz sampling */
        gyro-fs = <ICM42688_GYRO_FS_16>; /* 16G scale */
    };
 };
```

> 译注：这段不是可以照搬到任意板的接线方案，`pioc` 和引脚 6 是原例的板级占位选择，需要核对实际芯片引脚、片选、时钟和中断极性。原例省略了 SPI 总线其他配置及部分公共宏头文件，必须配套当前板的完整设备树。

> 译注：所核对的本地头文件路径为 `include/zephyr/dt-bindings/sensor/icm42688.h`，含 `sensor/` 层级；电源、采样率和量程宏使用 `ICM42688_DT_...` 命名。原例的无 `_DT_` 名称不应直接用于该版本。尤其 `gyro-fs = <ICM42688_GYRO_FS_16>` 及注释“16G scale”混用了加速度量程：陀螺仪测量角速度，其可选范围应从实际绑定头文件与芯片规格选择，不能用 16 g 代替。保留原代码展示差异，本次没有修改设备树或验证硬件。
