# 第54章\_MAX6675热电偶数字转换示例

原文：[官方页面](https://docs.zephyrproject.org/latest/samples/sensor/max6675/README.html)。读取日期：2026-10-14；保存的latest页面及HTML摘要见[来源记录](../SOURCES.md)。

<a id="overview"></a>

## 54.1 概述（Overview）

本示例读取外接MAX6675转换器。该器件将K型热电偶（K-type thermocouple）信号转换为数字量，并提供冷端补偿（Cold-junction compensation）。

<a id="requirements"></a>

## 54.2 要求（Requirements）

- 将MAX6675连接到开发板的SPI总线。
- 将K型热电偶连接到MAX6675的`T+`／`T-`输入。

<a id="building-and-running"></a>

## 54.4 构建与运行（Building and Running）

> 译注——执行位置：主机构建命令从读者自己的Zephyr源码根目录执行，终端及工具链按官方入门说明准备。读取真实传感器还需要对应目标板、设备树节点和接线；下面的命令与日志来自官方文档，本次没有执行硬件实验。

本示例可为支持SPI的开发板构建。示例提供NUCLEO-F030R8开发板的覆盖文件（Overlay）。

```sh
west build -b nucleo_f030r8 samples/sensor/max6675
```

<a id="sample-output"></a>

### 54.4.1 示例输出（Sample Output）

应用每秒读取并打印一次温度。没有连接K型热电偶时，温度获取会失败，因为MAX6675能够检测热电偶是否接入。

```text
Temperature: 25.25 C
Temperature: 25.50 C

<repeats endlessly every second>
```

以上输出每秒不断重复（`<repeats endlessly every second>`）。

> 译注——失败行为：当前实现获取或读取温度失败后会打印错误并从主函数返回，不会继续自动重试。随附板级覆盖文件将`maxim,max6675`节点挂在`arduino_spi`下，最大SPI频率设为4300000 Hz；换板时应对照实际节点与接线。
