# 第65章\_SX9500电容接近传感器示例

原文：[官方页面](https://docs.zephyrproject.org/latest/samples/sensor/sx9500/README.html)。读取日期：2026-10-14；保存的latest页面及HTML摘要见[来源记录](../SOURCES.md)。

<a id="overview"></a>

## 65.1 概述（Overview）

本示例说明如何使用Zephyr[传感器（Sensors）](P001_传感器驱动概览.md#sensor)API驱动访问[Semtech SX9500](https://www.semtech.com/products/smart-sensing/touch-proximity-devices/sx9500)电容式SAR接近传感器（Capacitive Sense and Respond proximity sensor）。这里的SAR按原文展开为感知与响应（Sense and Respond）。

示例根据配置使用轮询模式（Polling mode）或触发模式（Trigger mode）。轮询模式周期性获取并打印接近值；触发模式配置接近／远离中断（Near/Far interrupt），每次触发时打印接近值。

<a id="building-and-running"></a>

## 65.2 构建与运行（Building and Running）

> 译注——执行位置：主机构建命令从读者自己的Zephyr源码根目录执行，使用已完成官方入门配置的UCRT64 Bash或Linux Bash终端。读取真实传感器还需要对应目标板、设备树节点和接线；下面的命令与日志来自官方文档，本次没有执行硬件实验。

示例支持通过I2C连接的SX9500，配置通过[设备树（Devicetree）](../devicetree/P013_设备树文档入口.md#dt-guide)完成。设备树必须包含已启用节点，具有`compatible = "semtech,sx9500";`。绑定信息见[semtech,sx9500](../sensor_realtek_rohm_sensirion_binding_reference/P019_semtech_sx9500.md#std-dtcompatible-semtech-sx9500)，下面给出常见配置下的输出。

如果开发板没有内置传感器，先按[SX9500数据手册](https://www.semtech.com/products/smart-sensing/touch-proximity-devices/sx9500)的连接图接线；引脚图见数据手册第4页。

> 译注——当前模式选择：源码使用`CONFIG_SX9500_TRIGGER`选择分支。轮询分支每次读取后休眠1秒；触发分支注册`SENSOR_TRIG_NEAR_FAR`后由回调获取数据，主线程的1秒休眠不代表1秒采样定时器。原文的产品资料与数据手册链接指向同一个Semtech产品入口。

<a id="sample-output"></a>

### 65.2.1 示例输出（Sample Output）

示例向串口控制台（Serial console）输出，SX9500驱动消息也可能被记录。如何连接控制台，请参阅相应开发板文档。

以下示例采用默认应用设置，假设仅有一个SX9500连接到标准I2C引脚。`device is 2000XXXX`中的值代表设备结构体在内存中的地址；实际值取决于开发板、内存布局及Zephyr版本，不应当作固定常量。

轮询模式输出：

```text
*** Booting Zephyr OS vX.X.X ***
device is 2000XXXX, name is SX9500
prox is 0
prox is 1
prox is 1
prox is 0
```

触发模式输出：

```text
*** Booting Zephyr OS vX.X.X ***
device is 2000XXXX, name is SX9500
prox is 1
prox is 0
prox is 1
```
