# 第10章\_加速度计触发器示例

原文：[官方页面](https://docs.zephyrproject.org/latest/samples/sensor/accel_trig/README.html)。读取日期：2026-10-14；保存的latest页面及HTML摘要见[来源记录](../SOURCES.md)。

<a id="overview"></a>

## 10.1 概述（Overview）

本示例演示如何通过触发器（Trigger）使用三轴加速度计。默认使用数据就绪触发器（Data ready trigger）读取加速度数据，并将其打印到控制台。

如果为加速度计启用了轻敲触发器（Tap trigger），示例就在轻敲事件发生时读取并打印加速度数据。

<a id="building-and-running"></a>

## 10.2 构建与运行（Building and Running）

> 译注——命令位置：以下主机构建命令从读者自己的Zephyr源码根目录执行，使用已完成官方入门配置的UCRT64 Bash或Linux Bash终端。代码中的`<board to use>`、`<your_board>`等是待替换占位符；设备树片段属于覆盖文件内容，不是Shell命令。构建成功只说明固件生成，烧录和传感器输出需要实际目标硬件及接线。出现设备未就绪或读取错误时，先核对别名、节点启用状态、驱动配置及总线连接。

设备树中的别名示例如下：

```devicetree
/ {
  aliases {
    accel0 = &fxos8700;
  };
};
```

确认别名已加入设备树后，构建并运行：

```sh
west build -b <board to use> samples/sensor/accel_trig
west flash
```

启用`CONFIG_SAMPLE_TAP_DETECTION`还可以检测双击（Double tap）。这里以带有LIS2DW12加速度计的`x_nucleo_iks01a3`扩展板为例，原文给出的构建命令为：

```sh
west build -b nrf52dk/nrf52832 --extra-dtc-overlay x_nucleo_iks01a3.overlay --shield x_nucleo_iks01a3 samples/sensor/accel_trig
```

> 译注——双击配置：当前应用Kconfig中`CONFIG_SAMPLE_TAP_DETECTION`默认关闭；Twister的`sample.sensor.accel_trig.shield-tap`用例另外传入`CONFIG_SAMPLE_TAP_DETECTION=y`。上方原命令本身没有这个参数。复现双击分支时，还需在应用配置中设置该选项，或在构建命令末尾通过`-- -DCONFIG_SAMPLE_TAP_DETECTION=y`传入，并确认传感器驱动及中断接线支持双击。仅指定Shield和设备树覆盖文件不能作为已启用双击的判断依据。
