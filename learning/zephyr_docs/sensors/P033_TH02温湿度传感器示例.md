# 第33章\_TH02温湿度传感器示例

原文：[官方页面](https://docs.zephyrproject.org/latest/samples/sensor/th02/README.html)。读取日期：2026-10-14；保存的latest页面及HTML摘要见[来源记录](../SOURCES.md)。

<a id="overview"></a>

## 33.1 概述（Overview）

本示例周期性读取Grove温湿度传感器（Temperature and humidity sensor，TH02），并在Grove液晶显示屏（LCD）上显示结果。

<a id="requirements"></a>

## 33.2 要求（Requirements）

需要TH02传感器及Grove LCD。两者均通过I2C接口控制。

更多信息见：

- [Grove温湿度传感器（Grove Temperature And Humidity）](http://wiki.seeed.cc/Grove-TemptureAndHumidity_Sensor-High-Accuracy_AndMini-v1.0/)。
- [Grove液晶显示模块（Grove LCD Module）](http://wiki.seeed.cc/Grove-LCD_RGB_Backlight/)。

<a id="wiring"></a>

## 33.3 接线（Wiring）

较简单的方式是使用Grove Shield，将两个设备都接到I2C接口；这种连接不需要其他额外布线。根据所用开发板，可能需要在`SDL`和`SDA`线上接入两个10 kΩ电阻。LCD需要5 V，因此原文要求将Shield的电压开关设为5 V。

> 译注——信号名与供电：原文的`SDL`应按I2C时钟线`SCL`理解。5 V说明针对原文使用的Grove LCD及Shield供电，不代表所用开发板的I2C引脚可承受5 V上拉；应核对实际模块及底板的接口电平。当前源码通过`DT_NODELABEL(glcd)`取得显示屏，通过`hoperf,th02`兼容节点取得传感器，两者都必须就绪。原页面没有构建命令或控制台输出示例，本译文不另编一套冒充原文。
