# 第73章\_BQ274XX电量计示例

原文：[官方页面](https://docs.zephyrproject.org/latest/samples/sensor/bq274xx/README.html)。读取日期：2026-10-14；保存的latest页面及HTML摘要见[来源记录](../SOURCES.md)。

<a id="overview"></a>

## 73.1 概述（Overview）

本示例从BQ274XX传感器取得电量计（Fuel gauge）参数，并将信息打印到UART控制台。原文列出的参数为：

- 电压（Voltage），单位V。
- 平均电流（Average current），单位A。
- 待机电流（Standby current），单位A。
- 最大负载电流（Maximum load current），单位A。
- 电量计温度（Gauge temperature）。
- 荷电状态（State of charge，SOC），以百分比表示。
- 满充容量（Full Charge Capacity），单位mAh。
- 剩余电荷容量（Remaining Charge Capacity），单位mAh。
- 标称可用容量（Nominal Available Capacity），单位mAh。
- 完全可用容量（Full Available Capacity），单位mAh。
- 平均功率（Average power），单位mW。
- 健康状态（State of health，SOH），以百分比表示。

<a id="building-and-running"></a>

## 73.3 构建与运行（Building and Running）

> 译注——执行位置：主机构建命令从读者自己的Zephyr源码根目录执行；Windows使用UCRT64 Bash，Linux使用原生Bash，主机工具、模块与目标工具链先按官方入门说明准备。读取真实传感器还需要对应目标板、设备树节点和接线；下面的命令与日志来自官方文档，本次没有执行硬件实验。

使用下列命令构建本示例：

```sh
# From the root of the zephyr repository
west build -b innblue22/nrf9160 samples/sensor/bq274xx
west flash
```

> 译注——当前输出范围与单位：当前主程序读取并显示上述项目中的10项，没有读取“标称可用容量”和“完全可用容量”。它将满充／剩余容量标为Ah、平均功率标为W，温度标为摄氏度，并在每轮成功读取后休眠5秒。上方参数列表按原文保留；比对当前串口结果时，须区分Ah与mAh、W与mW的1000倍关系。
