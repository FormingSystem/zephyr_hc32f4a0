# 第13章\_IEEE 802.15.4 网络管理（Net Management）

原文：[官方页面](https://docs.zephyrproject.org/latest/doxygen/html/group__ieee802154__mgmt.html)。读取日期：2026-10-17；来源摘要见[来源记录](../SOURCES.md)。

IEEE 802.15.4 网络管理库。

<a id="details"></a>

IEEE 802.15.4 网络管理库（Net Management Library）。引入版本（Since）：1.0；API 版本（Version）：0.8.0。此库提供应用可直接调用的运行时配置功能（Runtime Configuration）。多数命令也可通过 Shell 使用，参见 Shell 帮助功能（shell> IEEE 802.15.4 and Thread APIs help）。注意（Note）：所有章节、表格和图号均指 IEEE 802.15.4-2020 标准。

## 13.3\_事件宏（Event Macros）

IEEE 802.15.4 网络管理事件（Net Management Events）。

应用可通过 net_mgmt_init_event_callback、net_mgmt_add_event_callback 和 net_mgmt_del_event_callback 订阅这些 IEEE 802.15.4 子系统网络管理事件。

<a id="r_ga0442eaa04068a7b66f9b4ae40b570470"></a>

```c
#define NET_EVENT_IEEE802154_SCAN_RESULT (NET_IEEE802154_EVENT | NET_EVENT_IEEE802154_CMD_SCAN_RESULT)
```

相关声明：[NET_EVENT_IEEE802154_SCAN_RESULT](#ga0442eaa04068a7b66f9b4ae40b570470)。

通知 NET_REQUEST_IEEE802154_ACTIVE_SCAN 或 NET_REQUEST_IEEE802154_PASSIVE_SCAN 网络管理命令的结果。
