## 17.3\_详细说明（Detailed Documentation）

<a id="gaa488348f55e1d329ef0b671cdc3b6596"></a>

### `sensor_attribute_max30210`

```c
enum sensor_attribute_max30210
```

```c
#include <zephyr/drivers/sensor/max30210.h>
```

MAX30210 的自定义传感器属性（Custom Sensor Attributes）。

**枚举值（Enumerators）**

| 名称／方向 | 说明 |
| --- | --- |
| `SENSOR_ATTR_MAX30210_INTERRUPT_POLARITY` | 中断极性（Interrupt Polarity），保留供未来使用。 |
| `SENSOR_ATTR_MAX30210_CONTINUOUS_CONVERSION_MODE` | 启用连续转换模式（Continuous Conversion Mode）。忽略 sensor_value.val1 和 sensor_value.val2。 |
| `SENSOR_ATTR_MAX30210_TEMP_INC_FAST_THRESH` | 用于快速变化检测（Fast-change Detection）的相邻温度采样增量阈值，单位为 °C。sensor_value.val1 为阈值整数部分（°C），sensor_value.val2 为小数部分，单位为百万分之一摄氏度。 |
| `SENSOR_ATTR_MAX30210_TEMP_DEC_FAST_THRESH` | 用于快速变化检测（Fast-change Detection）的相邻温度采样减量阈值，单位为 °C。sensor_value.val1 为阈值整数部分（°C），sensor_value.val2 为小数部分，单位为百万分之一摄氏度。必须是 0.005 °C 的整数倍。 |
| `SENSOR_ATTR_MAX30210_RATE_CHG_FILTER` | 变化率滤波系数（Rate-of-change Filter Coefficient），范围为 0～7。sensor_value.val1 为滤波值，sensor_value.val2 未使用且始终为 0。 |
| `SENSOR_ATTR_MAX30210_HI_TRIP_COUNT` | 高温告警触发计数（High-temperature Alarm Trip Count），范围为 1～4。sensor_value.val1 为连续高于阈值的采样次数，sensor_value.val2 未使用且始终为 0。 |
| `SENSOR_ATTR_MAX30210_LO_TRIP_COUNT` | 低温告警触发计数（Low-temperature Alarm Trip Count），范围为 1～4。sensor_value.val1 为连续低于阈值的采样次数，sensor_value.val2 未使用且始终为 0。 |
| `SENSOR_ATTR_MAX30210_HI_TRIP_COUNT_RESET` | 复位高温触发计数器（High-temperature Trip Counter）。sensor_value.val1 为 0 时保持计数器不变，为 1 时复位；sensor_value.val2 未使用且始终为 0。 |
| `SENSOR_ATTR_MAX30210_LO_TRIP_COUNT_RESET` | 复位低温触发计数器（Low-temperature Trip Counter）。sensor_value.val1 为 0 时保持计数器不变，为 1 时复位；sensor_value.val2 未使用且始终为 0。 |
| `SENSOR_ATTR_MAX30210_HI_NON_CONSECUTIVE_MODE` | 高温告警非连续模式（High-temperature Alarm Non-consecutive Mode）。sensor_value.val1 为 0 时使用连续模式，为 1 时使用非连续模式；sensor_value.val2 未使用且始终为 0。 |
| `SENSOR_ATTR_MAX30210_LO_NON_CONSECUTIVE_MODE` | 低温告警非连续模式（Low-temperature Alarm Non-consecutive Mode）。sensor_value.val1 为 0 时使用连续模式，为 1 时使用非连续模式；sensor_value.val2 未使用且始终为 0。 |
| `SENSOR_ATTR_MAX30210_ALERT_MODE` | 告警模式（Alert Mode），比较器模式或中断模式。sensor_value.val1 为 0 时使用比较器模式，为 1 时使用中断模式；sensor_value.val2 未使用且始终为 0。 |
| `SENSOR_ATTR_MAX30210_SOFTWARE_RESET` | 执行软件复位（Software Reset）。忽略 sensor_value.val1 和 sensor_value.val2。 |
| `SENSOR_ATTR_MAX30210_TEMP_CONVERT` | 触发单次温度转换（Single Temperature Conversion），保留供未来使用。 |
| `SENSOR_ATTR_MAX30210_AUTO_MODE` | 启用自动模式（Auto Mode），保留供未来使用。 |

### `sensor_sampling_rate_max30210`

```c
enum sensor_sampling_rate_max30210
```

```c
#include <zephyr/drivers/sensor/max30210.h>
```

`SENSOR_ATTR_SAMPLING_FREQUENCY` 的取值，单位为赫兹（Hz）。

设置采样频率（Sampling Frequency）时，sensor_value.val1 为整数部分（Hz），sensor_value.val2 为百万分之一单位的小数部分。对于小数频率，例如 0.0625 Hz，使用 val1=0、val2=62500。

**枚举值（Enumerators）**

| 名称／方向 | 说明 |
| --- | --- |
| `SENSOR_SAMPLING_RATE_MAX30210_0_015625` | 采样频率（Sampling Frequency）：0.015625 Hz。 |
| `SENSOR_SAMPLING_RATE_MAX30210_0_03125` | 采样频率（Sampling Frequency）：0.03125 Hz。 |
| `SENSOR_SAMPLING_RATE_MAX30210_0_0625` | 采样频率（Sampling Frequency）：0.0625 Hz。 |
| `SENSOR_SAMPLING_RATE_MAX30210_0_125` | 频率（Frequency）：0.125 Hz。 |
| `SENSOR_SAMPLING_RATE_MAX30210_0_25` | 采样频率（Sampling Frequency）：0.25 Hz。 |
| `SENSOR_SAMPLING_RATE_MAX30210_0_5` | 频率（Frequency）：0.5 Hz。 |
| `SENSOR_SAMPLING_RATE_MAX30210_1` | 频率：1 Hz。 |
| `SENSOR_SAMPLING_RATE_MAX30210_2` | 频率（Frequency）：2 Hz。 |
| `SENSOR_SAMPLING_RATE_MAX30210_4` | 频率（Frequency）：4 Hz。 |
| `SENSOR_SAMPLING_RATE_MAX30210_8` | 采样频率（Sampling Frequency）：8 Hz。 |

### `sensor_trigger_type_max30210`

```c
enum sensor_trigger_type_max30210
```

```c
#include <zephyr/drivers/sensor/max30210.h>
```

MAX30210 的自定义传感器触发类型（Custom Sensor Trigger Types）。

**枚举值（Enumerators）**

| 名称／方向 | 说明 |
| --- | --- |
| `SENSOR_TRIG_TEMP_INC_FAST` | 温度上升超过快速变化阈值（Fast Threshold）时触发。 |
| `SENSOR_TRIG_TEMP_DEC_FAST` | 温度下降超过快速变化阈值（Fast Threshold）时触发。 |
