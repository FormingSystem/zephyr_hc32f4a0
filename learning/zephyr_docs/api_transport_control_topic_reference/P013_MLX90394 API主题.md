## 13.3\_详细说明（Detailed Documentation）

### `mlx90394_sensor_attribute`

```c
enum mlx90394_sensor_attribute
```

```c
#include <zephyr/drivers/sensor/mlx90394.h>
```

MLX90394 的自定义传感器属性（Custom Sensor Attributes）。

**枚举值（Enumerators）**

| 名称／方向 | 说明 |
| --- | --- |
| `MLX90394_SENSOR_ATTR_MAGN_LOW_NOISE` | 低噪声模式（Low Noise Mode），仅适用于 `SENSOR_CHAN_MAGN_XYZ` 通道。 |
| `MLX90394_SENSOR_ATTR_MAGN_FILTER_XY` | X 轴和 Y 轴的数字滤波设置（Digital Filter Setting）。控制用于两轴降噪的滤波器抽头数（Filter Taps）；更高的设置值能够改善噪声性能，但会增加测量时间。`sensor_value.val1`：滤波设置值，范围 `0–7`。 |
| `MLX90394_SENSOR_ATTR_MAGN_FILTER_Z` | Z 轴的数字滤波配置（Digital Filter Configuration）。与 XY 滤波器类似，但单独配置，因为 Z 轴通常具有不同的噪声特性。`sensor_value.val1`：滤波设置值，范围 `0–7`。 |
| `MLX90394_SENSOR_ATTR_MAGN_OSR` | 磁场测量的过采样率（Over-sampling Ratio）。`sensor_value.val1 == 0`：正常采样率；`sensor_value.val1 == 1`：双倍采样率。 |
| `MLX90394_SENSOR_ATTR_TEMP_FILTER` | 温度测量的数字滤波配置（Digital Filter Configuration）。更高的设置值可以提高温度测量稳定性。`sensor_value.val1`：滤波设置值，范围 `0–7`。 |
| `MLX90394_SENSOR_ATTR_TEMP_OSR` | 温度测量的过采样率（Over-sampling Ratio）。`sensor_value.val1 == 0`：正常采样率；`sensor_value.val1 == 1`：双倍采样率。 |
