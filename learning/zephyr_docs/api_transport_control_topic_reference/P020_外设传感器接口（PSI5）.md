## 20.6\_详细说明（Detailed Documentation）

### `psi5_rx_frame_callback_t`

```c
typedef void(* psi5_rx_frame_callback_t) (const struct device *dev, uint8_t channel, uint32_t num_frame, void *user_data)
```

```c
#include <zephyr/drivers/psi5/psi5.h>
```

定义用于接收帧的应用程序回调处理函数签名。

**参数（Parameters）**

| 名称／方向 | 说明 |
| --- | --- |
| `dev` | 指向驱动实例的设备结构（Device Structure）。 |
| `channel` | 驱动实例的硬件通道（Hardware Channel）。 |
| `num_frame` | 接收到的帧（Frame）数量。 |
| `user_data` | 接收帧（Frame）时提供的用户数据（User Data）。 |

<a id="gaac8c99036369b14d639cfb82f3b9cd32"></a>

<a id="ga37b0fcdecd4629c5f2657b1cc2e227b4"></a>

### `psi5_register_callback()`

```c
int psi5_register_callback ( const struct device * dev, uint8_t channel, struct psi5_rx_callback_configs callback_configs )
```

```c
#include <zephyr/drivers/psi5/psi5.h>
```

添加回调函数，以处理指定通道接收到的消息。

通道配置为同步模式（Synchronous Mode）时，必须在启动同步脉冲发生器（Sync Pulse Generator）之前注册回调。

**参数（Parameters）**

| 名称／方向 | 说明 |
| --- | --- |
| `dev` | 指向驱动实例的设备结构（Device Structure）。 |
| `channel` | 驱动实例的硬件通道（Hardware Channel）。 |
| `callback_configs` | 回调配置（Callback Configurations）。 |

**返回值（Return Values）**

| 名称／方向 | 说明 |
| --- | --- |
| `0` | 成功。 |
| `-EINVAL` | 通道（Channel）无效。 |

<a id="ga3a27606e2828206608a79ada7238466d"></a>

### `psi5_send()`

```c
int psi5_send ( const struct device * dev, uint8_t channel, const uint64_t data, k_timeout_t timeout, psi5_tx_callback_t callback, void * user_data )
```

```c
#include <zephyr/drivers/psi5/psi5.h>
```

在指定通道上传输 PSI5 数据。

通道必须配置为同步模式（Synchronous Mode），并且只能在同步脉冲发生器（Sync Pulse Generator）启动后开始传输。

**参数（Parameters）**

| 名称／方向 | 说明 |
| --- | --- |
| `dev` | 指向驱动实例的设备结构（Device Structure）。 |
| `channel` | 驱动实例的硬件通道（Hardware Channel）。 |
| `data` | 要发送的 PSI5 数据（Data）。 |
| `timeout` | 等待就绪以发送新数据的超时时间（Timeout）。 |
| `callback` | 可选回调（Callback），在帧发送完成或发生传输错误时调用。若为 `NULL`，本函数阻塞直到帧发送完成。 |
| `user_data` | 要传递给回调函数（Callback Function）的用户数据（User Data）。 |

**返回值（Return Values）**

| 名称／方向 | 说明 |
| --- | --- |
| `0` | 成功。 |
| `-EINVAL` | 通道（Channel）无效。 |
| `-ENOTSUP` | 向函数传入了不支持的参数（Unsupported Parameter）。 |
| `-ENETDOWN` | 处于已停止状态（Stopped State）。 |
| `-EIO` | 发生一般发送错误（General Transmit Error）。 |
| `-EAGAIN` | 超时（Timeout） |
