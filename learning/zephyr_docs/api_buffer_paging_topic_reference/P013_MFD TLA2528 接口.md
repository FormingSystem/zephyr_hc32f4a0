## 13.4\_详细说明（Detailed Documentation）

<a id="ga73edc358e1817027d25c3d199d544080"></a>

### `tla2528_general_cfg`

```c
enum tla2528_general_cfg
```

```c
#include <zephyr/drivers/mfd/tla2528.h>
```

TLA2528 的 `GENERAL_CFG` 寄存器位映射（Bit Mapping）。

**枚举值（Enumerators）**

| 名称／方向 | 说明 |
| --- | --- |
| `TLA2528_CNVST` | 启动转换（Conversion）。 |
| `TLA2528_CH_RST` | 将所有通道重置为模拟模式（Analog Mode）。 |
| `TLA2528_CAL` | 校准 ADC 偏移（Offset）。 |
| `TLA2528_RST` | 软件复位（Soft Reset）所有寄存器。 |

<a id="gae9ef53f1a7533dcce0125a0f81e3d2f9"></a>

### `tla2528_reg`

```c
enum tla2528_reg
```

```c
#include <zephyr/drivers/mfd/tla2528.h>
```

TLA2528 寄存器映射（Register Mapping）。

**枚举值（Enumerators）**

| 名称／方向 | 说明 |
| --- | --- |
| `TLA2528_SYSTEM_STATUS` | 系统状态寄存器（System Status Register）。 |
| `TLA2528_GENERAL_CFG` | 通用配置寄存器（General Configuration Register）。 |
| `TLA2528_DATA_CFG` | 数据配置寄存器（Data Configuration Register）。 |
| `TLA2528_OSR_CFG` | 过采样配置寄存器（Oversampling Configuration Register）。 |
| `TLA2528_OPMODE_CFG` | 工作模式配置寄存器（Operation Mode Configuration Register）。 |
| `TLA2528_PIN_CFG` | 引脚配置寄存器（Pin Configuration Register）。 |
| `TLA2528_GPIO_CFG` | GPIO 配置寄存器（Configuration Register）。 |
| `TLA2528_GPO_DRIVE_CFG` | GPIO 输出驱动配置寄存器（Output Drive Configuration Register）。 |
| `TLA2528_GPO_VALUE` | GPIO 输出值寄存器（Output Value Register）。 |
| `TLA2528_GPI_VALUE` | GPIO 输入值寄存器（Input Value Register）。 |
| `TLA2528_SEQUENCE_CFG` | ADC 序列配置寄存器（Sequence Configuration Register）。 |
| `TLA2528_CHANNEL_SEL` | ADC 通道选择寄存器（Channel Selection Register）。 |
| `TLA2528_AUTO_SEQ_CH_SEL` | ADC 序列通道选择寄存器（Sequence Channel Selection Register）。 |

### `tla2528_register_clear_bits()`

```c
int tla2528_register_clear_bits ( const struct device * dev, enum tla2528_reg reg, uint8_t bits )
```

```c
#include <zephyr/drivers/mfd/tla2528.h>
```

将 TLA2528 寄存器中的指定位（Bits）清零。

以“原子”方式（Atomically，即在一次 I2C 事务中）清除位，无需读—修改—写周期（Read-modify-write Cycle）。

**参数（Parameters）**

| 名称／方向 | 说明 |
| --- | --- |
| `dev` | TLA2528 实例（Instance） |
| `reg` | 要修改的寄存器（Register） |
| `bits` | 要清除的位（Bits） |

**返回值（Return Values）**

| 名称／方向 | 说明 |
| --- | --- |
| `0` | 成功时的返回值；否则返回负 errno 错误码。 |
