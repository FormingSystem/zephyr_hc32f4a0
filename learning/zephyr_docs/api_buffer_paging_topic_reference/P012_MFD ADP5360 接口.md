### `adp5360_interrupt_type`

```c

```

```c
#include <zephyr/drivers/mfd/adp5360.h>
```

ADP5360 中断类型（Interrupt Types）。

**枚举值（Enumerators）**

| 名称／方向 | 说明 |
| --- | --- |
| `ADP5360_INTERRUPT_VBUS_VOLTAGE_THRESHOLD` | VBUS 电压阈值中断（Voltage Threshold Interrupt）。 |
| `ADP5360_INTERRUPT_CHARGER_MODE_CHANGE` | 充电器模式变化中断（Charger Mode Change Interrupt）。 |
| `ADP5360_INTERRUPT_BAT_VOLTAGE_THRESHOLD` | 电池电压阈值中断（Battery Voltage Threshold Interrupt）。 |
| `ADP5360_INTERRUPT_TEMP_THRESHOLD` | 温度阈值中断（Temperature Threshold Interrupt）。 |
| `ADP5360_INTERRUPT_BAT_PROTECTION` | 电池保护中断（Battery Protection Interrupt）。 |
| `ADP5360_INTERRUPT_ADPICHG` | 自适应充电中断（Adaptive Charge Interrupt）。 |
| `ADP5360_INTERRUPT_SOC_ACM` | 荷电状态（State of Charge）ACM 中断。 |
| `ADP5360_INTERRUPT_SOC_LOW` | 低荷电状态中断（Low State of Charge Interrupt）。 |
| `ADP5360_INTERRUPT_BUCKBSTPGOOD` | 升降压电源正常中断（Buck Boost Power Good Interrupt）。 |
| `ADP5360_INTERRUPT_BUCKPGOOD` | 降压电源正常中断（Buck Power Good Interrupt）。 |
| `ADP5360_INTERRUPT_WATCHDOG_TIMEOUT` | 看门狗超时中断（Watchdog Timeout Interrupt）。 |
| `ADP5360_INTERRUPT_MANUAL_RESET` | 手动复位中断（Manual Reset Interrupt）。 |
