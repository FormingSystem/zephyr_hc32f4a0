<a id="gadd60f7b760371c0a141a1e4da253a0f0"></a>

### `k_mbox_async_put()`

```c
void k_mbox_async_put ( struct k_mbox * mbox, struct k_mbox_msg * tx_msg, struct k_sem * sem )
```

```c
#include <zephyr/kernel.h>
```

以异步方式发送邮箱消息。

本例程向mbox发送一条消息，不等待接收者处理该消息。消息数据可以存放在缓冲区中，也可以不存在，即空消息。如果提供了信号量sem，则会在消息被接收且接收者完成全部处理后，对它执行给予（give）操作。

**参数（Parameters）**

| 名称／方向 | 说明 |
| --- | --- |
| `mbox` | 邮箱的地址。 |
| `tx_msg` | 发送消息描述符（Transmit Message Descriptor）的地址。 |
| `sem` | 信号量的地址；不需要时传NULL。 |

> 译注——源码核对：“异步”指不等待接收方完成处理，不保证调用永远立即返回。当前实现先以K_FOREVER从共享栈取得异步描述符，池耗尽时会阻塞；相关实现仅在CONFIG_NUM_MBOX_ASYNC_MSGS大于0时编译。它复制描述符但不复制tx_data指向的数据，因此函数返回后仍须保持源数据有效且不被改写，直到处置完成。完成时先归还内部描述符，再对可选sem执行give；传NULL时应用须自行建立完成／寿命协议。调用者原描述符不会自动收到内部副本后续的info、size和目标线程更新。

<a id="ga3d19e648e67f109609259543c9a01d6e"></a>

### `k_mbox_data_get()`

```c
void k_mbox_data_get ( struct k_mbox_msg * rx_msg, void * buffer )
```

```c
#include <zephyr/kernel.h>
```

将邮箱消息数据取到缓冲区。

本例程把已接收消息的数据取到缓冲区，然后处置该消息，从而完成消息处理。

也可以用本例程直接处置已接收的消息，而不取出其数据。

**参数（Parameters）**

| 名称／方向 | 说明 |
| --- | --- |
| `rx_msg` | 接收消息描述符（Receive Message Descriptor）的地址。 |
| `buffer` | 接收数据的缓冲区地址；传NULL表示丢弃数据。 |

> 译注——源码核对：此处“处置”是结束邮箱交换并通知发送方，不是释放应用缓冲区。buffer为NULL会把接收size设为0后完成处置；非NULL时按rx_msg->size复制，不额外接收一个目标容量参数，调用者应确保空间足够。同步发送者获唤醒或异步完成信号发出后，源数据可能立即被复用，不能再次把旧rx_msg当成仍有效的数据读取句柄。

<a id="ga2ea91154620b139dbed1ad949b97c3ef"></a>

### `k_mbox_get()`

```c
int k_mbox_get ( struct k_mbox * mbox, struct k_mbox_msg * rx_msg, void * buffer, k_timeout_t timeout )
```

```c
#include <zephyr/kernel.h>
```

接收邮箱消息。

本例程从mbox接收一条消息，随后可以选择取出消息数据并处置消息。

**参数（Parameters）**

| 名称／方向 | 说明 |
| --- | --- |
| `mbox` | 邮箱的地址。 |
| `rx_msg` | 接收消息描述符（Receive Message Descriptor）的地址。 |
| `buffer` | 接收数据的缓冲区地址；传NULL表示将数据提取和消息处置延后。 |
| `timeout` | 等待消息被接收的时间，或特殊值K_NO_WAIT、K_FOREVER之一。 |

**返回值（Return Values）**

| 名称／方向 | 说明 |
| --- | --- |
| `0` | 消息已接收。 |
| `-ENOMSG` | 未等待即返回。 |
| `-EAGAIN` | 等待超时。 |

> 译注——源码核对：接收前设置rx_source_thread筛选来源、size表示可接受的最大字节数、info表示返回给发送方的信息；实际接收线程由内核记录。匹配后size为双方长度的较小值，tx_data指向发送方缓冲区。buffer为NULL且size大于0时保留消息供后续处理；size为0则当前实现立即处置，即使buffer为NULL也不会延后。

<a id="gaa1e5cdd992d8b9be11f82254e1886ed2"></a>

### `k_mbox_put()`

```c
int k_mbox_put ( struct k_mbox * mbox, struct k_mbox_msg * tx_msg, k_timeout_t timeout )
```

```c
#include <zephyr/kernel.h>
```

以同步方式发送邮箱消息。

本例程向mbox发送一条消息，并等待接收者接收且处理该消息。消息数据可以存放在缓冲区中，也可以不存在，即空消息。

**参数（Parameters）**

| 名称／方向 | 说明 |
| --- | --- |
| `mbox` | 邮箱的地址。 |
| `tx_msg` | 发送消息描述符（Transmit Message Descriptor）的地址。 |
| `timeout` | 等待消息被接收的时间，或特殊值K_NO_WAIT、K_FOREVER之一。一旦消息已被接收，本例程就会按需要持续等待，直到消息完全处理完毕。 |

**返回值（Return Values）**

| 名称／方向 | 说明 |
| --- | --- |
| `0` | 消息已发送。 |
| `-ENOMSG` | 未等待即返回。 |
| `-EAGAIN` | 等待超时。 |

> 译注——源码核对：timeout只控制等待兼容接收者的阶段。一旦匹配，当前实现取消原等待超时，并继续等待接收者取走或丢弃数据；即使使用K_NO_WAIT，只要已匹配，也可能等待消息处置完成。发送描述符与源数据必须在调用完成前保持有效。返回0表示邮箱处理阶段结束，不代表接收者的后续业务运算也已完成。

## 1.5\_源码定位与版本边界

> 译注——阅读与源码边界：配合[邮箱指南](../kernel/P018_邮箱.md)阅读。邮箱供线程之间交换消息，不用于ISR。同步发送的接收等待和后续处置等待是两个阶段，异步发送仍可能等待内部描述符资源。
