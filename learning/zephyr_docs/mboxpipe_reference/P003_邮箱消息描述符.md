## 3.2\_详细说明（Detailed Documentation）

<a id="aa79f2bf71431b474ec4551ade4d7a8dd"></a>

### `info`

```c
uint32_t k_mbox_msg::info
```

应用定义的信息值。

> 译注——源码核对：当前匹配逻辑交换双方info，不用info筛选消息。应用可赋予其命令号或应答含义，但若要按info分类，须在接收后自己处理；同步发送者可以从更新后的描述符读取对方信息。

<a id="a9eb145a242ac66e80d90286d83fe7a61"></a>

### `rx_source_thread`

```c
k_tid_t k_mbox_msg::rx_source_thread
```

源线程标识符。

> 译注——源码核对：接收方设置期望来源或K_ANY；发送方不必预填自己的标识，当前发送实现写入当前线程。匹配成功后接收描述符保存实际来源。

<a id="aeabf45e9599a64852a1cfd656b1ece8e"></a>

### `size`

```c
size_t k_mbox_msg::size
```

消息大小，以字节为单位。

> 译注——源码核对：发送时表示提供的字节数，接收时表示接受上限；匹配后接收方size被缩减为两者较小值。当前实现到消息处置时才把接收size写回发送描述符；丢弃数据时该值为0。异步发送更新的是内部副本。

<a id="a74b0edeed4c44cb5932eb292efc9d9c2"></a>

### `tx_data`

```c
void* k_mbox_msg::tx_data
```

发送者的消息数据缓冲区。

> 译注——源码核对：发送者提供的数据缓冲区地址，接收描述符匹配后得到同一地址；并不因此转移缓冲区所有权。异步提交复制的只是该指针值，实际数据通常到接收方取数据时才复制。

<a id="a73236acb7d27bb0233f5abb7214fb19c"></a>

### `tx_target_thread`

```c
k_tid_t k_mbox_msg::tx_target_thread
```

目标线程标识符。

> 译注——源码核对：发送方设置目标线程或K_ANY；接收方不必预填自己的标识，当前接收实现写入当前线程。发送目标限制与接收来源限制必须同时满足，匹配后记录实际目标。

## 3.3\_源码定位与版本边界

> 译注——阅读与源码边界：公开的五个字段分别描述长度、应用信息、源缓冲区和通信双方；匹配依赖双方线程限制，不匹配info。隐藏的_syncing_thread与条件成员_async_sem由内核管理，不由应用当作公开协议字段使用。
