# CPU负载与线程运行参考大纲

本册完整翻译 CPU 负载（CPU Load）与旧指标兼容头文件、线程分析器（Thread Analyzer）头文件及各自源码，以及函数插桩（Instrumentation）源码和线程运行统计（Thread Runtime Statistics）结构，共八份官方页面。它们为观测 CPU 时间、线程栈空间及函数进入／退出提供不同层次的接口。

源码页保留全部可见代码、法律声明、原始行号锚点和符号提示，英文注释另列中文对照。源码跟踪译注解释单位换算、测量窗口、配置字段和回调数据的生命周期；不把空的结构体网页补写成虚构成员表。完整的功能接口说明分别见[CPU负载接口](../observability/P049_CPU负载接口.md)、[线程分析器接口](../observability/P050_线程分析器接口.md)和[插桩接口](../observability/P025_插桩接口参考.md)。

本地源码使用相对链接，保留中英文术语和原始许可证；仓库环境与实验记录仍在独立资料区。完整范围见[全站进度](../PROGRESS.md)。
