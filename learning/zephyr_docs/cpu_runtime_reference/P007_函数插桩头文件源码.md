## 7.4\_源码跟踪译注

> 译注——插桩（Instrumentation）的enabled与turned_on是两层状态。当前enable/disable只改_instr_enabled，turn_on/turn_off只改_instr_on；instr_turned_on在disabled时返回false。不能把重新enable理解为必然开始全新记录，也不能把disable理解为清空缓冲区。

> 译注——本次GCC钩子在触发函数进入时turn_on，在停止函数的退出事件处理后turn_off。初始化先检查基本运行条件；启用能力、初始化完成、运行开关以及跟踪／性能分析能力查询应分别理解。

> 译注——事件上下文含3位mode、5位cpu、线程指针，以及受CONFIG_THREAD_NAME控制的线程名称。__packed只约束布局，不消除指针宽度、位域布局、字节序和配置差异；记录消费者须与生成记录的目标构建保持格式一致。

> 译注——源码浏览页的若干符号提示以“i.e.”结尾，是官方摘要截断，中文同样标明截断。完整接口说明见对应公共API页；不根据截断提示补造未展示的契约。
