原文：[官方页面](https://docs.zephyrproject.org/latest/doxygen/html/group__bt__gmap__lc3__preset.html)。读取日期：2026-10-17；来源摘要见[来源记录](../SOURCES.md)。

游戏音频配置文件（Gaming Audio Profile，GMAP）的 LC3 预设

<a id="details"></a>

游戏音频配置文件（Gaming Audio Profile，GMAP）的 LC3 预设（Presets）。**引入版本（Since）：**3.5。**版本（Version）：**0.8.0。这些 API 依据 GMAP v1.0 规范表 3.16 中编解码器配置的取值，提供编解码器配置（Codec Configuration）与服务质量（QoS）预设。

### `BT_GMAP_LC3_PRESET_16_1_GS`

```c
#define BT_GMAP_LC3_PRESET_16_1_GS ( _loc, _stream_context )
```

```c
#include <zephyr/bluetooth/audio/gmap_lc3_preset.h>
```

展开值（Value）：

```c
BT_BAP_LC3_PRESET(BT_AUDIO_CODEC_LC3_CONFIG(BT_AUDIO_CODEC_CFG_FREQ_16KHZ,                 \
                                            BT_AUDIO_CODEC_CFG_DURATION_7_5, _loc, 30U, 1, \
                                            _stream_context),                              \
                  BT_BAP_QOS_CFG_UNFRAMED(7500u, 30U, 1U, 15U, 60000U))
```

声明 LC3 `16_1_gs` 编解码器配置（Codec Configuration）的辅助接口。

**参数（Parameters）**

| 名称／方向 | 说明 |
| --- | --- |
| `_loc` | 音频通道位置位域（Audio Channel Location Bitfield），即 `bt_audio_location`。 |
| `_stream_context` | 流上下文（Stream Context），即 `BT_AUDIO_CONTEXT_*`。 |
