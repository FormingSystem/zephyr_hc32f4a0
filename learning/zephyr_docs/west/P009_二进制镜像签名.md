# 第9章\_二进制镜像签名

原文：[官方页面](https://docs.zephyrproject.org/latest/develop/west/sign.html)。本次读取日期：2026-10-14；基线为所保存的 `latest` 页面，HTML摘要见[来源记录](../SOURCES.md)。

扩展命令 `west sign` 调用外部工具，为 Zephyr 应用二进制镜像签名，供**引导加载程序（Bootloader）**使用。某些配置中，它也调用外部后处理工具，把最终镜像的各个组成部分“拼接”起来。命令行帮助见 `west sign -h`；扩展机制见[west扩展命令机制](P012_扩展命令机制.md)。

## 9.1\_rimage

`rimage` 配置采用 [west config](P003_配置.md)，而不依赖 Kconfig 或 CMake，其方式类似于[永久CMake参数](P007_构建烧录与调试.md)。

签名可能经过层层**包装脚本（Wrapper Script）**：`west flash` 调用 `west build`，后者调用 CMake 和 Ninja，再调用 `west sign`，最终调用 `imgtool` 或 [rimage](https://github.com/thesofproject/rimage)。如果签名参数都是默认值且基本不变，这些间接调用通常没有问题；若要将 `imgtool` 或 `rimage` 选项穿过所有层传递，就会遇到各层没有提供有效抽象时的典型问题：

- 每层通常都需要重复的适配代码。
- 空白和其他特殊字符需要穿过多层引用与转义，容易出错。
- 为排查构建问题而重现底层 `west sign` 命令很耗时，至少需要开启详细日志并搜索准确选项。
- 从日志复制选项未必可靠，细微的环境差异也可能改变结果。
- 更严重的是，新签名功能或选项往往要等每层都补上适配代码后才能使用。

为避免这些问题，可以将 `rimage` 参数写入 west 配置。以下是工作区 `.west/config` 的示例：

```ini
[sign]
# Not needed when invoked from CMake
tool = rimage

[rimage]
# Quoting is optional and works like in Unix shells
# Not needed when rimage can be found in the default PATH
path = "<rimage-executable>"

# Not needed when using the default development key
extra-args = -i 4 -k 'keys/key argument with space.pem'
```

> 路径说明：原例的作者主机路径已改为 `<rimage-executable>`。使用时替换为自己安装的可执行文件位置；该占位符不会自动展开。若 `rimage` 已在当前 `PATH` 中，可省略整个 `path` 设置。密钥路径同样按实际调用环境选择；配置文件中的相对路径不应未经核对就认定相对于 `.west` 目录。

原例注释说明：由 CMake 调用时不需要 `sign.tool`；引号可选，按 Unix shell 规则解释；使用默认开发密钥时不需要示例中的附加密钥参数。为支持引号，配置值由 Python 的 `shlex.split()` 解析，与[单次CMake参数](P007_构建烧录与调试.md)相同。

`extra-args` 直接传给 `rimage`，上述示例等价于在命令行 `--` 后追加这些参数：`west sign --tool rimage -- -i 4 -k 'keys/key argument with space.pem'`。如果两种方式同时使用，命令行参数排在最后。

## 9.2\_silabs_commander

`silabs_commander` 用于对 Silicon Labs 设备的二进制镜像执行签名、添加**消息完整性码（Message Integrity Code，MIC）**或加密。将 `sign.tool` 配置为 `silabs_commander` 时可由 `west sign` 调用；设置 `CONFIG_SIWX91X_SIGN_KEY` 或 `CONFIG_SIWX91X_MIC_KEY` 时，也可以由 `west build` 调用。

只要设置了上述任一配置项，`west flash` 就会自动烧录经过签名处理的二进制版本。

主机需要安装 [Simplicity Commander](https://www.silabs.com/developer-tools/simplicity-studio/simplicity-commander?tab=downloads)。设备密钥的**置备（Provisioning）**方法见 [UG574 SiWx917 SoC Manufacturing Utility User Guide](https://www.silabs.com/documents/public/user-guides/ug574-siwx917-soc-manufacturing-utility-user-guide.pdf)。
