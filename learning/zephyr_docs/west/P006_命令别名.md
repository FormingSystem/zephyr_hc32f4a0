# 第6章\_west命令别名

原文：[West aliases](https://docs.zephyrproject.org/latest/develop/west/alias.html)。读取日期：2026-10-12，`latest`。

west 可在工作区、用户或系统配置中添加命令别名，为常用或难记的命令提供快捷写法。

## 6.1\_定义与展开

类似 Git 别名，调用时用别名的完整文本替换该命令，并解析成新的参数列表。内部使用 Python 的 `shlex.split()` 拆分，因此附加参数可以像传给原命令一样使用。空格是参数分隔符，不希望拆分的参数应正确引用或转义。

在已有工作区内添加别名：

```text
west config alias.mylist "list -f '{name} {revision}'"
```

可使用 `west help some_alias` 查看别名。允许递归别名，即别名内容包含其他别名，从而组合成复杂但便于记忆的命令。

也可以覆盖已有命令，例如附加默认参数：

```text
west config alias.update "update -o=--depth=1 -n"
```

覆盖或遮蔽内置及其他命令属于高级用法，可能造成不易察觉的副作用，应谨慎使用。

## 6.2\_示例

给用户级配置增加 `west run` 与 `west menuconfig`，分别调用对应 CMake 构建目标：

```text
west config --global alias.run "build --pristine=never --target run"
west config --global alias.menuconfig "build --pristine=never --target menuconfig"
```

为当前开发的示例设置带附加选项的别名：

```text
west config alias.sample "build -b native_sim samples/hello_world -t run -- -DCONFIG_ASSERT=y"
```

覆盖 `west update`，让它检查本地缓存：

```bash
# 原文使用 $HOME 的 shell 语法；在 Bash 等相应 shell 中执行。
west config alias.update "update --path-cache $HOME/.cache/zephyrproject"
```

经由 west 运行 Twister 时，自动排除 32 位原生模拟目标。对于没有 32 位主机 C 库的主机，例如 Linux/AArch64，这尤其有用：

```text
west config alias.twister "twister --exclude-platform native_sim/native"
```

> 译注：这些是可选配置示例，不是要按顺序全部执行的安装步骤。默认写入当前工作区配置，显式 `--global` 才写用户级配置；作用范围和覆盖规则见[配置](P003_配置.md)。
