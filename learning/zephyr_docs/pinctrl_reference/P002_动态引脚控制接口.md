## 2.3\_详细说明（Detailed Documentation）

<a id="ga6331121c706ba721e5bd43491dcc14d2"></a>

### `PINCTRL_DT_STATE_INIT`

```c
#define PINCTRL_DT_STATE_INIT ( prop, state )
```

```c
#include <zephyr/drivers/pinctrl.h>
```

展开值（Value）：

```c
{                                                                      \
        .pins = prop ## _pins,                                         \
        .pin_cnt = ARRAY_SIZE(prop ## _pins),                          \
        .id = state                                                    \
}
```

用于初始化引脚控制状态的辅助宏。

使用动态引脚控制（Dynamic Pin Control）定义设备树中存储的替代状态配置时，此宏应与PINCTRL_DT_STATE_PINS_DEFINE配合使用。

示例：

```dts
// board.dts

/{
     zephyr,user {
             // uart0_alt_default node contains alternative pin config
             uart0_alt_default = <&uart0_alt_default>;
     };
};
```

```c
// application

PINCTRL_DT_STATE_PINS_DEFINE(DT_PATH(zephyr_user), uart0_alt_default);

static const struct pinctrl_state uart0_alt[] = {
    PINCTRL_DT_STATE_INIT(uart0_alt_default, PINCTRL_STATE_DEFAULT)
};
```

**参数（Parameters）**

| 名称／方向 | 说明 |
| --- | --- |
| `prop` | 设备树中包含状态配置的属性名称。 |
| `state` | prop代表的状态，见PINCTRL_STATES。 |

**注意（Attention）**：注意：仅在启用Kconfig选项CONFIG_PINCTRL_DYNAMIC时可用。

**参阅（See Also）**：另请参阅PINCTRL_DT_STATE_PINS_DEFINE。

> 译注——源码核对：示例注释中的board.dts表示设备树文件，application表示应用代码；uart0_alt_default节点保存替代引脚配置。示例展示声明与初始化，并没有调用pinctrl_update_states或应用状态。属性名与状态ID是两个参数，不应混为一项。

<a id="ga202dbcf2bcde364733996673dbdf2922"></a>

### `PINCTRL_DT_STATE_PINS_DEFINE`

```c
#define PINCTRL_DT_STATE_PINS_DEFINE ( node_id, prop )
```

```c
#include <zephyr/drivers/pinctrl.h>
```

展开值（Value）：

```c
static const pinctrl_soc_pin_t prop ## _pins[] =                       \
Z_PINCTRL_STATE_PINS_INIT(node_id, prop);                              \
```

用于从设备树（Devicetree）定义一个引脚控制状态所用引脚的辅助宏。

所定义的状态引脚变量名称与prop所用名称相同。本宏预期与PINCTRL_DT_STATE_INIT配合使用。

**参数（Parameters）**

| 名称／方向 | 说明 |
| --- | --- |
| `node_id` | 包含prop的节点标识符。 |
| `prop` | node_id中包含状态配置的属性。 |

**注意（Attention）**：注意：仅在启用Kconfig选项CONFIG_PINCTRL_DYNAMIC时可用。

**参阅（See Also）**：另请参阅PINCTRL_DT_STATE_INIT。

> 译注——源码核对：上文变量名说明按原文保留；实际宏通过prop ## _pins生成名称。例如prop为uart0_alt_default时，数组名是uart0_alt_default_pins，不是裸prop名称。

<a id="ga647115208cbed7534a98c56d93a517b8"></a>

### `pinctrl_update_states()`

```c
int pinctrl_update_states ( struct pinctrl_dev_config * config, const struct pinctrl_state * states, uint8_t state_cnt )
```

```c
#include <zephyr/drivers/pinctrl.h>
```

用一组新状态更新现有状态。

**参数（Parameters）**

| 名称／方向 | 说明 |
| --- | --- |
| `config` | 引脚控制配置。 |
| `states` | 要设置的新状态。 |
| `state_cnt` | 要设置的新状态数量。 |

**返回值（Return Values）**

| 名称／方向 | 说明 |
| --- | --- |
| `-EINVAL` | 新配置未包含与当前活动配置相同的一组状态。 |
| `-ENOSYS` | 此功能不可用。 |
| `0` | 成功。 |

**说明（Note）**：注意：为保证设备驱动正确运行，必须提供相同的一组状态。例如当前状态列表包含default和sleep时，新状态数组也应同时包含这两个状态。

**注意（Attention）**：注意：仅在启用Kconfig选项CONFIG_PINCTRL_DYNAMIC时可用。

> 译注——源码核对：当前实现先检查state_cnt相等，再逐项检查新状态ID是否能在旧表中找到，最后只执行config->states = states，不复制数组、不应用硬件配置，也不提供并发同步。新数组及其pins须在后续使用期间保持有效。它没有检查新表ID唯一性，重复ID可能通过现有检查却遗漏旧状态；调用方仍必须满足原文要求，提供完整且不重复的一组状态。未启用CONFIG_PINCTRL_DYNAMIC时，头文件的内联回退返回-ENOSYS。

## 2.4\_源码定位与使用边界

公共声明及宏见[drivers/pinctrl.h](../../../include/zephyr/drivers/pinctrl.h)，查找和动态更新实现在[drivers/pinctrl/common.c](../../../drivers/pinctrl/common.c)，配置条件见[Kconfig](../../../drivers/pinctrl/Kconfig)。对应的[头文件参考](P006_引脚控制驱动头文件参考.md)与[源码浏览译文](P007_引脚控制驱动头文件源码.md)可交叉阅读。

> 译注——状态保留与生效：本次头文件在未启用CONFIG_PINCTRL_KEEP_SLEEP_STATE时定义PINCTRL_SKIP_SLEEP=1；Kconfig在PM、PM_DEVICE或DEVICE_DEINIT_SUPPORT启用时默认保留sleep状态。定义配置、替换状态表和实际应用引脚是三个不同动作。动态更新应结合设备初始化及使用时序管理，不能把改表成功当成正在工作的外设已安全换脚。

动态示例中的英文注释已在PINCTRL_DT_STATE_INIT译注中解释；原始代码、节点名和属性名保留。

本次核对的官方main[驱动头文件](https://github.com/zephyrproject-rtos/zephyr/blob/main/include/zephyr/drivers/pinctrl.h)、[公共实现](https://github.com/zephyrproject-rtos/zephyr/blob/main/drivers/pinctrl/common.c)、[Kconfig](https://github.com/zephyrproject-rtos/zephyr/blob/main/drivers/pinctrl/Kconfig)及[设备树头文件](https://github.com/zephyrproject-rtos/zephyr/blob/main/include/zephyr/devicetree/pinctrl.h)摘要见[来源记录](../SOURCES.md)。仓库源码、main和latest不能自动视为同一版本。本批只翻译和核对，没有编译设备树、构建固件、切换引脚或进行实板验证。
