## 1.7\_详细说明（Detailed Documentation）

<a id="gace422fcd4b28e6e6e6fdbbc64b99468f"></a>

### `PINCTRL_DT_DEFINE`

```c
#define PINCTRL_DT_DEFINE ( node_id)
```

```c
#include <zephyr/drivers/pinctrl.h>
```

展开值（Value）：

```c
LISTIFY(DT_NUM_PINCTRL_STATES(node_id),                                \
             Z_PINCTRL_STATE_PINS_DEFINE, (;), node_id);               \
Z_PINCTRL_STATES_DEFINE(node_id)                                       \
Z_PINCTRL_DEV_CONFIG_STATIC Z_PINCTRL_DEV_CONFIG_CONST                 \
struct pinctrl_dev_config Z_PINCTRL_DEV_CONFIG_NAME(node_id) =         \
Z_PINCTRL_DEV_CONFIG_INIT(node_id)
```

为给定节点标识符定义全部引脚控制信息。

此辅助宏应与设备定义一起调用。它为node_id代表的设备定义并初始化引脚控制配置，也定义并初始化每个引脚控制状态（pinctrl-0至pinctrl-N）。标记为跳过的状态不会被定义，详情见Z_PINCTRL_SKIP_STATE。

**参数（Parameters）**

| 名称／方向 | 说明 |
| --- | --- |
| `node_id` | 节点标识符。 |

> 译注——源码核对：此宏定义配置数据，不会立刻写入硬件。状态ID通过pinctrl-names的大写词法单元拼接PINCTRL_STATE_<NAME>得到，不等同于pinctrl-N的N。实际引脚应用由pinctrl_apply_state等接口完成。

<a id="ga636656676e81c65e1133607c972d65f4"></a>

### `PINCTRL_DT_DEV_CONFIG_DECLARE`

```c
#define PINCTRL_DT_DEV_CONFIG_DECLARE ( node_id)
```

```c
#include <zephyr/drivers/pinctrl.h>
```

展开值（Value）：

```c
extern Z_PINCTRL_DEV_CONFIG_CONST struct pinctrl_dev_config            \
Z_PINCTRL_DEV_CONFIG_NAME(node_id)
```

为给定节点标识符（Node Identifier）声明引脚控制配置。

测试或使用运行时引脚控制的应用程序应使用此宏声明设备的引脚控制配置。之后可通过PINCTRL_DT_DEV_CONFIG_GET取得该配置的引用。

仅在选择CONFIG_PINCTRL_NON_STATIC时可用。

**参数（Parameters）**

| 名称／方向 | 说明 |
| --- | --- |
| `node_id` | 节点标识符。 |

> 译注——源码核对：CONFIG_PINCTRL_NON_STATIC控制配置对象能否被其他翻译单元引用；CONFIG_PINCTRL_DYNAMIC则使配置对象可修改，并由Kconfig选择NON_STATIC。extern声明不会新建配置对象，仍须由对应设备定义生成实际对象。

```c

```

```c

```

查找给定状态ID对应的状态配置。

**参数（Parameters）**

| 名称／方向 | 说明 |
| --- | --- |

## 1.8\_源码定位与使用边界

公共声明及宏见[drivers/pinctrl.h](../../../include/zephyr/drivers/pinctrl.h)，查找和动态更新实现在[drivers/pinctrl/common.c](../../../drivers/pinctrl/common.c)，配置条件见[Kconfig](../../../drivers/pinctrl/Kconfig)。对应的[头文件参考](P006_引脚控制驱动头文件参考.md)与[源码浏览译文](P007_引脚控制驱动头文件源码.md)可交叉阅读。

> 译注——状态保留与生效：本次头文件在未启用CONFIG_PINCTRL_KEEP_SLEEP_STATE时定义PINCTRL_SKIP_SLEEP=1；Kconfig在PM、PM_DEVICE或DEVICE_DEINIT_SUPPORT启用时默认保留sleep状态。定义配置、替换状态表和实际应用引脚是三个不同动作。动态更新应结合设备初始化及使用时序管理，不能把改表成功当成正在工作的外设已安全换脚。

本次核对的官方main[驱动头文件](https://github.com/zephyrproject-rtos/zephyr/blob/main/include/zephyr/drivers/pinctrl.h)、[公共实现](https://github.com/zephyrproject-rtos/zephyr/blob/main/drivers/pinctrl/common.c)、[Kconfig](https://github.com/zephyrproject-rtos/zephyr/blob/main/drivers/pinctrl/Kconfig)及[设备树头文件](https://github.com/zephyrproject-rtos/zephyr/blob/main/include/zephyr/devicetree/pinctrl.h)摘要见[来源记录](../SOURCES.md)。仓库源码、main和latest不能自动视为同一版本。本批只翻译和核对，没有编译设备树、构建固件、切换引脚或进行实板验证。
