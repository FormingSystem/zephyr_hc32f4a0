### `DT_NUM_PINCTRL_STATES`

```c
#define DT_NUM_PINCTRL_STATES ( node_id)
```

```c
#include <zephyr/devicetree/pinctrl.h>
```

展开值（Value）：

```c
DT_CAT(node_id, _PINCTRL_NUM)
```

取得节点中pinctrl属性的数量。

如果不存在任何pinctrl-'i'属性，则展开为0；否则展开为这些属性的数量。

设备树片段示例：

```dts
n1: node-1 {
```
