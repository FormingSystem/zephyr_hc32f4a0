## 6.2\_宏定义（Macros）

<a id="r_ga6e283a1a1b040323b96227b2ea8f731e"></a>

```c
#define PINCTRL_REG_NONE 0U
```

相关声明：[PINCTRL_REG_NONE](P001_引脚控制公共接口.md#ga6e283a1a1b040323b96227b2ea8f731e)。

<a id="r_ga636656676e81c65e1133607c972d65f4"></a>

```c
#define PINCTRL_DT_DEV_CONFIG_DECLARE(node_id)
```

相关声明：[PINCTRL_DT_DEV_CONFIG_DECLARE](P001_引脚控制公共接口.md#ga636656676e81c65e1133607c972d65f4)。

为给定节点标识符（Node Identifier）声明引脚控制配置。

<a id="r_gace422fcd4b28e6e6e6fdbbc64b99468f"></a>

```c
#define PINCTRL_DT_DEFINE(node_id)
```

相关声明：[PINCTRL_DT_DEFINE](P001_引脚控制公共接口.md#gace422fcd4b28e6e6e6fdbbc64b99468f)。

为给定节点标识符定义全部引脚控制信息。

<a id="r_ga8e984a57fd3c7a04cc921131ce79ac28"></a>

```c
#define PINCTRL_DT_INST_DEFINE(inst)
```

相关声明：[PINCTRL_DT_INST_DEFINE](P001_引脚控制公共接口.md#ga8e984a57fd3c7a04cc921131ce79ac28)。

为给定兼容标识实例索引定义全部引脚控制信息。

<a id="r_ga502c3b6faec140188dd5d614f4777918"></a>

```c
#define PINCTRL_DT_DEV_CONFIG_GET(node_id)
```

相关声明：[PINCTRL_DT_DEV_CONFIG_GET](P001_引脚控制公共接口.md#ga502c3b6faec140188dd5d614f4777918)。

根据节点标识符取得引脚控制配置的引用。

<a id="r_ga32748ffc5be4710707c7f1d9380cf93c"></a>

```c
#define PINCTRL_DT_INST_DEV_CONFIG_GET(inst)
```

相关声明：[PINCTRL_DT_INST_DEV_CONFIG_GET](P001_引脚控制公共接口.md#ga32748ffc5be4710707c7f1d9380cf93c)。

根据当前兼容标识的实例编号取得引脚控制配置的引用。

<a id="r_ga202dbcf2bcde364733996673dbdf2922"></a>

```c
#define PINCTRL_DT_STATE_PINS_DEFINE(node_id, prop)
```

相关声明：[PINCTRL_DT_STATE_PINS_DEFINE](P002_动态引脚控制接口.md#ga202dbcf2bcde364733996673dbdf2922)。

用于从设备树（Devicetree）定义一个引脚控制状态所用引脚的辅助宏。

```c

```

相关声明：[PINCTRL_DT_STATE_INIT](P002_动态引脚控制接口.md#ga6331121c706ba721e5bd43491dcc14d2)、[state](https://docs.zephyrproject.org/latest/doxygen/html/parser__state_8h.html#adc6e5733fc3c22f0a7b2914188c49c90)。

用于初始化引脚控制状态的辅助宏。

<a id="r_ga9bc564353cb9b1a7238c9fe8796023e6"></a>

```c
#define PINCTRL_STATE_DEFAULT 0U
```

相关声明：[PINCTRL_STATE_DEFAULT](P001_引脚控制公共接口.md#ga9bc564353cb9b1a7238c9fe8796023e6)。

默认状态（Default State）：设备正常运行时使用的状态。

<a id="r_ga2ea5ac271930e0e2e9f77952b2dbea1b"></a>

```c

```

相关声明：[PINCTRL_STATE_SLEEP](P001_引脚控制公共接口.md#ga2ea5ac271930e0e2e9f77952b2dbea1b)。

休眠状态（Sleep State）：设备处于低功耗模式时使用的状态。


相关声明：[PINCTRL_STATE_PRIV_START](P001_引脚控制公共接口.md#ga25989d7b48b2d7aa4f8ca6a30d9c9077)。

从此值开始的更高取值用于自定义私有状态（Private State）。

## 6.4\_源码定位与使用边界

公共声明及宏见[drivers/pinctrl.h](../../../include/zephyr/drivers/pinctrl.h)，查找和动态更新实现在[drivers/pinctrl/common.c](../../../drivers/pinctrl/common.c)，配置条件见[Kconfig](../../../drivers/pinctrl/Kconfig)。对应的[头文件参考](P006_引脚控制驱动头文件参考.md)与[源码浏览译文](P007_引脚控制驱动头文件源码.md)可交叉阅读。

> 译注——状态保留与生效：本次头文件在未启用CONFIG_PINCTRL_KEEP_SLEEP_STATE时定义PINCTRL_SKIP_SLEEP=1；Kconfig在PM、PM_DEVICE或DEVICE_DEINIT_SUPPORT启用时默认保留sleep状态。定义配置、替换状态表和实际应用引脚是三个不同动作。动态更新应结合设备初始化及使用时序管理，不能把改表成功当成正在工作的外设已安全换脚。

本次核对的官方main[驱动头文件](https://github.com/zephyrproject-rtos/zephyr/blob/main/include/zephyr/drivers/pinctrl.h)、[公共实现](https://github.com/zephyrproject-rtos/zephyr/blob/main/drivers/pinctrl/common.c)、[Kconfig](https://github.com/zephyrproject-rtos/zephyr/blob/main/drivers/pinctrl/Kconfig)及[设备树头文件](https://github.com/zephyrproject-rtos/zephyr/blob/main/include/zephyr/devicetree/pinctrl.h)摘要见[来源记录](../SOURCES.md)。仓库源码、main和latest不能自动视为同一版本。本批只翻译和核对，没有编译设备树、构建固件、切换引脚或进行实板验证。
