## 8.1\_宏定义（Macros）

<a id="r_ga24089220a93bc955700fba2c6170090e"></a>

```c
#define DT_PINCTRL_BY_IDX(node_id, pc_idx, idx)
```

相关声明：[DT_PINCTRL_BY_IDX](P005_引脚控制设备树宏.md#ga24089220a93bc955700fba2c6170090e)。

按索引取得pinctrl属性中某个句柄（Phandle）对应的节点标识符。

<a id="r_gaf4e6f811ea4b1698c048d5dd8bfa604a"></a>

```c
#define DT_PINCTRL_0(node_id, idx)
```

相关声明：[DT_PINCTRL_0](P005_引脚控制设备树宏.md#gaf4e6f811ea4b1698c048d5dd8bfa604a)。

从pinctrl-0属性取得节点标识符。

<a id="r_ga1cd336f902738fd684f3d81b3fb6caae"></a>

```c
#define DT_PINCTRL_BY_NAME(node_id, name, idx)
```

相关声明：[DT_PINCTRL_BY_NAME](P005_引脚控制设备树宏.md#ga1cd336f902738fd684f3d81b3fb6caae)。

按名称选取pinctrl配置，并取得其中句柄对应的节点标识符。

<a id="r_ga36eb691efc2a4854ccb62555aeade785"></a>

```c
#define DT_PINCTRL_NAME_TO_IDX(node_id, name)
```

相关声明：[DT_PINCTRL_NAME_TO_IDX](P005_引脚控制设备树宏.md#ga36eb691efc2a4854ccb62555aeade785)。

将pinctrl名称转换成对应索引。

```c
#define DT_PINCTRL_IDX_TO_NAME_TOKEN(node_id, pc_idx)
```

相关声明：[DT_PINCTRL_IDX_TO_NAME_TOKEN](P005_引脚控制设备树宏.md#ga47b0e5a18919f9f4829209cccbdeb430)。

将pinctrl属性索引转换成名称词法单元（Token）。

```c
#define DT_PINCTRL_IDX_TO_NAME_UPPER_TOKEN(node_id, pc_idx)
```

相关声明：[DT_PINCTRL_IDX_TO_NAME_UPPER_TOKEN](P005_引脚控制设备树宏.md#gaa6eec236ccde612e88017b027f4ba711)。

与DT_PINCTRL_IDX_TO_NAME_TOKEN()类似，但结果转为大写。

<a id="r_ga6ae1bab2a71cb628405ec43d38705606"></a>


相关声明：[DT_NUM_PINCTRLS_BY_IDX](P005_引脚控制设备树宏.md#ga6ae1bab2a71cb628405ec43d38705606)。


与DT_NUM_PINCTRLS_BY_IDX()类似，但按名称选取。

## 8.2\_源码定位与使用边界

宏定义位于[devicetree/pinctrl.h](../../../include/zephyr/devicetree/pinctrl.h)，[设备树宏组](P005_引脚控制设备树宏.md)给出完整参数及示例，[头文件参考](P008_引脚控制设备树头文件参考.md)和[源码浏览译文](P009_引脚控制设备树头文件源码.md)提供声明与展开关系。pc_idx、idx和状态ID分别表示属性序号、属性内句柄序号及运行时状态标识，不能互换。

> 译注——示例边界：设备树片段中的<...>、省略节点及未定义句柄用于展示宏关系，不是完整板级配置。HAS系列只判断生成的属性信息存在，不证明引脚状态已经应用或设备可用。厂商专用主题链接仍按单独页面跟踪，目录出现不代表该主题已翻译完成。

本次核对的官方main[驱动头文件](https://github.com/zephyrproject-rtos/zephyr/blob/main/include/zephyr/drivers/pinctrl.h)、[公共实现](https://github.com/zephyrproject-rtos/zephyr/blob/main/drivers/pinctrl/common.c)、[Kconfig](https://github.com/zephyrproject-rtos/zephyr/blob/main/drivers/pinctrl/Kconfig)及[设备树头文件](https://github.com/zephyrproject-rtos/zephyr/blob/main/include/zephyr/devicetree/pinctrl.h)摘要见[来源记录](../SOURCES.md)。仓库源码、main和latest不能自动视为同一版本。本批只翻译和核对，没有编译设备树、构建固件、切换引脚或进行实板验证。
