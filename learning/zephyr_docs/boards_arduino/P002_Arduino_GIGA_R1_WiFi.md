## 概述（Overview）

Arduino GIGA R1 WiFi是Arduino推出的开发板，采用STM32H747XI双核ARM Cortex-M7 + Cortex-M4微控制器（MCU），配备2 MB闪存（Flash）和1 MB SRAM。

开发板具有以下特性：


- RGB发光二极管（LED）
- 复位（Reset）与启动（Boot）按键
- USB-C设备接口（Device）
- USB主机接口（Host）
- 16 MB外部四线SPI闪存（QSPI Flash）
- 8 MB外部同步动态随机存储器（SDRAM）
- Murata Type 1DX蓝牙与Wi-Fi模块，基于CYW4343W
- 音频插孔（Audio Jack）
- ATECC608A安全元件（Secure Element）

开发板的更多信息，包括数据手册、引脚分配（Pinout）及原理图（Schematics），见[Arduino GIGA网站](https://docs.arduino.cc/hardware/giga-r1-wifi)。

STM32H747XIH6的更多信息见：


- [ST网站上的STM32H747XI（www.st.com）](https://www.st.com/content/st_com/en/products/microcontrollers-microprocessors/stm32-32-bit-arm-cortex-mcus/stm32-high-performance-mcus/stm32h7-series/stm32h747-757/stm32h747xi.html)
- [STM32H747xx参考手册（Reference Manual）](https://www.st.com/resource/en/reference_manual/dm00176879.pdf)
- [STM32H747xx数据手册（Datasheet）](https://www.st.com/resource/en/datasheet/stm32h747xi.pdf)

<a id="resources-sharing"></a>

### 资源共享（Resources Sharing）

STM32H747片上系统的双核特性要求在两个内核之间共享硬件资源，主要通过以下三种方式实现：


- 编译（Compilation）：只有M7内核可访问时钟配置；M4内核只能启用或停用总线时钟。
- 编译前静态分配（Static Pre-Compilation Assignment）：UART等外设在编译前通过设备树分配，必须确保同一外设不会同时分配给两个内核。
- 运行时保护（Run Time Protection）：两个内核可能在运行时访问中断控制器和GPIO配置，通过硬件信号量（Hardware Semaphore）保护访问，以避免潜在的并发访问问题。

<a id="flashing"></a>

### 烧录（Flashing）

可以使用dfu-util烧录，也可以将J-Link或Black Magic Probe等外部调试探针连接到板上标为“JTAG”的MIPI-10串行线调试端口（SWD）后烧录。

注意（Note）

开发板出厂时在第一个闪存页中写入了Arduino定制引导加载程序，快速连按两次RST按键即可进入。它兼容USB设备固件升级（USB-DFU），支持内部和外部闪存编程，也是`west flash`默认使用的引导加载程序。按住BOOT0按键再按RST也可进入STM32内部ROM引导加载程序；它同样支持USB-DFU，但只能编程内部闪存，并可能覆盖Arduino引导加载程序。详情见[Arduino GIGA速查表（Cheat Sheet）](https://docs.arduino.cc/tutorials/giga-r1-wifi/cheat-sheet)的“Boot0”一节。

先通过USB端口将Arduino GIGA R1连接到主机，快速连按两次RST按键进入Arduino引导加载模式，然后构建并烧录应用。

下面以[Hello World](../getting_started/P005_HelloWorld示例.md#hello_world)应用为例。

```text
# From the root of the zephyr repository
west build -b arduino_giga_r1/stm32h747xx/m7 samples/hello_world
west flash
```

运行主机串口程序连接开发板：

```text
$ minicom -D /dev/ttyACM0
```

控制台上应显示以下消息：

```text
Hello World! arduino_giga_r1
```

同样，也可以为M4目标构建和烧录示例。

以下以M4内核上的[Blinky](../getting_started/P004_LED闪烁示例.md#blinky)应用为例。

```text
# From the root of the zephyr repository
west build -b arduino_giga_r1/stm32h747xx/m4 samples/basic/blinky
west flash
```

<a id="debugging"></a>

### 调试（Debugging）

可使用`west debug`调试；将J-Link或Black Magic Probe等外部探针连接到板上标为“JTAG”的MIPI-10 SWD端口。例如：

```text
west debug -r jlink
```
