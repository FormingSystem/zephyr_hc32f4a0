原文：[官方页面](https://docs.zephyrproject.org/latest/doxygen/html/mchp__flash_8h.html)。读取日期：2026-10-17；来源摘要见[来源记录](../SOURCES.md)。

Microchip闪存控制器（Flash Controller）驱动的头文件。

查看此文件的源码。

<a id="details"></a>

Microchip 闪存控制器驱动头文件（Flash Controller Driver Header）。本头文件按条件包含受支持的控制器版本（例如 G1、G2）对应的 Microchip 闪存控制器驱动头文件。它根据构建配置（Build Configuration）包含适用的版本专用头文件，以支持相应的闪存控制器外设（Flash Controller Peripheral）。
