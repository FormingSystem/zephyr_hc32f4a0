# 第3章\_zephyr\_\_arch\_\_tricore\_\_syscall.h\_文件参考

原文：[官方页面](https://docs.zephyrproject.org/latest/doxygen/html/arch_2tricore_2syscall_8h.html)。读取日期：2026-10-17；来源摘要见[来源记录](../SOURCES.md)。

TriCore专用系统调用（Syscall）的头文件。

查看此文件的源码。

<a id="details"></a>

TriCore 专用系统调用头文件（Syscall Header）。内核（Kernel）使用这些陷阱编号（Trap Numbers），通过系统调用指令（Syscall Instruction）分派上下文切换（Context Switch）、异常（Exception）和中断卸载（IRQ Offload）。
