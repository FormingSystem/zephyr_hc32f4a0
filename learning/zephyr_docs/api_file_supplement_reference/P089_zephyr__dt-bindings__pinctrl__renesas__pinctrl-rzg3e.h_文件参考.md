Renesas RZ/G3E 的引脚与功能定义（Pin and Function Definitions）。本头文件提供宏常量（Macro Constants），用于编码 Renesas RZ/G3E 片上系统（SoCs）的引脚功能选择（Pin Function Selections）及引脚索引（Pin Indices）。设备树引脚控制子系统（Devicetree Pinctrl Subsystem）使用这些值描述外设引脚映射（Peripheral Pin Mappings）。
