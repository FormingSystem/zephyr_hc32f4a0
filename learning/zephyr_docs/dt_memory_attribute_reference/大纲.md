# 设备树内存属性参考大纲

本册完整翻译设备树内存属性（Devicetree Memory Attributes）的总览、通用／软件／架构字段，以及软件分配、Arm、Arm64、RISC-V和Xtensa的类型接口，包含六个头文件的参考页与源码浏览页。

先读第1至4章建立字段划分，再按目标架构选择头文件或第17至21章的详细宏说明。通用、软件与架构属性的含义不同；写入属性描述后，还需要相应子系统或架构代码读取并处理。源码跟踪译注说明提取结果不右移、软件堆精确匹配、Arm旧式定义及Arm64组合编码，原文掩码差异单独标示。

原始声明、展开式、可见源码和许可证保留；所有仓库定位使用相对链接。完整范围见[全站进度](../PROGRESS.md)。
