# 第11章\_实时时钟时间结构

原文：[structrtc__time](https://docs.zephyrproject.org/latest/doxygen/html/structrtc__time.html)。读取日期：2026-10-13，`latest`。

结构体`rtc_time`存储具有亚秒精度（Sub-second Precision）的日期和时间，供实时时钟（Real-Time Clock，RTC）接口使用。头文件为：

```c
#include <zephyr/drivers/rtc.h>
```

## 11.1\_全部字段与有效范围

十个字段的类型都是`int`。注意月份从0开始、月内日期从1开始，年份存储相对1900年的偏移。

| 类型 | 字段 | 含义 | 范围或特殊值 |
| --- | --- | --- | --- |
| `int` | `tm_sec` | 秒（Second） | 0至59。 |
| `int` | `tm_min` | 分（Minute） | 0至59。 |
| `int` | `tm_hour` | 小时（Hour） | 0至23。 |
| `int` | `tm_mday` | 月内日期（Day of Month） | 1至31。 |
| `int` | `tm_mon` | 月（Month） | 0至11。 |
| `int` | `tm_year` | 年份（Year） | 实际年份减1900。 |
| `int` | `tm_wday` | 星期（Day of Week） | 0至6；星期日为0，未知为-1。 |
| `int` | `tm_yday` | 年内日序（Day of Year） | 0至365；未知为-1。 |
| `int` | `tm_isdst` | 夏令时标志（Daylight Saving Time Flag） | 原文取值范围为[-1]；未知为-1。 |
| `int` | `tm_nsec` | 纳秒（Nanosecond） | 0至999999999；未知为0。 |

## 11.2\_与标准时间结构的兼容

从`tm_sec`到`tm_isdst`的成员与标准时间库（Standard Time Library）的`struct tm`一一映射，因此可与标准时间库配合。应使用`rtc_time_to_tm`把`rtc_time`指针安全转换为`tm`指针，见[公共接口辅助函数](P009_实时时钟公共接口.md)。

`tm_nsec`是附加的纳秒字段。原文将夏令时字段的范围写为`[-1]`，本译文按原样保留，不把标准库其他场景中的0或正数规则自动扩展到本接口。
