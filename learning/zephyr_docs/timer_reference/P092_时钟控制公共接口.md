# 第92章\_时钟控制公共接口

原文：[group__clock__control__interface](https://docs.zephyrproject.org/latest/doxygen/html/group__clock__control__interface.html)。读取日期：2026-10-13，`latest`。

## 92.2\_全部子系统选择器

```c
#define CLOCK_CONTROL_SUBSYS_ALL NULL
```

`CLOCK_CONTROL_SUBSYS_ALL`宏是子系统选择器（Subsystem Selector），表示该控制器的全部子系统。`NULL`为空指针值。

## 92.3\_不透明句柄

```c
typedef void *clock_control_subsys_t;
typedef void *clock_control_subsys_rate_t;
```

`clock_control_subsys_t`是不透明句柄（Opaque Handle），用于标识时钟控制器子系统；其指向的数据仅对所使用的控制器驱动实例有意义。

`clock_control_subsys_rate_t`是不透明句柄，用于标识子系统的时钟频率（Clock Rate）；其数据仅在设置所使用控制器驱动实例的频率时有意义。不要把这个`void *`类型自动改成整数频率参数。

## 92.4\_启动完成回调

```c
typedef void (*clock_control_cb_t)(const struct device *dev,
                                   clock_control_subsys_t subsys,
                                   void *user_data);
```

时钟已经启动时调用此回调（Callback）。`user_data`为用户数据（User Data）；`—`表示原参数表未标注方向，`[out]`表示输出。

**参数：**

| 参数 | 方向 | 说明 |
| --- | --- | --- |
| `dev` | — | 其驱动负责控制时钟的设备结构 |
| `subsys` | — | 表示时钟的不透明数据 |
| `user_data` | — | 传给`clock_control_async_on()`的用户数据 |


## 92.5\_时钟状态

```c
enum clock_control_status {
        CLOCK_CONTROL_STATUS_STARTING,
        CLOCK_CONTROL_STATUS_OFF,
        CLOCK_CONTROL_STATUS_ON,
        CLOCK_CONTROL_STATUS_UNKNOWN
};
```

| 枚举项 | 含义 |
| --- | --- |
| `CLOCK_CONTROL_STATUS_STARTING` | 时钟正在启动（Starting） |
| `CLOCK_CONTROL_STATUS_OFF` | 时钟关闭（Off） |
| `CLOCK_CONTROL_STATUS_ON` | 时钟开启（On） |
| `CLOCK_CONTROL_STATUS_UNKNOWN` | 状态未知（Unknown） |

## 92.6\_异步开启时钟

```c
static inline int clock_control_async_on(const struct device *dev,
                                         clock_control_subsys_t sys,
                                         clock_control_cb_t cb,
                                         void *user_data);
```

请求启动时钟，并在时钟已经启动后调用用户回调。函数为非阻塞（Non-blocking），可以从任意上下文调用。

**参数：**

| 参数 | 方向 | 说明 |
| --- | --- | --- |
| `dev` | — | 设备 |
| `sys` | — | 表示子系统的不透明数据指针 |
| `cb` | — | 回调函数 |
| `user_data` | — | 传给回调的用户上下文 |


**返回值：**

| 返回值 | 条件 |
| --- | --- |
| `0` | 成功发起启动 |
| `-EALREADY` | 此前已启动，当前处于启动中或运行状态 |
| `-ENOTSUP` | 不支持请求的操作模式 |
| `-ENOSYS` | 未实现该接口 |
| `<0` | 厂商特定错误对应的其他负错误码 |


## 92.7\_配置源时钟

```c
static inline int clock_control_configure(const struct device *dev,
                                          clock_control_subsys_t sys,
                                          void *data);
```

配置源时钟（Source Clock）。函数非阻塞，可从任意上下文调用；成功时所选时钟按调用者请求完成配置。

调用者有责任确保之后的 API 调用提供正确的信息，以便驱动执行正确操作，例如`clock_control_get_rate`应使用正确的时钟源。`data`由实现定义，可携带达到预期时钟配置所需的补充信息。

**参数：**

| 参数 | 方向 | 说明 |
| --- | --- | --- |
| `dev` | — | 其驱动负责控制时钟的设备结构 |
| `sys` | — | 表示时钟的不透明数据 |
| `data` | — | 为时钟配置提供额外输入的不透明数据 |


**返回值：**

| 返回值 | 条件 |
| --- | --- |
| `0` | 成功 |
| `-ENOSYS` | 设备驱动未实现此调用 |
| `-errno` | 失败时的其他负错误码 |


## 92.8\_读取子系统频率

```c
static inline int clock_control_get_rate(const struct device *dev,
                                         clock_control_subsys_t sys,
                                         uint32_t *rate);
```

取得给定子系统的时钟频率。输出参数`rate`由驱动填写。

**参数：**

| 参数 | 方向 | 说明 |
| --- | --- | --- |
| `dev` | — | 时钟控制器驱动实例的设备结构指针 |
| `sys` | — | 表示子系统的不透明数据指针 |
| `rate` | [out] | 子系统时钟频率 |


**返回值：**

| 返回值 | 条件 |
| --- | --- |
| `0` | 成功读取频率 |
| `-EAGAIN` | 无法读取频率；某些驱动不支持在时钟关闭时返回频率 |
| `-ENOTSUP` | 不支持读取指定子系统的时钟频率 |
| `-ENOSYS` | 未实现该接口 |

```c
static inline enum clock_control_status clock_control_get_status(const struct device *dev,
```

**参数：**

| 参数 | 方向 | 说明 |
| --- | --- | --- |
| `dev` | — | 设备 |
| `sys` | — | 表示子系统的不透明数据指针 |


## 92.10\_关闭时钟

```c
static inline int clock_control_off(const struct device *dev,
                                    clock_control_subsys_t sys);
```

关闭设备控制的时钟。函数非阻塞，可从任意上下文调用。成功时，函数返回前时钟已经关闭。

返回值：成功为0，失败为负错误码。

**参数：**

| 参数 | 方向 | 说明 |
| --- | --- | --- |
| `dev` | — | 其驱动负责控制时钟的设备结构 |
| `sys` | — | 表示时钟的不透明数据 |


## 92.11\_开启时钟

```c
static inline int clock_control_on(const struct device *dev,
                                   clock_control_subsys_t sys);
```

开启设备控制的时钟。成功时，函数返回前时钟已经启用并就绪。**此函数可能休眠（Sleep），因此只能在线程上下文（Thread Context）调用。** 需要非阻塞操作时使用`clock_control_async_on()`。

返回值：成功为0，失败为负错误码。

**参数：**

| 参数 | 方向 | 说明 |
| --- | --- | --- |
| `dev` | — | 其驱动负责控制时钟的设备结构 |
| `sys` | — | 表示时钟的不透明数据 |


## 92.12\_设置时钟频率

```c
static inline int clock_control_set_rate(const struct device *dev,
                clock_control_subsys_t sys,
                clock_control_subsys_rate_t rate);
```

设置设备控制的时钟频率。成功时，函数返回前新频率已经设置并就绪。**此函数可能休眠，因此只能在线程上下文调用。**

**参数：**

| 参数 | 方向 | 说明 |
| --- | --- | --- |
| `dev` | — | 其驱动负责控制时钟的设备结构 |
| `sys` | — | 表示时钟的不透明数据 |
| `rate` | — | 表示目标时钟频率的不透明数据 |


**返回值：**

| 返回值 | 条件 |
| --- | --- |
| `-EALREADY` | 时钟已经处于指定频率 |
| `-ENOTSUP` | 不支持请求的操作模式 |
| `-ENOSYS` | 未实现该接口 |
| `<0` | 厂商特定错误对应的其他负错误码 |


原返回值表只列出失败情形，未单独列出成功数值；上方成功行为按原说明保留。

后端回调签名见[时钟控制驱动后端接口](P093_时钟控制驱动后端接口.md)；完整源码见[时钟控制完整头文件](P096_时钟控制完整头文件.md)。
