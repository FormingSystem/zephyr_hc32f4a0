# 第87章\_内核超时类型

原文：[structk__timeout__t](https://docs.zephyrproject.org/latest/doxygen/html/structk__timeout__t.html)。读取日期：2026-10-13，`latest`。

`k_timeout_t`是不透明（Opaque）的内核超时类型（Kernel Timeout Type），定义于`zephyr/sys/clock.h`，用于保存传给内核应用程序接口（Application Programming Interface，API）的超时参数。

## 87.1\_构造与比较约定

该类型能表示不同格式和单位的时间。应用应使用专门的构造宏，例如`K_MSEC()``K_TIMEOUT_ABS_TICKS()`，或使用两个常量`K_NO_WAIT`、`K_FOREVER`。

构造完成后，应用不应检查其内部数据。比较两个超时值是否相等，应使用`K_TIMEOUT_EQ()`。
