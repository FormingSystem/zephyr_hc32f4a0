# 第12章\_实时时钟驱动操作结构

原文：[structrtc__driver__api](https://docs.zephyrproject.org/latest/doxygen/html/structrtc__driver__api.html)。读取日期：2026-10-13，`latest`。

`rtc_driver_api`是每个实时时钟（Real-Time Clock，RTC）驱动需要定义的驱动应用程序接口（Driver Application Programming Interface，Driver API）结构。它包含驱动实现的操作函数指针，也可容纳驱动专用常量数据，定义于：

```c
#include <zephyr/drivers/rtc.h>
```

## 12.1\_必填、可选与编译条件

必填（Required，REQ）成员必须由驱动设置；可选（Optional，OPT）成员可以不设置。可选成员还受下表所列Kconfig配置选项控制，仅在相应配置启用时可用。

| 类型 | 字段 | 要求 | 作用 | Kconfig条件 |
| --- | --- | --- | --- | --- |
| `rtc_api_set_time` | `set_time` | 必填 | 设置RTC时间。 | 无额外条件 |
| `rtc_api_get_time` | `get_time` | 必填 | 取得RTC时间。 | 无额外条件 |
| `rtc_api_alarm_get_supported_fields` | `alarm_get_supported_fields` | 可选 | 取得闹钟支持的时间字段。 | `CONFIG_RTC_ALARM` |
| `rtc_api_alarm_set_time` | `alarm_set_time` | 可选 | 设置闹钟时间。 | `CONFIG_RTC_ALARM` |
| `rtc_api_alarm_get_time` | `alarm_get_time` | 可选 | 取得闹钟时间。 | `CONFIG_RTC_ALARM` |
| `rtc_api_alarm_is_pending` | `alarm_is_pending` | 可选 | 检查闹钟待处理状态。 | `CONFIG_RTC_ALARM` |
| `rtc_api_alarm_set_callback` | `alarm_set_callback` | 可选 | 设置闹钟回调。 | `CONFIG_RTC_ALARM` |
| `rtc_api_update_set_callback` | `update_set_callback` | 可选 | 设置每秒更新回调。 | `CONFIG_RTC_UPDATE` |
| `rtc_api_set_calibration` | `set_calibration` | 可选 | 设置RTC校准。 | `CONFIG_RTC_CALIBRATION` |
| `rtc_api_get_calibration` | `get_calibration` | 可选 | 取得RTC校准。 | `CONFIG_RTC_CALIBRATION` |

每个函数指针的完整类型见[驱动后端接口](P010_实时时钟驱动后端接口.md)。原文的配置条件分别是闹钟（Alarm）的`CONFIG_RTC_ALARM`、更新（Update）的`CONFIG_RTC_UPDATE`和校准（Calibration）的`CONFIG_RTC_CALIBRATION`。

## 12.2\_设备注册与源码对应

原页同时列出设备定义宏`DEVICE_DT_INST_DEFINE()`、`DEVICE_DT_DEFINE()`及驱动接口声明宏`DEVICE_API()`供交叉阅读。完整结构体和条件编译见[公共头文件源码](P014_实时时钟公共头文件源码.md)；文档生成条件`__DOXYGEN__`允许生成器展示可选字段，不代表这些字段在任意构建中都存在。
