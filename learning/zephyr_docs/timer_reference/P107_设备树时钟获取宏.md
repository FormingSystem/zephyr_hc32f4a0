# 第107章\_设备树时钟获取宏

原文：[group__devicetree-clocks](https://docs.zephyrproject.org/latest/doxygen/html/group__devicetree-clocks.html)。读取日期：2026-10-13，`latest`。

本页介绍设备树时钟（Devicetree Clocks）应用程序编程接口（Application Programming Interface，API）的18个宏，头文件为`zephyr/devicetree/clocks.h`。

## 107.1\_术语与参数约定

`clocks`是引用时钟控制器（Clock Controller）的 phandle 数组（phandle-array）属性；phandle 是设备树节点的引用句柄。时钟说明符（Clock Specifier）中可以包含由绑定（Binding）命名的单元（Cell），例如`bus`和`bits`。`clock-names`为各时钟元素提供名称。

`node_id`是节点标识（Node Identifier），`idx`是逻辑索引（Logical Index），`inst`是实例编号（Instance Number）。`DT_DRV_COMPAT`是驱动兼容字符串（Driver Compatible String）宏；`DT_DRV_INST(inst)`把相应驱动实例编号转换为节点标识。`DT_NODELABEL`宏通过节点标签（Node Label）取得节点标识。

`name`和`cell`参数必须使用**小写字母和下划线**形式。以下示例中的`//`注释表示预期展开结果；省略号`...`是原示例的省略写法，片段并非完整设备树文件。

## 107.3\_取得首个说明符单元

```c
#define DT_CLOCKS_CELL(node_id, cell)
```

等价于`DT_CLOCKS_CELL_BY_IDX(node_id, 0, cell)`。

宏展开：

```c
DT_CLOCKS_CELL_BY_IDX(node_id, 0, cell)
```

**参数：**

| 参数 | 含义 |
| --- | --- |
| `node_id` | 具有`clocks`属性的节点标识 |
| `cell` | 以小写字母和下划线表示的单元名称 |


**展开结果：** 索引0处的单元值。

另见 [DT_CLOCKS_CELL_BY_IDX()](P107_设备树时钟获取宏.md)。

## 107.4\_按索引取得说明符单元

```c
#define DT_CLOCKS_CELL_BY_IDX(node_id, idx, cell)
```

取得指定索引处的时钟说明符单元值。

宏展开：

```c
DT_PHA_BY_IDX(node_id, clocks, idx, cell)
```

设备树片段：

```dts
clk1: clock-controller@... {
        compatible = "vnd,clock";
        #clock-cells = <2>;
};

n: node {
        clocks = <&clk1 10 20>, <&clk1 30 40>;
};
```

`vnd,clock`兼容字符串的绑定片段：

```yaml
clock-cells:
  - bus
  - bits
```

用法示例：

```c
DT_CLOCKS_CELL_BY_IDX(DT_NODELABEL(n), 0, bus) // 10
DT_CLOCKS_CELL_BY_IDX(DT_NODELABEL(n), 1, bits) // 40
```

**参数：**

| 参数 | 含义 |
| --- | --- |
| `node_id` | 具有`clocks`属性的节点标识 |
| `idx` | `clocks`属性中的逻辑索引 |
| `cell` | 以小写字母和下划线表示的单元名称 |


**展开结果：** 索引`idx`处的单元值。

另见 [DT_PHA_BY_IDX()](../dt_property_reference/P001_设备树属性读取宏.md#ga118b63fd22c20ef940ac2fa073c126ed)。

## 107.5\_按名称取得说明符单元

```c
#define DT_CLOCKS_CELL_BY_NAME(node_id, name, cell)
```

按名称取得时钟说明符中的单元值。

宏展开：

```c
DT_PHA_BY_NAME(node_id, clocks, name, cell)
```

设备树片段：

```dts
clk1: clock-controller@... {
        compatible = "vnd,clock";
        #clock-cells = <2>;
};

n: node {
        clocks = <&clk1 10 20>, <&clk1 30 40>;
        clock-names = "alpha", "beta";
};
```

`vnd,clock`兼容字符串的绑定片段：

```yaml
clock-cells:
  - bus
  - bits
```

用法示例：

```c
DT_CLOCKS_CELL_BY_NAME(DT_NODELABEL(n), alpha, bus) // 10
DT_CLOCKS_CELL_BY_NAME(DT_NODELABEL(n), beta, bits) // 40
```

**参数：**

| 参数 | 含义 |
| --- | --- |
| `node_id` | 具有`clocks`属性的节点标识 |
| `name` | 由节点`clock-names`属性定义的`clocks`元素名称，以小写字母和下划线表示 |
| `cell` | 以小写字母和下划线表示的单元名称 |


**展开结果：** 指定名称元素的说明符中的单元值。

另见 [DT_PHA_BY_NAME()](../dt_property_reference/P001_设备树属性读取宏.md#gae469615356a867c49416da15bdc44a26)。

## 107.7\_按索引取得时钟控制器

```c
#define DT_CLOCKS_CTLR_BY_IDX(node_id, idx)
```

从`clocks`phandle 数组属性的指定索引处，取得控制器 phandle 对应的节点标识。

宏展开：

```c
DT_PHANDLE_BY_IDX(node_id, clocks, idx)
```

设备树片段：

```dts
clk1: clock-controller@... { ... };

clk2: clock-controller@... { ... };

n: node {
        clocks = <&clk1 10 20>, <&clk2 30 40>;
};
```

用法示例：

```c
DT_CLOCKS_CTLR_BY_IDX(DT_NODELABEL(n), 0)) // DT_NODELABEL(clk1)
DT_CLOCKS_CTLR_BY_IDX(DT_NODELABEL(n), 1)) // DT_NODELABEL(clk2)
```

**译注：** 上面原用法示例的两行调用各多写了一个右括号，即`0))``1))`。这里保留原代码用于对照；实际使用时应移除多余的右括号。注释分别表示得到`clk1``clk2`的节点标识。

**参数：**

| 参数 | 含义 |
| --- | --- |
| `node_id` | 节点标识 |
| `idx` | `clocks`属性中的逻辑索引 |


**展开结果：** 索引`idx`处引用的时钟控制器节点标识。

另见 [DT_PHANDLE_BY_IDX()](../dt_property_reference/P001_设备树属性读取宏.md#ga8ff163c240878a988d29d727671671de)。

## 107.9\_检查时钟索引是否存在

```c
#define DT_CLOCKS_HAS_IDX(node_id, idx)
```

检查节点`clocks`phandle 数组属性的指定索引是否有效。有效时展开为1，否则展开为0。

宏展开：

```c
DT_PROP_HAS_IDX(node_id, clocks, idx)
```

设备树片段：

```dts
n1: node-1 {
        clocks = <...>, <...>;
};

n2: node-2 {
        clocks = <...>;
};
```

用法示例：

```c
DT_CLOCKS_HAS_IDX(DT_NODELABEL(n1), 0) // 1
DT_CLOCKS_HAS_IDX(DT_NODELABEL(n1), 1) // 1
DT_CLOCKS_HAS_IDX(DT_NODELABEL(n1), 2) // 0
DT_CLOCKS_HAS_IDX(DT_NODELABEL(n2), 1) // 0
```

**参数：**

| 参数 | 含义 |
| --- | --- |
| `node_id` | 节点标识；该节点可以有，也可以没有`clocks`属性 |
| `idx` | 要检查是否存在的`clocks`phandle 数组索引 |


**展开结果：** 索引存在为1，否则为0。

## 107.10\_检查时钟名称是否存在

```c
#define DT_CLOCKS_HAS_NAME(node_id, name)
```

检查节点的`clock-names`数组属性是否含有给定名称。作为数组单元值存在时展开为1，否则展开为0。

宏展开：

```c
DT_PROP_HAS_NAME(node_id, clocks, name)
```

设备树片段：

```dts
n1: node-1 {
        clocks = <...>, <...>;
        clock-names = "alpha", "beta";
};

n2: node-2 {
        clocks = <...>;
        clock-names = "alpha";
};
```

用法示例：

```c
DT_CLOCKS_HAS_NAME(DT_NODELABEL(n1), alpha) // 1
DT_CLOCKS_HAS_NAME(DT_NODELABEL(n1), beta)  // 1
DT_CLOCKS_HAS_NAME(DT_NODELABEL(n2), beta)  // 0
```

**参数：**

| 参数 | 含义 |
| --- | --- |
| `node_id` | 节点标识；该节点可以有，也可以没有`clock-names`属性 |
| `name` | 要检查的`clock-names`单元值名称，以小写字母和下划线表示 |


**展开结果：** 时钟名称存在为1，否则为0。
