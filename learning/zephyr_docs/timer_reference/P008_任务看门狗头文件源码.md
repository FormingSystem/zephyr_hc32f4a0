# 第8章\_任务看门狗头文件源码

原文：[task__wdt_8h_source](https://docs.zephyrproject.org/latest/doxygen/html/task__wdt_8h_source.html)。读取日期：2026-10-13，`latest`。

本页保存`zephyr/task_wdt/task_wdt.h`官方源码浏览页的全部可见代码、版权与许可，仅移除网页行号和行尾空白。任务看门狗（Task Watchdog）用于任务通道的超时监测，接口中文说明已见[任务看门狗接口](../power/P009_任务看门狗接口.md)和[头文件参考](../power/P010_任务看门狗头文件.md)。

## 8.1\_完整可见源码

原声明保留通道编号、用户数据指针、回调（Callback）类型及C++条件包装。

```c
/*
 * Copyright (c) 2020 Libre Solar Technologies GmbH
 *
 * SPDX-License-Identifier: Apache-2.0
 */


#ifndef ZEPHYR_INCLUDE_TASK_WDT_TASK_WDT_H_
#define ZEPHYR_INCLUDE_TASK_WDT_TASK_WDT_H_

#include <zephyr/types.h>
#include <zephyr/kernel.h>
#include <zephyr/device.h>


#ifdef __cplusplus
extern "C" {
#endif

typedef void (*task_wdt_callback_t)(int channel_id, void *user_data);

int task_wdt_init(const struct device *hw_wdt);

int task_wdt_add(uint32_t reload_period, task_wdt_callback_t callback,
                 void *user_data);

int task_wdt_delete(int channel_id);

int task_wdt_feed(int channel_id);

void task_wdt_suspend(void);

void task_wdt_resume(void);

#ifdef __cplusplus
}
#endif


#endif /* ZEPHYR_INCLUDE_TASK_WDT_TASK_WDT_H_ */
```

## 8.2\_声明用途

`task_wdt_callback_t`接收通道ID（Channel ID）与用户数据，和硬件看门狗的`wdt_callback_t`签名不同。六个函数依次初始化任务看门狗、增加通道、删除通道、给通道喂狗（Feed）、挂起（Suspend）和恢复（Resume）。

参数、返回值及硬件回退（Hardware Fallback）行为以[任务看门狗接口](../power/P009_任务看门狗接口.md)为准，使用示例见[任务看门狗示例](../power/P011_任务看门狗示例.md)。原源码页只有声明，未展示函数实现或额外的实现注释。
