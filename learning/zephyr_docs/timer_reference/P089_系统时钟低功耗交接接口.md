# 第89章\_系统时钟低功耗交接接口

原文：[group__clock__lpm](https://docs.zephyrproject.org/latest/doxygen/html/group__clock__lpm.html)。读取日期：2026-10-13，`latest`。

本页对应系统定时器低功耗配套接口（System Timer Low-power Companion Interface）分组。配置了低功耗配套计时功能时使用该接口。

## 89.1\_可用配置

原注意栏列出的配置选项是`CONFIG_SYSTEM_TIMER_LPM_COMPANION_COUNTER`与`CONFIG_SYSTEM_TIMER_LPM_COMPANION_HOOKS`。启用`CONFIG_SYSTEM_TIMER_LPM_COMPANION_NONE`时，该接口不可用。

选择`CONFIG_SYSTEM_TIMER_LPM_COMPANION_HOOKS`时，所有钩子（Hook）的实现由片上系统（System-on-Chip，SoC）或平台专用代码提供；否则由系统定时器子系统提供。

> 译注：原注意栏并列列出两项配置，容易被理解为必须同时开启。官方[Kconfig选择项](https://docs.zephyrproject.org/latest/kconfig.html#CONFIG_SYSTEM_TIMER_LPM_COMPANION)把`NONE`、`COUNTER``HOOKS`列为同一个选择（Choice）的三个成员，不能将COUNTER与HOOKS两种可用实现译为必须同时启用。这里保留原列项，并按其正文和Kconfig选择关系解释。

## 89.2\_对应头文件

接口用途见[低功耗配套头文件参考](P084_系统定时器低功耗配套头文件参考.md)，三个内部钩子的可见声明见[对应源码](P085_系统定时器低功耗配套头文件源码.md)。原分组页没有列出单个函数的详细契约。
