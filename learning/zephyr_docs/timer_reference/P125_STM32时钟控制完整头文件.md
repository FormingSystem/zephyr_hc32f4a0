# 第125章\_STM32时钟控制完整头文件

原文：[stm32__clock__control_8h_source](https://docs.zephyrproject.org/latest/doxygen/html/stm32__clock__control_8h_source.html)。读取日期：2026-10-13，`latest`。

本页完整保留官方源码网页中的`zephyr/drivers/clock_control/stm32_clock_control.h`。该文件为 STM32 时钟驱动提供从设备树（Devicetree）派生的内部配置；**不是应用程序公共应用程序编程接口（Public Application API）**。

## 125.1\_源码阅读约定

文件中的`CONFIG_SOC_SERIES_*`是片上系统（System on Chip，SoC）系列构建配置符号；不同系列通过条件编译（Conditional Compilation）选择不同定义。节点标签（Node Label）由`DT_NODELABEL`取得；`DT_PROP`读取属性，`DT_PROP_OR`在属性不存在时使用代码给定的回退值；`DT_NODE_HAS_COMPAT_STATUS`同时检查兼容字符串（Compatible String）和节点状态。

复位与时钟控制（Reset and Clock Control，RCC）节点的标签为`rcc`。`STM32_HCLK_FREQUENCY`从该节点的`clock_frequency`属性取得主系统时钟频率。总线名称中的 AHB 指高级高性能总线（Advanced High-performance Bus），APB 指高级外设总线（Advanced Peripheral Bus）；CPU 指中央处理器（Central Processing Unit），Flash 指闪存。

时钟源中 HSI／HSE 分别指高速内部／外部（High-speed Internal／External）时钟，LSI／LSE 分别指低速内部／外部（Low-speed Internal／External）时钟，MSI 指多速内部（Multi-speed Internal）时钟，PLL 指锁相环（Phase-Locked Loop）。其他芯片专用源标识，如`MSIS``MSIK``CSI``HSIS``HSIK``PSIS``PSIK``SHSI`以及`IC1`至`IC20`，按原代码保留；具体适用性由系列和设备树绑定决定，不跨系列推定频率。

以下导读是对本页可见代码的阅读说明。全部宏、分支和声明在后面的代码中完整保留，不能只按导读中的一项回退值构造整套时钟配置。

## 125.2\_分频、源选择与PLL配置

预分频器（Prescaler）宏读取`rcc`的 AHB、APB、CPU 等属性；其中`STM32_AHB5_PRESCALER`对不存在的`ahb5_prescaler`使用1。`STM32_CORE_PRESCALER`优先取`ahb_prescaler`，否则在存在`cpu1_prescaler`时取后者。闪存预分频依次选择`ahb3_prescaler`、`ahb4_prescaler`，否则使用内核预分频。H7RS 系列还具有与其他分支不同的属性命名。

系统时钟源（System Clock Source）宏依据 RCC 所引用的控制器节点判定。原注释要求：为了支持工具宏`IS_ENABLED`，这些符号**不应直接定义为`DT_SAME_NODE`表达式**；源代码采用条件判断后将对应符号定义为1的形式。

STM32N6 的 CPU 时钟选择只在 RCC 兼容字符串及状态匹配、且`cpusw`第0项时钟控制器为 RCC 时，继续按`bus`单元判断时钟源。原条件末注`cpusw clk source is rcc`意为“cpusw 的时钟源是 RCC”；另一末注意为“RCC 节点兼容 st_stm32n6_rcc 且状态为 okay”。

STM32C5 分支分别检查`st_psi_frequency`和`st_psi_source`是否存在；缺失时的144和`HSIDIV18`附有原注释“用于构造宏的占位值（Dummy Value）”。**这不等于宣告对应硬件配置已启用，也不等于所有板的工作频率为144 MHz**。

PLL 参数随节点兼容类型分组处理，包括输入分频（Input Divider）、倍频（Multiplier）、P／Q／R／S／T输出分频、小数值（Fractional Value）及后级分频（Post-divider）。是否存在某输出属性由独立的`*_ENABLED`宏判断；许多分频值缺失时回退到1，小数值缺失时回退到0。F1／F0／F100／F105／L0及N6等分支使用各自参数形式。各 PLL 的时钟源选择还要求相应节点启用并具有`clocks`属性。

## 125.3\_振荡器、编译提示与可见注释

振荡器（Oscillator）配置依次覆盖 LSE、MSI、MSIS、MSIK、CSI、LSI、HSI及其变体、HSE、HSI48、PSI相关源、SHSI以及时钟多路复用器（Clock Multiplexer）。源代码分别保留频率、分频、驱动能力（Driving Capability）、旁路（Bypass）、使能判断等条件定义，并不保证每个系列都定义全部宏。

HSE 部分还涉及温度补偿晶体振荡器（Temperature-Compensated Crystal Oscillator，TCXO）和时钟安全系统（Clock Security System，CSS）。HSI48 分支的`CRS_USB_SOF`涉及时钟恢复系统（Clock Recovery System，CRS）、通用串行总线（Universal Serial Bus，USB）的帧起始（Start of Frame，SOF）信号。

代码中的两条编译错误（Compile-time Error）文字含义分别是：

- `Unsupported STM32 SoC series`：不支持该 STM32 SoC 系列。
- `On STM32L4 series, MSI PLL mode requires LSE to be enabled`：在 STM32L4 系列上，MSI PLL 模式要求启用 LSE。

`Retrieve the main system clock from DTS`意为从设备树源码（Devicetree Source，DTS）取得主系统时钟。其余仅含宏名或条件表达式的`#endif`注释标识相应条件块的结束，原样保留。

## 125.4\_时钟信息结构与辅助宏注释翻译

可见源码中的结构体`stm32_pclken`有三个字段：`bus`与`div`是合计32位的位域（Bit Field），边界由`STM32_CLOCK_DIV_SHIFT`决定；`enr`为`uint32_t`32位无符号整数。初始化宏从时钟说明符（Clock Specifier）的`bus`单元分离低位和高位，并将`bits`单元填入`enr`。不能把未经拆分的整个`bus`单元当作结构体`bus`字段。

| 宏 | 原注释的中文翻译 |
| --- | --- |
| `STM32_CLOCK_INFO(clk_index, node_id)` | 取得设备树节点中指定索引的时钟节点引用（Clock Phandle）所对应的 STM32 时钟信息 |
| `STM32_DT_CLOCKS(node_id)` | 为设备树节点列出的各个时钟生成 STM32 时钟信息数组（Array） |
| `STM32_DT_INST_CLOCKS(inst)` | 为`DT_DRV_COMPAT`驱动兼容实例（Driver-compatible Instance）节点列出的各时钟生成信息数组 |
| `STM32_DT_INST_CLOCK_INFO_BY_IDX(clk_index, inst)` | 取得`DT_DRV_COMPAT`实例节点中指定索引的时钟节点引用所对应的信息 |
| `STM32_DT_INST_CLOCK_INFO(inst)` | 取得`DT_DRV_COMPAT`实例节点中索引0的时钟信息 |
| `STM32_DT_CLOCK_INFO_BY_NAME(node_id, name)` | 取得设备树节点中指定名称的时钟节点引用所对应的信息 |
| `STM32_DT_INST_CLOCK_INFO_BY_NAME(inst, name)` | 取得`DT_DRV_COMPAT`实例节点中指定名称的时钟节点引用所对应的信息 |
| `STM32_DT_INST_DEV_DOMAIN_CLOCK_SUPPORT`及其辅助宏`STM32_DOMAIN_CLOCK_INST_SUPPORT(inst)` | 只有当`DT_DRV_COMPAT`的至少一个启用实例具有至少两个时钟时，才返回真（True） |

最后一组宏检查索引1是否存在；源码中`STM32_DOMAIN_CLOCK_INST_SUPPORT(inst)`尾部的`||`与后续展开配合，整体表达式以0结束，不能将该符号视为误排而删掉。

`STM32_DT_CLKSEL_REG_GET`、`STM32_DT_CLKSEL_SHIFT_GET`、`STM32_DT_CLKSEL_MASK_GET`、`STM32_DT_CLKSEL_VAL_GET`分别提取时钟选择编码中的寄存器（Register）、移位（Shift）、掩码（Mask）和值（Value）信息。掩码宏保留“编码宽度加1”后传给`BIT_MASK`的原表达式。

末尾在`STM32_HSE_CSS`条件下声明`stm32_hse_css_callback(void)`回调函数（Callback）。STM32WB0 系列条件下声明回调类型`lsi_update_cb_t`，其参数为`uint32_t new_lsi_frequency`，以及注册函数`stm32wb0_register_lsi_update_callback(lsi_update_cb_t cb)`。本源码页没有提供调用上下文、参数单位或返回码的完整说明，此处不推定其契约。

        uint32_t bus : STM32_CLOCK_DIV_SHIFT;
        uint32_t div : (32 - STM32_CLOCK_DIV_SHIFT);
        uint32_t enr;
};


/* Get STM32 clock information for an indexed clock phandle in a DT node */
#define STM32_CLOCK_INFO(clk_index, node_id)                                    \
        {                                                                       \
                .bus = DT_CLOCKS_CELL_BY_IDX(node_id, clk_index, bus) &         \
                       GENMASK(STM32_CLOCK_DIV_SHIFT - 1, 0),                   \
                .div = DT_CLOCKS_CELL_BY_IDX(node_id, clk_index, bus) >>        \
                       STM32_CLOCK_DIV_SHIFT,                                   \
                .enr = DT_CLOCKS_CELL_BY_IDX(node_id, clk_index, bits),         \
        }

/* Get an array of STM32 clocks information for clocks listed in a DT node */
#define STM32_DT_CLOCKS(node_id)                                        \
        {                                                               \
                LISTIFY(DT_NUM_CLOCKS(node_id),                         \
                        STM32_CLOCK_INFO, (,), node_id)                 \
        }

/* Get an array of STM32 clocks information for clocks listed in a @c DT_DRV_COMPAT instance node */
#define STM32_DT_INST_CLOCKS(inst)                                      \
        STM32_DT_CLOCKS(DT_DRV_INST(inst))

/* Get STM32 clock information for an indexed clock phandle in a @c DT_DRV_COMPAT instance node */
#define STM32_DT_INST_CLOCK_INFO_BY_IDX(clk_index, inst)                \
        STM32_CLOCK_INFO(clk_index, DT_DRV_INST(inst))

/* Get STM32 clock information for clock index 0 in a @c DT_DRV_COMPAT instance node */
#define STM32_DT_INST_CLOCK_INFO(inst)                                  \
        STM32_DT_INST_CLOCK_INFO_BY_IDX(0, inst)

/* Get STM32 clock information for a named clock phandle in DT node */
#define STM32_DT_CLOCK_INFO_BY_NAME(node_id, name)                              \
        {                                                               \
                .bus = DT_CLOCKS_CELL_BY_NAME(node_id, name, bus) &     \
                       GENMASK(STM32_CLOCK_DIV_SHIFT - 1, 0),           \
                .div = DT_CLOCKS_CELL_BY_NAME(node_id, name, bus) >>    \
                       STM32_CLOCK_DIV_SHIFT,                           \
                .enr = DT_CLOCKS_CELL_BY_NAME(node_id, name, bits),     \
        }

/* Get STM32 clock information for named clock phandle in a @c DT_DRV_COMPAT instance node */
#define STM32_DT_INST_CLOCK_INFO_BY_NAME(inst, name)                    \
        STM32_DT_CLOCK_INFO_BY_NAME(DT_DRV_INST(inst), name)

/* Return true only if at least an enabled instance of the @c DT_DRV_COMPAT has at least 2 clocks */
