# 第62章\_MCP7940N时间寄存器组合

原文：[structmcp7940n__time__registers](https://docs.zephyrproject.org/latest/doxygen/html/structmcp7940n__time__registers.html)。读取日期：2026-10-13，`latest`。

`struct mcp7940n_time_registers`是MCP7940N的时间寄存器组合（Time Registers）结构，定义于`zephyr/drivers/rtc/mcp7940n.h`。RTC指实时时钟（Real-Time Clock）。本页对应原结构参考中的全部字段（Data Fields）。

## 62.2\_完整组合声明

以下定义取自[对应源码](P046_MCP7940N头文件源码.md)，保留`__packed`紧凑布局（Packed Layout）标记。

```c
struct mcp7940n_time_registers {
        struct mcp7940n_rtc_sec rtc_sec;
        struct mcp7940n_rtc_min rtc_min;
        struct mcp7940n_rtc_hours rtc_hours;
        struct mcp7940n_rtc_weekday rtc_weekday;
        struct mcp7940n_rtc_date rtc_date;
        struct mcp7940n_rtc_month rtc_month;
        struct mcp7940n_rtc_year rtc_year;
        struct mcp7940n_rtc_control rtc_control;
        struct mcp7940n_rtc_osctrim rtc_osctrim;
} __packed;
```

寄存器枚举和设置时间函数见[文件参考](P045_MCP7940N寄存器与设置接口.md)。原结构页未增加其他行为说明。
