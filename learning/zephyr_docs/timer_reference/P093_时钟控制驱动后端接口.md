# 第93章\_时钟控制驱动后端接口

原文：[group__clock__control__interface__backend](https://docs.zephyrproject.org/latest/doxygen/html/group__clock__control__interface__backend.html)。读取日期：2026-10-13，`latest`。

本页包含实现时钟控制（Clock Control）驱动所需的应用程序编程接口（Application Programming Interface，API）类型定义、回调签名（Callback Signature）及辅助项。头文件为`zephyr/drivers/clock_control.h`。

驱动操作结构（Driver Operations）见[时钟控制驱动操作结构](P094_时钟控制驱动操作结构.md)。各类型中的子系统和频率是不透明句柄（Opaque Handle），公共类型说明见[时钟控制公共接口](P092_时钟控制公共接口.md)。

## 93.1\_开启或关闭时钟回调

```c
typedef int (*clock_control)(const struct device *dev, clock_control_subsys_t sys);
```

用于开启或关闭时钟的回调接口；参数说明见[时钟控制公共接口](P092_时钟控制公共接口.md)中的`clock_control_on()``clock_control_off()`。

## 93.2\_异步启动时钟回调

```c
typedef int (*clock_control_async_on_fn)(const struct device *dev,
                                         clock_control_subsys_t sys,
                                         clock_control_cb_t cb,
                                         void *user_data);
```

用于异步启动时钟的回调接口；参数说明见[时钟控制公共接口](P092_时钟控制公共接口.md)中的`clock_control_async_on()`。

## 93.3\_配置时钟回调

```c
typedef int (*clock_control_configure_fn)(const struct device *dev,
                                          clock_control_subsys_t sys,
                                          void *data);
```

用于配置时钟的回调接口；参数说明见[时钟控制公共接口](P092_时钟控制公共接口.md)中的`clock_control_configure()`。

## 93.4\_读取时钟频率回调

```c
typedef int (*clock_control_get)(const struct device *dev,
                                 clock_control_subsys_t sys,
                                 uint32_t *rate);
```

用于读取时钟频率的回调接口；参数说明见[时钟控制公共接口](P092_时钟控制公共接口.md)中的`clock_control_get_rate()`。

## 93.5\_读取时钟状态回调

```c
typedef enum clock_control_status (*clock_control_get_status_fn)(
                                                    const struct device *dev,
                                                    clock_control_subsys_t sys);
```

用于读取时钟状态的回调接口；参数说明见[时钟控制公共接口](P092_时钟控制公共接口.md)中的`clock_control_get_status()`。

## 93.6\_设置时钟频率回调

```c
typedef int (*clock_control_set)(const struct device *dev,
                                 clock_control_subsys_t sys,
                                 clock_control_subsys_rate_t rate);
```

用于设置时钟频率的回调接口；参数说明见[时钟控制公共接口](P092_时钟控制公共接口.md)中的`clock_control_set_rate()`。

完整源码见[时钟控制完整头文件](P096_时钟控制完整头文件.md)。
