# 第108章\_设备树时钟头文件参考

原文：[clocks_8h](https://docs.zephyrproject.org/latest/doxygen/html/clocks_8h.html)。读取日期：2026-10-13，`latest`。

本页对应`zephyr/devicetree/clocks.h`，即设备树时钟宏（Clocks Devicetree Macro）的公共应用程序编程接口（Application Programming Interface，API）头文件。

节点标识（Node Identifier）、逻辑索引（Logical Index）、时钟说明符（Clock Specifier）单元（Cell）及驱动实例（Driver Instance）的参数约定见[设备树时钟获取宏](P107_设备树时钟获取宏.md)。`clocks`是时钟控制器 phandle 引用数组，`clock-names`提供元素名称。`DT_DRV_COMPAT`标识驱动兼容字符串，`DT_DRV_INST`取得相应实例的节点标识。

## 108.1\_节点形式的宏


```c
#define DT_CLOCKS_HAS_IDX(node_id, idx)
```

检查节点`clocks`phandle 数组属性的指定索引是否有效。有效时展开为1，否则展开为0。


```c
#define DT_CLOCKS_HAS_NAME(node_id, name)
```

检查节点的`clock-names`数组属性是否含有给定名称。作为数组单元值存在时展开为1，否则展开为0。


```c
#define DT_NUM_CLOCKS(node_id)
```

取得`clocks`属性的元素数量。


```c
#define DT_CLOCKS_CTLR_BY_IDX(node_id, idx)
```

从`clocks`phandle 数组属性的指定索引处，取得控制器 phandle 对应的节点标识。


```c
#define DT_CLOCKS_CTLR(node_id)
```

等价于`DT_CLOCKS_CTLR_BY_IDX(node_id, 0)`。


```c
#define DT_CLOCKS_CTLR_BY_NAME(node_id, name)
```

从`clocks`phandle 数组属性中，按名称取得控制器 phandle 对应的节点标识。


```c
#define DT_CLOCKS_CELL_BY_IDX(node_id, idx, cell)
```

取得指定索引处的时钟说明符单元值。


```c
#define DT_CLOCKS_CELL_BY_NAME(node_id, name, cell)
```

按名称取得时钟说明符中的单元值。


```c
#define DT_CLOCKS_CELL(node_id, cell)
```

等价于`DT_CLOCKS_CELL_BY_IDX(node_id, 0, cell)`。

## 108.2\_驱动实例形式的宏


```c
#define DT_INST_CLOCKS_HAS_IDX(inst, idx)
```

等价于`DT_CLOCKS_HAS_IDX(DT_DRV_INST(inst), idx)`。


```c
#define DT_INST_CLOCKS_HAS_NAME(inst, name)
```

等价于`DT_CLOCKS_HAS_NAME(DT_DRV_INST(inst), name)`。


```c
#define DT_INST_NUM_CLOCKS(inst)
```

等价于`DT_NUM_CLOCKS(DT_DRV_INST(inst))`。


```c
#define DT_INST_CLOCKS_CTLR_BY_IDX(inst, idx)
```

从实例的`clocks`phandle 数组属性的指定索引处，取得控制器 phandle 对应的节点标识。


```c
#define DT_INST_CLOCKS_CTLR(inst)
```

等价于`DT_INST_CLOCKS_CTLR_BY_IDX(inst, 0)`。


```c
#define DT_INST_CLOCKS_CTLR_BY_NAME(inst, name)
```

从实例的`clocks`phandle 数组属性中，按名称取得控制器 phandle 对应的节点标识。


```c
#define DT_INST_CLOCKS_CELL_BY_IDX(inst, idx, cell)
```

取得`DT_DRV_COMPAT`实例的指定索引处时钟说明符单元值。


```c
#define DT_INST_CLOCKS_CELL_BY_NAME(inst, name, cell)
```

按名称取得`DT_DRV_COMPAT`实例的时钟说明符单元值。


```c
#define DT_INST_CLOCKS_CELL(inst, cell)
```

等价于`DT_INST_CLOCKS_CELL_BY_IDX(inst, 0, cell)`。

所有参数、展开结果和原始示例见[设备树时钟获取宏](P107_设备树时钟获取宏.md)；完整源码见[设备树时钟完整头文件](P109_设备树时钟完整头文件.md)。
