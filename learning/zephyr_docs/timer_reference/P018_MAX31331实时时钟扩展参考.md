# 第18章\_MAX31331实时时钟扩展参考

原文：[rtc__max31331_8h](https://docs.zephyrproject.org/latest/doxygen/html/rtc__max31331_8h.html)。读取日期：2026-10-13，`latest`。

`zephyr/drivers/rtc/rtc_max31331.h`提供MAX31331实时时钟（Real-Time Clock，RTC）驱动专用的应用程序接口（Application Programming Interface，API），用于读取时间戳（Timestamp）并注册时间戳事件通知。包含：

```c
#include <zephyr/device.h>
#include <zephyr/drivers/rtc.h>
#include <zephyr/drivers/gpio.h>
#include <stdint.h>
```

## 18.1\_时间戳回调类型

`rtc_max31331_timestamp_callback`是MAX31331时间戳回调（Callback）类型：

```c
typedef void (*rtc_max31331_timestamp_callback)(const struct device *dev, void *user_data);
```

`dev`指向RTC设备，`user_data`指向用户上下文（User Context）。

## 18.2\_读取已存储的时间戳

`rtc_max31331_get_timestamps`从MAX31331读取一个已保存的时间戳：

```c
int rtc_max31331_get_timestamps(const struct device *dev, struct rtc_time *timeptr, uint8_t index,
                                uint8_t *flags);
```

| 参数 | 含义 |
| --- | --- |
| `dev` | RTC设备指针。 |
| `timeptr` | 指向`struct rtc_time`，用于保存读取结果。 |
| `index` | 时间戳索引（Index），范围为0至3。 |
| `flags` | 指向接收时间戳标志（Timestamp Flags）的变量。 |

成功返回0，否则返回负错误码（Negative errno）。原页没有列出标志位定义，本页保留输出类型，不为这些位补造含义。

## 18.3\_注册时间戳事件回调

`rtc_max31331_set_timestamp_callback`注册时间戳事件回调：

```c
int rtc_max31331_set_timestamp_callback(const struct device *dev,
                                        rtc_max31331_timestamp_callback cb, void *user_data);
```

`dev`指向RTC设备，`cb`为回调函数指针，`user_data`为应用提供的上下文。成功返回0，否则返回负错误码。原页未说明空回调的禁用语义，不能直接套用公共闹钟接口的规则。

时间字段见[RTC时间结构](P011_实时时钟时间结构.md)，完整声明见[源码页](P019_MAX31331实时时钟扩展源码.md)。
