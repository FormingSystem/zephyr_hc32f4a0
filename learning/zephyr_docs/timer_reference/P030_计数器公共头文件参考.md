# 第30章\_计数器公共头文件参考

原文：[drivers_2counter_8h](https://docs.zephyrproject.org/latest/doxygen/html/drivers_2counter_8h.html)。读取日期：2026-10-13，`latest`。

`zephyr/drivers/counter.h`是计数器（Counter）驱动应用程序接口（Application Programming Interface，API）的主头文件。包含：

```c
#include <errno.h>
#include <zephyr/types.h>
#include <stddef.h>
#include <zephyr/device.h>
#include <zephyr/devicetree.h>
#include <zephyr/devicetree/counter-capture.h>
#include <zephyr/sys/clock.h>
#include <stdbool.h>
#include <zephyr/dt-bindings/counter/counter-capture.h>
#include <zephyr/syscalls/counter.h>
```

## 30.1\_数据结构

原页包含七种结构：设备树（Devicetree）捕获规格`counter_capture_dt_spec`、[32位告警配置](P024_计数器32位告警配置.md)`counter_alarm_cfg`、[64位告警配置](P025_计数器64位告警配置.md)`counter_alarm_cfg_64`、[32位顶值配置](P026_计数器32位顶值配置.md)`counter_top_cfg`、[64位顶值配置](P027_计数器64位顶值配置.md)`counter_top_cfg_64`、[通用能力配置](P028_计数器只读配置信息.md)`counter_config_info`及[驱动操作](P029_计数器驱动操作结构.md)`counter_driver_api`。捕获规格的字段详见[官方结构页](P033_计数器捕获设备树规格.md)。

## 30.2\_标志与捕获规格构造宏

下列八个宏控制能力、顶值、告警、保护周期和捕获行为。
| 宏 | 原值 | 含义 |
| --- | --- | --- |
| `COUNTER_CONFIG_INFO_COUNT_UP` | `BIT(0)` | 向上计数（Count Up）能力标志。 |
| `COUNTER_TOP_CFG_DONT_RESET` | `BIT(0)` | 更新顶值时禁止复位（Do Not Reset），让计数器继续自由运行。 |
| `COUNTER_TOP_CFG_RESET_WHEN_LATE` | `BIT(1)` | 改变顶值后越过新边界时，要求计数器复位。 |
| `COUNTER_ALARM_CFG_ABSOLUTE` | `BIT(0)` | 告警刻度为绝对值（Absolute Value）；未设时相对调用期间读取的计数值。 |
| `COUNTER_ALARM_CFG_EXPIRE_WHEN_LATE` | `BIT(1)` | 驱动发现绝对告警设置过晚时立即到期（Expire When Late），回调上下文必须与准时设置时相同。 |
| `COUNTER_GUARD_PERIOD_LATE_TO_SET` | `BIT(0)` | 标识用于检测绝对告警设置过晚的保护周期。 |
| `COUNTER_CAPTURE_CONTINUOUS` | `0` | 连续捕获（Continuous Capture），直到停止。 |
| `COUNTER_CAPTURE_SINGLE_SHOT` | `BIT(2)` | 单次捕获（Single-Shot Capture）。 |

十二个设备树捕获规格宏的参数形式如下；BY_NAME按名称选择，BY_IDX按索引选择，INST使用`DT_DRV_COMPAT`实例，OR在节点或属性不存在时提供回退值（Fallback Value）。

```c
#define COUNTER_CAPTURE_DT_SPEC_GET_BY_NAME(node_id, prop, name)
#define COUNTER_CAPTURE_DT_SPEC_INST_GET_BY_NAME(inst, prop, name)
#define COUNTER_CAPTURE_DT_SPEC_GET_BY_NAME_OR(node_id, prop, name, default_value)
#define COUNTER_CAPTURE_DT_SPEC_INST_GET_BY_NAME_OR(inst, prop, name, default_value)
#define COUNTER_CAPTURE_DT_SPEC_GET_BY_IDX(node_id, prop, idx)
#define COUNTER_CAPTURE_DT_SPEC_INST_GET_BY_IDX(inst, prop, idx)
#define COUNTER_CAPTURE_DT_SPEC_GET_BY_IDX_OR(node_id, prop, idx, default_value)
#define COUNTER_CAPTURE_DT_SPEC_INST_GET_BY_IDX_OR(inst, prop, idx, default_value)
#define COUNTER_CAPTURE_DT_SPEC_GET(node_id, prop)
#define COUNTER_CAPTURE_DT_SPEC_INST_GET(inst, prop)
#define COUNTER_CAPTURE_DT_SPEC_GET_OR(node_id, prop, default_value)
#define COUNTER_CAPTURE_DT_SPEC_INST_GET_OR(inst, prop, default_value)
```

不带BY_NAME或BY_IDX的四个入口选择索引0。原参考页的“等价于”简介省略了`prop`参数；实际展开式仍传递`prop`，完整公式、原始示例与译注见[公共接口](P022_计数器公共接口.md)。

## 30.3\_应用回调与捕获标志类型

告警回调（Alarm Callback）接收设备、通道、触发计数值和用户数据；顶值回调（Top Callback）在回绕（Turnaround）时接收设备与用户数据；捕获回调（Capture Callback）还接收捕获标志。32位与64位刻度回调分别保留。捕获标志类型为32位无符号值，低8位用于标准标志，高24位保留给片上系统（System on Chip，SoC）专用标志。

```c
typedef uint32_t counter_capture_flags_t;
typedef void (*counter_capture_cb_t)(const struct device *dev, uint8_t chan_id,
                                     counter_capture_flags_t flags, uint32_t ticks,
                                     void *user_data);
typedef void (*counter_alarm_callback_t)(const struct device *dev, uint8_t chan_id, uint32_t ticks,
                                         void *user_data);
typedef void (*counter_top_callback_t)(const struct device *dev, void *user_data);
typedef void (*counter_alarm_callback_64_t)(const struct device *dev, uint8_t chan_id,
                                            uint64_t ticks, void *user_data);
typedef void (*counter_capture_cb_64_t)(const struct device *dev, uint8_t chan_id,
                                        counter_capture_flags_t flags, uint64_t ticks,
                                        void *user_data);
```

## 30.5\_公共操作与捕获辅助函数

完整签名如下。前部覆盖方向、通道、频率、单位换算、运行控制、读写计数、告警、顶值与保护周期；随后是对应64位操作、捕获及校准。单位为计数刻度（Tick）、微秒（Microsecond）、纳秒（Nanosecond）、赫兹（Hertz）或十亿分率（Parts Per Billion），具体以各参数说明为准。

捕获配置函数注册通道回调；其`_dt`版本从设备树规格取得设备、通道和标志。64位捕获配置接收64位刻度回调。启用和禁用捕获也分别提供设备／通道参数形式与设备树规格形式，详细约束见[官方捕获接口](P032_计数器捕获接口.md)。

公共函数的参数、错误返回、线程安全和64位回退差异见[公共接口](P022_计数器公共接口.md)。原参考页把六个捕获内联辅助函数显示为`static`；上面的签名仅列返回类型和参数，内联与系统调用包装完整保存在[源码页](P031_计数器公共头文件源码.md)。
