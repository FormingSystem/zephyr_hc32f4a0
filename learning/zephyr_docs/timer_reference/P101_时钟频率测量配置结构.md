# 第101章\_时钟频率测量配置结构

原文：[structclock__monitor__measure__cfg](https://docs.zephyrproject.org/latest/doxygen/html/structclock__monitor__measure__cfg.html)。读取日期：2026-10-13，`latest`。

结构体`clock_monitor_measure_cfg`配置`CLOCK_MONITOR_MODE_MEASURE`测量模式（Measurement Mode），头文件为`zephyr/drivers/clock_monitor.h`。

## 101.1\_结构声明

```c
struct clock_monitor_measure_cfg {
        uint32_t window_ns;
};
```

## 101.2\_测量时间窗口

唯一成员`uint32_t window_ns`表示测量窗口持续时间（Measurement Window Duration），单位为纳秒（Nanosecond，ns），**必须大于0**。

顶层配置见[时钟监控配置结构](P100_时钟监控配置结构.md)，单次测量和重复启动的行为见[时钟监控公共接口](P098_时钟监控公共接口.md)，完整源码见[时钟监控完整头文件](P106_时钟监控完整头文件.md)。
