# 第37章\_计数器捕获边沿常量参考

原文：[dt-bindings_2counter_2counter-capture_8h](https://docs.zephyrproject.org/latest/doxygen/html/dt-bindings_2counter_2counter-capture_8h.html)。读取日期：2026-10-13，`latest`。

`zephyr/dt-bindings/counter/counter-capture.h`定义计数器捕获（Counter Capture）供设备树（Devicetree）使用的边沿选择（Edge Selection）标志。它们与`counter_capture_configure`配合使用，位于`counter_capture_flags_t`的低8位。

## 37.1\_三个边沿标志

| 宏 | 原值 | 含义 |
| --- | --- | --- |
| `COUNTER_CAPTURE_RISING_EDGE` | `(1U << 0)` | 捕获上升沿（Rising Edge）。 |
| `COUNTER_CAPTURE_FALLING_EDGE` | `(1U << 1)` | 捕获下降沿（Falling Edge）。 |
| `COUNTER_CAPTURE_BOTH_EDGES` | `(COUNTER_CAPTURE_RISING_EDGE \| COUNTER_CAPTURE_FALLING_EDGE)` | 同时捕获两个边沿（Both Edges）。 |

## 37.2\_对应接口和源码

配置函数见[计数器捕获接口](P032_计数器捕获接口.md)。本文件没有额外包含项或函数，完整宏定义与版权许可见[边沿常量源码](P038_计数器捕获边沿常量源码.md)。
