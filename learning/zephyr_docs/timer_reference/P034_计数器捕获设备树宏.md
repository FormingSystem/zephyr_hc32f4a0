# 第34章\_计数器捕获设备树宏

原文：[group__devicetree-counter-captures](https://docs.zephyrproject.org/latest/doxygen/html/group__devicetree-counter-captures.html)。读取日期：2026-10-13，`latest`。

本页为计数器捕获（Counter Capture）设备树（Devicetree，DT）公共宏接口，头文件是`zephyr/devicetree/counter-capture.h`。捕获说明符（Capture Specifier）通过句柄数组（Phandle Array）引用计数器控制器（Counter Controller），其单元（Cell）含义由绑定（Binding）规定。

本页逐项保留24个宏及38段原展开式和示例。宏参数仍使用原标识；原文部分实例宏参数表省略`counter_capture_pha`，下文按实际签名补列其属性名含义。

原例中的`COUNTER_CAPTURE_RISING_EDGE`宏表示上升沿（Rising Edge），`COUNTER_CAPTURE_BOTH_EDGES`宏表示双边沿（Both Edges）；`DT_NODELABEL`宏由节点标签（Node Label）取得节点标识。展开式中的`DT_PHA_BY_IDX`／`DT_PHA_BY_NAME`宏按索引／名称读取句柄数组单元，带`_OR`后缀的形式提供默认值；`DT_PHANDLE_BY_IDX`／`DT_PHANDLE_BY_NAME`宏取得所引用节点的标识。

## 34.1\_DT_COUNTER_CAPTURES_CELL

从指定节点的捕获属性中取得索引0处的首项的`cell`指定的单元值。

```c
#define DT_COUNTER_CAPTURES_CELL(node_id, counter_capture_pha, cell)
```

| 参数 | 含义 |
| --- | --- |
| `node_id` | 节点标识符（Node Identifier）。 |
| `counter_capture_pha` | 类型为`phandle-array`的捕获属性名，采用小写字母与下划线形式；例如属性`counter-captures`传入为`counter_captures`。 |
| `cell` | 单元名称（Cell Name），采用小写字母与下划线形式。 |

返回`cell`指定的单元值，选择位置为索引0处的首项。

展开值：

```c
DT_COUNTER_CAPTURES_CELL_BY_IDX(node_id, counter_capture_pha, 0, cell)
```

相关宏：`DT_COUNTER_CAPTURES_CELL_BY_IDX`。

## 34.2\_DT_COUNTER_CAPTURES_CELL_BY_IDX

从指定节点的捕获属性中取得索引`idx`处的元素的`cell`指定的单元值。

```c
#define DT_COUNTER_CAPTURES_CELL_BY_IDX(node_id, counter_capture_pha, idx, cell)
```

| 参数 | 含义 |
| --- | --- |
| `node_id` | 节点标识符（Node Identifier）。 |
| `counter_capture_pha` | 类型为`phandle-array`的捕获属性名，采用小写字母与下划线形式；例如属性`counter-captures`传入为`counter_captures`。 |
| `idx` | 捕获属性内的逻辑索引（Logical Index）。 |
| `cell` | 单元名称（Cell Name），采用小写字母与下划线形式。 |

返回`cell`指定的单元值，选择位置为索引`idx`处的元素。

展开值：

```c
DT_PHA_BY_IDX(node_id, counter_capture_pha, idx, cell)
```

原设备树片段：

```dts
counter1: counter-controller@... {
        compatible = "vnd,counter-capture";
        #counter-capture-cells = <2>;
};

counter2: counter-controller@... {
        compatible = "vnd,counter-capture";
        #counter-capture-cells = <2>;
};

n: node {
        counter-captures = <&counter1 1 COUNTER_CAPTURE_RISING_EDGE>,
                           <&counter2 3 COUNTER_CAPTURE_BOTH_EDGES>;
};
```

`vnd,counter-capture`绑定片段：

```yaml
counter-capture-cells:
  - channel
  - flags
```

原用法及展开结果：

```c
DT_COUNTER_CAPTURES_CELL_BY_IDX(DT_NODELABEL(n), counter_captures, 0, channel) // 1
DT_COUNTER_CAPTURES_CELL_BY_IDX(DT_NODELABEL(n), counter_captures, 1, channel) // 3
DT_COUNTER_CAPTURES_CELL_BY_IDX(DT_NODELABEL(n), counter_captures, 0, flags)
    // COUNTER_CAPTURE_RISING_EDGE
DT_COUNTER_CAPTURES_CELL_BY_IDX(DT_NODELABEL(n), counter_captures, 1, flags)
    // COUNTER_CAPTURE_BOTH_EDGES
```

相关宏：`DT_PHA_BY_IDX`。

## 34.25\_实例标志宏的原文差异

原文对`DT_INST_COUNTER_CAPTURES_FLAGS`、`DT_INST_COUNTER_CAPTURES_FLAGS_BY_IDX``DT_INST_COUNTER_CAPTURES_FLAGS_BY_NAME`均写有“缺少标志单元时为0”的返回说明，但其可见源码分别经索引0包装、实例`CELL_BY_IDX`或`CELL_BY_NAME`宏，最终调用不带默认值的`DT_PHA_BY_IDX`或`DT_PHA_BY_NAME`。

因此，这三个实例宏在缺失`flags`单元时的行为，不能仅凭返回值文字保证为0。此处保留原返回说明与原展开式并明确指出不一致；未擅自修改实现。普通节点的两个`FLAGS_BY_*`宏则确实使用`*_OR(..., flags, 0)`。完整原代码见[设备树捕获头文件源码](P036_计数器捕获设备树头文件源码.md)。
