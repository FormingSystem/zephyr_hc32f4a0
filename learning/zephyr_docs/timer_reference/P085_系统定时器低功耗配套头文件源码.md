## 85.2\_源码注释与阅读说明

源码包含三个内部函数声明：`z_sys_clock_lpm_init(void)`返回`void`；`z_sys_clock_lpm_enter(uint64_t max_lpm_time_us)`返回`void`；`z_sys_clock_lpm_exit(void)`返回`uint64_t`。

保留64位参数`max_lpm_time_us`的名称与类型，以及退出函数的返回类型。原源码浏览页没有额外说明这些值的契约或函数实现。低功耗计时（Low-power Timekeeping）的接口用途见前一章；C++条件包装、包含项、原版权与许可完整保留。
