# 第68章\_nRF53同步实时时钟示例

原文：[Synchronized RTC](https://docs.zephyrproject.org/latest/samples/boards/nordic/nrf53_sync_rtc/README.html)。读取日期：2026-10-13，`latest`。

本例演示应用核（Application Core）与网络核（Network Core）上用于系统时钟（System Clock）的RTC时钟如何同步（Synchronization）。实时时钟（Real-Time Clock，RTC）同步的结果，是网络核上的一个偏移量（Offset）；该偏移量可以应用到系统计数刻度（System Tick），用于日志时间戳（Logging Timestamp）。[示例源码](https://github.com/zephyrproject-rtos/zephyr/tree/main/samples/boards/nordic/nrf53_sync_rtc)位于`samples/boards/nordic/nrf53_sync_rtc`。

## 68.1\_双核事件与偏移量

示例使用处理器间邮箱（Inter-Processor Mailbox，IPM）驱动和处理器间通信（Inter-Processor Communication，IPC）硬件抽象层（Hardware Abstraction Layer，HAL），产生同时发生在两个核上的事件。

应用核周期性读取当前系统tick，将其存入共享内存（Shared Memory），并触发IPC任务（IPC Task）。该任务在网络核上引起中断。在IPC中断处理程序（Interrupt Handler）中，网络核记录共享内存里的时间戳，以及加上偏移量后的本地系统tick。

在同步过程完成之前，两组时间戳存在明显差异；完成之后，时间戳开始同步。由于中断处理的延迟（Latency），网络核时间戳可能稍晚，通常相差1个tick。为了保持简单和较低延迟，本示例没有采用更复杂的IPM协议。IPM驱动说明见[处理器间消息](../hardware/P068_处理器间消息.md)。

## 68.2\_为nrf5340dk应用核构建

针对`nrf5340dk/nrf5340/cpuapp`，在Zephyr仓库根目录执行：

```sh
# From the root of the zephyr repository
west build -b nrf5340dk/nrf5340/cpuapp --sysbuild samples/boards/nordic/nrf53_sync_rtc
west flash --hex-file build/nrf53_sync_rtc/zephyr/zephyr.hex
```

打开串口终端（Serial Terminal），例如Minicom或PuTTY，以如下设置连接开发板：

| 设置 | 值 |
| --- | --- |
| 速率（Speed） | 115200。 |
| 数据位（Data Bits） | 8位。 |
| 校验（Parity） | 无（None）。 |
| 停止位（Stop Bits） | 1位。 |

```text
[00:00:00.607,025] <inf> main: Local timestamp: 19891, application core timestamp: 19890

```

主端的`IPC send at ... ticks`表示发送IPC时的tick计数；远端的`Local timestamp`和`application core timestamp`分别为本地时间戳与应用核时间戳。`Updated timestamp to synchronized RTC by 8270 ticks (252380us)`表示将时间戳调整8270个tick，即252380微秒，以同步RTC。

最初，两核对应事件的日志时间戳不一致，网络核报告的本地／远端时间戳也不一致；RTC同步完成后开始匹配。原例中远端本地计数18252对应应用核18251，反映前述约1个tick的处理延迟。

> 译注：原文示例日志含`v2.7.0-rc1-89-ge755863d66c9`启动标识。本页保留该原始输出，不将它当作当前`latest`文档的构建版本，也不是本项目实测日志。

## 68.4\_为模拟的nrf5340bsim构建

在Zephyr仓库根目录执行：

```sh
# From the root of the zephyr repository
west build -b nrf5340bsim/nrf5340/cpuapp --sysbuild samples/boards/nordic/nrf53_sync_rtc
```

然后运行应用：

```sh
$ ./build/zephyr/zephyr.exe -nosim
# Press Ctrl+C to exit
```

原注释“Press Ctrl+C to exit”表示按`Ctrl+C`退出。调用命令的控制台中应显示与真实硬件（Hardware，HW）类似的输出。
