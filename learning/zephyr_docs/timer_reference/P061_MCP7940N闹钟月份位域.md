# 第61章\_MCP7940N闹钟月份位域

原文：[structmcp7940n__alm__month](https://docs.zephyrproject.org/latest/doxygen/html/structmcp7940n__alm__month.html)。读取日期：2026-10-13，`latest`。

`struct mcp7940n_alm_month`是MCP7940N的闹钟月份（Alarm Month）结构，定义于`zephyr/drivers/rtc/mcp7940n.h`。RTC指实时时钟（Real-Time Clock）。本页对应原结构参考中的全部字段（Data Fields）。

## 61.1\_字段声明

字段类型均为`uint8_t`，冒号后的数值为位域（Bit Field）宽度，单位是位（Bit）。原结构页没有逐字段的行为说明，下表保留名称、类型与宽度。

| 类型 | 字段 | 位宽 |
| --- | --- | --- |
| `uint8_t` | `month_one` | 4位。 |
| `uint8_t` | `month_ten` | 1位。 |
| `uint8_t` | `nimp` | 3位。 |

## 61.2\_完整结构声明

以下声明取自[同一官方头文件源码](P046_MCP7940N头文件源码.md)，包括原`__packed`紧凑布局（Packed Layout）标记。

```c
struct mcp7940n_alm_month {
        uint8_t month_one : 4;
        uint8_t month_ten : 1;
        uint8_t nimp : 3;
} __packed;
```

该结构的组合容器见[闹钟寄存器组合（Alarm Registers）](P063_MCP7940N闹钟寄存器组合.md)；设置UNIX时间（Unix Time）的接口见[文件参考](P045_MCP7940N寄存器与设置接口.md)。
