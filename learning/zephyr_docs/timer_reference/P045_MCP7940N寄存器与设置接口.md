# 第45章\_MCP7940N寄存器与设置接口

原文：[mcp7940n_8h](https://docs.zephyrproject.org/latest/doxygen/html/mcp7940n_8h.html)。读取日期：2026-10-13，`latest`。

`zephyr/drivers/rtc/mcp7940n.h`定义基于MCP7940N实时时钟（Real-Time Clock，RTC）的计数器（Counter）驱动寄存器布局（Register Layout）和应用程序接口（Application Programming Interface，API）。该文件包含：

```c
#include <zephyr/sys/timeutil.h>
#include <time.h>
```

| `REG_ALM1_WDAY` | `0x14` |
| `REG_ALM1_DATE` | `0x15` |
| `REG_ALM1_MONTH` | `0x16` |
| `REG_PWR_DWN_MIN` | `0x18` |

| `REG_PWR_UP_DATE` | `0x1E` |

| `SRAM_MIN` | `0x20` |
| `SRAM_MAX` | `0x5F` |

`REG_RTC_*`对应RTC寄存器，`REG_ALM0_*`与`REG_ALM1_*`分别对应闹钟（Alarm）0与1；`REG_PWR_DWN_*`与`REG_PWR_UP_*`分别为掉电（Power-down）和上电（Power-up）相关寄存器名称。`SRAM_MIN`、`SRAM_MAX`为静态随机存取存储器（Static Random-Access Memory，SRAM）区域的边界名称。原文件参考未给出这些成员的进一步文字解释。

## 45.3\_闹钟触发枚举

`enum mcp7940n_alarm_trigger`列出下列闹钟触发（Alarm Trigger）选择：

| 枚举成员 | 原值 | 对应名称 |
| --- | --- | --- |
| `MCP7940N_ALARM_TRIGGER_SECONDS` | `0x0` | 秒（Seconds）。 |
| `MCP7940N_ALARM_TRIGGER_MINUTES` | `0x1` | 分（Minutes）。 |
| `MCP7940N_ALARM_TRIGGER_HOURS` | `0x2` | 小时（Hours）。 |
| `MCP7940N_ALARM_TRIGGER_WDAY` | `0x3` | 星期（Weekday）。 |
| `MCP7940N_ALARM_TRIGGER_DATE` | `0x4` | 日期（Date）。 |
| `MCP7940N_ALARM_TRIGGER_ALL` | `0x7` | 全部（All）。 |

源码注释说明这些选择**互斥（Mutually Exclusive）**；`MCP7940N_ALARM_TRIGGER_ALL`匹配秒、分、小时、星期、日期和月份。这两条说明来自[原源码注释](P046_MCP7940N头文件源码.md)，不是由枚举名补造的行为。

## 45.4\_设置UNIX时间

`mcp7940n_rtc_set_time`把RTC设置为给定的UNIX时间（Unix Time）：

```c
int mcp7940n_rtc_set_time(const struct device *dev, time_t unix_time);
```

RTC每秒前进一个计数刻度（Tick），不能访问亚秒精度（Sub-second Precision）。该函数将`unix_time`转换为秒、分、小时、星期、月内日期、月份和年份。

UNIX时间0表示协调世界时（Coordinated Universal Time，UTC）**1970年1月1日，星期四，00:00:00**。

| 参数 | 含义 |
| --- | --- |
| `dev` | MCP7940N设备指针。 |
| `unix_time` | 要设置的UNIX时间，类型为`time_t`。 |

成功返回0；失败返回由集成电路互连总线（Inter-Integrated Circuit，I²C）事务或无效参数产生的负错误码（Negative Error Code）。原文没有将这些失败进一步限定为某几个具体错误常量。
