# 第126章\_STM32复位与时钟控制绑定

<a id="dtbinding-st-stm32-rcc"></a>

原文：[st,stm32-rcc](https://docs.zephyrproject.org/latest/build/dts/api/bindings/clock/st,stm32-rcc.html)。读取日期：2026-10-13，`latest`。

`st,stm32-rcc`是 STMicroelectronics 的设备树绑定（Devicetree Binding）。

采用此兼容字符串的开发板见[官方筛选目录](https://docs.zephyrproject.org/latest/boards/index.html#compatibles=st,stm32-rcc)。

RCC 指复位与时钟控制器（Reset and Clock Controller），负责系统时钟（System Clock，SYSCLK）源及总线域（Bus Domain）的时钟控制。AHB 为高级高性能总线（Advanced High-performance Bus），APB 为高级外设总线（Advanced Peripheral Bus）；预分频器称为 Prescaler。

## 126.1\_配置系统和总线时钟

系统时钟源应从`clocks`节点中可用的时钟节点选择，例如`clk_hse`、`clk_hsi`或`pll`。HSE 是高速外部（High-speed External）时钟，HSI 是高速内部（High-speed Internal）时钟，PLL 是锁相环（Phase-Locked Loop）。还应通过`clock-frequency`定义内核时钟频率（Core Clock Frequency），其关系为：

`内核时钟频率 = SYSCLK / AHB预分频系数`。

最后用相应预分频属性配置外设总线时钟（Peripheral Bus Clock），通常为`PCLK1`和`PCLK2`。下面的`DT_FREQ_M`是以MHz表示频率的宏，官方 RCC 示例：

```dts
&rcc {
         clocks = <&pll>;  /* Select 80MHz pll as SYSCLK source */
         ahb-prescaler = <2>;
         clock-frequency = <DT_FREQ_M(40)>; /* = SYSCLK / AHB prescaler */
         apb1-prescaler = <1>;
         apb2-prescaler = <1>;
}
```

原注释说明选用80 MHz的 PLL 作为 SYSCLK，经 AHB 二分频得到40 MHz内核时钟；`DT_FREQ_M(40)`表示40 MHz。译注：本段及后续示意片段按原样保留，包括原文未写的结尾分号；使用时须将片段放入完整且语法有效的设备树源码，含`...`的片段不能直接构建。

## 126.2\_指定门控时钟

门控时钟（Gated Clock）通过外设节点的`clocks`属性指定；原例的`STM32_CLOCK`是时钟说明符宏，`APB2`为APB总线域2：

```dts
... {
         ...
         clocks = <&rcc STM32_CLOCK(APB2, 5)>;
         ...
}
```

在指向`rcc`的节点引用（Phandle）后使用`STM32_CLOCK()`宏。第一个参数指定外设所连总线，第二个参数是 RCC 中该总线控制寄存器的时钟门控位编号（Gate Bit Number）。原例选择`RCC_APB2ENR`的第5位，即 STM32F401 上的`USART6EN`位；USART 指通用同步异步收发器（Universal Synchronous/Asynchronous Receiver/Transmitter）。

访问外设控制器时需要门控时钟，通常用于设备配置。若不使用双时钟域（Dual Clock Domain），它也用于外设运行。

需要多个门控位时，使用显式写法；`STM32_CLOCK_BUS_APB2`为APB2总线标识宏：

```dts
... {
         ...
         clocks = <&rcc STM32_CLOCK_BUS_APB2 ((1 << 14) | (1 << 7))>;
         ...
}
```

第14位和第7位控制门控；位数可以多于两个，也不要求连续。

## 126.3\_指定独立时钟域源

可在`clocks`属性中增加一个时钟说明符（Clock Specifier）。原例使用HSI源标识宏`STM32_SRC_HSI`和I2C1源选择宏`I2C1_SEL`：

```dts
... {
         ...
         clocks = <&rcc STM32_CLOCK(APB2, 5)>,
                      <&rcc STM32_SRC_HSI I2C1_SEL(2)>;
         ...
}
```

原例将`I2C1`的时钟域源指定为 HSI；I²C 是集成电路间总线（Inter-Integrated Circuit）。时钟域时钟（Domain Clock）独立于总线／门控时钟。原文称它“允许在门控时钟关闭时访问设备寄存器”，随后又说明：它不向外设控制器供时钟，因此允许外设运行，但不能用于外设配置。

译注：上述“可访问设备寄存器”与后一句的限制存在表述张力，这里如实保留。不要据此前半句推定所有寄存器在总线时钟关闭后均可访问；实际访问要求应以对应芯片参考手册和驱动为准。外设驱动负责按`clock_control`时钟控制应用程序编程接口（Clock Control API）的规定查询、使用时钟源信息。

外设子系统的速率由运行时钟决定，调用`clock_control_get_rate()`时必须使用同一时钟。

若没有额外说明符，门控时钟同时就是时钟源，即随设备而定的`PCLK``PCLK1`或`PCLK2`；无须额外增加第二项来显式设置。默认外设时钟配置应符合 SoC 的复位状态（Reset State），各外设时钟源的复位值应查参考手册（Reference Manual）。原文将提供默认配置的文件写为`*.dsti`；译注：Zephyr 设备树包含文件通常使用`*.dtsi`，此处指出原文拼写差异。

## 126.4\_指定分频后的时钟域源

某些外设经固定时钟分频器（Fixed Clock Divider）供时钟，可用分频编码宏`STM32_CLOCK_DIV()`指定分频值，源标识宏`STM32_SRC_HSE`表示HSE。选择 HSE/2，即 HSE 频率除以2的原例：

```dts
... {
         ...
         clocks = <&rcc (STM32_SRC_HSE | STM32_CLOCK_DIV(2)) ...>;
         ...
}
```

## 126.5\_节点专用属性

属性类型：`int`为整数，`boolean`为布尔属性，`string`为字符串，`string-array`为字符串数组，`array`为数值数组，`compound`为复合类型；`phandle`为节点引用（Phandle），`phandles`为节点引用列表，`phandle-array`为节点引用与说明符单元数组。

CPU 指中央处理器（Central Processing Unit），DMA 指直接存储器访问（Direct Memory Access）；Hz 为赫兹（Hertz），MHz 为兆赫（Megahertz）。

| 属性 | 类型 | 中文说明与约束 |
| --- | --- | --- |
| `#clock-cells` | `int` | **必需**。时钟说明符（Clock Specifier）所需的单元数量；固定值：`2` |
| `clock-frequency` | `int` | **必需**。时钟输出的默认频率，单位为Hz |
| `ahb-prescaler` | `int` | **必需**。AHB预分频系数：根据输入系统频率确定实际内核时钟频率`HCLK`；HCLK 为CPU、AHB、存储器及DMA供时钟；合法值：`1, 2, 4, 8, 16, 64, 128, 256, 512` |
| `apb1-prescaler` | `int` | **必需**。APB1预分频系数；原属性栏没有额外文字说明；合法值：`1, 2, 4, 8, 16` |
| `apb2-prescaler` | `int` | **必需**。APB2预分频系数；原属性栏没有额外文字说明；合法值：`1, 2, 4, 8, 16` |
| `undershoot-prevention` | `boolean` | 部分器件设置较高内核频率（>80 MHz）时，可能必须分两步完成以防止下冲（Undershoot）：先应用中间AHB预分频系数，再将系统时钟源切换到PLL，完成后将预分频系数恢复为期望值 |

本页没有已弃用的节点专用属性。

## 126.6\_基础属性

以下属性继承自基础绑定（Base Binding），**并非全部一定适用于本兼容字符串**。表中还涉及中断（Interrupt）、时钟（Clock）、输入输出（Input/Output，I/O）、邮箱（Mailbox，MBOX）、处理器间消息（Inter-Processor Messaging，IPM）、电源域（Power Domain）和硬件自旋锁（Hardware Spinlock）。

| 属性 | 类型 | 中文说明与约束 |
| --- | --- | --- |
| `reg` | `array` | **必需**。给出寻址设备所需的信息，具体含义随设备及 `compatible` 而变化。通常是一组地址与长度对，每对称为寄存器块（Register Block），数值通常写为十六进制。参见规范v0.4第2.3.6节及[重要属性](../devicetree/P003_语法与结构.md) |
| `status` | `string` | 节点代表的硬件或其他资源的运行状态（Operational Status）。`okay` 表示资源可运行，例如可供驱动使用；`disabled` 表示资源不可运行，系统应将其视为不存在。参见《设备树规范》（Devicetree Specification）v0.4第2.3.4节；合法值：`okay, disabled, reserved, fail, fail-sss` |
| `compatible` | `string-array` | **必需**。字符串列表定义节点代表的硬件或其他资源类型。设备驱动通过特定兼容字符串（Compatible String）寻找应由自身管理的设备。推荐格式为 `vendor,device`：前者是厂商简称，后者通常来自数据手册。多个值从最具体到最通用排列，让具体设备匹配当前可用的最具体驱动。参见规范v0.4第2.3.1节 |
| `reg-names` | `string-array` | 为 `reg` 中每个寄存器块提供可选名称；原始例子及逐项说明见本层表后 |
| `ranges` | `compound` | 定义总线子地址空间与总线节点父地址空间之间的映射或转换。通常为空，或由子总线地址、父总线地址、长度三元组组成。**空属性表示两侧地址空间相同、不需要转换；总线节点没有此属性则认为子、父地址空间之间不存在映射**。参见规范v0.4第2.3.8节 |
| `interrupts` | `array` | 设备产生的中断，编码为一个或多个中断说明符；格式由设备在中断树中的位置决定，具有相同 `interrupt-parent` 的设备使用相同格式；中断（Interrupt）及中断映射见《设备树规范》v0.4第2.4节 |
| `interrupts-extended` | `compound` | 扩展中断说明符，可替代 `interrupts`；中断（Interrupt）及中断映射见《设备树规范》v0.4第2.4节 |
| `interrupt-names` | `string-array` | 设备各中断的可选名称；中断本身在 `interrupts` 或 `interrupts-extended` 中定义；中断（Interrupt）及中断映射见《设备树规范》v0.4第2.4节 |
| `interrupt-parent` | `phandle` | 若存在，引用负责处理此设备所产生中断的节点；中断（Interrupt）及中断映射见《设备树规范》v0.4第2.4节 |
| `label` | `string` | 描述设备的可读字符串；除逐案确有需要外，已不推荐使用此属性。参见规范 v0.4 第 4.1.2 节“其他属性” |
| `clocks` | `phandle-array` | 设备的时钟提供者（Clock Provider）信息，通常应遵守[dt-schema时钟绑定约定](https://github.com/devicetree-org/dt-schema/blob/main/dtschema/schemas/clock/clock.yaml) |
| `clock-names` | `string-array` | `clocks` 中各时钟提供者的名称；通用说明称其为可选名称，是否必须填写以本层的必需标记为准 |
| `#address-cells` | `int` | 子节点 `reg` 地址字段所用的 `<u32>` 单元数量；`<u32>` 为32位无符号单元，参见《设备树规范》v0.4第2.3.5节 |
| `#size-cells` | `int` | 子节点 `reg` 大小字段所用的 `<u32>` 单元数量；`<u32>` 为32位无符号单元，参见《设备树规范》v0.4第2.3.5节 |
| `dma-coherent` | `boolean` | 表示设备支持一致性 DMA 操作，见规范 v0.4 第 2.3.10 节 |
| `dmas` | `phandle-array` | 与设备相关的 DMA 通道说明符 |
| `dma-names` | `string-array` | `dmas` 中各 DMA 通道说明符的可选名称 |
| `dma-ranges` | `compound` | 定义总线物理地址空间与其父总线物理地址空间之间的映射或转换，见规范 v0.4 第 2.3.9 节 |
| `io-channels` | `phandle-array` | 与设备相关的 I/O 通道说明符 |
| `io-channel-names` | `string-array` | `io-channels` 中各通道说明符的可选名称 |
| `mboxes` | `phandle-array` | 与设备相关的邮箱/IPM 通道说明符 |
| `mbox-names` | `string-array` | `mboxes` 中各邮箱说明符的可选名称 |
| `power-domains` | `phandle-array` | 与设备相关的电源域说明符 |
| `power-domain-names` | `string-array` | `power-domains` 中各电源域说明符的可选名称 |
| `#power-domain-cells` | `int` | `power-domains` 属性中的单元数量 |
| `hwlocks` | `phandle-array` | 与设备相关的硬件自旋锁（Hardware Spinlock）标识 |
| `hwlock-names` | `string-array` | `hwlocks` 中各锁说明符的可选名称 |
| `zephyr,deferred-init` | `boolean` | 延迟初始化（Deferred Initialization）：启动时不自动初始化设备，应由应用使用 `device_init()` 手动初始化 |
| `wakeup-source` | `boolean` | 标记设备可用作唤醒源（Wakeup Source）。设置该属性后，设备中会设置专门标志，通知系统此设备有唤醒能力。唤醒功能默认禁用，即中断不会唤醒系统；必要时可在运行期间启用 |
| `zephyr,pm-device-runtime-auto` | `boolean` | 初始化函数执行后，自动为设备配置运行时电源管理（Runtime Power Management） |
| `zephyr,disabling-power-states` | `phandles` | 会关闭该设备电源的电源状态（Power State）列表 |

## 126.7\_寄存器块命名原例

以下为`reg-names`原设备树源码（Devicetree Source，DTS）示例；`uart`为通用异步收发器（Universal Asynchronous Receiver/Transmitter，UART）节点名称。

```dts
  / {
       soc {
           #address-cells = <1>;
           #size-cells = <1>;

           uart@1000 {
               reg = <0x1000 0x2000>, <0x3000 0x4000>;
               reg-names = "foo", "bar";
           };
       };
  };
```

`uart@1000`包含两个寄存器块（Register Block）：`foo`的基址`0x1000`、大小`0x2000`；`bar`的基址`0x3000`、大小`0x4000`。

## 126.8\_说明符单元名称

时钟说明符依次包含`bus`和`bits`两个单元（Specifier Cells）。
