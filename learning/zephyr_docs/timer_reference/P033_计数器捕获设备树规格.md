# 第33章\_计数器捕获设备树规格

原文：[structcounter__capture__dt__spec](https://docs.zephyrproject.org/latest/doxygen/html/structcounter__capture__dt__spec.html)。读取日期：2026-10-13，`latest`。

`struct counter_capture_dt_spec`保存设备树（Devicetree，DT）中计数器捕获（Counter Capture）的信息，定义于`zephyr/drivers/counter.h`。

## 33.1\_字段

| 类型 | 字段 | 含义 |
| --- | --- | --- |
| `const struct device *` | `dev` | 计数器设备实例（Device Instance）。 |
| `counter_capture_flags_t` | `flags` | 适用于该通道的捕获标志（Capture Flags）。 |
| `uint8_t` | `chan_id` | 由该计数器设备控制的通道标识（Channel ID）。 |

## 33.2\_设备树初始化宏

原页列出下列六个相关宏，完整参数、展开式和用例见[计数器公共接口](P022_计数器公共接口.md)：

- `COUNTER_CAPTURE_DT_SPEC_GET_BY_NAME`：按名称取得捕获规格。
- `COUNTER_CAPTURE_DT_SPEC_GET_BY_NAME_OR`：按名称取得，缺少时使用备选初始化值。
- `COUNTER_CAPTURE_DT_SPEC_GET_BY_IDX`：按索引取得捕获规格。
- `COUNTER_CAPTURE_DT_SPEC_GET_BY_IDX_OR`：按索引取得，缺少时使用备选初始化值。
- `COUNTER_CAPTURE_DT_SPEC_GET`：取得首项捕获规格。
- `COUNTER_CAPTURE_DT_SPEC_GET_OR`：取得首项，缺少时使用备选初始化值。

使用规格的函数见[捕获接口](P032_计数器捕获接口.md)，底层设备树取值宏见[捕获设备树宏](P034_计数器捕获设备树宏.md)。
