# 第29章\_计数器驱动操作结构

原文：[structcounter__driver__api](https://docs.zephyrproject.org/latest/doxygen/html/structcounter__driver__api.html)。读取日期：2026-10-13，`latest`。

`counter_driver_api`是每个计数器（Counter）驱动需要定义的驱动应用程序接口（Driver Application Programming Interface，Driver API）结构，包含操作函数指针及驱动专用常量数据。定义于：

```c
#include <zephyr/drivers/counter.h>
```

## 29.1\_操作与可用条件

必填（Required，REQ）成员必须设置；可选（Optional，OPT）成员可不设置。带配置条件的成员仅在对应Kconfig选项启用时可用；多个条件需同时满足。捕获（Capture）、校准（Calibration）、保护周期（Guard Period）、顶值（Top Value）与单次告警（Single-Shot Alarm）分别对应下表操作。

| 类型 | 字段 | 要求 | 作用 | Kconfig条件 |
| --- | --- | --- | --- | --- |
| `counter_api_start` | `start` | 必填 | 启动自由运行计数器。 | 无额外条件 |
| `counter_api_stop` | `stop` | 必填 | 停止计数器。 | 无额外条件 |
| `counter_api_get_value` | `get_value` | 必填 | 取得当前计数值。 | 无额外条件 |
| `counter_api_reset` | `reset` | 可选 | 复位到初始值。 | 无额外条件 |
| `counter_api_set_value` | `set_value` | 可选 | 设置当前计数值。 | 无额外条件 |
| `counter_api_set_alarm` | `set_alarm` | 必填 | 设置通道单次告警。 | 无额外条件 |
| `counter_api_cancel_alarm` | `cancel_alarm` | 必填 | 取消通道告警。 | 无额外条件 |
| `counter_api_set_top_value` | `set_top_value` | 必填 | 设置顶值。 | 无额外条件 |
| `counter_api_get_pending_int` | `get_pending_int` | 必填 | 取得待处理中断状态。 | 无额外条件 |
| `counter_api_get_top_value` | `get_top_value` | 必填 | 取得当前顶值。 | 无额外条件 |
| `counter_api_get_guard_period` | `get_guard_period` | 可选 | 取得保护周期，单位为计数刻度。 | 无额外条件 |
| `counter_api_set_guard_period` | `set_guard_period` | 可选 | 设置保护周期，单位为计数刻度。 | 无额外条件 |
| `counter_api_get_freq` | `get_freq` | 可选 | 取得频率，单位为赫兹。 | 无额外条件 |
| `counter_api_get_freq_64` | `get_freq_64` | 可选 | 取得64位频率，单位为赫兹。 | `CONFIG_COUNTER_64BITS_FREQ` |
| `counter_api_get_value_64` | `get_value_64` | 可选 | 取得64位当前计数值。 | `CONFIG_COUNTER_64BITS_TICKS` |
| `counter_api_set_value_64` | `set_value_64` | 可选 | 设置64位当前计数值。 | `CONFIG_COUNTER_64BITS_TICKS` |
| `counter_api_set_alarm_64` | `set_alarm_64` | 必填 | 设置64位通道单次告警。 | `CONFIG_COUNTER_64BITS_TICKS` |
| `counter_api_get_guard_period_64` | `get_guard_period_64` | 可选 | 取得64位保护周期，单位为计数刻度。 | `CONFIG_COUNTER_64BITS_TICKS` |
| `counter_api_set_guard_period_64` | `set_guard_period_64` | 可选 | 设置64位保护周期，单位为计数刻度。 | `CONFIG_COUNTER_64BITS_TICKS` |
| `counter_api_get_top_value_64` | `get_top_value_64` | 必填 | 取得64位当前顶值。 | `CONFIG_COUNTER_64BITS_TICKS` |
| `counter_api_set_top_value_64` | `set_top_value_64` | 必填 | 设置64位顶值。 | `CONFIG_COUNTER_64BITS_TICKS` |
| `counter_api_capture_configure` | `capture_configure` | 必填 | 配置捕获通道并注册回调。 | `CONFIG_COUNTER_CAPTURE` |
| `counter_api_capture_configure_64` | `capture_configure_64` | 必填 | 配置捕获通道并注册64位刻度回调。 | `CONFIG_COUNTER_CAPTURE`、`CONFIG_COUNTER_64BITS_TICKS` |
| `counter_api_enable_capture` | `enable_capture` | 必填 | 启用通道捕获。 | `CONFIG_COUNTER_CAPTURE` |
| `counter_api_disable_capture` | `disable_capture` | 必填 | 禁用通道捕获。 | `CONFIG_COUNTER_CAPTURE` |
| `counter_api_set_calibration` | `set_calibration` | 可选 | 设置校准值，单位为十亿分率。 | `CONFIG_COUNTER_CALIBRATION` |
| `counter_api_get_calibration` | `get_calibration` | 可选 | 取得校准值，单位为十亿分率。 | `CONFIG_COUNTER_CALIBRATION` |

原字段`get_freq`没有附带简述；此处的频率含义来自原后端类型`counter_api_get_freq`说明。回调签名见[驱动后端接口](P023_计数器驱动后端接口.md)。
