# 第104章\_时钟监控驱动操作结构

原文：[structclock__monitor__driver__api](https://docs.zephyrproject.org/latest/doxygen/html/structclock__monitor__driver__api.html)。读取日期：2026-10-13，`latest`。

结构体`clock_monitor_driver_api`是时钟监控（Clock Monitor）驱动操作（Driver Operations）表，头文件为`zephyr/drivers/clock_monitor.h`。

每个时钟监控驱动都需要定义此应用程序编程接口（Application Programming Interface，API）结构。它保存已实现操作的函数指针（Function Pointer），以及驱动专用的其他常量数据。

标记为必需（Required，REQ）的成员**必须由驱动设置**；标记为可选（Optional，OPT）的成员可以省略。本接口前三项必需，后两项可选。

## 104.1\_完整声明

```c
__subsystem struct clock_monitor_driver_api {
        clock_monitor_api_configure      configure;
        clock_monitor_api_start          start;
        clock_monitor_api_stop           stop;
        clock_monitor_api_get_rate       get_rate;
        clock_monitor_api_set_source     set_source;
};
```

## 104.2\_成员与实现要求

| 成员 | 类型 | 标记 | 用途 |
| --- | --- | --- | --- |
| `configure` | `clock_monitor_api_configure` | REQ | 应用监控配置 |
| `start` | `clock_monitor_api_start` | REQ | 启动所配置的模式 |
| `stop` | `clock_monitor_api_stop` | REQ | 停止监控器 |
| `get_rate` | `clock_monitor_api_get_rate` | OPT | 轮询最近一次已完成的测量 |
| `set_source` | `clock_monitor_api_set_source` | OPT | 运行时切换参考／目标时钟输入 |
