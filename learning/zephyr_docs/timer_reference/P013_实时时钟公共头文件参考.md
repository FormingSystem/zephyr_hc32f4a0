# 第13章\_实时时钟公共头文件参考

原文：[rtc_8h](https://docs.zephyrproject.org/latest/doxygen/html/rtc_8h.html)。读取日期：2026-10-13，`latest`。

`zephyr/drivers/rtc.h`是实时时钟（Real-Time Clock，RTC）驱动应用程序接口（Application Programming Interface，API）的主头文件，包含：

```c
#include <zephyr/kernel.h>
#include <zephyr/device.h>
#include <errno.h>
#include <zephyr/syscalls/rtc.h>
```

## 13.1\_数据结构与闹钟掩码

`rtc_time`存储亚秒精度（Sub-second Precision）的日期和时间；`rtc_driver_api`保存驱动操作（Driver Operations）。字段分别见[时间结构](P011_实时时钟时间结构.md)与[驱动操作结构](P012_实时时钟驱动操作结构.md)。

闹钟（Alarm）时间掩码（Mask）指定设置时启用的匹配字段：
| 掩码宏 | 原值 | 匹配字段 |
| --- | --- | --- |
| `RTC_ALARM_TIME_MASK_SECOND` | `BIT(0)` | 秒（Second） |
| `RTC_ALARM_TIME_MASK_MINUTE` | `BIT(1)` | 分（Minute） |
| `RTC_ALARM_TIME_MASK_HOUR` | `BIT(2)` | 小时（Hour） |
| `RTC_ALARM_TIME_MASK_MONTHDAY` | `BIT(3)` | 月内日期（Day of Month） |
| `RTC_ALARM_TIME_MASK_MONTH` | `BIT(4)` | 月（Month） |
| `RTC_ALARM_TIME_MASK_YEAR` | `BIT(5)` | 年（Year） |
| `RTC_ALARM_TIME_MASK_WEEKDAY` | `BIT(6)` | 星期（Day of Week） |
| `RTC_ALARM_TIME_MASK_YEARDAY` | `BIT(7)` | 年内日序（Day of Year） |
| `RTC_ALARM_TIME_MASK_NSEC` | `BIT(8)` | 纳秒（Nanosecond） |

## 13.2\_通知回调与后端类型

前两个类型分别为RTC更新事件和闹钟触发回调（Callback）。后十个类型依次对应设置／取得时间、取得支持的闹钟字段、设置／取得闹钟时间、检查待处理闹钟、设置闹钟回调、设置更新回调以及设置／取得校准。

```c
typedef void (*rtc_update_callback)(const struct device *dev, void *user_data);
typedef void (*rtc_alarm_callback)(const struct device *dev, uint16_t id, void *user_data);
typedef int (*rtc_api_set_time)(const struct device *dev, const struct rtc_time *timeptr);
typedef int (*rtc_api_get_time)(const struct device *dev, struct rtc_time *timeptr);
typedef int (*rtc_api_alarm_get_supported_fields)(const struct device *dev, uint16_t id,
                                                  uint16_t *mask);
typedef int (*rtc_api_alarm_set_time)(const struct device *dev, uint16_t id, uint16_t mask,
                                      const struct rtc_time *timeptr);
typedef int (*rtc_api_alarm_get_time)(const struct device *dev, uint16_t id, uint16_t *mask,
                                      struct rtc_time *timeptr);
typedef int (*rtc_api_alarm_is_pending)(const struct device *dev, uint16_t id);
typedef int (*rtc_api_alarm_set_callback)(const struct device *dev, uint16_t id,
                                          rtc_alarm_callback callback, void *user_data);
typedef int (*rtc_api_update_set_callback)(const struct device *dev,
                                           rtc_update_callback callback, void *user_data);
typedef int (*rtc_api_set_calibration)(const struct device *dev, int32_t calibration);
typedef int (*rtc_api_get_calibration)(const struct device *dev, int32_t *calibration);
```

完整参数含义见[公共接口](P009_实时时钟公共接口.md)，后端类型见[驱动后端接口](P010_实时时钟驱动后端接口.md)。

## 13.3\_公共函数与辅助函数

以下依次列出时间、闹钟、更新、校准及两个辅助函数，保留完整参数类型。校准（Calibration）使用十亿分率（Parts Per Billion，ppb），频率换算辅助函数接收纳赫兹（Nanohertz，nHz）。

```c
int rtc_set_time(const struct device *dev, const struct rtc_time *timeptr);
int rtc_get_time(const struct device *dev, struct rtc_time *timeptr);
int rtc_alarm_get_supported_fields(const struct device *dev, uint16_t id, uint16_t *mask);
int rtc_alarm_set_time(const struct device *dev, uint16_t id, uint16_t mask, const struct rtc_time *timeptr);
int rtc_alarm_get_time(const struct device *dev, uint16_t id, uint16_t *mask, struct rtc_time *timeptr);
int rtc_alarm_is_pending(const struct device *dev, uint16_t id);
static inline int rtc_alarm_set_callback(const struct device *dev, uint16_t id, rtc_alarm_callback callback, void *user_data);
static inline int rtc_update_set_callback(const struct device *dev, rtc_update_callback callback, void *user_data);
int rtc_set_calibration(const struct device *dev, int32_t calibration);
int rtc_get_calibration(const struct device *dev, int32_t *calibration);
static inline struct tm *rtc_time_to_tm(struct rtc_time *timeptr);
static inline int32_t rtc_calibration_from_frequency(uint32_t frequency);
```

`rtc_time_to_tm`安全转换到标准时间结构指针；`rtc_calibration_from_frequency`计算校准到1赫兹（Hertz，Hz）所需的校准量。原文件参考页把内联函数显示为`static`，上列声明依据同页对应源码保留`inline`。

调用条件、回调禁用方法、错误码和校准正负方向见[公共接口](P009_实时时钟公共接口.md)，所有可见代码见[源码页](P014_实时时钟公共头文件源码.md)。
