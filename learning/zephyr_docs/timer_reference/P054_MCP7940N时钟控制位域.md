# 第54章\_MCP7940N时钟控制位域

原文：[structmcp7940n__rtc__control](https://docs.zephyrproject.org/latest/doxygen/html/structmcp7940n__rtc__control.html)。读取日期：2026-10-13，`latest`。

`struct mcp7940n_rtc_control`是MCP7940N的时钟控制（RTC Control）结构，定义于`zephyr/drivers/rtc/mcp7940n.h`。RTC指实时时钟（Real-Time Clock）。本页对应原结构参考中的全部字段（Data Fields）。

## 54.1\_字段声明

字段类型均为`uint8_t`，冒号后的数值为位域（Bit Field）宽度，单位是位（Bit）。原结构页没有逐字段的行为说明，下表保留名称、类型与宽度。

| 类型 | 字段 | 位宽 |
| --- | --- | --- |
| `uint8_t` | `sqwfs` | 2位。 |
| `uint8_t` | `crs_trim` | 1位。 |
| `uint8_t` | `ext_osc` | 1位。 |
| `uint8_t` | `alm0_en` | 1位。 |
| `uint8_t` | `alm1_en` | 1位。 |
| `uint8_t` | `sqw_en` | 1位。 |
| `uint8_t` | `out` | 1位。 |

## 54.2\_完整结构声明

以下声明取自[同一官方头文件源码](P046_MCP7940N头文件源码.md)，包括原`__packed`紧凑布局（Packed Layout）标记。

```c
struct mcp7940n_rtc_control {
        uint8_t sqwfs : 2;
        uint8_t crs_trim : 1;
        uint8_t ext_osc : 1;
        uint8_t alm0_en : 1;
        uint8_t alm1_en : 1;
        uint8_t sqw_en : 1;
        uint8_t out : 1;
} __packed;
```

该结构的组合容器见[时间寄存器组合（Time Registers）](P062_MCP7940N时间寄存器组合.md)；设置UNIX时间（Unix Time）的接口见[文件参考](P045_MCP7940N寄存器与设置接口.md)。
