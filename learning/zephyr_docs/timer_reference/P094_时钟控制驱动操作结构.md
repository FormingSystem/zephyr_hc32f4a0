# 第94章\_时钟控制驱动操作结构

原文：[structclock__control__driver__api](https://docs.zephyrproject.org/latest/doxygen/html/structclock__control__driver__api.html)。读取日期：2026-10-13，`latest`。

结构体`clock_control_driver_api`是时钟控制（Clock Control）驱动操作（Driver Operations）表，头文件为`zephyr/drivers/clock_control.h`。

每个时钟控制驱动都需要定义此应用程序编程接口（Application Programming Interface，API）结构。它包含驱动所实现操作的函数指针（Function Pointer），以及驱动专用的其他常量数据。标记为必需（Required，REQ）的成员**必须设置**，标记为可选（Optional，OPT）的成员可以省略。本页列出的七个成员均为 OPT。

## 94.1\_完整声明

```c
__subsystem struct clock_control_driver_api {
        clock_control on;
        clock_control off;
        clock_control_async_on_fn async_on;
        clock_control_get get_rate;
        clock_control_get_status_fn get_status;
        clock_control_set set_rate;
        clock_control_configure_fn configure;
};
```

## 94.2\_成员与可选性

| 成员 | 类型 | 标记 | 操作 |
| --- | --- | --- | --- |
| `on` | `clock_control` | OPT | 开启设备控制的时钟 |
| `off` | `clock_control` | OPT | 关闭设备控制的时钟 |
| `async_on` | `clock_control_async_on_fn` | OPT | 请求启动时钟，并在启动完成后通知 |
| `get_rate` | `clock_control_get` | OPT | 取得指定子系统的时钟频率 |
| `get_status` | `clock_control_get_status_fn` | OPT | 取得时钟状态 |
| `set_rate` | `clock_control_set` | OPT | 设置设备控制的时钟频率 |
| `configure` | `clock_control_configure_fn` | OPT | 配置源时钟 |
