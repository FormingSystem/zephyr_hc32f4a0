# 第65章\_计数器告警示例

原文：[Counter Alarm](https://docs.zephyrproject.org/latest/samples/drivers/counter/alarm/README.html)。读取日期：2026-10-13，`latest`。

本示例使用[计数器（Counter）API](../hardware/P017_计数器.md)实现告警（Alarm）应用。最初设置2秒延迟；每次告警到期后，重新配置一个延迟翻倍的告警。[示例源码](https://github.com/zephyrproject-rtos/zephyr/tree/main/samples/drivers/counter/alarm)位于`samples/drivers/counter/alarm`。

## 65.1\_精度与硬件要求

如果计数频率为1赫兹（Hertz，Hz），例如实时时钟（Real-Time Clock，RTC），计时精度就是1秒。因此，示例输出可能相差1秒。

本示例要求目标支持可设置告警的定时器硬件模块（Timer IP）。原文的参考开发板为[Disco L475 IOT01（B-L475E-IOT01A）](https://docs.zephyrproject.org/latest/boards/st/disco_l475_iot1/doc/index.html#disco_l475_iot1)。

## 65.2\_构建与运行

官方命令如下：

```sh
west build -b disco_l475_iot1 samples/drivers/counter/alarm
west build -t run
```

## 65.3\_预期输出

以下是官方示例输出，保留原日志文本：

```text
Counter alarm sample

Set alarm in 2 sec
!!! Alarm !!!
Now: 2
Set alarm in 4 sec
!!! Alarm !!!
Now: 6
Set alarm in 8 sec
!!! Alarm !!!
Now: 14
Set alarm in 16 sec
!!! Alarm !!!
Now: 30

<repeats endlessly>
```

`Counter alarm sample`表示计数器告警示例；`Set alarm in ... sec`表示设置若干秒后触发告警；`Alarm`表示告警已触发；`Now`为当前计数。示例中的2、6、14、30对应连续增加的2、4、8、16秒延迟；`<repeats endlessly>`表示持续重复。

API详细说明见[计数器公共接口](P022_计数器公共接口.md)。
