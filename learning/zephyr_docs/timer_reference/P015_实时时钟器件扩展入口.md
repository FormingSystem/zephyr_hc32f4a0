# 第15章\_实时时钟器件扩展入口

原文：[group__rtc__interface__ext](https://docs.zephyrproject.org/latest/doxygen/html/group__rtc__interface__ext.html)。读取日期：2026-10-13，`latest`。

本页对应官方的器件专用实时时钟（Real-Time Clock，RTC）应用程序接口（Application Programming Interface，API）扩展分组。当前页面只有一个文件条目，没有额外的详细说明。

## 15.1\_扩展文件

原页列出`rtc_max31331.h`，说明为“MAX31331 RTC驱动专用API”。完整译文见[MAX31331实时时钟扩展参考](P018_MAX31331实时时钟扩展参考.md)，可见代码见[对应源码](P019_MAX31331实时时钟扩展源码.md)。

## 15.2\_与公共接口的关系

公共时间、闹钟（Alarm）、更新通知及校准（Calibration）功能见[RTC公共接口](P009_实时时钟公共接口.md)。本页是官方扩展分组入口的完整对应页，不把其他文件或未在原分组出现的能力补写进清单。
