# 第27章\_计数器64位顶值配置

原文：[structcounter__top__cfg__64](https://docs.zephyrproject.org/latest/doxygen/html/structcounter__top__cfg__64.html)。读取日期：2026-10-13，`latest`。

结构体`counter_top_cfg_64`保存计数器（Counter）的64位顶值（Top Value）配置，定义于：

```c
#include <zephyr/drivers/counter.h>
```

## 27.1\_完整字段

顶值刻度类型与回调（Callback）指针分别保留。

| 类型 | 字段 | 含义 |
| --- | --- | --- |
| `uint64_t` | `ticks` | 顶值。 |
| `counter_top_callback_t` | `callback` | 回调函数，可以为`NULL`。 |
| `void *` | `user_data` | 传给回调的用户数据；回调为`NULL`时此字段无效。 |
| `uint32_t` | `flags` | 顶值配置标志，见`COUNTER_TOP_CFG_*`。 |

## 27.2\_对应设置接口


```c
int counter_set_top_value_64(const struct device *dev, const struct counter_top_cfg_64 *cfg);
```

改变顶值时是否复位（Reset），由`COUNTER_TOP_CFG_DONT_RESET`与`COUNTER_TOP_CFG_RESET_WHEN_LATE`控制。没有活动通道告警时才能改变顶值，完整语义与错误码见[公共接口](P022_计数器公共接口.md)。源码见[公共头文件源码](P031_计数器公共头文件源码.md)。
