# 第1章\_看门狗公共接口

原文：[group__watchdog__interface](https://docs.zephyrproject.org/latest/doxygen/html/group__watchdog__interface.html)。读取日期：2026-10-13，`latest`。

本页是看门狗（Watchdog）设备的应用程序接口（Application Programming Interface，API），自Zephyr 1.0引入，接口版本为1.0.0。看门狗概览见[看门狗](../hardware/P016_看门狗.md)；公共头文件为：

```c
#include <zephyr/drivers/watchdog.h>
```

## 1.1\_选项与超时行为

`WDT_OPT_*`是设置看门狗实例时使用的选项（Option）；`WDT_FLAG_*`是超时配置中的行为标志（Behavior Flag）。两类参数不能仅凭名称相似就互换。
| 宏 | 原值 | 含义 |
| --- | --- | --- |
| `WDT_OPT_PAUSE_IN_SLEEP` | `BIT(0)` | 中央处理器（Central Processing Unit，CPU）处于睡眠状态（Sleep State）时暂停看门狗计时器。 |
| `WDT_OPT_PAUSE_HALTED_BY_DBG` | `BIT(1)` | CPU被调试器（Debugger）暂停时，暂停看门狗计时器。 |
| `WDT_FLAG_RESET_NONE` | `(0 << WDT_FLAG_RESET_SHIFT)` | 不复位（No Reset）。 |
| `WDT_FLAG_RESET_CPU_CORE` | `(1 << WDT_FLAG_RESET_SHIFT)` | 复位CPU核心（CPU Core）。 |
| `WDT_FLAG_RESET_SOC` | `(2 << WDT_FLAG_RESET_SHIFT)` | 复位片上系统（System on Chip，SoC）。 |

## 1.2\_超时窗口、配置与回调

结构体`wdt_window`描述超时窗口（Timeout Window），`wdt_timeout_cfg`描述超时配置。完整字段分别见[喂狗窗口结构](P003_看门狗喂狗窗口结构.md)与[超时配置结构](P004_看门狗超时配置结构.md)。

看门狗回调（Callback）的类型如下：

```c
typedef void (*wdt_callback_t)(const struct device *dev, int channel_id);
```

`dev`是看门狗设备实例，`channel_id`是通道标识（Channel Identifier）。驱动实现所需的操作类型另见[后端接口](P002_看门狗驱动后端接口.md)。

## 1.3\_安装超时

`wdt_install_timeout`安装一个新的超时配置：

```c
static inline int wdt_install_timeout(const struct device *dev, const struct wdt_timeout_cfg *cfg);
```

`dev`是看门狗设备实例，输入参数`cfg`指向超时配置。**必须在调用`wdt_setup`之前安装超时；此处的更改要等到调用`wdt_setup`后才生效。**

成功时返回通道ID（Channel ID），之后调用`wdt_feed`时使用该ID；失败时返回负错误码（Negative errno）。成功返回值不应只按“等于0”判断。

| 返回值 | 原文含义 |
| --- | --- |
| `-EBUSY` | 看门狗已经完成设置，不能再安装超时。 |
| `-ENOMEM` | 无法继续安装更多超时。 |
| `-ENOTSUP` | 设置的某个标志不受支持。 |
| `-EINVAL` | 某个窗口超时值超出可能范围；如果看门狗的所有超时只能使用同一个超时值，而新窗口与此前已安装的窗口不同，也返回此值。 |

## 1.4\_设置并启用实例

`wdt_setup`配置影响所有超时的全局设置：

```c
int wdt_setup(const struct device *dev, uint8_t options);
```

应先安装超时再调用本函数。`dev`是设备实例，`options`为前述`WDT_OPT_*`配置选项。成功返回后，所有已安装超时均有效，必须周期性调用`wdt_feed`进行服务。

成功返回0，失败返回负错误码。`-ENOTSUP`表示某个选项不受支持；`-EBUSY`表示该实例已经完成设置。

## 1.5\_喂狗

`wdt_feed`为指定的看门狗超时喂狗（Feed），`dev`为设备实例，`channel_id`为通道索引：

```c
int wdt_feed(const struct device *dev, int channel_id);
```

成功返回0，失败返回负错误码。

| 返回值 | 原文含义 |
| --- | --- |
| `-EAGAIN` | 完成喂狗操作会使调用者停顿，例如已有看门狗操作仍在进行，可能是先前的一次`wdt_feed`调用。 |
| `-EINVAL` | 所给通道没有已安装的超时。 |

## 1.6\_禁用实例

`wdt_disable`禁用看门狗实例，并自动卸载全部超时：

```c
int wdt_disable(const struct device *dev);
```

`dev`是设备实例。若要重新设置，应重新安装超时，再调用`wdt_setup`。**并非所有看门狗在禁用后都能重新启动。**

成功返回0，失败返回负错误码。`-EFAULT`表示实例尚未启用；`-EPERM`表示应用程序代码不能直接禁用该看门狗。
