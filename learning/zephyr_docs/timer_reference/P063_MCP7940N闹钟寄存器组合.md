# 第63章\_MCP7940N闹钟寄存器组合

原文：[structmcp7940n__alarm__registers](https://docs.zephyrproject.org/latest/doxygen/html/structmcp7940n__alarm__registers.html)。读取日期：2026-10-13，`latest`。

`struct mcp7940n_alarm_registers`是MCP7940N的闹钟寄存器组合（Alarm Registers）结构，定义于`zephyr/drivers/rtc/mcp7940n.h`。RTC指实时时钟（Real-Time Clock）。本页对应原结构参考中的全部字段（Data Fields）。

## 63.1\_字段声明

各字段的类型链接指向其完整位域（Bit Field）参考；顺序与原文件一致。

| [`struct mcp7940n_alm_min`](P057_MCP7940N闹钟分位域.md) | `alm_min` | 闹钟分（Alarm Minutes）。 |
| [`struct mcp7940n_alm_hours`](P058_MCP7940N闹钟小时位域.md) | `alm_hours` | 闹钟小时（Alarm Hours）。 |

## 63.2\_完整组合声明

以下定义取自[对应源码](P046_MCP7940N头文件源码.md)，保留`__packed`紧凑布局（Packed Layout）标记。

```c
struct mcp7940n_alarm_registers {
        struct mcp7940n_alm_sec alm_sec;
        struct mcp7940n_alm_min alm_min;
        struct mcp7940n_alm_hours alm_hours;
        struct mcp7940n_alm_weekday alm_weekday;
        struct mcp7940n_alm_date alm_date;
        struct mcp7940n_alm_month alm_month;
} __packed;
```

寄存器枚举和设置时间函数见[文件参考](P045_MCP7940N寄存器与设置接口.md)。原结构页未增加其他行为说明。
