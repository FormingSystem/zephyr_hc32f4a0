# 第97章\_时钟控制扩展接口总览

原文：[group__clock__control__interface__ext](https://docs.zephyrproject.org/latest/doxygen/html/group__clock__control__interface__ext.html)。读取日期：2026-10-13，`latest`。

本页是设备专用时钟控制扩展接口（Device-specific Clock Control API Extensions）的主题总览。API 为应用程序编程接口（Application Programming Interface）。

原页只列出以下32个厂商或系列的子主题，没有额外接口说明。厂商、产品系列和模块名称按官方拼写保留；下表中的中文描述均表示对应设备或系列的时钟控制扩展（Clock Control Extension），不额外推断尚未进入的子页行为。
