# 第39章\_计数器捕获仿真接口

原文：[counter__capture__emul_8h](https://docs.zephyrproject.org/latest/doxygen/html/counter__capture__emul_8h.html)。读取日期：2026-10-13，`latest`。

`zephyr/drivers/counter/counter_capture_emul.h`提供计数器捕获（Counter Capture）仿真（Emulation）的后端应用程序接口（Backend API）。包含：

```c
#include <zephyr/device.h>
#include <zephyr/drivers/counter.h>
```

## 39.1\_设置仿真输入电平

`counter_capture_emul_input_set`设置指定通道的仿真输入电平；`counter_capture_emul_input_set_dt`从设备树规格（Devicetree Specification）取得设备与通道：

```c
int counter_capture_emul_input_set(const struct device *dev, uint8_t chan_id, int level);
static inline int counter_capture_emul_input_set_dt(const struct counter_capture_dt_spec *spec,
                                                    int level);
```

`dev`为设备指针，`chan_id`为通道标识，`level`为输入电平；`spec`指向计数器捕获设备树规格。文件参考页只提供功能简介；电平变化如何触发回调（Callback）、有效电平及返回值的详细原文见[计数器仿真后端接口](../hardware/P493_计数器仿真后端接口.md)。

## 39.2\_读取仿真输入电平

`counter_capture_emul_input_get`取得通道的仿真输入电平；`counter_capture_emul_input_get_dt`根据设备树规格读取：

```c
int counter_capture_emul_input_get(const struct device *dev, uint8_t chan_id);
static inline int counter_capture_emul_input_get_dt(const struct counter_capture_dt_spec *spec);
```

参数`dev`、`chan_id`和`spec`分别为设备、通道标识和捕获规格。两种设备树包装函数的转发实现见[仿真源码](P040_计数器捕获仿真源码.md)，规格字段见[捕获设备树规格](P033_计数器捕获设备树规格.md)。
