# 第43章\_STM32计数器头文件参考

原文：[counter_2stm32_8h](https://docs.zephyrproject.org/latest/doxygen/html/counter_2stm32_8h.html)。读取日期：2026-10-13，`latest`。

本页对应`zephyr/drivers/counter/stm32.h`的文件参考，列出全部20个公共配置宏。STM32专用宏用于计数器捕获（Counter Capture）配置，声明于`zephyr/drivers/counter/stm32.h`。

## 43.1\_输入捕获预分频

输入捕获预分频器（Input Capture Prescaler）决定每隔多少个输入边沿产生一次捕获。

| 宏 | 原值 | 捕获间隔 |
| --- | --- | --- |
| `COUNTER_CAPTURE_STM32_PRESCALER_DIV1` | `(0 << COUNTER_CAPTURE_STM32_PRESCALER_DIV_POS)` | 每个边沿捕获一次。 |
| `COUNTER_CAPTURE_STM32_PRESCALER_DIV2` | `(1 << COUNTER_CAPTURE_STM32_PRESCALER_DIV_POS)` | 每2个边沿捕获一次。 |
| `COUNTER_CAPTURE_STM32_PRESCALER_DIV4` | `(2 << COUNTER_CAPTURE_STM32_PRESCALER_DIV_POS)` | 每4个边沿捕获一次。 |
| `COUNTER_CAPTURE_STM32_PRESCALER_DIV8` | `(3 << COUNTER_CAPTURE_STM32_PRESCALER_DIV_POS)` | 每8个边沿捕获一次。 |

## 43.2\_输入采样频率与数字滤波长度

数字滤波器（Digital Filter）的配置同时规定采样频率（Sampling Frequency）和滤波长度（Filter Length）`N`。下表保留原频率符号`fDTS`与`fTIM_KER_CK`，不将其替换成未经原文给定的固定赫兹数值。

| 宏 | 原值 | 采样频率 | N |
| --- | --- | --- | --- |
| `COUNTER_CAPTURE_STM32_FILTER_DTS_DIV1_N1` | `(0 << COUNTER_CAPTURE_STM32_FILTER_POS)` | `fDTS` | 1，不滤波（No Filter）。 |
| `COUNTER_CAPTURE_STM32_FILTER_TIM_KER_CK_N2` | `(1 << COUNTER_CAPTURE_STM32_FILTER_POS)` | `fTIM_KER_CK` | 2。 |
| `COUNTER_CAPTURE_STM32_FILTER_TIM_KER_CK_N4` | `(2 << COUNTER_CAPTURE_STM32_FILTER_POS)` | `fTIM_KER_CK` | 4。 |
| `COUNTER_CAPTURE_STM32_FILTER_TIM_KER_CK_N8` | `(3 << COUNTER_CAPTURE_STM32_FILTER_POS)` | `fTIM_KER_CK` | 8。 |
| `COUNTER_CAPTURE_STM32_FILTER_DTS_DIV2_N6` | `(4 << COUNTER_CAPTURE_STM32_FILTER_POS)` | `fDTS/2` | 6。 |
| `COUNTER_CAPTURE_STM32_FILTER_DTS_DIV2_N8` | `(5 << COUNTER_CAPTURE_STM32_FILTER_POS)` | `fDTS/2` | 8。 |
| `COUNTER_CAPTURE_STM32_FILTER_DTS_DIV4_N6` | `(6 << COUNTER_CAPTURE_STM32_FILTER_POS)` | `fDTS/4` | 6。 |
| `COUNTER_CAPTURE_STM32_FILTER_DTS_DIV4_N8` | `(7 << COUNTER_CAPTURE_STM32_FILTER_POS)` | `fDTS/4` | 8。 |
| `COUNTER_CAPTURE_STM32_FILTER_DTS_DIV8_N6` | `(8 << COUNTER_CAPTURE_STM32_FILTER_POS)` | `fDTS/8` | 6。 |
| `COUNTER_CAPTURE_STM32_FILTER_DTS_DIV8_N8` | `(9 << COUNTER_CAPTURE_STM32_FILTER_POS)` | `fDTS/8` | 8。 |
| `COUNTER_CAPTURE_STM32_FILTER_DTS_DIV16_N5` | `(10 << COUNTER_CAPTURE_STM32_FILTER_POS)` | `fDTS/16` | 5。 |
| `COUNTER_CAPTURE_STM32_FILTER_DTS_DIV16_N6` | `(11 << COUNTER_CAPTURE_STM32_FILTER_POS)` | `fDTS/16` | 6。 |
| `COUNTER_CAPTURE_STM32_FILTER_DTS_DIV16_N8` | `(12 << COUNTER_CAPTURE_STM32_FILTER_POS)` | `fDTS/16` | 8。 |
| `COUNTER_CAPTURE_STM32_FILTER_DTS_DIV32_N5` | `(13 << COUNTER_CAPTURE_STM32_FILTER_POS)` | `fDTS/32` | 5。 |
| `COUNTER_CAPTURE_STM32_FILTER_DTS_DIV32_N6` | `(14 << COUNTER_CAPTURE_STM32_FILTER_POS)` | `fDTS/32` | 6。 |
| `COUNTER_CAPTURE_STM32_FILTER_DTS_DIV32_N8` | `(15 << COUNTER_CAPTURE_STM32_FILTER_POS)` | `fDTS/32` | 8。 |
