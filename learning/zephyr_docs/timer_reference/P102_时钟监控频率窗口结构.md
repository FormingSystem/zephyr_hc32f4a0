# 第102章\_时钟监控频率窗口结构

原文：[structclock__monitor__window__cfg](https://docs.zephyrproject.org/latest/doxygen/html/structclock__monitor__window__cfg.html)。读取日期：2026-10-13，`latest`。

结构体`clock_monitor_window_cfg`配置`CLOCK_MONITOR_MODE_WINDOW`窗口模式（Window Mode），头文件为`zephyr/drivers/clock_monitor.h`。

## 102.1\_结构声明

```c
struct clock_monitor_window_cfg {
        uint32_t expected_hz;
        uint32_t tolerance_ppm;
        uint32_t window_ns;
};
```

## 102.2\_标称频率、允许偏差与时间窗口

| 成员 | 类型 | 含义 |
| --- | --- | --- |
| `expected_hz` | `uint32_t` | 被监控时钟的标称预期频率（Nominal Expected Frequency），单位为赫兹（Hertz，Hz） |
| `tolerance_ppm` | `uint32_t` | 可接受偏差（Acceptable Deviation），以百万分率（Parts Per Million，ppm）表示；为正负`±`偏差值 |
| `window_ns` | `uint32_t` | 测量窗口持续时间（Measurement Window Duration），单位为纳秒（Nanosecond，ns），**必须大于0** |

顶层配置见[时钟监控配置结构](P100_时钟监控配置结构.md)，连续阈值检查及事件标志见[时钟监控公共接口](P098_时钟监控公共接口.md)，完整源码见[时钟监控完整头文件](P106_时钟监控完整头文件.md)。
