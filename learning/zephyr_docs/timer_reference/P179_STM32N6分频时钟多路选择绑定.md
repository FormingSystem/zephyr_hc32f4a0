# 第179章\_STM32N6分频时钟多路选择绑定

<a id="dtbinding-st-stm32n6-ic-clock-mux"></a>

原文：[st,stm32n6-ic-clock-mux](https://docs.zephyrproject.org/latest/build/dts/api/bindings/clock/st,stm32n6-ic-clock-mux.html)。读取日期：2026-10-13，`latest`。

`st,stm32n6-ic-clock-mux`是 STMicroelectronics 的设备树绑定（Devicetree Binding）。

本绑定描述STM32N6的IC分频时钟多路选择器（Divider IC Multiplexer）。该节点选择一个时钟输入（Clock Input）和一个分频器（Divider）；IC为原页保留的硬件模块标识。

采用此兼容字符串的开发板见[官方筛选目录](https://docs.zephyrproject.org/latest/boards/index.html#compatibles=st,stm32n6-ic-clock-mux)。

## 179.1\_配置说明与官方示例

原例修改标签为`ic6`的节点，将`pll-src`设为2以选用锁相环（Phase-Locked Loop，PLL）PLL2，并将`ic-div`设为16，把输入时钟除以16；`status = "okay"`表示节点可用。设备树源码（Devicetree Source，DTS）原例如下：

```dts
  &ic6 {
    pll-src = <2>;
    ic-div = <16>;
    status = "okay";
  };
```

译注：原例写有`status`，但本页基础属性列表为空；这里保留该示例与列表的原貌，不把其他绑定的通用属性整表移入本页。

## 179.2\_节点专用属性

属性类型：`int`为整数，`boolean`为布尔属性，`string`为字符串，`string-array`为字符串数组，`array`为数值数组，`compound`为复合类型；`phandle`为节点引用（Phandle），`phandles`为节点引用列表，`phandle-array`为节点引用与说明符单元数组。

| 属性 | 类型 | 中文说明与约束 |
| --- | --- | --- |
| `pll-src` | `int` | **必需**。用作时钟源的PLL：1对应PLL1，2对应PLL2，3对应PLL3，4对应PLL4；范围：`1 to 4` |
| `ic-div` | `int` | ICx整数分频系数（Integer Division Factor）；输入ICx频率除以本属性指定的值；范围：`1 to 256` |

本页没有已弃用的节点专用属性。
