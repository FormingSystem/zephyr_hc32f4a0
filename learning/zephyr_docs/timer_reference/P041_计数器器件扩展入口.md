# 第41章\_计数器器件扩展入口

原文：[group__counter__interface__ext](https://docs.zephyrproject.org/latest/doxygen/html/group__counter__interface__ext.html)。读取日期：2026-10-13，`latest`。

本页是器件专用计数器（Device-specific Counter）应用程序接口（Application Programming Interface，API）扩展的官方分组入口，列出一个主题和两个头文件。

## 41.1\_扩展主题

[STM32计数器捕获驱动接口](P042_STM32计数器扩展接口.md)提供输入捕获预分频（Input Capture Prescaler）和数字滤波（Digital Filter）的专用配置。

## 41.2\_扩展文件

| 文件 | 原页说明 |
| --- | --- |
| [mcp7940n.h](P045_MCP7940N寄存器与设置接口.md) | 基于MCP7940N实时时钟（Real-Time Clock，RTC）的计数器驱动寄存器布局（Register Layout）和API。 |
| [mcux_snvs_rtc.h](P020_MCUXSNVS实时时钟扩展参考.md) | 基于MCUX i.MX SNVS计数器API的RTC控制。 |

公共计数器接口见[对应章节](P022_计数器公共接口.md)。MCP7940N的寄存器、枚举、设置接口及全部结构参考已收录于第45至63章。
