# 第123章\_STM32时钟控制接口

原文：[group__clock__control__stm32](https://docs.zephyrproject.org/latest/doxygen/html/group__clock__control__stm32.html)。读取日期：2026-10-13，`latest`。

本页对应 STMicroelectronics STM32 器件的时钟控制（Clock Control）文档组。

## 123.1\_文件

官方页面列出头文件[`stm32_clock_control.h`](P124_STM32时钟控制头文件参考.md)，该文件包含 STM32 器件的时钟控制定义（Clock Control Definitions）。

原页的详细说明（Detailed Description）区没有额外正文，也没有单独列出宏、函数或数据结构成员。
