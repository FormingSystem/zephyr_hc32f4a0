# 第110章\_固定比例时钟绑定

<a id="dtbinding-fixed-factor-clock"></a>

原文：[fixed-factor-clock](https://docs.zephyrproject.org/latest/build/dts/api/bindings/clock/fixed-factor-clock.html)。读取日期：2026-10-13，`latest`。

`fixed-factor-clock`是通用或厂商无关（Generic or Vendor-independent）的设备树绑定（Devicetree Binding）。

它描述通用固定比例时钟提供者（Generic Fixed-factor Clock Provider）。

采用此兼容字符串的开发板见[官方筛选目录](https://docs.zephyrproject.org/latest/boards/index.html#compatibles=fixed-factor-clock)。

属性类型：`int`为整数，`boolean`为布尔属性，`string`为字符串，`string-array`为字符串数组，`array`为数值数组，`compound`为复合类型；`phandle`为节点引用（Phandle），`phandles`为节点引用列表，`phandle-array`为节点引用与说明符单元数组。

## 110.1\_节点专用属性

| 属性 | 类型 | 中文说明与约束 |
| --- | --- | --- |
| `clock-div` | `int` | 固定时钟分频系数（Fixed Clock Divider） |
| `clock-mult` | `int` | 固定时钟倍频系数（Fixed Clock Multiplier） |
| `#clock-cells` | `int` | **必需**。时钟说明符（Clock Specifier）所需的单元数量；固定值：`0` |

本页没有已弃用的节点专用属性。

## 110.2\_基础属性

以下属性继承自基础绑定（Base Binding），是可用于许多节点的通用定义，**并非全部一定适用于本兼容字符串**。

| 属性 | 类型 | 中文说明与约束 |
| --- | --- | --- |
| `clocks` | `phandle-array` | 输入时钟源（Input Clock Source） |
