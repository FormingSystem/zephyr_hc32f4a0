# 第154章\_STM32H7锁相环时钟绑定

<a id="dtbinding-st-stm32h7-pll-clock"></a>

原文：[st,stm32h7-pll-clock](https://docs.zephyrproject.org/latest/build/dts/api/bindings/clock/st,stm32h7-pll-clock.html)。读取日期：2026-10-13，`latest`。

`st,stm32h7-pll-clock`是 STMicroelectronics 的设备树绑定（Devicetree Binding），描述STM32H7主PLL节点。PLL为锁相环（Phase-Locked Loop），VCO为压控振荡器（Voltage-Controlled Oscillator）。

采用此兼容字符串的开发板见[官方筛选目录](https://docs.zephyrproject.org/latest/boards/index.html#compatibles=st,stm32h7-pll-clock)。

## 154.1\_输入源与频率计算

输入分频（Input Division）、VCO倍频（Multiplication）和输出分频（Output Division）共同决定PLL输出频率。以下频率公式保持原文；`f`表示频率（Frequency），MHz为兆赫（Megahertz），GHz为吉赫（Gigahertz），`with`引出VCO频率关系。

此绑定可描述3个PLL：`PLL1`为主PLL（Main PLL），另有`PLL2`和`PLL3`。输入可选高速外部时钟（High-speed External Clock，HSE）节点`clk_hse`、高速内部时钟（High-speed Internal Clock，HSI）节点`clk_hsi`或内部校准时钟（Calibrated Internal Clock，CSI）节点`clk_csi`。输入允许范围为**1至16 MHz**，通过`PLLM`分频系数将输入调整到此范围。

**当前只支持PLL1和PLL3**。上文描述可表示的PLL种类，不代表PLL2已受支持。

每个PLL最多有3路输出。`PLL_Px`、`PLL_Qx`、`PLL_Rx`分别除以`PLLPx`、`PLLQx`、`PLLRx`，输出标识为`pllx_p_ck`、`pllx_q_ck`、`pllx_r_ck`；其中`pll1_p_ck`供系统时钟（System Clock）`sys_ck`使用。`REFx_CK`为公式中的参考输入时钟，`PLLNx`为倍频系数，`PLLMx`为输入分频系数，x表示相应PLL实例。

```text
  f(PLL_Px) = f(VCOx clock) / PLLPx   -> pllx_p_ck ((pll1_p_ck : sys_ck))
  f(PLL_Qx) = f(VCOx clock) / PLLQx   -> pllx_q_ck
  f(PLL_Rx) = f(VCOx clock) / PLLRx   -> pllx_r_ck

    with f(VCOx clock) = f(REFx_CK) × (PLLNx / PLLMx)
```

PLL最大输出频率取决于具体器件；详细限制应查对应产品的参考手册（Reference Manual）和数据手册（Data Sheet）。本页没有给出统一上限。

## 154.2\_节点专用属性

属性类型：`int`为整数，`boolean`为布尔属性，`string`为字符串，`string-array`为字符串数组，`array`为数值数组，`compound`为复合类型；`phandle`为节点引用（Phandle），`phandles`为节点引用列表，`phandle-array`为节点引用与说明符单元数组。

| 属性 | 类型 | 中文说明与约束 |
| --- | --- | --- |
| `#clock-cells` | `int` | **必需**。时钟说明符（Clock Specifier）所需的单元数量；固定值：`0` |
| `div-m` | `int` | **必需**。PLLx输入时钟分频系数；范围：`1 to 63` |
| `mul-n` | `int` | **必需**。主PLL的VCOx倍频系数；范围：`4 to 512` |
| `div-p` | `int` | `pllx_p_ck`输出分频系数。**PLL1的P分频系数必须为1或偶数**；范围：`1 to 128` |
| `div-q` | `int` | `pllx_q_ck`输出分频系数；范围：`1 to 128` |
| `div-r` | `int` | `pllx_r_ck`输出分频系数；范围：`1 to 128` |
| `fracn` | `int` | PLLx的小数值（Fractional Value）`FRACN`；范围：`0 to 8191` |

本页没有已弃用的节点专用属性。

## 154.3\_基础属性

以下31项属性继承自基础绑定（Base Binding），**并非全部一定适用于本兼容字符串**。表中涉及中断（Interrupt）、时钟（Clock）、直接存储器访问（Direct Memory Access，DMA）、输入输出（Input/Output，I/O）、邮箱（Mailbox，MBOX）、处理器间消息（Inter-Processor Messaging，IPM）、电源域（Power Domain）和硬件自旋锁（Hardware Spinlock）。

| 属性 | 类型 | 中文说明与约束 |
| --- | --- | --- |
| `clocks` | `phandle-array` | **必需**。设备的时钟提供者（Clock Provider）信息，通常应遵守[dt-schema时钟绑定约定](https://github.com/devicetree-org/dt-schema/blob/main/dtschema/schemas/clock/clock.yaml) |
| `status` | `string` | 节点代表的硬件或其他资源的运行状态（Operational Status）。`okay` 表示资源可运行，例如可供驱动使用；`disabled` 表示资源不可运行，系统应将其视为不存在。参见《设备树规范》（Devicetree Specification）v0.4第2.3.4节；合法值：`okay, disabled, reserved, fail, fail-sss` |
| `compatible` | `string-array` | **必需**。字符串列表定义节点代表的硬件或其他资源类型。设备驱动通过特定兼容字符串（Compatible String）寻找应由自身管理的设备。推荐格式为 `vendor,device`：前者是厂商简称，后者通常来自数据手册。多个值从最具体到最通用排列，让具体设备匹配当前可用的最具体驱动。参见规范v0.4第2.3.1节 |
| `reg` | `array` | 给出寻址设备所需的信息，具体含义随设备及 `compatible` 而变化。通常是一组地址与长度对，每对称为寄存器块（Register Block），数值通常写为十六进制。参见规范v0.4第2.3.6节及[重要属性](../devicetree/P003_语法与结构.md) |
| `reg-names` | `string-array` | 为 `reg` 中每个寄存器块提供可选名称；原始例子及逐项说明见本层表后 |
| `ranges` | `compound` | 定义总线子地址空间与总线节点父地址空间之间的映射或转换。通常为空，或由子总线地址、父总线地址、长度三元组组成。**空属性表示两侧地址空间相同、不需要转换；总线节点没有此属性则认为子、父地址空间之间不存在映射**。参见规范v0.4第2.3.8节 |
| `interrupts` | `array` | 设备产生的中断，编码为一个或多个中断说明符；格式由设备在中断树中的位置决定，具有相同 `interrupt-parent` 的设备使用相同格式；中断（Interrupt）及中断映射见《设备树规范》v0.4第2.4节 |
| `interrupts-extended` | `compound` | 扩展中断说明符，可替代 `interrupts`；中断（Interrupt）及中断映射见《设备树规范》v0.4第2.4节 |
| `interrupt-names` | `string-array` | 设备各中断的可选名称；中断本身在 `interrupts` 或 `interrupts-extended` 中定义；中断（Interrupt）及中断映射见《设备树规范》v0.4第2.4节 |
| `interrupt-parent` | `phandle` | 若存在，引用负责处理此设备所产生中断的节点；中断（Interrupt）及中断映射见《设备树规范》v0.4第2.4节 |
| `label` | `string` | 描述设备的可读字符串；除逐案确有需要外，已不推荐使用此属性。参见规范 v0.4 第 4.1.2 节“其他属性” |
| `clock-names` | `string-array` | `clocks` 中各时钟提供者的名称；通用说明称其为可选名称，是否必须填写以本层的必需标记为准 |
| `#address-cells` | `int` | 子节点 `reg` 地址字段所用的 `<u32>` 单元数量；`<u32>` 为32位无符号单元，参见《设备树规范》v0.4第2.3.5节 |
| `#size-cells` | `int` | 子节点 `reg` 大小字段所用的 `<u32>` 单元数量；`<u32>` 为32位无符号单元，参见《设备树规范》v0.4第2.3.5节 |
| `dma-coherent` | `boolean` | 表示设备支持一致性 DMA 操作，见规范 v0.4 第 2.3.10 节 |
| `dmas` | `phandle-array` | 与设备相关的 DMA 通道说明符 |
| `dma-names` | `string-array` | `dmas` 中各 DMA 通道说明符的可选名称 |
| `dma-ranges` | `compound` | 定义总线物理地址空间与其父总线物理地址空间之间的映射或转换，见规范 v0.4 第 2.3.9 节 |
| `io-channels` | `phandle-array` | 与设备相关的 I/O 通道说明符 |
| `io-channel-names` | `string-array` | `io-channels` 中各通道说明符的可选名称 |
| `mboxes` | `phandle-array` | 与设备相关的邮箱/IPM 通道说明符 |
| `mbox-names` | `string-array` | `mboxes` 中各邮箱说明符的可选名称 |
| `power-domains` | `phandle-array` | 与设备相关的电源域说明符 |
| `power-domain-names` | `string-array` | `power-domains` 中各电源域说明符的可选名称 |
| `#power-domain-cells` | `int` | `power-domains` 属性中的单元数量 |
| `hwlocks` | `phandle-array` | 与设备相关的硬件自旋锁（Hardware Spinlock）标识 |
| `hwlock-names` | `string-array` | `hwlocks` 中各锁说明符的可选名称 |
| `zephyr,deferred-init` | `boolean` | 延迟初始化（Deferred Initialization）：启动时不自动初始化设备，应由应用使用 `device_init()` 手动初始化 |
| `wakeup-source` | `boolean` | 标记设备可用作唤醒源（Wakeup Source）。设置该属性后，设备中会设置专门标志，通知系统此设备有唤醒能力。唤醒功能默认禁用，即中断不会唤醒系统；必要时可在运行期间启用 |
| `zephyr,pm-device-runtime-auto` | `boolean` | 初始化函数执行后，自动为设备配置运行时电源管理（Runtime Power Management） |
| `zephyr,disabling-power-states` | `phandles` | 会关闭该设备电源的电源状态（Power State）列表 |

## 154.4\_寄存器块命名原例

以下为`reg-names`的原设备树源码（Devicetree Source，DTS）示例；`uart`为通用异步收发器（Universal Asynchronous Receiver/Transmitter，UART）节点。

```dts
  / {
       soc {
           #address-cells = <1>;
           #size-cells = <1>;

           uart@1000 {
               reg = <0x1000 0x2000>, <0x3000 0x4000>;
               reg-names = "foo", "bar";
           };
       };
  };
```

`uart@1000`包含两个寄存器块（Register Block）：`foo`基址`0x1000`、大小`0x2000`；`bar`基址`0x3000`、大小`0x4000`。
