# 第6章\_看门狗公共头文件参考

原文：[watchdog_8h](https://docs.zephyrproject.org/latest/doxygen/html/watchdog_8h.html)。读取日期：2026-10-13，`latest`。

`zephyr/drivers/watchdog.h`是看门狗（Watchdog）驱动应用程序接口（Application Programming Interface，API）的主头文件。包含类型、工具宏、设备及生成的系统调用（System Call）声明：

```c
#include <zephyr/types.h>
#include <zephyr/sys/util.h>
#include <zephyr/device.h>
#include <zephyr/syscalls/watchdog.h>
```

## 6.1\_结构体与配置宏

原页列出的结构体为`wdt_window`（[超时窗口](P003_看门狗喂狗窗口结构.md)）、`wdt_timeout_cfg`（[超时配置](P004_看门狗超时配置结构.md)）和`wdt_driver_api`（[驱动操作](P005_看门狗驱动操作结构.md)）。选项与行为标志如下：
| 宏 | 原值 | 含义 |
| --- | --- | --- |
| `WDT_OPT_PAUSE_IN_SLEEP` | `BIT(0)` | 中央处理器（Central Processing Unit，CPU）处于睡眠状态（Sleep State）时暂停看门狗计时器。 |
| `WDT_OPT_PAUSE_HALTED_BY_DBG` | `BIT(1)` | CPU被调试器（Debugger）暂停时，暂停看门狗计时器。 |
| `WDT_FLAG_RESET_NONE` | `(0 << WDT_FLAG_RESET_SHIFT)` | 不复位（No Reset）。 |
| `WDT_FLAG_RESET_CPU_CORE` | `(1 << WDT_FLAG_RESET_SHIFT)` | 复位CPU核心（CPU Core）。 |
| `WDT_FLAG_RESET_SOC` | `(2 << WDT_FLAG_RESET_SHIFT)` | 复位片上系统（System on Chip，SoC）。 |

## 6.2\_回调及驱动类型

第一个类型是看门狗回调（Callback），后四个类型依次设置实例、禁用实例、安装超时和喂狗。参数说明见[公共接口](P001_看门狗公共接口.md)与[后端接口](P002_看门狗驱动后端接口.md)。

```c
typedef void (*wdt_callback_t)(const struct device *dev, int channel_id);
typedef int (*wdt_api_setup)(const struct device *dev, uint8_t options);
typedef int (*wdt_api_disable)(const struct device *dev);
typedef int (*wdt_api_install_timeout)(const struct device *dev,
                                       const struct wdt_timeout_cfg *cfg);
typedef int (*wdt_api_feed)(const struct device *dev, int channel_id);
```

## 6.3\_公共函数

原文件参考页的四个完整函数签名如下，顺序与前述驱动操作相对应。

```c
int wdt_setup(const struct device *dev, uint8_t options);
int wdt_disable(const struct device *dev);
static int wdt_install_timeout(const struct device *dev, const struct wdt_timeout_cfg *cfg);
int wdt_feed(const struct device *dev, int channel_id);
```

`wdt_install_timeout`必须在`wdt_setup`之前调用；安装成功返回通道ID（Channel ID），该ID用于`wdt_feed`。完整调用条件、错误码及禁用后的限制见[公共接口](P001_看门狗公共接口.md)。全部可见定义保存在[源码页](P007_看门狗公共头文件源码.md)。
