# 第99章\_时钟监控驱动后端接口

原文：[group__clock__monitor__interface__backend](https://docs.zephyrproject.org/latest/doxygen/html/group__clock__monitor__interface__backend.html)。读取日期：2026-10-13，`latest`。

本页包含实现时钟监控（Clock Monitor）驱动所需的应用程序编程接口（Application Programming Interface，API）类型、回调签名（Callback Signature）和辅助项。头文件为`zephyr/drivers/clock_monitor.h`。

驱动操作结构（Driver Operations）见[时钟监控驱动操作结构](P104_时钟监控驱动操作结构.md)，公共契约见[时钟监控公共接口](P098_时钟监控公共接口.md)。

## 99.1\_配置时钟监控器回调

```c
typedef int (*clock_monitor_api_configure)(const struct device *dev,
                                           const struct clock_monitor_config *cfg);
```

用于配置时钟监控器的回调接口。

## 99.2\_轮询最近一次测量频率回调

```c
typedef int (*clock_monitor_api_get_rate)(const struct device *dev,
                                          uint32_t *rate_hz);
```

用于轮询最近一次测量频率的回调接口。

## 99.3\_切换参考／目标时钟输入回调

```c
typedef int (*clock_monitor_api_set_source)(const struct device *dev,
                                            uint32_t reference,
                                            uint32_t target);
```

用于切换参考／目标时钟输入的回调接口。

## 99.4\_启动所配置的模式回调

```c
typedef int (*clock_monitor_api_start)(const struct device *dev);
```

用于启动所配置的模式的回调接口。

## 99.5\_停止时钟监控器回调

```c
typedef int (*clock_monitor_api_stop)(const struct device *dev);
```

用于停止时钟监控器的回调接口。停止操作可安全地在中断服务程序（Interrupt Service Routine，ISR）中调用。

完整源码见[时钟监控完整头文件](P106_时钟监控完整头文件.md)。
