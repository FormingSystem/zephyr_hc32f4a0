# 第124章\_STM32时钟控制头文件参考

原文：[stm32__clock__control_8h](https://docs.zephyrproject.org/latest/doxygen/html/stm32__clock__control_8h.html)。读取日期：2026-10-13，`latest`。

`zephyr/drivers/clock_control/stm32_clock_control.h`包含 STMicroelectronics STM32 器件的时钟控制定义（Clock Control Definitions）。

## 124.1\_用途与接口边界

**这个头文件中的符号是从设备树（Devicetree）派生的时钟配置内部定义，供 STM32 时钟驱动使用；它们不属于应用程序公共应用程序编程接口（Public Application API）。**

这是官方详细说明中的明确限制。阅读内部宏有助于理解设备树配置如何传递给驱动，但不能据此将所有内部符号视为面向应用的公共接口。
