# 第32章\_计数器捕获接口

原文：[group__counter__capture](https://docs.zephyrproject.org/latest/doxygen/html/group__counter__capture.html)。读取日期：2026-10-13，`latest`。

计数器捕获（Counter Capture）应用程序接口（Application Programming Interface，API）用于配置捕获通道、注册回调以及启用或禁用捕获。该接口为**实验性（Experimental）**：随着开发推进，API可能发生变化。所有函数由`zephyr/drivers/counter.h`声明。

## 32.1\_配置32位捕获及回调

`counter_capture_configure`配置通道的边沿极性（Edge Polarity）与捕获模式（Capture Mode）：单次（Single-shot）或连续（Continuous），并注册用于传递捕获计数值（Captured Tick Values）的回调（Callback）。

```c
static inline int counter_capture_configure(const struct device *dev, uint8_t chan_id,
    counter_capture_flags_t flags, counter_capture_cb_t cb, void *user_data);
```

| 参数 | 含义 |
| --- | --- |
| `dev` | 驱动实例的设备结构指针。 |
| `chan_id` | 通道标识（Channel ID）。 |
| `flags` | 捕获配置标志；原参数说明称为`COUNTER_CAPTURE_FLAGS`，各标志见[公共接口](P022_计数器公共接口.md)和[边沿常量](P037_计数器捕获边沿常量参考.md)。 |
| `cb` | 回调函数引用。 |
| `user_data` | 传给回调函数的用户参数。 |

仅在启用`CONFIG_COUNTER_CAPTURE`时可用。成功返回0，失败返回负错误码（Negative Error Code）。

## 32.2\_输入源由设备绑定决定

捕获通道到输入源（Input Source）的映射依赖厂商，例如物理焊盘（Physical Pad）或内部信号（Internal Signal），不属于此API。多数片上系统（System-on-Chip，SoC）的通道与引脚关联由硬件固定，通过设备树（Devicetree）公开，通常使用引脚控制（Pin Control，pinctrl）或计数器节点的专用属性。如何选择输入，应查阅该计数器的设备树绑定（Binding）。

原文说明：如果具有可配置输入互连的SoC确有需要，未来版本可能加入运行时输入源选择调用，例如`counter_capture_set_source`，或给本函数增加源参数。**这里描述的是未来可能的变化，不是现有接口。** 此说明同样适用于64位配置函数。

## 32.3\_从设备树规格配置32位捕获

`counter_capture_configure_dt`使用计数器捕获设备树规格（Counter Capture DT Specification）配置通道并注册回调。

```c
static inline int counter_capture_configure_dt(const struct counter_capture_dt_spec *spec,
    counter_capture_cb_t cb, void *user_data);
```

`spec`指向[捕获设备树规格](P033_计数器捕获设备树规格.md)；`cb`为回调引用；`user_data`传给回调。仅在`CONFIG_COUNTER_CAPTURE`启用时可用。成功返回0，失败返回负错误码。

## 32.4\_配置64位捕获及回调

`counter_capture_configure_64`设置相同的边沿极性和单次／连续捕获模式，注册传递64位捕获计数值的回调。

```c
static inline int counter_capture_configure_64(const struct device *dev, uint8_t chan_id,
    counter_capture_flags_t flags, counter_capture_cb_64_t cb, void *user_data);
```

参数`dev`、`chan_id``flags`、`cb``user_data`分别是设备指针、通道标识、捕获配置标志、64位回调引用和用户参数。输入源映射限制见本章32.2节。必须同时启用`CONFIG_COUNTER_CAPTURE`与`CONFIG_COUNTER_64BITS_TICKS`。成功返回0，失败返回负错误码。

`counter_capture_configure_64_dt`从设备树规格配置通道并注册64位回调：

```c
static inline int counter_capture_configure_64_dt(const struct counter_capture_dt_spec *spec,
    counter_capture_cb_64_t cb, void *user_data);
```

`spec`指向捕获规格；`cb`为64位回调引用；`user_data`传给回调。同样要求上述两个配置选项同时启用，成功返回0，失败返回负错误码。

## 32.5\_启用通道捕获

`counter_enable_capture`函数启用指定通道的捕获；`counter_enable_capture_dt`函数通过设备树规格完成相同操作。

```c
int counter_enable_capture(const struct device *dev, uint8_t chan_id);
static inline int counter_enable_capture_dt(const struct counter_capture_dt_spec *spec);
```

前者的`dev`指向驱动实例设备，`chan_id`为通道标识；后者的`spec`指向捕获设备树规格。两者都要求`CONFIG_COUNTER_CAPTURE`，成功返回0，失败返回负错误码。

## 32.6\_禁用通道捕获

`counter_disable_capture`函数禁用指定通道捕获；`counter_disable_capture_dt`函数使用设备树规格禁用。

```c
int counter_disable_capture(const struct device *dev, uint8_t chan_id);
static inline int counter_disable_capture_dt(const struct counter_capture_dt_spec *spec);
```

`dev`与`chan_id`分别为设备指针和通道标识；`spec`为捕获设备树规格指针。两者都要求`CONFIG_COUNTER_CAPTURE`，成功返回0，失败返回负错误码。完整代码见[计数器公共头文件源码](P031_计数器公共头文件源码.md)。
