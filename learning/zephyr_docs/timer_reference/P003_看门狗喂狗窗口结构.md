# 第3章\_看门狗喂狗窗口结构

原文：[structwdt__window](https://docs.zephyrproject.org/latest/doxygen/html/structwdt__window.html)。读取日期：2026-10-13，`latest`。

结构体`wdt_window`描述看门狗（Watchdog）的超时窗口（Timeout Window），定义于：

```c
#include <zephyr/drivers/watchdog.h>
```

## 3.1\_窗口上下限

两个字段的单位均为毫秒（Millisecond，ms），类型均为32位无符号整数`uint32_t`。

| 类型 | 字段 | 含义 |
| --- | --- | --- |
| `uint32_t` | `min` | 看门狗喂狗超时的下限（Lower Limit）。 |
| `uint32_t` | `max` | 看门狗喂狗超时的上限（Upper Limit）。 |

## 3.2\_窗口要求与取整

每个已安装的超时都必须在指定时间窗口内喂狗（Feed），否则会触发看门狗。**如果看门狗实例不支持窗口超时，则`min`必须等于0。**

如果指定的值无法被硬件精确设置，**总是向上取整（Round Up）**。该窗口作为`wdt_timeout_cfg.window`使用，见[超时配置结构](P004_看门狗超时配置结构.md)。
