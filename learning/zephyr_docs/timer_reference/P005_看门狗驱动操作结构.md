# 第5章\_看门狗驱动操作结构

原文：[structwdt__driver__api](https://docs.zephyrproject.org/latest/doxygen/html/structwdt__driver__api.html)。读取日期：2026-10-13，`latest`。

`wdt_driver_api`是每个看门狗（Watchdog）驱动需要定义的驱动应用程序接口（Driver Application Programming Interface，Driver API）结构。它包含驱动实现的操作函数指针，也可容纳驱动专用的常量数据。头文件为：

```c
#include <zephyr/drivers/watchdog.h>
```

## 5.1\_必填驱动操作

原文中必填（Required，REQ）成员必须由驱动设置，可选（Optional，OPT）成员可以不设置。本结构的四个成员全部标为REQ。

| 类型 | 字段 | 要求与作用 |
| --- | --- | --- |
| `wdt_api_setup` | `setup` | 必填；设置看门狗实例。 |
| `wdt_api_disable` | `disable` | 必填；禁用看门狗实例。 |
| `wdt_api_install_timeout` | `install_timeout` | 必填；安装新的超时。 |
| `wdt_api_feed` | `feed` | 必填；给指定的看门狗超时喂狗（Feed）。 |

每个函数指针类型的完整签名见[驱动后端接口](P002_看门狗驱动后端接口.md)，操作语义见[公共接口](P001_看门狗公共接口.md)。
