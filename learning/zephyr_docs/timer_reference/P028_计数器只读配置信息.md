# 第28章\_计数器只读配置信息

原文：[structcounter__config__info](https://docs.zephyrproject.org/latest/doxygen/html/structcounter__config__info.html)。读取日期：2026-10-13，`latest`。

结构体`counter_config_info`保存计数器（Counter）的通用能力信息（Generic Features），定义于：

```c
#include <zephyr/drivers/counter.h>
```

## 28.1\_原参考页列出的字段

原结构体参考页展示以下四个字段：

| 类型 | 字段 | 含义 |
| --- | --- | --- |
| `uint32_t` | `freq` | 统计同步事件（Synchronous Events）时，源时钟的频率（Frequency）。 |
| `uint32_t` | `max_top_value` | 使计数器复位的最大／默认顶值（Top Value）；复位表现为清零或重载（Reload）。 |
| `uint8_t` | `flags` | 能力标志，见`COUNTER_CONFIG_INFO_COUNT_UP`。 |
| `uint8_t` | `channels` | 可用于设置告警（Alarm）的通道数量，参见`counter_set_channel_alarm`。 |

## 28.2\_源码中的64位条件布局

> 译注：上表保留原结构体参考页的展示类型，实际布局还受Kconfig选项控制。启用`CONFIG_COUNTER_64BITS_FREQ`时，`freq`是`uint64_t`；否则是`uint32_t`。启用`CONFIG_COUNTER_64BITS_TICKS`时，顶值包含`max_top_value_64`的64位联合体视图及32位`max_top_value`与保留字段`reserved`。`CONFIG_BIG_ENDIAN`控制两段32位成员的排列，以适配大端序（Big Endian）。

因此不能把参考页的默认32位展示当作所有构建下的固定布局。完整条件定义见[公共头文件源码](P031_计数器公共头文件源码.md)，最大顶值的32／64位读取方式见[公共接口](P022_计数器公共接口.md)。
