# 第35章\_计数器捕获设备树头文件参考

原文：[devicetree_2counter-capture_8h](https://docs.zephyrproject.org/latest/doxygen/html/devicetree_2counter-capture_8h.html)。读取日期：2026-10-13，`latest`。

`zephyr/devicetree/counter-capture.h`是计数器捕获（Counter Capture）设备树（Devicetree）公共宏接口头文件。本页完整列出文件参考中的24个宏；逐宏参数、返回值及原示例见[设备树宏详解](P034_计数器捕获设备树宏.md)。

## 35.1\_按节点取得控制器、单元、通道和标志

| 完整宏签名 | 原页用途或等价展开 |
| --- | --- |
| `DT_COUNTER_CAPTURES_CTLR_BY_IDX(node_id, counter_capture_pha, idx)` | 按索引取得计数器控制器节点标识；展开为`DT_PHANDLE_BY_IDX(node_id, counter_capture_pha, idx)`。 |
| `DT_COUNTER_CAPTURES_CTLR_BY_NAME(node_id, counter_capture_pha, name)` | 按名称取得计数器控制器节点标识；展开为`DT_PHANDLE_BY_NAME(node_id, counter_capture_pha, name)`。 |
| `DT_COUNTER_CAPTURES_CTLR(node_id, counter_capture_pha)` | 从索引0取得计数器控制器节点标识；展开为`DT_COUNTER_CAPTURES_CTLR_BY_IDX(node_id, counter_capture_pha, 0)`。 |
| `DT_COUNTER_CAPTURES_CELL_BY_IDX(node_id, counter_capture_pha, idx, cell)` | 按索引取得指定单元值；展开为`DT_PHA_BY_IDX(node_id, counter_capture_pha, idx, cell)`。 |
| `DT_COUNTER_CAPTURES_CELL_BY_NAME(node_id, counter_capture_pha, name, cell)` | 按名称取得指定单元值；展开为`DT_PHA_BY_NAME(node_id, counter_capture_pha, name, cell)`。 |
| `DT_COUNTER_CAPTURES_CELL(node_id, counter_capture_pha, cell)` | 从索引0取得指定单元值；展开为`DT_COUNTER_CAPTURES_CELL_BY_IDX(node_id, counter_capture_pha, 0, cell)`。 |
| `DT_COUNTER_CAPTURES_CHANNEL_BY_IDX(node_id, counter_capture_pha, idx)` | 按索引取得通道单元值；展开为`DT_COUNTER_CAPTURES_CELL_BY_IDX(node_id, counter_capture_pha, idx, channel)`。 |
| `DT_COUNTER_CAPTURES_CHANNEL_BY_NAME(node_id, counter_capture_pha, name)` | 按名称取得通道单元值；展开为`DT_COUNTER_CAPTURES_CELL_BY_NAME(node_id, counter_capture_pha, name, channel)`。 |
| `DT_COUNTER_CAPTURES_CHANNEL(node_id, counter_capture_pha)` | 从索引0取得通道单元值；展开为`DT_COUNTER_CAPTURES_CHANNEL_BY_IDX(node_id, counter_capture_pha, 0)`。 |
| `DT_COUNTER_CAPTURES_FLAGS_BY_IDX(node_id, counter_capture_pha, idx)` | 按索引取得标志单元值；展开为`DT_PHA_BY_IDX_OR(node_id, counter_capture_pha, idx, flags, 0)`。 |
| `DT_COUNTER_CAPTURES_FLAGS_BY_NAME(node_id, counter_capture_pha, name)` | 按名称取得标志单元值；展开为`DT_PHA_BY_NAME_OR(node_id, counter_capture_pha, name, flags, 0)`。 |
| `DT_COUNTER_CAPTURES_FLAGS(node_id, counter_capture_pha)` | 从索引0取得标志单元值；展开为`DT_COUNTER_CAPTURES_FLAGS_BY_IDX(node_id, counter_capture_pha, 0)`。 |

## 35.2\_按驱动实例取得捕获信息

实例（Instance）由`DT_DRV_COMPAT`确定，编号参数为`inst`。

| 完整宏签名 | 原页用途或等价展开 |
| --- | --- |
| `DT_INST_COUNTER_CAPTURES_CTLR_BY_IDX(inst, counter_capture_pha, idx)` | 按索引取得计数器控制器节点标识；展开为`DT_COUNTER_CAPTURES_CTLR_BY_IDX(DT_DRV_INST(inst), counter_capture_pha, idx)`。 |
| `DT_INST_COUNTER_CAPTURES_CTLR_BY_NAME(inst, counter_capture_pha, name)` | 按名称取得计数器控制器节点标识；展开为`DT_COUNTER_CAPTURES_CTLR_BY_NAME(DT_DRV_INST(inst), counter_capture_pha, name)`。 |
| `DT_INST_COUNTER_CAPTURES_CTLR(inst, counter_capture_pha)` | 从索引0取得计数器控制器节点标识；展开为`DT_INST_COUNTER_CAPTURES_CTLR_BY_IDX(inst, counter_capture_pha, 0)`。 |
| `DT_INST_COUNTER_CAPTURES_CELL_BY_IDX(inst, counter_capture_pha, idx, cell)` | 按索引取得指定单元值；展开为`DT_COUNTER_CAPTURES_CELL_BY_IDX(DT_DRV_INST(inst), counter_capture_pha, idx, cell)`。 |
| `DT_INST_COUNTER_CAPTURES_CELL_BY_NAME(inst, counter_capture_pha, name, cell)` | 按名称取得指定单元值；展开为`DT_COUNTER_CAPTURES_CELL_BY_NAME(DT_DRV_INST(inst), counter_capture_pha, name, cell)`。 |
| `DT_INST_COUNTER_CAPTURES_CELL(inst, counter_capture_pha, cell)` | 从索引0取得指定单元值；展开为`DT_INST_COUNTER_CAPTURES_CELL_BY_IDX(inst, counter_capture_pha, 0, cell)`。 |
| `DT_INST_COUNTER_CAPTURES_CHANNEL_BY_IDX(inst, counter_capture_pha, idx)` | 按索引取得通道单元值；展开为`DT_INST_COUNTER_CAPTURES_CELL_BY_IDX(inst, counter_capture_pha, idx, channel)`。 |
| `DT_INST_COUNTER_CAPTURES_CHANNEL_BY_NAME(inst, counter_capture_pha, name)` | 按名称取得通道单元值；展开为`DT_INST_COUNTER_CAPTURES_CELL_BY_NAME(inst, counter_capture_pha, name, channel)`。 |
| `DT_INST_COUNTER_CAPTURES_CHANNEL(inst, counter_capture_pha)` | 从索引0取得通道单元值；展开为`DT_INST_COUNTER_CAPTURES_CHANNEL_BY_IDX(inst, counter_capture_pha, 0)`。 |
| `DT_INST_COUNTER_CAPTURES_FLAGS_BY_IDX(inst, counter_capture_pha, idx)` | 按索引取得标志单元值；展开为`DT_INST_COUNTER_CAPTURES_CELL_BY_IDX(inst, counter_capture_pha, idx, flags)`。 |
| `DT_INST_COUNTER_CAPTURES_FLAGS_BY_NAME(inst, counter_capture_pha, name)` | 按名称取得标志单元值；展开为`DT_INST_COUNTER_CAPTURES_CELL_BY_NAME(inst, counter_capture_pha, name, flags)`。 |
| `DT_INST_COUNTER_CAPTURES_FLAGS(inst, counter_capture_pha)` | 从索引0取得标志单元值；展开为`DT_INST_COUNTER_CAPTURES_FLAGS_BY_IDX(inst, counter_capture_pha, 0)`。 |

`CTLR`取得计数器控制器（Counter Controller）节点；`CELL`取得指定单元；`CHANNEL`取得通道（Channel）单元；`FLAGS`取得标志（Flags）单元。`BY_IDX`按索引选择，`BY_NAME`按名称选择，不带这两个后缀的宏选择索引0。

原文件参考页的简述把实例通道与标志宏定义为相应单元宏的等价调用。缺少标志时的默认值差异见[详解末尾译注](P034_计数器捕获设备树宏.md)；[源码页](P036_计数器捕获设备树头文件源码.md)保留全部原实现。
