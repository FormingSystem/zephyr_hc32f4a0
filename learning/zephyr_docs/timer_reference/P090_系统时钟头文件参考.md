# 第90章\_系统时钟头文件参考

原文：[clock_8h](https://docs.zephyrproject.org/latest/doxygen/html/clock_8h.html)。读取日期：2026-10-13，`latest`。

`zephyr/sys/clock.h`声明系统定时器设备驱动和使用定时功能的内核组件共用的变量，并提供读取、设置系统时钟和基于时钟睡眠的应用程序接口（Application Programming Interface，API）。原文件参考列出的包含项如下：

```c
#include <zephyr/sys/dlist.h>
#include <zephyr/sys/time_units.h>
#include <zephyr/sys/util.h>
#include <zephyr/toolchain.h>
#include <zephyr/types.h>
#include <zephyr/syscalls/clock.h>
```

## 90.1\_两种不透明类型与刻度类型

[`k_timeout_t`](P087_内核超时类型.md)为内核超时（Kernel Timeout）类型，[`k_timepoint_t`](P088_内核时间点类型.md)为内核时间点（Kernel Timepoint）类型。

`k_ticks_t`规定超时API的tick精度。原文件参考显示`typedef uint32_t k_ticks_t`，而源码的`CONFIG_TIMEOUT_64BIT`分支使用`int64_t`，详见[完整源码](P091_系统时钟头文件源码.md)。

## 90.2\_十七个公开宏

`K_TIMEOUT_EQ(a, b)`比较超时是否相等；`K_TICKS_FOREVER`为永久等待的tick值。时间单位常量与换算宏的全部原值如下：

| 宏 | 原值或展开式 | 用途 |
| --- | --- | --- |
| `K_TICKS_FOREVER` | `((k_ticks_t)(-1))` | 永久等待刻度值。 |
| `K_TIMEOUT_EQ(a, b)` | `((a).ticks == (b).ticks)` | 比较两个超时是否相等。 |
| `NSEC_PER_USEC` | `1000U` | 每微秒的纳秒数。 |
| `NSEC_PER_MSEC` | `1000000U` | 每毫秒的纳秒数。 |
| `USEC_PER_MSEC` | `1000U` | 每毫秒的微秒数。 |
| `MSEC_PER_SEC` | `1000U` | 每秒的毫秒数。 |
| `SEC_PER_MIN` | `60U` | 每分钟的秒数。 |
| `SEC_PER_HOUR` | `3600U` | 每小时的秒数。 |
| `SEC_PER_DAY` | `86400U` | 每天的秒数。 |
| `MIN_PER_HOUR` | `60U` | 每小时的分钟数。 |
| `HOUR_PER_DAY` | `24U` | 每天的小时数。 |
| `USEC_PER_SEC` | `((USEC_PER_MSEC) * (MSEC_PER_SEC))` | 每秒的微秒数。 |
| `NSEC_PER_SEC` | `((NSEC_PER_USEC) * (USEC_PER_MSEC) * (MSEC_PER_SEC))` | 每秒的纳秒数。 |
| `SYS_CLOCK_HW_CYCLES_TO_NS_AVG(X, NCYCLES)` | `(uint32_t)(k_cyc_to_ns_floor64(X) / NCYCLES)` | 把CPU时钟周期换算为纳秒并计算平均周期时间。 |
| `SYS_CLOCK_REALTIME` | `1` | 实时时钟（Real-time Clock），即墙上时钟（Wall Clock）。 |
| `SYS_CLOCK_MONOTONIC` | `4` | 单调时钟（Monotonic Clock）。 |
| `SYS_TIMER_ABSTIME` | `4` | 指定绝对超时（Absolute Timeout）的标志。 |

CPU为中央处理器（Central Processing Unit）。微秒（Microsecond）、纳秒（Nanosecond）、毫秒（Millisecond）及周期（Cycle）保持原单位，换算时的取整形式和结果类型没有改动。

## 90.3\_十个函数

原文件参考列出的函数签名如下：

```c
uint32_t sys_clock_tick_get_32(void);
int64_t sys_clock_tick_get(void);
k_timepoint_t sys_timepoint_calc(k_timeout_t timeout);
k_timeout_t sys_timepoint_timeout(k_timepoint_t timepoint);
static inline int sys_timepoint_cmp(k_timepoint_t a, k_timepoint_t b);
static inline bool sys_timepoint_expired(k_timepoint_t timepoint);
void sys_clock_getrtoffset(struct timespec *tp);
int sys_clock_gettime(int clock_id, struct timespec *tp);
int sys_clock_settime(int clock_id, const struct timespec *tp);
int sys_clock_nanosleep(int clock_id, int flags, const struct timespec *rqtp, struct timespec *rmtp);
```

| 函数 | 原页用途 |
| --- | --- |
| `sys_clock_tick_get_32` | 返回当前系统tick计数的低位部分。 |
| `sys_clock_tick_get` | 返回当前系统tick计数。 |
| `sys_timepoint_calc` | 计算时间点（Timepoint）。 |
| `sys_timepoint_timeout` | 返回距给定时间点的剩余时间。 |
| `sys_timepoint_cmp` | 比较两个时间点。 |
| `sys_timepoint_expired` | 指示时间点是否已经过期。 |
| `sys_clock_getrtoffset` | 获取实时钟相对于单调时钟的偏移（Offset）。 |
| `sys_clock_gettime` | 从指定时钟取得当前时间。 |
| `sys_clock_settime` | 设置指定时钟的当前时间。 |
| `sys_clock_nanosleep` | 按指定时钟睡眠给定时长。 |

逐项参数、错误返回和使用限制见[系统时钟公共接口](P086_系统时钟公共接口.md)。
