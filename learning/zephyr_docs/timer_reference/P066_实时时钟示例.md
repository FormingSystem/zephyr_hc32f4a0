# 第66章\_实时时钟示例

原文：[Real-Time Clock (RTC)](https://docs.zephyrproject.org/latest/samples/drivers/rtc/README.html)。读取日期：2026-10-13，`latest`。

本示例使用实时时钟（Real-Time Clock，RTC）驱动应用程序接口（Application Programming Interface，API），设置并读取RTC中的日期和时间，再显示到控制台（Console）。可以在支持RTC的开发板上构建并运行。[示例源码](https://github.com/zephyrproject-rtos/zephyr/tree/main/samples/drivers/rtc)位于`samples/drivers/rtc`，驱动概览见[实时时钟](../hardware/P018_实时时钟.md)。

## 66.1\_构建与烧录

按以下命令构建和烧录，将`stm32f3_disco`替换为所使用的开发板：

```sh
west build -b stm32f3_disco samples/drivers/rtc
west flash
```

原页还给出MIMXRT700 EVK两个处理器目标的命令。代码注释“From the root of the zephyr repository”表示从Zephyr仓库根目录执行：

```sh
# From the root of the zephyr repository
west build -b mimxrt700_evk/mimxrt798s/cm33_cpu0 samples/drivers/rtc
west flash
```

第二个处理器目标使用`west build -t ram`：

```sh
# From the root of the zephyr repository
west build -b mimxrt700_evk/mimxrt798s/cm33_cpu1 samples/drivers/rtc
west build -t ram
```

三个原命令块分别保留；第二个处理器目标的RAM运行目标没有改写成烧录命令。

## 66.2\_预期输出

```text
RTC date and time: 2024-11-17 04:19:00
RTC date and time: 2024-11-17 04:19:01

<repeats endlessly>
```

`RTC date and time`表示RTC日期与时间，示例从`2024-11-17 04:19:00`递增到下一秒；`<repeats endlessly>`表示持续重复。详细函数说明见[RTC公共接口](P009_实时时钟公共接口.md)。
