# 第2章\_看门狗驱动后端接口

原文：[group__watchdog__interface__backend](https://docs.zephyrproject.org/latest/doxygen/html/group__watchdog__interface__backend.html)。读取日期：2026-10-13，`latest`。

看门狗（Watchdog）驱动后端应用程序接口（Backend Application Programming Interface，Backend API）包含实现驱动所需的类型定义、回调（Callback）签名和辅助声明。均位于：

```c
#include <zephyr/drivers/watchdog.h>
```

## 2.1\_四种驱动操作类型

四个函数指针类型分别用于设置实例、禁用实例、安装新超时和给指定超时喂狗（Feed）。

```c
typedef int (*wdt_api_setup)(const struct device *dev, uint8_t options);
typedef int (*wdt_api_disable)(const struct device *dev);
typedef int (*wdt_api_install_timeout)(const struct device *dev,
                                       const struct wdt_timeout_cfg *cfg);
typedef int (*wdt_api_feed)(const struct device *dev, int channel_id);
```

各参数的含义分别与`wdt_setup`、`wdt_disable`、`wdt_install_timeout`和`wdt_feed`相同，详见[公共接口](P001_看门狗公共接口.md)。其中安装超时的成功返回值是通道ID（Channel ID），其余操作成功返回0。

## 2.2\_驱动操作结构

`wdt_driver_api`是看门狗驱动操作（Driver Operations）结构体，保存上述四种操作的函数指针。字段和必填要求见[驱动操作结构](P005_看门狗驱动操作结构.md)，定义与调用转发见[公共头文件源码](P007_看门狗公共头文件源码.md)。
