# 第178章\_STM32N6处理器时钟多路选择绑定

<a id="dtbinding-st-stm32n6-cpu-clock-mux"></a>

原文：[st,stm32n6-cpu-clock-mux](https://docs.zephyrproject.org/latest/build/dts/api/bindings/clock/st,stm32n6-cpu-clock-mux.html)。读取日期：2026-10-13，`latest`。

`st,stm32n6-cpu-clock-mux`是 STMicroelectronics 的设备树绑定（Devicetree Binding）。

本绑定描述STM32N6中央处理器（Central Processing Unit，CPU）的时钟多路选择器（Clock Multiplexer）；在STM32N6上，该CPU时钟还供给系统节拍定时器（System Tick Timer，SysTick）。

采用此兼容字符串的开发板见[官方筛选目录](https://docs.zephyrproject.org/latest/boards/index.html#compatibles=st,stm32n6-cpu-clock-mux)。

## 178.1\_配置说明与官方示例

原例修改标签为`cpusw`的节点；`rcc`为复位与时钟控制器（Reset and Clock Controller，RCC）节点引用，`STM32_SRC_IC1`为IC1时钟源标识，`CPU_SEL(3)`为CPU时钟源选择说明符。`DT_FREQ_M(600)`表示600 MHz，`status = "okay"`表示节点可用。设备树源码（Devicetree Source，DTS）原例如下：

```dts
&cpusw {
  clocks = <&rcc STM32_SRC_IC1 CPU_SEL(3)>;
  clock-frequency = <DT_FREQ_M(600)>;
  status = "okay";
};
```

## 178.2\_节点专用属性

属性类型：`int`为整数，`boolean`为布尔属性，`string`为字符串，`string-array`为字符串数组，`array`为数值数组，`compound`为复合类型；`phandle`为节点引用（Phandle），`phandles`为节点引用列表，`phandle-array`为节点引用与说明符单元数组。

| 属性 | 类型 | 中文说明与约束 |
| --- | --- | --- |
| `clock-frequency` | `int` | **必需**。CPU时钟`sysa_ck/sys_cpu_ck`的默认频率，单位为赫兹（Hertz，Hz） |

本页没有已弃用的节点专用属性。

## 178.3\_基础属性

以下属性继承自基础绑定（Base Binding），**并非全部一定适用于本兼容字符串**。

| 属性 | 类型 | 中文说明与约束 |
| --- | --- | --- |
| `status` | `string` | 节点代表的硬件或其他资源的运行状态（Operational Status）。`okay` 表示资源可运行，例如可供驱动使用；`disabled` 表示资源不可运行，系统应将其视为不存在。参见《设备树规范》（Devicetree Specification）v0.4第2.3.4节；合法值：`okay, disabled, reserved, fail, fail-sss` |
| `compatible` | `string-array` | **必需**。字符串列表定义节点代表的硬件或其他资源类型。设备驱动通过特定兼容字符串（Compatible String）寻找应由自身管理的设备。推荐格式为 `vendor,device`：前者是厂商简称，后者通常来自数据手册。多个值从最具体到最通用排列，让具体设备匹配当前可用的最具体驱动。参见规范v0.4第2.3.1节 |
| `clocks` | `phandle-array` | 设备的时钟提供者（Clock Provider）信息，通常应遵守[dt-schema时钟绑定约定](https://github.com/devicetree-org/dt-schema/blob/main/dtschema/schemas/clock/clock.yaml) |
