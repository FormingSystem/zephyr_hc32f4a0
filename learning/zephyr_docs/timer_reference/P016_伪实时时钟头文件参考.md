# 第16章\_伪实时时钟头文件参考

原文：[rtc__fake_8h](https://docs.zephyrproject.org/latest/doxygen/html/rtc__fake_8h.html)。读取日期：2026-10-13，`latest`。

`zephyr/drivers/rtc/rtc_fake.h`声明伪实时时钟（Fake Real-Time Clock，Fake RTC）驱动的应用程序接口（Application Programming Interface，API）。头文件包含公共RTC接口和伪函数框架（Fake Function Framework，FFF）：

```c
#include <zephyr/drivers/rtc.h>
#include <zephyr/fff.h>
```

## 16.1\_十个伪操作

每个`rtc_fake_*`函数是`rtc_driver_api`中对应驱动操作的伪实现（Fake Implementation），供测试使用。

| 伪函数 | 对应驱动操作 | 用途 |
| --- | --- | --- |
| `rtc_fake_set_time` | `rtc_driver_api::set_time` | 设置RTC时间。 |
| `rtc_fake_get_time` | `rtc_driver_api::get_time` | 取得RTC时间。 |
| `rtc_fake_alarm_get_supported_fields` | `rtc_driver_api::alarm_get_supported_fields` | 取得闹钟支持的时间字段。 |
| `rtc_fake_alarm_set_time` | `rtc_driver_api::alarm_set_time` | 设置闹钟时间。 |
| `rtc_fake_alarm_get_time` | `rtc_driver_api::alarm_get_time` | 取得闹钟时间。 |
| `rtc_fake_alarm_is_pending` | `rtc_driver_api::alarm_is_pending` | 检查闹钟待处理状态。 |
| `rtc_fake_alarm_set_callback` | `rtc_driver_api::alarm_set_callback` | 设置闹钟回调。 |
| `rtc_fake_update_set_callback` | `rtc_driver_api::update_set_callback` | 设置更新回调。 |
| `rtc_fake_set_calibration` | `rtc_driver_api::set_calibration` | 设置校准。 |
| `rtc_fake_get_calibration` | `rtc_driver_api::get_calibration` | 取得校准。 |

## 16.2\_完整函数签名

原文件参考页没有给形参命名，下列签名保留这种形式及全部类型。

```c
int rtc_fake_set_time(const struct device *, const struct rtc_time *);
int rtc_fake_get_time(const struct device *, struct rtc_time *);
int rtc_fake_alarm_get_supported_fields(const struct device *, uint16_t, uint16_t *);
int rtc_fake_alarm_set_time(const struct device *, uint16_t, uint16_t, const struct rtc_time *);
int rtc_fake_alarm_get_time(const struct device *, uint16_t, uint16_t *, struct rtc_time *);
int rtc_fake_alarm_is_pending(const struct device *, uint16_t);
int rtc_fake_alarm_set_callback(const struct device *, uint16_t, rtc_alarm_callback, void *);
int rtc_fake_update_set_callback(const struct device *, rtc_update_callback, void *);
int rtc_fake_set_calibration(const struct device *, int32_t);
int rtc_fake_get_calibration(const struct device *, int32_t *);
```

闹钟（Alarm）相关声明受`CONFIG_RTC_ALARM`控制，更新（Update）受`CONFIG_RTC_UPDATE`控制，校准（Calibration）受`CONFIG_RTC_CALIBRATION`控制；这是对应源码中的配置条件，见[源码页](P017_伪实时时钟头文件源码.md)。

控制返回值、自定义伪函数与检查调用记录的方法见[RTC伪设备接口](../hardware/P497_RTC伪设备接口.md)；公共参数语义见[RTC接口](P009_实时时钟公共接口.md)。
