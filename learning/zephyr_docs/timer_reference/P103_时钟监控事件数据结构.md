# 第103章\_时钟监控事件数据结构

原文：[structclock__monitor__event__data](https://docs.zephyrproject.org/latest/doxygen/html/structclock__monitor__event__data.html)。读取日期：2026-10-13，`latest`。

结构体`clock_monitor_event_data`是交给用户回调（User Callback）的事件载荷（Event Payload），头文件为`zephyr/drivers/clock_monitor.h`。

## 103.1\_结构声明

```c
struct clock_monitor_event_data {
        uint32_t events;
        uint32_t measured_hz;
};
```

## 103.2\_成员与有效条件

| 成员 | 类型 | 含义 |
| --- | --- | --- |
| `events` | `uint32_t` | 已锁存（Latched）的`CLOCK_MONITOR_EVT_*`标志组成的位掩码（Bitmask） |
| `measured_hz` | `uint32_t` | 随本次事件完成的测量结果，单位为赫兹（Hertz，Hz）；仅在`events & CLOCK_MONITOR_EVT_MEASURE_DONE`成立时有效 |

回调参数的生命周期在回调返回时结束，此约束见[时钟监控公共接口](P098_时钟监控公共接口.md)。标志可以按位或（Bitwise OR）组合，不能假设一次事件始终只有一个标志。完整源码见[时钟监控完整头文件](P106_时钟监控完整头文件.md)。
