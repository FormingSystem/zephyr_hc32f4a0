# 第84章\_系统定时器低功耗配套头文件参考

原文：[system__timer__lpm_8h](https://docs.zephyrproject.org/latest/doxygen/html/system__timer__lpm_8h.html)。读取日期：2026-10-13，`latest`。

`zephyr/drivers/timer/system_timer_lpm.h`声明系统定时器低功耗配套接口（System Timer Low-power Companion Interface）。头文件包含：

```c
#include <zephyr/types.h>
```

## 84.1\_低功耗状态下的计时交接

当主系统定时器（Primary System Timer）无法保持活动时，该文件声明的内部应用程序接口（Internal API）用于在跨越低功耗状态（Low-power States）时交接计时（Timekeeping）。

原文件参考页没有列出具体函数的详细契约；三个可见声明完整保存在[对应源码](P085_系统定时器低功耗配套头文件源码.md)。
