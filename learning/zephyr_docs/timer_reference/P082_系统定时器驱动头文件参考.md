# 第82章\_系统定时器驱动头文件参考

原文：[system__timer_8h](https://docs.zephyrproject.org/latest/doxygen/html/system__timer_8h.html)。读取日期：2026-10-13，`latest`。

`zephyr/drivers/timer/system_timer.h`声明由系统定时器（System Timer）驱动实现、供内核组件（Kernel Components）使用的应用程序接口（Application Programming Interface，API）。包含：

```c
#include <stdbool.h>
#include <zephyr/types.h>
#include <zephyr/spinlock.h>
```

## 82.1\_最大等待刻度数

`SYS_CLOCK_MAX_WAIT`是内核请求定时器驱动等待的最大刻度数（Tick Count）：

```c
#define SYS_CLOCK_MAX_WAIT (UINT32_MAX / 2)
```

完整原源码注释解释了为什么仅使用无符号范围的一半，见[源码注释译文](P083_系统定时器驱动头文件源码.md)。

## 82.2\_无需唤醒的空闲哨兵值

`SYS_CLOCK_IDLE_FOREVER`表示“没有任何事情需要唤醒中央处理器（Central Processing Unit，CPU）”的tick计数值：

```c
#define SYS_CLOCK_IDLE_FOREVER UINT32_MAX
```

当预期不需要唤醒时，该值传给`sys_clock_idle_enter`。它大于`SYS_CLOCK_MAX_WAIT`这一内核可能请求的最长等待值，因此不会被误认成普通等待时长。

这里不能使用`K_TICKS_FOREVER`：启用`CONFIG_TIMEOUT_64BIT`时，它是`(int64_t)-1`；未启用时则是`UINT32_MAX`。因此，将一个无符号tick计数与它比较，在这两种配置下含义不同。

## 82.3\_十二个驱动操作

下表完整翻译原文件参考列出的函数简介。自旋锁（Spinlock）状态键类型为`k_spinlock_key_t`。

| 函数 | 原页用途 |
| --- | --- |
| `sys_clock_lock` | 锁定系统时钟（System Clock）。 |
| `sys_clock_unlock` | 解锁系统时钟。 |
| `sys_clock_set_timeout` | 设置系统时钟超时（Timeout）。 |
| `sys_clock_idle_exit` | 通知定时器退出空闲状态（Idle Exit）。 |
| `sys_clock_announce_locked` | 向内核通告时间进展（Time Progress）。 |
| `sys_clock_announce` | 向内核通告时间进展的旧接口包装（Legacy Wrapper）。 |
| `sys_clock_elapsed` | 返回自上次`sys_clock_announce()`调用之后经过的tick数。 |
| `sys_clock_disable` | 禁用系统定时器。 |
| `sys_clock_no_timeout` | 通知定时器驱动当前没有待处理超时。 |
| `sys_clock_idle_enter` | 通知定时器驱动CPU正在进入低功耗空闲（Low-power Idle）。 |
| `sys_clock_cycle_get_32` | 读取硬件周期计数器（Hardware Cycle Counter）。 |
| `sys_clock_cycle_get_64` | 读取64位硬件周期计数器。 |

完整签名如下。锁与解锁是否内联取决于配置，下一章保存两个条件分支：

```c
k_spinlock_key_t sys_clock_lock(void);
void sys_clock_unlock(k_spinlock_key_t key);
void sys_clock_set_timeout(uint32_t ticks, bool idle);
void sys_clock_idle_exit(void);
void sys_clock_announce_locked(uint32_t ticks, k_spinlock_key_t key);
static inline void sys_clock_announce(uint32_t ticks);
uint32_t sys_clock_elapsed(void);
void sys_clock_disable(void);
void sys_clock_no_timeout(void);
void sys_clock_idle_enter(uint32_t ticks);
uint32_t sys_clock_cycle_get_32(void);
uint64_t sys_clock_cycle_get_64(void);
```

这些操作更详细的API分组原文见[系统时钟API](P086_系统时钟公共接口.md)；本页仅对应官方文件参考的内容范围。
