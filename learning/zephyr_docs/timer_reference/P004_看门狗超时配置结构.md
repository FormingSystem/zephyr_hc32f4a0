# 第4章\_看门狗超时配置结构

原文：[structwdt__timeout__cfg](https://docs.zephyrproject.org/latest/doxygen/html/structwdt__timeout__cfg.html)。读取日期：2026-10-13，`latest`。

结构体`wdt_timeout_cfg`保存看门狗（Watchdog）的超时配置（Timeout Configuration），定义于：

```c
#include <zephyr/drivers/watchdog.h>
```

## 4.1\_配置字段

原页列出四个字段，其中`next`受配置条件控制。

| 类型 | 字段 | 含义 |
| --- | --- | --- |
| `struct wdt_window` | `window` | 超时的时间参数，见[喂狗窗口结构](P003_看门狗喂狗窗口结构.md)。 |
| `wdt_callback_t` | `callback` | 超时回调（Timeout Callback），可以为`NULL`。 |
| `struct wdt_timeout_cfg *` | `next` | 指向下一份超时配置的指针。 |
| `uint8_t` | `flags` | 行为标志（Behavior Flag），见[公共接口的复位行为](P001_看门狗公共接口.md)。 |

## 4.2\_多阶段超时

`next`仅在启用`CONFIG_WDT_MULTISTAGE`时可用，该配置对应支持分阶段超时（Staged Timeouts）的看门狗。**对于单阶段超时，此指针值必须为`NULL`。** 此要求适用于该字段存在的配置，不能在未启用配置时仍假定结构体包含该成员。

完整条件编译见[公共头文件源码](P007_看门狗公共头文件源码.md)，配置通过`wdt_install_timeout`安装。
