# 第10章\_实时时钟驱动后端接口

原文：[group__rtc__interface__backend](https://docs.zephyrproject.org/latest/doxygen/html/group__rtc__interface__backend.html)。读取日期：2026-10-13，`latest`。

实时时钟（Real-Time Clock，RTC）驱动后端应用程序接口（Backend Application Programming Interface，Backend API）包含实现驱动所需的类型定义、回调（Callback）签名及其他辅助声明。头文件为：

```c
#include <zephyr/drivers/rtc.h>
```

## 10.1\_十种操作类型

下表列出每种驱动回调的用途；完整签名紧随其后。原文中每个类型的参数说明均指向对应的公共函数。

| 类型 | 用途 | 对应公共函数 |
| --- | --- | --- |
| `rtc_api_set_time` | 设置RTC时间。 | `rtc_set_time` |
| `rtc_api_get_time` | 取得RTC时间。 | `rtc_get_time` |
| `rtc_api_alarm_get_supported_fields` | 取得闹钟支持的时间字段。 | `rtc_alarm_get_supported_fields` |
| `rtc_api_alarm_set_time` | 设置闹钟时间。 | `rtc_alarm_set_time` |
| `rtc_api_alarm_get_time` | 取得闹钟时间。 | `rtc_alarm_get_time` |
| `rtc_api_alarm_is_pending` | 检查闹钟待处理状态。 | `rtc_alarm_is_pending` |
| `rtc_api_alarm_set_callback` | 设置闹钟回调。 | `rtc_alarm_set_callback` |
| `rtc_api_update_set_callback` | 设置每秒更新回调。 | `rtc_update_set_callback` |
| `rtc_api_set_calibration` | 设置RTC校准。 | `rtc_set_calibration` |
| `rtc_api_get_calibration` | 取得RTC校准。 | `rtc_get_calibration` |

```c
typedef int (*rtc_api_set_time)(const struct device *dev, const struct rtc_time *timeptr);
typedef int (*rtc_api_get_time)(const struct device *dev, struct rtc_time *timeptr);
typedef int (*rtc_api_alarm_get_supported_fields)(const struct device *dev, uint16_t id,
                                                  uint16_t *mask);
typedef int (*rtc_api_alarm_set_time)(const struct device *dev, uint16_t id, uint16_t mask,
                                      const struct rtc_time *timeptr);
typedef int (*rtc_api_alarm_get_time)(const struct device *dev, uint16_t id, uint16_t *mask,
                                      struct rtc_time *timeptr);
typedef int (*rtc_api_alarm_is_pending)(const struct device *dev, uint16_t id);
typedef int (*rtc_api_alarm_set_callback)(const struct device *dev, uint16_t id,
                                          rtc_alarm_callback callback, void *user_data);
typedef int (*rtc_api_update_set_callback)(const struct device *dev,
                                           rtc_update_callback callback, void *user_data);
typedef int (*rtc_api_set_calibration)(const struct device *dev, int32_t calibration);
typedef int (*rtc_api_get_calibration)(const struct device *dev, int32_t *calibration);
```

所有参数的输入输出方向、闹钟ID、掩码、回调及校准单位见[公共接口](P009_实时时钟公共接口.md)。这里的函数指针返回`int`状态或事件结果，不等同于返回`void`的应用通知回调。

## 10.2\_操作结构与配置条件

`rtc_driver_api`保存上述操作。设置和取得时间是必填操作，闹钟、更新和校准操作为可选，并受相应配置选项控制，详见[驱动操作结构](P012_实时时钟驱动操作结构.md)。完整声明与调用转发见[源码页](P014_实时时钟公共头文件源码.md)。
