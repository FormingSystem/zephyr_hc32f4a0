# 第133章\_STM32时钟多路复用绑定

<a id="dtbinding-st-stm32-clock-mux"></a>

原文：[st,stm32-clock-mux](https://docs.zephyrproject.org/latest/build/dts/api/bindings/clock/st,stm32-clock-mux.html)。读取日期：2026-10-13，`latest`。

`st,stm32-clock-mux`是 STMicroelectronics 的设备树绑定（Devicetree Binding）。

本绑定描述 STM32 时钟多路复用器（Clock Multiplexer），例如 STM32H7 的`per_ck`或 STM32WB 的`CLK48`。节点的作用是选择一个时钟输入（Clock Input）。

驱动源码：[`drivers/clock_control/clock_stm32_mux.c`](https://github.com/zephyrproject-rtos/zephyr/blob/main/drivers/clock_control/clock_stm32_mux.c)。

采用此兼容字符串的开发板见[官方筛选目录](https://docs.zephyrproject.org/latest/boards/index.html#compatibles=st,stm32-clock-mux)。

## 133.1\_配置说明与官方示例

原例的`perck`为设备树节点标签（Node Label），`rcc`为复位与时钟控制器（Reset and Clock Controller，RCC）节点；源标识宏`STM32_SRC_HSI_KER`选择相应高速内部（High-speed Internal，HSI）内核时钟源，`CKPER_SEL`为时钟源选择宏。原示例如下：

```dts
        &perck {
                clocks = <&rcc STM32_SRC_HSI_KER CKPER_SEL(0)>;
                status = "okay";
        };
```

## 133.2\_节点专用属性

属性类型：`int`为整数，`boolean`为布尔属性，`string`为字符串，`string-array`为字符串数组，`array`为数值数组，`compound`为复合类型；`phandle`为节点引用（Phandle），`phandles`为节点引用列表，`phandle-array`为节点引用与说明符单元数组。

本页没有节点专用属性。

本页没有已弃用的节点专用属性。

## 133.3\_基础属性

以下属性继承自基础绑定（Base Binding），**并非全部一定适用于本兼容字符串**。

| 属性 | 类型 | 中文说明与约束 |
| --- | --- | --- |
| `clocks` | `phandle-array` | **必需**。设备的时钟提供者（Clock Provider）信息，通常应遵守[dt-schema时钟绑定约定](https://github.com/devicetree-org/dt-schema/blob/main/dtschema/schemas/clock/clock.yaml) |
| `status` | `string` | 节点代表的硬件或其他资源的运行状态（Operational Status）。`okay` 表示资源可运行，例如可供驱动使用；`disabled` 表示资源不可运行，系统应将其视为不存在。参见《设备树规范》（Devicetree Specification）v0.4第2.3.4节；合法值：`okay, disabled, reserved, fail, fail-sss` |
| `compatible` | `string-array` | **必需**。字符串列表定义节点代表的硬件或其他资源类型。设备驱动通过特定兼容字符串（Compatible String）寻找应由自身管理的设备。推荐格式为 `vendor,device`：前者是厂商简称，后者通常来自数据手册。多个值从最具体到最通用排列，让具体设备匹配当前可用的最具体驱动。参见规范v0.4第2.3.1节 |
