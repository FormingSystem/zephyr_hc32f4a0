# 位数组参考大纲

本册翻译位数组（Bit Array）公共接口和头文件参考，包括单个位读写、原子检查修改（Atomic Test and Update）、连续位分配与释放、区域查询、置位计数（Population Count）、第n个置位查找以及按位异或（Bitwise XOR）。

位数组只管理状态；[内存块分配器](../memblocks_reference/大纲.md)将其索引映射到数据块。原始声明、宏展开、参数和返回值完整保留，源码译注说明输出条件、锁定、查询与占用的区别。所有仓库链接使用相对路径；源码浏览另见[位数组头文件源码](../memory_source_reference/P001_位数组头文件源码.md)，逐页覆盖状态见[全站进度](../PROGRESS.md)。
