## 2.4\_源码定位与版本边界

位数组是[内存块分配公共接口](../memblocks_reference/P001_内存块分配公共接口.md)的基础，配合[内存块分配器指南](../kernel/P025_内存块分配器.md)阅读。位数组仅管理状态；索引到实际数据地址的映射由上层完成。

源码定位：[bitarray.h](../../../include/zephyr/sys/bitarray.h)、[bitarray.c](../../../lib/utils/bitarray.c)、[check.h](../../../include/zephyr/sys/check.h)及[util.h](../../../include/zephyr/sys/util.h)。官方依据为[位数组头文件](https://github.com/zephyrproject-rtos/zephyr/blob/main/include/zephyr/sys/bitarray.h)、[位数组实现](https://github.com/zephyrproject-rtos/zephyr/blob/main/lib/utils/bitarray.c)、[可配置错误检查](https://github.com/zephyrproject-rtos/zephyr/blob/main/include/zephyr/sys/check.h)和[取整与位操作工具](https://github.com/zephyrproject-rtos/zephyr/blob/main/include/zephyr/sys/util.h)，摘要见[来源记录](../SOURCES.md)。

> 译注——前提与错误检查：应提供有效非空对象、有效输出地址及不溢出的区域范围。可先保证offset小于总位数，再保证0 < num_bits <= 总位数 - offset，不能把size_t加法回绕当成合法范围。部分空输出检查使用CHECKIF：默认返回错误，CONFIG_ASSERT_ON_ERRORS改为断言且不执行错误返回块，CONFIG_NO_RUNTIME_CHECKS省略检查。对象有效性还有独立断言；原返回码表不代表所有错误输入都能安全返回-EINVAL。

> 译注——页面范围：本页是官方头文件参考；[源码浏览译文](../memory_source_reference/P001_位数组头文件源码.md)单独保留可见代码、行号锚点及中文注释。内部字段未作为本页公开成员列出，其源码定义可在源码册对照。
