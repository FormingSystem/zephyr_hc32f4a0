### `SYS_BITARRAY_DEFINE`

```c
#define SYS_BITARRAY_DEFINE ( name, total_bits )
```

```c
#include <zephyr/sys/bitarray.h>
```

展开值（Value）：

```c
_SYS_BITARRAY_DEFINE(name, total_bits,)
```

创建位数组对象。

**参数（Parameters）**

| 名称／方向 | 说明 |
| --- | --- |
| `name` | 位数组对象的名称。 |
| `total_bits` | 此位数组对象包含的总位数。 |

> 译注——源码核对：当前宏生成uint32_t存储单元数组（Bundle Array），向上补齐到足够容量并初始化为0；有效位数仍是total_bits，末尾填充位不属于有效范围。运行时接口要求位数组非空，不能把total_bits=0当正常可用对象。对象内还包含自旋锁（Spinlock），应用不要直接改写底层存储绕过同步。

### `sys_bitarray_alloc()`

```c
int sys_bitarray_alloc ( sys_bitarray_t * bitarray, size_t num_bits, size_t * offset )
```

```c
#include <zephyr/sys/bitarray.h>
```

在位数组中分配位。

在先前未分配的空间中寻找一个包含 num_bits 位的连续区域（Contiguous Region）。若找到，就把这些位标为已分配，并通过 offset 返回该区域的起始偏移。

**参数（Parameters）**

| 名称／方向 | 说明 |
| --- | --- |
| `[in] bitarray` | 位数组结构。 |
| `[in] num_bits` | 要分配的位数。 |
| `[out] offset` | 成功时，输出已分配区域的起始偏移。 |

**返回值（Return Values）**

| 名称／方向 | 说明 |
| --- | --- |
| `0` | 分配成功。 |
| `-EINVAL` | 参数无效，例如分配位数超过位数组容量，或尝试分配 0 位等。 |
| `-ENOSPC` | 没有足够大的连续区域满足本次分配。 |

> 译注——源码核对：当前在对象自旋锁内查找连续0位并置1，成功才写*offset；失败时不清空旧输出。num_bits=0或超过容量返回-EINVAL，无足够连续空间返回-ENOSPC；总空闲位数足够也可能因碎片而失败。它只管理位，不分配数据缓冲区，也没有等待参数。

### `sys_bitarray_find_nth_set()`

```c
int sys_bitarray_find_nth_set ( sys_bitarray_t * bitarray, size_t n, size_t num_bits, size_t offset, size_t * found_at )
```

```c
#include <zephyr/sys/bitarray.h>
```

查找区域中第 n 个置位（Set Bit）。

在由 offset 和 num_bits 指定的区域中搜索第 n 个置位；若存在，将其索引写入 found_at，并返回 0。

若不存在，则不更新 found_at，并返回 1。

**参数（Parameters）**

| 名称／方向 | 说明 |
| --- | --- |
| `[in] bitarray` | 位数组结构。 |
| `[in] n` | 要查找的第 n 个置位。 |
| `[in] num_bits` | 要检查的位数，必须大于 0。 |
| `[in] offset` | 起始位位置。 |
| `[out] found_at` | 找到时，输出第 n 个置位的索引。 |

**返回值（Return Values）**

| 名称／方向 | 说明 |
| --- | --- |
| `0` | 操作成功。 |
| `1` | 在区域中未找到第 n 个置位。 |
| `-EINVAL` | 参数无效，例如越界访问或尝试统计 0 位等。 |

> 译注——源码核对：当前n从1开始，n=0返回-EINVAL；found_at是从整个位数组第0位算起的索引，不是相对offset的偏移。找到返回0，找不到返回1并保持原输出不变，非法范围返回-EINVAL。实现未单独检查found_at是否为NULL，调用者必须传入可写指针。结果只是查询快照，不消费该位。

### `sys_bitarray_free()`

```c
int sys_bitarray_free ( sys_bitarray_t * bitarray, size_t num_bits, size_t offset )
```

```c
#include <zephyr/sys/bitarray.h>
```

释放位数组中的位。

将从 offset 开始的 num_bits 位标记为不再分配。

**参数（Parameters）**

| 名称／方向 | 说明 |
| --- | --- |
| `bitarray` | 位数组结构。 |
| `num_bits` | 要释放的位数。 |
| `offset` | 要释放区域的起始位位置。 |

**返回值（Return Values）**

| 名称／方向 | 说明 |
| --- | --- |
| `0` | 释放成功。 |
| `-EINVAL` | 参数无效，例如释放位数超过位数组容量，或尝试释放 0 位等。 |
| `-EFAULT` | 指定区域中的位并非全部处于已分配状态。 |

> 译注——源码核对：当前在同一锁内先验证指定区域全部为1，再将整段清0；只要有未分配位，返回-EFAULT且不局部清位。num_bits=0不被视为成功空操作。它不要求区域必须对应某一次alloc的完整返回范围，因此应用仍需维护分配范围及所有权。

### `sys_bitarray_test_and_set_region()`

```c
int sys_bitarray_test_and_set_region ( sys_bitarray_t * bitarray, size_t num_bits, size_t offset, bool to_set )
```

```c
#include <zephyr/sys/bitarray.h>
```

在一次原子操作（Atomic Operation）中，检查区域中的位是否全部为 0／1，并将它们置 1／清零。

检查从 offset 开始的 num_bits 位是否全部处于要求的状态。只要有一位不满足，就返回 -EEXIST。若整个区域全部为 1／0，则将其变为相反状态。检查和修改作为一次原子操作完成。

**参数（Parameters）**

| 名称／方向 | 说明 |
| --- | --- |
| `bitarray` | 位数组结构。 |
| `num_bits` | 要测试并修改的位数。 |
| `offset` | 要测试并修改区域的起始位位置。 |
| `to_set` | 为 true 时，只有区域内所有位均为 0 才将它们置 1；为 false 时，只有所有位均为 1 才将它们清零。 |

**返回值（Return Values）**

| 名称／方向 | 说明 |
| --- | --- |
| `0` | 操作成功。 |
| `-EINVAL` | 参数无效，例如要置位的位索引超出位数组范围等。 |
| `-EEXIST` | 区域中至少有一位已处于目标状态，操作取消。 |

> 译注——源码核对：to_set=true要求原来全为0，然后整段置1；to_set=false要求原来全为1，然后整段清0。检查和修改都在同一把锁内，条件不满足返回-EEXIST且不修改；区域无效或长度0返回-EINVAL。这里的原子性（Atomicity）是锁保护的组合操作，不表示无锁或单条CPU指令。

## 1.6\_源码定位与版本边界

位数组是[内存块分配公共接口](../memblocks_reference/P001_内存块分配公共接口.md)的基础，配合[内存块分配器指南](../kernel/P025_内存块分配器.md)阅读。位数组仅管理状态；索引到实际数据地址的映射由上层完成。

源码定位：[bitarray.h](../../../include/zephyr/sys/bitarray.h)、[bitarray.c](../../../lib/utils/bitarray.c)、[check.h](../../../include/zephyr/sys/check.h)及[util.h](../../../include/zephyr/sys/util.h)。官方依据为[位数组头文件](https://github.com/zephyrproject-rtos/zephyr/blob/main/include/zephyr/sys/bitarray.h)、[位数组实现](https://github.com/zephyrproject-rtos/zephyr/blob/main/lib/utils/bitarray.c)、[可配置错误检查](https://github.com/zephyrproject-rtos/zephyr/blob/main/include/zephyr/sys/check.h)和[取整与位操作工具](https://github.com/zephyrproject-rtos/zephyr/blob/main/include/zephyr/sys/util.h)，摘要见[来源记录](../SOURCES.md)。

> 译注——前提与错误检查：应提供有效非空对象、有效输出地址及不溢出的区域范围。可先保证offset小于总位数，再保证0 < num_bits <= 总位数 - offset，不能把size_t加法回绕当成合法范围。部分空输出检查使用CHECKIF：默认返回错误，CONFIG_ASSERT_ON_ERRORS改为断言且不执行错误返回块，CONFIG_NO_RUNTIME_CHECKS省略检查。对象有效性还有独立断言；原返回码表不代表所有错误输入都能安全返回-EINVAL。

仓库源码、滚动main与latest页面不能自动视为同一版本。本次只完成文档和源码核对，未构建或运行并发异或、边界溢出、资源耗尽及实板实验。
