原文：[官方页面](https://docs.zephyrproject.org/latest/doxygen/html/group__ieee802154__l2.html)。读取日期：2026-10-17；来源摘要见[来源记录](../SOURCES.md)。

IEEE 802.15.4 二层（L2）API

<a id="details"></a>

IEEE 802.15.4 二层（L2）API。**引入版本（Since）：**1.0。**版本（Version）：**0.8.0。本 API 提供与 Zephyr 套接字（Sockets）和网络上下文（Network Contexts）的集成。应用和驱动开发者不得直接使用此 API，它仅面向子系统维护者。

本 API 实现并扩展以下结构：

- 实现 Zephyr 内部的 L2 套接字和网络上下文抽象，包括上下文／套接字操作，参见网络二层抽象层（Network L2 Abstraction Layer）。
- 为网络接口结构提供协议专用扩展，参见网络接口抽象层（Network Interface Abstraction Layer）。
- 为网络数据包结构提供协议专用扩展，参见网络数据包库（Network Packet Library）。

**注意（Note）：**全部章节、表和图引用均指 IEEE 802.15.4-2020 标准。

<a id="ga987d42d1d8117ec58cf3f9cae4e66139"></a>

### `IEEE802154_MTU`

```c
#define IEEE802154_MTU (IEEE802154_MAX_PHY_PACKET_SIZE - IEEE802154_FCS_LENGTH)
```

```c
#include <zephyr/net/ieee802154.h>
```

IEEE 802.15.4“硬件”最大传输单元（Hardware MTU），不要与三层／IP MTU 混淆，即：

下一较高层实际可用的载荷（Payload）。

这等于 IEEE 802.15.4 MAC 帧长减去校验和字节数，也等于 PHY 载荷，即 PSDU 长度减去校验和字节数。此定义为兼容 Linux 和 Zephyr 三层（L3）中的同名概念而存在，并非 IEEE 802.15.4 标准中的概念。

**说明（Note）**：**注意（Note）：**目前只支持 2006 版及更早标准的原始帧大小。2015 版及以后的标准引入了更大 PHY 载荷的物理层，Zephyr 尚未支持。
