## 概述（Overview）

EVAL-ADIN2111EBZ是一个灵活的平台，可用于快速评估稳健、低功耗的ADIN2111 10BASE-T1L双端口以太网交换机（2-Port Ethernet Switch）。评估板提供两个10BASE-T1L通道，支持10 Mbit/s单对以太网（SPE / Single Pair Ethernet）连接，链路距离最长1.7 km。

ADIN2111的内部交换机可以配置为在两个10BASE-T1L通道和SPI主机之间采用存储转发模式（Store-and-forward Mode）。Port 1和Port 2之间也可使用直通模式（Cut-through Mode），该模式无需SPI主机，即非管理型配置（Unmanaged Configuration）。

评估板提供两种工作模式，以获得最大的灵活性。通过USB端口连接到PC后，可以使用评估固件实现的串行命令接口（Serial Command Interface），经USB访问ADIN2111的全部寄存器设置，以及链路质量监测（Link Quality Monitoring）、诊断（Diagnostics）等功能。

此外，开发板可以在Port 1和Port 2之间运行直通模式（Cut-through Mode），即不使用固件的非管理型配置（Unmanaged Configuration）。此时EVAL-ADIN2111EBZ充当网络交换机，在两个10BASE-T1L端口之间转发数据包。通过设置ADIN2111硬件配置引脚的跳线（Jumpers）和开关（Switches）来配置这两条链路。两个板载活动LED（Activity LEDs）分别指示各端口的链路活动状态。

也可以开发自定义固件（Custom Firmware）；ADIN2111驱动支持包包含简单项目示例，便于开始自定义实现。

SPI接口提供对管理寄存器（Management Registers）的访问，用于交换机配置、两个PHY的配置，以及SPI主机与端口之间的数据交换。

重要提示（Important）

S1拨码开关（DIP Switches）出厂设置为Open Alliance SPI模式。当前Zephyr的默认开发板配置采用“通用SPI，启用CRC（Generic SPI, CRC enabled）”，因此必须将S1设置为SPI_CFG0 OFF、SPI_CFG1 OFF。S1拨码开关配置不一致会导致启动停止。

<a id="connections-and-ios"></a>

### 连接与输入输出（Connections and IOs）

ADI ADIN2111EBZ评估板有7个GPIO控制器（A至G），负责引脚复用（Pin Muxing）、输入／输出（Input/Output）、上拉（Pull-up）等功能。

更多模式细节请参阅[EVAL-ADIN2111EBZ用户指南（User Guide）](https://wiki.analog.com/resources/eval/user-guides/eval-adin2111ebz-user-guide)。

<a id="default-zephyr-peripheral-mapping"></a>

#### Zephyr 默认外设映射（Peripheral Mapping）：


- UART_1 TX/RX：PA9/PA10（UART连接到FT232，用于控制台 / Console）
- SPI1 SCK/MISO/MOSI：PA5/PA6/PA7（SPI连接到外部NOR闪存IS25LP128）
- SPI2 SCK/MISO/MOSI：PB13/PB14/PB15（SPI连接到外部ADIN2111）
- LED1：POWER电源（绿色LED / Green LED）
- UC_LED1：PB6（蓝色LED / Blue LED）
- MOD LED1：PE2（SR LED）
- MOD LED2：PE6（BG LED）
- NET LED1：PB10（SR LED）
- NET LED2：PB11（BG LED）

<a id="system-clock"></a>

#### 系统时钟（System Clock）

EVAL-ADIN2111EBZ的系统时钟（System Clock）可以由内部或外部振荡器（Oscillator）驱动，也可以由主锁相环（PLL）时钟驱动。默认使用80 MHz PLL时钟，其输入来自16 MHz高速内部振荡器（HSI / High-speed Internal Oscillator）。

<a id="serial-port"></a>

#### 串口（Serial Port）

EVAL-ADIN2111EBZ有1路U(S)ART。Zephyr控制台（Console）输出分配给UART1，该接口连接到FT232，可通过Micro USB接口使用。默认串口设置为115200 8N1。FT232之前的同一组UART1 TX和RX CMOS信号也引出到P9接口。

<a id="flashing"></a>

### 烧录（Flashing）

EVAL-ADIN2111EBZ包含一个ST-LINK/V2-1 JTAG/SWD 10针或20针接口。Zephyr SDK所包含的OpenOCD版本支持该接口。

<a id="flashing-an-application-to-discovery-kit"></a>

#### 将应用烧录到Discovery套件（Flashing an Application to Discovery Kit）

使用USB端口将EVAL-ADIN2111EBZ连接到主机，然后运行主机串口程序连接ADI开发板。例如：

```text
$ minicom -D /dev/serial/by-id/usb-ADI_EVAL-ADIN2111EBZ_XXXXXX-12-if00-port0
```

其中，`XXXXXX`是已连接设备的序列号（Serial Number）。随后按通常方式构建和烧录。以下以[Hello World](../getting_started/P005_HelloWorld示例.md#hello_world)应用为例。

```text
# From the root of the zephyr repository
west build -b adi_eval_adin2111ebz samples/hello_world
west flash
```

控制台上应显示以下消息：

```text
Hello World! adi_eval_adin2111ebz
```

### 调试（Debugging）

```text
# From the root of the zephyr repository
west build -b adi_eval_adin2111ebz samples/hello_world
west debug
```
