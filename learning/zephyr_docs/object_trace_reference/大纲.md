# 数据交换与内存对象跟踪接口大纲

本册完整翻译FIFO、LIFO、队列、消息队列、邮箱、管道、栈、堆和内存块池九组跟踪接口，共九份官方页面。跟踪钩子（Tracing Hooks）用于记录API入口、阻塞、出口和生命周期事件，具体记录行为由后端实现。

各页保留宏签名、摘要、完整参数说明与交叉引用。源码译注说明配置与后端、事件位置、返回值语义及原文和调用点的差异，区分返回码、数据指针、布尔结果与传输字节数，并说明嵌套事件、重新调度标记及缺少出口的实际分支。

本地源码使用相对链接，保留中英文术语和原始许可证；本册不加入作者机器的采集环境或实板步骤。完整范围见[全站进度](../PROGRESS.md)。
