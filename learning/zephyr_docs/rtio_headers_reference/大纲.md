# RTIO事件与设备头文件参考大纲

本册完整翻译实时输入输出（Real-Time I/O，RTIO）的提交队列事件（SQE）、完成队列事件（CQE）与输入输出设备（IODEV）三个头文件，各包含参考页和源码浏览页。阅读时可先查参考页声明，再沿相邻源码页定位准备函数、对象池与设备函数表实现。

源码页保留全部可见代码、原注释、行号锚点和符号提示，并补充中文对照；API完整约定连接至[RTIO核心接口](../rtio_core_reference/大纲.md)，成员与标志说明连接至[数据结构与事件标志](../rtio_model_reference/大纲.md)。

源码译注说明初始化、异步内存寿命、对象池回收和版本边界，不混入本机环境或实验步骤。原代码与许可证保留，本地链接使用相对路径。完整范围见[全站进度](../PROGRESS.md)。
