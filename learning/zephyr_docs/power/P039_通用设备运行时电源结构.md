# 第39章\_通用设备运行时电源结构

原文：[structpm__device](https://docs.zephyrproject.org/latest/doxygen/html/structpm__device.html)。读取日期：2026-10-13，`latest`。

`struct pm_device` 保存采用通用电源管理（Power Management，PM）的设备运行时 PM 信息。通用 PM 的挂起和恢复操作可能阻塞、耗时较长或异步完成；在中断上下文（Interrupt Context）中使用运行时 PM 应用程序编程接口（Application Programming Interface，API）受到限制。头文件为 `zephyr/pm/device.h`。

## 39.1\_数据成员

| 成员 | 原始类型 | 含义 |
| --- | --- | --- |
| [`base`](https://docs.zephyrproject.org/latest/doxygen/html/structpm__device.html#afb5db0142ebab7891a42f71b59fd55cb) | `struct pm_device_base` | [基础信息](P038_设备电源管理基础结构.md) |
| [`dev`](https://docs.zephyrproject.org/latest/doxygen/html/structpm__device.html#aec09c5708cda21c6e3af2a4e7082b432) | `const struct device *` | 设备指针 |
| [`lock`](https://docs.zephyrproject.org/latest/doxygen/html/structpm__device.html#ab7e54f9195359f60cc0a4b06677df0c7) | `struct k_sem` | 同步 `get`/`put` 操作的锁（Lock），使用信号量（Semaphore） |
| [`event`](https://docs.zephyrproject.org/latest/doxygen/html/structpm__device.html#aa8ed27c6c0cff89062922bedae4dca35) | `struct k_event` | 监听同步请求事件的事件变量（Event Variable） |
| [`work`](https://docs.zephyrproject.org/latest/doxygen/html/structpm__device.html#a5dc3b48b3139d546206c8b9cacaf09fd) | `struct k_work_delayable` | 异步调用的工作对象（Work Object） |
