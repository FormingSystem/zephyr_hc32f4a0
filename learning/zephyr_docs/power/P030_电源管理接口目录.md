# 第30章\_电源管理接口目录

原文：[Power Management APIs](https://docs.zephyrproject.org/latest/services/pm/api/index.html)。读取日期：2026-10-13，`latest`。

本页汇集电源管理（Power Management，PM）的应用程序编程接口（Application Programming Interface，API）及相关代码示例。

## 30.1\_系统电源管理

系统接口分为[系统](P032_系统电源管理接口.md)、[状态](P034_电源状态接口.md)、[策略](P035_系统电源管理策略接口.md)和[钩子（Hooks）](P033_系统电源管理钩子.md)。

| 相关示例 | 原页说明 |
| --- | --- |
| [NXP MCX挂起到RAM](P052_NXP_MCX挂起到RAM示例.md) | 将 NXP MCXA/MCXN 片上系统（System on Chip，SoC）挂起到随机存取存储器（Random Access Memory，RAM），通过唤醒控制器（WUU）传递的低功耗定时器（Low-Power Timer，LPTMR）或按键唤醒后恢复 |
| [PM策略延迟](P050_电源策略延迟示例.md) | 利用最大可容忍退出延迟（Exit Latency）约束允许的电源状态 |

## 30.2\_设备电源管理

参见[设备PM接口](P036_设备电源管理接口.md)。

| 相关示例 | 原页说明 |
| --- | --- |
| [设备空闲电源管理](P049_设备空闲电源管理示例.md) | 在父子设备层级中使用设备运行时电源管理（Device Runtime PM） |
| [串口唤醒](P056_STM32串口唤醒示例.md) | STM32 上由串口活动唤醒 |
| [系统关闭](P051_Nordic系统关闭示例.md) | 在 Nordic 平台上使用深度睡眠（Deep Sleep） |

## 30.3\_设备运行时电源管理

参见[设备运行时PM接口](P037_设备运行时电源管理接口.md)。相关示例为[设备空闲电源管理](P049_设备空闲电源管理示例.md)，以及在 STM32 上使用挂起到 RAM 低功耗模式的[挂起到RAM示例](P059_STM32挂起到RAM示例.md)。
