# 第102章\_MAX20335稳压器设备树头文件

原文：[max20335_8h](https://docs.zephyrproject.org/latest/doxygen/html/max20335_8h.html)。读取日期：2026-10-13，`latest`。

本头文件提供Maxim MAX20335 电源管理集成电路（Power Management Integrated Circuit，PMIC）稳压器驱动的**设备树辅助接口（Devicetree Helpers）**。头文件路径为 `zephyr/dt-bindings/regulator/max20335.h`。


## 102.1\_源码与包含关系

[查看官方源码](https://docs.zephyrproject.org/latest/doxygen/html/max20335_8h_source.html)。本参考页未列出包含项。

相关的[设备树辅助接口](P087_MAX20335稳压器设备树辅助接口.md)给出同组常量说明。

## 102.2\_稳压器模式

```c
#define MAX20335_LDO_MODE 0
#define MAX20335_LOAD_SWITCH_MODE 1
```

| 宏 | 值 | 中文说明 |
