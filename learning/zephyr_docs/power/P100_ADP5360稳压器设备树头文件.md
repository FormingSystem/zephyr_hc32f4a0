# 第100章\_ADP5360稳压器设备树头文件

原文：[dt-bindings_2regulator_2adp5360_8h](https://docs.zephyrproject.org/latest/doxygen/html/dt-bindings_2regulator_2adp5360_8h.html)。读取日期：2026-10-13，`latest`。

本头文件提供Analog Devices ADP5360 电源管理集成电路（Power Management Integrated Circuit，PMIC）稳压器驱动的**设备树辅助接口（Devicetree Helpers）**。头文件路径为 `zephyr/dt-bindings/regulator/adp5360.h`。


## 100.1\_源码与包含关系

[查看官方源码](https://docs.zephyrproject.org/latest/doxygen/html/dt-bindings_2regulator_2adp5360_8h_source.html)。本参考页未列出包含项。

相关的[设备树辅助接口](P085_ADP5360稳压器设备树辅助接口.md)给出同组常量说明。

## 100.2\_稳压器模式

```c
#define ADP5360_MODE_HYS 0
#define ADP5360_MODE_PWM 1
```

| 宏 | 值 | 中文说明 |
