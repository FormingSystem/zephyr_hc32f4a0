# 第56章\_STM32串口唤醒示例

原文：[Serial wakeup](https://docs.zephyrproject.org/latest/samples/boards/st/power_mgmt/serial_wakeup/README.html)。读取日期：2026-10-13，`latest`。

## 56.1\_概述与要求

本最小应用演示低功耗环境中的串口唤醒（Serial Wakeup）。开发板应支持电源管理（Power Management，PM）。STM32 目标需要能替代 Cortex SysTick 系统节拍定时器、且可在核心睡眠状态下工作的时钟源，例如低功耗定时器（Low-Power Timer，LPTIM），见 [st,stm32-lptim绑定](../stm32_ti_silabs_timer_binding_reference/P007_st_stm32-lptim.md#std-dtcompatible-st-stm32-lptim)。

命令解释器（Shell）使用的串口必须通过设备树（Devicetree）配置为有效唤醒源：

- 由停止模式（Stop Mode）中仍可工作的振荡器供时钟，例如低速外部（Low-Speed External，LSE）或低速内部（Low-Speed Internal，LSI）振荡器；也可使用设备检测到活动时能够动态请求的振荡器，例如STM32WB的高速内部（High-Speed Internal，HSI）振荡器。
- 启用对应振荡器源。
- 如果选择LSE且shell串口是低功耗通用异步收发器（Low-Power UART，LPUART），应将速率调整为9600波特。
- 串口节点应设置 `wakeup-source` 属性。

译注：原页还有一句未完成的提示“Note: Using HSI clock is a specific”。该句仅表达将要说明HSI的特殊情况，但没有给出完整内容；此处不推测缺失结论。

## 56.2\_构建与运行

以下构建并烧录示例，将 `nucleo_wb55rg` 替换为已按上述要求配置的兼容开发板：

```shell
west build -b nucleo_wb55rg samples/boards/st/power_mgmt/serial_wakeup
west flash
```

烧录后shell启用，设备进入睡眠。向shell输入字符即可唤醒设备。

## 56.3\_PM配置与调试

默认启用 Kconfig 选项 [`CONFIG_PM_DEVICE`](https://docs.zephyrproject.org/latest/kconfig.html#CONFIG_PM_DEVICE) 和 [`CONFIG_PM_DEVICE_RUNTIME`](https://docs.zephyrproject.org/latest/kconfig.html#CONFIG_PM_DEVICE_RUNTIME)，分别为设备PM与设备运行时PM；也可同时禁用两者，或只禁用前者，观察配置行为。

可启用 [`CONFIG_DEBUG`](https://docs.zephyrproject.org/latest/kconfig.html#CONFIG_DEBUG) 进行调试，但调试模式会阻止目标达到低功耗。关闭调试配置后，还应给目标断电，使其恢复正常模式并达到低功耗。

## 56.4\_stm32l562e_dk功耗测量

使用stm32l562e_dk PM扩展板时，原文要求：

1. 插上Power扩展板。
2. 连接ST-Link。
3. 将跳线JP4设置为 `5V ST-Link`。
4. 将开关SW1设置为 `PM_SEL_VDD`。
5. 在STM32Cube PowerMonitor中，将采样频率（Sampling Freq）设置为 `max`，工作模式（Functional Mode）设置为 `High`。

## 56.5\_更低功耗的配置条件

为达到更低功耗，原文给出以下条件：

- 使用LPUART，替代普通通用同步/异步收发器（Universal Synchronous/Asynchronous Receiver/Transmitter，USART/UART）节点。
- 选择LSE作为时钟源。
- 确保没有其他振荡器启用，例如禁用HSI。
- 为其他UART节点提供 `sleep` 引脚控制（Pin Control，pinctrl）配置。
- 关闭调试模式。

满足全部条件时，原文报告此示例在stm32l562e_dk上可达到10 µA。

另见[设备电源管理接口](P036_设备电源管理接口.md)。
