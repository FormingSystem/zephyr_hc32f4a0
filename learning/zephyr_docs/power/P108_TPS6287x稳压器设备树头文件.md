# 第108章\_TPS6287x稳压器设备树头文件

原文：[ti__tps6287x_8h](https://docs.zephyrproject.org/latest/doxygen/html/ti__tps6287x_8h.html)。读取日期：2026-10-13，`latest`。

本头文件提供Texas Instruments TPS6287x降压转换器（Step-Down Converter）驱动的**设备树辅助接口（Devicetree Helpers）**。头文件路径为 `zephyr/dt-bindings/regulator/ti_tps6287x.h`。


宏名中的PFM表示脉频调制（Pulse Frequency Modulation），原页将对应项描述为节能模式。

## 108.1\_源码与包含关系

[查看官方源码](https://docs.zephyrproject.org/latest/doxygen/html/ti__tps6287x_8h_source.html)。本参考页未列出包含项。

相关的[设备树辅助接口](P093_TPS6287x稳压器设备树辅助接口.md)给出同组常量说明。

## 108.2\_稳压器模式

```c
#define TI_TPS6287X_MODE_PFM 0U
#define TI_TPS6287X_MODE_PWM 1U
```

| 宏 | 值 | 中文说明 |
| --- | --- | --- |
| [`TI_TPS6287X_MODE_PFM`](https://docs.zephyrproject.org/latest/doxygen/html/group__regulator__ti__tps6287x.html#gabcb0955b3ddf184d558c25078994d261) | `0U` | 节能模式（Power Saving Mode） |
| [`TI_TPS6287X_MODE_PWM`](https://docs.zephyrproject.org/latest/doxygen/html/group__regulator__ti__tps6287x.html#ga2eebd3d5703288664de2d3aa07d57294) | `1U` | 强制脉宽调制模式（Forced Pulse Width Modulation，Forced PWM） |
