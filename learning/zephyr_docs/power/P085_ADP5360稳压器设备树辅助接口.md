# 第85章\_ADP5360稳压器设备树辅助接口

原文：[group__regulator__adp5360](https://docs.zephyrproject.org/latest/doxygen/html/group__regulator__adp5360.html)。读取日期：2026-10-13，`latest`。

本页提供Analog Devices ADP5360 电源管理集成电路（Power Management Integrated Circuit，PMIC）稳压器驱动的**设备树辅助接口（Devicetree Helpers）**。相应头文件包含方式为：

```c
#include <zephyr/dt-bindings/regulator/adp5360.h>
```

## 85.1\_稳压器模式

```c
#define ADP5360_MODE_HYS 0
#define ADP5360_MODE_PWM 1
```

| 宏 | 值 | 中文说明 |
| --- | --- | --- |
| [`ADP5360_MODE_HYS`](https://docs.zephyrproject.org/latest/doxygen/html/group__regulator__adp5360.html#gae2cf6777a5ff129d6fda7200b581e7c5) | `0` | 迟滞模式（Hysteresis Mode） |
| [`ADP5360_MODE_PWM`](https://docs.zephyrproject.org/latest/doxygen/html/group__regulator__adp5360.html#gab23bd874d4ad25543a728bd0b5d03ced) | `1` | 脉宽调制（Pulse Width Modulation，PWM）模式 |
