# 第38章\_设备电源管理基础结构

原文：[structpm__device__base](https://docs.zephyrproject.org/latest/doxygen/html/structpm__device__base.html)。读取日期：2026-10-13，`latest`。

`struct pm_device_base` 保存设备电源管理（Device Power Management，Device PM）信息，包含通用和同步两类 PM 设备共有的字段。使用头文件 `zephyr/pm/device.h`。

## 38.1\_数据成员

| 成员 | 原始类型 | 含义 |
| --- | --- | --- |
| [`flags`](https://docs.zephyrproject.org/latest/doxygen/html/structpm__device__base.html#af9a24c7aaa0425b335fe147908c1fd4d) | [`atomic_t`](../atomic_reference/P001_原子操作公共接口.md#ga124f07c3a788e53c3a40e4e1c06d8af8) | 设备 PM 状态标志（Status Flags） |
| [`state`](https://docs.zephyrproject.org/latest/doxygen/html/structpm__device__base.html#af4c9ef16800538148dcfa1d93b69bccb) | `enum pm_device_state` | 设备电源状态（Power State） |
| [`action_cb`](https://docs.zephyrproject.org/latest/doxygen/html/structpm__device__base.html#abd3a07f0e7c54cb0bee7f835be79dac6) | [`pm_device_action_cb_t`](https://docs.zephyrproject.org/latest/doxygen/html/group__subsys__pm__device.html#ga81d4ee32f5bbb1b343234b9b3afc0179) | 设备 PM 动作回调（Action Callback） |
| [`usage`](https://docs.zephyrproject.org/latest/doxygen/html/structpm__device__base.html#a4a9eeb093de1b1e60222b25a06a6361d) | [`uint32_t`](https://docs.zephyrproject.org/latest/doxygen/html/stdint_8h.html#a0a8582351ac627ee8bde2973c825e47f) | 设备使用计数（Usage Count） |

状态枚举和回调定义见[设备电源管理接口](P036_设备电源管理接口.md)。
