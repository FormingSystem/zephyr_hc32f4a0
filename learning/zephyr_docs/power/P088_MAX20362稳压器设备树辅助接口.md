# 第88章\_MAX20362稳压器设备树辅助接口

原文：[group__regulator__max20362](https://docs.zephyrproject.org/latest/doxygen/html/group__regulator__max20362.html)。读取日期：2026-10-13，`latest`。

本页提供Analog Devices MAX20362 电源管理集成电路（Power Management Integrated Circuit，PMIC）稳压器驱动的**设备树辅助接口（Devicetree Helpers）**。相应头文件包含方式为：

```c
#include <zephyr/dt-bindings/regulator/max20362.h>
```

BAT和BBIN是原页使用的电源节点名称，分别表示电池侧与升降压输入侧；mV为毫伏（Millivolt）。DVS表示动态电压调节（Dynamic Voltage Scaling），LDO表示低压差稳压器（Low-Dropout Regulator）。

## 88.1\_BAT到BBIN压降

```c
#define MAX20362_BAT_BBIN_VDROP_55MV 0
#define MAX20362_BAT_BBIN_VDROP_100MV 1
#define MAX20362_BAT_BBIN_VDROP_150MV 2
#define MAX20362_BAT_BBIN_VDROP_200MV 3
```
