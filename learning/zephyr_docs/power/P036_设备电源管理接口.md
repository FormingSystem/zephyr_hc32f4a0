# 第36章\_设备电源管理接口

原文：[group__subsys__pm__device](https://docs.zephyrproject.org/latest/doxygen/html/group__subsys__pm__device.html)。读取日期：2026-10-13，`latest`。

设备电源管理（Device Power Management，Device PM）应用程序编程接口（Application Programming Interface，API）自 Zephyr 2.7 提供，版本1.0.0，使用头文件 `zephyr/pm/device.h`。

结构 [`pm_device_base`](P038_设备电源管理基础结构.md) 保存设备 PM 信息；[`pm_device`](P039_通用设备运行时电源结构.md) 保存采用通用 PM 的设备运行时信息；[`pm_device_isr`](P040_中断安全设备电源结构.md) 保存采用同步 PM 的设备运行时信息。

## 36.1\_定义与取得PM资源

原始宏值中，`DT_INVALID_NODE` 表示无效设备树节点，`DT_DRV_INST` 按驱动实例取得节点；`Z_DEVICE_DT_DEV_ID` 转换设备标识，`Z_PM_DEVICE_DEFINE`、`Z_PM_DEVICE_GET` 是内部资源定义/查找辅助宏，`COND_CODE_1`、`IS_EMPTY` 处理可选参数。

下列三个定义宏的参数 `pm_action_cb` 都是 PM 控制回调（Callback），可变参数 `...` 是可选的中断服务程序（Interrupt Service Routine，ISR）安全标志，使用 [`PM_DEVICE_ISR_SAFE`](https://docs.zephyrproject.org/latest/doxygen/html/group__subsys__pm__device.html#ga18bb96fc4d5003516ab2eaf73cb35912) 或 `0`。未启用 Kconfig 选项 [`CONFIG_PM_DEVICE`](https://docs.zephyrproject.org/latest/kconfig.html#CONFIG_PM_DEVICE) 时，定义宏不执行任何操作。

`PM_DEVICE_DEFINE(dev_id, pm_action_cb, ...)` 按设备标识 `dev_id` 定义资源：

```c
Z_PM_DEVICE_DEFINE(DT_INVALID_NODE, dev_id, pm_action_cb,       \
                COND_CODE_1(IS_EMPTY(__VA_ARGS__), (0), (__VA_ARGS__)))
```

`PM_DEVICE_DT_DEFINE(node_id, pm_action_cb, ...)` 按设备树（Devicetree，DT）节点标识 `node_id` 定义资源：

```c
Z_PM_DEVICE_DEFINE(node_id, Z_DEVICE_DT_DEV_ID(node_id), pm_action_cb, \
                COND_CODE_1(IS_EMPTY(__VA_ARGS__), (0), (__VA_ARGS__)))
```

`PM_DEVICE_DT_GET(node_id)` 取得节点 `node_id` 的设备 PM 资源引用；禁用 [`CONFIG_PM_DEVICE`](https://docs.zephyrproject.org/latest/kconfig.html#CONFIG_PM_DEVICE) 时为 `NULL`：

```c
PM_DEVICE_GET(Z_DEVICE_DT_DEV_ID(node_id))
```

`PM_DEVICE_DT_INST_DEFINE(idx, pm_action_cb, ...)` 按实例索引 `idx` 定义资源：

```c
Z_PM_DEVICE_DEFINE(DT_DRV_INST(idx),                            \
                   Z_DEVICE_DT_DEV_ID(DT_DRV_INST(idx)),        \
                   pm_action_cb,                                \
                   COND_CODE_1(IS_EMPTY(__VA_ARGS__), (0), (__VA_ARGS__)))
```

`PM_DEVICE_DT_INST_GET(idx)` 取得实例索引 `idx` 对应的资源引用；禁用 [`CONFIG_PM_DEVICE`](https://docs.zephyrproject.org/latest/kconfig.html#CONFIG_PM_DEVICE) 时为 `NULL`：

```c
PM_DEVICE_DT_GET(DT_DRV_INST(idx))
```

`PM_DEVICE_GET(dev_id)` 取得设备标识 `dev_id` 对应的资源引用；禁用 [`CONFIG_PM_DEVICE`](https://docs.zephyrproject.org/latest/kconfig.html#CONFIG_PM_DEVICE) 时为 `NULL`：

```c
Z_PM_DEVICE_GET(dev_id)
```

以上保留的是原页宏展开值；`Z_PM_*` 是内部资源定义/查找辅助宏，`DT_*` 与 `Z_DEVICE_DT_DEV_ID` 用于设备树节点及设备标识转换，[`COND_CODE_1`](../util_reference/P001_通用工具公共接口.md#ga358bc3e7669c860a98839a51cd526b20)、[`IS_EMPTY`](../util_reference/P001_通用工具公共接口.md#gab9487eea703d51cb1f235432dab4a1c7) 用于处理可选参数。

## 36.2\_中断安全标志

```c
#define PM_DEVICE_ISR_SAFE 1
```

在设备定义中使用此标志，表示设备运行时 PM 接口可从任何上下文调用，PM 动作同步执行。由于动作在临界区（Critical Section）中运行，这适用于挂起和恢复耗时短的设备。此模式占用资源更少，约节省80字节随机存取存储器（Random Access Memory，RAM），并支持从包括中断在内的任何上下文使用运行时 PM。

## 36.3\_动作与失败回调类型

```c
typedef int (*pm_device_action_cb_t)(const struct device *dev, enum pm_device_action action);
typedef bool (*pm_device_action_failed_cb_t)(const struct device *dev, int err);
```

动作回调 [`pm_device_action_cb_t`](https://docs.zephyrproject.org/latest/doxygen/html/group__subsys__pm__device.html#ga81d4ee32f5bbb1b343234b9b3afc0179) 的 `dev` 是设备实例，`action` 是请求的动作。成功返回 `0`，失败返回负错误码；不支持请求动作时返回 `-ENOTSUP`。

失败回调 [`pm_device_action_failed_cb_t`](https://docs.zephyrproject.org/latest/doxygen/html/group__subsys__pm__device.html#ga9cfb6437873089714635d2b26aafefac) 的 `dev` 是动作失败的设备，`err` 是失败返回码。返回 [`true`](https://docs.zephyrproject.org/latest/doxygen/html/stdbool_8h.html#a41f9c5fb8b08eb5dc3edce4dcb37fee7) 继续遍历，返回 [`false`](https://docs.zephyrproject.org/latest/doxygen/html/stdbool_8h.html#a65e9886d74aaee76545e83dd09011727) 停止遍历。

## 36.4\_设备动作枚举

枚举 `enum pm_device_action` 定义以下动作：

| 动作 | 含义与约束 |
| --- | --- |
| [`PM_DEVICE_ACTION_SUSPEND`](https://docs.zephyrproject.org/latest/doxygen/html/group__subsys__pm__device.html#ggaee5546eacb9be7caa9d59ab63926cc4ca5b7ae11deaee85eb0b8452bc89383790) | 挂起（Suspend） |
| [`PM_DEVICE_ACTION_RESUME`](https://docs.zephyrproject.org/latest/doxygen/html/group__subsys__pm__device.html#ggaee5546eacb9be7caa9d59ab63926cc4ca757c6ab81eeac0d6afae479d6a0ac564) | 恢复（Resume） |
| [`PM_DEVICE_ACTION_TURN_OFF`](https://docs.zephyrproject.org/latest/doxygen/html/group__subsys__pm__device.html#ggaee5546eacb9be7caa9d59ab63926cc4ca2bcd7dee3a85b27157bbc465bacf521e) | 关闭（Turn Off），仅由电源域（Power Domain）触发，通知设备所属电源域即将断电。动作完成后，设备必须已禁用中断请求（Interrupt Request，IRQ）、释放资源并充分准备好失去供电。实际断电时机由平台决定，可能立即发生、延后发生或作为系统级电源切换的一部分；本动作只表示应准备可能的失电 |
| [`PM_DEVICE_ACTION_TURN_ON`](https://docs.zephyrproject.org/latest/doxygen/html/group__subsys__pm__device.html#ggaee5546eacb9be7caa9d59ab63926cc4cac7690e0ffd27742acf58fdbdb7b89544) | 开启（Turn On），仅由电源域触发，通知设备所属电源域已经上电 |

## 36.5\_设备状态枚举

枚举 `enum pm_device_state` 包含四个状态。

**活动状态（Active），[`PM_DEVICE_STATE_ACTIVE`](https://docs.zephyrproject.org/latest/doxygen/html/group__subsys__pm__device.html#gga561c0789071e3c3963f21f4c4a1bb2c6a54b207e01b4dfc5e1ff56149817120c7)**：硬件已供电，系统需要该设备；设备应启用，可以调用任何设备驱动 API。

**挂起状态（Suspended），[`PM_DEVICE_STATE_SUSPENDED`](https://docs.zephyrproject.org/latest/doxygen/html/group__subsys__pm__device.html#gga561c0789071e3c3963f21f4c4a1bb2c6a03f61cb7cd5e4820c1c731500fd053b5)**：硬件仍有供电，但系统不需要该设备。设备应进入其最低内部功耗状态，通常称为“禁用”或“停止”。如果指定了电源域设备，且该电源域不再被系统需要，则先将本设备转为 [`PM_DEVICE_STATE_OFF`](https://docs.zephyrproject.org/latest/doxygen/html/group__subsys__pm__device.html#gga561c0789071e3c3963f21f4c4a1bb2c6a2456389354b744d4e96847e38f8b61c2)，再将电源域设备转为 [`PM_DEVICE_STATE_SUSPENDED`](https://docs.zephyrproject.org/latest/doxygen/html/group__subsys__pm__device.html#gga561c0789071e3c3963f21f4c4a1bb2c6a03f61cb7cd5e4820c1c731500fd053b5)。

驱动可以在挂起状态下反初始化（Deinitialize）。驱动反初始化后，隐式转入 [`PM_DEVICE_STATE_OFF`](https://docs.zephyrproject.org/latest/doxygen/html/group__subsys__pm__device.html#gga561c0789071e3c3963f21f4c4a1bb2c6a2456389354b744d4e96847e38f8b61c2)，因为硬件可能失去供电，而此时已没有驱动响应对应的 [`PM_DEVICE_ACTION_TURN_OFF`](https://docs.zephyrproject.org/latest/doxygen/html/group__subsys__pm__device.html#ggaee5546eacb9be7caa9d59ab63926cc4ca2bcd7dee3a85b27157bbc465bacf521e) 动作。挂起状态**不是**设备仍部分可操作的“低功耗”状态；后者通过驱动专用 API 配置，只适用于 [`PM_DEVICE_STATE_ACTIVE`](https://docs.zephyrproject.org/latest/doxygen/html/group__subsys__pm__device.html#gga561c0789071e3c3963f21f4c4a1bb2c6a54b207e01b4dfc5e1ff56149817120c7)。

**正在挂起（Suspending），[`PM_DEVICE_STATE_SUSPENDING`](https://docs.zephyrproject.org/latest/doxygen/html/group__subsys__pm__device.html#gga561c0789071e3c3963f21f4c4a1bb2c6a51a5904aff980deff73d29568b6f7deb)**：硬件有供电，但系统已不再需要设备，已安排挂起。调用 [`pm_device_runtime_put_async()`](https://docs.zephyrproject.org/latest/doxygen/html/group__subsys__pm__device__runtime.html#ga9e90089b0ab78f365905418646e196c6) 后，挂起委托给 PM 子系统执行，可以设置驻留时间（Residency），避免不必要的挂起/恢复循环。如果系统重新需要设备，会取消这一挂起安排。在此状态下不得调用设备驱动 API。该状态是对驱动隐藏的内部状态：进入时不会调用任何 [`pm_device_action`](https://docs.zephyrproject.org/latest/doxygen/html/group__subsys__pm__device.html#gaee5546eacb9be7caa9d59ab63926cc4c)，只由 `PM_DEVICE_RUNTIME` 运行时机制使用。

**关闭状态（Off），[`PM_DEVICE_STATE_OFF`](https://docs.zephyrproject.org/latest/doxygen/html/group__subsys__pm__device.html#gga561c0789071e3c3963f21f4c4a1bb2c6a2456389354b744d4e96847e38f8b61c2)**：硬件没有供电，是驱动开始初始化时的初始状态。驱动初始化时无法知道设备内部状态，因此 [`PM_DEVICE_ACTION_TURN_ON`](https://docs.zephyrproject.org/latest/doxygen/html/group__subsys__pm__device.html#ggaee5546eacb9be7caa9d59ab63926cc4cac7690e0ffd27742acf58fdbdb7b89544) 应能将设备从任意内部状态转为 [`PM_DEVICE_STATE_SUSPENDED`](https://docs.zephyrproject.org/latest/doxygen/html/group__subsys__pm__device.html#gga561c0789071e3c3963f21f4c4a1bb2c6a03f61cb7cd5e4820c1c731500fd053b5)，因为跨复位不能保证状态。通常先翻转复位引脚，或写寄存器触发软件复位，再执行达到挂起状态所需的其他配置。

无法这样复位的设备，驱动必须假定初始化时设备处于 [`PM_DEVICE_STATE_OFF`](https://docs.zephyrproject.org/latest/doxygen/html/group__subsys__pm__device.html#gga561c0789071e3c3963f21f4c4a1bb2c6a2456389354b744d4e96847e38f8b61c2) 或 [`PM_DEVICE_STATE_SUSPENDED`](https://docs.zephyrproject.org/latest/doxygen/html/group__subsys__pm__device.html#gga561c0789071e3c3963f21f4c4a1bb2c6a03f61cb7cd5e4820c1c731500fd053b5)，因为驱动只能在这两个状态中反初始化。如果设备属于某个电源域，且该电源域开始被系统需要，则先将电源域设备转为 [`PM_DEVICE_STATE_ACTIVE`](https://docs.zephyrproject.org/latest/doxygen/html/group__subsys__pm__device.html#gga561c0789071e3c3963f21f4c4a1bb2c6a54b207e01b4dfc5e1ff56149817120c7)，再将本设备转为 [`PM_DEVICE_STATE_SUSPENDED`](https://docs.zephyrproject.org/latest/doxygen/html/group__subsys__pm__device.html#gga561c0789071e3c3963f21f4c4a1bb2c6a03f61cb7cd5e4820c1c731500fd053b5)。

## 36.6\_执行设备动作

```c
int pm_device_action_run(const struct device *dev, enum pm_device_action action);
void pm_device_children_action_run(const struct device *dev, enum pm_device_action action,
                                    pm_device_action_failed_cb_t failure_cb);
```

[`pm_device_action_run()`](https://docs.zephyrproject.org/latest/doxygen/html/group__subsys__pm__device.html#ga3840d6e7832a00b93763247a5951bfde) 调用设备 PM 控制回调，让设备执行请求动作所需的操作。`dev` 为设备实例，`action` 为动作；成功返回 `0`，失败返回负错误码。

| 返回值 | 原页规定的含义 |
| --- | --- |
| `-ENOTSUP` | 设备当前状态不支持该动作（Not Supported） |
| `-EALREADY` | 设备已经处于该动作所要求的状态（Already） |
| `-EBUSY` | 设备正在切换状态（Busy） |
| `-ENOSYS` | 设备不支持 PM（Not Implemented） |
| `-EPERM` | 设备电源状态已锁定（Operation Not Permitted） |

[`pm_device_children_action_run()`](https://docs.zephyrproject.org/latest/doxygen/html/group__subsys__pm__device.html#ga765a5412f66070ccefd8e80ed9f62b1b) 对 `dev` 的所有子设备调用 PM 控制回调，执行 `action`。子设备动作失败时调用 `failure_cb`，该参数可以为 `NULL`；回调的继续/停止规则见前文。

## 36.7\_读取状态与初始化状态标记

```c
const char *pm_device_state_str(enum pm_device_state state);
int pm_device_state_get(const struct device *dev, enum pm_device_state *state);
static inline void pm_device_init_suspended(const struct device *dev);
static inline void pm_device_init_off(const struct device *dev);
```

[`pm_device_state_str()`](https://docs.zephyrproject.org/latest/doxygen/html/group__subsys__pm__device.html#gad109511e4314fa6145ee97dd655ec7bb) 返回状态标识 [`state`](https://docs.zephyrproject.org/latest/doxygen/html/parser__state_8h.html#adc6e5733fc3c22f0a7b2914188c49c90) 对应的名称。

[`pm_device_state_get()`](https://docs.zephyrproject.org/latest/doxygen/html/group__subsys__pm__device.html#gaffcf0aea5df10657235d4ed1f8c74d5a) 将设备实例 `dev` 的电源状态存入 [`state`](https://docs.zephyrproject.org/latest/doxygen/html/parser__state_8h.html#adc6e5733fc3c22f0a7b2914188c49c90) 指向的位置；成功返回 `0`，设备没有实现 PM 时返回 `-ENOSYS`。

默认设备状态初始化为 [`PM_DEVICE_STATE_ACTIVE`](https://docs.zephyrproject.org/latest/doxygen/html/group__subsys__pm__device.html#gga561c0789071e3c3963f21f4c4a1bb2c6a54b207e01b4dfc5e1ff56149817120c7)，通常初始化函数会恢复并配置设备，使其可运行。为了节能，有些驱动只将设备初始化到挂起状态，或主动挂起；可用 [`pm_device_init_suspended()`](https://docs.zephyrproject.org/latest/doxygen/html/group__subsys__pm__device.html#ga4c366f49e326a8b8e01d90cb2ee424ba) 通知 PM 子系统实际为 [`PM_DEVICE_STATE_SUSPENDED`](https://docs.zephyrproject.org/latest/doxygen/html/group__subsys__pm__device.html#gga561c0789071e3c3963f21f4c4a1bb2c6a03f61cb7cd5e4820c1c731500fd053b5)。

启用电源域后，设备可能接在可切换的电源上，启动时尚未供电；可用 [`pm_device_init_off()`](https://docs.zephyrproject.org/latest/doxygen/html/group__subsys__pm__device.html#gafb12ecf4679dd449e2faad0ede2c75fd) 通知 PM 子系统实际为 [`PM_DEVICE_STATE_OFF`](https://docs.zephyrproject.org/latest/doxygen/html/group__subsys__pm__device.html#gga561c0789071e3c3963f21f4c4a1bb2c6a2456389354b744d4e96847e38f8b61c2)。两者的 `dev` 都是设备实例。

## 36.8\_忙状态

```c
void pm_device_busy_set(const struct device *dev);
void pm_device_busy_clear(const struct device *dev);
bool pm_device_is_any_busy(void);
bool pm_device_is_busy(const struct device *dev);
```

[`pm_device_busy_set()`](https://docs.zephyrproject.org/latest/doxygen/html/group__subsys__pm__device.html#ga7ea002352f3d1c90aecff1d54c255a06) 标记设备实例 `dev` 为忙（Busy），例如设备正在事务处理中。系统进入低功耗状态时不会挂起被标记为忙的设备。[`pm_device_busy_clear()`](https://docs.zephyrproject.org/latest/doxygen/html/group__subsys__pm__device.html#ga8b527314f0c61b85602876b4f5a52275) 清除此标记。

[`pm_device_is_any_busy()`](https://docs.zephyrproject.org/latest/doxygen/html/group__subsys__pm__device.html#gae59a1fbcd2399717076fbfcee1e5e411) 在一个或多个设备忙时返回 [`true`](https://docs.zephyrproject.org/latest/doxygen/html/stdbool_8h.html#a41f9c5fb8b08eb5dc3edce4dcb37fee7)，没有设备忙时返回 [`false`](https://docs.zephyrproject.org/latest/doxygen/html/stdbool_8h.html#a65e9886d74aaee76545e83dd09011727)。[`pm_device_is_busy()`](https://docs.zephyrproject.org/latest/doxygen/html/group__subsys__pm__device.html#ga8ff7c3197d5ded860878302d00ac709c) 对指定设备作相同检查，忙返回 [`true`](https://docs.zephyrproject.org/latest/doxygen/html/stdbool_8h.html#a41f9c5fb8b08eb5dc3edce4dcb37fee7)，否则返回 [`false`](https://docs.zephyrproject.org/latest/doxygen/html/stdbool_8h.html#a65e9886d74aaee76545e83dd09011727)。

## 36.9\_唤醒源

```c
bool pm_device_wakeup_enable(const struct device *dev, bool enable);
bool pm_device_wakeup_is_enabled(const struct device *dev);
bool pm_device_wakeup_is_capable(const struct device *dev);
```

`dev` 为设备实例。[`pm_device_wakeup_enable()`](https://docs.zephyrproject.org/latest/doxygen/html/group__subsys__pm__device.html#ga74fde62f71393fb9863916b3a2e5c460) 启用或禁用设备作为唤醒源（Wakeup Source），`enable=true` 启用，[`false`](https://docs.zephyrproject.org/latest/doxygen/html/stdbool_8h.html#a65e9886d74aaee76545e83dd09011727) 禁用。标记为唤醒源的设备在系统进入低功耗时不被挂起，从而可以唤醒系统。原页返回值说明为：成功启用唤醒源返回 [`true`](https://docs.zephyrproject.org/latest/doxygen/html/stdbool_8h.html#a41f9c5fb8b08eb5dc3edce4dcb37fee7)，未成功启用返回 [`false`](https://docs.zephyrproject.org/latest/doxygen/html/stdbool_8h.html#a65e9886d74aaee76545e83dd09011727)。

[`pm_device_wakeup_is_enabled()`](https://docs.zephyrproject.org/latest/doxygen/html/group__subsys__pm__device.html#ga0716c6158804ac48022280d8d237f8c1) 检查唤醒源是否启用，启用返回 [`true`](https://docs.zephyrproject.org/latest/doxygen/html/stdbool_8h.html#a41f9c5fb8b08eb5dc3edce4dcb37fee7)，否则返回 [`false`](https://docs.zephyrproject.org/latest/doxygen/html/stdbool_8h.html#a65e9886d74aaee76545e83dd09011727)。[`pm_device_wakeup_is_capable()`](https://docs.zephyrproject.org/latest/doxygen/html/group__subsys__pm__device.html#gac818aafb748b57d70909808b45d89379) 检查设备是否具备唤醒能力，有能力返回 [`true`](https://docs.zephyrproject.org/latest/doxygen/html/stdbool_8h.html#a41f9c5fb8b08eb5dc3edce4dcb37fee7)，否则返回 [`false`](https://docs.zephyrproject.org/latest/doxygen/html/stdbool_8h.html#a65e9886d74aaee76545e83dd09011727)。

## 36.10\_电源域与供电检查

```c
bool pm_device_on_power_domain(const struct device *dev);
bool pm_device_is_powered(const struct device *dev);
int pm_device_power_domain_add(const struct device *dev, const struct device *domain);
int pm_device_power_domain_remove(const struct device *dev, const struct device *domain);
```

[`pm_device_on_power_domain()`](https://docs.zephyrproject.org/latest/doxygen/html/group__subsys__pm__device.html#ga32eb5e210d2f0ba533b0185a94c8744e) 检查设备实例 `dev` 是否处于可切换电源域，是则返回 [`true`](https://docs.zephyrproject.org/latest/doxygen/html/stdbool_8h.html#a41f9c5fb8b08eb5dc3edce4dcb37fee7)，否则返回 `false`。

[`pm_device_is_powered()`](https://docs.zephyrproject.org/latest/doxygen/html/group__subsys__pm__device.html#ga9e926dffd7eafc567499ce1ea537486b) 在设备当前有供电，或被假定有供电时返回 `true`。不支持 PM 或不在 PM 电源域中的设备被假定有供电。当前未供电时返回 `false`。

[`pm_device_power_domain_add()`](https://docs.zephyrproject.org/latest/doxygen/html/group__subsys__pm__device.html#gaa10a3f1ce71409cb591db416a1611377) 将 `dev` 加入电源域 `domain`：成功返回 `0`；已属于该域返回 `-EALREADY`；应用构建时未包含电源域支持返回 `-ENOSYS`；域中没有容纳该设备的空间返回 `-ENOSPC`（No Space）。

[`pm_device_power_domain_remove()`](https://docs.zephyrproject.org/latest/doxygen/html/group__subsys__pm__device.html#ga1d7ab9b0b497e016b9b22d2506cd23f9) 从 `domain` 移除 `dev`：成功返回 `0`；构建未包含电源域支持返回 `-ENOSYS`；设备不属于该域返回 `-ENOENT`（No Entry）。

## 36.11\_驱动初始化与反初始化

本节的 Kconfig 选项 `CONFIG_PM_DEVICE` 控制设备 PM，`CONFIG_PM_DEVICE_RUNTIME` 控制设备运行时 PM。

```c
int pm_device_driver_init(const struct device *dev, pm_device_action_cb_t action_cb);
int pm_device_driver_deinit(const struct device *dev, pm_device_action_cb_t action_cb);
```

两者的 `dev` 是设备实例，`action_cb` 是设备 PM 控制回调；成功返回 `0`，失败返回负错误码。

[`pm_device_driver_init()`](https://docs.zephyrproject.org/latest/doxygen/html/group__subsys__pm__device.html#gad563094c2d4ad066bc4ce30586e13fb3) 使用驱动内部 PM 钩子（Hook），将设备从关闭状态移到系统要求的初始状态。**必须在驱动初始化函数末尾调用。**原页列出的初始状态规则为：

| 目标状态 | 条件 |
| --- | --- |
| `ACTIVE` | `CONFIG_PM_DEVICE=n`；或 `CONFIG_PM_DEVICE=y` 且 `CONFIG_PM_DEVICE_RUNTIME=n`；或 `CONFIG_PM_DEVICE_RUNTIME=y` 且 `!pm_device_runtime_is_enabled(dev)` |
| `SUSPENDED` | `CONFIG_PM_DEVICE_RUNTIME=y`，且设备的父电源域为 `ACTIVE` |
| `OFF` | `CONFIG_PM_DEVICE_RUNTIME=y`，且设备的父电源域为 `SUSPENDED` |

[`pm_device_driver_deinit()`](https://docs.zephyrproject.org/latest/doxygen/html/group__subsys__pm__device.html#gadf145eb83c32eac741ab08fb7b262a55) 为驱动反初始化做准备，确保设备处于 `SUSPENDED` 或 `OFF`。`CONFIG_PM_DEVICE=y` 时检查 PM 是否已将设备转为这两个状态之一；`CONFIG_PM_DEVICE=n` 时使用驱动内部 PM 钩子将设备移至 `SUSPENDED`。**必须在驱动反初始化函数开头调用。**设备既未挂起也未关闭时返回 `-EBUSY`。
