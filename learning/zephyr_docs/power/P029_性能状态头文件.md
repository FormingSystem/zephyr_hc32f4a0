# 第29章\_性能状态头文件

原文：[pstate_8h](https://docs.zephyrproject.org/latest/doxygen/html/pstate_8h.html)。读取日期：2026-10-13，`latest`。

`zephyr/cpu_freq/pstate.h` 是中央处理器（Central Processing Unit，CPU）调频性能状态（Performance State，P-state）的头文件。

## 29.1\_包含关系

以下按原页保留全部包含项：

```c
#include <zephyr/types.h>
#include <zephyr/devicetree.h>
#include <zephyr/cpu_freq/pstate.h>
```

[查看官方头文件源码](https://docs.zephyrproject.org/latest/doxygen/html/pstate_8h_source.html)。

## 29.2\_数据结构与宏

`struct pstate` 表示 CPU 性能状态，成员说明见[性能状态结构](P026_性能状态结构.md)。

| 宏签名 | 用途 |
| --- | --- |
| `PSTATE_DT_SYM(_node)` | 根据设备树（Devicetree）依赖序号（Dependency Ordinal）构造性能状态符号 |
| `PSTATE_DT_DEFINE(_node, _config)` | 为指定节点标识定义全部性能状态信息 |
| `PSTATE_DT_GET(_node)` | 根据设备树节点标识取得性能状态引用 |

本页列出原文的宏签名；宏值和参数说明见[性能状态接口](P025_性能状态接口.md)。
