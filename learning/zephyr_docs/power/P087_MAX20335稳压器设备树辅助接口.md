# 第87章\_MAX20335稳压器设备树辅助接口

原文：[group__regulator__max20335](https://docs.zephyrproject.org/latest/doxygen/html/group__regulator__max20335.html)。读取日期：2026-10-13，`latest`。

本页提供Maxim MAX20335 电源管理集成电路（Power Management Integrated Circuit，PMIC）稳压器驱动的**设备树辅助接口（Devicetree Helpers）**。相应头文件包含方式为：

```c
#include <zephyr/dt-bindings/regulator/max20335.h>
```

## 87.1\_稳压器模式

```c
#define MAX20335_LDO_MODE 0
#define MAX20335_LOAD_SWITCH_MODE 1
```

| 宏 | 值 | 中文说明 |
| --- | --- | --- |
| [`MAX20335_LDO_MODE`](https://docs.zephyrproject.org/latest/doxygen/html/group__regulator__max20335.html#gab4f4f6f5831a451e24d0a98ed3f11ef7) | `0` | 低压差稳压器（Low-Dropout Regulator，LDO）模式 |
| [`MAX20335_LOAD_SWITCH_MODE`](https://docs.zephyrproject.org/latest/doxygen/html/group__regulator__max20335.html#ga3f2088abb8548e0bf7326be2bf778c16) | `1` | 负载开关模式（Load Switch Mode） |
