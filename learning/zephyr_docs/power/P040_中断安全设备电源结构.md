# 第40章\_中断安全设备电源结构

原文：[structpm__device__isr](https://docs.zephyrproject.org/latest/doxygen/html/structpm__device__isr.html)。读取日期：2026-10-13，`latest`。

`struct pm_device_isr` 保存采用同步电源管理（Synchronous Power Management，PM）的设备运行时信息。中断服务程序（Interrupt Service Routine，ISR）也可使用这类设备的运行时 PM 接口。

同步 PM 适用于挂起和恢复操作短暂、不阻塞、可在临界区（Critical Section）内完成的设备。这种情况下，运行时 PM 应用程序编程接口（Application Programming Interface，API）可以从任意上下文调用。使用头文件 `zephyr/pm/device.h`。
