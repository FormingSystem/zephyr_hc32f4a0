# 第71章\_电源状态头文件

原文：[state_8h](https://docs.zephyrproject.org/latest/doxygen/html/state_8h.html)。读取日期：2026-10-13，`latest`。

`zephyr/pm/state.h` 定义系统电源管理（System Power Management，PM）的状态。本页涉及中央处理器（Central Processing Unit，CPU）和设备树（Devicetree，DT）。

## 71.1\_包含关系与源文件

```c
#include <zephyr/sys/util.h>
#include <zephyr/devicetree.h>
#include <errno.h>
```

[查看官方源码](https://docs.zephyrproject.org/latest/doxygen/html/state_8h_source.html)。

## 71.2\_数据结构

| 结构 | 中文说明 |

| [`pm_state_info`](https://docs.zephyrproject.org/latest/doxygen/html/structpm__state__info.html) | 电源管理状态的信息，见[状态信息结构](P047_电源状态信息结构.md) |
| [`pm_state_constraint`](https://docs.zephyrproject.org/latest/doxygen/html/structpm__state__constraint.html) | 为设备或系统功能引用某个电源状态作为约束所需的信息，见[状态约束结构](P045_电源状态约束结构.md) |

下表保留原页宏签名。`node_id` 为节点标识符，`prop` 为属性；宏值和完整示例见[电源状态接口](P034_电源状态接口.md)。

| 宏签名 | 中文说明 |
| --- | --- |
| `PM_STATE_INFO_DT_INIT(node_id)` | 使用兼容字符串为 `zephyr,power-state` 的设备树节点标识符，初始化 `struct pm_state_info` |
| `PM_STATE_DT_INIT(node_id)` | 使用兼容字符串为 `zephyr,power-state` 的设备树节点标识符，初始化 `enum pm_state` |
| `DT_NUM_CPU_POWER_STATES(node_id)` | 取得指定CPU节点支持且已启用的电源状态数量 |
| `PM_STATE_INFO_LIST_FROM_DT_CPU(node_id)` | 使用指定CPU节点中存在且已启用的全部状态信息，初始化 `struct pm_state_info` 数组 |

## 71.4\_状态枚举

```c
enum pm_state {
    PM_STATE_ACTIVE,
    PM_STATE_RUNTIME_IDLE,
    PM_STATE_SUSPEND_TO_IDLE,
    PM_STATE_STANDBY,
    PM_STATE_SUSPEND_TO_RAM,
    PM_STATE_SUSPEND_TO_DISK,
    PM_STATE_SOFT_OFF,
    PM_STATE_COUNT
};
```

这些枚举项依次表示活动（Active）、运行时空闲（Runtime Idle）、挂起到空闲（Suspend to Idle）、待机（Standby）、挂起到随机存取存储器（Suspend to RAM，RAM为Random Access Memory）、挂起到磁盘（Suspend to Disk）、软关机（Soft Off），以及枚举计数（Count）。各状态的完整定义见[电源状态接口](P034_电源状态接口.md)。
