# 第74章\_父级稳压器接口

原文：[group__regulator__parent__interface](https://docs.zephyrproject.org/latest/doxygen/html/group__regulator__parent__interface.html)。读取日期：2026-10-13，`latest`。

父级稳压器接口（Regulator Parent Interface）用于控制父级稳压器设备。相关子主题为 [MAX20362公共接口](P083_MAX20362父级控制接口.md)和[PCA9420辅助接口](P084_PCA9420父级控制接口.md)。

```c
#include <zephyr/drivers/regulator.h>
```

## 74.1\_设置动态电压状态

```c
static inline int regulator_parent_dvs_state_set(const struct device *dev, regulator_dvs_state_t state);
```

一些电源管理集成电路（Power Management Integrated Circuit，PMIC）通过为多个状态分别编程电压值，提供动态电压调节（Dynamic Voltage Scaling，DVS）功能。这些状态可由硬件通过通用输入输出（General-Purpose Input/Output，GPIO）引脚自动切换。

某些微控制器（Microcontroller Unit，MCU）甚至可以在进入低功耗模式时自动配置特定输出引脚，使PMIC状态变化无需软件介入。需要由软件切换状态时，可使用 [`regulator_parent_dvs_state_set()`](https://docs.zephyrproject.org/latest/doxygen/html/group__regulator__parent__interface.html#ga980feabe8415a9643eb66c8566d700bf)。

| 参数 | 中文说明 |
| --- | --- |
| `dev` | 父级稳压器设备实例 |
| [`state`](https://docs.zephyrproject.org/latest/doxygen/html/parser__state_8h.html#adc6e5733fc3c22f0a7b2914188c49c90) | DVS状态，采用厂商专用标识符 |

成功返回 `0`，失败返回负错误码（errno）：`-ENOTSUP` 表示不支持给定状态，`-EPERM` 表示不能由软件改变状态，`-ENOSYS` 表示功能未实现。

## 74.2\_进入运输模式

```c
static inline int regulator_parent_ship_mode(const struct device *dev);
```

一些PMIC具有运输模式（Ship Mode），使系统能够节省电力。通常通过引脚电平变化退出这一低功耗状态。

需要进入运输模式时调用 [`regulator_parent_ship_mode()`](https://docs.zephyrproject.org/latest/doxygen/html/group__regulator__parent__interface.html#gaa65d0a8d792256818a2ba06ad67a4f02)。参数 `dev` 为父级稳压器设备实例。成功返回 `0`，失败返回负错误码；`-ENOSYS` 表示功能未实现。
