# 第67章\_系统电源管理头文件

原文：[pm_8h](https://docs.zephyrproject.org/latest/doxygen/html/pm_8h.html)。读取日期：2026-10-13，`latest`。

`zephyr/pm/pm.h`：电源管理（Power Management，PM）应用程序编程接口（Application Programming Interface，API）的头文件。SoC表示片上系统（System on Chip）。

## 67.1\_包含关系与源文件

```c
#include <zephyr/types.h>
#include <zephyr/sys/slist.h>
#include <zephyr/pm/state.h>
#include <zephyr/toolchain.h>
#include <errno.h>
#include <stdbool.h>
```

[查看官方源码](https://docs.zephyrproject.org/latest/doxygen/html/pm_8h_source.html)。

## 67.2\_类型与宏

通知结构 [`pm_notifier`](https://docs.zephyrproject.org/latest/doxygen/html/structpm__notifier.html) 保存电源管理通知信息，详见[电源管理通知结构](P041_电源管理通知结构.md)。

## 67.3\_函数声明与用途

```c
bool pm_state_force (uint8_t cpu, const struct pm_state_info *info);
void pm_notifier_register (struct pm_notifier *notifier);
int pm_notifier_unregister (struct pm_notifier *notifier);
const struct pm_state_info * pm_state_next_get (uint8_t cpu);
void pm_system_resume (void);
void pm_state_set (enum pm_state state, uint8_t substate_id);
void pm_state_exit_post_ops (enum pm_state state, uint8_t substate_id);
```

| 函数 | 原页用途 |

| [`pm_notifier_unregister()`](https://docs.zephyrproject.org/latest/doxygen/html/group__subsys__pm__sys.html#gab0856d662e50a3847a1b70cb8370849a) | 注销电源管理通知对象。 |
| [`pm_state_next_get()`](https://docs.zephyrproject.org/latest/doxygen/html/group__subsys__pm__sys.html#ga3861a1a0009b96d15de00059257848dd) | 取得下一次将使用的电源状态。 |
