# 第113章\_nPM6001稳压器设备树头文件

原文：[npm6001_8h](https://docs.zephyrproject.org/latest/doxygen/html/npm6001_8h.html)。读取日期：2026-10-13，`latest`。

本头文件提供Nordic nPM6001 电源管理集成电路（Power Management Integrated Circuit，PMIC）稳压器驱动的**设备树辅助接口（Devicetree Helpers）**。头文件路径为 `zephyr/dt-bindings/regulator/npm6001.h`。


## 113.1\_源码与包含关系

[查看官方源码](https://docs.zephyrproject.org/latest/doxygen/html/npm6001_8h_source.html)。本参考页未列出包含项。

相关的[设备树辅助接口](P098_nPM6001稳压器设备树辅助接口.md)给出同组常量说明。

## 113.2\_稳压器模式

```c
#define NPM6001_MODE_HYS 0
#define NPM6001_MODE_PWM 1
```

| 宏 | 值 | 中文说明 |
| --- | --- | --- |
| [`NPM6001_MODE_HYS`](https://docs.zephyrproject.org/latest/doxygen/html/group__regulator__npm6001.html#gac0d4c250b4f1ec831dd12f54b0b9c7e5) | `0` | 迟滞模式（Hysteretic Mode） |
| [`NPM6001_MODE_PWM`](https://docs.zephyrproject.org/latest/doxygen/html/group__regulator__npm6001.html#ga499a8fb0120be966aef80dea307f178f) | `1` | 脉宽调制（Pulse Width Modulation，PWM）模式 |
