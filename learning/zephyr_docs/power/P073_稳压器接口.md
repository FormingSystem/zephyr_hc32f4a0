# 第73章\_稳压器接口

原文：[group__regulator__interface](https://docs.zephyrproject.org/latest/doxygen/html/group__regulator__interface.html)。读取日期：2026-10-13，`latest`。

稳压器（Regulator）应用程序编程接口（Application Programming Interface，API）自Zephyr **2.4** 引入，接口版本为 **0.1.0**。

```c
#include <zephyr/drivers/regulator.h>
```

这是稳压器驱动API的主头文件。相关主题包括[设备树稳压器接口](P081_设备树稳压器辅助接口目录.md)、[稳压器伪设备驱动](../hardware/P498_稳压器伪设备接口.md)、[驱动后端接口](P077_稳压器驱动后端接口.md)和[父级稳压器接口](P074_父级稳压器接口.md)。

本页所有函数的 `dev` 参数均指稳压器设备实例。声明中的 `static inline` 对应原页详细接口的静态内联标记。

## 73.1\_类型、错误标志与事件

动态电压调节（Dynamic Voltage Scaling，DVS）状态、工作模式（Mode）和错误标志（Error Flags）分别使用以下类型：

```c
typedef uint8_t regulator_dvs_state_t;
typedef uint8_t regulator_mode_t;
typedef uint8_t regulator_error_flags_t;
```

前两个是不透明类型（Opaque Type），分别存储稳压器DVS状态和模式；第三个是不透明位图（Bitmap），表示下列错误标志。`BIT(n)` 表示第n个位的位掩码。

```c
#define REGULATOR_ERROR_OVER_VOLTAGE BIT(0)
#define REGULATOR_ERROR_OVER_CURRENT BIT(1)
#define REGULATOR_ERROR_OVER_TEMP BIT(2)
```

三个标志依次表示电压过高（Over Voltage）、电流过高（Over Current）、温度过高（Over Temperature）。

稳压器事件（Event）使用结构 [`regulator_event`](P080_稳压器事件结构.md) 和下列事件类型枚举：

```c
enum regulator_event_type {
    REGULATOR_VOLTAGE_DETECTED,
    REGULATOR_VOLTAGE_REMOVED
};
```

[`REGULATOR_VOLTAGE_DETECTED`](https://docs.zephyrproject.org/latest/doxygen/html/group__regulator__interface.html#ggad21aa12c6df397ee4f6591b8f6266763a27703e597bfb6cc290eeaac9442776a1) 表示检测到稳压器电压，[`REGULATOR_VOLTAGE_REMOVED`](https://docs.zephyrproject.org/latest/doxygen/html/group__regulator__interface.html#ggad21aa12c6df397ee4f6591b8f6266763ab919a4157612a42cfff33616802c2e9b) 表示稳压器电压已移除。

回调（Callback）函数类型为：

```c
typedef void (*regulator_callback_t)(const struct device *dev, const struct regulator_event *const evt, const void *const user_data);
```

其中 `dev` 为稳压器设备实例，`evt` 为稳压器事件，`user_data` 为用户数据。

## 73.2\_启用、释放与状态查询

```c
int regulator_enable(const struct device *dev);
int regulator_disable(const struct device *dev);
bool regulator_is_enabled(const struct device *dev);
```

[`regulator_enable()`](https://docs.zephyrproject.org/latest/doxygen/html/group__regulator__interface.html#ga06e3109b9607521fe07686c6d601e460) 通过**引用计数（Reference Counting）**请求打开稳压器。稳压器达到稳定、可用状态后才被认为已经打开。始终开启的稳压器，以及在设备树（Devicetree）中设置 `regulator-always-on` 的稳压器，会一直保持启用，因此该函数总是成功。

[`regulator_disable()`](https://docs.zephyrproject.org/latest/doxygen/html/group__regulator__interface.html#gaac417fbf6e30bbbfbd5ea5029a8ef298) 释放此前一次成功的启用请求。**每次成功的 [`regulator_enable()`](https://docs.zephyrproject.org/latest/doxygen/html/group__regulator__interface.html#ga06e3109b9607521fe07686c6d601e460) 最多只能对应一次此调用。**始终开启或设置了 `regulator-always-on` 的稳压器会保持启用，释放函数仍总是成功。

上述启用与释放函数成功返回 `0`，失败返回负错误码（errno）。`-ENOTSUP` 分别表示无法控制稳压器的启用或禁用。

[`regulator_is_enabled()`](https://docs.zephyrproject.org/latest/doxygen/html/group__regulator__interface.html#ga28744a6cabadfe5a22bc96792c8ad124) 查询状态：启用返回 [`true`](https://docs.zephyrproject.org/latest/doxygen/html/stdbool_8h.html#a41f9c5fb8b08eb5dc3edce4dcb37fee7)，禁用返回 [`false`](https://docs.zephyrproject.org/latest/doxygen/html/stdbool_8h.html#a65e9886d74aaee76545e83dd09011727)。

## 73.3\_枚举支持的电压

```c
static inline unsigned int regulator_count_voltages(const struct device *dev);
static inline int regulator_list_voltage(const struct device *dev, unsigned int idx, int32_t *volt_uv);
```

稳压器支持的每个电压档位都有从 **0** 开始的索引。[`regulator_count_voltages()`](https://docs.zephyrproject.org/latest/doxygen/html/group__regulator__interface.html#ga96bf136ff2deca774931ca27300b03a6) 返回支持的电压档位数，与 [`regulator_list_voltage()`](https://docs.zephyrproject.org/latest/doxygen/html/group__regulator__interface.html#ga62d9ea1d7dc2987101cf31b324ca7c51) 配合可遍历所有支持电压。

列表函数的 `idx` 为电压索引，输出参数 `volt_uv` 接收对应电压，单位为微伏（Microvolt，µV）。索引对应受支持电压时返回 `0`，否则返回 `-EINVAL`。

## 73.4\_检查电压范围

```c
bool regulator_is_supported_voltage(const struct device *dev, int32_t min_uv, int32_t max_uv);
```

[`regulator_is_supported_voltage()`](https://docs.zephyrproject.org/latest/doxygen/html/group__regulator__interface.html#ga31b42ddfe94fee47158632f355ad864c) 检查是否支持指定范围内的电压。`min_uv` 为最小电压，`max_uv` 为最大电压，单位均为微伏。支持返回 [`true`](https://docs.zephyrproject.org/latest/doxygen/html/stdbool_8h.html#a41f9c5fb8b08eb5dc3edce4dcb37fee7)，不支持返回 [`false`](https://docs.zephyrproject.org/latest/doxygen/html/stdbool_8h.html#a65e9886d74aaee76545e83dd09011727)。

## 73.5\_设置和查询输出电压

```c
int regulator_set_voltage(const struct device *dev, int32_t min_uv, int32_t max_uv);
static inline int regulator_get_voltage(const struct device *dev, int32_t *volt_uv);
```

[`regulator_set_voltage()`](https://docs.zephyrproject.org/latest/doxygen/html/group__regulator__interface.html#ga2c2b345da9029013edbf59fd8c565d85) 将输出电压配置为最接近的受支持电压。参数 `min_uv`、`max_uv` 分别为可接受的最小和最大电压，单位为微伏。电压应用到当前活动或选中的模式。设备树中的 `regulator-min-microvolt` 和／或 `regulator-max-microvolt` 可以进一步限制输出电压。

通过 [`regulator_get_voltage()`](https://docs.zephyrproject.org/latest/doxygen/html/group__regulator__interface.html#gaa0114ee43a137ee98f98f5bce93d8579) 取得实际配置的输出电压，结果存入输出参数 `volt_uv`。

两个函数均在成功时返回 `0`，失败返回负错误码。设置函数的 `-EINVAL` 表示给定电压范围无效；两个函数的 `-ENOSYS` 均表示功能未实现。

## 73.6\_枚举支持的电流限制

```c
static inline unsigned int regulator_count_current_limits(const struct device *dev);
static inline int regulator_list_current_limit(const struct device *dev, unsigned int idx, int32_t *current_ua);
```

支持的每个电流限制（Current Limit）档位都有从 **0** 开始的索引。计数函数返回支持的档位数量，与列表函数配合可遍历所有档位。

列表函数的 `idx` 为电流档位索引，输出参数 `current_ua` 接收对应电流，单位为微安（Microampere，µA）。索引对应受支持档位时返回 `0`，否则返回 `-EINVAL`。

## 73.7\_设置和查询输出电流限制

```c
int regulator_set_current_limit(const struct device *dev, int32_t min_ua, int32_t max_ua);
static inline int regulator_get_current_limit(const struct device *dev, int32_t *curr_ua);
```

[`regulator_set_current_limit()`](https://docs.zephyrproject.org/latest/doxygen/html/group__regulator__interface.html#ga2ccf66175b37754e2c21f341ecb2acbd) 将输出电流限制配置为最接近的受支持档位。`min_ua` 和 `max_ua` 分别为可接受的最小、最大电流限制，单位为微安。

[`regulator_get_current_limit()`](https://docs.zephyrproject.org/latest/doxygen/html/group__regulator__interface.html#ga88c3ddeed962b5368713ad8fef0e7d7a) 取得实际配置的输出电流限制，存入输出参数 `curr_ua`。两个函数成功返回 `0`，失败返回负错误码。设置函数的 `-EINVAL` 表示给定电流范围无效；两个函数的 `-ENOSYS` 均表示功能未实现。

原页说明可用设备树属性 `current-min-microamp` 和／或 `current-max-microamp` 限制电流。

译注：核对官方[稳压器基础绑定](https://github.com/zephyrproject-rtos/zephyr/blob/main/dts/bindings/regulator/regulator.yaml)后，这两个属性的实际名称为 **`regulator-min-microamp`** 与 **`regulator-max-microamp`**；原接口说明的属性名称不一致，配置时应按绑定名称填写。

## 73.8\_设置和查询模式

```c
int regulator_set_mode(const struct device *dev, regulator_mode_t mode);
static inline int regulator_get_mode(const struct device *dev, regulator_mode_t *mode);
```

稳压器可支持多个模式，用于不同电压配置或更好的节能效果。设置函数将参数 `mode` 所指模式应用到稳压器；允许的模式可能受设备树属性 `regulator-allowed-modes` 限制。查询函数把当前模式写入输出参数 `mode`。

两个函数成功返回 `0`，失败返回负错误码。设置函数的 `-ENOTSUP` 表示不支持该模式；两个函数的 `-ENOSYS` 均表示功能未实现。

## 73.9\_主动放电

```c
static inline int regulator_set_active_discharge(const struct device *dev, bool active_discharge);
static inline int regulator_get_active_discharge(const struct device *dev, bool *active_discharge);
```

第一个函数设置主动放电（Active Discharge）的启用或禁用状态，参数 `active_discharge` 为所需状态。第二个函数查询此设置，并写入输出参数 `active_discharge`。

两个函数成功返回 `0`，失败返回负错误码；`-ENOSYS` 表示功能未实现。

## 73.10\_读取错误标志

```c
static inline int regulator_get_error_flags(const struct device *dev, regulator_error_flags_t *flags);
```

[`regulator_get_error_flags()`](https://docs.zephyrproject.org/latest/doxygen/html/group__regulator__interface.html#ga9133662844a20eaf703d6d075347c62f) 查询当前生效的错误标志，写入输出参数 [`flags`](https://docs.zephyrproject.org/latest/doxygen/html/parser_8h.html#ab6b306ef981f5e21bb41ea2c2dbe8cd9)。成功返回 `0`，失败返回负错误码；`-ENOSYS` 表示功能未实现。

## 73.11\_设置事件处理函数

```c
static inline int regulator_set_callback(const struct device *dev, regulator_callback_t cb, const void *const user_data);
```

稳压器可能在检测到电压等情况下产生中断。例如，通用串行总线（Universal Serial Bus，USB）的总线供电线路 `VBUS` 稳压器可以通过此机制通知设备已连接到端口。

[`regulator_set_callback()`](https://docs.zephyrproject.org/latest/doxygen/html/group__regulator__interface.html#gad63e752a30ec12edc6a12e5d08c573dd) 设置事件处理函数。参数 `cb` 为事件处理回调，`user_data` 为用户数据。成功返回 `0`，未实现此功能返回 `-ENOSYS`。
