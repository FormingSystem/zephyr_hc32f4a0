# 第83章\_MAX20362父级控制接口

原文：[group__regulator__parent__max20362](https://docs.zephyrproject.org/latest/doxygen/html/group__regulator__parent__max20362.html)。读取日期：2026-10-13，`latest`。

本页提供MAX20362稳压器（Regulator）驱动的公共应用程序编程接口（Application Programming Interface，API）。MAX20362是电源管理集成电路（Power Management Integrated Circuit，PMIC）；主头文件为 `zephyr/drivers/regulator/max20362.h`。

```c
#include <zephyr/drivers/regulator/max20362.h>
```

## 83.1\_主中断位

以下宏对应主中断寄存器 `INT`（地址 `0x14`）及其屏蔽寄存器 `INT_MASK`（地址 `0x18`）。中断屏蔽（Interrupt Mask）使用位掩码，`BIT(n)` 表示第n位。

```c
#define MAX20362_INT_CAPOVLO_MASK BIT(7)
#define MAX20362_INT_CAPUVLO_MASK BIT(6)
#define MAX20362_INT_BBSTON_MASK BIT(5)
#define MAX20362_INT_BBSTOFF_MASK BIT(4)
#define MAX20362_INT_BBINUVLO_MASK BIT(3)
#define MAX20362_INT_UVLO_MASK BIT(2)
#define MAX20362_INT_BSTFLT_MASK BIT(1)
#define MAX20362_INT_THMFLT_MASK BIT(0)
```

## 83.2\_低压差稳压器中断位

以下宏对应低压差稳压器（Low-Dropout Regulator，LDO）的中断寄存器 `LDO_INT`（`0x17`）和屏蔽寄存器 `LDO_INT_MASK`（`0x1B`）。

```c
#define MAX20362_LDOINT_DIV_MASK BIT(3)
#define MAX20362_LDOINT_SHR_MASK BIT(2)
#define MAX20362_LDOINT_THM_MASK BIT(1)
#define MAX20362_LDOINT_CLP_MASK BIT(0)
```

## 83.3\_Ingenuity中断位

以下宏对应Ingenuity中断寄存器 `INGEN_INT`（`0x16`）及屏蔽寄存器 `INGEN_INT_MASK`（`0x1A`）。Ingenuity是原页使用的功能名称，SIMO是原页使用的引脚标识。

```c
#define MAX20362_INGENINT_OUTTMO_MASK BIT(4)
#define MAX20362_INGENINT_DRPMIN_MASK BIT(3)
#define MAX20362_INGENINT_TNKTMO_MASK BIT(2)
#define MAX20362_INGENINT_SIMOPIN_MASK BIT(1)
#define MAX20362_INGENINT_DRPMAX_MASK BIT(0)
```

| --- | --- |

| [`MAX20362_INGENINT_DRPMIN_MASK`](https://docs.zephyrproject.org/latest/doxygen/html/group__regulator__parent__max20362.html#ga886c3bd5f8f04c496566d5ae4d830f7b) | 压降下限（Droop Min） |
| [`MAX20362_INGENINT_TNKTMO_MASK`](https://docs.zephyrproject.org/latest/doxygen/html/group__regulator__parent__max20362.html#ga860a173430349a49c5b731d18fd6f331) | 储能电容超时（Tank Timeout） |

| [`MAX20362_INGENINT_DRPMAX_MASK`](https://docs.zephyrproject.org/latest/doxygen/html/group__regulator__parent__max20362.html#ga54a06997b332c094d2c8451b299883a7) | 压降上限（Droop Max） |

译注：为核对原文的简略名称，查阅了 [MAX20362数据手册Rev.0](https://www.analog.com/media/en/technical-documentation/data-sheets/max20362.pdf)。其中第52页将Tank超时关联到输出启动后的CAP储能电容再充电阶段。另有两处名称差异：手册第53页将 `0x18` 的第3位命名为 `VddaUvloMsk`，第54页将 `0x1A` 的第3位命名为 `BootTmoMsk`；原API分别使用 `BBINUVLO` 和 `DRPMIN`。这里保留官方API名称、值及说明，工程使用时应按对应芯片手册核对位的实际含义。

## 83.4\_全部屏蔽的便捷值

```c
#define MAX20362_INT_MASK_ALL 0xFF
#define MAX20362_LDO_INT_MASK_ALL 0x0F
#define MAX20362_INGEN_INT_MASK_ALL 0x1F
```

第一个值屏蔽全部 `INT` 位；第二个屏蔽全部 `LDO_INT` 位，即 `DIV | SHR | THM | CLP`；第三个屏蔽全部 `INGEN_INT` 位，即 `OUTTMO | DRPMIN | TNKTMO | SIMOPIN | DRPMAX`。这些大写片段对应上面各宏的位名称。

## 83.5\_设置中断屏蔽寄存器

```c
int regulator_max20362_set_int_mask(const struct device *dev, uint8_t mask);
int regulator_max20362_set_ingen_int_mask(const struct device *dev, uint8_t mask);
int regulator_max20362_set_ldo_int_mask(const struct device *dev, uint8_t mask);
```

三个函数的 `dev` 均为驱动实例的设备结构指针，`mask` 为要写入的中断屏蔽值：**位值1表示屏蔽／禁用，位值0表示启用**。成功返回 `0`，失败返回负错误码（errno）。
