# 第79章\_父级稳压器驱动操作表

原文：[structregulator__parent__driver__api](https://docs.zephyrproject.org/latest/doxygen/html/structregulator__parent__driver__api.html)。读取日期：2026-10-13，`latest`。

[`regulator_parent_driver_api`](https://docs.zephyrproject.org/latest/doxygen/html/structregulator__parent__driver__api.html) 是父级稳压器（Regulator）驱动必须定义的应用程序编程接口（Application Programming Interface，API）结构。它包含驱动所实现操作的函数指针，以及驱动专用的其他常量数据。

```c
#include <zephyr/drivers/regulator.h>
```

## 79.1\_成员类型与要求

原页用 `REQ` 表示必需（Required）成员，必须由驱动设置；`OPT` 表示可选（Optional）成员。**本页列出的所有成员均标为可选。**

DVS表示动态电压调节（Dynamic Voltage Scaling），运输模式（Ship Mode）用于节省电力。

```c
struct regulator_parent_driver_api {
    regulator_dvs_state_set_t dvs_state_set;
    regulator_ship_mode_t ship_mode;
};
```
