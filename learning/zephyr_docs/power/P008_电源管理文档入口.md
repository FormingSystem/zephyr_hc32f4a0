# 第8章\_电源管理文档入口

原文：[Power Management](https://docs.zephyrproject.org/latest/services/pm/index.html)。读取日期：2026-10-12，`latest`。

Zephyr **实时操作系统（Real-Time Operating System，RTOS）** 电源管理子系统提供多种机制，使系统集成者能够充分利用 **片上系统（System on Chip，SoC）** 的节能特性实现电源管理。

## 8.1\_官方文档结构

| 文档 | 原页列出的内容 |
| --- | --- |
| [概述](P001_电源管理概述.md) | 通用 **电源管理（Power Management，PM）** 与 SoC 实现的分工 |
| [系统电源管理](P002_系统电源管理.md) | 介绍 |
| [设备电源管理](P003_设备电源管理.md) | 介绍、设备状态、完整及部分 PM 支持的设备模型、shell 命令、忙状态、设备与系统 PM 的配合、唤醒能力、示例 |
| [设备运行时PM](P004_设备运行时电源管理.md) | 介绍、设计原则、实现指南、示例 |
| [电源域](P005_电源域.md) | 介绍、实现指南、示例 |
