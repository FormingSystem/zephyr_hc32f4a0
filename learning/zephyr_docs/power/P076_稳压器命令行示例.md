# 第76章\_稳压器命令行示例

原文：[Regulator Shell Sample](https://docs.zephyrproject.org/latest/samples/regulator/regulator_shell/README.html)。读取日期：2026-10-13，`latest`。

此示例允许用户通过命令行解释器（Shell）与稳压器（Regulator）设备交互。[查看官方示例源码](https://github.com/zephyrproject-rtos/zephyr/tree/main/samples/regulator/regulator_shell)。

## 76.1\_构建与运行

按下列方式构建和烧录，将 `arduino_nano_matter` 替换为自己的开发板目标。命令使用Zephyr的工作区管理工具west。

```bash
west build -b arduino_nano_matter samples/regulator/regulator_shell
west flash
```

## 76.2\_命令帮助

在Shell中输入 `regulator` 即可访问稳压器命令模块。输入 `help` 可查看所有可用命令。
