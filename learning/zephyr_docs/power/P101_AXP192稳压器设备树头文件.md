# 第101章\_AXP192稳压器设备树头文件

原文：[dt-bindings_2regulator_2axp192_8h](https://docs.zephyrproject.org/latest/doxygen/html/dt-bindings_2regulator_2axp192_8h.html)。读取日期：2026-10-13，`latest`。

本头文件提供X-Powers AXP192 电源管理集成电路（Power Management Integrated Circuit，PMIC）稳压器驱动的**设备树辅助接口（Devicetree Helpers）**。头文件路径为 `zephyr/dt-bindings/regulator/axp192.h`。


DCDC表示直流到直流转换（DC-to-DC，DC为Direct Current）。

## 101.1\_源码与包含关系

[查看官方源码](https://docs.zephyrproject.org/latest/doxygen/html/dt-bindings_2regulator_2axp192_8h_source.html)。本参考页未列出包含项。

相关的[设备树辅助接口](P086_AXP192稳压器设备树辅助接口.md)给出同组常量说明。

## 101.2\_直流转换模式

```c
#define AXP192_DCDC_MODE_AUTO 0x00U
#define AXP192_DCDC_MODE_PWM 0x01U
```

| 宏 | 值 | 中文说明 |
| --- | --- | --- |
| [`AXP192_DCDC_MODE_AUTO`](https://docs.zephyrproject.org/latest/doxygen/html/group__regulator__axp192.html#ga08c7dbe4ab36c27901f7d6a513fe962c) | `0x00U` | 自动模式（Automatic Mode） |
| [`AXP192_DCDC_MODE_PWM`](https://docs.zephyrproject.org/latest/doxygen/html/group__regulator__axp192.html#gaeca7433bdd315f8ae1a218adcb972445) | `0x01U` | 脉宽调制（Pulse Width Modulation，PWM）模式 |
