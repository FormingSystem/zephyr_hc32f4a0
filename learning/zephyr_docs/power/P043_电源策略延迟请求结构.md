# 第43章\_电源策略延迟请求结构

原文：[structpm__policy__latency__request](https://docs.zephyrproject.org/latest/doxygen/html/structpm__policy__latency__request.html)。读取日期：2026-10-13，`latest`。

`struct pm_policy_latency_request` 表示电源管理（Power Management，PM）策略的延迟请求（Latency Request），使用头文件 `zephyr/pm/policy.h`。

## 43.1\_字段可见性

原文明确说明：此结构的所有字段均供内部私有使用（Private Usage）。该参考页未列出公共字段。

添加、更新与移除延迟要求见[系统电源管理策略接口](P035_系统电源管理策略接口.md)。
