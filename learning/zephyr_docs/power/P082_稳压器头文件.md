# 第82章\_稳压器头文件

原文：[regulator_8h](https://docs.zephyrproject.org/latest/doxygen/html/regulator_8h.html)。读取日期：2026-10-13，`latest`。

`zephyr/drivers/regulator.h` 是稳压器（Regulator）驱动应用程序编程接口（Application Programming Interface，API）的主头文件。

## 82.1\_包含关系与源码


[查看官方源码](https://docs.zephyrproject.org/latest/doxygen/html/regulator_8h_source.html)。

## 82.2\_结构与错误标志

本页列出[事件结构](P080_稳压器事件结构.md) [`regulator_event`](https://docs.zephyrproject.org/latest/doxygen/html/structregulator__event.html)、[父级驱动操作表](P079_父级稳压器驱动操作表.md) [`regulator_parent_driver_api`](https://docs.zephyrproject.org/latest/doxygen/html/structregulator__parent__driver__api.html) 与[稳压器驱动操作表](P078_稳压器驱动操作表.md) [`regulator_driver_api`](https://docs.zephyrproject.org/latest/doxygen/html/structregulator__driver__api.html)。

错误标志（Error Flags）如下，`BIT(n)` 为第n个位的位掩码：

```c
#define REGULATOR_ERROR_OVER_VOLTAGE BIT(0)
#define REGULATOR_ERROR_OVER_CURRENT BIT(1)
#define REGULATOR_ERROR_OVER_TEMP BIT(2)
```

三个标志依次表示电压过高（Over Voltage）、电流过高（Over Current）和温度过高（Over Temperature）。

## 82.3\_状态、模式与事件回调

以下类型分别保存动态电压调节（Dynamic Voltage Scaling，DVS）状态、工作模式（Mode）和错误标志位图（Bitmap）。它们作为不透明类型（Opaque Type）使用。最后一项是事件回调（Callback）签名。

```c
typedef uint8_t regulator_dvs_state_t;
typedef uint8_t regulator_mode_t;
typedef uint8_t regulator_error_flags_t;
typedef void (*regulator_callback_t)(const struct device *dev, const struct regulator_event *const evt, const void *const user_data);
```

## 82.5\_事件类型枚举

```c
enum regulator_event_type {
    REGULATOR_VOLTAGE_DETECTED,
    REGULATOR_VOLTAGE_REMOVED
};
```

[`REGULATOR_VOLTAGE_DETECTED`](https://docs.zephyrproject.org/latest/doxygen/html/group__regulator__interface.html#ggad21aa12c6df397ee4f6591b8f6266763a27703e597bfb6cc290eeaac9442776a1) 表示检测到稳压器电压，[`REGULATOR_VOLTAGE_REMOVED`](https://docs.zephyrproject.org/latest/doxygen/html/group__regulator__interface.html#ggad21aa12c6df397ee4f6591b8f6266763ab919a4157612a42cfff33616802c2e9b) 表示稳压器电压已移除。
