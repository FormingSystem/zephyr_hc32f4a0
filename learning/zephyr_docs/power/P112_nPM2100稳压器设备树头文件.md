# 第112章\_nPM2100稳压器设备树头文件

原文：[dt-bindings_2regulator_2npm2100_8h](https://docs.zephyrproject.org/latest/doxygen/html/dt-bindings_2regulator_2npm2100_8h.html)。读取日期：2026-10-13，`latest`。

本头文件提供Nordic nPM2100 电源管理集成电路（Power Management Integrated Circuit，PMIC）稳压器驱动的**设备树辅助接口（Devicetree Helpers）**。头文件路径为 `zephyr/dt-bindings/regulator/npm2100.h`。


BOOST表示升压转换器（Boost Converter）。GPIO表示通用输入输出（General-Purpose Input/Output）；LDOSW是低压差稳压器／负载开关（Low-Dropout Regulator / Load Switch）部分的名称。

## 112.1\_源码与包含关系

[查看官方源码](https://docs.zephyrproject.org/latest/doxygen/html/dt-bindings_2regulator_2npm2100_8h_source.html)。本参考页未列出包含项。

相关的[设备树辅助接口](P097_nPM2100稳压器设备树辅助接口.md)给出同组常量说明。
