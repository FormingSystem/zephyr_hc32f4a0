# 第32章\_系统电源管理接口

原文：[group__subsys__pm__sys](https://docs.zephyrproject.org/latest/doxygen/html/group__subsys__pm__sys.html)。读取日期：2026-10-13，`latest`。

系统电源管理（Power Management，PM）应用程序编程接口（Application Programming Interface，API）自 Zephyr 1.2 提供，版本为1.0.0。使用头文件 `zephyr/pm/pm.h`。相关主题为[钩子](P033_系统电源管理钩子.md)与[策略](P035_系统电源管理策略接口.md)；通知对象使用结构 [`pm_notifier`](P041_电源管理通知结构.md)。

## 32.1\_强制下一次电源状态

```c
bool pm_state_force(uint8_t cpu, const struct pm_state_info *info);
```

覆盖 PM 策略的决策，强制在下一次进入空闲线程（Idle Thread）时使用指定电源状态。**只能在线程上下文（Thread Context）运行。**

参数 `cpu` 是中央处理器（Central Processing Unit，CPU）索引；`info` 指向应在挂起操作中采用的电源状态信息。原页没有进一步解释本函数的布尔返回值。

## 32.2\_注册与注销通知对象

```c
void pm_notifier_register(struct pm_notifier *notifier);
int pm_notifier_unregister(struct pm_notifier *notifier);
```

[`pm_notifier_register()`](https://docs.zephyrproject.org/latest/doxygen/html/group__subsys__pm__sys.html#ga066945118b8f287ee56aacf41b677a78) 将参数 `notifier` 指定的通知对象（Notifier）注册到 PM 通知列表。

[`pm_notifier_unregister()`](https://docs.zephyrproject.org/latest/doxygen/html/group__subsys__pm__sys.html#gab0856d662e50a3847a1b70cb8370849a) 将该对象从列表中移除，此后不再调用它的回调（Callback）。成功返回 `0`，失败返回负错误码（Errno）。

## 32.3\_读取下一个状态

```c
const struct pm_state_info *pm_state_next_get(uint8_t cpu);
```

返回片上系统（System on Chip，SoC）下一次将使用的 [`pm_state_info`](P047_电源状态信息结构.md) 状态信息。`cpu` 为 CPU 索引。

## 32.4\_通知内核退出睡眠

```c
void pm_system_resume(void);
```

如果先前处理了对应的 `pm_system_suspend()` 通知，且未返回 `PM_STATE_ACTIVE` 活动状态，本函数通知系统已退出内核空闲。

应在导致内核退出空闲的事件所对应的中断服务程序（Interrupt Service Routine，ISR）上下文中调用。

对于进入低功耗状态时必须启用中断的 CPU 电源状态，例如 x86 的 C1，这一步是必需的。在这种情况下，事件唤醒 CPU 后会立即进入 ISR，CPU 等待指令之后的代码尚无机会运行。如果唤醒事件通知时没有需要处理的操作，则可以忽略此通知。
