# 第70章\_设备运行时电源头文件

原文：[device__runtime_8h](https://docs.zephyrproject.org/latest/doxygen/html/device__runtime_8h.html)。读取日期：2026-10-13，`latest`。

`zephyr/pm/device_runtime.h`：设备运行时电源管理（Device Runtime Power Management，PM）应用程序编程接口（Application Programming Interface，API）的头文件。

## 70.1\_包含关系与源文件

```c
#include <zephyr/device.h>
#include <zephyr/kernel.h>
```

[查看官方源码](https://docs.zephyrproject.org/latest/doxygen/html/device__runtime_8h_source.html)。

## 70.2\_类型与宏

原页列出12个失败日志宏。`GET`记录恢复失败（Failed to Resume），`PUT`记录挂起失败（Failed to Suspend）；`DBG`、`WRN`、`ERR`分别是调试（Debug）、警告（Warning）、错误（Error）级别。带 `LOG_INST_` 前缀的宏面向日志实例（Logging Instance）。

| 宏签名 | 原页用途 |
| --- | --- |
| `LOG_DBG_PM_DEVICE_RUNTIME_GET(dev, ...)` | 向日志写入恢复失败的调试消息 |
| `LOG_WRN_PM_DEVICE_RUNTIME_GET(dev, ...)` | 向日志写入恢复失败的警告消息 |
| `LOG_ERR_PM_DEVICE_RUNTIME_GET(dev, ...)` | 向日志写入恢复失败的错误消息 |
| `LOG_DBG_PM_DEVICE_RUNTIME_PUT(dev, ...)` | 向日志写入挂起失败的调试消息 |
| `LOG_WRN_PM_DEVICE_RUNTIME_PUT(dev, ...)` | 向日志写入挂起失败的警告消息 |
| `LOG_ERR_PM_DEVICE_RUNTIME_PUT(dev, ...)` | 向日志写入挂起失败的错误消息 |
| `LOG_INST_DBG_PM_DEVICE_RUNTIME_GET(_log_inst, dev, ...)` | 向指定日志实例写入恢复失败的调试消息 |
| `LOG_INST_WRN_PM_DEVICE_RUNTIME_GET(_log_inst, dev, ...)` | 向指定日志实例写入恢复失败的警告消息 |
| `LOG_INST_ERR_PM_DEVICE_RUNTIME_GET(_log_inst, dev, ...)` | 向指定日志实例写入恢复失败的错误消息 |
| `LOG_INST_DBG_PM_DEVICE_RUNTIME_PUT(_log_inst, dev, ...)` | 向指定日志实例写入挂起失败的调试消息 |
| `LOG_INST_WRN_PM_DEVICE_RUNTIME_PUT(_log_inst, dev, ...)` | 向指定日志实例写入挂起失败的警告消息 |
| `LOG_INST_ERR_PM_DEVICE_RUNTIME_PUT(_log_inst, dev, ...)` | 向指定日志实例写入挂起失败的错误消息 |

宏展开值和参数规则见本章末的运行时接口说明。
