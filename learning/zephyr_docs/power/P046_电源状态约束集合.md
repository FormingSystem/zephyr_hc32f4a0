# 第46章\_电源状态约束集合

原文：[structpm__state__constraints](https://docs.zephyrproject.org/latest/doxygen/html/structpm__state__constraints.html)。读取日期：2026-10-13，`latest`。

`struct pm_state_constraints` 表示多个电源状态约束（Power State Constraint）的集合。使用头文件 `zephyr/pm/state.h`。

## 46.1\_数据成员

| 成员 | 原始类型 | 含义 |
| --- | --- | --- |
| [`list`](https://docs.zephyrproject.org/latest/doxygen/html/structpm__state__constraints.html#a1a4b1ecf767148ef1ebed535369291a0) | `struct pm_state_constraint *` | 电源状态约束数组 |
| [`count`](https://docs.zephyrproject.org/latest/doxygen/html/structpm__state__constraints.html#a248e920d4b1bcfe5834a9afd2ca48667) | `size_t` | 数组中的约束数量 |

每项的结构见[电源状态约束结构](P045_电源状态约束结构.md)。
