# 第47章\_电源状态信息结构

原文：[structpm__state__info](https://docs.zephyrproject.org/latest/doxygen/html/structpm__state__info.html)。读取日期：2026-10-13，`latest`。

`struct pm_state_info` 保存电源管理（Power Management，PM）状态信息。使用头文件 `zephyr/pm/state.h`。

## 47.1\_数据成员

| 成员 | 原始类型 | 含义与约束 |
| --- | --- | --- |
| [`state`](https://docs.zephyrproject.org/latest/doxygen/html/structpm__state__info.html#aed57fc8a935951aa2687614b954c7225) | `enum pm_state` | 电源管理状态 |
| [`substate_id`](https://docs.zephyrproject.org/latest/doxygen/html/structpm__state__info.html#a422bc0c9aedc107dbfa57c3ac8eb2445) | [`uint8_t`](https://docs.zephyrproject.org/latest/doxygen/html/stdint_8h.html#a3cb4a16b0e8d6af0af86d4fd6ba5fd9d) | 子状态标识（Substate ID）；一些平台有多个状态映射到同一个 Zephyr 电源状态，通过此字段区分 |
| [`pm_device_disabled`](https://docs.zephyrproject.org/latest/doxygen/html/structpm__state__info.html#ac0a5ee091648225ba25ea34c75163814) | [`bool`](https://docs.zephyrproject.org/latest/doxygen/html/stdbool_8h.html#abb452686968e48b67397da5f97445f5b) | 控制此状态是否触发设备 PM。值为 `false` 时，PM 子系统在进入该状态前挂起设备，并在离开时正确恢复设备 |
| [`min_residency_us`](https://docs.zephyrproject.org/latest/doxygen/html/structpm__state__info.html#a442654715d3872de1b7b0dcf08bffb8b) | [`uint32_t`](https://docs.zephyrproject.org/latest/doxygen/html/stdint_8h.html#a0a8582351ac627ee8bde2973c825e47f) | 最小驻留时间（Minimum Residency），单位为微秒：使进入该空闲状态在能耗上值得的最短时间。`0` 表示该状态未提供此属性 |
| [`exit_latency_us`](https://docs.zephyrproject.org/latest/doxygen/html/structpm__state__info.html#a6fc8e0a78df78c7a28a0bc2a27292818) | [`uint32_t`](https://docs.zephyrproject.org/latest/doxygen/html/stdint_8h.html#a0a8582351ac627ee8bde2973c825e47f) | 退出空闲状态所需的最坏情况延迟（Worst-Case Exit Latency），单位为微秒。`0` 表示该状态未提供此属性 |

## 47.2\_子状态示例

以下设备树（Devicetree）片段将两个平台状态映射到同一 Zephyr 状态，通过 `substate-id` 区分；原始驻留时间、退出延迟和设备 PM 标志完整保留：

```devicetree
power-states {
   state0: state0 {
           compatible = "zephyr,power-state";
           power-state-name = "suspend-to-idle";
           substate-id = <1>;
           min-residency-us = <10000>;
           exit-latency-us = <100>;
   };
   state1: state1 {
           compatible = "zephyr,power-state";
           power-state-name = "suspend-to-idle";
           substate-id = <2>;
           min-residency-us = <20000>;
           exit-latency-us = <200>;
           zephyr,pm-device-disabled;
   };
};
```

完整枚举及查询接口见[电源状态接口](P034_电源状态接口.md)。
