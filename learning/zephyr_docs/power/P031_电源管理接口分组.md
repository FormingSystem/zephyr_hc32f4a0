# 第31章\_电源管理接口分组

原文：[group__subsys__pm](https://docs.zephyrproject.org/latest/doxygen/html/group__subsys__pm.html)。读取日期：2026-10-13，`latest`。

系统与设备电源管理（Power Management，PM）接口自 Zephyr 1.2 提供。主头文件为 `pm.h`，它声明电源管理应用程序编程接口（Application Programming Interface，API）。

## 31.1\_接口主题

| 主题 | 说明 |
| --- | --- |
| [CPU电源管理](P061_CPU电源管理接口.md) | 中央处理器（Central Processing Unit，CPU）电源管理 |
| [设备](P036_设备电源管理接口.md) | 设备电源管理（Device PM）接口 |
| [设备运行时](P037_设备运行时电源管理接口.md) | 设备运行时电源管理（Device Runtime PM）接口 |
| [S2RAM接口](P062_挂起到RAM接口.md) | 挂起到随机存取存储器（Suspend to RAM，S2RAM）接口 |
| [状态](P034_电源状态接口.md) | 系统电源管理状态 |
| [系统](P032_系统电源管理接口.md) | 系统电源管理接口 |

原页列出的文件参考：[pm.h](P067_系统电源管理头文件.md)。
