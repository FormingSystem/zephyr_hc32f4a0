# 第81章\_设备树稳压器辅助接口目录

原文：[group__devicetree-regulator](https://docs.zephyrproject.org/latest/doxygen/html/group__devicetree-regulator.html)。读取日期：2026-10-13，`latest`。

本页汇总稳压器（Regulator）驱动的设备树（Devicetree）辅助接口。PMIC表示电源管理集成电路（Power Management Integrated Circuit），VREF表示参考电压（Voltage Reference），DCDC表示直流到直流转换（DC-to-DC，DC为Direct Current）。
