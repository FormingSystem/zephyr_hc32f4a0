# 第1章\_电源管理概述

原文：[Overview](https://docs.zephyrproject.org/latest/services/pm/overview.html)。读取日期：2026-10-12，`latest`。

**电源管理（Power Management，PM）**子系统的接口与 **应用程序编程接口（Application Programming Interface，API）** 设计为独立于架构和 **片上系统（System on Chip，SoC）**，便于把电源管理实现适配到不同芯片与架构。

这种独立性通过分离通用 PM 基础设施与 SoC 专用实现获得，从而向操作系统其他部分和应用层提供一致的抽象。

## 1.1\_功能分类

电源管理分为[系统电源管理](P002_系统电源管理.md)和[设备电源管理](P003_设备电源管理.md)。
