# 第63章\_系统关机接口

原文：[group__sys__poweroff](https://docs.zephyrproject.org/latest/doxygen/html/group__sys__poweroff.html)。读取日期：2026-10-13，`latest`。

系统关机（System Power Off）应用程序编程接口（Application Programming Interface，API）自 Zephyr 3.5 提供，版本1.0.0，使用头文件 `zephyr/sys/poweroff.h`。

<a id="gaf4552a8ea40b4adb94f85b0a1ff06e39"></a>

## 63.1\_立即关机

```c
FUNC_NORETURN void sys_poweroff(void);
```

本函数立即关闭系统。`FUNC_NORETURN` 标记函数不会返回。调用者负责保证系统已经处于可安全断电的状态，并且必须在调用前启用需要的唤醒源（Wakeup Source）。

使用该接口必须启用 Kconfig 配置选项 [`CONFIG_POWEROFF`](https://docs.zephyrproject.org/latest/kconfig.html#CONFIG_POWEROFF)。头文件参考见[系统关机头文件](P066_系统关机头文件.md)。
