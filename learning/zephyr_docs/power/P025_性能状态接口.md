# 第25章\_性能状态接口

原文：[group__subsys__cpu__freq__pstate](https://docs.zephyrproject.org/latest/doxygen/html/group__subsys__cpu__freq__pstate.html)。读取日期：2026-10-13，`latest`。

本页描述中央处理器（Central Processing Unit，CPU）调频性能状态（Performance State，P-state）。自 Zephyr 4.3 提供，应用程序编程接口（Application Programming Interface，API）版本为 0.8.0。头文件为 `zephyr/cpu_freq/pstate.h`，数据结构见[性能状态结构](P026_性能状态结构.md)。

## 25.1\_定义节点的性能状态信息

宏签名为 `PSTATE_DT_DEFINE(_node, _config)`，为指定的设备树（Devicetree）节点标识定义完整的性能状态信息。原页给出的宏值如下：

```c
const struct pstate PSTATE_DT_SYM(_node) = {                                               \
        .load_threshold = DT_PROP(_node, load_threshold),                                  \
        .config = _config,                                                                 \
};
```

| 参数 | 含义 |
| --- | --- |
| `_node` | 节点标识 |
| `_config` | 指向该状态的片上系统（System on Chip，SoC）专用配置的指针 |

## 25.2\_获取性能状态引用

宏签名为 `PSTATE_DT_GET(_node)`，从设备树节点标识取得性能状态引用，用于 [`DT_FOREACH_CHILD()`](../dt_foreach_reference/P001_设备树遍历宏.md#ga2f4eead8e8190110f5c0eb353e6a408f) 或类似宏。`_node` 是节点标识。原页宏值：

```c
&PSTATE_DT_SYM(_node)
```

## 25.3\_构造性能状态符号

宏签名为 `PSTATE_DT_SYM(_node)`，根据设备树依赖序号（Dependency Ordinal）合成性能状态的符号名。原页宏值：

```c
_CONCAT(__pstate_, DT_DEP_ORD(_node))
```

译注：以上按官方页面展示宏的展开值；宏签名中的参数是该展开值的输入，代码块并非独立应用代码。[`DT_PROP`](../dt_property_reference/P001_设备树属性读取宏.md#ga8e1fd9ebacd85d2013df027d041d506b) 读取属性，[`DT_DEP_ORD`](../dt_node_reference/P004_设备树依赖顺序宏.md#ga5b96dccfd349dd0ddba1812aa942c1bd) 取得依赖序号，`_CONCAT` 拼接符号，`DT_FOREACH_CHILD` 遍历子节点。完整头文件见[性能状态头文件](P029_性能状态头文件.md)。
