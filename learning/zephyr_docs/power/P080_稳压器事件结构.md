# 第80章\_稳压器事件结构

原文：[structregulator__event](https://docs.zephyrproject.org/latest/doxygen/html/structregulator__event.html)。读取日期：2026-10-13，`latest`。

[`regulator_event`](https://docs.zephyrproject.org/latest/doxygen/html/structregulator__event.html) 是稳压器（Regulator）的事件（Event）结构。

```c
#include <zephyr/drivers/regulator.h>
```

## 80.1\_成员

```c
struct regulator_event {
    enum regulator_event_type type;
};
```

成员 [`type`](https://docs.zephyrproject.org/latest/doxygen/html/structregulator__event.html#ac2aeb7b44893bc89f217170e76cc11c7) 表示事件类型，其类型为 `enum regulator_event_type`。枚举定义和事件回调见[稳压器接口](P073_稳压器接口.md)。

## 80.2\_来源

结构文档从 `zephyr/drivers/regulator.h` 生成，见[头文件参考](P082_稳压器头文件.md)。
