# 第42章\_电源策略事件结构

原文：[structpm__policy__event](https://docs.zephyrproject.org/latest/doxygen/html/structpm__policy__event.html)。读取日期：2026-10-13，`latest`。

`struct pm_policy_event` 表示电源管理（Power Management，PM）策略的事件（Event），使用头文件 `zephyr/pm/policy.h`。

## 42.1\_字段可见性

原文明确说明：此结构的所有字段均供内部私有使用（Private Usage）。该参考页未列出公共字段。

通过[系统电源管理策略接口](P035_系统电源管理策略接口.md)登记、更新和注销事件。
