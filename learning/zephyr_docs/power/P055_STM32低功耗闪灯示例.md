# 第55章\_STM32低功耗闪灯示例

原文：[Blinky with power management](https://docs.zephyrproject.org/latest/samples/boards/st/power_mgmt/blinky/README.html)。读取日期：2026-10-13，`latest`。

## 55.1\_概述

本最小应用在低功耗环境中通过通用输入输出（General-Purpose Input/Output，GPIO）应用程序编程接口（Application Programming Interface，API）驱动发光二极管（Light-Emitting Diode，LED）闪烁，演示基本电源管理（Power Management，PM）行为。

在设备树（Devicetree）中，通过标准化的 chosen 项 `zephyr,system-timer` 选择作为系统定时器的低功耗定时器（Low-Power Timer，LPTIM）实例。设置预分频器（Prescaler）降低 LPTIM 输入时钟频率后，可以使用更长的睡眠超时，并相应调整 Kconfig 选项 [`CONFIG_SYS_CLOCK_TICKS_PER_SEC`](https://docs.zephyrproject.org/latest/kconfig.html#CONFIG_SYS_CLOCK_TICKS_PER_SEC)。

例如，使用32768 Hz低速外部时钟（Low-Speed External，LSE）并设置预分频值 `<32>`，内核睡眠时间可达 `65536 * 32/32768 = 64` 秒，此时 [`CONFIG_SYS_CLOCK_TICKS_PER_SEC`](https://docs.zephyrproject.org/latest/kconfig.html#CONFIG_SYS_CLOCK_TICKS_PER_SEC) 设置为1024。

## 55.2\_要求

开发板应支持 PM。STM32 目标需要一种可替代 Cortex SysTick 系统节拍定时器、并能在核心睡眠状态中使用的时钟源，例如 [LPTIM绑定](../stm32_ti_silabs_timer_binding_reference/P007_st_stm32-lptim.md#std-dtcompatible-st-stm32-lptim)定义的定时器。

## 55.3\_构建与运行

将 `stm32l562e_dk` 替换为自己的开发板：

```shell
west build -b stm32l562e_dk samples/boards/st/power_mgmt/blinky
west flash
```

烧录后，LED 按常量 `SLEEP_TIME_MS` 指定的固定周期闪烁。定义LPTIM的 `st,prescaler` 属性后，可以测试更长的低功耗周期，最长64秒。

## 55.4\_调试警告与PM配置

调试本示例可能需要 `CONFIG_DEBUG=y`。它会启用 [`CONFIG_STM32_ENABLE_DEBUG_SLEEP_STOP`](https://docs.zephyrproject.org/latest/kconfig.html#CONFIG_STM32_ENABLE_DEBUG_SLEEP_STOP)，使系统无法实现预期的低功耗：进入低功耗模式时，本应关闭的电源域仍保持供电，以确保调试逻辑始终可用。因此，这一配置下低功耗模式不再降低系统功耗，与本示例演示目标相反。

默认启用设备PM选项 [`CONFIG_PM_DEVICE`](https://docs.zephyrproject.org/latest/kconfig.html#CONFIG_PM_DEVICE) 和运行时PM选项 [`CONFIG_PM_DEVICE_RUNTIME`](https://docs.zephyrproject.org/latest/kconfig.html#CONFIG_PM_DEVICE_RUNTIME)，也可分别禁用其中一项，观察各配置的行为。
