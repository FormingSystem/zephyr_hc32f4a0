# 第69章\_设备电源管理头文件

原文：[pm_2device_8h](https://docs.zephyrproject.org/latest/doxygen/html/pm_2device_8h.html)。读取日期：2026-10-13，`latest`。

`zephyr/pm/device.h`：设备电源管理（Device Power Management，PM）应用程序编程接口（Application Programming Interface，API）的头文件。

## 69.1\_包含关系与源文件

```c
#include <zephyr/device.h>
#include <zephyr/kernel.h>
#include <zephyr/sys/atomic.h>
#include <zephyr/sys/iterable_sections.h>
```

[查看官方源码](https://docs.zephyrproject.org/latest/doxygen/html/pm_2device_8h_source.html)。

## 69.2\_类型与宏

原页列出[设备基础信息](P038_设备电源管理基础结构.md) [`pm_device_base`](https://docs.zephyrproject.org/latest/doxygen/html/structpm__device__base.html)、[通用运行时信息](P039_通用设备运行时电源结构.md) [`pm_device`](https://docs.zephyrproject.org/latest/doxygen/html/structpm__device.html) 和[同步运行时信息](P040_中断安全设备电源结构.md) [`pm_device_isr`](https://docs.zephyrproject.org/latest/doxygen/html/structpm__device__isr.html)。

中断服务程序（Interrupt Service Routine，ISR）安全标志表示该设备的运行时PM接口可以从任何上下文调用：

```c
#define PM_DEVICE_ISR_SAFE 1
```

| 宏签名 | 用途 |
| --- | --- |
| `PM_DEVICE_DEFINE(dev_id, pm_action_cb, ...)` | 按设备标识定义PM资源 |
| `PM_DEVICE_DT_DEFINE(node_id, pm_action_cb, ...)` | 按设备树（Devicetree，DT）节点标识定义资源 |
| `PM_DEVICE_DT_INST_DEFINE(idx, pm_action_cb, ...)` | 按实例索引定义资源 |
| `PM_DEVICE_GET(dev_id)` | 取得设备的PM资源引用 |
| `PM_DEVICE_DT_GET(node_id)` | 取得设备树节点的PM资源引用 |
| `PM_DEVICE_DT_INST_GET(idx)` | 取得实例的PM资源引用 |

设备动作及失败回调（Callback）类型：

```c
typedef int (*pm_device_action_cb_t)(const struct device *dev, enum pm_device_action action);
typedef bool (*pm_device_action_failed_cb_t)(const struct device *dev, int err);
```

状态枚举与动作枚举：

```c
enum pm_device_state {
    PM_DEVICE_STATE_ACTIVE,
    PM_DEVICE_STATE_SUSPENDED,
    PM_DEVICE_STATE_SUSPENDING,
    PM_DEVICE_STATE_OFF
};
enum pm_device_action {
    PM_DEVICE_ACTION_SUSPEND,
    PM_DEVICE_ACTION_RESUME,
    PM_DEVICE_ACTION_TURN_OFF,
    PM_DEVICE_ACTION_TURN_ON
};
```

四个状态依次是活动（Active）、挂起（Suspended）、正在挂起（Suspending）、关闭（Off）；四个动作依次是挂起（Suspend）、恢复（Resume）、关闭（Turn Off）、开启（Turn On）。宏展开值及完整状态规则见本章末链接的设备接口说明。
