# 第26章\_性能状态结构

原文：[structpstate](https://docs.zephyrproject.org/latest/doxygen/html/structpstate.html)。读取日期：2026-10-13，`latest`。

`struct pstate` 表示中央处理器（Central Processing Unit，CPU）的性能状态（Performance State，P-state）。它保存状态信息，以及对厂商专用设备树（Devicetree）属性的引用。使用头文件 `zephyr/cpu_freq/pstate.h`。

## 26.1\_数据成员

| 成员 | 原始类型 | 含义 |
| --- | --- | --- |
| [`load_threshold`](https://docs.zephyrproject.org/latest/doxygen/html/structpstate.html#ac5c9e7d72a359e667ea84d0e75bfcda3) | [`uint8_t`](https://docs.zephyrproject.org/latest/doxygen/html/stdint_8h.html#a3cb4a16b0e8d6af0af86d4fd6ba5fd9d) | 应触发此性能状态的 CPU 负载阈值（Load Threshold） |
| [`config`](https://docs.zephyrproject.org/latest/doxygen/html/structpstate.html#a323a2eadb17ea552b15468b1c59a4372) | `const void *` | 厂商专用设备树属性（Vendor-Specific Devicetree Properties） |

本结构参考由 `zephyr/cpu_freq/pstate.h` 生成。定义和获取状态的宏见[性能状态接口](P025_性能状态接口.md)。
