# 第44章\_电源策略延迟订阅结构

原文：[structpm__policy__latency__subscription](https://docs.zephyrproject.org/latest/doxygen/html/structpm__policy__latency__subscription.html)。读取日期：2026-10-13，`latest`。

`struct pm_policy_latency_subscription` 表示电源管理（Power Management，PM）策略的延迟变化订阅（Latency Change Subscription），使用头文件 `zephyr/pm/policy.h`。

## 44.1\_字段可见性

原文明确说明：此结构的所有字段均供内部私有使用（Private Usage）。该参考页未列出公共字段。

最大延迟变化的订阅、取消及回调说明见[系统电源管理策略接口](P035_系统电源管理策略接口.md)。
