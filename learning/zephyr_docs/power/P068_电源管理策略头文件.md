# 第68章\_电源管理策略头文件

原文：[pm_2policy_8h](https://docs.zephyrproject.org/latest/doxygen/html/pm_2policy_8h.html)。读取日期：2026-10-13，`latest`。

`zephyr/pm/policy.h`：系统电源管理（Power Management，PM）策略（Policy）应用程序编程接口（Application Programming Interface，API）的头文件。

## 68.1\_包含关系与源文件

```c
#include <stdbool.h>
#include <stdint.h>
#include <zephyr/device.h>
#include <zephyr/pm/state.h>
#include <zephyr/sys/slist.h>
#include <zephyr/toolchain.h>
```

[查看官方源码](https://docs.zephyrproject.org/latest/doxygen/html/pm_2policy_8h_source.html)。

## 68.2\_类型与宏

原页列出[延迟变化订阅](P044_电源策略延迟订阅结构.md) [`pm_policy_latency_subscription`](https://docs.zephyrproject.org/latest/doxygen/html/structpm__policy__latency__subscription.html)、[延迟请求](P043_电源策略延迟请求结构.md) [`pm_policy_latency_request`](https://docs.zephyrproject.org/latest/doxygen/html/structpm__policy__latency__request.html) 和[事件](P042_电源策略事件结构.md) [`pm_policy_event`](https://docs.zephyrproject.org/latest/doxygen/html/structpm__policy__event.html) 三个结构。

宏 [`PM_ALL_SUBSTATES`](https://docs.zephyrproject.org/latest/doxygen/html/group__subsys__pm__sys__policy.html#gab241e40f9282a1c8ebc602997fbb3190) 是代表全部子状态的特殊值：

```c
#define PM_ALL_SUBSTATES (UINT8_MAX)
```

最大延迟变化通知回调（Callback）类型：

```c
typedef void (*pm_policy_latency_changed_cb_t)(int32_t latency);
```
