# 第41章\_电源管理通知结构

原文：[structpm__notifier](https://docs.zephyrproject.org/latest/doxygen/html/structpm__notifier.html)。读取日期：2026-10-13，`latest`。

`struct pm_notifier` 是电源管理（Power Management，PM）通知对象（Notifier），包含目标进入和退出电源状态时调用的回调（Callback），使用头文件 `zephyr/pm/pm.h`。

## 41.1\_调用时机与约束

按当前实现，从活动状态 `PM_STATE_ACTIVE` 转到其他状态时调用进入回调；从非活动状态转回 `PM_STATE_ACTIVE` 时调用退出回调。原文指出，此行为未来可能变化。

回调可能从导致内核退出空闲的事件所对应的中断服务程序（Interrupt Service Routine，ISR）中调用。回调中**不得调用** [`pm_notifier_unregister()`](https://docs.zephyrproject.org/latest/doxygen/html/group__subsys__pm__sys.html#gab0856d662e50a3847a1b70cb8370849a) 或 [`pm_notifier_register()`](https://docs.zephyrproject.org/latest/doxygen/html/group__subsys__pm__sys.html#ga066945118b8f287ee56aacf41b677a78)：调用回调时，相关函数使用的自旋锁（Spinlock）处于锁定状态。

## 41.2\_匿名联合体中的两组回调

原页公开的四个回调位于一个匿名联合体（Anonymous Union）中：一组匿名结构包含普通进入/退出回调，另一组匿名结构包含报告子状态的进入/退出回调。只设置其中一组，通过 [`report_substate`](https://docs.zephyrproject.org/latest/doxygen/html/structpm__notifier.html#a1f1581563a6fa98bcee5d2776d8ac03f) 选择使用哪组。

| 成员 | 原始函数指针类型 | 含义 |
| --- | --- | --- |
| [`state_entry`](https://docs.zephyrproject.org/latest/doxygen/html/structpm__notifier.html#ab84353bcc32f4262ea1a34f316d21278) | `void (*)(enum pm_state state)` | 应用定义的进入电源状态时执行的目标专用操作 |
| [`state_exit`](https://docs.zephyrproject.org/latest/doxygen/html/structpm__notifier.html#aeb6bcf67d2d4c5342d8d81cea3728ec5) | `void (*)(enum pm_state state)` | 应用定义的退出电源状态时执行的目标专用操作 |
| [`substate_entry`](https://docs.zephyrproject.org/latest/doxygen/html/structpm__notifier.html#a65912a1e94d9428aa32ae10d416c51a8) | `void (*)(enum pm_state state, uint8_t substate_id)` | 应用定义的进入操作，同时报告子状态标识 |
| [`substate_exit`](https://docs.zephyrproject.org/latest/doxygen/html/structpm__notifier.html#ac4e86624ef88da3b9021af43461bdcb3) | `void (*)(enum pm_state state, uint8_t substate_id)` | 应用定义的退出操作，同时报告子状态标识 |

## 41.3\_子状态报告选择

成员 `report_substate` 的类型为 [`bool`](https://docs.zephyrproject.org/latest/doxygen/html/stdbool_8h.html#abb452686968e48b67397da5f97445f5b)。为 `true` 时表示设置了报告子状态的回调；为 `false` 时选择不报告子状态标识的回调。为保持向后兼容（Backward Compatibility），默认值为 `false`。

注册与注销见[系统电源管理接口](P032_系统电源管理接口.md)。
