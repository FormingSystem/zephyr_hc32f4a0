# 第110章\_nPM1100稳压器设备树头文件

原文：[npm1100_8h](https://docs.zephyrproject.org/latest/doxygen/html/npm1100_8h.html)。读取日期：2026-10-13，`latest`。

本头文件提供Nordic nPM1100 电源管理集成电路（Power Management Integrated Circuit，PMIC）稳压器驱动的**设备树辅助接口（Devicetree Helpers）**。头文件路径为 `zephyr/dt-bindings/regulator/npm1100.h`。


## 110.1\_源码与包含关系

[查看官方源码](https://docs.zephyrproject.org/latest/doxygen/html/npm1100_8h_source.html)。本参考页未列出包含项。

相关的[设备树辅助接口](P095_nPM1100稳压器设备树辅助接口.md)给出同组常量说明。

## 110.2\_稳压器模式

```c
#define NPM1100_MODE_AUTO 0
#define NPM1100_MODE_PWM 1
```

| 宏 | 值 | 中文说明 |
| --- | --- | --- |
| [`NPM1100_MODE_AUTO`](https://docs.zephyrproject.org/latest/doxygen/html/group__regulator__npm1100.html#gad9ef7b5b04ff76053081d20b9e20a649) | `0` | 自动模式（Automatic Mode） |
| [`NPM1100_MODE_PWM`](https://docs.zephyrproject.org/latest/doxygen/html/group__regulator__npm1100.html#ga6817155a2168e20a95cdb313838b596a) | `1` | 脉宽调制（Pulse Width Modulation，PWM）模式 |
