# 第37章\_设备运行时电源管理接口

原文：[group__subsys__pm__device__runtime](https://docs.zephyrproject.org/latest/doxygen/html/group__subsys__pm__device__runtime.html)。读取日期：2026-10-13，`latest`。

设备运行时电源管理（Device Runtime Power Management，Device Runtime PM）应用程序编程接口（Application Programming Interface，API）自 Zephyr 3.0 提供，版本1.0.0，使用头文件 `zephyr/pm/device_runtime.h`。本页函数的 `dev` 均为设备实例指针。

## 37.1\_自动启用

```c
int pm_device_runtime_auto_enable(const struct device *dev);
```

根据设备树（Devicetree）属性自动启用设备运行时 PM。**应用代码不得调用。**参见 `pm.yaml` 中的 `zephyr,pm-device-runtime-auto` 属性和初始化函数 `z_sys_init_run_level`。

成功启用，或设备树未为该设备请求自动启用时，返回 `0`；失败返回负错误码（Errno）。

## 37.2\_启用、禁用与查询

```c
int pm_device_runtime_enable(const struct device *dev);
int pm_device_runtime_disable(const struct device *dev);
bool pm_device_runtime_is_enabled(const struct device *dev);
```

这三个函数允许在内核启动前（Pre-Kernel）使用。

[`pm_device_runtime_enable()`](https://docs.zephyrproject.org/latest/doxygen/html/group__subsys__pm__device__runtime.html#gaabcd2cc694c9e201dd87bf42f02b454c) 为设备启用运行时 PM。设备当前处于 [`PM_DEVICE_STATE_ACTIVE`](https://docs.zephyrproject.org/latest/doxygen/html/group__subsys__pm__device.html#gga561c0789071e3c3963f21f4c4a1bb2c6a54b207e01b4dfc5e1ff56149817120c7) 活动状态时，会挂起设备。成功返回 `0`，失败返回负错误码；设备忙返回 `-EBUSY`（Busy），设备不支持 PM 返回 `-ENOTSUP`（Not Supported）。另见 [`pm_device_init_suspended()`](https://docs.zephyrproject.org/latest/doxygen/html/group__subsys__pm__device.html#ga4c366f49e326a8b8e01d90cb2ee424ba)。

[`pm_device_runtime_disable()`](https://docs.zephyrproject.org/latest/doxygen/html/group__subsys__pm__device__runtime.html#gaa7fc78138e282b0eae7da67876baee80) 禁用设备运行时 PM；如果设备当前挂起，会恢复它。成功返回 `0`，失败返回负错误码；设备不支持 PM 返回 `-ENOTSUP`。

[`pm_device_runtime_is_enabled()`](https://docs.zephyrproject.org/latest/doxygen/html/group__subsys__pm__device__runtime.html#ga605cd2a3d0ea31efe6bd0b9a6f723219) 在该设备已启用运行时 PM 时返回 [`true`](https://docs.zephyrproject.org/latest/doxygen/html/stdbool_8h.html#a41f9c5fb8b08eb5dc3edce4dcb37fee7)，禁用时返回 [`false`](https://docs.zephyrproject.org/latest/doxygen/html/stdbool_8h.html#a65e9886d74aaee76545e83dd09011727)。

## 37.3\_按使用计数恢复

```c
int pm_device_runtime_get(const struct device *dev);
```

允许在内核启动前使用。根据使用计数（Usage Count）恢复设备：设备挂起、使用计数为0时恢复设备。恢复失败则计数和设备状态保持不变；其他情况下增加使用计数。

如果设备因先前调用 [`pm_device_runtime_put_async()`](https://docs.zephyrproject.org/latest/doxygen/html/group__subsys__pm__device__runtime.html#ga9e90089b0ab78f365905418646e196c6) 仍在挂起过程中，本函数等待该操作完成，再恢复设备。

只要设备 PM 实现本身不阻塞，本函数便可安全用于不允许阻塞的上下文，例如中断服务程序（Interrupt Service Routine，ISR）。调用将阻塞、但当前上下文不允许阻塞时，返回 `-EWOULDBLOCK`（Would Block）。

成功返回 `0`，包括运行时 PM 未启用或不可用的情况；失败返回负错误码。

## 37.4\_按使用计数同步挂起

```c
int pm_device_runtime_put(const struct device *dev);
```

允许在内核启动前使用。设备不再需要、使用计数为0时挂起设备。挂起失败则计数和设备状态不变；其他情况下递减使用计数，最低到0。

成功返回 `0`，包括运行时 PM 未启用或不可用；失败返回负错误码。设备已经挂起时返回 `-EALREADY`（Already），这只会在 `get`/`put` 调用不配对时发生。异步版本见下一节。

## 37.5\_按使用计数异步挂起

```c
int pm_device_runtime_put_async(const struct device *dev, k_timeout_t delay);
```

原页标记为允许内核启动前调用、异步（Asynchronous）且可从 ISR 调用。设备不再需要、使用计数为0时安排挂起；其他情况下递减使用计数，最低到0。`delay` 是触发动作之前至少等待的时间。

**内核启动前不支持异步操作。**在该阶段调用会阻塞，等效于 [`pm_device_runtime_put()`](https://docs.zephyrproject.org/latest/doxygen/html/group__subsys__pm__device__runtime.html#ga98daba53a992fb6bd2c2b31cb445844f)。

成功返回 `0`，包括运行时 PM 未启用或不可用；失败返回负错误码。设备忙返回 `-EBUSY`，设备已挂起返回 `-EALREADY`，后者只会在 `get`/`put` 不配对时发生。

## 37.6\_查询使用计数

```c
int pm_device_runtime_usage(const struct device *dev);
```

返回当前设备使用计数。设备未使用运行时 PM 时返回 `-ENOTSUP`；本次构建未启用运行时 PM，即 Kconfig 选项 `CONFIG_PM_DEVICE_RUNTIME` 禁用时，返回 `-ENOSYS`（Not Implemented）。

## 37.7\_失败日志宏的参数与级别

展开值中的 `LOG_INST_DBG`、`LOG_INST_WRN`、`LOG_INST_ERR` 是日志实例输出宏，分别使用调试、警告和错误级别。

下方12个日志宏以设备名称作为引用信息，供检查运行时 `get` 或 `put` 返回值时使用。`GET` 版本写入“恢复失败”（Failed to Resume），`PUT` 版本写入“挂起失败”（Failed to Suspend）；日志字符串原样保留。

每个宏的 `dev` 都是 `struct device` 指针。可变参数 `...` 是对应 [`pm_device_runtime_get()`](https://docs.zephyrproject.org/latest/doxygen/html/group__subsys__pm__device__runtime.html#ga530d4be65757fb2276ab6f631953e045) 或 [`pm_device_runtime_put()`](https://docs.zephyrproject.org/latest/doxygen/html/group__subsys__pm__device__runtime.html#ga98daba53a992fb6bd2c2b31cb445844f) 的可选返回码；只使用第一个可变参数，其余全部丢弃。

带 `LOG_INST_` 前缀的宏写入指定日志实例（Logging Instance），额外参数 `_log_inst` 指向该实例关联的日志结构。`DBG`、`WRN`、`ERR` 分别表示调试（Debug）、警告（Warning）和错误（Error）级别。

宏值中的 [`COND_CODE_1`](../util_reference/P001_通用工具公共接口.md#ga358bc3e7669c860a98839a51cd526b20)、[`IS_EQ`](../util_reference/P001_通用工具公共接口.md#gaa35a6894bca38a8ffb558c2c22a1eee1)、[`NUM_VA_ARGS`](../util_reference/P001_通用工具公共接口.md#ga1e5b59140ab2bf4471a512b689eda2cb) 用于选择有无返回码的分支，[`GET_ARGS_FIRST_N`](../util_reference/P001_通用工具公共接口.md#ga572d39f00fd9b12c4084525609051b4c) 选取第一个可变参数；原始展开值如下。

## 37.8\_LOG_DBG_PM_DEVICE_RUNTIME_GET

宏签名 `LOG_DBG_PM_DEVICE_RUNTIME_GET(dev, ...)`，向日志写入恢复失败的调试消息。参数规则见37.7节。

```c
COND_CODE_1(IS_EQ(NUM_VA_ARGS(__VA_ARGS__), 0), \
            (LOG_DBG("Failed to resume %s", (dev) ? (dev)->name : "(null)")), \
            (LOG_DBG("Failed to resume %s (%d)", (dev) ? (dev)->name : "(null)", \
                     GET_ARGS_FIRST_N(1, __VA_ARGS__))))
```
