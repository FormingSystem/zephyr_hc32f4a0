# 第10章\_任务看门狗头文件

原文：[task__wdt_8h](https://docs.zephyrproject.org/latest/doxygen/html/task__wdt_8h.html)。读取日期：2026-10-13，`latest`。

`zephyr/task_wdt/task_wdt.h` 声明任务看门狗（Task Watchdog）应用程序编程接口（Application Programming Interface，API）的函数原型。任务看门狗用于监测各个线程是否正常运行，也可搭配硬件看门狗提供后备保护（Fallback）。

## 10.1\_包含关系与源文件

```c
#include <zephyr/types.h>
#include <zephyr/kernel.h>
#include <zephyr/device.h>
```

[查看官方头文件源码](https://docs.zephyrproject.org/latest/doxygen/html/task__wdt_8h_source.html)。

## 10.2\_回调类型

```c
typedef void (*task_wdt_callback_t)(int channel_id, void *user_data);
```

这是任务看门狗回调（Callback）类型。

## 10.3\_函数声明

```c
int task_wdt_init(const struct device *hw_wdt);
int task_wdt_add(uint32_t reload_period, task_wdt_callback_t callback, void *user_data);
int task_wdt_delete(int channel_id);
int task_wdt_feed(int channel_id);
void task_wdt_suspend(void);
void task_wdt_resume(void);
```
