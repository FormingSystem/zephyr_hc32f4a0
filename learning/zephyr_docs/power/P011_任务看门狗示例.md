# 第11章\_任务看门狗示例

原文：[Task watchdog](https://docs.zephyrproject.org/latest/samples/subsys/task_wdt/README.html)。读取日期：2026-10-13，`latest`。

## 11.1\_概述

本示例用于测试任务看门狗（Task Watchdog）子系统。

## 11.2\_构建与运行

任务看门狗示例应能在几乎所有开发板上构建和运行。如果设备树（Devicetree）中定义了硬件看门狗，就使用它作为后备保护（Fallback）；否则任务看门狗独立运行。

下面在 [ST Nucleo L073RZ](https://docs.zephyrproject.org/latest/boards/st/nucleo_l073rz/doc/index.html#nucleo_l073rz) 上构建和运行：

```shell
west build -b nucleo_l073rz samples/subsys/task_wdt
west flash
```

其他开发板只需替换开发板名称。

## 11.3\_示例输出

以下输出会持续重复，每次复位后重新开始：

```text

Main thread still alive...

```
