# 第53章\_STM32电源管理示例目录

原文：[Power Management](https://docs.zephyrproject.org/latest/samples/boards/st/power_mgmt/index.html)。读取日期：2026-10-13，`latest`。

本组示例演示 STM32 开发板的电源管理（Power Management，PM）功能。

## 53.1\_示例入口

| 示例 | 展示内容 |
| --- | --- |
| [ADC电源管理](P054_STM32_ADC电源管理示例.md) | 在低功耗环境中使用模数转换器（Analog-to-Digital Converter，ADC） |
| [低功耗闪灯](P055_STM32低功耗闪灯示例.md) | 通过通用输入输出（General-Purpose Input/Output，GPIO）接口使发光二极管（Light-Emitting Diode，LED）闪烁 |
| [STM32WB蓝牙低功耗](P057_STM32WB蓝牙低功耗示例.md) | 启用Zephyr PM时执行低功耗蓝牙（Bluetooth Low Energy，Bluetooth LE）操作 |
| [唤醒引脚](P060_STM32唤醒引脚示例.md) | 将GPIO引脚作为唤醒引脚（Wake-up Pin） |
| [串口唤醒](P056_STM32串口唤醒示例.md) | 通过串口活动唤醒 |
| [STOP3模式](P058_STM32_STOP3示例.md) | 使用STM32U5的STOP3低功耗模式 |
| [挂起到RAM](P059_STM32挂起到RAM示例.md) | 使用挂起到随机存取存储器（Suspend to RAM）低功耗模式 |
