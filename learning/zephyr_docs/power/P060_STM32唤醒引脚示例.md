# 第60章\_STM32唤醒引脚示例

原文：[GPIO as wake-up pin](https://docs.zephyrproject.org/latest/samples/boards/st/power_mgmt/wkup_pins/README.html)。读取日期：2026-10-13，`latest`。

## 60.1\_概述与唤醒引脚选择

本最小应用在STM32片上系统（System on Chip，SoC）上，演示通用输入输出（General-Purpose Input/Output，GPIO）引脚在系统关机（Poweroff）和挂起到随机存取存储器（Suspend to RAM，RAM 为 Random Access Memory）两种场景中作为唤醒引脚（Wake-up Pin）的用法。

通过 Kconfig 选项选择场景：`CONFIG_SAMPLE_SCENARIO_POWEROFF` 是默认关机场景，`CONFIG_SAMPLE_SCENARIO_S2RAM` 选择挂起到RAM。

示例需要设备树（Devicetree）别名 `wkup-src`，指向一个带有 `gpios` 属性的节点。在大多数STM32开发板上，至少一个板载按键连接到支持唤醒的GPIO；在这些板上，将 `wkup-src` 指向代表该按键的节点，即设备树 `/gpio_keys` 的一个子节点。

某些板的所有板载按键都未连接到支持唤醒的GPIO。这时需要在开发板叠加配置（Overlay）中创建新的 `/gpio_keys` 子节点，使其 `gpios` 属性对应一个唤醒GPIO，并让 `wkup-src` 指向它；实际测试需要使用跳线使该引脚进入有效状态。

以下将 `wkup-src` 指定的GPIO称为“WAKEUP按键引脚”，将使该引脚进入有效状态的操作称为“按下WAKEUP按键”，不论实际是否连接了物理按键。

## 60.2\_关机场景

将WAKEUP引脚配置为GPIO输入和唤醒引脚，等待 `CONFIG_SAMPLE_BUSY_WAIT_TIME_MS` 指定的毫秒数，默认4000 ms，然后调用 [`sys_poweroff()`](P063_系统关机接口.md) 关闭系统。

进入关机状态后按下WAKEUP，应使SoC上电，其启动方式如同把低有效复位引脚 `nRESET` 拉低。在多数STM32系列上，软件可以区分唤醒引脚触发的复位与nRESET触发的复位；能够区分时，示例打印：

```text
Reset from low-power state detected.
Continuing sample execution...
```

STM32平台将Poweroff映射到该系列功耗最低的模式，通常称为待机（Standby）或关闭（Shutdown），具体名称依SoC系列而定。

## 60.3\_挂起到RAM场景

将WAKEUP引脚配置为GPIO输入和唤醒引脚，注册GPIO回调（Callback），并启用该引脚中断。这样，无论处于运行模式（Run Mode）还是挂起到RAM，按键都能调用回调：运行时由GPIO控制器感知中断，挂起时由电源控制器感知。回调打印消息并释放信号量（Semaphore）。

随后反复执行演示循环：

1. 打印消息，然后忙等待 `CONFIG_SAMPLE_BUSY_WAIT_TIME_MS` 毫秒。
2. 尝试获取信号量，超时由 `CONFIG_SAMPLE_BUTTON_PRESS_TIMEOUT_MS` 指定。如果此前没有按键，系统应进入挂起到RAM。
3. 挂起期间按WAKEUP会唤醒系统，执行已注册回调、打印消息并释放信号量。等待信号量的主线程因此恢复，避免系统因为没有可运行线程而立即再次挂起。
4. 成功取得信号量时打印成功消息并开始下一轮。若先超时，打印超时消息并暂停，直到按下WAKEUP后再开始下一轮。

唤醒引脚只支持单边沿检测（Single-Edge Detection），即上升沿或下降沿。

## 60.4\_要求

SoC 必须实现硬件信息（Hardware Information）应用程序编程接口（Application Programming Interface，API）和关机API。

挂起到RAM场景还要求SoC具有对应低功耗模式，并提供软件支持：设备树中应存在兼容属性为 `zephyr,power-state`、`power-state-name` 值为 `"suspend-to-ram"` 的节点。

需要为本示例添加各开发板的叠加配置，以提供 `wkup-src` 别名。

## 60.5\_构建与运行

按下列命令构建并烧录，将 `nucleo_u5a5zj_q` 替换为自己的开发板：

```shell
west build -b nucleo_u5a5zj_q samples/boards/st/power_mgmt/wkup_pins
west flash
```

复位后，板载发光二极管（Light-Emitting Diode，LED）点亮；当系统关机或进入挂起到RAM时熄灭，具体取决于所选场景。
