# 第49章\_设备空闲电源管理示例

原文：[Device Idle Power Management](https://docs.zephyrproject.org/latest/samples/subsys/pm/device_pm/README.html)。读取日期：2026-10-13，`latest`。

## 49.1\_概述

本示例使用父子设备层级（Parent-Child Device Hierarchy）演示 Zephyr 设备电源管理（Device Power Management，PM）子系统。定义了两个模拟设备（Dummy Device）：父总线设备和子外设设备；它们的 PM 动作回调（Action Callback）处理 [`PM_DEVICE_ACTION_SUSPEND`](https://docs.zephyrproject.org/latest/doxygen/html/group__subsys__pm__device.html#ggaee5546eacb9be7caa9d59ab63926cc4ca5b7ae11deaee85eb0b8452bc89383790) 挂起与 [`PM_DEVICE_ACTION_RESUME`](https://docs.zephyrproject.org/latest/doxygen/html/group__subsys__pm__device.html#ggaee5546eacb9be7caa9d59ab63926cc4ca757c6ab81eeac0d6afae479d6a0ac564) 恢复转换。

应用依次执行：

1. 打开子设备，先通过 [`pm_device_runtime_get()`](https://docs.zephyrproject.org/latest/doxygen/html/group__subsys__pm__device__runtime.html#ga530d4be65757fb2276ab6f631953e045) 恢复父设备，再恢复自身。
2. 通过父总线执行一次写操作和一次读操作。
3. 关闭子设备，通过 [`pm_device_runtime_put()`](https://docs.zephyrproject.org/latest/doxygen/html/group__subsys__pm__device__runtime.html#ga98daba53a992fb6bd2c2b31cb445844f) 挂起子设备及父设备。

示例展示如何用宏 [`PM_DEVICE_DEFINE`](https://docs.zephyrproject.org/latest/doxygen/html/group__subsys__pm__device.html#gae85fb5a7c31863a3663cef8dd7229c6c) 定义支持 PM 的设备，用函数 [`pm_device_driver_init()`](https://docs.zephyrproject.org/latest/doxygen/html/group__subsys__pm__device.html#gad563094c2d4ad066bc4ce30586e13fb3) 初始化设备 PM，用 [`pm_device_runtime_get()`](https://docs.zephyrproject.org/latest/doxygen/html/group__subsys__pm__device__runtime.html#ga530d4be65757fb2276ab6f631953e045)/[`pm_device_runtime_put()`](https://docs.zephyrproject.org/latest/doxygen/html/group__subsys__pm__device__runtime.html#ga98daba53a992fb6bd2c2b31cb445844f) 管理电源状态，用 [`pm_device_state_get()`](https://docs.zephyrproject.org/latest/doxygen/html/group__subsys__pm__device.html#gaffcf0aea5df10657235d4ed1f8c74d5a) 查询状态，以及如何协调父子设备的供电依赖。

## 49.2\_要求与构建

不需要特殊硬件，可在 QEMU 模拟器或任何支持设备 PM 的开发板上运行，对应 Kconfig 选项为 [`CONFIG_PM_DEVICE`](https://docs.zephyrproject.org/latest/kconfig.html#CONFIG_PM_DEVICE)。

以下命令构建并运行，将 `qemu_x86` 替换为自己的开发板：

```shell
west build -b qemu_x86 samples/subsys/pm/device_pm
west build -t run
```

## 49.3\_示例输出

成功运行时控制台显示以下内容，其中OS表示操作系统（Operating System）：

```text
*** Booting Zephyr OS build zephyr-vX.Y.Z ***
Device PM sample app start
parent resuming..
child resuming..
Dummy device resumed
child suspending..
parent suspending..
Device PM sample app complete
```

设备通过 [`pm_device_driver_init()`](https://docs.zephyrproject.org/latest/doxygen/html/group__subsys__pm__device.html#gad563094c2d4ad066bc4ce30586e13fb3) 初始化到挂起状态。应用打开子设备时恢复父子设备；完成输入输出（Input/Output，I/O）后，关闭设备并挂起两者。

按 `Ctrl+A`，再按 `x` 退出 QEMU。
