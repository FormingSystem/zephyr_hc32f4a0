## 1.5\_详细说明（Detailed Documentation）

<a id="ga480cea1dffcdbedce403c3127bebe910"></a>

### `SYS_RINGQ_DEFINE`

```c
#define SYS_RINGQ_DEFINE ( name, item_size, item_capacity )
```

```c
#include <zephyr/sys/ringq.h>
```

展开值（Value）：

```c
static uint8_t __noinit CONCAT(_ringq_data_, name)[(item_size) * (item_capacity)];      \
struct sys_ringq name = SYS_RINGQ_INIT(CONCAT(_ringq_data_, name), (item_size),         \
                                       (item_capacity))
```

定义并初始化环形队列。

此宏建立固定大小的sys_ringq队列。

**参数（Parameters）**

| 名称／方向 | 说明 |
| --- | --- |
| `name` | ringq实例的名称。 |
| `item_size` | 每个ringq元素的大小，单位为字节。 |
| `item_capacity` | 容量，单位为元素个数。 |

> 译注——源码核对：该宏声明静态__noinit字节数组，容量为item_size乘item_capacity，并初始化队列。没有自行检查非零参数、乘法溢出或底层容量上限；应使用正的固定项大小和项数，并事先保证总字节容量有效。它复制数据项字节，不为结构中的指针所指对象建立副本或所有权管理。

### `sys_ringq_init()`

```c
void sys_ringq_init ( struct sys_ringq * ringq, uint8_t * data, size_t data_size, size_t item_size )
```

声明属性：`inline`、`static`。

```c
#include <zephyr/sys/ringq.h>
```

初始化ringq队列。

此例程初始化ringq队列。

**参数（Parameters）**

| 名称／方向 | 说明 |
| --- | --- |
| `ringq` | sys_ringq结构的地址。 |
| `data` | ringq的sys_ringq数据存储区域。 |
| `data_size` | ringq数据区域的大小，单位为字节。 |
| `item_size` | 每个ringq元素的大小，单位为字节。 |

**说明（Note）**：data_size应为item_size的整数倍。否则，将其向下调整为最接近的item_size整数倍。

> 译注——源码核对：当前先断言data非NULL、item_size大于0，再把data_size向下舍入到整项倍数，并断言结果大于0。比如17字节区域配4字节数据项，使用16字节、容纳4项，余下1字节不用；小于一项的区域不是正常的零容量队列。断言不是返回错误码机制，禁用断言不使非法参数成为有效输入。

## 1.6\_源码定位与版本边界

对照[公共API](P001_环形队列公共接口.md)、[结构说明](P002_环形队列结构.md)、[头文件参考](P003_环形队列头文件参考.md)和[源码浏览译文](P004_环形队列头文件源码.md)。

相对源码定位：[include/zephyr/sys/ringq.h](../../../include/zephyr/sys/ringq.h)与[include/zephyr/sys/ring_buffer.h](../../../include/zephyr/sys/ring_buffer.h)；本次依据为[官方队列头文件](https://github.com/zephyrproject-rtos/zephyr/blob/main/include/zephyr/sys/ringq.h)与[官方缓冲区头文件](https://github.com/zephyrproject-rtos/zephyr/blob/main/include/zephyr/sys/ring_buffer.h)，摘要见[来源记录](../SOURCES.md)。

> 译注——源码核对：对象关系：环形队列（Ring Queue）包装字节环形缓冲区（Ring Buffer），额外保存固定数据项大小item_size。sys_ringq容量、空闲量和已有数据量以元素个数表示，底层ring_buf则以字节表示；不能混用这两套单位。

> 译注——源码核对：固定项不变量（Invariant）：后备容量为item_size的整数倍，所有读写都按整项进行，才能保持数据项边界。不要直接对内部rb执行任意长度的字节流操作，也不要在多个同侧访问者之间无保护地混用读写；当前包装只根据底层返回量是否为0判断成功，不另外验证非零返回值是否等于item_size。

> 译注——源码核对：同步与生命周期：sys_ringq不新增锁、阻塞等待或通知机制。官方指南要求应用根据并发参与者提供同步；底层索引的内存顺序不等于环形队列提供任意多线程安全。对象与后备区域须在使用期间有效，初始化及复位与读写之间也须协调。

> 译注——源码核对：容量和版本：本次官方ring_buffer.h的默认字节上限为32767，LARGE配置下为1073741823。item_size、项数及两者乘积必须满足底层容量与整数表示范围；数据区以size_t传入不代表支持任意size_t大小，底层初始化容量参数为uint32_t，内部索引类型还取决于配置。仓库ring_buffer实现与本次main不同，实际使用须核对目标版本。

本次未构建或运行跨核、DMA、并发读写、边界容量及实板实验。
