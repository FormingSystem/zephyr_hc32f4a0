# 环形队列参考大纲

环形队列（Ring Queue）在固定后备区域中保存大小相同的数据项，按先进先出（First In First Out，FIFO）顺序复制进出。先读[环形队列指南](../kernel/P057_环形队列.md)，再按公共API、结构、头文件与源码查询；底层字节流接口另见[环形缓冲区参考](../ringbuffer_reference/大纲.md)。

队列容量、空闲量与有效量按项数返回，每项大小及后备区域长度按字节指定。源码译注说明向下舍入、整项不变量、数据复制、同步与版本边界。原始代码、宏展开、参数、返回值及法律注释保留，仓库定位使用相对链接。完整范围见[全站进度](../PROGRESS.md)。
