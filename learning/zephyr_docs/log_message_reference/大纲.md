# 日志消息接口参考大纲

本册完整翻译日志消息（Log Message）API、头文件参考和源码三份官方页面。接口覆盖消息总字长、域与级别、日志源、时间戳、线程／核心编号、cbprintf包及附加数据。

源码页保留官方全部可见代码、注释、宏展开、符号提示和行号锚点。中文对照说明构建路径、对齐、VLA后备数组和编译器屏障；原注释存在缺词或版本限制时独立标明。

源码译注区分字与字节、消息内部借用指针、时间戳单位和跨域来源编号。公共调用见[日志公共接口与控制参考](../log_core_reference/大纲.md)，完整覆盖状态见[全站进度](../PROGRESS.md)。
