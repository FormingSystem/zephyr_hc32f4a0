# 核心转储与GDB头文件参考大纲

本册翻译核心转储（Core Dump）公共头文件、核心转储伪设备（Pseudo-device）驱动头文件和GDB调试桩（GDB Stub）头文件的参考与源码，共六份官方页面。相关的[核心转储公共接口](../observability/P052_核心转储接口.md)、[设备接口](../observability/P053_核心转储设备接口.md)及[架构调试桩接口](../observability/P061_GDB桩架构接口.md)继续沿用已有译文。

公共头文件规定转储格式和命令，伪设备接口将内存区域或回调数据纳入转储，GDB头文件规定调试桩的内存区域与转换辅助接口。三者职责不同，注册区域不意味着立刻复制数据，查询访问属性也不等于实际探测硬件地址。

三个源码浏览页保留全部可见代码、原注释、许可证、符号提示和对应行号锚点，中文对照另列。源码跟踪译注说明每CPU快照、注册节点生命周期、设备类型差异，以及GDB空区域表和无字符串结束符的转换行为。原网页交叉索引异常和截断提示明确标注。完整范围及状态见[全站进度](../PROGRESS.md)。
