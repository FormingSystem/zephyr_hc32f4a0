原文：[官方页面](https://docs.zephyrproject.org/latest/doxygen/html/structstats__name__map.html)。读取日期：2026-10-17；来源摘要见[来源记录](../SOURCES.md)。

描述一个生成的统计条目名称（Statistic Entry Name）。

```c
#include <zephyr/stats/stats.h>
```

<a id="details"></a>

描述一个生成的统计条目名称。名称映射通常使用 `STATS_NAME_START`、`STATS_NAME` 和 `STATS_NAME_END` 生成，而不是手工初始化。

本数据类型文档由以下文件生成：

- `zephyr/stats/stats.h`
