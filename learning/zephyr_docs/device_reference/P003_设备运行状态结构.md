## 3.2\_详细说明（Detailed Documentation）

<a id="a4895f511a9246d27a378253ab82e263e"></a>

### `init_res`

```c
uint8_t device_state::init_res
```

设备初始化返回码，以正errno值保存。

设备初始化函数失败时返回负errno码。Zephyr中的errno值不超过255，因此可以把它的正值保存在uint8_t类型中。

> 译注——源码核对：当前初始化路径把负错误码转为正值保存，并以uint8_t容纳；源码还具有错误范围断言和最大值截断。成功路径没有显式清零旧错误值，这一字段不应由应用自行改写以强行标记就绪。

<a id="a26bb28bbe4c17c4f0e496d2b04d4a3ad"></a>

### `initialized`

```c
bool device_state::initialized
```

表示设备初始化函数已经被调用。

> 译注——源码核对：该标志表示初始化已执行；do_device_init即使收到错误返回，也会置为true。判断可用性还需要init_res为0，应调用device_is_ready而不是单独检查此位。
