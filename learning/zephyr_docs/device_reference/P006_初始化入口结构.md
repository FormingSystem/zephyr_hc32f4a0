## 6.1\_数据成员（Data Fields）

<a id="r_ac0b2a7ee85ad51e462b557bcb3faf6b9"></a>

```c
int(* init_fn )(void)
```

相关声明：[init_fn](#ac0b2a7ee85ad51e462b557bcb3faf6b9)。

初始化函数属于SYS_INIT时，本字段保存该初始化函数，否则设为NULL。

<a id="r_af03b5e4991da3a75059bc4b254a3e21e"></a>

```c
const struct device * dev
```

相关声明：[device](P002_设备对象结构.md)、[dev](#af03b5e4991da3a75059bc4b254a3e21e)。

初始化入口属于某个设备时，本字段保存该设备的引用，否则设为NULL。

## 6.2\_详细说明（Detailed Documentation）

<a id="af03b5e4991da3a75059bc4b254a3e21e"></a>

### `dev`

```c
const struct device* init_entry::dev
```

初始化入口属于某个设备时，本字段保存该设备的引用，否则设为NULL。

<a id="ac0b2a7ee85ad51e462b557bcb3faf6b9"></a>

### `init_fn`

```c
int(* init_entry::init_fn) (void)
```

初始化函数属于SYS_INIT时，本字段保存该初始化函数，否则设为NULL。

## 6.3\_源码定位与版本边界

设备对象、句柄与定义宏可在[device.h](../../../include/zephyr/device.h)定位，初始化入口在[init.h](../../../include/zephyr/init.h)，运行时行为分别见[kernel/device.c](../../../kernel/device.c)和[kernel/init.c](../../../kernel/init.c)。本次另核对对应的[官方device.h](https://github.com/zephyrproject-rtos/zephyr/blob/main/include/zephyr/device.h)、[官方init.h](https://github.com/zephyrproject-rtos/zephyr/blob/main/include/zephyr/init.h)、[官方device.c](https://github.com/zephyrproject-rtos/zephyr/blob/main/kernel/device.c)及[官方init.c](https://github.com/zephyrproject-rtos/zephyr/blob/main/kernel/init.c)，摘要见[来源记录](../SOURCES.md)。本地源码、滚动更新的main与latest网页不自动视为同一版本；译注仅描述所读取快照。

> 译注——入口两种形式：SYS_INIT入口保存int (*init_fn)(void)，dev为NULL；设备入口保存dev，init_fn为NULL。调度器依据dev分支处理，不会不加判断地对每个入口调用init_fn。设备的初始化函数实际保存在设备操作表中。

本批完成官方文档翻译与源码静态核对；没有执行初始化、反初始化、固件构建或实板实验。
