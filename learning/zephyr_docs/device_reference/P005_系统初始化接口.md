# 第5章\_系统初始化接口

原文：[官方页面](https://docs.zephyrproject.org/latest/doxygen/html/group__sys__init.html)。读取日期：2026-10-15；来源摘要见[来源记录](../SOURCES.md)。

> 译注——阅读位置：本页是设备模型（Device Model）与系统初始化（System Initialization）应用程序接口（Application Programming Interface，API）参考。先读[设备驱动模型](../hardware/P003_设备驱动模型.md)，再按[本册大纲](大纲.md)区分设备对象（Device Object）、运行状态（Runtime State）、生命周期操作（Lifecycle Operations）和初始化入口（Initialization Entry）。原始标识符、类型与常量保持不变；重复的接口摘要与详细说明均保留。

<a id="details"></a>

自1.0起提供；接口版本为1.0.0。Zephyr提供在main之前调用初始化代码的基础设施，可通过SYS_INIT()或SYS_INIT_NAMED()登记初始化调用。组合初始化级别与优先级，可以按需要调整初始化顺序。可用级别依次如下：

1. EARLY：启动过程的极早阶段，刚进入C执行域z_cstart()后调用。适用于扩展或实现架构代码的架构及SoC：它们所使用的驱动或系统服务，需要在内核调用任何架构专用初始化代码之前完成初始化。
2. PRE_KERNEL_1：在内核初始化上下文中执行，使用中断栈；此时尚不能使用内核服务。
3. PRE_KERNEL_2：与PRE_KERNEL_1相同。
4. POST_KERNEL：内核已运行后执行，从此可以使用内核原语（Kernel Primitives）。
5. APPLICATION：紧接应用代码main之前执行。
6. SMP：仅在启用CONFIG_SMP时可用，用于对称多处理（Symmetric Multiprocessing，SMP）的专用初始化。

初始化优先级可以取0～999。注意：设备也使用同一套初始化基础设施。

## 5.4\_详细说明（Detailed Documentation）

<a id="ga3025b426a99f8351d4b483205f437e48"></a>

### `INIT_LEVEL_ORD`

```c
#define INIT_LEVEL_ORD ( level)
```

```c
#include <zephyr/init.h>
```

展开值（Value）：

```c
COND_CASE_1(Z_INIT_EARLY_##level, (Z_INIT_ORD_EARLY),                  \
            Z_INIT_PRE_KERNEL_1_##level, (Z_INIT_ORD_PRE_KERNEL_1),    \
            Z_INIT_PRE_KERNEL_2_##level, (Z_INIT_ORD_PRE_KERNEL_2),    \
            Z_INIT_POST_KERNEL_##level, (Z_INIT_ORD_POST_KERNEL),      \
            Z_INIT_APPLICATION_##level, (Z_INIT_ORD_APPLICATION),      \
            Z_INIT_SMP_##level, (Z_INIT_ORD_SMP),                      \
            (ZERO_OR_COMPILE_ERROR(0)))
```

取得初始化级别的序号（Ordinal）。

**参数（Parameters）**

| 名称／方向 | 说明 |
| --- | --- |
| `level` | 初始化级别：EARLY、PRE_KERNEL_1、PRE_KERNEL_2、POST_KERNEL、APPLICATION、SMP。 |

**返回（Returns）**：返回初始化级别序号。

> 译注——源码核对：输入是编译期的级别词法单元，不是运行时字符串。它不把任意动态输入转换成合法初始化级别。

<a id="gaf507cc0613add8113c41896bd631254f"></a>

### `SYS_INIT`

```c
#define SYS_INIT ( init_fn, level, prio )
```

```c
#include <zephyr/init.h>
```

展开值（Value）：

```c
SYS_INIT_NAMED(init_fn, init_fn, level, prio)
```

登记初始化函数。

系统初始化期间，会按照给定级别和优先级调用此函数。

**参数（Parameters）**

| 名称／方向 | 说明 |
| --- | --- |
| `init_fn` | 初始化函数（Initialization Function）。 |
| `level` | 初始化级别。允许的词法单元为EARLY、PRE_KERNEL_1、PRE_KERNEL_2、POST_KERNEL、APPLICATION，以及启用CONFIG_SMP时的SMP。 |
| `prio` | 所属_level内的初始化优先级。必须是没有前导零或正负号的十进制整数字面量，例如32；也可以是等价的符号名称，例如#define MY_INIT_PRIO 32。不允许使用符号表达式，例如CONFIG_KERNEL_INIT_PRIORITY_DEFAULT + 5。 |

**说明（Note）**：注意：初始化函数的返回值会被忽略。

> 译注——源码核对：系统初始化入口的返回值不用于停止启动流程；本次调度代码仍可把结果传给跟踪钩子。设备初始化则由do_device_init记录状态，不能把这里的“忽略返回值”泛化成设备初始化错误也不记录。SYS_INIT支持的六个级别，与设备定义宏允许的PRE_KERNEL_1、PRE_KERNEL_2、POST_KERNEL不同。

<a id="gae862feb31eb4628b8ec95b471e5d4c54"></a>

### `SYS_INIT_NAMED`

```c
#define SYS_INIT_NAMED ( name, init_fn_, level, prio )
```

```c
#include <zephyr/init.h>
```

展开值（Value）：

```c
static const Z_DECL_ALIGN(struct init_entry)                                      \
        Z_INIT_ENTRY_SECTION(level, prio, 0) __used __noasan                      \
        Z_INIT_ENTRY_NAME(name) = {.init_fn = (init_fn_), .dev = NULL}            \
```

登记具有指定名称的初始化函数。

**参数（Parameters）**

| 名称／方向 | 说明 |
| --- | --- |
| `name` | SYS_INIT入口的唯一名称。 |
| `init_fn_` | 见SYS_INIT()。 |
| `level` | 见SYS_INIT()。 |
| `prio` | 见SYS_INIT()。 |

**说明（Note）**：注意：多个初始化调用使用同一个初始化函数时，可使用此宏。初始化函数的返回值会被忽略。

**参阅（See Also）**：另请参阅SYS_INIT()。

> 译注——源码核对：此宏为入口使用独立名称，便于同一个初始化函数登记多次；每个入口名称须唯一。回调结果不会用作启动流程中止条件。

## 5.5\_源码定位与版本边界

设备对象、句柄与定义宏可在[device.h](../../../include/zephyr/device.h)定位，初始化入口在[init.h](../../../include/zephyr/init.h)，运行时行为分别见[kernel/device.c](../../../kernel/device.c)和[kernel/init.c](../../../kernel/init.c)。本次另核对对应的[官方device.h](https://github.com/zephyrproject-rtos/zephyr/blob/main/include/zephyr/device.h)、[官方init.h](https://github.com/zephyrproject-rtos/zephyr/blob/main/include/zephyr/init.h)、[官方device.c](https://github.com/zephyrproject-rtos/zephyr/blob/main/kernel/device.c)及[官方init.c](https://github.com/zephyrproject-rtos/zephyr/blob/main/kernel/init.c)，摘要见[来源记录](../SOURCES.md)。本地源码、滚动更新的main与latest网页不自动视为同一版本；译注仅描述所读取快照。

> 译注——启动调度：当前z_sys_init_run_level通过entry->dev区分设备入口与SYS_INIT入口；有设备指针时调用设备初始化，但跳过标记为延后初始化的设备，否则调用init_fn。POST_KERNEL、APPLICATION及条件性的SMP阶段位于进入main之前；SYS_INIT优先级的字面量限制仍须遵守，不能用普通算术表达式替代。

本批完成官方文档翻译与源码静态核对；没有执行初始化、反初始化、固件构建或实板实验。
