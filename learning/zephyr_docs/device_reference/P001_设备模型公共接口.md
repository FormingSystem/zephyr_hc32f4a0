## 1.8\_详细说明（Detailed Documentation）

<a id="ga4e763eae14dcd41d599c485410ac2983"></a>

### `DEVICE_DECLARE`

```c
#define DEVICE_DECLARE ( dev_id)
```

```c
#include <zephyr/device.h>
```

展开值（Value）：

```c
static const struct device DEVICE_NAME_GET(dev_id)
```

声明一个静态设备对象。

可以在文件顶层使用此宏声明设备，从而在DEVICE_DEFINE()提供完整定义之前使用DEVICE_GET()。

在设备初始化函数或每实例配置函数中静态配置中断时，这通常很有用：DEVICE_DEFINE()需要初始化函数，而该函数内部又要使用DEVICE_GET()，由此形成循环依赖。

**参数（Parameters）**

| 名称／方向 | 说明 |
| --- | --- |
| `dev_id` | 设备标识符（Device Identifier）。 |

<a id="gac12521f4d900e8947aac45c1b228366d"></a>

DEVICE_DEINIT_DEFINE(dev_id, name, init_fn, NULL, pm, data, config,    \

**参阅（See Also）**：另请参阅DEVICE_DEINIT_DEFINE()。

<a id="ga61d851f960a701c9d47d6167b35ac99c"></a>

### `DEVICE_DEINIT_DEFINE`

```c
#define DEVICE_DEINIT_DEFINE ( dev_id, name, init_fn, deinit_fn, pm, data, config, level, prio, api )
```

```c
#include <zephyr/device.h>
```

展开值（Value）：

```c
Z_DEVICE_STATE_DEFINE(dev_id);                                         \
Z_DEVICE_DEFINE(DT_INVALID_NODE, dev_id, name, init_fn, deinit_fn, 0U, \
                pm, data, config, level, prio, api,                    \
                &Z_DEVICE_STATE_NAME(dev_id))
```

创建设备对象，安排其在启动时初始化，并提供反初始化（De-initialization）能力。

此宏定义一个在系统初始化期间由内核自动配置的设备。仅当设备不是从设备树节点分配时才应使用本宏；若从设备树节点分配设备，应改用DEVICE_DT_DEINIT_DEFINE()或DEVICE_DT_INST_DEINIT_DEFINE()。

注意：仅在启用CONFIG_DEVICE_DEINIT_SUPPORT时才使用deinit_fn。

**参数（Parameters）**

| 名称／方向 | 说明 |
| --- | --- |
| `dev_id` | 一个唯一的词法单元（Token），用于组成全局设备结构的C标识符名称。 |
| `name` | 设备的字符串名称，保存到device::name。可用此名称通过device_get_binding()查找设备。若要从用户模式查找，名称长度必须小于Z_DEVICE_MAX_NAME_LEN字符，包括末尾的空字符。 |

### `device_deinit()`

```c
int device_deinit ( const struct device * dev)
```

```c
#include <zephyr/device.h>
```

反初始化设备（De-initialize）。

反初始化时，设备会释放已取得的全部资源，例如引脚、内存、时钟和DMA通道，并恢复到复位状态。

注意：启用CONFIG_DEVICE_DEINIT_SUPPORT时可使用此功能。

**参数（Parameters）**

| 名称／方向 | 说明 |
| --- | --- |
| `dev` | 待反初始化的设备。 |

| --- | --- |

### `device_required_foreach()`
