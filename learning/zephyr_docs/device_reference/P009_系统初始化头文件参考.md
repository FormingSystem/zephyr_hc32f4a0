## 9.3\_源码定位与版本边界

设备对象、句柄与定义宏可在[device.h](../../../include/zephyr/device.h)定位，初始化入口在[init.h](../../../include/zephyr/init.h)，运行时行为分别见[kernel/device.c](../../../kernel/device.c)和[kernel/init.c](../../../kernel/init.c)。本次另核对对应的[官方device.h](https://github.com/zephyrproject-rtos/zephyr/blob/main/include/zephyr/device.h)、[官方init.h](https://github.com/zephyrproject-rtos/zephyr/blob/main/include/zephyr/init.h)、[官方device.c](https://github.com/zephyrproject-rtos/zephyr/blob/main/kernel/device.c)及[官方init.c](https://github.com/zephyrproject-rtos/zephyr/blob/main/kernel/init.c)，摘要见[来源记录](../SOURCES.md)。本地源码、滚动更新的main与latest网页不自动视为同一版本；译注仅描述所读取快照。

> 译注——宏与入口：完整的初始化级别、优先级和返回值规则见[系统初始化接口](P005_系统初始化接口.md)，入口字段见[初始化入口结构](P006_初始化入口结构.md)。本头文件参考页只含原始概览和摘要，宏的真实展开保留在[源码浏览页](P010_系统初始化头文件源码.md)。

本批只做官方文档翻译及源码核对，没有构建固件或执行设备初始化实验。
