# 第210章\_虚拟网络接口示例

原文：[官方页面](https://docs.zephyrproject.org/latest/samples/net/virtual/README.html)。读取日期：2026-10-14；保存的latest页面及HTML摘要见[来源记录](../SOURCES.md)。

<a id="overview"></a>

## 210.1 概述（Overview）

此示例创建用于演示的虚拟网络接口（Virtual network interface），本身并不执行实际业务。

原文介绍的结构共有4个网络接口。以太网接口提供实际网络连接，所有虚拟接口都运行在它之上。以太网接口之上有两个虚拟接口，一个仅提供IPv6隧道，另一个仅提供IPv4隧道；这两个隧道由IP套IP（IPIP）提供。示例自身提供的隧道接口则运行在IPv6隧道之上。

源码位于[samples/net/virtual](https://github.com/zephyrproject-rtos/zephyr/blob/main/samples/net/virtual)。

<a id="requirements"></a>

## 210.2 要求（Requirements）

完成[与主机系统联网（Networking with the host system）](P007_与主机系统联网.md#networking-with-host)所述准备。

<a id="building-and-running"></a>

## 210.3 构建与运行（Building and Running）

[net-tools](https://github.com/zephyrproject-rtos/net-tools)项目提供可在主机侧创建示例隧道的配置：

```sh
net-setup.sh -c zeth-tunnel.conf
```

注意，应用要求开发板提供以太网接口。构建命令如下：

```sh
west build -b <board to use> samples/net/virtual
```

> 译注——接口数量：前面的4接口结构保留自官方说明。当前`src/main.c`已注册`VIRTUAL_TEST`、`VIRTUAL_TEST2`、`VIRTUAL_TEST3`三个演示虚拟接口，并包含附着关系调整代码，不能假定运行时仍只有原文列举的4个接口。应以当前`net iface`输出与`net_virtual_interface_attach()`调用为依据跟踪层次；示例源码末尾也说明可以通过net-shell产生ping或UDP／TCP流量。
