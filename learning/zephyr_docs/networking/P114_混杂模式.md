# 第114章\_混杂模式

原文：[官方页面](https://docs.zephyrproject.org/latest/services/connectivity/networking/api/promiscuous.html)。读取日期：2026-10-14；保存的 latest 页面及 HTML 摘要见[来源记录](../SOURCES.md)。

## 1. 概述（Overview）

混杂模式（Promiscuous Mode）是网络接口控制器（Network Interface Controller，NIC）的一种工作模式：控制器把收到的所有流量交给应用，而不只传递其被配置为接收的那些帧。

这种模式通常用于数据包嗅探（Packet Sniffing），例如让应用查看网络上传输的数据，以诊断网络连接问题。更多背景见原文链接的[混杂模式百科条目](https://en.wikipedia.org/wiki/Promiscuous_mode)。

网络混杂模式 API 用于启用／禁用该模式，以及等待并接收网络数据。并非所有网络技术和设备驱动都支持混杂模式。

> 译注——接收范围：“所有流量”指控制器实际收到的流量。混杂模式改变接收过滤行为，并不会使未到达该接口的其他链路流量自动出现在应用中。

## 2. 用法示例（Sample Usage）

应用首先启用混杂模式：

```c
ret = net_promisc_mode_on(iface);
if (ret < 0) {
        if (ret == -EALREADY) {
                printf("Promiscuous mode already enabled\n");
        } else {
                printf("Cannot enable promiscuous mode for "
                       "interface %p (%d)\n", iface, ret);
        }
}
```

如果没有发生错误，应用可以开始等待网络数据：

```c
while (true) {
        pkt = net_promisc_mode_wait_data(K_FOREVER);
        if (pkt) {
                print_info(pkt);
        }

        net_pkt_unref(pkt);
}
```

最后，应用可以关闭混杂模式：

```c
ret = net_promisc_mode_off(iface);
if (ret < 0) {
        if (ret == -EALREADY) {
                printf("Promiscuous mode already disabled\n");
        } else {
                printf("Cannot disable promiscuous mode for "
                       "interface %p (%d)\n", iface, ret);
        }
}
```

> 译注——源码跟踪：上面是分段展示的用法。接收片段的无限循环配合 `K_FOREVER` 会一直等待和处理数据，必须由应用安排退出或其他控制路径，才会执行关闭操作。收到的 `net_pkt` 在处理完成后通过 `net_pkt_unref()` 释放该引用；当前官方 [`net_pkt.c`](https://github.com/zephyrproject-rtos/zephyr/blob/main/subsys/net/ip/net_pkt.c) 中此函数允许空指针并直接返回，因此不能把原片段中无条件调用它直接判定为空指针错误。等待队列及模式切换的实现见 [`promiscuous.c`](https://github.com/zephyrproject-rtos/zephyr/blob/main/subsys/net/ip/promiscuous.c)。

更完整的例子见[混杂模式示例（Promiscuous Mode）](P115_混杂模式示例.md#net-promiscuous-mode)。
