# 第109章\_链路层地址处理

原文：[官方页面](https://docs.zephyrproject.org/latest/services/connectivity/networking/api/net_linkaddr.html)。读取日期：2026-10-14；保存的 latest 页面及 HTML 摘要见[来源记录](../SOURCES.md)。

## 1. 概述（Overview）

需要为网络接口设置链路层地址（Link Layer Address），以便网络协议栈的第二层（Layer 2，L2）连接能够正常工作。

链路层地址通常为 6 字节，例如以太网（Ethernet）地址；IEEE 802.15.4 的链路层地址长度则为 8 字节。

## 2. API 参考（API Reference）

详细接口见[网络链路层地址库（Network Link Address Library）](https://docs.zephyrproject.org/latest/doxygen/html/group__net__linkaddr.html)。
