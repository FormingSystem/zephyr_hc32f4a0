# 第212章\_网络示例目录

原文：[官方页面](https://docs.zephyrproject.org/latest/samples/net/net.html)。读取日期：2026-10-14；保存的latest页面及HTML摘要见[来源记录](../SOURCES.md)。

这些示例演示网络子系统（Networking subsystem）的用法。

- [802.15.4串口无线电（802.15.4 "serial-radio"）](P177_IEEE802154串口无线电.md#wpan-serial)：为基于Contiki的边界路由器实现SLIP无线电设备（slip-radio）。

- [蜂窝调制解调器（Cellular modem）](P214_蜂窝调制解调器示例.md#cellular-modem)：使用蜂窝调制解调器与UDP服务器通信。

- [DHCPv4客户端（DHCPv4 client）](P035_DHCPv4客户端示例.md#dhcpv4-client)：启动DHCPv4客户端，从DHCPv4服务器获得IPv4地址。

- [DHCPv6前缀委派（DHCPv6 prefix delegation）](P036_DHCPv6前缀委派示例.md#dhcpv6-pd)：使用DHCPv6（RFC 8415）获取并委派IPv6前缀。

- [DNS解析（DNS resolve）](P037_DNS解析示例.md#dns-resolve)：解析给定主机名对应的IP地址。

- [FTP客户端Shell示例（FTP client shell sample）](P076_FTP客户端示例.md#ftp-client)：通过Zephyr Shell与FTP服务器交互。

- [IPv4自动配置客户端（IPv4 autoconf client）](P199_IPv4自动配置客户端示例.md#ipv4-autoconf)：执行IPv4自动配置，为自身分配随机IPv4地址。

- [Latmon客户端（Latmon Client）](P095_Latmon客户端示例.md#latmon-client)：测量GPIO事件间的时间差，通过latmon向被测系统（System under test，SUT）上运行的latmus服务报告延迟指标。

- [LwM2M客户端（LwM2M client）](P074_LwM2M客户端示例.md#lwm2m-client)：实现连接LwM2M服务器的客户端。

- [mDNS响应器（mDNS responder）](P200_mDNS响应器示例.md#mdns-responder)：监听并响应组播DNS查询。

- [MIDI2网络传输（MIDI2 network transport）](P219_MIDI2网络传输示例.md#netmidi2)：通过Network MIDI 2.0协议交换通用MIDI数据包（Universal MIDI Packet，UMP）。

- [MQTT发布者（MQTT publisher）](P060_MQTT发布者示例.md#mqtt-publisher)：向MQTT服务器发送PUBLISH消息。

- [MQTT-SN发布者（MQTT-SN publisher）](P063_MQTT_SN发布者示例.md#mqtt-sn-publisher)：向MQTT-SN网关发送PUBLISH消息。

- [网络数据包捕获（Network packet capture）](P201_网络数据包捕获示例.md#net-capture)：捕获数据包，经IP套IP（IPIP）隧道发送到远端主机。

- [网络数据包过滤器（Network packet filter）](P202_网络数据包过滤示例.md#net-pkt-filter)：安装网络数据包过滤钩子（Hook）。

- [网络统计（Network statistics）](P207_网络统计示例.md#net-stats)：从用户应用查询并显示网络统计。

- [OCPP充电桩（OCPP charge point）](P182_OCPP充电桩示例.md#ocpp)：实现连接中央系统（Central System）服务器、模拟电表读数的OCPP充电桩。

- [Prometheus示例（Prometheus Sample）](P220_Prometheus指标示例.md#prometheus)：实现展示多种指标类型的Prometheus指标服务器。

- [混杂模式（Promiscuous mode）](P115_混杂模式示例.md#net-promiscuous-mode)：为全部接口启用混杂模式，并打印传入数据包的信息。

- [精确时间协议（PTP）](P132_PTP示例.md#ptp)：启用PTP支持，通过日志监视消息与事件。

- [远程系统日志（Remote syslog）](P208_远程系统日志示例.md#syslog-net)：启用向远端服务器发送syslog消息的服务。

- [实时传输协议（RTP）](P142_RTP发送示例.md#net-rtp)：通过UDP组播发送或接收RTP音频流。

- [安全MQTT传感器与执行器（Secure MQTT Sensor/Actuator）](P061_安全MQTT传感器与执行器示例.md#secure-mqtt-sensor-actuator)：实现基于MQTT的物联网传感器／执行器设备。

- [SSH服务端与客户端（SSH server and client）](P221_SSH服务端与客户端示例.md#ssh-server-client)：实现SSH服务端和客户端Shell支持。

- [Telnet控制台（Telnet console）](P209_Telnet控制台示例.md#telnet-console)：通过Telnet访问Zephyr Shell。

- [TFTP客户端（TFTP client）](P078_TFTP客户端示例.md#tftp-client)：使用TFTP客户端库，从服务器获取文件或向服务器上传文件。

- [虚拟网络接口（Virtual network interface）](P210_虚拟网络接口示例.md#virtual-network-interface)：创建示例虚拟网络接口。

- [WireGuard虚拟专用网（Wireguard VPN）](P211_WireGuard虚拟专用网示例.md#wireguard-vpn)：实现回显服务器，通过WireGuard VPN连接将接收的数据包送回发送方。

- [zperf网络流量生成器（zperf: Network Traffic Generator）](P097_zperf网络流量生成器示例.md#zperf)：使用zperf Shell工具评估网络带宽。
