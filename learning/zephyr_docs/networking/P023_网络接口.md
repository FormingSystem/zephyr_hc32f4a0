# 第23章\_网络接口

原文：[官方页面](https://docs.zephyrproject.org/latest/services/connectivity/networking/api/net_if.html)。读取日期：2026-10-14；保存的 latest 页面及 HTML 摘要见[来源记录](../SOURCES.md)。

## 23.1\_概览（Overview）

网络接口（Network Interface）连接网络设备驱动与协议栈上层，所有收发数据都经过接口。接口不能在运行时创建；其信息放入专用链接器段（Linker Section），在链接阶段填充。

使用 `NET_DEVICE_INIT()` 宏创建接口。以太网应使用 `ETH_NET_DEVICE_INIT()`，启用 [`CONFIG_NET_VLAN`](https://docs.zephyrproject.org/latest/kconfig.html#CONFIG_NET_VLAN) 后，该宏还会自动创建虚拟局域网（Virtual LAN，VLAN）接口。这些宏通常出现在网络驱动源码中。

调用 [`net_if_up()`](https://docs.zephyrproject.org/latest/doxygen/html/group__net__if.html#ga02644cc623fc7a8878c17d54984e4210) 开启接口，调用 [`net_if_down()`](https://docs.zephyrproject.org/latest/doxygen/html/group__net__if.html#ga2187650062d6139b9f4b81745a206803) 关闭接口。设备上电时，接口默认也会启用。

接口可以通过 `struct net_if *` 指针或接口索引（Interface Index）引用。`net_if_get_by_index()` 从索引取得接口，`net_if_get_by_iface()` 从接口指针取得索引。

要让网络设备建立 IP 通信，需要分配 IP 地址。动态网络通常通过 DHCPv4 等方式自动设置；应用也可用 `net_if_ipv4_addr_add()` 等 API 手动添加地址。

`net_if_get_default()` 返回默认接口（Default Interface）。默认接口的选择由 [`CONFIG_NET_DEFAULT_IF_FIRST`](https://docs.zephyrproject.org/latest/kconfig.html#CONFIG_NET_DEFAULT_IF_FIRST)、[`CONFIG_NET_DEFAULT_IF_ETHERNET`](https://docs.zephyrproject.org/latest/kconfig.html#CONFIG_NET_DEFAULT_IF_ETHERNET) 等选项决定，完整选项见[网络 IP 层 Kconfig](https://github.com/zephyrproject-rtos/zephyr/blob/main/subsys/net/ip/Kconfig)。

收发分组可以按网络分组优先级（Packet Priority）分类，以太网 VLAN 场景经常使用这一机制，使较高优先级的分组更早发送或接收。流量类别（Traffic Class）队列由 [`CONFIG_NET_TC_TX_COUNT`](https://docs.zephyrproject.org/latest/kconfig.html#CONFIG_NET_TC_TX_COUNT) 和 [`CONFIG_NET_TC_RX_COUNT`](https://docs.zephyrproject.org/latest/kconfig.html#CONFIG_NET_TC_RX_COUNT) 配置。

启用 [`CONFIG_NET_PROMISCUOUS_MODE`](https://docs.zephyrproject.org/latest/kconfig.html#CONFIG_NET_PROMISCUOUS_MODE) 且底层网络技术支持混杂模式（Promiscuous Mode）时，可以接收设备驱动能够收到的全部分组，见[混杂模式 API](P114_混杂模式.md#promiscuous-interface)。

## 23.2\_网络接口状态管理（Network Interface State Management）

Zephyr 按 RFC 2863 区分管理状态（Administrative State）与运行状态（Operational State）。管理状态表明接口被开启还是关闭，由 [`NET_IF_UP`](https://docs.zephyrproject.org/latest/doxygen/html/group__net__if.html#ggae691e5537917ffce27ad0db82c730371ab0ab7393d643354c46c3437d74c15840) 标志表示，应用通过 [`net_if_up()`](https://docs.zephyrproject.org/latest/doxygen/html/group__net__if.html#ga02644cc623fc7a8878c17d54984e4210)、[`net_if_down()`](https://docs.zephyrproject.org/latest/doxygen/html/group__net__if.html#ga2187650062d6139b9f4b81745a206803) 控制。网络驱动或 L2 实现不应自行改变管理状态。

管理状态开启不代表已经能够发送分组，因此还需要表示接口内部状况的运行状态。以下变化都会重新计算运行状态：

- 应用开启或关闭接口，即管理状态变化。
- 驱动／L2 通知物理层（PHY）状态变化。
- 驱动／L2 通知接口加入或离开网络。

物理层状态由 [`NET_IF_LOWER_UP`](https://docs.zephyrproject.org/latest/doxygen/html/group__net__if.html#ggae691e5537917ffce27ad0db82c730371ab1a529826bad6b4bcd04185372f97d6d) 表示，通过 [`net_if_carrier_on()`](https://docs.zephyrproject.org/latest/doxygen/html/group__net__if.html#ga35e5db3a631ac9039f14d86e59fc0dcc)、[`net_if_carrier_off()`](https://docs.zephyrproject.org/latest/doxygen/html/group__net__if.html#ga6839941422a88c1f707ab70ea34df323) 设置。新初始化的接口默认置位此标志。以太网线插入或拔出就是载波状态（Carrier State）变化的例子。

关联状态由 [`NET_IF_DORMANT`](https://docs.zephyrproject.org/latest/doxygen/html/group__net__if.html#ggae691e5537917ffce27ad0db82c730371a7dd1db72a37b1fbc4c4491ce1c75238d) 表示，通过 [`net_if_dormant_on()`](https://docs.zephyrproject.org/latest/doxygen/html/group__net__if.html#ga89a3374d4bb116460a7b7c50a750b593)、[`net_if_dormant_off()`](https://docs.zephyrproject.org/latest/doxygen/html/group__net__if.html#ga1c31fac887d944ac0a16aad70e889496) 设置。新初始化接口默认清除此标志。以 Wi-Fi 为例，驱动初始化时应开启等待状态（Dormant），成功连接接入点（Access Point）后再关闭等待状态。

运行状态按下表更新：

| 判断条件 | 运行状态 |
| --- | --- |
| `!net_if_is_admin_up()` | [`NET_IF_OPER_DOWN`](https://docs.zephyrproject.org/latest/doxygen/html/group__net__if.html#ggadfe9d90f24046cd9bd4bbee096e747b9adb20a95215310c420f8dae7e17a2f367)，接口关闭。 |
| `net_if_is_admin_up() && !net_if_is_carrier_ok()` | 普通接口为 [`NET_IF_OPER_DOWN`](https://docs.zephyrproject.org/latest/doxygen/html/group__net__if.html#ggadfe9d90f24046cd9bd4bbee096e747b9adb20a95215310c420f8dae7e17a2f367)；堆叠的虚拟接口为 [`NET_IF_OPER_LOWERLAYERDOWN`](https://docs.zephyrproject.org/latest/doxygen/html/group__net__if.html#ggadfe9d90f24046cd9bd4bbee096e747b9ae7e9b8b12ae618a5ee1483dee916aab4)，表示下层关闭。 |
| `net_if_is_admin_up() && net_if_is_carrier_ok() && net_if_is_dormant()` | [`NET_IF_OPER_DORMANT`](https://docs.zephyrproject.org/latest/doxygen/html/group__net__if.html#ggadfe9d90f24046cd9bd4bbee096e747b9a5cbe2aa27a444444d4acf122113d430d)，仍在等待网络关联就绪。 |
| `net_if_is_admin_up() && net_if_is_carrier_ok() && !net_if_is_dormant()` | [`NET_IF_OPER_UP`](https://docs.zephyrproject.org/latest/doxygen/html/group__net__if.html#ggadfe9d90f24046cd9bd4bbee096e747b9a6b99bfc28d831292029761d74209ee03)，运行状态就绪。 |

只有进入 [`NET_IF_OPER_UP`](https://docs.zephyrproject.org/latest/doxygen/html/group__net__if.html#ggadfe9d90f24046cd9bd4bbee096e747b9a6b99bfc28d831292029761d74209ee03)，接口才设置 [`NET_IF_RUNNING`](https://docs.zephyrproject.org/latest/doxygen/html/group__net__if.html#ggae691e5537917ffce27ad0db82c730371add3e2ecdcd5de3154f9bd2836428a25a)，表示应用可使用该接口。
