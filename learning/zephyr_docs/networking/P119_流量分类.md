# 第119章\_流量分类

原文：[官方页面](https://docs.zephyrproject.org/latest/services/connectivity/networking/api/traffic-class.html)。读取日期：2026-10-14；保存的 latest 页面及 HTML 摘要见[来源记录](../SOURCES.md)。

## 1. 概述（Overview）

[流量分类（Traffic Classification）](https://en.wikipedia.org/wiki/Traffic_classification)是根据不同参数自动对计算机网络流量归类的过程。Zephyr 使用 VLAN 优先级代码点（Priority Code Point，PCP）对发送和接收的网络包分类。VLAN 优先级的进一步信息见 [IEEE 802.1Q](https://en.wikipedia.org/wiki/IEEE_802.1Q)。

默认情况下，Zephyr 平等对待全部网络流量。需要区分时，可以用 [`CONFIG_NET_TC_TX_COUNT`](https://docs.zephyrproject.org/latest/kconfig.html#CONFIG_NET_TC_TX_COUNT) 设置发送队列数，用 [`CONFIG_NET_TC_RX_COUNT`](https://docs.zephyrproject.org/latest/kconfig.html#CONFIG_NET_TC_RX_COUNT) 设置接收队列数。原文将每个流量类别队列描述为对应一个具有优先级的内核工作队列（Kernel Work Queue）。

VLAN 优先级按照 [IEEE 802.1Q 规范](https://ieeexplore.ieee.org/document/6991462/)附录 I.3、第 8.6.6 节表 8-4 和第 34.5 节表 34-1 中的规则映射到流量类别（Traffic Class，TC）；流量类别再映射到对应内核工作队列。接收（Rx）和发送（Tx）方向各自最多支持 8 个流量类别。

各种映射的具体实现见 [`subsys/net/ip/net_tc.c`](https://github.com/zephyrproject-rtos/zephyr/blob/main/subsys/net/ip/net_tc.c)。

> 译注——源码跟踪：当前官方 [`net_tc.c`](https://github.com/zephyrproject-rtos/zephyr/blob/main/subsys/net/ip/net_tc.c) 为各类别初始化 FIFO，并通过 `k_thread_create()` 创建收发处理线程，线程从 FIFO 取出数据包。原文中的“工作队列”描述不应被理解为当前代码一定使用 `k_work_q` API。分类优先级、线程调度优先级和以太网硬件队列是相互关联但不同的对象；本页描述的软件分类本身不等于已启用硬件整形。
