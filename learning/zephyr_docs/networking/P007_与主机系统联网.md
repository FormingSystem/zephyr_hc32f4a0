# 第7章\_与主机系统联网

原文：[官方页面](https://docs.zephyrproject.org/latest/services/connectivity/networking/networking_with_host.html)。读取日期：2026-10-14；保存的 latest 页面及 HTML 摘要见[来源记录](../SOURCES.md)。

## 7.1\_与主机通信的方式

开发网络软件时，通常需要与 Linux 桌面电脑等主机系统（Host System）连接并交换数据。根据开发板，可以采用以下方式。

| 方式 | 工作原理与适用说明 | 官方详细文档 |
| --- | --- | --- |
| QEMU与SLIP | 通过串口在Zephyr和主机之间传输IP分组。串行线路网际协议（Serial Line Internet Protocol，SLIP）属于旧式传输方式，速度也较慢，仅在必要时使用。 | [QEMU联网](P009_QEMU联网概览.md#networking-with-qemu) |
| QEMU内置以太网驱动 | 通过QEMU内置以太网驱动交换IP分组。并非所有QEMU开发板都支持内置以太网，部分情况下仍需SLIP。 | [QEMU以太网联网](P010_QEMU以太网联网.md#networking-with-eth-qemu) |
| QEMU用户网络SLIRP | slirp在QEMU中提供完整TCP/IP协议栈，实现带网络地址转换（NAT）的虚拟网络。原文称可用于任意模型，无需TAP所需的主机管理员权限；但存在性能等限制，降低了实际用途。 | [QEMU用户网络](P011_QEMU用户网络.md#networking-with-user-qemu) |
| Arm FVP用户模式网络 | 仿真IP路由器和DHCP服务器，在客户机与主机之间路由TCP／UDP流量，并通过主机用户模式套接字与其他主机通信。多种IP网络服务可在无需管理员权限或额外主机驱动的情况下使用。 | [Arm FVP用户网络](P013_ArmFVP用户网络.md#networking-with-armfvp) |
| native_sim开发板 | Zephyr作为主机上的用户空间进程运行，可直接附加主机调试器，便于调试。需要适配驱动与主机接口，可使用TAP虚拟以太网驱动或卸载套接字（Offloaded Sockets）驱动。 | [native_sim联网](P008_native_sim联网.md#networking-with-native-sim) |
| USB设备网络 | Zephyr运行于真实开发板，通过USB与主机连接。 | [USB设备联网](P014_USB设备联网.md#usb-device-networking-setup) |
| 连接多个Zephyr实例 | 将多个QEMU实例或native_sim进程互联。 | [多个Zephyr实例联网](P015_多个Zephyr实例联网.md#networking-with-multiple-instances) |
| 两个QEMU间仿真IEEE 802.15.4 | 两个Zephyr实例通过UART承载IEEE 802.15.4链路层。 | [QEMU与IEEE 802.15.4联网](P012_QEMU与IEEE802154联网.md#networking-with-ieee802154-qemu) |
| native_sim仿真以太网桥 | 一个Zephyr实例启用 [`CONFIG_NET_ETHERNET_BRIDGE`](https://docs.zephyrproject.org/latest/kconfig.html#CONFIG_NET_ETHERNET_BRIDGE)，主机侧创建 `zeth0`、`zeth1`，两接口之间的网络分组经过桥接（Bridging）。 | [native_sim以太网桥](P016_native_sim以太网桥.md#networking-with-native-sim-eth-bridge) |

译注：各方式的具体硬件模型、驱动和版本约束以对应章节为准。例如，当前Zephyr的QEMU用户网络启动逻辑仍要求配置受支持的网卡模型，不能把“无需TAP”理解为任意客户机无需网络设备即可联网。
