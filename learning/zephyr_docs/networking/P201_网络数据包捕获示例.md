# 第201章\_网络数据包捕获示例

原文：[官方页面](https://docs.zephyrproject.org/latest/samples/net/capture/README.html)。读取日期：2026-10-14；保存的latest页面及HTML摘要见[来源记录](../SOURCES.md)。

<a id="overview"></a>

## 201.1 概述（Overview）

此应用配置设备，使网络命令行（net-shell）能够启用网络数据包捕获（Network packet capture）。

捕获的数据包经IP套IP隧道（IP-in-IP，IPIP tunnel）发送到远端主机。隧道可以与被捕获流量使用同一连接，也可以使用独立的承载链路（Bearer）。例如，捕获接口1的流量时，接收数据包的远端主机既可以通过接口1到达，也可以在设备连接了多个网络接口时通过另一个接口到达。

<a id="requirements"></a>

## 201.2 要求（Requirements）

完成[与主机系统联网（Networking with the host system）](P007_与主机系统联网.md#networking-with-host)所述准备。

<a id="building-and-running"></a>

## 201.3 构建与运行（Building and Running）

按以下方式构建应用：

```sh
west build -b <board to use> samples/net/capture
```

面向[原生模拟器（Native simulator，native_sim）](../native_reference/P004_Native_Simulator本机模拟器.md#native_sim)的构建示例：

```sh
west build -b native_sim samples/net/capture -- -DEXTRA_CONF_FILE=overlay-tunnel.conf
```

./net-setup.sh -c zeth-tunnel.conf

### 201.4.1 网络捕获配置（Network Capture Configuration）

在Zephyr控制台输入：

```text
uart:~$ net iface

Interface 0x807df74 (Virtual) [1]
=================================
Interface is down.

Interface 0x807e040 (Ethernet) [2]
==================================
Link addr : 02:00:5E:00:53:3B
MTU       : 1452
Flags     : AUTO_START,IPv4,IPv6
Ethernet capabilities supported:
IPv6 unicast addresses (max 4):
     fe80::5eff:fe00:533b autoconf preferred infinite
     2001:db8::1 manual preferred infinite
IPv6 multicast addresses (max 4):
     ff02::1
     ff02::1:ff00:533b
     ff02::1:ff00:1
IPv6 prefixes (max 2):
     <none>
IPv6 hop limit           : 64
IPv6 base reachable time : 30000
IPv6 reachable time      : 43300
IPv6 retransmit timer    : 0
IPv4 unicast addresses (max 2):
     192.0.2.1 manual preferred infinite
IPv4 multicast addresses (max 1):
     <none>
IPv4 gateway : 0.0.0.0
IPv4 netmask : 255.255.255.0
```

接着设置监控，将捕获的数据包作为IPv6/UDP数据包的有效载荷（Payload）发送：

```text
uart:~$ net capture setup 192.0.2.2 2001:db8:200::1 2001:db8:200::2
Capture setup done, next enable it by "net capture enable <idx>"
```

`net capture`显示当前配置。由于尚未启用捕获，被捕获接口尚未设置：

```text
uart:~$ net capture
Network packet capture disabled
                Capture  Tunnel
Device          iface    iface   Local                  Peer
NET_CAPTURE0    -        1      [2001:db8:200::1]:4242  [2001:db8:200::2]:4242
```

接下来启用对接口2的网络数据包捕获：

```sh
uart:~$ net capture enable 2
```

隧道接口进入UP状态，捕获的数据包被发送到对端主机：

```text
uart:~$ net iface 1

Interface 0x807df74 (Virtual) [1]
=================================
Name      : IPv4 tunnel
Attached  : 2 (Ethernet / 0x807e040)
Link addr : 8E:F9:94:6D:B9:E6
MTU       : 1452
Flags     : POINTOPOINT,NO_AUTO_START,IPv6
IPv6 unicast addresses (max 4):
     fe80::aee6:fbff:fe50:28c0 autoconf preferred infinite
     2001:db8:200::1 manual preferred infinite
IPv6 multicast addresses (max 4):
     <none>
IPv6 prefixes (max 2):
     <none>
IPv6 hop limit           : 64
IPv6 base reachable time : 30000
IPv6 reachable time      : 22624
IPv6 retransmit timer    : 0
IPv4 not enabled for this interface.
```

此时执行：

```sh
uart:~$ net ping -c 1 192.0.2.2
```

应能看到发往`192.0.2.2`的ICMPv4消息；捕获到的数据包也会发往`192.0.2.2`，并通过隧道送达`2001:db8:200::2`。UDP端口默认是4242，可在设置隧道端点地址时修改。
