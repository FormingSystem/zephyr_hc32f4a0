# 第170章\_IEEE802154无线网络

原文：[官方页面](https://docs.zephyrproject.org/latest/services/connectivity/networking/api/ieee802154.html)。读取日期：2026-10-14；保存的 latest 页面及 HTML 摘要见[来源记录](../SOURCES.md)。

## 1. 简介（Introduction）

IEEE 802.15.4 是定义低速率无线个域网（Low-Rate Wireless Personal Area Networks，LR-WPANs）运行方式的技术标准。原文提供[IEEE 802.15.4 维基百科条目](https://en.wikipedia.org/wiki/IEEE_802.15.4)作为较详细的概览入口。

原文说明，可通过[IEEE GET 计划](https://ieeexplore.ieee.org/browse/standards/get-program/page/series?id=68)访问标准的最新版本，创建免费的 IEEE 账户后即可下载。

Zephyr 本页声明遵循 IEEE 802.15.4-2020 规范。该版本向后兼容 IEEE 802.15.4-2015，后者的一部分被纳入 Thread 协议栈。2020 版还包含此前已采纳的扩展：与工业物联网（Industrial IoT）和自动化相关的 IEEE 802.15.4g，即智能公用事业网络的频移键控（Smart Utility Networks Frequency-Shift Keying，SUN FSK），以及 IEEE 802.15.4e，即时隙信道跳频（Time Slotted Channel Hopping，TSCH）。关于超宽带（Ultra-Wideband，UWB）测距的新进展，原文指向 IEEE 802.15.4z，并说明它尚未整合到该版主标准中。

除非另有说明，文档引用标准的章节、表格和图号，均以 IEEE 802.15.4-2020 为准。

> 译注：以上年份与“尚未整合”的表述保留本页的规范基线，不应理解为翻译日期的全部 IEEE 标准发布状态。本章翻译 Zephyr 说明页，不复制或翻译外部 IEEE 标准全文。

Zephyr 支持原生 IEEE 802.15.4 和[Thread 协议](P171_Thread协议.md#thread-protocol-interface)，两者均使用低功耗无线个域网 IPv6（IPv6 over Low-Power Wireless Personal Area Networks，6LoWPAN）。Zephyr 的 Thread 实现基于[OpenThread](https://openthread.io/)；原生 IEEE 802.15.4 使用 6LoWPAN 的 IPv6 首部压缩（Header Compression）。

## 2. 支持的驱动（Supported Drivers）

Zephyr 源码树内包含多种硬件平台的 IEEE 802.15.4 无线电驱动（Radio Drivers）。原文称下表概述驱动、厂商、频段、总线及启用所需 Kconfig；实际表格的第三列是设备树兼容标识（Devicetree Compatible），没有单列 Kconfig 符号。下表保留实际五列的全部内容，具体配置另见表后链接。

## 3. API 参考（API Reference）

### 3.1 IEEE 802.15.4 API 总览

[IEEE 802.15.4 与 Thread API 总览](https://docs.zephyrproject.org/latest/doxygen/html/group__ieee802154.html)面向所有读者，介绍整个 IEEE 802.15.4 子系统，以及其 API、配置和用户接口。

相关示例：[802.15.4 串口无线电（Serial-Radio）](P177_IEEE802154串口无线电.md#wpan-serial)，为基于 Contiki 的边界路由器实现 SLIP 无线电设备。

### 3.2 管理 API（Management API）

这是 IEEE 802.15.4 应用开发者主要使用的子系统专用 API，允许在运行时配置子系统。其他相关接口还包括常见的 Shell、套接字（Socket）、Kconfig 和设备树（Devicetree）API，可在 Zephyr 与子系统无关的通用文档中查找，注意 `IEEE802154`／`ieee802154` 前缀。

入口：[IEEE 802.15.4 网络管理 API](https://docs.zephyrproject.org/latest/doxygen/html/group__ieee802154__mgmt.html)。

### 3.3 驱动 API（Driver API）

这是 IEEE 802.15.4 驱动开发者主要关注的 API。

入口：[IEEE 802.15.4 驱动 API](https://docs.zephyrproject.org/latest/doxygen/html/group__ieee802154__driver.html)。

### 3.4 二层与原生协议栈 API（L2 / Native Stack API）

该接口描述 IEEE 802.15.4 二层（Layer 2，L2）原生协议栈。应用与驱动不会直接访问它；Zephyr 上层网络（L3+）、套接字和网络上下文（Network Context）抽象在内部调用它。因此，它主要面向 IEEE 802.15.4 子系统贡献者。

入口：[IEEE 802.15.4 L2 API](https://docs.zephyrproject.org/latest/doxygen/html/group__ieee802154__l2.html)。

### 3.5 OpenThread 二层适配 API（L2 Adaptation Layer API）

Zephyr 的 OpenThread L2 平台适配层把外部 OpenThread 协议栈与不绑定上层协议的 IEEE 802.15.4 驱动 API 接合起来。该接口主要面向 OpenThread L2 子系统贡献者。

OpenThread API 属于[Thread 协议子系统](P171_Thread协议.md#thread-protocol-interface)，在该处说明。上述自动生成 API 页面分别跟踪翻译状态，本章总览完成不等于每个详细接口都已翻译。
