# 第44章\_简单回显服务器示例

原文：[官方页面](https://docs.zephyrproject.org/latest/samples/net/sockets/echo/README.html)。读取日期：2026-10-14；保存的 latest 页面及 HTML 摘要见[来源记录](../SOURCES.md)。

## 44.1 概览（Overview）

Zephyr 的 `sockets/echo` 示例通过 BSD 套接字兼容 API（BSD Sockets Compatible API），实现同时支持 IPv4 和 IPv6 的 TCP 回显服务器（TCP Echo Server）。TCP 是传输控制协议（Transmission Control Protocol）。

示例旨在演示如何编写能在 POSIX 系统和 Zephyr 之间移植的套接字应用。因此它保持精简，只支持 IPv4、IPv6 和 TCP。

源码位于[samples/net/sockets/echo](https://github.com/zephyrproject-rtos/zephyr/blob/main/samples/net/sockets/echo)，也可[在 GitHub 浏览官方源码](https://github.com/zephyrproject-rtos/zephyr/blob/main//samples/net/sockets/echo/README.rst/..)。

## 44.2 运行要求（Requirements）

使用[与主机系统联网](P007_与主机系统联网.md#networking-with-host)的环境，或使用具有硬件联网能力的开发板。

## 44.3 构建与运行（Building and Running）

构建 `sockets/echo` 的 Zephyr 版本：

```shell
west build -b <board_to_use> samples/net/sockets/echo
```

`<board_to_use>` 表示所使用的开发板目标，需要替换为实际目标名。命令中的示例路径相对于 Zephyr 源码根目录。

示例启动后，在 `192.0.2.1` 的 `4242` 端口等待连接。最简单的连接方式是：

```shell
$ telnet 192.0.2.1 4242
```

连接建立后，应用将收到的每一行回显给客户端。服务器使用单线程（Single Thread）和阻塞套接字（Blocking Socket），所以一次只能服务一个客户端连接。当前客户端断开后，下一个连接才能继续得到服务。

### 在 POSIX 主机上运行（Running on POSIX Host）

同一份应用源码也能在 Linux 等 POSIX 系统上构建。原文说明，两种环境主要使用不同的头文件，应用代码相同。

在该示例目录中构建：

```shell
$ make -f Makefile.host
```

运行程序：

```shell
$ ./socket_echo
```

从另一个终端测试：

```shell
$ telnet 127.0.0.1 4242
```

应用行为与 Zephyr 版本相同。`127.0.0.1` 是主机本地回环地址（Loopback Address）；`$` 是原文 Shell 提示符，不属于要输入的命令。主机程序名已与官方 [Makefile.host](https://github.com/zephyrproject-rtos/zephyr/blob/main/samples/net/sockets/echo/Makefile.host) 核对。

### 在 cc3220sf_launchxl 上运行

参见[CC3220SF LaunchXL](https://docs.zephyrproject.org/latest/boards/ti/cc3220sf_launchxl/doc/index.html#cc3220sf_launchxl) 页面中关于配网（Provisioning）和快速连接（Fast Connect）的说明。

先使用 Wi-Fi Shell 示例连接无线接入点（Access Point，AP），再运行本回显应用。控制台会打印 IP 地址，然后可按前述方法测试。

> 译注：这里的开发板与配网说明来自官方原页，不是本仓库的芯片实验步骤。连接时使用实际打印的地址；本轮未进行主机编译、烧录或回显通信测试。
