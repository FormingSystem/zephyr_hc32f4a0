原文：[官方页面](https://docs.zephyrproject.org/latest/services/connectivity/networking/network_tracing.html)。读取日期：2026-10-14；保存的 latest 页面及 HTML 摘要见[来源记录](../SOURCES.md)。

## 1. 网络跟踪（Network Tracing）

用户可以启用网络核心协议栈（Network Core Stack）和套接字 API 调用的跟踪（Tracing）。

[`CONFIG_TRACING_NET_CORE`](https://docs.zephyrproject.org/latest/kconfig.html#CONFIG_TRACING_NET_CORE) 控制核心网络协议栈跟踪。如果跟踪和联网功能均已启用，此选项默认启用。系统开始收集接收与发送调用的处理结论（Verdict），即网络包是否成功发送或接收；也收集发送／接收的耗时，即交付网络包用了多长时间，以及使用的网络接口（Network Interface）、优先级（Priority）和流量类别（Traffic Class）。

[`CONFIG_TRACING_NET_SOCKETS`](https://docs.zephyrproject.org/latest/kconfig.html#CONFIG_TRACING_NET_SOCKETS) 用于跟踪系统内 BSD 套接字（BSD Sockets）调用的使用情况。启用跟踪与 BSD 套接字 API 支持后，此选项启用。系统开始收集调用了哪些 BSD 套接字 API，以及这些调用使用的参数与返回内容。

跟踪服务的使用方法见 [跟踪文档（Tracing Documentation）](https://docs.zephyrproject.org/latest/services/tracing/index.html#tracing)。
