# 第213章\_套接字示例目录

原文：[官方页面](https://docs.zephyrproject.org/latest/samples/net/sockets/sockets.html)。读取日期：2026-10-14；保存的latest页面及HTML摘要见[来源记录](../SOURCES.md)。

这些示例演示[BSD套接字（BSD Sockets）](P040_BSD套接字.md#bsd-sockets-interface)API的用法。

- [使用poll()的异步回显服务器（Asynchronous echo server using poll()）](P045_poll异步回显示例.md#async-sockets-echo)：使用BSD套接字与poll()实现异步IPv4／IPv6 TCP回显服务器。

- [使用select()的异步回显服务器（Asynchronous echo server using select()）](P046_select异步回显示例.md#async-sockets-echo-select)：使用BSD套接字与select()实现异步IPv4／IPv6 TCP回显服务器。

- [CoAP客户端（CoAP client）](P068_CoAP客户端示例.md#coap-client)：使用CoAP库实现获取资源的客户端。

- [CoAP下载（CoAP download）](P070_CoAP下载示例.md#coap-download)：使用CoAP客户端API，通过GET请求下载数据。

- [CoAP服务（CoAP service）](P072_CoAP服务示例.md#coap-server)：使用CoAP服务器子系统注册CoAP资源。

- [CoAP的TCP客户端（CoAP TCP Client）](P069_CoAP_TCP客户端示例.md#coap-client-tcp)：使用CoAP over TCP客户端与CoAP服务器通信。

- [CoAP上传（CoAP upload）](P071_CoAP上传示例.md#coap-upload)：使用CoAP客户端API，通过PUT请求上传数据。

- [简易HTTP服务器（Dumb HTTP server）](P057_简易HTTP服务器示例.md#socket-dumb-http-server)：使用BSD套接字实现简单、可移植的HTTP服务器。

- [多线程简易HTTP服务器（Dumb HTTP server (multi-threaded)）](P058_多线程HTTP服务器示例.md#socket-dumb-http-server-mt)：使用BSD套接字实现支持并发连接的简单HTTP服务器。

- [高级回显客户端（Echo client (advanced)）](P048_高级回显客户端示例.md#sockets-echo-client)：实现发送IP数据包、等待回传数据并进行校验的客户端。

- [高级回显服务器（Echo server (advanced)）](P047_高级回显服务器示例.md#sockets-echo-server)：实现将接收数据包回送给发送方的UDP／TCP服务器。

- [套接字服务回显服务器（Echo server (service)）](P043_套接字服务回显示例.md#sockets-service-echo)：使用BSD套接字与套接字服务API实现简单的IPv4／IPv6 TCP回显服务器。

- [简单回显服务器（Echo server (simple)）](P044_简单回显服务器示例.md#sockets-echo)：使用BSD套接字实现简单的IPv4／IPv6 TCP回显服务器。

- [HTTP客户端（HTTP Client）](P050_HTTP客户端示例.md#sockets-http-client)：实现发出多种HTTP请求的HTTP(S)客户端。

- [使用普通套接字的HTTP GET（HTTP GET using plain sockets）](P051_普通套接字HTTP_GET示例.md#sockets-http-get)：使用普通BSD套接字实现HTTP(S)客户端。

- [HTTP服务器（HTTP Server）](P056_HTTP服务器示例.md#sockets-http-server)：实现展示多种资源类型的HTTP(S)服务器。

- [HTTP大文件下载（Large HTTP download）](P052_HTTP大文件下载示例.md#sockets-big-http-download)：使用BSD套接字从Web服务器下载大文件。

- [网络管理套接字（Network management socket）](P204_网络管理套接字示例.md#sockets-net-mgmt)：通过网络管理套接字监听网络管理事件。

- [数据包套接字（Packet socket）](P133_数据包套接字示例.md#packet-socket)：在以太网上使用原始数据包套接字。

- [SNTP客户端（SNTP client）](P038_SNTP客户端示例.md#sntp-client)：使用SNTP从主机取得当前时间。

- [SNTP服务器（SNTP server）](P039_SNTP服务器示例.md#sntp-server)：向网络上的SNTP客户端提供当前时间。

- [SocketCAN（SocketCAN）](P206_SocketCAN示例.md#socket-can)：使用BSD套接字API发送和接收原始CAN帧。

- [套接字对（Socketpair）](P205_套接字对示例.md#sockets-socketpair)：通过套接字对实现线程间通信。

- [使用SO_TXTIME的UDP发送器（UDP sender using SO_TXTIME）](P134_SO_TXTIME定时发送示例.md#so_txtime)：通过SO_TXTIME套接字选项控制数据包发送时间。

- [WebSocket客户端（WebSocket Client）](P054_WebSocket客户端示例.md#sockets-websocket-client)：实现连接WebSocket服务器的客户端。



对应官方文档源码：[samples/net/sockets/sockets.rst](https://raw.githubusercontent.com/zephyrproject-rtos/zephyr/main/samples/net/sockets/sockets.rst)。
