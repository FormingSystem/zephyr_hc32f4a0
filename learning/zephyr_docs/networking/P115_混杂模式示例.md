# 第115章\_混杂模式示例

原文：[官方页面](https://docs.zephyrproject.org/latest/samples/net/promiscuous_mode/README.html)。读取日期：2026-10-14；保存的 latest 页面及 HTML 摘要见[来源记录](../SOURCES.md)。

## 1. 概述（Overview）

本应用在系统中的每个网络接口上启用混杂模式（Promiscuous Mode），随后监听传入的网络数据包并显示相关信息。

应用还提供命令行（Shell），使用户可以在运行期间启用或禁用混杂模式。命令名称是 `promisc on` 和 `promisc off`。

示例可[在 GitHub 查看官方源码](https://github.com/zephyrproject-rtos/zephyr/blob/main//samples/net/promiscuous_mode/README.rst/..)。

> 译注——源码跟踪：当前官方 [`src/main.c`](https://github.com/zephyrproject-rtos/zephyr/blob/main/samples/net/promiscuous_mode/src/main.c) 在启动时遍历接口并尝试启用混杂模式，驱动不支持等失败会记录到日志中；因此“每个接口”描述的是尝试范围。交互命令还要求接口索引，完整形式为 `promisc on <interface index>` 或 `promisc off <interface index>`。索引可先通过 `net iface` 查看，不能省略这个参数。

## 2. 前提条件（Requirements）

先完成[与主机系统联网](P007_与主机系统联网.md#networking-with-host)所述的网络准备。

## 3. 构建和运行（Building and Running）

此应用有多种使用方式。下面的原文示例使用 QEMU：

```sh
west build -b qemu_x86 samples/net/promiscuous_mode -- -DCONF_FILE=<config file to use>
```

> 译注——执行位置与配置：在准备好 Zephyr 构建环境的终端中，从 Zephyr 源码根目录执行。`<config file to use>` 是配置文件占位符；官方示例已有 [`samples/net/promiscuous_mode/prj.conf`](https://github.com/zephyrproject-rtos/zephyr/blob/main/samples/net/promiscuous_mode/prj.conf)，可用 `prj.conf` 替换占位符。主机与 QEMU 的连通准备按前面的联网文档执行；编译后还需启动 QEMU 目标。应用接收到数据包时输出其信息，没有输出时应先核对应用是否运行、接口是否支持并启用了混杂模式，以及是否有流量到达接口。
