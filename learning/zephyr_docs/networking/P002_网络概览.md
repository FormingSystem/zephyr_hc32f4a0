# 第2章\_网络概览

原文：[官方页面](https://docs.zephyrproject.org/latest/services/connectivity/networking/overview.html)。读取日期：2026-10-14；保存的 latest 页面及 HTML 摘要见[来源记录](../SOURCES.md)。

## 2.1\_支持的功能

IP 网络协议栈采用模块化设计，在构建时配置。只启用应用需要的功能，可以尽量减少内存占用；几乎所有功能都能禁用。

### 2.1.1\_IPv6

支持 IPv6（[RFC 8200](https://datatracker.ietf.org/doc/html/rfc8200.html)），以下子功能可在构建时配置：

- 同时活动的单播（Unicast）和组播（Multicast）地址数量。
- 静态地址或无状态地址自动配置（Stateless Address Autoconfiguration，SLAAC；[RFC 4862](https://datatracker.ietf.org/doc/html/rfc4862.html)）。
- 多个地址前缀（Prefix），最大数量可配置。
- 可选的邻居缓存（Neighbor Cache），大小可配置。
- 默认启用邻居发现（Neighbor Discovery；[RFC 4861](https://datatracker.ietf.org/doc/html/rfc4861.html)）和组播侦听者发现第2版（Multicast Listener Discovery v2；[RFC 3810](https://datatracker.ietf.org/doc/html/rfc3810.html)）。
- 面向 IEEE 802.15.4 网络的 6LoWPAN 报头压缩（Header Compression；[RFC 4944](https://datatracker.ietf.org/doc/html/rfc4944.html)）。
- DHCPv6（[RFC 8415](https://datatracker.ietf.org/doc/html/rfc8415.html)）客户端与服务器，包括前缀委派（Prefix Delegation）；详见 [DHCPv6](P031_DHCPv6.md#dhcpv6-interface)。
- 从路由器通告（Router Advertisement）获取 DNS 服务器地址，即递归 DNS 服务器选项（Recursive DNS Server，RDNSS；[RFC 8106](https://datatracker.ietf.org/doc/html/rfc8106.html)）。
- 隐私扩展（Privacy Extensions；[RFC 8981](https://datatracker.ietf.org/doc/html/rfc8981.html)）。
- 分片（Fragmentation）和路径最大传输单元发现（Path MTU Discovery；[RFC 8201](https://datatracker.ietf.org/doc/html/rfc8201.html)）。
- 组播路由与转发（Multicast Routing and Forwarding）。

### 2.1.2\_IPv4

支持 IPv4（[RFC 791](https://datatracker.ietf.org/doc/html/rfc791.html)），例如用于以太网、Wi-Fi 和蜂窝网络；IEEE 802.15.4 仅支持 IPv6。

- DHCPv4（[RFC 2131](https://datatracker.ietf.org/doc/html/rfc2131.html)）客户端与服务器，详见 [DHCPv4](P030_DHCPv4.md#dhcpv4-interface)。
- 默认启用静态地址。
- 链路本地地址自动配置（Link-local Address Autoconfiguration；[RFC 3927](https://datatracker.ietf.org/doc/html/rfc3927.html)）和地址冲突检测（Address Conflict Detection；[RFC 5227](https://datatracker.ietf.org/doc/html/rfc5227.html)）。示例：[IPv4自动配置客户端](P199_IPv4自动配置客户端示例.md#ipv4-autoconf)。
- 互联网组管理协议第2版与第3版（Internet Group Management Protocol，IGMPv2／IGMPv3），分别见 [RFC 2236](https://datatracker.ietf.org/doc/html/rfc2236.html)、[RFC 3376](https://datatracker.ietf.org/doc/html/rfc3376.html)。
- 分片和路径 MTU 发现，见 [RFC 1191](https://datatracker.ietf.org/doc/html/rfc1191.html)。
- 网络地址转换（Network Address Translation，NAT）：接口之间的源地址转换（SNAT）和目的地址转换（DNAT），配合连接跟踪（Connection Tracking）和类似 iptables 的规则，在子网之间过滤、转发分组。

### 2.1.3\_传输协议与套接字

- **双协议栈（Dual Stack）**：可同时使用 IPv6 和 IPv4。
- **用户数据报协议（User Datagram Protocol，UDP）**：支持 [RFC 768](https://datatracker.ietf.org/doc/html/rfc768.html)，可发送数据报及监听端口；支持 UDP 选项（[RFC 9868](https://datatracker.ietf.org/doc/html/rfc9868.html)）。为基于 UDP 的协议提供数据报分组化层路径 MTU 发现（Datagram Packetization Layer Path MTU Discovery，DPLPMTUD；[RFC 8899](https://datatracker.ietf.org/doc/html/rfc8899.html)），普通 UDP 套接字可通过 UDP 选项使用该能力（[RFC 9869](https://datatracker.ietf.org/doc/html/rfc9869.html)）；详见 [DPLPMTUD](P139_数据报分组层路径MTU发现.md#net-dplpmtud)。
- **传输控制协议（Transmission Control Protocol，TCP）**：支持 [RFC 9293](https://datatracker.ietf.org/doc/html/rfc9293.html) 的客户端和服务器，套接字数量可在构建时配置。[`CONFIG_NET_TCP_SACK`](https://docs.zephyrproject.org/latest/kconfig.html#CONFIG_NET_TCP_SACK) 启用已接收数据的选择性确认（Selective Acknowledgment；[RFC 2018](https://datatracker.ietf.org/doc/html/rfc2018.html)）。
- **QUIC**：支持 [RFC 9000](https://datatracker.ietf.org/doc/html/rfc9000.html)，集成 TLS 1.3（[RFC 9001](https://datatracker.ietf.org/doc/html/rfc9001.html)）；详见 [QUIC](P143_QUIC传输接口.md#quic-transport-interface)。示例：[QUIC回显客户端](P145_QUIC回显客户端.md#quic-client-echo)、[QUIC回显服务器](P146_QUIC回显服务端.md#quic-service-echo)。
- **BSD 套接字 API（BSD Sockets API）**：实现 [BSD套接字API](P040_BSD套接字.md#bsd-sockets-interface) 的一个子集，包括阻塞和非阻塞的数据报（UDP）、流（TCP）套接字，以及分组套接字 `AF_PACKET`。
- **安全套接字 API（Secure Sockets API）**：由 Mbed TLS 支持，为套接字提供 TLS 和 DTLS；详见 [安全套接字](P040_BSD套接字.md#secure-sockets-interface)。

### 2.1.4\_应用层协议

- **MQTT**：支持 ISO/IEC PRF 20922 的3.1.1版和5.0版。示例：[MQTT发布者](https://docs.zephyrproject.org/latest/samples/net/mqtt_publisher/README.html#mqtt-publisher)。
- **MQTT-SN**：支持1.2版。示例：[MQTT-SN发布者](https://docs.zephyrproject.org/latest/samples/net/mqtt_sn_publisher/README.html#mqtt-sn-publisher)。
- **受限应用协议（Constrained Application Protocol，CoAP）**：支持 [RFC 7252](https://datatracker.ietf.org/doc/html/rfc7252.html)、分块传输（Block-wise Transfer；[RFC 7959](https://datatracker.ietf.org/doc/html/rfc7959.html)）、资源观察（Resource Observation；[RFC 7641](https://datatracker.ietf.org/doc/html/rfc7641.html)）、受限REST环境对象安全（Object Security for Constrained RESTful Environments，OSCORE；[RFC 8613](https://datatracker.ietf.org/doc/html/rfc8613.html)），以及客户端侧通过 TCP 和 TLS 传输 CoAP（[RFC 8323](https://datatracker.ietf.org/doc/html/rfc8323.html)）。示例：[CoAP客户端](P068_CoAP客户端示例.md#coap-client)、[CoAP服务](P072_CoAP服务示例.md#coap-server)。
- **轻量级机器到机器协议（OMA Lightweight Machine-to-Machine，LwM2M）**：支持 [LwM2M规范1.0.2](https://www.openmobilealliance.org/release/LightweightM2M/V1_0_2-20180209-A/OMA-TS-LightweightM2M-V1_0_2-20180209-A.pdf)，并可通过 Kconfig 选择 [规范1.1.1](https://www.openmobilealliance.org/release/LightweightM2M/V1_1_1-20190617-A/)。包括引导（Bootstrap）、客户端注册（Client Registration）、设备管理与服务启用（Device Management & Service Enablement）、信息上报（Information Reporting）接口，必需核心对象及多个 IPSO 智能对象（IPSO Smart Objects）。示例：[LwM2M客户端](P074_LwM2M客户端示例.md#lwm2m-client)。
- **超文本传输协议（Hypertext Transfer Protocol，HTTP）**：[客户端](P049_HTTP客户端库.md#http-client-interface)支持 HTTP/1.1（[RFC 2616](https://datatracker.ietf.org/doc/html/rfc2616.html)）；[服务器](P055_HTTP服务器库.md#http-server-interface)支持 HTTP/1.1、HTTP/2（[RFC 9113](https://datatracker.ietf.org/doc/html/rfc9113.html)）、HTTP/3（[RFC 9114](https://datatracker.ietf.org/doc/html/rfc9114.html)）。示例：[HTTP客户端](P050_HTTP客户端示例.md#sockets-http-client)、[HTTP服务器](P056_HTTP服务器示例.md#sockets-http-server)。
- **WebSocket**：支持客户端（[RFC 6455](https://datatracker.ietf.org/doc/html/rfc6455.html)），以及 HTTP 服务器中的 WebSocket 升级。示例：[WebSocket客户端](P054_WebSocket客户端示例.md#sockets-websocket-client)。
- **域名系统（Domain Name System，DNS）**：支持 [RFC 1035](https://datatracker.ietf.org/doc/html/rfc1035.html) 的 IPv4 A记录和 IPv6 AAAA记录解析、多播 DNS（Multicast DNS，mDNS；[RFC 6762](https://datatracker.ietf.org/doc/html/rfc6762.html)）、DNS服务发现（DNS Service Discovery，DNS-SD；[RFC 6763](https://datatracker.ietf.org/doc/html/rfc6763.html)），以及已弃用的链路本地多播名称解析（Link-Local Multicast Name Resolution，LLMNR；[RFC 4795](https://datatracker.ietf.org/doc/html/rfc4795.html)）。mDNS响应器会回答查询并发布 DNS-SD 服务。示例：[mDNS响应器](P200_mDNS响应器示例.md#mdns-responder)。
- **简单网络时间协议（Simple Network Time Protocol，SNTP）**：支持 [RFC 5905](https://datatracker.ietf.org/doc/html/rfc5905.html) 的客户端与服务器；详见 [SNTP](P034_SNTP时间同步库.md#sntp-interface)。示例：[SNTP客户端](P038_SNTP客户端示例.md#sntp-client)、[SNTP服务器](P039_SNTP服务器示例.md#sntp-server)。
- **SOCKS5代理（Proxy）**：见 [RFC 1928](https://datatracker.ietf.org/doc/html/rfc1928.html)。
- **简单文件传输协议（Trivial File Transfer Protocol，TFTP）**：支持 [RFC 1350](https://datatracker.ietf.org/doc/html/rfc1350.html) 客户端。示例：[TFTP客户端](P078_TFTP客户端示例.md#tftp-client)。
- **文件传输协议（File Transfer Protocol，FTP）**：支持 [RFC 959](https://datatracker.ietf.org/doc/html/rfc959.html) 客户端，详见 [FTP客户端接口](P075_FTP客户端库.md#ftp-client-interface)；示例：[FTP客户端Shell示例](P076_FTP客户端示例.md#ftp-client)。
- **安全外壳（Secure Shell，SSH）**：支持 SSH-2 服务器和客户端（[RFC 4251](https://datatracker.ietf.org/doc/html/rfc4251.html) 至 [RFC 4254](https://datatracker.ietf.org/doc/html/rfc4254.html)）。会话通道承载 shell、exec 及子系统请求，可经 SSH 使用 Zephyr Shell。示例：[SSH服务器和客户端](P221_SSH服务端与客户端示例.md#ssh-server-client)。
- **WireGuard虚拟专用网络（Virtual Private Network，VPN）**：采用 [WireGuard协议](https://www.wireguard.com/)。示例：[WireGuard VPN](P211_WireGuard虚拟专用网示例.md#wireguard-vpn)。
- **实时传输协议（Real-time Transport Protocol，RTP）**：见 [RFC 3550](https://datatracker.ietf.org/doc/html/rfc3550.html)。示例：[RTP](P142_RTP发送示例.md#net-rtp)。
- **MIDI2**：MIDI 2.0 的 UDP 网络传输。示例：[MIDI2网络传输](P219_MIDI2网络传输示例.md#netmidi2)。
- **开放充电桩协议（Open Charge Point Protocol，OCPP）**：示例为 [OCPP充电桩](P182_OCPP充电桩示例.md#ocpp)。
- **Prometheus指标服务器（Metrics Server）**：示例为 [Prometheus示例](P220_Prometheus指标示例.md#prometheus)。
- **模型上下文协议（Model Context Protocol，MCP）服务器**：通过 HTTP 暴露设备工具，供 AI 智能体发现和调用。详见 [MCP服务器](P178_MCP服务器.md#mcp-server-interface)；示例：[MCP服务器Hello World](P181_MCP服务器入门示例.md#mcp-server-hello-world)。

### 2.1.5\_管理、流量处理与诊断

- 网络管理 API（Network Management API）接收协议栈事件，例如添加 IP 地址或接口启用。
- Wi-Fi 管理 API（Wi-Fi Management API）管理接口，例如扫描和连接网络。
- Wi-Fi 网络管理器 API（Wi-Fi Network Manager API）供向 Wi-Fi 协议栈注册、并实现 Wi-Fi 管理 API 的网络管理器使用。
- 可在 Kconfig 中同时启用以太网、Wi-Fi、IEEE 802.15.4 等多种网络技术。它们之间不自动路由；应用选择通过哪个接口发送。
- 尽量减少复制的缓冲区管理（Minimal Copy Buffer Management）：原文说明协议栈在发送路径上避免复制应用数据。
- 虚拟局域网（Virtual LAN，VLAN）将物理以太网划分成逻辑网络，详见 [VLAN](P110_VLAN虚拟局域网.md#vlan-interface)。
- 流量分类（Traffic Classification）为收发分组设置优先级，详见 [流量分类](P119_流量分类.md#traffic-class-support)。
- 时间敏感网络（Time Sensitive Networking，TSN），配合通用精确时间协议（generalized Precision Time Protocol，gPTP）和精确时间协议（Precision Time Protocol，PTP；IEEE 1588）。详见 [gPTP](P117_gPTP通用精确时间协议.md#gptp-interface) 与 [PTP](P128_PTP精确时间协议.md#ptp-interface)。
- 分组过滤与捕获（Packet Filtering and Capture）：按规则过滤收发分组，并将流量捕获到远端主机分析，详见 [分组过滤](P028_网络分组过滤.md#net-pkt-filter-interface)、[网络分组捕获](P029_网络分组捕获.md#net-capture-interface)。
- 网络 Shell（Network Shell）：检查网络状态、启停功能，执行 ping 或 DNS 查询等命令，详见 [网络Shell](P092_网络Shell.md#net-shell)。
- zperf 网络性能与带宽测量工具，支持客户端和服务器，兼容 iPerf v2 与 iperf3。示例：[zperf网络流量生成器](P097_zperf网络流量生成器示例.md#zperf)。

> 译注：支持某项网络功能不表示当前板级配置已启用它，也不构成 HC32 外设或网络性能实测结论。“尽量减少复制”应结合具体 API 和数据路径理解，架构页仍描述套接字数据复制至内部缓冲区的步骤。

## 2.2\_支持的链路层技术

- IEEE 802.15.4。
- 以太网（Ethernet），IEEE 802.3。
- Wi-Fi，IEEE 802.11。
- 蜂窝网络／点对点协议（Cellular / Point-to-Point Protocol，PPP；[RFC 1661](https://datatracker.ietf.org/doc/html/rfc1661.html)）。
- Thread；示例见 [OpenThread](P172_OpenThread示例目录.md#openthread)。
- 供 SocketCAN 使用的 CAN 总线。
- 串行线路IP（Serial Line IP，SLIP）：将 QEMU 目标连接到主机并表现为以太网接口，让主机应用与 Zephyr 交换数据。

## 2.3\_源码目录布局

网络协议栈源码按以下方式组织：

| 官方源码目录 | 内容 |
| --- | --- |
| [`subsys/net/`](https://github.com/zephyrproject-rtos/zephyr/blob/main/subsys/net/) | 连接管理器、分组过滤代码、主机名处理等可选协议栈组件。 |
| [`subsys/net/ip/`](https://github.com/zephyrproject-rtos/zephyr/blob/main/subsys/net/ip/) | 核心网络协议栈实现。 |
| [`subsys/net/l2/`](https://github.com/zephyrproject-rtos/zephyr/blob/main/subsys/net/l2) | IP协议栈第二层代码，包括以太网、IEEE 802.15.4和Wi-Fi的通用支持。 |
| [`subsys/net/lib/`](https://github.com/zephyrproject-rtos/zephyr/blob/main/subsys/net/lib/) | DNS、MQTT等应用层协议，以及BSD套接字等附加组件。 |
| [`include/zephyr/net/`](https://github.com/zephyrproject-rtos/zephyr/blob/main/include/zephyr/net/) | 公共API头文件，应用需要包含这些头文件才能使用IP网络功能。 |
| [`samples/net/`](https://github.com/zephyrproject-rtos/zephyr/blob/main/samples/net/) | 网络示例代码，适合作为网络应用开发的起点。 |
| [`tests/net/`](https://github.com/zephyrproject-rtos/zephyr/blob/main/tests/net/) | 验证IP协议栈功能的测试应用；若需要示例代码，优先参考 `samples/net/`，测试不是最佳示例来源。 |

译注：本仓库的[网络实现](../../../subsys/net)、[网络头文件](../../../include/zephyr/net)和[网络示例](../../../samples/net)可用于源码跟踪，均采用相对路径；仓库版本不自动等同于本轮官方 latest。
