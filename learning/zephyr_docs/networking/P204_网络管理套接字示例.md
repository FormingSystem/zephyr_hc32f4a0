# 第204章\_网络管理套接字示例

原文：[官方页面](https://docs.zephyrproject.org/latest/samples/net/sockets/net_mgmt/README.html)。读取日期：2026-10-14；保存的latest页面及HTML摘要见[来源记录](../SOURCES.md)。

<a id="overview"></a>

## 204.1 概述（Overview）

Zephyr的`net-mgmt-socket`示例实现一个监听器（Listener），接收网络子系统发出的网络管理事件（Network management event）。源码位于[samples/net/sockets/net_mgmt](https://github.com/zephyrproject-rtos/zephyr/blob/main/samples/net/sockets/net_mgmt)。

<a id="requirements"></a>

## 204.2 要求（Requirements）

完成[与主机系统联网（Networking with the host system）](P007_与主机系统联网.md#networking-with-host)所述准备。

<a id="building-and-running"></a>

## 204.3 构建与运行（Building and Running）

此应用有多种使用方式。原文提到，一种常见使用场景是在QEMU中运行回显服务器（Echo server），详见[与QEMU联网（Networking with QEMU）](P009_QEMU联网概览.md#networking-with-qemu)。

网络管理套接字示例的构建命令为：

```sh
west build -b <board to use> samples/net/sockets/net_mgmt -- -DCONF_FILE=<config file to use>
```

以`native_sim`为例，构建并运行：

```sh
west build -b native_sim samples/net/sockets/net_mgmt -- -DCONF_FILE=prj.conf
west build -t run
```

> 译注——实际示例行为：上文提及Echo server作为网络环境使用场景，本页构建的应用本身是网络管理事件监听器。当前源码创建`AF_NET_MGMT`数据报套接字，监听IPv6地址增加、删除和重复地址检测成功（Duplicate address detection，DAD）事件；辅助线程轮流增删`2001:db8::3`以产生可观察事件。不要将它误当成TCP／UDP回显服务。
