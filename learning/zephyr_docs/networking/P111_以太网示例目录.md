## 1. 以太网网络示例（Network Ethernet）

这些示例面向支持以太网的开发板，演示不同的以太网应用场景。

| 官方示例 | 说明 |
| --- | --- |
| [10BASE-T1S 测试（OA_TC6）](P125_10BASE-T1S测试示例.md#t1s) | 设置测试，以检查 10BASE-T1S 通信的长期稳定性。 |
| [以太网桥（bridge）](P113_以太网桥示例.md#bridge) | 测试和调试以太网桥。 |
| [分布式交换机架构（Distributed Switch Architecture，DSA）](P123_DSA分布式交换机示例.md#dsa) | 测试和调试分布式交换机架构。 |
| [通用精确时间协议（gPTP）](P121_gPTP示例.md#gptp) | 启用 gPTP 支持，并通过网络命令行（net-shell）监测功能。 |
| [链路层发现协议（LLDP）](P120_LLDP示例.md#lldp) | 启用 LLDP 支持，并设置 VLAN。 |
| [时间敏感网络交换机（TSN Switch）](P124_TSN交换机示例.md#tsn-switch) | 测试和调试 TSN 交换机。 |
| [虚拟局域网（Virtual LAN）](P112_VLAN示例.md#vlan) | 设置两个虚拟局域网，并使用 net-shell 查看网络设置。 |
