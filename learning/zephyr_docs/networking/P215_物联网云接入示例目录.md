# 第215章\_物联网云接入示例目录

原文：[官方页面](https://docs.zephyrproject.org/latest/samples/net/cloud/README.html)。读取日期：2026-10-14；保存的latest页面及HTML摘要见[来源记录](../SOURCES.md)。

这些示例演示如何将Zephyr设备连接到不同的物联网云服务（IoT Cloud services）。

- [AWS物联网MQTT（AWS IoT Core MQTT）](P216_AWS物联网MQTT示例.md#aws-iot-mqtt)：连接AWS IoT Core并通过MQTT发布消息。

- [Azure物联网MQTT（Microsoft Azure IoT Hub MQTT）](P217_Azure物联网MQTT示例.md#mqtt-azure)：连接Azure IoT Hub并通过MQTT发布消息。

- [TagoIO的HTTP上报（TagoIO HTTP Post）](P218_TagoIO的HTTP上报示例.md#tagoio-http-post)：通过HTTP向TagoIO物联网云平台发送随机温度值。



对应官方文档源码：[samples/net/cloud/README.rst](https://raw.githubusercontent.com/zephyrproject-rtos/zephyr/main/samples/net/cloud/README.rst)。
