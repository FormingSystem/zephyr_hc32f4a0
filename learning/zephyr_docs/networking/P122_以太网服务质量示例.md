# 第122章\_以太网服务质量示例

原文：[官方页面](https://docs.zephyrproject.org/latest/samples/net/qos/ethernet/README.html)。读取日期：2026-10-14；保存的 latest 页面及 HTML 摘要见[来源记录](../SOURCES.md)。

## 1. 概述（Overview）

本示例演示以太网层的服务质量（Quality of Service，QoS）。可[在 GitHub 查看官方源码](https://github.com/zephyrproject-rtos/zephyr/blob/main//samples/net/qos/ethernet/README.rst/..)。

## 2. 构建和运行（Building and Running）

构建命令如下：

```sh
west build -b <board_to_use> samples/net/qos/ethernet
```

本示例仅适用于原生模拟器（Native Simulator）。启动后，它在模拟的网络接口上生成模拟接收数据包，并打印相关统计。

在具备 Linux 原生模拟器构建环境的终端中，从 Zephyr 源码根目录执行下面的具体命令，即可构建并运行：

```sh
west build -b native_sim samples/net/qos/ethernet
west build -t run
```

> 译注——统计范围：下面保留的是官方页面的示例统计，不是实体以太网端口的吞吐量或本次测试结果。当前官方 [`src/main.c`](https://github.com/zephyrproject-rtos/zephyr/blob/main/samples/net/qos/ethernet/src/main.c) 注入接收包，改变模拟处理工作量，分别在加入优先级过滤规则之前和之后统计命令与回显服务的处理计数。表中 `100` 是计数值，不能未经换算直接解释为 `100%`。程序实际输出会包含测试过程中的统计。
