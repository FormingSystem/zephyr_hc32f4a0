# 第205章\_套接字对示例

原文：[官方页面](https://docs.zephyrproject.org/latest/samples/net/sockets/socketpair/README.html)。读取日期：2026-10-14；保存的latest页面及HTML摘要见[来源记录](../SOURCES.md)。

<a id="overview"></a>

## 205.1 概述（Overview）

Zephyr的`sockets/socketpair`示例演示多线程应用如何通过成对的、无名且已连接的UNIX域套接字（UNIX-domain socket）通信。顾名思义，套接字对由`socketpair(2)`创建。这些套接字兼容BSD套接字API，因此本示例也进一步说明：可以开发同时移植到POSIX和Zephyr的套接字应用。

源码位于[samples/net/sockets/socketpair](https://github.com/zephyrproject-rtos/zephyr/blob/main/samples/net/sockets/socketpair)。

## 205.2 要求（Requirements）

无特殊要求。

<a id="building-and-running"></a>

## 205.3 构建与运行（Building and Running）

按下列方式构建Zephyr版本。原文在此将应用称为`sockets/echo`，但命令使用的是本页的`sockets/socketpair`：

```sh
west build -b <board_to_use> samples/net/sockets/socketpair
```

示例启动后创建多个客户端线程，每个线程向服务器（主线程，`main`）发送固定数量的消息。

```text
*** Booting Zephyr OS build v3.3.0-rc1-97-g432ff20a72e1 ***
setting-up
Alpha: socketpair: 4 <=> 3
Bravo: socketpair: 6 <=> 5
Charlie: socketpair: 8 <=> 7
main: read 'Alpha' on fd 4
main: read 'Bravo' on fd 6
main: read 'Charlie' on fd 8
main: read 'Alpha' on fd 4
main: read 'Bravo' on fd 6
main: read 'Charlie' on fd 8
main: read 'Alpha' on fd 4
main: read 'Bravo' on fd 6
main: read 'Charlie' on fd 8
tearing-down
SUCCESS
```

<a id="running-application-on-posix-host"></a>

### 205.3.1 在POSIX主机上运行（Running application on POSIX Host）

同一份应用源码可以在Linux等POSIX系统上构建。构建命令：

```console
$ make -f Makefile.host
```

运行命令及输出：

```text
./socketpair_example
setting-up
Alpha: socketpair: 3 <=> 4
Bravo: socketpair: 5 <=> 6
Charlie: socketpair: 7 <=> 8
main: read 'Alpha' on fd 3
main: read 'Bravo' on fd 5
main: read 'Charlie' on fd 7
main: read 'Alpha' on fd 3
main: read 'Alpha' on fd 3
main: read 'Bravo' on fd 5
main: read 'Charlie' on fd 7
main: read 'Bravo' on fd 5
main: read 'Charlie' on fd 7
tearing-down
SUCCESS
```

可以看到，应用行为与Zephyr版本大致相同。

> 译注——执行目录与并发输出：POSIX命令在[`samples/net/sockets/socketpair`](https://github.com/zephyrproject-rtos/zephyr/blob/main/samples/net/sockets/socketpair)目录中执行，`Makefile.host`使用主机C编译器并链接`pthread`。当前示例创建三对套接字，Alpha、Bravo、Charlie线程各发送三次消息并校验回显。文件描述符（File descriptor，fd）编号和多线程交错顺序可以不同；应关注消息与成功结束条件，不要求输出逐行顺序与示例完全一致。
