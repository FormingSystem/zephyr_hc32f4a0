# 第116章\_LLDP链路层发现协议

原文：[官方页面](https://docs.zephyrproject.org/latest/services/connectivity/networking/api/lldp.html)。读取日期：2026-10-14；保存的 latest 页面及 HTML 摘要见[来源记录](../SOURCES.md)。

## 1. 概述（Overview）

链路层发现协议（Link Layer Discovery Protocol，LLDP）是一种与厂商无关的链路层协议。网络设备用它在有线以太网中通告自身的标识、能力以及邻居信息。

进一步介绍见原文链接的[LLDP 百科条目](https://en.wikipedia.org/wiki/Link_Layer_Discovery_Protocol)。
