# 第214章\_蜂窝调制解调器示例

原文：[官方页面](https://docs.zephyrproject.org/latest/samples/net/cellular_modem/README.html)。读取日期：2026-10-14；保存的latest页面及HTML摘要见[来源记录](../SOURCES.md)。

<a id="overview"></a>

## 214.1 概述（Overview）

本示例包含一个简单应用：给蜂窝调制解调器（Cellular modem）上电，启用网络接口，然后将包含伪随机数据（Pseudo-random data）的数据包发送到`test-endpoint.com`。原文将其描述为运行`server`目录中Python脚本的公开服务器，应用通过DNS查询其IP地址。

<a id="notes"></a>

## 214.2 说明（Notes）

本示例使用设备树（Devicetree）别名`modem`确定使用哪个调制解调器实例，并假设调制解调器驱动创建了系统中唯一的点对点协议（Point-to-Point Protocol，PPP）网络接口。

<a id="setup"></a>

## 214.3 设置（Setup）

首先在设备树中加入所需节点：

```dts
/dts-v1/;

/ {
        aliases {
                modem = &modem;
        };
};

&usart2 {
        pinctrl-0 = <&usart2_tx_pa2 &usart2_rx_pa3 &usart2_rts_pa1 &usart2_cts_pa0>;
        pinctrl-names = "default";
        current-speed = <115200>;
        hw-flow-control;
        status = "okay";

        modem: modem {
                compatible = "quectel,bg9x";
                mdm-power-gpios = <&gpioe 2 GPIO_ACTIVE_HIGH>;
                mdm-reset-gpios = <&gpioe 3 GPIO_ACTIVE_HIGH>;
                status = "okay";
        };
};
```

接着，通过`CONFIG_UART_INTERRUPT_DRIVEN=y`或`CONFIG_UART_ASYNC_API=y`指定UART API；驱动不支持UART轮询（Polling）。最后，使用`CONFIG_MODEM_CELLULAR_APN=""`配置接入点名称（Access Point Name，APN）。

> 译注——硬件与配置边界：原设备树以`usart2`、指定引脚与Quectel BG9x为例，不能直接视为本仓库目标芯片的接线方案。应按照实际开发板和调制解调器选择节点、引脚、流控与电源／复位信号。空APN字符串是原文配置写法，实际值取决于使用的网络；当前示例还提供基于SIM IMSI的可选APN配置，但这不改变原文所列的手动配置步骤。

<a id="shell-commands"></a>

## 214.4 Shell命令（Shell commands）

示例启用[`CONFIG_MODEM_CELLULAR_SHELL`](https://docs.zephyrproject.org/latest/kconfig.html#CONFIG_MODEM_CELLULAR_SHELL)，加入`modem_cellular`命令，用于在运行时控制`cellular_modem`驱动的周期性命令应答脚本（Periodic chat script）：

```sh
modem_cellular pause <device>
modem_cellular resume <device>
```

在命令通道上执行耗时较长的AT操作，例如固件升级、eSIM配置或出厂测试时，可使用`modem_cellular pause`暂停周期性的CSQ／CREG查询。`modem_cellular resume`重新启用查询；如果暂停期间跳过了计划执行的一次任务，恢复后会立即触发下一次周期执行。已暂停时再次暂停，或尚未暂停时请求恢复，都会返回`-EINVAL`。

<a id="server-setup"></a>

## 214.5 服务器设置（Server setup）

将服务器部署到可以公开访问的主机，再把`prj.conf`中的`CONFIG_SAMPLE_CELLULAR_MODEM_ENDPOINT_HOSTNAME`设为该服务器的主机名：

```sh
git clone --depth=1 https://github.com/zephyrproject-rtos/zephyr.git
cd zephyr/samples/net/cellular_modem/server
python te.py
```

> 译注——已有源码与执行位置：以上浅克隆命令保留自官方步骤；已有对应Zephyr源码时，可直接进入该源码的`samples/net/cellular_modem/server`目录，不需要嵌套克隆。`te.py`启动UDP回显与接收服务，设备侧仍须正确解析配置的主机名并连接相应服务。这里没有部署服务器、联系示例公网端点、操作SIM或执行AT升级，原文对公共服务的描述不代表本次验证了其在线状态。
