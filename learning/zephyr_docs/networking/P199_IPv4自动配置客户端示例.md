# 第199章\_IPv4自动配置客户端示例

原文：[官方页面](https://docs.zephyrproject.org/latest/samples/net/ipv4_autoconf/README.html)。读取日期：2026-10-14；保存的latest页面及HTML摘要见[来源记录](../SOURCES.md)。

<a id="overview"></a>

## 199.1 概述（Overview）

此应用启动IPv4自动配置（IPv4 autoconf），从`169.254.0.0/16`范围中随机选择并为自身分配一个IPv4地址。它会维护该地址的使用权；如果多个参与者试图分配同一地址，则处理IPv4地址冲突。

<a id="requirements"></a>

## 199.2 要求（Requirements）

先完成[与主机系统联网（Networking with the host system）](P007_与主机系统联网.md#networking-with-host)所述准备。

<a id="building-and-running"></a>

## 199.3 构建与运行（Building and Running）

以下说明介绍如何在[FRDM-K64F](https://docs.zephyrproject.org/latest/boards/nxp/frdm_k64f/doc/index.html#frdm_k64f)开发板上运行此示例，配置IPv4链路本地地址（Link-local address），并连接Linux主机。用以太网线连接[Freedom-K64F开发板](https://docs.zephyrproject.org/latest/boards/nxp/frdm_k64f/doc/index.html#frdm_k64f)与Linux主机，然后检查主机上出现的网络接口。

<a id="running-avahi-client-in-linux-host"></a>

### 199.3.1 在Linux主机运行Avahi客户端（Running Avahi client in Linux Host）

为Linux系统中的接口分配IPv4链路本地地址：

```console
$ avahi-autoipd --force-bind -D eth0
```

<a id="frdm-k64f"></a>

### 199.3.2 FRDM\_K64F开发板（FRDM\_K64F）

按以下步骤构建并烧录Zephyr的`samples/net/ipv4_autoconf`应用：

```sh
west build -b frdm_k64f samples/net/ipv4_autoconf
west flash
```

IPv4链路本地配置（IPv4 LL）完成探测（Probing）与通告（Announcement）后，可通过串口查看详细信息：

```console
$ sudo screen /dev/ttyACM0 115200
```

```text
[ipv4ll] [INF] main: Run ipv4 autoconf client
[ipv4ll] [INF] handler: Your address: 169.254.218.128
```

注意，每次自动分配时IP地址都可能变化。要检查Zephyr应用是否已运行并配置IP地址，可输入：

```console
$ ping -I eth1 169.254.218.128
```

> 译注——接口与地址：原文在Avahi命令中使用`eth0`，而在`ping -I`中使用`eth1`。两者应按实际连接开发板的Linux接口统一，不能将示例中的不同名称直接当作同一接口。`169.254.218.128`也是原日志中的随机地址；应读取本次串口输出后再探测。`/dev/ttyACM0`是原示例串口设备节点，不是仓库绝对路径。
