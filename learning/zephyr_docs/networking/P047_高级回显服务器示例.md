# 第47章\_高级回显服务器示例

原文：[官方页面](https://docs.zephyrproject.org/latest/samples/net/sockets/echo_server/README.html)。读取日期：2026-10-14；保存的 latest 页面及 HTML 摘要见[来源记录](../SOURCES.md)。

## 47.1 概览（Overview）

Zephyr 的 `echo-server` 示例实现 UDP/TCP 回显服务器（Echo Server），与回显客户端（Echo Client）配套。服务器监听客户端发来的 IPv4 或 IPv6 分组，再把它们原样发回。UDP 是用户数据报协议（User Datagram Protocol），TCP 是传输控制协议（Transmission Control Protocol）。

源码位于[samples/net/sockets/echo_server](https://github.com/zephyrproject-rtos/zephyr/blob/main/samples/net/sockets/echo_server)，也可[在 GitHub 浏览官方源码](https://github.com/zephyrproject-rtos/zephyr/blob/main//samples/net/sockets/echo_server/README.rst/..)。

## 47.2 前置要求与配置（Requirements and Configuration）

先准备[与主机系统联网](P007_与主机系统联网.md#networking-with-host)的环境。运行方式有多种，常见方式是在 QEMU 模拟器中运行，见[QEMU 联网](P009_QEMU联网概览.md#networking-with-qemu)。

示例目录包含适用于不同开发板和设置的配置文件：

| 文件 | 作用 |
| --- | --- |
| `prj.conf` | 通用配置，通常应使用这个文件 |
| `overlay-ot.conf` | 启用 OpenThread 支持，即 Thread 协议的开源实现 |
| `overlay-802154.conf` | 启用原生 IEEE 802.15.4 联网。默认 IEEE 802.15.4 第二层（L2）通信不使用确认；可通过 Shell 命令 `ieee802154 ack set` 启用确认（Acknowledgment），提高连接可靠性 |
| `overlay-qemu_802154.conf` | 支持两个相互连接的 QEMU 实例模拟 IEEE 802.15.4 网络 |
| `overlay-tls.conf` | 启用传输层安全（Transport Layer Security，TLS） |
| `overlay-tunnel.conf` | 启用 IP 隧道（IP Tunneling） |
| `overlay-vlan.conf` | 启用虚拟局域网（Virtual Local Area Network，VLAN），详见[网络示例通用说明](P198_网络示例通用配置.md#networking-samples-common) |

## 47.3 构建与运行（Building and Running）

构建命令的通用形式为：

```shell
west build -b <board to use> samples/net/sockets/echo_server -- -DCONF_FILE=<config file to use>
```

> 译注：`<board to use>` 和 `<config file to use>` 是原文占位符，必须分别替换为开发板目标和配置文件；不能把尖括号内容直接交给 Shell。所有示例源码路径均相对于 Zephyr 源码根目录。

为 `nrf52840dk/nrf52840` 构建带 OpenThread 支持的版本：

```shell
west build -b nrf52840dk/nrf52840 samples/net/sockets/echo_server -- -DCONF_FILE="prj.conf overlay-ot.conf"
west build -t run
```

> 译注：原文在物理开发板示例后写了 `west build -t run`。`run` 是构建系统的运行目标，并不等于烧录命令。官方 [`board.cmake`](https://github.com/zephyrproject-rtos/zephyr/blob/main/boards/nordic/nrf52840dk/board.cmake) 配置了该板的烧录／调试执行器（Runner）；使用实板时应按板卡说明完成 `west flash` 等相应步骤。本轮未验证原文 `run` 在该目标上可用。

为使用 RF2XX 驱动的 `samr21_xpro` 等开发板构建：

```shell
west build -b [samr21_xpro | sam4e_xpro | sam_v71_xult/samv71q21] samples/net/sockets/echo_server -- -DEXTRA_CONF_FILE=overlay-802154.conf
west flash
```

> 译注：方括号和竖线表示三个开发板名称中任选一个，不是可直接执行的 Shell 参数。这里完整保留了原文列出的 `samr21_xpro`、`sam4e_xpro` 与 `sam_v71_xult/samv71q21`。

在终端中观察通信情况：

```shell
$ minicom -D /dev/ttyACM0
```

`/dev/ttyACM0` 是官方 Linux 示例中的串口设备节点（Device Node），不是仓库安装位置，应根据实际枚举结果选择；`$` 是提示符。

### 启用 TLS（Enabling TLS Support）

构建时加入 `overlay-tls.conf`，例如：

```shell
west build -b qemu_x86 samples/net/sockets/echo_server -- -DCONF_FILE="prj.conf overlay-tls.conf"
```

也可在运行 `west build` 或 `cmake` 时指定 `-DEXTRA_CONF_FILE=overlay-tls.conf`。

示例证书位于 `src` 目录。回显服务器与[高级回显客户端](P048_高级回显客户端示例.md#sockets-echo-client)的默认证书可以用于建立两个示例之间的安全连接。

### Wi-Fi

通过[Wi-Fi 配置片段（Snippet）](../snippets/P027_WiFi_IPv4配置片段.md#snippet-wifi-ipv4)启用 IPv4 Wi-Fi 支持。

## 47.4 在 Linux 主机运行客户端（Running echo-client in Linux Host）

一种实用测试布局是在 QEMU 中运行服务器，在 Linux 主机中运行客户端。先按[QEMU 联网](P009_QEMU联网概览.md#networking-with-qemu)准备环境，然后在 QEMU 中启动服务器：

```shell
west build -b qemu_x86 samples/net/sockets/echo_server
west build -t run
```

在主机终端运行客户端：

```shell
$ sudo ./echo-client -i tap0 2001:db8::1
```

必须先在 QEMU 中启动服务器，再启动主机客户端。这里 `./echo-client` 是官方[net-tools](https://github.com/zephyrproject-rtos/net-tools) 提供的主机工具，应在准备好该工具的目录中执行；`tap0` 是该联网方案使用的虚拟网络接口（TAP Interface）。

也可以与 Linux 主机验证 TLS 通信，方法见[net-tools 官方说明](https://github.com/zephyrproject-rtos/net-tools)。另一种布局是在 Linux 主机运行服务器、QEMU 中运行客户端，见[高级回显客户端](P048_高级回显客户端示例.md#sockets-echo-client)。

> 译注：这些开发板和主机联网步骤都来自官方示例，不是本仓库额外增加的芯片教程。本轮未构建、烧录、配置主机网络或测试回显／TLS 通信。
