# 第131章\_网络超时

原文：[官方页面](https://docs.zephyrproject.org/latest/services/connectivity/networking/api/net_timeout.html)。读取日期：2026-10-14；保存的 latest 页面及 HTML 摘要见[来源记录](../SOURCES.md)。

## 1. 概述（Overview）

Zephyr 的网络基础设施大多用毫秒分辨率的系统运行时间（Uptime）跟踪超时。截止时刻（Deadline）与持续时长（Duration）都用 32 位无符号值表示；该值会在 49 天 17 小时 2 分 47.296 秒时回绕（Rollover）。

超时处理常受延迟影响，检查超时的实际时间可能晚于应到期的时间。要正确处理这种情况，而不随意假定最大延迟，可直接表示的最大延迟必须限制为 31 位非负值，即 `INT32_MAX`。原文描述的相应溢出边界为 24 天 20 小时 31 分 23.648 秒。

大部分网络超时短于这一延迟回绕周期，但少数协议用以秒为单位的 32 位无符号数表示延迟，换算成毫秒需要 42 位计数。

[`net_timeout`](../time_headers_reference/P011_网络超时结构.md) API 提供通用的超时机制，以便正确跟踪这些超长超时的剩余时间。

> 译注——数值边界：原文的 23.648 秒对应 `2^31` 毫秒边界；`INT32_MAX` 本身为 `2^31 - 1`，因此最大可表示延迟实际比该边界小 1 ms，即 24 天 20 小时 31 分 23.647 秒。官方 [`net_timeout.h`](https://github.com/zephyrproject-rtos/zephyr/blob/main/include/zephyr/net/net_timeout.h) 把 `NET_TIMEOUT_MAX_VALUE` 定义为转换成无符号类型的 `INT32_MAX`。

## 2. 使用方法（Use）

最简单的用法如下：

1. 使用 [`net_timeout_set()`](../time_headers_reference/P008_网络超时接口.md#ga833e08b83a671d4adff799d648a12417) 配置网络超时。
2. 用 [`net_timeout_evaluate()`](../time_headers_reference/P008_网络超时接口.md#ga07b07966dd10929f6d3774467614f006) 判断距超时还有多久，并在返回的延迟之后安排一次超时回调。
3. 回调执行时，再次调用 [`net_timeout_evaluate()`](../time_headers_reference/P008_网络超时接口.md#ga07b07966dd10929f6d3774467614f006)，确定整个超时是否已经结束，或是否仍有剩余时间。若仍未结束，重新安排回调。
4. 超时运行期间，可用 [`net_timeout_remaining()`](../time_headers_reference/P008_网络超时接口.md#ga34e39484b19c39b3e37a4799848ad502) 取得距到期还有多少秒。若需要据此显式更新超时，应先取消已安排的回调，再以新的超时时长从第 1 步重新开始。

[`net_timeout`](../time_headers_reference/P011_网络超时结构.md) 中包含一个 `sys_snode_t` 节点，可将多个超时实例组织起来，共用一个内核定时元素。应用必须对所有实例调用 [`net_timeout_evaluate()`](../time_headers_reference/P008_网络超时接口.md#ga07b07966dd10929f6d3774467614f006)，找出下一次应该发生的超时事件。

[`net_timeout_deadline()`](../time_headers_reference/P008_网络超时接口.md#ga3d9804474050d070fc4224e834f8cefc) 可以重建完整精度的到期时间。它主要用于测试，但也可供某些应用以毫秒分辨率计算剩余时间。

> 译注——单位和调用约束：官方 [头文件](https://github.com/zephyrproject-rtos/zephyr/blob/main/include/zephyr/net/net_timeout.h) 与 [实现](https://github.com/zephyrproject-rtos/zephyr/blob/main/subsys/net/ip/net_timeout.c) 中，[`net_timeout_set()`](../time_headers_reference/P008_网络超时接口.md#ga833e08b83a671d4adff799d648a12417) 的 `lifetime` 单位为秒，`now` 和 [`net_timeout_evaluate()`](../time_headers_reference/P008_网络超时接口.md#ga07b07966dd10929f6d3774467614f006) 的非零返回值单位为毫秒。[`net_timeout_remaining()`](../time_headers_reference/P008_网络超时接口.md#ga34e39484b19c39b3e37a4799848ad502) 向下取整到整秒，因此不足 1 秒时可能返回 `0`；用 [`net_timeout_evaluate()`](../time_headers_reference/P008_网络超时接口.md#ga07b07966dd10929f6d3774467614f006) 判断实际到期。长超时要求按规定间隔持续评估状态，不能设定一次后任意长时间不处理，再期待自动恢复所有回绕信息。
