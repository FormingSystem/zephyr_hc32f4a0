# 第107章\_以太网管理

原文：[官方页面](https://docs.zephyrproject.org/latest/services/connectivity/networking/api/ethernet_mgmt.html)。读取日期：2026-10-14；保存的 latest 页面及 HTML 摘要见[来源记录](../SOURCES.md)。

## 1. 概述（Overview）

以太网管理 API（Ethernet Management API）提供管理以太网网络接口底层状态的函数。调用方可以：

- 触发载波接通（`carrier ON`）或载波断开（`carrier OFF`）管理事件。
- 触发 VLAN 启用（`VLAN enabled`）或 VLAN 禁用（`VLAN disabled`）管理事件。

通常，以太网设备驱动发现网线断开时，会产生载波断开事件；发现网线重新连接时，会产生载波接通事件。

目前，当某个 VLAN 标签（VLAN Tag）启用或禁用时，相应事件由以太网链路层（Ethernet L2 Layer）产生。

如果用户应用需要响应这些状态变化，就可以监听对应的管理事件。
