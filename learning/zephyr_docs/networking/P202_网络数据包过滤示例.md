# 第202章\_网络数据包过滤示例

原文：[官方页面](https://docs.zephyrproject.org/latest/samples/net/pkt_filter/README.html)。读取日期：2026-10-14；保存的latest页面及HTML摘要见[来源记录](../SOURCES.md)。

<a id="overview"></a>

## 202.1 概述（Overview）

本示例演示如何从用户应用中设置网络数据包过滤器（Network packet filter）。源码位于[samples/net/pkt_filter](https://github.com/zephyrproject-rtos/zephyr/blob/main/samples/net/pkt_filter)。

<a id="requirements"></a>

## 202.2 要求（Requirements）

完成[与主机系统联网（Networking with the host system）](P007_与主机系统联网.md#networking-with-host)所述准备。

<a id="building-and-running"></a>

## 202.3 构建与运行（Building and Running）

一种适合此示例的运行方式，是按照[与主机系统联网](P007_与主机系统联网.md#networking-with-host)说明使用QEMU或`native_sim`。

为了演示，需要在主机启用虚拟局域网（VLAN）支持。在终端执行：

```console
$ cd tools/net-tools
$ ./net-setup.sh  -c zeth-vlan.conf
```

随后为`qemu_x86`或`native_sim`构建网络过滤示例：

```sh
west build -b <board to use> samples/net/pkt_filter -- -DCONF_FILE="prj.conf overlay-vlan.conf"
```

本例的[samples/net/pkt_filter/overlay-vlan.conf](https://github.com/zephyrproject-rtos/zephyr/blob/main/samples/net/pkt_filter/overlay-vlan.conf)创建两个VLAN，设置如下：

- VLAN标签100：IPv4为`198.51.100.1`，IPv6为`2001:db8:100::1`。
- VLAN标签200：IPv4为`203.0.113.1`，IPv6为`2001:db8:200::1`。

在网络Shell中查看数据包过滤器：

```text
uart:~$ net filter
Rule  Type        Verdict   Pkt-Prio  Queue  Thread-Prio  Tests
[ 1]  recv        OK             N/A    N/A          N/A  3    iface[2],eth vlan type[0x0800],size max[200]
[ 2]  recv        OK             N/A    N/A          N/A  3    iface[3],eth vlan type[0x0800],size min[100]
[ 3]  recv        OK             N/A    N/A          N/A  1    iface[1]
[ 4]  recv        OK             N/A    N/A          N/A  2    iface[2],eth vlan type[0x0806]
[ 5]  recv        OK             N/A    N/A          N/A  2    iface[3],eth vlan type[0x0806]
[ 6]  recv        DROP           N/A    N/A          N/A  0
[ 7]  IPv4 recv   OK             N/A    N/A          N/A  1    ip src block[192.0.2.2,198.51.100.2]
[ 8]  IPv6 recv   OK             N/A    N/A          N/A  1    ip src block[2001:db8::2,2001:db8::100:2]
```

上述规则的含义如下：

1. 向网络接口2（第一个VLAN接口）放行最大200字节的IPv4数据包，以太网类型为`0x0800`。
2. 向网络接口3（第二个VLAN接口）放行最小100字节的IPv4数据包。
3. 放行进入以太网接口1的全部流量。
4. 向VLAN接口2放行地址解析协议（Address Resolution Protocol，ARP）数据包，以太网类型为`0x0806`。
5. 向VLAN接口3放行ARP数据包。
6. 丢弃其他数据包；原文说明这也会丢弃IPv6数据包。
7. 丢弃源地址为`192.0.2.2`或`198.51.100.2`的IPv4数据包。
8. 丢弃源地址为`2001:db8::2`或`2001:db8::100:2`的IPv6数据包。

启用数据包优先级选项`CONFIG_NET_SAMPLE_USE_PACKET_PRIORITIES`后，示例会安装额外的优先级规则：

```text
uart:~$ net filter
Rule  Type        Verdict   Pkt-Prio  Queue  Thread-Prio  Tests
[ 1]  recv        CONTINUE         1      0            1  1    iface[1]
[ 2]  recv        CONTINUE         7      2         SKIP  2    iface[1],eth type[0x88f7]
[ 3]  recv        CONTINUE         2      0            1  2    iface[1],eth type[0x8100]
[ 4]  recv        CONTINUE         1      0            1  2    iface[2],eth vlan type[0x0806]
[ 5]  recv        CONTINUE         1      0            1  2    iface[3],eth vlan type[0x0806]
[ 6]  recv        OK             N/A    N/A          N/A  3    iface[2],eth vlan type[0x0800],size max[200]
[ 7]  recv        OK             N/A    N/A          N/A  3    iface[3],eth vlan type[0x0800],size min[100]
[ 8]  recv        OK             N/A    N/A          N/A  1    iface[1]
[ 9]  recv        OK             N/A    N/A          N/A  2    iface[2],eth vlan type[0x0806]
[10]  recv        OK             N/A    N/A          N/A  2    iface[3],eth vlan type[0x0806]
[11]  recv        DROP           N/A    N/A          N/A  0
[12]  IPv4 recv   OK             N/A    N/A          N/A  1    ip src block[192.0.2.2,198.51.100.2]
[13]  IPv6 recv   OK             N/A    N/A          N/A  1    ip src block[2001:db8::2,2001:db8::100:2]
```

上述列表中，规则1—5为特定类型的数据包设置优先级；规则6—13与前一个列表的规则相同。

网络统计可以用于观察丢包；使用`net stats`监控。也可从网络Shell验证规则：

```text
uart:~$ net ping 2001:db8:100::2 -c 2
PING 2001:db8:100::2
Ping timeout
uart:~$ net stats 2
Interface 0x8089c6c (Virtual) [2]
==================================
IPv6 recv      0        sent    3       drop    0       forwarded       0
IPv6 ND recv   0        sent    7       drop    1
IPv6 MLD recv  0        sent    0       drop    0
ICMP recv      0        sent    3       drop    0
...
Filter drop rx 10       tx      0
Bytes received 320
Bytes sent     660
Processing err 10

uart:~$ net ping 198.51.100.2 -c 1
PING 198.51.100.2
28 bytes from 198.51.100.2 to 198.51.100.1: icmp_seq=1 ttl=64 time=100 ms

uart:~$ net ping 198.51.100.2 -c 1 -s 201
PING 198.51.100.2
Ping timeout

uart:~$ net ping 203.0.113.2 -c 1
PING 203.0.113.2
Ping timeout

uart:~$ net ping 203.0.113.2 -c 1 -s 101
PING 203.0.113.2
125 bytes from 203.0.113.2 to 203.0.113.1: icmp_seq=1 ttl=64 time=20 ms
```

> 译注——过滤阶段与判定：`recv`、`IPv4 recv`和`IPv6 recv`属于不同规则链。当前阻止列表（Blocklist）条件使用“源地址不在列表中”作为匹配条件，因此表中`OK`并不表示放行被列出的地址：列表外地址匹配后放行，列表内地址没有匹配规则而被丢弃。优先级规则返回`CONTINUE`，设置优先级后继续检查后续规则。原文规则6对IPv6的说明应结合接口理解：基础以太网接口已有允许规则，而VLAN接口只显式放行了IPv4与ARP。

> 译注——旧验证输出的边界：上面旧输出展示来自`198.51.100.2`的ping回复，但当前示例又将该源地址加入IPv4阻止列表，因而不能把旧成功日志当作当前完整规则集的必然结果。IPv6阻止列表中的`2001:db8::100:2`也不同于前面VLAN的`2001:db8:100::2`，原文与实现中的不同地址均保留。长度条件根据过滤点看到的`net_pkt_get_len()`判定，不应直接等同于`ping -s`指定的负载长度。排查时先核对当前规则、接口编号和接收计数。
