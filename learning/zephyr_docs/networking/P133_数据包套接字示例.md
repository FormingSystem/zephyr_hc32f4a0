# 第133章\_数据包套接字示例

原文：[官方页面](https://docs.zephyrproject.org/latest/samples/net/sockets/packet/README.html)。读取日期：2026-10-14；保存的 latest 页面及 HTML 摘要见[来源记录](../SOURCES.md)。

## 1. 概述（Overview）

本示例是一个简单的数据包套接字（Packet Socket）应用，展示如何在以太网上使用这类套接字。它打印收到的每个包，并每隔 5 秒发送一个演示包。原文说明，Zephyr 网络子系统不修改这些包的 L2、L3 等任何头部。

可[在 GitHub 查看官方源码](https://github.com/zephyrproject-rtos/zephyr/blob/main//samples/net/sockets/packet/README.rst/..)。

> 译注——源码版本与套接字类型：当前官方 [`src/packet.c`](https://github.com/zephyrproject-rtos/zephyr/blob/main/samples/net/sockets/packet/src/packet.c) 根据 `CONFIG_NET_SAMPLE_ENABLE_PACKET_DGRAM` 选择 `SOCK_DGRAM` 或 `SOCK_RAW`。样例 [Kconfig](https://github.com/zephyrproject-rtos/zephyr/blob/main/samples/net/sockets/packet/Kconfig) 明确指出，数据报模式会去掉接收以太网头，并在发送时添加以太网头。因此，原文“不修改头部”的描述应与所选套接字模式一起理解，不能对数据报模式照搬。

## 2. 构建和运行（Building and Running）

应用运行时打开数据包套接字，打印收到的数据包长度，并每隔 5 秒发送一个演示包。可以用 Wireshark 观察收发数据。

接收套接字还会加入一个以太网组播组（Ethernet Multicast Group），让网络接口额外监听一个组播 MAC 地址。加入使用 `PACKET_ADD_MEMBERSHIP` 套接字选项，示例停止时通过 `PACKET_DROP_MEMBERSHIP` 离开。

可以设置 [`CONFIG_NET_SAMPLE_MCAST_ADDR`](https://github.com/zephyrproject-rtos/zephyr/blob/main/samples/net/sockets/packet/Kconfig) 选择该地址，或禁用 [`CONFIG_NET_SAMPLE_MCAST_MEMBERSHIP`](https://github.com/zephyrproject-rtos/zephyr/blob/main/samples/net/sockets/packet/Kconfig)，完全跳过加入操作。

加入和离开也会报告为网络管理事件（Network Management Events），可以在运行中设备的 Zephyr Shell 执行以下命令查看：

```text
uart:~$ net events on
```

进一步信息见 [net-tools](https://github.com/zephyrproject-rtos/net-tools) 项目。按照[与主机系统联网](P007_与主机系统联网.md#networking-with-host)的说明，可以在 QEMU 或 `native_sim` 中构建、运行本示例。

> 译注——事件观察时机：加入事件发生在应用执行加入操作时；如果之后才打开事件输出，不能期待回放已经发生的事件。应结合应用的加入／离开日志及抓包判断状态。上面的命令在目标 Shell 执行，`uart:~$` 是提示符，不是 Linux 主机命令的一部分。
