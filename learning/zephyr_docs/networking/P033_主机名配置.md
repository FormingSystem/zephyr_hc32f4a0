# 第33章\_主机名配置

原文：[官方页面](https://docs.zephyrproject.org/latest/services/connectivity/networking/api/net_hostname.html)。读取日期：2026-10-14；保存的 latest 页面及 HTML 摘要见[来源记录](../SOURCES.md)。

## 33.1\_主机名配置（Hostname Configuration）

联网设备可能需要主机名（Hostname）。例如配置成 mDNS 响应器（Responder）后，需要回答 `<hostname>.local` 查询，相关说明见[DNS 解析](P032_DNS解析.md#dns-resolve-interface)。

设置 [`CONFIG_NET_HOSTNAME_ENABLE`](https://docs.zephyrproject.org/latest/kconfig.html#CONFIG_NET_HOSTNAME_ENABLE) 才能保存主机名并启用相关 API。启用后，默认主机名由 [`CONFIG_NET_HOSTNAME`](https://docs.zephyrproject.org/latest/kconfig.html#CONFIG_NET_HOSTNAME) 指定，默认值为 `zephyr`。

同一固件烧录到多块板时，让所有板都使用相同名称并不实用。可以启用 [`CONFIG_NET_HOSTNAME_UNIQUE`](https://docs.zephyrproject.org/latest/kconfig.html#CONFIG_NET_HOSTNAME_UNIQUE)，为名称追加唯一后缀（Unique Postfix）。默认取第一个网络接口的链路地址；原文称为 link local address，在以太网中指 MAC 地址。例如 `01:02:03:04:05:06` 可生成 `zephyr010203040506`。

若要自行设置后缀，在网络接口创建前调用 `net_hostname_set_postfix_str()`；若希望把数据转换成十六进制后缀，则调用 `net_hostname_set_postfix()`。以太网初始化优先级由 [`CONFIG_ETH_INIT_PRIORITY`](https://docs.zephyrproject.org/latest/kconfig.html#CONFIG_ETH_INIT_PRIORITY) 指定，因此应在此优先级的接口初始化之前设置后缀。

原文称后缀只能设置一次。

> 源码跟踪译注：原文中两处 prefix 应理解为本节的“后缀”，不是前缀；这里的链路地址也不是 IPv6 链路本地 IP 地址。当前 [`subsys/net/hostname.c`](../../../subsys/net/hostname.c) 在未启用 `CONFIG_NET_HOSTNAME_UNIQUE_UPDATE` 时限制重复设置，启用该选项后行为不同，所以“只能一次”不是所有配置的统一限制。API 入口为 [`hostname.h`](../../../include/zephyr/net/hostname.h)，实际读取版本摘要见[来源记录](../SOURCES.md)。
