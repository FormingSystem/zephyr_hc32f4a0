# 第208章\_远程系统日志示例

原文：[官方页面](https://docs.zephyrproject.org/latest/samples/net/syslog_net/README.html)。读取日期：2026-10-14；保存的latest页面及HTML摘要见[来源记录](../SOURCES.md)。

<a id="overview"></a>

## 208.1 概述（Overview）

此应用启用远程系统日志（Remote syslog）服务，按照`prj.conf`配置向远端服务器发送syslog消息。关于通过UDP传输syslog协议的更多细节，参阅[RFC 5424](https://datatracker.ietf.org/doc/html/rfc5424.html)与[RFC 5426](https://datatracker.ietf.org/doc/html/rfc5426.html)。

源码位于[samples/net/syslog_net](https://github.com/zephyrproject-rtos/zephyr/blob/main/samples/net/syslog_net)。

<a id="requirements"></a>

## 208.2 要求（Requirements）

完成[与主机系统联网（Networking with the host system）](P007_与主机系统联网.md#networking-with-host)所述准备。

<a id="building-and-running"></a>

## 208.3 构建与运行（Building and Running）

配置远端IPv6 syslog服务器时，在`prj.conf`设置：

```cfg
CONFIG_LOG_BACKEND_NET=y
CONFIG_LOG_BACKEND_NET_SERVER="[2001:db8::2]:514"
```

如果未显式指定，默认端口为514，默认协议为UDP。服务器地址与端口支持以下语法：

```text
192.0.2.1:514
192.0.2.42
[2001:db8::1]:514
[2001:db8::2]
2001:db::42
```

要改用TCP，在服务器地址前加上`tcp://`前缀：

```text
tcp://192.0.2.1:514
tcp://192.0.2.42
tcp://[2001:db8::1]:514
```

构建`syslog_net`示例：

```sh
west build -b <board to use> samples/net/syslog_net -- -DCONF_FILE=<config file to use>
```

> 译注——TCP依赖：当前网络日志后端要求同时启用`CONFIG_NET_TCP`，才能按`tcp://`前缀使用TCP。未启用时，实现会记录“requires CONFIG_NET_TCP”的错误并退回UDP。因此修改地址前缀后，还要核对构建配置与接收端协议，而不能仅凭前缀判断TCP已经生效。
