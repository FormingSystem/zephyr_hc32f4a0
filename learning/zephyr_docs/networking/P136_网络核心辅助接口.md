# 第136章\_网络核心辅助接口

原文：[官方页面](https://docs.zephyrproject.org/latest/services/connectivity/networking/api/net_core.html)。读取日期：2026-10-14；保存的 latest 页面及 HTML 摘要见[来源记录](../SOURCES.md)。

## 1. 概述（Overview）

网络子系统包含两个用于向网络发送数据和从网络接收数据的函数。

`net_recv_data()` 通常由网络设备驱动使用，把收到的网络数据向上传递给协议栈作进一步处理。全部数据都通过某个网络接口接收，该接口通常由设备驱动创建。

发送时可使用 `net_send_data()`。应用通常不直接调用它，因为 [BSD 套接字（BSD Sockets）](P040_BSD套接字.md#bsd-sockets-interface) API 已提供网络数据收发功能。

> 译注——源码跟踪：这两个函数处于驱动与网络协议栈之间的路径，不是应用必须绕过套接字使用的另一套普通收发接口。官方 [`net_core.h`](https://github.com/zephyrproject-rtos/zephyr/blob/main/include/zephyr/net/net_core.h) 明确要求：`net_send_data()` 返回负值时，调用者负责释放数据包引用，避免内存泄漏。调用时还需遵守所用接口的执行上下文与包所有权约定。
