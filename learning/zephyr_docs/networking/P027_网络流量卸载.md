# 第27章\_网络流量卸载

原文：[官方页面](https://docs.zephyrproject.org/latest/services/connectivity/networking/api/net_offload.html)。读取日期：2026-10-14；保存的 latest 页面及 HTML 摘要见[来源记录](../SOURCES.md)。

## 27.1\_网络卸载（Network Offloading）

网络卸载 API 提供钩子（Hook），设备厂商可借此提供另一套 IP 协议栈实现。此时，实际的网络连接创建、数据传输等工作由厂商硬件抽象层（Hardware Abstraction Layer，HAL）完成，而不是由 Zephyr 协议栈完成。

接口参考见[网络卸载接口（Network Offloading Interface）](https://docs.zephyrproject.org/latest/doxygen/html/group__net__offload.html)。

## 27.2\_套接字卸载（Socket Offloading）

除了网络卸载 API，Zephyr 还允许在套接字 API 层卸载网络功能。若厂商的另一套协议栈向网络设备提供套接字 API，就可以用这种方式接入 Zephyr。

实现示例见[官方 SimpleLink 套接字驱动源码](https://github.com/zephyrproject-rtos/zephyr/blob/main/drivers/wifi/simplelink/simplelink_sockets.c)，其路径为 [`drivers/wifi/simplelink/simplelink_sockets.c`](https://github.com/zephyrproject-rtos/zephyr/blob/main/drivers/wifi/simplelink/simplelink_sockets.c)，说明如何在套接字层接入网络卸载。
