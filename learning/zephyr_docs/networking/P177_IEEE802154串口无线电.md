# 第177章\_IEEE802154串口无线电

原文：[官方页面](https://docs.zephyrproject.org/latest/samples/net/wpan_serial/README.html)。读取日期：2026-10-14；保存的 latest 页面及 HTML 摘要见[来源记录](../SOURCES.md)。

## 1. 概述（Overview）

`wpan_serial` 示例展示如何把具有 IEEE 802.15.4 无线电和 USB 控制器的硬件作为“串口无线电”（Serial-Radio），供基于 Contiki 的边界路由器（Border Router）使用。官方[示例源码](https://github.com/zephyrproject-rtos/zephyr/tree/main/samples/net/wpan_serial)实现相应设备端逻辑。

## 2. 要求（Requirements）

开发板必须同时支持 IEEE 802.15.4 无线电和 USB 控制器。例如，可以通过覆盖文件（Overlays）选择 CC2520 或 RF2xx 收发器，也可以使用内置无线电的片上系统（System-on-Chip，SoC），如 `kw41z`、`nrf5`、`samr21`。

## 3. 构建与运行

### 3.1 准备 Linux 串口环境

原文要求在构建和运行前禁用 Linux 系统的 ModemManager，防止它干扰串口通信，给出的命令为：

```sh
$ sudo systemctl disable ModemManager.service
```

> 译注：该命令修改系统服务的启用状态；`disable` 本身不等于立即停止已在运行的服务，见官方[systemctl 手册源码](https://github.com/systemd/systemd/blob/main/man/systemctl.xml)。这里保留原始命令和前提，不把它当作本次翻译需要执行的操作，也不适用于所有主机系统。

### 3.2 构建并烧写 Zephyr 设备端

选择带无线电和 USB 控制器的开发板。`samples/net/wpan_serial` 目录为不同组合提供配置，其中 `prj.conf` 是标准默认配置，可单独用于原生支持 IEEE 802.15.4 的硬件。

在已准备 Zephyr 目标依赖的主机上，从读者自己的 Zephyr 源码根目录构建：

```sh
west build -b <board name> samples/net/wpan_serial -- -DCONF_FILE="prj.conf [overlay-<RADIO>.conf]"
```

> 译注：`<board name>`、`<RADIO>` 和方括号中的可选部分是说明性占位。实际执行时替换目标，只列入当前版本真实存在且适合硬件的覆盖文件，不把方括号原样传给 CMake。`CONF_FILE` 是所选配置文件集合。

原文以 Atmel SAM R21 Xplained Pro 开发套件为例构建并烧写：

```sh
west build -b samr21_xpro samples/net/wpan_serial
west flash
```

### 3.3 连接 Linux 主机并启动 Contiki 路由器

把开发板接到 Linux PC，系统中应出现 `/dev/ttyACM[number]`。这是 Linux 设备节点命名示例，不是仓库路径，`[number]` 应按实际枚举结果替换。

运行基于 Contiki 的原生边界路由器，例如 `6lbr` 或 `native-router`。原文的 Contiki 示例为：

```sh
$ cd examples/ipv6/native-border-router
$ make
$ sudo ./border-router.native -v5 -s ttyACM0 fd01::1/64
```

> 译注：这里的 `cd examples/ipv6/native-border-router` 从包含该示例的 Contiki 源码根目录解析，不是 Zephyr 源码根目录。该步骤需要相应 Contiki 版本与主机构建环境。`ttyACM0` 应匹配自己的设备，`fd01::1/64` 是本例网络前缀；执行路由器会涉及主机网络，本次未运行。

### 3.4 查看 Web 界面

原文说明，此时应有一个 Contiki 原生边界路由器。使用其输出中显示的服务器地址，通过浏览器访问 Web 界面。示例输出为：

```console
...
Server IPv6 addresses:
 0x62c5c0: =>fd01::212:4b00:531f:113a
...
```

原文使用 `http://[fd01::212:4b00:531f:113a]/` 查看可用邻居（Neighbors）与路由（Routes）。实际应使用自己的运行输出地址，并保留 IPv6 URL 的方括号。

> 源码对照：当前[prj.conf](https://github.com/zephyrproject-rtos/zephyr/blob/main/samples/net/wpan_serial/prj.conf)启用 IEEE 802.15.4 原始模式（Raw Mode）和 USB CDC ACM。它是供 Contiki 主机侧配合使用的串口无线电示例，与前面的 OpenThread NCP／RCP 示例属于不同方案，不能直接用其固件替换 OpenThread 协处理器固件。
