# 第21章\_网络配置库

原文：[官方页面](https://docs.zephyrproject.org/latest/services/connectivity/networking/api/net_config.html)。读取日期：2026-10-14；保存的 latest 页面及 HTML 摘要见[来源记录](../SOURCES.md)。

## 21.1\_概览（Overview）

网络配置库（Network Configuration Library）依据用户提供的 Kconfig 选项，在系统启动时以半自动方式设置网络设备。以下选项决定其行为。

| 配置选项 | 作用 |
| --- | --- |
| [`CONFIG_NET_CONFIG_SETTINGS`](https://docs.zephyrproject.org/latest/kconfig.html#CONFIG_NET_CONFIG_SETTINGS) | 控制是否使用配置库配置／初始化网络。关闭时，应用负责全部网络配置；开启后，可选择为系统的第一个网络接口设置静态 IP 地址。原文说明静态地址设置通常只适用于测试，不应直接用于生产代码。具体选项见[网络配置库 Kconfig](https://github.com/zephyrproject-rtos/zephyr/blob/main/subsys/net/lib/config/Kconfig)。 |
| [`CONFIG_NET_CONFIG_AUTO_INIT`](https://docs.zephyrproject.org/latest/kconfig.html#CONFIG_NET_CONFIG_AUTO_INIT) | 在设备启动时自动配置网络系统。 |
| [`CONFIG_NET_CONFIG_INIT_TIMEOUT`](https://docs.zephyrproject.org/latest/kconfig.html#CONFIG_NET_CONFIG_INIT_TIMEOUT) | 等待网络就绪可用的时间上限。例如未在此时间内从 DHCPv4 获得 IPv4 地址，启动阶段的 `net_config_init()` 将返回错误。 |
| [`CONFIG_NET_CONFIG_NEED_IPV4`](https://docs.zephyrproject.org/latest/kconfig.html#CONFIG_NET_CONFIG_NEED_IPV4) | 声明应用需要 IPv4，确保为其完成相应初始化。若 [`CONFIG_NET_IPV4`](https://docs.zephyrproject.org/latest/kconfig.html#CONFIG_NET_IPV4) 尚未启用，该选项会自动启用它。 |
| [`CONFIG_NET_CONFIG_NEED_IPV6`](https://docs.zephyrproject.org/latest/kconfig.html#CONFIG_NET_CONFIG_NEED_IPV6) | 声明应用需要 IPv6，确保为其完成相应初始化。若 [`CONFIG_NET_IPV6`](https://docs.zephyrproject.org/latest/kconfig.html#CONFIG_NET_IPV6) 尚未启用，该选项会自动启用它。 |
| [`CONFIG_NET_CONFIG_NEED_IPV6_ROUTER`](https://docs.zephyrproject.org/latest/kconfig.html#CONFIG_NET_CONFIG_NEED_IPV6_ROUTER) | 启用 IPv6 时，要求应用继续执行前已有 IPv6 路由器；实际表现为等待收到 IPv6 路由器通告（Router Advertisement）消息。 |
| [`CONFIG_NET_CONFIG_MY_IPV6_ADDR`](https://docs.zephyrproject.org/latest/kconfig.html#CONFIG_NET_CONFIG_MY_IPV6_ADDR) | 分配给默认网络接口的本地静态 IPv6 地址。 |
| [`CONFIG_NET_CONFIG_PEER_IPV6_ADDR`](https://docs.zephyrproject.org/latest/kconfig.html#CONFIG_NET_CONFIG_PEER_IPV6_ADDR) | 对端静态 IPv6 地址，主要用于连接预先指定主机的测试场景。 |
| [`CONFIG_NET_CONFIG_MY_IPV4_ADDR`](https://docs.zephyrproject.org/latest/kconfig.html#CONFIG_NET_CONFIG_MY_IPV4_ADDR) | 分配给默认网络接口的本地静态 IPv4 地址。 |
| [`CONFIG_NET_CONFIG_MY_IPV4_NETMASK`](https://docs.zephyrproject.org/latest/kconfig.html#CONFIG_NET_CONFIG_MY_IPV4_NETMASK) | 与 IPv4 地址配套的静态子网掩码（Netmask）。 |
| [`CONFIG_NET_CONFIG_MY_IPV4_GW`](https://docs.zephyrproject.org/latest/kconfig.html#CONFIG_NET_CONFIG_MY_IPV4_GW) | 分配给默认网络接口的静态 IPv4 网关（Gateway）地址。 |
| [`CONFIG_NET_CONFIG_PEER_IPV4_ADDR`](https://docs.zephyrproject.org/latest/kconfig.html#CONFIG_NET_CONFIG_PEER_IPV4_ADDR) | 对端静态 IPv4 地址，主要用于连接预先指定主机的测试场景。 |

> 源码跟踪译注：这里的 `SETTINGS` 指网络配置库选项，不是泛指持久化 Settings 子系统。官方 [`subsys/net/lib/config/Kconfig`](../../../subsys/net/lib/config/Kconfig) 明确定位为快速示例／测试配置，而不是正式的参数下发（Provisioning）机制。当前定义中的初始化等待时间以秒为单位；网页与本地源码版本依据分别记录在[来源记录](../SOURCES.md)。

## 21.2\_SNTP 时钟初始化（SNTP Clock Initialization）

启用 [`CONFIG_NET_CONFIG_CLOCK_SNTP_INIT`](https://docs.zephyrproject.org/latest/kconfig.html#CONFIG_NET_CONFIG_CLOCK_SNTP_INIT) 后，库还会通过简单网络时间协议（Simple Network Time Protocol，SNTP）服务器初始化系统时钟；可再启用 [`CONFIG_NET_CONFIG_SNTP_INIT_RESYNC`](https://docs.zephyrproject.org/latest/kconfig.html#CONFIG_NET_CONFIG_SNTP_INIT_RESYNC)，持续保持同步。

查询服务器按以下优先顺序选择：

1. 运行时通过 [`net_config_sntp_set_server()`](https://docs.zephyrproject.org/latest/doxygen/html/group__net__config.html#ga4d71cd03a40db9155b29fab43f7d5ec5) 指定的服务器。需要启用 [`CONFIG_NET_CONFIG_SNTP_INIT_SERVER_RUNTIME`](https://docs.zephyrproject.org/latest/kconfig.html#CONFIG_NET_CONFIG_SNTP_INIT_SERVER_RUNTIME)；适用于运行过程中才知道应使用哪个时间服务器的应用，例如完成参数下发之后。
2. DHCPv4 的 NTP 服务器选项提供的服务器，需要启用 [`CONFIG_NET_CONFIG_SNTP_INIT_SERVER_USE_DHCPV4_OPTION`](https://docs.zephyrproject.org/latest/kconfig.html#CONFIG_NET_CONFIG_SNTP_INIT_SERVER_USE_DHCPV4_OPTION)。
3. [`CONFIG_NET_CONFIG_SNTP_INIT_SERVER`](https://docs.zephyrproject.org/latest/kconfig.html#CONFIG_NET_CONFIG_SNTP_INIT_SERVER) 指定的服务器。如果启用了 [`CONFIG_NET_CONFIG_CLOCK_SNTP_INIT`](https://docs.zephyrproject.org/latest/kconfig.html#CONFIG_NET_CONFIG_CLOCK_SNTP_INIT)，但运行时服务器选项与 DHCPv4 服务器选项均未启用，则必须设置这一项。

## 21.3\_使用方式（Sample Usage）

设置 [`CONFIG_NET_CONFIG_AUTO_INIT`](https://docs.zephyrproject.org/latest/kconfig.html#CONFIG_NET_CONFIG_AUTO_INIT) 后，网络配置库在设备启动过程中自动启用并运行，自行调用 `net_config_init()`，应用无需再执行这一网络配置流程。

如果希望使用配置库但不自动初始化，可以手动调用 `net_config_init()`。其 `flags` 参数告诉库，在应用正式开始前希望具备哪些功能。
