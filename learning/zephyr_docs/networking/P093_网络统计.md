# 第93章\_网络统计

原文：[官方页面](https://docs.zephyrproject.org/latest/services/connectivity/networking/api/net_stats.html)。读取日期：2026-10-14；保存的 latest 页面及 HTML 摘要见[来源记录](../SOURCES.md)。

## 93.1\_概述

设置[`CONFIG_NET_STATISTICS`](https://docs.zephyrproject.org/latest/kconfig.html#CONFIG_NET_STATISTICS)后，系统会收集网络统计（Network Statistics）。不需要的IPv4或IPv6组件统计可以分别关闭；具体选项见[subsys/net/ip/Kconfig.stats](https://github.com/zephyrproject-rtos/zephyr/blob/main/subsys/net/ip/Kconfig.stats)。

默认按网络接口（Network Interface）分别收集统计信息，可通过[`CONFIG_NET_STATISTICS_PER_INTERFACE`](https://docs.zephyrproject.org/latest/kconfig.html#CONFIG_NET_STATISTICS_PER_INTERFACE)控制此行为。

应用若要获取统计数据并进一步处理，可设置[`CONFIG_NET_STATISTICS_USER_API`](https://docs.zephyrproject.org/latest/kconfig.html#CONFIG_NET_STATISTICS_USER_API)。它使用网络管理接口API（Network Management Interface API），详见[网络管理](P022_网络管理.md#net-mgmt-interface)。

设置[`CONFIG_NET_STATISTICS_ETHERNET`](https://docs.zephyrproject.org/latest/kconfig.html#CONFIG_NET_STATISTICS_ETHERNET)可以收集通用以太网统计（Generic Ethernet Statistics）。设置[`CONFIG_NET_STATISTICS_ETHERNET_VENDOR`](https://docs.zephyrproject.org/latest/kconfig.html#CONFIG_NET_STATISTICS_ETHERNET_VENDOR)后，以太网设备驱动可以收集设备专用统计（Device-specific Statistics），随后交给应用处理。

设置[`CONFIG_NET_SHELL`](https://docs.zephyrproject.org/latest/kconfig.html#CONFIG_NET_SHELL)后，可以在网络Shell中用`net stats`显示统计信息。
