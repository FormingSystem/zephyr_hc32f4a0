# 第138章\_Trickle定时器库

原文：[官方页面](https://docs.zephyrproject.org/latest/services/connectivity/networking/api/trickle.html)。读取日期：2026-10-14；保存的 latest 页面及 HTML 摘要见[来源记录](../SOURCES.md)。

## 1. 概述（Overview）

Trickle 定时器库（Trickle Timer Library）实现 [RFC 6206](https://datatracker.ietf.org/doc/html/rfc6206.html)。

Trickle 算法使有损共享介质中的节点，例如低功耗有损网络（Low-power and Lossy Networks）中的节点，能够以稳健、节能、简单且可扩展的方式交换信息。
