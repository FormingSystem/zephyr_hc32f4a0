# 第207章\_网络统计示例

原文：[官方页面](https://docs.zephyrproject.org/latest/samples/net/stats/README.html)。读取日期：2026-10-14；保存的latest页面及HTML摘要见[来源记录](../SOURCES.md)。

<a id="overview"></a>

## 207.1 概述（Overview）

本示例演示如何从用户应用中查询并显示网络统计（Network statistics）。源码位于[samples/net/stats](https://github.com/zephyrproject-rtos/zephyr/blob/main/samples/net/stats)。

<a id="requirements"></a>

## 207.2 要求（Requirements）

完成[与主机系统联网（Networking with the host system）](P007_与主机系统联网.md#networking-with-host)所述准备。

<a id="building-and-running"></a>

## 207.3 构建与运行（Building and Running）

按照[与主机系统联网](P007_与主机系统联网.md#networking-with-host)说明，在QEMU或`native_sim`中运行此示例是一种适合的方式。构建步骤如下：

```sh
west build -b <board to use> samples/net/stats -- -DCONF_FILE=prj.conf
```

如果全部配置正确，应用会定期向控制台打印当前网络统计：

```text
Global network statistics
IPv6 recv      27   sent    8       drop    0       forwarded       0
IPv6 ND recv   2    sent    5       drop    2
IPv6 MLD recv  0    sent    3       drop    0
IPv4 recv      20   sent    0       drop    20      forwarded       0
IP vhlerr      0    hblener 0       lblener 0
IP fragerr     0    chkerr  0       protoer 0
ICMP recv      15   sent    3       drop    13
ICMP typeer    0    chkerr  0
UDP recv       0    sent    0       drop    30
UDP chkerr     0
TCP bytes recv 0    sent    0
TCP seg recv   0    sent    0       drop    0
TCP seg resent 0    chkerr  0       ackerr  0
TCP seg rsterr 0    rst     0       re-xmit 0
TCP conn drop  0    connrst 0
Bytes received 7056
Bytes sent     564
Processing err 1
```

> 译注——统计周期：当前`CONFIG_SAMPLE_PERIOD`默认30秒，允许范围为1—3600秒。实现通过延迟工作（Delayable work）周期性调用`NET_REQUEST_STATS_GET_ALL`查询全局统计；启用对应配置时，还查询各网络接口及以太网统计。原输出是历史计数示例，不是固定的预期值；具体协议字段取决于当前构建配置和实际流量。
