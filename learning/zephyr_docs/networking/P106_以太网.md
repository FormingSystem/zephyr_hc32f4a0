# 第106章\_以太网

原文：[官方页面](https://docs.zephyrproject.org/latest/services/connectivity/networking/api/ethernet.html)。读取日期：2026-10-14；保存的 latest 页面及 HTML 摘要见[来源记录](../SOURCES.md)。

## 1. 概述（Overview）

以太网（Ethernet）是一种广泛用于局域网（Local Area Network，LAN）的网络技术。进一步介绍见原文链接的[以太网百科条目](https://en.wikipedia.org/wiki/Ethernet)。

Zephyr 支持以下以太网特性：

- 10、100 和 1000 Mbit/s 链路。
- 自动协商（Auto Negotiation）。
- 半双工／全双工（Half/Full Duplex）。
- 混杂模式（Promiscuous Mode）。
- 发送和接收校验和卸载（TX/RX Checksum Offloading）。
- MAC 地址过滤（MAC Address Filtering）。
- [MAC 地址配置（MAC Address Configuration）](P108_MAC地址配置.md#mac-address-config)。
- [虚拟局域网（Virtual LAN，VLAN）](P110_VLAN虚拟局域网.md#vlan-interface)。
- [优先级队列（Priority Queues）](P119_流量分类.md#traffic-class-support)。
- [IEEE 802.1AS 通用精确时间协议（gPTP）](P117_gPTP通用精确时间协议.md#gptp-interface)。
- [IEEE 802.1Qav 基于信用值的整形（Credit Based Shaping）](P118_IEEE8021Qav流量整形.md#qav)。
- [链路层发现协议（Link Layer Discovery Protocol，LLDP）](P116_LLDP链路层发现协议.md#lldp-interface)。

并非所有以太网设备驱动都支持以上全部特性。可以在网络命令行（net-shell）中执行 `net iface`，查看当前设备支持的以太网特性。
