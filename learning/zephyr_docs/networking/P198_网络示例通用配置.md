# 第198章\_网络示例通用配置

原文：[官方页面](https://docs.zephyrproject.org/latest/samples/net/common/README.html)。读取日期：2026-10-14；保存的latest页面及HTML摘要见[来源记录](../SOURCES.md)。

## 198.1 概述（Overview）

不同网络示例可以复用公共代码，启用虚拟局域网（Virtual LAN，VLAN）等通用功能。公共示例代码位于[samples/net/common](https://github.com/zephyrproject-rtos/zephyr/blob/main/samples/net/common)。

<a id="vlan"></a>

## 198.2 虚拟局域网（VLAN）

要在网络示例应用中启用VLAN支持，可将`overlay-vlan.conf`加入应用构建。例如，回显服务器（Echo server）示例可以这样构建并运行：

```sh
west build -b native_sim samples/net/sockets/echo_server -- -DCONF_FILE="prj.conf overlay-vlan.conf"
west build -t run
```

主机上的VLAN设置可以这样完成：

```console
$ cd tools/net-setup
$ ./net-setup.sh -c zeth-vlan.conf
```

示例配置会建立以下网络结构。

**主机侧：**

- 创建普通`zeth`接口，地址为`192.0.2.2/24`。发往Zephyr的全部网络流量都经过这个接口。
- `vlan.100`接口处理VLAN标签（Tag）100的流量，IPv4地址为`198.51.100.2`，IPv6地址为`2001:db8:100::2`。
- `vlan.200`接口处理VLAN标签200的流量，IPv4地址为`203.0.113.2`，IPv6地址为`2001:db8:200::2`。

**Zephyr侧：**

- `eth0`为主接口，地址为`192.0.2.1/24`，用于连接主机。
- `VLAN-100`是处理VLAN标签100流量的虚拟接口，地址为`198.51.100.1/24`与`2001:db8:100::1/64`。
- `VLAN-200`是处理VLAN标签200流量的虚拟接口，地址为`203.0.113.1/24`与`2001:db8:200::1/64`。

> 警告：示例中的IPv4与IPv6地址只能用于这些网络示例，不能用于实际网络。这些地址专门保留供文档使用，不具备公网可路由性。

> 译注——目录基准：上面`cd tools/net-setup`是原文写法。当前官方`west.yml`将`net-tools`项目放在West工作区的`tools/net-tools`；`net-setup.sh`与`zeth-vlan.conf`位于该工具项目中。应先按所用清单确认该项目实际位置，再进入包含这两个文件的目录执行主机配置。它与运行`west build`时使用的Zephyr源码根目录不同，不要据旧目录名创建空目录，也不要写死读者电脑上的仓库位置。
