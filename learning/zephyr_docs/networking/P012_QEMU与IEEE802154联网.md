# 第12章\_QEMU与IEEE802154联网

原文：[官方页面](https://docs.zephyrproject.org/latest/services/connectivity/networking/qemu_802154_setup.html)。读取日期：2026-10-14；保存的 latest 页面及 HTML 摘要见[来源记录](../SOURCES.md)。

## 12.1\_用途与基本准备（Basic Setup）

本页说明如何在两个 QEMU 实例之间建立虚拟网络（Virtual Network）：两个实例通过 UART 相连，并在该连接上运行 IEEE 802.15.4 链路层（Link Layer）。此方法只适用于 Linux 主机。

需要两个终端窗口：终端 1 运行 Zephyr 回显服务器（echo-server）示例；终端 2 运行回显客户端（echo-client）示例。

如果需要捕获传输的网络数据，先编译 `tools/net-tools` 目录中的 `monitor_15_4` 程序。在 Linux 终端中执行：

```sh
cd $ZEPHYR_BASE/../tools/net-tools
make monitor_15_4
```

> 译注：`ZEPHYR_BASE` 表示当前 Zephyr 源码根目录；命令假定官方外部 `net-tools` 已位于工作区的 `tools/net-tools` 中。它不是本仓库随附的实验目录。下面两个构建终端都从 Zephyr 源码根目录执行；`build/server` 和 `build/client` 是构建命令生成的独立目录。

## 12.2\_编译并启动服务器（echo-server）

在终端 1 中执行：

```sh
west build -b qemu_x86 -d build/server samples/net/sockets/echo_server -- -DEXTRA_CONF_FILE=overlay-qemu_802154.conf
west build -t server -d build/server
```

若要同时捕获两个 QEMU 之间的网络流量，使用下面这一组服务器命令：

```sh
west build -b qemu_x86 -d build/server samples/net/sockets/echo_server -- -G'Unix Makefiles' -DEXTRA_CONF_FILE=overlay-qemu_802154.conf -DPCAP=capture.pcap
west build -t server -d build/server
```

在命令行启用分组捕获（Packet Capture）时，`server` 目标必须使用 Make 构建后端，因此上例显式选择 `Unix Makefiles`。传输的数据保存到 `build/server/capture.pcap`。

> 译注：普通运行与捕获运行是两个选择。如果已有构建目录使用其他生成器（Generator），切换为 `Unix Makefiles` 时应使用新的构建目录，并相应调整后续 `-d` 参数与捕获文件位置。

## 12.3\_编译并启动客户端（echo-client）

在终端 2 中执行：

```sh
west build -b qemu_x86 -d build/client samples/net/sockets/echo_client -- -DEXTRA_CONF_FILE=overlay-qemu_802154.conf
west build -t client -d build/client
```

随后应能看到两个 QEMU 之间传递数据。按 `Ctrl+A`，再按 `x` 退出 QEMU。
