# 第43章\_套接字服务回显示例

原文：[官方页面](https://docs.zephyrproject.org/latest/samples/net/sockets/echo_service/README.html)。读取日期：2026-10-14；保存的 latest 页面及 HTML 摘要见[来源记录](../SOURCES.md)。

## 43.1 概览（Overview）

`sockets/echo_service` 示例实现一个支持 IPv4 和 IPv6 的 TCP、UDP 回显服务器（Echo Server），采用 BSD 套接字兼容 API（BSD Sockets Compatible API）。TCP 是传输控制协议（Transmission Control Protocol），UDP 是用户数据报协议（User Datagram Protocol）。

本示例演示套接字服务（Socket Service）API：由一个线程监听多个阻塞套接字（Blocking Socket），当其中某个套接字有活动时触发回调函数（Callback）。这种安排只需创建一个服务线程，因而节省内存。应用同时支持 IPv4、IPv6、UDP 和 TCP。

源码位于[samples/net/sockets/echo_service](https://github.com/zephyrproject-rtos/zephyr/blob/main/samples/net/sockets/echo_service)，也可[在 GitHub 浏览官方源码](https://github.com/zephyrproject-rtos/zephyr/blob/main//samples/net/sockets/echo_service/README.rst/..)。

## 43.2 运行要求（Requirements）

使用[与主机系统联网](P007_与主机系统联网.md#networking-with-host)的环境，或使用具有硬件联网能力的开发板。

## 43.3 构建与运行（Building and Running）

按以下方式构建 Zephyr 的 `sockets/echo_service` 应用：

```shell
west build -b <board_to_use> samples/net/sockets/echo_service
```

> 译注：`<board_to_use>` 是待替换的开发板目标占位符。命令中的 [`samples/net/sockets/echo_service`](https://github.com/zephyrproject-rtos/zephyr/blob/main/samples/net/sockets/echo_service) 是相对于 Zephyr 源码根目录的路径，不依赖作者电脑的盘符或仓库位置。

示例启动后，在 `192.0.2.1` 或 `2001:db8::1` 地址的 `4242` 端口等待连接。最简单的连接方式是：

```shell
$ telnet 192.0.2.1 4242
```

建立连接后，应用会将发送给它的任意一行内容回显给客户端。

> 译注：`$` 是原文的主机 Shell 提示符，执行时只输入后面的命令。这里的 Telnet 测试使用 TCP；不能以它代替 UDP 分支验证。以上 IP 地址是官方示例的网络配置，不是本仓库作者的固定环境；实际网络需按前置主机联网文档配置。本轮仅翻译和核对文档，未执行构建或联网测试。
