## 7.3\_详细说明（Detailed Documentation）

<a id="gad7b4e3a8910b78e4beb0ec20524426e1"></a>

### `SYS_SEM_DEFINE`

```c
#define SYS_SEM_DEFINE ( _name, _initial_count, _count_limit )
```

```c
#include <zephyr/sys/sem.h>
```

展开值（Value）：

```c
struct sys_sem _name = { \
        .futex = { _initial_count }, \
        .limit = _count_limit \
}; \
BUILD_ASSERT(((_count_limit) != 0) && \
             ((_initial_count) <= (_count_limit)))
```

静态定义并初始化用户模式信号量sys_sem（User Mode Semaphore）。

在定义此信号量的模块之外，可通过以下声明访问它：

原始示例（Example）：

```c
extern struct sys_sem <name>;
```

使用K_APP_DMEM()将它放入相应内存域（Memory Domain）关联的内存分区。

**参数（Parameters）**

| 名称／方向 | 说明 |
| --- | --- |
| `_name` | 信号量的名称。 |
| `_initial_count` | 信号量的初始计数。 |
| `_count_limit` | 允许的最大信号量计数。 |

> 译注——源码核对：原页展开为用户模式分支，初始化futex.val与limit；非用户模式分支改为把嵌入k_sem的包装对象加入可遍历段。当前静态宏只断言上限非零和初始计数不超过上限，没有执行运行时sys_sem_init中的INT_MAX上界检查；使用者仍须遵守当前后端可表示范围。

<a id="ga43f2c8aae5ff633364e141a0c0340e93"></a>

### `SYS_SEM_LOCK`

```c
#define SYS_SEM_LOCK ( sem)
```

```c
#include <zephyr/sys/sem.h>
```

展开值（Value）：

```c
for (int __rc SYS_SEM_LOCK_ONEXIT = sys_sem_take((sem), K_FOREVER); ({                     \
             __ASSERT(__rc >= 0, "Failed to take sem: %d", __rc);                          \
             __rc == 0;                                                                    \
     });                                                                                   \
     ({                                                                                    \
             __rc = sys_sem_give((sem));                                                   \
             __ASSERT(__rc == 0, "Failed to give sem: %d", __rc);                          \
     }),                                                                                   \
              __rc = 1)
```

使用给定sys_sem保护一个代码块，在执行代码块前自动取得信号量。

执行到代码块末尾，或者通过SYS_SEM_LOCK_BREAK离开代码块时，会释放信号量。

使用示例：

原始示例（Example）：

```c
SYS_SEM_LOCK(&sem) {

  ...execute statements with the semaphore held...

  if (some_condition) {
    ...release the lock and leave the guarded section prematurely:
    SYS_SEM_LOCK_BREAK;
  }

  ...execute statements with the lock held...

}
```

这种写法实际展开为一个for循环，其循环体恰好执行一次：

原始示例（Example）：

```c
for (sys_sem_take(&sem, K_FOREVER); ...; sys_sem_give(&sem)) {
    ...
}
```

**参数（Parameters）**

| 名称／方向 | 说明 |
| --- | --- |
| `sem` | 用于保护所包围代码块的信号量（sys_sem）。 |

**警告（Warning）**：代码块必须执行到末尾，或通过SYS_SEM_LOCK_BREAK离开。否则，例如用break、goto或return语句退出，离开时不会释放信号量。

> 译注——源码核对：该宏是for循环：正常离开循环体或执行指向该循环的continue，都会经过递增表达式中的sys_sem_give。GNU cleanup辅助函数仅断言__rc==1，并不补做give；关闭断言也不会使break／goto／return自动释放资源。示例里的英文省略段分别表示“持有信号量执行语句”“提前释放并离开”“继续持锁执行”，属于伪代码，不是可直接编译的完整程序。所谓恰好一次是成功取得信号量的正常路径；失败时会断言，且循环体不会按成功路径执行。

<a id="ga2e5d53d02732b7df60853a00ed240cff"></a>

### `SYS_SEM_LOCK_BREAK`

```c
#define SYS_SEM_LOCK_BREAK continue
```

```c
#include <zephyr/sys/sem.h>
```

释放信号量后离开SYS_SEM_LOCK保护的代码块。

详细信息见SYS_SEM_LOCK。

> 译注——源码核对：实际展开是continue。应确保它作用于SYS_SEM_LOCK展开出的for循环；若放在另一个内层循环中，continue只作用于最内层循环，不会按名称自动跳出外层保护块。

<a id="ga7b287ca3cc3ab2766d7c1beec1849894"></a>

### `sys_sem_count_get()`

```c
unsigned int sys_sem_count_get ( struct sys_sem * sem)
```

```c
#include <zephyr/sys/sem.h>
```

读取sys_sem的值。

此例程返回sem的当前值。

**参数（Parameters）**

| 名称／方向 | 说明 |
| --- | --- |
| `sem` | sys_sem的地址。 |

**返回（Returns）**：返回sys_sem的当前值。

> 译注——源码核对：启用用户模式时，内部负值用于表示竞争状态，返回时将非正数折算为0；它不是等待线程数量。计数查询不预留一次成功获取，后续仍须检查take返回值。

<a id="gaae32032398db1f693ad3f876863f78b4"></a>

### `sys_sem_give()`

```c
int sys_sem_give ( struct sys_sem * sem)
```

```c
#include <zephyr/sys/sem.h>
```

给出信号量（Give）。

此例程给出sem，除非信号量已经达到允许的最大计数。

**参数（Parameters）**

| 名称／方向 | 说明 |
| --- | --- |
| `sem` | 信号量的地址。 |

**返回值（Return Values）**

| 名称／方向 | 说明 |
| --- | --- |
| `0` | 已给出信号量。 |
| `-EINVAL` | 参数地址无法识别。 |
| `-EACCES` | 调用者没有足够的访问权限。 |
| `-EAGAIN` | 计数已经达到允许的最大值，应稍后重试。 |

> 译注——源码核对：用户模式实现以原子比较并设置增加计数，达到上限时返回-EAGAIN；遇到负的竞争标记时会唤醒全部Futex等待者，等待者再竞争可用计数。非用户模式实现转发k_sem_give后始终返回0，包括已饱和情形。用户内存的原子访问先于可能发生的Futex系统调用，不能把错误码表理解为所有无效指针都会安全转成错误返回。

<a id="gae20385545bbf7a9dfd59afa74bf1120a"></a>

### `sys_sem_init()`

```c
int sys_sem_init ( struct sys_sem * sem, unsigned int initial_count, unsigned int limit )
```

```c
#include <zephyr/sys/sem.h>
```

初始化信号量（Semaphore）。

此例程在信号量实例第一次使用前初始化它。

**参数（Parameters）**

| 名称／方向 | 说明 |
| --- | --- |
| `sem` | 信号量的地址。 |
| `initial_count` | 信号量的初始计数。 |
| `limit` | 允许的最大信号量计数。 |

**返回值（Return Values）**

| 名称／方向 | 说明 |
| --- | --- |
| `0` | 初始化成功。 |
| `-EINVAL` | 参数无效：limit必须处于(0, INT_MAX]范围内，且initial_count不得大于limit。 |

> 译注——源码核对：用户模式实现检查NULL、limit非零、initial_count不大于limit及limit不大于INT_MAX。当前非用户模式包装调用k_sem_init却忽略其返回值，随后返回0；原接口表保留，但不能据此声称该后端会把所有初始化参数错误返回给调用者。此处记录源码行为，没有修改实现。

<a id="gaf742a29f89a816fa34b8d6d33e221b77"></a>

### `sys_sem_take()`

```c
int sys_sem_take ( struct sys_sem * sem, k_timeout_t timeout )
```

```c
#include <zephyr/sys/sem.h>
```

获取sys_sem（Take）。

此例程获取sem。

**参数（Parameters）**

| 名称／方向 | 说明 |
| --- | --- |
| `sem` | sys_sem的地址。 |
| `timeout` | 等待获取sys_sem的时长，或特殊值K_NO_WAIT、K_FOREVER之一。 |

**返回值（Return Values）**

| 名称／方向 | 说明 |
| --- | --- |
| `0` | 已取得sys_sem。 |
| `-EINVAL` | 参数地址无法识别。 |
| `-ETIMEDOUT` | 等待时间已到，发生超时。 |
| `-EACCES` | 调用者没有足够的访问权限。 |

> 译注——源码核对：用户模式实现先原子尝试减计数；旧值大于0则成功，否则把零值标成-1并在Futex上等待。唤醒或值不匹配时继续循环，每轮复用传入的timeout，未按已耗时扣减，反复竞争时不能将其视为整个调用的严格耗时上限。非用户模式包装把底层-EBUSY和-EAGAIN统一转换为-ETIMEDOUT；不要套用k_sem_take的全部返回码区分。
