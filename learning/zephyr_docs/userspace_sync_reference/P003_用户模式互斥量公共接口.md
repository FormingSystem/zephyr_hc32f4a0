## 3.3\_详细说明（Detailed Documentation）

<a id="ga486bd6a11d0b0d312cdf8a6a8f66c1a3"></a>

### `SYS_MUTEX_DEFINE`

```c
#define SYS_MUTEX_DEFINE ( name)
```

```c
#include <zephyr/sys/mutex.h>
```

展开值（Value）：

```c
struct sys_mutex name
```

静态定义并初始化用户模式互斥量sys_mutex（User Mode Mutex）。

在定义此互斥量的模块之外，可通过以下声明访问它：

原始示例（Example）：

```c
extern struct sys_mutex <name>;
```

使用K_APP_DMEM()将它放入相应内存域（Memory Domain）关联的内存分区。

**参数（Parameters）**

| 名称／方向 | 说明 |
| --- | --- |
| `name` | 互斥量的名称。 |

> 译注——源码核对：官方展开显示CONFIG_USERSPACE分支，仅声明struct sys_mutex对象；底层内核互斥量经元数据关联，并非在这里调用动态分配。原始extern示例中的<name>应换成实际标识符。K_APP_DMEM用于对象的内存放置，不表示仅加这个宏就完成线程的全部内存域授权。

<a id="ga5456b75934cb26abc974a45ae82d717b"></a>

### `sys_mutex_init()`

```c
void sys_mutex_init ( struct sys_mutex * mutex)
```

声明属性：`inline`、`static`。

```c
#include <zephyr/sys/mutex.h>
```

初始化互斥量（Mutex）。

此例程在互斥量对象第一次使用前初始化它。

完成后，互斥量可用，且没有拥有者（Owner）。

只有在未启用用户空间（Userspace）、且互斥量不是通过SYS_MUTEX_DEFINE()创建时，才需要调用此例程。

**参数（Parameters）**

| 名称／方向 | 说明 |
| --- | --- |
| `mutex` | 互斥量的地址。 |

> 译注——源码核对：启用用户模式时此函数只有ARG_UNUSED和注释，不创建底层内核对象。未启用用户模式时，它调用嵌入对象的k_mutex_init；不得把调用此函数当成注册任意动态地址为sys_mutex的步骤。

<a id="ga6887005f8223d4f36de5ae5c02ba4b17"></a>

### `sys_mutex_lock()`

```c
int sys_mutex_lock ( struct sys_mutex * mutex, k_timeout_t timeout )
```

声明属性：`inline`、`static`。

```c
#include <zephyr/sys/mutex.h>
```

锁定互斥量。

此例程锁定mutex。如果互斥量已被另一个线程锁定，调用线程会等待，直到互斥量可用或发生超时。

允许线程再次锁定自己已持有的互斥量。该操作立即完成，并将加锁计数（Lock Count）增加1。

**参数（Parameters）**

| 名称／方向 | 说明 |
| --- | --- |
| `mutex` | 互斥量的地址，可以位于用户内存中。 |
| `timeout` | 等待锁定互斥量的时长，或特殊值K_NO_WAIT、K_FOREVER之一。 |

**返回值（Return Values）**

| 名称／方向 | 说明 |
| --- | --- |
| `0` | 互斥量已锁定。 |
| `-EBUSY` | 未等待便返回。 |
| `-EAGAIN` | 等待时间已到，发生超时。 |
| `-EACCES` | 调用者无权访问给定互斥量地址。 |
| `-EINVAL` | 内核无法识别给定互斥量。 |

> 译注——源码核对：当前用户模式分支无条件调用z_sys_mutex_kernel_lock，未实现注释中规划的无竞争原子快速路径。内核按地址查找K_OBJ_SYS_MUTEX及其关联k_mutex，无法识别时返回-EINVAL；可写内存检查与对象识别是两个不同条件。它仍遵守底层互斥量的线程上下文、拥有者和递归计数约束。

<a id="ga7d4babcd161600dab5f1842c58be2a1f"></a>

### `sys_mutex_unlock()`

```c
int sys_mutex_unlock ( struct sys_mutex * mutex)
```

声明属性：`inline`、`static`。

```c
#include <zephyr/sys/mutex.h>
```

解锁互斥量。

此例程解锁mutex。调用线程必须已经锁定该互斥量。

只有当调用线程解锁的次数与此前加锁的次数相等后，其他线程才能取得该互斥量。

**参数（Parameters）**

| 名称／方向 | 说明 |
| --- | --- |
| `mutex` | 互斥量的地址，可以位于用户内存中。 |

**返回值（Return Values）**

| 名称／方向 | 说明 |
| --- | --- |
| `0` | 互斥量已解锁。 |
| `-EACCES` | 调用者无权访问给定互斥量地址。 |
| `-EINVAL` | 内核无法识别给定互斥量，或者该互斥量未锁定。 |
| `-EPERM` | 调用者不是该互斥量的拥有者。 |

> 译注——源码核对：启用用户模式时内核先查找关联k_mutex并检查计数，再调用k_mutex_unlock；未启用时直接转发到嵌入的k_mutex。成功返回0可能只减少一次递归计数，并不必然把锁完全交出。
