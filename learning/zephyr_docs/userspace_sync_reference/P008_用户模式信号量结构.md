## 8.3\_源码定位与版本边界

> 译注——阅读与源码边界：本结构文档由zephyr/sys/sem.h生成，页面公开用户模式分支的futex和limit声明，原页未给这两个字段单独添加说明。非用户模式分支只包含kernel_sem。负Futex值用于实现竞争标记，应用应通过sys_sem API访问，不直接把它当作公开的等待者计数。

仓库相对定位：[include/zephyr/sys/sem.h](../../../include/zephyr/sys/sem.h)与[kernel/userspace/sem.c](../../../kernel/userspace/sem.c)；本次核对[官方头文件](https://github.com/zephyrproject-rtos/zephyr/blob/main/include/zephyr/sys/sem.h)和[官方实现](https://github.com/zephyrproject-rtos/zephyr/blob/main/kernel/userspace/sem.c)。

非用户模式另见[仓库kernel/sys/sem.c](../../../kernel/sys/sem.c)与[官方实现](https://github.com/zephyrproject-rtos/zephyr/blob/main/kernel/sys/sem.c)。构建分派由[官方kernel/CMakeLists.txt](https://github.com/zephyrproject-rtos/zephyr/blob/main/kernel/CMakeLists.txt)、[userspace/CMakeLists.txt](https://github.com/zephyrproject-rtos/zephyr/blob/main/kernel/userspace/CMakeLists.txt)和[sys/CMakeLists.txt](https://github.com/zephyrproject-rtos/zephyr/blob/main/kernel/sys/CMakeLists.txt)核对。

官方源码摘要见[来源记录](../SOURCES.md)；仓库源码、滚动更新的main和latest网页不能自动视为同一版本。本批完成文档与源码核对，未构建或运行用户模式、并发及实板实验。
