# 第1章\_优化入口

原文：[Optimizations](https://docs.zephyrproject.org/latest/develop/optimizations/index.html)。读取日期：2026-10-12，`latest`。

本组指南说明如何优化 Zephyr 的性能、功耗与**存储占用（Footprint）**。存储占用指固件代码、数据及运行所需内存占用的空间；优化工具用于观察这些大小，而具体取舍取决于应用需求。

## 1.1\_本组官方指南

官方入口列出以下两篇文档：

1. [优化存储占用](P002_优化存储占用.md)：检查系统栈大小、未使用外设和调试选项。
2. [优化分析工具](P003_优化分析工具.md)：查看镜像内存占用、结构体布局、栈分析和构建仪表板。

> 译注：本页是官方导航页的完整翻译，不代表所有性能或功耗专题均已译完。电源管理另见[电源管理译文大纲](../power/大纲.md)。
