# 第7章\_随机数接口

原文：[官方页面](https://docs.zephyrproject.org/latest/doxygen/html/group__random__api.html)。读取日期：2026-10-14；保存的 latest 页面及 HTML 摘要见[来源记录](../SOURCES.md)。

## 7.1\_概述

随机数函数API（Random Function APIs）。原文标注：自1.0版本起提供（Since），接口版本（Version）为1.0.0。

```c
#include <zephyr/random/random.h>
```

## 7.2\_sys\_csrand\_get()

<a id="ga98f123f216b5df6e27eb980d6e5dec86"></a>
<a id="r_ga98f123f216b5df6e27eb980d6e5dec86"></a>

```c
int sys_csrand_get ( void * dst, size_t len )
```

```c
#include <zephyr/random/random.h>
```

用密码学安全随机数据（Cryptographically Secure Random Data）填充目标缓冲区。


**参数（Parameters）**

| 名称／方向 | 说明 |
| --- | --- |
| `[out] dst` | 要填充的目标缓冲区。 |
| `len` | 目标缓冲区大小。 |

**原文注意（Note）**：若所需随机值不要求密码学安全性，改用 [`sys_rand_get`](#gaf4f6792ac29c876d59ace1deae53bbd7)()。

**返回（Returns）**：成功返回 0；熵重新播种（Entropy Reseed）发生错误时返回 -EIO。

## 7.3\_sys\_rand16\_get()

<a id="ga27581a2b65faa6f1f3978ad6794300ba"></a>
<a id="r_ga27581a2b65faa6f1f3978ad6794300ba"></a>

```c
static inline uint16_t sys_rand16_get ( void )
```

```c
#include <zephyr/random/random.h>
```

返回一个应能通过一般随机性测试的16位随机值。


**原文注意（Note）**：返回的随机值不具备密码学安全性。

**返回（Returns）**：返回16位随机值。

## 7.7\_sys\_rand\_get()

<a id="gaf4f6792ac29c876d59ace1deae53bbd7"></a>
<a id="r_gaf4f6792ac29c876d59ace1deae53bbd7"></a>

```c
void sys_rand_get ( void * dst, size_t len )
```

```c
#include <zephyr/random/random.h>
```

用应能通过一般随机性测试的随机数据值填充目标缓冲区。


**参数（Parameters）**

| 名称／方向 | 说明 |
| --- | --- |
| `[out] dst` | 用于填入随机数据的目标缓冲区。 |
| `len` | 目标缓冲区大小。 |

**原文注意（Note）**：返回的随机值不被视为密码学安全随机数。
