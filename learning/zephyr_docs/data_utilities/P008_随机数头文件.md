# 第8章\_随机数头文件

原文：[官方页面](https://docs.zephyrproject.org/latest/doxygen/html/random_8h.html)。读取日期：2026-10-14；保存的 latest 页面及 HTML 摘要见[来源记录](../SOURCES.md)。

## 8.1\_概述

随机数生成器头文件（Random Number Generator Header File）。本文件声明内核随机数生成 API 的函数原型。通常，平台根据硬件能力启用适当的随机数来源；或者仅出于测试目的启用 TEST_RANDOM_GENERATOR 配置选项。

```c
#include <zephyr/types.h>
#include <stddef.h>
#include <zephyr/kernel.h>
#include <zephyr/syscalls/random.h>
```

[查看源码浏览译页](P009_随机数头文件源码.md)。
