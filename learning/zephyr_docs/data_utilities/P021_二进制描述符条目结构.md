## 21.3\_详细说明（Detailed Documentation）

<a id="a8cc383c8f7e11caff91912c8c2cc6b41"></a>

### `data`

```c
uint8_t bindesc_entry::data[]
```

条目的值（Value）。

该值为整数或字符串。

> 译注（源码核对）：原文只提整数和字符串；`BINDESC_TYPE_BYTES` 与定义宏还支持字节数组。`data[]` 是柔性数组成员（Flexible Array Member），不计入 `sizeof(struct bindesc_entry)`；应结合 `tag` 的类型和 `len` 解释内容。

<a id="ad756a440a8dfa9d396258707a1f681e4"></a>

### `len`

```c
uint16_t bindesc_entry::len
```

描述符数据的长度。

### `tag`

```c
uint16_t bindesc_entry::tag
```
