# 第6章\_随机数生成

原文：[官方页面](https://docs.zephyrproject.org/latest/services/crypto/random/index.html)。读取日期：2026-10-14；保存的 latest 页面及 HTML 摘要见[来源记录](../SOURCES.md)。

## 6.1\_概述（Overview）

随机数 API 子系统提供密码学安全与非密码学安全两类随机数生成接口（Random Number Generation APIs）。应根据随机数的密码学要求选择接口；只需非密码学用途时，非密码学接口生成随机值的速度会快得多。

- 使用 [`sys_rand_get()`](P007_随机数接口.md#gaf4f6792ac29c876d59ace1deae53bbd7) 及相关函数处理随机延迟、数据打乱或一般随机化。它们速度较快，但不适合安全用途。
- 使用 [`sys_csrand_get()`](P007_随机数接口.md#ga98f123f216b5df6e27eb980d6e5dec86) 处理密码学用途，例如生成加密密钥、一次性数（Nonce）、初始化向量（Initialization Vector，IV），或其他必须使攻击者无法预测的数据。

**原文警告（Warning）**：绝不能把非密码学随机函数 [`sys_rand_get()`](P007_随机数接口.md#gaf4f6792ac29c876d59ace1deae53bbd7)、[`sys_rand8_get()`](P007_随机数接口.md#ga810eaca8c5f71c9417d87f05c8fa4ebb)、[`sys_rand16_get()`](P007_随机数接口.md#ga27581a2b65faa6f1f3978ad6794300ba)、[`sys_rand32_get()`](P007_随机数接口.md#ga62cb24a6049b7aa9d03d66786e4a4db6)、[`sys_rand64_get()`](P007_随机数接口.md#ga26da47b7d5a76475b2fc528f5d6eced6) 用于安全敏感操作。它们不提供密码学安全的随机数。

## 6.2\_API用法（API Usage）

### 非密码学随机数（Non-Cryptographic Random Numbers）

以下函数提供非密码学安全的随机数：

| 函数 | 用途 |
| --- | --- |
| [`sys_rand_get()`](P007_随机数接口.md#gaf4f6792ac29c876d59ace1deae53bbd7) | 用随机字节填充缓冲区 |
| [`sys_rand8_get()`](P007_随机数接口.md#ga810eaca8c5f71c9417d87f05c8fa4ebb) | 取得一个8位随机值 |
| [`sys_rand16_get()`](P007_随机数接口.md#ga27581a2b65faa6f1f3978ad6794300ba) | 取得一个16位随机值 |
| [`sys_rand32_get()`](P007_随机数接口.md#ga62cb24a6049b7aa9d03d66786e4a4db6) | 取得一个32位随机值 |
| [`sys_rand64_get()`](P007_随机数接口.md#ga26da47b7d5a76475b2fc528f5d6eced6) | 取得一个64位随机值 |

用法示例：

```c
#include <zephyr/random/random.h>

void example_random_usage(void)
{
    uint8_t buffer[16];
    uint32_t random_value;

    /* Fill buffer with random bytes */
    sys_rand_get(buffer, sizeof(buffer));

    /* Get a single random 32-bit value */
    random_value = sys_rand32_get();
}
```

两处注释分别表示“用随机字节填充缓冲区”和“取得单个32位随机值”。

### 密码学安全随机数（Cryptographically Secure Random Numbers）

密码学用途使用 [`sys_csrand_get()`](P007_随机数接口.md#ga98f123f216b5df6e27eb980d6e5dec86)：

```c
#include <zephyr/random/random.h>

int generate_encryption_key(uint8_t *key, size_t key_len)
{
    int ret;

    ret = sys_csrand_get(key, key_len);
    if (ret != 0) {
        /* Handle error - entropy source may have failed */
        return ret;
    }

    return 0;
}
```

注释表示“处理错误：熵源（Entropy Source）可能发生故障”。

**原文注意（Note）**：[`sys_csrand_get()`](P007_随机数接口.md#ga98f123f216b5df6e27eb980d6e5dec86) 成功返回 `0`，熵源失败返回 `-EIO`。生成密码学材料时，始终检查返回值。

## 6.3\_Kconfig选项（Kconfig Options）

全部配置选项见官方 [`subsys/random/Kconfig`](https://github.com/zephyrproject-rtos/zephyr/blob/main/subsys/random/Kconfig)。

### 通用选项（General Options）

[`CONFIG_TEST_RANDOM_GENERATOR`](https://docs.zephyrproject.org/latest/kconfig.html#CONFIG_TEST_RANDOM_GENERATOR)：用于测试，允许使用非随机的数值生成器，也允许随机数 API 返回并非真正随机的值。

**原文警告（Warning）**：此选项仅供缺少硬件熵支持的平台测试使用。启用后生成的数值可预测，不适合任何安全敏感用途。

### 非密码学随机数生成器选择

[`CONFIG_ENTROPY_DEVICE_RANDOM_GENERATOR`](https://docs.zephyrproject.org/latest/kconfig.html#CONFIG_ENTROPY_DEVICE_RANDOM_GENERATOR) 直接使用硬件熵驱动生成随机数。它提供高质量随机数，但可能慢于伪随机方案。当硬件熵源的性能足以满足应用需求时选择此项。

[`CONFIG_XOSHIRO_RANDOM_GENERATOR`](https://docs.zephyrproject.org/latest/kconfig.html#CONFIG_XOSHIRO_RANDOM_GENERATOR) 使用 Xoshiro128++ 伪随机数生成器（Pseudo-random Number Generator，PRNG），以硬件熵源作为种子来源。这是一种快速、通用且具有128位状态的 PRNG；原文说明它通过了所有标准随机性测试。原文推荐大多数需要快速非密码学随机数的应用使用此项。

[`CONFIG_TIMER_RANDOM_GENERATOR`](https://docs.zephyrproject.org/latest/kconfig.html#CONFIG_TIMER_RANDOM_GENERATOR) 使用系统定时器生成伪随机数。这些数值可预测，仅供缺少硬件熵支持的平台测试使用。要求启用 `CONFIG_TEST_RANDOM_GENERATOR`。

### 密码学安全随机数生成器选择

Kconfig 选择组 `CSPRNG_GENERATOR_CHOICE` 选择密码学安全伪随机数生成器（Cryptographically Secure Pseudo-random Number Generator，CSPRNG）的来源。

若要在开发板或片上系统（System on Chip，SoC）配置文件中覆盖默认选择：

```kconfig
choice CSPRNG_GENERATOR_CHOICE
        default PSA_CSPRNG_GENERATOR
endchoice
```

可选生成器如下：

- [`CONFIG_HARDWARE_DEVICE_CS_GENERATOR`](https://docs.zephyrproject.org/latest/kconfig.html#CONFIG_HARDWARE_DEVICE_CS_GENERATOR)：直接使用硬件熵驱动作为密码学安全随机数来源。硬件随机数生成器已获密码学用途认证或验证时选择此项。
- [`CONFIG_PSA_CSPRNG_GENERATOR`](https://docs.zephyrproject.org/latest/kconfig.html#CONFIG_PSA_CSPRNG_GENERATOR)：启用使用 PSA Crypto API 的 CSPRNG。此实现使用底层 PSA Crypto 库的安全随机数生成能力，可在硬件熵源可用时使用它。PSA CSPRNG 提供适用于安全敏感应用的密码学安全随机数。译注：PSA 为平台安全架构（Platform Security Architecture），PSA Crypto 是其密码学接口。
- [`CONFIG_TEST_CSPRNG_GENERATOR`](https://docs.zephyrproject.org/latest/kconfig.html#CONFIG_TEST_CSPRNG_GENERATOR)：把 [`sys_csrand_get()`](P007_随机数接口.md#ga98f123f216b5df6e27eb980d6e5dec86) 调用转交给 [`sys_rand_get()`](P007_随机数接口.md#gaf4f6792ac29c876d59ace1deae53bbd7)，使缺少硬件熵支持的平台能够测试要求 CSPRNG 的库。要求启用 `CONFIG_TEST_RANDOM_GENERATOR`。

**原文警告（Warning）**：`CONFIG_TEST_CSPRNG_GENERATOR` 不提供密码学安全性，只能用于测试。

## 6.4\_设备树配置（Devicetree Configuration）

随机数子系统通过 chosen 节点的 `zephyr,entropy` 选择硬件熵设备：

```dts
/ {
    chosen {
        zephyr,entropy = &rng;
    };
};
```

如果平台有硬件随机数生成器，应确保开发板设备树正确指定这一选择。
