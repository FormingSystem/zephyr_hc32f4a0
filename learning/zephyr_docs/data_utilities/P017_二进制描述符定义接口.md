## 17.3\_详细说明（Detailed Documentation）

<a id="ga137cc1f8fcc0e36e71c8ea4b8c0e8885"></a>

### `BINDESC_BYTES_DEFINE`

```c
#define BINDESC_BYTES_DEFINE ( name, id, value )
```

```c
#include <zephyr/bindesc.h>
```

```c
__BINDESC_ENTRY_DEFINE(name) = {                                                        \
        .tag = BINDESC_TAG(BYTES, id),                                                  \
        .len = (uint16_t)sizeof((uint8_t [])__DEBRACKET value),                         \
        .data = __DEBRACKET value,                                                      \
};                                                                                      \
BUILD_ASSERT(sizeof((uint8_t [])__DEBRACKET value) <=                                   \
             CONFIG_BINDESC_DEFINE_MAX_DATA_SIZE,                                       \
             "Bindesc " STRINGIFY(name) " exceeded maximum size, consider reducing the" \
             " size or changing CONFIG_BINDESC_DEFINE_MAX_DATA_SIZE. ")
```

定义字节数组（bytes）类型的二进制描述符。

定义一个 `uint8_t` 数组，并将其注册到二进制描述符头部中。可以使用 `BINDESC_GET_BYTES` 访问所定义的数组。值应以数组字面量（Array Literal）给出，并用圆括号包围，例如：

```c
BINDESC_BYTES_DEFINE(name, id, ({1, 2, 3, 4}));
```

**参数（Parameters）**

| 名称／方向 | 说明 |
| --- | --- |
| `name` | 描述符名称。 |
| `id` | 描述符的唯一标识符（Unique ID）。 |
| `value` | 用作描述符数据的 `uint8_t` 数组。 |

**注意（Note）**：所定义的数组不是静态对象（static），因此其名称不得与可执行文件中的任何其他符号冲突。

<a id="ga1fbf08f04e66c250aecdd70045242a37"></a>

### `BINDESC_GET_BYTES`

```c
#define BINDESC_GET_BYTES ( name)
```

```c
#include <zephyr/bindesc.h>
```

```c
BINDESC_NAME(name).data
```

获取字节数组二进制描述符的值。

获取先前用 `BINDESC_BYTES_DEFINE` 定义的字符串二进制描述符的值。返回值可以按数组访问：

```c
for (size_t i = 0; i < BINDESC_GET_SIZE(name); i++)
    BINDESC_GET_BYTES(name)[i];
```

**参数（Parameters）**

| 名称／方向 | 说明 |
| --- | --- |
| `name` | 描述符名称。 |

> 译注（源码核对）：原说明中的“字符串”是原文笔误。宏实际返回由 `BINDESC_BYTES_DEFINE` 定义的字节数组数据；按 `BINDESC_GET_SIZE` 给出的长度访问，不按空字符判断结束。
