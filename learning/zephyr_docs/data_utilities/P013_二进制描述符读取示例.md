# 第13章\_二进制描述符读取示例

原文：[官方页面](https://docs.zephyrproject.org/latest/samples/subsys/bindesc/read_bindesc/README.html)。读取日期：2026-10-14；保存的 latest 页面及 HTML 摘要见[来源记录](../SOURCES.md)。

## 13.1\_概述

这是定义和读取二进制描述符的简单示例。

## 13.2\_构建与运行

按照以下步骤构建 `read_bindesc` 应用。主机终端位于已具备工具链与依赖模块的 Zephyr 源码根目录，把 `<board to use>` 整体替换为目标开发板名称：

```sh
west build -b <board to use> samples/subsys/bindesc/read_bindesc
```

译注：原文仅给出构建命令，没有声称已经烧录或运行。当前示例定义字符串、整数和字节描述符，演示内存映射闪存、RAM和Flash三种读取后端。配套配置启用三种后端及闪存接口；源码还依赖设备树中的 `zephyr,flash-controller`，不能仅凭“示例通用”就断言任何目标都可运行。

译注：源程序为了适配不同设备，会扫描映像起始附近寻找魔数；注释说明普通应用通常应使用已知偏移，并可用 `west bindesc get_offset` 从映像文件取得。示例RAM缓冲区为 `0x100` 字节，不能据此认定所有映像的描述符均能放入。移用代码时应检查打开、查找和闪存读取的返回值，并依据实际描述符大小安排缓冲区。
