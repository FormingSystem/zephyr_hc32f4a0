## 16.2\_主题（Topics）

```c
Binary Descriptor Definition
```

用于在固件映像（Firmware Image）中定义二进制描述符（Binary Descriptor）的宏。

相关声明：[Binary Descriptor Definition](P017_二进制描述符定义接口.md)。

<a id="r_bindesc_5Fread"></a>

```c
Binary Descriptor Reading
```

用于从固件映像中读取二进制描述符的函数。

相关声明：[Binary Descriptor Reading](P018_二进制描述符读取接口.md)。

## 16.4\_宏定义（Macros）

<a id="r_ga8e7d54173280f72eb5f031d752c19197"></a>

```c
#define BINDESC_MAGIC 0xb9863e5a7ea46046
```

用于识别固件映像内二进制描述符区段的魔数（Magic Number）。

<a id="r_ga674bcf8c1d881131b5e82d5dec48ee33"></a>

```c
#define BINDESC_ALIGNMENT 4
```

二进制描述符条目要求的内存对齐（Memory Alignment）。

<a id="r_ga3327af407c3d5a7c05e9fd5c3c53380a"></a>

```c
#define BINDESC_ENTRY_HEADER_SIZE (sizeof(struct bindesc_entry))
```

二进制描述符条目头部的大小。

相关声明：[bindesc_entry](P021_二进制描述符条目结构.md)。

## 16.5\_二进制描述符类型（Binary Descriptor Types）

<a id="r_gadac0fea8ab54ea428c533f509058b910"></a>

```c
#define BINDESC_TYPE_UINT 0x0
```

无符号整数（Unsigned Integer）数据。

<a id="r_ga68acc09b5e324134e5c83eeaa064fc41"></a>

```c
#define BINDESC_TYPE_STR 0x1
```

字符串（String）数据。

<a id="r_ga24e6723b552f65cc1f143bcb7f66f125"></a>

```c
#define BINDESC_TYPE_BYTES 0x2
```

字节数组（Byte Array）数据。

<a id="r_gac98ab7042b1b3f6654e910fa4d0c2d40"></a>

```c
#define BINDESC_TYPE_DESCRIPTORS_END 0xf
```

标记二进制描述符区段的结束。
