# 第12章\_二进制描述符定义示例

原文：[官方页面](https://docs.zephyrproject.org/latest/samples/subsys/bindesc/hello_bindesc/README.html)。读取日期：2026-10-14；保存的 latest 页面及 HTML 摘要见[来源记录](../SOURCES.md)。

## 12.1\_概述

这是定义和使用二进制描述符（Binary Descriptors）的简单示例。

## 12.2\_构建与运行

按以下步骤构建 `hello_bindesc` 应用：

译注：主机终端位于已准备好工具链与依赖模块的 Zephyr 源码根目录。`<board to use>` 是原文占位符，应整体替换为实际开发板名称；尖括号不是要保留的Shell语法。示例是官方已有的 `samples/subsys/bindesc/hello_bindesc`。

```sh
west build -b <board to use> samples/subsys/bindesc/hello_bindesc
```

要转储（Dump）映像中的全部描述符，执行：

```sh
west bindesc dump build/zephyr/zephyr.bin
```

注意：若构建不生成 `*.bin` 文件，例如为 `native_sim` 编译，也可转储 `zephyr.elf`。

译注：`dump` 在主机读取构建产物，并不烧录或运行固件。当前源程序既定义字符串、无符号整数、字节序列三种自定义描述符，也读取内核版本、应用版本、构建时间和编译器信息等内置描述符；这些内置对象由配套配置选择，不是任意构建都会自动包含。
