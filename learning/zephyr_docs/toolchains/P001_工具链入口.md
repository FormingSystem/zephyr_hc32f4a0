# 第1章\_工具链入口

原文：[Toolchains](https://docs.zephyrproject.org/latest/develop/toolchains/index.html)。读取日期：2026-10-12，`latest`。本页汇总如何配置用于 Zephyr 开发的工具链。

## 1.1\_工具链配置指南

- [Zephyr SDK](P002_ZephyrSDK.md)。
- [Arm Compiler 6](P007_ArmCompiler6.md)。
- [Arm Toolchain for Embedded（ATfE）](P008_Arm嵌入式工具链.md)。
- [Cadence Tensilica Xtensa C/C++ Compiler（XCC）](P012_Cadence_XCC工具链.md)。
- [DesignWare ARC MetaWare Development Toolkit（MWDT）](P013_ARC_MetaWare工具链.md)。
- [GNU Arm Embedded](P004_GNUArmEmbedded.md)。
- [Qualcomm Hexagon LLVM 工具链](P014_Hexagon_LLVM工具链.md)。
- [IAR Arm 工具链](P010_IARArm工具链.md)。
- [Intel oneAPI Toolkit](P015_Intel_oneAPI工具包.md)。
- [MPLAB XC32](P016_MPLAB_XC32工具链.md)。
- [主机工具链](P006_主机工具链.md)。
- [其他交叉编译器](P005_其他交叉编译器.md)。
- [自定义 CMake 工具链](P009_自定义CMake工具链.md)。
- [Embedded Linker（ELD）](P011_嵌入式链接器ELD.md)。

> 译注：不同工具链不是需要顺序安装的依赖。先依据目标架构、Zephyr 版本和工具链支持情况选择一条路线。环境变量的设置方式见[环境变量](P003_环境变量.md)。本页对尚未完成翻译的工具链保留官方英文入口。
