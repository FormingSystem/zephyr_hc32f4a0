# 第6章\_主机工具链

原文：[Host Toolchains](https://docs.zephyrproject.org/latest/develop/toolchains/host.html)。读取日期：2026-10-12，`latest`。

## 6.1\_使用操作系统提供的开发工具

在某些特定配置下，可以复用操作系统提供的原生开发工具。例如，在 Linux 主机上为非 MCU 的 x86 目标构建时，可能适用这种方式。

要使用主机 GCC，将环境变量 `ZEPHYR_TOOLCHAIN_VARIANT` 设为 `host/gnu`；要使用 Clang，则设为 `host/llvm`。设置方法见[环境变量](P003_环境变量.md)。

> 译注：这里的“主机”是运行构建工具的计算机。能够运行主机 GCC，不表示它可以直接生成 HC32 的 Cortex-M 固件；芯片固件仍需要匹配目标架构的工具链。
