# 内存域与应用分区参考大纲

本册翻译内存域（Memory Domain）接口及其头文件和结构、内存分区（Memory Partition）结构、应用内存分区宏以及应用分区和应用内存域头文件，共十份官方页面。三个源码浏览页保留全部可见代码、原始注释、许可证、符号提示及行号锚点，中文解释另列。

分区描述一段已有内存及其权限，内存域组织分区并关联线程。定义应用分区、由链接器安排全局变量、把分区加入域和将线程加入域是不同动作；本册按官方接口保留各自条件与返回值，不把声明宏等同于已经建立访问权限。

源码跟踪译注独立说明描述复制、有效分区数量、反初始化支持和链接符号等实现细节。源码与译文使用相对链接，仓库环境与实验资料保留在独立资料区。完整范围及待译状态见[全站进度](../PROGRESS.md)。
