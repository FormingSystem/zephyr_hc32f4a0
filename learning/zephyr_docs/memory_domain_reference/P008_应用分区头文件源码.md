## 8.4\_源码跟踪译注

> 译注——partitions.h只在CONFIG_USERSPACE与CONFIG_MBEDTLS同时满足时声明外部k_mbedtls_partition。extern声明本身不定义存储，不把分区加入当前线程的内存域，也不能据此断言Mbed TLS相关数据已经被授权。该页没有隐藏的额外配置步骤或硬件验证结果。

头文件定位：[include/zephyr/app_memory/partitions.h](../../../include/zephyr/app_memory/partitions.h)，关联实现／接口：[include/zephyr/app_memory/app_memdomain.h](../../../include/zephyr/app_memory/app_memdomain.h)；[官方原始头文件](https://github.com/zephyrproject-rtos/zephyr/blob/main/include/zephyr/app_memory/partitions.h)与[官方关联文件](https://github.com/zephyrproject-rtos/zephyr/blob/main/include/zephyr/app_memory/app_memdomain.h)的摘要见来源记录。去掉注释和展示空白后，本页代码与本次读取的原始头文件一致，不能推广到以后滚动更新的main或任意本地版本。
