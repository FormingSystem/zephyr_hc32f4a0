> 译注——阅读位置：从[本册大纲](大纲.md)进入内存域、内存分区与应用分区接口参考，再通过接口链接进入完整说明。源码跟踪译注与官方原文分开标示。

内存分区（Memory Partition）。

```c
#include <zephyr/app_memory/mem_domain.h>
```

<a id="details"></a>

内存分区是线性地址空间中具有特定访问策略的一段内存。起始地址和大小的对齐要求，可能因底层内存管理硬件能力而不同；任意选择的数值很可能无法使用。
