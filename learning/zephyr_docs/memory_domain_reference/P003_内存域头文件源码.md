## 3.4\_源码跟踪译注

> 译注——内存域（Memory Domain）描述用户线程可访问的内存区域，不等于进程地址空间或动态内存分配器。把线程加入域不分配RAM，也不自动授予内核对象权限；内存访问策略与对象权限是不同机制。监督模式线程的域成员关系仍会被子线程继承。

> 译注——当前实现添加分区时复制start、size和attr到域内部数组，而不是长期保存传入的分区描述指针。之后修改原描述结构不会自动更新域内副本；移除操作按起始地址和大小匹配分区，不按描述结构指针身份匹配。内存区本体的生命周期仍须覆盖线程使用期。

> 译注——配置中的CONFIG_MAX_DOMAIN_PARTITIONS规定结构数组容量，运行时还从架构取得max_partitions。实际可用槽位可能更少，不能仅按数组长度判断硬件映射资源充足。初始化或添加前仍必须满足不重叠、对齐、大小和权限约束，不能依赖所有配置都以相同运行时检查拒绝错误参数。

> 译注——当前通用代码拒绝零长度和地址加长度回绕的分区；CONFIG_EXECUTE_XOR_WRITE启用时会检查可写且可执行属性。该检查不能代替架构对齐或MPU粒度要求，也不是自动识别内核私有数据的扫描器；暴露哪些内容仍是调用者必须满足的约束。

> 译注——k_mem_domain_deinit仅在CONFIG_ARCH_MEM_DOMAIN_SUPPORTS_DEINIT支持时执行，否则返回-ENOTSUP；默认域不能反初始化，仍有关联线程时返回-EBUSY。它不会替调用者把线程自动迁移到默认域。架构反初始化失败在当前通用包装中映射为-ENOMEM。

> 译注——k_mem_domain_init原文提到“给定名称”，但函数实际参数只有域指针、分区数量和分区指针数组，没有名称字符串。正文按原文保留；不要据这句描述额外添加参数。重复初始化同一域的禁止约束仍需遵守。

> 译注——部分操作先更新域的软件描述再调用架构钩子，失败时不能笼统假定所有状态已经自动回滚。当前接口不是对多个线程和分区批量变更提供事务保证；需要按实际返回码和所选架构处理失败。
