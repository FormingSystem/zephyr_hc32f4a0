> 译注——源码核对：以下源码跟踪译注独立于官方正文，依据来源记录中保存摘要的官方main文件。仓库源码定位采用相对链接；未把源码对照视为目标板已启用用户模式或完成MPU／MMU隔离测试。

> 译注——源码核对：partitions.h只在CONFIG_USERSPACE与CONFIG_MBEDTLS同时满足时声明外部k_mbedtls_partition。extern声明本身不定义存储，不把分区加入当前线程的内存域，也不能据此断言Mbed TLS相关数据已经被授权。该页没有隐藏的额外配置步骤或硬件验证结果。
