# 第8章\_状态机上下文

原文：[官方页面](https://docs.zephyrproject.org/latest/doxygen/html/structsmf__ctx.html)。本次读取日期：2026-10-14；基线为保存的`latest`页面，HTML摘要见[来源记录](../SOURCES.md)。

## 8.1\_概述

定义状态机的当前上下文（Current Context）。

```c
#include <zephyr/smf.h>
```

## 8.2\_成员说明（Field Documentation）

<a id="a48736dbfad38f0b25e4ab2a36d2f482a"></a>
<a id="r_a48736dbfad38f0b25e4ab2a36d2f482a"></a>

### `current`

```c
const struct smf_state* smf_ctx::current
```

状态机正在执行的当前状态。

<a id="afb094c0e87d42ec7ca780a2859be7bf8"></a>
<a id="r_afb094c0e87d42ec7ca780a2859be7bf8"></a>

### `internal`

```c
uint32_t smf_ctx::internal
```

状态机将其转换为`struct internal_ctx`，用于跟踪状态机上下文。

<a id="a2cebcd02bfc6b36278c20fe8e0f95418"></a>
<a id="r_a2cebcd02bfc6b36278c20fe8e0f95418"></a>

### `previous`

```c
const struct smf_state* smf_ctx::previous
```

状态机先前执行的状态。

<a id="a1018c3dc6d7cc94ac2b64f95e5c053cd"></a>
<a id="r_a1018c3dc6d7cc94ac2b64f95e5c053cd"></a>

### `terminate_val`

```c
int32_t smf_ctx::terminate_val
```

此值由`set_terminate`函数设置。设为非零值后，当`run_state`函数返回该值时，应终止状态机。
