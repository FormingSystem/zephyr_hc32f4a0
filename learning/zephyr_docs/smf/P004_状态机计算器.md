# 第4章\_状态机计算器

原文：[官方页面](https://docs.zephyrproject.org/latest/samples/subsys/smf/smf_calculator/README.html)。本次读取日期：2026-10-14；基线为保存的`latest`页面，HTML摘要见[来源记录](../SOURCES.md)。

<a id="smf_calculator"></a>

<a id="overview"></a>

## 4.1\_概述（Overview）

本例创建一个基本桌面计算器（Desk Calculator），由使用状态机框架（State Machine Framework，SMF）编写的状态机驱动。实现见[官方GitHub源码](https://github.com/zephyrproject-rtos/zephyr/tree/main/samples/subsys/smf/smf_calculator)。

计算器的业务逻辑（Business Logic）基于Miro Samek所著《Practical UML Statecharts in C/C++》第2版图2.18。它使用三层层次状态图（Hierarchical Statechart），处理忽略前导零、不允许多个小数点等情况。

原状态图经过轻微修改：在`op_entered`状态，根据是否已有上一次计算结果，在屏幕上显示不同输出。

<a id="id1"></a>

![SMF计算器业务逻辑状态图（Statechart for the SMF Calculator Business Logic）](images/smf_calculator.svg)

图形界面（Graphical User Interface，GUI）使用LVGL按钮矩阵（Button Matrix）接收输入，使用文本标签（Text Label）显示输出，基于`samples/drivers/display`示例。每次调用[`smf_run_state()`](P005_状态机API参考.md#ga8399cfa9e793a7f188b4ed4fec9f4f90)之后，状态机都会更新输出文本标签。

[`CONFIG_LV_Z_VDB_SIZE`](https://docs.zephyrproject.org/latest/kconfig.html#CONFIG_LV_Z_VDB_SIZE)已减小到14%，以便在Disco L475 IOT01（B-L475E-IOT01A）等RAM受限的开发板上运行。

<a id="requirements"></a>

## 4.2\_要求（Requirements）

GUI应当适用于Zephyr支持的任何触摸屏（Touchscreen Display）。必须通过`west build`的`--shield`选项指定扩展板（Shield），例如`--shield adafruit_2_8_tft_touch_v2`。

基于Arduino接口的触摸屏扩展板包括：

- [Adafruit 2.8英寸TFT Touch Shield v2](https://docs.zephyrproject.org/latest/boards/shields/adafruit_2_8_tft_touch_v2/doc/index.html)。
- [Buydisplay 2.8英寸TFT Touch Shield，带Arduino适配器](https://docs.zephyrproject.org/latest/boards/shields/buydisplay_2_8_tft_touch_arduino/doc/index.html)。
- [Buydisplay 3.5英寸TFT Touch Shield，带Arduino适配器](https://docs.zephyrproject.org/latest/boards/shields/buydisplay_3_5_tft_touch_arduino/doc/index.html)。

本例也应适用于带内置触摸屏的STM32 Discovery套件，例如：

- [STM32F412G Discovery](https://docs.zephyrproject.org/latest/boards/st/stm32f412g_disco/doc/index.html)。
- [ST25DV Discovery，MB1283版本](https://docs.zephyrproject.org/latest/boards/st/st25dv_mb1283_disco/doc/index.html)。
- [STM32F7508-DK Discovery Kit](https://docs.zephyrproject.org/latest/boards/st/stm32f7508_dk/doc/index.html)。
- [STM32F769I Discovery](https://docs.zephyrproject.org/latest/boards/st/stm32f769i_disco/doc/index.html)。

这些设备的触摸屏已经内置，无须定义扩展板。

<a id="building-and-running"></a>

## 4.3\_构建与运行（Building and Running）

以下示例面向Disco L475 IOT01（B-L475E-IOT01A）开发板和Adafruit 2.8英寸TFT Touch Shield v2。

译注：命令在已配置Zephyr环境的Bash中执行，当前位置为Zephyr源码根目录。目标和选项保持官方原样。

```sh
west build -b disco_l475_iot1 --shield adafruit_2_8_tft_touch_v2 samples/subsys/smf/smf_calculator
```

为便于不使用硬件进行测试，本例也支持[`native_sim`目标](../native_reference/P004_Native_Simulator本机模拟器.md#native_sim)，可按如下方式构建：

```sh
west build -b native_sim samples/subsys/smf/smf_calculator
```

<a id="cli-control"></a>

## 4.4\_命令行控制（CLI Control）

除GUI外，也可以通过Shell控制计算器，说明同一个状态机可以接收多个来源的输入。

`key <key>`命令向状态机发送按键。数字键为`0`到`9`；`.`、`+`、`-`、`*`、`/`和`=`执行各自对应的功能；`C`表示取消（Cancel），`E`表示取消当前输入（Cancel Entry）。

在Disco L475 IOT01（B-L475E-IOT01A）配合Adafruit 2.8英寸TFT Touch Shield v2时，GUI更新耗时约为0.8秒。这是因为按下按钮矩阵中的按钮，会使整个矩阵区域失效并需要重绘，而不是只使所选按钮失效。使用18个独立按钮代替单个矩阵可以加快更新，但当前方式已足以演示。
