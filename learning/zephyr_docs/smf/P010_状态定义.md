# 第10章\_状态定义

原文：[官方页面](https://docs.zephyrproject.org/latest/doxygen/html/structsmf__state.html)。本次读取日期：2026-10-14；基线为保存的`latest`页面，HTML摘要见[来源记录](../SOURCES.md)。

## 10.1\_概述

可用于多个状态机的通用状态（General State）。

```c
#include <zephyr/smf.h>
```

## 10.2\_成员说明（Field Documentation）

<a id="a742fe438b7b5b014d23bde210a512dee"></a>
<a id="r_a742fe438b7b5b014d23bde210a512dee"></a>

### `entry`

```c
const state_method smf_state::entry
```

进入此状态时执行的可选方法（Optional Method）。

<a id="a0661b4257b2ff7c508aeef9822b90a2f"></a>
<a id="r_a0661b4257b2ff7c508aeef9822b90a2f"></a>

### `exit`

```c
const state_method smf_state::exit
```

退出此状态时执行的可选方法（Optional Method）。

> 译注：原文将“exits”误写为“exists”。结合成员名与[指南](P001_状态机框架.md)的退出动作说明，此处译为“退出状态时”。

<a id="a94adbcd4e1a8bce8f3b30082874f1911"></a>
<a id="r_a94adbcd4e1a8bce8f3b30082874f1911"></a>

### `run`

```c
const state_execution smf_state::run
```

在状态机循环（State Machine Loop）期间反复执行的可选方法。
