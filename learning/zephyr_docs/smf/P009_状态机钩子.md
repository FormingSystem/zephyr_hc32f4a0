# 第9章\_状态机钩子

原文：[官方页面](https://docs.zephyrproject.org/latest/doxygen/html/structsmf__hooks.html)。本次读取日期：2026-10-14；基线为保存的`latest`页面，HTML摘要见[来源记录](../SOURCES.md)。

## 9.1\_概述

可选观测钩子（Instrumentation Hooks）的集合。

```c
#include <zephyr/smf.h>
```

任意成员都可以设为`NULL`，以跳过对应通知（Notification）。

## 9.2\_成员说明（Field Documentation）

<a id="ab9347618aeb69ec59fd125b71d041a5f"></a>
<a id="r_ab9347618aeb69ec59fd125b71d041a5f"></a>

### `on_action`

```c
smf_action_hook smf_hooks::on_action
```

在进入／运行／退出动作时调用的钩子（Action Hook）。

<a id="a1c58ad5a42077f5680f426bdc59cafb0"></a>
<a id="r_a1c58ad5a42077f5680f426bdc59cafb0"></a>

### `on_error`

```c
smf_error_hook smf_hooks::on_error
```

发生错误时调用的钩子（Error Hook）。

<a id="aadb8c7db3ee14a07dc64b25a98f57879"></a>
<a id="r_aadb8c7db3ee14a07dc64b25a98f57879"></a>

### `on_transition`

```c
smf_transition_hook smf_hooks::on_transition
```

状态转换时调用的钩子（Transition Hook）。
