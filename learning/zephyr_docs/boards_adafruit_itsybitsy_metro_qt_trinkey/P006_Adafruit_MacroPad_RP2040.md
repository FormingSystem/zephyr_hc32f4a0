## Adafruit MacroPad RP2040

<a id="overview"></a>

### 概述（Overview）

Adafruit MacroPad RP2040是一款采用Raspberry Pi RP2040微控制器（Microcontroller）的3 × 4机械键盘开发板。它包含12个机械按键开关，每个按键配有独立的RGB NeoPixel，还带有可按压的旋转编码器（Rotary Encoder）、128 × 64 OLED显示屏，以及用于声音反馈的小型扬声器。

<a id="hardware"></a>

### 硬件（Hardware）


- 双核Cortex-M0+，最高运行频率133 MHz
- 264 KB静态随机存储器（SRAM）
- 8 MB四线SPI闪存（QSPI Flash）
- 12个机械按键开关（Mechanical Key Switches），兼容Cherry MX
- 12个RGB NeoPixel LED，每个按键1个
- 128 × 64单色OLED显示屏，采用SH1106
- 带按键的旋转编码器（Rotary Encoder with Push Button）
- 带D类放大器（Class D Amplifier）的小型扬声器
- STEMMA QT / Qwiic I2C接口
- USB Type-C接口
- 复位按键（Reset Button）
- 4个M3安装孔（Mounting Holes）

<a id="building-and-flashing"></a>

### 构建与烧录（Building and Flashing）

MacroPad RP2040内置UF2引导加载程序（Bootloader）。按住旋转编码器按键（BOOT），保持按下的同时按一下并松开复位按键，即可进入引导加载程序；主机上应出现名为`RPI-RP2`的存储盘。

下面演示如何使用UF2构建和烧录[闪灯（Blinky）](../getting_started/P004_LED闪烁示例.md#blinky)示例应用。

```text
# From the root of the zephyr repository
west build -b adafruit_macropad_rp2040 samples/basic/blinky
west flash --runner uf2
```
