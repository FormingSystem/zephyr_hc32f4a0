## 概述（Overview）

<a id="id3"></a>

[Adafruit Trinkey QT2040](https://learn.adafruit.com/adafruit-trinkey-qt2040)[注1](#id2)开发板采用Raspberry Pi Ltd.的RP2040微控制器（Microcontroller），提供便于连接传感器的STEMMA QT接口及USB Type-A接口。开发板轮廓与许多Adafruit STEMMA QT扩展板（Shields）相似。

<a id="hardware"></a>

## 硬件（Hardware）


- Raspberry Pi RP2040微控制器（Microcontroller），最高频率133 MHz
- 双ARM Cortex-M0+内核
- 264 kByte静态随机存储器（SRAM）
- 8 Mbyte四线SPI闪存（QSPI Flash）
- USB Type-A接口
- 复位和启动按键（Reset / Boot Buttons）
- RGB发光二极管（LED，NeoPixel）
- STEMMA QT I2C接口

<a id="default-zephyr-peripheral-mapping"></a>

### Zephyr默认外设映射（Default Peripheral Mapping）


- 启动／用户按键（Boot/User Button）：GPIO12
- RGB LED：GPIO27
- `I2C0_SDA : GPIO16`
- `I2C0_SCL : GPIO17`

注意，开发板没有引出串口RX或TX引脚，默认使用USB输出终端信息。

启动／用户按键（Boot/User Button）会通过二极管拉低QSPI片选线（Chip-select Line），在上电时进入内置USB引导加载程序（Bootloader）。设备树文件为该按键启用了片内上拉电阻（Pull-up Resistor），使它可以在运行期间使用，例如[输入事件转储（Input Dump）](../interaction/P014_输入事件转储示例.md#input-dump)或[按键（Button）](../basic_samples/P003_按钮输入.md#button)示例。不过，这些示例可能产生大量中断，可靠性有限。可以通过PCB背面的TP4测试点增加更强的外部上拉，例如用10 kΩ电阻连接到+3.3 V，来解决此问题。

Adafruit Trinkey QT2040开发板未引出SWDIO和SWCLK引脚，因此必须通过USB端口编程。按住BOOT按键，再按RST按键，设备便会显示为USB大容量存储设备（USB Mass Storage Unit）。构建应用后会生成`build/zephyr/zephyr.uf2`文件，将该文件拖放到USB存储设备中，即可重新编程开发板。

有关RP2040开发板编程的更多信息，请参阅编程与调试（[Programming and Debugging](https://docs.zephyrproject.org/latest/boards/raspberrypi/rpi_pico/doc/index.html#rpi-pico-programming-and-debugging)）。

<a id="flashing"></a>

### 烧录（Flashing）

使用以下命令构建并烧录LED[灯带（LED Strip）](../hardware/P191_LED灯带示例.md#led-strip)应用，使板载RGB LED以不同颜色闪烁：

```text
# From the root of the zephyr repository
west build -b adafruit_trinkey_qt2040 samples/drivers/led/led_strip
west flash
```

也可以尝试[哲学家就餐（Dining Philosophers）](../basic_samples/P030_哲学家就餐示例.md#dining-philosophers)示例，验证USB控制台输出。像[Hello World](../getting_started/P005_HelloWorld示例.md#hello_world)这样只在启动时打印文字的示例不便使用，因为等到连接上新建的USB控制台端点（Endpoint）时，文字已经打印完毕。

可以方便地通过STEMMA QT I2C接口连接传感器扩展板（Shield），例如`adafruit_lis3dh`。运行[通用三轴加速度计轮询（Generic 3-Axis Accelerometer Polling）](../sensors/P009_三轴加速度计轮询示例.md#accel_polling)示例：

```text
# From the root of the zephyr repository
west build -b adafruit_trinkey_qt2040 --shield adafruit_lis3dh samples/sensor/accel_polling/
west flash
```

或者运行[传感器Shell（Sensor Shell）](../sensors/P025_传感器Shell示例.md#sensor_shell)示例：

```text
# From the root of the zephyr repository
west build -b adafruit_trinkey_qt2040 --shield adafruit_lis3dh samples/sensor/sensor_shell/
west flash
```

通过Shell读取加速度计数值：

```text
uart:~$ sensor get lis3dh@18
channel type=0(accel_x) index=0 shift=4 num_samples=1 value=22974328296ns (0.000000)
channel type=1(accel_y) index=0 shift=4 num_samples=1 value=22974328296ns (-0.114912)
channel type=2(accel_z) index=0 shift=4 num_samples=1 value=22974328296ns (9.882431)
channel type=3(accel_xyz) index=0 shift=4 num_samples=1 value=22974328296ns, (0.000000, -0.114912, 9.882431)
```
