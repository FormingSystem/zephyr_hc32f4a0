# 第4章\_集成电路间音频总线（I2S）

原文：[官方页面](https://docs.zephyrproject.org/latest/doxygen/html/group__i2s__interface.html)。读取日期：2026-10-17；来源摘要见[来源记录](../SOURCES.md)。

集成电路间音频（Inter-IC Sound，I2S）控制器接口。

<a id="details"></a>

芯片间音频（Inter-IC Sound，I2S）控制器接口。自（Since）1.9 起提供，版本（Version）1.0.0。I2S API 支持标准 I2S 接口，也支持常见的非标准扩展，例如 PCM 短／长帧同步（Short/Long Frame Sync）、左／右对齐数据格式（Left/Right Justified Data Format）。

| `I2S_TRIGGER_STOP` | 停止发送／接收数据。在当前内存块结束时停止发送／接收数据。此触发操作（Trigger）仅可在 `RUNNING` 状态使用，首先将接口状态改为 `STOPPING`。当前 TX／RX 块发送／接收完毕后，状态改为 `READY`。随后执行 `START` 触发操作将从停止的位置继续发送／接收。 |
| `I2S_TRIGGER_DRAIN` | 排空发送队列（Transmit Queue）。发送队列中的全部数据发送完成后停止发送。若此触发操作作用于 RX 队列，则效果与 `I2S_TRIGGER_STOP` 相同。此操作仅可在 `RUNNING` 状态使用，首先将接口状态改为 `STOPPING`；所有 TX 块发送完毕后，状态改为 `READY`。 |
| `I2S_TRIGGER_DROP` | 丢弃发送／接收队列（Transmit/Receive Queue）。立即停止发送／接收，并丢弃相应队列中的内容。此触发操作可用于除 `NOT_READY` 以外的任何状态，并将接口状态改为 `READY`。 |
| `I2S_TRIGGER_PREPARE` | 发生欠载／溢出（Underrun/Overrun）错误后，准备队列。此触发操作仅可在 `ERROR` 状态使用，并将接口状态改为 `READY`。 |

<a id="ga5c8ca0bf6b394170ffbe031de8e37c28"></a>

### `i2s_buf_read()`

```c
int i2s_buf_read ( const struct device * dev, void * buf, size_t * size )
```

```c
#include <zephyr/drivers/i2s.h>
```

将接收队列（RX Queue）的数据读入所提供的缓冲区。

I2S 接口收到的数据保存在 RX 队列中，该队列由此函数从 `rx_mem_slab`（由 `i2s_configure` 定义）预先分配的内存块组成。调用此函数会从队列移除一个块，将其复制到提供的缓冲区，然后释放该块。

提供的缓冲区必须足以容纳一个完整内存块的数据；该通道的内存块大小由 `i2s_configure()` 配置。

除此之外，此函数等价于 `i2s_read()`。

**参数（Parameters）**

| 名称／方向 | 说明 |
| --- | --- |
| `dev` | 指向驱动实例的设备结构（Device Structure）。 |
| `buf` | 存放所读数据的目标缓冲区，其大小不得小于 RX 通道所配置的内存块大小。 |
| `size` | 指向存储已读字节数的变量的指针。 |

**返回值（Return Values）**

| 名称／方向 | 说明 |
| --- | --- |
| `0` | 成功时返回。 |
| `-EIO` | 接口处于 `NOT_READY` 或 `ERROR` 状态，且 RX 队列中已没有数据块。 |
| `-EBUSY` | 未等待便返回。 |
| `-EAGAIN` | 等待时间已到，发生超时。 |

<a id="ga98cbfe351a8dd5db361f4667959d0b58"></a>

### `i2s_buf_write()`

```c
int i2s_buf_write ( const struct device * dev, void * buf, size_t size )
```

```c
#include <zephyr/drivers/i2s.h>
```

将所提供缓冲区中的数据写入发送队列（TX Queue）。

此函数从 I2S 通道 TX 队列获取一个内存块，并将提供的数据缓冲区复制到其中。除此之外，它等价于 `i2s_write()`。

`i2s_config` 配置的超时分别独立用于获取内存块和将其加入队列，因此最坏情况下，此调用可能阻塞两个超时周期。

**参数（Parameters）**

| 名称／方向 | 说明 |
| --- | --- |
| `dev` | 指向驱动实例的设备结构（Device Structure）。 |
| `buf` | 指向包含待发送数据的缓冲区的指针。 |
| `size` | 要写入的字节数。此值必须小于或等于通道所配置的 TX 内存块大小。 |

**返回值（Return Values）**

| 名称／方向 | 说明 |
| --- | --- |
| `0` | 成功时返回。 |
| `-EIO` | 接口不处于 `READY` 或 `RUNNING` 状态。 |
| `-EBUSY` | 未等待便返回。 |
| `-EAGAIN` | 等待时间已到，发生超时。 |
| `-ENOMEM` | TX 内存块池队列（TX Slab Queue）中没有可用内存。 |
| `-EINVAL` | 大小参数超过 TX 队列内存块的大小。 |

### `i2s_configure()`

```c
int i2s_configure ( const struct device * dev, enum i2s_dir dir, const struct i2s_config * cfg )
```

```c
#include <zephyr/drivers/i2s.h>
```

配置主机 I2S 控制器（Host I2S Controller）的运行方式。

`dir` 参数指定使用 `cfg` 参数提供的数据来配置发送（TX）方向还是接收（RX）方向。

| 名称／方向 | 说明 |

<a id="ga7f23b7959280e1c4075a4305c3edd655"></a>

### `i2s_read()`

```c
int i2s_read ( const struct device * dev, void ** mem_block, size_t * size )
```

声明属性：`inline`、`static`。

```c
#include <zephyr/drivers/i2s.h>
```

从接收队列（RX Queue）读取数据。

I2S 接口收到的数据保存在 RX 队列中，该队列由此函数从 `rx_mem_slab`（由 `i2s_configure` 定义）预先分配的内存块组成。RX 内存块的所有权（Ownership）移交给用户应用，应用必须将其释放。

每次读取一个内存块大小的数据。如果接口处于 `READY` 状态，读取的字节数可能更少。

RX 队列没有数据时，函数将阻塞，等待下一个 RX 内存块填满。此操作可按 `i2s_configure` 定义的超时返回。超时值设为 `K_NO_WAIT` 时，函数不阻塞。

除 `NOT_READY` 以外的任何状态均可读取 RX 队列。接口处于 `ERROR` 状态时，仍可读取 RX 队列中保存的所有有效数据；读完后，函数将返回 `-EIO` 错误。

**参数（Parameters）**

| 名称／方向 | 说明 |
| --- | --- |
| `dev` | 指向驱动实例的设备结构（Device Structure）。 |
| `mem_block` | 指向包含已接收数据的 RX 内存块的指针。 |
| `size` | 指向存储已读字节数的变量的指针。 |

**返回值（Return Values）**

| 名称／方向 | 说明 |
| --- | --- |
| `0` | 成功时返回。 |
| `-EIO` | 接口处于 `NOT_READY` 或 `ERROR` 状态，且 RX 队列中已没有数据块。 |
| `-EBUSY` | 未等待便返回。 |
| `-EAGAIN` | 等待时间已到，发生超时。 |

### `i2s_write()`

```c
int i2s_write ( const struct device * dev, void * mem_block, size_t size )
```

声明属性：`inline`、`static`。

```c
#include <zephyr/drivers/i2s.h>
```

向发送队列（TX Queue）写入数据。

I2S 接口要发送的数据先保存在 TX 队列中。TX 队列由用户从 `tx_mem_slab`（由 `i2s_configure` 定义）预先分配的内存块组成。此函数取得内存块的所有权（Ownership），并在全部数据发送完毕后释放它。

TX 队列没有空闲位置时，函数将阻塞，等待下一个 TX 内存块发送完毕并从队列移除。此操作可按 `i2s_configure` 定义的超时返回。超时值设为 `K_NO_WAIT` 时，函数不阻塞。

只有接口处于 `READY` 或 `RUNNING` 状态时，才能写入 TX 队列。

**参数（Parameters）**

| 名称／方向 | 说明 |
| --- | --- |
| `dev` | 指向驱动实例的设备结构（Device Structure）。 |
| `mem_block` | 指向包含待发送数据的 TX 内存块的指针。 |
| `size` | 要写入的字节数。此值必须小于或等于内存块大小。 |

**返回值（Return Values）**

| 名称／方向 | 说明 |
| --- | --- |
| `0` | 成功时返回。 |
| `-EIO` | 接口不处于 `READY` 或 `RUNNING` 状态。 |
| `-EBUSY` | 未等待便返回。 |
| `-EAGAIN` | 等待时间已到，发生超时。 |
