# 日志输出与格式化参考大纲

本册翻译日志输出API、输出头文件参考和源码、输出对象及控制块，以及自定义与字典输出头文件参考和源码，共九份官方页面。原始声明、宏展开、参数、返回值和示例完整保留。

格式化器负责生成文本、MIPI Sys-T或字典二进制数据，再经输出函数处理。源码译注区分格式编号与格式化标志，说明回调消费字节数、缓冲区刷新、指针生命周期、时间戳比例以及自定义格式示例中的类型问题。

字典输出字段的独立类型页面仍单独跟踪。后端契约见[日志后端接口参考](../log_backend_reference/大纲.md)，完整覆盖状态见[全站进度](../PROGRESS.md)。
