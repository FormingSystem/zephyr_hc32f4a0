## 6.2\_详细说明（Detailed Documentation）

<a id="a92eda6f74e14725a875eaece6169987a"></a>

### `log_timestamp_format_func_t`

```c
typedef int(* log_timestamp_format_func_t) (const struct log_output *output, const log_timestamp_t timestamp, const log_timestamp_printer_t printer)
```

在LOG_OUTPUT_FORMAT_CUSTOM_TIMESTAMP条件下对时间戳应用自定义格式的函数原型。

函数示例：

原始示例（Example）：

```c
int custom_timestamp_formatter(const struct log_output* output,
                               const log_timestamp_t timestamp,
                               const log_timestamp_printer_t printer) {
    return printer(output, "%d ", timestamp);
}
```

**参数（Parameters）**

| 名称／方向 | 说明 |
| --- | --- |
| `output` | 要写入的日志输出实例。 |
| `timestamp` | 要格式化的消息时间戳。 |
| `printer` | 格式化时间戳时使用的打印函数。 |

<a id="a40a92ad6ae0991cbb0f0af45681ae35e"></a>

### `log_timestamp_printer_t`

```c
typedef int(* log_timestamp_printer_t) (const struct log_output *output, const char *fmt,...)
```

将给定时间戳打印到指定日志输出实例的打印函数原型。

使用示例：

原始示例（Example）：

```c
log_timestamp_printer_t *printer = ...;
printer(log_instance, "%02u:%02u", hours, minutes);
```

**参数（Parameters）**

| 名称／方向 | 说明 |
| --- | --- |
| `output` | 要写入的日志输出实例。 |
| `fmt` | 格式字符串。 |

## 6.3\_源码定位与版本边界

源码定位：[include/zephyr/logging/log_output_custom.h](../../../include/zephyr/logging/log_output_custom.h)、[subsys/logging/log_output_custom.c](../../../subsys/logging/log_output_custom.c)。官方源码摘要见[来源记录](../SOURCES.md)。

> 译注——源码核对：以下源码跟踪译注独立于官方正文，依据来源记录中保存摘要的官方main文件。本地源码与译文采用相对链接。

> 译注——源码核对：自定义消息格式化与自定义时间戳格式化各保存一个全局函数指针，不是每个输出实例独立保存。后一次set会替换同类回调；当前未安装消息回调时不输出，未安装时间戳回调时返回0。

> 译注——源码核对：原打印示例写作log_timestamp_printer_t *printer，但该typedef本身已经是函数指针，额外的星号会得到函数指针的指针。原示例完整保留；真正作为回调值调用时应按typedef使用log_timestamp_printer_t类型。

> 译注——源码核对：原时间戳示例使用%d格式，实际log_timestamp_t宽度取决于配置，使用时需匹配真实类型与打印格式。原示例是接口说明，不应把其占位符、类型与格式组合直接当作所有配置下可编译的完整程序。

本次验证范围为文档与源码对照，未构建固件、配置实板引脚或操作硬件。
