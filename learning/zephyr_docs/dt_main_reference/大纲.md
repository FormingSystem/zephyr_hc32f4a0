# 设备树主头文件参考大纲

本册完整翻译设备树（Devicetree）主头文件的参考页与源码浏览页。参考页保留286项宏声明、摘要及对应专题链接；源码页保留全部可见代码，并对内部注释、20种属性后缀和包含文件提示提供中文对照。

主头文件由Zephyr维护，当前应用的设备树生成头文件由构建流程产生，两者职责不同。阅读时先确定所需对象是节点标识、属性值、地址还是中断号，再选择接口；实例、逻辑长度、回退与遍历规则见链接到的完整专题。源码跟踪译注明确原摘要较简略之处与后缀拼写差异。

原代码、标识符和许可证完整保留，所有仓库定位采用相对链接。完整范围见[全站进度](../PROGRESS.md)。
