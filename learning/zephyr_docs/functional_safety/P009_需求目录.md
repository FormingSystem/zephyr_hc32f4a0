# 第9章\_需求目录（Requirements Catalog）

原文：[官方页面](https://docs.zephyrproject.org/latest/safety/safety_requirements/requirements_catalog.html)。快照读取日期：2026-10-15；来源摘要见[来源记录](../SOURCES.md)。

Zephyr 在独立的 `reqmgmt` 仓库中使用 [StrictDoc](https://github.com/strictdoc-project/strictdoc) 维护需求。该仓库作为 west 项目拉取；当工作区中存在它时，需求会被导出并直接渲染到下方文档中。

> 译注——目录页完成范围：本页是需求目录入口，下面三个链接分别指向生成目录、软件需求和系统需求全文。这三个页面已有构建系统册中的独立译文，下方链接可直接阅读；它们在全站清单中独立计数，本入口不会重复增加需求全文的完成数量。外部 `reqmgmt` 仓库也不因本次翻译自动下载到读者工作区。

- [需求目录（Requirements Catalog）](../build_system/P006_需求目录.md)；[Zephyr 软件需求（Zephyr Software Requirements）](../build_system/P007_软件需求.md)；[Zephyr 系统需求（Zephyr System Requirements）](../build_system/P008_系统需求.md)。

对应官方文档源码：[doc/safety/safety_requirements/requirements_catalog.rst](https://raw.githubusercontent.com/zephyrproject-rtos/zephyr/main/doc/safety/safety_requirements/requirements_catalog.rst)。

> 译注——源码跟踪：本仓库[对应源码](../../../doc/safety/safety_requirements/requirements_catalog.rst)可用于对照，版本可能与网页不同。本批仅翻译和核对文档，未安装或运行需求工具、生成认证材料或连接设备。
