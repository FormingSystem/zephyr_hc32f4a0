# 第1章\_功能安全（Safety）

原文：[官方页面](https://docs.zephyrproject.org/latest/safety/index.html)。快照读取日期：2026-10-15；来源摘要见[来源记录](../SOURCES.md)。

这些文档说明 Zephyr 项目为处理安全问题所采用的流程、开发者指南和要求。

> 译注——术语边界：本册 Safety 主要指功能安全（Functional Safety），与信息安全（Security）的关注点不同。安全认证目标、阶段进度及待办事项均按官方页面快照翻译，不表示本仓库、任意开发板或所有 Zephyr 功能已经通过认证。
