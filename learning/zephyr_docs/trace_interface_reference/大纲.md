# CoreSight与STP跟踪接口参考大纲

本册完整翻译CoreSight接口目录、STM扩展激励端口（STMESP）底层接口和MIPI系统跟踪协议第2版（STPv2）解码器源码三份官方页面。底层接口保留完整声明、参数和返回值；源码保留全部可见代码、注释、符号提示与行号锚点。
