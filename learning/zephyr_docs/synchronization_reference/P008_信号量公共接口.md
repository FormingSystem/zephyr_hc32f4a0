## 8.4\_详细说明（Detailed Documentation）

<a id="ga018a8aa43e02e704deee7b6341502946"></a>

### `K_SEM_DEFINE`

```c
#define K_SEM_DEFINE ( name, initial_count, count_limit )
```

```c
#include <zephyr/kernel.h>
```

展开值（Value）：

```c
STRUCT_SECTION_ITERABLE(k_sem, name) =                                                     \
        Z_SEM_INITIALIZER(name, initial_count, count_limit);                               \
BUILD_ASSERT(((count_limit) != 0) &&                                                       \
             (((initial_count) < (count_limit)) || ((initial_count) == (count_limit))) &&  \
             ((count_limit) <= K_SEM_MAX_LIMIT));
```

静态定义并初始化信号量（Semaphore）。

在定义此信号量的模块之外，可通过以下声明访问它：

原始示例（Example）：

```c
extern struct k_sem <name>;
```

**参数（Parameters）**

| 名称／方向 | 说明 |
| --- | --- |
| `name` | 信号量的名称。 |
| `initial_count` | 信号量的初始计数。 |
| `count_limit` | 允许的最大信号量计数。 |

> 译注——源码核对：宏初始化计数和上限，并带编译期断言检查上限非零、初始计数不超过上限及上限不大于K_SEM_MAX_LIMIT。extern示例中的<name>须替换成实际标识符。

<a id="ga689359a77a0cebe737ef644c188f7e57"></a>

### `K_SEM_MAX_LIMIT`

```c
#define K_SEM_MAX_LIMIT UINT_MAX
```

```c
#include <zephyr/kernel.h>
```

信号量所允许的最大上限值。

用于没有显式最大上限、仅用于计数的信号量。

> 译注——源码核对：本次宏值为UINT_MAX。“没有显式最大上限”指业务不另设较小限制，不代表无界计数；达到该值后，give仍不会继续增加计数。

<a id="ga58843b581e170a1811fc38eecbfd01f3"></a>

### `k_sem_count_get()`

```c
unsigned int k_sem_count_get ( struct k_sem * sem)
```

```c
#include <zephyr/kernel.h>
```

读取信号量的计数。

此例程返回sem的当前计数。

**参数（Parameters）**

| 名称／方向 | 说明 |
| --- | --- |
| `sem` | 信号量的地址。 |

**返回（Returns）**：返回当前信号量计数。

> 译注——源码核对：当前内联实现读取sem->count。返回计数不预留资源，读取后其他线程或ISR可以改变它；“先检查count再take”不能替代直接检查take的返回值。

<a id="gab9be3cf1988af2cd6afdace52d497c84"></a>

### `k_sem_give()`

```c
void k_sem_give ( struct k_sem * sem)
```

声明属性：`isr-ok`。

```c
#include <zephyr/kernel.h>
```

给出信号量（Give）。

此例程给出sem，除非信号量已经达到允许的最大计数。

**参数（Parameters）**

| 名称／方向 | 说明 |
| --- | --- |
| `sem` | 信号量的地址。 |

> 译注——源码核对：当前实现优先唤醒一个阻塞在take上的线程；有这样的等待者时，不再额外递增可用计数。没有take等待者时才按上限增加计数并处理轮询通知。give返回void，不返回新计数或是否饱和。

<a id="gadcd0e6cfba3392fb887222eafe4c1845"></a>

### `k_sem_init()`

```c
int k_sem_init ( struct k_sem * sem, unsigned int initial_count, unsigned int limit )
```

```c
#include <zephyr/kernel.h>
```

初始化信号量。

此例程在信号量对象第一次使用前初始化它。

**参数（Parameters）**

| 名称／方向 | 说明 |
| --- | --- |
| `sem` | 信号量的地址。 |
| `initial_count` | 信号量的初始计数。 |
| `limit` | 允许的最大信号量计数。 |

**返回值（Return Values）**

| 名称／方向 | 说明 |
| --- | --- |
| `0` | 信号量创建成功。 |
| `-EINVAL` | 数值无效。 |

**参阅（See Also）**：参见K_SEM_MAX_LIMIT。

> 译注——源码核对：本次实现检查limit为零或initial_count大于limit的情况，并通过CHECKIF路径报告-EINVAL；参数类型为unsigned int。初始计数为零是合法的，计数上限为零则不是。

<a id="ga1bd12d8d8c1b9c6be9b665d0fefe5562"></a>

### `k_sem_reset()`

```c
void k_sem_reset ( struct k_sem * sem)
```

```c
#include <zephyr/kernel.h>
```

将信号量计数重置为零。

此例程将sem的计数设置为零。任何尚未完成的信号量获取操作都会被中止，并返回-EAGAIN。

**参数（Parameters）**

| 名称／方向 | 说明 |
| --- | --- |
| `sem` | 信号量的地址。 |

**说明（Note）**：重置不会唤醒信号量的轮询等待者（Poll Waiter）。它们继续等待，直到信号量变为可用或轮询操作超时。

> 译注——源码核对：当前实现以-EAGAIN唤醒所有take等待者并将count清零，保留原limit。它没有调用信号量的轮询事件通知函数，因此poll等待者仍等待可用事件或自身超时；reset不能作为唤醒所有poll调用者的取消操作。

<a id="gac71e2383c1920dddc45a561cacfef090"></a>

### `k_sem_take()`

```c
int k_sem_take ( struct k_sem * sem, k_timeout_t timeout )
```

声明属性：`isr-ok`。

```c
#include <zephyr/kernel.h>
```

获取信号量（Take）。

此例程获取sem。

**参数（Parameters）**

| 名称／方向 | 说明 |
| --- | --- |
| `sem` | 信号量的地址。 |
| `timeout` | 等待获取信号量的时长，或特殊值K_NO_WAIT、K_FOREVER之一。 |

**返回值（Return Values）**

| 名称／方向 | 说明 |
| --- | --- |
| `0` | 已取得信号量。 |
| `-EBUSY` | 未等待便返回。 |
| `-EAGAIN` | 等待时间已到，或者信号量在等待期间被重置。 |

**说明（Note）**：如果从ISR调用，timeout必须设置为K_NO_WAIT。

> 译注——源码核对：计数大于零时先减1并返回0；零计数且K_NO_WAIT时返回-EBUSY。阻塞等待者可以因超时或reset收到-EAGAIN，不能仅凭该错误码区分两种原因。ISR调用必须使用K_NO_WAIT。

## 8.5\_源码定位与版本边界

> 译注——阅读与源码边界：配合[信号量指南](../kernel/P010_信号量.md)阅读。计数与可用资源、阻塞take等待者、poll等待者是不同状态；give可以直接满足一个take等待者，reset不会通知poll等待者。信号量没有互斥量的拥有者语义，计数查询也不会预留一次成功获取。
