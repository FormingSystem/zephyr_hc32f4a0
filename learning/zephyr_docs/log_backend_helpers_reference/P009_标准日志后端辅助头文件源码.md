## 9.4\_源码跟踪译注

> 译注——get_flags按编译配置组合时间戳、级别、颜色、换行、线程和跳过来源等标志。这里的current指当前构建所启用的格式选项，不是逐后端运行时过滤级别，也不是查询硬件状态。

> 译注——当前log_backend_std_panic仅调用log_output_flush；后端仍需根据自身输出设备实现panic模式要求。辅助函数本身没有创建线程、改变过滤级别或保证外设已完成物理传输。

> 译注——log_backend_std_dropped把丢弃数量交给log_output_dropped_process输出说明；它不恢复被丢弃消息，也不是重新发送这些消息的队列。

头文件定位：[include/zephyr/logging/log_backend_std.h](../../../include/zephyr/logging/log_backend_std.h)，关联实现／接口：[include/zephyr/logging/log_backend_std.h](../../../include/zephyr/logging/log_backend_std.h)；[官方原始头文件](https://github.com/zephyrproject-rtos/zephyr/blob/main/include/zephyr/logging/log_backend_std.h)与[官方关联文件](https://github.com/zephyrproject-rtos/zephyr/blob/main/include/zephyr/logging/log_backend_std.h)的摘要见来源记录。去掉注释和展示空白后，本页代码与本次读取的原始头文件一致，不能推广到以后滚动更新的main或任意本地版本。
