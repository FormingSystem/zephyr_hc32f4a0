# ADSP与日志后端辅助参考大纲

本册翻译Intel ADSP HDA、mtrace后端与标准后端辅助工具的接口、头文件参考和源码，再加上多域后端辅助接口，共十份官方页面。ADSP内容来自Zephyr官方日志后端文档。

HDA与mtrace分别通过DMA流和SRAM缓冲区向主机提供日志，钩子的并发与通知契约分别保留。标准辅助函数组合格式标志、刷新缓冲并报告丢弃数量；多域辅助模块提供链路与后端之间的消息及控制回报接口。

源码跟踪译注独立标注。HDA仅核对本次取得的官方头文件，不补造实现行为；多域消息类型的独立页面仍分别跟踪。通用契约见[日志后端接口参考](../log_backend_reference/大纲.md)，完整覆盖状态见[全站进度](../PROGRESS.md)。
