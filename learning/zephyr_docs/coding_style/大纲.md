# 编码风格官方译文大纲

本册翻译官方 `contribute/style/` 下的八个页面，涵盖驱动、板级文件、构建配置和 API 注释的书写约定。各页保留完整官方示例，英文注释与提示文字另附中文解释；源码跟踪使用相对链接。风格检查命令仅作为原文示例保留，本批没有运行格式化器或改动工程源码。

1. [代码风格指南](P001_代码风格指南.md)：各语言入口、Checkpatch、clang-format、dts-linter 和编辑器集成。
2. [C语言编码风格](P002_C语言编码风格.md)：适用范围、缩进、行长、花括号、注释与命名。
3. [CMake编码风格](P003_CMake编码风格.md)：命令大小写、变量作用范围、引号、路径和条件逻辑。
4. [设备树编码风格](P004_设备树编码风格.md)：节点、标签、属性、数组换行和完整 DTS 示例。
5. [Kconfig编码风格](P005_Kconfig编码风格.md)：启用符号、配置符号、子树前缀与文件组织。
6. [命名规范](P006_命名规范.md)：C 语言公共符号的子系统前缀。
7. [Python编码风格](P007_Python编码风格.md)：PEP 8、Ruff、格式参数和旧文件排除规则。
8. [Doxygen注释规范](P008_Doxygen注释规范.md)：API 语义、分组、版本、参数、返回值、引用和驱动后端文档。

本册八页已完成，不代表整个贡献者指南或全站翻译完成。全站范围与待译页面见[进度清单](../PROGRESS.md)。
