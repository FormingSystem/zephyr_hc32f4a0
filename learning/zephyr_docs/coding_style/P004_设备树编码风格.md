# 第4章\_设备树编码风格

原文：[官方页面](https://docs.zephyrproject.org/latest/contribute/style/devicetree.html)。读取日期：2026-10-14；保存的 latest 页面及 HTML 摘要见[来源记录](../SOURCES.md)。

## 4.1\_设备树格式规则

设备树（Devicetree）源文件遵循以下规则：

- 使用制表符（tab）缩进，制表宽度为 8 个字符。
- 遵循设备树规范的约定和规则。Linux 内核的[设备树源文件（Devicetree Sources，DTS）编码风格](https://docs.kernel.org/devicetree/bindings/dts-coding-style.html)提出的建议，也是 Zephyr 优先采用的风格。
- 如果有助于阅读，可以在相关属性组之间插入一个空行，即两个换行符，将它们划分成“段落”。
- 节点名（node name）和属性名（property name）中的单词使用连字符 `-` 分隔。
- 节点标签（node label）中的单词使用下划线 `_` 分隔。
- 属性定义中的等号 `=` 两侧各保留一个空格。
- 不要在缩进回退的 `};` 前插入空行。
- 同一层级的节点之间插入一个空行。
- 将较长的属性值拆成多行时，第一个值应与左括号 `<` 或 `[` 放在同一行；右括号与分号 `>;` 或 `];` 应紧跟最后一个属性值，放在最后一行。

## 4.2\_示例（Examples）

> 译注——示例来源：官方 [`style-example.dts`](https://raw.githubusercontent.com/zephyrproject-rtos/zephyr/main/doc/contribute/style/style-example.dts)，本仓库[对应文件](../../../doc/contribute/style/style-example.dts)。原始声明为 `SPDX-FileCopyrightText: Copyright The Zephyr Project Contributors`、`SPDX-License-Identifier: Apache-2.0`。页面只展示该文件标记之后的示例正文，以下按原页保留。

```dts
/dts-v1/;

/ {
	/* Node labels use the "_" separator, but node names use "-". */
	psa_rng: psa-rng {
		compatible = "zephyr,psa-crypto-rng";
		status = "okay";
	};

	ramdisk0 {
		compatible = "zephyr,ram-disk";
		/* Property names use the "-" separator. */
		disk-name = "RAM";
		sector-size = <512>;
		sector-count = <128>;
	};

	periph0 {
		/* Wrap array values to conform with line lengths. Indent
		 * continuation so that values align.
		 */
		pinctrl-0 = <&periph0_siga_px0_default &periph0_sigb_py7_default
			     &periph0_sigc_pz1_default>;
		pinctrl-names = "default";
	};

	mipi-dbi {
		compatible = "zephyr,mipi-dbi-spi";

		lcd0: lcd@0 {
			compatible = "sitronix,st7735r";
			/* Split array values across multiple lines to help readability. */
			gamctrp1 = [10 0e 02 03
				    0e 07 02 07
				    0a 12 27 37
				    00 0d 0e 10];
			gamctrn1 = [10 0e 03 03
				    0f 06 02 08
				    0a 13 26 36
				    00 0d 0e 10];
		};
	};
};
```

> 译注——示例注释译文：节点标签用 `_` 分隔单词，节点名用 `-`；属性名用 `-` 分隔单词；数组值为满足行长要求而换行时，对续行缩进，使各值对齐；数组值也可以拆成多行，以提高可读性。上例中的标签、节点、属性、数值和制表符均保留原文。
