## 1.2\_风格检查工具（Style Tools）

### 1.2.1\_Checkpatch

Linux 内核的 `checkpatch` 工具采用 GPL 许可证，用于检查编码风格是否合规。

> 注意：该工具目前不能在 Windows 上运行。

工具位于 `scripts` 目录。要在提交时运行它，将 `$ZEPHYR_BASE/.git/hooks/pre-commit` 设置为可执行文件，并写入以下内容：

```sh
#!/bin/sh
set -e exec
exec git diff --cached | ${ZEPHYR_BASE}/scripts/checkpatch.pl -
```

也可以在推送（push）时检查，而不是在每次提交时检查。此时，将 `$ZEPHYR_BASE/.git/hooks/pre-push` 设置为可执行文件，并写入：

```sh
#!/bin/sh
remote="$1"
url="$2"

z40=0000000000000000000000000000000000000000

echo "Run push hook"

while read local_ref local_sha remote_ref remote_sha
do
    args="$remote $url $local_ref $local_sha $remote_ref $remote_sha"
    exec ${ZEPHYR_BASE}/scripts/series-push-hook.sh $args
done

exit 0
```

原文说明：若要覆盖 Checkpatch 的判断，即使存在问题也继续推送，可以在 `git push` 后添加 `–no-verify`。

> 译注：以上是官方 Git 钩子（hook）示例；`ZEPHYR_BASE` 指当前 Zephyr 源码根目录，由读者的实际工作区确定。原页面把选项开头显示成了长横线；Git 选项的实际拼写为 `--no-verify`。原脚本中的 `Run push hook` 表示“运行推送钩子”。这里保留官方说明，不将这些示例安装到本仓库，也不改变本仓库已有的提交和推送规则。

另一个选择是 [合规检查脚本 `check_compliance.py`](../contributing/P002_贡献指南.md#check-compliance-py)，它提供额外的风格检查和合规检查。

### 1.2.2\_clang-format

[clang-format 工具](https://clang.llvm.org/docs/ClangFormat.html)结合仓库提供的 `.clang-format` 文件，可以快速整理大量新增代码的格式。多数编辑器已集成该工具，也可以手动调用：

```sh
clang-format -i my_source_file.c
```

clang-format 属于 LLVM 项目，可从其[发行页面](https://github.com/llvm/llvm-project/releases)下载。Linux 发行版通常也提供对应的软件包。

如果格式化结果与[编码风格指南](#coding-style-guidelines)存在差异，以指南为准；存在歧义时由维护者决定。

### 1.2.3\_dts-linter

[dts-linter](https://www.npmjs.com/package/dts-linter)可以按照设备树风格指南快速格式化设备树文件。例如，仅格式化指定文件、生成补丁再应用：

```sh
npx --ignore-scripts --prefix ./scripts/ci dts-linter --format --file board.dts --file board_pinctrl.dtsi --patchFile diff.patch
git apply diff.patch
```

省略 `--file` 后，工具会处理调用目录下的所有文件。`--cwd` 用于指定基准目录，同时影响补丁中生成的相对路径。

也可以直接修改文件：

```sh
npx --ignore-scripts --prefix ./scripts/ci dts-linter --formatFixAll
```

### 1.2.4\_编辑器集成（Editor Integration）

VS Code 用户可从 [VS Code Marketplace](https://marketplace.visualstudio.com/items?itemName=KyleMicallefBonnici.dts-lsp) 或 [Open VSIX](https://open-vsx.org/extension/KyleMicallefBonnici/dts-lsp) 安装扩展。其他支持语言服务器协议（Language Server Protocol，LSP）的客户端可以使用 [devicetree-language-server](https://www.npmjs.com/package/devicetree-language-server)。

配置编辑器时，应遵循[设备树编码风格指南](P004_设备树编码风格.md)。

> 译注：本页命令与脚本均为官方原例。相对命令从 Zephyr 源码根目录解析；使用前应已有对应工具与依赖。`my_source_file.c`、`board.dts` 等是示例文件名，应替换为要处理的文件。代码格式化、应用补丁和安装扩展是不同操作，本批只翻译说明，没有执行它们。


对应官方文档源码：[doc/contribute/style/index.rst](https://raw.githubusercontent.com/zephyrproject-rtos/zephyr/main/doc/contribute/style/index.rst)。
