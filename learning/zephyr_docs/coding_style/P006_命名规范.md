# 第6章\_命名规范

原文：[官方页面](https://docs.zephyrproject.org/latest/contribute/style/naming.html)。读取日期：2026-10-14；保存的 latest 页面及 HTML 摘要见[来源记录](../SOURCES.md)。

## 6.1\_命名约定

每种编程语言和工具都有自己的命名约定。以下 C 语言约定适用于 C 源文件和头文件。

## 6.2\_C 语言：公共符号前缀（Public Symbol Prefixes）

所有新增的[公共应用程序编程接口（public Application Programming Interface，public API）](../getting_started/P006_术语表.md#term-public-API)都应使用前缀，标明接口所属的领域或子系统：

| 前缀 | 对应领域或子系统 |
| --- | --- |
| `k_` | 内核（kernel）。 |
| `sys_` | 系统范围的代码与功能（system-wide code and features）。 |
| `net_` | 网络（networking）。 |
| `bt_` | 蓝牙（Bluetooth）。 |
| `i2c_` | I2C 控制器子系统（I2C controller subsystem）。 |


对应官方文档源码：[doc/contribute/style/naming.rst](https://raw.githubusercontent.com/zephyrproject-rtos/zephyr/main/doc/contribute/style/naming.rst)。

本仓库的[对应源码](../../../doc/contribute/style/naming.rst)可用于跟踪，版本可能与网页不同；本批仅翻译和核对文档，没有执行固件构建、模拟运行或烧录。
