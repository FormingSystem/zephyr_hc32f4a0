## 7.3\_详细说明（Detailed Documentation）

<a id="ga5526336abc0394bd8d8c7541473ad4ef"></a>

### `sys_port_trace_syscall_enter`

```c
#define sys_port_trace_syscall_enter ( id, name, ... )
```

```c
#include <zephyr/tracing/tracing_syscall.h>
```

跟踪系统调用（Syscall）的入口。

**参数（Parameters）**

| 名称／方向 | 说明 |
| --- | --- |
| `id` | 系统调用标识（Syscall ID），定义于生成的syscall_list.h中 |
| `name` | 以标记（Token）形式提供的系统调用名称，例如k_thread_create |
| `...` | 传递给系统调用的其他参数 |

<a id="gaed9dc749bc6da68e4df2ba9cd098f863"></a>

### `sys_port_trace_syscall_exit`

```c
#define sys_port_trace_syscall_exit ( id, name, ... )
```

```c
#include <zephyr/tracing/tracing_syscall.h>
```

跟踪系统调用（Syscall）的出口。

**参数（Parameters）**

| 名称／方向 | 说明 |
| --- | --- |
| `id` | 系统调用标识（Syscall ID），定义于生成的syscall_list.h中 |
| `name` | 以标记（Token）形式提供的系统调用名称，例如k_thread_create |
| `...` | 传递给系统调用的其他参数；如果系统调用有返回值，该返回值是参数列表中的最后一项 |

## 7.4\_源码定位与版本边界

相对源码定位：[跟踪入口](../../../include/zephyr/tracing/tracing.h)、[钩子声明](../../../include/zephyr/tracing/tracing_hooks.h)、[包装宏](../../../include/zephyr/tracing/tracing_macros.h)、[系统调用跟踪](../../../include/zephyr/tracing/tracing_syscall.h)、[跟踪配置](../../../subsys/tracing/Kconfig)、[系统调用生成器](../../../scripts/build/gen_syscalls.py)、[信号量](../../../kernel/sem.c)、[互斥锁](../../../kernel/mutex.c)、[条件变量](../../../kernel/condvar.c)、[事件对象](../../../kernel/events.c)、[定时器](../../../kernel/timer.c)及[轮询](../../../kernel/poll.c)。官方源码摘要见[来源记录](../SOURCES.md)。

> 译注——源码核对：本页描述跟踪钩子（Tracing Hooks），实际同步、等待或定时操作仍由相应内核API完成。tracing_hooks.h通过#ifndef为未实现的钩子提供空宏；仅有声明不表示后端已输出事件。CONFIG_TRACING以及各对象或功能开关共同影响具体调用点，后端格式与输出方式也需分别配置。

> 译注——源码核对：钩子在原调用位置执行，可能处于中断、锁保护或调度敏感路径，不会自动转入独立线程。Enter、Blocking、Exit表示各自标记位置，不保证每条路径都有成对记录。timeout是接口参数，不能直接解释成实测阻塞时长；ret需按具体API解释。

> 译注——源码核对：系统调用（Syscall）的ID来自生成的syscall_list.h，不应假定跨构建保持不变；name是C标记（Token），不是预先转换好的字符串。exit的可变参数只在非void调用时追加返回值，void调用不能把最后一个业务参数误认作返回值。

> 译注——源码核对：gen_syscalls.py生成的跟踪宏包围API调用。内部包装会根据用户态陷入判断选择架构系统调用路径或直接调用z_impl实现，因此观察到该跟踪入口不证明必然发生特权级切换。生成器还排除notracing集合，宏受CONFIG_TRACING_SYSCALL和DISABLE_SYSCALL_TRACING控制。

> 译注——源码核对：系统调用钩子的后端选择由tracing_syscall.h单独处理，包含SystemView、CTF和测试后端分支，其他分支为空宏。参数是传递给钩子的值或指针，接口约定没有保证自动深拷贝指针所指数据；不能仅据通用跟踪配置推定这组钩子已经输出完整参数快照。

> 译注——源码核对：以上译注以来源记录中的官方源码摘要为界；仓库源码通过相对链接定位，读者可核对自己使用的版本。未配置采集设备或验证运行时事件时序。

本次验证范围为文档与源码对照，未构建固件、配置实板引脚或操作硬件。
