# 同步与系统调用跟踪接口大纲

本册完整翻译信号量、互斥锁、条件变量、事件对象、定时器、轮询和系统调用七组跟踪接口，共七份官方页面。跟踪钩子（Tracing Hooks）用于记录API入口、阻塞、出口和生命周期事件，具体记录行为由后端实现。

各页保留宏签名、摘要、完整参数说明与交叉引用。源码译注说明配置与后端、事件位置、返回值语义及原文和调用点的差异，区分返回码、事件位集合、唤醒线程数与到期次数，并说明缺少成对记录的实际分支。

本地源码使用相对链接，保留中英文术语和原始许可证；本册不加入作者机器的采集环境或实板步骤。完整范围见[全站进度](../PROGRESS.md)。
