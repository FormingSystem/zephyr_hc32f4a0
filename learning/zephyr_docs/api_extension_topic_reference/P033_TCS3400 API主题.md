### `sensor_attribute_tcs3400`

```c
enum sensor_attribute_tcs3400
```

```c
#include <zephyr/drivers/sensor/tcs3400.h>
```

TCS3400 的自定义传感器属性（Custom Sensor Attributes）。

**枚举值（Enumerators）**

| 名称／方向 | 说明 |
| --- | --- |
| `SENSOR_ATTR_TCS3400_INTEGRATION_CYCLES` | 红／绿／蓝／透明光积分周期数（RGBC Integration Cycles）。`sensor_value.val1` 应介于 1 和 256 之间。 |
