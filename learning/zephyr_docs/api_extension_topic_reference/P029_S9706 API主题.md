### `sensor_attribute_s9706`

```c
enum sensor_attribute_s9706
```

```c
#include <zephyr/drivers/sensor/s9706.h>
```

S9706 的自定义传感器属性（Custom Sensor Attributes）。

**枚举值（Enumerators）**

| 名称／方向 | 说明 |
| --- | --- |
| `SENSOR_ATTR_S9706_CLOCK` | 读出传感器数值时的时钟频率（Clock Speed），单位为赫兹（Hz）。 |
| `SENSOR_ATTR_S9706_INTEGRATION_TIME` | 积分时间（Integration Time），单位为微秒（Microseconds）。 |
