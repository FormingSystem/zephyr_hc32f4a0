# 第1章\_adi_tmc2209

原文：[官方页面](https://docs.zephyrproject.org/latest/build/dts/api/bindings/stepper/adi/adi,tmc2209.html)。读取日期：2026-10-16；来源摘要见[来源记录](../SOURCES.md)。

<a id="adi-tmc2209"></a>
<a id="dtbinding-adi-tmc2209"></a>
<a id="std-dtcompatible-adi-tmc2209"></a>

兼容字符串（Compatible String）：`adi,tmc2209`。厂商：[ Analog Devices ](https://docs.zephyrproject.org/latest/build/dts/api/bindings.html#dt-vendor-adi)。

采用此设备树绑定（Devicetree Binding）的开发板见[官方筛选目录](https://docs.zephyrproject.org/latest/boards/index.html#compatibles=adi,tmc2209)。

驱动源码（Driver Source）：[drivers/stepper/adi_tmc/tmc22xx/tmc22xx.c](https://github.com/zephyrproject-rtos/zephyr/blob/main/drivers/stepper/adi_tmc/tmc22xx/tmc22xx.c)。

<a id="description"></a>

Analog Devices TMC2209步进电机驱动器（Stepper Motor Driver）。

<a id="examples"></a>

官方设备树示例（Devicetree Example）：

```dts
tmc2209: tmc2209 {
    compatible = "adi,tmc2209";
    enable-gpios = <&gpio0 0 GPIO_ACTIVE_HIGH>;
    m0-gpios = <&gpio0 1 GPIO_ACTIVE_HIGH>;
    m1-gpios = <&gpio0 2 GPIO_ACTIVE_HIGH>;
}
```

原例说明：原例使用`enable-gpios`，本页属性表列出的是`en-gpios`；此处保留原例并注明名称差异。

<a id="properties"></a>

属性类型：`int` 为整数，`boolean` 为布尔属性，`string` 为字符串，`string-array` 为字符串数组，`array` 为数值数组，`compound` 为复合类型；`phandle` 为节点引用（Phandle），`phandles` 为节点引用列表，`phandle-array` 为节点引用与说明符单元数组。

## 1.1\_节点专用属性

这些属性不继承自基础绑定文件。

| 属性 | 类型 | 中文说明与约束 |
| --- | --- | --- |
| `step-width-ns` | `int` | 步进信号（Step Signal）的最小脉冲宽度，单位为纳秒（ns）。；默认值：`100` |
| `dual-edge-step` | `boolean` | 存在此属性时，步进电机控制器支持双边沿步进信号（Dual-edge Step Signal），即上升沿与下降沿均可触发步进。 |
| `micro-step-res` | `int` | 初始化设备驱动时设置的微步分辨率（Microstep Resolution）。；默认值：`1`；合法值：`1, 2, 4, 8, 16, 32, 64, 128, 256` |
| `en-gpios` | `phandle-array` | 控制电机驱动器使能信号（Enable Signal）的GPIO引脚。 |
| `m0-gpios` | `phandle-array` | 微步配置引脚（Microstep Configuration Pin）0。 |
| `m1-gpios` | `phandle-array` | 微步配置引脚（Microstep Configuration Pin）1。 |

本页没有已弃用的节点专用属性。
