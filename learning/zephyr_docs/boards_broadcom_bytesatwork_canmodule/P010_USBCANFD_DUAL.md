## 概述（Overview）

USBCANFD DUAL是一款高性能双通道USB转CAN FD适配器开发板，支持最高8 Mbps数据速率。更多信息见[can-module.com网站](https://can-module.com)。

<a id="hardware"></a>

## 硬件（Hardware）

USBCANFD DUAL开发板配备STM32G4微控制器，提供电气隔离（Galvanic Isolation）、两个CAN通道各自独立的状态LED，以及用于进入内置引导加载程序（Bootloader）模式的软件可配置启动设置。

<a id="default-zephyr-peripheral-mapping"></a>

### Zephyr默认外设映射（Default Peripheral Mapping）


- `CAN_RX1/BOOT0 : PB8`
- `CAN_TX1 : PB9`
- `CAN_RX2 : PB5`
- `CAN_TX2 : PB6`
- `ledRX1 : PA6`
- `ledTX1 : PA5`
- `ledRX2 : PA4`
- `ledTX2 : PA3`
- `USB_DN : PA11`
- `USB_DP : PA12`
- `SWDIO : PA13`
- `SWCLK : PA14`
- `NRST : PG10`

<a id="flashing"></a>

### 烧录（Flashing）

通过USB DFU烧录需要进入内置ROM引导加载程序。由于开发板没有物理BOOT0引脚，必须通过选项字节（Option Bytes）控制DFU模式的进入。使用外部调试器，例如ST-LINK，将`nswBoot0`位改为1，以进入DFU模式。经USB DFU烧录固件后，必须将`nswBoot0`位改回0，才能保证从闪存（Flash）正常启动。

也可使用ST-LINK调试器直接烧录开发板。

以下以[Blinky](../getting_started/P004_LED闪烁示例.md#blinky)应用为例。

```text
# From the root of the zephyr repository
west build -b usbcanfd_dual samples/basic/blinky
west flash
```
