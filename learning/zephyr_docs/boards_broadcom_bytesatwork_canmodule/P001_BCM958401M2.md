## 博通BCM958401M2

<a id="overview"></a>

### 概述（Overview）

博通BCM958401M2开发板采用Valkyrie BCM58400片上系统（SoC），提供PCIe卸载引擎（Offload Engine）功能。

<a id="hardware"></a>

### 硬件（Hardware）

BCM958401M2是一张PCIe卡，具有以下物理接口：


- PCIe Gen3接口
- RS232通用异步收发器（UART），可选装
- JTAG接口，可选装

<a id="supported-features"></a>

#### 支持的功能（Supported Features）

`bcm958401m2`开发板支持下表所列的硬件功能。

片上／板载（On-Chip / On-Board）

功能集成在片上系统（SoC）内／位于开发板上。

2 / 2

分别表示已启用／已禁用的实例数。点击数量标签，可查看开发板或SoC设备树源码（DTS）中该功能的第一个实例。

`vnd,foo`

与此功能匹配的设备树绑定兼容字符串（Compatible String）；点击链接可查看绑定文档。

<a id="programming-and-debugging"></a>

### 烧录与调试（Programming and Debugging）

<a id="flashing"></a>

#### 烧录（Flashing）

Zephyr目前不支持板载闪存。开发板通过PCIe接口启动。

<a id="debugging"></a>

#### 调试（Debugging）

`bcm958401m2`开发板预留了焊接JTAG连接器的焊盘。也可以通过观察UART控制台输出，测试运行在M7内核上的Zephyr应用。
