## 12.4\_源码跟踪译注

> 译注——sys_poweroff执行立即关机（Power Off），调用者须先使系统处于安全状态并配置所需唤醒源（Wake-up Source）；它不同于线程睡眠或CPU空闲。使用接口需要CONFIG_POWEROFF，实际关机能力仍由平台提供。

> 译注——本次通用实现锁定普通中断及配置允许的零延迟中断，然后调用平台钩子z_sys_poweroff。该钩子在官方文档中隐藏为内部接口，但源码浏览页仍可见，因此代码保留；不能把它当作供普通应用调用的另一套公共关机API。

头文件定位：[include/zephyr/sys/poweroff.h](../../../include/zephyr/sys/poweroff.h)，关联实现／接口：[lib/os/poweroff.c](../../../lib/os/poweroff.c)；[官方原始头文件](https://github.com/zephyrproject-rtos/zephyr/blob/main/include/zephyr/sys/poweroff.h)与[官方关联文件](https://github.com/zephyrproject-rtos/zephyr/blob/main/lib/os/poweroff.c)的摘要见来源记录。去掉注释和展示空白后，本页代码与本次读取的原始头文件一致，不能推广到以后滚动更新的main或任意本地版本。
