## 7.4\_源码跟踪译注

> 译注——架构系统调用头文件是编译期选择入口，根据所选CPU架构包含对应的syscall.h；它本身没有提供运行时可切换的跨架构调用层。架构选择与应用二进制接口（Application Binary Interface，ABI）必须一致，不能把ARM寄存器传参方式套到其他架构。

> 译注——本次ARM头文件通过SVC等架构机制实现系统调用入口，并根据运行状态判断用户权限。这里仅作源码定位，不声称任何目标芯片已经具备MPU、用户模式或系统调用实测支持。

头文件定位：[include/zephyr/arch/syscall.h](../../../include/zephyr/arch/syscall.h)，关联实现／接口：[include/zephyr/arch/arm/syscall.h](../../../include/zephyr/arch/arm/syscall.h)；[官方原始头文件](https://github.com/zephyrproject-rtos/zephyr/blob/main/include/zephyr/arch/syscall.h)与[官方关联文件](https://github.com/zephyrproject-rtos/zephyr/blob/main/include/zephyr/arch/arm/syscall.h)的摘要见来源记录。去掉注释和展示空白后，本页代码与本次读取的原始头文件一致，不能推广到以后滚动更新的main或任意本地版本。

本次验证范围为文档与源码对照，未构建固件、配置实板引脚或操作硬件。
