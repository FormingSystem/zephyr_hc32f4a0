## 9.4\_源码跟踪译注

> 译注——arch_early_memset与arch_early_memcpy用于非常早期的启动阶段。通用实现为弱定义并调用普通memset／memcpy；若硬件状态尚不允许使用优化实现，架构可提供安全覆盖。这不是应用启动后应改用的新内存API。

> 译注——arch_bss_zero按链接器定义的区间清零BSS（Block Started by Symbol），并根据配置处理附加内存区；CONFIG_SKIP_BSS_CLEAR可使它直接返回。不能把它解释为无条件清零全部RAM。

> 译注——arch_bss_zero_boot只在CONFIG_LINKER_USE_BOOT_SECTION下提供独立启动区域清零，未启用时头文件内联实现为空。启动区域可能包含分页初始化前必须使用的符号，因此与普通BSS清零分开；z_cstart是内核C启动入口，不是应用可重复调用的初始化函数。

头文件定位：[include/zephyr/arch/common/init.h](../../../include/zephyr/arch/common/init.h)，关联实现／接口：[arch/common/init.c](../../../arch/common/init.c)；[官方原始头文件](https://github.com/zephyrproject-rtos/zephyr/blob/main/include/zephyr/arch/common/init.h)与[官方关联文件](https://github.com/zephyrproject-rtos/zephyr/blob/main/arch/common/init.c)的摘要见来源记录。去掉注释和展示空白后，本页代码与本次读取的原始头文件一致，不能推广到以后滚动更新的main或任意本地版本。
