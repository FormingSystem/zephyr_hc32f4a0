## 8.3\_源码定位与版本边界

源码定位：[include/zephyr/arch/common/init.h](../../../include/zephyr/arch/common/init.h)、[arch/common/init.c](../../../arch/common/init.c)、[kernel/init.c](../../../kernel/init.c)。官方源码摘要见[来源记录](../SOURCES.md)。

> 译注——源码核对：以下源码跟踪译注独立于官方正文，依据来源记录中保存摘要的官方main文件。存在于本仓库的源码使用相对链接；尚未纳入本仓库的上游文件仅链接官方来源，不创建同名占位源码。

> 译注——源码核对：arch_early_memset与arch_early_memcpy用于非常早期的启动阶段。通用实现为弱定义并调用普通memset／memcpy；若硬件状态尚不允许使用优化实现，架构可提供安全覆盖。这不是应用启动后应改用的新内存API。

> 译注——源码核对：arch_bss_zero按链接器定义的区间清零BSS（Block Started by Symbol），并根据配置处理附加内存区；CONFIG_SKIP_BSS_CLEAR可使它直接返回。不能把它解释为无条件清零全部RAM。

> 译注——源码核对：arch_bss_zero_boot只在CONFIG_LINKER_USE_BOOT_SECTION下提供独立启动区域清零，未启用时头文件内联实现为空。启动区域可能包含分页初始化前必须使用的符号，因此与普通BSS清零分开；z_cstart是内核C启动入口，不是应用可重复调用的初始化函数。
