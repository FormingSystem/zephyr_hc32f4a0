## 10.2\_详细说明（Detailed Documentation）

<a id="a11651e65cf1213ff10b2a33d9ee92804"></a>

### `sys_boot_fdt_copy()`

```c
int sys_boot_fdt_copy ( uint8_t * dst, size_t dst_size, const uint8_t * src, uint32_t * fdt_size )
```

验证并复制启动固件的扁平设备树二进制块（Flattened Device Tree，FDT；亦称Device Tree Blob，DTB）。

此辅助函数验证 FDT 头部魔数（Magic）和总大小字段，检查二进制块能否放入调用者提供的存储区，然后将其复制进去。目标缓冲区归调用者所有，由调用者决定复制后的数据保留多久。

**参数（Parameters）**

| 名称／方向 | 说明 |
| --- | --- |
| `dst` | 存放复制后 FDT 的目标缓冲区。 |
| `dst_size` | 目标缓冲区大小，单位为字节。 |
| `src` | 源 FDT 指针。 |
| `fdt_size` | 用于输出 FDT 大小（字节数）。成功及返回 `-ENOSPC` 时都会设置。 |

**返回值（Return Values）**

| 名称／方向 | 说明 |
| --- | --- |
| `0` | FDT 已验证并复制时。 |
| `-EINVAL` | 参数无效或 `src` 不是有效 FDT 时。 |
| `-ENOSPC` | `dst` 太小，无法容纳 FDT 时。 |

**注意（Attention）**：注意（Attention）：只有启用了以下 Kconfig 选项时才可用：`CONFIG_BOOT_FDT`。

## 10.3\_源码定位与版本边界

源码定位：[include/zephyr/sys/boot_fdt.h](https://github.com/zephyrproject-rtos/zephyr/blob/main/include/zephyr/sys/boot_fdt.h)、[lib/os/boot_fdt.c](https://github.com/zephyrproject-rtos/zephyr/blob/main/lib/os/boot_fdt.c)。官方源码摘要见[来源记录](../SOURCES.md)。

> 译注——源码核对：以下源码跟踪译注独立于官方正文，依据来源记录中保存摘要的官方main文件。存在于本仓库的源码使用相对链接；尚未纳入本仓库的上游文件仅链接官方来源，不创建同名占位源码。

> 译注——源码核对：本次sys_boot_fdt_copy只读取大端格式的魔数与总大小字段，要求大小至少为8字节，再检查目标容量并memcpy。它不遍历完整FDT结构块、字符串块或节点，也不验证签名；不能将此处“验证”解释为完整设备树语义或真实性验证。

> 译注——源码核对：函数没有源缓冲区长度参数，调用者须保证源头部和声明大小对应的数据确实可读；空指针检查不代替内存映射与访问权限保证。使用memcpy意味着源与目标不能依赖重叠复制语义。

> 译注——源码核对：fdt_size只在头部检查通过后赋值，成功和-ENOSPC时有效；-EINVAL时不能假定它已经被更新。-ENOSPC返回前不复制数据，可据输出大小准备足够目标缓冲区。目标存储的所有权和保留时间仍由调用者管理。

> 译注——源码核对：本次本地源码版本尚无sys/boot_fdt.h与lib/os/boot_fdt.c，故仅给出官方源码链接及摘要。此运行时启动固件FDT辅助接口不等于把Zephyr构建期Devicetree自动改成运行时解析，也不意味着本仓库已经启用CONFIG_BOOT_FDT。

本次验证范围为文档与源码对照，未构建固件、配置实板引脚或操作硬件。
