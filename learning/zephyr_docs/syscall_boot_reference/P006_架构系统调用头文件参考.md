## 6.1\_源码定位与版本边界

源码定位：[include/zephyr/arch/syscall.h](../../../include/zephyr/arch/syscall.h)、[include/zephyr/arch/arm/syscall.h](../../../include/zephyr/arch/arm/syscall.h)。官方源码摘要见[来源记录](../SOURCES.md)。

> 译注——源码核对：以下源码跟踪译注独立于官方正文，依据来源记录中保存摘要的官方main文件。存在于本仓库的源码使用相对链接；尚未纳入本仓库的上游文件仅链接官方来源，不创建同名占位源码。

> 译注——源码核对：架构系统调用头文件是编译期选择入口，根据所选CPU架构包含对应的syscall.h；它本身没有提供运行时可切换的跨架构调用层。架构选择与应用二进制接口（Application Binary Interface，ABI）必须一致，不能把ARM寄存器传参方式套到其他架构。

> 译注——源码核对：本次ARM头文件通过SVC等架构机制实现系统调用入口，并根据运行状态判断用户权限。这里仅作源码定位，不声称任何目标芯片已经具备MPU、用户模式或系统调用实测支持。

本次验证范围为文档与源码对照，未构建固件、配置实板引脚或操作硬件。
