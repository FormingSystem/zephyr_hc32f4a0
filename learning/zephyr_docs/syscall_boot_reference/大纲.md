# 系统调用与启动辅助参考大纲

本册翻译用户模式与系统调用（User Mode and System Calls）接口、系统调用声明与处理头文件、架构选择与公共初始化头文件、启动固件设备树（Boot Firmware Device Tree）辅助接口及系统关机头文件源码，共十二份官方页面。六个源码浏览页保留全部可见代码、原始注释、许可证、行号锚点和符号提示，中文对照另列。

系统调用部分面向扩展Zephyr内部功能的开发者，保留官方内部API限制，分别说明对象类型、权限、初始化状态、用户缓冲区和动态对象生命周期。官方正文与源码跟踪译注明确分开，原始宏展开不替换为中文；源码译注指出当前实现与原文措辞的边界。

启动辅助接口与应用运行期API分开理解；FDT头部复制不等于完整内容校验。存在于本仓库的源码使用相对链接，尚未纳入的上游文件仅链接官方来源。完整翻译范围及待译状态见[全站进度](../PROGRESS.md)。
