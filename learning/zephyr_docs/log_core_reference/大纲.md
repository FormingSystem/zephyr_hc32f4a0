# 日志公共接口与控制参考大纲

本册翻译日志（Logging）主题总览、日志公共API、日志控制API，以及公共与控制两个头文件的参考和源码，共七份官方页面。主题总览保留官方导航范围，其他日志子模块仍按独立页面跟踪。

公共接口覆盖日志级别、模块注册、实例过滤、单次与限速日志、原始输出及十六进制转储；控制接口覆盖初始化、处理线程、待处理消息、前后端过滤、日志域、时间戳、标签、内存用量和panic模式。模块、实例、源、域与后端各自承担不同职责，译文保留全部参数、配置条件、返回语义与原始宏展开。

两个源码浏览页保留全部可见代码、注释、许可证、符号提示和对应行号锚点。源码跟踪译注说明编译期与运行时过滤、每调用位置限速、处理返回值、用户模式条件和截断副作用；不将缓冲区排空自动等同于存储持久化。入门与示例见[可观测性主线](../observability/大纲.md)，完整覆盖状态见[全站进度](../PROGRESS.md)。
