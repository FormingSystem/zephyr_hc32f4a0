# 时间类型与网络超时参考大纲

本册完整翻译最小C库（Minimal C Library）的timespec.h与_timespec.h参考和源码、timespec与itimerspec结构、旧系统时钟兼容头文件及源码，以及网络长超时（Network Long Timeout）的公共接口、头文件参考与源码和状态结构，共十二份官方页面。

时间结构、时间运算和超时调度各有职责。最小C库头文件提供布局，时间工具负责转换与规范化，网络超时则需要调用方安排周期评估。阅读时先区分秒、毫秒与纳秒单位，以及绝对时刻与相对时长。

完整相关功能见[时间工具参考册](../timeutil_reference/大纲.md)和[系统时钟公共接口](../timer_reference/P086_系统时钟公共接口.md)。源码页保留可见代码、原始法律声明、行号锚点与符号提示，注释另列中文对照；译注解释C库边界、回绕分段和向下取整，与官方正文分开。

文档和本地源码使用相对链接。官方构建机前缀仅从交叉引用的显示标签中去除，来源URL和符号目标保持原样，读者无需复制官方构建目录。完整范围见[全站进度](../PROGRESS.md)。
