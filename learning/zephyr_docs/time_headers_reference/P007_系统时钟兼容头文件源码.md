## 7.4\_源码跟踪译注

> 译注——zephyr/sys_clock.h是兼容入口（Compatibility Header），源码主动发出#warning并转入zephyr/sys/clock.h。它不是独立的时钟驱动；迁移包含路径应使用新入口，完整系统时钟接口见[已有系统时钟公共接口译文](../timer_reference/P086_系统时钟公共接口.md)。原始警告字符串在代码中保留，中文对照为“该头文件已弃用，请改用include/zephyr/sys/clock.h”。

头文件相对定位：[include/zephyr/sys_clock.h](../../../include/zephyr/sys_clock.h)，关联实现／接口：[include/zephyr/sys/clock.h](../../../include/zephyr/sys/clock.h)；[官方原始头文件](https://github.com/zephyrproject-rtos/zephyr/blob/main/include/zephyr/sys_clock.h)与[官方关联文件](https://github.com/zephyrproject-rtos/zephyr/blob/main/include/zephyr/sys/clock.h)的摘要见来源记录。去掉注释和展示空白后，本页代码与本次读取的原始头文件一致，不能推广到以后滚动更新的main或任意本地版本。
