> 译注——源码核对：以下源码跟踪译注独立于官方正文，依据来源记录中保存摘要的官方main文件。译文与仓库内已有源码采用相对链接，不依赖作者机器位置；不同C库和构建配置须分别核对。

> 译注——源码核对：zephyr/sys_clock.h是兼容入口（Compatibility Header），源码主动发出#warning并转入zephyr/sys/clock.h。它不是独立的时钟驱动；迁移包含路径应使用新入口，完整系统时钟接口见[已有系统时钟公共接口译文](../timer_reference/P086_系统时钟公共接口.md)。原始警告字符串在代码中保留，中文对照为“该头文件已弃用，请改用include/zephyr/sys/clock.h”。
