<a id="hardware"></a>

## 硬件（Hardware）


- STM32F030F4P6 Arm Cortex-M0处理器，最高48 MHz
- 16 KiB闪存及4 KiB RAM
- 8 MHz石英晶体
- 一个用户LED
- 1个复位按键（Reset Button）
- 两档BOOT0跳线
- 串口，1×4引脚、2.54 mm间距杜邦公头
- SWD，1×4引脚、2.54 mm间距杜邦公头
- USB端口，仅供电

<a id="flashing"></a>

### 烧录（Flashing）

可使用ST-LINK/V2在线调试及编程器烧录，Zephyr SDK附带的OpenOCD支持该接口。

<a id="flashing-an-application-to-stm32f030-demo-board"></a>

#### 向STM32F030演示板烧录应用

以下以[Blinky](../getting_started/P004_LED闪烁示例.md#blinky)应用为例。

```text
# From the root of the zephyr repository
west build -b stm32f030_demo samples/basic/blinky
west flash
```

可以看到LED每秒闪烁一次。

<a id="debugging"></a>

### 调试（Debugging）

可以按通常方式调试应用，以下以[Blinky](../getting_started/P004_LED闪烁示例.md#blinky)为例。

```text
# From the root of the zephyr repository
west build -b stm32f030_demo samples/basic/blinky
west debug
```
