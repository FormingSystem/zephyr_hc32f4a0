## 概述（Overview）

JZ-F407VET6采用基于Arm Cortex-M4的STM32F407VE MCU，面向工业自动化应用，提供广泛的连接支持。其主要特点如下：


- LQFP100封装的STM32微控制器
- 25 MHz高速外部晶体
- 32.768 kHz RTC晶体
- 灵活的开发板供电方式：


  - 5 V直流圆孔电源插座
  - Mini-USB连接器
- 3个用户LED
- 3个用户按键
- 带DB9连接器的RS232接口
- 支持Modbus的RS485接口
- 双路CAN总线，采用TJA1050收发器
- 10／100以太网，带RMII PHY
- MicroSD卡槽（Card Slot）
- W25Q64JV 8 MB SPI NOR闪存
- AT24C02 256字节I2C EEPROM
- USB主机，USB-A连接器
- USB设备，Mini-USB连接器
- 两个16引脚扩展排针
- 8引脚NRF24L01排针
- 3引脚DS18B20排针
- 为VBAT提供电源的纽扣电池座
- SWD／JTAG调试接口

## 硬件（Hardware）

JZ-F407VET6提供以下硬件组件：


- LQFP100封装的STM32F407VET6
- 32位Arm Cortex-M4 CPU，带浮点单元（FPU）
- CPU 最高频率 168 MHz。
- VDD电压范围1.8–3.6 V
- 512 KB 闪存（Flash）。
- 192 KB SRAM，包括64 KB核耦合存储器（CCM）
- 4 KB备份SRAM
- 支持外部中断（External Interrupt）的 GPIO。
- 12位ADC，共24通道
- 12位数模转换器（DAC）
- 实时时钟（RTC）
- 高级控制定时器（Advanced-control Timers）
- 通用定时器（General Purpose Timers）
- 看门狗定时器（Watchdog Timers）
- USART/UART
- 集成电路间总线（I2C）
- 串行外设接口（SPI）
- SD输入输出接口（SDIO）
- 控制器局域网（CAN）
- USB 2.0 OTG 全速接口（Full Speed，FS）。
- USB 2.0 OTG高速／全速
- 10／100以太网MAC
- 循环冗余校验计算单元（CRC Calculation Unit）
- 真随机数发生器（True Random Number Generator）
- 直接存储器访问控制器（DMA Controller）。

STM32F407VE的更多信息见：


- [ST网站上的STM32F407VE](https://www.st.com/en/microcontrollers/stm32f407ve.html)

<a id="connections-and-ios"></a>

### 连接与输入输出（Connections and IOs）

JZ-F407VET6有5个GPIO控制器，负责引脚复用、输入输出及上拉等。

<a id="default-zephyr-peripheral-mapping"></a>

#### Zephyr 默认外设映射（Peripheral Mapping）：


- USART_1 TX/RX : PA9/PA10 (RS232)
- USART_2 TX/RX/DE : PD5/PD6/PD7 (RS485)
- I2C1 SCL/SDA : PB8/PB9
- SPI2 SCK/MISO/MOSI : PB10/PC2/PC3
- SPI2闪存片选（CS）：PE3
- CAN1 RX/TX : PD0/PD1
- CAN2 RX/TX : PB5/PB6
- ETH : PA1, PA2, PA7, PB11, PB12, PB13, PC1, PC4, PC5
- SDIO D0-D3/CK/CMD : PC8-PC11/PC12/PD2
- SDIO CD : PD3
- USB OTG FS DM/DP : PA11/PA12
- USB OTG HS DM/DP : PB14/PB15
- LED1 : PE13
- LED2 : PE14
- LED3 : PE15
- SW1 : PE10
- SW2 : PE11
- SW3 : PE12

<a id="system-clock"></a>

#### 系统时钟（System Clock）

JZ-F407VET6系统时钟可由内部或外部振荡器，或主PLL提供。默认采用25 MHz高速外部时钟驱动PLL，生成168 MHz系统时钟。

<a id="serial-port"></a>

#### 串口（Serial Port）

JZ-F407VET6有6路UART，Zephyr控制台输出分配给USART1，默认115200、8N1。

USART1经RS232收发器连接到DB9连接器。

USART2配置为支持Modbus的RS485，PD7用作驱动使能（Driver Enable）引脚。

<a id="flashing"></a>

### 烧录（Flashing）

可将外部ST-LINK/V2或兼容JTAG编程器连接到JTAG排针，为JZ-F407VET6烧录。

也可通过`--runner`（或`-r`）选项选择OpenOCD或JLink烧录：

```text
$ west flash --runner openocd
$ west flash --runner jlink
```

<a id="flashing-an-application-to-jz-f407vet6"></a>

#### 向JZ-F407VET6烧录应用

下面以[Hello World](../getting_started/P005_HelloWorld示例.md#hello_world)应用为例。

运行主机串口程序，通过DB9 RS232端口连接开发板：

```text
$ minicom -D /dev/ttyUSB0
```

构建并烧录应用：

```text
# From the root of the zephyr repository
west build -b jz_f407vet6 samples/hello_world
west flash
```

控制台上应显示以下消息：

```text
$ Hello World! jz_f407vet6/stm32f407xx
```
