# 第13章\_MAX31790 API主题

原文：[官方页面](https://docs.zephyrproject.org/latest/doxygen/html/group__max31790__interface.html)。读取日期：2026-10-17；来源摘要见[来源记录](../SOURCES.md)。

Maxim MAX31790 六通道 PWM 输出风扇转速（RPM）控制器。

<a id="details"></a>

Maxim MAX31790 六通道 PWM 输出风扇转速控制器（6-Channel PWM-Output Fan RPM Controller）。MAX31790 提供风扇故障监测（Fan Fault Monitoring）和风扇转速感测（Fan Speed RPM Sensing）。风扇转速使用标准通道 `SENSOR_CHAN_RPM`。

### `sensor_channel_max31790`

```c
enum sensor_channel_max31790
```

```c
#include <zephyr/drivers/sensor/max31790.h>
```

MAX31790 的自定义传感器通道（Custom Sensor Channels）。

**枚举值（Enumerators）**

| 名称／方向 | 说明 |
| --- | --- |
| `SENSOR_CHAN_MAX31790_FAN_FAULT` | 风扇故障状态位掩码（Fan Fault Status Bitmask）。每一位表示对应风扇（1～6）的故障：位 0 表示风扇 1 故障，位 1 表示风扇 2 故障，依此类推，位 5 表示风扇 6 故障。`sensor_value.val1` 是 6 位故障掩码；`sensor_value.val2` 不使用，始终为 0。 |
