# 第12章\_用于打印 Q 格式数值的辅助宏。

原文：[官方页面](https://docs.zephyrproject.org/latest/doxygen/html/group__math__printing.html)。读取日期：2026-10-17；来源摘要见[来源记录](../SOURCES.md)。

扩展现有的 `inttypes` 头文件，以支持打印格式化。

<a id="details"></a>

扩展现有整数类型（`inttypes`）头文件，以支持打印格式（Print Formatting）。用法（Usage）：

```c
printk("Value=%" PRIq "\n", PRIq_arg(value, 6, 2));
```

原页随示例提供的符号说明（Symbol Descriptions）：

- `PRIq`：`#define PRIq(precision)`，插入 Q 值格式字符串（Q Value Format String）；定义位于 `print_format.h:30`。
- `PRIq_arg`：`#define PRIq_arg(q, precision, shift)`，向打印格式插入 Q 值参数（Q Value Arguments）；定义位于 `print_format.h:58`。
- `printk`：`void printk(const char *fmt,...)`，打印内核调试消息（Kernel Debugging Message）。

当 Q 值表示 0.5 时，预期输出为 `"Value=2.000000"`。


相关声明：[PRIq_arg](#gad0393d2bb183784a9c09f2c05d7987f9)。

将 Q 值参数（Q Value Arguments）插入打印格式（Print Format）。

## 12.2\_详细说明（Detailed Documentation）

<a id="ga08618ad8449ee21f0a57c151541e8ef8"></a>

### `PRIq`

```c
#define PRIq ( precision)
```

```c
#include <zephyr/dsp/print_format.h>
```

展开值（Value）：

```c
"s%" PRIu32 ".%0" STRINGIFY(precision) PRIu32
```

插入 Q 值格式字符串（Q Value Format String）。

<a id="gad0393d2bb183784a9c09f2c05d7987f9"></a>

### `PRIq_arg`

```c
#define PRIq_arg ( q, precision, shift )
```

```c
#include <zephyr/dsp/print_format.h>
```

展开值（Value）：

```c
((q) < 0 ? "-" : ""), (uint32_t)__PRIq_arg_get_int(q, shift),                              \
        (uint32_t)__PRIq_arg_get_frac(q, precision, shift)
```

将 Q 值参数（Q Value Arguments）插入打印格式（Print Format）。

**参数（Parameters）**

| 名称／方向 | 说明 |
| --- | --- |
| `[in] q` | Q 值（Q Value）。 |
| `[in] precision` | 要打印的小数位数（Number of Decimal Points to Print）。 |
| `[in] shift` | 用于移位 Q 值的缩放量（Scale）。 |
