## 18.3\_详细说明（Detailed Documentation）

<a id="gaa70dd183377503db716ec6277dade83a"></a>

### `pmw3610_force_awake()`

```c
int pmw3610_force_awake ( const struct device * dev, bool enable )
```

```c
#include <zephyr/input/input_pmw3610.h>
```

设置 pmw3610 设备的强制唤醒模式（Force Awake Mode）。

**参数（Parameters）**

| 名称／方向 | 说明 |
| --- | --- |
| `dev` | pmw3610 设备（Device）。 |
| `enable` | 是否启用或禁用强制唤醒模式（Force Awake Mode）。 |

**返回值（Return Values）**

| 名称／方向 | 说明 |
| --- | --- |
| `0` | 成功。 |
| `-errno` | 发生错误（An Error Occurred）。 |

<a id="ga7c20acd4c9ed5b1e16ebc2e093119e0b"></a>

### `pmw3610_set_resolution()`

```c
int pmw3610_set_resolution ( const struct device * dev, uint16_t res_cpi )
```

```c
#include <zephyr/input/input_pmw3610.h>
```

设置 pmw3610 设备的分辨率（Resolution）。

**参数（Parameters）**

| 名称／方向 | 说明 |
| --- | --- |
| `dev` | pmw3610 设备（Device）。 |
| `res_cpi` | 每英寸计数分辨率（CPI Resolution）：200～3200。 |

**返回值（Return Values）**

| 名称／方向 | 说明 |
| --- | --- |
| `0` | 成功。 |
| `-EINVAL` | 无效分辨率（Invalid Resolution）。 |
| `-errno` | 发生其他错误（Another Error Occurred）。 |
