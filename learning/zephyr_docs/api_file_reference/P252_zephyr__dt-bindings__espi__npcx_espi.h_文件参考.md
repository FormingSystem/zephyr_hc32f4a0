## 252.2\_详细说明（Detailed Documentation）

<a id="a2dcad76fd6ebf24e755a741edc2719be"></a>

### `ESPI_NPCX_VW_EX_DIR`

```c
#define ESPI_NPCX_VW_EX_DIR ( e)
```

展开值（Value）：

```c
(((e) >> 12) & 0x1)
```

<a id="ab992e56a785a9e60fcf3d92af0c94ea7"></a>

### `ESPI_NPCX_VW_EX_GROUP_NUM`

```c
#define ESPI_NPCX_VW_EX_GROUP_NUM ( e)
```

展开值（Value）：

```c
(((e) >> 8) & 0xf)
```

<a id="a014b58b053bd26e2a365cbe8520d0421"></a>

### `ESPI_NPCX_VW_EX_INDEX`

```c
#define ESPI_NPCX_VW_EX_INDEX ( e)
```

展开值（Value）：

```c
((e) & 0xff)
```

<a id="ac5bf7f75ecd869d2ed1d1209f5b46248"></a>

### `ESPI_NPCX_VW_EX_VAL`

```c
#define ESPI_NPCX_VW_EX_VAL ( dir, group, index )
```

展开值（Value）：

```c
(((dir & 0x1) << 12) + ((group & 0xf) << 8) + (index & 0xff))
```
