# 第23章\_蓝牙标准服务

原文：[官方页面](https://docs.zephyrproject.org/latest/services/connectivity/bluetooth/api/services.html)。读取日期：2026-10-14；保存的 latest 页面及 HTML 摘要见[来源记录](../SOURCES.md)。

本页按官方分类组织蓝牙标准服务（Bluetooth standard services）的API及相关示例。

<a id="battery-service"></a>

## 23.1\_电池服务（Battery Service）

[电池服务API（Battery Service，BAS）](https://docs.zephyrproject.org/latest/doxygen/html/group__bt__bas.html)。

相关代码示例（Related code samples）：

- [环境感知外设（Environmental Sensing Profile，ESP Peripheral）](https://docs.zephyrproject.org/latest/samples/bluetooth/peripheral_esp/README.html#ble_peripheral_esp)：通过环境感知配置文件提供环境信息。
- [健康温度计外设（Health Thermometer，HT）](https://docs.zephyrproject.org/latest/samples/bluetooth/peripheral_ht/README.html#ble_peripheral_ht)：提供生成模拟温度值的HT GATT服务。
- [心率监视器外设（Heart Rate，HR）](../bluetooth_samples/P007_心率服务外设.md#ble_peripheral_hr)：提供生成模拟心率值的HR GATT服务。

<a id="current-time-service"></a>

## 23.2\_当前时间服务（Current Time Service）

[当前时间服务API（Current Time Service，CTS）](https://docs.zephyrproject.org/latest/doxygen/html/group__bt__cts.html)。

<a id="elapsed-time-service"></a>

## 23.3\_已逝时间服务（Elapsed Time Service）

[已逝时间服务API（Elapsed Time Service，ETS）](https://docs.zephyrproject.org/latest/doxygen/html/group__bt__ets.html)。

相关代码示例：[ETS外设](https://docs.zephyrproject.org/latest/samples/bluetooth/peripheral_ets/README.html#ble_peripheral_ets)，提供ETS GATT服务。

<a id="heart-rate-service"></a>

## 23.4\_心率服务（Heart Rate Service）

[心率服务API（Heart Rate Service，HRS）](https://docs.zephyrproject.org/latest/doxygen/html/group__bt__hrs.html)。

相关代码示例：

- [HCI功率控制（HCI Power Control）](../bluetooth_samples/P019_HCI功率控制.md#bluetooth_hci_pwr_ctrl)：使用主机控制器接口（Host Controller Interface，HCI）的厂商专用命令，动态控制LE Controller发送功率。
- [心率监视器外设（Heart-rate Monitor）](../bluetooth_samples/P007_心率服务外设.md#ble_peripheral_hr)：提供生成模拟心率值的HR GATT服务。

<a id="immediate-alert-service"></a>

## 23.5\_即时警报服务（Immediate Alert Service）

[即时警报服务API（Immediate Alert Service，IAS）](https://docs.zephyrproject.org/latest/doxygen/html/group__bt__ias.html)。

<a id="object-transfer-service"></a>

## 23.6\_对象传输服务（Object Transfer Service）

[对象传输服务API（Object Transfer Service，OTS）](https://docs.zephyrproject.org/latest/doxygen/html/group__bt__ots.html)。

相关代码示例：[对象传输服务外设](https://docs.zephyrproject.org/latest/samples/bluetooth/peripheral_ots/README.html#ble_peripheral_ots)，提供OTS GATT服务。

> 译注：原页提供六类服务入口和七处相关示例引用，不在本页重复各服务的完整API。GATT为通用属性配置文件（Generic Attribute Profile）；示例中的温度与心率为模拟数据，不是本次传感器测量结果。


对应官方文档源码：[doc/services/connectivity/bluetooth/api/services.rst](https://raw.githubusercontent.com/zephyrproject-rtos/zephyr/main/doc/services/connectivity/bluetooth/api/services.rst)。
