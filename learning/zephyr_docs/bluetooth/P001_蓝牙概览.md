# 第1章\_蓝牙概览

原文：[官方页面](https://docs.zephyrproject.org/latest/services/connectivity/bluetooth/index.html)。读取日期：2026-10-14；保存的 latest 页面及 HTML 摘要见[来源记录](../SOURCES.md)。

本节介绍 Zephyr 操作系统的蓝牙（Bluetooth）协议栈。通过这些资料，可以了解各层的工作原理以及具体实现方式。

Zephyr 包含从应用到射频硬件的完整低功耗蓝牙（Bluetooth Low Energy，BLE，规范中也简称 LE）协议栈，同时实现了经典蓝牙（Classic Bluetooth，BR/EDR）主机层的一部分。BR/EDR 分别表示基本速率（Basic Rate）和增强数据速率（Enhanced Data Rate）。
