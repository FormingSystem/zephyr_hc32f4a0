# 第2章\_蓝牙支持特性

原文：[官方页面](https://docs.zephyrproject.org/latest/services/connectivity/bluetooth/features.html)。读取日期：2026-10-14；保存的 latest 页面及 HTML 摘要见[来源记录](../SOURCES.md)。

Zephyr 从项目创立起就十分重视蓝牙，尤其是低功耗蓝牙（Bluetooth Low Energy，LE）。参与现有蓝牙规范开源实现——例如 Linux 的 BlueZ——以及 LE 射频硬件设计与开发的多家公司和个人贡献了代码，使 Zephyr 蓝牙协议栈逐渐成熟，并具备下列丰富特性。

## 2.1\_总体能力

- 符合蓝牙 5.3 规范。
- 可高度配置：包括功能、缓冲区大小与数量、线程栈大小等；可移植到 Zephyr 支持的全部体系结构，涵盖大端、小端以及不同对齐要求。
- 支持主机（Host）与控制器（Controller）的全部构建组合：仅控制器构建通过 UART、SPI、USB 和 IPC 等物理传输承载主机控制器接口（Host Controller Interface，HCI）；仅主机构建通过 UART、SPI 和 IPC 共享内存连接控制器；合并构建同时包含 Host 与 Controller。
- 可进行蓝牙技术联盟（Bluetooth Special Interest Group，Bluetooth SIG）的资格认证。使用 Nordic Semiconductor 硬件定期对控制器和主机各层执行一致性测试，经典蓝牙（Bluetooth Classic）除外。

> 译注：UART 是通用异步收发器（Universal Asynchronous Receiver/Transmitter），SPI 是串行外设接口（Serial Peripheral Interface），USB 是通用串行总线（Universal Serial Bus），IPC 是进程间通信（Inter-Process Communication；此处也用于处理器核之间的通信）。这些术语表示传输或通信机制，并不意味着所有目标板都提供相同组合。本页的版本号和能力范围按读取时官方原文保留，不能据此推断本仓库目标板已经实现射频控制器或通过认证。

## 2.2\_低功耗蓝牙控制器（LE Link Layer）

低功耗蓝牙控制器实现 LE 链路层（Link Layer，LL），具有以下能力：

- 不限制角色与连接的数量，支持全部角色。
- 除少数细小项目外，支持 5.3 规范的全部特性。
- 已为并发多协议支持做好准备。
- 通过智能角色调度，尽量减少时间重叠。
- 采用可移植设计，可适配具有开放接口的 LE 射频硬件；目前支持 Nordic Semiconductor nRF52x、nRF53x 片上系统（System on Chip，SoC）系列以及专有射频硬件。
- 支持小端与大端体系结构，将硬实时相关细节抽象出来，封装在硬件专用模块中。
- 支持通过不同物理传输实现控制器 HCI 构建。
- 支持等时信道（Isochronous Channels）。

> 译注：“不限制角色与连接的数量”是原文对实现能力的描述，不表示有限内存、无线带宽与调度时间可以支持无限连接。实际可用数量还取决于配置、资源及业务时序。

## 2.3\_蓝牙主机（Bluetooth Host）

通用访问配置文件（Generic Access Profile，GAP）支持所有 LE 角色：外设（Peripheral）、中心设备（Central）、观察者（Observer）与广播者（Broadcaster）。它还支持多个物理层（Physical Layer，PHY），包括 2 Mbit/s 和编码物理层（Coded PHY）、扩展广播（Extended Advertising），以及包含同步信息传输（Sync Transfer）的周期广播（Periodic Advertising）。

通用属性配置文件（Generic Attribute Profile，GATT）支持：

- 服务端（Server），例如充当传感器。
- 客户端（Client），例如连接传感器。
- 增强属性协议（Enhanced Attribute Protocol，EATT）。
- GATT 数据库散列（GATT Database Hash）。
- GATT 多重通知（GATT Multiple Notifications）。

主机支持配对（Pairing），包括蓝牙 4.2 引入的安全连接（Secure Connections）；支持非易失性存储（Non-volatile Storage），可持久保存蓝牙专用设置及数据。

蓝牙网状网络（Bluetooth Mesh）支持：

- 中继（Relay）、友谊节点（Friend Node）、低功耗节点（Low-Power Node，LPN）和 GATT 代理（GATT Proxy）。
- 两种配网角色与承载：基于广播的配网承载（Provisioning Bearer over Advertising，PB-ADV）和基于 GATT 的配网承载（Provisioning Bearer over GATT，PB-GATT）。
- 基础模型（Foundation Models）。
- 高度可配置，可适用于 RAM 小至 16 KiB 的设备。

主机还提供基本的经典蓝牙 BR/EDR 支持：GAP、逻辑链路控制与适配协议（Logical Link Control and Adaptation Protocol，L2CAP）、串口仿真协议 RFCOMM，以及服务发现协议（Service Discovery Protocol，SDP）。

HCI 驱动具有清晰的抽象层，支持三线 UART（3-Wire，H:5）、五线 UART（5-Wire，H:4）和 SPI；可将本地控制器表示为虚拟 HCI 驱动，并已在多种常用控制器上验证。

其他主机能力包括等时信道，以及低功耗蓝牙音频（LE Audio）。
