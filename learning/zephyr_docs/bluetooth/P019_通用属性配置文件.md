# 第19章\_通用属性配置文件

原文：[官方页面](https://docs.zephyrproject.org/latest/services/connectivity/bluetooth/api/gatt.html)。读取日期：2026-10-14；保存的 latest 页面及 HTML 摘要见[来源记录](../SOURCES.md)。

通用属性配置文件（Generic Attribute Profile，GATT）管理服务数据库，提供服务注册与属性声明API。

GATT客户端（Client）向服务端（Server）发出命令和请求，并接收服务端的响应（Response）、指示（Indication）与通知（Notification）；通过 [`CONFIG_BT_GATT_CLIENT`](https://docs.zephyrproject.org/latest/kconfig.html#CONFIG_BT_GATT_CLIENT) 启用。GATT服务端接受客户端发来的命令和请求，并向客户端发送响应、指示和通知。

## 19.1\_服务与属性

使用 [`bt_gatt_service_register()`](https://docs.zephyrproject.org/latest/doxygen/html/group__bt__gatt__server.html#gab4d9cfea04e44445d5dc30ad52842b64) 注册服务，参数为 [`bt_gatt_service`](https://docs.zephyrproject.org/latest/doxygen/html/structbt__gatt__service.html)，其中包含该服务的属性列表。辅助宏 [`BT_GATT_SERVICE()`](https://docs.zephyrproject.org/latest/doxygen/html/group__bt__gatt__server.html#ga7d413ec013b91a633ec24d80d2814e2b) 可用于声明服务。

属性可以用 [`bt_gatt_attr`](https://docs.zephyrproject.org/latest/doxygen/html/structbt__gatt__attr.html) 声明，也可使用下列辅助宏。

| 宏 | 声明内容 |
| --- | --- |
| [`BT_GATT_PRIMARY_SERVICE`](https://docs.zephyrproject.org/latest/doxygen/html/group__bt__gatt__server.html#gaacada0ff1029af959b6fcd6703d4a0bf) | 主服务（Primary Service） |
| [`BT_GATT_SECONDARY_SERVICE`](https://docs.zephyrproject.org/latest/doxygen/html/group__bt__gatt__server.html#gaecb4d30282677d3450ad79c5f83f3445) | 次服务（Secondary Service） |
| [`BT_GATT_INCLUDE_SERVICE`](https://docs.zephyrproject.org/latest/doxygen/html/group__bt__gatt__server.html#ga08ffee706d271b75a54b1b99249dba24) | 包含服务（Include Service） |
| [`BT_GATT_CHARACTERISTIC`](https://docs.zephyrproject.org/latest/doxygen/html/group__bt__gatt__server.html#ga9e739546dbd906d3b3c4f1ed5ad9f41e) | 特征（Characteristic） |
| [`BT_GATT_DESCRIPTOR`](https://docs.zephyrproject.org/latest/doxygen/html/group__bt__gatt__server.html#ga83207fc083454327004f7d3c3e5b3840) | 描述符（Descriptor） |
| [`BT_GATT_ATTRIBUTE`](https://docs.zephyrproject.org/latest/doxygen/html/group__bt__gatt__server.html#gac4abfeb068d16dcdaceee812c12bf406) | 属性（Attribute） |
| [`BT_GATT_CCC`](https://docs.zephyrproject.org/latest/doxygen/html/group__bt__gatt__server.html#ga140b9c25d10244bebd9c891f881fdc94) | 客户端特征配置（Client Characteristic Configuration） |
| [`BT_GATT_CEP`](https://docs.zephyrproject.org/latest/doxygen/html/group__bt__gatt__server.html#ga55a82cada1093c4ff75fe5504ac504b1) | 特征扩展属性（Characteristic Extended Properties） |
| [`BT_GATT_CUD`](https://docs.zephyrproject.org/latest/doxygen/html/group__bt__gatt__server.html#ga1e1cd9d0853e2dcbefcb85fda44dc9c7) | 原文写作“特征用户格式（Characteristic User Format）”，实际为特征用户描述，见下方译注 |

> 译注——CUD名称：原指南及宏的简述把CUD写成User Format；但[官方GATT头文件](https://raw.githubusercontent.com/zephyrproject-rtos/zephyr/main/include/zephyr/bluetooth/gatt.h)的宏参数是以零字符（NUL）结尾的用户描述字符串，并使用 `BT_UUID_GATT_CUD`。[官方UUID定义](https://raw.githubusercontent.com/zephyrproject-rtos/zephyr/main/include/zephyr/bluetooth/uuid.h)明确将0x2901命名为特征用户描述（Characteristic User Description，CUD）。不要与特征表示格式（Characteristic Presentation Format，CPF）混淆。

每个属性都有描述类型的 `uuid`、`read`回调、`write`回调和一组访问权限。若权限不允许相应操作，可把对应读写回调设为 `NULL`。

> 原文说明：GATT不支持32位UUID。UUID包含在属性协议数据单元（Attribute Protocol PDU，ATT PDU）中时，所有32位UUID都必须转为128位UUID。

> 原文说明：属性的 `read` 和 `write` 回调直接从接收线程（RX Thread）调用，因此不建议在其中长时间阻塞。

## 19.2\_通知与指示

属性值变化可以通过 [`bt_gatt_notify()`](https://docs.zephyrproject.org/latest/doxygen/html/group__bt__gatt__server.html#ga74ee552864c563aa5bc939f37395c14a) 通知客户端；也可使用 [`bt_gatt_notify_cb()`](https://docs.zephyrproject.org/latest/doxygen/html/group__bt__gatt__server.html#ga55e3ef7cb43b8acb0a27643c78390146) 传入回调。原文描述这种回调用于需要获知数据已经通过空口发送的确切时刻。指示由 [`bt_gatt_indicate()`](https://docs.zephyrproject.org/latest/doxygen/html/group__bt__gatt__server.html#ga4f2272692cc0f1d44638828012296c80) 支持。

> 译注——完成回调的边界：[官方头文件](https://raw.githubusercontent.com/zephyrproject-rtos/zephyr/main/include/zephyr/bluetooth/gatt.h)把它定义为通知完成回调，保证在线程上下文而非ISR执行；回调参数没有射频时间戳。因此不能直接将进入回调时读取的主机时间当成精确空口发送时间，更不能把通知完成当作对端应用已处理数据的确认。原指南的“确切时刻”表述需结合实际控制器和协议栈实现理解。

## 19.3\_发现、读取与写入

通过 [`bt_gatt_discover()`](https://docs.zephyrproject.org/latest/doxygen/html/group__bt__gatt__client.html#gac06a945e5f7939b6716bc4f2cea781bd) 发起发现过程，传入描述发现类型的 [`bt_gatt_discover_params`](https://docs.zephyrproject.org/latest/doxygen/html/structbt__gatt__discover__params.html)。该参数还可作为过滤器：设置 `uuid` 后，只发现匹配的属性；设为 `NULL` 则允许发现全部属性。

> 原文说明：不支持缓存已发现的属性。

读取过程由 [`bt_gatt_read()`](https://docs.zephyrproject.org/latest/doxygen/html/group__bt__gatt__client.html#ga1a18dd726ab960a88d7f85f2a014141a) 支持，参数为 [`bt_gatt_read_params`](https://docs.zephyrproject.org/latest/doxygen/html/structbt__gatt__read__params.html)。可以指定一个或多个属性，但多个句柄需要启用 [`CONFIG_BT_GATT_READ_MULTIPLE`](https://docs.zephyrproject.org/latest/kconfig.html#CONFIG_BT_GATT_READ_MULTIPLE)。

写入过程由 [`bt_gatt_write()`](https://docs.zephyrproject.org/latest/doxygen/html/group__bt__gatt__client.html#ga843a42e68e0497d88d3f655f8ffd58d4) 支持，参数为 [`bt_gatt_write_params`](https://docs.zephyrproject.org/latest/doxygen/html/structbt__gatt__write__params.html)。如果写入不需要响应，可以使用 [`bt_gatt_write_without_response()`](https://docs.zephyrproject.org/latest/doxygen/html/group__bt__gatt__client.html#ga9fc78e32230637a6f092da2400c50fe7) 或 [`bt_gatt_write_without_response_cb()`](https://docs.zephyrproject.org/latest/doxygen/html/group__bt__gatt__client.html#ga49439413d12b5a8a1c68735e961ab6fa)，后者的回调方式与 [`bt_gatt_notify_cb()`](https://docs.zephyrproject.org/latest/doxygen/html/group__bt__gatt__server.html#ga55e3ef7cb43b8acb0a27643c78390146) 类似。

## 19.4\_订阅

通过 [`bt_gatt_subscribe()`](https://docs.zephyrproject.org/latest/doxygen/html/group__bt__gatt__client.html#ga7d4a8e18f51ba6476886a15f81f48e5c) 订阅通知和指示，参数为 [`bt_gatt_subscribe_params`](https://docs.zephyrproject.org/latest/doxygen/html/structbt__gatt__subscribe__params.html)。支持对同一属性建立多个订阅，因此同一属性可能触发多个 `notify` 回调。使用 [`bt_gatt_unsubscribe()`](https://docs.zephyrproject.org/latest/doxygen/html/group__bt__gatt__client.html#ga56509c9b8f73f729cfa5e75be22d79ae) 移除订阅。

> 原文说明：订阅移除时会调用 `notify`，并把 `data` 设为 `NULL`。
