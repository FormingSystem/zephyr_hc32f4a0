# 第11章\_连接管理

原文：[官方页面](https://docs.zephyrproject.org/latest/services/connectivity/bluetooth/api/connection_mgmt.html)。读取日期：2026-10-14；保存的 latest 页面及 HTML 摘要见[来源记录](../SOURCES.md)。

Zephyr蓝牙协议栈使用 [`bt_conn`](https://docs.zephyrproject.org/latest/doxygen/html/structbt__conn.html) 抽象表示与其他设备的连接。应用不能直接访问该结构体内部内容，但可以通过 [`bt_conn_get_info()`](https://docs.zephyrproject.org/latest/doxygen/html/group__bt__conn.html#ga2de54f2ac83f0d8dca2a85a9fbfadcaa) 获取有限信息，例如远端地址。

连接对象采用引用计数（Reference Counting）。应用需要长期保存连接指针时，应调用 [`bt_conn_ref()`](https://docs.zephyrproject.org/latest/doxygen/html/group__bt__conn.html#ga060d51eb2208de6f805b1fc0672d2d0c) 持有引用，使对象即使在连接断开后仍然有效。释放该引用时，对应调用 [`bt_conn_unref()`](https://docs.zephyrproject.org/latest/doxygen/html/group__bt__conn.html#ga4b18c6b22a9f02be0d7d078b2ce51ff6)。

常见错误是忘记释放由 [`bt_conn_le_create()`](https://docs.zephyrproject.org/latest/doxygen/html/group__bt__conn.html#ga8d66f3e0262a51279e9fa8b3139252e6) 或 [`bt_conn_le_create_synced()`](https://docs.zephyrproject.org/latest/doxygen/html/group__bt__conn.html#ga98f99c893e444d1ad1ecd9139803c0b1) 创建的连接对象引用。可启用 [`CONFIG_BT_CONN_CHECK_NULL_BEFORE_CREATE`](https://docs.zephyrproject.org/latest/kconfig.html#CONFIG_BT_CONN_CHECK_NULL_BEFORE_CREATE)：传入的连接对象指针值不是 `NULL` 时，这些函数返回错误，帮助发现未释放对象导致的间歇性缺陷。

应用可以通过 [`bt_conn_cb_register()`](https://docs.zephyrproject.org/latest/doxygen/html/group__bt__conn.html#gaa9b79cd44734c1e560d6f30509be4d0b) 或 [`BT_CONN_CB_DEFINE`](https://docs.zephyrproject.org/latest/doxygen/html/group__bt__conn.html#ga9227880a1ae5fc373d334171e1450f00) 注册 [`bt_conn_cb`](https://docs.zephyrproject.org/latest/doxygen/html/structbt__conn__cb.html) 来跟踪连接。该结构体允许定义连接、断连，以及安全等级变化、连接参数变化等回调。作为中心设备（Central）时，应用也会在调用 [`bt_conn_le_create()`](https://docs.zephyrproject.org/latest/doxygen/html/group__bt__conn.html#ga8d66f3e0262a51279e9fa8b3139252e6) 后取得连接对象。

> 译注——返回值与输出参数：原文称通过 [`bt_conn_le_create()`](https://docs.zephyrproject.org/latest/doxygen/html/group__bt__conn.html#ga8d66f3e0262a51279e9fa8b3139252e6) 的“return value”取得对象；[官方连接头文件](https://raw.githubusercontent.com/zephyrproject-rtos/zephyr/main/include/zephyr/bluetooth/conn.h)的实际签名返回 `int`，成功为0，失败为负错误码。对象通过 `struct bt_conn **conn` 输出参数取得；上述空值检查指调用者对象指针的值，不是要求把输出参数地址本身设为NULL。应区分返回状态、对象引用与实际连接状态。
