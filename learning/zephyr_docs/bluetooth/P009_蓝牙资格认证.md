# 第9章\_蓝牙资格认证

原文：[官方页面](https://docs.zephyrproject.org/latest/services/connectivity/bluetooth/bluetooth-qual.html)。读取日期：2026-10-14；保存的 latest 页面及 HTML 摘要见[来源记录](../SOURCES.md)。

蓝牙技术联盟（Bluetooth Special Interest Group，Bluetooth SIG）资格认证流程的详细说明见[官方资格认证入口](https://www.bluetooth.com/develop-with-bluetooth/qualify)。

<a id="qualification-setup"></a>

## 9.1\_资格认证设置（Qualification setup）

Zephyr蓝牙主机（Host）可以使用蓝牙协议配置测试套件（Profile Tuning Suite，PTS）进行资格认证测试。原本是手工流程，可通过 [AutoPTS自动化软件](https://github.com/auto-pts/auto-pts)自动执行。详细设置见：

- [Windows 10与nRF52开发板上的AutoPTS](P065_Windows10上的AutoPTS.md)。
- [Linux上的AutoPTS](P064_Linux上的AutoPTS.md)。

<a id="ics-features"></a>

## 9.2\_实现一致性声明特性（ICS Features）

Zephyr Host特性的实现一致性声明（Implementation Conformance Statement，ICS）文件已按原件保存：[ICS_Zephyr_Bluetooth_Host.pts](files/ICS_Zephyr_Bluetooth_Host.pts)。也可从[官方原始附件](https://docs.zephyrproject.org/latest/_downloads/6f0d89ee8c4a7803a28deb6f1e9659c8/ICS_Zephyr_Bluetooth_Host.pts)下载。

使用[蓝牙资格认证网站](https://qualification.bluetooth.com/)查看和编辑ICS。

> 译注：此处本地附件保留官方原始字节，来源及SHA-256摘要见[来源记录](../SOURCES.md)。文件随译文交付，不要求阅读器直接识别`.pts`；需要查看或编辑时使用官方说明的工具。

<a id="qualified-releases"></a>

## 9.3\_已通过资格认证的发行版本（Qualified releases）

Zephyr项目提供预先通过资格认证的蓝牙Host协议栈，便于用户构建通过资格认证的蓝牙产品。该协议栈可以纳入产品的资格认证设计，提供功能覆盖并减少认证工作。不同发行版本的认证范围可能不同，详情见下表。

| 发行版本（Release） | 设计编号（Design Number） | 详情（Details） |
| --- | --- | --- |
| v4.4 | Q385945 | [蓝牙资格认证记录332380](https://qualification.bluetooth.com/ListingDetails/332380) |

> 译注：表格保留读取时官方页面所列版本与编号，不表示所有后续版本自动具有同一覆盖范围，也不表示集成该协议栈的最终产品无需完成自身流程。本次未提交认证申请或执行PTS测试。

对应官方文档源码：[doc/services/connectivity/bluetooth/bluetooth-qual.rst](https://raw.githubusercontent.com/zephyrproject-rtos/zephyr/main/doc/services/connectivity/bluetooth/bluetooth-qual.rst)。
