# 第103章\_固件更新客户端（Firmware Update Client）

原文：[官方页面](https://docs.zephyrproject.org/latest/services/connectivity/bluetooth/api/mesh/dfu_cli.html)。快照读取日期：2026-10-15；来源摘要见[来源记录](../SOURCES.md)。

固件更新客户端（Firmware Update Client）负责通过 Mesh 网络分发固件更新，并使用大对象传输客户端作为底层传输机制。 相关链接：[大对象传输客户端（BLOB Transfer Client）](P099_Mesh大对象传输客户端.md#bluetooth-mesh-blob-cli)。
