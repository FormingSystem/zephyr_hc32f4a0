## 概述（Overview）

Microchip M2GL025是一款基于IGLOO2 FPGA的开发板，可部署Mi-V RISC-V软核CPU。原文此处也使用MGL025名称，更多信息见[Microchip网站](https://www.microchip.com/en-us/products/fpgas-and-plds/fpga-and-soc-design-tools/mi-v)。

<a id="flashing"></a>

### 烧录（Flashing）

向设备上传应用需要支持RISC-V的OpenOCD和GDB，可从SoftConsole SDK获取，下载及安装说明见[Microchip SoftConsole网站](https://www.microchip.com/en-us/products/fpgas-and-plds/fpga-and-soc-design-tools/soc-fpga/softconsole)。

安装所需工具后，可通过OpenOCD连接开发板，执行以下命令建立连接：

```text
sudo LD_LIBRARY_PATH=<softconsole_path>/openocd/bin \
<softconsole_path>/openocd/bin/openocd  --file \
<softconsole_path>/openocd/share/openocd/scripts/board/microsemi-riscv.cfg
```

保持OpenOCD运行，在另一个终端中通过GDB将二进制文件上传到开发板。可使用SoftConsole SDK工具链提供的RISC-V GDB。

在GDB终端中使用以下命令连接设备并加载二进制文件：

```text
<softconsole_path>/riscv-unknown-elf-gcc/bin/riscv64-unknown-elf-gdb \
-ex "target extended-remote localhost:3333" \
-ex "set mem inaccessible-by-default off" \
-ex "set arch riscv:rv32" \
-ex "set riscv use_compressed_breakpoints no" \
-ex "load" <path_to_executable>
```
