## 概述（Overview）

UPD301C基础受电端应用示例评估套件EV11L78A，是面向Microchip UPD301C独立可编程USB供电协议（PD / Power Delivery）控制器的低成本评估平台。它符合RoHS，采用小尺寸设计，并遵循USB Type-C连接器规范及USB PD 3.0规范。

<a id="hardware"></a>

## 硬件（Hardware）


- 48 MHz ATSAMD20E16 Arm Cortex-M0+处理器
- UPD301C结合SAMD20内核及UPD350 USB-PD控制器
- 受电端电源数据对象（Sink PDO）选择开关
- 板载LED电压表（Voltmeter）

<a id="serial-port"></a>

### 串口（Serial Port）

SAMD20 MCU有6个基于串行通信模块（SERCOM）的USART，其中SERCOM1引出到Debug／Status排针。

<a id="spi-port"></a>

### SPI端口（SPI Port）

SAMD20 MCU有6个基于SERCOM的SPI，其中SERCOM0在内部连接SAMD20内核与UPD350。

<a id="i2c-port"></a>

### I²C端口（Port）

SAMD20 MCU有6个基于SERCOM的I2C，其中SERCOM3引出到Debug／Status排针。
