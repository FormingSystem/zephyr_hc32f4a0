# 线性插值参考大纲

线性插值（Linear Interpolation）使用相邻采样点之间的直线估算给定X坐标的Y值。本册对应官方公共接口、头文件参考和源码浏览页，保留参数、返回值、可见代码及法律注释。

源码译注说明升序数组和点数前提、端点直接返回、区间查找、浮点舍入和整数差值范围；原表排版缺陷与实现差异均明确标注。所有本地定位使用相对路径，完整范围见[全站进度](../PROGRESS.md)。
