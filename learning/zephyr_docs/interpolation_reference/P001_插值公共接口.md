## 1.2\_详细说明（Detailed Documentation）

<a id="ga8abbb1799796222b39a051819bd19a2a"></a>

### `linear_interpolate()`

```c
int32_t linear_interpolate ( const int32_t * x_axis, const int32_t * y_axis, uint8_t len, int32_t x )
```

声明属性：`inline`、`static`。

```c
#include <zephyr/math/interpolation.h>
```

在任意曲线的数据点之间执行线性插值（Linear Interpolation）。

**参数（Parameters）**

| 名称／方向 | 说明 |
| --- | --- |
| `x_axis` | y_axis 数据点对应的 X 坐标列表，按升序排列。 |
| `y_axis` | 每个 X 数据点对应的 Y 坐标。 |
| `len` | x_axis 与 y_axis 两个数组的长度。 |
| `x` | 要查询的 X 坐标。 |

**返回值（Return Values）**

| 名称／方向 | 说明 |
| --- | --- |
| `y_axis[0]` | x < x_axis[0] 时。 |
| `y_axis[len` | - 1]，当 x > x_axis[len - 1] 时。 |
| `int32_t` | 在最接近的两个 y_axis 值之间进行线性插值的结果。 |

**说明（Note）**：注意：结果向远离 0 的方向舍入，例如 1.5 -> 2、-5.5 -> -6。

> 译注——源码核对：端点处理：原文返回值条件写x<首点和x>末点，实际实现分别使用<=和>=，相等时也直接返回相应端点值。范围外返回端点值，不延长末端线段做外推（Extrapolation）；范围内从头顺序查找区间，恰好命中采样点时直接返回该点Y值。
>
> 译注——源码核对：返回表排版：官方Doxygen表把y_axis[len - 1]在空格处拆开，左列成为y_axis[len，右列以- 1]开头。表中保留原页形态，完整含义是x大于末端X时返回y_axis[len - 1]，不是另一个返回表达式或错误码。
>
> 译注——源码核对：舍入语义：源码调用roundf，按最接近的整数舍入，只有恰好位于半整数时才选择远离0的一侧；例如1.5得到2、-5.5得到-6，但1.2得到1。原文“远离0”不能理解为所有非整数都向外取整。计算还使用float，舍入之前的插值结果本身可能已有浮点误差。
>
> 译注——源码核对：数值范围：x-x_axis[idx_low]以及相邻X、Y之差先按int32_t进行减法，再用于或转换为float。即使变量rise和run声明为float，也不能防止减法中间结果先发生有符号溢出。输入跨度应保证这些差值可表示，舍入后的浮点结果也必须可由int32_t表示；函数不做饱和处理或溢出报告。

## 1.3\_源码定位与版本边界

本册包含[公共接口](P001_插值公共接口.md)、[头文件参考](P002_插值头文件参考.md)和[可见源码](P003_插值头文件源码.md)。相对源码定位：[interpolation.h](../../../include/zephyr/math/interpolation.h)。对应[官方原始头文件](https://github.com/zephyrproject-rtos/zephyr/blob/main/include/zephyr/math/interpolation.h)的本次摘要见[来源记录](../SOURCES.md)。

> 译注——源码核对：数据前提：两个数组须有效且都至少含len个元素，X坐标应严格递增，使每个区间有正宽度。len为uint8_t，调用者应保证有效点数在1至255范围；函数不检查空指针、零长度、数组长度不一致或乱序。len=1时，当前边界分支始终返回唯一的Y值。

> 译注——源码核对：版本与验证：完整保留声明、参数、返回值及源码注释。源码页去除注释和展示空白后与本次官方interpolation.h一致；相对源码链接用于跟踪，不保证本地基线与滚动main相同。本次只做文档和源码核对，未编译运行端点、精度或溢出实验。
