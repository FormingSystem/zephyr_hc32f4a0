# SPI驱动头文件参考大纲

本册完整翻译SPI（串行外设接口，Serial Peripheral Interface）驱动主头文件的参考页及源码浏览页，涵盖控制器（Controller）与外设（Peripheral）模式、时钟与数据字配置、片选（Chip Select，CS）、同步和异步传输、实时I/O（RTIO）与设备定义。详细约定见[SPI公共API](../hardware/P318_SPI公共接口.md)，绑定常量见[SPI绑定头文件参考](../dt_bus_binding_reference/P003_SPI绑定常量头文件参考.md)。

参考页保留声明和摘要，源码页保留可见实现、注释、行号定位和符号提示。源码跟踪译注说明操作位、片选初始化形式与延时单位、总线就绪、异步等待、RTIO入口及统计范围。原代码、许可证与中英文术语保留，仓库定位使用相对路径。完整范围见[全站进度](../PROGRESS.md)。
