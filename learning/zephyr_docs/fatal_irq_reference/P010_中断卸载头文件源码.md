## 10.4\_源码跟踪译注

> 译注——中断卸载（IRQ Offload）同步地在中断上下文执行回调，不是把工作提交给工作队列（Workqueue）。原文参数说明提到“所提供的设备”，但声明的实际参数类型是const void *，用于传递调用方上下文，并不限定为设备对象。

> 译注——通用实现只在CONFIG_IRQ_OFFLOAD_NESTED分支直接调用架构卸载接口；其他配置先取得信号量，再调用并释放。是否允许从ISR嵌套卸载仍取决于架构能力、硬件优先级和配置，不可由同步调用性质推断任意ISR都能调用。

> 译注——本次ARM实现通过SVC进入中断上下文，在进入前后锁定／解锁调度器，并临时保存回调与参数。部分基线架构对PRIMASK状态另有断言。本页跟踪官方架构实现，未验证某块板的SVC优先级或嵌套行为。

头文件相对定位：[include/zephyr/irq_offload.h](../../../include/zephyr/irq_offload.h)，关联实现／接口：[kernel/irq_offload.c](../../../kernel/irq_offload.c)；[官方原始头文件](https://github.com/zephyrproject-rtos/zephyr/blob/main/include/zephyr/irq_offload.h)与[官方关联文件](https://github.com/zephyrproject-rtos/zephyr/blob/main/kernel/irq_offload.c)的摘要见来源记录。去掉注释和展示空白后，本页代码与本次读取的原始头文件一致，不能推广到以后滚动更新的main或任意本地版本。
