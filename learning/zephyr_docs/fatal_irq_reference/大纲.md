# 致命错误与中断参考大纲

本册翻译致命错误处理（Fatal Error Handling）、错误原因（Fatal Error Reasons）、中断服务例程（ISR）、架构中断（Architecture Interrupts）、中断卸载（IRQ Offload）、CPU空闲（CPU Idle）与浮点上下文（Floating-point Context）的官方参考，包含三个头文件的完整可见源码，共十二份官方页面。

正文保留接口签名、参数、返回值、调用约束和原始示例。源码页保留代码、法律声明、原始行号锚点和符号提示，英文注释另列中文对照。源码跟踪译注独立说明配置分支、中断状态恢复、直接中断限制与架构差异；仓库环境和实验记录位于独立资料区。
