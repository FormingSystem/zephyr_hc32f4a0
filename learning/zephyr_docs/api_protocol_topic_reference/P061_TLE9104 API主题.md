### `sensor_channel_tle9104`

```c
enum sensor_channel_tle9104
```

```c
#include <zephyr/drivers/sensor/tle9104.h>
```

TLE9104 的自定义传感器通道（Custom Sensor Channels）。

**枚举值（Enumerators）**

| 名称／方向 | 说明 |
| --- | --- |
| `SENSOR_CHAN_TLE9104_OPEN_LOAD` | 检测到负载开路（open load）。布尔值，每个输出对应一位。例如，若 `sensor_value.val1 == 0b0101`，则表示在 `OUT1` 和 `OUT3` 上检测到负载开路。 |
| `SENSOR_CHAN_TLE9104_OVER_CURRENT` | 检测到过流（over current）。布尔值，每个输出对应一位。例如，若 `sensor_value.val1 == 0b0110`，则表示在 `OUT2` 和 `OUT3` 上检测到过流。 |
