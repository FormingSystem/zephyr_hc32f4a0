## 21.3\_详细说明（Detailed Documentation）

<a id="ga807b05c9730fdb0e79190d8fac16b938"></a>

### `hx711_gain`

```c
enum hx711_gain
```

```c
#include <zephyr/drivers/sensor/hx711.h>
```

下次读取操作（Read Operation）的增益选项（Gain Options）。

**枚举值（Enumerators）**

| 名称／方向 | 说明 |
| --- | --- |
| `HX711_GAIN_64` | 增益（Gain）为 64。 |
| `HX711_GAIN_128` | 增益（Gain）为 128。 |

<a id="ga33e13fc2924e2c67ff411d8518290c88"></a>

### `sensor_attribute_hx711`

```c
enum sensor_attribute_hx711
```

```c
#include <zephyr/drivers/sensor/hx711.h>
```

HX711 的自定义传感器属性（Custom Sensor Attributes）。

**枚举值（Enumerators）**

| 名称／方向 | 说明 |
| --- | --- |
| `SENSOR_ATTR_HX711_CONV_FACTOR` | 电压到质量的换算系数（voltage to mass conversion factor），单位为 kg/μV。 |
| `SENSOR_ATTR_HX711_OFFSET` | 相对于传感器真实零点的电压偏移（voltage offset），用于质量换算。 |

<a id="ga16ab3a4dd1f68f004c9c7797c4ec8f54"></a>

### `sensor_channel_hx711`

```c
enum sensor_channel_hx711
```

```c
#include <zephyr/drivers/sensor/hx711.h>
```

HX711 的自定义传感器通道（Custom Sensor Channels）。

**枚举值（Enumerators）**

| 名称／方向 | 说明 |
| --- | --- |
| `SENSOR_CHAN_HX711_MASS` | 测得的质量（mass），单位为克。 |
