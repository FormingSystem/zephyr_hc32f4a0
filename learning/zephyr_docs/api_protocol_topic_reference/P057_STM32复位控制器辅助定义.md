# 第57章\_STM32复位控制器辅助定义

原文：[官方页面](https://docs.zephyrproject.org/latest/doxygen/html/group__reset__controller__stm32.html)。读取日期：2026-10-17；来源摘要见[来源记录](../SOURCES.md)。

用于编码STM32外设复位说明单元的宏。

<a id="details"></a>

用于编码 STM32 外设复位单元（peripheral reset cells）的宏。此设备树宏用于编码 STM32 设备的外设复位单元，供兼容 `st,stm32-rcc-rctl` 的复位控制器使用。各 SoC 系列头文件（例如 `stm32h5_reset.h`）均将该系列的 RCC 总线复位寄存器偏移量定义为 `STM32_RESET_BUS_<bus>` 常量。随后使用 `STM32_RESET()`，将总线常量与外设复位线在该总线复位寄存器中的位位置组合，编码成外设复位单元。

注意：STM32MP1 和 STM32MP13 使用独立的置位／清零（SET/CLEAR）偏移量重新定义 `STM32_RESET()`；STM32MP2 则使用每个外设各自的寄存器。下方保留原始配置示例。

```c
#include <zephyr/dt-bindings/reset/stm32h5_reset.h>

&usart1 {
        resets = <&rctl STM32_RESET(APB2, 14)>;
};
```

## 57.2\_宏定义（Macros）

<a id="r_ga6a12a4b8c042157a88ddf7da442c137c"></a>

```c
#define STM32_RESET(bus, bit)
```

相关声明：[STM32_RESET](#ga6a12a4b8c042157a88ddf7da442c137c)。

为 `st,stm32-rcc-rctl` 绑定编码外设复位单元值（Peripheral Reset Cell Value）。

## 57.3\_详细说明（Detailed Documentation）

<a id="ga6a12a4b8c042157a88ddf7da442c137c"></a>

### `STM32_RESET`

```c
#define STM32_RESET ( bus, bit )
```

```c
#include <zephyr/dt-bindings/reset/stm32-common.h>
```

展开值（Value）：

```c
(((STM32_RESET_BUS_##bus) << 5U) | (bit))
```

为 `st,stm32-rcc-rctl` 绑定编码外设复位单元值（Peripheral Reset Cell Value）。

将 RCC 总线寄存器偏移量及位位置打包为一个 32 位复位单元值（reset cell value）。

位 `[4:0]` 保存复位位在 32 位 RCC 总线寄存器中的位置；位 `[16:5]` 保存 RCC 寄存器相对于 RCC 基地址的字节偏移量。

**参数（Parameters）**

| 名称／方向 | 说明 |
| --- | --- |
| `bus` | RCC 总线名称（bus name）。 |
| `bit` | 外设复位线在总线复位寄存器中的位位置。 |
