## 43.3\_详细说明（Detailed Documentation）

<a id="ga6e9d013c0dc687f05c27dc907bb56c65"></a>

### `sensor_channel_pat9136`

```c
enum sensor_channel_pat9136
```

```c
#include <zephyr/drivers/sensor/pat9136.h>
```

PAT9136 的自定义传感器通道（Custom Sensor Channels）。

此传感器能够以有实际意义的单位提供 DXY，而标准通道（`SENSOR_CHAN_POS_DX`、`SENSOR_CHAN_POS_DY`、`SENSOR_CHAN_POS_DXYZ`）的单位是点（points），因此定义以下通道，为此传感器提供另一种表示方式。

**枚举值（Enumerators）**

| 名称／方向 | 说明 |
| --- | --- |
| `SENSOR_CHAN_POS_DX_MM` | X 轴位置变化（position change），单位为毫米。 |
| `SENSOR_CHAN_POS_DY_MM` | Y 轴位置变化，单位为毫米。 |
| `SENSOR_CHAN_POS_DXYZ_MM` | X、Y 和 Z 轴的位置变化，单位为毫米。加入额外的偏移量（offset），以便即使不支持 DZ，也能相对于 XYZ 访问 X 和 Y 通道。 |
