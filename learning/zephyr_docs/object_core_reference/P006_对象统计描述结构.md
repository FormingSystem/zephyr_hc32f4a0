## 6.3\_源码定位与版本边界

相对源码定位：[对象核心头文件](../../../include/zephyr/kernel/obj_core.h)、[对象核心实现](../../../kernel/obj_core.c)、[内核配置入口](../../../kernel/Kconfig)、[内核构建入口](../../../kernel/CMakeLists.txt)、[对象核心配置](../../../kernel/Kconfig.obj_core)。官方源码摘要见[来源记录](../SOURCES.md)。

> 译注——源码核对：对象核心（Object Core）用于按对象类型组织、枚举内核对象并接入统计，不等同于跟踪事件输出。以下源码译注以来源记录中的官方版本摘要为界，与官方正文分开；仓库定位使用相对路径。

> 译注——源码核对：对象登记与统计登记是两件事。stats_register检查类型的统计描述符及raw_size后保存stats指针，不分配或复制统计缓冲区；deregister清除该指针，不释放调用者内存。官方“自动启用”是接口语义，本次register实现没有调用描述符的enable回调，不能推断注册会执行与显式enable完全相同的后端动作。

> 译注——源码核对：raw按raw_size检查缓冲区长度，query按query_size检查，要求相等而不是至少足够大；query可由回调生成平均值等报告数据。描述符或对应回调缺失时返回-ENOTSUP，大小错误或对象尚未登记统计时可返回-EINVAL，其余结果由回调返回。

> 译注——源码核对：统计raw、query、reset、disable、enable在obj_core_lock持锁期间调用对应回调，这与对象walk_locked在回调前解锁不同。统计回调应遵守自旋锁上下文，不能阻塞或递归进入再次获取同一锁的对象核心操作。

> 译注——源码核对：原文disable说明中包含损坏的:c:func标记，本译文保留其目标k_obj_core_stats_enable并正常呈现函数名称。disable与reset、deregister各有独立职责；停止收集不等于清零或释放统计存储。

> 译注——源码核对：描述符保存raw_size、query_size和五个操作函数指针，不包含实际统计缓冲区；对象自己的stats指针关联原始数据。不同类型可不实现某些回调，调用端需要处理不支持结果。

> 译注——源码核对：本次验证限于官方文档及源码对照，未运行对象并发测试、统计采集或实板验证。

本次验证范围为文档与源码对照，未构建固件、配置实板引脚或操作硬件。
