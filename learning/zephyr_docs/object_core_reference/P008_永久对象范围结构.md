# 第8章\_永久对象范围结构

原文：[官方页面](https://docs.zephyrproject.org/latest/doxygen/html/structk__obj__range.html)。读取日期：2026-10-15；来源摘要见[来源记录](../SOURCES.md)。

> 译注——阅读位置：从[本册大纲](大纲.md)进入对象核心、统计接口、头文件源码及配套结构体参考，再通过接口链接进入完整说明。源码跟踪译注与官方原文分开标示。

同一类型永久对象（Permanent Objects）的连续范围。

```c
#include <zephyr/kernel/obj_core.h>
```

<a id="details"></a>

同一类型永久对象（Permanent Objects）的连续范围。范围中的对象通过遍历该范围枚举，因此从不在运行时逐个登记。范围保存对象本身；若设置indirect，则保存指向这些对象的指针。

## 8.3\_源码定位与版本边界

相对源码定位：[对象核心头文件](../../../include/zephyr/kernel/obj_core.h)、[对象核心实现](../../../kernel/obj_core.c)、[内核配置入口](../../../kernel/Kconfig)、[内核构建入口](../../../kernel/CMakeLists.txt)、[对象核心配置](../../../kernel/Kconfig.obj_core)。官方源码摘要见[来源记录](../SOURCES.md)。

> 译注——源码核对：对象核心（Object Core）用于按对象类型组织、枚举内核对象并接入统计，不等同于跟踪事件输出。以下源码译注以来源记录中的官方版本摘要为界，与官方正文分开；仓库定位使用相对路径。

> 译注——源码核对：范围采用半开区间[start, end)，stride表示相邻元素之间的字节步长。indirect为false时元素本身是对象，为true时元素保存对象指针；当前range_core据此先取对象地址，再加类型的obj_core_offset得到核心地址。

> 译注——源码核对：永久范围的存储须满足官方生命周期约定；间接范围中的对象指针也必须有效。stride为0终止范围列表，不表示逐字节遍历；函数不会自动校验任意地址、步长或对象布局是否匹配。

> 译注——源码核对：本次k_obj_type_init_range仅填statics[0]。类型结构最多容纳K_OBJ_TYPE_MAX_RANGES个范围，多范围初始化与可迭代段（Iterable Sections）的具体方式应结合头文件源码，不能把一个范围的元素数量误当作范围槽数量。

> 译注——源码核对：本次验证限于官方文档及源码对照，未运行对象并发测试、统计采集或实板验证。
