### `bt_mesh_suspend()`

```c
int bt_mesh_suspend ( void )
```

```c
#include <zephyr/bluetooth/mesh/main.h>
```

临时挂起 Mesh 网络（Suspend Mesh Network）。

此 API 可用于节能（Power Saving），但用户应注意，长时间挂起本地节点可能使其永久脱离 Mesh 网络。只要可行，就应改用友谊关系特性（Friendship Feature），使节点成为低功耗节点（Low Power Node）。

**返回值（Return Values）**

| 名称／方向 | 说明 |
| --- | --- |

| `-EBUSY` | 配网（Provisioning）正在进行。 |
| `Other` | 失败时返回负 `errno` 错误码。 |

**说明（Note）**：注意（Note）：配网（Provisioning）在设计上不支持挂起。如果在配网过程中调用此 API，将无法挂起，函数会返回错误。

### `bt_mesh_va_uuid_get()`

```c
const uint8_t * bt_mesh_va_uuid_get ( uint16_t addr, const uint8_t * uuid, uint16_t * retaddr )
```

```c
#include <zephyr/bluetooth/mesh/main.h>
```

遍历存储的标签 UUID（Label UUIDs）。

addr 为 BT_MESH_ADDR_UNASSIGNED 时，此函数从 uuid 开始遍历所有可用地址。此时通过 retaddr 获取返回的标签 UUID（Label UUID）所对应的虚拟地址（Virtual Address）。addr 为虚拟地址时，此函数返回该 addr 对应的下一个标签 UUID。uuid 为 NULL 时，返回第一个可用 UUID；uuid 为先前返回的 UUID 时，返回后续 UUID。

**参数（Parameters）**

| 名称／方向 | 说明 |
| --- | --- |
| `addr` | 要搜索的虚拟地址（Virtual Address），或 BT_MESH_ADDR_UNASSIGNED。 |
| `uuid` | 指向先前返回的标签 UUID（Label UUID）的指针，或 NULL。 |
| `retaddr` | 指向一块内存的指针，用于存放返回 UUID 所对应的虚拟地址（Virtual Address）。 |

返回（Returns）：指向标签 UUID（Label UUID）的指针；没有更多条目时返回 NULL。
