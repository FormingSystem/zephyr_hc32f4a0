# PWM设备树与总线绑定常量参考大纲

本册完整翻译PWM设备树访问宏、PWM绑定常量和I2C绑定常量三个头文件的参考页与源码浏览页。PWM（脉宽调制，Pulse Width Modulation）访问宏读取控制器、通道、周期和标志；绑定常量表达周期尺度和极性。I2C（集成电路互连总线，Inter-Integrated Circuit）绑定头文件提供比特率与通道编号。

从参考页辨认接口，再对照源码页理解实际展开；详细驱动接口通过相对链接进入已译专题。源码跟踪译注明确flags缺省值的节点版与实例版差异、频率换算中的整数除法以及硬件支持边界。原代码、注释和许可证保留，术语中英文对照，所有仓库定位使用相对路径。完整范围见[全站进度](../PROGRESS.md)。
