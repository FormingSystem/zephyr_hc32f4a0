# 日志链路接口参考大纲

本册翻译日志链路（Log Link）API、头文件参考与源码，以及链路对象、操作表、配置和控制块，共七份官方页面。链路把远端日志域的消息接入本地核心。

接口覆盖实例定义、专用缓冲区、初始化与激活、域与源数量、名称查询和级别设置。源码跟踪译注说明缓冲区以32位字计量、状态查询的整数返回值、相对域编号、名称长度及当前零级别断言限制。
