<a id="ga72e1a700a3c87c718f1b0aae694e4bb8"></a>

### `sys_ref_get()`

```c
void sys_ref_get ( struct sys_ref *const ref)
```

声明属性：`inline`、`static`。

```c
#include <zephyr/sys/ref.h>
```

增加对象的引用。

只有调用者已经持有有效引用时才可安全调用；这个引用使对象保持存活，并确保计数器非零。本函数不能用于取得第一个引用，首次建立引用应参见sys_ref_init()；也不能复活引用数可能已经降为零的对象。

**参数（Parameters）**

| 名称／方向 | 说明 |
| --- | --- |
| `[in] ref` | 引用。 |

> 译注——源码核对：取得引用的前提：get要求调用者已持有有效引用。仅从无同步的裸指针读取对象地址后再get，不能阻止另一方在两步之间释放对象；本接口没有从零尝试获取的try-get或弱引用（Weak Reference）机制。发布对象指针与取得有效所有权需要调用者另行保证。

<a id="gab120c720185f1949af6ad515f213d55d"></a>

### `sys_ref_init()`

```c
void sys_ref_init ( struct sys_ref *const ref)
```

声明属性：`inline`、`static`。

```c
#include <zephyr/sys/ref.h>
```

将引用初始化为1。

对象创建者必须在对引用执行其他操作之前调用一次。它建立第一个引用，该引用归调用者所有，并通过sys_ref_put()释放。

**参数（Parameters）**

| 名称／方向 | 说明 |
| --- | --- |
| `[in] ref` | 引用。 |

<a id="ga57f2e3a7b98f0141c1f29aa118db82cb"></a>

### `sys_ref_put()`

```c
bool sys_ref_put ( struct sys_ref *const ref, const sys_ref_release_t release )
```

声明属性：`inline`、`static`。

```c
#include <zephyr/sys/ref.h>
```

减少对象的引用。

递减引用数，并在最后一个引用被释放时调用release。调用后，调用者不得再访问对象，因为对象可能已经被释放。

释放处理函数通过CONTAINER_OF找回包含此引用的外层对象，并释放其持有的资源：

原始示例（Example）：

```c
struct my_obj {
        struct sys_ref ref;
        ...
};

static void my_obj_release(struct sys_ref *const ref)
{
        struct my_obj *obj = CONTAINER_OF(ref, struct my_obj, ref);

        k_free(obj);
}

sys_ref_put(&obj->ref, my_obj_release);
```

**参数（Parameters）**

| 名称／方向 | 说明 |
| --- | --- |
| `[in] ref` | 引用。 |
| `[in] release` | 释放对象的处理函数。 |

**返回值（Return Values）**

| 名称／方向 | 说明 |
| --- | --- |
| `true` | 对象已被释放时。 |
| `false` | 其他情况。 |

> 译注——源码核对：释放语义：put把本次持有权交还后，调用者不能再凭该引用访问对象，即使返回false也不能推断之后一直存活；其他持有者可能随即完成最后一次put。返回true表示本次递减到零并调用了release，资源是否实际释放由处理函数负责。 回调（Callback）：release作为每次put的参数传入，不存储在sys_ref中。所有持有者应采用与对象类型及分配方式一致的释放处理函数。回调在最后一次put的调用上下文中同步执行，没有自动转交线程或工作队列；是否可阻塞、能否在中断中运行取决于调用上下文及处理函数。

<a id="gaa0532e7482ec96eda9906fb17b7e0e2c"></a>

### `sys_refcount_dec()`

```c
bool sys_refcount_dec ( struct sys_refcount *const rc)
```

声明属性：`inline`、`static`。

```c
#include <zephyr/sys/ref.h>
```

递减引用计数器。

计数器不得为零。饱和计数器（Saturated Counter）保持固定，不会再降为零。

**参数（Parameters）**

| 名称／方向 | 说明 |
| --- | --- |
| `[in] rc` | 引用计数器。 |

**返回值（Return Values）**

| 名称／方向 | 说明 |
| --- | --- |
| `true` | 计数器降为零时。 |
| `false` | 其他情况。 |

> 译注——源码核对：饱和（Saturation）：当前上限为LONG_MAX；计数达到此值后，inc直接返回，dec始终返回false，既不继续增长也不下降，因而不会触发最终释放。这是避免计数回绕后过早释放的取舍，可能保留对象而造成泄漏，不是正常生命周期已完成的标记。 断言边界：原文的下溢保护依赖断言启用。当前inc检查old!=0，dec检查old>0；断言关闭后，对零计数调用仍可能写入1或-1，不能把接口解释成无条件拒绝错误调用。对象已释放后，连读取计数本身也可能无效，断言不提供悬空指针保护。

<a id="ga3a00a4e15971bac0d238078dd340cac4"></a>

## 1.6\_源码定位与版本边界

对照[公共API](P001_引用计数接口.md)、[引用对象](P002_引用计数对象.md)、[头文件参考](P003_引用计数头文件参考.md)、[源码浏览](P004_引用计数头文件源码.md)与[内部计数器](P005_内部引用计数结构.md)。实现位于官方include/zephyr/sys/ref.h；当前仓库源码基线尚无此文件，本地阅读请使用[官方源码译文页](P004_引用计数头文件源码.md)。本次[官方原始头文件](https://github.com/zephyrproject-rtos/zephyr/blob/main/include/zephyr/sys/ref.h)摘要见[来源记录](../SOURCES.md)。

> 译注——源码核对：用途与所有权：sys_ref嵌入共享对象，管理其生命周期（Lifetime）；它不分配对象，也不自动知道如何释放外层资源。init或静态初始化建立调用者拥有的第一个引用，后续每个有效的get应由相应持有者以put配对释放。不要对仍被共享的对象再次初始化计数。

> 译注——源码核对：取得引用的前提：get要求调用者已持有有效引用。仅从无同步的裸指针读取对象地址后再get，不能阻止另一方在两步之间释放对象；本接口没有从零尝试获取的try-get或弱引用（Weak Reference）机制。发布对象指针与取得有效所有权需要调用者另行保证。

> 译注——源码核对：原子操作范围：增减通过原子比较并交换（Compare-and-swap，CAS）循环更新计数，竞争失败后重新读取再尝试。它保护计数更新，不替代对象其他字段的互斥，也不自动解除对象之间的循环持有。对象之间的引用环需由应用设计打破。

> 译注——源码核对：饱和（Saturation）：当前上限为LONG_MAX；计数达到此值后，inc直接返回，dec始终返回false，既不继续增长也不下降，因而不会触发最终释放。这是避免计数回绕后过早释放的取舍，可能保留对象而造成泄漏，不是正常生命周期已完成的标记。

> 译注——源码核对：断言边界：原文的下溢保护依赖断言启用。当前inc检查old!=0，dec检查old>0；断言关闭后，对零计数调用仍可能写入1或-1，不能把接口解释成无条件拒绝错误调用。对象已释放后，连读取计数本身也可能无效，断言不提供悬空指针保护。

> 译注——源码核对：释放语义：put把本次持有权交还后，调用者不能再凭该引用访问对象，即使返回false也不能推断之后一直存活；其他持有者可能随即完成最后一次put。返回true表示本次递减到零并调用了release，资源是否实际释放由处理函数负责。

> 译注——源码核对：回调（Callback）：release作为每次put的参数传入，不存储在sys_ref中。所有持有者应采用与对象类型及分配方式一致的释放处理函数。回调在最后一次put的调用上下文中同步执行，没有自动转交线程或工作队列；是否可阻塞、能否在中断中运行取决于调用上下文及处理函数。

> 译注——源码核对：示例与版本：原例中的省略号表示结构或初始化内容尚未展开，不是可原样编译的完整程序。k_free只适用于相应堆分配的对象；静态、栈或其他分配器管理的对象不能照抄此释放方式。原文和代码保留，本次源码核对不代表已运行并发、饱和或释放实验。

本次验证范围为文档与源码对照，未编译或执行引用计数、并发释放、饱和及实板实验。
