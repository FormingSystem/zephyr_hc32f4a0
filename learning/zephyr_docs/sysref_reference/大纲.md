# 引用计数参考大纲

引用计数（Reference Counting）让多个使用者共同持有对象：创建者先建立一个引用，已有持有者可增加引用，每次放弃持有权时递减，最后一次释放调用处理函数。sys_ref嵌入应用对象，sys_refcount提供内部的原子饱和计数；引用计数管理存活时间，不替代对象内容的互斥访问。

本册覆盖官方公共接口、两种结构及头文件参考与源码。原文声明、参数、返回值、两个示例、原始代码和法律注释完整保留；源码跟踪译注说明获取引用的前提、CAS竞争、饱和、断言配置和回调执行上下文。所有本地定位采用相对路径，完整范围见[全站进度](../PROGRESS.md)。
