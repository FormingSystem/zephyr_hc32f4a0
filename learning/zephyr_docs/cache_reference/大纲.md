# 缓存公共接口与头文件参考大纲

本册翻译公共缓存接口（Cache Interface）、外部缓存控制器接口（External Cache Controller Interface），以及公共、外部控制器和架构缓存三个头文件的参考与源码，共八份官方页面。架构操作的完整函数说明见[架构缓存接口](../arch_core_reference/P002_架构缓存接口.md)。

公共sys_cache_*接口按配置选择后端。写回（Flush）、失效（Invalidate）、缓存行大小查询、缓存地址别名与内存一致性查询各有不同条件；本册保留参数、返回值、调用限制和原始声明，尤其保留区间失效的对齐要求及未定义行为警告。

三个源码浏览页保留全部可见代码、注释、许可证、符号提示和行号锚点。源码跟踪译注区分配置不满足时的空操作与-ENOTSUP，说明用户空间校验、地址别名以及原文的一致性和缓存类型措辞差异。文档链接与仓库源码定位采用相对路径，官方待译内容仍按[全站进度](../PROGRESS.md)跟踪。
