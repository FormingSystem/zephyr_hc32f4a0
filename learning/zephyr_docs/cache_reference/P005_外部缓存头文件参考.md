## 5.2\_源码定位与版本边界

源码定位：[include/zephyr/drivers/cache.h](../../../include/zephyr/drivers/cache.h)、[include/zephyr/cache.h](../../../include/zephyr/cache.h)。官方源码摘要见[来源记录](../SOURCES.md)。

> 译注——源码核对：以下源码跟踪译注独立于官方正文，依据来源记录中保存摘要的官方main文件。源码定位采用相对链接；接口与后端实现对照不表示目标板已经启用缓存或通过DMA／多核一致性验证。

> 译注——源码核对：外部缓存控制器（External Cache Controller）页给出cache_data_*与cache_instr_*后端函数契约，头文件本身只声明这些函数，不完成设备初始化，也不保证具体控制器实现全部操作。需要区分CONFIG_DCACHE／ICACHE可用条件和-ENOTSUP返回语义。

> 译注——源码核对：动态缓存行检测接口由CONFIG_DCACHE_LINE_SIZE_DETECT_SUPPORT或CONFIG_ICACHE_LINE_SIZE_DETECT_SUPPORT约束；公共包装是否使用运行时探测则由对应LINE_SIZE_DETECT选项选择。支持能力与是否选用探测不是同一个条件。

> 译注——源码核对：失效区间未按缓存行对齐的未定义行为与可能损坏邻接数据的风险，在外部缓存后端同样成立。不要因为函数接受字节长度，就假设控制器能安全地只处理缓存行中的任意几个字节。

本次验证范围为文档与源码对照，未构建固件、配置实板引脚或操作硬件。
