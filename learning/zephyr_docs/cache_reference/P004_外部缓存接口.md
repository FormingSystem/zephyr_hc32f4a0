### `cache_data_flush_and_invd_range()`

```c
int cache_data_flush_and_invd_range ( void * addr, size_t size )
```

```c
#include <zephyr/drivers/cache.h>
```

写回数据缓存中的指定地址范围并使其失效。

写回数据缓存中的指定地址范围并使其失效。

**参数（Parameters）**

| 名称／方向 | 说明 |
| --- | --- |
| `addr` | 要写回并使其失效的起始地址。 |
| `size` | 范围大小。 |

**返回值（Return Values）**

| 名称／方向 | 说明 |
| --- | --- |
| `-ENOTSUP` | 不支持。 |

**注意（Attention）**：注意（Attention）：仅在启用 Kconfig 选项 `CONFIG_DCACHE` 时可用。

说明（Note）：缓存操作以缓存行为单位。如果多个数据结构共用正在写回的缓存行，所有共享该行的数据结构部分都会先写回，再失效。这通常不会造成问题，因为写回是非破坏性操作，硬件随时可能触发它，因此并不严格要求 `addr` 对齐或将 `size` 填充到对齐大小。

返回（Returns）：成功时为 0，失败时为负的 errno 错误值。

| --- | --- |
| `size` | 指令缓存行大小。 |
| `0` | 指令缓存未启用。 |

**注意（Attention）**：注意（Attention）：仅在启用 Kconfig 选项 `CONFIG_ICACHE_LINE_SIZE_DETECT_SUPPORT` 时可用。

> 译注——源码核对：以下源码跟踪译注独立于官方正文，依据来源记录中保存摘要的官方main文件。源码定位采用相对链接；接口与后端实现对照不表示目标板已经启用缓存或通过DMA／多核一致性验证。

> 译注——源码核对：失效区间未按缓存行对齐的未定义行为与可能损坏邻接数据的风险，在外部缓存后端同样成立。不要因为函数接受字节长度，就假设控制器能安全地只处理缓存行中的任意几个字节。
