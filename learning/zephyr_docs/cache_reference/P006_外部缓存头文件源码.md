## 6.4\_源码跟踪译注

> 译注——外部缓存控制器（External Cache Controller）页给出cache_data_*与cache_instr_*后端函数契约，头文件本身只声明这些函数，不完成设备初始化，也不保证具体控制器实现全部操作。需要区分CONFIG_DCACHE／ICACHE可用条件和-ENOTSUP返回语义。

> 译注——动态缓存行检测接口由CONFIG_DCACHE_LINE_SIZE_DETECT_SUPPORT或CONFIG_ICACHE_LINE_SIZE_DETECT_SUPPORT约束；公共包装是否使用运行时探测则由对应LINE_SIZE_DETECT选项选择。支持能力与是否选用探测不是同一个条件。

> 译注——失效区间未按缓存行对齐的未定义行为与可能损坏邻接数据的风险，在外部缓存后端同样成立。不要因为函数接受字节长度，就假设控制器能安全地只处理缓存行中的任意几个字节。

头文件定位：[include/zephyr/drivers/cache.h](../../../include/zephyr/drivers/cache.h)，关联实现／接口：[include/zephyr/cache.h](../../../include/zephyr/cache.h)；[官方原始头文件](https://github.com/zephyrproject-rtos/zephyr/blob/main/include/zephyr/drivers/cache.h)与[官方关联文件](https://github.com/zephyrproject-rtos/zephyr/blob/main/include/zephyr/cache.h)的摘要见来源记录。去掉注释和展示空白后，本页代码与本次读取的原始头文件一致，不能推广到以后滚动更新的main或任意本地版本。
