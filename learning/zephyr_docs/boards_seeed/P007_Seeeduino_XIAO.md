## 概述（Overview）

Seeeduino XIAO是一块20 mm × 17.5 mm的微型Arm开发板，带板载LED及USB端口，通过14个引脚引出多种I/O。

<a id="hardware"></a>

## 硬件（Hardware）


- ATSAMD21G18A ARM Cortex-M0+处理器，运行频率48 MHz
- 256 KiB闪存（Flash）和32 KiB随机存储器（RAM）
- 3个用户LED
- 原生USB端口（Native USB Port）

<a id="system-clock"></a>

### 系统时钟（System Clock）

SAMD21配置为使用32 kHz外部晶体，通过片上PLL生成48 MHz系统时钟。内部APB及通用时钟（GCLK）单元的设置方式与上游Arduino库相同。

<a id="spi-port"></a>

### SPI端口（SPI Port）

SAMD21具有6个基于串行通信模块（SERCOM）的SPI。XIAO可将SERCOM0设为SPI模式，通过第9脚MISO、第10脚MOSI及第8脚SCK连接设备。

<a id="i2c-port"></a>

### I2C端口（I2C Port）

原文称SAMD21具有6个基于SERCOM的USART，并将XIAO的SERCOM2列在第4脚SDA及第5脚SCL上；此段位于I2C说明中，USART字样与I2C引脚功能不一致，按原文注明。

<a id="serial-port"></a>

### 串口（Serial Port）

SAMD21具有6个基于SERCOM的USART。XIAO使用SERCOM4提供Zephyr控制台，位于第7脚RX及第6脚TX。

<a id="usb-device-port"></a>

### USB设备端口（USB Device Port）

SAMD21微控制器（MCU）的[USB](../usb/P065_USB示例目录.md#usb)设备端口可用于与主机PC通信。更多内容见USB示例应用，例如[USB CDC ACM UART示例](../usb/P054_CDCACM串口示例.md#usb-cdc-acm)；它创建一个虚拟串口（Virtual Serial Port），将收到的字符回显给主机PC。

<a id="dac"></a>

### 数模转换器（DAC）

SAMD21具有单通道10位分辨率数模转换器（DAC），XIAO在第0脚引出DAC。

<a id="flashing"></a>

### 烧录（Flashing）


1. 构建Zephyr内核和[Hello World](../getting_started/P005_HelloWorld示例.md#hello_world)示例应用：

  ```text
  west build -b seeeduino_xiao samples/hello_world
  ```
2. 通过USB将XIAO连接主机。
3. 将3.3 V USB转串口适配器连接到开发板和主机。开发板引脚连接见前面的[串口（Serial Port）](#serial-port)一节。
4. 运行你惯用的终端程序，监听输出。Linux下的终端设备应为`/dev/ttyUSB0`，例如：

  ```text
  $ minicom -D /dev/ttyUSB0 -o
  ```

  `-o`选项让`minicom`不发送调制解调器初始化字符串（Modem Initialization String）。连接参数应配置如下：


  - 速率（Speed）：115200波特率
  - 数据位（Data）：8位
  - 奇偶校验（Parity）：无（None）
  - 停止位（Stop Bits）：1位
5. 快速短接RST与GND焊盘两次，进入引导模式。
6. 烧录镜像（Flash the Image）：

  ```text
  west build -b seeeduino_xiao samples/hello_world
  west flash
  ```

  应在终端中看到“Hello World! seeeduino_xiao”。
