## 概述（Overview）

XIAO RP2350是Seeed Studio的微型物联网开发板，搭载RP2350A SoC、板载WS2812可寻址LED及USB连接器。USB引导加载器支持拖放式烧录，无需额外适配器。

<a id="id3"></a>

详情见[Seeed Studio XIAO RP2350](https://wiki.seeedstudio.com/getting-started-xiao-rp2350/) Wiki [注1](#id2)。

<a id="hardware"></a>

## 硬件（Hardware）

原文将Seeed Studio XIAO RP2350描述为搭载双核RP2350A的低功耗微控制器开发板，时钟可灵活配置，最高133 MHz，具有264 KB SRAM及2 MB板载闪存；这些数值按此页原文保留。

原文称Seeed Studio XIAO RP2350共有14个GPIO引脚，其中提供11个数字引脚、3个模拟引脚、11个PWM引脚，以及各一个I2C、UART、SPI接口及SWD焊盘接口。PCB底面另有8个GPIO测试焊盘，提供用于第二组接口的8个数字引脚及各一个I2C、UART、SPI接口。

### 烧录（Flashing）

<a id="using-uf2"></a>

#### 使用UF2（Using UF2）

可使用UF2文件烧录XIAO RP2350。默认构建此板应用会生成build/zephyr/zephyr.uf2。按住BOOTSEL上电后，主机上会出现大容量存储设备；将UF2文件复制到该设备，即可烧录XIAO RP2350。
