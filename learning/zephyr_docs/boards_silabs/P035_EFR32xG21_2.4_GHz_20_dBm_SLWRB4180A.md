## 概述（Overview）

EFR32MG21 Mighty Gecko无线电板是EFR32-SLWSTK6006A套件随附的两块无线电板之一，搭载基于Arm Cortex-M33F的EFR32MG21系列无线SoC，具有优良低功耗能力。（[EFR32-SLWSTK6006A网站](https://www.silabs.com/products/development-tools/wireless/efr32xg21-wireless-starter-kit)）

BRD4180A，也称SLWRB4180A，插接无线入门套件主板BRD4001A，作为一种无线电板获得支持。（[无线电板（Radio Boards）](P023_Radio_Boards.md#silabs-radio-boards)）

<a id="hardware"></a>

## 硬件（Hardware）


- EFR32MG21A020F1024IM32 Mighty Gecko片上系统（SoC）
- CPU内核：ARM Cortex®-M33，带浮点单元（FPU）
- 闪存容量：1024 kB
- RAM容量：96 kB
- 发射功率（Transmit Power）：最高+20 dBm
- 工作频率（Operation Frequency）：2.4 GHz
- 低频外部振荡器（LFXO）晶体32.768 kHz，高频外部振荡器（HFXO）晶体38.4 MHz。

- [EFR32-SLWSTK6006A网站](https://www.silabs.com/products/development-tools/wireless/efr32xg21-wireless-starter-kit)

<a id="flashing"></a>

### 烧录（Flashing）

将BRD4180A无线电板安装到BRD4001A主板，通过USB连接主机。

下面以[Hello World](../getting_started/P005_HelloWorld示例.md#hello_world)应用为例。

```text
# From the root of the zephyr repository
west build -b slwrb4180a samples/hello_world
west flash
```

打开串口终端（如minicom或PuTTY），设置如下：


- 速率（Speed）：115200波特率
- 数据位（Data）：8位
- 奇偶校验（Parity）：无（None）
- 停止位（Stop Bits）：1位

复位开发板后，终端应显示以下消息：

```text
Hello World! slwrb4180a
```
