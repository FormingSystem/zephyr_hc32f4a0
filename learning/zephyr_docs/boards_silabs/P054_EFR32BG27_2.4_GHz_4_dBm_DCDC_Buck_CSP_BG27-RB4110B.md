## 概述（Overview）

采用芯片尺寸封装（CSP）的EFR32BG27 +4 dBm无线电板BG27-RB4110B，插接BRD4001A无线入门套件主板或BRD4002A无线专业套件主板。它提供EFR32BG27无线SoC的完整参考设计，包含用于2.4 GHz频段4 dBm输出的匹配网络及PCB天线。

无线主板平台详情见“无线电板”。（[无线电板（Radio Boards）](P023_Radio_Boards.md#silabs-radio-boards)）

<a id="hardware"></a>

## 硬件（Hardware）


- EFR32BG27C320F768GJ39片上系统（SoC）
- CPU内核：Arm Cortex-M33，带FPU、数字信号处理（DSP）及TrustZone
- 存储器：768 kB闪存、64 kB RAM
- 发射功率：最高+4 dBm
- 工作频率（Operation Frequency）：2.4 GHz
- LFXO晶体32.768 kHz及HFXO晶体38.4 MHz
- 8 Mbit SPI NOR闪存

EFR32BG27 SoC及BRD4110B更多信息见：

<a id="system-clock"></a>

### 系统时钟（System Clock）

EFR32BG27 SoC使用76.8 MHz的HFRCODPLL振荡器作为系统时钟，锁定到板载38.4 MHz晶体振荡器。

<a id="serial-port"></a>

### 串口（Serial Port）

EFR32BG27 SoC具有2个USART及1个EUSART。USART1连接板卡控制器，用作控制台。

<a id="buttons-and-leds"></a>

### 按键与LED

此板的两个按键及两个LED共享GPIO。应用若需同时使用相同编号的按键及LED，例如按键0与LED0，必须对两种功能进行分时复用（Time Multiplexing）。

将BRD4110B无线电板安装到BRD4002A主板，通过USB连接主机。

下面以[Hello World](../getting_started/P005_HelloWorld示例.md#hello_world)应用为例。

```text
# From the root of the zephyr repository
west build -b bg27_rb4110b samples/hello_world
west flash
```

打开串口终端（如minicom或PuTTY），设置如下：


- 速率（Speed）：115200波特率
- 数据位（Data）：8位
- 奇偶校验（Parity）：无（None）
- 停止位（Stop Bits）：1位

复位开发板后，终端应显示以下消息：

```text
Hello World! bg27_rb4110b
```

<a id="bluetooth"></a>

### 蓝牙（Bluetooth）

使用蓝牙功能前，运行以下命令从Silicon Labs硬件抽象层（HAL）仓库获取所需二进制固件（Binary Blobs）。

```text
west blobs fetch hal_silabs
```

随后用以下命令构建Zephyr内核和蓝牙示例。本例使用[Observer](../bluetooth_samples/P003_蓝牙观察者.md#bluetooth_observer)观察者示例应用。

```text
# From the root of the zephyr repository
west build -b bg27_rb4110b samples/bluetooth/observer
```
