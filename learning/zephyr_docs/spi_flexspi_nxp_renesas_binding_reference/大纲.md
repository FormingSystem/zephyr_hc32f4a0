# FlexSPI闪存与SPI时序绑定参考大纲

本册翻译二十二份官方串行外设接口（Serial Peripheral Interface，SPI）绑定，涵盖NXP、OpenCores、OpenISA、Raspberry Pi、Realtek与Renesas。FlexSPI按原文区分控制器与闪存子节点，保留AHB访问、SFDP数据及四字节寻址条件；其他页面保留片选延迟、三态输出、缓冲区阈值和已弃用属性的替代项。
