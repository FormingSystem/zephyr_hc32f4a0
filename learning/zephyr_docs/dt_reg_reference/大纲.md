# 设备树寄存器与地址映射参考大纲

本册翻译设备树（Devicetree）的寄存器资源reg、地址范围ranges和直接内存访问（Direct Memory Access，DMA）地址范围dma-ranges宏。先区分地址、长度、条目数量及名称，再核对子总线与父总线的字段布局。

原始声明、宏展开和C／设备树示例保留；译注解释RAW类型后缀、父级单元数、存在检查边界、分隔符，以及原例数值注释和数组类型问题。宏读取构建时信息，不执行寄存器或DMA操作。源码定位采用相对链接，完整范围见[全站进度](../PROGRESS.md)。
