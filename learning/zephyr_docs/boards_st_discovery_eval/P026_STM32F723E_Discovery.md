## 概述（Overview）

本Discovery套件利用音频、多传感器、图形、安全、视频及高速连接功能支持多种应用，主要特点如下。译注：原文security重复一次，译文合并重复词。


- BGA176封装STM32F723IEK6，具有512 Kbytes Flash及256+16+4 Kbytes RAM
- 板载ST-LINK/V2-1，支持USB重新枚举（Re-Enumeration）
- 240×240像素TFT LCD，带触摸面板
- SAI音频编解码器（Codec）
- 音频线路输入及输出插孔
- 立体声扬声器输出
- 4个意法半导体MEMS麦克风
- 2个按键：用户键及复位键
- 512 Mbit Quad-SPI Flash
- 8 Mbit外部PSRAM
- USB OTG高速，带Micro-AB连接器
- USB OTG全速，带Micro-AB连接器

更多信息见[32F723E-DISCO网站](https://www.st.com/en/evaluation-tools/32f723ediscovery.html)。

## 硬件（Hardware）

STM32F723E Discovery套件提供以下硬件组件：


- BGA176封装的STM32F723IEK6
- 带浮点单元（FPU）的ARM® 32位Cortex®-M7 CPU
- CPU最高频率216 MHz
- VDD电压范围1.8–3.6 V
- 1 MB闪存（Flash）
- 256+16+4 KB SRAM，其中包含64 KB紧耦合存储器（TCM）
- 支持外部中断（External Interrupt）的 GPIO。
- 三个12位ADC，合计24个通道
- 两个12位数模转换器（D/A Converters）
- 实时时钟（RTC）
- 两个高级控制定时器（Advanced-control Timer）
- 13个通用定时器
- 两个看门狗定时器（Watchdog Timers）。
- 8路USART/UART
- 3 个 I2C。
- 5路串行外设接口（SPI）
- 2路串行音频接口（SAI）
- 2路SDIO
- 控制器局域网（CAN）
- USB 2.0 OTG全速（FS），带片上物理层（PHY）
- USB 2.0 OTG高速／全速，带专用DMA、片上全速PHY及高速PHY
- 循环冗余校验计算单元（CRC Calculation Unit）
- 真随机数发生器（True Random Number Generator）
- 直接存储器访问控制器（DMA Controller）。

更多STM32F723IEK6信息见：


- [ST官网的STM32F723IEK6产品页](https://www.st.com/en/microcontrollers/stm32f723ie.html)
- [STM32F72xxx参考手册](https://www.st.com/resource/en/reference_manual/dm00305990.pdf)

<a id="pin-mapping"></a>

### 引脚映射（Pin Mapping）

STM32F723E Discovery套件有7个GPIO控制器，负责引脚复用、输入输出、上拉等功能。

更多细节见[32F723E-DISCO开发板用户手册](https://www.st.com/resource/en/user_manual/dm00342318.pdf)。

<a id="default-zephyr-peripheral-mapping"></a>

#### Zephyr 默认外设映射（Peripheral Mapping）：


- UART2 TX/RX：PA2/PA3，Arduino串口
- UART_6 TX/RX : PC6/PC7（ST-Link虚拟COM端口）
- I2C1 SCL/SDA : PB8/PB9
- I2C2 SCL/SDA：PH4/PH5，Arduino I2C
- I2C3 SCL/SDA : PA8/PH8
- SPI1 SCK/MISO/MOSI：PA5/PB4/PB5，Arduino SPI
- LD1 : PA5
- LD5 : PA7
- LD6 : PB1
- OTG_FS_DM : PA11
- OTG_FS_DP : PA12

<a id="system-clock"></a>

### 系统时钟（System Clock）

STM32F723E系统时钟可来自内部振荡器、外部振荡器或主PLL，默认以25 MHz高速外部时钟驱动PLL，产生216 MHz系统时钟。

<a id="serial-port"></a>

### 串口（Serial Port）

STM32F723E Discovery套件最多有8路UART，Zephyr控制台分配给UART6，连接板载ST-LINK/V2虚拟COM端口，默认通信参数115200、8N1。

<a id="flashing"></a>

### 烧录（Flashing）

此板默认通过west的[STM32CubeProgrammer](https://www.st.com/en/development-tools/stm32cubeprog.html)运行器（Runner）烧录，因此需要安装该工具。（[installation](https://docs.zephyrproject.org/latest/develop/flash_debug/host-tools.html#stm32cubeprog-flash-host-tools)）

也可通过`--runner`（或`-r`）选项选择OpenOCD或JLink烧录：

```text
$ west flash --runner openocd
$ west flash --runner jlink
```

<a id="flashing-an-application-to-stm32f723e-disco"></a>

#### 向STM32F723E-DISCO烧录应用

先通过USB将STM32F723E Discovery套件连接主机，再构建并烧录应用。

下面以[Hello World](../getting_started/P005_HelloWorld示例.md#hello_world)应用为例。

```text
# From the root of the zephyr repository
west build -b stm32f723e_disco samples/hello_world
west flash
```

运行主机串口程序连接开发板：

```text
$ minicom -D /dev/ttyACM0
```

控制台上应显示以下消息：

```text
Hello World! arm
```
