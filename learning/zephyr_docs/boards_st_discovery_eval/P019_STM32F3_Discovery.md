## 概述（Overview）

STM32F3DISCOVERY Discovery套件搭载基于Arm Cortex-M4的STM32F303VC MCU，提供初学者及有经验用户快速入门所需功能，主要特点如下：


- LQFP100封装的STM32微控制器
- 全部LQFP100 I/O引出到扩展排针，便于连接原型板及探测信号
- PCB A或B版板载ST-LINK/V2，C及后续版板载ST-LINK/V2-B，均为带SWD连接器的调试器／编程器
- 通过USB总线或外部3 V／5 V电源供电
- 对外提供3 V及5 V应用电源
- 10个LED：


  - 3.3 V电源指示灯LD1
  - USB通信指示灯LD2
  - 8个用户LED：红色LD3/LD10、蓝色LD4/LD9、橙色LD5/LD9及绿色LD6/LD7。译注：原文LD9重复，照录。
- 两个按键：USER及RESET
- 用户USB采用Mini-B连接器
- L3GD20或I3G4250D：意法半导体MEMS运动传感器，三轴数字输出陀螺仪
- LSM303DLHC或LSM303AGR：意法半导体MEMS系统级封装，包含三维数字线性加速度传感器及三维数字磁场传感器

提示（Hint）

较新的PCB版本E及以后出厂配置I3G4250D及LSM303AGR。

更多信息见[STM32F3DISCOVERY网站](https://www.st.com/en/evaluation-tools/stm32f3discovery.html)。

## 硬件（Hardware）

STM32F3DISCOVERY Discovery套件提供以下硬件组件：


- LQFP100封装的STM32F303VCT6
- 带浮点单元（FPU）的 ARM 32 位 Cortex-M4 CPU。
- CPU最高频率72 MHz
- VDD电压范围2.0–3.6 V
- 256 KB闪存
- 40 KB SRAM
- 程序加速存储器（Routine Booster）：指令及数据总线上的8 Kbytes SRAM
- 支持外部中断（External Interrupt）的 GPIO。
- 4个12位ADC，39个通道
- 两个12位数模转换器（D/A Converters）
- 实时时钟（RTC）
- 13个通用定时器
- 5路USART/UART
- I2C接口（2路）
- 3 个 SPI。
- 控制器局域网（CAN）
- USB 2.0全速接口（Full Speed）
- 红外发射器（Infrared Transmitter）
- 直接存储器访问控制器（DMA Controller）。

更多STM32F303VC信息见：


- [ST官网的STM32F303VC产品页](https://www.st.com/en/microcontrollers/stm32f303vc.html)
- [STM32F303xC参考手册](https://www.st.com/resource/en/reference_manual/dm00043574.pdf)

<a id="pin-mapping"></a>

### 引脚映射（Pin Mapping）

STM32F3DISCOVERY Discovery套件有6个GPIO控制器，负责引脚复用、输入输出、上拉等功能。

更多细节见[STM32F3DISCOVERY开发板用户手册](https://www.st.com/resource/en/user_manual/dm00063382.pdf)。

<a id="default-zephyr-peripheral-mapping"></a>

<a id="system-clock"></a>

### 系统时钟（System Clock）

STM32F3DISCOVERY系统时钟可来自内部振荡器、外部振荡器或主PLL，默认使用ST-Link的8 MHz MCO输出驱动PLL，产生72 MHz系统时钟。

<a id="serial-port"></a>

### 串口（Serial Port）

STM32F3DISCOVERY Discovery套件最多有5路UART，Zephyr控制台分配给UART1，默认参数115200、8N1。

<a id="i2c"></a>

### 集成电路间总线（I2C）

STM32F3DISCOVERY最多有2路I2C。I2C1连接LSM303DLHC，这是一种超紧凑低功耗系统级封装，包含三维数字线性加速度传感器及三维数字磁场传感器。

<a id="usb"></a>

### 通用串行总线（USB）

STM32F3DISCOVERY通过Mini-USB用户连接器提供USB 2.0全速设备接口。

<a id="can"></a>

### 控制器局域网（CAN）

STM32F3DISCOVERY没有板载CAN收发器；使用CAN总线时，须将外部CAN收发器连接到PD0（CAN1_RX）及PD1（CAN1_TX）。

<a id="flashing"></a>

### 烧录（Flashing）

此板默认通过west的[STM32CubeProgrammer](https://www.st.com/en/development-tools/stm32cubeprog.html)运行器（Runner）烧录，因此需要安装该工具。（[installation](https://docs.zephyrproject.org/latest/develop/flash_debug/host-tools.html#stm32cubeprog-flash-host-tools)）

也可通过`--runner`（或`-r`）选项选择OpenOCD或JLink烧录：

```text
$ west flash --runner openocd
$ west flash --runner jlink
```

<a id="flashing-an-application-to-stm32f3discovery"></a>

#### 向STM32F3DISCOVERY烧录应用

先通过USB将STM32F3DISCOVERY Discovery套件连接主机，再构建并烧录应用。

下面以[Hello World](../getting_started/P005_HelloWorld示例.md#hello_world)应用为例。

```text
# From the root of the zephyr repository
west build -b stm32f3_disco samples/hello_world
west flash
```

使用较新PCB版本E或以后时，必须选择相应的开发板定义：

```text
# From the root of the zephyr repository
west build -b stm32f3_disco@E samples/hello_world
west flash
```

运行主机串口程序连接开发板。PCB A或B版需要TTL电平3.3 V串口适配器；PCB C及后续版通过USB ST-LINK接口提供虚拟COM端口（VCP）。

```text
$ minicom -D /dev/<tty device>
```

将<tty_device>替换为STM32F3DISCOVERY所在串口，例如Linux中的/dev/ttyUSB0。

控制台上应显示以下消息：

```text
Hello World! arm
```
