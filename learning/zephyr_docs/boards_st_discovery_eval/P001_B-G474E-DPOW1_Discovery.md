## 概述（Overview）

B-G474E-DPOW1 Discovery是一套数字电源方案，也是STM32G474RET6微控制器的完整演示与开发平台。它利用该器件面向高分辨率定时器（HRTimer）的新功能、96 Kbytes内置RAM、数学加速及USB-PD 3.0，通过USB 2.0全速Type-C接口，帮助用户为升降压转换器（Buck-boost Converter）、RGB大功率LED照明或D类音频放大器建立数字电源原型。套件内置STLINK-V3E调试器／编程器，无需独立探针。译注：此概述的RAM为96 Kbytes，下方硬件列表写128 Kbytes，两处原文保留。


- 基于Arm® Cortex®-M4的STM32G474RET6，LQFP64封装，具有512 Kbytes Flash及128 Kbytes SRAM
- USB Type-C®及USB 2.0全速接口，兼容USB电力传输（USB-PD）3.0
- 用于高亮照明的RGB大功率LED
- 数字电源升降压转换器，可用内部或外部输入电压，配有板载电阻负载
- 支持D类音频放大器（Class-D Amplifier）
- 4个用户LED
- 3个电源及ST-LINK通信LED
- 四向摇杆，带选择按键
- 复位按键（Reset Push-Button）
- 板上连接器（Board Connectors）


  - USB Type-C®接口
  - USB Micro-B接口
  - 2组32针、2.54 mm间距的子板扩展排针，可连接面包板
- 灵活供电方式：ST-LINK USB VBUS、USB Type-C® VBUS或外部电源
- 板载STLINK-V3E调试器／编程器支持USB重新枚举，提供大容量存储、虚拟COM端口及调试端口

<a id="connections-and-ios"></a>

### 连接与输入输出（Connections and IOs）

每个GPIO都可由软件配置为推挽／开漏输出、带或不带上拉／下拉的输入，或外设复用功能。大多数GPIO与数字或模拟功能复用，除模拟输入外，所有GPIO均支持大电流驱动。

<a id="default-zephyr-peripheral-mapping"></a>

#### Zephyr 默认外设映射（Peripheral Mapping）：


- UART_3 TX/RX : PC10/PC11（ST-Link虚拟COM端口）
- 摇杆选择键JOY_SEL：PC13
- 摇杆左键JOY_LEFT：PC4
- 摇杆下键JOY_DOWN：PC5
- 摇杆右键JOY_RIGHT：PB2
- 摇杆上键JOY_UP：PB10
- 下方蓝色LED：PA15
- 左侧橙色LED：PB1
- 上方红色LED：PB5
- 右侧绿色LED：PB7
- `USB DM : PA11`
- `USB DP : PA12`
- UCPD CC2 : PB4
- UCPD CC1 : PB6

更多细节见[B-G474E-DPOW1 Discovery开发板用户手册](https://www.st.com/resource/en/user_manual/um2577-discovery-kit-with-stm32g474re-mcu-stmicroelectronics.pdf)[注3](#id6)。

<a id="flashing"></a>

### 烧录（Flashing）

<a id="id11"></a>

开发板默认使用west的[STM32CubeProgrammer](https://www.st.com/en/development-tools/stm32cubeprog.html)运行器[注5](#id10)烧录，需要先安装该工具。（[installation](https://docs.zephyrproject.org/latest/develop/flash_debug/host-tools.html#stm32cubeprog-flash-host-tools)）

```text
$ west flash
```

<a id="flashing-an-application-to-the-b-g474e-dpow1"></a>

#### 向B_G474E_DPOW1烧录应用

以下以[Blinky](../getting_started/P004_LED闪烁示例.md#blinky)应用为例。

```text
# From the root of the zephyr repository
west build -b b_g474e_dpow1 samples/basic/blinky
west flash
```

可以看到LED每秒闪烁一次。

<a id="debugging"></a>

### 调试（Debugging）

可以按常规方式调试应用。下面以[Hello World](../getting_started/P005_HelloWorld示例.md#hello_world)应用为例。

```text
# From the root of the zephyr repository
west build -b b_g474e_dpow1 samples/hello_world
west debug
```
