## 概述（Overview）

ST25DV04K是双接口动态NFC/RFID标签芯片，内置4 Kbit EEPROM，可通过I2C、13.56 MHz RFID读写器或NFC手机操作。套件的Class 5天线子板可替换为Class 1或Class 6天线。

ST25DV-DISCOVERY用于评估ST25DV系列的功能和能力，采用带Class 5天线的ST25DV04K NFC子板，以及由STM32处理器驱动的主板。

注意（Note）

原文指出ST25DV本身的支持尚未实现。

<a id="hardware"></a>

## 硬件（Hardware）

ST25DV Discovery套件提供以下硬件组件：


- 主板：ST25DV_Discovery_Mboard


  - LQFP100封装的32位STM32F405VGT6，具有1 Mbyte Flash及192 + 4 Kbytes SRAM
  - 320×200像素彩色LCD
  - 触摸屏驱动器
  - 电源、用户及ST-LINK的不同颜色LED
  - 用户按键
  - 用于菜单选择的摇杆
  - 复位按键（Reset Button）
  - 板载ST-LINK，用于MCU固件升级及调试
  - ST-LINK Mini-USB接口
  - 用户Micro-USB接口
  - Micro-USB或Mini-USB供电接口
  - 可选演示扩展模块，带Bluetooth® LE、Wi-Fi®及20针JTAG连接器

主板有MB1283及MB1285两个变体。


- 天线子板：ST25DV_Discovery_ANT_C5


  - 40×24 mm、13.56 MHz PCB蚀刻电感天线
  - ST25DV04K动态NFC／RFID标签
  - I2C接口连接器
  - 能量采集（Energy Harvesting）输出VOUT，带10 nF电容滤波电路
  - 通用输出（GPO）可配置为射频写入进行中／忙（RF WIP/BUSY），指示射频操作正在进行

可移除天线板，将其14针排针用作评估接口；原文间距写0.254 mm，照录并提示。

### 连接与输入输出（Connections and IOs）

<a id="default-zephyr-peripheral-mapping"></a>

#### Zephyr默认外设映射（Default Peripheral Mapping）


- UART_6 TX/RX : PC6/PC7（ST-Link虚拟COM端口）
- UART_2 TX/RX：PA2/PA3，引出到J6连接器
- I2C1 SCL/SDA：PB6/PB7，连接STMPE811触摸控制器，中断PB5
- SPI2 SCK/MOSI/CS：PB13/PC3/PB12，连接FRD24048TP LCD，复位PC1、数据命令DC为PC0
- SPI1 SCK/MISO/MOSI/CS：PA5/PA6/PA7/PA4，连接外部ST25DV接口J6
- 摇杆GPIO：PE8/PE9/PE10/PE11/PE12
- 橙色LED LD1：PC13
- 黄色LED LD2：PC4
- GPIO PE15/PE7：引出到外部ST25DV连接器J6
- GPIO PE14：引出到J5连接器

<a id="flashing"></a>

### 烧录（Flashing）

ST25DV Discovery内置ST-LINK/V2调试接口，Zephyr SDK所带OpenOCD支持该接口。

<a id="flashing-an-application-to-st25dv-discovery"></a>

#### 向ST25DV Discovery烧录应用

先通过USB将ST25DV Discovery连接主机，再构建并烧录应用。

下面以[Hello World](../getting_started/P005_HelloWorld示例.md#hello_world)应用为例。

```text
# From the root of the zephyr repository
west build -b st25dv_mb1283_disco samples/hello_world
west flash
```

运行主机串口程序连接开发板：

```text
$ minicom -D /dev/ttyACM0
```

控制台上应显示以下消息：

```text
Hello World! st25dv_mb1283_disco
```

### 调试（Debugging）

```text
# From the root of the zephyr repository
west build -b st25dv_mb1283_disco samples/hello_world
west debug
```
