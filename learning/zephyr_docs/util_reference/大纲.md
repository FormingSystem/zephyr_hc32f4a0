# 通用工具与预处理宏参考大纲

通用工具（Utility Functions）覆盖数组、位掩码、整数计算、内存、字符串和硬件轮询；预处理宏（Preprocessor Macros）还支持条件选择、列表展开及有限范围整数查表。先在公共接口页查使用契约，再按符号定位至对应头文件和实现。

本册保留原始声明、参数、返回值、全部代码示例、七份源码浏览页的完整可见代码及法律注释；重复的相等判断、递减、递增和倍乘定义均完整保留。源码跟踪译注说明原文与实现的已核对差异，不混作官方原话。所有本地链接使用相对路径，整站剩余范围见[全站进度](../PROGRESS.md)。
