## 3.1\_弃用项与替代方式（Deprecated APIs and replacements）

### 1. 全局符号（Global）

```c
audio_codec_api
```

音频编解码器（Audio codec）驱动应使用 `DEVICE_API()` 宏声明其驱动 API。

### 2. 全局符号（Global）

```c
bt_conn_le_info::interval
```

请改用 `bt_conn_le_info::interval_us`。

### 3. 全局符号（Global）

```c
BT_GATT_CHRC_AUTH
```

此 API 已弃用（Deprecated）。

### 4. 全局符号（Global）

```c
bt_hci_api_setup_t )(const struct device *dev, const struct bt_hci_setup_params *param)
```

参见 `bt_hci_setup()`。

### 5. 全局符号（Global）

```c
bt_hci_driver_api::setup
```

参见 `bt_hci_setup()`。

### 6. 全局符号（Global）

```c
bt_hci_setup (const struct device *dev, struct bt_hci_setup_params *params)
```

驱动应在 `open()` 内，通过自身的传输机制执行供应商特定的初始化。参见 4.5 迁移指南（Migration guide）。

### 7. 结构体（Struct）

```c
bt_hci_setup_params
```

此项与操作本身一同弃用，参见 `bt_hci_setup()`。驱动应改为通过 `bt_hci_get_public_addr()` 获取公开地址（Public address）。

### 8. 全局符号（Global）

```c
can_set_state_change_callback (const struct device *dev, can_state_change_callback_t callback, void *user_data)
```

请改用 `can_add_state_change_callback()` 和 `can_remove_state_change_callback()`。

### 9. 全局符号（Global）

```c
cdc_acm_dte_rate_callback_set (const struct device *dev, cdc_dte_rate_callback_t callback)
```

请改用 USB 设备核心 API（USB device core API）和 `USBD_MSG_CDC_ACM_LINE_CODING`。

### 10. 文件（File）

```c
cpu_load_metric.h
```

请改为包含 `<zephyr/sys/cpu_load.h>`。`cpu_load_metric_get()` 仍保留在该文件中，作为 `cpu_load_get_cpu()` 的已弃用封装。

### 11. 全局符号（Global）

```c
cpu_load_metric_get (int cpu_id)
```

请改用 `cpu_load_get_cpu()`。注意：`cpu_load_get_cpu()` 返回的负载单位为千分比（Per mille），而非百分比（Percent）。

### 12. 全局符号（Global）

```c
ECUSTOM_HOST_SUBS_INTERRUPT_EN
```

请改用 `espi_interrupt_config`。

### 13. 全局符号（Global）

### 72. 全局符号（Global）

```c
net_buf_max_len (const struct net_buf *buf)
```

使用 `net_buf_tailroom()` 查询仍可向末尾添加多少数据，使用 `net_buf_headroom()` 查询可向前部压入多少数据。从 `net_buf::data` 开始的临时工作区（Scratch area）大小为 `net_buf::len` 加上尾部空余空间（Tailroom）。

### 73. 全局符号（Global）

```c
net_buf_simple_max_len (const struct net_buf_simple *buf)
```

使用 `net_buf_simple_tailroom()` 查询仍可向末尾添加多少数据，使用 `net_buf_simple_headroom()` 查询可向前部压入多少数据。从 `net_buf_simple::data` 开始的临时工作区大小为 `net_buf_simple::len` 加上尾部空余空间（Tailroom）。

### 75. 全局符号（Global）

```c
RTIO_SQE_CANCELED
```

取消状态（Cancellation state）已移入所属 `rtio_iodev_sqe` 的原子状态字（Atomic status word）。使用 `rtio_sqe_cancel()` 请求取消，使用 `rtio_iodev_sqe_is_canceled()` 检查取消状态。在提交前设置此标志仍会取消该次提交，但读取此标志已无法反映运行时请求的取消。
