# 第31章\_BMM350自检结果

原文：[官方页面](https://docs.zephyrproject.org/latest/doxygen/html/structbmm350__self__test__result.html)。读取日期：2026-10-16；来源摘要见[来源记录](../SOURCES.md)。

BMM350 用户自检结果（User Self-test Result）。

```c
#include <zephyr/drivers/sensor/bmm350.h>
```

<a id="details"></a>

BMM350 用户自检结果（User Self-test Result）。保存 X 轴和 Y 轴在用户自检正向及负向激励下的磁响应，单位为微特斯拉（μT），以及每个轴的差值（正向值减负向值）。健康传感器两个轴的差值都会明显高于器件自检限值；预期幅值参见 BMM350 数据手册。
