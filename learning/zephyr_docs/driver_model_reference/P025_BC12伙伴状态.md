
<a id="a3a04b815fcc4c283d342b071dda1a0da"></a>

### `current_ua`

```c
int bc12_partner_state::current_ua
```

充电伙伴提供的电流，单位为 μA。

当 `bc12_role` 为 `BC12_PORTABLE_DEVICE` 时有效。

<a id="a4c1a653bd2393d79680f75afef334ac9"></a>

### `pd_partner_connected`

```c
bool bc12_partner_state::pd_partner_connected
```

当前连接了 USB 电力传输（Power Delivery，PD）伙伴时为 `true`。

当 `bc12_role` 为 `BC12_CHARGING_PORT` 时有效。

<a id="adeeb33acadfa0e1a8a57b862dfad97a1"></a>

### `type`

```c
enum bc12_type bc12_partner_state::type
```

充电伙伴类型（Charging Partner Type）。

当 `bc12_role` 为 `BC12_PORTABLE_DEVICE` 时有效。

### `voltage_uv`

```c
int bc12_partner_state::voltage_uv
```

充电伙伴提供的电压，单位为 μV。

当 `bc12_role` 为 `BC12_PORTABLE_DEVICE` 时有效。
