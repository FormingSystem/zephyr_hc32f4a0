# 第8章\_模拟轴校准

原文：[官方页面](https://docs.zephyrproject.org/latest/doxygen/html/structanalog__axis__calibration.html)。读取日期：2026-10-16；来源摘要见[来源记录](../SOURCES.md)。

模拟轴校准数据结构（Analog Axis Calibration Data Structure）。

```c
#include <zephyr/input/input_analog_axis.h>
```

<a id="details"></a>

模拟轴校准数据结构（Analog Axis Calibration Data Structure）。保存单个模拟轴的校准数据。初始值来自设备树（Devicetree），应用可以在运行时使用 `analog_axis_calibration_set` 和 `analog_axis_calibration_get` 修改和读取这些值。
