# 第22章\_辅助显示器驱动接口

原文：[官方页面](https://docs.zephyrproject.org/latest/doxygen/html/structauxdisplay__driver__api.html)。读取日期：2026-10-16；来源摘要见[来源记录](../SOURCES.md)。

驱动操作（Driver Operations）：辅助显示器（Auxiliary Display）驱动操作。

```c
#include <zephyr/drivers/auxdisplay.h>
```

<a id="details"></a>

驱动操作（Driver Operations）：辅助显示器（Auxiliary Display）驱动操作。所有辅助显示器驱动都需要定义此驱动 API 结构体。它包含指向驱动所实现操作的函数指针，以及其他驱动专用的常量数据。标记为 `REQ` 的成员必须由驱动设置，标记为 `OPT` 的成员则是可选项。另见 `DEVICE_DT_INST_DEFINE()`、`DEVICE_DT_DEFINE()` 和 `DEVICE_API()`。
