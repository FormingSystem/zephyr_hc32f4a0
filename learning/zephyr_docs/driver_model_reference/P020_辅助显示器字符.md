
相关声明：[uint8_t](https://docs.zephyrproject.org/latest/doxygen/html/stdint_8h.html#a3cb4a16b0e8d6af0af86d4fd6ba5fd9d)、[index](#a9f0bb424b9918e0f0c07c12eb4235677)。

显示器上的自定义字符索引。

<a id="r_a4b011716576201818278aa853bfe542e"></a>

```c
uint8_t * data
```

相关声明：[uint8_t](https://docs.zephyrproject.org/latest/doxygen/html/stdint_8h.html#a3cb4a16b0e8d6af0af86d4fd6ba5fd9d)、[data](#a4b011716576201818278aa853bfe542e)。

自定义字符的像素数据。字符必须适用于目标显示器，并以大小为“字符宽度 × 字符高度”的 `uint8` 数组提供；像素关闭时取 `0x00`，点亮时取 `0xff`。如果显示器支持灰度，则可以使用 `0x00` 到 `0xff` 之间的值，具体取决于显示器驱动。

相关声明：[uint8_t](https://docs.zephyrproject.org/latest/doxygen/html/stdint_8h.html#a3cb4a16b0e8d6af0af86d4fd6ba5fd9d)、[character_code](#a217dd562886158efec238649fb4ade04)。

此成员会被更新为显示器写入函数所需的自定义字符索引，以显示该自定义字符。
