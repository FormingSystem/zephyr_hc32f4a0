# 单向链表与通用生成宏参考大纲

单向链表（Single-linked List）通过节点中的后继指针连接应用对象。本册覆盖公共API、slist.h参考／源码及list_gen.h内部生成宏参考／源码。先读[单向链表指南](../kernel/P054_单向链表.md)，再从接口追踪到基础字段访问函数和通用宏展开。

SAFE遍历允许处理当前节点，不提供线程安全；容器（Container）宏根据嵌入节点恢复外层对象，不分配或释放它。原始声明、宏展开、示例、参数、返回值和法律注释保留，源码中的边界差异另标译注。带用户标志的变体另见[带标志单向链表参考](../sflist_reference/大纲.md)。需要前驱指针的结构另见[双向链表参考](../dlist_reference/大纲.md)。仓库定位使用相对路径，完整范围见[全站进度](../PROGRESS.md)。
