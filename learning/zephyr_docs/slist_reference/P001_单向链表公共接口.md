# 第1章\_单向链表公共接口

原文：[官方页面](https://docs.zephyrproject.org/latest/doxygen/html/group__single-linked-list__apis.html)。读取日期：2026-10-15；来源摘要见[来源记录](../SOURCES.md)。

> 译注——阅读位置：先读[单向链表指南](../kernel/P054_单向链表.md)，再查公共API及两个头文件。源码跟踪说明另外标注，不将内部宏生成器当作额外的公开接口。

单向链表（Single-linked List）实现。

<a id="details"></a>

单向链表实现。自1.2版本提供（Since），接口版本为1.0.0（Version）。实现使用内联宏／函数。此API不具备线程安全性（Thread Safety）；若链表跨线程使用，必须用同步原语（Synchronization Primitives）保护函数调用。

## 1.5\_详细说明（Detailed Documentation）

<a id="ga07e4257835751e18a6c06bfa5f9c25e8"></a>

### `SYS_SLIST_CONTAINER`

```c
#define SYS_SLIST_CONTAINER ( __ln, __cn, __n )
```

```c
#include <zephyr/sys/slist.h>
```

展开值（Value）：

```c
Z_GENLIST_CONTAINER(__ln, __cn, __n)
```

提供从链表节点取得所属容器（Container）的基本操作。注意：节点指针为NULL时也可安全使用。

**参数（Parameters）**

| 名称／方向 | 说明 |
| --- | --- |
| `__ln` | 指向sys_node_t的指针，用于取得其所属容器。 |
| `__cn` | 容器结构类型的指针。 |
| `__n` | 容器结构中sys_node_t成员的字段名。 |

> 译注——源码核对：__cn是提供容器类型的指针表达式，宏使用__typeof__(*(__cn))和成员名__n计算所属对象，不是传裸结构类型名。原参数说明中的sys_node_t在此指实际sys_snode_t节点；NULL节点返回NULL，但类型／成员与真实布局仍须匹配。

<a id="gacd97d2f1044c0560d96c9f9a6f26d2f6"></a>

### `SYS_SLIST_FOR_EACH_CONTAINER`

```c
#define SYS_SLIST_FOR_EACH_CONTAINER ( __sl, __cn, __n )
```

```c
#include <zephyr/sys/slist.h>
```

展开值（Value）：

```c
Z_GENLIST_FOR_EACH_CONTAINER(slist, __sl, __cn, __n)
```

提供以容器形式遍历链表的基本操作。注意：此循环不支持安全摘除当前容器，因此不应摘除__cn。

用户必须为循环语句添加花括号，以包围自己的代码：

原始示例（Example）：

```c
SYS_SLIST_FOR_EACH_CONTAINER(l, c, n) {
    <user code>
}
```

**参数（Parameters）**

| 名称／方向 | 说明 |
| --- | --- |
| `__sl` | 指向待遍历sys_slist_t的指针。 |
| `__cn` | 用于逐一查看链表条目的指针。 |
| `__n` | 容器结构中sys_node_t成员的字段名。 |

> 译注——源码核对：根据容器指针类型及节点成员偏移还原对象，循环后继计算仍依赖当前容器中的节点；普通版本不支持在循环体中摘除／释放当前容器。

<a id="gacf3aaf32a6a3389229b548588c6d655e"></a>

### `SYS_SLIST_FOR_EACH_CONTAINER_SAFE`

```c
#define SYS_SLIST_FOR_EACH_CONTAINER_SAFE ( __sl, __cn, __cns, __n )
```

```c
#include <zephyr/sys/slist.h>
```

展开值（Value）：

```c
Z_GENLIST_FOR_EACH_CONTAINER_SAFE(slist, __sl, __cn, __cns, __n)
```

提供以容器形式安全遍历链表的基本操作。注意：可以摘除__cn，不会破坏循环。

用户必须为循环语句添加花括号，以包围自己的代码：

原始示例（Example）：

```c
SYS_SLIST_FOR_EACH_NODE_SAFE(l, c, cn, n) {
    <user code>
}
```

**参数（Parameters）**

| 名称／方向 | 说明 |
| --- | --- |
| `__sl` | 指向待遍历sys_slist_t的指针。 |
| `__cn` | 用于逐一查看链表条目的指针。 |
| `__cns` | 使循环能够安全运行的辅助指针。 |
| `__n` | 容器结构中sys_node_t成员的字段名。 |

> 译注——源码核对：提前保存下一个容器指针__cns，允许摘除当前容器对应的节点。它不负责释放容器，也不保护__cns指向对象的生命周期。原页示例误写成带四个参数的SYS_SLIST_FOR_EACH_NODE_SAFE；原代码保留，实际容器遍历应使用SYS_SLIST_FOR_EACH_CONTAINER_SAFE(l, c, cn, n)。

### `SYS_SLIST_FOR_EACH_NODE`

```c
#define SYS_SLIST_FOR_EACH_NODE ( __sl, __sn )
```

```c
#include <zephyr/sys/slist.h>
```

展开值（Value）：

```c
Z_GENLIST_FOR_EACH_NODE(slist, __sl, __sn)
```

提供遍历链表的基本操作。注意：此循环不支持安全删除当前节点，因此不应移除__sn。

用户必须为循环语句添加花括号，以包围自己的代码：

原始示例（Example）：

```c
SYS_SLIST_FOR_EACH_NODE(l, n) {
    <user code>
}
```

此宏与其他SYS_SLIST_*()宏均不具备线程安全性。

**参数（Parameters）**

| 名称／方向 | 说明 |
| --- | --- |
| `__sl` | 指向待遍历sys_slist_t的指针。 |
| `__sn` | 用于逐一查看链表节点的sys_snode_t指针。 |

> 译注——源码核对：循环递增时读取当前节点的next；不要在普通版本中摘除或释放当前节点。调用方须提供循环体花括号，并保证链表有效、无环且节点在遍历期间有效。

> 译注——源码核对：侵入式链表（Intrusive List）：节点通常嵌入应用对象，链表只连接节点，不复制对象、不分配节点，也不自动释放容器。一个节点只有一个next链接，同一节点不能同时加入多条链或重复加入同一链；需要多个成员关系时，应使用不同节点成员。

> 译注——源码核对：同步边界：所有宏和函数都不自行加锁。SAFE只表示循环提前保存下一节点／容器，允许在本次循环体中摘除当前项；它不使跨线程访问安全，也不保证预存的下一项被其他代码移除或释放后还能继续遍历。

> 译注——源码核对：生成关系：slist.h定义节点／链表布局和访问字段的基础函数，再用list_gen.h中的Z_GENLIST_*宏生成派生接口。原页把这些函数列作公共API，查找实际实现须同时阅读两个头文件；内部生成宏不是额外的一套稳定公共接口。

> 译注——源码核对：复杂度与状态：已有正确前驱时插入／删除为O(1)，查找、查找删除和长度统计为O(n)。初始化清空链表头尾，不负责释放原节点；获取或删除节点也不释放容器存储。无锁的查询结果不能替代对后续修改的同步。

本次未构建或运行并发遍历、节点生命周期、性能及实板实验。
