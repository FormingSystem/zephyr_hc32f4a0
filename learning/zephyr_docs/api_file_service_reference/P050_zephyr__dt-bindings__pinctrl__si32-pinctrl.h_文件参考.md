## 50.2\_详细说明（Detailed Documentation）

<a id="a46f9809ef3476aca9aadc07081003e42"></a>

### `SI32_MUX`

```c
#define SI32_MUX ( fun, port, pin )
```

展开值（Value）：

```c
((((port)&0x7)) | (((pin)&0xF) << 3) | ((SI32_SIGNAL_##fun & 0x7F) << 22))
```

指定复用器字段（MUX Field）。

**参数（Parameters）**

| 名称／方向 | 说明 |
| --- | --- |
| `fun` | 功能名称（Function Name）。 |
| `port` | 端口编号（Port Number）：0～4。 |
| `pin` | 端口引脚编号（Port Pin Number）：0～15。 |
