## 概述（Overview）

基于Olimex BB-STM32WL模块的LoRaWAN开发套件，采用STM32WLE5CCU6 MCU。

<a id="hardware"></a>

## 硬件（Hardware）

此板具有以下硬件功能：


- BB-STM32WL模块，256 KB闪存、64 KB RAM及外部天线
- 3 V锂电池连接器，不含电池
- 用于外部传感器的UEXT连接器
- BME280温度、湿度及压力传感器
- 用于光照测量的光敏电阻（LDR）
- 用于智能停车的IIS2MDCTR三轴磁力计
- 用于原型开发的GPIO连接器
- 低功耗设计
- 1个用户LED
- 用户、启动及复位按键各1个
- 32.768 kHz LSE晶体振荡器

开发板及模块的更多信息见：


- [LoRa-STM32WL-DevKit仓库](https://github.com/OLIMEX/LoRa-STM32WL-DevKIT)
- [OLIMEX网站上的LoRa-STM32WL-DevKit页面](https://www.olimex.com/Products/IoT/LoRa/LoRa-STM32WL-DevKit/open-source-hardware)
- [BB-STM32WL模块网站](https://www.olimex.com/Products/IoT/LoRa/BB-STM32WL/)
- [STM32WLE5CC参考手册（Reference Manual）](https://www.st.com/resource/en/reference_manual/dm00530369-stm32wlex-advanced-armbased-32bit-mcus-with-subghz-radio-solution-stmicroelectronics.pdf)
- [ST网站上的STM32WLE5CC](https://www.st.com/en/microcontrollers-microprocessors/stm32wle5cc.html)

```text
$ pyocd pack --update
$ pyocd pack --install stm32wl
```

<a id="flashing-an-application"></a>

### 烧录应用（Flashing an Application）

将开发板连接主机，构建并烧录应用。

```text
# From the root of the zephyr repository
west build -b olimex_lora_stm32wl_devkit samples/hello_world
west flash
```

使用C或更高修订版本的套件时，必须指定相应版本字母，以启用UEXT1连接器及CON1排针的VDDIO电源。

```text
# From the root of the zephyr repository
west build -b olimex_lora_stm32wl_devkit@D samples/hello_world
west flash
```

运行串口终端连接开发板，默认可通过内置USB转UART转换器访问usart1。

```text
$ picocom --baud 115200 /dev/ttyACM0
```

<a id="debugging"></a>

### 调试（Debugging）

可以按通常方式调试应用，以下以[Blinky](../getting_started/P004_LED闪烁示例.md#blinky)为例。

```text
# From the root of the zephyr repository
west build -b olimex_lora_stm32wl_devkit samples/basic/blinky
west debug
```

对C或更新修订版本开发板：

```text
# From the root of the zephyr repository
west build -b olimex_lora_stm32wl_devkit@D samples/basic/blinky
west debug
```

## 译注

LoRa开发套件的C及更新版必须指定修订版本，才能启用UEXT1及CON1的VDDIO；板载CMSIS-DAP配合pyOCD需额外STM32WL器件包。
