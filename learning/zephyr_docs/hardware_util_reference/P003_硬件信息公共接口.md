<a id="ga197b58d995c77aae423527d0f8d9ff31"></a>

### `hwinfo_get_device_id()`

```c
ssize_t hwinfo_get_device_id ( uint8_t * buffer, size_t length )
```

```c
#include <zephyr/drivers/hwinfo.h>
```

将设备标识（Device ID）复制到缓冲区。

此例程将设备ID的length个字节复制到缓冲区。如果设备ID短于length，缓冲区剩余部分保持不变。ID取决于硬件，不保证唯一。

驱动负责确保ID的数据结构是字节序列（Byte Sequence）。不应按厂商特有的字节序（Byte Order）假设解释返回的ID值；它应将标识表示为原始字节序列，完成必要的大小端转换（Endian Conversion），使这些字节的十六进制表示能产生预期的序列号（Serial Number）。

**参数（Parameters）**

| 名称／方向 | 说明 |
| --- | --- |
| `buffer` | 用于写入ID的缓冲区。 |
| `length` | 缓冲区的最大长度。 |

**返回值（Return Values）**

| 名称／方向 | 说明 |
| --- | --- |
| `-ENOSYS` | 没有针对该设备的实现。 |

**返回（Returns）**：返回（Returns）：已复制的设备ID大小，失败时返回负错误码。

> 译注——源码核对：标识与容量：普通设备ID不保证唯一；hwinfo_get_device_id以ssize_t返回已复制字节数或负错误码。先检查负值，再按实际长度消费缓冲区；当ID较短时，尾部未被填充，不应作为有效ID输出。该接口写入原始字节，不添加字符串结束符，也不是直接写十六进制文本。驱动负责字节排列，应用不应再次套用厂商寄存器端序将字节倒序。

<a id="ga390c1c29088813ace17856ffa97d97b5"></a>

### `hwinfo_get_reset_cause()`

```c
int hwinfo_get_reset_cause ( uint32_t * cause)
```

```c
#include <zephyr/drivers/hwinfo.h>
```

获取设备复位原因（Reset Cause）。

此例程获取表示设备为何复位的标志。

某些平台的复位原因标志会在连续复位之间累积，因此此例程可能返回多个标志，表示设备上电以来的所有复位原因。如果只需获取最近一次复位的原因，应在调用此例程之后调用hwinfo_clear_reset_cause，在下一次复位事件发生前清除硬件标志。

连续调用此例程会返回相同值，除非已调用hwinfo_clear_reset_cause。

**参数（Parameters）**

| 名称／方向 | 说明 |
| --- | --- |
| `cause` | 按位或（Bitwise OR）组合的复位原因标志。 |

**返回值（Return Values）**

| 名称／方向 | 说明 |
| --- | --- |
| `-ENOSYS` | 没有针对该设备的实现。 |

**返回（Returns）**：返回（Returns）：成功时返回0，失败时返回负错误码（Negative errno Value）。

> 译注——源码核对：读取与清除：部分平台会跨多次复位累积标志。要区分下一次复位，应先读取并保存本次结果，再确认hwinfo_clear_reset_cause清除成功；清除动作会消除现存原因记录。函数不触发新的复位，不设置下一次原因，也不等于查询支持位。连续读取相同值的原文描述应放在期间没有新复位事件的语境中理解。

| `supported` | 按位或组合的、受支持的复位原因标志。 |

**返回值（Return Values）**

| 名称／方向 | 说明 |
| --- | --- |
| `-ENOSYS` | 没有针对该设备的实现。 |

**返回（Returns）**：返回（Returns）：成功时返回0，失败时返回负错误码（Negative errno Value）。

> 译注——源码核对：复位位掩码：RESET_PIN至RESET_FLASH对应BIT(0)至BIT(16)，这些是可组合标志而非互斥枚举。读取原因时用按位与检查目标位，支持位集合只说明硬件能报告哪些原因，不表示这些原因已经发生。输出参数只应在返回成功后作为有效结果使用。
