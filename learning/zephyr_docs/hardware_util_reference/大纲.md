# 熵源与硬件信息参考大纲

熵源（Entropy Source）提供随机性来源，硬件信息（Hardware Information）接口提供设备标识和复位原因。本册补齐熵源头文件的参考与源码，并收录硬件信息公共接口和头文件的完整官方说明。

熵源参数与后端要求先读[已有公共接口](../hardware/P039_熵源接口参考.md)、[驱动后端](../hardware/P048_熵源驱动后端接口.md)和[操作结构](../hardware/P053_熵源驱动操作结构.md)。硬件信息部分区分普通设备ID与EUI-64、复位原因与支持位，并说明读后清除、弱实现和用户空间校验。源码定位使用相对路径，完整范围见[全站进度](../PROGRESS.md)。
