# 第55章\_IEEE 802.15.4 与 Thread API

原文：[官方页面](https://docs.zephyrproject.org/latest/doxygen/html/group__ieee802154.html)。读取日期：2026-10-17；来源摘要见[来源记录](../SOURCES.md)。

IEEE 802.15.4 原生与 OpenThread 二层（L2）、配置、管理和驱动 API。

<a id="details"></a>

IEEE 802.15.4 原生二层（Native L2）和 OpenThread 二层（L2）、配置（Configuration）、管理（Management）及驱动（Driver）API。

自 1.0 版提供（Since 1.0）；接口版本（Version）0.8.0。

IEEE 802.15.4 和 Thread 子系统包含 OpenThread L2 子系统、原生 IEEE 802.15.4 L2 子系统（“软”媒体访问控制，Soft MAC）、供 OpenThread 与原生 L2 协议栈共享且基本不依赖厂商和协议的驱动 API（“硬”MAC 和物理层 PHY），以及用于配置子系统的若干 API，包括 Shell、网络管理（Net Management）、Kconfig 和设备树（Devicetree）等。

OpenThread 子系统 API 将外部 OpenThread 协议栈集成到 Zephyr 中，并建立在 Zephyr 原生 IEEE 802.15.4 驱动 API 之上。

原生 IEEE 802.15.4 子系统 API 在不同层次公开，面向不同使用者：

- Shell：面向最终用户和应用开发者，提供一组 IEEE 802.15.4 Shell 命令；参见 Shell 中的 IEEE 802.15.4 和 Thread API 帮助（原文入口：`shell> IEEE 802.15.4 and Thread APIs help`）。
- 应用 API（Application API）：面向应用开发者，提供 IPv6、数据报（DGRAM）和原始（RAW）套接字，用于节点间实际的点对点、多播和广播数据交换，并包含连接特定配置。原文说明示例即将提供，目前可参见 [wpan-tools 示例](https://github.com/linux-wpan/wpan-tools/tree/master/examples)；它启发了这里的 API，因此套接字 API 相似。
- Kconfig 和设备树配置选项：包括网络配置库扩展（Net Config Library Extension）、子系统范围的 MAC 和 PHY Kconfig／DT 选项，以及驱动／厂商特定 Kconfig／DT 选项；注意以 `IEEE802154`／`ieee802154` 为前缀的选项。
- 网络管理（Network Management）：在 MAC（二层 L2）和 PHY（一层 L1）层面，运行时配置 IEEE 802.15.4 协议栈；参见 IEEE 802.15.4 网络管理（IEEE 802.15.4 Net Management）。
- 二层集成（L2 Integration）：面向子系统贡献者，参见 IEEE 802.15.4 L2。它实现 Zephyr 内部二层套接字和网络上下文抽象（Context / Socket Operations，参见 Network L2 Abstraction Layer），对接口结构增加协议特定扩展（参见 Network Interface Abstraction Layer），并对网络数据包结构增加协议特定扩展（参见 Network Packet Library）。
- 共享驱动 API（Common Driver API）：OpenThread 和原生 IEEE 802.15.4 共用，面向驱动维护者和贡献者，参见 IEEE 802.15.4 Drivers。它包含所有驱动都应实现的、主要位于 PHY 层的基础驱动 API，以及若干“硬 MAC”（硬件／固件卸载，Hardware / Firmware Offloading）扩展点，用于处理协议中对性能或时序敏感的部分。
