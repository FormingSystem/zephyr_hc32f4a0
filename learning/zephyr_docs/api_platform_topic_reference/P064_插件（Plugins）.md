# 第64章\_插件（Plugins）

原文：[官方页面](https://docs.zephyrproject.org/latest/doxygen/html/group__mpipe__plugins.html)。读取日期：2026-10-17；来源摘要见[来源记录](../SOURCES.md)。

按所服务的领域分组的具体元素。

<a id="details"></a>

按所服务的领域（Domain）分组的具体元素（Concrete Elements）。插件（Plugins）连接框架与实际硬件、实际格式。插件添加自身的目录、Kconfig 和头文件（Headers），无需改动框架，因此厂商或中间件提供者（Middleware Provider）可以交付自己的元素；应用程序只需承担其启用领域的开销。
