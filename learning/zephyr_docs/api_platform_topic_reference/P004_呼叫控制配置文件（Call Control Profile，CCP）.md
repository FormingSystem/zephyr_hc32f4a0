呼叫控制配置文件（Call Control Profile，CCP）

<a id="details"></a>

呼叫控制配置文件（Call Control Profile，CCP）。

自 3.7 版提供（Since 3.7）；接口版本（Version）0.1.0。

CCP 提供发起和控制呼叫（Calls）的过程，定义呼叫控制客户端（Call Control Client）和呼叫控制服务器（Call Control Server）角色。前者通常位于耳机等资源受限设备（Resource Constrained Devices），后者通常位于手机和个人计算机（PCs）等能力更强的设备。该配置文件不限于运营商电话呼叫，也可用于 Discord、Teams 等常见应用程序。
