# 第6章\_Silicon Labs Series 2 和 Series 3 设备树辅助功能（Devicetree helpers）

原文：[官方页面](https://docs.zephyrproject.org/latest/doxygen/html/group__clock__control__dt__silabs.html)。读取日期：2026-10-17；来源摘要见[来源记录](../SOURCES.md)。

<a id="details"></a>

Silicon Labs 第 2 代和第 3 代（Series 2 and 3）设备的时钟使能（Clock Enables）和时钟分支（Clock Branches）设备树宏（Devicetree Macros），与 `silabs,series-clock` 绑定配合使用。`CLOCK_BRANCH_*` 宏表示时钟分支，`CLOCK_*` 宏表示时钟使能。
