# 第116章\_Nuvoton M48X 复位控制器设备树辅助工具（Reset controller Devicetree helpers）

原文：[官方页面](https://docs.zephyrproject.org/latest/doxygen/html/group__reset__controller__nuvoton__m48x.html)。读取日期：2026-10-17；来源摘要见[来源记录](../SOURCES.md)。

<a id="details"></a>

Nuvoton M48x 设备复位标识（Reset IDs）的设备树宏／定义（Devicetree Macros / Defines），与 `nuvoton,numaker-rst` 绑定配合使用。`_Pos` 定义表示寄存器位位置偏移（Register Bit Position Offsets）；`_RST` 定义表示可供绑定使用的标识，其中包含寄存器与位偏移。
