# 设备树节点查询与依赖参考大纲

本册收录设备树（Devicetree）的总线控制器查询、/chosen所选节点、CPU遍历和依赖序号（Dependency Ordinal）宏，并提供CPU与依赖顺序头文件的参考和源码。宏在构建时处理生成的设备树信息，节点标识、设备对象、依赖序号和硬件地址是不同对象。

源码译注说明存在性与就绪的区别、CPU筛选条件、尾随分隔符、依赖方向与补零排序形式。原始声明、宏展开、C／设备树示例、代码注释和许可证完整保留；发现的原文与实现差异明确标注。本地源码使用相对定位，完整范围见[全站进度](../PROGRESS.md)。
