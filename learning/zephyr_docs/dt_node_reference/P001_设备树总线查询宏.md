## 1.1\_宏定义（Macros）

```c

```

相关声明：[DT_BUS](#ga1082d31ac2dafdf9e085d4c23f2169dc)。

节点的总线控制器（Bus Controller）。

<a id="r_gabe5eea44ff838c11dc5b75f9ec2a9317"></a>

```c
#define DT_ON_BUS(node_id, bus)
```

相关声明：[DT_ON_BUS](#gabe5eea44ff838c11dc5b75f9ec2a9317)。

## 1.2\_详细说明（Detailed Documentation）

<a id="ga1082d31ac2dafdf9e085d4c23f2169dc"></a>

### `DT_BUS`

```c
#define DT_BUS ( node_id)
```

```c
#include <zephyr/devicetree.h>
```

展开值（Value）：

```c
DT_CAT(node_id, _BUS)
```

节点的总线控制器（Bus Controller）。

取得节点所属总线控制器的节点标识符（Node Identifier）。可与DT_PROP()组合，获取总线控制器的属性。

对没有总线控制器的节点使用此宏是错误的。

设备树（Devicetree）片段示例：

原始示例（Example）：

```dts
i2c@deadbeef {
        status = "okay";
        clock-frequency = <100000>;

        i2c_device: accelerometer@12 {
                ...
        };
};
```

使用示例：

原始示例（Example）：

```c
DT_PROP(DT_BUS(DT_NODELABEL(i2c_device)), clock_frequency) // 100000
```

**参数（Parameters）**

| 名称／方向 | 说明 |
| --- | --- |
| `node_id` | 节点标识符。 |

返回（Returns）：节点所属总线控制器的节点标识符。

> 译注——源码核对：返回对象：DT_BUS返回总线控制器的设备树节点标识，不是struct device指针，也不是总线编号或寄存器基地址。后续可用DT_PROP读取控制器属性；若要操作运行时设备，还需要相应设备对象及就绪检查。

<a id="gabe5eea44ff838c11dc5b75f9ec2a9317"></a>

### `DT_ON_BUS`

```c
#define DT_ON_BUS ( node_id, bus )
```

```c
#include <zephyr/devicetree.h>
```

展开值（Value）：

```c
IS_ENABLED(DT_CAT3(node_id, _BUS_, bus))
```

节点是否位于给定类型的总线（Bus）上？

设备树覆盖文件（Devicetree Overlay）示例：

原始示例（Example）：

```dts
&i2c0 {
       temp: temperature-sensor@76 {
                compatible = "vnd,some-sensor";
                reg = <0x76>;
       };
};
```

使用示例：假定i2c0是I2C总线控制器节点，因此temp位于I2C总线上：

原始示例（Example）：

```c
DT_ON_BUS(DT_NODELABEL(temp), i2c) // 1
DT_ON_BUS(DT_NODELABEL(temp), spi) // 0
```

**参数（Parameters）**

| 名称／方向 | 说明 |
| --- | --- |
| `node_id` | 节点标识符。 |
| `bus` | 采用小写字母和下划线形式的总线类型，作为C预处理标记（Token）传入，即不加引号。 |

返回（Returns）：节点位于给定类型的总线上时为1，否则为0。

## 1.3\_源码定位与版本边界

本册收录总线、chosen、CPU和依赖顺序四组宏，以及CPU／依赖顺序头文件参考与源码。相对源码定位：[devicetree.h](../../../include/zephyr/devicetree.h)、[cpu.h](../../../include/zephyr/devicetree/cpu.h)、[ordinals.h](../../../include/zephyr/devicetree/ordinals.h)和[生成脚本](../../../scripts/dts/gen_defines.py)。本次官方文件摘要见[来源记录](../SOURCES.md)。

> 译注——源码核对：总线来源：生成器write_bus依据解析后的bus_node和on_buses生成_BUS及_BUS_<type>信息。DT_BUS不等于简单取父节点，DT_ON_BUS也不是根据节点名字猜测总线类型；使用的设备树绑定需要正确描述总线关系。DT_ON_BUS的bus参数写成i2c或spi这样的标记，不是带引号的字符串。

> 译注——源码核对：示例性质：原始设备树片段与overlay用于演示属性获取，带...处为省略内容。宏读取的是构建时生成的设备树信息，不执行运行时总线探测，也不验证I2C地址上确实连接了器件。

> 译注——源码核对：版本与范围：本册仅翻译所列官方页面。CPU和依赖顺序源码去掉注释与展示空白后与本次官方头文件一致；总线和chosen展开式结合本次devicetree.h及生成脚本核对。相对源码定位用于跟踪，不把任意本地基线视为与滚动main相同。本次未编译展开示例或进行CPU、总线、初始化及实板实验。

本次验证范围为文档与源码对照，未编译或执行CPU、总线、初始化、宏边界及实板实验。
