## 1.8\_详细说明（Detailed Documentation）

<a id="gab5a853358480f93d77f83fe7c765ca39"></a>

### `i128_multiply_i64_i64()`

```c
void i128_multiply_i64_i64 ( int64_t a, int64_t b, int128_t * result )
```

声明属性：`static`。

```c
#include <zephyr/sys/math_extras.h>
```

将两个有符号 64 位整数相乘，并将结果存储到一个 128 位整数中。

此函数对两个有符号 64 位数值执行全精度乘法，保证结果可由 128 位表示容纳，不发生溢出（Overflow）。

**参数（Parameters）**

| 名称／方向 | 说明 |
| --- | --- |
| `a` | 被乘数。 |
| `b` | 乘数。 |
| `result` | 指向用于存放结果的 int128_t 结构的指针。 |

> 译注——源码核对：原文“无溢出”描述的是两个有符号64位数相乘可由128位容纳的数学范围。当前无原生128位类型的后备实现先计算(uint64_t)-a及(uint64_t)-b；当操作数为INT64_MIN时，有符号取负发生在无符号转换之前，结果不可由int64_t表示，存在未定义行为。不能把数学范围保证直接推广为该后备代码对全部输入均可靠；原生__int128分支不经过这条取绝对值路径。

```c

```

声明属性：`static`。

```c
#include <zephyr/sys/math_extras.h>
```

将两个无符号 16 位整数相乘。

**参数（Parameters）**

| 名称／方向 | 说明 |
| --- | --- |
| `a` | 第一个操作数（Operand）。 |
| `b` | 第二个操作数。 |
| `result` | 指向结果存储位置的指针。 |

**返回（Returns）**：返回值：运算发生溢出时返回 true。

> 译注——源码核对：后备分支写作uint16_t c = a * b。在32位int能够表示全部uint16_t取值的平台上，两个实参先提升为int再相乘；例如65535*65535超过INT_MAX，可能发生有符号溢出的未定义行为（Undefined Behavior），不能认为赋值到uint16_t会消除此前的问题。内建函数分支不使用这个乘法表达式；这里保留原源码并指出分支差异，没有修改上游实现或宣称实测通过。

> 译注——源码核对：返回方向：加法与乘法接口返回true表示发生溢出，false才表示结果可由目标类型完整表示。result仍必须指向有效、可写且类型匹配的对象；错误标志不是“完全没有写入”的保证，也不是饱和运算（Saturating Arithmetic）。

> 译注——源码核对：类型与输入：u16、u32、u64和size接口分别按其参数类型进行计算。较宽或有符号的表达式传入时可能先发生类型转换；函数只能检查转换后的操作数，不能追溯传参前已丢失的数据。size_t的位宽取决于目标ABI。

> 译注——源码核对：选择分支：实现按HAS_BUILTIN选择相应编译器内建函数；128位乘法还检查__SIZEOF_INT128__。在首次包含公共头文件前定义PORTABLE_MISC_MATH_EXTRAS可强制后备分支，主要供测试使用；源码注释中的<misc/math_extras.h>是历史路径，当前公共入口是<zephyr/sys/math_extras.h>。
