# 数学辅助接口参考大纲

数学辅助接口（Math Extras）提供带溢出检测的无符号加法与乘法、前导／尾随零计数，以及有符号64位操作数的128位乘积。先读公共接口的分组说明、参数和返回值，再查头文件与内联实现；int128_t结构页说明高低64位的含义。

本册保留完整声明、五类接口分组说明、原始可见代码和法律注释。译注区分编译器内建函数（Compiler Builtins）与C后备实现，说明零输入、返回方向、整数提升及INT64_MIN边界。全部本地定位使用相对路径，剩余范围见[全站进度](../PROGRESS.md)。
