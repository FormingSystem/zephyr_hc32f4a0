## 2.2\_函数（Functions）

这些函数计算 a + b，将结果存放到 *result；运算发生溢出时返回 true。

这些函数计算 a * b，将结果存放到 *result；运算发生溢出时返回 true。

统计 x 的二进制位表示中的前导零位数量。当 x = 0 时，结果等于 x 的位宽。

统计 x 的二进制位表示中的尾随零位数量。当 x = 0 时，结果等于 x 的位宽。

用于对 128 位整数执行算术运算的函数。在不具备原生 128 位类型的平台上，这些函数为高精度计算提供支持。

## 2.3\_源码定位与版本边界

本册提供[公共接口](P001_数学辅助公共接口.md)、两份头文件的参考与源码，以及[int128_t结构](P006_128位整数结构.md)。相对源码定位：[math_extras.h](../../../include/zephyr/sys/math_extras.h)和[math_extras_impl.h](../../../include/zephyr/sys/math_extras_impl.h)。对应[官方公共头文件](https://github.com/zephyrproject-rtos/zephyr/blob/main/include/zephyr/sys/math_extras.h)和[官方实现头文件](https://github.com/zephyrproject-rtos/zephyr/blob/main/include/zephyr/sys/math_extras_impl.h)的本次摘要见[来源记录](../SOURCES.md)。

> 译注——源码核对：返回方向：加法与乘法接口返回true表示发生溢出，false才表示结果可由目标类型完整表示。result仍必须指向有效、可写且类型匹配的对象；错误标志不是“完全没有写入”的保证，也不是饱和运算（Saturating Arithmetic）。

> 译注——源码核对：类型与输入：u16、u32、u64和size接口分别按其参数类型进行计算。较宽或有符号的表达式传入时可能先发生类型转换；函数只能检查转换后的操作数，不能追溯传参前已丢失的数据。size_t的位宽取决于目标ABI。

> 译注——源码核对：选择分支：实现按HAS_BUILTIN选择相应编译器内建函数；128位乘法还检查__SIZEOF_INT128__。在首次包含公共头文件前定义PORTABLE_MISC_MATH_EXTRAS可强制后备分支，主要供测试使用；源码注释中的<misc/math_extras.h>是历史路径，当前公共入口是<zephyr/sys/math_extras.h>。

> 译注——源码核对：版本与验证：声明、分组说明、完整可见代码及法律注释均保留。两份源码页的非注释内容与本次官方原始头文件一致；本仓库相对链接用于跟踪，不能替代版本核对。本次仅做文档和源码对照，未编译、运行或验证特定优化器的输出。

本次验证范围为文档与源码对照，未编译或执行算术边界、后备分支、性能及实板实验。
