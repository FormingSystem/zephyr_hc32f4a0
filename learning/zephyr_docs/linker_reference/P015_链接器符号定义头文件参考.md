## 15.2\_详细说明（Detailed Documentation）

<a id="a7401dc3cb7ae4d3bb3afcb99c79a50c2"></a>

### `CREATE_OBJ_LEVEL`

```c
#define CREATE_OBJ_LEVEL ( object, level )
```

展开值（Value）：

```c
PLACE_SYMBOL_HERE(__##object##_##level##_start);\
KEEP(*(SORT(.z_##object##_##level##_P_?_*)));   \
KEEP(*(SORT(.z_##object##_##level##_P_??_*)));  \
KEEP(*(SORT(.z_##object##_##level##_P_???_*)));
```

#define PLACE_SYMBOL_HERE ( symbol)

> 译注——源码核对：同一头文件的三种入口：_LINKER分支提供创建链接对象段的宏，_ASMLANGUAGE分支提供汇编外部符号声明，普通C分支声明链接器导出的地址和大小符号。extern char symbol[]通常是引用链接符号的写法，不表示本头文件分配了相同名称的C数组；大小符号要按其定义理解，不能直接解引用为存放大小的变量。

> 译注——源码核对：对象排序与保留：CREATE_OBJ_LEVEL为指定object和level生成开始符号，并用KEEP与SORT分别保留一位、两位、三位优先级形式的输入段；它描述链接排序，不执行对象初始化函数。PLACE_SYMBOL_HERE对Renesas RX额外PROVIDE一个前导下划线别名，以配合该架构的C符号命名。

> 译注——源码核对：条件化符号：XIP、MMU、用户态、非缓存内存、RAM函数、TLS、启动段和按需段等符号只在相应配置下声明；声明可见不证明对应运行时功能已经启用或硬件已配置。ZTEST_UNITTEST分支把设备树状态检查临时替换为0，并在文件末尾取消定义；不能将该测试分支用作正常应用的设备树判断。

> 译注——源码核对：版本边界：本批记录八份链接器头文件、设备树绑定、三份链接器CMake文件、日志链接片段及两份内存管理头文件，共十五份官方源码摘要。八个源码浏览页的非注释代码与本次读取的原始头文件逐项核对；滚动main、latest与本仓库参照版本不自动等同。本次未预处理或链接示例、构建固件、配置内存权限或执行硬件实验。

本次验证范围为文档与源码对照，未编译宏／DTS示例、构建固件或操作硬件。
