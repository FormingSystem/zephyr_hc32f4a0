## 1.2\_详细说明（Detailed Documentation）

<a id="a9805cb87c4b9298baff4ce37285a6382"></a>

### `LINKER_DT_NODE_REGION_FLAGS`

```c
#define LINKER_DT_NODE_REGION_FLAGS ( node_id)
```

展开值（Value）：

```c
COND_CODE_1(DT_NODE_HAS_PROP(node_id, zephyr_memory_region_flags),                         \
            (COND_CODE_1(_LINKER_IS_EMPTY_TOKEN(_DT_MEMORY_REGION_FLAGS_TOKEN(node_id)),   \
                         (),                                                               \
                         (_LINKER_ENCLOSE_PAREN(                                           \
                                _DT_MEMORY_REGION_FLAGS_UNQUOTED(node_id))                 \
                         ))),                                                              \
            (_LINKER_ENCLOSE_PAREN(rw)))
```

获取带圆括号的链接器内存区域标志（Memory-region Flags）。

尝试返回加上圆括号的 `zephyr,memory-region-flags` 属性。原文称未设置该属性时返回空字符串。

> 译注——当前宏实现对缺失属性返回 `(rw)`；属性存在且为空字符串时才展开为空。下方原例中 no_flags 的英文注释与此实现不符。

设备树片段示例（Devicetree Fragment）：

原始示例（Example）：

```dts
/ {
        soc {
                rx: memory@2000000 {
                        zephyr,memory-region = "READ_EXEC";
                        zephyr,memory-region-flags = "rx";
                };
                rx_not_w: memory@2001000 {
                        zephyr,memory-region = "READ_EXEC_NOT_WRITE";
                        zephyr,memory-region-flags = "rx!w";
                };
                no_flags: memory@2001000 {
                        zephyr,memory-region = "NO_FLAGS";
                };
        };
};
```

使用示例（Example Usage）：

原始示例（Example）：

```c
LINKER_DT_NODE_REGION_FLAGS(DT_NODELABEL(rx))       // (rx)
LINKER_DT_NODE_REGION_FLAGS(DT_NODELABEL(rx_not_w)) // (rx!w)
LINKER_DT_NODE_REGION_FLAGS(DT_NODELABEL(no_flags)) // [flags will not be specified]
```

**参数（Parameters）**

| 名称／方向 | 说明 |
| --- | --- |
| `node_id` | 节点标识符（Node Identifier）。 |

返回（Returns）：设备树中指定的内存区域标志值，外加圆括号。

<a id="a3244e16032cc575ab5c7275caca14801"></a>

### `LINKER_DT_NODE_REGION_NAME`

```c
#define LINKER_DT_NODE_REGION_NAME ( node_id)
```

展开值（Value）：

```c
STRINGIFY(LINKER_DT_NODE_REGION_NAME_TOKEN(node_id))
```

获取链接器内存区域名称。

尝试使用 `zephyr,memory-region` 属性，并将其中非字母数字字符替换为下划线。

设备树片段示例（Devicetree Fragment）：

原始示例（Example）：

```dts
/ {
        soc {
                sram1: memory@2000000 {
                    zephyr,memory-region = "MY_NAME";
                };
                sram2: memory@2001000 {
                    zephyr,memory-region = "MY@OTHER@NAME";
                };
        };
};
```

使用示例（Example Usage）：

原始示例（Example）：

```c
LINKER_DT_NODE_REGION_NAME(DT_NODELABEL(sram1)) // "MY_NAME"
LINKER_DT_NODE_REGION_NAME(DT_NODELABEL(sram2)) // "MY_OTHER_NAME"
```

**参数（Parameters）**

| 名称／方向 | 说明 |
| --- | --- |
| `node_id` | 节点标识符（Node Identifier）。 |

返回（Returns）：该节点将生成的内存区域名称。

### `LINKER_DT_NODE_REGION_NAME_TOKEN`

```c
#define LINKER_DT_NODE_REGION_NAME_TOKEN ( node_id)
```

```c
DT_STRING_TOKEN(node_id, zephyr_memory_region)
```

以标记（Token）形式获取链接器内存区域名称。

尝试使用 `zephyr,memory-region` 属性，将其中非字母数字字符替换为下划线，然后返回标记（Token）。

```dts
                sram1: memory@2000000 {

                };
        };
};
```

使用示例（Example Usage）：

原始示例（Example）：

```c
LINKER_DT_NODE_REGION_NAME_TOKEN(DT_NODELABEL(sram1)) // MY_NAME
LINKER_DT_NODE_REGION_NAME_TOKEN(DT_NODELABEL(sram2)) // MY_OTHER_NAME
```

**参数（Parameters）**

| 名称／方向 | 说明 |
| --- | --- |

<a id="a1b743e1c6c735c87d4fbd2094819c573"></a>

### `LINKER_DT_REGIONS`

```c
#define LINKER_DT_REGIONS ( )
```

展开值（Value）：

```c
DT_FOREACH_STATUS_OKAY(_DT_COMPATIBLE, _REGION_DECLARE)
```

根据兼容标识（Compatible）为 `zephyr,memory-region` 的设备树节点生成链接器内存区域（Memory Regions）。

注意：原文称目前不处理 MEMORY 属性，因为这些属性可选、Zephyr 实际未使用，而且可能与内存保护单元（Memory Protection Unit，MPU）的配置冲突。

> 译注——当前 `_REGION_DECLARE` 已调用区域 flags 宏；这段说明与当前实现存在差异。链接器 MEMORY 标志与设备树的 `zephyr,memory-attr` 属性也不是同一套属性。

<a id="a171f1425c840f60dd94722ff046e0e81"></a>

```c
#define LINKER_DT_SECTIONS ( )
```

```c
DT_FOREACH_STATUS_OKAY(_DT_COMPATIBLE, _SECTION_DECLARE)
```

根据兼容标识（Compatible）为 `zephyr,memory-region` 的设备树节点生成链接器内存段（Memory Sections）。

## 1.3\_源码定位与版本边界

相对源码定位：[设备树区域](../../../include/zephyr/linker/devicetree_regions.h)、[只读检测](../../../include/zephyr/linker/utils.h)、[适配选择](../../../include/zephyr/linker/linker-tool.h)、[GCC](../../../include/zephyr/linker/linker-tool-gcc.h)、[LLD](../../../include/zephyr/linker/linker-tool-lld.h)、[MWDT](../../../include/zephyr/linker/linker-tool-mwdt.h)、[devnull](../../../include/zephyr/linker/linker-devnull.h)、[链接符号](../../../include/zephyr/linker/linker-defs.h)、[区域绑定](../../../dts/bindings/base/zephyr,memory-region.yaml)、[LLD构建入口](../../../cmake/linker/lld/target.cmake)、[LLD标志](../../../cmake/linker/lld/linker_flags.cmake)、[通用LD标志](../../../cmake/linker/ld/linker_flags.cmake)、[日志段](../../../include/zephyr/linker/common-rom/common-rom-logging.ld)、[内存管理](../../../include/zephyr/kernel/mm.h)和[虚拟内核条件](../../../include/zephyr/kernel/internal/mm.h)。本次官方源码摘要见[来源记录](../SOURCES.md)。

> 译注——源码核对：名称与区域：NAME_TOKEN将zephyr,memory-region字符串转换为标记（Token），NAME再把该标记字符串化。MY@OTHER@NAME变为MY_OTHER_NAME，节点标签sram1本身不作为区域名。字符替换可能使不同原始名称发生碰撞，调用者仍需保证生成的链接器区域名与符号名有效且不重复。

> 译注——源码核对：flags三种情况：属性缺失时展开为(rw)；属性存在且值为空字符串时不输出标志；非空值如rx!w则输出(rx!w)。原文“未设置返回空字符串”和no_flags例注“flags will not be specified（不指定标志）”与当前实现不符。flags是链接器MEMORY区域标志，不是MPU寄存器配置，也不是zephyr,memory-attr位掩码。

> 译注——源码核对：从节点到链接声明：LINKER_DT_REGIONS与LINKER_DT_SECTIONS遍历兼容zephyr,memory-region且状态为okay的节点。区域声明取第0个reg的地址与长度；段声明生成同名NOLOAD输出段，KEEP保留同名及名称后接.*的输入段，并生成__名称_start、_end、_size和_load_start符号。仅有zephyr,memory-region属性不等于宏会自动遍历该节点，还需要兼容标识及状态符合条件。

> 译注——源码核对：加载与例子边界：NOLOAD不等于自动清零或从ROM复制，生成链接符号也不会创建运行时内存分配器。原名称／flags示例省略compatible、reg等完整上下文，flags示例还有两个同名memory@2001000兄弟节点；这些片段只用于解释宏取值，不能原样当作完整可构建设备树。原文称不处理MEMORY属性的说明已经与调用FLAGS宏的实现不一致。

> 译注——源码核对：版本边界：本批记录八份链接器头文件、设备树绑定、三份链接器CMake文件、日志链接片段及两份内存管理头文件，共十五份官方源码摘要。八个源码浏览页的非注释代码与本次读取的原始头文件逐项核对；滚动main、latest与本仓库参照版本不自动等同。本次未预处理或链接示例、构建固件、配置内存权限或执行硬件实验。

本次验证范围为文档与源码对照，未编译宏／DTS示例、构建固件或操作硬件。
