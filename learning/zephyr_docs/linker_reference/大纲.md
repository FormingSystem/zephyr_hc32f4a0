# 链接器头文件参考大纲

本册完整翻译设备树链接区域（Devicetree Linker Regions）、只读数据检测、链接器适配选择、GCC／LLD／MWDT宏集、devnull区域和链接符号定义的八个头文件参考页及源码浏览页。

先了解设备树怎样提供区域名称、flags和reg，再区分链接器输出段、运行地址（VMA）与装载地址（LMA）。工具链适配决定相同宏在不同配置下如何展开，链接符号声明则连接链接脚本、C与汇编使用方。devnull用于保留ELF中的部分信息，不等同于从ELF删除段。

原始代码、示例、注释和许可证保留，源码跟踪译注明确原文与当前实现的差异。所有仓库定位采用相对链接，完整范围见[全站进度](../PROGRESS.md)。
