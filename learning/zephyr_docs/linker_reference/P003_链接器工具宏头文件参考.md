## 3.2\_详细说明（Detailed Documentation）

<a id="a6a48d32446fade9372ab88092d9b4861"></a>

### `linker_is_in_rodata()`

```c
bool linker_is_in_rodata ( const void * addr)
```

声明属性：`inline`、`static`。

检查地址是否位于只读段（Read-only Section）中。

检查默认的 `.rodata` 区域，以及通过弱引用（Weak References）暴露链接器符号的重定位只读数据段（CCM_RODATA、SMEM_RODATA）。这样，由 `zephyr_code_relocate(LOCATION ..._RODATA)` 放入自定义只读段的字符串字面量仍可被 `cbprintf` 识别为只读，避免延迟日志打包器（Deferred-logging Packager）将其指针置为 NULL 后再附加副本，而下游进程间通信（IPC）日志传输可能无法正确重建这些副本。

**参数（Parameters）**

| 名称／方向 | 说明 |
| --- | --- |
| `addr` | 地址（Address）。 |

返回（Returns）：如果判定地址位于任一只读段中，返回 true。

> 译注——源码核对：只读判断范围：linker_is_in_rodata检查单个地址是否位于半开区间[start,end)，先查默认rodata，再查CCM和SMEM的*_rodata_reloc_start／end弱符号范围。它不验证一个缓冲区的长度、NUL结尾或全部内容，也不询问MPU／MMU访问权限。任意自定义段不会仅因命名为rodata而自动加入此检查。

> 译注——源码核对：架构与重定位：这些检查位于源码列出的架构条件内，其他目标返回false。CCM／SMEM检查先确认弱起始符号不为NULL；未定义相关段时跳过。不得把空范围的__ccm_rodata_start／end等标记代替*_reloc_*边界；源码说明native／POSIX的符号本地化步骤可能破坏未定义弱引用，所以此处保留架构保护。

> 译注——源码核对：版本边界：本批记录八份链接器头文件、设备树绑定、三份链接器CMake文件、日志链接片段及两份内存管理头文件，共十五份官方源码摘要。八个源码浏览页的非注释代码与本次读取的原始头文件逐项核对；滚动main、latest与本仓库参照版本不自动等同。本次未预处理或链接示例、构建固件、配置内存权限或执行硬件实验。
