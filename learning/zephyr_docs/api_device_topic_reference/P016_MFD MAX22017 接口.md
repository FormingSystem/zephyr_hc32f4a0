## 16.2\_详细说明（Detailed Documentation）

<a id="ga7c051fa0697ae672a4dddbfa84059ad0"></a>

### `max22017_reg_read()`

```c
int max22017_reg_read ( const struct device * dev, uint8_t addr, uint16_t * value )
```

```c
#include <zephyr/drivers/mfd/max22017.h>
```

读取 max22017 的寄存器（Register）。

**参数（Parameters）**

| 名称／方向 | 说明 |
| --- | --- |
| `dev` | MAX22017 多功能设备（MFD）。 |
| `addr` | 要读取的寄存器地址（register address）。 |
| `value` | 指向接收数据缓冲区的指针。 |

**返回值（Return Values）**

| 名称／方向 | 说明 |
| --- | --- |
| `0` | 成功时。 |
| `-errno` | 发生任何错误时，参见 `spi_transceive_dt()`。 |

int max22017_reg_write ( const struct device * dev, uint8_t addr, uint16_t value )

#include <zephyr/drivers/mfd/max22017.h>
