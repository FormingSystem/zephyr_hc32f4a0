## 3.3\_详细说明（Detailed Documentation）

<a id="gac4c25a1ed054a8a06c87d4df9c25ffc6"></a>

### `timeutil_sync_estimate_skew()`

```c
float timeutil_sync_estimate_skew ( const struct timeutil_sync_state * tsp)
```

```c
#include <zephyr/sys/timeutil.h>
```

根据当前状态估算时钟偏斜（Skew）。

利用状态中的base和latest同步点，确定本地时钟相对于参考时钟的偏斜。参见timeutil_sync_state::skew。

**参数（Parameters）**

| 名称／方向 | 说明 |
| --- | --- |
| `tsp` | 指向时间同步状态的指针。必须已有base和latest同步点，且在本地时间尺度上latest必须晚于base。 |

**返回（Returns）**：估算的偏斜；无法估算时返回零。

<a id="gad8ef92e5dc72bd26d765567134044400"></a>

### `timeutil_sync_local_from_ref()`

```c
int timeutil_sync_local_from_ref ( const struct timeutil_sync_state * tsp, uint64_t ref, int64_t * localp )
```

```c
#include <zephyr/sys/timeutil.h>
```

由参考时刻插值得到本地时间尺度上的时刻。

**参数（Parameters）**

| 名称／方向 | 说明 |
| --- | --- |
| `tsp` | 指向时间同步状态的指针，必须已设置基准点和偏斜。 |
| `ref` | 参考时间尺度中的时刻，可以早于或晚于基准时刻。 |
| `localp` | 保存对应本地时刻的位置。插值得到早于本地时间0的值也不会报错；插值失败时不修改所指对象。 |

**返回值（Return Values）**

| 名称／方向 | 说明 |
| --- | --- |
| `0` | 成功且偏斜为1时。 |
| `1` | 成功且偏斜不等于1时。 |
| `-EINVAL` | 时间同步状态未充分初始化，或localp为空时。 |

**说明（Note）**：仅在启用CONFIG_TIMEUTIL_APPLY_SKEW时应用时钟偏斜修正。

### `timeutil_sync_ref_from_local()`

```c
int timeutil_sync_ref_from_local ( const struct timeutil_sync_state * tsp, uint64_t local, uint64_t * refp )
```

```c
#include <zephyr/sys/timeutil.h>
```

由本地时刻插值得到参考时间尺度上的时刻。

**参数（Parameters）**

| 名称／方向 | 说明 |
| --- | --- |
| `tsp` | 指向时间同步状态的指针，必须已设置基准点和偏斜。 |
| `local` | 本地时间尺度中的时刻，可以早于或晚于基准时刻。 |
| `refp` | 保存对应参考时刻的位置。插值得到负参考时间会报错；插值失败时不修改所指对象。 |

**返回值（Return Values）**

| 名称／方向 | 说明 |
| --- | --- |
| `0` | 使用偏斜1完成插值时。 |
| `1` | 使用不等于1的偏斜完成插值时。 |
| `-EINVAL` | 时间同步状态未充分初始化，或refp为空时。 |
| `-ERANGE` | 插值得到的参考时间将为负值时。 |

**说明（Note）**：仅在启用CONFIG_TIMEUTIL_APPLY_SKEW时应用时钟偏斜修正。

<a id="gabe374cf629ee64b850cc49e954666d8d"></a>

### `timeutil_sync_skew_to_ppb()`

```c
int32_t timeutil_sync_skew_to_ppb ( float skew)
```

```c
#include <zephyr/sys/timeutil.h>
```

将时钟偏斜转换为十亿分比误差（Parts per Billion，ppb）。

偏斜1.0对应零误差；偏斜小于1表示正误差，即时钟比预期快；偏斜大于1表示负误差，即时钟比预期慢。

由于float的精度低于double，可表示的最小误差约为120 ppb。“精密”时间源的误差可能约为2000 ppb。

偏斜大于3.14748时，可能下溢超出32位表示范围；这对应时钟运行速度低于标称速率的三分之一。

**返回（Returns）**：以ppb表示的偏斜误差；无法用返回类型表示时，返回INT32_MIN。

<a id="ga01142931b299e848b0642634a0922be5"></a>

### `timeutil_sync_state_set_skew()`

```c
int timeutil_sync_state_set_skew ( struct timeutil_sync_state * tsp, float skew, const struct timeutil_sync_instant * base )
```

```c
#include <zephyr/sys/timeutil.h>
```

用新的时钟偏斜（Skew）以及可选基准值更新状态。

使用从持久存储读出的值，或依据近期偏斜估算结果计算出的值设置偏斜；估算来源可以包括timeutil_sync_estimate_skew()。

可以选择更新基准时间戳。如果替换基准，则清空latest时刻，直到再次调用timeutil_sync_state_update()。

**参数（Parameters）**

| 名称／方向 | 说明 |
| --- | --- |
| `tsp` | 指向时间同步状态的指针。 |
| `skew` | 要使用的偏斜，必须为正值，且不应偏离1太远。 |
| `base` | 可选的新基准点。如果提供，则成为基准时间戳，与skew一起用于参考／本地时刻转换；设置基准会清空已捕获的latest值。 |

**返回（Returns）**：偏斜更新成功时返回0；偏斜无效时返回-EINVAL。

<a id="gaa6926a23d1c4fbb61584e957d157bd62"></a>

### `timeutil_sync_state_update()`

```c
int timeutil_sync_state_update ( struct timeutil_sync_state * tsp, const struct timeutil_sync_instant * inst )
```

```c
#include <zephyr/sys/timeutil.h>
```

在时间同步状态中记录一个新的时刻。

注意，此操作只更新保存的最新时刻，不会自动调整偏斜。

**参数（Parameters）**

| 名称／方向 | 说明 |
| --- | --- |
| `tsp` | 指向timeutil_sync_state对象的指针。 |
| `inst` | 要记录的新时刻。如果尚无基准时刻，它将成为基准；否则，在参考和本地两个时间尺度上都必须严格晚于基准时刻。 |

**返回值（Return Values）**

| 名称／方向 | 说明 |
| --- | --- |
| `0` | 成功设置了新的基准点时。 |
| `1` | 设置了新的latest时刻时。 |
| `-EINVAL` | 新时刻与基准时刻不兼容时。 |

## 3.4\_源码定位与版本边界

本册提供[时间表示](P002_时间表示接口.md)、[时间同步](P003_时间同步接口.md)、[单位换算](P007_时间单位辅助接口.md)与[timespec工具](P008_timespec时间工具接口.md)。头文件相对定位：[timeutil.h](../../../include/zephyr/sys/timeutil.h)、[time_units.h](../../../include/zephyr/sys/time_units.h)，实现定位：[timeutil.c](../../../lib/utils/timeutil.c)。

配置与构建定位：[Kconfig](../../../lib/utils/Kconfig)、[CMakeLists.txt](../../../lib/utils/CMakeLists.txt)。本次[官方头文件](https://github.com/zephyrproject-rtos/zephyr/blob/main/include/zephyr/sys/timeutil.h)、[单位换算头文件](https://github.com/zephyrproject-rtos/zephyr/blob/main/include/zephyr/sys/time_units.h)及[官方实现](https://github.com/zephyrproject-rtos/zephyr/blob/main/lib/utils/timeutil.c)摘要见[来源记录](../SOURCES.md)。

> 译注——源码核对：阅读边界：时间表示（Time Representation）处理UTC日历字段与POSIX秒数，时间同步（Time Synchronization）映射两个计数时钟，单位换算（Unit Conversion）处理时长的单位与舍入，timespec工具处理秒／纳秒二元组。它们不自动校准RTC、选择时区或建立网络授时服务。

> 译注——源码核对：版本与定位：以下译注核对本次官方main源码，链接中的本仓库源码只是相对定位入口，不保证读者的本地版本与滚动更新的latest相同。官方原文、原始代码及法律注释保留；译注不修改接口契约。

> 译注——源码核对：先将同步状态（Synchronization State）清零并设置cfg，使配置对象在使用期间有效。ref_Hz与local_Hz应为正；参考计数ref的0被用作未初始化哨兵，本地计数local允许为0。接口没有为所有配置指针和频率提供运行时有效性检查。

> 译注——源码核对：state_update安装首个有效基准时总把skew设为1.0f，与原说明中“仅当skew为0时设置”的措辞存在差异。后续采样只与base比较，不与已有latest比较；只要晚于base，也可能用比原latest更早的采样替换latest。更新采样不会自动估计或应用skew。

> 译注——源码核对：estimate_skew计算参考增量×本地标称频率÷本地增量÷参考标称频率，返回估计值而不修改状态。set_skew只检查skew>0；调用者还应保证有限值（Finite Value）及有效基准。它不验证新基准的ref非零或时间顺序。

> 译注——源码核对：CONFIG_TIMEUTIL_APPLY_SKEW决定换算是否应用校正：本地到参考方向乘skew，反方向除skew。返回值1仅表示存储的skew不等于1，即使关闭该配置也可能返回1，不能单凭返回值认定已应用校正。

> 译注——源码核对：换算使用有符号64位中间量，未覆盖所有差值、乘法和类型转换溢出。参考结果为负时返回-ERANGE且不写结果；反向结果类型为int64_t，允许负本地时间。调用者应约束计数跨度、频率与输出范围，不能按任意uint64_t全范围外推。

> 译注——源码核对：skew_to_ppb按(1-skew)×10^9转换，正误差表示本地时钟偏快。超出int32_t可表达范围时返回INT32_MIN；它没有完整处理NaN／无穷值的输入验证。float分辨率也限制校正精度，不能把ppb单位理解为达到1 ppb测量精度。

本次验证范围为文档与源码对照，未编译或执行时间同步、计时精度及实板实验。
