# 时间工具参考大纲

时间工具（Time Utilities）连接四类不同问题：把UTC日历字段转换为POSIX秒数，在参考时钟与本地计数之间建立映射，按明确的精度与舍入规则换算时长，以及对秒／纳秒组成的timespec进行规范化和算术运算。先读[时间工具指南](../kernel/P037_时间工具.md)，再根据数据的含义选用下列接口。

本册覆盖官方接口分组、同步配置与状态、两个头文件的参考与可见源码。单位辅助接口的116个原始展开块逐项保留。专有术语采用中英文对照；代码、标识符与法律注释保持原样，源码跟踪译注单独标出版本差异、时钟偏差（Skew）、溢出前提与超时舍入边界。所有本地链接采用相对路径，完整范围见[全站进度](../PROGRESS.md)。
