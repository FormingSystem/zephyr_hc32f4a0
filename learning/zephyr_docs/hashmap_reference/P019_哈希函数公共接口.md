## 19.4\_详细说明（Detailed Documentation）

<a id="ga2566ca73d30b47ae66659e26fc985fad"></a>

### `sys_hash_func32_t`

```c
typedef uint32_t(* sys_hash_func32_t) (const void *str, size_t n)
```

```c
#include <zephyr/sys/hash_function.h>
```

32位哈希函数接口。

哈希函数把任意大空间中的数据映射到通常较小的固定大小空间。对给定输入，哈希函数始终生成相同的、具有一定区分能力的数值。即使输入数据只有细微差别，良好的哈希函数在与有限数值域上的模运算结合时，也会将熵（Entropy）近乎均匀地分散到哈希值的所有位上。

**参数（Parameters）**

| 名称／方向 | 说明 |
| --- | --- |
| `str` | 一段输入数据。 |
| `n` | str中的字节数量。 |

**返回（Returns）**：str对应的数值哈希。

> 译注——源码核对：输入与用途：str是长度为n的原始字节序列，不必是以NUL结尾的字符串；哈希映射的C后端对64位键的字节表示进行哈希，再比较键值判断相等。32位哈希可能碰撞，不是唯一ID，也不是密码学摘要或认证机制。

<a id="gadd3f6fd78ce2c0bf10e1c82a9c50f39d"></a>

### `sys_hash32()`

```c
uint32_t sys_hash32 ( const void * str, size_t n )
```

声明属性：`inline`、`static`。

```c
#include <zephyr/sys/hash_function.h>
```

系统默认的32位哈希函数。

**参数（Parameters）**

| 名称／方向 | 说明 |
| --- | --- |
| `str` | 一段输入数据。 |
| `n` | str中的字节数量。 |

**返回（Returns）**：str对应的数值哈希。

> 译注——源码核对：Murmur3与默认选择：此实现种子为0，按本机32位读取或UNALIGNED_GET处理分组，再混合尾部和长度。不能仅凭名称假定不同平台或外部库生成完全相同的数值。sys_hash32通过CONFIG_SYS_HASH_FUNC32_CHOICE_*选派；若没有选择，会断言并返回0，不是自动探测可用算法。

<a id="gaaf45db9467193fe9e9d597537dd41c5e"></a>

### `sys_hash32_djb2()`

```c
uint32_t sys_hash32_djb2 ( const void * str, size_t n )
```

```c
#include <zephyr/sys/hash_function.h>
```

Daniel J. Bernstein的哈希函数。

几点说明：

- 通常，此哈希函数用于以NUL结尾的字符串。
- 这里经过修改，支持任意字节序列。
- 这里经过修改，使用异或（XOR）代替加法。

**参数（Parameters）**

| 名称／方向 | 说明 |
| --- | --- |
| `str` | 一段输入数据。 |
| `n` | str中的字节数量。 |

**返回（Returns）**：str对应的数值哈希。

**说明（Note）**：通过CONFIG_SYS_HASH_FUNC32_DJB2启用。

**参阅（See Also）**：[原文参考：djb2](https://theartincode.stanis.me/008-djb2/)。

> 译注——源码核对：DJB2变体：从5381开始，对每字节先乘33再异或，而不是常见的加字符形式；严格处理n字节，包括中间的零字节，不自行扫描字符串终止符。通过CONFIG_SYS_HASH_FUNC32_DJB2加入实现。

<a id="ga3bc327796b6836648e5dcf7c46cf38fa"></a>

### `sys_hash32_identity()`

```c
uint32_t sys_hash32_identity ( const void * str, size_t n )
```

声明属性：`inline`、`static`。

```c
#include <zephyr/sys/hash_function.h>
```

朴素的恒等哈希函数（Identity Hash Function）。

此函数要求n等于某种基本类型的大小，例如[u]int8_t、[u]int16_t、[u]int32_t、[u]int64_t、float、double或void *，且str的对齐（Alignment）与对应本机类型的要求一致。

**参数（Parameters）**

| 名称／方向 | 说明 |
| --- | --- |
| `str` | 一段输入数据。 |
| `n` | str中的字节数量。 |

**说明（Note）**：恒等哈希函数用于测试sys_hashmap。

**返回（Returns）**：str对应的数值哈希。

> 译注——源码核对：恒等哈希（Identity Hash）：实际仅接受1、2、4、8字节，并按相应无符号整数类型读取；8字节只返回低32位。名称不意味着任意长度数据原样返回。长度不支持时触发断言，之后返回0；调用者仍须保证有效对象、对齐及相应C语言访问规则。
