# 哈希映射与哈希函数参考大纲

哈希映射（Hashmap／Hash Table）以空间换取键值查找速度。通用API保存64位键值，由操作表连接C++、开放寻址／线性探测（Open Addressing / Linear Probing）和分离链接（Separate Chaining）三种实现；哈希函数（Hash Function）的选择与表实现分开配置。先读[哈希映射示例](../basic_samples/P009_哈希映射.md)，再从下列接口、结构和源码查具体契约。

本册保留原文声明、宏展开、参数、返回值、六份头文件的可见源码及法律注释；未写完的官方Note明确保留未完成状态。源码译注说明动态存储、键值所有权、负载因子、迭代前提，以及当前后端在容量检查、替换和失败路径上的差异。全部本地定位使用相对路径，完整范围见[全站进度](../PROGRESS.md)。
