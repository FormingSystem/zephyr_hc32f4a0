## 概述（Overview）

TWR-KV58F220M是基于NXP Kinetis KV5x 32位MCU的平台开发板。板载OpenSDAv2串行及调试适配器运行开源引导程序，支持串行通信、闪存编程和运行控制调试。

<a id="hardware"></a>

## 硬件（Hardware）


- MKV58F1M0VLQ24 MCU：最高240 MHz、1 MB闪存、256 KB RAM及144引脚低外形四方扁平封装（LQFP）
- MCU工作电压为1.8 V或3.3 V
- 六轴FXOS8700CQ数字加速度计及磁力计
- 4个用户LED
- 4个用户按键
- 电位器（Potentiometer）
- 两个通用TWRPI排针
- 电机引脚排针

<a id="system-clock"></a>

### 系统时钟（System Clock）

KV58 SoC使用板载50 MHz外部振荡器及片上PLL，生成237.5 MHz系统时钟。

<a id="serial-port"></a>

### 串口（Serial Port）

KV58 SoC有6路UART，UART0用作控制台，其余未使用。

<a id="accelerometer-and-magnetometer"></a>

### 加速度计与磁力计（Accelerometer and Magnetometer）

TWR-KV58F220M默认只支持轮询FXOS8700加速度计及磁力计以获取传感器数值，即CONFIG_FXOS8700_TRIGGER_NONE=y。

若需支持FXOS8700触发／中断，须在J2及J9安装跳线帽，并启用CONFIG_FXOS8700_TRIGGER_GLOBAL_THREAD=y或CONFIG_FXOS8700_TRIGGER_OWN_THREAD=y。

<a id="configuring-a-debug-probe"></a>

### 配置调试探针（Configuring a Debug Probe）

此板集成OpenSDA探针，但目前只能通过向USB大容量存储设备复制已编译固件来烧录KV58。由于pyOCD不支持此目标，不能用OpenSDA探针调试；截至原文所述2019-06-03版本，OpenSDA J-Link固件也不能使用，因为当时KV58闪存算法似乎存在问题。此限制按原文时间背景保留。

调试目标时，使用连接到JTAG排针J13的外部J-Link探针。

安装J-Link调试主机工具（Debug Host Tools），并确保工具位于搜索路径中。（[J-Link主机调试工具（Debug Host Tools）](https://docs.zephyrproject.org/latest/develop/flash_debug/host-tools.html#jlink-debug-host-tools)）

使用west：

```text
# From the root of the zephyr repository
west build -b twr_kv58f220m samples/hello_world
```

使用CMake及Ninja：

```text
# From the root of the zephyr repository
# Use cmake to configure a Ninja-based buildsystem:
cmake -Bbuild -GNinja -DBOARD=twr_kv58f220m samples/hello_world

# Now run the build tool on the generated build system:
ninja -Cbuild
```

<a id="configuring-a-console"></a>

### 配置控制台（Configuring a Console）

虽然OpenSDA探针不能用于调试，仍可作为串口控制台的USB转串口适配器。

用USB线缆将PC连接J22。

在串口终端中使用以下设置，例如minicom或PuTTY：


- 速率（Speed）：115200波特率
- 数据位（Data）：8位
- 奇偶校验（Parity）：无（None）
- 停止位（Stop Bits）：1位
