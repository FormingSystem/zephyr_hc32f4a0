## 概述（Overview）

LS1046A参考设计板（Reference Design Board，RDB）是支持Layerscape LS1046A架构处理器的高性能计算、评估与开发平台，针对DDR4内存和完整的高速SerDes端口配置进行了优化。

Layerscape LS1046A处理器集成4个64位Arm Cortex-A72核、数据包处理加速器及高速外设。其性能超过32000 CoreMarks，结合10 Gb以太网、PCIe第三代、SATA 3.0、USB 3.0和QSPI接口，适用于企业及服务提供商的网络、存储、安全和工业应用。

<a id="hardware"></a>

## 硬件（Hardware）

LS1046A RDB支持以下功能：


- 4个32／64位Arm Cortex-V8 A72 CPU，核频率最高1.6 GHz；架构名称按原文保留
- 支持8 GB DDR4 SDRAM
- SDHC端口直接连接适配卡插槽，配备4 GB eMMCi存储器件
- 一颗512 MB SLC NAND闪存，支持纠错码（ECC），1.8 V
- CPLD连接：通过CPLD中的8位寄存器配置复用／解复用（Mux/Demux）选择
- 支持两颗板载64 MB QSPI NOR闪存
- USB：两个集成PHY的USB 3.0控制器；一个USB1 3.0端口连接Type-A主机连接器；一个USB1 3.0端口通过Micro-AB连接器配置为OTG；一个USB 2.0接口连接miniPCIe连接器。USB1名称按原文保留。
- 以太网（Ethernet）：Lane 2及Lane 3支持SGMII千兆PHY；支持带XFI重定时器（Retimer）的SFP+模块；支持使用XFI／2.5G SGMII的AQR106／107万兆PHY。
- PCIe及SATA：一个Mini PCIe x1卡接口，支持Gen1／2／3；两个标准PCIe x1卡接口，均支持Gen1／2／3；一个SATA 3.0连接器。

使用以下配置在LS1046A RDB上运行基本Zephyr应用及内核测试。以下以基本同步（[Basic Synchronization](../basic_samples/P029_基本同步示例.md#synchronization)）示例为例：


1. 非SMP模式，即不启用对称多处理（Non-SMP）

```text
# From the root of the zephyr repository
west build -b ls1046ardb samples/synchronization
```

这会构建包含同步（Synchronization）示例应用的镜像。

使用U-Boot加载Zephyr.bin，并在CPU内核0上启动：

```text
tftp c0000000 zephyr.bin; dcache off; dcache flush; icache flush; icache off; go  0xc0000000;
```

也可在其他CPU核上启动Zephyr.bin，例如在Core3上运行Zephyr：

```text
tftp c0000000 zephyr.bin; dcache off; dcache flush; icache flush; icache off; cpu 3 release 0xc0000000;
```

控制台应显示以下输出：

```text
*** Booting Zephyr OS build zephyr-v2.5.0-1922-g3265b69d47e7  ***
thread_a: Hello World from cpu 0 on nxp_ls1046ardb!
thread_b: Hello World from cpu 0 on nxp_ls1046ardb!
thread_a: Hello World from cpu 0 on nxp_ls1046ardb!
```


1. 在4个CPU核上运行对称多处理（SMP）模式

```text
# From the root of the zephyr repository
west build -b ls1046ardb/ls1046a/smp/4cores samples/synchronization
```

这会构建包含同步（Synchronization）示例应用的镜像。

使用U-Boot加载Zephyr.bin，并在CPU内核0上启动：

```text
tftp c0000000 zephyr.bin; dcache off; dcache flush; icache flush; icache off; go  0xc0000000;
```

控制台应显示以下输出：

```text
*** Booting Zephyr OS build zephyr-v2.5.0-1922-g3265b69d47e7  ***
Secondary CPU core 1 (MPID:0x1) is up
Secondary CPU core 2 (MPID:0x2) is up
Secondary CPU core 3 (MPID:0x3) is up
thread_a: Hello World from cpu 0 on nxp_ls1046ardb!
thread_b: Hello World from cpu 1 on nxp_ls1046ardb!
thread_a: Hello World from cpu 0 on nxp_ls1046ardb!
```


1. 在两个CPU核Core2及Core3上运行SMP模式

```text
# From the root of the zephyr repository
west build -b ls1046ardb/ls1046a/smp samples/synchronization
```

这会构建包含同步（Synchronization）示例应用的镜像。

使用U-Boot加载Zephyr.bin，并在CPU Core2上启动：

```text
tftp c0000000 zephyr.bin; dcache off; dcache flush; icache flush; icache off; cpu 2 release 0xc0000000;
```

控制台应显示以下输出：

```text
*** Booting Zephyr OS build zephyr-v2.5.0-1922-g3265b69d47e7  ***
Secondary CPU core 1 (MPID:0x3) is up
thread_a: Hello World from cpu 0 on nxp_ls1046ardb!
thread_b: Hello World from cpu 1 on nxp_ls1046ardb!
thread_a: Hello World from cpu 0 on nxp_ls1046ardb!
```


1. 在Jailhouse客户分区（Inmate Cell）中运行Zephyr

按以下方式在Jailhouse客户分区中运行Zephyr。非SMP模式需为客户分区配置单核；SMP双核镜像需使用Core2及Core3。


1. 使用根分区（Root Cell）的DTS启动根分区Linux。
2. 安装Jailhouse模块：

```text
modprobe jailhouse
```


1. 在客户分区中运行Zephyr演示：

```text
jailhouse enable ls1046a-rdb.cell
jailhouse cell create ls1046a-rdb-inmate-demo.cell
jailhouse cell load 1 zephyr.bin --address 0xc0000000
jailhouse cell start 1
```

<a id="flashing"></a>

### 烧录（Flashing）

Zephyr镜像可在U-Boot中从SD卡、eMMC、QSPI闪存加载，或从网络下载，放入DDR地址0xc0000000处。
