## 概述（Overview）

VMU RT1170配备i.MX RT1176双核MCU，其Cortex-M7运行于1 GHz、Cortex-M4运行于400 MHz。该MCU支持宽温度范围，适用于消费、工业及汽车市场。VMU RT1170是CogniPilot Cerebri的默认车辆管理单元，Cerebri是基于Zephyr实时操作系统的自动驾驶系统。

<a id="hardware"></a>

## 硬件（Hardware）


- MIMXRT1176DVMAA微控制器


  - 1 GHz Cortex-M7及400 MHz Cortex-M4
  - 2 MB SRAM，其中Cortex-M7具有512 KB紧耦合存储器（TCM），Cortex-M4具有256 KB TCM
- 存储器（Memory）


  - 512 Mbit八线闪存（Octal Flash）
  - SD卡TF插槽
- 以太网（Ethernet）


  - 双线100BASE-T1
- 通用串行总线（USB）


  - USB 2.0连接器
- 电源（Power）


  - 双路冗余Picoflex电源端口
- 调试（Debug）


  - 10引脚调试及Shell适配板，转换为20引脚JTAG调试器接口与USB-C Shell接口
- 传感器（Sensor）


  - BMI088六轴惯性测量单元（IMU）
  - BMM150磁力计
  - 两个BMP388气压计
  - 两个ICM-42688六轴IMU
  - IST8310三轴磁力计
  - U-blox NEO-M8N全球导航卫星系统（GNSS）模块
- UART JST-GH连接器
- I2C JST-GH连接器
- CAN总线JST-GH连接器
- 遥控输入（RC IN）


  - 用于兼容SBUS遥控接收机的RC输入连接器

<a id="using-j-link"></a>

#### 使用J-Link

安装J-Link调试主机工具（Debug Host Tools），并确保工具位于搜索路径中。（[J-Link主机调试工具（Debug Host Tools）](https://docs.zephyrproject.org/latest/develop/flash_debug/host-tools.html#jlink-debug-host-tools)）

通过调试适配板连接J-Link调试器。

<a id="configuring-a-console"></a>

### 配置控制台（Configuring a Console）

通过调试适配板的USB-C接口访问控制台，在所选串口终端，如screen、minicom或PuTTY中使用以下设置：


- 速率（Speed）：115200波特率
- 数据位（Data）：8位
- 奇偶校验（Parity）：无（None）
- 停止位（Stop Bits）：1位

<a id="flashing"></a>

### 烧录（Flashing）

下面以[Hello World](../getting_started/P005_HelloWorld示例.md#hello_world)应用为例。

```text
# From the root of the zephyr repository
west build -b vmu_rt1170 samples/hello_world
west flash
```

终端中应出现以下消息：

```text
***** Booting Zephyr OS v3.4.0-xxxx-xxxxxxxxxxxxx *****
Hello World! vmu_rt1170
```

<a id="debugging"></a>

### 调试（Debugging）

下面以[Hello World](../getting_started/P005_HelloWorld示例.md#hello_world)应用为例。

```text
# From the root of the zephyr repository
west build -b vmu_rt1170 samples/hello_world
west debug
```

打开串口终端，在调试器中单步运行应用，应能在终端中看到以下消息：

```text
***** Booting Zephyr OS v3.4.0-xxxx-xxxxxxxxxxxxx *****
Hello World! vmu_rt1170
```
