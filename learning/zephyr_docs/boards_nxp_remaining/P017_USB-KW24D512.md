## 概述（Overview）

USB-KW24D512是一款USB棒形的小型评估板，基于NXP MKW24D512系统级封装（SiP）器件，属于KW2xD无线MCU系列。MKW24D512将IEEE 802.15.4无线电集成于紧凑的低功耗器件中。此板可用作数据包嗅探器（Packet Sniffer）、网络节点、边界路由器或开发板。

<a id="hardware"></a>

## 硬件（Hardware）


- Kinetis KW2xD 2.4 GHz IEEE 802.15.4无线微控制器：50 MHz、512 KB闪存、64 KB RAM、低功耗及无晶体USB
- USB Type-A连接器
- 两个蓝色LED
- 一个用户按键
- 1个复位按键（Reset Button）
- 集成PCB折叠F型天线（Folded F-type Antenna）
- 目标MCU的10引脚、0.05英寸间距JTAG调试端口

<a id="system-clock"></a>

### 系统时钟（System Clock）

USB-KW24D512的32 MHz晶体连接到无线收发器时钟引脚。MCU使用收发器输出的4 MHz外部时钟及片上PLL，生成48 MHz系统时钟。

<a id="serial-port"></a>

### 串口（Serial Port）

KW2xD SoC有3路UART，其中一路已配置，可作控制台；但该UART与JTAG接口共用引脚，且只能通过JTAG SWD连接器访问。

<a id="usb"></a>

### 通用串行总线（USB）

KW2xD的USB OTG控制器支持设备及主机功能，目前Zephyr只支持USB设备功能。USB-KW24D512使用USB Type-A连接器，只能作为设备使用。

<a id="configuring-a-console"></a>

### 配置控制台（Configuring a Console）

控制台通过[Segger RTT](https://www.segger.com/products/debug-probes/j-link/technology/about-real-time-transfer/)提供。

用USB线缆将PC连接J5。

启动调试会话后，运行telnet：

```text
Trying 127.0.0.1...
Connected to localhost.
Escape character is '^]'.
SEGGER J-Link V6.44 - Real time terminal output
SEGGER J-Link ARM V10.1, SN=600111924
Process: JLinkGDBServerCLExe
```

<a id="flashing"></a>

### 烧录（Flashing）

下面以[Hello World](../getting_started/P005_HelloWorld示例.md#hello_world)应用为例。

```text
# From the root of the zephyr repository
west build -b usb_kw24d512 samples/hello_world
west flash
```

Segger RTT控制台仅在调试会话期间可用。使用attach启动会话：

```text
# From the root of the zephyr repository
west build -b usb_kw24d512 samples/hello_world
west attach
```

按前述方式运行telnet，终端应显示以下消息：

```text
***** Booting Zephyr OS v1.14.0-rc1 *****
Hello World! usb_kw24d512
```
