# 环形缓冲区参考大纲

环形缓冲区（Ring Buffer）在固定后备内存中保存先进先出（First In First Out，FIFO）字节流。本册翻译公共API、结构说明、头文件参考及源码浏览，供驱动收发与流式处理查阅。先读[环形缓冲区指南](../kernel/P019_环形缓冲区.md)，了解复制与零复制（Zero-copy）访问，再查具体接口。

新版默认仅需头文件，采用ptr／commit／consume访问；CONFIG_RING_BUFFER用于兼容已弃用接口。源码跟踪译注区分官方main、latest网页与仓库源码，保留原始代码、宏展开和法律注释，所有仓库链接采用相对路径。固定大小数据项另见[环形队列参考](../ringq_reference/大纲.md)。完整范围与待译情况见[全站进度](../PROGRESS.md)。
