# 第42章\_LLEXT_REMOVE_FLAGS

原文：[LLEXT_REMOVE_FLAGS](https://docs.zephyrproject.org/latest/build/cmake-ref/variable/LLEXT_REMOVE_FLAGS.html)。本次读取日期：2026-10-14；基线为保存的 `latest` 页面，HTML 摘要见[来源记录](../SOURCES.md)。

<a id="variable:LLEXT_REMOVE_FLAGS"></a>

全局正则表达式（Regular Expression）列表，描述编译可加载扩展（Loadable Extension）时，要从编译器调用中移除的选项。

这些选项取决于目标和编译器，通常在工具链文件（Toolchain File）中设置。另见 `add_llext_target()`。
