# 第41章\_LLEXT_APPEND_FLAGS

原文：[LLEXT_APPEND_FLAGS](https://docs.zephyrproject.org/latest/build/cmake-ref/variable/LLEXT_APPEND_FLAGS.html)。本次读取日期：2026-10-14；基线为保存的 `latest` 页面，HTML 摘要见[来源记录](../SOURCES.md)。

<a id="variable:LLEXT_APPEND_FLAGS"></a>

编译可加载扩展（Loadable Extension）时，要添加到编译器调用中的编译器选项（Compiler Flag）全局列表。

这些选项取决于目标和编译器，通常在工具链文件（Toolchain File）中设置。另见 `add_llext_target()`。
