# 第19章\_LIBC_LINK_LIBRARIES

原文：[LIBC_LINK_LIBRARIES](https://docs.zephyrproject.org/latest/build/cmake-ref/prop_tgt/LIBC_LINK_LIBRARIES.html)。本次读取日期：2026-10-14；基线为保存的 `latest` 页面，HTML 摘要见[来源记录](../SOURCES.md)。

<a id="prop_tgt:LIBC_LINK_LIBRARIES"></a>

构建 C 标准库（C Standard Library）时要链接到该库的库列表。本目标属性（Target Property）用于定义 C 标准库可能对其他库存在的额外依赖。

另见 `zephyr_libc_link_libraries()`。
