原文：[SB_APPLICATION_CONFIG_DIR](https://docs.zephyrproject.org/latest/build/cmake-ref/variable/SB_APPLICATION_CONFIG_DIR.html)。本次读取日期：2026-10-14；基线为保存的 `latest` 页面，HTML 摘要见[来源记录](../SOURCES.md)。

<a id="variable:SB_APPLICATION_CONFIG_DIR"></a>

搜索 Sysbuild 自身配置文件的目录。

若设置了此变量，在定位 `SB_CONF_FILE` 时，它的优先级高于 `APPLICATION_CONFIG_DIR`。另见 `sysbuild_kconfig`、`APPLICATION_CONFIG_DIR` 和 `SB_CONF_FILE`。
