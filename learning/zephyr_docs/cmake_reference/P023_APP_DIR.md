# 第23章\_APP_DIR

原文：[APP_DIR](https://docs.zephyrproject.org/latest/build/cmake-ref/variable/APP_DIR.html)。本次读取日期：2026-10-14；基线为保存的 `latest` 页面，HTML 摘要见[来源记录](../SOURCES.md)。

<a id="variable:APP_DIR"></a>

Sysbuild 中主应用（Main Application）的源目录。

由构建选项 `-DAPP_DIR=<path>` 或同名环境变量设置。Sysbuild 相对于此目录解析配置文件和根目录列表（Root List）。另见 Sysbuild。
