# 第27章\_BOARD

原文：[BOARD](https://docs.zephyrproject.org/latest/build/cmake-ref/variable/BOARD.html)。本次读取日期：2026-10-14；基线为保存的 `latest` 页面，HTML 摘要见[来源记录](../SOURCES.md)。

<a id="variable:BOARD"></a>

作为 `boards` 模块的输入：包含可选修订版（Revision）的开发板（Board）名称，例如 `foo` 或 `foo@1.0.0`。

作为 `boards` 模块的输出：不含修订版字段的开发板名称。另见 `boards` 模块。
