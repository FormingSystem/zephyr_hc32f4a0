# 第31章\_BOARD_ROOT

原文：[BOARD_ROOT](https://docs.zephyrproject.org/latest/build/cmake-ref/variable/BOARD_ROOT.html)。本次读取日期：2026-10-14；基线为保存的 `latest` 页面，HTML 摘要见[来源记录](../SOURCES.md)。

<a id="variable:BOARD_ROOT"></a>

作为 `boards` 模块的输入：包含开发板（Board）实现的目录列表。

作为 `boards` 模块的输出：包含开发板实现的目录列表，更新时追加 `ZEPHYR_BASE`。另见 `boards` 模块。
