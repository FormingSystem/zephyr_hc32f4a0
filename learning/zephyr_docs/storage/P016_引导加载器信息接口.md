# 第16章\_引导加载器信息接口

原文：[group__bootloader__info__interface](https://docs.zephyrproject.org/latest/doxygen/html/group__bootloader__info__interface.html)。读取日期：2026-10-13，`latest`。

**引导加载器信息接口（Bootloader Info Interface）**自 Zephyr 3.5 提供，接口版本 0.1.0。头文件为 `zephyr/retention/blinfo.h`。

## 16.1\_查询共享启动信息

[`blinfo_lookup()`](https://docs.zephyrproject.org/latest/doxygen/html/group__bootloader__info__interface.html#ga7b172c65244678070c9b6ca6e24cee0f) 返回启动信息（Boot Information）。函数签名如下：

```c
int blinfo_lookup(uint16_t key, char *val, int val_len_max);
```

| 参数 | 含义 |
| --- | --- |
| `key` | 要查询的信息标识；对于 MCUboot，它是 minor TLV 标识 |
| `val` | 存放返回信息的缓冲区 |
| `val_len_max` | 调用者提供缓冲区的最大大小 |

**类型—长度—值（Type-Length-Value，TLV）**是原文所用的数据项术语，`minor TLV` 表示 MCUboot 对该信息项使用的次级标识；MCUboot 是引导加载器项目名称。

## 16.2\_返回长度与错误

成功时返回大于或等于零的值，表示已读取的数据长度。其他情况如下：

| 返回值 | 含义 |
| --- | --- |
| `-EOVERFLOW` | 数据过大，无法放入给定缓冲区 |
| `-EIO` | 没有找到请求的键 |
| 其他负错误码 | 操作失败 |
