# 第81章\_Ext2挂载表示例

原文：[EXT2 filesystem fstab](https://docs.zephyrproject.org/latest/samples/subsys/fs/ext2_fstab/README.html)。读取日期：2026-10-13，`latest`。

## 81.1\_示例用途

本示例演示如何在**设备树（Devicetree）**中定义 Ext2 **文件系统挂载表（File System Table，fstab）**条目。它运行于 `native_sim` 主机原生模拟目标，使用**内存磁盘（RAM Disk）**保存 Ext2；RAM 指随机存取存储器（Random-Access Memory）。

[官方示例源码](https://github.com/zephyrproject-rtos/zephyr/tree/main/samples/subsys/fs/ext2_fstab)。

## 81.2\_构建与运行

先为 `native_sim` 构建，然后运行构建目录内生成的可执行文件。以下为官方命令；`DTC_OVERLAY_FILE` 指定设备树覆盖文件（Devicetree Overlay），`ext2_fstab.overlay` 是本示例的配置文件。

译注：在已按 Zephyr 环境指南配置好的 Linux 开发终端中，从 Zephyr 源码根目录执行；这里使用主机模拟目标，不是将固件烧写到 HC32。

```shell
west build -b native_sim samples/subsys/fs/ext2_fstab -- -DDTC_OVERLAY_FILE=ext2_fstab.overlay
```

## 81.3\_预期输出

运行成功时应看到：

```console
I: Filesystem access successful
```

该行表示“文件系统访问成功”。原网页将 `.. code-block:: console` 排版指令显示成正文；此处按其意图恢复为控制台输出块，消息原文未改动。本译文未构建或运行示例。
