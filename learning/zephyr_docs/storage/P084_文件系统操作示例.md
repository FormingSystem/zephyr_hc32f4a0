# 第84章\_文件系统操作示例

原文：[File system manipulation](https://docs.zephyrproject.org/latest/samples/subsys/fs/fs_sample/README.html)。读取日期：2026-10-13，`latest`。

## 84.1\_用途与存储设备

本示例演示**文件系统应用编程接口（File System Application Programming Interface，File System API）**，通过 FAT 或 Ext2 驱动访问 SDHC 卡、片上系统闪存或外部闪存芯片。FAT 是文件分配表（File Allocation Table）文件系统，SDHC 是高容量安全数字卡（Secure Digital High Capacity），**片上系统（System on Chip，SoC）**集成片内闪存。

示例通过[磁盘访问（Disk Access）](https://docs.zephyrproject.org/latest/services/storage/disk/access.html)接口访问设备。[官方示例源码](https://github.com/zephyrproject-rtos/zephyr/tree/main/samples/subsys/fs/fs_sample)。

## 84.2\_SD卡与片内闪存要求

使用安全数字卡（Secure Digital，SD）时，需要平台支持 SD 卡，并准备已格式化为 FAT 或 Ext2 的 microSD 卡。实现细节见磁盘访问文档。

默认使用 SD 卡存储的开发板有 `arduino_mkrzero`、`esp_wrover_kit`、`mimxrt1050_evk`、`nrf52840_blip` 和 `olimexino_stm32`。其他启用了 `zephyr,sdmmc-disk` **设备树（Devicetree）**节点的开发板也应能运行。

若要在片内闪存上使用 FAT，设备的擦除页大小必须 **不超过 4096 字节**，并且至少有 **64 KiB** 闪存专供 FAT 分区使用。原页当前列出的支持板为 `nrf52840dk/nrf52840`。

## 84.3\_外部闪存要求

开发板必须具备外部闪存。原页列出的配置是 `nrf52840dk/nrf52840` 配合 `nrf52840dk_nrf52840_qspi`。

**四线串行外设接口（Quad Serial Peripheral Interface，QSPI）**用于连接该配置中的 MX25 外部闪存。

## 84.4\_构建并运行FAT场景

对于默认配置的开发板，例如 `arduino_mkrzero`，或使用片内闪存的 `nrf52840dk/nrf52840`，可按下面形式构建。命令中的 `nrf52840_blip` 只是示例板名，应替换为实际目标。

译注：在已配置 Zephyr 环境的开发终端中，从 Zephyr 源码根目录执行；以下命令均保留原文。

```shell
west build -b nrf52840_blip samples/subsys/fs/fs_sample
```

若要使用更具体的板级配置，例如 nRF52840 DK 上通过 QSPI 连接 MX25，还必须选择附加配置和设备树覆盖文件（Overlay）：

```shell
west build -b nrf52840dk/nrf52840 samples/subsys/fs/fs_sample -- -DEXTRA_CONF_FILE=nrf52840dk_nrf52840_qspi.conf -DDTC_OVERLAY_FILE=nrf52840dk_nrf52840_qspi.overlay
```

`EXTRA_CONF_FILE` 选择附加配置文件，`DTC_OVERLAY_FILE` 选择设备树覆盖文件。使用 SD 卡的开发板必须插入 FAT 格式 microSD 卡；卡上已有文件或目录时，示例会通过调试串口输出其列表。

**原文警告：挂载失败时，设备可能被重新格式化为 FAT。** 若要禁用此行为，应关闭 Kconfig 配置项 [`CONFIG_FS_FATFS_MOUNT_MKFS`](https://docs.zephyrproject.org/latest/kconfig.html#CONFIG_FS_FATFS_MOUNT_MKFS)。

## 84.5\_构建并运行Ext2场景

原页说明 Ext2 示例可为 `hifive_unmatched/fu740/s7` 或 `bl5340_dvk/nrf5340/cpuapp` 构建。由于示例默认采用 FAT，必须传入额外配置。原命令如下：

```shell
west build -b hifive_unmatched/fu740/s7 hifive_unmatched/fu740/u74 samples/subsys/fs/fs_sample -- -DCONF_FILE=prj_ext.conf
```

译注：这条官方命令在 `-b` 后同时出现 `hifive_unmatched/fu740/s7` 和 `hifive_unmatched/fu740/u74` 两个目标字符串，与通常的单目标构建形式不一致。这里保留原始命令；实际构建应明确选择一个受支持目标，将 `samples/subsys/fs/fs_sample` 作为示例路径，并保留 `-DCONF_FILE=prj_ext.conf`，不能把两个目标字符串原样视为一个板名。本译文未验证这些目标的构建结果。

运行时必须在开发板卡槽中插入 microSD 卡。启动后应在控制台看到根目录内容。

相关参考：[文件系统接口](P033_文件系统接口.md)、[磁盘访问接口](https://docs.zephyrproject.org/latest/doxygen/html/group__disk__access__interface.html)。
