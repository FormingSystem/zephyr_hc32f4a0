# 第56章\_非易失性存储实例结构

原文：[structnvs__fs](https://docs.zephyrproject.org/latest/doxygen/html/structnvs__fs.html)。读取日期：2026-10-13，`latest`。

## 56.1\_实例职责

`struct nvs_fs` 是**非易失性存储（Non-volatile Storage，NVS）**文件系统结构，声明于 `zephyr/kvss/nvs.h`。

**分配表条目（Allocation Table Entry，ATE）**描述存储分配信息；**扇区（Sector）**划分存储空间；**互斥锁（Mutex）**用于同步访问。

## 56.3\_分配表地址编码

`ate_wra` 的地址以 [`uint32_t`](https://docs.zephyrproject.org/latest/doxygen/html/stdint_8h.html#a0a8582351ac627ee8bde2973c825e47f) 保存：**高 2 字节对应扇区，低 2 字节为扇区内偏移**。这描述的是该字段的编码方式，不是另一个裸指针类型。
