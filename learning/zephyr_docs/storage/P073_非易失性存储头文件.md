# 第73章\_非易失性存储头文件

原文：[kvss_2nvs_8h](https://docs.zephyrproject.org/latest/doxygen/html/kvss_2nvs_8h.html)。读取日期：2026-10-13，`latest`。

`zephyr/kvss/nvs.h` 声明**非易失性存储（Non-volatile Storage，NVS）应用编程接口（Application Programming Interface，API）**。

## 73.1\_包含关系

官方头文件的包含项如下：

```c
#include <sys/types.h>
#include <zephyr/kernel.h>
#include <zephyr/device.h>
#include <zephyr/toolchain.h>
```

[查看官方源文件页面](https://docs.zephyrproject.org/latest/doxygen/html/kvss_2nvs_8h_source.html)。

## 73.2\_结构、宏与类型

`struct nvs_fs` 是 NVS 文件系统结构，详见[实例结构参考](P056_非易失性存储实例结构.md)。

## 73.3\_函数声明与中文索引

函数 [`nvs_mount()`](https://docs.zephyrproject.org/latest/doxygen/html/group__nvs__high__level__api.html#gab932ea2d6e933825c2378bef8c30b065)：将 NVS 文件系统挂载到 `fs` 指定的闪存设备。

```c
int nvs_mount(struct nvs_fs *fs);
```

函数 [`nvs_clear()`](https://docs.zephyrproject.org/latest/doxygen/html/group__nvs__high__level__api.html#ga42ee9fd0d98f89dcabc5888f8b4600f0)：从闪存清除 NVS 文件系统。

```c
int nvs_clear(struct nvs_fs *fs);
```

函数 [`nvs_write()`](https://docs.zephyrproject.org/latest/doxygen/html/group__nvs__high__level__api.html#ga34d40e9f63ba514d7915b72c4fef0b82)：向文件系统写入一个条目。

```c
ssize_t nvs_write(struct nvs_fs *fs, uint16_t id, const void *data, size_t len);
```

函数 [`nvs_delete()`](https://docs.zephyrproject.org/latest/doxygen/html/group__nvs__high__level__api.html#ga5fd4175a4976e6d3ee8621ed95e0ee9e)：删除一个条目。

```c
int nvs_delete(struct nvs_fs *fs, uint16_t id);
```

函数 [`nvs_read()`](https://docs.zephyrproject.org/latest/doxygen/html/group__nvs__high__level__api.html#ga341fd2ad029709cbb6eafde1ae88603f)：读取一个条目。

```c
ssize_t nvs_read(struct nvs_fs *fs, uint16_t id, void *data, size_t len);
```

函数 [`nvs_read_hist()`](https://docs.zephyrproject.org/latest/doxygen/html/group__nvs__high__level__api.html#ga8e525038e353045ad6cd90607e887b0d)：读取条目的历史版本。

```c
ssize_t nvs_read_hist(struct nvs_fs *fs, uint16_t id, void *data, size_t len, uint16_t cnt);
```

函数 [`nvs_calc_free_space()`](https://docs.zephyrproject.org/latest/doxygen/html/group__nvs__high__level__api.html#ga37e5a55f0b9209c7c0c95db9e1e84715)：计算文件系统可用空闲空间。

```c
ssize_t nvs_calc_free_space(struct nvs_fs *fs);
```

函数 [`nvs_sector_max_data_size()`](https://docs.zephyrproject.org/latest/doxygen/html/group__nvs__high__level__api.html#ga7ce6065cf3ac68544f51d26cabd983b2)：查询当前活动扇区的连续空闲空间。

```c
size_t nvs_sector_max_data_size(struct nvs_fs *fs);
```

函数 [`nvs_sector_use_next()`](https://docs.zephyrproject.org/latest/doxygen/html/group__nvs__high__level__api.html#ga52db47389e9aa2b0de77497f0e60ed5b)：关闭当前活动扇区并切换到下一个扇区。

```c
int nvs_sector_use_next(struct nvs_fs *fs);
```

参数、返回值和使用条件见[对应接口参考](P055_非易失性存储接口.md)。
