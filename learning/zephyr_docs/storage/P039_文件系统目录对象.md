# 第39章\_文件系统目录对象

原文：[structfs__dir__t](https://docs.zephyrproject.org/latest/doxygen/html/structfs__dir__t.html)。读取日期：2026-10-13，`latest`。

`struct fs_dir_t` 表示一个已打开目录的**目录对象（Directory Object）**。使用前必须通过 [`fs_dir_t_init()`](https://docs.zephyrproject.org/latest/doxygen/html/group__file__system__api.html#gacd31440cd0b10308e55a0484828ea2f3) 初始化。

```c
#include <zephyr/fs/fs_interface.h>
```

## 39.1\_字段定义

| 字段 | 类型 | 含义 |
| --- | --- | --- |
| [`dirp`](https://docs.zephyrproject.org/latest/doxygen/html/structfs__dir__t.html#afdd8e0b7b0c528a420c050718213d1ff) | `void *` | 指向底层目录对象结构 |
| [`mp`](https://docs.zephyrproject.org/latest/doxygen/html/structfs__dir__t.html#a6d8e0c603a33ed4870fcd7b82e1bc0a4) | `const struct fs_mount_t *` | 指向挂载点结构 |

初始化和目录打开、读取、关闭操作见[文件系统接口](P033_文件系统接口.md)。
