# 第66章\_设置动态处理器结构

原文：[structsettings__handler](https://docs.zephyrproject.org/latest/doxygen/html/structsettings__handler.html)。读取日期：2026-10-13，`latest`。

## 66.1\_结构职责与注册

`struct settings_handler` 为**设置子系统（Settings Subsystem）**的子树提供一组**处理器（Handler）**函数，声明于 `zephyr/settings/settings.h`。使用 [`settings_register()`](https://docs.zephyrproject.org/latest/doxygen/html/group__settings.html#gab2043a6d799202e177cc3dfa0cbfa531) 注册。

**提交（Commit）**用于将已加载设置应用到程序；**导出（Export）**用于提供待保存设置。

| 字段 | 类型 | 中文说明 |
| --- | --- | --- |
| [`name`](https://docs.zephyrproject.org/latest/doxygen/html/structsettings__handler.html#ab8eee945dc866ec90b272fb526abc646) | `const char *` | 子树名称 |
| [`cprio`](https://docs.zephyrproject.org/latest/doxygen/html/structsettings__handler.html#ad2eae214e3ba8e50ead1a0e9afe2b251) | `int` | 提交优先级，数值越小优先级越高 |
| [`node`](https://docs.zephyrproject.org/latest/doxygen/html/structsettings__handler.html#a6aa2cc76c84341c3d29b679d2cc9c6ab) | [`sys_snode_t`](../slist_reference/P001_单向链表公共接口.md#ga69bf43aad81e3ee2d55250c59b857493) | 模块内部使用的单向链表节点（Singly Linked List Node）信息 |

## 66.2\_获取回调

函数指针字段 [`h_get`](https://docs.zephyrproject.org/latest/doxygen/html/structsettings__handler.html#a8d4036babe22872777610e54c4dadf21) 按关键字名称获取设置值。

```c
int (*h_get)(const char *key, char *val, int val_len_max);
```

输入参数 `key` 是跳过注册处理器所用名称部分后的键名；输出 `val` 指向接收值的缓冲区；输入 `val_len_max` 为缓冲区大小。成功返回读取数据长度，失败返回负值。

## 66.3\_设置回调

函数指针字段 [`h_set`](https://docs.zephyrproject.org/latest/doxygen/html/structsettings__handler.html#a70aa25bf3b53898ab22906e9949963a4) 按关键字名称设置值。

```c
int (*h_set)(const char *key, size_t len, settings_read_cb read_cb, void *cb_arg);
```

所有参数均按原页标为输入：`key` 是跳过注册名称部分后的键名；`len` 是后端中找到的数据大小；`read_cb` 是后端提供的读取函数；`cb_arg` 是后端提供给该函数的参数。成功返回 0，失败返回非零。

## 66.4\_提交回调

函数指针字段 [`h_commit`](https://docs.zephyrproject.org/latest/doxygen/html/structsettings__handler.html#ad5e23a2acf29bbb2a5a4f249b5f80e0a) 在设置完整加载之后被调用，可用于将设置应用到程序。

```c
int (*h_commit)(void);
```

成功返回 0，失败返回非零。

## 66.5\_导出回调

函数指针字段 [`h_export`](https://docs.zephyrproject.org/latest/doxygen/html/structsettings__handler.html#a30207125407f57a0f117ecaee5a2054a) 导出全部当前设置项，在 [`settings_save()`](https://docs.zephyrproject.org/latest/doxygen/html/group__settings.html#ga789410aa059398d6c8a7851ea6945b55) 尝试保存设置时调用。

```c
int (*h_export)(int (*export_func)(const char *name,
                                  const void *val, size_t val_len));
```

输入参数 `export_func` 指向内部函数，它将单个**键值对（Key-value Pair）**追加到持久化设置中；不要保存重复值。[`name`](https://docs.zephyrproject.org/latest/doxygen/html/structsettings__handler.html#ab8eee945dc866ec90b272fb526abc646) 为 `subtree/key` 形式的字符串；原文将 `val` 描述为保存值的字符串，其函数声明实际为 `const void *`，此处保留原声明。`val_len` 是该导出函数接收的值长度。

原文备注：使用者可以将处理器实现限制为每次仅处理一个关键字；这样获取/设置值就受到必须使用完整 `subtree/key` 名称的限制。

`h_export` 成功返回 0，失败返回非零。
