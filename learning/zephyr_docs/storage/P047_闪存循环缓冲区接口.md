# 第47章\_闪存循环缓冲区接口

原文：[group__fcb__api](https://docs.zephyrproject.org/latest/doxygen/html/group__fcb__api.html)。读取日期：2026-10-13，`latest`。

## 47.1\_头文件与遍历回调

本页为**闪存循环缓冲区（Flash Circular Buffer，FCB）应用编程接口（Application Programming Interface，API）**。所有声明来自 `zephyr/fs/fcb.h`：

```c
#include <zephyr/fs/fcb.h>
```

[`fcb_walk_cb`](https://docs.zephyrproject.org/latest/doxygen/html/group__fcb__api.html#gaeed5144438ee00d83c9b3d3b4b7490ea) 是**遍历回调（Walk Callback）**函数类型，由 [`fcb_walk()`](https://docs.zephyrproject.org/latest/doxygen/html/group__fcb__api.html#gad50e579ec9430a23ef5525e74ceb21b2) 遍历条目时调用。

```c
typedef int (*fcb_walk_cb)(struct fcb_entry_ctx *loc_ctx, void *arg);
```

输入参数 `loc_ctx` 包含条目位置的完整上下文；输入/输出参数 `arg` 是从 [`fcb_walk()`](https://docs.zephyrproject.org/latest/doxygen/html/group__fcb__api.html#gad50e579ec9430a23ef5525e74ceb21b2) 传入的回调上下文。可将 `loc_ctx` 的字段用作 [`flash_area_read()`](https://docs.zephyrproject.org/latest/doxygen/html/group__flash__area__api.html#ga7c55704b0c0061a4715470676114b127) 的参数，读取条目数据。回调返回 **0** 继续遍历，返回**非零**停止遍历。

## 47.2\_初始化与追加条目

[`fcb_init()`](https://docs.zephyrproject.org/latest/doxygen/html/group__fcb__api.html#gab304f3e9e28f6229d7ddbe638eda2f70) 初始化 FCB 实例。

```c
int fcb_init(int f_area_id, struct fcb *fcbp);
```

`f_area_id` 为输入参数，指定存储所在**闪存区域（Flash Area）**的标识符；`fcbp` 为输入/输出参数，指向 FCB 实例结构。成功返回 0，失败返回非零。

[`fcb_append()`](https://docs.zephyrproject.org/latest/doxygen/html/group__fcb__api.html#gad567d124d8b0fe181ed54cfbe33b315c) 向循环缓冲区追加一个**条目（Entry）**，输出其位置，供调用者写入**有效载荷（Payload）**。

```c
int fcb_append(struct fcb *fcbp, uint16_t len, struct fcb_entry *loc);
```

输入 `fcbp` 为实例；输入 `len` 为预计写入的有效载荷长度；输出 `loc` 为条目位置信息。成功返回 0，失败返回非零。

写入条目内容时，结合 `loc->fe_sector`、`loc->fe_data_off` 调用 [`flash_area_write()`](https://docs.zephyrproject.org/latest/doxygen/html/group__flash__area__api.html#gaa56052f8d6bf4f6966752bc21f5cceb8)，写入 FCB 使用的 [`flash_area`](https://docs.zephyrproject.org/latest/doxygen/html/structflash__area.html)。写完后，必须将该位置交给 [`fcb_append_finish()`](https://docs.zephyrproject.org/latest/doxygen/html/group__fcb__api.html#gaae445e8376db192ce45fff9dcf95c954) 完成追加：

```c
int fcb_append_finish(struct fcb *fcbp, struct fcb_entry *append_loc);
```

输入参数 `fcbp` 为实例，`append_loc` 为条目位置信息。成功返回 0，失败返回非零。

## 47.3\_遍历与获取条目位置

[`fcb_walk()`](https://docs.zephyrproject.org/latest/doxygen/html/group__fcb__api.html#gad50e579ec9430a23ef5525e74ceb21b2) 遍历指定**扇区（Sector）**内的全部条目。

```c
int fcb_walk(struct fcb *fcbp, struct flash_sector *sector,
             fcb_walk_cb cb, void *cb_arg);
```

| 参数 | 方向 | 含义 |
| --- | --- | --- |
| `fcbp` | 输入 | FCB 实例 |
| `sector` | 输入 | 待遍历扇区；为 `NULL` 时遍历整个存储区域 |
| `cb` | 输入 | 每个条目对应的回调函数；返回非零即停止遍历 |
| `cb_arg` | 输入/输出 | 传给回调实现的上下文 |

成功返回 0。负值表示失败，也可能是从回调传递而来的返回值；正值同样来自回调返回值。

[`fcb_getnext()`](https://docs.zephyrproject.org/latest/doxygen/html/group__fcb__api.html#ga7908a252a09ebbb98b60a505220072bc) 根据 `loc` 当前指向的位置获取下一位置。

```c
int fcb_getnext(struct fcb *fcbp, struct fcb_entry *loc);
```

`fcbp` 为输入实例；`loc` 为输入/输出位置信息，其输入状态决定查找方式：

| `loc` 的输入状态 | 查找目标 |
| --- | --- |
| `fe_sector` 已设置，且 `fe_elem_off != 0` | 下一个 FCB 条目 |
| `fe_sector == NULL` | 整个 FCB 中最旧的条目 |
| `fe_sector` 已设置，且 `fe_elem_off == 0` | 该扇区的第一个条目 |

成功返回 0，失败返回非零。

[`fcb_offset_last_n()`](https://docs.zephyrproject.org/latest/doxygen/html/group__fcb__api.html#gac15df95c0d9bed45c9da39802411598d) 查找一个条目位置，从该位置开始最多可取得末尾的 n 个条目。

```c
int fcb_offset_last_n(struct fcb *fcbp, uint8_t entries,
                      struct fcb_entry *last_n_entry);
```

输入 `fcbp` 为实例，输入 `entries` 为希望取得的条目数，输出 `last_n_entry` 为找到的 [`fcb_entry`](https://docs.zephyrproject.org/latest/doxygen/html/structfcb__entry.html)。只要存在可用条目即返回 0，否则返回 `-ENOENT`。

## 47.4\_扇区轮换与暂存扇区

[`fcb_rotate()`](https://docs.zephyrproject.org/latest/doxygen/html/group__fcb__api.html#gad2fb288645e678dd6ea05b0871d5e774) **轮换（Rotate）**FCB 扇区：擦除最旧扇区的数据，使下一个扇区成为最旧扇区，并在需要时切换**活动扇区（Active Sector）**。

```c
int fcb_rotate(struct fcb *fcbp);
```

`fcbp` 为输入实例。原页未列出该函数的返回值说明。

[`fcb_append_to_scratch()`](https://docs.zephyrproject.org/latest/doxygen/html/group__fcb__api.html#ga22b2bab8af3004c93e5d40659ccfec29) 启用一个**暂存块（Scratch Block）**，使暂存扇区成为可追加条目的活动扇区。

```c
int fcb_append_to_scratch(struct fcb *fcbp);
```

`fcbp` 为输入实例。成功返回 0，失败返回非零。

## 47.5\_容量查询与清空

以下函数均以输入参数 `fcbp` 指定实例。

```c
int fcb_free_sector_cnt(struct fcb *fcbp);
int fcb_is_empty(struct fcb *fcbp);
int fcb_clear(struct fcb *fcbp);
```

| 函数 | 功能 | 返回值 |
| --- | --- | --- |
| [`fcb_free_sector_cnt()`](https://docs.zephyrproject.org/latest/doxygen/html/group__fcb__api.html#gaa9beaa3f5a6cc52b7e460d5670fdaabf) | 查询空闲扇区数 | 空闲扇区的数量 |
| [`fcb_is_empty()`](https://docs.zephyrproject.org/latest/doxygen/html/group__fcb__api.html#gade8af12645d769ce3b27848976ada32a) | 检查 FCB 是否包含数据 | 为空时返回正值，否则返回 0 |
| [`fcb_clear()`](https://docs.zephyrproject.org/latest/doxygen/html/group__fcb__api.html#gaab78da410b7e709854e29219eb02a0c9) | 清空 FCB 实例的存储内容 | 成功返回 0，失败返回非零 |
