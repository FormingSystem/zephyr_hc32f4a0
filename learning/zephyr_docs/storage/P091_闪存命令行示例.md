# 第91章\_闪存命令行示例

原文：[Flash shell](https://docs.zephyrproject.org/latest/samples/drivers/flash_shell/README.html)。读取日期：2026-10-13，`latest`。

## 91.1\_示例用途

本示例提供简单的**命令行（Shell）**模块，使任何具备**闪存驱动（Flash Driver）**支持的开发板都能通过命令查看和操作闪存设备。

[官方示例源码](https://github.com/zephyrproject-rtos/zephyr/tree/main/samples/drivers/flash_shell)。

## 91.2\_构建与运行

以下官方命令使用 `qemu_x86` 模拟目标构建并运行。执行位置为 Zephyr 源码根目录，前提是开发终端已配置工具链和 QEMU 模拟器。

```shell
west build -b qemu_x86 samples/drivers/flash_shell
west build -t run
```

## 91.3\_原始交互记录

下面的 `uart:~$` 是示例串口命令行提示符；UART 指通用异步收发器（Universal Asynchronous Receiver/Transmitter）。`flash page_info` 查询页信息，`flash erase` 擦除，`flash write` 写入，`flash read` 读取。`OK` 表示成功，`Verified` 表示校验通过，`ERROR` 表示错误。

```console
uart:~$ flash page_info 0
Page for address 0x0:
start offset: 0x0
size: 4096
index: 0
uart:~$ flash erase 0x1000
Erase success.
uart:~$ flash write 0x1000 0x12345678 0x9abcdef0
Write OK.
Verified.
uart:~$ flash write 0x1000 0x11111111
Write internal ERROR!
uart:~$ flash read 0x1000 0x10
00001000: 78 56 34 12 f0 de bc 9a  ff ff ff ff ff ff ff ff |xV4..... ........|

uart:~$ flash write 0x101c 0xabcd1234
Write OK.
Verified.
uart:~$ flash read 0x1000 0x20
00001000: 78 56 34 12 f0 de bc 9a  ff ff ff ff ff ff ff ff |xV4..... ........|
00001010: ff ff ff ff ff ff ff ff  ff ff ff ff 34 12 cd ab |........ ....4...|
```

原记录先查询地址 0 的闪存页，再擦除 `0x1000` 所在范围，写入并校验两个数值；直接再次写入 `0x11111111` 时报告内部错误。后续读取展示已存字节，又在 `0x101c` 写入一个值并读取。地址、字节顺序及错误消息均保持原样。

这些是会产生擦写的交互命令；本译文保留官方示范，并未对模拟器或实物设备执行它们。
