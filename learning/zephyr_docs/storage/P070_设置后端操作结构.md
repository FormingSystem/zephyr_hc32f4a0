# 第70章\_设置后端操作结构

原文：[structsettings__store__itf](https://docs.zephyrproject.org/latest/doxygen/html/structsettings__store__itf.html)。读取日期：2026-10-13，`latest`。

## 70.1\_后端操作职责

`struct settings_store_itf` 定义**设置子系统（Settings Subsystem）存储后端（Storage Backend）**处理函数，声明于 `zephyr/settings/settings.h`。读取来源通过 [`settings_src_register()`](https://docs.zephyrproject.org/latest/doxygen/html/group__settings__backend.html#gad16bb70588cf69873f8872d7bf90e1c6) 注册，写入目的通过 [`settings_dst_register()`](https://docs.zephyrproject.org/latest/doxygen/html/group__settings__backend.html#ga37bcada0be44b023cd3759e519e69d01) 注册。

下述各项都是函数指针字段；共同输入参数 `cs` 指向对应的后端处理器节点。

## 70.2\_加载子树

[`csi_load`](https://docs.zephyrproject.org/latest/doxygen/html/structsettings__store__itf.html#a8c08da2cd010f5d73689e84d02d12734) 从存储中加载由子树条件限定的值，输入参数 `arg` 指向包含额外加载数据的结构。

```c
int (*csi_load)(struct settings_store *cs, const struct settings_load_arg *arg);
```

**后端不得提供重复条目。** 若后端无法真正删除旧键，就必须过滤旧条目，仅为最终条目调用加载回调。

原文返回说明为“成功时返回与 `name` 对应值的实际大小，失败返回负值”。译注：该声明没有 `name` 参数；这里保留原文返回说明，并指出它与函数参数及子树加载职责的差异。

## 70.3\_加载单个值

[`csi_load_one`](https://docs.zephyrproject.org/latest/doxygen/html/structsettings__store__itf.html#ae3492100b922be0ef0f44022044ed151) 加载与字符串键 `name` 对应的一个值，数据复制到 `buf`，其缓冲区长度为 `buf_len`。

```c
ssize_t (*csi_load_one)(struct settings_store *cs, const char *name,
                       char *buf, size_t buf_len);
```

原文将所有参数标为输入，包括作为数据复制目标的 `buf`。成功返回该键对应值的实际大小，失败返回负值。

## 70.4\_查询值长度

[`csi_get_val_len`](https://docs.zephyrproject.org/latest/doxygen/html/structsettings__store__itf.html#ace444937a6c762d88c0143871cb71600) 查询字符串键 `name` 对应值的长度，键值对不存在时返回 **0**。

```c
ssize_t (*csi_get_val_len)(struct settings_store *cs, const char *name);
```

`cs` 和 `name` 均为输入参数。原页返回说明仅单列不存在时的 0，未进一步列出错误码。

## 70.5\_保存开始与结束

[`csi_save_start`](https://docs.zephyrproject.org/latest/doxygen/html/structsettings__store__itf.html#af6aae0b06cdc935975f19eb4c56eb991) 在**导出（Export）**操作之前调用，[`csi_save_end`](https://docs.zephyrproject.org/latest/doxygen/html/structsettings__store__itf.html#a90c2506cb06e5d80dffc6c08c6007bce) 在导出操作之后调用；两者都只接收输入参数 `cs`。

```c
int (*csi_save_start)(struct settings_store *cs);
int (*csi_save_end)(struct settings_store *cs);
```

两者成功返回 0，失败返回负错误码。

## 70.6\_保存键值对

[`csi_save`](https://docs.zephyrproject.org/latest/doxygen/html/structsettings__store__itf.html#af97b8a3e2bdac663dd3872117251f0d2) 将单个**键值对（Key-value Pair）**保存到存储。

```c
int (*csi_save)(struct settings_store *cs, const char *name,
                const char *value, size_t val_len);
```

参数均为输入：`cs` 为后端节点，`name` 为字符串键，`value` 为二进制值（Binary Value），`val_len` 为值的字节长度。`value` 虽声明为 `const char *`，原文仍明确将其描述为二进制值。成功返回 0，失败返回负错误码。

## 70.7\_获取存储实例

[`csi_storage_get`](https://docs.zephyrproject.org/latest/doxygen/html/structsettings__store__itf.html#a01440145124432463ada9a7e1badf727) 返回后端使用的存储实例指针，输入参数 `cs` 为后端节点。

```c
void *(*csi_storage_get)(struct settings_store *cs);
```

返回值为存储对象指针。
