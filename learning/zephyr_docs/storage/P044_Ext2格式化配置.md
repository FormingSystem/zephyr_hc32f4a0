# 第44章\_Ext2格式化配置

原文：[structext2__cfg](https://docs.zephyrproject.org/latest/doxygen/html/structext2__cfg.html)。读取日期：2026-10-13，`latest`。

`struct ext2_cfg` 保存格式化 **Ext2 文件系统（File System）**时使用的配置。

```c
#include <zephyr/fs/ext2.h>
```

## 44.1\_字段定义

**索引节点（Index Node，inode）**用于文件系统对象管理；[`bytes_per_inode`](https://docs.zephyrproject.org/latest/doxygen/html/structext2__cfg.html#a04309de819dc1b31a7578667c82678b6) 用于计算创建文件系统时所需的 inode 数量。**通用唯一标识符（Universally Unique Identifier，UUID）**用于标识所创建的文件系统。

| 字段 | 类型 | 含义与约束 |
| --- | --- | --- |
| [`block_size`](https://docs.zephyrproject.org/latest/doxygen/html/structext2__cfg.html#a3eb5587725f3fee4dd8ea86a7077e662) | [`uint32_t`](https://docs.zephyrproject.org/latest/doxygen/html/stdint_8h.html#a0a8582351ac627ee8bde2973c825e47f) | 请求的块大小，单位为字节 |
| [`fs_size`](https://docs.zephyrproject.org/latest/doxygen/html/structext2__cfg.html#ab8b546e8256994362261085fb4e826df) | [`uint32_t`](https://docs.zephyrproject.org/latest/doxygen/html/stdint_8h.html#a0a8582351ac627ee8bde2973c825e47f) | 请求的文件系统大小，以块数表示；为 0 时使用全部可用存储空间 |
| `bytes_per_inode` | [`uint32_t`](https://docs.zephyrproject.org/latest/doxygen/html/stdint_8h.html#a0a8582351ac627ee8bde2973c825e47f) | 每个 inode 对应的请求存储量，单位为字节；用于计算 inode 数量 |
| `uuid[16]` | [`uint8_t`](https://docs.zephyrproject.org/latest/doxygen/html/stdint_8h.html#a3cb4a16b0e8d6af0af86d4fd6ba5fd9d) | 创建的文件系统 UUID，仅在 [`set_uuid`](https://docs.zephyrproject.org/latest/doxygen/html/structext2__cfg.html#a63d3fca7ab9c60da4457569c51e3a511) 为真时使用 |
| `volume_name[16]` | [`uint8_t`](https://docs.zephyrproject.org/latest/doxygen/html/stdint_8h.html#a3cb4a16b0e8d6af0af86d4fd6ba5fd9d) | 创建的文件系统名称；首字节为 0 时使用默认名称 `ext2` |
| [`set_uuid`](https://docs.zephyrproject.org/latest/doxygen/html/structext2__cfg.html#a63d3fca7ab9c60da4457569c51e3a511) | [`bool`](https://docs.zephyrproject.org/latest/doxygen/html/stdbool_8h.html#abb452686968e48b67397da5f97445f5b) | 为真时使用 [`uuid`](https://docs.zephyrproject.org/latest/doxygen/html/structext2__cfg.html#ad11fad3e7fd7088263b578babd60c77d) 中指定的 UUID；为假时生成版本 4 UUID |

## 44.2\_默认值规则

原文通用规则为：字段设置为 0 时使用其默认值。对于卷名，需要把数组首字节设为 0 才会使用默认值。各字段的特殊含义见上表。

译注：原文 `set_uuid` 的说明将来源字段写成大写 [`UUID`](https://docs.zephyrproject.org/latest/doxygen/html/group__uuid.html)，此处按实际成员名 `uuid` 说明。
