# 第71章\_闪存循环缓冲区头文件

原文：[fcb_8h](https://docs.zephyrproject.org/latest/doxygen/html/fcb_8h.html)。读取日期：2026-10-13，`latest`。

`zephyr/fs/fcb.h` 声明**闪存循环缓冲区（Flash Circular Buffer，FCB）应用编程接口（Application Programming Interface，API）**。

## 71.1\_包含关系

官方头文件的包含项如下：

```c
#include <inttypes.h>
#include <limits.h>
#include <zephyr/storage/flash_map.h>
#include <zephyr/sys/util_macro.h>
#include <zephyr/kernel.h>
```

[查看官方源文件页面](https://docs.zephyrproject.org/latest/doxygen/html/fcb_8h_source.html)。

## 71.2\_结构、宏与类型

**循环冗余校验（Cyclic Redundancy Check，CRC）**可通过标志禁用；**条目（Entry）**位置由结构描述。

| 结构 | 中文说明 |
| --- | --- |
| `struct fcb_entry` | 条目信息 |
| `struct fcb_entry_ctx` | 传递条目在闪存中的完整位置上下文 |
| `struct fcb` | FCB 实例 |

| 宏及原页定义 | 中文说明 |
| --- | --- |
| `FCB_MAX_LEN (0x3fffu)` | 元素最大长度 16,383 |
| `FCB_ENTRY_FA_DATA_OFF(entry)` | 计算数据相对于 FCB 闪存区域起点的偏移；本头文件参考页仅列宏签名 |
| `FCB_FLAGS_CRC_DISABLED BIT(0)` | 禁用闪存中条目的 CRC；`BIT(0)` 为第 0 位掩码 |

[`fcb_walk_cb`](https://docs.zephyrproject.org/latest/doxygen/html/group__fcb__api.html#gaeed5144438ee00d83c9b3d3b4b7490ea) 是遍历回调（Walk Callback）类型：

```c
typedef int (*fcb_walk_cb)(struct fcb_entry_ctx *loc_ctx, void *arg);
```

宏展开与结构细节见[FCB数据结构](P048_闪存循环缓冲区数据结构目录.md)。

## 71.3\_函数声明与中文索引

函数 [`fcb_init()`](https://docs.zephyrproject.org/latest/doxygen/html/group__fcb__api.html#gab304f3e9e28f6229d7ddbe638eda2f70)：初始化 FCB 实例。

```c
int fcb_init(int f_area_id, struct fcb *fcbp);
```

函数 [`fcb_append()`](https://docs.zephyrproject.org/latest/doxygen/html/group__fcb__api.html#gad567d124d8b0fe181ed54cfbe33b315c)：向循环缓冲区追加一个条目。

```c
int fcb_append(struct fcb *fcbp, uint16_t len, struct fcb_entry *loc);
```

函数 [`fcb_append_finish()`](https://docs.zephyrproject.org/latest/doxygen/html/group__fcb__api.html#gaae445e8376db192ce45fff9dcf95c954)：完成条目追加操作。

```c
int fcb_append_finish(struct fcb *fcbp, struct fcb_entry *append_loc);
```

函数 [`fcb_walk()`](https://docs.zephyrproject.org/latest/doxygen/html/group__fcb__api.html#gad50e579ec9430a23ef5525e74ceb21b2)：遍历 FCB 扇区中的所有条目。

```c
int fcb_walk(struct fcb *fcbp, struct flash_sector *sector, fcb_walk_cb cb, void *cb_arg);
```

函数 [`fcb_getnext()`](https://docs.zephyrproject.org/latest/doxygen/html/group__fcb__api.html#ga7908a252a09ebbb98b60a505220072bc)：获取下一个 FCB 条目的位置。

```c
int fcb_getnext(struct fcb *fcbp, struct fcb_entry *loc);
```

函数 [`fcb_rotate()`](https://docs.zephyrproject.org/latest/doxygen/html/group__fcb__api.html#gad2fb288645e678dd6ea05b0871d5e774)：轮换 FCB 扇区。

```c
int fcb_rotate(struct fcb *fcbp);
```

函数 [`fcb_append_to_scratch()`](https://docs.zephyrproject.org/latest/doxygen/html/group__fcb__api.html#ga22b2bab8af3004c93e5d40659ccfec29)：开始使用暂存块（Scratch Block）。

```c
int fcb_append_to_scratch(struct fcb *fcbp);
```

函数 [`fcb_free_sector_cnt()`](https://docs.zephyrproject.org/latest/doxygen/html/group__fcb__api.html#gaa9beaa3f5a6cc52b7e460d5670fdaabf)：查询空闲扇区数。

```c
int fcb_free_sector_cnt(struct fcb *fcbp);
```

函数 [`fcb_is_empty()`](https://docs.zephyrproject.org/latest/doxygen/html/group__fcb__api.html#gade8af12645d769ce3b27848976ada32a)：检查 FCB 是否包含数据。

```c
int fcb_is_empty(struct fcb *fcbp);
```

函数 [`fcb_offset_last_n()`](https://docs.zephyrproject.org/latest/doxygen/html/group__fcb__api.html#gac15df95c0d9bed45c9da39802411598d)：找到一个条目位置，以取得末尾最多 n 个条目。

```c
int fcb_offset_last_n(struct fcb *fcbp, uint8_t entries, struct fcb_entry *last_n_entry);
```

函数 [`fcb_clear()`](https://docs.zephyrproject.org/latest/doxygen/html/group__fcb__api.html#gaab78da410b7e709854e29219eb02a0c9)：清空 FCB 实例的存储内容。

```c
int fcb_clear(struct fcb *fcbp);
```

函数 [`fcb_flash_read()`](https://docs.zephyrproject.org/latest/doxygen/html/group__fcb__internal.html#ga0b921b509dab767661058d164e80f55e)：从 FCB 闪存扇区读取原始数据。

```c
int fcb_flash_read(const struct fcb *fcbp, const struct flash_sector *sector, off_t off, void *dst, size_t len);
```

函数 [`fcb_flash_write()`](https://docs.zephyrproject.org/latest/doxygen/html/group__fcb__internal.html#gafcfb9b6d4b5c0e593c0a9e512a0ec309)：向 FCB 闪存扇区写入原始数据。

```c
int fcb_flash_write(const struct fcb *fcbp, const struct flash_sector *sector, off_t off, const void *src, size_t len);
```

参数、返回值和使用条件见[对应接口参考](P047_闪存循环缓冲区接口.md)。
