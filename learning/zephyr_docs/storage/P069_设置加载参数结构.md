# 第69章\_设置加载参数结构

原文：[structsettings__load__arg](https://docs.zephyrproject.org/latest/doxygen/html/structsettings__load__arg.html)。读取日期：2026-10-13，`latest`。

## 69.1\_加载参数

`struct settings_load_arg` 是**设置子系统（Settings Subsystem）**的数据加载参数结构，声明于 `zephyr/settings/settings.h`。它保存影响数据从后端加载方式的全部参数。

## 69.2\_字段参考

**子树（Subtree）**限定加载范围，**回调（Callback）**指定接收数据的处理函数。

| 字段 | 类型 | 中文说明 |
| --- | --- | --- |
| [`subtree`](https://docs.zephyrproject.org/latest/doxygen/html/structsettings__load__arg.html#a0764239993147761b12e8999f860d267) | `const char *` | 待加载子树名称；为 `NULL` 时加载所有值 |
| [`cb`](https://docs.zephyrproject.org/latest/doxygen/html/structsettings__load__arg.html#aec32e51b4a6b61aff2ea415aa80a9987) | [`settings_load_direct_cb`](https://docs.zephyrproject.org/latest/doxygen/html/group__settings.html#ga767bf6c2709b1c58afcf4d1c5ef0d535) | 回调函数指针；为 `NULL` 时使用匹配的已注册函数 |
| [`param`](https://docs.zephyrproject.org/latest/doxygen/html/structsettings__load__arg.html#a7cbe713a1e0d2885528644b5a54f27d3) | `void *` | 传给回调函数的参数 |
