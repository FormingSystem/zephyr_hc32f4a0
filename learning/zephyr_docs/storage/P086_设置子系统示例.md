# 第86章\_设置子系统示例

原文：[Settings API](https://docs.zephyrproject.org/latest/samples/subsys/settings/README.html)。读取日期：2026-10-13，`latest`。

## 86.1\_示例用途与要求

本示例演示**设置子系统（Settings Subsystem）**的运行时配置模块：用不同方法从**持久存储（Persistent Storage）**加载配置值，并将值导出回存储；同时演示模块**处理器（Handler）**的实现与注册。

要求使用支持设置子系统的开发板，例如 `nrf52840dk/nrf52840`，或使用 `qemu_x86` 模拟目标；原文另要求 **`nvs_sector_size <= 0xFFFF`**，即非易失性存储（Non-volatile Storage，NVS）的该扇区大小条件。[官方示例源码](https://github.com/zephyrproject-rtos/zephyr/tree/main/samples/subsys/settings)。

## 86.2\_构建与运行

示例可用于多个平台。以下命令为 `qemu_x86` 构建并运行；需在已配置 Zephyr 环境和 QEMU 模拟器的开发终端中，从 Zephyr 源码根目录执行。

```shell
west build -b qemu_x86 samples/subsys/settings
west build -t run
```

运行镜像后，控制台显示设置操作消息。

## 86.3\_官方输出与中文说明

以下完整保留原示例输出，包括旧版 Zephyr 构建标识、数值及末尾省略号；它不是当前环境的执行记录。输出中的 OS 指操作系统（Operating System），`OK` 表示该操作成功。


输出依次演示：

1. 初始化设置子系统，注册 `alpha` 子树处理器，显示 `alpha/beta` 使用静态处理器。
2. 通过已注册处理器加载全部键值对（Key-value Pair），直接保存 `alpha/beta/voltage`，再按子树加载，得到示例值 `-3025`。
3. 通过处理器导出并保存所有键值对，再次加载。
4. 将子树直接加载到调用者提供的目标，示例长度值分别为 100、41、59。
5. 删除 `alpha/length` 后，按预期无法再次加载该值。
6. 不使用专用处理器处理 `gamma` 键，先显示默认值 0，再直接保存。
