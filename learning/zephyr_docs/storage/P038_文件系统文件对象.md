# 第38章\_文件系统文件对象

原文：[structfs__file__t](https://docs.zephyrproject.org/latest/doxygen/html/structfs__file__t.html)。读取日期：2026-10-13，`latest`。

`struct fs_file_t` 表示一个已打开文件的**文件对象（File Object）**。使用前必须通过 [`fs_file_t_init()`](https://docs.zephyrproject.org/latest/doxygen/html/group__file__system__api.html#gad44be87cbda3ddc48021ed16d515f564) 初始化。

```c
#include <zephyr/fs/fs_interface.h>
```
