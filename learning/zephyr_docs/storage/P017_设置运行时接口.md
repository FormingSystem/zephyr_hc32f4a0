# 第17章\_设置运行时接口

原文：[group__settings__rt](https://docs.zephyrproject.org/latest/doxygen/html/group__settings__rt.html)。读取日期：2026-10-13，`latest`。

**设置运行时接口（Runtime Settings API）**用于向模块处理器（Module Handler）设置、取得或应用配置值。头文件为 `zephyr/settings/settings.h`，三个函数均仅在启用 Kconfig 配置项 [`CONFIG_SETTINGS_RUNTIME`](https://docs.zephyrproject.org/latest/kconfig.html#CONFIG_SETTINGS_RUNTIME) 时可用。API 表示应用程序编程接口（Application Programming Interface）。

## 17.1\_设置键对应的值

[`settings_runtime_set()`](https://docs.zephyrproject.org/latest/doxygen/html/group__settings__rt.html#gae1b95c47c49774d53b4745af810e881e) 把指定键的值交给模块处理器。参数 `name` 为字符串形式的键，`data` 指向二进制值，`len` 是该值的字节长度。

```c
int settings_runtime_set(const char *name, const void *data, size_t len);
```

成功返回 `0`，失败返回非零值。

## 17.2\_读取键对应的值

[`settings_runtime_get()`](https://docs.zephyrproject.org/latest/doxygen/html/group__settings__rt.html#ga99a4714ba8c184afc659c43ec2020844) 从模块处理器取得键对应的值。参数 `name` 为字符串键，`data` 接收返回的二进制值，`len` 为请求值的字节长度。

```c
int settings_runtime_get(const char *name, void *data, size_t len);
```

成功返回读取的数据长度，失败返回负值。

## 17.3\_应用模块中的设置

[`settings_runtime_commit()`](https://docs.zephyrproject.org/latest/doxygen/html/group__settings__rt.html#gafa96974170dced7a131bfd5f022483f8) 应用模块处理器中的设置。参数 `name` 是字符串形式的键。

```c
int settings_runtime_commit(const char *name);
```

成功返回 `0`，失败返回非零值。
