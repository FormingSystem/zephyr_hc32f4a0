# 第76章\_设置子系统头文件

原文：[include_2zephyr_2settings_2settings_8h](https://docs.zephyrproject.org/latest/doxygen/html/include_2zephyr_2settings_2settings_8h.html)。读取日期：2026-10-13，`latest`。

`zephyr/settings/settings.h` 声明**设置子系统（Settings Subsystem）**的处理器、存储后端和运行时接口。

## 76.1\_包含关系

官方头文件的包含项如下：

```c
#include <sys/types.h>
#include <zephyr/sys/util.h>
#include <zephyr/sys/slist.h>
#include <zephyr/sys/iterable_sections.h>
#include <stdint.h>
```

[查看官方源文件页面](https://docs.zephyrproject.org/latest/doxygen/html/include_2zephyr_2settings_2settings_8h_source.html)。

## 76.2\_结构、宏与类型

**处理器（Handler）**为设置子树提供回调；**后端（Backend）**负责存储；**提交（Commit）**应用设置，**导出（Export）**提供待保存的数据。

| 结构 | 中文说明 |
| --- | --- |
| `struct settings_handler` | 实现子树的一组处理函数 |
| `struct settings_handler_static` | 不含链表节点元素的静态处理器 |
| `struct settings_store` | 用于存储处理的后端节点 |
| `struct settings_load_arg` | 数据加载参数 |
| `struct settings_store_itf` | 后端处理函数集合 |

| 宏及原页定义/签名 | 中文说明 |
| --- | --- |
| `SETTINGS_MAX_DIR_DEPTH 8` | 设置树最大深度 |
| `SETTINGS_MAX_NAME_LEN (8 * SETTINGS_MAX_DIR_DEPTH)` | 设置名称最大长度 |
| `SETTINGS_MAX_VAL_LEN 256` | 设置值最大长度 |
| `SETTINGS_NAME_SEPARATOR '/'` | 名称字段分隔符 |
| `SETTINGS_NAME_END '='` | 名称结束字符 |
| `SETTINGS_EXTRA_LEN ((SETTINGS_MAX_DIR_DEPTH - 1) + 2)` | 最多 7 个分隔符、`=` 和 `\0` 的额外空间 |
| `SETTINGS_FULL_NAME_LEN ((SETTINGS_MAX_NAME_LEN) + (SETTINGS_EXTRA_LEN) + 1)` | 包含分隔符的名称最大长度 |
| `SETTINGS_STATIC_HANDLER_DEFINE_WITH_CPRIO(_hname, _tree, _get, _set, _commit, _export, _cprio)` | 定义带提交优先级的静态处理器 |
| `SETTINGS_STATIC_HANDLER_DEFINE(_hname, _tree, _get, _set, _commit, _export)` | 定义静态处理器 |

宏体见[设置子系统接口](P063_设置子系统接口.md)。本页原文只列签名的宏未在此伪造为空定义。

[`settings_read_cb`](https://docs.zephyrproject.org/latest/doxygen/html/group__settings.html#ga51cdac276c1fb8cd27fc3eec42749a04) 是 `h_set` 实现中从存储读取数据的回调，[`settings_load_direct_cb`](https://docs.zephyrproject.org/latest/doxygen/html/group__settings.html#ga767bf6c2709b1c58afcf4d1c5ef0d535) 是直接加载回调：

```c
typedef ssize_t (*settings_read_cb)(void *cb_arg, void *data, size_t len);
typedef int (*settings_load_direct_cb)(const char *key, size_t len,
                                      settings_read_cb read_cb,
                                      void *cb_arg, void *param);
```

## 76.4\_存储实例查询细节

`settings_storage_get()` 的输出参数 `storage` 是用于接收存储对象引用的指针。对象类型取决于所用后端：可能是 `struct nvs_fs` 指针、`struct fcb` 指针，或者表示文件名的字符串。成功返回 0，失败返回负错误码。
