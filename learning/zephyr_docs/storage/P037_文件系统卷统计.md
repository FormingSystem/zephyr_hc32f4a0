# 第37章\_文件系统卷统计

原文：[structfs__statvfs](https://docs.zephyrproject.org/latest/doxygen/html/structfs__statvfs.html)。读取日期：2026-10-13，`latest`。

`struct fs_statvfs` 用于接收**卷统计信息（Volume Statistics）**，从中取得卷的总空间与可用空间。

```c
#include <zephyr/fs/fs.h>
```

## 37.1\_字段定义

| 字段 | 类型 | 含义 |
| --- | --- | --- |
| [`f_bsize`](https://docs.zephyrproject.org/latest/doxygen/html/structfs__statvfs.html#a52680f515f68ec36ce6a459f35cb2fa0) | `unsigned long` | 最佳传输块大小（Optimal Transfer Block Size） |
| [`f_frsize`](https://docs.zephyrproject.org/latest/doxygen/html/structfs__statvfs.html#a575b703b19d5ac15624075d64fa4bfdc) | `unsigned long` | 分配单元大小（Allocation Unit Size） |
| [`f_blocks`](https://docs.zephyrproject.org/latest/doxygen/html/structfs__statvfs.html#a6a6d04bdeae1976a80e51c8f679e216d) | `unsigned long` | 文件系统大小，以 `f_frsize` 为单位 |
| [`f_bfree`](https://docs.zephyrproject.org/latest/doxygen/html/structfs__statvfs.html#abd27b93cd5ce72d63c1b4e982cb399a6) | `unsigned long` | 空闲块数量 |

用于填充该结构的 [`fs_statvfs()`](https://docs.zephyrproject.org/latest/doxygen/html/structfs__statvfs.html) 见[文件系统接口](P033_文件系统接口.md)。

本结构的参考文档由 `zephyr/fs/fs.h` 生成。
