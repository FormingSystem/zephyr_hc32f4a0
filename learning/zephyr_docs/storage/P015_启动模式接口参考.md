# 第15章\_启动模式接口参考

原文：[group__boot__mode__interface](https://docs.zephyrproject.org/latest/doxygen/html/group__boot__mode__interface.html)。读取日期：2026-10-13，`latest`。

**启动模式接口（Boot Mode Interface）**用于设置、检查和清除设备的启动模式，头文件为 `zephyr/retention/bootmode.h`。

## 15.1\_启动模式枚举

枚举 [`BOOT_MODE_TYPES`](https://docs.zephyrproject.org/latest/doxygen/html/group__boot__mode__interface.html#ga0ef8476e9ece13f7bf8bd83dd6290cbf) 定义普通启动与引导加载器启动两种模式。

<a id="ga0ef8476e9ece13f7bf8bd83dd6290cbf"></a>

<a id="gga0ef8476e9ece13f7bf8bd83dd6290cbfa43117c269b0c758fcbaff59d39836241"></a>

<a id="gga0ef8476e9ece13f7bf8bd83dd6290cbfa36dc141ab12f3e759be685de443bda13"></a>

```c
enum BOOT_MODE_TYPES {
    BOOT_MODE_TYPE_NORMAL = 0x00,
    BOOT_MODE_TYPE_BOOTLOADER
};
```

[`BOOT_MODE_TYPE_NORMAL`](https://docs.zephyrproject.org/latest/doxygen/html/group__boot__mode__interface.html#gga0ef8476e9ece13f7bf8bd83dd6290cbfa43117c269b0c758fcbaff59d39836241) 是默认普通启动，进入用户应用；[`BOOT_MODE_TYPE_BOOTLOADER`](https://docs.zephyrproject.org/latest/doxygen/html/group__boot__mode__interface.html#gga0ef8476e9ece13f7bf8bd83dd6290cbfa36dc141ab12f3e759be685de443bda13) 是引导加载器（Bootloader）启动模式，例如 MCUboot 的串口恢复（Serial Recovery）。MCUboot 是引导加载器项目名称。

## 15.2\_检查当前模式

[`bootmode_check()`](https://docs.zephyrproject.org/latest/doxygen/html/group__boot__mode__interface.html#gaf48099813e4857baf1c049f4e64cf608) 检查设备启动模式是否等于指定值，参数 `boot_mode` 为待匹配的预期启动模式。

<a id="gaf48099813e4857baf1c049f4e64cf608"></a>

```c
int bootmode_check(uint8_t boot_mode);
```

成功且匹配返回 `1`，不匹配返回 `0`，操作错误返回负 `errno` 错误码。

## 15.3\_设置启动模式

[`bootmode_set()`](https://docs.zephyrproject.org/latest/doxygen/html/group__boot__mode__interface.html#gaab5686ba28fa96363129be82c646d0da) 设置设备启动模式，参数 `boot_mode` 为要保存的模式值。

<a id="gaab5686ba28fa96363129be82c646d0da"></a>

```c
int bootmode_set(uint8_t boot_mode);
```

成功返回 `0`，失败返回负错误码。

## 15.4\_清除启动模式

[`bootmode_clear()`](https://docs.zephyrproject.org/latest/doxygen/html/group__boot__mode__interface.html#ga8d40754ab808ea63882c356b0d851c75) 把启动模式值清为 `0`，即 [`BOOT_MODE_TYPE_NORMAL`](https://docs.zephyrproject.org/latest/doxygen/html/group__boot__mode__interface.html#gga0ef8476e9ece13f7bf8bd83dd6290cbfa43117c269b0c758fcbaff59d39836241) 普通启动。

<a id="ga8d40754ab808ea63882c356b0d851c75"></a>

```c
int bootmode_clear(void);
```

成功返回 `0`，失败返回负错误码。
