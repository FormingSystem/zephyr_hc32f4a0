# 第43章\_Ext2配置头文件

原文：[ext2_8h](https://docs.zephyrproject.org/latest/doxygen/html/ext2_8h.html)。读取日期：2026-10-13，`latest`。

`zephyr/fs/ext2.h` 提供 **Ext2 文件系统（File System）**配置结构。

```c
#include <stdint.h>
```

## 43.1\_格式化配置结构

`struct ext2_cfg` 用于配置 Ext2 文件系统的**格式化（Format）**操作，字段与取值约定见[Ext2格式化配置](P044_Ext2格式化配置.md)。

## 43.2\_默认配置宏

`FS_EXT2_DECLARE_DEFAULT_CONFIG(name)` 声明一个采用默认值的 Ext2 格式化配置对象。`name` 为所声明的 [`ext2_cfg`](https://docs.zephyrproject.org/latest/doxygen/html/structext2__cfg.html) 对象名称。

```c
static struct ext2_cfg name = {                         \
        .block_size = 1024,                             \
        .fs_size = 0x800000,                            \
        .bytes_per_inode = 4096,                        \
        .volume_name = {'e', 'x', 't', '2', '\0'},      \
        .set_uuid = false,                              \
}
```

译注：宏中的 `block_size`、`fs_size`、`bytes_per_inode`、`volume_name` 和 `set_uuid` 分别是块大小、文件系统大小、每索引节点字节量、卷名以及是否使用指定**通用唯一标识符（Universally Unique Identifier，UUID）** 的配置字段。原宏的 `fs_size = 0x800000` 数值原样保留；字段参考页将其单位写为块数。
