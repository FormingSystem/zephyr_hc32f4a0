# 第72章\_非易失性存储旧接口头文件

原文：[fs_2nvs_8h](https://docs.zephyrproject.org/latest/doxygen/html/fs_2nvs_8h.html)。读取日期：2026-10-13，`latest`。

`zephyr/fs/nvs.h` 是**非易失性存储（Non-volatile Storage，NVS）应用编程接口（Application Programming Interface，API）**的旧接口头文件（Legacy Interface Header）。

## 72.1\_包含关系

官方头文件的包含项如下：

```c
#include <zephyr/kvss/nvs.h>
```

[查看官方源文件页面](https://docs.zephyrproject.org/latest/doxygen/html/fs_2nvs_8h_source.html)。

## 72.2\_弃用说明

该头文件已**弃用（Deprecated）**。请改用 `zephyr/kvss/nvs.h`；原文件通过上面的包含指令转入新头文件。
