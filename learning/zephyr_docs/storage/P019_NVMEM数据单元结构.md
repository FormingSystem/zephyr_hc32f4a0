# 第19章\_NVMEM数据单元结构

原文：[structnvmem__cell](https://docs.zephyrproject.org/latest/doxygen/html/structnvmem__cell.html)。读取日期：2026-10-13，`latest`。

`struct nvmem_cell` 表示一个**非易失性存储器（Non-Volatile Memory，NVMEM）**数据单元。公共头文件为 `zephyr/nvmem.h`。

## 19.1\_结构来源

包含以下头文件即可引用该结构：

```c
#include <zephyr/nvmem.h>
```

官方结构页的说明由 `zephyr/nvmem.h` 生成，只给出上述结构用途，没有列出成员字段。完整初始化宏和访问操作见[NVMEM接口参考](P013_NVMEM接口参考.md)，公共声明列表见[NVMEM公共头文件](P020_NVMEM公共头文件.md)。
