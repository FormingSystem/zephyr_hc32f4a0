# 第88章\_非易失性存储示例

原文：[Non-Volatile Storage (NVS)](https://docs.zephyrproject.org/latest/samples/subsys/kvss/nvs/README.html)。读取日期：2026-10-13，`latest`。

## 88.1\_持久化重启计数

此简单应用演示**非易失性存储（Non-volatile Storage，NVS）**模块如何使用闪存保存数据。每次重启，计数器递增并写入闪存；应用再次重启后，从存储中取回重启计数。要求开发板支持闪存。

[官方示例源码](https://github.com/zephyrproject-rtos/zephyr/tree/main/samples/subsys/kvss/nvs)。

## 88.2\_构建与运行

示例可为多个平台构建。以下官方命令为 `nrf51dk/nrf51822` 构建并烧写；应在已配置 Zephyr 工具链及对应开发板烧写环境的开发终端中，从 Zephyr 源码根目录执行。

```shell
west build -b nrf51dk/nrf51822 samples/subsys/kvss/nvs
west flash
```

烧写后，控制台会输出重启计数，开发板多次重启以展示计数逐次增加。

## 88.3\_官方输出与解读

以下保留原始输出。OS 表示操作系统（Operating System），`DBG`、`INF` 是调试/信息日志级别；`Id`/`ID` 为条目标识符，`DATA` 是原输出中的数据字符串。版本、地址和数据属于官方示例记录。

首次启动未找到地址、密钥和计数等条目，便写入初值；后续启动读回地址 `192.168.1.1`、二进制密钥、重启计数和其他数据。`Reboot counter history` 显示历史计数，`Oldest reboot counter` 显示最旧计数。

译注：原始输出首次写入长数组时写作 `id 4`，后续读取行却为 `Id: 5`；此处保留原样，不据此推导实际代码的标识符分配。本译文未运行或烧写该示例。
