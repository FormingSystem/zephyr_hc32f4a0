# 第36章\_文件系统目录项

原文：[structfs__dirent](https://docs.zephyrproject.org/latest/doxygen/html/structfs__dirent.html)。读取日期：2026-10-13，`latest`。

`struct fs_dirent` 用于接收**文件或目录信息（File or Directory Information）**，读取目录项的函数通过它取得相应信息。

```c
#include <zephyr/fs/fs.h>
```

## 36.1\_字段定义

| 字段 | 类型 | 含义 |
| --- | --- | --- |
| [`type`](https://docs.zephyrproject.org/latest/doxygen/html/structfs__dirent.html#ac3dcca17b8b22401913e5b3215d4be11) | `enum fs_dir_entry_type` | 条目类型；`FS_DIR_ENTRY_FILE` 为文件，`FS_DIR_ENTRY_DIR` 为目录 |
| `name[MAX_FILE_NAME+1]` | `char` | 文件或目录的名称 |
| [`size`](https://docs.zephyrproject.org/latest/doxygen/html/structfs__dirent.html#ac94ea69af234587aae3cea5cbd98d533) | `size_t` | 文件大小；若条目是目录则为 0 |

[`MAX_FILE_NAME`](P078_文件系统接口头文件.md) 为文件名长度限制宏，[`name`](https://docs.zephyrproject.org/latest/doxygen/html/structfs__dirent.html#af9c22b97ead96be25fb3edf0df98a769) 数组的声明完整保留为 `char name[MAX_FILE_NAME+1]`。读取与状态查询函数见[文件系统接口](P033_文件系统接口.md)。

本结构的参考文档由 `zephyr/fs/fs.h` 生成。
