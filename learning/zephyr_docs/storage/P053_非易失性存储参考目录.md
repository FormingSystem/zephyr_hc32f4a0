## 53.1\_接口与数据结构

**非易失性存储（Non-volatile Storage，NVS）**参考组自 Zephyr **1.12** 提供，标注的接口版本为 **1.0.0**。

- [NVS 应用编程接口（Application Programming Interface，API）](https://docs.zephyrproject.org/latest/doxygen/html/group__nvs__high__level__api.html)
- [NVS 数据结构（Data Structures）](https://docs.zephyrproject.org/latest/doxygen/html/group__nvs__data__structures.html)

原页列出两个同名 `nvs.h` 文件：[`zephyr/fs/nvs.h`](P072_非易失性存储旧接口头文件.md) 是旧接口头文件（Legacy Interface Header）；[`zephyr/kvss/nvs.h`](P073_非易失性存储头文件.md) 是 NVS 接口头文件。
