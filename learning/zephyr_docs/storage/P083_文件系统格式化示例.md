# 第83章\_文件系统格式化示例

原文：[Format filesystem](https://docs.zephyrproject.org/latest/samples/subsys/fs/format/README.html)。读取日期：2026-10-13，`latest`。

## 83.1\_格式化场景

本示例演示怎样将不同存储设备**格式化（Format）**为不同**文件系统（File System，FS）**，提供两种场景：

- 闪存设备上的 LittleFS。
- **内存磁盘（RAM Disk）**上的 **FAT（File Allocation Table，文件分配表）**文件系统；RAM 指随机存取存储器（Random-Access Memory）。

[官方示例源码](https://github.com/zephyrproject-rtos/zephyr/tree/main/samples/subsys/fs/format)。

## 83.2\_构建与烧写

选择目标开发板和场景构建，再烧写到开发板。闪存场景支持 `nrf52dk/nrf52832`，内存磁盘场景支持 `mimxrt1064_evk`。后者必须通过 `CONF_FILE=prj_ram.conf` 选择 `prj_ram.conf` 配置文件。

译注：以下为在 Zephyr 源码根目录执行的官方 west 命令，需要已配置的 Zephyr 工具链和对应开发板烧写环境。`west flash` 会实际烧写所选开发板；示例运行会格式化其目标存储区域。

nRF52 DK 的闪存场景：

```shell
west build -b nrf52dk/nrf52832 samples/subsys/fs/format
west flash
```

MIMXRT1064-EVK 的内存磁盘场景：

```shell
west build -b mimxrt1064_evk samples/subsys/fs/format -- -DCONF_FILE="prj_ram.conf"
west flash
```

## 83.3\_预期输出

成功运行时，官方给出的 LittleFS 输出为：

```console
I: LittleFS version 2.4, disk version 2.0
I: FS at flash-controller@4001e000:0x7a000 is 6 0x1000-byte blocks with 512 cycle
I: sizes: rd 16 ; pr 16 ; ca 64 ; la 32
I: Format successful
```

输出包含 LittleFS 与磁盘格式版本、闪存块布局，以及读取/编程/缓存/前瞻参数。最后的 `Format successful` 表示格式化成功。版本和地址是原示例数据，并非本地运行结果。

相关参考：[文件系统接口](P033_文件系统接口.md)。
