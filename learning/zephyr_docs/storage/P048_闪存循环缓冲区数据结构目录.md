# 第48章\_闪存循环缓冲区数据结构目录

原文：[group__fcb__data__structures](https://docs.zephyrproject.org/latest/doxygen/html/group__fcb__data__structures.html)。读取日期：2026-10-13，`latest`。

## 48.1\_结构入口

**闪存循环缓冲区（Flash Circular Buffer，FCB）**的数据结构与宏声明于 `zephyr/fs/fcb.h`。

- [`struct fcb_entry`](https://docs.zephyrproject.org/latest/doxygen/html/structfcb__entry.html)：条目信息结构。
- [`struct fcb_entry_ctx`](https://docs.zephyrproject.org/latest/doxygen/html/structfcb__entry__ctx.html)：在闪存中传递条目完整位置上下文的结构。
- [`struct fcb`](https://docs.zephyrproject.org/latest/doxygen/html/structfcb.html)：FCB 实例结构。

## 48.2\_长度与校验标志

[`FCB_MAX_LEN`](https://docs.zephyrproject.org/latest/doxygen/html/group__fcb__data__structures.html#gaccabb1cb7f83c0d8919571cf3de7ee47) 宏指定元素的最大长度 **16,383**。[`FCB_FLAGS_CRC_DISABLED`](https://docs.zephyrproject.org/latest/doxygen/html/group__fcb__data__structures.html#ga2fc8801bea1d91a422aa622bcf4cb6e0) 宏标志用于禁用闪存条目的**循环冗余校验（Cyclic Redundancy Check，CRC）**；`BIT(0)` 表示第 0 位的位掩码（Bit Mask）。

```c
#define FCB_MAX_LEN (0x3fffu)
#define FCB_FLAGS_CRC_DISABLED BIT(0)
```

## 48.3\_计算区域内数据偏移

辅助宏 `FCB_ENTRY_FA_DATA_OFF(entry)` 计算数据相对于 FCB 所用**闪存区域（Flash Area）**起点的偏移。参数 `entry` 是 FCB 条目结构。原宏展开表达式如下：

```c
(entry.fe_sector->fs_off +\
entry.fe_data_off)
```
