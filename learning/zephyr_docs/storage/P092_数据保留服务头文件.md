# 第92章\_数据保留服务头文件

原文：[retention_8h](https://docs.zephyrproject.org/latest/doxygen/html/retention_8h.html)。读取日期：2026-10-13，`latest`。

`zephyr/retention/retention.h` 提供数据保留（Retention）的公共应用程序编程接口（Application Programming Interface，API）。

## 92.1\_包含关系与源码

```c
#include <stdint.h>
#include <stddef.h>
#include <sys/types.h>
#include <zephyr/kernel.h>
#include <zephyr/device.h>
#include <zephyr/types.h>
```

[查看官方源码](../memory_retention_reference/P005_数据保留服务头文件源码.md)。

## 92.2\_函数声明

```c
ssize_t retention_size(const struct device *dev);
int retention_is_valid(const struct device *dev);
int retention_read(const struct device *dev, off_t offset, uint8_t *buffer, size_t size);
int retention_write(const struct device *dev, off_t offset, const uint8_t *buffer, size_t size);
int retention_clear(const struct device *dev);
```

## 92.3\_函数用途

| 函数 | 中文说明 |
| --- | --- |
| [`retention_size()`](https://docs.zephyrproject.org/latest/doxygen/html/group__retention__api.html#gaf20780720d64144b50e03f9e04d3f39b) | 返回保留区域大小 |
| [`retention_is_valid()`](https://docs.zephyrproject.org/latest/doxygen/html/group__retention__api.html#gaa3f12ad0b1929a828e8d42c7c073a16d) | 检查保留区域的底层数据是否有效 |
| [`retention_read()`](https://docs.zephyrproject.org/latest/doxygen/html/group__retention__api.html#ga7b4c04850ec0b57d120a0f1425d8b583) | 从保留区域读取数据 |
| [`retention_write()`](https://docs.zephyrproject.org/latest/doxygen/html/group__retention__api.html#ga6131168ffc3f6d0e4329cf56f32071cc) | 向保留区域写入数据，写入前不需要清除底层数据；函数成功返回后，通过 [`retention_is_valid()`](https://docs.zephyrproject.org/latest/doxygen/html/group__retention__api.html#gaa3f12ad0b1929a828e8d42c7c073a16d) 查询时，数据会被判定为有效 |
| [`retention_clear()`](https://docs.zephyrproject.org/latest/doxygen/html/group__retention__api.html#gaab8a56b5879faabd10982bc110577a1d) | 清除保留区域的全部数据，将其设置为0 |

参数、返回值和详细条件见[数据保留接口参考](P014_数据保留接口参考.md)。
