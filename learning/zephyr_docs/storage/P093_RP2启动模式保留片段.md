# 第93章\_RP2启动模式保留片段

原文：[RP2040/RP2350 boot mode retention setup (rp2-boot-mode-retention)](https://docs.zephyrproject.org/latest/snippets/rp2-boot-mode-retention/README.html)。读取日期：2026-10-13，`latest`。

`rp2-boot-mode-retention` 是RP2040/RP2350的**启动模式保留（Boot Mode Retention）配置片段（Snippet）**。

## 93.1\_用途

此片段为基于RP2040/RP2350的开发板配置静态随机存取存储器（Static Random Access Memory，SRAM）中的保留内存（Retained Memory），以便保留已经设置的启动模式。

它同时启用保留内存驱动与数据保留系统所需的Kconfig配置符号。原页仅提供这段用途说明，没有附带构建命令、设备树代码或示例输出。
