# 第78章\_文件系统接口头文件

原文：[fs__interface_8h](https://docs.zephyrproject.org/latest/doxygen/html/fs__interface_8h.html)。读取日期：2026-10-13，`latest`。

## 78.1\_核心结构与包含项

`zephyr/fs/fs_interface.h` 定义**文件系统（File System）**核心结构与文件名长度限制。

```c
#include <stdint.h>
```

[查看官方源文件页面](https://docs.zephyrproject.org/latest/doxygen/html/fs__interface_8h_source.html)。

- [`struct fs_file_t`](P038_文件系统文件对象.md)：代表已打开文件的文件对象（File Object）。
- [`struct fs_dir_t`](P039_文件系统目录对象.md)：代表已打开目录的目录对象（Directory Object）。

## 78.2\_文件名长度宏

宏 [`MAX_FILE_NAME`](https://docs.zephyrproject.org/latest/doxygen/html/fs__interface_8h.html#af43dedece15d018ffad8970492870bac) 指定文件名最大长度，不包含末尾的空字符（Null Character）。原页显示：

```c
#define MAX_FILE_NAME 12
```

实际值取决于启用的文件系统。未显式选择文件系统时，使用标准 **8.3 文件名（8.3 Filename）**长度，即最多 8 个主名称字符、一个点和最多 3 个扩展名字符。

## 78.3\_打开标志类型

[`fs_mode_t`](https://docs.zephyrproject.org/latest/doxygen/html/fs__interface_8h.html#a7090a1b41e73d393b8be3e18ab411027) 是 [`fs_open()`](https://docs.zephyrproject.org/latest/doxygen/html/group__file__system__api.html#ga9c90031ba3e5a10da8e00e81d53ef63b) 标志参数所用的类型。

```c
typedef uint8_t fs_mode_t;
```
