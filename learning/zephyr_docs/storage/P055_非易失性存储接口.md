# 第55章\_非易失性存储接口

原文：[group__nvs__high__level__api](https://docs.zephyrproject.org/latest/doxygen/html/group__nvs__high__level__api.html)。读取日期：2026-10-13，`latest`。

## 55.1\_头文件与挂载

本页为**非易失性存储（Non-volatile Storage，NVS）应用编程接口（Application Programming Interface，API）**。所有声明来自以下头文件；各函数的 `fs` 参数均为指向 `struct nvs_fs` 实例的指针。

```c
#include <zephyr/kvss/nvs.h>
```

[`nvs_mount()`](https://docs.zephyrproject.org/latest/doxygen/html/group__nvs__high__level__api.html#gab932ea2d6e933825c2378bef8c30b065) 将 NVS 文件系统**挂载（Mount）**到 `fs` 指定的闪存设备上。

```c
int nvs_mount(struct nvs_fs *fs);
```

成功返回 0；失败返回负的 `errno` 错误码。原文用 `-ERRNO` 表示这一类错误返回值。

## 55.2\_写入与删除

[`nvs_write()`](https://docs.zephyrproject.org/latest/doxygen/html/group__nvs__high__level__api.html#ga34d40e9f63ba514d7915b72c4fef0b82) 写入一个**条目（Entry）**。参数 `id` 为条目标识符，`data` 指向待写数据，`len` 为待写字节数。

```c
ssize_t nvs_write(struct nvs_fs *fs, uint16_t id,
                  const void *data, size_t len);
```

成功时返回写入的字节数，等于请求的长度。若尝试重写已经存储的相同数据，则**不会写入闪存，返回 0**。失败返回 `errno.h` 定义的错误码的负值。

**`len == 0` 实际删除条目，等价于调用 [`nvs_delete()`](https://docs.zephyrproject.org/latest/doxygen/html/group__nvs__high__level__api.html#ga5fd4175a4976e6d3ee8621ed95e0ee9e)。** 对长度为 0 的条目调用 [`nvs_read()`](https://docs.zephyrproject.org/latest/doxygen/html/group__nvs__high__level__api.html#ga341fd2ad029709cbb6eafde1ae88603f) 会返回错误；无法区分“已删除条目”和“数据长度为 0 的条目”。

`nvs_delete()` 删除 `id` 指定的条目。

```c
int nvs_delete(struct nvs_fs *fs, uint16_t id);
```

成功返回 0，失败返回负的 `errno` 错误码。

## 55.3\_读取当前值与历史值

`nvs_read()` 读取 `id` 指定的条目；`data` 指向接收数据的缓冲区，`len` 为希望读取的字节数。

```c
ssize_t nvs_read(struct nvs_fs *fs, uint16_t id,
                 void *data, size_t len);
```

原文将返回值描述为读取字节数：成功时等于请求的字节数；**返回值大于请求长度，表示并未读完全部字节，还有更多数据可读**。失败返回 `errno.h` 定义的错误码的负值。不能将一个大于 `len` 的返回值当作缓冲区中实际写入了那么多字节。

[`nvs_read_hist()`](https://docs.zephyrproject.org/latest/doxygen/html/group__nvs__high__level__api.html#ga8e525038e353045ad6cd90607e887b0d) 读取条目的**历史版本（History Entry）**。`fs`、`id`、`data` 和 `len` 的含义同上；历史计数参数 `cnt` 为 **0** 时读取最新条目，为 **1** 时读取最新条目之前的一条，依此类推。

```c
ssize_t nvs_read_hist(struct nvs_fs *fs, uint16_t id,
                      void *data, size_t len, uint16_t cnt);
```

其返回值规则与 `nvs_read()` 相同：成功时返回读取字节数；大于请求长度表示尚有数据未读；失败返回负的 `errno.h` 错误码。

## 55.4\_空闲空间查询

[`nvs_calc_free_space()`](https://docs.zephyrproject.org/latest/doxygen/html/group__nvs__high__level__api.html#ga37e5a55f0b9209c7c0c95db9e1e84715) 计算整个文件系统的可用空闲空间。

```c
ssize_t nvs_calc_free_space(struct nvs_fs *fs);
```

成功返回仍能写入文件系统的字节数，失败返回负的 `errno.h` 错误码。计算空闲空间是耗时操作，在**串行外设接口（Serial Peripheral Interface，SPI）**闪存上尤其明显。

[`nvs_sector_max_data_size()`](https://docs.zephyrproject.org/latest/doxygen/html/group__nvs__high__level__api.html#ga7ce6065cf3ac68544f51d26cabd983b2) 查询当前**活动扇区（Active Sector）**还剩多少连续空闲空间。

```c
size_t nvs_sector_max_data_size(struct nvs_fs *fs);
```

返回连续空闲字节数。

## 55.5\_切换扇区与清空

[`nvs_sector_use_next()`](https://docs.zephyrproject.org/latest/doxygen/html/group__nvs__high__level__api.html#ga52db47389e9aa2b0de77497f0e60ed5b) 关闭当前活动扇区并切换到下一个扇区，同时在新扇区上调用**垃圾回收（Garbage Collection）**过程。

```c
int nvs_sector_use_next(struct nvs_fs *fs);
```

成功返回 0，失败返回负的 `errno.h` 错误码。

**原文警告：** 此函数仅为特定用例提供。它违背了 NVS 避免不必要闪存擦除的目标；频繁使用可能导致闪存设备过早失效。

[`nvs_clear()`](https://docs.zephyrproject.org/latest/doxygen/html/group__nvs__high__level__api.html#ga42ee9fd0d98f89dcabc5888f8b4600f0) 从闪存中清除 NVS 文件系统。

```c
int nvs_clear(struct nvs_fs *fs);
```

成功返回 0，失败返回负的 `errno` 错误码。
