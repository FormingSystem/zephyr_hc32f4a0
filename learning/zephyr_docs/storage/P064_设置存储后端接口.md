# 第64章\_设置存储后端接口

原文：[group__settings__backend](https://docs.zephyrproject.org/latest/doxygen/html/group__settings__backend.html)。读取日期：2026-10-13，`latest`。

## 64.1\_后端结构与头文件

本页为**设置子系统（Settings Subsystem）存储后端（Storage Backend）**接口，声明于 `zephyr/settings/settings.h`。

- [`struct settings_store`](P068_设置存储节点结构.md)：负责存储处理的后端处理器节点。
- [`struct settings_load_arg`](P069_设置加载参数结构.md)：数据加载参数。
- [`struct settings_store_itf`](P070_设置后端操作结构.md)：后端处理函数集合。

## 64.2\_注册来源与目的后端

[`settings_src_register()`](https://docs.zephyrproject.org/latest/doxygen/html/group__settings__backend.html#gad16bb70588cf69873f8872d7bf90e1c6) 将处理器注册为读取来源（Source），[`settings_dst_register()`](https://docs.zephyrproject.org/latest/doxygen/html/group__settings__backend.html#ga37bcada0be44b023cd3759e519e69d01) 将其注册为写入目的（Destination）。参数 `cs` 是包含处理器信息的后端节点，两个函数均无返回值。

```c
void settings_src_register(struct settings_store *cs);
void settings_dst_register(struct settings_store *cs);
```

## 64.3\_解析名称并查找处理器

[`settings_parse_and_lookup()`](https://docs.zephyrproject.org/latest/doxygen/html/group__settings__backend.html#gab03a10ed0b65809369b4b6f220aa3df6) 将**键（Key）**解析为组成元素并定位对应模块处理器。

```c
struct settings_handler_static *settings_parse_and_lookup(const char *name,
                                                          const char **next);
```

输入 `name` 是字符串形式的键名；输出 `next` 指向匹配处理器名称之后剩余的名称。成功返回 [`settings_handler_static`](P067_设置静态处理器结构.md) 结构指针，失败返回 `NULL`。

## 64.4\_调用设置处理器

[`settings_call_set_handler()`](https://docs.zephyrproject.org/latest/doxygen/html/group__settings__backend.html#gaf94e311eba2b109cdbddd2767e502e77) 调用设置处理器，后端通过它交付找到的数据及读取方法。

```c
int settings_call_set_handler(const char *name, size_t len,
                              settings_read_cb read_cb, void *read_cb_arg,
                              const struct settings_load_arg *load_arg);
```

| 参数 | 原文方向 | 中文说明 |
| --- | --- | --- |
| `name` | 输入 | 后端中找到的数据名称 |
| `len` | 输入 | 后端中找到的数据大小 |
| `read_cb` | 输入 | 后端提供的读取函数 |
| `read_cb_arg` | 输入/输出 | 后端提供给读取函数的参数 |
| `load_arg` | 输入/输出 | 数据加载参数；函数声明保留 `const` |

返回 0 或负错误码。参数方向和声明的 `const` 均按原页保留。
