# 第50章\_闪存循环缓冲区实例结构

原文：[structfcb](https://docs.zephyrproject.org/latest/doxygen/html/structfcb.html)。读取日期：2026-10-13，`latest`。

## 50.1\_结构职责

`struct fcb` 描述**闪存循环缓冲区（Flash Circular Buffer，FCB）**实例，声明于 `zephyr/fs/fcb.h`。调用 [`fcb_init()`](https://docs.zephyrproject.org/latest/doxygen/html/group__fcb__api.html#gab304f3e9e28f6229d7ddbe638eda2f70) 之前，使用者应填好结构的第一部分；第二部分由 FCB 用作内部状态管理（Internal Bookkeeping）。

## 50.2\_初始化配置字段

**魔数（Magic Value）**用于识别扇区中的有效数据；**暂存空间（Scratch Space）**可供缓冲区满时的**垃圾回收（Garbage Collection）**使用。

| 字段 | 类型 | 中文说明 |
| --- | --- | --- |
| [`f_magic`](https://docs.zephyrproject.org/latest/doxygen/html/structfcb.html#a4206faa9ed633ba2315163c52e557397) | [`uint32_t`](https://docs.zephyrproject.org/latest/doxygen/html/stdint_8h.html#a0a8582351ac627ee8bde2973c825e47f) | 魔数，不应为 `0xFFFFFFFF` |
| [`f_version`](https://docs.zephyrproject.org/latest/doxygen/html/structfcb.html#a030b96abd6c857295f154197278cca69) | [`uint8_t`](https://docs.zephyrproject.org/latest/doxygen/html/stdint_8h.html#a3cb4a16b0e8d6af0af86d4fd6ba5fd9d) | 当前数据版本号 |
| [`f_sector_cnt`](https://docs.zephyrproject.org/latest/doxygen/html/structfcb.html#a6e66e3657ff946da9b87594b819de075) | [`uint16_t`](https://docs.zephyrproject.org/latest/doxygen/html/stdint_8h.html#a5debae8b2a1ec20a6694c0c443ee399e) | 扇区数组中的元素数量 |
| [`f_scratch_cnt`](https://docs.zephyrproject.org/latest/doxygen/html/structfcb.html#aab748de6989e30de6571fc94d66ee365) | [`uint8_t`](https://docs.zephyrproject.org/latest/doxygen/html/stdint_8h.html#a3cb4a16b0e8d6af0af86d4fd6ba5fd9d) | 需要保持为空的扇区数量；可为 FCB 写满时的垃圾回收预留暂存空间 |
| [`f_sectors`](https://docs.zephyrproject.org/latest/doxygen/html/structfcb.html#afc96f045d541c8d141d3427884f1fb44) | `struct flash_sector *` | 扇区数组，必须连续 |

`f_magic` 与 [`f_erase_value`](https://docs.zephyrproject.org/latest/doxygen/html/structfcb.html#a614c6441395637c6c0a17a4fd6107db3) 的反值进行异或后，放置在 FCB 闪存扇区的开头。FCB 用它判断扇区是否包含有效数据。原文说明：将魔数设为 `0xFFFFFFFF`，相当于让该字段的字节保留在“已擦除”状态。

## 50.3\_内部状态字段

**互斥锁（Mutex）**用于保护数据访问；**活动条目（Active Entry）**记录当前写入位置。字段声明与说明如下：

| 字段 | 类型 | 中文说明 |
| --- | --- | --- |
| [`f_mtx`](https://docs.zephyrproject.org/latest/doxygen/html/structfcb.html#a1f30c78d7e02748fbf0bf5033d4bdadf) | `struct k_mutex` | 访问 FCB 数据时使用的锁，内部状态 |
| [`f_oldest`](https://docs.zephyrproject.org/latest/doxygen/html/structfcb.html#ac6dc6236f8b03e4b03f691c55b4d3327) | `struct flash_sector *` | 指向包含最旧数据的扇区，内部状态 |
| [`f_active`](https://docs.zephyrproject.org/latest/doxygen/html/structfcb.html#a1f7922dc1e8076bcfffca117260d5e02) | `struct fcb_entry` | 内部状态；原字段说明未进一步展开 |
| [`f_active_id`](https://docs.zephyrproject.org/latest/doxygen/html/structfcb.html#a8da1d0b4bef7d9ddcd5922d9bbef0cef) | [`uint16_t`](https://docs.zephyrproject.org/latest/doxygen/html/stdint_8h.html#a5debae8b2a1ec20a6694c0c443ee399e) | 原文说明为最新数据所在的闪存位置，内部状态 |
| [`f_align`](https://docs.zephyrproject.org/latest/doxygen/html/structfcb.html#aa745e88d4477408b40a759dd1baea637) | [`uint8_t`](https://docs.zephyrproject.org/latest/doxygen/html/stdint_8h.html#a3cb4a16b0e8d6af0af86d4fd6ba5fd9d) | 闪存写入必须满足的对齐要求，内部状态 |
| [`fap`](https://docs.zephyrproject.org/latest/doxygen/html/structfcb.html#a16cfc82afc8abe70291f4b462e617f2f) | `const struct flash_area *` | 实例使用的闪存区域（Flash Area），内部状态；可传递给 FCB 使用者 |
| `f_erase_value` | [`uint8_t`](https://docs.zephyrproject.org/latest/doxygen/html/stdint_8h.html#a3cb4a16b0e8d6af0af86d4fd6ba5fd9d) | 闪存擦除后的值；在 `fcb_init()` 中读取闪存参数并初始化 |
