# 第35章\_文件系统挂载结构

原文：[structfs__mount__t](https://docs.zephyrproject.org/latest/doxygen/html/structfs__mount__t.html)。读取日期：2026-10-13，`latest`。

`struct fs_mount_t` 保存**文件系统挂载信息（File System Mount Information）**。

```c
#include <zephyr/fs/fs.h>
```

## 35.1\_字段定义

| 字段 | 类型 | 含义 |
| --- | --- | --- |
| [`node`](https://docs.zephyrproject.org/latest/doxygen/html/structfs__mount__t.html#aef11f6864a114ce5a0ebdf5c8f367c65) | [`sys_dnode_t`](../dlist_reference/P001_双向链表公共接口.md#ga57fdb936802a617d16c00ab08cd2ad98) | 挂载列表 `fs_mount_list` 中的链表条目 |
| [`type`](https://docs.zephyrproject.org/latest/doxygen/html/structfs__mount__t.html#a6cd46d4e3106c7d8cfbab00fef54580f) | `int` | 文件系统类型 |
| [`mnt_point`](https://docs.zephyrproject.org/latest/doxygen/html/structfs__mount__t.html#a30e9d3bcfb3b08b051dbbdbd52ae0fdf) | `const char *` | **挂载点（Mount Point）**的目录名，例如文件系统内的 `/fatfs` |
| [`fs_data`](https://docs.zephyrproject.org/latest/doxygen/html/structfs__mount__t.html#a5c2e3e4fa34e5396b6e37fa0b09d5554) | `void *` | 指向文件系统专属数据 |
| [`storage_dev`](https://docs.zephyrproject.org/latest/doxygen/html/structfs__mount__t.html#a3e4c227d5a3c837f21bedff1ada91261) | `void *` | 指向后端存储设备 |
| [`mountp_len`](https://docs.zephyrproject.org/latest/doxygen/html/structfs__mount__t.html#a9b9bdef7b6a7185167ba51bc7a9848b6) | `size_t` | 挂载点字符串的长度 |
| [`fs`](https://docs.zephyrproject.org/latest/doxygen/html/structfs__mount__t.html#a2c70ac7f92ef5ae7d387a8db38a49983) | `const struct fs_file_system_t *` | 指向此挂载点的文件系统接口 |
| [`flags`](https://docs.zephyrproject.org/latest/doxygen/html/structfs__mount__t.html#ac5bd11869b64cfe1794b446d388c7116) | [`uint8_t`](https://docs.zephyrproject.org/latest/doxygen/html/stdint_8h.html#a3cb4a16b0e8d6af0af86d4fd6ba5fd9d) | 挂载标志 |

挂载标志、类型标识及挂载成功后的结构生命周期要求见[文件系统接口](P033_文件系统接口.md)。

本结构的参考文档由 `zephyr/fs/fs.h` 生成。
