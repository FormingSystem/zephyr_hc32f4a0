# 第51章\_闪存循环缓冲区条目结构

原文：[structfcb__entry](https://docs.zephyrproject.org/latest/doxygen/html/structfcb__entry.html)。读取日期：2026-10-13，`latest`。

## 51.1\_条目位置与读写参数

`struct fcb_entry` 是**闪存循环缓冲区（Flash Circular Buffer，FCB）条目（Entry）**信息结构，声明于 `zephyr/fs/fcb.h`，描述元素在闪存中的位置。

读取内容时，可用这些信息确定传给 [`flash_area_read()`](https://docs.zephyrproject.org/latest/doxygen/html/group__flash__area__api.html#ga7c55704b0c0061a4715470676114b127) 的参数；追加新元素时，可用于确定 [`flash_area_write()`](https://docs.zephyrproject.org/latest/doxygen/html/group__flash__area__api.html#gaa56052f8d6bf4f6966752bc21f5cceb8) 的参数。条目位置由指向 `fcb->f_sectors` 中区域的指针，以及区域内偏移共同表示。
