# 第77章\_文件系统公共头文件

原文：[fs_8h](https://docs.zephyrproject.org/latest/doxygen/html/fs_8h.html)。读取日期：2026-10-13，`latest`。

## 77.1\_接口与包含关系

`zephyr/fs/fs.h` 是**文件系统（File System，FS）**子系统的公共**应用编程接口（Application Programming Interface，API）**头文件。原文件包含：

```c
#include <sys/types.h>
#include <zephyr/sys/dlist.h>
#include <zephyr/fs/fs_interface.h>
```

[查看官方源文件页面](https://docs.zephyrproject.org/latest/doxygen/html/fs_8h_source.html)。

## 77.3\_挂载标志与挂载表宏

**挂载表（File System Table，fstab）**条目可以预先描述挂载点。`BIT(n)` 是第 n 位的**位掩码（Bit Mask）**宏。

```c
#define FS_MOUNT_FLAG_NO_FORMAT BIT(0)
#define FS_MOUNT_FLAG_READ_ONLY BIT(1)
#define FS_MOUNT_FLAG_AUTOMOUNT BIT(2)
#define FS_MOUNT_FLAG_USE_DISK_ACCESS BIT(3)
```

| 标志 | 中文说明 |
| --- | --- |
| [`FS_MOUNT_FLAG_NO_FORMAT`](https://docs.zephyrproject.org/latest/doxygen/html/group__file__system__api.html#ga37b6ee15dc50499516fc51e9cb6287d5) | 未找到所请求文件系统时，禁止格式化设备 |
| [`FS_MOUNT_FLAG_READ_ONLY`](https://docs.zephyrproject.org/latest/doxygen/html/group__file__system__api.html#ga789e7f0fbbbb1c751f9dee9d9ca9693d) | 将挂载的文件系统设为只读（Read-only） |
| [`FS_MOUNT_FLAG_AUTOMOUNT`](https://docs.zephyrproject.org/latest/doxygen/html/group__file__system__api.html#gac11f7ecef01b7758b6f8f70fdcd7089d) | 用于启动时应自动挂载的预定义挂载结构 |
| [`FS_MOUNT_FLAG_USE_DISK_ACCESS`](https://docs.zephyrproject.org/latest/doxygen/html/group__file__system__api.html#gadb6c0761d7d537f73b23b1056d12686e) | 请求驱动使用磁盘访问接口（Disk Access API） |

原头文件参考页对下列宏仅列签名，具体展开见[文件系统接口](P033_文件系统接口.md)。`node_id` 为设备树节点标识，`inst` 为实例编号。

| 宏签名 | 中文说明 |
| --- | --- |
| `FSTAB_ENTRY_DT_MOUNT_FLAGS(node_id)` | 获取 fstab 条目的公共挂载标志 |
| `FSTAB_ENTRY_DT_MOUNT_POINT(node_id)` | 获取 fstab 条目的挂载点 |
| `FSTAB_ENTRY_DT_INST_MOUNT_POINT(inst)` | 按实例获取 fstab 条目的挂载点 |
| `FS_FSTAB_ENTRY(node_id)` | `zephyr,fstab` 条目挂载结构所用的定义名称 |
| `FS_FSTAB_DECLARE_ENTRY(node_id)` | 为外部定义的 fstab 条目生成声明 |

## 77.4\_打开与创建模式

下列宏是 [`fs_open()`](https://docs.zephyrproject.org/latest/doxygen/html/group__file__system__api.html#ga9c90031ba3e5a10da8e00e81d53ef63b) 的打开/创建模式标志（Open/Create Mode Flags）。

```c
#define FS_O_READ 0x01
#define FS_O_WRITE 0x02
#define FS_O_RDWR (FS_O_READ | FS_O_WRITE)
#define FS_O_MODE_MASK 0x03
#define FS_O_CREATE 0x10
#define FS_O_APPEND 0x20
#define FS_O_TRUNC 0x40
#define FS_O_FLAGS_MASK 0x70
#define FS_O_MASK (FS_O_MODE_MASK | FS_O_FLAGS_MASK)
```

| 宏 | 中文说明 |
| --- | --- |
| [`FS_O_READ`](https://docs.zephyrproject.org/latest/doxygen/html/group__file__system__api.html#gafd1228407bcf929a175cc18802cda4b2) | 为读取而打开 |
| [`FS_O_WRITE`](https://docs.zephyrproject.org/latest/doxygen/html/group__file__system__api.html#ga0e86c5413b46133e824deaa89b16ee8d) | 为写入而打开 |
| [`FS_O_RDWR`](https://docs.zephyrproject.org/latest/doxygen/html/group__file__system__api.html#ga24ebd0220844552dd044bc2f16de4bef) | 读写标志组合 |
| [`FS_O_MODE_MASK`](https://docs.zephyrproject.org/latest/doxygen/html/group__file__system__api.html#ga728a9885ecf444cec4a1610671cc68bf) | 读写模式位的掩码 |
| [`FS_O_CREATE`](https://docs.zephyrproject.org/latest/doxygen/html/group__file__system__api.html#gaa0965d6d26ece16ee1300f815d31b4e8) | 文件不存在时创建 |
| [`FS_O_APPEND`](https://docs.zephyrproject.org/latest/doxygen/html/group__file__system__api.html#ga51d5d3c5df852cbb3699b3a7357dbcb3) | 以追加（Append）方式打开或创建 |

## 77.5\_定位基准与枚举

[`fs_seek()`](https://docs.zephyrproject.org/latest/doxygen/html/group__file__system__api.html#ga81fc26a759e82d7da7531f9687c1ea50) 的参数 `whence` 选择**文件定位（Seek）**的偏移基准：文件起点、当前位置或文件末尾。

```c
#define FS_SEEK_SET 0
#define FS_SEEK_CUR 1
#define FS_SEEK_END 2
```

枚举 [`fs_dir_entry_type`](https://docs.zephyrproject.org/latest/doxygen/html/group__file__system__api.html#ga79f37397a1590284fae2c4b456f26afb) 区分普通文件条目和目录条目：

```c
enum fs_dir_entry_type {
    FS_DIR_ENTRY_FILE = 0,
    FS_DIR_ENTRY_DIR
};
```

以下匿名枚举唯一标识文件系统类型。名称分别对应 FatFs、LittleFS、Ext2、Virtiofs、RPMsgFS、本机挂载（Native Mount）；[`FS_TYPE_EXTERNAL_BASE`](https://docs.zephyrproject.org/latest/doxygen/html/group__file__system__api.html#gga342d09da6adbf7d1576ce7f933c1b4ffa37c6c9e64a57fee8c51884e18facf25f) 是外部类型编号的起点。

```c
enum {
    FS_FATFS = 0,
    FS_LITTLEFS,
    FS_EXT2,
    FS_VIRTIOFS,
    FS_RPMSGFS,
    FS_NATIVE_MOUNT,
    FS_TYPE_EXTERNAL_BASE
};
```
