# 第49章\_闪存循环缓冲区内部读写接口

原文：[group__fcb__internal](https://docs.zephyrproject.org/latest/doxygen/html/group__fcb__internal.html)。读取日期：2026-10-13，`latest`。

## 49.1\_内部接口边界

本页对应**闪存循环缓冲区（Flash Circular Buffer，FCB）内部非公共接口（Non-API Prototypes）**组，声明位于 `zephyr/fs/fcb.h`，用于对 FCB 闪存扇区进行原始数据读写。

## 49.2\_读取原始数据

[`fcb_flash_read()`](https://docs.zephyrproject.org/latest/doxygen/html/group__fcb__internal.html#ga0b921b509dab767661058d164e80f55e) 从 FCB 扇区读取原始数据。

```c
int fcb_flash_read(const struct fcb *fcbp,
                   const struct flash_sector *sector,
                   off_t off, void *dst, size_t len);
```

输入参数 `fcbp` 为实例，`sector` 为扇区，`off` 为相对于扇区起点的读取偏移，`len` 为读取大小；输出参数 `dst` 为目标缓冲区。成功返回 0，失败返回负的 `errno` 错误码。

## 49.3\_写入原始数据

[`fcb_flash_write()`](https://docs.zephyrproject.org/latest/doxygen/html/group__fcb__internal.html#gafcfb9b6d4b5c0e593c0a9e512a0ec309) 向 FCB 扇区写入原始数据。

```c
int fcb_flash_write(const struct fcb *fcbp,
                    const struct flash_sector *sector,
                    off_t off, const void *src, size_t len);
```

所有参数均为输入：`fcbp` 为实例，`sector` 为扇区，`off` 为相对于扇区起点的写入偏移，`src` 为源缓冲区，`len` 为写入大小。成功返回 0，失败返回负的 `errno` 错误码。
