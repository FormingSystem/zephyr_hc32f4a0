# 第14章\_数据保留接口参考

原文：[group__retention__api](https://docs.zephyrproject.org/latest/doxygen/html/group__retention__api.html)。读取日期：2026-10-13，`latest`。

**数据保留接口（Retention API）**自 Zephyr 3.4 提供，接口版本 0.1.0，头文件为 `zephyr/retention/retention.h`。其子主题为[启动模式接口](P015_启动模式接口参考.md)和[引导加载器信息接口](P016_引导加载器信息接口.md)。这里的 API 指应用程序编程接口（Application Programming Interface）。

## 14.1\_取得区域大小

<a id="gaf20780720d64144b50e03f9e04d3f39b"></a>

[`retention_size()`](https://docs.zephyrproject.org/latest/doxygen/html/group__retention__api.html#gaf20780720d64144b50e03f9e04d3f39b) 返回保留区域的大小。参数 `dev` 是要操作的保留设备。

```c
ssize_t retention_size(const struct device *dev);
```

成功时返回表示字节大小的正数；失败时返回负 `errno` 错误码。

## 14.2\_检查数据有效性

<a id="gaa3f12ad0b1929a828e8d42c7c073a16d"></a>

[`retention_is_valid()`](https://docs.zephyrproject.org/latest/doxygen/html/group__retention__api.html#gaa3f12ad0b1929a828e8d42c7c073a16d) 检查保留区域中的底层数据是否有效，参数 `dev` 为保留设备。

```c
int retention_is_valid(const struct device *dev);
```

| 返回值 | 含义 |
| --- | --- |
| `1` | 检查成功，数据有效 |
| `0` | 数据无效 |
| `-ENOTSUP` | 此区域没有配置头部或校验和，因此不支持有效性判断 |
| 其他负错误码 | 操作失败 |

## 14.3\_读取保留数据

<a id="ga7b4c04850ec0b57d120a0f1425d8b583"></a>

[`retention_read()`](https://docs.zephyrproject.org/latest/doxygen/html/group__retention__api.html#ga7b4c04850ec0b57d120a0f1425d8b583) 从区域读取数据。参数 `dev` 为保留设备，`offset` 为读取起点偏移，`buffer` 接收读出的数据，`size` 为要读取的数据大小。

```c
int retention_read(const struct device *dev, off_t offset,
                   uint8_t *buffer, size_t size);
```

成功返回 `0`，失败返回负错误码。

## 14.4\_写入并建立有效状态

<a id="ga6131168ffc3f6d0e4329cf56f32071cc"></a>

[`retention_write()`](https://docs.zephyrproject.org/latest/doxygen/html/group__retention__api.html#ga6131168ffc3f6d0e4329cf56f32071cc) 向区域写入数据，写入前不需要清除底层数据。函数成功返回后，通过 [`retention_is_valid()`](https://docs.zephyrproject.org/latest/doxygen/html/group__retention__api.html#gaa3f12ad0b1929a828e8d42c7c073a16d) 查询时数据会被视为有效。参数 `dev` 为保留设备，`offset` 为写入起点偏移，`buffer` 为待写数据，`size` 为待写数据大小。

```c
int retention_write(const struct device *dev, off_t offset,
                    const uint8_t *buffer, size_t size);
```

成功返回 `0`，否则返回负 `errno` 错误码。有效性查询在未配置头部/校验和时的限制仍见前节。

## 14.5\_清零保留区域

<a id="gaab8a56b5879faabd10982bc110577a1d"></a>

[`retention_clear()`](https://docs.zephyrproject.org/latest/doxygen/html/group__retention__api.html#gaab8a56b5879faabd10982bc110577a1d) 把保留区域中的全部数据设置为零。参数 `dev` 为保留设备。

```c
int retention_clear(const struct device *dev);
```

成功返回 `0`，否则返回负 `errno` 错误码。
