# 第40章\_文件系统驱动操作结构

原文：[structfs__file__system__t](https://docs.zephyrproject.org/latest/doxygen/html/structfs__file__system__t.html)。读取日期：2026-10-13，`latest`。

`struct fs_file_system_t` 是**文件系统接口（File System Interface）**结构，包含文件操作、目录操作和文件系统级操作的函数指针。

```c
#include <zephyr/fs/fs_sys.h>
```

以下代码分别给出各成员的完整函数指针声明。参数 `filp` 指向文件对象，`dirp` 指向目录对象，`mountp` 指向**挂载点（Mount Point）**结构。面向应用的公共函数参考见[文件系统接口](P033_文件系统接口.md)。

## 40.2\_打开或创建文件

## 40.5\_定位文件

```c
int (*lseek)(struct fs_file_t *filp, off_t off, int whence);
```

将文件位置移动到新位置。

| 参数 | 含义 |
| --- | --- |
| `filp` | 要调整位置的文件 |
| `off` | 相对于 `whence` 指定位置的偏移量 |
| `whence` | 文件中的基准位置；原文列出 `SEEK_CUR`、`SEEK_SET`、`SEEK_END` |

返回值：原文写为返回新的文件位置，失败返回负错误码。

译注：此处原文使用 `SEEK_*` 名称，返回约定也与公共 `fs_seek()` 参考页的“成功返回 0”不同。这里保留该结构参考页的原始说明，未把两处约定混写成同一条。
