# 第63章\_设置子系统接口

原文：[group__settings](https://docs.zephyrproject.org/latest/doxygen/html/group__settings.html)。读取日期：2026-10-13，`latest`。

## 63.1\_范围、版本与声明

**设置子系统（Settings Subsystem）**负责设置项的加载、应用与持久保存。本**应用编程接口（Application Programming Interface，API）**组自 Zephyr **1.12** 提供，接口版本为 **1.0.0**。**序列化（Serialization）**是将设置转换成可存储的数据表示；**持久化（Persistence）**使设置在运行结束后仍能保存。

相关参考包括[存储后端（Storage Backend）](https://docs.zephyrproject.org/latest/doxygen/html/group__settings__backend.html)、[键名处理（Name Processing）](https://docs.zephyrproject.org/latest/doxygen/html/group__settings__name__proc.html)和[运行时设置（Runtime Settings）](P017_设置运行时接口.md)。[动态处理器结构 [`settings_handler`](P066_设置动态处理器结构.md)](P066_设置动态处理器结构.md)为子树提供处理函数；[静态处理器结构 [`settings_handler_static`](P067_设置静态处理器结构.md)](P067_设置静态处理器结构.md)不包含动态链表节点元素。

本页声明来自 `zephyr/settings/settings.h`：

```c
#include <zephyr/settings/settings.h>
```

## 63.2\_名称与值长度宏

**设置树（Settings Tree）**以 `/` 分隔名称层级。以下宏限定树深度、名称和值长度；完整名称容量公式保持原文。

```c
#define SETTINGS_MAX_DIR_DEPTH 8
#define SETTINGS_MAX_NAME_LEN (8 * SETTINGS_MAX_DIR_DEPTH)
#define SETTINGS_MAX_VAL_LEN 256
#define SETTINGS_NAME_SEPARATOR '/'
#define SETTINGS_NAME_END '='
#define SETTINGS_EXTRA_LEN ((SETTINGS_MAX_DIR_DEPTH - 1) + 2)
#define SETTINGS_FULL_NAME_LEN ((SETTINGS_MAX_NAME_LEN) + (SETTINGS_EXTRA_LEN) + 1)
```

| 宏 | 中文说明 |
| --- | --- |
| [`SETTINGS_MAX_DIR_DEPTH`](https://docs.zephyrproject.org/latest/doxygen/html/group__settings.html#ga2afa32b032e88a188c5263156d9e73e1) | 设置树最大深度 |
| [`SETTINGS_MAX_NAME_LEN`](https://docs.zephyrproject.org/latest/doxygen/html/group__settings.html#gad96357290d7289dd1d7917abd575c4f7) | 设置名称最大长度 |
| [`SETTINGS_MAX_VAL_LEN`](https://docs.zephyrproject.org/latest/doxygen/html/group__settings.html#gaa9705c71c2d7cfdf3beab49d6b510769) | 设置值最大长度 |
| [`SETTINGS_NAME_SEPARATOR`](https://docs.zephyrproject.org/latest/doxygen/html/group__settings.html#gab66e3bb2f0f5f5e3a20c6702df6a0694) | 名称字段分隔符 |
| [`SETTINGS_NAME_END`](https://docs.zephyrproject.org/latest/doxygen/html/group__settings.html#ga41fb7b74ecb502093d4aa5cd6adb4093) | 名称结束字符 |
| [`SETTINGS_EXTRA_LEN`](https://docs.zephyrproject.org/latest/doxygen/html/group__settings.html#ga9f10069ed74c368aef366d659d3a917d) | 为最多 7 个分隔符、`=` 和 `\0` 预留的额外空间 |
| [`SETTINGS_FULL_NAME_LEN`](https://docs.zephyrproject.org/latest/doxygen/html/group__settings.html#gaec4d6fb4a186afb90c74574bab8db855) | 包含分隔符的设置全名最大长度 |

## 63.3\_静态处理器定义宏

**处理器（Handler）**为设置子树提供读取、设置、提交和导出回调；**提交（Commit）**将已经设置但尚未应用的值应用到运行状态；**导出（Export）**提供待保存的值。静态处理器在编译时定义。

宏 `SETTINGS_STATIC_HANDLER_DEFINE(_hname, _tree, _get, _set, _commit, _export)` 的原始展开为：

```c
SETTINGS_STATIC_HANDLER_DEFINE_WITH_CPRIO(_hname, _tree, _get, _set, _commit, _export, 0)
```

它将提交优先级设为 **0**。译注：原文说明中的字母 `O` 与宏展开不一致，此处按展开中的数值 `0` 表达。所创建变量的名称以 `settings_handler_` 为前缀。

带优先级的宏 `SETTINGS_STATIC_HANDLER_DEFINE_WITH_CPRIO(_hname, _tree, _get, _set, _commit, _export, _cprio)` 原始展开如下。其中 [`STRUCT_SECTION_ITERABLE`](../iterable_reference/P001_可遍历段公共接口.md#ga9104f42cbe4a67a931bed7f7cc8f600f) 是将处理器放入可遍历段的宏，`##` 是 C 预处理器的标记拼接运算符（Token Pasting Operator）。

```c
const STRUCT_SECTION_ITERABLE(settings_handler_static, settings_handler_##_hname) = {      \
        .name = _tree,                                                                     \
        .cprio = _cprio,                                                                   \
        .h_get = _get,                                                                     \
        .h_set = _set,                                                                     \
        .h_commit = _commit,                                                               \
        .h_export = _export,                                                               \
}
```

| 参数 | 中文说明 |
| --- | --- |
| `_hname` | 处理器名称；变量名拼为 `settings_handler_` 加此名称 |
| `_tree` | 子树名称 |
| `_get` | 获取回调，可以为 `NULL` |
| `_set` | 设置回调，可以为 `NULL` |
| `_commit` | 提交回调，可以为 `NULL` |
| `_export` | 导出回调，可以为 `NULL` |
| `_cprio` | 提交优先级，**数值越小，优先级越高**；仅用于带优先级的宏 |

## 63.4\_存储读取回调

类型 [`settings_read_cb`](https://docs.zephyrproject.org/latest/doxygen/html/group__settings.html#ga51cdac276c1fb8cd27fc3eec42749a04) 用于 `h_set` 处理函数从设置存储中读取数据。

```c
typedef ssize_t (*settings_read_cb)(void *cb_arg, void *data, size_t len);
```

输入 `cb_arg` 为读函数上下文，由后端传给 `h_set`；输出 `data` 指向目标缓冲区；输入 `len` 为读取长度。返回正值表示读取字节数，**0 表示键值对（Key-value Pair）已删除**；错误返回负的 `errno` 错误码，原文记作 `-ERRNO`。

## 63.5\_直接加载回调

[`settings_load_direct_cb`](https://docs.zephyrproject.org/latest/doxygen/html/group__settings.html#ga767bf6c2709b1c58afcf4d1c5ef0d535) 是 [`settings_load_subtree_direct()`](https://docs.zephyrproject.org/latest/doxygen/html/group__settings.html#ga1dfe42f40a7d63bbdb81aed864d0ff12) 使用的**直接加载（Direct Loading）**回调类型。

```c
typedef int (*settings_load_direct_cb)(const char *key, size_t len,
                                      settings_read_cb read_cb,
                                      void *cb_arg, void *param);
```

| 参数 | 方向 | 中文说明 |
| --- | --- | --- |
| `key` | 输入 | 已跳过注册处理器所用名称部分的键名 |
| `len` | 输入 | 后端中找到的数据大小 |
| `read_cb` | 输入 | 后端提供的读取函数 |
| `cb_arg` | 输入/输出 | 后端提供给读取函数的上下文 |
| `param` | 输入/输出 | 传入 [`settings_load_subtree_direct()`](https://docs.zephyrproject.org/latest/doxygen/html/group__settings.html#ga1dfe42f40a7d63bbdb81aed864d0ff12) 的参数 |

回调返回非零时，停止继续搜索子树。

## 63.6\_初始化

[`settings_subsys_init()`](https://docs.zephyrproject.org/latest/doxygen/html/group__settings.html#gaf81fad8575840f73a739d16d79613f8e) 函数的声明如下：

```c
int settings_subsys_init(void);
```

初始化设置子系统和存储后端，可在应用启动时调用。若后端是**文件系统（File System，FS）**，必须在文件系统挂载后调用；**闪存循环缓冲区（Flash Circular Buffer，FCB）**后端没有此项前置限制。成功返回 0，失败返回非零。

## 63.7\_按优先级注册

[`settings_register_with_cprio()`](https://docs.zephyrproject.org/latest/doxygen/html/group__settings.html#gadf612631e30119ff688f83f16ad5aa89) 函数的声明如下：

```c
int settings_register_with_cprio(struct settings_handler * cf, int cprio);
```

为保存在**随机存取存储器（Random-Access Memory，RAM）**中的设置项注册处理器，并指定提交优先级。参数 `cf` 指向包含注册信息的结构；`cprio` 为提交优先级，数值越小优先级越高。成功返回 0，失败返回非零。

## 63.8\_按默认优先级注册

[`settings_register()`](https://docs.zephyrproject.org/latest/doxygen/html/group__settings.html#gab2043a6d799202e177cc3dfa0cbfa531) 函数的声明如下：

```c
int settings_register(struct settings_handler * cf);
```

为保存在 RAM 中的设置项注册处理器，提交优先级使用默认值。参数 `cf` 指向包含注册信息的结构。成功返回 0，失败返回非零。

## 63.9\_加载全部设置

[`settings_load()`](https://docs.zephyrproject.org/latest/doxygen/html/group__settings.html#ga89c6d618df81f197cc5c1a2018b00648) 函数的声明如下：

```c
int settings_load(void);
```

从已注册的持久化来源加载序列化条目。遇到设置值时，调用之前为相应子树注册的处理器。成功返回 0，失败返回非零。

## 63.10\_加载指定子树

[`settings_load_subtree()`](https://docs.zephyrproject.org/latest/doxygen/html/group__settings.html#gab80e8a21c80243359b652386f7ce2424) 函数的声明如下：

```c
int settings_load_subtree(const char * subtree);
```

从已注册的持久化来源加载部分序列化条目。输入参数 `subtree` 指定待加载子树；只为属于该子树的值调用此前注册的处理器。成功返回 0，失败返回非零。

## 63.11\_直接读取单个值

[`settings_load_one()`](https://docs.zephyrproject.org/latest/doxygen/html/group__settings.html#ga6ada8f687dcd3f3374a766ca173fdf27) 函数的声明如下：

```c
ssize_t settings_load_one(const char * name, void * buf, size_t buf_len);
```

从已注册的持久化来源加载一个序列化条目。输入 `name` 为设置名称/键，输出 `buf` 指向接收缓冲区，输入 `buf_len` 为已分配缓冲区的长度。成功返回该名称对应值的实际大小，失败返回负值。

## 63.12\_查询值长度

[`settings_get_val_len()`](https://docs.zephyrproject.org/latest/doxygen/html/group__settings.html#gacadb36d1cd5f6c7c6cbaf46e0e81ac7c) 函数的声明如下：

```c
ssize_t settings_get_val_len(const char * key);
```

输入 `key` 为设置名称/键。条目存在时返回值长度；不存在时返回 0；失败返回负值。

## 63.13\_通过回调直接加载

[`settings_load_subtree_direct()`](https://docs.zephyrproject.org/latest/doxygen/html/group__settings.html#ga1dfe42f40a7d63bbdb81aed864d0ff12) 函数的声明如下：

```c
int settings_load_subtree_direct(const char * subtree, settings_load_direct_cb cb, void * param);
```

使用指定回调加载部分序列化条目，绕过设置模块通常的数据处理流程；找到的所有设置值都传给回调。输入 `subtree` 为子树名称，输入 `cb` 为回调函数指针，输入/输出 `param` 为传递给回调的参数。

**该函数阻塞执行，不调用提交函数。** 操作结束后，由调用者决定调用何种提交函数。成功返回 0，失败返回非零。

## 63.14\_保存全部运行中设置

[`settings_save()`](https://docs.zephyrproject.org/latest/doxygen/html/group__settings.html#ga789410aa059398d6c8a7851ea6945b55) 函数的声明如下：

```c
int settings_save(void);
```

保存当前运行状态中的序列化条目。仅保存与当前持久化值不同的条目。成功返回 0，失败返回非零。

## 63.15\_保存指定子树

[`settings_save_subtree()`](https://docs.zephyrproject.org/latest/doxygen/html/group__settings.html#ga988b9cb22e256c87ac99d8007ff54a13) 函数的声明如下：

```c
int settings_save_subtree(const char * subtree);
```

保存当前运行状态中属于 `subtree` 的序列化条目，且仅保存与持久化值不同的项。输入 `subtree` 为目标子树名称。成功返回 0，失败返回非零。

译注：原参数说明写为“待加载的子树”，而函数总述及行为均为保存；这里按保存函数的上下文说明参数，保留对原文字样差异的记录。

## 63.16\_保存单个序列化值

[`settings_save_one()`](https://docs.zephyrproject.org/latest/doxygen/html/group__settings.html#gaf22356f0dd01d4cf43a6297fafa86e30) 函数的声明如下：

```c
int settings_save_one(const char * name, const void * value, size_t val_len);
```

当值发生变化时，将单个序列化值写入持久存储。参数 `name` 为设置名称/键，`value` 指向待保存值，`val_len` 为值长度。成功返回 0，失败返回非零。

原页称 `value` 将传给 [`settings_handler::h_export`](P066_设置动态处理器结构.md)。译注：此次核对的[官方 `settings_store.c`](https://github.com/zephyrproject-rtos/zephyr/blob/main/subsys/settings/src/settings_store.c) 中，`settings_save_one()` 直接调用存储后端的 `csi_save(cs, name, value, val_len)`，不经 `h_export`。这里保留原文说法并标出实现差异，避免将调用路径混淆。

## 63.17\_删除持久化条目

[`settings_delete()`](https://docs.zephyrproject.org/latest/doxygen/html/group__settings.html#ga070b6ad31bca0bee71ec1f1a4d67618d) 函数的声明如下：

```c
int settings_delete(const char * name);
```

删除持久化存储中的单个序列化设置；删除已有键值对意味着将其值设为 `NULL`。参数 `name` 为设置名称/键。成功返回 0，失败返回非零。

## 63.18\_提交全部处理器

[`settings_commit()`](https://docs.zephyrproject.org/latest/doxygen/html/group__settings.html#ga623c60b89dda3145f9334343748d5954) 函数的声明如下：

```c
int settings_commit(void);
```

为所有设置处理器调用提交操作，应用那些已经设置、但尚未应用的设置。成功返回 0，失败返回非零。

## 63.19\_提交指定子树

[`settings_commit_subtree()`](https://docs.zephyrproject.org/latest/doxygen/html/group__settings.html#ga11523bc43121d78e0ac8ee1443559e42) 函数的声明如下：

```c
int settings_commit_subtree(const char * subtree);
```

仅为属于 `subtree` 的处理器调用提交操作，应用已经设置、但尚未应用的设置。输入 `subtree` 为待提交子树名称。成功返回 0，失败返回非零。

## 63.20\_不修改运行值而保存单项或子树

[`settings_save_subtree_or_single_without_modification()`](https://docs.zephyrproject.org/latest/doxygen/html/group__settings.html#ga5d82a2e0a16585df406a45aa9beab4c6) 函数的声明如下：

```c
int settings_save_subtree_or_single_without_modification(const char * name, bool save_if_subtree, bool save_if_single_setting);
```

可通过获取函数（Get Function）读出当前运行值，并在它与持久化值不同时保存单个序列化值；也可保存整个子树当前运行中的序列化条目。

**仅在启用 Kconfig 配置项 [`CONFIG_SETTINGS_SAVE_SINGLE_SUBTREE_WITHOUT_MODIFICATION`](https://docs.zephyrproject.org/latest/kconfig.html#CONFIG_SETTINGS_SAVE_SINGLE_SUBTREE_WITHOUT_MODIFICATION) 时可用。**

| 参数 | 中文说明 |
| --- | --- |
| `name` | 设置项或子树的名称/键 |
| `save_if_subtree` | 若目标是子树且希望保存，将此参数设为 `true` |
| `save_if_single_setting` | 若目标是单个设置项且希望保存，将此参数设为 `true` |

成功返回 0，失败返回非零。
