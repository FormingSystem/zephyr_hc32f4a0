# 带标志单向链表参考大纲

带标志单向链表（Flagged Single-linked List）在节点指针的对齐空余位中保存应用标志，复用普通单向链表的通用操作。先读[单向链表指南](../kernel/P054_单向链表.md)与[通用链表宏参考](../slist_reference/大纲.md)，再查本册API、头文件与源码。

标志位数由目标应用二进制接口（ABI）的节点对齐决定；链接修改保留标志，节点初始化与标志更新有不同前提。源码跟踪译注区分对齐、初始化、同步和遍历语义，原始声明、宏展开、示例、参数、返回值及法律注释保留。仓库定位使用相对链接，完整范围见[全站进度](../PROGRESS.md)。
