# 第1章\_带标志单向链表公共接口

原文：[官方页面](https://docs.zephyrproject.org/latest/doxygen/html/group__flagged-single-linked-list__apis.html)。读取日期：2026-10-15；来源摘要见[来源记录](../SOURCES.md)。

> 译注——阅读位置：先读[单向链表指南](../kernel/P054_单向链表.md)，再查带标志链表公共API及头文件。源码跟踪说明另外标注，不将内部宏生成器当作额外的公开接口。

带标志单向链表（Flagged Single-linked List）实现。

<a id="details"></a>

带标志单向链表实现。它类似普通单向链表，并允许为每个节点定义用户标志位（Flag Bits）；可通过sys_sfnode_flags_get()与sys_sfnode_flags_set()访问和修改这些位。实现采用内联宏／函数。此API不具备线程安全性（Thread Safety）；若链表跨线程使用，必须用同步原语（Synchronization Primitives）保护函数调用。

## 1.5\_详细说明（Detailed Documentation）

<a id="ga68dae6db03b52bc27777a2b8c274a852"></a>

### `SYS_SFLIST_CONTAINER`

```c
#define SYS_SFLIST_CONTAINER ( __ln, __cn, __n )
```

```c
#include <zephyr/sys/sflist.h>
```

展开值（Value）：

```c
Z_GENLIST_CONTAINER(__ln, __cn, __n)
```

提供从链表节点取得所属容器（Container）的基本操作。注意：节点指针为NULL时也可安全使用。

**参数（Parameters）**

| 名称／方向 | 说明 |
| --- | --- |
| `__ln` | 指向sys_sfnode_t的指针，用于取得其所属容器。 |
| `__cn` | 容器结构类型的指针。 |
| `__n` | 容器结构中sys_sfnode_t成员的字段名。 |

> 译注——源码核对：__cn是提供容器类型的指针表达式，__n是嵌入的sys_sfnode_t字段名；宏用__typeof__与CONTAINER_OF计算外层对象。NULL节点返回NULL，但真实类型、成员偏移及对齐仍须匹配。

<a id="gae4b3f68c446d3da06cb3101c8d0942a5"></a>

### `SYS_SFLIST_FLAG_BITS`

```c
#define SYS_SFLIST_FLAG_BITS LOG2(__alignof__(sys_sfnode_t))
```

```c
#include <zephyr/sys/sflist.h>
```

此应用二进制接口（ABI）下，节点指针中可用标志位的数量。

> 译注——源码核对：当前为LOG2(__alignof__(sys_sfnode_t))，与FLAGS_MASK对应。较旧网页或指南中的“两位”说明不是对所有ABI的约束；结构本身仍只有一个uintptr_t编码字段，没有独立标志数组。

<a id="ga46e57329036b76ab03267d2e9258d5c2"></a>

### `SYS_SFLIST_FLAGS_MASK`

```c
#define SYS_SFLIST_FLAGS_MASK ((uintptr_t)(__alignof__(sys_sfnode_t) - 1))
```

```c
#include <zephyr/sys/sflist.h>
```

此应用二进制接口（Application Binary Interface，ABI）下，节点指针中可用标志位的掩码（Mask）。

> 译注——源码核对：当前表达式为节点类型对齐值减1，保留指针自然对齐所留下的低位。例如节点对齐4字节时掩码为3，对齐8字节时为7；不能把所有目标统一写成两个标志位。实际值以目标ABI及头文件为准。

### `SYS_SFLIST_FOR_EACH_CONTAINER`

```c
#define SYS_SFLIST_FOR_EACH_CONTAINER ( __sl, __cn, __n )
```

```c
#include <zephyr/sys/sflist.h>
```

展开值（Value）：

```c
Z_GENLIST_FOR_EACH_CONTAINER(sflist, __sl, __cn, __n)
```

提供以容器形式遍历链表的基本操作。注意：此循环不支持安全摘除当前容器，因此不应摘除__cn。

```c
}
```

### `sys_sfnode_init()`

```c

```

声明属性：`inline`、`static`。

```c
#include <zephyr/sys/sflist.h>
```

初始化sflist节点。

为此链表节点设置初始标志值。该值必须能由SYS_SFLIST_FLAG_BITS给出的位数表示。即使节点在链表内移动、被移除或移入另一条链表，这些标志也会保留。

**参数（Parameters）**

| 名称／方向 | 说明 |
| --- | --- |
| `node` | 指向要设置其标志的节点。 |
| `flags` | 要设置的标志值。 |

> 译注——源码核对：先检查flags可由有效低位表示，再把next_and_flags直接设为flags，等价于空后继加初始标志。必须在节点未入链时调用；对仍在链内的节点重新初始化会丢掉它的后继链接。首次入链前须初始化节点，不能让append／prepend读取未初始化的标志。

## 1.6\_源码定位与版本边界

对照[公共API](P001_带标志单向链表公共接口.md)、[头文件参考](P002_带标志单向链表头文件参考.md)、[源码浏览](P003_带标志单向链表头文件源码.md)及[通用生成宏源码](../slist_reference/P005_链表通用生成宏源码.md)。

相对源码定位：[sflist.h](../../../include/zephyr/sys/sflist.h)与[list_gen.h](../../../include/zephyr/sys/list_gen.h)；本次依据为[官方sflist.h](https://github.com/zephyrproject-rtos/zephyr/blob/main/include/zephyr/sys/sflist.h)和[官方list_gen.h](https://github.com/zephyrproject-rtos/zephyr/blob/main/include/zephyr/sys/list_gen.h)，摘要见[来源记录](../SOURCES.md)。

> 译注——源码核对：编码与对齐：sys_sfnode_t将后继指针与标志合并到uintptr_t类型的next_and_flags中；后继读取时屏蔽FLAGS_MASK，链接写入时保留当前标志。节点地址必须满足类型对齐，不能以packed容器或任意字节偏移破坏低位为零的前提。

> 译注——源码核对：位数随ABI变化：本次头文件提供SYS_SFLIST_FLAGS_MASK和SYS_SFLIST_FLAG_BITS，由__alignof__(sys_sfnode_t)推导。通常4字节对齐有2位、8字节对齐有3位；指南“两位”表述应结合版本和目标核对，不能代替这两个常量。

> 译注——源码核对：初始化与生命周期：先初始化链表头尾，并对每个新节点调用sys_sfnode_init设置初始标志；仅sys_sflist_init不会初始化各节点。节点移动或摘除不清标志，但不分配、复制或释放容器。同一节点不能重复入链或同时加入多条链。

> 译注——源码核对：并发与遍历：标志修改和链接修改都可能读改写同一个编码字，须由调用者提供同步。SAFE遍历只预存后继，不提供线程安全；非NULL起始节点从其后继开始，源链合并后清空，get不主动清后继而remove清逻辑后继并保留标志。

> 译注——源码核对：实现衔接：sflist.h提供编码字段访问函数，list_gen.h生成派生操作。单向链表通用宏已在相邻参考册翻译；内部生成细节不等于允许应用直接修改编码字段。

本次未构建或运行并发遍历、节点生命周期、性能及实板实验。
