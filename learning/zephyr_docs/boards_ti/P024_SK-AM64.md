## 概述（Overview）

SK-AM64板级配置用于在TI AM64x平台的Cortex-M4F及Cortex-R5F核上运行Zephyr应用。

此板配置也启用半主机（Semihosting）调试控制台。

详情见[TI AM64产品页](https://www.ti.com/product/AM6442)。

<a id="hardware"></a>

## 硬件（Hardware）

SK-AM64 EVM搭载AM64 SoC，包含双核Cortex-A53集群及MCU域内一个Cortex-M4核。原文在此介绍Zephyr的M4F移植及以下使用的硬件规格：


- 低功耗Arm Cortex-M4F


  - 256 KB SRAM
- 两个Arm双核Cortex-R5F集群


  - 每个64 KB SRAM
- 存储器（Memory）


  - 2 GB DDR4
- 调试（Debug）


  - 基于XDS110的JTAG

<a id="devices"></a>

### 设备（Devices）

<a id="system-clock"></a>

#### 系统时钟（System Clock）

此开发板配置使用400 MHz系统时钟。

<a id="ddr-ram"></a>

#### DDR随机存取存储器（DDR RAM）

开发板具有2 GB DDR RAM，此板级配置为Zephyr分配：


- 1 MB用于核间通信（IPC），包括VirtIO及虚拟环形队列（Vrings）
- 4 KB用于Linux RemoteProc资源表
- 15 MB用于一般用途

<a id="serial-port"></a>

#### 串口（Serial Port）

此配置使用MCU域UART，即MCU_UART0，作为唯一串行通信通道。

<a id="gpio"></a>

#### 通用输入输出（GPIO）

SK-AM64的心跳指示灯（Heartbeat LED）连接MCU_GPIO0_6，板级配置可构建并运行[Blinky](../getting_started/P004_LED闪烁示例.md#blinky)示例。

<a id="sd-card"></a>

## SD卡（SD Card）

下载TI官方[WIC](https://dr-download.ti.com/software-development/software-development-kit-sdk/MD-yXgchBCk98/10.01.10.04/tisdk-default-image-am64xx-evm-10.01.10.04.rootfs.wic.xz)镜像，用镜像写入软件写入SD卡，在评估板A53应用核上启动Linux；再由这些核通过remoteproc将Zephyr二进制加载到M4核。

默认配置位于[boards/ti/sk_am64/sk_am64_am6442_m4_defconfig](https://github.com/zephyrproject-rtos/zephyr/blob/main/boards/ti/sk_am64/sk_am64_am6442_m4_defconfig)。

<a id="flashing"></a>

## 烧录（Flashing）

开发板通过OpenAMP资源表使用remoteproc。

测试前需将二进制文件复制到SD卡，使A53内核在启动时通过remoteproc加载它。

测试M4F内核时，使用以下命令构建[Hello World](../getting_started/P005_HelloWorld示例.md#hello_world)示例。

```text
# From the root of the Zephyr repository
west build -p -b sk_am64/am6442/m4 samples/hello_world
```

构建生成的二进制文件名为`zephyr.elf`，位于`build/zephyr`目录。

将此二进制复制到SD卡的/lib/firmware目录，命名为am64-mcu-m4f0_0-fw。

```text
# Mount the SD card at sdcard for example
sudo mount /dev/sdX sdcard
# copy the elf to the /lib/firmware directory
sudo cp --remove-destination zephyr.elf sdcard/lib/firmware/am64-mcu-m4f0_0-fw
```

随后可用SD卡启动系统，启动时二进制程序会被加载到M4F内核。

要从SD卡启动，请将启动引脚设为SD卡启动模式，参见《[SK-AM64B EVM User’s Guide](https://www.ti.com/lit/ug/spruj64/spruj64.pdf)》。

更改启动模式后，开发板上电时应执行启动流程，二进制程序运行并向MCU_UART0端口打印Hello world。
