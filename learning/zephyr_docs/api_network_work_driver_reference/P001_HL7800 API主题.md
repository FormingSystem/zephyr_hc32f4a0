**枚举值（Enumerators）**

| 名称／方向 | 说明 |

| `HL7800_EVENT_STARTUP_STATE_CHANGE` | 调制解调器启动状态（Modem Startup State）发生变化。 事件数据指向 `struct mdm_hl7800_compound_event`，其中包含 `enum mdm_hl7800_startup_state` 状态码。 |
| `HL7800_EVENT_SLEEP_STATE_CHANGE` | 睡眠状态（Sleep State）发生变化。 事件数据指向 `struct mdm_hl7800_compound_event`，其中包含 `enum mdm_hl7800_sleep` 状态码。 |
| `HL7800_EVENT_RAT` | 无线接入技术（Radio Access Technology，RAT）发生变化。 事件数据指向一个 `enum mdm_hl7800_radio_mode` 值。 |
| `HL7800_EVENT_BANDS` | 配置的 LTE 频段（Bands）已变化。 事件数据指向一个以空字符结尾的频段配置字符串（Band Configuration String）。 |
| `HL7800_EVENT_ACTIVE_BANDS` | 活动 LTE 频段（Active Bands）已变化。 事件数据指向一个以空字符结尾的频段配置字符串（Band Configuration String）。 |
| `HL7800_EVENT_FOTA_STATE` | 固件更新状态（Firmware Update State）发生变化。 事件数据指向 `struct mdm_hl7800_compound_event`，其中包含 `enum mdm_hl7800_fota_state` 状态码。 |
| `HL7800_EVENT_FOTA_COUNT` | 固件更新进度（Firmware Update Progress）。 事件数据指向一个 `uint32_t`，其中保存已发送给调制解调器的字节数。 |
| `HL7800_EVENT_REVISION` | 固件修订版本（Firmware Revision）发生变化。 事件数据指向一个以空字符结尾的修订版本字符串（Revision String）。 |

| `HL7800_EVENT_GPS_POSITION_STATUS` | 定位状态（Position Fix Status）发生变化。 事件数据指向一个 `int`，其中保存 `enum mdm_hl7800_gnss_position_event` 值。 |

| `HL7800_EVENT_POLTE_LOCATE_STATUS` | 发出 PoLTE 定位命令（Locate Command）的结果。 事件数据指向 `struct mdm_hl7800_polte_location_data`，其中只有状态（Status）有效。 |
