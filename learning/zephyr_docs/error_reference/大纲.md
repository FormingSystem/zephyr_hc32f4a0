# 断言与错误号参考大纲

断言（Assertion）检查程序预期成立的条件；错误号（Error Number）用于具体接口约定的错误报告。本册收录官方最小C标准库（Minimal C Library）的assert.h与errno.h，以及错误号公共接口和内部访问器，保留全部声明、常量、源码及许可证。

阅读时先区分运行时断言与编译期静态断言，再按具体函数判断应读直接返回的错误码还是errno。源码译注解释NDEBUG与Zephyr断言配置、历史错误措辞、编号与别名，以及外部C库、线程局部存储和系统调用三种errno访问分支。源码定位均使用相对路径，完整翻译范围见[全站进度](../PROGRESS.md)。
