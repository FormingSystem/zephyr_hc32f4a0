系统错误号（System Error Numbers）。

<a id="details"></a>

系统错误号（System Error Numbers）。函数返回的错误码（Error Codes），包括IEEE Std 1003.1-2017规定的错误码列表。

原文预格式说明（Preformatted Description）：

```text
   Error codes returned by functions.
   Includes a list of those defined by IEEE Std 1003.1-2017.
```

> 译注——源码核对：原文措辞：表中Not owner、No such context、Not enough core和Not a typewriter等历史描述按原文译出。core在此指内存，不是CPU核心数量；ENOTTY的打字机说法是历史终端措辞。EDOM原文写Argument too large，但不能由此推断它只适用于正向越界，具体数学函数应按自身定义域说明判断。列出错误号不代表Zephyr实现了该错误所涉及的全部POSIX或STREAMS功能。

> 译注——源码核对：存储分支：z_errno()先检查CONFIG_LIBC_ERRNO，直接返回外部C库errno的地址；否则CONFIG_ERRNO_IN_TLS使用线程局部存储（Thread Local Storage，TLS）的z_errno_var；再否则声明为系统调用（System Call），由errno.c返回当前线程对应位置。用户空间（Userspace）分支使用userspace_local_data->errno_var，其他分支使用线程结构中的errno_var。不能把它理解为所有线程共享一个普通全局int。

> 译注——源码核对：配置与边界：CONFIG_ERRNO默认启用；CONFIG_ERRNO_IN_TLS依赖ERRNO、THREAD_LOCAL_STORAGE且不使用LIBC_ERRNO，满足条件时默认启用，可避免用户空间访问该值所需的系统调用。内部头文件被单独放置是为了避免errno.h与kernel.h相互包含；应用不应据此绕过所选C库的公开入口。这里分析当前线程的存储实现，不把它推广为中断上下文可用性的保证。

> 译注——源码核对：版权与版本：errno源码保留Wind River及加州大学董事会的版权文字、Berkeley软件许可说明和历史标记；不以中文文件的整体说明覆盖原有声明。本次源码浏览页的非注释内容与所下载头文件一致，本地源码链接用于跟踪，不能保证任意本地基线与滚动main相同。
