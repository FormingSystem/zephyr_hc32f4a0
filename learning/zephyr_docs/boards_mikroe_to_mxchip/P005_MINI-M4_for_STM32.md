## 概述（Overview）

MINI-M4 for STM32是搭载[STM32F415RG](https://www.st.com/resource/en/datasheet/stm32f415rg.pdf)微控制器的小型ARM® Cortex®-M4开发板，引脚兼容PIC16F887及PIC18(L)F45K20微控制器，可安装到标准DIP40插座。板载16 MHz表面贴装晶体振荡器，以及可用于内部实时时钟／日历模块（RTCC）的32.768 kHz晶体。开发板带一个复位按键及3个信号LED，工作电压3.3 V；板载稳压器允许直接通过USB线缆供电。

<a id="pin-mapping"></a>

### 引脚映射（Pin Mapping）

此移植是供自定义修改的起点，并非针对特定开发板的完整移植。STM32 SoC的大多数GPIO通过外部排针引出，丝印标签与SoC引脚名称一致。

引脚映射（Pin Mapping）详情见[MINI-M4 for STM32用户手册](https://download.mikroe.com/documents/starter-boards/mini/stm32/f4/mini-m4-stm32-manual-v100.pdf)。

<a id="flashing"></a>

### 烧录（Flashing）

开发板初始处于锁定状态，烧录时会失败并显示以下消息：

```text
Error: stm32x device protected
```

使用OpenOCD解锁后即可烧录。

```text
$ openocd -f /usr/share/openocd/scripts/interface/stlink-v2.cfg \
    -f /usr/share/openocd/scripts/target/stm32f4x.cfg -c init\
    -c "reset halt" -c "stm32f4x unlock 0" -c "reset run" -c shutdown
```

下面以[Hello World](../getting_started/P005_HelloWorld示例.md#hello_world)应用为例。

```text
# From the root of the zephyr repository
west build -b mikroe_mini_m4_for_stm32 samples/hello_world
west flash
```

控制台上应显示以下消息：

```text
Hello World! mikroe_mini_m4_for_stm32
```
