## 概述（Overview）

MXChip AZ3166 IoT DevKit是面向物联网（IoT / Internet of Things）项目的开发板，使用Arm Cortex-M4处理器。板载外设包含OLED屏、耳机输出、立体声麦克风，以及温湿度、压力、运动传感器（加速度计及陀螺仪）和磁力计等。

<a id="id3"></a>

开发板更多信息见[MXChip AZ3166网站](https://www.mxchip.com/en/az3166) [注1](#id2)。

<a id="hardware"></a>

## 硬件（Hardware）

MXChip AZ3166 IoT DevKit具有以下硬件特性：


- 96 MHz STM32F412 Arm Cortex-M4F处理器
- 工作电压3.3 V，或通过USB供电
- 支持3.3 V DC-DC，最大电流1.5 A
- 128×64像素OLED显示屏
- 两个可编程按键
- 一个RGB LED
- 三个状态指示LED，分别标记Wi-Fi、Azure及User
- 安全加密芯片（Security Encryption Chip）
- 用于红外遥控或交互的红外发射器（Infrared Emitter）
- 运动传感器LSM6DSL
- 磁力计LIS3MDL
- 气压传感器LPS22HB
- 温湿度传感器HTS221
- EMW3166 Wi-Fi模块，带256K SRAM及1M+2M Byte SPI闪存，容量单位按原文保留

<a id="flashing"></a>

### 烧录（Flashing）

按通常方式构建并烧录应用，详见“构建应用”（[Building an Application](../application/P001_应用开发.md#build-an-application)）与“运行应用”（[Run an Application](https://docs.zephyrproject.org/latest/develop/application/index.html#application-run)）。

下面以[Hello World](../getting_started/P005_HelloWorld示例.md#hello_world)应用为例。

首先运行常用终端程序查看输出。

```text
$ minicom -D <tty_device> -b 115200
```

将`<tty_device>`替换为micro:bit所在串口，例如Linux上的`/dev/ttyACM0`。

随后按通常方式构建并烧录应用。

```text
# From the root of the zephyr repository
west build -b az3166_iotdevkit samples/hello_world
west flash
```
