# 贡献流程官方译文大纲

本册翻译 Zephyr 官方贡献流程，覆盖提交、审查、提案、停滞 PR 处理、二进制文件要求、编码准则、文档编写与生成以及外部组件集成。适合准备提交驱动、修复或功能的人查阅；源码跟踪使用相对链接，并说明参照版本边界。

1. [参与Zephyr开发](P001_参与Zephyr开发.md)：总体入口及各类贡献资源。
2. [贡献指南](P002_贡献指南.md)：许可、来源证明、AI辅助、源码树、Git、提交说明、CI和完整工作流。
3. [贡献者职责](P003_贡献者职责.md)：修改拆分、提交历史、测试文档要求及技术争议升级。
4. [审查者职责](P004_审查者职责.md)：优先次序、阻塞意见、审查范围与AI辅助反馈责任。
5. [拉取请求生命周期](P005_拉取请求生命周期.md)：草稿、待审查、无活动、例外、替代和重新打开。
6. [修改他人的贡献](P006_修改他人的贡献.md)：拣选、接续修改、原作者确认和署名。
7. [提案与征求意见稿](P007_提案与征求意见稿.md)：适用范围、内容要求与讨论流程。
8. [二进制文件](P008_二进制文件.md)：第三方托管、模块声明、污点标记、类型、预编译库及维护要求。

9. [编码准则](P009_编码准则.md)：147条主要规则、5条附加规则、包容性术语与标准库边界。
10. [文档编写指南](P010_文档编写指南.md)：reST、Sphinx、代码与链接、媒体、全部自定义选项及无障碍。
11. [文档生成](P011_文档生成.md)：各系统依赖、本地构建、开发模式、预览及Doxygen交叉引用。
12. [外部组件贡献](P012_外部组件贡献.md)：许可、价值、集成方式、维护与TSC审查流程。

本册12页已翻译；加上单独成册的[编码风格译文](../coding_style/大纲.md)8页，当前清单中贡献目录的20页均有译文。整站其余资料仍按[全站进度](../PROGRESS.md)登记，本册完成不代表整套完成。

文中的提交、推送、变基、签署及沟通是官方工作流说明；本批没有执行这些操作，也未将官方上游规则改写为本仓库既有约定。英文代码和声明完整保留，说明性文字在相邻正文翻译。个人环境与实验路线见独立的[项目实验补充](../../zephyr_project_notes/README.md)。
