# 第7章\_Zephyr软件需求规格

原文：[Zephyr Software Requirements](https://docs.zephyrproject.org/latest/build/requirements/zephyr_software_requirements.html)。本次读取日期：2026-10-14；基线为保存的 `latest` 页面，HTML摘要见[来源记录](../SOURCES.md)。

<a id="zephyr-software-requirements"></a>

> 译注：本页完整翻译261条软件需求（Software Requirements）。所有条目的状态都是草稿（Draft），类型都是功能性（Functional）；`shall`译为“应”，表达规范要求，不表示对应实现已通过验证。需求编号、原文顺序、组件、用户故事（User Story）和父需求（Parents）关系均保留。原文的替换建议、待定项（TBD）、疑问和未填写的字段不作补全；没有父需求或用户故事的条目不擅自新增这些字段。Zephyr RTOS指Zephyr实时操作系统（Real-time Operating System），本页CPU指中央处理器（Central Processing Unit）。

## 7.1\_ZEP-SRS-19-1：原子操作（Atomic Operations）

Zephyr RTOS应提供在确保互斥的同时访问内存的接口。

| 字段 | 值 |
| --- | --- |
| 状态（Status） | 草稿（Draft） |
| 类型（Type） | 功能性（Functional） |
| 组件（Component） | 硬件架构接口（Hardware Architecture Interface） |

**用户故事（User Story）：**作为Zephyr RTOS用户，我希望读写内存区域时不受其他线程或中断服务程序（Interrupt Service Routine，ISR）干扰。

**父需求（Parents）：**[ZEP-SYRS-1](P008_系统需求.md#zep-syrs-1)。
