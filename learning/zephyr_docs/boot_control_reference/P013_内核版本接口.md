原文：[官方页面](https://docs.zephyrproject.org/latest/doxygen/html/group__version__apis.html)。读取日期：2026-10-15；来源摘要见[来源记录](../SOURCES.md)。

内核版本 API（Kernel Version APIs）。

<a id="details"></a>

内核版本 API。内核版本已从字符串转换为一个四字节数值，分为两部分。第一部分：最高的三个字节表示内核的数字版本 x.y.z，其中 x 为主版本（Major Release），y 为次版本（Minor Release），z 为补丁版本（Patchlevel Release）；因此每个分量的取值范围均为 0 至 255（含端点）。第二部分：最低字节保留供将来使用。

## 13.3\_详细说明（Detailed Documentation）

### `SYS_KERNEL_VER_MAJOR`

```c
#define SYS_KERNEL_VER_MAJOR ( ver)
```

```c
#include <zephyr/kernel_version.h>
```

展开值（Value）：

```c
(((ver) >> 24) & 0xFF)
```

<a id="ga7979b71e0ee58ec1951b675a29368374"></a>

### `sys_kernel_version_get()`

```c
uint32_t sys_kernel_version_get ( void )
```

```c
#include <zephyr/kernel_version.h>
```

返回当前构建的内核版本（Kernel Version）。

内核版本是一个四字节数值，其格式在 `kernel_version.h` 文件中说明。

返回（Returns）：内核版本。

## 13.4\_源码定位与版本边界

相对源码定位：[include/zephyr/kernel_version.h](../../../include/zephyr/kernel_version.h)、[kernel/version.c](../../../kernel/version.c)。官方源码摘要见[来源记录](../SOURCES.md)。

> 译注——源码核对：以下源码跟踪译注独立于官方正文，依据来源记录中保存摘要的官方main文件。源码定位采用相对链接；本地版本如有差异，应核对来源摘要与实际实现，不把文档核对视为固件升级或重启实测。

> 译注——源码核对：本次sys_kernel_version_get直接返回构建时生成的KERNELVERSION。三个宏分别提取位31至24、23至16、15至8，低8位保留；这是数值位布局，不是字节序相关的指针解析方法。

> 译注——源码核对：该值表示本次构建的Zephyr内核版本，不是应用固件版本、MCUboot版本、Git提交号或运行时探测的另一镜像版本。它也不携带诸如rc预发布标签的完整字符串，不能单凭三个数字证明源码完全一致。
