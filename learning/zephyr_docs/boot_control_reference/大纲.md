# 镜像控制与启动参考大纲

本册翻译MCUboot镜像控制（Image Control）及其头文件和三种镜像头结构、系统重启（System Reboot）、内核版本（Kernel Version）和启动模式（Boot Mode）头文件，附内核版本完整接口，共十三份官方页面。四个头文件的源码浏览页保留全部可见代码、原始注释、许可证和行号锚点，中文说明另列。

升级请求、镜像确认与系统重启分别改变不同状态。阅读时需区分镜像对索引、槽位编号与Flash区域标识，并依据原页调用约束和返回值处理失败。源码跟踪译注独立说明配置分支、头部解码与验证的区别、偏移交换模式，以及保持区域清除行为；仓库环境和实验记录继续放在独立资料区。

启动模式的完整参数和返回值见[启动模式接口](../storage/P015_启动模式接口参考.md)。本地源码和译文之间采用相对链接；完整范围及待译状态见[全站进度](../PROGRESS.md)。
