## 9.3\_源码定位与版本边界

相对源码定位：[include/zephyr/kernel_version.h](../../../include/zephyr/kernel_version.h)、[kernel/version.c](../../../kernel/version.c)。官方源码摘要见[来源记录](../SOURCES.md)。

> 译注——源码核对：以下源码跟踪译注独立于官方正文，依据来源记录中保存摘要的官方main文件。源码定位采用相对链接；本地版本如有差异，应核对来源摘要与实际实现，不把文档核对视为固件升级或重启实测。

> 译注——源码核对：本次sys_kernel_version_get直接返回构建时生成的KERNELVERSION。三个宏分别提取位31至24、23至16、15至8，低8位保留；这是数值位布局，不是字节序相关的指针解析方法。

> 译注——源码核对：该值表示本次构建的Zephyr内核版本，不是应用固件版本、MCUboot版本、Git提交号或运行时探测的另一镜像版本。它也不携带诸如rc预发布标签的完整字符串，不能单凭三个数字证明源码完全一致。

本次验证范围为文档与源码对照，未构建固件、配置实板引脚或操作硬件。
