## 11.3\_源码定位与版本边界

相对源码定位：[include/zephyr/retention/bootmode.h](../../../include/zephyr/retention/bootmode.h)、[subsys/retention/bootmode.c](../../../subsys/retention/bootmode.c)、[subsys/retention/retention.c](../../../subsys/retention/retention.c)。官方源码摘要见[来源记录](../SOURCES.md)。

> 译注——源码核对：以下源码跟踪译注独立于官方正文，依据来源记录中保存摘要的官方main文件。源码定位采用相对链接；本地版本如有差异，应核对来源摘要与实际实现，不把文档核对视为固件升级或重启实测。

> 译注——源码核对：启动模式（Boot Mode）通过设备树chosen项zephyr,boot-mode选择保持存储（Retention）设备。当前实现读写该设备偏移0处的一个字节；设置模式不立即重启，也不自行进入引导加载程序，仍需要启动端理解相同约定。

> 译注——源码核对：bootmode_check先检查保持数据有效性；有效或不支持有效性检查时才读模式。匹配返回1，不匹配返回0，负值是错误，应先检查返回码。bootmode_clear调用retention_clear；当前保持层清零整个所选保持区域并使内部头部状态无效，不是只把模式字节作为一次普通有效写入改为0。不要假定清除后立刻检查NORMAL一定得到1。

> 译注——源码核对：保持存储能否跨某种复位或掉电保留由设备及其供电域决定；公共枚举存在不代表目标板已提供启动模式存储。此处只跟踪官方接口和源码，没有配置本仓库的具体芯片实验。

本次验证范围为文档与源码对照，未构建固件、配置实板引脚或操作硬件。
