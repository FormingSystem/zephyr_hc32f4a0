## 10.4\_源码跟踪译注

> 译注——本次sys_kernel_version_get直接返回构建时生成的KERNELVERSION。三个宏分别提取位31至24、23至16、15至8，低8位保留；这是数值位布局，不是字节序相关的指针解析方法。

> 译注——该值表示本次构建的Zephyr内核版本，不是应用固件版本、MCUboot版本、Git提交号或运行时探测的另一镜像版本。它也不携带诸如rc预发布标签的完整字符串，不能单凭三个数字证明源码完全一致。

头文件相对定位：[include/zephyr/kernel_version.h](../../../include/zephyr/kernel_version.h)，关联实现／接口：[kernel/version.c](../../../kernel/version.c)；[官方原始头文件](https://github.com/zephyrproject-rtos/zephyr/blob/main/include/zephyr/kernel_version.h)与[官方关联文件](https://github.com/zephyrproject-rtos/zephyr/blob/main/kernel/version.c)的摘要见来源记录。去掉注释和展示空白后，本页代码与本次读取的原始头文件一致，不能推广到以后滚动更新的main或任意本地版本。
