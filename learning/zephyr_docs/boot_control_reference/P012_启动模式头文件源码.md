## 12.4\_源码跟踪译注

> 译注——启动模式（Boot Mode）通过设备树chosen项zephyr,boot-mode选择保持存储（Retention）设备。当前实现读写该设备偏移0处的一个字节；设置模式不立即重启，也不自行进入引导加载程序，仍需要启动端理解相同约定。

> 译注——bootmode_check先检查保持数据有效性；有效或不支持有效性检查时才读模式。匹配返回1，不匹配返回0，负值是错误，应先检查返回码。bootmode_clear调用retention_clear；当前保持层清零整个所选保持区域并使内部头部状态无效，不是只把模式字节作为一次普通有效写入改为0。不要假定清除后立刻检查NORMAL一定得到1。

> 译注——保持存储能否跨某种复位或掉电保留由设备及其供电域决定；公共枚举存在不代表目标板已提供启动模式存储。此处只跟踪官方接口和源码，没有配置本仓库的具体芯片实验。

头文件相对定位：[include/zephyr/retention/bootmode.h](../../../include/zephyr/retention/bootmode.h)，关联实现／接口：[subsys/retention/bootmode.c](../../../subsys/retention/bootmode.c)；[官方原始头文件](https://github.com/zephyrproject-rtos/zephyr/blob/main/include/zephyr/retention/bootmode.h)与[官方关联文件](https://github.com/zephyrproject-rtos/zephyr/blob/main/subsys/retention/bootmode.c)的摘要见来源记录。去掉注释和展示空白后，本页代码与本次读取的原始头文件一致，不能推广到以后滚动更新的main或任意本地版本。
