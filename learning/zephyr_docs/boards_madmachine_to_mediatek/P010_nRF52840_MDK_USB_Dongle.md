## 概述（Overview）

nRF52840 MDK USB Dongle是一款采用nRF52840多协议SoC的小型低成本开发平台，外形为便于使用的USB适配器。

<a id="hardware"></a>

## 硬件（Hardware）

设计具有以下特性：


- 可编程用户按键
- RGB发光二极管（LED）
- 最多12个GPIO
- 2.4 GHz芯片天线

USB适配器可用作：


- 低成本Bluetooth 5／Thread／802.15.4／ANT／2.4 GHz多协议节点
- 开发板（Development Board）
- 网络协处理器（NCP / Network Co-Processor），可方便地连接计算机或其他USB设备
