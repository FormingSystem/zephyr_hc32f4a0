# 第1章\_配置系统Kconfig

原文：[Configuration System (Kconfig)](https://docs.zephyrproject.org/latest/build/kconfig/index.html)。读取日期：2026-10-12，`latest`。

Zephyr 内核及子系统可以在构建时配置，以适应应用和平台的具体需求。配置由 Kconfig 管理，它也是 Linux 内核使用的配置系统，目标是在不修改源代码的情况下进行配置。

配置选项通常称为“符号”，定义在 `Kconfig` 文件中。文件还描述符号之间的依赖，决定哪些配置有效。符号可以组织为菜单和子菜单，让交互式配置界面保持清晰。

Kconfig 输出的 `autoconf.h` 头文件包含可在构建时判断的宏。没有使用的功能可以不编译进程序，节省空间。

官方后续文档介绍如何设置选项、Zephyr 如何使用 Kconfig，以及编写 Kconfig 文件的建议：

1. [交互式配置界面](P002_交互式配置界面.md)。
2. [追踪配置值来源](https://docs.zephyrproject.org/latest/build/kconfig/tracing.html)。
3. [设置配置值](P003_设置配置值.md)。
4. [技巧与最佳实践](https://docs.zephyrproject.org/latest/build/kconfig/tips.html)。
5. [自定义预处理函数](https://docs.zephyrproject.org/latest/build/kconfig/preprocessor-functions.html)。
6. [Kconfig 扩展](https://docs.zephyrproject.org/latest/build/kconfig/extensions.html)。

如果希望从安全角度优化配置，参阅安全指南中的[加固工具](../security/P005_安全加固工具.md)。
