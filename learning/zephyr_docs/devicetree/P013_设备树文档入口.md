# 第13章\_设备树文档入口

原文：[Devicetree](https://docs.zephyrproject.org/latest/build/dts/index.html)。读取日期：2026-10-12，`latest`。

**设备树（Devicetree）**是主要用于描述硬件的层次化数据结构。Zephyr 主要用它向**设备驱动模型（Device Driver Model）**描述硬件，并提供这些硬件的初始配置。

本页连接设备树高层指南与参考材料。指南解释使用方式，参考部分提供具体接口和内置绑定。

## 13.2\_接口与绑定参考

官方参考分为两类：

- [设备树API参考](https://docs.zephyrproject.org/latest/build/dts/api/api.html)：通用节点与属性操作、`ranges`、`reg`、`interrupts`、遍历与存在性检查、节点依赖和总线辅助宏、基于实例的接口、硬件专用接口，以及 `chosen` 节点。
- [内置绑定索引](https://docs.zephyrproject.org/latest/build/dts/api/bindings.html)：按设备类型和厂商查找绑定。**绑定（Binding）**描述节点属性、类型和约束，供工具校验并解释设备树内容。

平台无关的细节见[设备树规范](https://www.devicetree.org/)。驱动怎样使用这些描述，见[设备驱动模型](https://docs.zephyrproject.org/latest/kernel/drivers/index.html#device-model-api)。
