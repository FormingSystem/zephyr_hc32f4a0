# 第8章\_设备树绑定概述

原文：[Devicetree bindings](https://docs.zephyrproject.org/latest/build/dts/bindings.html)。读取日期：2026-10-12，`latest`。

设备树本身的格式相对缺少结构约束，只完成了硬件描述的一半；另一半由 binding（绑定）提供。绑定声明节点内容的要求，并为合法节点的内容提供语义信息。Zephyr 绑定是采用自定义格式的 YAML 文件，不使用 Linux 内核的 dt-schema 工具。

后续页面介绍绑定的作用、查找位置和数据格式：

- [绑定入门](P009_绑定入门.md)：简单示例、构建系统怎样使用绑定、其他匹配方式、查找目录。
- [绑定语法](P010_绑定语法.md)：顶层键、标题、描述、compatible、属性、子绑定、bus/on-bus、设备类、示例、说明项 cell 名称、include、nexus 节点与映射。
- [上游绑定规则](P011_上游绑定规则.md)：已有绑定、通用规则、厂商前缀、默认值和 `zephyr,` 前缀。

内置绑定的具体参考见[绑定索引](https://docs.zephyrproject.org/latest/build/dts/api/bindings.html)。本页是官方绑定专题入口，子页面分别计入翻译进度。
