# 第1章\_比较器公共头文件参考

原文：[comparator_8h](https://docs.zephyrproject.org/latest/doxygen/html/comparator_8h.html)。读取日期：2026-10-13，`latest`。

`zephyr/drivers/comparator.h`是比较器（Comparator）驱动应用程序接口（Application Programming Interface，API）的主头文件，包含设备声明、错误码和生成的系统调用（System Call）声明：

```c
#include <zephyr/device.h>
#include <errno.h>
#include <zephyr/syscalls/comparator.h>
```

## 1.1\_触发方式

枚举`comparator_trigger`定义比较器触发（Trigger）选项：

```c
enum comparator_trigger {
        COMPARATOR_TRIGGER_NONE = 0,
        COMPARATOR_TRIGGER_RISING_EDGE,
        COMPARATOR_TRIGGER_FALLING_EDGE,
        COMPARATOR_TRIGGER_BOTH_EDGES
};
```

四项分别表示不触发（None）、上升沿（Rising Edge）、下降沿（Falling Edge）和双边沿（Both Edges）。只有首项显式赋值为0，其余按原枚举顺序保留。

## 1.2\_回调与驱动操作类型

`comparator_callback_t`是比较器回调（Callback）模板，接收设备和用户数据。其余四个函数指针类型依次取得输出状态、设置触发方式、设置触发回调，以及检查并清除待处理触发状态（Pending Trigger）。

```c
typedef void (*comparator_callback_t)(const struct device *dev, void *user_data);
typedef int (*comparator_api_get_output)(const struct device *dev);
typedef int (*comparator_api_set_trigger)(const struct device *dev,
                                          enum comparator_trigger trigger);
typedef int (*comparator_api_set_trigger_callback)(const struct device *dev,
                                                   comparator_callback_t callback,
                                                   void *user_data);
typedef int (*comparator_api_trigger_is_pending)(const struct device *dev);
```

结构体`comparator_driver_api`保存驱动操作（Driver Operations），字段见[比较器驱动操作结构](../hardware/P094_比较器驱动操作结构.md)，后端接口见[比较器驱动后端接口](../hardware/P093_比较器驱动后端接口.md)。

## 1.3\_公共函数

公共函数与上述四种操作一一对应。`comparator_trigger_is_pending`既检查状态也清除状态，不能把它当作无副作用的只读查询。

```c
int comparator_get_output(const struct device *dev);
int comparator_set_trigger(const struct device *dev, enum comparator_trigger trigger);
static int comparator_set_trigger_callback(const struct device *dev, comparator_callback_t callback, void *user_data);
int comparator_trigger_is_pending(const struct device *dev);
```

参数约束和返回值见[比较器接口参考](../hardware/P089_比较器接口参考.md)。这里按文件参考页保留签名，完整内联定义及系统调用包装见[源码页](P002_比较器公共头文件源码.md)。
