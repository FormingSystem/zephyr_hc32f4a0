# 第8章\_运算放大器公共头文件源码

原文：[opamp_8h_source](https://docs.zephyrproject.org/latest/doxygen/html/opamp_8h_source.html)。读取日期：2026-10-13，`latest`。

本页保留官方源码浏览页的全部可见代码、版权和许可，仅去除网页行号与行尾空白。接口的中文解释见[参考页](P007_运算放大器公共头文件参考.md)。

## 8.1\_完整可见源码

原代码中的条件编译、类型、赋值和函数声明均按原样保留。

```c
/*
 * Copyright 2025 NXP
 *
 * SPDX-License-Identifier: Apache-2.0
 */


#ifndef ZEPHYR_INCLUDE_DRIVERS_OPAMP_H_
#define ZEPHYR_INCLUDE_DRIVERS_OPAMP_H_


#include <zephyr/device.h>
#include <errno.h>

#ifdef __cplusplus
extern "C" {
#endif

enum opamp_gain {
        OPAMP_GAIN_1_7 = 0,
        OPAMP_GAIN_1_3,
        OPAMP_GAIN_1,
        OPAMP_GAIN_5_3,
        OPAMP_GAIN_2,
        OPAMP_GAIN_11_5,
        OPAMP_GAIN_3,
        OPAMP_GAIN_4,
        OPAMP_GAIN_13_3,
        OPAMP_GAIN_7,
        OPAMP_GAIN_8,
        OPAMP_GAIN_15,
        OPAMP_GAIN_16,
        OPAMP_GAIN_31,
        OPAMP_GAIN_32,
        OPAMP_GAIN_33,
        OPAMP_GAIN_63,
        OPAMP_GAIN_64,
};


enum opamp_functional_mode {
        OPAMP_FUNCTIONAL_MODE_DIFFERENTIAL = 0,
        OPAMP_FUNCTIONAL_MODE_INVERTING,
        OPAMP_FUNCTIONAL_MODE_NON_INVERTING,
        OPAMP_FUNCTIONAL_MODE_FOLLOWER,
        OPAMP_FUNCTIONAL_MODE_STANDALONE,
};

typedef int (*opamp_api_set_gain_t)(const struct device *dev, enum opamp_gain gain);

__subsystem struct opamp_driver_api {
        opamp_api_set_gain_t set_gain;
};


__syscall int opamp_set_gain(const struct device *dev, enum opamp_gain gain);

static inline int z_impl_opamp_set_gain(const struct device *dev, enum opamp_gain gain)
{
        return DEVICE_API_GET(opamp, dev)->set_gain(dev, gain);
}

#ifdef __cplusplus
}
#endif


#include <zephyr/syscalls/opamp.h>

#endif /* ZEPHYR_INCLUDE_DRIVERS_OPAMP_H_ */
```

## 8.2\_阅读说明

增益（Gain）与功能模式（Functional Mode）的全部枚举、驱动操作结构、回调类型和系统调用包装都保留。`z_impl_opamp_set_gain`通过`DEVICE_API_GET`宏取得驱动接口，再调用`set_gain`；原页没有额外的实现注释。
