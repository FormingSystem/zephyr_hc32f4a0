# 第7章\_运算放大器公共头文件参考

原文：[opamp_8h](https://docs.zephyrproject.org/latest/doxygen/html/opamp_8h.html)。读取日期：2026-10-13，`latest`。

`zephyr/drivers/opamp.h`是运算放大器（Operational Amplifier，OPAMP）驱动应用程序接口（Application Programming Interface，API）的主头文件，包含设备、错误码和生成的系统调用（System Call）声明：

```c
#include <zephyr/device.h>
#include <errno.h>
#include <zephyr/syscalls/opamp.h>
```

## 7.1\_增益系数

枚举`opamp_gain`定义增益系数（Gain Factor），全部18项如下。名称中的分数形式保留，不改写为近似小数；首项的整数编码0不表示零增益。

```c
enum opamp_gain {
        OPAMP_GAIN_1_7 = 0,
        OPAMP_GAIN_1_3,
        OPAMP_GAIN_1,
        OPAMP_GAIN_5_3,
        OPAMP_GAIN_2,
        OPAMP_GAIN_11_5,
        OPAMP_GAIN_3,
        OPAMP_GAIN_4,
        OPAMP_GAIN_13_3,
        OPAMP_GAIN_7,
        OPAMP_GAIN_8,
        OPAMP_GAIN_15,
        OPAMP_GAIN_16,
        OPAMP_GAIN_31,
        OPAMP_GAIN_32,
        OPAMP_GAIN_33,
        OPAMP_GAIN_63,
        OPAMP_GAIN_64,
};
```

各项对应的物理倍率见[全部增益枚举说明](../hardware/P091_运算放大器接口参考.md)。

## 7.2\_功能模式

枚举`opamp_functional_mode`定义功能模式（Functional Mode），依次为差分（Differential）、反相（Inverting）、同相（Non-Inverting）、跟随器（Follower）和独立（Standalone）模式。

```c
enum opamp_functional_mode {
        OPAMP_FUNCTIONAL_MODE_DIFFERENTIAL = 0,
        OPAMP_FUNCTIONAL_MODE_INVERTING,
        OPAMP_FUNCTIONAL_MODE_NON_INVERTING,
        OPAMP_FUNCTIONAL_MODE_FOLLOWER,
        OPAMP_FUNCTIONAL_MODE_STANDALONE,
};
```

具体模式的约束见[运算放大器驱动后端接口](../hardware/P095_运算放大器驱动后端接口.md)。

## 7.3\_增益操作与驱动结构

`opamp_api_set_gain_t`是设置增益的回调（Callback）类型。结构体`opamp_driver_api`保存驱动操作（Driver Operations），字段见[运算放大器操作结构](../hardware/P096_运算放大器操作结构.md)。

```c
typedef int (*opamp_api_set_gain_t)(const struct device *dev, enum opamp_gain gain);
```

公共函数`opamp_set_gain`设置运算放大器增益：

```c
int opamp_set_gain(const struct device *dev, enum opamp_gain gain);
```

详细参数和返回值见[运算放大器接口参考](../hardware/P091_运算放大器接口参考.md)，系统调用包装与操作转发见[完整源码](P008_运算放大器公共头文件源码.md)。
