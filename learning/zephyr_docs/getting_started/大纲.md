# 官方入门文档中文译文大纲

这是整套翻译的第一批，覆盖介绍、基本环境、入门后续说明、两个基础示例、术语表和各平台补充页。它保留官方文档的内容职责，不替代本项目已有的 G 盘实验教程。

| 顺序 | 已完成译文 | 用途 |
| --- | --- | --- |
| 1 | [Zephyr介绍](P001_Zephyr介绍.md) | 认识系统定位、支持架构、功能和社区资源 |
| 2 | [入门指南](P002_入门指南.md) | 对照三个系统的环境准备、源码、构建和烧录流程 |
| 3 | [入门之后](P003_入门之后.md) | 查阅更新、工具链、开发板别名、模拟与原生运行 |
| 4 | [LED闪烁示例](P004_LED闪烁示例.md) | 核对 GPIO LED 和设备树别名要求，理解常见构建错误 |
| 5 | [Hello World示例](P005_HelloWorld示例.md) | 无 LED 时从控制台输出开始，查看 QEMU 运行方式 |
| 6 | [术语表](P006_术语表.md) | 查询全部 37 个官方词条，分清板、SoC、目标、工作区和模块 |
| 7 | [Linux主机依赖](P007_Linux主机依赖.md) | 查询四类发行版安装分支及工具版本补齐方式 |
| 8 | [macOS补充配置](P008_macOS补充配置.md) | 查询 Gatekeeper 与 MacPorts 说明 |
| 9 | [Windows补充配置](P009_Windows补充配置.md) | 查询官方保留的 WSL 补充说明及历史版本边界 |

首次接触 Zephyr 可先读 1、2，再按有无合适开发板选择 4 或 5。第 3 篇在主线环境建立后阅读；第 6 篇按词查阅；第 7—9 篇按操作系统选择，不必全部操作。
