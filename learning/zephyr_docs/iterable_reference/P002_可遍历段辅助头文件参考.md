## 2.2\_源码定位与版本边界

C侧辅助宏位于[sys/iterable_sections.h](../../../include/zephyr/sys/iterable_sections.h)，链接脚本侧定义位于[linker/iterable_sections.h](../../../include/zephyr/linker/iterable_sections.h)。本次核对[官方C侧头文件](https://github.com/zephyrproject-rtos/zephyr/blob/main/include/zephyr/sys/iterable_sections.h)与[官方链接器头文件](https://github.com/zephyrproject-rtos/zephyr/blob/main/include/zephyr/linker/iterable_sections.h)，摘要见[来源记录](../SOURCES.md)；本地源码、滚动更新的main和latest网页不能自动视为同一版本。

完整宏说明、参数和31段原始展开集中在[公共接口](P001_可遍历段公共接口.md)；本头文件参考页保留官方概览和摘要。设备注册对这些机制的使用可继续阅读[设备模型参考册](../device_reference/大纲.md)。

本批只做官方文档翻译与源码核对，没有编译或链接测试固件，也未执行运行时注册／遍历实验。
