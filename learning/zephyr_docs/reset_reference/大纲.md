# 复位控制器参考大纲

复位控制器（Reset Controller）通过特定复位线让外设进入或退出复位状态。本册完整收录官方公共接口、驱动后端、描述与操作结构，以及驱动／设备树两份头文件的参考和源码。

先区分控制器设备、复位线ID和状态返回，再阅读设备树的resets、reset-names与说明单元（Cell）。源码译注解释高低有效电平、可选回调、静态初始化器与就绪检查，以及普通节点和实例_OR宏的回退差异。原始C、设备树和YAML示例完整保留，发现的字段名、参数名和多余括号另作译注。

公共接口页仍包含官方各厂商编码主题链接；这些主题逐页独立跟踪，不因本册完成而宣布全部已译。所有本地定位使用相对路径，完整范围见[全站进度](../PROGRESS.md)。
