
原始示例（Example）：

```yaml
reset-cells:

```

使用示例：

原始示例（Example）：

```c
DT_RESET_CELL_BY_IDX(DT_NODELABEL(n), 0, id) // 10
```

此宏只适用于含有名为id的说明单元的复位控制器描述符。必要时查阅该节点的绑定进行确认。
