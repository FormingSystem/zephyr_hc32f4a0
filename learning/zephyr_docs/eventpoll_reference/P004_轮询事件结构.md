原文：[官方页面](https://docs.zephyrproject.org/latest/doxygen/html/structk__poll__event.html)。读取日期：2026-10-15；来源摘要见[来源记录](../SOURCES.md)。

> 译注——阅读位置：本册覆盖事件（Event）与轮询（Polling）接口、对象和字段。k_event保存32位事件集合；k_poll通过事件描述符观察受支持对象的就绪状态。两者的等待、消费与复位规则不同，原始声明和说明保留，源码对照另作明确译注。

## 4.2\_详细说明（Detailed Documentation）

### `[union]`

```c
union { ... } k_poll_event
```

各类型使用的数据。

> 译注——源码核对：这些指针共享同一联合体（Union）存储，表示同一个被轮询对象，不能同时表示多个对象。_typed_*别名供初始化宏检查指针类型，实际选择仍由type决定。


事件状态位域，由K_POLL_STATE_xxx值按位或组成。

> 译注——源码核对：内核以按位或记录通知。再次k_poll前由调用者恢复K_POLL_STATE_NOT_READY；清除此字段不会同时清除k_poll_signal.signaled。

<a id="a37c5f45deaa046b356d95af569220c70"></a>

### `tag`

```c
uint32_t k_poll_event::tag
```

可选的用户指定标签；API不解释也不修改它。

> 译注——源码核对：当前字段宽度为8位。动态k_poll_event_init不设置tag，需使用者赋值；API不解释这个标签。

<a id="a8f9e251aa8722eb4716f622e85be34ae"></a>

### `type`

```c
uint32_t k_poll_event::type
```

事件类型位域，由K_POLL_TYPE_xxx值按位或组成。

> 译注——源码核对：原文描述为可按位或的类型位域；当前poll.c按单一类型值分派，除相同值的别名外，不应任意组合不同对象类型。对象指针必须与选用类型一致。

<a id="a750ac48e7aa3c8fb70814b24e951fc85"></a>

### `unused`

```c
uint32_t k_poll_event::unused
```

32位字中未使用的位。

> 译注——源码核对：保留位，不应用来私藏协议状态；初始化宏与动态初始化都将其置0。

## 4.3\_源码定位与版本边界

> 译注——阅读与源码边界：轮询事件描述符连接type、对象指针和通知state；它不是被观察对象本身。结构内有隐藏注册节点，不能把同一实例同时交给并发轮询过程，或在轮询尚未结束时移动／改写它。为独立轮询过程准备各自有效的描述符与寿命管理。

仓库相对定位：[kernel.h](../../../include/zephyr/kernel.h)、[kernel/events.c](../../../kernel/events.c)与[kernel/poll.c](../../../kernel/poll.c)。本次依据为[官方内核头文件](https://github.com/zephyrproject-rtos/zephyr/blob/main/include/zephyr/kernel.h)、[官方事件实现](https://github.com/zephyrproject-rtos/zephyr/blob/main/kernel/events.c)及[官方轮询实现](https://github.com/zephyrproject-rtos/zephyr/blob/main/kernel/poll.c)，摘要见[来源记录](../SOURCES.md)。

仓库源码、滚动更新的main和latest网页不能自动视为同一版本。本批完成文档与源码核对，未构建或执行事件并发、轮询竞争、用户模式及实板实验。
