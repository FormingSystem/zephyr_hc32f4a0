## FANKE FK7B0M1-VBT6

<a id="overview"></a>

### 概述（Overview）

反客科技（FANKE Technology Co., Ltd.）的FK7B0M1-VBT6核心板基于STMicroelectronics STM32H7B0VBT6微控制器及其Arm Cortex-M7内核。该板功能丰富，支持复杂显示及触摸技术，适合开发高性能应用，尤其适用于人机界面（HMI / Human-Machine Interface）。

FK7B0M1-VBT6作为应用开发参考设计，用于向最终产品过渡前的开发，简化开发流程。它具备包括先进显示及触摸能力在内的多种硬件功能，尤其适合HMI应用，可全面评估和测试外设及相关功能。

### 硬件（Hardware）

FK7B0M1-VBT6提供以下硬件组件：


- LQFP100封装的STM32H7B6VB，型号按原文保留
- Arm 32位Cortex-M7 CPU，带浮点单元（FPU）
- CPU最高频率280 MHz
- VDD电压范围1.62–3.6 V
- 128 KB闪存（Flash）
- 最多约1.4 MB SRAM：1.18 Mbytes用户SRAM、64 Kbytes ITCM RAM、128 Kbytes DTCM RAM，以及备份域中的4 Kbytes SRAM。
- 主时钟：外部25 MHz晶体振荡器。
- 实时时钟（RTC）：32.768 kHz晶体振荡器。
- 2个32位定时器
- 12个16位定时器
- 1个复位按键、1个用户按键和1个BOOT启动按键
- 一个用户LED
- 外部64 Mbit QSPI NOR闪存W25Q64。
- 外部64 Mbit SPI NOR闪存W25Q64。
- 1路全速及高速USB OTG
- 1个microSD卡接口
- 1个RGB LCD接口
- 通过排针访问SWD和串口
- 引出39个I/O端口

STM32H7B0VB更多信息见：

<a id="default-zephyr-peripheral-mapping"></a>

##### Zephyr 默认外设映射（Peripheral Mapping）：

FK7B0M1-VBT6的配置如下：


- UART_1 TX/RX：PA9／PA10，可通过排针访问
- 用户LED（蓝色 / blue）：PC1
- 用户按键（PB）：PC13
- SPI1 NCS/CLK/MISO/MOSI：PA15／PB3／PB4／PB5，用于NOR闪存
- QuadSPI NCS/CLK/IO0/IO1/IO2/IO3：PB6／PB2／PD11／PD12／PE2／PD13，用于NOR闪存
- `USB DM/DP : PA11/PA12`

<a id="system-clock"></a>

#### 系统时钟（System Clock）

FK7B0M1-VBT6系统时钟可由内部或外部振荡器，以及主PLL时钟驱动。默认使用外部25 MHz晶体振荡器作为PLL输入，由PLL产生280 MHz系统时钟。

<a id="serial-port"></a>

#### 串口（Serial Port）

Zephyr控制台分配到UART1，默认通信设置为115200、8N1。

<a id="programming-and-debugging"></a>

### 烧录与调试（Programming and Debugging）

`fk7b0m1_vbt6`开发板配置的应用可按常规方式构建及烧录，详见构建应用及运行应用。（[构建应用（Building an Application）](../application/P001_应用开发.md#build-an-application)；[运行应用（Run an Application）](https://docs.zephyrproject.org/latest/develop/application/index.html#application-run)）

<a id="flashing"></a>

#### 烧录（Flashing）

FK7B0M1-VBT6不含板载调试器，编程和调试需要ST-Link等外部调试器。

开发板通过排针提供串行线调试接口（SWD / Serial Wire Debug）。

<a id="flashing-an-application-to-fk7b0m1-vbt6"></a>

##### 向FK7B0M1-VBT6烧录应用

首先通过SWD将ST-Link调试编程器连接到FK7B0M1-VBT6，再通过USB端口将ST-Link连接到主机。完成连接后，即可构建并烧录应用。

下面以[Hello World](../getting_started/P005_HelloWorld示例.md#hello_world)应用为例。

```text
# From the root of the zephyr repository
west build -b fk7b0m1_vbt6 samples/hello_world
west flash
```

运行主机串口程序连接开发板：

```text
$ minicom -D /dev/ttyACM0 -b 115200
```

随后按RESET键，应看到以下消息：

```text
Hello World! fk7b0m1_vbt6
```
