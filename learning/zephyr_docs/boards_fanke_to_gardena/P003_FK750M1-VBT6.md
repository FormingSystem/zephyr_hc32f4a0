## 概述（Overview）

反客科技（FANKE Technology Co., Ltd.）的FK750M1-VBT6核心板基于STMicroelectronics STM32H750VBT6微控制器及其Arm Cortex-M7内核。该板功能丰富，支持复杂显示及图像处理技术，适合开发高性能应用。

FK750M1-VBT6作为应用开发参考设计（Reference Design），用于向最终产品过渡前的开发，简化开发流程。它具备包括先进显示及图像处理能力在内的多种硬件功能，可全面评估和测试外设及相关功能。

<a id="hardware"></a>

## 硬件（Hardware）

FK750M1-VBT6提供以下硬件组件：


- LQFP100封装的STM32H750VB
- Arm 32位Cortex-M7 CPU，带浮点单元（FPU）
- CPU最高频率480 MHz
- 128 KB闪存（Flash）
- 1 MB SRAM：192 Kbytes紧耦合存储器（TCM RAM），包括64 Kbytes指令TCM（ITCM）和128 Kbytes数据TCM（DTCM）；864 Kbytes用户SRAM；备份域（Backup Domain）中4 Kbytes SRAM。数值按原文保留。
- 主时钟：外部25 MHz晶体振荡器。
- 实时时钟（RTC）：32.768 kHz晶体振荡器。
- 1个高分辨率定时器，最高分辨率2.1 ns
- 2个32位定时器
- 17个16位定时器
- 1个复位按键和1个BOOT启动按键
- 一个用户LED
- 外部64 Mbit QSPI NOR闪存W25Q64。
- 1路全速及高速USB OTG
- 1个microSD卡接口
- 1个数字摄像头接口（DCMI）
- 1个SPI LCD接口
- 通过排针访问SWD和串口
- 引出73个I/O端口

STM32H750VB更多信息见：

<a id="pin-mapping"></a>

### 引脚映射（Pin Mapping）

FK750M1-VBT6有5个GPIO控制器，负责引脚复用（Pin Muxing）、输入输出和上拉等功能。

<a id="default-zephyr-peripheral-mapping"></a>

#### Zephyr 默认外设映射（Peripheral Mapping）：

FK750M1-VBT6的配置如下：


- UART_1 TX/RX：PA9／PA10，可通过排针访问
- 用户LED（蓝色 / blue）：PC13
- SPI4 NCS/CLK/MOSI：PE11／PE12／PE14，用于SPI LCD
- QuadSPI NCS/CLK/IO0/IO1/IO2/IO3：PB6／PB2／PD11／PD12／PE2／PD13，用于NOR闪存
- `USB DM/DP : PA11/PA12`

<a id="system-clock"></a>

### 系统时钟（System Clock）

FK750M1-VBT6系统时钟可由内部或外部振荡器，以及主PLL时钟驱动。默认使用外部25 MHz晶体振荡器作为PLL输入，由PLL产生480 MHz系统时钟。

<a id="serial-port"></a>

### 串口（Serial Port）

Zephyr控制台分配到UART1，默认通信设置为115200、8N1。

<a id="flashing"></a>

### 烧录（Flashing）

FK750M1-VBT6不含板载调试器，编程和调试需要ST-Link等外部调试器。

开发板通过排针提供串行线调试接口（SWD / Serial Wire Debug）。

<a id="flashing-an-application-to-fk750m1-vbt6"></a>

#### 向FK750M1-VBT6烧录应用

首先通过SWD将ST-Link调试编程器连接到FK750M1-VBT6，再通过USB端口将ST-Link连接到主机。完成连接后，即可构建并烧录应用。

下面以[Hello World](../getting_started/P005_HelloWorld示例.md#hello_world)应用为例。

```text
# From the root of the zephyr repository
west build -b fk750m1_vbt6 samples/hello_world
west flash
```

运行主机串口程序连接开发板：

```text
$ minicom -D /dev/ttyACM0 -b 115200
```

随后按RESET键，应看到以下消息：

```text
Hello World! fk750m1_vbt6
```
