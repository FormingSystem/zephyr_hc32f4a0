## 概述（Overview）

FK723M1-ZGT6是一块用于STM32H723ZGT6片上系统（SoC）的开发板。

主要特性（Key Features）：


- LQFP144封装的STM32微控制器
- USB双角色接口（OTG）或全速设备（Full-Speed Device）
- 1个用户LED
- 1个启动与复位按键（Boot and Reset Push-Buttons，数量按原文表述）
- 15 MHz及32.768 kHz晶体振荡器

开发板连接器（Board Connectors）：


- USB-C接口的USB连接
- FPC10P LCD连接器
- FPC20P摄像头连接器
- 8针调试连接器

开发板更多信息见[FK723M1-ZGT6原理图（Schematic）](https://community.st.com/ysqtg83639/attachments/ysqtg83639/mcu-boards-hardware-tools-forum/20009/1/FK723M1-ZGT6.zh-CN.en.pdf)。

## 硬件（Hardware）

FK723M1-ZGT6提供以下硬件组件：


- LQFP144封装的STM32H723ZG
- Arm 32位Cortex-M7 CPU，带浮点单元（FPU）
- Chrom-ART图形加速器（Accelerator）
- 硬件JPEG编解码器（Codec）
- CPU最高频率550 MHz
- VDD电压范围1.62–3.6 V
- 1 MB闪存（Flash）
- 最多562 kB SRAM，目前使用376 kb；大小写单位按原文保留
- 高分辨率定时器（High-Resolution Timer），2.1 ns
- 2个32位定时器
- 12个16位定时器
- 6路SPI
- 4路I2C
- 3路I2S
- 4路USART
- 4路UART
- 1路全速USB OTG
- 2路CAN FD
- 2路串行音频接口（SAI）
- 4路SPDIF接收（SPDIF_Rx）
- 1路HDMI消费电子控制（HDMI_CEC）
- 1路双模式四线SPI（Dual Mode Quad SPI）
- 摄像头接口（Camera Interface）
- 最多114个GPIO，支持外部中断
- 3个16位ADC，36个通道，3.6 MSPS
- 2个12位DAC，每个2通道
- 真随机数发生器（RNG / True Random Number Generator）
- 16通道直接存储器访问（DMA）
- 支持XGA分辨率的LCD-TFT控制器

#### Zephyr 默认外设映射（Peripheral Mapping）：

FK723M1-ZGT6具有一个USB端口、两个30 × 2排针、一个4 × 2调试排针、一个microSD卡槽、一个FPC10P LCD接口、一个FPC20P摄像头接口，以及板载外部Quad SPI闪存。开发板配置如下：


- UART_1 TX/RX：PA9／PA10，位于调试排针的UART
- `LD1 : PG7`

<a id="system-clock"></a>

#### 系统时钟（System Clock）

FK723M1-ZGT6系统时钟可由内部或外部振荡器，以及主锁相环（PLL）时钟驱动。默认使用15 MHz高速外部时钟作为PLL输入，由PLL产生550 MHz系统时钟。

<a id="serial-port"></a>

#### 串口（Serial Port）

FK723M1-ZGT6有4路UART和4路USART。Zephyr控制台分配到UART1，默认设置为115200、8N1。

<a id="programming-and-debugging"></a>

## 烧录与调试（Programming and Debugging）

FK723M1-ZGT6提供专用SWD排针。

<a id="flashing"></a>

### 烧录（Flashing）

此板默认通过west的[STM32CubeProgrammer](https://www.st.com/en/development-tools/stm32cubeprog.html)运行器（Runner）烧录，因此需要安装该工具。（[installation](https://docs.zephyrproject.org/latest/develop/flash_debug/host-tools.html#stm32cubeprog-flash-host-tools)）

也可通过`--runner`（或`-r`）选项选择OpenOCD或JLink烧录：

```text
$ west flash --runner openocd
$ west flash --runner jlink
```

<a id="flashing-an-application-to-fk723m1-zgt6"></a>

#### 向FK723M1-ZGT6烧录应用

首先，将支持SWD的调试器连接到FK723M1-ZGT6调试排针；然后将调试器连接到主机，为烧录准备开发板；最后构建并烧录应用。

以下以[Blinky](../getting_started/P004_LED闪烁示例.md#blinky)应用为例。

可选：将USB转串口适配器接到RX和TX，注意交叉连接。

```text
$ minicom -b 115200 -D /dev/ttyACM0
```

或使用`screen`：

```text
$ screen /dev/ttyACM0 115200
```

构建并烧录应用：

```text
# From the root of the zephyr repository
west build -b fk723m1_zgt6 samples/basic/blinky
west flash
```

控制台应反复显示以下消息：

```text
$ LED state: ON
$ LED state: OFF
```

也可使用Hello World示例：

```text
# From the root of the zephyr repository
west build -b fk723m1_zgt6 samples/hello_world
west flash
```

<a id="debugging"></a>

### 调试（Debugging）

可以按常规方式调试应用。下面以[Hello World](../getting_started/P005_HelloWorld示例.md#hello_world)应用为例。

```text
# From the root of the zephyr repository
west build -b fk723m1_zgt6 samples/hello_world
west debug
```
