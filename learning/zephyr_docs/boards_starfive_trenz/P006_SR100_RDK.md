## 概述（Overview）

Synaptics Astra SR100系列AI微控制器旨在为消费、企业及工业物联网提供高性能、原生AI多模态计算。


- Astra Machina Micro SR100评估平台包含：


  - Synaptics SR110音频及视觉AI处理器，122-FCCSP封装
  - Synaptics SR100调试芯片，84-WCCSP封装
  - 存储：128 Mbit QSPI NOR闪存
  - 电源管理：用于SR100 VBAT的升降压直流转换器（Buck-Boost DC/DC）
  - 高灵敏度环境光传感器TCS34303
  - 三轴加速度计MC3479
  - M.2 E-key 2230插座，通过SDIO、UART及PCM连接Wi-Fi／Bluetooth模块
  - 两个USB 2.0 Type-C端口，用于高速外设模式及系统供电
  - 系统复位及唤醒按键
  - 用于镜像编程、静音控制及调试的滑动开关
  - 多个LED，其中两个可由用户控制
- 子卡接口选项：


  - 两个双通道MIPI CSI-2接收接口，最高1.5 Gbit/s带宽；CSI0位于Samtec连接器，与DVP共用，CSI1位于15引脚FPC连接器
  - 一个MIPI CSI-2发送接口，最高1.5 Gbit/s，15引脚FPC连接器
  - 用于调试的SWD／JTAG子卡
  - 两个20引脚GPIO排针，用于附加应用
  - 4引脚UART调试排针
  - 3引脚被动红外（PIR）排针
- 系统电源：


  - USB Type-C 接口（USB Type-C）
  - 2引脚、2.0 mm间距排针，用于单节锂离子电池
  - 3引脚系统电源来源选择排针

### 构建（Building）

通过标准Zephyr命令构建，以下以[Hello World](../getting_started/P005_HelloWorld示例.md#hello_world)为例。

```text
# From the root of the zephyr repository
west build -b sr100_rdk samples/hello_world
```

<a id="flashing"></a>

### 烧录（Flashing）

通过USB-C连接主机，用lsusb确认可看到CMSIS-DAP端点：

```text
$ lsusb | grep CMSIS-DAP
Bus 001 Device 058: ID cafe:4006 Synaptics, Inc SR100 CMSIS-DAP
```

随后运行west debugserver。

```text
# From the root of the zephyr repository
west build -b sr100_rdk samples/hello_world
west debugserver
```

在另一终端运行Synaptics提供的烧录脚本：

```text
python openocd_flash.py build/zephyr/zephyr.bin 0x0 0x0 1
```
