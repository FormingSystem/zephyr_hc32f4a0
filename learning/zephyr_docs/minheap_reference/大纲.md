# 最小堆参考大纲

最小堆（Min-heap）把比较器定义的最小元素保存在根节点，用于优先队列等排序需求。值堆（Value Min-heap）复制元素到数组；引用堆（Reference Min-heap）保存调用者对象中嵌入的句柄指针。先读[最小堆指南](../kernel/P055_最小堆.md)，再按两种实现分别查声明、结构和源码。

本册保留原页声明、宏展开、示例、参数、返回说明及源码中的法律注释。单独标注的源码译注说明复制与所有权、当前下标与句柄位置、满容量返回值、索引范围和成员资格前提。它与[内存分配堆](../lowheap_reference/大纲.md)属于不同用途；所有本地定位采用相对路径，完整范围见[全站进度](../PROGRESS.md)。
