最小堆（Min-heap）实现。

<a id="details"></a>

最小堆实现。最小堆是基于二叉树的数据结构，最小元素始终位于根节点。它支持以O(log n)时间高效插入元素和移除最小元素。

## 1.6\_详细说明（Detailed Documentation）

<a id="ga2363fb8ce4cd36e21ae5100e62d450c4"></a>

### `MIN_HEAP_DEFINE`

```c
#define MIN_HEAP_DEFINE ( name, cap, elem_sz, align, cmp_func )
```

```c
#include <zephyr/sys/min_heap.h>
```

展开值（Value）：

```c
static uint8_t name##_storage[(cap) * (elem_sz)] __aligned(align);                         \
struct min_heap name = {.storage = name##_storage,                                         \
                        .capacity = (cap),                                                 \
                        .elem_size = (elem_sz),                                            \
                        .size = 0,                                                         \
                        .cmp = (cmp_func)}
```

定义最小堆实例。

**参数（Parameters）**

| 名称／方向 | 说明 |
| --- | --- |
| `name` | 堆实例的基础名称。 |
| `cap` | 容量，以元素个数表示。 |
| `elem_sz` | 每个元素的字节大小。 |
| `align` | 每个元素所需的对齐（Alignment）。 |
| `cmp_func` | 堆使用的比较器函数。 |

> 译注——源码核对：底层name_storage始终是static字节数组；DEFINE_STATIC还让堆结构对象具有static存储期／链接属性。两种宏都不动态分配元素。

<a id="gab4b10202a0a9f63608061b2ce35d902c"></a>

### `MIN_HEAP_DEFINE_STATIC`

```c
#define MIN_HEAP_DEFINE_STATIC ( name, cap, elem_sz, align, cmp_func )
```

```c
#include <zephyr/sys/min_heap.h>
```

展开值（Value）：

```c
static uint8_t name##_storage[(cap) * (elem_sz)] __aligned(align); \
static struct min_heap name = { \
                .storage = name##_storage, \
                .capacity = (cap), \
                .elem_size = (elem_sz), \
                .size = 0, \
                .cmp = (cmp_func) \
}
```

定义静态分配且满足对齐要求的最小堆实例。

**参数（Parameters）**

| 名称／方向 | 说明 |
| --- | --- |
| `name` | 堆实例的基础名称。 |
| `cap` | 容量，以元素个数表示。 |
| `elem_sz` | 每个元素的字节大小。 |
| `align` | 每个元素所需的对齐（Alignment）。 |
| `cmp_func` | 堆使用的比较器函数。 |

> 译注——源码核对：对齐（Alignment）：定义宏只对底层字节数组的起始地址施加align，元素步长仍为elem_sz，不自动向上补齐。调用者应保证步长、对齐及cap乘elem_sz均有效；指针成员按字节浅拷贝（Shallow Copy），指向的外部对象不会被复制或释放。

### `MIN_HEAP_FOREACH`

```c
#define MIN_HEAP_FOREACH ( heap, node_var )
```

```c
#include <zephyr/sys/min_heap.h>
```

展开值（Value）：

```c
for (size_t _i = 0;                                                                        \
     _i < (heap)->size && (((node_var) = min_heap_get_element((heap), _i)) || true); ++_i)
```

遍历堆中的每个节点。

示例：

原始示例（Example）：

```c
void *node;
MIN_HEAP_FOREACH(&heap, node) {
     printk("Value: %d\n", node->value);
}
```

**参数（Parameters）**

| 名称／方向 | 说明 |
| --- | --- |
| `heap` | 指向堆的指针。 |
| `node_var` | 用于引用每个节点的循环变量。 |

> 译注——源码核对：按数组下标遍历，不是排序输出。原示例声明void *node后直接访问node->value，在标准C中缺少具体结构类型转换；示例原样保留，使用时应按实际元素类型转换后再访问成员。

<a id="ga638b9c8b6023ec281b1adcb9ca6ba814"></a>

### `min_heap_cmp_t`

```c
typedef int(* min_heap_cmp_t) (const void *a, const void *b)
```

```c
#include <zephyr/sys/min_heap.h>
```

用于确定最小堆顺序的比较器函数类型。

此函数比较两个堆节点，以确定它们的相对顺序。用户必须实现该函数，并在最小堆初始化时提供它。

**参数（Parameters）**

| 名称／方向 | 说明 |
| --- | --- |
| `a` | 用于比较的第一个用户定义数据指针。 |
| `b` | 用于比较的第二个用户定义数据指针。 |

**返回（Returns）**：a小于b时返回负值，a大于b时返回正值，相等时返回0。

> 译注——源码核对：返回值是三路比较关系，不是布尔谓词。若键是无符号数或可能很大，不应未经溢出分析就用a-b实现比较。

### `min_heap_find()`

```c
void * min_heap_find ( struct min_heap * heap, min_heap_eq_t eq, const void * other, size_t * out_id )
```

```c
#include <zephyr/sys/min_heap.h>
```

在堆中查找符合条件的节点。

**参数（Parameters）**

| 名称／方向 | 说明 |
| --- | --- |
| `heap` | 指向堆结构的指针。 |
| `eq` | 用于将各节点与查找目标进行比较的函数。 |
| `other` | 传给eq函数进行比较的数据指针。 |
| `out_id` | 可选输出参数，用于保存找到节点的下标。 |

**返回（Returns）**：指向第一个匹配元素的指针；未找到时返回NULL。

> 译注——源码核对：按内部数组顺序逐项调用eq，最坏O(n)；首个匹配才写可选out_id，未找到时返回NULL并保留out_id原值。所得下标是当前的位置，后续重排会使其失去原有对象含义。

### `min_heap_init()`

```c
void min_heap_init ( struct min_heap * heap, void * storage, size_t cap, size_t elem_size, min_heap_cmp_t cmp )
```

```c
#include <zephyr/sys/min_heap.h>
```

在运行时初始化最小堆实例。

使用用户提供的内存区域、容量和比较器函数建立最小堆内部结构。如果堆未通过静态定义建立，使用前必须调用此函数。

**参数（Parameters）**

| 名称／方向 | 说明 |
| --- | --- |
| `heap` | 指向最小堆结构的指针。 |
| `storage` | 指向用于存储元素的内存区域。 |
| `cap` | 堆可存储的最大元素数量。 |
| `elem_size` | 每个元素的字节大小。 |
| `cmp` | 用于确定堆元素顺序的比较器函数。 |

**说明（Note）**：所有参数都必须有效。此函数不分配内存。

> 译注——源码核对：存储与配置：值堆的非内联函数实现于lib/min_heap/min_heap.c，由CONFIG_MIN_HEAP控制对应子目录编译。init只保存指针、容量、元素尺寸及比较器并将size置0，不分配、清除或释放元素，也不验证参数；存储区必须持续有效且足以容纳capacity个元素。

### `min_heap_pop()`

```c
bool min_heap_pop ( struct min_heap * heap, void * out_buf )
```

```c
#include <zephyr/sys/min_heap.h>
```

移除并返回堆中优先级最高的元素。

调用者取得返回元素的所有权，并负责后续内存管理或复用。移除后会重新调整最小堆，以保持正确顺序。

**参数（Parameters）**

| 名称／方向 | 说明 |
| --- | --- |
| `heap` | 指向堆的指针。 |
| `out_buf` | 用户提供的缓冲区，被移除元素将复制到这里。 |

**返回（Returns）**：成功时返回true，否则返回false。

> 译注——源码核对：当前直接调用min_heap_remove(heap, 0, out_buf)；空堆返回false且不写输出，成功复制根元素到调用者缓冲区。不存在返回堆内存指针或释放元素的动作。

<a id="ga4cb5ee2bf40ab6f1ba557f8fa3927ba3"></a>

### `min_heap_push()`

```c
int min_heap_push ( struct min_heap * heap, const void * item )
```

```c
#include <zephyr/sys/min_heap.h>
```

向最小堆插入元素（Push）。

向最小堆添加新元素，并在必要时将其向上移动，以恢复堆顺序。若最小堆已达到容量上限，插入操作失败。

**参数（Parameters）**

| 名称／方向 | 说明 |
| --- | --- |
| `heap` | 指向最小堆的指针。 |
| `item` | 指向待插入数据项的指针。 |

**返回（Returns）**：成功时返回0；堆已满时返回-ENOMEM。

> 译注——源码核对：满容量返回-ENOMEM，表示预先提供的存储已无槽位，并非本函数申请动态内存失败。成功路径复制elem_size字节、向上调整后再增加size。

<a id="gab65afad260840bff650977b137404c7c"></a>

### `min_heap_remove()`

```c
bool min_heap_remove ( struct min_heap * heap, size_t id, void * out_buf )
```

```c
#include <zephyr/sys/min_heap.h>
```

从最小堆中移除指定元素。

根据元素在内部保存的ID，从最小堆中移除指定节点。移除后会重新调整最小堆，以保持正确顺序。调用者取得返回元素的所有权，并负责后续内存管理或复用。

**参数（Parameters）**

| 名称／方向 | 说明 |
| --- | --- |
| `heap` | 指向最小堆的指针。 |
| `id` | 待移除元素的ID。 |
| `out_buf` | 用户提供的缓冲区，被移除元素将复制到这里。 |

**返回（Returns）**：成功时返回true，否则返回false。

> 译注——源码核对：原文称“内部保存的ID”，当前实现实际把id直接当作从0开始的数组下标，没有永久对象ID。id>=size返回false且不写out_buf；成功先复制输出，再以末元素填空并重排。重排后旧下标不能继续代表同一元素。原文所有权描述应结合复制到调用者缓冲区理解，不应释放内部地址。

配置依据：[库构建入口](../../../lib/CMakeLists.txt)、[最小堆构建规则](../../../lib/min_heap/CMakeLists.txt)与[Kconfig定义](../../../lib/min_heap/Kconfig)。本次说明依据[官方值堆实现](https://github.com/zephyrproject-rtos/zephyr/blob/main/lib/min_heap/min_heap.c)、[官方引用堆头文件](https://github.com/zephyrproject-rtos/zephyr/blob/main/include/zephyr/sys/min_heap_ref.h)及[官方构建入口](https://github.com/zephyrproject-rtos/zephyr/blob/main/lib/CMakeLists.txt)，摘要见[来源记录](../SOURCES.md)。

> 译注——源码核对：数据结构与顺序：这里的最小堆（Min-heap）用于排序和优先队列，不是动态内存分配器。比较器（Comparator）返回负数、零、正数表达小于、等于、大于；最高优先级对应比较关系下的最小元素。相等键的先入先出顺序不受保证，内部数组也不是全局排序结果。

> 译注——源码核对：同步与生命周期：两种实现均不自行加锁或等待，不发送通知。调用者应保护并发访问和对象生命周期；遍历期间修改堆可能改变数组位置及size，不能按原顺序继续访问或删除。直接修改影响比较结果的键也可能破坏堆性质。

> 译注——源码核对：接口边界：值堆复制elem_size字节，使用从0开始的当前数组下标删除；引用堆保存调用者对象的句柄指针，句柄idx从1开始，0表示未入堆。两者的容量、删除参数、返回值和所有权说明不能互换。

> 译注——源码核对：存储与配置：值堆的非内联函数实现于lib/min_heap/min_heap.c，由CONFIG_MIN_HEAP控制对应子目录编译。init只保存指针、容量、元素尺寸及比较器并将size置0，不分配、清除或释放元素，也不验证参数；存储区必须持续有效且足以容纳capacity个元素。

> 译注——源码核对：对齐（Alignment）：定义宏只对底层字节数组的起始地址施加align，元素步长仍为elem_sz，不自动向上补齐。调用者应保证步长、对齐及cap乘elem_sz均有效；指针成员按字节浅拷贝（Shallow Copy），指向的外部对象不会被复制或释放。

> 译注——源码核对：观察与删除：peek、find和get_element返回内部存储位置，后续插入、删除或重排可能改变该位置代表的元素。remove／pop把值复制到有效out_buf，不分配返回对象，不把内部缓冲区交给调用者释放；缓冲区须足够大并避免与内部存储重叠。

本次验证范围为文档与源码对照，未构建或运行最小堆及实板实验。
