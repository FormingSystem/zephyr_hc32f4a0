# 设备树分区参考大纲

本册完整翻译设备树分区API及三个头文件的参考页、源码浏览页，涵盖固定分区（Fixed Partition）、固定子分区（Fixed Subpartition）和映射分区（Mapped Partition）。先确认节点结构，再区分分区ID、存储器偏移（Offset）、CPU地址和所属存储技术设备（Memory Technology Device，MTD）。

原始声明、C与设备树示例、可见源码和许可证完整保留；译注解释label查找、祖先层级、ranges翻译、通用接口对子分区的处理边界，并指出原例缺项和映射范围差异。源码定位采用相对链接，完整范围见[全站进度](../PROGRESS.md)。
