# 架构基础接口参考大纲

本册翻译架构接口（Architecture Interface）总览，以及缓存、内存映射、用户空间、对称多处理、电源管理、线程局部存储和杂项接口，共八份官方参考页面。总览保留各主题入口，各专题保留全部摘要、详细说明、参数、返回值、原始宏展开与交叉引用。

这些接口描述通用内核与架构实现之间的约定。缓存写回与失效、虚拟映射与存储分配、CPU启动与线程创建、用户内存权限与对象授权各有不同条件。本册逐项保留调用上下文、对齐要求、配置条件和失败语义，不能据接口存在推断目标芯片支持全部能力。

源码跟踪译注独立标示Cortex-M空闲与用户模式入口、ARM线程局部存储、通用页帧管理和SMP启动握手等细节，以及原文与当前源码的名称差异。源码与已译页面使用相对链接；其余主题仍在[全站进度](../PROGRESS.md)中按实际状态跟踪。
