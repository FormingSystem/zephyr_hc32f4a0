# 第1章\_架构接口总览

原文：[官方页面](https://docs.zephyrproject.org/latest/doxygen/html/group__arch-interface.html)。读取日期：2026-10-15；来源摘要见[来源记录](../SOURCES.md)。

> 译注——阅读位置：从[本册大纲](大纲.md)进入架构缓存、内存映射、用户空间、多处理器、电源管理、线程局部存储与杂项接口参考，再通过接口链接进入完整说明。源码跟踪译注与官方原文分开标示。

具有公共可见范围的内核内部 API（Internal Kernel APIs with Public Scope）。

<a id="details"></a>

具有公共可见范围的内核内部 API。若公共内核 API 以内联函数实现，且需要调用架构专有 API，相应架构 API 的原型就在此声明；不以这种方式使用的架构 API 位于 `kernel/include/kernel_arch_interface.h`。公共头文件中的宏和内联函数内部使用的架构 API 也在此规定并记录。这里描述的所有宏和内联函数原型，最终都必须通过 `<arch/cpu.h>` 引入完整定义，即宏定义和内联函数体。`include/zephyr/kernel.h` 及其他公共头文件依赖此头文件中的定义。

## 1.2\_源码定位与版本边界

源码定位：[include/zephyr/arch/arch_interface.h](../../../include/zephyr/arch/arch_interface.h)、[kernel/include/kernel_arch_interface.h](../../../kernel/include/kernel_arch_interface.h)。官方源码摘要见[来源记录](../SOURCES.md)。

> 译注——源码核对：以下源码跟踪译注独立于官方正文，依据来源记录中保存摘要的官方main文件。仓库内源码采用相对链接，架构实现举例不表示全部架构都具有相同硬件能力，也不表示已在目标板执行验证。

> 译注——源码核对：架构接口（Architecture Interface）连接通用内核与处理器相关实现。应用通常通过内核或驱动的公共接口使用这些能力；不能仅凭arch_函数在参考页中出现，就假定任意配置都提供相同实现或适合应用直接调用。

> 译注——源码核对：本页是官方架构接口的主题索引，不是全部主题的合并正文。已翻译主题链接到本地译文，其余仍链接官方原页，并在全站清单中保留待译状态。

本次验证范围为文档与源码对照，未构建固件、配置实板引脚或操作硬件。
