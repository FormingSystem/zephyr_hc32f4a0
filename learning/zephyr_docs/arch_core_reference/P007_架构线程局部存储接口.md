## 7.2\_详细说明（Detailed Documentation）

<a id="ga7f159caca46063b04cf03a54b39255fc"></a>

### `arch_tls_stack_setup()`

```c
size_t arch_tls_stack_setup ( struct k_thread * new_thread, char * stack_ptr )
```

```c
#include <kernel_arch_interface.h>
```

在线程栈中建立架构专有的线程局部存储（Thread-local Storage，TLS）区域。

建立用于线程局部存储的栈区域；TLS 区域内部结构由架构决定。

**参数（Parameters）**

| 名称／方向 | 说明 |
| --- | --- |
| `new_thread` | 新线程对象。 |
| `stack_ptr` | 栈指针。 |

返回（Returns）：TLS 区域占用的字节数。

## 7.3\_源码定位与版本边界

源码定位：[include/zephyr/arch/arch_interface.h](../../../include/zephyr/arch/arch_interface.h)、[arch/arm/core/tls.c](../../../arch/arm/core/tls.c)。官方源码摘要见[来源记录](../SOURCES.md)。

> 译注——源码核对：以下源码跟踪译注独立于官方正文，依据来源记录中保存摘要的官方main文件。仓库内源码采用相对链接，架构实现举例不表示全部架构都具有相同硬件能力，也不表示已在目标板执行验证。

> 译注——源码核对：线程局部存储（Thread Local Storage，TLS）在这里指每个线程的数据区域，不是传输层安全协议（Transport Layer Security）。其布局由架构、工具链和配置共同决定。

> 译注——源码核对：当前ARM实现在传入栈指针下方放置TLS数据／BSS，通过z_tls_copy初始化；非IAR工具链另预留两个指针宽度，CONFIG_MULTITHREADING下记录new_thread->tls，返回总占用字节数。这个实现细节不是所有架构通用的固定偏移公式。
