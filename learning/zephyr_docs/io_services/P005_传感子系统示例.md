# 第5章\_传感子系统示例

原文：[官方页面](https://docs.zephyrproject.org/latest/samples/subsys/sensing/simple/README.html)。读取日期：2026-10-14；保存的latest页面及HTML摘要见[来源记录](../SOURCES.md)。

<a id="overview"></a>

## 5.1 概述（Overview）

这是一个简单示例，展示如何通过传感子系统API（Sensing Subsystem APIs）使用传感器。它定义两个传感器，底层设备使用BMI160仿真器（Emulator），并按规定的时间间隔获取传感器数据。

程序按以下顺序运行：

1. 在设备树源文件（Devicetree Source，DTS）中定义传感器。
2. 打开传感器。
3. 注册回调函数（Callback）。
4. 设置采样间隔（Sample Interval）。
5. 持续运行并获取传感器数据。

> 译注——回调和采样配置：当前源码在调用`sensing_open_sensor()`时传入回调列表，实际并非先打开后再独立注册回调。应用选取三轴加速度计及铰链角度传感器句柄，把加速度计间隔设为100毫秒，把铰链角度间隔设为该传感器的`minimal_interval`，随后设置并读取灵敏度配置。数据由回调处理；`main()`返回不表示后台传感服务停止。原文步骤表达整体流程，具体调用顺序应以相应版本源码为准。

<a id="building-and-running"></a>

## 5.2 构建与运行（Building and Running）

可以按以下方式在[native_sim模拟目标](../native_reference/P004_Native_Simulator本机模拟器.md#native_sim)上构建并执行本应用：

> 译注——命令前提：在已准备Zephyr及native_sim构建依赖的Linux Bash环境中，以Zephyr源码根目录执行。构建成功后再运行；构建失败时先处理依赖或配置问题。当前源码会打印传感器信息并在数据回调中记录样本，但本文未运行模拟器，不提供自行生成的实验日志。

```sh
west build -b native_sim samples/subsys/sensing/simple
west build -t run
```

若要为其他开发板构建，将上面的[`native_sim`](../native_reference/P004_Native_Simulator本机模拟器.md#native_sim)替换为该板名称。目前阶段仅支持native sim。

> 译注——支持范围：原文的两句话均予保留。当前`tests.yaml`的`platform_allow`只包含[`native_sim`](../native_reference/P004_Native_Simulator本机模拟器.md#native_sim)，且仿真设备由相应板覆盖文件提供；因此不能把“替换板名称”理解为实板无需其他适配便可运行。
