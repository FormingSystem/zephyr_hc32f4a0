# 设备树总览与电池及SRAM参考大纲

本册翻译设备树（Devicetree）API总览、默认电池开路电压曲线（Open-Circuit Voltage，OCV）以及选定静态随机存取存储器（Chosen SRAM）的接口、头文件参考和源码浏览页。总览保留全部41个官方主题；子主题是否已完成仍以[全站进度](../PROGRESS.md)为准。
