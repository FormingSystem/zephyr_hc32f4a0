## 2.2\_默认电池开路电压曲线（Default Battery OCV Curves）

不同电池化学体系（Battery Chemistries）的默认开路电压曲线（Open-Circuit Voltage，OCV）。

以下开路电压曲线提取自所列电池型号的数据手册（Datasheets）。它们无法完全准确地描述同一化学体系的所有电池，但可以提供一个较好的基准。环境温度（Ambient Temperature）和放电电流（Discharge Current）也会影响这些曲线。

每条曲线包含 11 个元素，依次表示电量从 0% 到 100%（包含两端）、以 10% 为步长时的开路电压值，单位为微伏（Microvolts，µV）。

这些曲线通常用于在设备树（Devicetree）中描述电池特性。

原始示例（Example）：

```dts
#include <zephyr/dt-bindings/battery/battery.h>

fuel_gauge: fuel_gauge {
        compatible = "zephyr,fuel-gauge-composite";
        source-primary = <&vbatt>;
        device-chemistry = "lithium-ion-polymer";
        ocv-capacity-table-0 = <BATTERY_OCV_CURVE_LITHIUM_ION_POLYMER_DEFAULT>;
        charge-full-design-microamp-hours = <1350000>;
};
```

## 2.4\_源码定位与版本边界

相对源码定位：[电池曲线常量](../../../include/zephyr/dt-bindings/battery/battery.h)、[电池查表接口](../../../include/zephyr/drivers/sensor/battery.h)、[组合电量计驱动](../../../drivers/fuel_gauge/composite/fuel_gauge_composite.c)、[电池绑定](../../../dts/bindings/battery/battery.yaml)、[组合电量计绑定](../../../dts/bindings/fuel-gauge/zephyr,fuel-gauge-composite.yaml)、[选定SRAM宏](../../../include/zephyr/devicetree/sram.h)和[架构配置](../../../arch/Kconfig)。本次官方文件摘要见[来源记录](../SOURCES.md)。

> 译注——源码核对：数据形态与单位：这些宏展开为11个以空白分隔的设备树单元（Cells），不是带逗号的C数组初始化器。ocv-capacity-table-0在battery.yaml中规定为11个微伏值，索引0至10对应0%、10%直至100%；示例charge-full-design-microamp-hours的1350000是设计容量，单位为微安时（µAh），即1350毫安时（mAh），不是电压。

> 译注——源码核对：消费路径：drivers/sensor/battery.h中的BATTERY_OCV_TABLE_DT_GET将设备树数组转为C初始化器，battery_soc_lookup以电压查表得到千分之一百分比（MilliPercent，100000表示100%）。组合电量计（Composite Fuel Gauge）优先读取传感器的荷电状态（State of Charge，SoC）通道，通道不支持时才尝试用电压和OCV表估算，并把查表结果除以1000转为百分比；仅写入曲线不会触发测量或证明估算准确。

> 译注——源码核对：示例前提：source-primary必须指向实现传感器API的设备；片段里的vbatt节点需要在完整设备树中提供。device-chemistry描述化学体系，ocv-capacity-table-0提供实际曲线；选择化学名称不会自动为此驱动填入曲线。没有曲线时，组合驱动不能利用该表估算电量，仍可能从设备支持的荷电状态通道直接读取。

> 译注——源码核对：原始数据保留：LITHIUM_MANGANESE曲线的80%和90%位置分别为2962000和2960000微伏，出现下降；此处逐值保留官方宏，不擅自排序、平滑或替换。原文的化学名称与所引电池型号也按原样标示。本册未验证这些默认数据对某一实际电池的适用性，不能把默认曲线视为该电池的实测标定结果。

> 译注——源码核对：版本边界：本批记录七份官方源码／绑定的读取摘要；两个源码浏览页的非注释代码与本次读取的对应原始头文件一致。latest和main会滚动变化，本仓库参照源码与它们不自动视为相同版本；本次未编译示例、构建固件或执行硬件实验。

本次验证范围为文档与源码对照，未编译宏／DTS示例、构建固件或操作硬件。
