## 3.3\_详细说明（Detailed Documentation）

<a id="ga60bc92eee58fcc5f121b8e4d82eaa69e"></a>

### `K_MEM_SLAB_DEFINE`

```c
#define K_MEM_SLAB_DEFINE ( name, slab_block_size, slab_num_blocks, slab_align )
```

```c
#include <zephyr/kernel.h>
```

展开值（Value）：

```c
K_MEM_SLAB_DEFINE_IN_SECT(name, __noinit_named(k_mem_slab_buf_##name), slab_block_size,    \
                          slab_num_blocks, slab_align)
```

以公开（非static）作用域静态定义并初始化固定块内存池。

固定块内存池的缓冲区包含slab_num_blocks个内存块，每块长slab_block_size字节。缓冲区按slab_align字节边界对齐。为了让每个块都保持同样的对齐，slab_block_size也必须是slab_align的整数倍。

可使用以下声明，在定义固定块内存池的模块之外访问它：

原始示例（Example）：

```c
extern struct k_mem_slab <name>;
```

**参数（Parameters）**

| 名称／方向 | 说明 |
| --- | --- |
| `name` | 固定块内存池名称。 |
| `slab_block_size` | 每个内存块的大小，以字节为单位。 |
| `slab_num_blocks` | 内存块数量。 |
| `slab_align` | 固定块内存池缓冲区的对齐值，必须是2的幂。 |

**说明（Note）**：此宏不能与static关键字一起使用。如需这种用法，请改用K_MEM_SLAB_DEFINE_STATIC。

> 译注——源码核对：当前宏最终用WB_UP把块大小及缓冲区对齐向上补齐到sizeof(void *)的整数倍，实际物理块可能大于传入值。原文长度描述保留；估算内存占用和统计量时须采用实际补齐值。extern示例中的<name>是变量名占位符。

### `k_mem_slab_alloc()`

```c
int k_mem_slab_alloc ( struct k_mem_slab * slab, void ** mem, k_timeout_t timeout )
```

声明属性：`isr-ok`（允许从中断服务程序ISR调用）。

```c
#include <zephyr/kernel.h>
```

从固定块内存池分配内存。

本例程从固定块内存池分配一个内存块。

**参数（Parameters）**

| 名称／方向 | 说明 |
| --- | --- |
| `slab` | 固定块内存池的地址。 |
| `mem` | 指向用于保存块地址的存储位置的指针。 |
| `timeout` | 等待操作完成的时间。K_NO_WAIT表示不等待，K_FOREVER表示按需要一直等待。 |

**返回值（Return Values）**

| 名称／方向 | 说明 |
| --- | --- |
| `0` | 内存已分配。mem指向的块地址存储位置被设置为该内存块的起始地址。 |
| `-ENOMEM` | 未等待即返回。 |
| `-EAGAIN` | 等待超时。 |

**说明（Note）**：从中断服务程序（Interrupt Service Routine，ISR）调用时，timeout必须设为K_NO_WAIT。CONFIG_MULTITHREADING=n时，任何timeout都按K_NO_WAIT处理。

> 译注——源码核对：成功返回0后，*mem才是取得的完整块。当前无空闲块且不等待时将*mem置NULL并返回-ENOMEM；等待超时分支却不重新写入*mem，不能假定失败总会清空旧指针。分配不清零数据，空闲链表曾使用块头保存链接。ISR只可K_NO_WAIT，关闭多线程时也不等待。

```c
#include <zephyr/kernel.h>
```

初始化固定块内存池。

在固定块内存池首次使用之前初始化它。

固定块内存池的缓冲区包含slab_num_blocks个内存块，每块长slab_block_size字节。缓冲区必须按满足机器字边界的N字节边界对齐；N是2的幂，例如32位系统上的4字节，也可以是8、16字节等。为使每个内存块都保持相同对齐，slab_block_size也必须是N的整数倍。

**参数（Parameters）**

| 名称／方向 | 说明 |
| --- | --- |
| `slab` | 固定块内存池的地址。 |
| `buffer` | 用于内存块的缓冲区指针。 |
| `block_size` | 每个内存块的大小，以字节为单位。 |
| `num_blocks` | 内存块数量。 |

**返回值（Return Values）**

| 名称／方向 | 说明 |
| --- | --- |
| `0` | 成功。 |
| `-EINVAL` | 提供的数据无效。 |

> 译注——源码核对：当前空闲链表把指针写入每个空闲块的开头，因此块大小和缓冲区地址必须满足指针字边界。零块大小及对齐检查使用CHECKIF，默认返回-EINVAL，断言模式或省略检查模式的行为不同；乘法和地址加法溢出另作显式检查。调用者仍需提供足够且有效的存储，初始化失败后不能继续分配；运行时初始化不会像定义宏那样替调用者补齐块大小。
