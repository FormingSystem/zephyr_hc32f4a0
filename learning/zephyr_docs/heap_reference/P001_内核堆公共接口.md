## 1.4\_详细说明（Detailed Documentation）

<a id="ga795d7f1e6d5b7b19a7a50198d7829a0f"></a>

### `K_HEAP_DEFINE`

```c
#define K_HEAP_DEFINE ( name, bytes )
```

```c
#include <zephyr/kernel.h>
```

展开值（Value）：

```c
Z_HEAP_DEFINE_IN_SECT(name, bytes,                      \
                      __noinit_named(kheap_buf_##name))
```

定义一个静态k_heap。

此宏按请求大小定义并初始化一块静态内存区域及一个k_heap。内核启动后，可以使用&name，其效果相当于已经调用k_heap_init()。

此宏会强制内存区域满足容纳元数据（Metadata）所需的最小大小；非常小的堆会被补足到该大小。

**参数（Parameters）**

| 名称／方向 | 说明 |
| --- | --- |
| `name` | struct k_heap对象的符号名称。 |
| `bytes` | 内存区域大小，以字节为单位。 |

> 译注——源码核对：bytes描述后备内存区域大小，不等于可分配给应用的净容量。当前宏以MAX(bytes, Z_HEAP_MIN_SIZE)保留区域，并在内核启动阶段调用k_heap_init完成底层管理结构初始化；元数据和对齐会占用空间。

### `k_aligned_alloc()`

```c
void * k_aligned_alloc ( size_t align, size_t size )
```

```c
#include <zephyr/kernel.h>
```

从堆分配具有指定对齐要求的内存。

本例程提供与aligned_alloc()相似的语义，从堆分配具有指定对齐要求的内存。一个小区别是：k_aligned_alloc()接受任意非零size，而aligned_alloc()只接受为align整数倍的size。

这里的aligned_alloc()指C11标准（ISO/IEC 9899:2011）第7.22.3.1节“aligned_alloc函数”，第347—348页。

**参数（Parameters）**

| 名称／方向 | 说明 |
| --- | --- |
| `align` | 请求的内存对齐值，以字节为单位。 |
| `size` | 请求的内存大小，以字节为单位。 |

**返回（Returns）**：成功时返回所分配内存的地址，否则返回NULL。

> 译注——源码核对：当前实现检查附加堆指针头部后的大小是否溢出，失败返回NULL；按指定对齐返回用户地址，释放仍用k_free。它不等待，不能套用k_heap_aligned_alloc的timeout语义。

### `k_calloc()`

```c
void * k_calloc ( size_t nmemb, size_t size )
```

```c
#include <zephyr/kernel.h>
```

按数组方式从堆分配内存。

本例程提供传统calloc()语义，从堆内存池分配内存并将其清零。

**参数（Parameters）**

| 名称／方向 | 说明 |
| --- | --- |
| `nmemb` | 请求数组中的元素数量。 |
| `size` | 每个数组元素的大小，以字节为单位。 |

**返回（Returns）**：成功时返回所分配内存的地址，否则返回NULL。

> 译注——源码核对：当前实现先检查nmemb乘size溢出，随后调用k_malloc并对请求范围清零。系统堆入口没有等待参数，失败需由调用者处理；内存释放用k_free。

### `k_free()`

```c
void k_free ( void * ptr)
```

```c
#include <zephyr/kernel.h>
```

释放从堆分配的内存。

本例程提供传统free()语义。归还的内存必须先前由堆内存池分配。

ptr为NULL时，不执行任何操作。

**参数（Parameters）**

| 名称／方向 | 说明 |
| --- | --- |
| `ptr` | 指向先前分配的内存的指针。 |

> 译注——源码核对：当前实现从用户地址前读取所属堆记录，再调用sys_heap_free；只适用于带这种包装的分配，不能传入普通k_heap_alloc、栈对象、Slab块或任意偏移指针。NULL立即无操作；重复释放不合法。

### `k_heap_aligned_alloc()`

```c
void * k_heap_aligned_alloc ( struct k_heap * h, size_t align, size_t bytes, k_timeout_t timeout )
```

声明属性：`isr-ok`（允许从中断服务程序ISR调用）。

```c
#include <zephyr/kernel.h>
```

从k_heap分配按指定边界对齐的内存。

本例程的行为与k_heap_alloc()相同，区别是返回内存（如果有）的起始地址为指定对齐值的整数倍；对齐值以字节计，必须是2的幂。得到的内存可通过k_heap_free()归还给堆。

**参数（Parameters）**

| 名称／方向 | 说明 |
| --- | --- |
| `h` | 用于分配内存的堆。 |
| `align` | 对齐值，以字节为单位，必须是2的幂。 |
| `bytes` | 请求的字节数。 |
| `timeout` | 等待时间，或K_NO_WAIT。 |

**说明（Note）**：从中断服务程序（Interrupt Service Routine，ISR）调用时，timeout必须设为K_NO_WAIT。CONFIG_MULTITHREADING=n时，任何timeout都按K_NO_WAIT处理。

**返回（Returns）**：返回调用者现在可以使用的内存指针；若在超时前无法满足分配请求，则返回NULL。

> 译注——源码核对：当前对齐断言也允许0作为内部无额外对齐路径，但公开接口按原文使用2的幂。较强对齐可能增加分配开销；有效字节数与对齐要求要分别核对。ISR只能使用K_NO_WAIT；该接口返回的指针仍归还同一个k_heap。

<a id="ga22b83564e50ae6177388dfe63e32a512"></a>

### `k_heap_alloc()`

```c
void * k_heap_alloc ( struct k_heap * h, size_t bytes, k_timeout_t timeout )
```

声明属性：`isr-ok`（允许从中断服务程序ISR调用）。

```c
#include <zephyr/kernel.h>
```

从k_heap分配内存。

从堆拥有的内存区域分配并返回一个缓冲区。如果没有立即可用的内存，调用会在指定timeout期间阻塞，等待内存被释放；timeout可由标准超时API构造，也可使用K_NO_WAIT或K_FOREVER。如果超时前无法完成分配，则返回NULL。所分配内存的地址按指针大小的整数倍对齐。

**参数（Parameters）**

| 名称／方向 | 说明 |
| --- | --- |
| `h` | 用于分配内存的堆。 |
| `bytes` | 希望分配的块大小。 |
| `timeout` | 等待时间，或K_NO_WAIT。 |

**说明（Note）**：从中断服务程序（Interrupt Service Routine，ISR）调用时，timeout必须设为K_NO_WAIT。CONFIG_MULTITHREADING=n时，任何timeout都按K_NO_WAIT处理。

**返回（Returns）**：有效堆内存的指针，或NULL。

> 译注——源码核对：这是显式指定k_heap的分配接口，应用之后用同一堆的k_heap_free归还。当前实现持堆锁尝试分配，内存不足可等待；释放时唤醒等待者重新竞争，不为某个线程预留大小。多轮等待共用一次调用的截止时间。应申请正数大小：当前sys_heap对0返回NULL，带等待的包装仍可能进入等待，不能将零大小请求当作无条件立即返回。

### `k_heap_calloc()`

```c
void * k_heap_calloc ( struct k_heap * h, size_t num, size_t size, k_timeout_t timeout )
```

声明属性：`isr-ok`（允许从中断服务程序ISR调用）。

```c
#include <zephyr/kernel.h>
```

从k_heap为对象数组分配并初始化内存。

为包含num个对象、每个对象大小为size的数组分配内存，并把分配区域中的全部字节初始化为0。如果没有立即可用的内存，调用会在指定timeout期间阻塞，等待内存被释放；timeout可由标准超时API构造，也可使用K_NO_WAIT或K_FOREVER。如果超时前无法完成分配，则返回NULL。所分配内存的地址按指针大小的整数倍对齐。

**参数（Parameters）**

| 名称／方向 | 说明 |
| --- | --- |
| `h` | 用于分配内存的堆。 |
| `num` | 要分配的对象数量。 |
| `size` | 希望分配的每个对象的大小。 |
| `timeout` | 等待时间，或K_NO_WAIT。 |

**说明（Note）**：从中断服务程序（Interrupt Service Routine，ISR）调用时，timeout必须设为K_NO_WAIT。CONFIG_MULTITHREADING=n时，任何timeout都按K_NO_WAIT处理。

**返回（Returns）**：有效堆内存的指针，或NULL。

> 译注——源码核对：当前实现先检查num乘size是否溢出；溢出返回NULL且不尝试等待。成功分配后仅将请求的乘积字节数清零，不表示额外可用容量也被清零。应使用有效的正数大小，并把零大小与普通内存不足区分。

<a id="ga6cf917a0b3d91a0101192bd4808ada9c"></a>

### `k_heap_free()`

```c
void k_heap_free ( struct k_heap * h, void * mem )
```

```c
#include <zephyr/kernel.h>
```

释放由k_heap_alloc()分配的内存。

将指定内存块归还给堆，供其他调用者使用；该块必须先前由k_heap_alloc()返回。允许传入NULL，此时没有效果。

**参数（Parameters）**

| 名称／方向 | 说明 |
| --- | --- |
| `h` | 要归还内存的堆。 |
| `mem` | 有效内存块，或NULL。 |

> 译注——源码核对：显式堆分配必须归还原堆，不能混用k_free。当前实现释放后唤醒该堆全部等待者重新尝试；这不保证每个等待者都能满足请求，也不清零数据。NULL不释放任何块；包装仍可能执行等待者唤醒，不能把“无效果”扩大理解为完全不涉及调度。

<a id="ga9273e06dc8d6a351499f2f5abfdcb39f"></a>

### `k_heap_init()`

```c
void k_heap_init ( struct k_heap * h, void * mem, size_t bytes )
```

```c
#include <zephyr/kernel.h>
```

初始化k_heap。

在用户指定的内存区域上构造一个带同步保护的k_heap对象。虽然可以传入任意对齐和大小的有效参数，但内部sys_heap的对齐约束意味着，并非所有字节都能用作可分配内存。

**参数（Parameters）**

| 名称／方向 | 说明 |
| --- | --- |
| `h` | 待初始化的堆结构。 |
| `mem` | 指向内存的指针。 |
| `bytes` | 内存区域大小，以字节为单位。 |

> 译注——源码核对：调用者提供实际有效的区域，其大小还要容纳sys_heap元数据、尾部标记及对齐损耗。原文的“任意对齐和大小”不表示任意小甚至空区域都合法：本次sys_heap_init包含最小容量断言和架构容量边界。该函数不返回状态码，不能用它覆盖仍有存活分配或等待者的堆。

### `k_heap_realloc()`

```c
void * k_heap_realloc ( struct k_heap * h, void * ptr, size_t bytes, k_timeout_t timeout )
```

声明属性：`isr-ok`（允许从中断服务程序ISR调用）。

```c
#include <zephyr/kernel.h>
```

从k_heap重新分配内存。

从堆拥有的内存区域重新分配并返回一个缓冲区。如果没有立即可用的内存，调用会在指定timeout期间阻塞，等待内存被释放；timeout可由标准超时API构造，也可使用K_NO_WAIT或K_FOREVER。如果超时前无法完成分配，则返回NULL。重新分配的内存按指针大小的整数倍对齐。

**参数（Parameters）**

| 名称／方向 | 说明 |
| --- | --- |
| `h` | 用于分配内存的堆。 |
| `ptr` | 先前分配返回的原始指针。 |
| `bytes` | 希望分配的块大小。 |
| `timeout` | 等待时间，或K_NO_WAIT。 |

**说明（Note）**：从中断服务程序（Interrupt Service Routine，ISR）调用时，timeout必须设为K_NO_WAIT。CONFIG_MULTITHREADING=n时，任何timeout都按K_NO_WAIT处理。

**返回（Returns）**：返回调用者现在可以使用的内存指针，或NULL。

> 译注——源码核对：正数bytes下，底层可原地调整或复制到新块；失败时保留原块，因此先用临时指针接收结果，成功后再替换。普通realloc不承诺保留此前额外指定的更强对齐。另需注意当前零大小路径：非NULL的ptr传给sys_heap_realloc且bytes为0时，底层已释放并返回NULL；k_heap_realloc的可等待循环仍把NULL当作未成功并可能再次使用原ptr。此组合不能当作可靠的释放用法，应明确调用k_heap_free；这是本次源码对照结论，未作运行复现。

### `k_malloc()`

```c
void * k_malloc ( size_t size)
```

```c
#include <zephyr/kernel.h>
```

从堆分配内存。

本例程提供传统malloc()语义，从堆内存池分配内存。所分配内存的地址按指针大小的整数倍对齐。

**参数（Parameters）**

| 名称／方向 | 说明 |
| --- | --- |
| `size` | 请求的内存大小，以字节为单位。 |

**返回（Returns）**：成功时返回所分配内存的地址，否则返回NULL。

> 译注——源码核对：当前系统接口从_system_heap分配，无timeout参数，不等待内存。mempool.c在返回的用户地址前保存所属堆指针，用于k_free定位；因此不能把该用户指针直接传给普通k_heap_free。它与线程resource_pool选用的z_thread_malloc不是同一个入口。

<a id="ga852a7a60dce5853b6925897b24a54e02"></a>

### `k_realloc()`

```c
void * k_realloc ( void * ptr, size_t size )
```

```c
#include <zephyr/kernel.h>
```

扩展已有分配的大小。

返回一个新内存区域的指针，其内容与原区域相同，但分配大小不同。若能够原地扩展，则返回指针不变；否则把数据复制到新块，并按sys_heap_free()的方式释放旧块。如果请求大小小于原大小，则原地缩小该块，并把剩余内存归还给堆。如果新块分配失败，则返回NULL，旧块不会被释放或修改。

**参数（Parameters）**

| 名称／方向 | 说明 |
| --- | --- |
| `ptr` | 先前分配返回的原始指针。 |
| `size` | 请求的内存大小，以字节为单位。 |

**返回（Returns）**：返回调用者现在可以使用的内存指针，或NULL。

> 译注——源码核对：当前实现明确规定size=0时调用k_free并返回NULL；ptr=NULL且size非零时走k_malloc。正数size的失败保留原块，应该用临时指针接收结果。它按隐藏堆记录调整包装块，不与普通k_heap_realloc互换；移动后也不保证保留更强的原始对齐。
