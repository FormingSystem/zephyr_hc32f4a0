# 第2章\_内核堆结构

原文：[官方页面](https://docs.zephyrproject.org/latest/doxygen/html/structk__heap.html)。读取日期：2026-10-15；来源摘要见[来源记录](../SOURCES.md)。

> 译注——阅读位置：本册覆盖内核堆（Kernel Heap）、系统堆接口与固定块内存池（Memory Slab）。堆支持可变大小分配，Slab管理等大小块；各自的分配、释放、等待、对齐和统计规则不能混用。原始声明、宏展开、参数和返回值保留，源码条件另作译注。

## 2.1\_源码定位与版本边界

> 译注——阅读与源码边界：本结构由zephyr/kernel.h生成，内部sys_heap、锁和等待队列没有公开为可直接访问的成员。页面无成员表不表示结构为空；应用使用[内核堆公共接口](P001_内核堆公共接口.md)。

仓库相对定位：[kernel.h](../../../include/zephyr/kernel.h)、[kheap.c](../../../kernel/kheap.c)、[mempool.c](../../../kernel/mempool.c)、[mem_slab.c](../../../kernel/mem_slab.c)和[底层heap.c](../../../lib/heap/heap.c)。本次依据为[官方内核头文件](https://github.com/zephyrproject-rtos/zephyr/blob/main/include/zephyr/kernel.h)、[内核堆实现](https://github.com/zephyrproject-rtos/zephyr/blob/main/kernel/kheap.c)、[系统分配包装](https://github.com/zephyrproject-rtos/zephyr/blob/main/kernel/mempool.c)、[Slab实现](https://github.com/zephyrproject-rtos/zephyr/blob/main/kernel/mem_slab.c)及[底层堆实现](https://github.com/zephyrproject-rtos/zephyr/blob/main/lib/heap/heap.c)，摘要见[来源记录](../SOURCES.md)。
