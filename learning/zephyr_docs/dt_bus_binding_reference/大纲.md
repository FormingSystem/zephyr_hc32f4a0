# GPIO与SPI绑定常量及设备树宏工具参考大纲

本册完整翻译GPIO与SPI绑定常量、设备树宏工具包装头文件的参考页与源码浏览页。GPIO（通用输入／输出，General-Purpose Input/Output）常量描述逻辑有效电平、输出驱动、偏置和唤醒；SPI（串行外设接口，Serial Peripheral Interface）常量描述双工模式与帧格式。dt-util.h为DTS预处理提供宏工具包含入口。

先从参考页辨认配置项，再通过源码页核对位编码、展开和包含关系；详细API通过相对链接进入已译专题。源码译注区分逻辑与物理电平、标准与SoC标志、按位或合并和运行时硬件能力。原代码、注释、署名与许可证保留，专有名词中英文对照。完整范围见[全站进度](../PROGRESS.md)。
