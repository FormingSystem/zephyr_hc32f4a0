## 6.2\_可见注释译文（Comments）

1. 版权：Copyright (c) 2020 Gerson Fernando Budke；原署名邮箱与Apache-2.0许可证在代码中保留。

2. 此文件用于保持源码树内DTS的包含方式整洁，即只使用`#include <zephyr/dt-bindings/foo.h>`这种形式。`<zephyr/dt-bindings/dt-util.h>`包装`<zephyr/sys/util_macro.h>`，将全部基础宏定义提供给DTS预处理器（Preprocessor），为包含零个或多个元素的可变参数宏（Variadic Macros）等复杂构造提供必要基础。

3. 结束设备树绑定工具头文件的包含保护ZEPHYR_INCLUDE_DT_BINDINGS_DT_UTIL_H_。

## 6.4\_源码跟踪译注

> 译注——包装职责：dt-util.h没有重新实现宏工具，而是以dt-bindings路径包装包含zephyr/sys/util_macro.h，使设备树源文件（Device Tree Source，DTS）的包含路径保持统一。这里只提供预处理宏，不会自行解析绑定、选择板卡或生成设备树。

> 译注——可变参数宏：源码注释中的零个或多个元素描述宏工具支持的复杂预处理构造，不表示任意宏都接受任意参数数量。具体宏的参数与展开约束见已译宏工具参考；不要把此头文件的包含关系理解为可以在DTS中调用C函数。

> 译注——版本边界：本批记录三个绑定头文件、GPIO与SPI驱动公共头文件、宏工具头文件和两个公共绑定，共八份官方源码摘要；三个源码浏览页的非注释内容与读取的原始头文件一致。latest、滚动main与仓库参照版本不自动相同。相对链接用于源码跟踪，本次未生成设备树、构建固件或操作硬件。

头文件相对定位：[include/zephyr/dt-bindings/dt-util.h](../../../include/zephyr/dt-bindings/dt-util.h)，关联实现／接口：[include/zephyr/sys/util_macro.h](../../../include/zephyr/sys/util_macro.h)；[官方原始头文件](https://github.com/zephyrproject-rtos/zephyr/blob/main/include/zephyr/dt-bindings/dt-util.h)与[官方关联文件](https://github.com/zephyrproject-rtos/zephyr/blob/main/include/zephyr/sys/util_macro.h)的摘要见来源记录。去掉注释和展示空白后，本页代码与本次读取的原始头文件一致，不能推广到以后滚动更新的main或任意本地版本。
