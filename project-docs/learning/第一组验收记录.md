## 可复用的实验入口

[run.py](../../scripts/learning/run.py)构建仓库内的学习应用，并为每次执行建立独立短目录。
主机测试编排采用当前源码中的 Twister，目标测试采用 ztest；这两个工具名称及其分工在 T06 解释。
以下命令均在本项目根目录、已激活开发环境的终端运行：

```powershell
python scripts/learning/run.py test --app tests/learning/c_lifetime --variant normal
python scripts/learning/inspect_objects.py
python scripts/learning/run.py build --app tests/learning/first_evidence --board mps2/an386 --variant build_only
python scripts/learning/run.py build --app tests/learning/first_evidence --board uyup_rpi_a/hc32f4a0pitb --variant hc32_build
python scripts/learning/run.py test --app tests/learning/first_evidence --variant normal
python scripts/learning/run.py test --app tests/learning/first_evidence --variant fault --extra-conf fail.conf
python scripts/learning/run.py test --app tests/learning/first_evidence --variant recovered
```

故障命令预期返回非零，执行脚本时应单独读取和断言其退出码，再进入恢复步骤。
不要把这一组命令无条件当作“每条都必须返回零”的批处理。
HC32 只构建命令通过后执行镜像布局审计，没有自动下载、连接探针或运行目标固件。

入口还核对实际工具版本、应用路径、源码根、编译器、目标配置及程序文件存在性。
准备失败也会把最新结果标成失败；零用例、过滤、跳过和仅构建都不会被测试入口接受为全部运行通过。
命令超时会清理该入口启动的进程树，并记录超时和清理结果；没有确认清理完成时不采集仍可能变化的产物摘要。
这些是主机工具的保证，不能替代每个实验自身的契约与断言。
