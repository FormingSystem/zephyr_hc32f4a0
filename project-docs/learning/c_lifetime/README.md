# T02：嵌入式 C 的对象与生命期

把三个采样值交给另一个函数，究竟交过去了数值、保存数值的空间，还是进入那片空间的地址？
这个专题用一个完整小实验区分三者，帮助你在后续使用消息队列、回调和设备驱动时判断数据还是否有效。
这里 C 是编程语言名称；**对象（Object）** 是运行中保存数据的一片存储，
**生命期（Lifetime）** 是这片存储被保证留给该对象使用的时间范围。

前置要求是会写简单 C 函数，能阅读整数赋值、条件判断和循环；其余术语在正文逐步解释。
阅读路线中的 T01 是项目为专题分配的稳定编号，不是技术缩写。
